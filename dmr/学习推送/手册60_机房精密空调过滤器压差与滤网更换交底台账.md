## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **滤网/过滤器台账钉死**：机型·级次·位置·备件角色入账（编号脱敏）；禁「看着干净就算过」「口头说滤网正常」。  
2. **换网有主有窗有方法/准用期**：更换窗·到场角色·更换前后ΔP核对等以本网与 OEM 书面为准；每次滤网更换有主人角色、有书面窗、有方法、有准用期；禁「口头换过」「滤网还在当窗过」「外观干净当更换窗过」。  
3. **压差与更换边界窗与方法钉死**：书面固定；方法含更换前后ΔP/门限核对、与 AU/AI/AT/AO/AD/N 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明逐步绕联锁/旁通滤网/不安全带电违章操作教条；**不重写 AU 气流组织全文**）；禁「窗再说」「绕压差联锁」「擅自旁通滤网冒充更换过」「不安全带电违章」「伪造台账」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、更换表、压差表必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「精密空调过滤器压差与滤网更换准用」；假绿 ≠ 放行。  
6. **禁顶替 AU/AI/AT/AO/AD/AN/AA/N/AQ/AZ/BE/BD/AX/AY/BF/BB/BA/AW/AS/AF/AV/AR/AG/AP/AJ/AK/AH/AL，主贴 BG，假绿≠放行挂 R**：气流组织签、温湿度签、冷凝加湿签、漏水签、仪表/备件签、门禁签、首年签、监控签、视频签、冷通道签……都不顶本期滤网更换签。**尤其：AU ≠ BG，AI ≠ BG，AD ≠ BG，N ≠ BG；AU过≠本期滤网更换窗过；外观干净≠更换窗过；压差绿≠更换准用。**  
7. **滤网堵塞/压差异常/更换窗乱签风暴挂 N，更换窗/压差门限/滤网策略变更走 J，禁功率战；禁绕压差联锁；禁旁通滤网冒充更换过；禁不安全带电违章；禁伪造台账**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/精密空调序列号全文/可还原坐标与联系人；禁公开传播未脱敏压差门限与参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签滤网更换准用、无实测冒充边界过、绕联锁/旁通滤网/不安全带电违章冒充秩序齐，不是法外运维智慧**。医院/数据中心 CRAC 滤网更换与压差公开资料只作故事与方法类比（§2.2）：**账要约、换要窗、差要法、验要本期、外观干净不算过、滤网还在不算窗过、口头换过不算方法过、压差绿不算更换准用、旁通滤网不算办法**——翻译成本网语言就是 BG-账 / BG-换 / BG-差 / BG-验 / BG-治。**这些是滤网更换交底秩序，不是「看着干净就签」「口头换过当过」「抬功率压告警」「旁通滤网先过」「绕联锁冒充」「带电违章冒充」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「精密空调过滤器压差与滤网更换准用」、对外宣传「看着干净/口头换过/滤网还在/压差绿秒过」、把未实测写成已过、把旁通滤网/绕联锁/带电违章写成秩序齐。允许做的：补滤网台账、补更换窗、重开压差边界窗、挂 R/N/J、内部挂整改。

## 6. 工作实例（12 则，教学虚构，L3）

1. **看着干净想签准用**：运维称滤网看着干净要签更换准用 → 查 BG1，无滤网台账本期核对 → **拒签**；补 BG-账。  
2. **口头换过 / 滤网还在当窗过**：外包称「换过了 / 滤网还在」免窗页 → **拒签**；补 BG-换 主人/窗/方法/准用期。  
3. **AU 顶替 BG**：班长用 AU 滤网压差气流签顶本期滤网更换签 → **挂 R**；主贴仍 BG；**AU过≠本期更换窗过**。  
4. **AI / AT 顶替**：站务称温湿度与冷凝加湿过了更换免做 → **拒签顶替**；AI≠BG、AT≠BG。  
5. **N 绿免实测**：大屏监控绿，本期更换/压差实测免 → **拒签**；N绿≠BG过；补 BG-验。  
6. **套邻站表**：外包拷邻站更换/压差表改机房号 → **BG-验 拒签重测**；禁套。  
7. **功率战**：滤网堵塞/高温告警，网优要抬功率 → **禁功率战**；先挂 N；缺秩序整改贴 BG；气流组织另问 AU。  
8. **旁通滤网冒充**：外包拆旁通滤网消告警后要求更换准用 → **禁**；挂 N/R；禁签。  
9. **绕压差联锁**：新人绕开压差高告警联锁再要求准用 → **禁**；挂整改；主贴 BG-治。  
10. **AD / AZ / BF 混签**：环境班称 AD 入库与 AZ 冷通道、BF 接地过了，更换免 → **拒签**；AD≠本期窗、AZ≠BG、BF≠BG。  
11. **不安全带电违章**：外包未授权带电拆滤网要求准用 → **禁**；挂 N/R；禁签。  
12. **泄密发群**：新人公开群贴真实精密空调序列号与压差门限 → **L3 违规**；脱敏重发；挂 BG-治。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **BG** 五子类：账 / 换 / 差 / 验 / 治——双字母续写在 BF 之后的第一张 **BG**，负责精密空调过滤器压差与滤网更换「台账清不清、更换有没有窗、压差与更换边界有没有法、本期过了没有」。  
- 口诀：**滤网有账，换网有窗，压差有法，会签才放。**  
- 故事：医院手术室/ICU / 数据中心 CRAC/CRAH 空气过滤器更换 + 更换前后压差（ΔP）——外观干净≠更换窗过；滤网还在≠窗过；口头换过≠方法过；压差绿≠更换准用。  
- 八条硬规则：**滤网台账钉死**；**换网有主有窗有方法/准用期**；**压差与更换边界窗与方法钉死**；**本期实测禁套**；**会签才放行**；**禁顶替 AU/AI/AT/AO/AD/AN/AA/N/AQ/AZ/…，主贴 BG，假绿≠放行挂 R**；**异常风暴挂 N、变更走 J、禁功率战/绕联锁/旁通滤网冒充/不安全带电违章/伪造台账**；**脱敏 L3**。  
- **BG 不替代 AU，也不替代 AI，也不替代 AD，也不替代 N**：AU=滤网压差气流组织；AI=温湿度联锁；AD=备件仪表准用；BG=滤网更换专项·更换前后ΔP准用。**AU ≠ BG；AI ≠ BG；AD ≠ BG；N ≠ BG。本篇不重写 AU 气流组织全文。**
