## 1. 为什么要写这篇手册（动机 + 现场对话）

前十二篇手册教你认病与交维：贴纸 A–E 协议层，F 射频层，G 实验室闭环，H 话务，I 室分/隧道，J 写频/基线，K 电源/后备。可现场还有一类「病」——**不是今晚空口才坏，而是楼宇三维结构把射频路径掐断，交维那天只测了走廊**：

- 保安：「电梯里一关门就没声，开门又好了。」——有人立刻挂手册02；没人先做门开/门关对照与井道路径证明。  
- 班长：「地下 B2 没信号，肯定是同频干扰。」——车库混凝土+钢筋像法拉第笼；手册07 气质有，**主因却可能是 L-库**。  
- 施工队：「交维走廊走测过了，可以签。」——电梯厅门、轿厢中运行、车库每层、坡道全没测；签字后第三天投诉刷屏。  
- 物业：「井道归电梯公司，无线归你们，车库室分归另一家。」——三家口头边界，出事时没人认；**L-交 空着**。  
- 射频同事：「加一点基站功率，电梯就亮了。」——功率是手册07/09/10 的禁区补丁；井道黑洞要用路径证明，不是用瓦数掩盖。  
- 话务同事：「忙时电梯里掉话，要加信道。」——其实是门关衰减 + 井道无泄漏/无厅门天线；手册09 气质有，**主贴仍是 L**。  
- 新人：「那不就是手册10 的 I-覆 吗？」——对，症状可以挂 I-覆，但**电梯井·地下车库要的是专项验收剧本与边界责任**，不是事后笼统「室分走测」叙事。

这几句背后是同一件事：

> **「电梯井 / 地下车库」这个词在现场至少有五个坑**：  
> **① L-井**：井道射频路径——泄漏同轴 / 厅门天线 / 层间黑洞 / 井道无源断点  
> **② L-库**：地下车库 DAS / 泄漏 / 停车层 / 坡道——层间混凝土屏蔽、车辆满停改变多径、远端失电  
> **③ L-门**：轿厢金属笼 + 厅门/轿门关闭衰减——门开尚可、门关数字悬崖  
> **④ L-切**：罐笼升降或坡道行驶时的重选/猎站毛刺——扇区边界穿过井道、门关瞬间切换失败  
> **⑤ L-交**：交维边界——楼宇室分商 / DMR 信源方 / 物业消防无线 / 电梯维保；签了等于签了一份说不清的三维覆盖债  
> 把 ①–⑤ 当成「干扰再慢慢查」或「先用手册07/09 分诊」，会把整栋楼的井道与车库债留给下一班，并污染空口病历。

本篇目标：能背出**电梯井·地下车库专项交维工作流**；会用新贴纸 **L（电梯井/地下车库）** 与五个子类；会填 **插页 L（R1–R8）** 和《本网电梯井·地下车库专项交维卡》；能用「**矿井罐笼 + 地下矿层停车场**」故事讲清井道/轿厢/厅门/车库层/坡道；能拒绝「只测走廊不测井道与车库、加功率掩盖黑洞、门开门关不对照」；自测过关后，回库把本网最近一次电梯/车库相关事件（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：不发明 ETSI 条款号；**不写真实批复频点、真实楼宇/站号、真实个号、真实密钥、真实单位名进公开仓库**；不重写手册07 / 08 / 09 / 10 / 11 / 12 全文（只给指针）；**不把「加功率 / 开大直放站增益」当井道或车库黑洞补丁**；井道/车库症状可**挂**手册07 F、手册10 I、手册01/02 A/B 气质，但**主贴 L**，禁止把结构射频病写成协议玄学；结案词用贴纸 L + 本网证据；公开楼宇 DAS / 泄漏电缆 / 电梯井覆盖工程常识可对齐公开工程指南的**精神**——**不背标准条款号当 ETSI**。

## 2. 总图 / 故事：大楼像「矿井罐笼 + 地下矿层停车场」

### 2.1 一句话：交维 = 先证明「罐笼在井道里全程有灯、每层矿层有灯、下坡道不黑、门关也有灯、谁管哪段灯写清」，再签字

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  矿井（本网楼宇电梯井 + 地下车库）                              │
   │                                                              │
   │   罐笼 = 电梯轿厢（金属笼子；门开/门关衰减差巨大）               │
   │   井筒 = 电梯井道（泄漏同轴 / 厅门天线 / 层间黑洞）              │
   │   地下矿层 = 停车库 B1/B2/…（混凝土+钢筋法拉第笼）               │
   │   螺旋坡道 = 出入坡道（行驶中重选/猎站）                        │
   │                                                              │
   │   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐     │
   │   │ 井道路径 │──▶│ 厅门/层间 │──▶│ 轿厢内部 │──▶│ 业务可达 │     │
   │   │ (L-井)  │   │ (L-井)  │   │ (L-门)  │   │ (金机)  │     │
   │   └────┬────┘   └────┬────┘   └────▲────┘   └────┬────┘     │
   │        │             │             │              │           │
   │        │断点/进水     │层间黑洞      │门关衰减      │症状可挂   │
   │        ▼             ▼             │              │F/I/A/B   │
   │   ┌─────────┐   ┌─────────┐       │              │但主贴 L  │
   │   │ 车库层  │◀──│ 坡道行驶 │───────┘              │           │
   │   │ (L-库)  │   │ (L-切)  │  猎站毛刺也要证据      │           │
   │   └─────────┘   └─────────┘                       │           │
   │        ▲                                          ▼           │
   │   谁管井道灯 / 谁管车库灯 / 谁管信源 = 交维边界（L-交）         │
   │   只测走廊 = 只在地面办公室量亮度就说矿井交接完成              │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **井道要有连续灯；轿厢门关也要亮；车库每层都要测；坡道行驶不能黑；签字前边界写清。**  
> 只测「一楼大厅有信号」就签字 = 只在矿井办公室量亮度就说罐笼交接完成。  
> 门一关数字悬崖 = 罐笼门封死后灯灭——**先查井道灯与门衰减，别先改病人药方（加功率）**。

### 2.2 「矿井三维覆盖」五段直觉（弱项短补，钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **井道路径** | 矿井井筒里的照明电缆/泄漏灯带 | 泄漏同轴是否通、厅门天线是否在位、DTF/VSWR、层间有无黑洞 | L-井 |
| **车库层** | 地下矿层巷道 | 每层走测、满车/空车差异、远端电源、坡道入口过渡 | L-库 |
| **门衰减** | 罐笼门封闭 | 门开 vs 门关对照；金属轿厢法拉第效应 | L-门 |
| **运动切换** | 罐笼升降 / 矿车下坡 | 重选/猎站毛刺、扇区边界是否穿过井道、坡道行驶连续 | L-切 |
| **交维边界** | 矿井分包合同 | 室分商 / DMR 信源 / 物业消防无线 / 电梯维保谁管哪段 | L-交 |

> 公开工程常识（泄漏/辐射电缆用于隧道与井道、厅门天线「尽力照进轿厢」、地下车库厚混凝土+钢筋屏蔽、高速升降时扇区边界会制造切换毛刺等）：本篇只借**顺序直觉**——先证明路径存在 → 再门开/门关对照 → 再运动中走测 → 再边界签字。**不背厂商菜单 / 国标条款号当 ETSI**。

### 2.3 和手册07 / 08 / 09 / 10 / 11 / 12 的咬合（指针，不重写）

- **手册07 贴纸 F**：覆盖/同频干扰五格梯子；井道/车库黑洞可引起「假 F-弱 / 假 F-同」气质——**先贴 L，再决定要不要进梯子**。  
- **手册08 贴纸 G**：实验室闭环；本篇金机走测的「刺激→观察→判定→证据包」**调用** G 的气质，不重写六闭环。  
- **手册09 贴纸 H**：话务/容量；井道/车库盲区会造成「假忙时 / 假容量」——禁「加信道/加功率」当结构补丁。  
- **手册10 贴纸 I**：室分/隧道交维；本篇是 **I-覆 的加深专项册**——电梯与车库从「抽测一句」升级为完整剧本。  
- **手册11 贴纸 J**：写频/金机；金机必须按本篇路径走完，才谈 J-验；别把井道盲当写频失败。  
- **手册12 贴纸 K**：电源；车库有源远端/井道有源设备掉电 → 先问 K，再回来 L。  
- **手册01 / 02**：门关/升降窗可出现短时登记失败 / Grant 无声——**挂**气质，**主贴 L**。  
- **手册06**：三联单证据五要素；电梯/车库事件尤其要对时（走测时刻、网管告警、物业投诉同一窗口）；脱敏到 L3。

### 2.4 新贴纸 L：电梯井 / 地下车库（五个子类）

```text
                    ┌──────── 贴纸 L · 电梯井/地下车库 ────────┐
                    │  L-井  井道射频路径 / 泄漏 / 厅门天线 / 层间 │
                    │  L-库  地下车库 DAS·泄漏·停车层·坡道入口   │
                    │  L-门  轿门/厅门开闭衰减 / 金属轿厢        │
                    │  L-切  升降/坡道运动中重选·猎站毛刺         │
                    │  L-交  交维边界 / 室分·信源·物业·电梯维保   │
                    └──────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签 / 拒放行触发 |
|------|--------|----------------------|
| **L-井** | 井道有可证明的连续射频路径 | 无泄漏/厅门方案照片；层间黑洞未闭环；井道 VSWR/DTF 空 |
| **L-库** | 车库每层 + 坡道可金机证明 | 只测 B1 不测 B2；满车未抽测；远端失电未查 |
| **L-门** | 门开与门关对照必须做 | 只开门测；门关数字悬崖仍签字 |
| **L-切** | 升降中与坡道行驶中连续可接受 | 从未做中运行走测；扇区边界穿过井道无记录 |
| **L-交** | 室分/信源/物业/电梯维保谁管写清 | 「井道归电梯公司」口头一句；备件与巡检周期空 |

**和贴纸 A–K / X 的咬合**：

- 电梯/车库结构射频异常期间**优先 L**；空口症状可挂 A/B/F/I/H，但结案词须写清「主贴 L + 次挂××」。  
- 室分总包气质挂 **I**；电源导致远端掉挂 **K**；实验室/金机锚挂 **G/J**。  
- 贴纸 **X**：只有「电梯里好像差点」的口述、无门开/门关对照与井道/车库走测表时，先 X，**禁止结案为干扰/容量/终端玄学，禁止签字**。

### 2.5 电梯井·地下车库专项最小工作流（背下来）

```text
  ① 开交维/专项单（L-交）：楼宇逻辑分区、谁签字、窗口、影响范围（脱敏）
  ② 读现状（L-井/L-库）：竣工点位表有无井道/车库？泄漏或厅门天线照片？车库远端状态？
  ③ 禁令检查：是否只测走廊？门开/门关是否打算跳过？有人要加功率？→ 停
  ④ 路径证明（L-井/L-库）：井道 VSWR/DTF（若有泄漏）；车库分支扫线；口功率/噪底抽检（调用 I 气质）
  ⑤ 金机剧本（L-门/L-切）：每层厅门 → 轿厢门开/门关 → 中运行升降 → 车库每层 → 坡道行驶
  ⑥ 证据包：插页 L、走测表、门开/门关对照、拒签或放行结论（脱敏 L3）
  ⑦ 过 → 更新交维卡与巡检周期；不过 → 拒签；禁止用加功率掩盖
```

## 3. 核心交付：插页 L + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 L（而不是先贴 A–F / H / I）

优先贴 **L** 的触发（命中一条就先走本篇）：

1. 电梯轿厢内断话、某几层厅门黑洞、井道无天线/泄漏方案。  
2. 地下车库某层无信号、坡道进出掉话、满车后覆盖变差。  
3. 「门开有、门关无」或未做门开/门关对照就要签字。  
4. 升降中或坡道行驶中猎站/重选毛刺成片。  
5. 交维「只测走廊」、电梯/车库未进点位表。  
6. 有人提议「加功率 / 开大直放站增益先照亮电梯」——**先 L 后**再决定是否挂 07/10。  
7. 边界口头「井道归电梯公司 / 车库归室分商」——**L-交**。

### 3.2 插页 L · 电梯井 / 地下车库（挂在总三联单或交维包首页后）

| 格 | 名称 | 你要填什么（脱敏 L3） |
|----|------|----------------------|
| R1 | 事件窗与对时 | 投诉时刻、走测时刻、网管告警是否同一时钟窗；对时差 |
| R2 | L 子类初判 | L-井 / L-库 / L-门 / L-切 / L-交（可多选，标主贴） |
| R3 | 井道路径 | 泄漏/厅门天线形态、VSWR·DTF 摘要、层间黑洞点（不写真实楼名） |
| R4 | 车库路径 | 每层点位数、远端状态、坡道入口、满车/空车抽测 |
| R5 | 门开/门关对照 | 同层同点：门开 RSSI·SYNC·BER vs 门关；差值与业务结论 |
| R6 | 运动剧本 | 升降中运行 / 坡道行驶：连续业务是否可接受；猎站毛刺记录 |
| R7 | 业务影响与次挂 | 是否出现登记/Grant/覆盖/话务气质；主贴仍写 L；次挂 F/I/A/B |
| R8 | 证据包清单 | 「插页 L；走测表；门对照；井道/车库曲线脱敏；拒签/放行；三联单号」 |

**插页组合**：L 常与 I（室分总包）、G（金机）、X（证据不足）、必要时 F/A/B（症状）同挂。**不要**把「井道没天线」写成「用户不会用机器」。

### 3.3 「未测井道/车库禁止签」卡（贴验收会议室 / 机房）

在插页 L 的 R3–R6 没填之前，下面这些话不许进交维窗：

> 「走廊走测过了，差不多。」  
> 「电梯里偶尔没声，开门就好，别管了。」  
> 「车库太暗太远，下次再测。」  
> 「井道归电梯公司，我们进不去。」（边界空 = L-交 拒签，不是免测理由）  
> 「先加功率照亮，交维过后再优化。」  
> 「门关测起来麻烦，只开门测吧。」

**拒签句式（背）**：

> 「插页 L 的 R5/R6 空着。先完成门开/门关对照 + 中运行升降 + 车库每层/坡道走测，再谈签字。加功率不是井道补丁。」

### 3.4 和总三联单怎么写（接手册06）

## 4. 深潜：八条硬规则 + 井道/车库射频直觉 + 假病禁令

### 4.1 八条硬规则（本篇钉子）

1. **先证明井道/车库射频路径，再写干扰或容量**——电梯/车库黑洞优先贴纸 L，禁止直接当纯 F 或纯 H。  
2. **禁止用加功率 / 开大直放站增益掩盖井道或车库黑洞**——功率是手册07/09/10 的禁区补丁，不是 L 的药。  
3. **金机走测强制包：每层厅门 + 轿厢中运行 + 车库每层 + 坡道**——少一项 = 未交维。  
4. **门开 vs 门关必须对照**——只开门测 = 拒签（L-门）。  
5. **边界写清再签字（L-交）**——楼宇室分 / DMR 信源 / 物业消防无线 / 电梯维保；口头「归××」不算。  
6. **对时与三联单五要素仍适用（指针手册06）**——走测、投诉、网管必须同一窗；脱敏到 L3。  
7. **症状可挂 F（覆盖/干扰）、I（室分）、A/B（登记/Grant），但不得主写成协议玄学**——主贴 L。  
8. **脱敏到 L3**——公开仓与教学推送禁止真实频点、楼宇名、站号、个号、密钥、单位名。

### 4.2 井道 / 轿厢 / 车库射频直觉（不背厂商菜单）

```text
  地面大厅有信号
        │
        ▼
  厅门区域（门开）── 尚可？──否──▶ 查 I-覆 / L-井（厅门天线或泄漏耦合）
        │是
        ▼
  轿厢内门开 ── 尚可？──否──▶ L-井 / L-门（耦合不够）
        │是
        ▼
  轿厢内门关 ── 尚可？──否──▶ L-门（金属笼衰减）+ 查井道路径是否「只靠门缝泄漏」
        │是
        ▼
  中运行升降（门关）── 连续？──否──▶ L-切 / L-井（层间黑洞、扇区边界）
        │是
        ▼
  车库每层 + 坡道行驶 ── 过？──否──▶ L-库 / L-切
        │是
        ▼
  边界书面（L-交）→ 可谈签字
```

现场口诀：

> **先路径，再门对照，再运动，后边界。**  
> 交维若跳过门关与中运行，等于没把罐笼放进井筒就签字。

### 4.3 专项剧本最低验收包（L-门 / L-切 心脏）

| 步骤 | 要看到什么 | 不过怎么办 |
|------|------------|------------|
| 点位表含井道/车库 | 设计测点含厅门、轿厢、每车库层、坡道 | 补点位；拒签「只测走廊」 |
| 井道/车库路径证明 | 泄漏或厅门方案可指认；必要 VSWR/DTF | L-井/L-库；开口项书面 |
| 门开对照 | 同层门开：金机梯子（能量→SYNC→身份→BER→业务） | 先修路径，不谈签字 |
| 门关对照 | 同层门关：同上；记录衰减差 | 门关失败 = L-门 拒签项 |
| 中运行升降 | 从最低到最高（或抽样连续段）门关行驶 | 层间黑洞记 R3/R6 |
| 车库每层 | 空车抽测 + 条件允许时满车抽测 | 只测一层 = 拒签 |
| 坡道行驶 | 进出坡道连续业务可接受 | L-切；查扇区边界 |
| 边界与证据 | L-交 书面；插页 L R1–R8 | 口头三家不管 = 拒签 |

### 4.4 「假覆盖 / 假干扰 / 假容量 / 假协议」怎么认

| 假病外表 | 常见井道/车库真因 | 错误处置 | 正确主贴 |
|----------|-------------------|----------|----------|
| 假覆盖（F-弱气质） | 井道无路径、车库层屏蔽、门关衰减 | 加功率、加直放站增益 | L-井/L-库/L-门 |
| 假干扰（F-同气质） | 门关瞬间 BER 跳、升降层间毛刺 | 扫「同频」几天 | L-门/L-切（次挂 F） |
| 假容量（H 气质） | 多部电梯/车库盲区造成掉话账假坏 | 加信道、拧 Hangtime | L（次挂 H） |
| 假登记/假 Grant | 升降/门关窗短时协议症状 | 立刻改写频/鉴权 | L（次挂 A/B） |
| 假室分总包过关 | 走廊 I-覆 过、井道/车库未测 | 直接签手册10 | 本篇 L 拒签 |

**三问快判（背）**：

1. **路径**：井道/车库有没有可指认的天线或泄漏？（R3/R4）  
2. **门**：门开/门关对照做了没有？（R5）  
3. **运动**：中运行升降与坡道行驶测了没有？（R6）  

三问里有「否」，就**先写 L**；三问全「是」且有持续同频/容量证据，再进手册07/09。切记：门关「抖一下又好」优先是 L-门/L-切 的结构副作用，不是先开同频工单。

### 4.5 泄漏 · 厅门天线 · 车库形态：现场只记「量级直觉」

| 对象 | 你要会问的三句话 | 常见坑 |
|------|------------------|--------|
| 井道泄漏同轴 | 有没有装？两端能否扫？进水/接头？ | 「图纸有」代替实物照片与 DTF |
| 厅门天线 | 每隔几层一副？门关能否耦进轿厢？ | 只在大堂放一副指望照亮全井 |
| 轿厢金属笼 | 门关衰减实测多少气质？ | 用门开数据签字 |
| 车库泄漏/天线 | 每层巷道是否连续？分支有无断？ | 只测坡道口，不进车位深处 |
| 有源远端 | 是否在线？电源是否稳（指针 K）？ | 远端掉电当「覆盖玄学」 |
| 扇区边界 | 井道/坡道是否被扇区缝劈开？ | 升降中疯狂猎站仍说「终端问题」 |

> 教学楼不要抄真实阈值进公开仓。本网门关衰减门限、走测点密度、BER 阈值，写在**本网交维卡**（脱敏），不写进本篇正文当「全世界标准」。

### 4.6 和弱项加餐的衔接

12.5 kHz / 4FSK / 30 ms 两槽背熟，你才说得清：**井道/车库改的是「路径与衰减」，不是「调制台阶」**。有人要用加功率治电梯黑洞时，回加餐 + 手册07/09/10 + 本篇八条硬规则。

### 5.2 对话脚本（六则）

**脚本 A · 交维只测走廊**

> 对方：「一楼到顶层走廊金机都过了，签吧。」  
> 你：「插页 L 的 R3–R6 空着。请做厅门 + 轿厢门开/门关 + 中运行 + 车库每层/坡道。只测走廊不算本专项交维。」

**脚本 B · 门关假干扰**

> 对方：「门关 BER 跳了，按手册07 扫同频。」  
> 你：「先做同层门开/门关对照。主贴 L-门；梯子可以挂，但加功率禁止。」

**脚本 C · 加功率掩盖**

> 对方：「基站功率加 3 dB，电梯就有了。」  
> 你：「八条硬规则第 2 条。加功率不是井道药。先证明路径与门对照，再谈射频优化。」

**脚本 D · 边界口头推诿**

> 对方：「井道归电梯维保，车库室分归甲公司，我们只管信源。」  
> 你：「L-交 拒签。交维卡上要有书面边界：谁管井道器件、谁管车库分支、谁管 DMR 信源、谁收投诉。口头三家不管 = 事故预告。」

**脚本 E · 假容量要加信道**

> 对方：「上班高峰电梯里掉话，按手册09 加信道。」  
> 你：「先把掉话时刻和门关/升降窗、车库层对齐。若对齐，主贴 L，次挂 H；结构盲区时加信道是假账。」

**脚本 F · 只开门测**

> 对方：「门关测起来要协调电梯，太麻烦，开门数据也行。」  
> 你：「L-门 拒签。罐笼门封死后才是真实勤务状态。门关对照是强制项，不是可选项。」

### 5.3 反例墙（贴验收会议室）

1. 只测走廊就签字。  
2. 只开门测，不做门关对照。  
3. 电梯/车库未进点位表。  
4. 井道黑洞先加功率。  
5. 把「门关数字悬崖」写成终端玄学。  
6. 边界口头「归电梯公司」。  
7. 车库只测 B1 不测更深一层。  
8. 从未做中运行升降走测。  
9. 用公网 LTE 绿图代替 DMR 金机梯子。  
10. 证据不对时，硬写手册01/07 结案。

```text
3'  金机：就近一部电梯 — 门开 / 门关各一次业务
3'  若有车库权限：抽最深一层一个角 + 坡道口
```

### 5.5 单次专项交维 40 分钟标准节奏（可复印；高层/多层车库加倍）

```text
0–5'   开单 + 边界确认（L-交）+ 禁令宣读（禁加功率、禁只测走廊）
5–12'  读现状：点位表、井道方案照片、车库远端、上次走测（L-井/L-库）
12–28' 金机剧本：厅门抽样 → 门开/门关 → 中运行升降段 → 车库层/坡道（L-门/L-切）
```

带条件放行只允许「非关键、有时限、有责任人」的尾巴（例如某层厅门照片补传），**不允许**「门关未测 / 中运行未测 / 车库未测先签」。

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「电梯关门断话，开门恢复」→ L-门

现象：保安投诉「轿厢里一关门就没声」。  
观察：同层门开金机业务过；门关 BER 上悬崖；厅门有天线但耦合仅靠门缝。  
错法：换手台；加基站功率；结案「终端批量异常」。  
正法：主贴 L-门；次挂 F 仅作症状；插页 R5；推动井道路径增强或厅门方案复测；三联单写清门对照。

### 例 2 · 「某几层厅门黑洞」→ L-井

现象：5–7 层厅门无声，其它层尚可。  
观察：泄漏/厅门间距过大；5 层接头 VSWR 异常；点位表缺层间抽测。  
错法：按 F-弱 扫同频一周。  
正法：L-井；修接头/补点；层间走测进交维包。

### 例 3 · 「交维走廊过，第三天电梯投诉」→ L-井 / L-交

现象：签字后电梯投诉刷屏。  
观察：交维包无电梯测点；井道方案口头「以后加」。  
错法：「先观察」。  
正法：拒收历史包为完整交维；开 L-交 边界会；补剧本后重签。

### 例 4 · 「B2 无信号，B1 正常」→ L-库

现象：地下二层对讲困难。  
观察：B2 远端告警退出；或 B2 分支未接；空车测与满车测差大。  
错法：加信道；开大直放站增益。  
正法：L-库；查远端/分支（可挂 K 若电源）；每层走测强制。

### 例 5 · 「坡道行驶猎站乱跳」→ L-切

现象：车辆进出坡道掉话、机器人音。  
观察：坡道被两个扇区缝劈开；门禁闸机金属加重；未做行驶剧本。  
错法：改终端猎站参数先顶锅。  
正法：L-切；记录行驶窗；调整扇区边界或补覆盖（室分侧）；主贴 L。

### 例 6 · 「加功率照亮电梯」→ 禁令命中

现象：夜班把基站功率加大后电梯「好像好点」。  
观察：井道仍无路径照片；门关对照未做；邻层干扰投诉上升。  
错法：把加功率写进「优化措施」。  
正法：回退功率；主贴 L；引用硬规则第 2 条；对齐会通报反例。

### 例 7 · 「假干扰：升降中 BER 跳」→ L-切（次挂 F）

现象：罐笼升降时 BER 告警闪。  
观察：时序紧贴穿过某层无天线区；稳定停层后门关业务恢复。  
错法：开工单「排查同频」一周。  
正法：R6 记录；主贴 L-切/L-井；次挂 F；禁加功率。

### 例 8 · 「假容量：早高峰电梯掉话」→ L（次挂 H）

现象：上班高峰掉话，申请加信道。  
观察：掉话集中在门关升降窗；话务模型未饱和；「忙时」其实是「罐笼窗」。  
错法：手册09 直接加信道。  
正法：主贴 L；H 次挂；路径与门对照过关后再谈容量。

### 例 9 · 「假协议：升降窗登记失败」→ L（次挂 A）

现象：升降中短时登记失败刷屏。  
观察：与层间黑洞对齐；停层后自愈；金机实验室 G 全过。  
错法：按手册01 改终端参数。  
正法：主贴 L；次挂 A；修井道路径；J/G 作对照证明终端锚还在。

### 例 10 ·（对照）手册10 走廊 I-覆 过 vs 本篇 L 未过

现象：室分总包按手册10 走廊/口部签字；电梯与车库未做专项。  
观察：I 插页 R6 只写「电梯抽测口头 OK」。  
错法：认为手册10 已覆盖本篇。  
正法：本篇是 I-覆 加深专项；L 剧本未完成不得宣称「楼宇三维覆盖交维完成」。

```text
16–20' 边界：室分商 / 信源 / 物业 / 电梯维保联系人是否仍有效
```
