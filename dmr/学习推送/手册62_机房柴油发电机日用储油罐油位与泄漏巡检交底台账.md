## 1. 为什么要写这篇手册（动机 + 现场对话）

前六十一篇手册从 A–E 协议一路写到 BH 冷却水泵组与冷凝水侧：其中 **AR 回答「柴油发电机房通风排烟与燃油安全巡检边界」**（燃油安全窗里会提到油位·泄漏·通气·围堰，但没有单独给日用油箱**和**储油罐各钉一张油位/泄漏台账），**AV 回答「日用油箱油品净化与加油交接」**（看着有油 ≠ 油品合格），**AF 回答「油机市电切换与机房供电巡检」**，**AO 回答「漏水与接地汇流排探测」**（漏的是水，不是油），**AN / AL / AD / AA / N / AQ / BH** 各管门禁、气灭、备件、首年巡检、监控风暴、视频证据与冷却水泵冷凝水侧。可还没有单独钉死一件事——**机房柴油发电机日用/储油罐油位与泄漏不是「看着有油 / 地面看着干 / 围堰看着在 / AR 燃油安全过 / AV 油品过 / AF 切换过 / AO 漏水探头过就能签」：日用油箱与储油罐的油位台账要各自钉死；泄漏侧要有主人有窗有方法有准用期；边界窗与方法要书面固定；本期实测禁套他站他期——能不能签「机房柴油发电机日用/储油罐油位与泄漏巡检准用」？** 这就是本篇的 **BI**——**机房柴油发电机日用/储油罐油位与泄漏巡检交底台账**（Excel 风格双字母：BH 之后 → **BI**）。

### 2.3 和手册45（AR）/ 49（AV）/ 33（AF）/ 42（AO）/ 41（AN）/ 39（AL）/ 15（N）等的咬合（指针，不重写）

- **AR（手册45）**：柴油发电机房通风排烟与燃油**安全**巡检；燃油安全窗会写到油位·泄漏·通气·围堰，但**没有**单独给日用油箱+储油罐一张油位/泄漏台账；**AR ≠ BI**——油箱看着有油 ≠ 燃油安全巡检过（AR 的钉），也 ≠ 油位台账过（BI 的钉）；燃油安全可挂 AR，油位/泄漏台账主贴仍 BI；**不得互相顶替**；**不重写 AR 全文**。  
- **AV（手册49）**：日用油箱油品、净化与加油交接；**AV ≠ BI**——油品报告过 ≠ 油位/泄漏窗过；看着有油 ≠ 油品合格（AV）并且看着有油 ≠ 油位台账过（BI）；**不重写 AV 全文**。

## 3. 核心交付：插页 BI + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 BI（而不是先贴 AR / AV / AF / AO / N）

- 要签「机房柴油发电机日用/储油罐油位与泄漏巡检准用」、要开油位交底窗、要交底泄漏侧（目视/油痕/探头/围堰/集油坑/油水分离） → **主贴 BI**。  
- 柴油发电机房通风排烟与燃油**安全** → **AR**（手册45）。**AR ≠ BI**；不重写 AR。  
- 日用油箱油品净化与加油交接 → **AV**（手册49）。**AV ≠ BI**；不重写 AV。  
- 油机市电切换与供电巡检 → **AF**（手册33）。**AF ≠ BI**。  
- 漏**水**探测与汇流排 → **AO**。**AO ≠ BI**（漏水探头 OK ≠ 漏油窗过）。  
- 进油机房做交底 → 先 **AN**；门禁过 ≠ 交底过。  
- 气灭疏散 → **AL**；气灭过 ≠ 油位/泄漏交底过。  
- 低油位/泄漏/窗乱签风暴 → 先 **N** 理风暴；缺秩序整改仍 **BI**；**禁功率战、不安全泄油、旁通、绕联锁**。  
- 假绿/顶替 → 挂 **R**；变更角色/窗方法/门限 → 走 **J** 后再验 BI。  
- 本站无日用油箱路径 → 日用油箱项书面勾「不适用」；储油罐侧单独勾选。  
- 本站无储油罐路径 → 储油罐项书面勾「不适用」；日用油箱侧单独勾选。  
- 本站无柴油发电机 → 两侧均可书面「不适用」；**不得**用 BI 顶 AR/AV/AF/AO，也不得用它们顶 BI。

### 3.4 与总三联单怎么写（脱敏 L3）

- **现象栏**：写「油位缺账 / 看着有油无核对 / 泄漏侧无窗 / 地面看着干当过 / 围堰看着在当过 / 口头不漏 / 日用油箱顶储油罐 / AR 顶油位泄漏 / AV 顶油位泄漏 / AF 顶油位泄漏 / AO 探头顶漏油窗 / 套票嫌疑 / 泄油/旁通嫌疑 / 绕联锁嫌疑」等角色化现象；**不写**真实机房全称、油箱序列号全文、可还原油位/泄漏门限全文。  
- **贴纸栏**：主贴 **BI**；邻贴指针 AR/AV/AF/AO/AN/AL/N/R/J 按需勾。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **油位台账钉死**：日用油箱与储油罐各自有账；液位计/浮球/高低油位告警角色入账（编号脱敏）；禁「看着有油就算过」「口头说油位正常」；日用油箱过 ≠ 储油罐过，储油罐过 ≠ 日用油箱过。  
2. **泄漏侧有主有窗有方法/准用期**：目视/油痕/探头/围堰/集油坑/油水分离等以本网与 OEM 书面为准；每次泄漏交底有主人角色、有书面窗、有方法、有准用期；禁「地面看着干当窗过」「围堰看着在当窗过」「口头说不漏」。  
3. **油位与泄漏边界窗与方法钉死**：书面固定；方法含与 AR/AV/AF/AO/AN/AL/N 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明逐步不安全泄油/旁通/绕联锁操作教条；**不重写 AR/AV/AF/AO 全文**）；禁「窗再说」「不安全泄油」「开旁通冒充」「绕油位/泄漏联锁」「伪造台账」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、日用油箱表、储油罐表、泄漏窗必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「机房柴油发电机日用/储油罐油位与泄漏巡检准用」；假绿 ≠ 放行。  
6. **禁顶替 AR/AV/AF/AO/AN/AL/AD/AA/N/AQ/AG/AP/AS/BH 等，主贴 BI，假绿≠放行挂 R**：燃油安全签、油品签、切换签、漏水探头签、门禁签、气灭签、备件签、首年签、监控签……都不顶本期油位/泄漏签。**尤其：AR ≠ BI，AV ≠ BI，AF ≠ BI，AO ≠ BI；油箱看着有油 ≠ 燃油安全巡检过；油品报告过 ≠ 油位/泄漏窗过；油机市电过 ≠ 油位泄漏过；漏水探头过 ≠ 漏油窗过；看着有油 ≠ 油位台账过；地面看着干 ≠ 泄漏窗过；围堰看着在 ≠ 泄漏窗过。**  
7. **油位异常/泄漏/窗乱签风暴挂 N，边界/门限/油位泄漏窗变更走 J，禁功率战；禁不安全泄油；禁旁通；禁绕联锁；禁伪造台账**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/油箱序列号全文/可还原坐标与联系人；禁公开传播未脱敏油位/泄漏门限与参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签油位/泄漏准用、无实测冒充边界过、不安全泄油/旁通/绕联锁冒充秩序齐，不是法外运维智慧**。医院/数据中心公开资料只作故事类比（§10），翻译成本网语言就是 BI-位 / BI-漏 / BI-界 / BI-验 / BI-治。

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机房柴油发电机日用/储油罐油位与泄漏巡检准用」、对外宣传「看着有油/地面干/围堰在/口头正常秒过」、把未实测写成已过、把不安全泄油/旁通/绕联锁写成秩序齐。允许做的：补油位台账、补泄漏窗、重开边界窗、挂 R/N/J、内部挂整改。

## 6. 工作实例（12 则，教学虚构，L3）

1. **看着有油想签准用**：称油箱看着有油要签 → 查 BI1 无本期台账核对 → **拒签**；补 BI-位。  
2. **地面看着干 / 围堰看着在 / 口头不漏**：称「地面是干的 / 围堰还在 / 班长说不漏」免窗页 → **拒签**；补 BI-漏。  
3. **AR 顶替 BI**：用燃油安全签顶本期油位/泄漏签 → **挂 R**；**燃油安全过 ≠ 油位/泄漏台账过**。  
4. **AV 顶替 BI**：称油品报告和加油交接刚过，油位泄漏窗免做 → **挂 R**；**油品报告过 ≠ 油位/泄漏窗过**。  
5. **AF 顶替 BI**：称油机市电切换过了，油肯定够 → **拒签**；**切换过 ≠ 油位泄漏过**。  
6. **AO 顶替 BI**：称漏水探头绿，漏油窗免 → **拒签**；**漏水探头过 ≠ 漏油窗过**。  
7. **N 绿免实测**：大屏监控绿，本期实测免 → **拒签**；N绿≠BI过；补 BI-验。  
8. **套邻站表**：拷邻站油位/泄漏表改机房号 → **BI-验 拒签重测**。  
9. **功率战**：低油位/泄漏告警，要抬功率 → **禁功率战**；先挂 N；缺秩序整改贴 BI。  
10. **不安全泄油 / 开旁通冒充**：泄油或开旁通消告警后要求准用 → **禁**；挂 N/R；禁签。  
11. **绕油位/泄漏联锁**：绕开低油位或泄漏联锁后要求准用 → **禁**；挂整改；主贴 BI-治。  
12. **日用油箱顶储油罐 / 无油机乱签 / 泄密**：称日用油箱签过故储油罐免，或无柴油发电机站点不写「不适用」却乱签准用，或公开群贴真实油箱编号 → **拒签顶替**并/或补书面不适用并/或 **L3 违规**；一侧不适用 ≠ 另一侧自动免。

### 参考答案

1. 位 / 漏 / 界 / 验 / 治；口诀：**油位有账，泄漏有窗，边界有法，会签才放。**  
2. 规则1（油位台账钉死）；属 **BI-位**。日用油箱 = day tank（近端供油）；储油罐 = bulk / storage tank（较大储量，常转供日用油箱）；**不能**互相顶；两侧各自入账、各自实测。  
3. 规则2。**不能**；地面看着干 ≠ 泄漏窗过；围堰看着在 ≠ 泄漏窗过。  
4. **不能**。AR ≠ BI；燃油安全过 ≠ 油位/泄漏台账过。本篇**不重写** AR 全文。油箱看着有油 ≠ 燃油安全巡检过（AR 的钉），也 ≠ 油位台账过（BI 的钉）。  
5. **都不能**。AV ≠ BI（油品报告过 ≠ 油位/泄漏窗过）；AF ≠ BI（切换过 ≠ 油位泄漏过）；AO ≠ BI（漏水探头过 ≠ 漏油窗过）。  
6. **不能**。N 绿 ≠ BI 过；看着有油 ≠ 油位台账过。  
7. **BI-验 拒签重测**；禁套他站他期。  
8. **不能**抬功率；先挂 **N**；缺秩序整改贴 **BI**；燃油安全问 **AR**，油品问 **AV**，切换问 **AF**，漏水问 **AO**；**禁功率战**。  
9. **不允许**；禁不安全泄油、开旁通冒充、绕油位/泄漏联锁；挂 N/R，禁签准用。  
10. **不能**互相顶替。无柴油发电机站点两侧均可书面勾「不适用」；有日用油箱无储油罐则只勾储油罐不适用，反之亦然。  
11. 日用油箱项书面勾「不适用」；储油罐按有无路径单独勾选，不得自动免。不得用 BI 顶 AR/AV/AF/AO。假绿挂 **R**；主贴仍 **BI**。  
12. **12.5 kHz** / **4FSK** / **2-slot TDMA**；告警窗 **禁功率战**；常被误当**覆盖病**→禁功率战，挂 N，变更走 J。
