## 1. 为什么要写这篇手册（动机 + 现场对话）

前六十篇手册从 A–E 协议一路写到 BG 精密空调过滤器压差与滤网更换：其中 **BA 回答「冷冻水与冷却塔侧边界」**，**BD 回答「冷冻水泵组与定压补水」**（冷冻水 = chilled water），**AT 回答「冷凝加湿联锁」**，**AO 回答「漏水与汇流排探测」**，**BB 回答「风冷室外机与制冷剂冷凝侧」**，**AX 回答「压缩机与制冷剂」**，**AI 回答「温湿度联锁」**，**BG 回答「滤网更换」**，**N 回答「监控/告警风暴」**。可还没有单独钉死一件事——**机房冷却水泵组与冷凝水侧不是「泵在转 / 塔风扇转 / 冷冻水泵签过 / 没看见滴水 / AT 联锁过 / AO 探头过就能签」：冷却水泵组台账要钉死；冷凝水侧要有主人有窗有方法有准用期；边界窗与方法要书面固定；本期实测禁套他站他期——能不能签「机房冷却水泵组与冷凝水侧准用」？** 这就是本篇的 **BH**——**机房冷却水泵组与冷凝水侧交底台账**（Excel 风格双字母：BG 之后 → **BH**）。

## 3. 核心交付：插页 BH + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 BH（而不是先贴 BA / BD / AT / AO / BB / N）

- 要签「机房冷却水泵组与冷凝水侧准用」、要开冷却水泵组交底窗、要交底冷凝水侧路径（集水/提升泵/水封/排放点/断气） → **主贴 BH**。  
- 冷冻水泵组与定压补水 → **BD**（手册57）。**BD ≠ BH**；不重写 BD。  
- 冷冻水与冷却塔侧（风机/填料/补水排污） → **BA**（手册54）。**BA ≠ BH**；不重写 BA。  
- 冷凝加湿**联锁** → **AT**（手册47）；冷凝水**侧/路径台账**仍 BH。**AT ≠ BH**。  
- 漏水探测与汇流排 → **AO**。**AO ≠ BH**（探头 OK ≠ 路径窗过）。  
- 风冷室外机与制冷剂冷凝侧 → **BB**。不得互相顶替；纯风冷站泵组可书面「不适用」，冷凝水侧仍可能适用。  
- 压缩机与制冷剂 → **AX**；温湿度联锁 → **AI**。均 **≠ BH**。  
- 进机房做交底 → 先 **AN**；门禁过≠交底过。  
- 冷却水泵跳闸/冷凝水溢流/泵组窗乱签风暴 → 先 **N** 理风暴；缺秩序整改仍 **BH**；**禁功率战、关阀、旁通、绕联锁、不安全泄水/带压违章**。  
- 假绿/顶替 → 挂 **R**；变更角色/窗方法/门限 → 走 **J** 后再验 BH。  
- 本站无冷却水泵路径 → 泵组项书面勾「不适用」；冷凝水侧单独勾选；**不得**用 BH 顶 BA/BD/AT/BB，也不得用它们顶 BH。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **冷却水泵组台账钉死**：主/备泵角色·变频器/启停角色·进出口阀件/除污器角色入账（编号脱敏）；禁「泵在转就算过」「口头说冷却水泵正常」。  
2. **冷凝水侧有主有窗有方法/准用期**：集水/提升泵/水封/排放点/断气等以本网与 OEM 书面为准；每次冷凝水侧交底有主人角色、有书面窗、有方法、有准用期；禁「没看见滴水当窗过」「口头说冷凝正常」。  
3. **冷却水泵与冷凝水侧边界窗与方法钉死**：书面固定；方法含与 BA/BD/AT/AO/BB/AX/AI/N 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明逐步关阀/开旁通/绕联锁/不安全泄水/带压违章操作教条；**不重写 BA/BD/AT/AO 全文**）；禁「窗再说」「关阀冒充」「开旁通冒充」「绕泵/冷凝联锁」「不安全泄水/带压违章」「伪造台账」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、冷却水泵组表、冷凝水侧表必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「机房冷却水泵组与冷凝水侧准用」；假绿 ≠ 放行。  
6. **禁顶替 BA/BD/AT/AO/BB/AX/AI/BG/BE/AU/AY/AZ/N/AD/AN/AA/AQ 等，主贴 BH，假绿≠放行挂 R**：塔侧签、冷冻水泵签、冷凝联锁签、漏水探头签、风冷室外机签、压缩机制冷剂签、温湿度签、滤网更换签、仪表/备件签、门禁签、首年签、监控签……都不顶本期冷却水泵/冷凝水侧签。**尤其：BD ≠ BH，BA ≠ BH，AT ≠ BH，AO ≠ BH；冷冻水泵过≠冷却水泵过；塔风扇转≠冷却水泵过；AT 过≠冷凝水路径台账过；AO 探头过≠冷凝水路径窗过；泵在转≠泵组台账过；没看见滴水≠冷凝水侧窗过。**  
7. **冷却水泵跳闸/冷凝水溢流/泵组窗乱签风暴挂 N，边界/门限/冷凝水侧窗变更走 J，禁功率战；禁关阀冒充；禁开旁通；禁绕联锁；禁不安全泄水/带压违章；禁伪造台账**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/回路编号全文/可还原坐标与联系人；禁公开传播未脱敏冷却水/冷凝水门限与参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签冷却水泵/冷凝水侧准用、无实测冒充边界过、关阀/旁通/绕联锁/不安全泄水带压违章冒充秩序齐，不是法外运维智慧**。医院/数据中心冷却水泵与冷凝水路径公开资料只作故事类比（§2.2 / §10）：翻译成本网语言就是 BH-泵 / BH-凝 / BH-界 / BH-验 / BH-治。**这些不是「泵在转就签」「没滴水就签」「抬功率压告警」「关阀/旁通/绕联锁/带压违章冒充」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机房冷却水泵组与冷凝水侧准用」、对外宣传「泵在转/塔风扇转/冷冻水泵签过/没看见滴水/口头正常秒过」、把未实测写成已过、把关阀/旁通/绕联锁/不安全泄水写成秩序齐。允许做的：补冷却水泵组台账、补冷凝水侧窗、重开边界窗、挂 R/N/J、内部挂整改。

## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 本篇用法（教学） |
|------|------------------|

6. **不能**。N 绿 ≠ BH 过；泵在转 ≠ 泵组台账过。  
7. **BH-验 拒签重测**；禁套他站他期。  
8. **不能**抬功率；先挂 **N**；缺秩序整改贴 **BH**；塔侧问 **BA**，冷冻水泵问 **BD**，冷凝联锁问 **AT**；**禁功率战**。
