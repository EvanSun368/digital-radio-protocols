## 1. 为什么要写这篇手册（动机 + 现场对话）

前三十三篇手册从 A–E 协议一路写到 AF 油机/市电切换：其中 **K 回答「市电/后备/倒换/告警/交维」物理层与交维剧本**，**N 回答「电源监控/对时/告警风暴」**，**AA 回答「交维后首年巡检」**，**AC 回答「机动开撤」**，**AD 回答「备件与金机账期」**，**AE 回答「区间联测与换乘界面」**，**AF 回答「油机/市电切换与机房供电巡检」**。可还没有单独钉死一件事——**机房 −48 V / UPS / 手台电池组与充电器不是「柜里有就能上岗」：梯队入库与轮换顺序要钉死（近效/低健康度优先轮出或隔离）；充电器与线缆要有主人有准用期；容量/内阻/浮充电压等须本组本机房本期抽检实测，禁套邻站曲线——能不能签「电池/充电器准用」？** 这就是本篇的 **AG**——**电池与充电器梯队轮换与容量抽检台账**。

- 库房：「柜里还有几组，随便拿一组顶上。」——**无梯队账/轮换规则仍准用** = 本篇拒签（规则1）。  
- 夜班：「充电器型号对得上就行，线随便找一根。」——**充电器/线缆无主人无准用期** = 规则2。  
- 电源岗：「网管浮充电压绿着，容量肯定够。」——**只看浮充绿，无抽检窗/方法** = 规则3。  
- 外包：「邻站上周放电曲线参数差不多，拷过来。」——**套他站他组他期** = 规则4。  
- 班长：「AD 备件签还在有效期，电池也能上岗。」——**用 AD 顶替 AG** = 规则6。  
- 站务：「AF 供电巡检刚签过，电池还在机柜里，不用再抽检。」——**「电池还在」≠ AG 抽检过** = 规则5/6。  
- 网优：「抽检窗基站抖了一下，功率抬一点稳住。」——**功率战** = 规则7。  
- 宣传岗：「把真实机房编号、电池序列号、放电曲线发群表扬。」——**L3 违规** = 规则8。  

这几句背后是同一件事：

> **「电池与充电器梯队轮换与容量抽检」在现场至少有五个坑**：**① AG-梯** 梯队入库、效期/健康度上架、近效或低健康度优先轮出或隔离，禁随意挑新组顶岗；**② AG-充** 充电器型号/线缆/适配器入账有主人有准用期，过期/漂移/来路不明禁顶岗；**③ AG-抽** 容量抽检窗、方法（容量/内阻/浮充电压等角色项）、到场角色书面固定，禁「看一眼浮充绿」；**④ AG-验** 本组本机房本期实测（禁套他站他组他期曲线），抽检通过才签「电池/充电器准用」；**⑤ AG-治** 治理（假绿、用 AD/AF/K 顶替、伪造抽检账、功率战、泄密）。  
> 把 ①–⑤ 当成「柜里有就能上岗」「浮充绿就算容量过」「口头说一声电池还行」，每一次市电闪断、每一次月度抽检、每一次手台轮换上岗，都会先吵「到底哪组该先出、曲线是不是这组的」。

本篇目标：能背出**电池/充电器梯队 + 容量抽检工作流**；会用新贴纸 **AG（梯 / 充 / 抽 / 验 / 治）**；会填**插页 AG（AG1–AG8）**和《本网电池与充电器梯队轮换与容量抽检台账卡》；能用「**医院抢救车/AED 电池与近效期药柜梯队 + 药房效期轮换抽检**」故事讲清入库贴签≠永远准用、近效/低健康度须先轮出或隔离、网管浮充绿≠容量过、套邻站放电曲线=拒签、用 AD/AF 签顶 AG 抽检=拒签；能拒绝随便挑新组顶岗、套曲线、用 AD/AF 顶替本期抽检签、假绿放行；自测过关后，回库把本网最近一次电池容量抽检或手台电池轮换（L3）重对一遍：梯队账、充电器准用、抽检窗、本期实测、签准用项、拒签项。

**本篇硬禁令（写进脑子）**：凡引法规与标准只指向已公开发布的文书标题与官方链接（无线电管理条例、频率使用许可管理办法、地面无线电台（站）管理规定、国无办〔2025〕1号；**只作故事类比**的医院 AED/抢救车电池与近效期药柜公开资料标题，以及公开的 VRLA/铅酸/UPS/−48 V 机房电池与浮充/容量抽检概述资料），**程序、期限、责任以原文与属地最新要求及本网制度 / 合同为准，本篇只作教学转述，不发明条款号与内部口径**；医院 AED 电池维护、境外 IEEE/厂商 VRLA 容量测试公开资料与 UPS 电池科普**不是**中国专网台站「贴纸 AG」的法定依据；**现象与台账一律用相对道号、角色标签、脱敏机房编号，禁真实频点 / 站名 / 机房全称 / 电池序列号全文 / 单位名 / 联系人**；**不教伪造容量台账、不教功率战、不教规避监测、不教套他站曲线、不教假绿顶替、不教绕过告警**；K / N / AA / AC / AD / AE / AF / R / T / J 各管各的——**电池与充电器梯队轮换与容量抽检主贴 AG**；备件金机回 AD，油机市电切换与供电巡检回 AF——**AG 管「梯队·充电器·容量抽检秩序」，不替代 AD 的备件金机账期本身，也不替代 AF 的切换/供电巡检门卫**。

## 2. 总图 / 故事：电池与充电器像「医院抢救车/AED 电池 + 近效期药柜梯队轮换抽检」

### 2.1 一句话：电池不是「柜里有就能上岗」、浮充绿不是「容量过了」——要先建梯队账与轮换顺序，充电器有主人有准用期，抽检窗与方法钉死，本组本机房本期实测，抽检通过才签准用；假绿、套邻站曲线、用 AD/AF 顶替，一律拒签

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  医院抢救车/AED电池 + 近效期药柜梯队  =  本网 AG 电池与充电器 │
   │                                                              │
   │  入库贴签·效期/健康度上架梯队     ≈ AG-梯  梯队入库与轮换顺序 │
   │  充电器/线缆有主人有准用期       ≈ AG-充  充电器与线缆准用   │
   │  抽检窗·方法·到场角色钉死       ≈ AG-抽  容量抽检窗与方法   │
   │  本期容量/内阻/浮充实测禁套     ≈ AG-验  本组本机房本期实测 │
   │  假绿≠放行·顶替·伪造账·功率战   ≈ AG-治  治理与脱敏 L3       │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **梯队有账，充电器有期，抽检有窗，本期实测，抽检才签。**  
> 近效/低健康度还顶岗 = 医院近效药还往抢救车塞——**拒签「电池/充电器准用/可上岗」**。  
> 网管浮充全绿但半年没抽检 = 药柜绿灯亮着却从未做效期抽检——**假绿，挂 R，拒签**。

### 2.2 「医院抢救车/AED 电池 + 近效期药柜」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **梯队** | 入库贴签→效期/健康度上架→近效或低健康度先轮出或隔离→过期隔离退库 | 梯队账与轮换规则钉死；禁随意挑新组顶岗 | AG-梯 |
| **充电器** | 充电座/适配器有型号、有主人、有校准或准用期；来路不明线缆禁充 | 充电器型号/线缆/适配器入账有主人有准用期 | AG-充 |
| **抽检** | 药房效期抽检有窗、有方法、有到场；禁「看一眼柜门绿」 | 容量/内阻/浮充等抽检窗与方法、到场角色书面固定 | AG-抽 |
| **验收** | 本期实测留痕；禁抄邻院药柜抽检账 | 本组本机房本期实测；禁套他站他组他期曲线 | AG-验 |
| **治理** | 假绿≠效期过；禁用「备件签」「供电签」顶本期抽检 | 假绿、顶替 AD/AF/K、伪造账、功率战、泄密 → 治理 | AG-治 |

> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：VRLA/铅酸公开科普强调**浮充电压维持满充，不等于容量/健康度已测**（§10，**只借秩序直觉**）；电信机房 −48 V 直流供电公开概述强调**切换间隙常靠电池浮充扛负载**（接 AF，§10）；医院 AED/抢救车电池公开资料强调**要有有效期、要自检/抽检留痕，不能只看柜子在**（§10，**故事类比，不是无线电法定依据**）。本篇只借这串顺序——**本网梯队规则、抽检门限、合格标准以本网制度与合同为准**。

### 2.3 和手册12（K）/ 15（N）/ 28（AA）/ 30（AC）/ 31（AD）/ 32（AE）/ 33（AF）等的咬合（指针，不重写）

- **K（手册12）**：市电/后备/倒换/告警/**交维**物理剧本；交维时可勾电池/后备，但交维签≠本期 AG 容量抽检。  
- **N（手册15）**：电源监控/**对时**/告警风暴；抽检窗铃响先挂 N 理风暴，**不先抬功率**；浮充监控绿≠ AG 抽检过。  
- **AA（手册28）**：交维后**首年巡检**日历；抽检电池可挂 AA，缺梯队/抽检秩序整改主贴仍 AG。  
- **AC（手册30）**：机动开撤常勾选手台电池；车载一夜勾选≠固定机房/库房 AG 台账。  
- **AD（手册31）**：备件/金机账期与准用；电池作为备件入库可挂 AD，**AD 备件签不替代 AG 本期容量抽检**；抽检仪表须 AD 准用期内。  
- **AE（手册32）**：区间联测；与电池抽检并行时各贴各的——区间过≠电池梯队过。  
- **AF（手册33）**：油机/市电切换与机房供电巡检；切换间隙靠电池浮充——**「电池还在」「供电巡检绿」≠ AG 抽检过**；换电池组常同时触发 AF 再验与 AG 抽检。  
- **R / T / J**：假绿挂 R；投诉挂 T；变更（换电池组、改浮充定值、换充电器型号）走 J 并评估再抽检。

### 2.5 建梯队账 → 充电器准用 → 抽检窗钉死 → 本期容量/内阻实测 → 会签准用 → 变更再验 阶段梯（背下来）

```text

        │  无主人 / 过期漂移 / 来路不明 → 拒进入「可充/可签」状态
        ▼
  ③ AG-抽 钉抽检窗：书面窗 · 方法（容量/内阻/浮充电压等角色项）· 到场角色
        │  无窗 / 无方法 / 「只看绿灯」 → 拒抽检签
        ▼
  ④ AG-验 本组本机房本期实测：容量 · 内阻 · 浮充电压（角色项）· 禁套他站他组他期
        │  套曲线 / 只看浮充绿 → 拒签
        ▼
  ⑤ 会签「电池/充电器准用/可上岗」或「有条件整改」：授权本人签
        │  缺签 / 假绿顶替 → 拒签准用
        ▼
  ⑥ 变更（换电池组/改浮充定值/换充电器型号）→ 走 J + 触发再抽检（常挂 N 看监控、挂 AF 看切换间隙）
```

> **一句话分辨**：**AD** 回答「备件/金机**账期与准用**」；**AF** 回答「切换窗·油机试车·供电巡检**能不能签合格**」；**N** 回答「监控**对时与风暴怎么治**」；**AG** 回答「这一组电池 + 这一台充电器 + 这一窗容量抽检**梯队清不清、充电器有没有期、本期过了没有**」。**四个问题，四张（类）贴纸，不能一笔带过。**

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **梯队入库与轮换顺序钉死：无梯队账/轮换规则不得签「电池/充电器准用」；近效或低健康度须优先轮出或隔离，禁随意挑新组顶岗**。  
2. **充电器与线缆有主人有准用期：充电器型号/线缆/适配器入账有主人；过期/漂移/来路不明禁顶岗**。  
3. **容量抽检窗与方法钉死：抽检窗、方法（容量/内阻/浮充电压等角色项）、到场角色书面固定；禁「看一眼浮充绿」**。  
4. **本组本机房本期实测：须本脱敏机房、本组、本窗实测；禁套他站/他组/他期放电或内阻曲线**。  
5. **抽检通过才签准用：授权本人会签后，方可签「电池/充电器准用/可上岗」；重大未闭项禁合格**。  
6. **禁顶替：可挂 AD/AF/K/N/AA/AC/R 支撑，但电池充电器梯队与容量抽检主贴 AG；AD 备件签、AF 供电签、浮充监控绿、K 交维签均不得顶替 AG 本期抽检签；主贴 AG；监测大屏/系统绿灯、假绿不等于放行（挂 R）**。  
7. **抽检窗射频抖动禁功率战；监控/告警风暴挂 N；换电池组/改浮充定值/换充电器型号等变更走 J 并评估再抽检**。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/电池序列号全文/可还原放电曲线含定位信息/联系人**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无梯队乱顶岗、无抽检冒充容量过关，不是法外运维智慧**。医院 AED/药柜效期与 VRLA/UPS 公开资料只作故事与方法类比（§2.2）：**梯要约、充要期、抽要窗、验要测、绿灯不算过**——翻译成本网语言就是 AG-梯 / AG-充 / AG-抽 / AG-验 / AG-治。**这些是电池与充电器抽检秩序，不是「随便拿一组顶上」「拷邻站曲线」「抬功率压抽检抖」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「电池/充电器准用/可上岗」、对外宣传「分钟级一键容量秒过」、把未抽检写成已过。允许做的：补梯队账、换准用充电器、重开抽检窗、重测、挂 R/N/J、内部挂整改。

### 4.10 −48 V / UPS / 手台电池与 AG 的咬合

- **−48 V 机房电池组**：梯队按组/串角色建账；抽检方法以本网规程（容量/内阻/浮充等角色项）为准；切换间隙直觉挂 AF。  
- **UPS 电池**：巡检对象可与 AF 并行；UPS 维护细节以本网规程为准，AG 钉「有没有按梯队轮、本期有没有抽检」。  
- **手台/车台电池与充电器**：入库与轮换常挂 AD 备件指针，**准用上岗前的容量/健康度抽检主贴仍 AG**；充电器准用期断档禁充。  
- **AD 指针**：抽检仪表、备用电池入库走 AD；**不能**用旧 AD 签日期顶本期 AG 窗。

### 4.11 与首年巡检（AA）/ 机动站（AC）/ 供电巡检（AF）怎么配合

- AA 抽到电池项：看 AG 台账是否断档；缺则主贴 AG 整改，AA 记抽检结果。  
- AC 机动站手台电池勾选：回库后仍要接上 AG 梯队/抽检指针，**车载一夜≠库房容量抽检**。  
- AF 供电巡检勾选「电池外观/在位」：可挂支撑，**在位≠容量过**；换组后常 AF 再验 + AG 再抽。

### 4.12 抽检窗话务抖与投诉（T）怎么并存

- 先 AG/N/AF：电池健康、监控与供电解释得清不清。  
- 解释不清再挂 T/射频分诊；**禁止**一抖就功率战。  
- 上行更脆：抽检或低健康度后先抽测上行登记/话音，再下「覆盖病」结论。

## 6. 工作实例（12 则，教学虚构，L3）

1. **随便挑新组顶岗**  
   现象：近效组仍在岗，新组被挑去「好看」。  
   处置：AG-梯 拒签准用；按近效优先轮出/隔离；补梯队规则。  

2. **充电器来路不明线缆**  
   现象：夜班随手找线充手台，发热。  
   处置：AG-充 拒充；隔离线缆；换准用期内充电器；挂整改。  

3. **网管浮充全绿半年未抽检**  
   现象：大屏绿，抽检台账停在半年前。  
   处置：AG-治 + R 假绿；重开抽检窗；主贴 AG。  

4. **套邻站放电曲线**  
   现象：报告组号涂改痕迹。  
   处置：AG-验/治 拒签；本窗重测。  

5. **用 AD 备件签顶本期抽检**  
   现象：「备件签还在有效期，不用再抽。」  
   处置：规则6；AD 可挂支撑，主贴仍 AG。  

6. **用 AF 供电签顶 AG**  
   现象：「供电巡检刚过，电池还在。」  
   处置：规则6；「电池还在」≠ 容量抽检；主贴 AG。  

7. **抽检仪表过期仍出数**  
   现象：内阻仪 AD 准用期已过。  
   处置：AG6 拒认测值；换期内仪表重测（挂 AD）。  

8. **抽检窗抬功率压登记失败**  
   现象：上行失败被写成覆盖病。  
   处置：AG-治 禁功率战；先 AG/N/AF；上行抽测。  

9. **改浮充定值未走 J**  
   现象：私自改参数后「浮充更绿」。  
   处置：挂 J；回退或评估后 AG 再抽检（常挂 N/AF）。  

10. **机动站 AC 电池勾选冒充库房 AG**  
    现象：车载一夜勾选当容量抽检。  
    处置：AC≠AG；回库另开 AG 窗。  

11. **告警风暴未对时就定「电池故障」**  
    现象：时钟漂移导致因果颠倒。  
    处置：先 N 对时；再 AG 验；禁空口定责。  

12. **公开群发电池序列号与放电曲线**  
    现象：含可定位机房信息。  
    处置：AG-治 规则8；撤回；L3 重发教学版。

## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 一句话（教学） |
|------|----------------|
| **梯队** | 按效期/健康度分档上架与轮出的电池组队列 |
| **近效优先** | 接近效期或低健康度者优先轮出或隔离，禁挑新弃旧 |
| **充电器准用期** | 充电器/线缆/适配器允许使用的书面期限（角色） |
| **浮充电压** | 充电器维持电池满充的稳态电压；**不等于**容量已测 |
| **内阻** | 电池内部电阻类观测量；升高常提示老化（以本网方法为准） |
| **容量抽检** | 按本网方法对容量/放电能力等做的本期实测 |
| **AG-梯** | 梯队入库与轮换顺序钉死 |
| **AG-充** | 充电器与线缆有主人有准用期 |
| **AG-抽** | 抽检窗与方法、到场齐全 |
| **AG-验** | 本组本机房本期实测禁套 |
| **AG-治** | 假绿、顶替、套曲线、功率战、泄密治理 |
| **假绿** | 系统/大屏显示正常，但无本期抽检会签 |
| **套曲线** | 把他站他组他期记录改号当本期 |
| **九字电池钉** | 梯充窗法房表签闭密（教学记忆） |
| **−48 V** | 电信机房常见直流供电标称（公开常识） |
| **VRLA** | 阀控式铅酸电池（公开常识词）；维护细节以本网规程为准 |
| **与 AD/AF 分工** | 备件账期 / 切换供电巡检；AG 管梯队与容量抽检门卫 |
| **切换间隙心跳** | 市电↔油机切换瞬间常靠电池浮充扛负载（接 AF） |

**易错观念**

- ❌「浮充绿=容量过」→ ✅ 假绿挂 R，主贴 AG。  
- ❌「AD 备件签=永远不用抽检」→ ✅ AD 不顶替 AG 本期。  
- ❌「AF 供电绿+电池还在=抽检过」→ ✅ 「电池还在」≠ AG。  
- ❌「拷邻站曲线更快」→ ✅ 禁套；本窗本组本机房实测。  
- ❌「随便挑新组顶岗」→ ✅ 近效/低健康度优先；无梯队拒签。  
- ❌「抽检抖就抬功率」→ ✅ 禁功率战；先 AG/N/AF。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AG** 五子类：梯 / 充 / 抽 / 验 / 治——双字母续写的第七张，负责梯队·充电器·容量抽检「梯队清不清、充电器有没有期、本期过了没有」。  
- 故事：医院抢救车/AED 电池 + 近效期药柜梯队轮换抽检——入库贴签≠永远准用；近效/低健康度须先轮出或隔离；浮充绿≠容量过；套邻站曲线=拒签；AD/AF 不顶替 AG。  
- 阶段梯：建梯队账 → 充电器准用 → 抽检窗钉死 → 本期实测 → 会签准用 → 变更再验。  
- 八条硬规则：**梯队入库与轮换顺序钉死**；**充电器与线缆有主人有准用期**；**容量抽检窗与方法钉死**；**本组本机房本期实测禁套他站他组**；**抽检通过才签准用**；**禁顶替 AD/AF/K/N/AA 等，主贴 AG，假绿≠放行挂 R**；**抽检窗禁功率战、监控风暴挂 N、变更走 J**；**脱敏 L3**。
