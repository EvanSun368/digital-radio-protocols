## 1. 为什么要写这篇手册（动机 + 现场对话）

第 35 课把「前台出题、你交卷、钥匙不出门」钉牢；第 40 课运维日历里，鉴权故障是登记三问的**下游深挖**——手册 01 只留名字指针（「本篇认门牌，第 35 课进门」），本篇就是把那扇门写成**可执行分诊卡**。

手册 01 专治「登不上」的三问与 Reason；手册 02 专治「Grant 了没声」；手册 03 专治 Stun/DGNA/短信话术；手册 04 专治猎站/CHAN 边界；本篇专治另一类更高频的**开鉴权后登不上 / 返厂机拒登 / 遥毙被拒 / 工单误写鉴权失败**——协议你会背，值班却卡在边界：

> 「网管写『鉴权失败』，空口其实根本没有 C_AHOY。」  
> 「有题有答，随后 `0x2B`——是钥匙错了，还是没开户？」  
> 「遥毙回了 `0x14`，要不要再发一次 Kill？」

现场你一定听过这些对话：

- 网管：「新开了鉴权，A 批都过了，B 批全部登记不上。」——十有八九是 **B 批 K 没导入网管**，或导入字节序/格式错位（第 35 课例；本篇七步③）。  
- 调度：「这台以前好好的，返厂修完回来就登不上。」——维修可能**换了主板**：PSN 出厂固化，网管还是旧钢印（七步④）。  
- 坐席：「工单写鉴权失败。」——你若立刻改 K，可能漏问第一句：**NACK 前面有没有一对「出题 + 交卷」？**（七步①）  
- 分析仪：「看见 C_AHOY，手台一直不回。」——不是钥匙错，是**没交卷**（不支持鉴权 / 未开启 / 入站没收到）→ 七步②，这时才谈射频。  
- 监听员：「C_ACKU 的 Target 显示成一个奇怪个号。」——那是 **24 bit 答案被当成地址显示**；Reason=`0x48` 就知道是交卷，不是个呼（第 35 课）。  
- 网管：「遥毙下发了，手台回 `0x14`。」——**反向鉴权失败**：手台不认网络答案；**禁止盲目重发 Kill**（七步⑦ + 手册03）。  
- 安全/采购：「用了 RC4，是不是等于没鉴权？话音有没有加密？」——**鉴权 ≠ 加密**；Part 4 Privacy 未定义（第 35 课 §8.3；本篇 §4.5）。  
- 班长：「Reason 是 `0x2A`，跟手册01剧本一样啊。」——对，**规范没有单独的「鉴权失败」Reason**；鉴权失败走登记拒绝路径。判法是**往前翻有没有题答对**（§2.3 贴纸）。

培训台如果只背「鉴权 = 密钥不对」六个字，值班会卡在同一处：

> **会背名词 ≠ 会走七步。**  
> 分诊 = 每次工单强制按便宜顺序问：  
> **① 真的是鉴权吗？**（有 C_AHOY 出题 + C_ACKU `0x48` 交卷）  
> **② 交卷了吗？**  
> **③ K 在网管且对吗？**  
> **④ PSN 两边一致吗？**  
> **⑤ 个号串号吗？**  
> **⑥ 网管/工具链算法对吗？**（测试向量自检，不重做第35课作业）  
> **⑦ 反向 Stun/Kill？**（指纹不同；失败勿盲发 Kill）  
> 七步答不清，不许升级为「覆盖差」或「换天线试试」；也不许在没题没答时结「鉴权失败」。

本篇目标：能画出「真鉴权 vs 普通登记拒绝 vs 猎站失败 vs Grant 无声」边界贴纸；会用七步分诊卡接单；会区分正向（TS 挑战 MS）与反向（MS 挑战 TS）；能说清鉴权≠加密；能填完《本网鉴权失败分诊卡》；自测过关后，回库翻第 35 / 32 / 34 / 39 课与 `鉴权与AnnexC频率.md` 把本网检查项补进卡——**不重做第 35 课 RC4 逐字节作业、不发明攻击步骤、不写真实 K/个号**。

**本篇硬禁令（写进脑子）**：不发明 ETSI 条款号（入口锚点以资料库 `04-集群协议/鉴权与AnnexC频率.md` §0–§6、`ReasonCode与Grant变体.md`、`Stun_DGNA_UDT与定时器.md`、第 35 / 32 / 34 / 39 / 40 课、手册 01–04 已有编号为准）；**不重 dump RC4 S-box / 测试向量逐字节作业**（第 35 课 §5 已做）；**不写密钥破解、重放攻击步骤、伪基站利用细节**（网络管理分诊口径，与手册 03 / 第 39 课 Stun 中性话术同级）；**不重 dump Reason 全表 / Grant 全变体 / Hunt 状态机 / CHAN 公式**（手册 01 / 02 / 04）；**不写真实批复频点、真实站点号、真实用户个号、真实 K/PSN 明文进公开仓库**（一律用占位符 / 脱敏）；不把厂商中文提示当成 ETSI 正式名；不把「用了 RC4」夸大成「端到端安全」或贬成「等于没鉴权」；本篇不写下一篇手册正文。

## 2. 总图 / 故事：旅馆暗号 + 边界贴纸

### 2.1 一句话：先证明「出过题、交过卷」，再查钥匙

继续旅馆比喻（第 31–40 课 + 手册 01–04 + 第 35 课）：

| 旅馆 | 空口 | 本篇工单常卡在哪 |
|------|------|------------------|
| 找导游集合点 | **Hunt**（手册04） | 还没到前台，谈不上鉴权 |
| 前台办入住 | **登记**（手册01） | 有 RAND+Reason，但**未必**走过鉴权 |
| 前台出随机题卡 | **C_AHOY**（Source=RAND） | 没题却结「鉴权失败」= 贴错贴纸 |
| 你用密码本交卷 | **C_ACKU**（Reason=`0x48`，Target=答案） | 有题无答 → 先查「交卷」，再查射频 |
| 前台用同一密码本判卷 | **C_ACKD `0x62` / C_NACKD `0x2A`·`0x2B`** | 规范**没有**单独「鉴权失败」Reason |
| 客房没声 | **Grant 无声**（手册02） | 鉴权通过后的问题，别回改 K |
| 前台要禁房卡，你先出题验前台 | **反向鉴权**（Stun/Kill） | 失败 → `0x14`；**勿盲发 Kill** |
| 密码本本身 | **K（128 bit）** | **永不上空口** |
| 钢印号 | **PSN** | 可选 XOR；换板最常踩 |

口诀：**先证明有题有答 → 再查钥匙与钢印 → 最后才谈射频。**  
把「普通登记拒绝」写成「鉴权失败」，或把「反向鉴权失败」当成「再发一次 Kill 就好」，是本篇最常见的两大口误。

```text
  │ 证据：无自家SYScode │ │ 证据：有登记RAND    │ │ 证据：C_AHOY+0x48  │ │ 证据：真Channel    │
  │       /Aloha       │ │       +ACK/NACK+Reason│ │       随后 2A/2B等 │ │       Grant        │

  └────────────────────┘ └────────────────────┘ └────────────────────┘ └────────────────────┘
```

划界口诀（本篇新增「贴纸 D」）：

| 你想确认的事 | 成功长什么样 | 失败 / 假故障长什么样 |
|--------------|--------------|------------------------|
| **摸到自家 TSCC 了吗？** | 能解码 SYScode / Aloha | 只有能量 → 贴纸 A（手册04） |
| **登记办成了吗？** | 终 ACK `0x62`/`0x65` | 有 RAND+Reason 拒绝 → 贴纸 B；**再问有没有题答对** |
| **鉴权中间步走过吗？** | 有 C_AHOY（出题）+ C_ACKU `0x48`（交卷） | 无题无答却写「鉴权失败」→ **假鉴权单**，退回 B 或 A |
| **Grant 后进客房了吗？** | Payload 有声 | 有 Grant 无声 → 贴纸 C；**与钥匙无关** |

**最重要一条（第 35 课 §7）**：看到 `0x2A` / `0x2B`，**不能直接断定是鉴权失败**——它们是登记拒绝的通用理由。判断方法：**往前翻**，看这条 NACK 前面**有没有一对 C_AHOY（Service_Kind=`1110₂`，Source=题）+ C_ACKU（Reason=`0x48`）**。有，才是贴纸 D；没有，就是贴纸 B（开户/站点不允许等）。

## 3. 核心交付：七步分诊工作流 + 决策树 + 分诊卡行

### 3.1 七步工作流（每次工单照念 · 便宜优先）

把第 35 课 §9 展开成可勾选的七步（**越靠前越常见、越便宜**）：

```text
  第1步 · 真的是鉴权问题吗？
     证据：NACK（常见 0x2A/0x2B）或「登不上」现象前面，
           有没有 C_AHOY（出题，Source=RAND）+ C_ACKU（Reason=0x48，Target=答案）？
     没有 ──────────────► 不是鉴权 → 贴纸B（手册01）或贴纸A（手册04）
     有   ──────────────► 进第2步（贴纸D）

  第2步 · 手台交卷了吗？
     出题之后有没有 C_ACKU 0x48？
     没有 ──► 不支持/未开鉴权，或入站没收到题 → 这时才查覆盖与射频
     有   ──► 进第3步

  第3步 · 这台的 K 在网管里吗、对吗？
     个号 ↔ K 是否一一对应？刚写频改过 K 网管同步了吗？
     导入格式/字节序是否错位？（批次全挂的经典指纹）

  第4步 · PSN 两边用法一致吗？
     网络启用了 PSN？手台支持吗？录的是不是**这台机器现在**的钢印？
     ※ 返厂换板、借机调号最常踩

  第5步 · 是不是个号写错 / 串号？
     手台自报个号对应的 K，是不是另一台机器的？
     两台共用一个个号 → 至少一台永远过不了

  第6步 · 网络侧算法 / 工具链对吗？
     用第35课官方测试向量喂网管/测试仪做自检（结构核对即可）
     ※ 本篇不重做逐字节作业；新上线第三方网管先过这关

  第7步 · 反向场景（Stun / Revive / Kill）？
     指纹：C_AHOY(STUNI|KILLI) → C_ACKVIT(出题) → C_ACKD(0x64交卷)
           → 失败则 C_NACKU 0x14 Recipient_Refused
     ※ 手台不认网络答案：先对网络侧该台 K；禁止盲目重发 Kill
```

**口诀**：**先确认有题有答，再查钥匙，再查钢印，最后才查射频。**  
**结束条件**：七步（或提前转出的贴纸）都有证据（空口顺序 / 网管个号-K 对照版本号 / 写频批次，均脱敏）写入工单，才能谈「覆盖差」或「硬件坏了」。只有中文「鉴权失败」四个字 = 线索不足。

### 3.3 分诊卡行模板（脱敏 · 运维×开户共用）

| 字段 | 填什么 | 禁止填什么 |
|------|--------|------------|
| **个号（脱敏）** | 末 2–4 位或内部工单号 | 完整个号明文入库学习仓 |
| **批次 / 写频包** | `2026-09-b` / `机型X-包3` | 真实密钥文件路径外泄 |
| **鉴权开关** | 本站开/关；独立轮询开/关 | — |
| **空口顺序** | `RAND→AHOY→ACKU0x48→NACK2B` | 只写「鉴权失败」四字 |
| **K 状态** | 网管有记录？与写频同步？ | **真实 K 十六进制** |
| **PSN 状态** | 启用？支持？换板后已重录？ | 真实 PSN 明文公开仓 |
| **结论贴纸** | A / B / D / C / 反向⑦ | 贴纸混贴不写清 |
| **下一动作** | 同步K / 重录PSN / 转01 / 转04… | 「再发一次Kill碰运气」 |

### 3.4 日志三联单（鉴权版）

| 栏 | 要写 | 好例子（脱敏） | 坏例子 |
|----|------|----------------|--------|
| **终端侧** | 型号/写频包；个号脱敏；是否支持鉴权；返厂换板否 | 「机型X，包2026-09-b；支持鉴权；本周返厂换板」 | 「用户说登不上」 |
| **空口侧** | 有无 AHOY；有无 0x48；随后 Reason；Mirror 是否全0（轮询） | 「有AHOY+0x48，随后0x2B；非独立轮询」 | 「鉴权失败」 |
| **网络侧** | 本站鉴权开？该个号有K？PSN启用？近期导入批次 | 「鉴权开；个号有K记录；PSN启用；B批今晨导入」 | 「系统有问题」 |

三联单填齐且七步指向同一贴纸之后，才进入 §4 深潜与 §5 现场对话。

## 4. 深潜：七步背后的六颗钉子（只取运维用）

### 4.1 四个量：谁持有、上不上空口

| 名 | 宽度 | 谁持有 | 空口？ | 运维一句话 |
|----|------|--------|-------|------------|
| **K** | 128 bit | MS 与网管各一份 | **不上** | 一机一钥；丢了只坏一台 |
| **PSN** | ≥3 字节（算 3） | 出厂固化；网管录入 | **不上**（只影响答案 XOR） | 换板必重录 |
| **RAND** | 24 bit | 挑战方当场产生 | **上**（C_AHOY Source / C_ACKVIT Target） | 题每次都换，防重放 |
| **Response** | 24 bit | 被挑战方算出 | **上**（C_ACKU Target / C_ACKD AddInfo） | 答案；别当成个号 |

口诀：**题和答上天，钥匙和钢印不出门。**

### 4.2 什么时候出题（五种场景 · 运维认指纹）

| 场景 | 空口指纹 | 值班怎么认 |
|------|----------|------------|
| **登记中鉴权** | C_RAND(登记) → C_AHOY → C_ACKU 0x48 → 终ACK/NACK | 最常见；Mirror 回拷登记 Service_Options |
| **呼叫建立中鉴权** | C_RAND(呼叫) → C_AHOY → … → 通过则常跟 Grant | 答错 → 呼叫失败，不是 Grant 无声 |
| **独立鉴权轮询** | **无人按铃**却出题；Mirror=`000 0000₂` | 抽查，正常现象 |
| **业务信道上** | P_AHOY / P_ACKU，字段同 | 已在客房仍可出题 |
| **反向 Stun/Kill** | AHOY(STUNI\|KILLI) → ACKVIT → ACKD 0x64 → 0x44/0x14 | Kill **必须**鉴权；Stun 可选 |

### 4.3 三种结局怎么读（登记路径）

| 结局 | 空口 | 含义 |
|------|------|------|
| **通过** | C_ACKD `0x62`（或呼叫继续→Grant） | 鉴权只是中间步；结论在终 ACK / Grant |
| **不通过** | C_NACKD `0x2A` / `0x2B` | **无单独 Auth-Fail Reason**；须有题答对才称贴纸D |
| **没判卷 / 没交卷** | 出题后无下文；或无 0x48 | TNP 到期→猎站；或七步② |

`0x2A` Refused 可换站再试；`0x2B` Denied 可能进本站拒绝名单（T_DENREG）。鉴权失败回哪一个，**规范不定、看厂商**（如 dmrtc 答错常回 Denied）。

### 4.4 反向鉴权：Stun / Kill 指纹（中性网络管理口径）

```text
  TS --C_AHOY(STUNI|KILLI, Kind=1101₂)--> MS     管理命令
  MS --C_ACKVIT(Target=手台出的题)--> TS           兼确认 + 出题
  TS --C_ACKD(Reason=0x64, AddInfo=网络答案)--> MS 网络交卷
  MS 判卷：
       对上 → 执行，回 C_ACKU（MS_Accepted 0x44）
       对不上 → 不执行，回 C_NACKU（Recipient_Refused 0x14）
```

运维铁律：

1. **Kill 必须鉴权**——永久禁用路径，防冒充网络毁机。  
2. **Stun/Revive 鉴权可选**——手台发不发 ACKVIT 看实现。  
3. **`0x14` 在此语境 = 手台验不过网络**，不是「用户拒接个呼」（第 34/35 课：同一 Reason 要结合场景）。  
4. **`0x00` MSNot_Supported** = 不支持 Stun，**与钥匙无关**（手册03）。  
5. **反向失败 → 先对网络侧该台 K/PSN，禁止「再发一次 Kill 碰运气」。**

### 4.5 鉴权 ≠ 加密（三条线别画混）

| | 回答的问题 | 空口看得到 |
|--|-----------|------------|
| **Colour Code / SYScode** | 是不是同一个系统/站？ | 明文字段 |
| **鉴权（本篇）** | 手里有没有这台的 K？ | 题和答（各 24 bit）；**K 不上空口** |
| **加密（Privacy）** | 旁人能不能听懂话音/数据？ | **不在 Part 4**（Privacy 位未定义） |

口诀：**听到「RC4」先问——说的是鉴权搅拌机，还是话音加密方案？** 同名算法、不同规范、不同钥匙、不同用途。给安全同事一句话：**Part 4 鉴权是入网门禁，不是端到端安全方案。**

### 4.6 和手册01的咬合：Reason「长得像拒绝」，根因可能是 K/PSN

手册 01 剧本里 `0x2A`/`0x2B` 常写「未开户 / 站点不允许 / Denied 名单」。本篇补充：

| 手册01视角 | 本篇加一刀 |
|------------|------------|
| 有 RAND + Reason → 走三问 | **再问**：前面有没有 AHOY+0x48？ |
| 有 → 可能是贴纸 D | 七步③–⑤：K/PSN/串号 |
| 无 → 贴纸 B 本色 | 开户、站点策略、跨字节误读等 |
| 无 RAND → 可能贴纸 A | 手册04；禁止结鉴权单 |

边界口诀：**手册01认门牌（Reason），本篇认题答对（鉴权中间步）。**

### 5.2 值班对话脚本（可直接照着说）

#### 对话 A · 「鉴权失败」四个字工单

- 坐席：「用户鉴权失败。」  
- 你：「空口顺序有没有？具体说：有没有看到网络出题（C_AHOY），手台有没有交卷（Reason 0x48）？随后拒绝码是多少？」（七步①）  
- 坐席：「……只有中文提示，没有码。」  
- 你：「没有题答对证据，不能结鉴权单。先按手册01补三联单；若连登记 RAND 都没有，转手册04看是否还在猎站。」

#### 对话 B · 整批开鉴权后挂掉

- 网管：「B 批 40 台全挂，A 批正常。」  
- 你：「分析仪上 B 批是有题有答再拒绝，还是出题不回？」（①②）  
- 网管：「有题有答，随后 Denied。」  
- 你：「那走钥匙线：B 批 K 导入文件格式/字节序是否与 A 批一致？网管里抽两台 B 批个号看 K 记录是否非空且与写频同步。」（③）

#### 对话 C · 返厂机

- 调度：「这台修完回来就登不上。」  
- 你：「有题有答吗？本网启用 PSN 吗？维修单是否换过主板？」（①④）  
- 调度：「换过板，PSN 启用。」  
- 你：「用厂商工具重读钢印，更新网管该个号的 PSN；不要先重写 K 碰运气。」

#### 对话 D · 遥毙回 0x14

- 网管：「Kill 下发了，手台回 Recipient_Refused。」  
- 你：「这是反向鉴权失败：手台不认网络的答案。先核网络侧这台的 K 是否与写频一致。**先不要连续重发 Kill。**」（⑦ + 手册03）

#### 对话 E · 「答案像个呼地址」

- 新人：「1001 在个呼一个奇怪号。」  
- 你：「看 Reason：若是 0x48，Target 栏是**答案**不是被叫。别开错个呼故障单。」

### 5.3 「先钥匙 / 题答，后覆盖 / 射频」反例集

| 一上来就做的动作 | 为何常错 | 应先做 |
|------------------|----------|--------|
| 一听「鉴权失败」就改 K | 可能无题无答 | 七步① |
| 一听「登不上」就换天线 | 可能是 K/PSN | ①–④ |
| 一听 0x2A 就开「未开户」剧本 | 可能是鉴权未过 | 往前翻题答对 |
| 遥毙失败就连发 Kill | 可能锁死/毁机风险 | 对网络侧 K |
| Grant 无声却重导 K | 门牌/CC/时隙问题 | 手册02 |
| 搜网工单改鉴权开关 | 可能还在猎站 | 手册04 |

## 6. 工作实例（10 个厚例，均脱敏）

### 例 1 · 假鉴权单：无 AHOY 却写「鉴权失败」

**现象**：坐席结「鉴权失败」。  
**七步**：① **无** C_AHOY、无 0x48；有登记 RAND + `0x2A`。  
**贴纸**：B（手册01），不是 D。  
**动作**：退回三问 + Reason 剧本；禁止改 K。

### 例 2 · 整批 K 导入错位

**现象**：开鉴权后 B 批全挂，A 批正常。  
**七步**：①有题有答；②有交卷；③ **B 批 K 导入字节序/格式错**。  
**动作**：修导入工具链；用测试向量自检网管（⑥）；脱敏记录「B 批导入格式」。

### 例 3 · 返厂换板 PSN

**现象**：单台返厂后拒登，同批次其余正常。  
**七步**：①②过；④ **PSN 仍是旧钢印**。  
**动作**：工具重读 PSN → 更新网管；培训「换板必改钢印库」。

### 例 4 · 出题不交卷：老型号不支持

**现象**：开鉴权后某老型号一直登不上。  
**七步**：①有 AHOY；② **始终无 0x48**；TNP 后去猎站。  
**动作**：升级固件或鉴权豁免名单；**先别测驻波**。

### 例 5 · 个号串号：两机一个号

**现象**：两台里总有一台鉴权过不了。  
**七步**：⑤ 两机写了同一自报个号，K 只对得上其中一把。  
**动作**：拆分个号；网管 K 一一对应；脱敏记「串号」。

### 例 6 · 独立轮询被当成故障

**现象**：「没人按 PTT 却周期性 AHOY→ACKU」。  
**七步**：Mirror=0 → **独立轮询**（§4.2）。  
**动作**：向监控说明正常抽查；勿开故障单。

### 例 7 · 反向 Kill 回 0x14

**现象**：遥毙被拒。  
**七步**：⑦ 反向指纹完整；手台不认答案。  
**动作**：对网络侧 K；**停止连发 Kill**；手册03话术同步调度。

### 例 8 · Stun 回 0x00（非鉴权）

**现象**：以为鉴权失败。  
**边界**：`MSNot_Supported`——不支持 Stun。  
**动作**：回手册03；本篇结「非鉴权」。

### 例 9 · 登记拒绝后去猎站——规范接法

**现象**：`0x2B` 后手台离开再搜网。  
**边界**：贴纸 D 或 B 结案后，猎站是规范接法（手册04例8）。  
**动作**：工单两段写：鉴权/登记剧本 + 随后 Hunt 指纹；别开两张无关单。

### 例 10 ·（对照）干净成功：题→答→Reg_Accepted

**现象**：试点机登记，30 秒内可通。  
**空口**：C_RAND → C_AHOY → C_ACKU 0x48 → C_ACKD 0x62。  
**教学用途**：给新人当「正常长什么样」；工单可存脱敏顺序栏，不存真实 RAND/答案/K。

## 6.5 运维 × 开户 / 安全对齐会：20 分钟议程（可复印）

```text
0–3 min   本周「鉴权失败」工单张数；有几张七步①不成立（假鉴权单）
3–10 min  打开分诊卡：批次K同步、PSN换板流程、豁免名单是否更新
10–15 min 抽一张整批失败或返厂机工单，当面走七步
15–18 min 与安全对齐一句话：鉴权≠加密；公开材料无真实K
18–20 min 确认 Stun/Kill 反向失败流程：先对K、禁止盲发Kill
```

对齐口令：

> 运维：没题没答，不结鉴权单。  
> 开户：个号↔K↔PSN 不同步，不开放鉴权开关。  
> 安全：Part 4 鉴权是门禁，不是话音加密证明。

### 6.6 「题答 / 钥匙 / 射频」三层工具心态

| 层 | 工具直觉 | 回答的问题 | 本篇用法 |
|----|----------|------------|----------|
| 题答 | 空口分析 / 网管信令 | 有没有出题、交卷、终局 Reason？ | 七步①② |
| 钥匙 | 写频工具 / 网管开户库 | K/PSN/个号是否一一对应？ | 七步③–⑤ |
| 射频 | 频谱 / 场强 | 入站是否根本收不到题？ | **仅**在②无交卷后 |

口诀：**题答证明「走过鉴权门」，钥匙证明「算得对」，射频证明「听得见题」。** 三层没走完，不许只写「覆盖差」。

| **鉴权** | 验证「有没有这台的 K」 | 当成话音加密 |
| **挑战 RAND** | 24 bit 随机题 | 当成个号/网关 |
| **响应 Response** | 24 bit 答案 | 当成被叫地址 |
| **K** | 128 bit 一机一钥 | 以为会上空口 |
| **PSN** | 出厂钢印，可选入算 | 换板后忘更新 |
| **C_AHOY** | 网络出题（正向） | 只当成「点名被叫」 |
| **C_ACKU 0x48** | 手台交卷 | 当成普通 ACK |
| **C_ACKD 0x64** | 网络交卷（反向） | 与 0x48 方向搞反 |
| **C_ACKVIT** | 手台对 Stun/Kill「先答题」 | 当成普通确认 |
| **0x62** | Reg_Accepted | 以为等于「鉴权专用成功码」 |
| **0x2A / 0x2B** | 登记拒绝通用 | 直接当「鉴权失败」 |
| **0x14** | 反向失败拒执行 | 当成用户拒接 |
| **0x00** | 不支持 Stun | 当成鉴权失败 |
| **0x44** | MS_Accepted（执行管理命令） | — |
| **0xE0 Wait** | 中间态 | 当成终失败 |
| **AUTHI** | 鉴权网关名 `FF FECD` | 与 RAND 范围混淆 |
| **独立轮询** | Mirror=0 的抽查 | 当成故障 |
| **正向鉴权** | TS 挑战 MS | — |
| **反向鉴权** | MS 挑战 TS（Stun/Kill） | 失败却盲发 Kill |
| **TNP_Timer** | 出题后等判卷 | 超时→猎站当射频故障 |
| **贴纸 D** | 真鉴权失败（有题有答） | 与 B 混贴 |
| **手册01三问** | 登记分诊 | 无题时误升 D |
| **手册04四问** | 猎站/CHAN | 无TSCC时开鉴权单 |
| **Privacy** | 话音加密位（Part4未定义） | 与鉴权混谈 |
| **RC4（本处）** | 鉴权搅拌机 | dump 攻击细节 / 当话音加密 |
| **测试向量** | 官方自检样例 | 本篇重做逐字节作业 |
| **dmrtc** | 开源控制器对照 | 当成规范本身 |
| **脱敏分诊卡** | 七步+批次表 | 填真实 K 入库 |

**易错观念对照**

| 错念 | 纠正 |
|------|------|
| 有 0x2A = 鉴权失败 | 先往前翻有没有题答对 |
| 鉴权失败 = 换天线 | 先①–④ |
| 鉴权 = 话音加密 | §4.5 三条线 |
| 遥毙失败再发一次 | 先对 K；Kill 很重 |
| 答案栏是被叫个号 | Reason 0x48 → 那是答案 |
| 没人按铃却出题 = 故障 | 独立轮询可能正常 |
| 用了 RC4 = 没鉴权 / = 绝对安全 | 门禁有效，但非端到端方案 |

### 参考答案

1. **不是第 41 课。** 手册模式第 5 篇。手册01认登记 Reason 门牌；本篇在有题有答时认鉴权中间步（贴纸 D）。  
2. ①真是鉴权吗 → ②交卷了吗 → ③K → ④PSN → ⑤串号 → ⑥工具链 → ⑦反向。证据：C_AHOY 出题 + C_ACKU Reason=`0x48`。  
3. A猎站（手册04）；B登记（手册01）；D真鉴权（本篇）；C Grant无声（手册02）。无 AHOY/无0x48 → **不能贴 D**，多贴 B（或查 A）。  
4. 它们是登记拒绝通用码；鉴权失败也走此路径。须往前翻题答对。  
5. **K 与 PSN 不上空口**；RAND/Response 上。换板后重读 PSN 并更新网管。  
6. 正向：TS 出题，MS 交卷 `0x48`。反向：MS 出题（ACKVIT），TS 交卷 `0x64`。  
7. Mirror=`000 0000₂`；通常是正常抽查，不当故障。  
8. 核网络侧该台 K；Kill 永久且必鉴权，盲发不能修钥匙问题，还有误操作风险。  
9. CC/SYS：是否同系统；鉴权：是否有 K；加密：旁人能否听懂（不在 Part4）。  
10. Grant无声 → 手册02，**不改 K**。无 SYScode → 手册04，**不开鉴权单**。  
11. 不是；`MSNot_Supported`；手册03。  
12. 真实 **K**、真实 **PSN**、**完整**个号（以及真实批复 MHz）。

## 11.7 常见问法速查（FAQ 式）

**Q1：Reason 是 0x2B，是不是一定鉴权失败？**  
A：不一定。往前翻有没有 AHOY+0x48。

**Q2：没有单独的「鉴权失败」Reason 吗？**  
A：Part 4 登记路径没有；失败走登记拒绝或超时猎站。

**Q3：鉴权过了话音就加密了吗？**  
A：**没有。** 鉴权≠加密；Privacy 不在 Part 4。

**Q4：分诊卡能不能写真实 K 方便夜班？**  
A：**不能写进学习推送/公开仓。** 真实 K 只留在受控开户系统。

**Q5：本篇要不要会手算 RC4、默写测试向量？**  
A：值班分诊**不要求**重做第35课作业；会认题答对与七步即可。工具链自检由责任人按第35课做。

**Q6：和手册01如何分工？**  
A：手册01管登记三问与 Reason 剧本；一旦确认有题有答后的拒绝，升级本篇贴纸 D 走七步。

**Q7：反向失败能当「用户拒接」结案吗？**  
A：**不能。** 管理场景下 `0x14` = 手台不认网络答案。
