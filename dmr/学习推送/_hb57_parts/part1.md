| **治** | 假绿≠可以签；禁用「冷冻水冷却塔签」「压缩机制冷剂签」「漏水签」「温湿度签」「监控签」顶本期泵组/定压补水 | 假绿、顶替 BA/AX/AO/…、关阀/旁通/绕联锁、功率战、泄密 → 治理 | BD-治 |

> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：冷冻水泵组与定压/膨胀罐/补水公开概述强调**有账要验、泵在转≠准用、压力绿≠窗过、口头补水正常≠方法过、边界要有书面方法、泵组与定压补水要有本期核对秩序**（§10，**只借秩序直觉**；**本篇不写逐步关阀/开旁通/不安全泄水/带压违章操作教条**）；医院手术室/ICU 与数据中心 CHW pump / pressurization / makeup-water 公开资料强调**环境绿≠泵组/定压补水合格、冷冻水冷却塔侧过≠泵组定压过、漏水探头过≠补水台账过、压缩机制冷剂过≠泵组过、温湿度过≠定压窗过、监控绿≠本期实测过**（§10，**只作故事类比**）。本篇只借这串顺序——**本网泵组台账格式、定压补水窗方法、边界顺序与合格门限以本网制度、合同与 OEM 书面为准**。

### 2.3 和手册54（BA）/ 51（AX）/ 42（AO）/ 36（AI）/ 47（AT）/ 15（N）/ 56（BC）等的咬合（指针，不重写）

### 3.1 什么时候贴 BD（而不是先贴 BA / AX / AO / AI / N）

### 3.4 与总三联单怎么写（脱敏 L3）

- **封面**：脱敏机房角色 + 本期相对期号 + 贴纸 BD + 「机房冷冻水泵组与定压补水交底」。  
- **现象栏**：只写角色与现象（如「泵组角色缺账」「定压无窗」「补水无书面方法」「套票嫌疑」），**不写**真实回路编号全文、定压门限可还原全文、单位名、联系人。  
- **动作栏**：补 BD-泵 / 补 BD-补 / 补 BD-界 / 本期实测 / 会签 / 拒签挂改 / 挂 R / 挂 N / 走 J。  
- **边界栏**：勾清 BA/AX/AO/AI/AT/AD/AN/N——各过≠BD 过；**尤其勾清 BA≠BD、AO≠BD、AX≠BD**。  
- **会签栏**：准用 / 有条件整改 / 拒签；假绿 ≠ 会签放行。  
- **附件**：插页 BD1–BD8；AD 仪表准用指针（若用）；J 变更指针（若有）。
