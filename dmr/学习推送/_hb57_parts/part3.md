## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 本篇用法（教学） |
|------|------------------|
| **泵组** | 冷冻水侧主/备泵及启停/变频角色；BD-泵 |
| **主/备泵** | 值班泵与备用泵角色（脱敏编号）；有切换秩序以本网书面为准 |
| **变频器/启停** | 泵组变频或启停控制角色；≠ BA 塔侧风机本身 |
| **定压** | 维持闭式回路压力稳定的装置/策略角色；膨胀罐/定压装置 |
| **膨胀罐** | Expansion tank；吸收水温变化体积；**压力绿≠窗过** |
| **补水** | Makeup water；向回路补充工质；有阀、有窗、有方法 |
| **补水压力窗** | 补水/定压相关书面维护窗；有主人有准用期；门限以本网书面为准 |

| **压力绿** | 定压/压力指示绿；**≠ 定压窗过** |
| **假绿** | 无实测/无会签却显示通过；挂 R；≠ 放行 |
| **套票** | 套他站他期泵组/定压/补水表；BD-验 拒签 |
| **关阀冒充** | 关阀消告警冒充可过；**本篇硬禁** |
| **开旁通冒充** | 开旁通让读数变绿冒充可过；**本篇硬禁** |
| **绕联锁** | 绕过泵/定压安全联锁冒充可过；**本篇硬禁** |
| **不安全泄水/带压违章** | 未授权不安全泄水或带压违章作业冒充可过；**本篇硬禁** |
| **功率战** | 用抬功率压泵组/定压/补水告警；**禁**；先挂 N |
| **贴纸 BD** | 本篇主贴；泵/补/界/验/治五子类 |
| **BA ≠ BD** | 冷冻水冷却塔侧边界 ≠ 泵组与定压补水 |
| **AO ≠ BD** | 漏水 ≠ 补水台账 |
| **AX ≠ BD** | 压缩机制冷剂 ≠ 泵组/定压补水 |
| **N ≠ BD** | 风暴秩序 ≠ 本期实测 |
| **脱敏 L3** | 禁真实站名/机房全称/回路编号全文/联系人 |

**易错观念（纠一次）**  
- 「泵在转 = 准用」→ 错；要 BD-泵台账 + 本期实测。  
- 「压力绿 / 口头补水正常 = 窗过」→ 错；要 BD-补 主人窗方法。  
- 「BA 过 = BD 过」→ 错；冷冻水冷却塔侧 ≠ 泵组与定压补水。  
- 「AO 过 = 补水台账过」→ 错；漏水 ≠ 补水台账。  
- 「AX 过 = 泵组过」→ 错；压缩机制冷剂 ≠ 泵组定压。  
- 「N 绿 = 本期实测过」→ 错；风暴绿 ≠ 交底准用。  
- 「关阀/旁通消告警 = 办法」→ 错；硬禁。  
- 「抬功率压定压告警 = 救急」→ 错；禁功率战。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **BD** 五子类：泵 / 补 / 界 / 验 / 治——双字母续写在 BC 之后的第一张 **BD**，负责机房冷冻水泵组与定压补水「台账清不清、补水有没有窗、边界有没有法、本期过了没有」。  
- 口诀：**泵组有账，补水有窗，边界有法，会签才放。**  
- 故事：医院手术室/ICU 冷冻水泵组与定压补水（或数据中心 chilled-water pump / pressurization / makeup-water）——泵在转≠准用；压力绿≠窗过；口头说泵组/补水正常≠方法过。  
- 八条硬规则：**泵组台账钉死**；**定压补水有主有窗有方法/准用期**；**泵组与定压补水边界窗与方法钉死**；**本期实测禁套**；**会签才放行**；**禁顶替 BA/AX/AO/AI/AT/AY/AZ/AU/BB/BC/AW/AF/AS/AD/AN/AA/N/AQ/AV/AR/AG/AP，主贴 BD，假绿≠放行挂 R**；**异常风暴挂 N、变更走 J、禁功率战/关阀冒充/开旁通/绕联锁/不安全泄水带压违章/伪造台账**；**脱敏 L3**。  
- **BD 不替代 BA，也不替代 AX，也不替代 AO，也不替代 AI**：BA=冷冻水与冷却塔侧边界；AX=压缩机制冷剂；AO=漏水汇排；AI=温湿度联锁巡检；BD=泵组与定压补水准用。**BA ≠ BD；AO ≠ BD；AX ≠ BD。**
