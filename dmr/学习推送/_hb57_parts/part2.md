## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **泵组台账钉死**：主/备泵角色、变频器/启停角色、进出口阀件角色入账（编号脱敏）；禁「泵在转就算过」「口头说泵组正常」。  
2. **定压补水有主有窗有方法/准用期**：膨胀罐/定压装置/补水阀·补水压力窗·补水水质测点等以本网与 OEM 书面为准；每次定压/补水相关维护有主人角色、有书面窗、有方法、有准用期；禁「压力绿当窗过」「口头补水正常」。  
3. **泵组与定压补水边界窗与方法钉死**：书面固定；方法含泵组与定压补水边界核对、与 BA/AO/AI/AX/N 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明逐步关阀/开旁通/绕联锁/不安全泄水/带压违章操作教条）；禁「窗再说」「关阀冒充」「开旁通冒充」「绕泵/定压联锁」「不安全泄水/带压违章」「伪造台账」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、泵组表、定压表、补水表必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「机房冷冻水泵组与定压补水准用」；假绿 ≠ 放行。  
6. **禁顶替 BA/AX/AO/AI/AT/AY/AZ/AU/BB/BC/AW/AF/AS/AD/AN/AA/N/AQ/AV/AR/AG/AP，主贴 BD，假绿≠放行挂 R**：冷冻水冷却塔签、压缩机制冷剂签、漏水签、温湿度签、冷凝加湿签、新风签、冷通道签、滤网气流签、室外机冷凝侧签、机柜PUE签、列头末端签、油机市电签、旁路签、仪表签、门禁签、首年签、监控签、视频签、油品签、通风燃油签、电池签、内阻签都不顶本期泵组/定压补水签。**尤其：BA ≠ BD，AO ≠ BD，AX ≠ BD。**  
7. **泵组/定压/补水异常风暴挂 N，边界/门限/定压窗变更走 J，禁功率战；禁关阀冒充；禁开旁通；禁绕联锁；禁不安全泄水/带压违章；禁伪造台账**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/回路编号全文/可还原坐标与联系人；禁公开传播未脱敏定压门限与补水参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签泵组/定压/补水准用、无实测冒充边界过、关阀/开旁通/绕联锁/不安全泄水/带压违章冒充秩序齐，不是法外运维智慧**。医院冷冻水泵组与定压补水、数据中心 CHW pump / pressurization / makeup-water 公开资料只作故事与方法类比（§2.2）：**泵要约、补要窗、界要法、验要本期、泵在转不算过、压力绿不算窗过、口头补水正常不算方法过、关阀旁通绕联锁不算办法**——翻译成本网语言就是 BD-泵 / BD-补 / BD-界 / BD-验 / BD-治。**这些是泵组与定压补水交底秩序，不是「泵在转就签」「压力绿当过」「抬功率压告警」「关阀先过」「旁通冒充」「绕联锁冒充」「带压违章冒充」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机房冷冻水泵组与定压补水准用」、对外宣传「泵在转/压力绿/口头补水正常秒过」、把未实测写成已过、把关阀/旁通/绕联锁/带压违章写成秩序齐。允许做的：补泵组台账、补定压补水窗、重开边界窗、挂 R/N/J、内部挂整改。

禁止写：真实站名、机房全称、回路编号全文、单位名、联系人、真实频点、未脱敏定压门限可还原信息；禁止写「泵在转就过」「压力绿就过」「口头泵组正常就过」「口头补水正常就过」「BA/AX/AO/AD/AN 签顶 BD」「抬功率压泵组/定压告警」「关阀冒充」「开旁通冒充」「绕联锁」「不安全泄水/带压违章」「套邻站泵组/定压表」「伪造台账步骤」。允许写：脱敏机房/泵组/定压/补水角色、现象（泵组缺账/定压无窗/边界无方法/假绿/风暴/关阀旁通嫌疑）、贴纸（BD/BA/AX/AO/AI/AT/AD/AN/N/R/J）、动作（补账/重测/拒签）。

### 5.5 与弱项的现场对照（再钉一次）

泵跳闸、定压失压、补水异常、假绿准用，往往先伤**站点环境与设备生存**，再伤空口：上行 12.5 kHz / 4FSK / 2-slot 本来就脆，有人把泵组/定压/补水告警当覆盖病去抬功率——**禁功率战**。先 BD 证泵组与定压补水秩序，再谈 X/I 覆盖干扰。

## 6. 工作实例（12 则，教学虚构，L3）

1. **泵在转想签准用**：泵指示灯转，运维要签准用 → 查 BD1，无泵组台账本期核对 → **拒签**；补 BD-泵。  
2. **压力绿 / 口头补水正常当窗过**：外包称「定压看着绿 / 补水正常」免窗页 → **拒签**；补 BD-补 主人/窗/方法/准用期。  
3. **BA 顶替 BD**：班长用 BA 冷冻水冷却塔签顶本期泵组定压签 → **挂 R**；主贴仍 BD；BA过≠BD过。  
4. **AO / AX 顶替**：站务称漏水与压缩机制冷剂过了泵组补水免做 → **拒签顶替**；AO≠BD、AX≠BD；漏水≠补水台账。  
5. **N 绿免实测**：大屏环境绿，本期实测免 → **拒签**；N绿≠BD过；补 BD-验。  
6. **套邻站表**：外包拷邻站泵组/定压表改机房号 → **BD-验 拒签重测**；禁套。  
7. **功率战**：泵跳闸/定压失压告警，网优要抬功率 → **禁功率战**；先挂 N；缺秩序整改贴 BD。  
8. **关阀冒充**：外包关阀消告警后要求准用 → **禁**；挂 N/R；禁签。  
9. **开旁通冒充**：新人开旁通让压力变绿 → **禁**；挂整改；主贴 BD-治。  
10. **AI/AT/BC 混签**：环境班称 AI 温湿度与 AT 冷凝、BC 机柜PUE过了，泵组定压免 → **拒签**；AI≠BD、AT≠BD、BC≠BD。  
11. **AD 顶实测**：仪表入库签日期还在，实测免 → **拒签**；AD 只支撑仪表；主窗仍 BD。  
12. **泄密发群**：新人公开群贴真实回路编号与定压门限 → **L3 违规**；脱敏重发；挂 BD-治。
