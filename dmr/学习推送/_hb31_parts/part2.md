## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **入库必账必签：备件/金机入正式库前须验收记录 + 脱敏编号 + 台账行；无账不得出库顶岗；账实不符先隔离**。  
2. **金机有基线有期：称「金机」必须有基线记录指针（G/J）与有效期角色；无基线或过期不得当对照锚**。  
3. **轮换有主有记录：出库/轮换/回库须有主人角色与记录；金机按计划轮换，禁口头周转**。  
4. **过期/漂移禁顶岗：基线过期、贴签过期、漂移巡检不过 → 状态改隔离/待检，禁继续准用或对照**。  
5. **禁套：禁套他站他机基线不经本网重基线；禁套他机过期贴签；禁改日期伪装期内**。  
6. **可挂 G/J/Y/AC/R/Q 支撑，但周转与轮换台账主贴 AD；库系统绿灯、假绿不等于已准用（挂 R 提醒）**。  
7. **写频/固件/角色变更走 J 并评估重基线；跨网挂 S，投诉挂 T；禁功率战；保修/巡检抽检可挂 AA**。  
8. **对外/公开仓一律脱敏 L3；禁贴序列号全文/库位坐标/真实站名单位名/联系人**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可、地面无线电台（站）规定决定「台站与设备按什么秩序管」——**备件乱发、过期金机当尺，不是法外运维智慧**。抢救车近效期与 golden unit 公开资料只作故事与方法类比（§2.2）：**有账、有期、近效先出、过期隔离、参考件要维护**——翻译成本网语言就是 AD-周 / AD-换 / AD-账 / AD-准 / AD-治。**这些是周转秩序，不是「无账先发」「过期继续对照」「拷他站基线」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「准用/可顶岗」「金机对照合格入库」、对外宣传「分钟级无账发机」、把隔离机写成准用。允许做的：补验收、补基线、隔离、挂 R/J、内部挂待检。

### 4.2 分诊题：这件事贴 AD 还是贴别的？

| 现场问题 | 先问 | 主贴 |
|----------|------|------|
| 台架上怎么用金机复现故障 | 对照方法 | **G** |
| 写频改了基线怎么回滚 | 变更单 | **J** |
| 金机指标是不是漂了 | 巡检窗 | **手册18** + AD 状态 |
| 活动场次机子检了没 | 贴签准入 | **Y**（常挂 AD） |
| 柜里这台能不能发 | 账、期、准用签 | **AD-周/准** |
| 金机该不该换、换了没记 | 轮换计划 | **AD-换** |
| 库绿灯想直接发 | 有无准用签 | **AD-治 + R** |
| 机动撤回的备件哪去了 | 回库指针 | **AC + AD** |
| 拷了邻网金机码片 | 是否本网重基线 | **AD-治** |

### 4.3 「准用」最小集（AD-准）——缺页不能签「准用/可顶岗」

| 序号 | 最小集项（教学） | 为什么必须有 | 缺了会怎样 |
|------|------------------|--------------|------------|
| 1 | **脱敏资产编号**与实物一致 | 防拿错机、防无账机 | 对不上 → 拒发 |
| 2 | **状态=准用**（非隔离/待修/过期） | 状态机是闸 | 非准用 → 拒发 |
| 3 | **金机：基线记录指针 + 有效期未过** | 尺必须在期内 | 过期 → 拒对照 |
| 4 | **贴签/校准有效期指针**（常挂 Y） | 防过期贴 | 过期/套贴 → 拒准 |
| 5 | **出库主人 + 用途角色 + 预计回库** | 有主可追 | 无主 → 拒发 |
| 6 | **授权本人签「准用」**（首次准入或复检后） | 可复核 | 「系统绿」不够 |
| 7 | **与写频/固件角色边界一致**（变更走 J） | 防旧基线套新码 | 不符 → 挂 J，拒准 |
| 8 | **回库点检勾选**（再次准用前） | 外勤机可能已伤 | 未点检 → 不改回准用 |
| 9 | **漂移巡检指针**（金机，挂手册18） | 期内也可能漂 | 应巡未巡 → 慎当锚 |

> **口诀**：号、态、基、签、主、人、界、回、漂——**九字准用钉**（教学记忆；现场以本网书面备件/金机规程为准，但 **账号 + 期内基线 + 准用签 + 有主人** 几乎不可砍）。  
> **弱项短补（为什么过期金机比坏备件更危险）**：坏备件顶岗，用户马上喊「不通」；**过期金机当尺**，实验室会把好机器判坏、坏机器判好，整网工单方向全反，还看起来「很科学」。这和抢救车发过期急救药一样——**不是「还能用一点」，是「用了会系统性害人」**。

### 4.4 入库与出库清单（AD-周）——缺页不能入正式库 / 不能发

| 清单项（教学） | 像抢救车/药房 | 未齐就入/发？ |
|----------------|--------------|---------------|
| 到货验收（型号角色、数量、外观） | 入库验收 | **否** → 隔离待查 |
| 脱敏编号赋号并贴物理标识 | 药签/基数编号 | **否** |
| 台账行建立（状态初始=在检或在库） | 基数卡建档 | **否** |
| 金机：基线任务挂起（G/J） | 标准样建档 | 无基线不得进「金机准用」 |
| 出库：主人、用途、预计回库 | 取用登记 | **否** → 拒发 |
| 账实盘点差异 | 盘点 | 差异未清 → 冻结相关号 |

### 4.5 轮换与隔离清单（AD-换 / AD-治）

| 项（教学） | 像近效期轮换 | 未齐？ |
|------------|--------------|--------|
| 轮换计划（周期角色以本网为准） | 定期开箱检查/近效替换 | 无计划乱换 → 治理 |
| 换下机：点检 → 在检/隔离/准用回库 | 近效退库调剂 | 换下失踪 → 账不闭环 |
| 换上机：须已准用 | 补新效期药 | 未准用顶上 → 拒 |
| 金机对照窗记录（与谁对、结果角色） | 检查表留痕 | 「对过了」三字不够 |
| 漂移不过 / 外观异常 / 私改写频 | 变色沉淀过期 | **强制隔离** |
| 报废/退役出库闭环 | 销毁/退库流程 | 禁回流准用 |

> **口诀**：计划换、换下检、换上准、对照留痕——**轮换八字钉**（教学；**换上须已准用**几乎不可砍）。

### 4.6 与 G / J / 手册18 / Y / AC 的分工表（钉死，防互相顶替）

| 问题 | 谁主答 | AD 做什么 |
|------|--------|-----------|
| 怎么在台架对照 | **G** | 提供「哪台期内金机」 |
| 基线怎么改、怎么回滚 | **J** | 更新台账基线指针与有效期 |
| 漂了没有 | **手册18** | 漂则改状态隔离，禁准用 |
| 活动场次贴签准入 | **Y** | 库内周转账与场次清单对齐 |
| 机动撤回的机 | **AC** 回库指针 | **必须**写入 AD 台账 |
| 能不能发、期过没过 | **AD** | 主职 |

> **口诀**：G 是量法，J 是改尺规矩，18 是看尺歪没歪，AD 是**哪把尺在不在保质期内、借还清不清**。

### 4.7 台账路径（一台机跑完一生片段）

| 时点（教学） | 台账动作 | 主贴 |
|--------------|----------|------|
| 到货 | AD1 入库建号；状态在检 | AD-周 |
| 基线/贴签完成 | AD2/AD3；签准用 AD5 | AD-准 |
| 出库顶岗 | AD4；主人时限 | AD-周 |
| 轮换点 | AD6；换上换下 | AD-换 |
| 回库/AC 撤收 | AD7；状态更新 | AD+AC |
| 过期/漂移 | 隔离；禁准用 | AD-治 |
| 公开交班 | 仅脱敏摘要 | AD8 |

### 4.8 签字前 15 分钟清单（可复印）

| 分钟 | 动作 |
|------|------|
| 0–3 | 打开台账卡：脱敏号、状态、主人、基线/贴签有效期角色 |
| 3–6 | AD1/AD4：账实是否一致；出库是否有主 |
| 6–9 | AD2/AD3/AD5：金机基线期内？贴签一致？准用签在？ |
| 9–12 | AD6：若轮换，换上是否已准用；对照窗记录 |
| 12–15 | AD7/AD8：回库点检或隔离；L3；拒签卡 |

夜班压缩版：至少确认「**有账 + 期内准用 + 有主人 + 非隔离**」四项——**四项缺一仍禁发、禁当金机锚**。

### 4.9 状态机表（钉死）

| 状态 | 含义（教学） | 允许动作 |
|------|--------------|----------|
| 在检 | 到货或回库待检 | 禁顶岗；可送检/做基线 |
| 在库 | 检毕未签准用或备货 | 禁当金机锚（除非另有准用） |
| **准用** | 期内+签准用 | 可出库顶岗/可作金机（若金机角色） |
| 在岗 | 已出库使用中 | 须有主人时限；回库改状态 |
| 待修 | 故障待修 | 禁准用 |
| **隔离** | 过期/漂移/可疑/套基线嫌疑 | 禁顶岗禁对照 |
| 报废 | 退役闭环 | 禁回流 |

> **口诀**：准用才是闸；**绿灯系统态 ≠ 准用签**。


### 4.10 金机「期内」不等于「免巡」——和手册18 的咬合表

| 情况 | 手册18 | AD |
|------|--------|-----|
| 到巡检窗，指标仍在容差 | 记「未漂」 | 保持准用；更新巡检指针日期角色 |
| 到巡检窗，指标出容差 | 记「漂移」 | **立即隔离**；禁对照；安排重基线或退役 |
| 未到巡检窗，但外勤磕碰/私改写频嫌疑 | 可提前触发巡检 | 先隔离待检，不凭感觉继续当锚 |
| 刚完成 J 变更重基线 | 新基线日起算巡检周期 | AD 更新基线有效期与准用签 |

> **口诀**：期内管「日历没过期」；巡检管「尺子还直不直」——**两道闸，缺一不可**。

### 4.11 备件品类最小分工（教学，不发明库存定额）

| 品类角色 | 周转关注点 | 常见拒发点 |
|----------|------------|------------|
| 手台/车台整机 | 写频角色是否与用途一致；电池电量直觉 | 无准用、写频角色不符（挂 K/J） |
| 功放 / 信道机模块 | 回库必点检；禁带伤准用 | 未点检改回准用 |
| 馈线 / 跳线 / 接头 | 外观与通断直觉；驻波相关故障高发 | 账实不符、混用他站线材角色 |
| 金机（对照专用） | 基线期 + 漂移巡检 + 少外勤滥用 | 当普通备件顶岗磨损耗尺 |
| 测试辅件（负载/衰减等） | 校准有效期指针 | 过期仍出具「定量」结论 |

> **金机尽量不做普通顶岗备件**：抢救车里的「标准对照液」不会拿去当日常输液——磨坏了，整网对照失真。

### 4.12 与保修 / 首年巡检（AA）抽检怎么配合

交维后首年巡检（手册28）若抽到「备件柜账实、金机期内、轮换记录」，**抽检结论可挂 AA，缺项整改主贴仍是 AD**——AA 不替代建账，AD 不替代巡检计划本身。保修期内设备返修进出库，同样走 AD-周，并在台账备注保修单号角色（脱敏）。

## 5. 现场映射：原话速查、对话脚本、夜班、禁写词、交班口述

### 5.1 原话 → 贴纸速查

| 你听到的原话 | 先贴 | 下一句该问 |
|--------------|------|------------|
| 「柜里有就先拿走补账」 | AD-周 | 台账行？脱敏号？主人？ |
| 「金机过期几天还能对照」 | AD-准 | 基线有效期？漂移巡检？ |
| 「他站金机码片拷过来」 | AD-治 | 本网重基线单号？禁套 |
| 「库系统全绿，发吧」 | AD-治 + R | 准用签？期内？假绿≠准用 |
| 「金机永不换更标准」 | AD-换 | 轮换计划？手册18 指针？ |
| 「机动撤回的机不知哪去了」 | AC + AD | 回库指针进账了吗？ |
| 「功率抬一点顶着」 | AD-治 + S | 禁功率战 |
| 「序列号发群表扬周转」 | AD-治 | 脱敏 L3；撤回 |

### 5.2 三段对话脚本（可练）

**脚本 A · 拒发（无账）**  
对方：「应急缺机，先拿一台，账明天补。」  
你：「AD-周：无账不得出库顶岗。今晚能建脱敏号、主人、用途、预计回库，我才能走准用闸——不是拒支援，是拒无账机满天飞。」

**脚本 B · 拒对照（过期金机）**  
对方：「金机标签还在，先对一把给结论。」  
你：「AD-准：基线有效期与漂移巡检指针呢？过期金机当尺，结论一律不入库。先隔离，重基线或换期内金机。」

**脚本 C · 拒套基线**  
对方：「邻市金机码片拷过来，参数差不多。」  
你：「AD-治：禁套他站他机基线。要当本网金机，走本网 G/J 重基线，台账换新有效期——拷贝不是基线。」

### 5.3 夜班压缩卡（四问）

1. **账**：要发的机有没有台账行与脱敏号？  
2. **准**：状态准用？基线/贴签期内？准用签在？  
3. **主**：出库主人与预计回库？  
4. **治**：有没有过期顶岗、套基线、假绿、公开泄密？

### 5.4 禁写词（三联单/交班）

- 禁：序列号全文、库位 GPS、真实站名单位名、联系人电话、真实频点。  
- 禁：「回头补账」「过期也能对」「拷他站基线」「系统绿就行」。  
- 改写：用脱敏编号、状态、角色主人、相对道号。

### 5.5 交班口述 30 秒模板

> 「AD 周转：脱敏号××状态××；金机基线有效至角色××；今夜出库××台主人××；待回库××；隔离××；AC 回库指针××；公开已 L3。下一班先对隔离与过期预警。」

## 6. 工作实例（10 则，教学虚构，L3）

1. **无账发机**  
   现象：夜班从柜里拿车台顶岗，未登台账。  
   处置：AD-周 追回或补建账并补准用核；三联单记治理。  
   教训：支援速度不等于无账机。

2. **过期金机对照**  
   现象：金机基线过期 40 天，仍出具「对照合格」。  
   处置：撤销结论；隔离金机；换期内金机重对；挂手册18。  
   教训：过期尺比坏机更害人。

3. **套他站基线**  
   现象：写频员拷邻网金机码片标「本网金机」。  
   处置：AD-治；取消金机角色；本网重基线（J/G）。  
   教训：拷贝≠基线。

4. **假绿放行**  
   现象：资产系统显示 Available，班长直接发重大活动场。  
   处置：挂 R；查准用签与 Y 贴签；缺则拒发。  
   教训：系统态≠AD-准。

5. **金机永不轮换**  
   现象：同一台金机使用两年未轮换未巡漂移。  
   处置：AD-换 强制轮换窗；手册18 巡检；必要时退役。  
   教训：不用的近效药也会过期——常用的尺也会磨。

6. **机动回库失踪**  
   现象：AC 签撤完，备件未进 AD 账。  
   处置：AC+AD；追实物；补回库点检；禁直接改准用。  
   教训：撤完指针必须接台账。

7. **热备顶岗未改状态**  
   现象：热备已在岗两周，台账仍显示在库准用。  
   处置：补出库行与主人；状态改在岗。  
   教训：账实长期背离是事故温床。

8. **批量 OTAP 后未重基线**  
   现象：手册14 批量升级后，金机未走 J 重基线仍对照。  
   处置：挂 J+AD；冻结对照结论；重基线后再准用。  
   教训：固件变了，尺的刻度也可能变。

9. **功率战顶岗**  
   现象：备件机被抬功率压邻居。  
   处置：禁功率战；挂 S；AD-治；参数回写走 J。  
   教训：备件不是功率战工具。

10. **公开仓泄密**  
    现象：把序列号全文与库位发到公开群。  
    处置：撤回；L3 重发；AD-治。  
    教训：周转效率可以表扬，编号必须脱敏。


11. **把金机当普通顶岗**  
    现象：缺机时把唯一金机发给现场用一周。  
    处置：AD-换/治；追回；点检+漂移巡检；必要时重基线；热备应另备非金机顶岗机。  
    教训：尺拿去干活，回来可能已不是尺。

12. **隔离机回流准用**  
    现象：隔离区机器被好心人「擦干净」放回准用架，未重检。  
    处置：追回隔离；强制在检流程；台账记治理。  
    教训：隔离不是「暂时放一下」的货架。
