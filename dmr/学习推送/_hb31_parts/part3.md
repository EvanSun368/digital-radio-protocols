## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 一句话（教学） |
|------|----------------|
| **备件** | 用于顶岗替换的手台/车台/模块等（非正在主用编制内的那一台角色） |
| **金机** | 已知基线、用于对照的参考机（golden unit 直觉）；**不是**「最好的新机」同义词 |
| **基线** | 金机在规定方法下记录的参考结果与配置指针（挂 G/J） |
| **AD-周** | 入库出库回库隔离的周转秩序 |
| **AD-换** | 金机/热备按计划轮换 |
| **AD-账** | 台账、状态机、主人、脱敏编号 |
| **AD-准** | 期内+签准用才可顶岗/当锚 |
| **AD-治** | 过期顶岗、套基线、假绿、伪账等治理 |
| **准用** | 授权签过的可用状态；≠系统绿灯 |
| **隔离** | 过期/漂移/可疑，禁顶岗禁对照 |
| **轮换** | 按计划换上换下并留痕 |
| **近效先出** | 故事借语：先消耗更近有效期的库存（FIFO/FEFO 直觉） |
| **假绿** | 系统/屏显示可用，但无准用签或已过期 |
| **套基线** | 把他站他机基线当成本网金机基线 |
| **回库点检** | 外勤返回后的最小检查，通过前不改回准用 |
| **九字准用钉** | 号态基签主人界回漂（教学记忆） |
| **轮换八字钉** | 计划换、换下检、换上准、对照留痕 |
| **与 G/J/18 分工** | 量法 / 改尺 / 看歪；AD 管账与期 |

**易错观念**

- ❌「柜里有就能发」→ ✅ 入库必账，准用才发。  
- ❌「金机标签=永远标准」→ ✅ 有基线有期，漂移要隔离。  
- ❌「拷他站基线更快」→ ✅ 禁套；本网重基线。  
- ❌「系统绿=准用」→ ✅ 假绿挂 R，主贴 AD。  
- ❌「机动撤完机自然回库」→ ✅ AC 指针必须接 AD 账。

## 9. 自测（12 题）+ 参考答案

1. 贴纸 AD 五个子类是什么？各用四个字以内说明。  
2. 抢救车/药房故事里，「近效先出 / 过期隔离」主要对应 AD 哪两段？  
3. 八条硬规则里，哪一条要求入库必账必签？  
4. 为什么过期金机比坏备件往往更危险？  
5. 「准用」至少要具备哪几样（九字准用钉里不可砍的）？  
6. 金机永不轮换有什么问题？主贴哪一子类？  
7. AD 与 G / J / 手册18 的分工一句话？  
8. 套他站金机基线，主贴什么？能不能直接当本网金机？  
9. 库系统绿灯想发机，应挂什么提醒？主贴谁？  
10. 机动 AC 撤完但备件未进账，应挂哪两张？  
11. 批量 OTAP 后金机未重基线仍对照，应走什么变更贴纸？  
12. 公开材料能不能贴序列号全文与库位？依据哪条规则？

### 参考答案

1. **周**（周转出入库）、**换**（金机/热备轮换）、**账**（台账状态主人）、**准**（期内准用签）、**治**（过期套基线假绿泄密）。  
2. **AD-换** 与 **AD-准/治**（近效轮换；过期隔离禁顶岗）。  
3. **规则1**。  
4. 它会系统性判错好坏，整网工单方向反转，还看起来「科学」。  
5. **脱敏号与账、状态准用、期内基线/贴签、准用签、出库主人**（规则1–4；九字钉核心）。  
6. 磨损与漂移积累，尺会歪；主贴 **AD-换**（并挂手册18）。  
7. **G 量法、J 改尺、18 看歪、AD 管哪把尺在不在保质期与借还清不清**。  
8. **AD-治**；**不能**，须本网重基线。  
9. 挂 **R**；主贴 **AD**（规则6）。  
10. **AC + AD**。  
11. **J**（并 AD 更新基线期；规则7）。  
12. **不能**；**规则8 脱敏 L3**。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AD** 五子类：周 / 换 / 账 / 准 / 治——双字母续写的第四张，负责备件与金机「账在不在、期在不在、轮换清不清」。  
- 故事：医院抢救车 / 药房近效期——入库贴签 → 效期上架 → 近效先出轮换 → 过期隔离退库；金机是「标准样」，过期不能当尺。  
- 阶段梯：入库建账 → 标定贴签 → 准用 → 在岗/轮换 → 回库/隔离/报废。  
- 八条硬规则：**入库必账必签**；**金机有基线有期**；**轮换有主有记录**；**过期漂移禁顶岗**；**禁套他站他机基线**；**主贴 AD，假绿≠可用**；**变更走 J、复测挂回**；**脱敏 L3**。

### 11.2 下一篇手册候选（本篇不写正文）
- **隧道/地铁区间联测与换乘责任界面**（与 AB/I/S/N 咬合）  
- **油机/市电切换与机房供电巡检边界**（与 AC 展开电源勾选、AA 巡检咬合，仍 L3）  
- **电池与充电器梯队轮换与容量抽检台账**（与 AD 备件周转咬合，可作 AD 延伸或独立 AE）

### 11.3 给带新人的三句话
1. 备件不是柜里有就能发：入库必账，准用才出库，回库要点检。  
2. 金机不是贴了标签就永远标准：有基线有期，漂移要隔离，禁套他站基线。  
3. 假绿挂 R；主贴 AD；变更走 J；机动回库接 AC；公开脱敏 L3。
