## 1. 为什么要写这篇手册（动机 + 现场对话）

前三十六篇手册从 A–E 协议一路写到 AI 温湿度联锁：其中 **AD 回答「备件仪表准用」**，**AA 回答「交维后首年巡检」**，**AB 回答「室分复测」**，**AI 回答「机房温湿度与空调联锁」**，**AH 回答「多业主合路/POI 界面」**，**N 回答「电源监控/对时/告警风暴」**。可还没有单独钉死一件事——**天馈不是「反射告警灭就能签驻波过」：驻波/VSWR 测点与门限、测向（前向/反射）要钉死；跳线/接头/馈线段要有主人有准用期；抽检窗与方法要书面固定；本组本站本期实测禁套他站他期——能不能签「天馈/驻波准用」？** 这就是本篇的 **AJ**——**天线驻波与跳线老化抽检台账**。

- 运维岗：「网管反射告警灭了，驻波肯定过。」——**无驻波台账/测点仍准用** = 本篇拒签（规则1）。  
- 外包：「跳线谁管口头说一声，接头谁拧也口头。」——**跳线接头无主人无准用期** = 规则2。  
- 网优：「监控反射灯灭，不用做 VSWR 抽检了。」——**只看监控灯，无抽检窗/方法** = 规则3。  
- 外包：「邻站上周驻波曲线参数差不多，拷过来改个站号。」——**套他站他期** = 规则4。  
- 班长：「AD 仪表签还在，AA 首年巡检也过了，天馈驻波也能签。」——**用 AD/AA/AB/AI/AH/N 顶替 AJ** = 规则6。  
- 站务：「大屏反射绿了，天馈准用就算过。」——**假绿≠会签放行** = 规则5/6。  
- 网优：「驻波告警响了，功率抬一点稳住。」——**功率战** = 规则7。  
- 宣传岗：「把真实站名、跳线序列号、驻波曲线发群表扬。」——**L3 违规** = 规则8。  

这几句背后是同一件事：

> **「天线驻波与跳线老化抽检」在现场至少有五个坑**：**① AJ-驻** 驻波/VSWR 台账与测点、门限、测向（前向/反射）角色入账，禁「网管绿就算驻波过」「手摸跳线不烫就算过」；**② AJ-馈** 跳线/接头/馈线段有主人、有准用期（进站日期、扭矩/密封/防水帽、老化外观等级），禁口头「谁管馈线」；**③ AJ-抽** 抽检窗与方法钉死（VSWR/回波损耗测量窗、仪表 AD 准用、到场角色），禁「只看监控反射告警灯」；**④ AJ-验** 本组本站本期实测（禁套他站他期曲线），会签才放行「天馈/驻波准用」；**⑤ AJ-治** 治理（假绿、用 AD/AA/AB/AI/AH/N 顶替、伪造驻波账、功率战、泄密）。  
> 把 ①–⑤ 当成「反射告警灭就能签」「手摸不烫就算过」「口头说一声谁管跳线」，每一次换跳线、每一次改门限、每一次驻波告警风暴，都会先吵「测点是谁的、跳线谁负责、曲线是不是本期的」。

本篇目标：能背出**驻波台账 + 跳线老化抽检工作流**；会用新贴纸 **AJ（驻 / 馈 / 抽 / 验 / 治）**；会填**插页 AJ（AJ1–AJ8）**和《本网天线驻波与跳线老化抽检台账卡》；能用「**医院中心供氧/负压管路接头渗漏与软管老化抽检**」故事讲清压力表绿≠接头不漏、网管反射灭≠本期 VSWR 过、套邻病房管路账=拒签、用 AD/AA/AB/AI 签顶 AJ 天馈签=拒签、假绿≠会签放行；能拒绝无主跳线、套曲线、用他贴顶替本期天馈签、假绿放行；自测过关后，回库把本网最近一次天馈驻波抽检或换跳线后复验（L3）重对一遍：驻波账、跳线主人、抽检窗、本期实测、会签项、拒签项。

**本篇硬禁令（写进脑子）**：凡引法规与标准只指向已公开发布的文书标题与官方链接（无线电管理条例、频率使用许可管理办法、地面无线电台（站）管理规定、国无办〔2025〕1号；**只作故事类比**的医院中心供氧/负压管路与消防水带接头渗漏/软管老化公开资料标题，以及公开的 VSWR/回波损耗/同轴/跳线/天线维护概述资料），**程序、期限、责任以原文与属地最新要求及本网制度 / 合同为准，本篇只作教学转述，不发明条款号与内部口径**；医院医用气体管路抽检、消防水带老化抽检、境外 VSWR/同轴公开科普**不是**中国专网台站「贴纸 AJ」的法定依据；**现象与台账一律用相对道号、角色标签、脱敏站/机房编号，禁真实频点 / 站名 / 机房全称 / 跳线序列号全文 / 单位名 / 联系人**；**不教伪造驻波台账、不教功率战、不教规避监测、不教套他站曲线、不教假绿顶替、不教绕过告警**；AD / AA / AB / AI / AH / N / R / J 各管各的——**天线驻波与跳线老化抽检主贴 AJ**；备件仪表回 AD，首年巡检回 AA，室分复测回 AB，温湿度联锁回 AI，合路界面回 AH，监控风暴回 N——**AJ 管「驻波·跳线·抽检秩序」，不替代 AD 的仪表准用期本身，也不替代 AA 的首年巡检日历，更不替代 AB 的室分复测门卫**。

## 2. 总图 / 故事：天馈驻波像「医院中心供氧/负压管路接头渗漏与软管老化——不能只看压力表绿」

### 2.1 一句话：网管反射告警灭不是「驻波过了」、手摸跳线不烫不是「接头未老化」——要先建驻波台账与测点，跳线接头有主人有准用期，抽检窗与方法钉死，本组本站本期实测，会签才放行；假绿、套邻站曲线、用 AD/AA/AB/AI/AH/N 顶替，一律拒签

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  医院中心供氧/负压管路接头渗漏与软管老化抽检  =  本网 AJ   │
   │                                                              │
   │  压力表/回压测点·门限·测向钉死     ≈ AJ-驻  驻波台账钉死   │
   │  软管/接头有主人有准用期·外观等级 ≈ AJ-馈  跳线有主有期   │
   │  渗漏抽检窗·方法·到场角色钉死     ≈ AJ-抽  抽检窗与方法   │
   │  本期实测禁套邻病房管路账         ≈ AJ-验  本组本站本期   │
   │  假绿≠放行·顶替·伪造账·功率战   ≈ AJ-治  治理与脱敏 L3   │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **驻波有账，跳线有主，抽检有窗，本期实测，会签才放。**  
> 反射告警灭还无驻波台账 = 手术室中心供氧只看压力表绿不查接头渗漏——**拒签「天馈/驻波准用」**。  
> 监控反射灯灭但半年没 VSWR 抽检 = 负压管路绿灯亮着却从未做软管老化抽检——**假绿，挂 R，拒签**。

### 2.2 「医院中心供氧/负压管路接头渗漏与软管老化」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **驻** | 供氧/负压测点入账→压力/回压门限→测向（前向/回流）书面 | 驻波/VSWR 台账与测点、门限、测向钉死；禁「网管绿就算过」「手摸不烫就算过」 | AJ-驻 |

| **抽** | 渗漏/老化抽检有窗、有方法、有到场；禁「看一眼压力表绿」 | 抽检窗与方法（VSWR/回波/外观）、到场角色书面固定 | AJ-抽 |

> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：VSWR/回波损耗/同轴跳线公开概述强调**测点要记、接头要验、绿灯不算过**（§10，**只借秩序直觉**）；医院医用气体管路与消防水带接头渗漏/软管老化公开资料强调**压力表绿≠接头不漏、软管未老化**（§10，**只作故事类比**）。本篇只借这串顺序——**本网 VSWR 门限、抽检方法、合格标准以本网制度与合同为准**。

### 2.3 和手册31（AD）/ 28（AA）/ 29（AB）/ 36（AI）/ 35（AH）/ 15（N）等的咬合（指针，不重写）

```text
        │  缺签 / 假绿顶替 → 拒签准用
        ▼
  ⑥ 变更（换跳线/改门限/换天线）→ 走 J + 触发再抽检/再验（常挂 N 看监控、挂 AD 看仪表、挂 AB/AI/AH 看相关）
```

> **一句话分辨**：**AD** 回答「仪表准用期**到了没有**」；**AA** 回答「首年巡检日历**到了没有**」；**AB** 回答「室分复测**过了没有**」；**AI** 回答「温湿度联锁**过了没有**」；**AJ** 回答「这一站天馈驻波测点 + 这一组跳线接头 + 这一窗 VSWR 抽检**台账清不清、跳线有没有主、本期过了没有**」。**五个问题，五张（类）贴纸，不能一笔带过。**

### 2.6 驻波与跳线抽检最小工作流（背下来）

```text
  AJ-驻 驻波台账 + 测点/门限/测向钉死
       ├─→ 有台账+测点？跳线接头有主人准用期？ ──否──→ 拒签 / 补账补主
       └─→ 是
  AJ-抽 约窗 + 书面方法 + 到场勾选 + 仪表 AD 期内
       │
  AJ-验 本组本站本期：VSWR/回波 → 外观老化等级 → 禁套声明
       │  套曲线 / 只看绿灯 → 拒签
       ▼
  会签「天馈/驻波准用」或挂整改；重大未闭禁签准用
       │
  放行或拒签；公开材料 L3；变更走 J 再触发
```

## 3. 核心交付：插页 AJ + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AJ（而不是先贴 AD / AA / AB / AI / N）

| 现场要办的事 | 主贴 | 说明 |
|--------------|------|------|
| 驻波台账、跳线主人、VSWR 抽检签、假绿拒签 | **AJ** | 本篇主职 |
| 驻波表/网络分析仪/定向功率计入库准用 | **AD**（可挂 AJ） | 仪表准用≠本期天馈抽检过 |
| 交维后首年巡检日历 | **AA**（可挂 AJ） | 首年日历≠本期抽检窗 |
| 室分复测 | **AB**（可挂 AJ） | 室分过≠天馈驻波过 |
| 温湿度联锁巡检 | **AI**（可挂 AJ） | 环境过≠天馈过 |
| 合路/POI 界面 | **AH**（可挂 AJ） | 界面清≠跳线老化过 |
| 监控对时、告警风暴 | **N**（可挂 AJ） | 反射灯灭≠抽检过 |
| 大屏反射绿想直接签天馈准用 | **AJ-治 + R** | 假绿≠天馈通过 |
| 套邻站旧驻波曲线 | **AJ-治** | 禁套；须本期本组本站实测 |

### 3.2 插页 AJ · 驻 / 馈 / 抽 / 验 / 治（挂在总三联单或天馈/驻波单后）

| 插页行 | 检查项（教学） | 缺了怎么办 |
|--------|----------------|------------|
| **AJ1** | 驻波台账在：测点角色、门限角色、测向（前向/反射）角色书面 | 缺 → **拒签准用** |
| **AJ2** | 测点清单可追溯：段位角色（室内跳线/室外馈线/天线口）、最近测量日角色 | 缺 → **拒「网管绿就算过」** |
| **AJ3** | 跳线/接头/馈线段有主人：主人角色；准用期（进站日/扭矩密封防水帽/老化外观等级）书面 | 缺 → **拒签** |
| **AJ4** | 抽检窗书面在（日期角色/天窗角色）；方法（VSWR/回波损耗/外观等角色项）书面；到场角色勾选 | 缺 → **拒抽检签** |
| **AJ5** | 本组本站本期实测记录在；脱敏站与窗一致；禁套他站他期 | 套/缺 → **拒签** |
| **AJ6** | 驻波表/网络分析仪/定向功率计在 AD 准用期内（挂 AD 指针）；条件角色项按本网规程记录 | 仪表过期 → **拒认测值或整改** |
| **AJ7** | 「天馈/驻波准用」会签：相关授权本人签；重大未闭禁准用 | 缺签 → **拒签** |
| **AJ8** | 公开材料 L3；变更项走 J；禁功率战叙事 | 违 → **治理** |

> 插页每一行都对应硬规则：AJ1/AJ2→规则1，AJ3→规则2，AJ4→规则3，AJ5/AJ6→规则4，AJ7→规则5，顶替/假绿→规则6，AJ8→规则7/8。**任何一行缺项，就停在那一行。**

### 3.3 和总三联单怎么写（接手册06）

- **现象栏**：写「驻波台账断档 / 跳线无主 / 抽检未实测 / 套他站曲线 / 网管假绿 / 接头渗水外观异常」等可复核现象，**不写空口玄学**。  
- **贴纸栏**：主贴 **AJ**；支撑可贴 AD / AA / AB / AI / AH / N / R / J。  
- **处置栏**：拒签 / 补驻波账 / 补跳线主人 / 重开抽检窗 / 重测 / 挂 R/N/J——**写动作，不写空口字段**。  
- **脱敏**：站/跳线用角色编号；禁单位名全文、禁真实站名、禁跳线序列号全文。

### 3.4 《本网天线驻波与跳线老化抽检台账卡》预告

§7 给出可复印模板：封面拒签门槛、驻波页、跳线主人页、抽检窗页、实测页、会签准用页、夜班速填五行。**一张卡跑完一窗驻波抽检/一次换跳线后复验：驻→馈→抽→验→签**；与 AD 仪表、AA 首年、AB 室分、AI 温湿度指针对齐，避免「仪表签还在就当天馈过」「首年绿就当驻波过」「室分复测绿就当跳线清」。
