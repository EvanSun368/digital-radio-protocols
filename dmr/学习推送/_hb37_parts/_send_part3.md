## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 一句话（教学） |
|------|----------------|
| **驻波 / VSWR** | 电压驻波比；前向与反射关系的公开常识词（门限以本网为准） |
| **回波损耗** | Return Loss；与 VSWR 可互换表达匹配好坏 |
| **测向** | 前向功率 / 反射功率测量角色 |
| **跳线** | 机房内短段同轴连接（教学词） |
| **馈线** | 室外/塔上长段同轴或波导段（教学词） |
| **准用期** | 进站、扭矩密封防水帽、外观等级等到期前可用 |
| **AJ-驻** | 驻波台账与测点/门限/测向钉死 |
| **AJ-馈** | 跳线/接头有主人有准用期 |
| **AJ-抽** | 抽检窗与方法、到场、仪表 AD 齐全 |
| **AJ-验** | 本组本站本期实测禁套 |
| **AJ-治** | 假绿、顶替、套曲线、功率战、泄密治理 |
| **假绿** | 系统/大屏显示正常，但无本期天馈会签 |
| **套曲线** | 把他站他期记录改号当本期 |
| **九字天馈钉** | 驻馈窗法站表签闭密（教学记忆） |
| **与 AD/AA/AB 分工** | 仪表 / 首年日历 / 室分；AJ 管天馈驻波门卫 |
| **上行更脆** | 高驻波/跳线老化时常先伤上行体验 |
| **供氧隐喻** | 压力表绿≠接头不漏；软管老化要抽检 |
| **反射告警** | 监控侧反射/驻波类告警；灯灭≠抽检过 |

**易错观念**

- ❌「网管反射绿=天馈过」→ ✅ 假绿挂 R，主贴 AJ。  
- ❌「AD/AA/AB/AI/AH 签=永远不用贴 AJ」→ ✅ 均不顶替 AJ 本期。  
- ❌「室分复测绿=跳线老化过」→ ✅ AB≠AJ。  
- ❌「拷邻站曲线更快」→ ✅ 禁套；本窗本组本站实测。  
- ❌「驻波告警就抬功率」→ ✅ 禁功率战；先 AJ/N。  
- ❌「手摸不烫=未老化」→ ✅ 外观等级+本期测值入账。
