## 3. 核心交付：插页 BN + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 BN（而不是先贴 BB / BK / AX / BJ / BM / AI / AT / AU / BG / BA / N）

- 要签「机房精密空调冷凝器盘管清洗与翅片完好巡检准用」、要开冷凝器盘管清洗交底窗、要交底翅片完好侧 → **主贴 BN**。
- 风冷室外机与冷凝侧边界（机位/回路/风扇转、进出风净距）→ **BB**（手册55）。**BB ≠ BN**；风扇转 ≠ 清洗/翅片过；BB 提到翅片清洁只是冷凝侧窗角色，不单独给本篇台账；不重写 BB。
- 蒸发器盘管清洗与翅片完好 → **BK**（手册64）。**BK ≠ BN**；蒸发侧 ≠ 冷凝侧；不重写 BK。
- 压缩机与制冷剂边界 → **AX**。吸排气压力与过热度过冷度 → **BJ**。膨胀阀开度与过热控制 → **BM**。**AX ≠ BN；BJ ≠ BN；BM ≠ BN**。
- 温湿度联锁 → **AI**。机内冷凝加湿 → **AT**。滤网压差/换网 → **AU / BG**。冷冻水冷却塔 → **BA**。冷却水泵/冷凝水侧 → **BH**。漏水汇排 → **AO**。
- 进机房/上屋面室外机区先 **AN**（门禁过 ≠ 交底过；**不教攀爬或不安全室外作业步骤**）。气灭 → **AL**。风暴先 **N**，缺秩序整改仍 **BN**；上述硬禁项与功率战一律禁止。
- 假绿/顶替挂 **R**；变更走 **J** 后再验 BN。
- 无精密空调，或无风冷冷凝器盘管/翅片路径（例如纯冷冻水 CRAH、水冷冷凝器/壳管且无翅片盘管路径） → 书面「不适用」；冷冻水/塔侧问 BA，**不得**用 BN 顶 BB/BK/AX/BJ/BM 等，也不得用它们顶 BN。清洗侧不适用 ≠ 翅片侧自动免；翅片侧不适用 ≠ 清洗侧自动免。BK 路径过了或 BK 不适用 ≠ 冷凝器路径自动免。

### 3.4 与总三联单怎么写（脱敏 L3）

- **现象栏**：写「盘管缺账 / 看着干净无核对 / 口头洗过 / 风扇转顶清洗 / 翅片看着齐或看着干净 / 一侧顶另一侧 / 他贴顶 BN / 套票 / 不安全清洗教条/高压水乱冲/运行中冲洗/旁通绕联锁嫌疑」等角色化现象；**不写**真实机房全称、精密空调或冷凝器序列号全文、可还原盘管细节或门限全文。

- **会签栏**：准用 / 有条件整改 / 拒签；假绿 ≠ 放行。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **冷凝器盘管清洗台账钉死**：冷凝器盘管角色与清洗窗、清洗前后对照各自有账（编号脱敏）；禁「盘管看着干净就算过」「口头说洗过了」「风扇转就算清洗过」；清洗过 ≠ 翅片过，翅片过 ≠ 清洗过。
2. **翅片完好侧有主有窗有方法/准用期（与清洗侧分开看）**：弯曲、压扁、缺失、大面积倒伏或堵塞对照以本网与 OEM 书面为准；每次翅片交底有主人角色、有书面窗、有方法、有准用期；禁「翅片看着齐/看着干净就算过」「套邻站翅片照片」；翅片过 ≠ 清洗过；BB 的翅片清洁角色 ≠ 本完好窗。
3. **边界窗与方法钉死**：书面固定；方法含与 BB/BK/AX/BJ/BM/AI/AT/AU/BG/BA/N 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明化学清洗配方、高压水乱冲、运行中冲洗或绕联锁操作教条；**不重写 BB/BK/AX/BJ/BM 全文**）；禁「窗再说」「绕室外机/冷凝风机/高压等保护联锁」「开旁通冒充」「不安全化学清洗教条」「高压水乱冲教条」「未授权在运行中冲洗/带电湿洗教条」「伪造台账」。
4. **本组本机房本期实测禁套他站他期**：实测记录、盘管清洗对照、翅片完好必须本期本组本机房；套邻站/邻院账 = 拒签。
5. **会签才放行**：缺授权会签不得签「机房精密空调冷凝器盘管清洗与翅片完好巡检准用」；假绿 ≠ 放行。
6. **禁顶替 BB/BK/AX/BJ/BM/AI/AT/AU/BG/BA/AO 等，主贴 BN，假绿≠放行挂 R**：他贴签都不顶本期冷凝器盘管清洗/翅片完好签。**尤其钉死 BB ≠ BN、BK ≠ BN、AX ≠ BN、BJ ≠ BN、BM ≠ BN，以及 AI/AT/AU/BG/BA/BH/AO ≠ BN；风扇转 ≠ 清洗/翅片过；冷冻水/冷却塔 ≠ 风冷冷凝器盘管。**
7. **异常风暴挂 N；变更走 J；禁功率战；禁绕室外机/冷凝风机/高压等保护联锁；禁旁通；禁不安全化学清洗教条；禁高压水乱冲翅片教条；禁未授权在运行中冲洗/带电湿洗教条；禁伪造**：上行更脆时先问秩序，不先抬功率。盘管/翅片乱窗、假绿、冷凝高压/高温告警风暴常被误当「覆盖病」→**禁功率战**；挂 N；变更走 J。
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/精密空调或冷凝器序列号全文/可还原坐标与联系人；禁公开传播未脱敏盘管细节、清洗参数与门限**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签准用、无实测冒充边界过、绕联锁/旁通/不安全清洗或高压水乱冲冒充秩序齐，不是法外运维智慧**。医院/数据中心公开资料只作故事类比（§10）。

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签准用、对外宣传「看着干净/风扇转秒过」、把未实测写成已过、把绕联锁/旁通/不安全清洗教条写成秩序齐。允许做的：补账、补窗、重开边界窗、挂 R/N/J、内部挂整改。

### 4.3 「机房精密空调冷凝器盘管清洗与翅片完好巡检准用」最小集（BN）——缺页不能签准用

1. 盘管清洗台账页（冷凝器盘管·清洗窗·清洗前后对照；含看着干净≠台账过、口头洗过≠窗过、风扇转≠清洗过、一侧过≠另一侧过勾选）
2. 翅片完好侧主人与书面窗、方法、准用期页（弯曲/压扁/缺失/堵塞分开看；含禁看着齐或看着干净、禁套邻站照片、BB 翅片清洁角色≠本完好窗勾选）
3. 书面边界窗与方法页（与 BB/BK/AX/BJ/BM/AI/AT/AU/BG/BA/N 分工；以本网与 OEM 为准；声明不重写 BB/BK/AX/BJ/BM）
4. 本期本组本机房实测记录（盘管清洗对照、翅片完好分别留痕；禁套声明）
5. BB/BK/AX/BJ/BM 及 AI/AT/AU/BG/BA/BH/AO 边界勾选（防顶替）
6. AD/AN/AL/N/AA/AQ 边界勾选（入库≠本期窗；门禁/气灭过≠交底过；N 绿≠BN 过）
7. 会签页（准用或有条件整改）
8. 未闭项清单（有则挂整改，重大未闭禁签准用）
9. 脱敏勾选（L3）
10. 变更指针（若本期有盘管角色/清洗或翅片窗方法/门限变更 → J）
11. 不适用声明（无精密空调，或无风冷冷凝器盘管/翅片路径，含纯冷冻水 CRAH、水冷壳管且无翅片盘管路径，书面勾选；不得顶 BB/BK/AX/BJ/BM；一侧不适用 ≠ 另一侧自动免；BK 路径过了或 BK 不适用 ≠ 冷凝器路径自动免）

> **口诀**：洗、翅、界、窗、房、测、签、闭、密、界——**十字盘管钉**（教学记忆；现场以本网书面规程为准，但 **冷凝器盘管清洗台账 + 翅片完好窗方法 + 边界方法 + 本组本机房本期实测 + 会签** 几乎不可砍）。

### 5.2 对话脚本（教学）

**脚本A（盘管看着干净 / 口头洗过想签）**
新人：「盘管看着挺干净的，班长也说上个月洗过了，签准用吧。」
班长：「BN1——冷凝器盘管清洗台账和本期对照呢？盘管看着干净≠清洗台账过，口头说洗过了≠窗过。补账再谈会签。」

**脚本B（BB 顶替 / 风扇转）**
外包：「BB 室外机和冷凝侧边界签还在，风扇也在转，盘管和翅片免了。」
班长：「BB≠BN。室外机/净距/风扇回BB；冷凝器盘管清洗与翅片完好主贴仍BN。风扇转≠清洗/翅片过。BB 提到翅片清洁只是冷凝侧窗角色，并不单独给清洗台账 + 翅片完好窗。顶替挂R。本篇不重写BB全文。」

**脚本C（BK 顶替 / 翅片看着齐）**
外包：「BK 蒸发器盘管和翅片刚过，而且冷凝器翅片远看又齐又干净，窗页免了。」
班长：「BK≠BN。蒸发器盘管清洗/翅片完好过≠冷凝器盘管清洗/翅片完好过；蒸发侧≠冷凝侧。翅片看着齐/看着干净≠窗过。补BN-翅主人窗方法。BK 路径过了或 BK 不适用，也不等于冷凝器路径自动免。本篇不重写BK全文。」

**脚本D（AX / BJ / BM 顶替）**
外包：「AX 压缩机冷媒边界刚过，BJ 吸排和过热过冷也刚测过，BM 开度控制也绿，排热没问题，清洗免了。」
班长：「AX≠BN，BJ≠BN，BM≠BN。压缩机/制冷剂边界回AX，吸排/过热过冷回BJ，开度/过热控制回BM；冷凝器盘管清洗与翅片完好主贴仍BN。空气侧脏、翅片扁，压力和控制即使当时能读到数，也不能顶清洗台账。」

**脚本E（不安全清洗教条 / 高压水 / 运行中冲洗 / 绕联锁 / 套票）**
外包：「邻站清洗表改个机房号交差。或者按经验配点药冲，高压水枪对着翅片冲，机组还在跑顺便带电湿洗，高压保护先绕开。」
班长：「BN-验拒签重测。禁套他站他期。禁不安全化学清洗教条，禁高压水乱冲教条，禁未授权在运行中冲洗/带电湿洗，禁旁通，禁绕联锁。挂N/R，禁签。清洗过≠翅片过。」

### 5.5 与弱项的现场对照（再钉一次）

冷凝器盘管乱账、翅片乱窗、假绿、冷凝高压/高温/脏堵告警风暴，常先伤站点环境与**上行**体验。有人把这些当「覆盖病」抬功率——**禁功率战**。先问 BN 秩序并分诊 BB/BK/AX/BJ/BM，风暴挂 N，变更走 J。弱项短补：**12.5 kHz / 4FSK / 2-slot TDMA**。
