## 6. 工作实例（12 则，教学虚构，L3）

1. **盘管看着干净 / 口头洗过想签准用**：称盘管外观干净、班长说洗过要签 → 查 BN1 无本期清洗对照 → **拒签**；补 BN-洗。
2. **翅片看着齐或看着干净 / 套邻站翅片照片**：称「远看又齐又干净 / 邻站照片差不多」免窗页 → **拒签**；补 BN-翅。
3. **BB 顶替 BN**：用室外机/冷凝侧边界签或「风扇在转」顶本期清洗/翅片签 → **挂 R**；**风冷室外机/冷凝侧边界过 ≠ 冷凝器盘管清洗/翅片完好过**；**风扇转 ≠ 清洗/翅片过**。BB 提到翅片清洁只是窗角色，并不单独给本篇台账。
4. **BK 顶替 BN**：称蒸发器盘管和翅片刚过，冷凝器免做 → **挂 R**；**蒸发器盘管清洗/翅片完好过 ≠ 冷凝器盘管清洗/翅片完好过**；蒸发侧 ≠ 冷凝侧。BK 路径过了或 BK 不适用 ≠ 冷凝器路径自动免。
5. **AX 顶替 BN**：用压缩机/制冷剂边界签顶本期盘管/翅片签 → **挂 R**；**压缩机/制冷剂边界过 ≠ 本篇**。
6. **BJ 顶替 BN**：称吸排压力和过热过冷刚过，排热没问题，清洗免 → **拒签**；**吸排/过热过冷巡检过 ≠ 本篇**。
7. **BM 顶替 BN**：称膨胀阀开度和过热控制刚过，翅片免 → **挂 R**；**开度/过热控制过 ≠ 本篇**。
8. **AI / AT / AU / BG / BA / BH / AO 顶替**：称温湿度、机内冷凝加湿、滤网、冷冻水冷却塔、冷却水泵或漏水探头过了，本窗免 → **拒签**；各过 ≠ BN 过；**冷冻水/冷却塔 ≠ 风冷冷凝器盘管**。
9. **N 绿免实测**：称大屏监控绿，本期实测免 → **拒签**；N绿≠BN过；补 BN-验。
10. **套邻站表**：拷邻站清洗/翅片表改机房号 → **BN-验 拒签重测**。
11. **功率战 / 不安全化学清洗教条 / 高压水乱冲 / 运行中冲洗 / 绕联锁 / 旁通**：冷凝高压或高温告警要抬功率，或按经验配药冲、高压水乱冲、运行中带电湿洗、绕保护、开旁通后要求准用 → **一律硬禁**；先挂 N/R；缺秩序整改贴 BN；禁签。
12. **清洗顶翅片 / 无风冷冷凝器路径乱签 / 泄密**：称清洗签过故翅片免，或纯冷冻水 CRAH、水冷壳管且无翅片盘管路径却不写「不适用」乱签准用，或公开群贴真实精密空调或冷凝器序列号与盘管细节 → **拒签顶替**并/或补书面不适用并/或 **L3 违规**；一侧不适用 ≠ 另一侧自动免。

### 11.3 给带新人的三句话
1. 冷凝器盘管不是看着干净、口头洗过、风扇转就能签：清洗有账，本期对照钉死；**室外机/冷凝侧边界过≠清洗过，蒸发器侧过≠冷凝器侧过**。
2. 翅片不是远看整齐或干净就算过，也不是吸排/过热过冷绿了就能顶：主人窗方法准用期，清洗与翅片分开实测，会签才算准用；禁绕联锁、禁旁通、禁不安全化学清洗教条、禁高压水乱冲教条、禁未授权运行中冲洗/带电湿洗。
3. 假绿挂 R；主贴 BN；BB/BK/AX/BJ/BM/N 不顶替；异常窗禁功率战；公开脱敏 L3。
