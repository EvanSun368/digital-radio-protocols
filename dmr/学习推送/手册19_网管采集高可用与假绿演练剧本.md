## 1. 为什么要写这篇手册（动机 + 现场对话）

前十八篇手册教你认病、交维、写频、批量、电源监控、有源隔离、口部泄漏、金机漂移：贴纸 A–E 协议层，F 射频，G 实验室，H 话务，I 室分，J 写频，K 电源，L 井库，M 批量/OTAP，N 监控/对时/风暴，O 有源隔离，P 口部切换，Q 金机漂移。可现场还有一类「病」——**不是告警风暴本身，而是采集链僵死、单路无备、从没故意断过探头证铃会响，值班屏却一直绿**：

- 网管：「大屏全绿，监控已就绪，可以签交维。」——采集进程早僵死，最后一拍还停在「正常」；**假绿**（指针 N，本篇加深 **采集 HA + 演练**）。  
- 班长：「我们有双采集。」——从没做过切换窗验证；主挂了备不接，或双写脑裂互相刷绿。  
- 新人：「假绿演练？那不是故意搞坏吗？」——不故意断一路，就不知道铃会不会响；无演练 = 假绿债。  
- 领导：「监控看不见，肯定是干扰，加功率 / 加信道。」——看不见 ≠ 空口病；加功率是手册07/09 禁区；本篇也禁。  
- 手册15 学过的人：「N 不是已经讲假绿了吗？」——N 管对时/风暴/假绿气质；本篇是 **采集链高可用与假绿演练剧本加深册**，主贴新贴纸 **R**。  
- 手册18 学过的人：「金机漂移 Q 和假绿一样吗？」——**配置漂移 ≠ 采集假绿**；Q 管柜台货漂开，R 管探头僵死仍显绿。  
- 电源同事：「倒换窗铃响是正常的。」——可挂 K；采集侧是否假绿、演练是否做过，**主贴仍 R**。  
- 有人：「断探头演练太吓人，签个字就算了。」——无书面演练窗、无「会响」证据 → 禁签「监控可靠」。

这几句背后是同一件事：

> **「网管采集高可用与假绿演练」这个词在现场至少有五个坑**：  
> **① R-采**：采集链身份与探头——谁采、采什么、心跳/超时  
> **② R-备**：采集高可用——双路/主备、切换窗、脑裂禁令  
> **③ R-绿**：假绿定义与探测——采集僵死仍显绿、静默缺口  
> **④ R-演**：假绿演练剧本——定期断探头/断采集证「会响」、演练窗书面  
> **⑤ R-治**：治理与拒签——无演练禁签交维、假绿拒放行、脱敏 L3  
> 把 ①–⑤ 当成「大屏绿就永远可靠」或「出了事用手册01–05 / 07 分诊」，会把整队假绿债留给下一班。

本篇目标：能背出**网管采集高可用与假绿演练工作流**；会用新贴纸 **R（采集/备/绿/演/治）** 与五个子类；会填 **插页 R（R1–R8）** 和《本网网管采集高可用与假绿演练卡》；能用「**机场塔台双雷达 + 值班屏全绿演练**」故事讲清主备采集与假绿债；能拒绝「无主备就签监控就绪、假绿放行、无演练宣称可靠、用加功率掩盖看不见、把配置漂移当采集假绿」；自测过关后，回库把本网最近一次采集中断/假绿/演练事件（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：不发明 ETSI 条款号；**不写真实批复频点、楼名、站号、个号、密钥、单位名、网管地址进公开仓库**；**不教攻击/仿冒/破解/空口劫持**——只讲制度与治理；不重写手册15 / 12 / 06 / 08 / 18 全文（只给指针）；**N/K/G/Q 仍生效，本篇加深采集 HA + 假绿演练**；**不把加功率/加信道当「监控看不见」止痛药**；采集与假绿**主贴 R**，可挂 N/K/G/Q；结案用 R + 本网证据；公开 NMS/HA/混沌演练资料只借**精神与顺序**——**不背条款当 ETSI、不背厂商菜单当制度、不把蜂窝 KPI / IT 工具名抄进 DMR 公开包当法规**。

## 2. 总图 / 故事：采集像「机场塔台双雷达 + 值班屏全绿演练」

### 2.1 一句话：必须先证明采集链心跳非假绿、主备切换可验证、假绿演练书面会响，再谈「监控已就绪」——否则值班屏全绿、探头早僵、交维假绿债

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  机场塔台（本网网管值班室 · 采集柜）                         │
   │                                                              │
   │   主雷达 = 主采集（R-采 / R-备）——有身份、心跳、超时          │
   │   备雷达 = 备采集（R-备）——切换窗可证；禁脑裂双写未治理       │
   │   值班屏 = 网管大屏 ——一直绿 ≠ 探头活着                      │
   │   故意断一路 = 假绿演练（R-演）——证铃会响、屏会变             │
   │   拒签台 = 交维拒签（R-治）——无演练签字 = 假绿债              │
   │                                                              │
   │   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐     │
   │   │ 核采集  │──▶│ 证主备  │──▶│ 定义假绿│──▶│ 演练会响│     │
   │   │ (R-采)  │   │ (R-备)  │   │ (R-绿)  │   │ (R-演)  │     │
   │   └────┬────┘   └────┬────┘   └────▲────┘   └────┬────┘     │
   │        │             │             │              │           │
   │        │无身份禁签   │无切换禁HA   │僵死仍绿拒签  │无窗禁签  │
   │        ▼             ▼             │              ▼           │
   │   ┌─────────┐   ┌─────────┐       │         ┌─────────┐     │
   │   │ 心跳超时│   │ 脑裂禁令│───────┘         │ 拒签交维│     │
   │   │ (R-采)  │   │ (R-备)  │                 │ (R-治)  │     │
   │   └─────────┘   └─────────┘                 └────┬────┘     │
   │        ▲                                          │           │
   │   禁加功率/加信道掩盖「监控看不见」→ 治理（R-治）◀───────────┘ │
   │   禁：大屏绿当可靠；无演练签交维；双写未治理当 HA 完成         │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **先核探头身份，再证主备切换，后定义假绿，末上演练证会响。**  
> 值班屏一直绿还说监控可靠 = 塔台雷达早停转、屏却假装没事——**假绿债。**  
> 有双路从不切 = 备雷达落灰——**有备 ≠ 高可用。**

### 2.2 「塔台双雷达」五段直觉（弱项短补，钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **采集身份** | 主雷达编号与扫区 | 谁采、采什么对象、心跳/超时；探头清单书面 | R-采 |
| **采集高可用** | 主备双雷达 + 切换窗 | 双路/主备；切换可测；脑裂双写禁当完成 | R-备 |
| **假绿定义** | 屏全绿但雷达停转 | 僵死/断链仍显绿；静默缺口；死人手柄气质 | R-绿 |
| **假绿演练** | 故意断一路证铃响 | 定期断探头/断采集；书面窗；证「会响」 | R-演 |
| **治理拒签** | 无演练拒签放飞 | 无演练禁签交维；假绿拒放行；脱敏 L3 | R-治 |

> 公开可观测性常识（如双采集器故障切换、Prometheus/Thanos HA 去重、混沌 Game Day、死人手柄/合成探测精神）：**采集要可冗余、静默失败要被发现、演练要有书面窗与中止条件**。本篇只借**顺序直觉**：核身份 → 证主备 → 定义假绿 → 演练会响 → 拒签治理。**不背工具名当 ETSI / 不背厂商网管菜单当本网制度 / 不把 IT 混沌实验剧本原文抄进 DMR 公开包当法规。**

### 2.4 新贴纸 R：采集 / 备 / 绿 / 演 / 治（五个子类）

```text
                    ┌──────── 贴纸 R · 采集/备/绿/演/治 ────────┐
                    │  R-采  采集链身份与探头：谁采·采什么·心跳/超时           │
                    │  R-备  采集高可用：双路/主备·切换窗·脑裂禁令             │
                    │  R-绿  假绿定义与探测：采集僵死仍显绿·静默缺口           │
                    │  R-演  假绿演练剧本：定期断探头/断采集证会响·书面窗       │
                    │  R-治  治理与拒签：无演练禁签交维·假绿拒放行·脱敏 L3     │
                    └──────────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签 / 拒放行触发 |
|------|--------|----------------------|
| **R-采** | 采集无身份/无心跳超时定义 → 禁签监控就绪 | 「大屏在绿」但说不清谁在采 |
| **R-备** | 无主备或无切换验证 / 脑裂未治理 → 禁当 HA | 「有两台采集机」从没切过 |
| **R-绿** | 僵死仍绿 / 静默缺口未探测 → 假绿拒签 | 进程死了墙仍全绿 |
| **R-演** | 假绿演练未做或无书面窗 → 禁签交维 | 「太吓人不做演练」仍宣称可靠 |
| **R-治** | 假绿放行；加功率掩盖看不见；泄密 | 「先上勤再慢慢看监控」 |

### 2.5 采集高可用与假绿演练最小工作流（背下来）

```text
  要签「监控已就绪」/ 交维 / 宣称可靠
        │
        ▼
  采集链身份清楚？心跳/超时书面？──否──▶ 拒签（R-采 / 规则1）
        │是
        ▼
  主备存在且切换窗验证过？脑裂已治？──否──▶ 禁签 HA / 禁「监控就绪」（R-备 / 规则3、7）
        │是
        ▼
  假绿探测存在？（僵死会变色/会响）──否──▶ 假绿拒签（R-绿 / 规则4）
        │是
        ▼
  假绿演练书面窗做过且「会响」有证？──否──▶ 禁签交维（R-演 / 规则5）
        │是
        ▼
  结案 + 脱敏 L3；主贴 R；可挂 N/K/G/Q
  禁加功率/加信道掩盖「看不见」；禁大屏绿代替演练账
```

现场口诀：

> **先身份，再主备，后假绿，末演练。**  
> 跳过演练的「全绿交维」= 塔台从没试过断雷达，却说双雷达可靠。

## 3. 核心交付：插页 R + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 R（而不是先贴 N / K / Q / G）

| 现场信号 | 主贴 | 可次挂 |
|----------|------|--------|
| 交维要签「监控已就绪」 | **R**（采集 HA + 演练） | N（对时/风暴气质） |
| 大屏全绿但怀疑采集僵死 | **R-绿** | N-监 |
| 双采集从没切过 / 疑脑裂 | **R-备** | — |
| 假绿演练窗 / 故意断探头 | **R-演** | N；物理倒换可挂 K |
| 倒换窗铃响像风暴 | 可挂 **N**；采集侧是否假绿仍问 **R** | K |
| 抽检对不上但采集也绿 | **Q** 与 **R** 分清：漂是 Q，采僵是 R | N |
| 「看不见就加功率」 | **R-治** + 禁令 | F/H（排除后） |

> **口诀**：对时/风暴/假绿气质走 **N**；电源倒换物理走 **K**；配置漂移走 **Q**；**采集链身份、主备、假绿探测、演练剧本走 R**。可叠挂，采集 HA 与假绿演练**主贴 R**。

### 3.2 插页 R · 采集 / 备 / 绿 / 演 / 治（挂在总三联单或网管交班首页后）

| 行 | 名称 | 填写示例（教学虚构） |
|----|------|----------------------|
| **R1** | 主子类 + 次子类 | 「主 R-演 / 次 R-备」（或 R-采 / R-绿 / R-治） |
| **R2** | 采集身份 | 「主采角色标签 A；对象清单版本（脱敏）；心跳周期/超时阈值」（禁真实网管地址） |
| **R3** | 主备与切换 | 「主/备角色；最近切换窗验证日期；切换结果过/失败；脑裂治理勾选」 |
| **R4** | 假绿定义 | 「僵死判据：心跳超时仍绿；静默缺口时长；死人手柄/合成探针气质（教学层）」 |
| **R5** | 假绿探测 | 「探针名（脱敏）；期望变色/响铃行为；最近探测结果」 |
| **R6** | 演练窗 | 「书面窗起止；审批人（脱敏角色）；中止条件；影响范围（对象清单子集）」 |
| **R7** | 演练动作与证据 | 「断哪路（主/备/探针）；铃是否响；屏是否变；恢复步骤；录像/日志指针（L3）」 |
| **R8** | 判定与动作 | 「可签交维 / 带条件（缩短复演）/ 拒签；脱敏 L3」 |

> **R2 与 R4 不过 → 禁止以「监控已就绪」名义签字。**  
> **R3 若宣称 HA 但切换验证空 → 禁止签 HA 完成（规则3、7）。**  
> **R6/R7 若交维要求监控可靠但为空 → 禁止签交维（规则5）。**  
> **R8 若写「加功率/加信道试试」或「大屏绿就算了」→ 本页作废重填。**

### 3.3 「假绿拒签 / 无演练禁签交维」卡（贴网管 / NOC / 交维台）

```text
  ┌────────────── 采集HA与假绿演练拒签卡（贴纸 R）──────────────┐
  │  × 说不清谁采、采什么、心跳/超时就把大屏当可靠                │
  │  × 无主备或无切换窗验证就签「监控高可用 / 已就绪」            │
  │  × 双采集脑裂/双写未治理仍当 HA 完成                          │
  │  × 采集僵死/断链墙仍全绿却放行（假绿）                        │
  │  × 假绿演练未做或无书面窗就签交维 / 宣称监控可靠              │
  │  × 用加功率 / 加信道掩盖「监控看不见」                        │
  │  × 把配置漂移（Q）和采集假绿（R）混成一锅结案                │
  │  × 用「值班屏一直绿」代替演练账与切换验证                    │
  │  × 公开包出现真实频点 / 个号 / 密钥 / 站名 / 网管地址 / 单位名│
  │  √ 例外：书面窗、原因、审批、到期复演——写进 R6/R8             │
  └────────────────────────────────────────────────────────────┘
```

### 3.4 和总三联单怎么写（接手册06）

- **现象**：写「采集心跳超时墙仍绿」或「演练断主采铃未响」，不要写「干扰」除非已排除 R。  
- **证据**：采集角色标签（脱敏）、对象清单版本、切换验证日期、演练窗、响铃/变色相对描述；禁真实网管 IP/URL。  
- **时钟**：若与手册15 风暴同时，写清三钟差；漂移大则禁秒级因果（指针 N-时）。  
- **贴纸栏**：主 **R-? **，次挂 N/K/G/Q（若有）。  
- **结案词**：用 R 子类 + 动作（复演/修复采集/拒签），禁用「加功率好了」「大屏绿了就算」。

## 4. 深潜：八条硬规则 + 采集/备/绿/演直觉 + 假病禁令

### 4.1 八条硬规则（本篇钉子）

1. **先证采集链心跳与非假绿，再写空口/干扰/协议玄学**——探头与屏没对上，射频单先冻结。  
2. **禁用加功率 / 加信道 / 乱拧参数掩盖「监控看不见」**——呼应手册07/09；功率不是采集补丁。  
3. **采集无主备或无切换验证 → 禁签「监控已就绪」交维**——有两台机器 ≠ 高可用。  
4. **假绿（采集僵死/断链仍全绿）= 拒签 / 拒放行**——值班屏假装没事比铃响更危险。  
5. **假绿演练未做或无书面窗 → 禁签交维 / 禁宣称监控可靠**——无「故意断一路」证据 = 假绿债。  
6. **演练窗可挂 N/K，但采集 HA 与假绿剧本主贴 R**——对时风暴与电源倒换不顶替采集演练账。  
7. **双采集脑裂 / 双写未治理 → 禁当高可用完成**——两路互刷绿比单路更会骗人。  
8. **公开材料脱敏 L3；不写真实站名/频点/个号/密钥/网管地址**——教学与公开仓双禁。

### 4.2 采集身份直觉：「雷达要有编号与扫区」（R-采）

采集不是「大屏在刷新」的口语，而是**可审计的探头身份**：

| 字段（教学） | 像什么 | 常见坑 |
|--------------|--------|--------|
| **采集角色标签** | 主雷达呼号 | 口头「那台服务器」无标签 |
| **对象清单版本** | 扫区图 | 采什么说不清；清单与墙不一致 |
| **心跳周期 / 超时** | 雷达转一圈时限 | 无超时定义，僵死永不发现 |
| **最近成功拍** | 最后回波时间 | 只看颜色不看时间戳 |
| **权限与变更** | 谁能动采集配置 | 随手改轮询间隔无单 |

```text
  这路采集能签「在线」吗？
        │
        ├─ 无角色标签 / 无对象清单版本 ──▶ 否（R-采）
        ├─ 无心跳或超时定义 ──▶ 否（假绿温床）
        ├─ 最近成功拍超过本网超时仍绿 ──▶ 假绿（R-绿）
        └─ 标签+清单+心跳均过 ──▶ 再问主备与演练
```

### 4.3 主备直觉：「备雷达要能接班」（R-备）

| 项 | 过关样子 | 不过样子 |
|----|----------|----------|
| **双路存在** | 主/备角色书面 | 「好像有两台」无角色 |
| **切换窗验证** | 有日期、有结果、有恢复 | 从没切过宣称 HA |
| **失败域分离** | 不同主机/路径气质（教学） | 同机双进程当双路 |
| **脑裂治理** | 同时只一路写主视图或有去重/仲裁 | 双写互刷、墙闪绿又红又绿 |
| **回切策略** | 自动/手动书面；禁乒乓无记录 | 回切无人知、账对不上 |

> 公开双采集器/failover 文档只借精神：**备机要够得着同一批对象、切换要可测、要有回切策略**。不绑定某商业 NMS 菜单。

### 4.4 假绿直觉：「屏绿不等于雷达转」（R-绿）

假绿 = **采集已死或静默缺口，墙仍显示正常/全绿**。

| 假绿样子 | 怎么认 | 动作 |
|----------|--------|------|
| 进程僵死仍绿 | 心跳超时；最近成功拍过老 | 拒签（规则4） |
| 链路断仍绿 | 合成探针/死人手柄不响 | 先修探测再谈业务 |
| 静默缺口 | 中间缺拍无人知 | 缺口告警；演练验证 |
| 「抑制」伪装绿 | 全静音交班（指针 N） | 禁全静音常态；例外书面 |

与手册18 **Q 漂移**分清：

| | 金机漂移 Q | 采集假绿 R |
|--|------------|------------|
| 坏在哪 | 柜台货相对对照样漂了 | 探头/采集链僵死屏却绿 |
| 典型原话 | 「机子怪」「抽检对不上」 | 「大屏全绿但站早挂了」 |
| 主贴 | Q | R |

### 4.5 演练直觉：「故意断一路证铃响」（R-演）

假绿演练最小剧本（教学默认，按本网裁剪）：

1. **书面窗**：起止、审批角色、影响范围、中止条件。  
2. **基线**：演练前确认墙状态、心跳、最近成功拍（脱敏记录）。  
3. **注入**：只断演练名单内一路（主采 / 备采 / 单探针），禁扩大杀伤。  
4. **期望**：在超时内铃响或屏变色；若不变 = 演练失败 = 假绿债坐实。  
5. **恢复**：按剧本恢复；确认回稳态；记恢复时长。  
6. **关闭**：假设成立否、意外影响、跟进项；脱敏 L3 入卡。

```text
  演练窗开了吗？──否──▶ 禁止开断（规则5）
        │是
        ▼
  只动书面名单？──否──▶ 中止
        │是
        ▼
  断后会响/会变？──否──▶ 演练失败；拒签「监控可靠」；开 R-治
        │是
        ▼
  恢复 + 记证 + 可缩短复演周期
```

### 4.6 「假干扰 / 假容量 / 假协议 / 假绿」怎么认

| 假病 | 听起来像 | 先问 |
|------|----------|------|
| 假干扰 | 「看不见肯定同频」 | 采集心跳？假绿？ |
| 假容量 | 「加信道就好了」 | 是监控盲还是真话务？手册09 |
| 假协议 | 「肯定鉴权玄学」 | 屏是否在说谎？ |
| 假绿 | 「全绿没事」 | 最近演练？僵死判据？ |

### 4.7 假病禁令墙（与加功率叙事）

```text
  × 监控看不见 → 加功率 / 加信道
  × 大屏绿 → 跳过采集身份与演练账
  × 有两台采集机 → 自动等于 HA 完成
  × 演练太吓人 → 签字代替「会响」证据
  × 倒换窗铃响 → 全静音交班（指针 N 禁令）
  × 配置漂移与采集假绿 → 混成一句「监控有问题」结案
  √ 先 R 工作流；可挂 N/K/G/Q；结案用子类+证据
```

### 4.8 假绿演练最小包（可复印）

| 项 | 必填 |
|----|------|
| 窗 | 起止 + 审批角色 |
| 范围 | 对象清单子集（脱敏） |
| 动作 | 断主 / 断备 / 断探针（选一） |
| 期望 | 超时内响铃或变色 |
| 中止 | 误伤扩大 / 真业务事故阈值 |
| 证据 | 相对描述 + 日志指针（L3） |
| 结果 | 过 / 失败→拒签→修复→复演 |

### 4.9 和手册15 N / 手册12 K / 手册18 Q 怎么叠挂

- 风暴铃墙：先排除 **R 假绿**，再按 **N** 根因/对时。  
- 市电倒换演练：物理主贴可 **K**，采集是否假绿、是否做过断采集演练主贴 **R**。  
- 抽检对不上：走 **Q**；同时墙全绿要问是否 **R-绿**。  
- 三者可同日爆发：先假绿（R）→ 再对时风暴（N）→ 再漂移（Q）；物理倒换挂 K。

### 4.10 和弱项加餐的衔接

12.5 kHz / 4FSK / 30 ms 两槽背熟，你才说得清：**采集 HA 管的是机房眼睛与心跳，不是调制台阶**。有人要用加功率/加信道治「监控看不见」时，回加餐 + 手册07/09 + 本篇八条硬规则。

## 5. 现场映射：原话 → R 子类；对话脚本；反例

### 5.1 原话速查表

| 现场原话 | 先贴 | 一句话动作 |
|----------|------|------------|
| 「大屏全绿，监控已就绪，签交维吧」 | R-演 / R-治 | 要演练账与切换验证；无则拒签 |
| 「采集进程好像挂了，但墙还绿」 | R-绿 | 假绿拒签；先修探测 |
| 「我们有双采集，高可用做完了」 | R-备 | 要切换窗记录；脑裂是否治理 |
| 「假绿演练太吓人，别做了」 | R-演 | 无书面窗禁宣称可靠 |
| 「监控看不见，肯定干扰，加功率」 | R-治 | 禁令；先 R 再谈 F |
| 「倒换窗铃响，把监控静音」 | N + R | 禁全静音常态；采集是否假绿另问 R |
| 「抽检对不上，监控也绿」 | Q 与 R 分清 | 漂→Q；采僵→R |
| 「两台采集同时写，墙闪来闪去」 | R-备 | 脑裂；禁当 HA 完成 |

| 「业务掉话，先别查采集了」 | R-采 | 先心跳非假绿，再空口玄学（规则1） |

### 5.2 对话脚本（六则）

**脚本 A · 交维要签监控就绪**  
- 对方：「大屏绿了，签吧。」  
- 你：「插页 R2/R3/R6 呢？采集身份、切换验证、假绿演练窗。」  
- 对方：「没有演练，但一直很稳。」  
- 你：「无演练 = 假绿债。规则5，拒签交维。」

**脚本 B · 假绿现场**  
- 对方：「站早不在线了，墙怎么还绿？」  
- 你：「R-绿。心跳超时了吗？最近成功拍？」  
- 对方：「超时定义……好像没写。」  
- 你：「先补 R-采 心跳/超时，再谈干扰。假绿拒放行。」

**脚本 C · 有双机无切换**  
- 对方：「两台采集都在，HA 完成。」  
- 你：「最近一次切换窗验证日期？脑裂治理勾选？」  
- 对方：「没切过，怕出事。」  
- 你：「没切过就不能签 HA。规则3、7。排演练窗。」

**脚本 D · 加功率叙事**  
- 对方：「监控老看不见，功率加两格。」  
- 你：「禁止。规则2。看不见先证采集链，不是抬功率。」  
- 对方：「那信道再开一个？」  
- 你：「同样禁。手册07/09 + 本篇 R-治。」

**脚本 E · 与 N/K 叠挂**  
- 对方：「倒换演练铃墙炸了，是不是风暴 N？」  
- 你：「可挂 N；物理可挂 K。问一句：断采集演练做过吗？主贴仍可能是 R。」  
- 对方：「只做过油机倒换。」  
- 你：「K 有了；R-演 还缺。别把倒换窗当假绿演练账。」

**脚本 F · 与 Q 分清**  
- 对方：「机子怪，监控又全绿，是不是假绿？」  
- 你：「先分：抽检对不上走 Q；采集僵死仍绿走 R。两边都要问，别混结案。」  
- 对方：「那先贴哪个？」  
- 你：「采集心跳超时优先排除 R-绿；心跳正常再 Q-比。」

### 5.3 反例墙（贴网管 / NOC / 交维台）

```text
  × 交维单「监控已就绪」无 R6/R7
  × HA 验收只拍两台服务器合影
  × 假绿演练用「桌面走走流程」代替真断一路
  × 演练失败（铃不响）仍签字「可靠」
  × 双写脑裂用「刷新一下就好」结案
  × 监控盲区开加功率/加信道工单
  × 把 Q 漂移单改标题成「假绿」糊弄
  × 公开材料贴网管 URL / 真实站号
  √ 书面窗 + 真断 + 会响证据 + L3
```

### 5.4 夜班 15 分钟怎么用

1. **3 分钟**：看采集心跳/最近成功拍（脱敏屏）；有超时仍绿 → 记 R-绿。  
2. **4 分钟**：主备角色是否都活；有无脑裂闪烁。  
3. **4 分钟**：本周假绿演练窗是否临近/过期；过期未做 → 交班写「R-演 债」。  
4. **4 分钟**：三联单现象栏禁用「干扰」除非已排除 R；贴纸栏主 R 若适用。

### 5.5 单次假绿演练 40 分钟标准节奏（可复印）

| 分钟 | 动作 |
|------|------|
| 0–5 | 开窗确认：审批、范围、中止、基线拍 |
| 5–10 | 复述期望：超时内响铃或变色 |
| 10–20 | 注入：断书面名单内一路；观察 |
| 20–28 | 记录：响/未响；屏变/未变；副作用 |
| 28–35 | 恢复：回稳态；确认心跳 |
| 35–40 | 关闭：过/失败；R8；脱敏入卡；失败则拒签 |

大范围演练加倍；禁止与真事故窗重叠。

### 5.6 「监控看不见三问」（贴射频班）

1. 采集心跳与最近成功拍正常吗？（R-采 / R-绿）  
2. 主备切换与假绿演练账在吗？（R-备 / R-演）  
3. 若前两问过，再挂 F/H/A–E——**禁止直接加功率**。

### 5.7 与手册15 / 12 交维当日的衔接（指针）

- 交维包：N 的对时/风暴卡 + **R 的采集 HA/演练卡** 齐；缺 R 禁「监控就绪」。  
- 电源倒换交维：K 三联单有，仍要问 R-演 是否覆盖采集侧。  
- 假绿气质拒签：N 规则6 与 R 规则4 同向；**演练剧本与主备账主贴 R**。

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「交维全绿无演练」→ R-演 / R-治

- **现象**：新站交维，网管大屏全绿，签字「监控已就绪」。  
- **排除**：问演练窗与切换验证——皆无。  
- **贴法**：主 R-演，次 R-治。  
- **动作**：拒签；排书面假绿演练；过后再签。  
- **禁令**：禁止用「一直很稳」代替演练账。

### 例 2 · 「采集僵死墙仍绿」→ R-绿

- **现象**：业务侧已发现站异常，墙仍全绿。  
- **排除**：心跳超时；最近成功拍远超本网阈值。  
- **贴法**：主 R-绿；可挂 N-监。  
- **动作**：拒放行；拉起采集；补死人手柄/合成探针气质探测；复测。  
- **禁令**：禁止先开同频干扰单。

### 例 3 · 「双机合影当 HA」→ R-备

- **现象**：验收材料两张采集机照片，无切换记录。  
- **贴法**：R-备。  
- **动作**：安排切换窗；记结果；脑裂检查。  
- **禁令**：禁签「高可用完成」。

### 例 4 · 「看不见就加功率」→ R-治 + 规则2

- **现象**：监控缺口，工单写加功率。  
- **贴法**：R-治。  
- **动作**：撤加功率叙事；走 R 工作流。  
- **禁令**：手册07/09 同步贴。

### 例 5 · 「演练桌面走过场」→ R-演

- **现象**：演练记录写「已桌面推演」，未真断一路。  
- **贴法**：R-演。  
- **动作**：判定演练无效；重做真断；要会响证据。  
- **禁令**：签字代替响铃不算过。

### 例 6 · 「双写脑裂闪绿」→ R-备 规则7

- **现象**：主备同时写，墙状态闪烁，偶发「全绿」。  
- **贴法**：R-备。  
- **动作**：仲裁/去重/单主视图；未治理前禁当 HA。  
- **禁令**：禁止「刷新就好」结案。

### 例 7 · 「倒换窗全静音」→ N + R

- **现象**：油机倒换怕铃，交班全静音；采集异常被盖。  
- **贴法**：次挂 N-治；问 R 是否假绿被静音掩盖。  
- **动作**：禁全静音常态；倒换窗书面抑制项要列清单到期恢复；采集心跳单独盯。  
- **禁令**：静音 ≠ 假绿演练。

### 例 8 · 「漂移单改名假绿」→ Q vs R

- **现象**：抽检对不上，有人把单改成「监控假绿」想走快捷拒签。  
- **贴法**：先分诊；心跳正常则主 Q；采僵则主 R。  
- **动作**：分清结案词；可叠挂不可偷换。  
- **禁令**：禁止标题游戏。

### 例 9 · 「公开报告写网管地址」→ R-治

- **现象**：周报截图含网管 URL 与站名。  
- **贴法**：R-治。  
- **动作**：撤回；L3 重写；追培训。  
- **禁令**：规则8。

### 例 10 · 「铃不响仍签可靠」→ R-演 / R-治

- **现象**：演练断主采，超时内无铃无变色，仍签「监控可靠」。  
- **贴法**：主 R-演，次 R-治。  
- **动作**：演练失败；拒签；修探测后再复演。  
- **禁令**：失败演练不得粉饰。

### 例厚补 · 「半绿半盲」五分钟口诀

> 先看心跳是否假绿（R）→ 再看对时是否漂移（N）→ 再看是否倒换窗（K）→ 末才空口分诊。  
> 任何一步不过，禁加功率叙事。

### 6.5 采集对齐会：20 分钟议程

1. **3 分钟**：本周假绿/采集中断事件条数（L3）。  
2. **5 分钟**：插页 R 抽查——R2/R3/R6 空的单子点名。  
3. **5 分钟**：下一次假绿演练窗排期与范围。  
4. **4 分钟**：脑裂/双写治理进度。  
5. **3 分钟**：与 N/K/Q 叠挂分工；行动项主人。

## 9. 自测（10 题）+ 参考答案

1. 贴纸 R 五个子类各是什么？各用一句话。  
2. 为什么「值班屏全绿」不能直接签「监控已就绪」？  
3. 八条硬规则里，哪一条禁止用加功率掩盖「监控看不见」？  
4. 有双采集但从没做过切换窗验证，能否签 HA 完成？依据哪条规则？  
5. 假绿的定义是什么？发现后动作是什么？  
6. 假绿演练最小包至少含哪几项？  
7. 演练窗如何与 N、K 叠挂？主贴是谁？  
8. 插页 R1–R8 里，哪几行不过必须拒签「监控就绪」？哪几行不过禁签交维（演练）？  
9. 配置漂移（Q）与采集假绿（R）如何一句话分清？  
10. 公开材料能否写真实网管地址？本篇脱敏要求是什么？

### 参考答案

1. **R-采** 身份与心跳；**R-备** 主备切换与脑裂禁令；**R-绿** 假绿定义与探测；**R-演** 演练剧本与会响；**R-治** 拒签与 L3。  
2. 全绿可能是假绿；须过采集身份、主备（若宣称 HA）、假绿探测与演练账。  
3. **规则2**。  
4. **不能**；**规则3**（及脑裂时 **规则7**）。  
5. 采集僵死/断链/静默缺口而屏仍绿；**拒签/拒放行（规则4）**，先修探测。  
6. 书面窗、范围、注入动作、期望（会响/变色）、中止、证据、结果与恢复。  
7. 可挂 N（风暴/对时）、K（电源倒换）；**采集 HA 与假绿剧本主贴 R（规则6）**。  
8. **R2/R4** 不过禁「监控就绪」；宣称 HA 时 **R3** 空也禁；交维要可靠时 **R6/R7** 空禁签（规则5）。  
9. Q=柜台货相对金机漂；R=探头/采集僵死屏却绿。  
10. **不能**；公开/教学 **L3**，禁真实站名/频点/个号/密钥/网管地址（规则8）。
