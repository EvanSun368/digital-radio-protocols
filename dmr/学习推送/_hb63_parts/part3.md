## 6. 工作实例（12 则，教学虚构，L3）

1. **压缩机灯绿 / 看着有数想签准用**：称灯绿、压力表有数要签 → 查 BJ1 无本期台账核对 → **拒签**；补 BJ-压。  
2. **口头说过热过冷正常 / 套邻站过热过冷数**：称「班长说正常 / 邻站数差不多」免窗页 → **拒签**；补 BJ-热。  
3. **AX 顶替 BJ**：用压缩机/制冷剂边界签顶本期吸排/过热过冷签 → **挂 R**；**AX 过 ≠ 吸排/过热过冷台账过**。  
4. **AI 顶替 BJ**：称温湿度刚过、回风稳，过热过冷窗免做 → **挂 R**；**温湿度过 ≠ 过热过冷过**。  
5. **AT 顶替 BJ**：称冷凝加湿过了，吸排过热过冷免 → **拒签**；**冷凝加湿过 ≠ 吸排/过热过冷过**。  
6. **AU / BG 顶替 BJ**：称滤网压差绿或刚换网，BJ 免 → **拒签**；**滤网压差/换网过 ≠ 吸排/过热过冷过**。  
7. **AO 顶替 / N 绿免实测**：称漏水探头绿或大屏监控绿，本期实测免 → **拒签**；漏水探头过 ≠ 窗过；N绿≠BJ过；补 BJ-验。  
8. **套邻站表**：拷邻站压力/过热过冷表改机房号 → **BJ-验 拒签重测**。  
9. **功率战**：高压/低压/过热过冷告警，要抬功率 → **禁功率战**；先挂 N；缺秩序整改贴 BJ。  
10. **不安全泄放 / 开旁通冒充**：泄放制冷剂或开旁通消告警后要求准用 → **禁**；挂 N/R；禁签。  
11. **绕高压/低压/油压联锁 / 按经验加放氟**：绕开保护或口头教逐步充注/泄放后要求准用 → **禁**；挂整改；充注/回收回 AX 书面窗，本篇不展开步骤；主贴 BJ-治。  
12. **吸气顶排气 / 过热度顶过冷度 / 无压缩机乱签 / 泄密**：称吸气签过故排气免，或过热度顶过冷度，或仅 CRAH 站点不写「不适用」却乱签准用，或公开群贴真实精密空调序列号 → **拒签顶替**并/或补书面不适用并/或 **L3 违规**；一侧不适用 ≠ 另一侧自动免。
