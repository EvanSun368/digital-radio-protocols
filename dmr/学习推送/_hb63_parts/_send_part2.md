## 3. 核心交付：插页 BJ + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 BJ（而不是先贴 AX / AI / AT / AU / BG / AO / N）

- 要签「机房精密空调压缩机吸排气压力与过热度过冷度巡检准用」、要开吸排气压力交底窗、要交底过热度/过冷度侧 → **主贴 BJ**。  
- 压缩机本体与制冷剂边界（类型·充注/检漏） → **AX**（手册51）。**AX ≠ BJ**；不重写 AX。  
- 温湿度联锁 → **AI**。冷凝加湿联锁 → **AT**。滤网压差气流 → **AU**。滤网更换 → **BG**。漏水汇排 → **AO**。**AI ≠ BJ；AT ≠ BJ；AU ≠ BJ；BG ≠ BJ；AO ≠ BJ**。  
- 进机房先 **AN**（门禁过 ≠ 交底过）。气灭 → **AL**。风暴先 **N**，缺秩序整改仍 **BJ**；本体另问 **AX**；**禁功率战、绕联锁、不安全泄放、旁通**。  
- 假绿/顶替挂 **R**；变更走 **J** 后再验 BJ。  
- 无直膨/CRAC 压缩机路径（例如仅冷冻水 CRAH） → 书面「不适用」；冷冻水侧问 BA/BD，**不得**用 BJ 顶 AX/AI/AT，也不得用它们顶 BJ。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **吸排气压力台账钉死**：吸气侧与排气侧各自有账；表计/变送器角色入账（编号脱敏）；禁「压缩机灯绿就算过」「看着有压力数就算过」「口头说压力正常」；吸气过 ≠ 排气过，排气过 ≠ 吸气过。  
2. **过热度/过冷度侧有主有窗有方法/准用期**：测点、查表或控制器读出、合格窗以本网与 OEM 书面为准；每次过热过冷交底有主人角色、有书面窗、有方法、有准用期；禁「口头说过热过冷正常」「套邻站过热过冷数」；过热度过 ≠ 过冷度过。  
3. **边界窗与方法钉死**：书面固定；方法含与 AX/AI/AT/AU/BG/AO/N 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明逐步充注/泄放/绕联锁操作教条；**不重写 AX/AI/AT/AU/BG/AO 全文**）；禁「窗再说」「绕高压/低压/油压等保护联锁」「不安全泄放制冷剂」「开旁通冒充」「伪造台账」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、吸气压力、排气压力、过热度、过冷度必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「机房精密空调压缩机吸排气压力与过热度过冷度巡检准用」；假绿 ≠ 放行。  
6. **禁顶替 AX/AI/AT/AU/BG/AO/AD/AA/N/AQ/AY/AZ/BB/BA/BE/AF/AS/AW 等，主贴 BJ，假绿≠放行挂 R**：他贴签都不顶本期吸排/过热过冷签。**尤其：AX ≠ BJ，AI ≠ BJ，AT ≠ BJ，AU ≠ BJ，BG ≠ BJ，AO ≠ BJ；压缩机/制冷剂边界过 ≠ 吸排/过热过冷台账过；温湿度过 ≠ 过热过冷过；冷凝加湿过 ≠ 吸排/过热过冷过；滤网压差/换网过 ≠ 吸排/过热过冷过；漏水探头过 ≠ 窗过；灯绿 ≠ 台账过；看着有数 ≠ 本期核对过；口头说过热过冷正常 ≠ 窗过。**  
7. **吸排压力异常/过热过冷乱窗/告警风暴挂 N，边界/门限/窗变更走 J，禁功率战；禁绕联锁；禁不安全泄放；禁旁通；禁伪造台账**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。吸排/过热过冷乱窗、假绿、告警风暴常被误当「覆盖病」→**禁功率战**；挂 N；变更走 J。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/精密空调序列号全文/可还原坐标与联系人；禁公开传播未脱敏吸排/过热过冷门限与参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签吸排/过热过冷准用、无实测冒充边界过、绕联锁/不安全泄放/旁通冒充秩序齐，不是法外运维智慧**。医院/数据中心公开资料只作故事类比（§10），翻译成本网语言就是 BJ-压 / BJ-热 / BJ-界 / BJ-验 / BJ-治。

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机房精密空调压缩机吸排气压力与过热度过冷度巡检准用」、对外宣传「灯绿/看着有数/口头正常秒过」、把未实测写成已过、把绕联锁/不安全泄放/旁通写成秩序齐。允许做的：补吸排气压力台账、补过热过冷窗、重开边界窗、挂 R/N/J、内部挂整改。

| 「AN 门禁过了 / AL 气灭过了 / AD 入库签还在」 | 门禁≠交底；气灭≠交底；入库≠本期窗 | 邻贴各回各位；交底/主窗仍 **BJ** |
| 「N 监控绿，实测免做」 | N≠BJ | 风暴 **N**；本期实测仍 **BJ** |
| 「高压/低压/过热过冷告警一片」 | 先风暴还是先抬功率？ | 先 **N**；缺秩序整改 **BJ**；压缩机/制冷剂另问 **AX**；温湿度另问 **AI**；冷凝另问 **AT**；滤网另问 **AU/BG**；漏水另问 **AO**；**禁功率战**；**禁绕联锁/不安全泄放/旁通** |
| 「改吸排角色/过热过冷窗方法/门限」 | 有没有走变更？ | **J** + 再验 **BJ** |
| 「邻站压力/过热过冷表拷过来改机房号」 | 套票？ | **BJ-验** 拒签 |
| 「泄放消告警 / 开旁通 / 绕高压低压油压联锁 / 按经验加放氟」 | 冒充/绕联锁/违章？ | **禁**；挂整改；主贴 **BJ-治**（充注/回收回 **AX** 书面窗，本篇不展开步骤） |
| 「本站只有冷冻水 CRAH，没有压缩机」 | 有没有直膨/CRAC 压缩机路径？ | 书面「不适用」；不拿 BJ 顶 AX/AI/AT，也不拿它们顶 BJ |

### 4.3 「机房精密空调压缩机吸排气压力与过热度过冷度巡检准用」最小集（BJ）——缺页不能签准用

1. 吸排气压力台账页（吸气侧·排气侧·表计/变送器；含灯绿≠台账过、看着有数≠本期核对、一侧过≠另一侧过勾选）  
2. 过热过冷侧主人与书面窗、方法、准用期页（过热度与过冷度分开；含禁口头正常、禁套邻站数勾选）  
3. 书面边界窗与方法页（与 AX/AI/AT/AU/BG/AO/N 分工；以本网与 OEM 为准；声明不重写 AX/AI/AT/AU/BG/AO）  
4. 本期本组本机房实测记录（吸气压力、排气压力、过热度、过冷度分别留痕；禁套声明）  
5. AX/AI/AT/AU/BG/AO 边界勾选（防顶替：压缩机/制冷剂边界过≠吸排/过热过冷台账过，温湿度过≠过热过冷过，冷凝加湿过≠吸排/过热过冷过，滤网压差/换网过≠吸排/过热过冷过，漏水探头过≠窗过）  
6. AD/AN/AL/N/AA/AQ 与 AY/AZ/BB/BA/BE 等边界勾选（入库≠本期窗；门禁/气灭过≠交底过；N 绿≠BJ 过；各过≠BJ 过）  
7. 会签页（准用或有条件整改）  
8. 未闭项清单（有则挂整改，重大未闭禁签准用）  
9. 脱敏勾选（L3）  
10. 变更指针（若本期有吸排角色/过热过冷窗方法/门限变更 → J）  
11. 不适用声明（无直膨/CRAC 压缩机路径书面勾选；不得顶 AX/AI/AT；一侧不适用 ≠ 另一侧自动免）

> **口诀**：压、热、界、窗、房、测、签、闭、密、界——**十字吸排钉**（教学记忆；现场以本网书面规程为准，但 **吸排气压力台账 + 过热过冷窗方法 + 边界方法 + 本组本机房本期实测 + 会签** 几乎不可砍）。

### 5.2 对话脚本（教学）

**脚本A（压缩机灯绿 / 看着有数想签）**  
新人：「压缩机灯是绿的，压力表上也有数，签准用吧。」  
班长：「BJ1——吸气侧和排气侧各自的压力台账与本期核对呢？压缩机灯绿≠吸排压力台账过，看着有数≠本期核对过。补账再谈会签。」

**脚本B（AX 顶替）**  
外包：「AX 压缩机和制冷剂边界签还在，吸排和过热过冷免了。」  
班长：「AX≠BJ。压缩机/制冷剂边界回AX；吸排/过热过冷主贴仍BJ。AX 会提到吸排气侧角色，并不单独给一张吸排+过热过冷巡检台账。顶替挂R。本篇不重写AX全文。」

**脚本C（AI / 口头过热过冷正常）**  
外包：「回风温度稳，而且班长说过热过冷都正常，窗页免了。」  
班长：「AI 温湿度过≠过热过冷过；口头说过热过冷正常≠窗过。补BJ-热主人窗方法。本篇不重写AI全文。」

**脚本D（泄放/旁通/绕联锁）**  
外包：「泄一点冷媒 / 旁通开一下 / 绕一下高压保护，告警就消，再签准用。」  
班长：「禁不安全泄放制冷剂，禁开旁通冒充，禁绕高压/低压/油压保护联锁。挂N/R，禁签。缺秩序整改贴BJ-治。」

**脚本E（套票 / 一侧顶另一侧）**  
外包：「邻站压力和过热过冷表参数差不多，改个机房号。吸气那边签过了，排气照抄；过热度算过了，过冷度用同一个数。」  
班长：「BJ-验拒签重测。禁套他站他期。吸气过≠排气过；过热度过≠过冷度过。」

### 5.4 禁写词 / 允许写

禁止写：真实站名、机房全称、精密空调序列号全文、单位名、联系人、真实频点、未脱敏门限；禁止写「灯绿就过」「看着有数就过」「口头过热过冷正常就过」「他贴顶 BJ」「抬功率」「不安全泄放/旁通/绕联锁」「按经验加/放氟步骤」「套邻站表」。允许写：脱敏角色、现象、贴纸（BJ/AX/AI/AT/AU/BG/AO/N/R/J）、动作（补账/重测/拒签）。

### 5.5 与弱项的现场对照（再钉一次）

吸排乱账、过热过冷乱窗、假绿、高压/低压告警风暴，常先伤站点环境与**上行**体验。有人把这些当「覆盖病」抬功率——**禁功率战**。先问 BJ 秩序并分诊 AX/AI/AT/AU/BG/AO，风暴挂 N，变更走 J。弱项短补：**12.5 kHz / 4FSK / 2-slot TDMA**。
