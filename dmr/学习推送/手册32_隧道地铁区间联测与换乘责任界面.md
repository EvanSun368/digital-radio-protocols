## 1. 为什么要写这篇手册（动机 + 现场对话）

前三十一篇手册从 A–E 协议一路写到 AD 备件金机：其中 **X/I 回答「覆盖与抽样怎么测」**，**AB 回答「室分电磁环境复测周期与变更触发」**，**S 回答「跨网互扰怎么挂」**，**Z 回答「开站验收与交维签字边界」**，**N/Q 历史回答「联测窗」指针**，**AC 回答「机动开撤」**，**AD 回答「备件与金机账期」**。可还没有单独钉死一件事——**隧道/地铁区间不是一座孤立基站：区间漏缆、站台室分、换乘通道、两线（或两段）责任界面，必须在同一联测窗用同一方法联合验收；界面主人不清、单边绿灯、套邻区间报告，能不能签「区间/换乘放行」？** 这就是本篇的 **AE**——**隧道地铁区间联测与换乘责任界面**。

- 网优：「区间 A 上行场强够了，整条隧道算合格。」——**单边/半段顶整段** = 本篇拒签（规则3/4）。  
- 项目经理：「换乘通道归土建，无线只签站台。」——**界面无主人** = 规则2。  
- 施工队：「邻区间上周测过，参数差不多，拷报告。」——**套他区间他期** = 规则3。  
- 室分岗：「AB 室分复测全绿，区间不用再联测。」——**用 AB 顶替 AE** = 规则5。  
- 班长：「监测大屏全绿，签放行吧。」——**假绿≠联测通过** = 规则6。  
- 调度：「两线车控室对不上话，先各报本侧合格。」——**缺联测窗仍签** = 规则1/4。  
- 施工队：「功率抬一点把换乘弱场压过去。」——**功率战** = 规则7。  
- 宣传岗：「把真实区间桩号、场强表、线路名发群表扬联测快。」——**L3 违规** = 规则8。  

这几句背后是同一件事：

> **「区间联测与换乘责任界面」在现场至少有五个坑**：**① AE-联** 联测窗（天窗/封锁点）与方法书面钉死，禁「随便找个夜班走一圈」；**② AE-换** 换乘站/换乘通道/两线界面有书面主人与配合清单；**③ AE-界** 责任界面（区间↔站台、线A↔线B、漏缆↔室分衔接）边界清楚，禁「都说归对方」；**④ AE-测** 本区间本期上下行双时隙实测，禁套他区间他站他期；**⑤ AE-治** 治理（假绿、顶替他贴、功率战、伪造联测账、泄密）。  
> 把 ①–⑤ 当成「半段绿就全段过」「室分绿就区间过」「口头说一声界面归谁」，每一次开通、每一次换乘站改造、每一次投诉弱场，都会先吵「到底谁该来联测、报告是不是这区间的」。

本篇目标：能背出**区间联测 + 换乘界面工作流**；会用新贴纸 **AE（联 / 换 / 界 / 测 / 治）**；会填**插页 AE（AE1–AE8）**和《本网隧道地铁区间联测与换乘责任界面台账卡》；能用「**地铁换乘站：消防分区联测 + 换乘通道责任界面移交**」故事讲清窗钉死、界面有主、双方到场联测、单边绿灯≠整段放行；能拒绝半段顶整段、套邻区间报告、用 AB/X 顶替联测签、假绿放行；自测过关后，回库把本网最近一次区间或换乘相关联测（L3）重对一遍：联测窗、界面主人、本期实测、联测签、拒签项。

**本篇硬禁令（写进脑子）**：凡引法规与标准只指向已公开发布的文书标题与官方链接（无线电管理条例、频率使用许可管理办法、地面无线电台（站）管理规定、国无办〔2025〕1号；**只作故事类比**的消防分区/防排烟联测与换乘站公开规范标题，以及公开的漏缆/隧道覆盖、城轨专用无线、验收联调资料），**程序、期限、责任以原文与属地最新要求及本网制度 / 合同为准，本篇只作教学转述，不发明条款号与内部口径**；城轨通信验收、消防分区联测与境外 leaky feeder 公开资料**不是**中国专网台站「贴纸 AE」的法定依据；**现象与台账一律用相对道号、角色标签、脱敏区间编号，禁真实频点 / 站名 / 线路名 / 桩号 / 单位名 / 联系人**；**不教伪造联测台账、不教功率战、不教规避监测、不教套他区间报告、不教假绿顶替**；X / I / AB / S / Z / AA / AC / AD / R / T 各管各的——**区间联测与换乘责任界面主贴 AE**；覆盖方法回 X/I，室分复测回 AB，跨网回 S，开站交维回 Z——**AE 管「窗·界面·联测秩序」，不替代覆盖抽样方法本身**。

## 2. 总图 / 故事：区间联测像「地铁换乘站：消防分区联测 + 换乘通道责任界面移交」

### 2.1 一句话：区间不是「半段绿就全段过」、换乘不是「本侧合格就算整站合格」——要先钉联测窗与方法，界面双方（或多方）主人到场，本区间本期实测，联测通过才签放行；单边绿灯、套邻区报告、用室分复测顶替，一律拒签

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  换乘站消防分区联测 + 界面移交  =  本网区间联测 + 换乘责任界面 │
   │                                                              │
   │  联测天窗·双方到场·方法书面     ≈ AE-联  联测窗与方法钉死     │
   │  换乘通道·两线交汇·谁管谁配     ≈ AE-换  换乘界面主人与清单   │
   │  防火分区界·责任分界书面清楚   ≈ AE-界  区间/站台/线际边界   │
   │  本分区本期实测·禁抄邻分区     ≈ AE-测  本区间本期双时隙实测 │
   │  单边绿≠整段过·假绿·功率战治理 ≈ AE-治  顶替·套报告·泄密     │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **窗钉死，界面有主，本期实测，联测才签。**  
> 半段绿就全段过 = 只测本分区烟感就说整栋楼防火过关——**拒签「区间/换乘放行」**。  
> 本侧合格、对面没来 = 防火门对面排烟没联锁还贴合格——**拒签**。

### 2.2 「换乘站消防分区联测 / 界面移交」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **联测** | 消防分区联测要预约天窗、双方到场、按书面方案测联锁 | 区间联测窗（天窗/封锁点）与方法书面钉死，相关角色到场 | AE-联 |
| **换乘** | 换乘通道、两线车控室互送广播/通话/信息有明确配合方 | 换乘站/通道/线际界面有主人角色与配合清单 | AE-换 |
| **界面** | 防火分区界、责任分界图书面清楚，禁「都说归对方」 | 区间↔站台、漏缆↔室分、线A↔线B 责任界面边界书面 | AE-界 |
| **实测** | 本分区本期实测，禁抄邻分区去年报告 | 本区间本期上下行双时隙实测；方法与 X/I 指针一致 | AE-测 |
| **治理** | 单边绿≠整栋过；禁涂改报告；禁口头补联测 | 假绿、顶替他贴、套他区报告、功率战、泄密 → 治理 | AE-治 |

> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：城轨通信工程质量验收与专用无线技术规范强调**区间漏缆覆盖、站厅站台覆盖、换乘站功能（含车控室通话、广播/信息互送等）与系统联调**（公开规范标题见 §10，**只借秩序直觉，程序以原文与本网合同为准**）；消防分区/防排烟联测公开资料强调**分区界清楚、联锁要联合测、单侧合格不代表整段**（§10，**故事类比，不是无线电法定依据**）；漏缆（leaky feeder）公开资料强调**沿程覆盖、上下行都要验证、安装与接头影响驻波**（§10）。本篇只借这串顺序——**本网联测窗、界面主人、合格门限以本网制度与合同为准**。

### 2.3 和手册（X/I）/ 29（AB）/ 20（S）/ 27（Z）/ 28（AA）/ 30（AC）/ 31（AD）等的咬合（指针，不重写）

- **X / I**：覆盖与抽样**方法**；AE 不重写怎么布点，只钉「这一窗、这一界面、联测有没有做完、谁签」。  
- **AB（手册29）**：室分电磁环境**复测周期与变更触发**；站厅/站台室分常挂 AB，但**区间联测与换乘界面主贴 AE**——AB 绿≠区间联测过。  
- **S（手册20）**：跨网/互扰；换乘站多制式、多业主同场时，互扰挂 S，联测秩序仍主贴 AE。  
- **Z（手册27）**：开站验收与交维；区间/换乘联测常是 Z 阶段梯上的一格——**Z 要看 AE 联测签，AE 不替代整站交维**。  
- **AA（手册28）**：交维后首年巡检；抽检区间/换乘可挂 AA，缺联测秩序整改主贴仍 AE。  
- **AC（手册30）**：机动开撤；隧道口机动补盲若进入区间责任界面，开撤清场后仍要接上 AE 界面台账指针。  
- **AD（手册31）**：备件/金机；联测用测试机/金机须 AD 准用期内，AD 不替代联测签。  
- **N / Q（历史）**：联测窗曾用 N/Q；**本篇起，区间联测与换乘责任界面主贴 AE**，N/Q 可作支撑指针。  
- **R / T**：假绿挂 R；投诉挂 T；禁功率战。

### 2.4 新贴纸 AE：联 / 换 / 界 / 测 / 治（五个子类）

> 小彩蛋：双字母贴纸续写——**AA** 首年巡检；**AB** 室分复测；**AC** 机动开撤；**AD** 备件金机；**AE** 管「区间联测与换乘责任界面」。A–Z 既有含义不改；新专题用 AA、AB、AC、AD、AE… 续写。

```text
                ┌──────────── 贴纸 AE · 联/换/界/测/治 ────────────┐
                │  AE-联  联测：窗钉死·方法书面·相关角色到场         │
                │  AE-换  换乘：换乘站/通道/线际主人与配合清单       │
                │  AE-界  界面：区间↔站台·漏缆↔室分·线A↔线B 边界   │
                │  AE-测  实测：本区间本期上下行双时隙·禁套他区     │
                │  AE-治  治理：假绿·顶替·套报告·功率战·泄密       │
                └──────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签触发 |
|------|--------|--------------|
| **AE-联** | 无书面窗/方法、该到场未到场仍要签 → 拒签 | 「夜班随便走走就算联测」 |
| **AE-换** | 换乘通道/两线界面无主人无配合清单 → 拒签 | 「通道归土建，无线不管」 |

| **AE-治** | 假绿、用 AB/X 顶替、功率战、泄密 → 治理 | 「室分绿了区间也算过」 |

### 2.5 钉窗 → 清界面 → 联测实测 → 会签放行 → 变更再联测 阶段梯（背下来）

```text
  ① AE-联 钉窗：联测窗角色 · 方法书面（挂 X/I 指针）· 到场角色清单
        │  无窗 / 无方法 → 不开测、不签放行
        ▼
  ② AE-换 / AE-界 清界面：换乘/线际/漏缆-室分衔接主人 · 分界图角色 · 配合清单
        │  无主人 / 分界口头 → 拒进入「可签」状态
        ▼
  ③ AE-测 本区间本期实测：上下行 · 双时隙 · 关键处抽样 · 禁套他区他期
        │  半段 / 单边 / 套报告 → 拒签
        ▼
  ④ 联测会签：界面各方授权本人签「联测通过/有条件整改项」
        │  缺签 / 假绿顶替 → 拒签放行
        ▼
  ⑤ 放行或挂整改：重大未闭禁「区间/换乘放行」；整改有主有期
        │
        ▼
  ⑥ 变更（装修/改管/换漏缆/改写频）→ 走 J + 触发再联测（常挂 AB 室分侧）
```

> **一句话分辨**：**X/I** 回答「覆盖**怎么测**」；**AB** 回答「室分**何时复测**」；**S** 回答「跨网**互扰挂谁**」；**Z** 回答「整站**交维签不签**」；**AE** 回答「这一段区间 + 换乘界面**窗清不清、主人清不清、联测过了没有**」。**五个问题，五张（类）贴纸，不能一笔带过。**

       │

       │

## 3. 核心交付：插页 AE + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AE（而不是先贴 X / AB / Z / S）

| 场景 | 主贴 | 为什么 |
|------|------|--------|

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **联测窗与方法钉死：无书面联测窗（天窗/封锁点角色）与方法（挂 X/I 指针）不得开测、不得签放行；该到场未到场视为联测未完成**。  
2. **换乘/责任界面主人清楚：换乘站、换乘通道、线际与漏缆-室分衔接须有书面主人角色与配合清单；口头分界无效**。  
3. **本区间本期实测：须本脱敏区间、本联测窗、上下行双时隙实测；禁套他区间/他站/他期报告；半段不得顶整段**。  
4. **联测通过才签：界面各方授权本人会签后，方可签「区间/换乘放行」；重大未闭项禁放行**。  
5. **禁顶替：可挂 X/I/AB/S/Z/AC/AD/R 支撑，但区间联测与换乘责任界面主贴 AE；AB 室分绿、X 单点绿、Z 他阶段签均不得顶替 AE 联测签**。  
6. **主贴 AE；监测大屏/系统绿灯、假绿不等于联测通过（挂 R 提醒）**。  
7. **跨网挂 S，投诉挂 T；禁功率战抬功率「压」换乘弱场；覆盖/写频/漏缆变更走 J 并评估再联测**。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/线路名/区间桩号/频点/可还原场强表/联系人**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**半段冒充整段、无联测放行，不是法外运维智慧**。城轨通信验收/专用无线与消防分区联测公开资料只作故事与方法类比（§2.2）：**窗要约、界要清、联要测、单边不算过**——翻译成本网语言就是 AE-联 / AE-换 / AE-界 / AE-测 / AE-治。**这些是联测秩序，不是「半段绿先开通」「拷邻区报告」「抬功率压弱场」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「区间/换乘放行」、对外宣传「分钟级半段绿秒过」、把未联测界面写成已过。允许做的：补窗、补主人、重测、挂 R/S/J、内部挂整改。

### 4.3 「联测放行」最小集（AE）——缺页不能签「区间/换乘放行」

| 序号 | 最小集项（教学） | 为什么必须有 | 缺了会怎样 |
|------|------------------|--------------|------------|
| 1 | **书面联测窗**与到场角色勾选 | 无窗则测无可追溯 | 拒开测/拒签 |
| 2 | **方法书面**（X/I 指针）含上下行双时隙 | 防只测好看的一侧 | 拒测 |
| 3 | **界面主人**与配合清单 | 防推诿 | 拒签 |
| 4 | **责任分界**角色图/表 | 防口头界 | 拒签 |
| 5 | **本区间本期**实测记录 | 防套报告 | 拒签 |
| 6 | **衔接处抽样**记录 | 换乘/接头最脆 | 该抽未抽→整改或拒 |
| 7 | **各方本人会签** | 可复核 | 「系统绿」不够 |
| 8 | **重大未闭清单**（若有）有主有期 | 带病放行禁 | 重大未闭→拒放行 |
| 9 | **公开材料 L3** | 防定位泄露 | 违→治理 |

> **口诀**：窗、法、主、界、区、衔、签、闭、密——**九字联测钉**（教学记忆；现场以本网书面联测规程为准，但 **书面窗 + 界面主人 + 本区本期实测 + 会签** 几乎不可砍）。  
> **弱项短补（为什么上行更先不够用）**：隧道里手台贴漏缆走，下行（基站→手台）往往还「听得见」，上行（手台→基站）功率小、耦合损失大，**先哑在上行**——只报下行绿就签放行，等于消防联测只看「本区烟感亮了」不看「对面排烟启没启」。这和换乘通道只测本侧话音、不测跨线呼叫一样危险。

## 6. 工作实例（12 则，教学虚构，L3）

1. **半段顶整段**  
   现象：只测区间中段下行，签发「全区间合格」。  
   处置：撤销；补上行与衔接；AE-测 拒认原签。  
   教训：半段绿不是整段过。

2. **换乘通道无主**  
   现象：站台签完，通道弱场投诉；双方互推。  
   处置：AE-换/界 书面定主人；重开联测窗。  
   教训：界面口头=事故温床。

3. **套邻区间报告**  
   现象：把邻区报告改脱敏号交差。  
   处置：AE-治；作废；本区本期重测。  
   教训：改号≠联测。

4. **AB 顶替 AE**  
   现象：室分复测全绿，班长主张区间免联测。  
   处置：规则5；主贴 AE；AB 仅支撑室分侧。  
   教训：日历绿≠界面联测过。

5. **假绿放行**  
   现象：网管全绿，无会签就对外宣布开通。  
   处置：挂 R；追 AE7；缺则改「未放行」。  
   教训：大屏≠会签。

6. **对侧未到场**  
   现象：线B 车控室未到，线A 单方签「换乘互通合格」。  
   处置：AE-联 认定未完成；拒签。  
   教训：单边签字像单侧防火联锁。

7. **只测下行**  
   现象：下行漂亮，上行掉话集中在漏缆远端。  
   处置：补上行；讲清弱项；拒原放行。  
   教训：上行往往先不够用。

8. **机动补盲冒充区间合格**  
   现象：AC 机动车在洞口补盲一夜，次日称「区间已好」。  
   处置：AC+AE；补盲≠联测窗；须正式 AE 联测。  
   教训：临时补盲不是验收。

9. **漏缆接头更换未再联测**  
   现象：换接头后直接恢复运营宣称合格。  
   处置：J + AE；衔接处重抽。  
   教训：硬件变了，联测要重生。

10. **功率战压换乘弱场**  
    现象：抬功率压邻居制式。  
    处置：禁功率战；挂 S；参数回写走 J。  
    教训：弱场要用联测与界面治理，不靠功率战。

11. **公开仓泄密**  
    现象：真实桩号+场强表发公开群。  
    处置：撤回；L3 重发；AE-治。  
    教训：联测效率可表扬，定位信息必须脱敏。

12. **金机过期仍出定量结论**  
    现象：联测用测试机校准过期，仍报精确 dBm 门限。  
    处置：AD+AE；结论降级或作废；换期内器具重测。  
    教训：尺歪了，联测数字不可信。

## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 一句话（教学） |
|------|----------------|
| **区间** | 站与站之间的隧道/高架段覆盖责任段（脱敏编号指称） |
| **漏缆** | 沿程辐射的泄漏同轴电缆（leaky feeder）；隧道常见覆盖手段 |
| **换乘责任界面** | 两线/两段/通道与站台之间无线责任与配合的分界 |
| **联测窗** | 书面约定的联合测试时段（常借天窗/封锁点角色） |
| **AE-联** | 窗钉死、方法书面、到场齐全 |
| **AE-换** | 换乘站/通道主人与配合清单 |
| **AE-界** | 责任分界书面清楚 |
| **AE-测** | 本区本期上下行双时隙实测 |
| **AE-治** | 假绿、顶替、套报告、功率战、泄密治理 |
| **半段顶整段** | 用局部合格冒充全区间合格 |
| **单边签字** | 对侧未到场仍签互通/界面合格 |
| **假绿** | 系统/大屏显示正常，但无联测会签 |
| **套报告** | 把他区他期记录改号当本期 |
| **九字联测钉** | 窗法主界区衔签闭密（教学记忆） |
| **界面八字钉** | 有主、有界、有清单、有对侧 |
| **与 X/I/AB/Z 分工** | 量法 / 室分日历 / 整站户口；AE 管联检签字 |
| **上行优先风险** | 隧道场景常先在上行失守 |
| **衔接处** | 漏缆接头、站台入口、换乘通道等脆点 |

**易错观念**

- ❌「中段够了整段过」→ ✅ 含衔接与上行，本区本期。  
- ❌「室分绿=区间过」→ ✅ AB 不顶替 AE。  
- ❌「拷邻区报告更快」→ ✅ 禁套；本窗本区实测。  
- ❌「大屏绿=放行」→ ✅ 假绿挂 R，主贴 AE。  
- ❌「抬功率压弱场」→ ✅ 禁功率战；挂 S/J/AE。

## 9. 自测（12 题）+ 参考答案

1. 贴纸 AE 五个子类是什么？各用四个字以内说明。  
2. 换乘站消防分区联测故事里，「双方到场 / 单边不算过」主要对应 AE 哪两段？  
3. 八条硬规则里，哪一条要求联测窗与方法钉死？  
4. 为什么隧道里「只测下行就签」特别危险？  
5. 「联测放行」至少要具备哪几样（九字联测钉里不可砍的）？  
6. 用 AB 室分全绿顶掉区间联测，违反哪条？主贴谁？  
7. AE 与 X/I / AB / Z 的分工一句话？  
8. 套邻区间报告，主贴什么？能不能改号交差？  
9. 大屏全绿想放行，应挂什么提醒？主贴谁？  
10. 机动车洞口补盲一夜，能不能代替 AE 联测签？  
11. 漏缆接头更换后应走什么变更贴纸并怎样处理联测？  
12. 公开材料能不能贴真实桩号与场强表？依据哪条规则？

### 参考答案

1. **联**（窗与方法到场）、**换**（换乘主人清单）、**界**（责任分界）、**测**（本区本期实测）、**治**（假绿套报告功率战泄密）。  
2. **AE-联** 与 **AE-治/换**（到场联测；单边拒签）。  
3. **规则1**。  
4. 上行往往先不够用；只看下行会系统性漏判「听得见但喊不回去」。  
5. **书面窗、界面主人、本区本期实测、会签**（规则1–4；九字钉核心）。  
6. **规则5**；主贴仍是 **AE**。  
7. **X/I 量法、AB 室分日历、Z 整站户口、AE 管区间与换乘门卫联检是否双方到齐签字**。  
8. **AE-治**；**不能**。  
9. 挂 **R**；主贴 **AE**（规则6）。  
10. **不能**；AC 补盲≠ AE 联测窗。  
11. **J**，并重开 AE 联测窗、衔接处重抽（规则7）。  
12. **不能**；**规则8 脱敏 L3**。
