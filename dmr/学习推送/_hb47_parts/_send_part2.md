## 3. 核心交付：插页 AT + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AT（而不是先贴 AI / AO / N）

- 要签「精密空调冷凝水与加湿除湿联锁准用」、要开加湿/冷凝窗、要交底联锁顺序 → **主贴 AT**。  
- 温湿度测点/门限/联锁巡检本身 → **AI**（手册36）；冷凝路径与加湿本体窗仍 AT。  
- 漏水探测/汇流排本身 → **AO**；冷凝排水路径交底仍 AT；溢水浸水可挂 AO。  
- 冷凝/加湿告警风暴 → 先 **N** 理风暴；缺冷凝/联锁秩序整改仍 **AT**；**禁功率战**。  
- 进机房做交底 → 先 **AN**；门禁过≠冷凝/加湿交底过。  
- UPS 旁路 → **AS**；AS 过≠ AT 过。  
- 假绿/顶替 → 挂 **R**；变更冷凝路径/加湿策略/联锁规程 → 走 **J** 后再验 AT。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **冷凝水路径台账钉死**：机房角色、接水盘 / 排水管 / 冷凝水泵 / 高水位告警入账；禁「接水盘看着干就能签」「口头说一声」。  
2. **加湿除湿有主有窗有方法/准用期**：每次加湿/除湿维护有主人角色、有书面窗、有方法、有准用期；禁「加湿罐在当窗过」。  
3. **联锁窗与方法钉死**：书面固定；方法含气流证明、高水位停加湿等核对项（**顺序与门限以本网与 OEM 书面为准**；本篇不发明逐步带电/排水操作教条）；禁「窗再说」「口头联锁」「绕过高水位联锁」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、照片、读数必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「精密空调冷凝水与加湿除湿联锁准用」；假绿 ≠ 放行。  
6. **禁顶替 AI/AO/AS/AF/AG/AP/AN/AD/AA/N/AQ/AR，主贴 AT，假绿≠放行挂 R**：温湿度签、漏水签、旁路签、油机签、电池签、门禁签、仪表签、首年签、监控签、视频签、通风燃油签都不顶本期冷凝/加湿联锁签。  
7. **冷凝水/加湿/联锁异常风暴挂 N，冷凝路径/加湿策略/联锁规程变更走 J，禁功率战；禁绕过安全联锁；禁不安全排水**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/精密空调序列号全文/可还原坐标与联系人；禁公开传播未脱敏加湿罐编号与联锁参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签冷凝/加湿联锁准用、无实测冒充联锁过、绕联锁冒充秩序齐，不是法外运维智慧**。医院精密空调/CRAC 公开资料、厂商冷凝水/加湿公开科普只作故事与方法类比（§2.2）：**凝要约、湿要窗、联要法、验要本期、盘干不算过**——翻译成本网语言就是 AT-凝 / AT-湿 / AT-联 / AT-验 / AT-治。**这些是精密空调冷凝水与加湿除湿联锁交底秩序，不是「盘干就签」「罐在当过」「抬功率压告警」「绕联锁」「不安全排水」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「精密空调冷凝水与加湿除湿联锁准用」、对外宣传「冷凝一通联锁秒过」、把未实测写成已过、把绕联锁写成秩序齐。允许做的：补冷凝台账、补加湿窗、重开联锁窗、挂 R/N/J、内部挂整改。

| 「真实精密空调序列号发群」 | AT-治 | L3 违规 |

### 5.2 对话脚本（教学）

- **运维→班长**：「接水盘干了，今晚签冷凝/加湿联锁准用？」——「先翻 AT1：有没有冷凝台账和本期联锁实测？没有就拒签，允许补账。」  
- **外包→运维**：「加湿罐还在，窗页免了吧？」——「罐在≠窗过。AT2 要有主人、窗、方法。」  
- **班长→外包**：「AI 温湿度签还在，冷凝也能过？」——「AI≠AT。温湿度过不等于冷凝/加湿联锁过。拒签顶替，可挂 R。」  
- **站务→运维**：「大屏环境绿，实测免？」——「N 绿≠AT 过。要有本期联锁实测与会签。」  
- **网优→班长**：「高湿/溢水告警一片，功率抬一点？」——「**禁功率战**。先 N 理风暴；缺冷凝/联锁秩序整改贴 AT。」  
- **新人→师傅**：「联锁顺序我口头记得，还用写吗？」——「要写。AT3 书面方法钉死；禁口头联锁；以本网与 OEM 书面为准。」

### 5.4 禁写词 / 允许写

禁止写：真实站名、机房全称、精密空调序列号全文、单位名、联系人、真实频点、未脱敏加湿罐编号可还原信息；禁止写「盘干就过」「罐在就过」「口头联锁就过」「AI/AO 签顶 AT」「抬功率压高湿告警」「绕联锁」「不安全排水」「套邻站照片」。允许写：脱敏机房角色、现象（冷凝缺失/加湿无窗/联锁无方法/假绿/风暴）、贴纸（AT/AI/AO/AS/N/AN/R/J）、动作（补账/重测/拒签）。

### 5.5 与弱项的现场对照（再钉一次）

冷凝乱排、加湿无窗、假绿准用，往往先伤**站点环境与设备生存**，再伤空口：上行 12.5 kHz / 4FSK / 2-slot 本来就脆，有人把高湿/溢水告警当覆盖病去抬功率——**禁功率战**。先 AT 证冷凝/加湿联锁秩序，再谈 X/I 覆盖干扰。

## 6. 工作实例（12 则，教学虚构，L3）

1. **接水盘看着干就要签准用** → 拒签；补 AT-凝台账与本期实测。  
2. **加湿罐在当窗过** → 拒签；补 AT-湿主人/窗/方法。  
3. **联锁口头说一声** → 拒签；补 AT-联书面方法。  
4. **套邻站冷凝/加湿照片改机房号** → AT-验 拒签重测。  
5. **AI 温湿度签顶本期冷凝/加湿联锁签** → 拒签顶替；AI≠AT；可挂 R。  
6. **AO 漏水签顶冷凝排水路径交底** → 拒签；漏水过≠冷凝路径交底过。  
7. **N 监控绿免本期实测** → 拒签；N≠AT。  
8. **高湿/溢水告警抬功率** → 挂 N；**禁功率战**；缺秩序整改 AT。  
9. **绕过高水位联锁消告警** → **禁**；挂 N/R；禁签准用。  
10. **不安全排水乱接** → **禁**；挂整改；本篇不教逐步乱排。  
11. **进机房门禁过了就当冷凝/加湿交底过** → AN 过≠AT 过；补 AT。  
12. **公开群贴真实精密空调序列号** → L3 违规；撤帖脱敏；AT-治。
