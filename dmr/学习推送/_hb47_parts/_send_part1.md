- **AI（手册36）**：温湿度与空调联锁**巡检边界**；**AI ≠ AT**——AI 管温湿度测点/门限/联锁巡检秩序；**AT 管精密空调冷凝水路径·加湿除湿本体窗·联锁交底准用**；温湿度过≠冷凝/加湿联锁过；「环境绿」「联锁巡检绿」≠ AT 过。  
- **AO（手册42）**：漏水探测与汇流排；**AO ≠ AT**——漏水探头/地漏/汇排过≠冷凝排水路径交底过；冷凝溢水可挂 AO 理浸水，冷凝/加湿联锁主贴仍 AT。  
- **AS（手册46）**：UPS 旁路；**AS ≠ AT**——UPS 旁路过≠精密空调冷凝过；机房保供电与环境各管各的。  
- **AF（手册33）**：油机市电；供电过≠冷凝/加湿联锁过。  
- **AG（手册34）** / **AP（手册43）**：电池/内阻；电池过≠冷凝/加湿联锁过。  
- **AN（手册41）**：门禁访客；进机房做冷凝/加湿交底仍要 AN——**门禁过≠冷凝/加湿交底过**。  
- **AD（手册31）**：仪表入库走 AD；**不能**用旧 AD 签日期顶本期 AT 窗。  
- **AA（手册28）**：首年巡检日历；冷凝/加湿抽检可挂 AA，缺冷凝秩序整改主贴仍 AT。  
- **N（手册15）**：监控/对时/告警风暴；冷凝/加湿/联锁异常风暴挂 N 理风暴，**不先抬功率**；**禁绕过高水位联锁、禁不安全排水**；N 绿≠ AT 过。  
- **AQ（手册44）**：视频调阅；冷凝溢水/加湿事件要调录像另开 AQ；视频过≠冷凝/加湿联锁过。  
- **AR（手册45）**：油机房通风燃油；AR 过≠ AT 过。  
- **R / J / X / I**：假绿挂 R；变更（冷凝水路径改造、加湿除湿策略、联锁规程）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 AT 证冷凝/加湿联锁秩序，再谈覆盖病**。

### 2.4 新贴纸 AT：凝 / 湿 / 联 / 验 / 治（五个子类）

> 小彩蛋：双字母贴纸续写——**AA** 首年巡检；**AB** 室分复测；**AC** 机动开撤；**AD** 备件金机；**AE** 区间联测；**AF** 油机市电；**AG** 电池充电器；**AH** 合路/POI 界面；**AI** 温湿度联锁；**AJ** 天馈驻波；**AK** 爬塔交叉；**AL** 气灭疏散；**AM** 接地浪涌；**AN** 门禁访客；**AO** 漏水汇排；**AP** 内阻核对；**AQ** 视频调阅；**AR** 油机房通风燃油；**AS** UPS 旁路；**AT** 管「机房精密空调冷凝水与加湿除湿联锁」。A–Z 既有含义不改；新专题用 AA、AB、AC… 续写。

```text
                ┌──────────── 贴纸 AT · 凝/湿/联/验/治 ────────────┐
                │  AT-凝  冷凝：冷凝水路径台账钉死（盘·管·泵·高水位） │
                │  AT-湿  加湿：加湿除湿有主有窗有方法准用期         │
                │  AT-联  联锁：窗·方法钉死（气流证明·高水位停等）   │
                │  AT-验  验收：本组本机房本期实测·禁套他站他期     │
                │  AT-治  治理：假绿·顶替AI/AO/N·绕联锁·乱排·泄密 │
                └──────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签触发 |
|------|--------|--------------|
| **AT-凝** | 无冷凝台账、接水盘看着干无本期联锁实测仍准用 → 拒签 | 「接水盘看着干就能签」「口头说一声」 |
| **AT-湿** | 加湿除湿无主人、无窗、只看罐在 → 拒签 | 「加湿罐在就算过」 |
| **AT-联** | 无书面联锁窗/方法、口头联锁、绕高水位联锁 → 拒签 | 「口头联锁就行」「高水位告警旁路掉」 |
| **AT-验** | 套他站他期曲线/照片、无会签 → 拒签 | 「邻站冷凝照片拷过来改机房号」 |
| **AT-治** | 假绿、用 AI/AO/AS/AF/AG/AP/AN/AD/AA/N/AQ/AR 顶替、绕联锁、不安全排水、功率战 → 治理 | 「AI/AO 签还在，冷凝也能过」 |

### 2.5 建冷凝台账 → 钉加湿窗 → 联锁方法钉死 → 本期实测 → 会签放行 → 变更再验 阶段梯（背下来）

```text
  ① AT-凝 建冷凝台账：机房角色 · 接水盘/排水管/冷凝水泵/高水位告警角色 · 禁「接水盘看着干就能签」「口头说一声」
        │  无账 / 盘干无实测 → 不签精密空调冷凝水与加湿除湿联锁准用
        ▼
  ② AT-湿 钉加湿窗：加湿除湿主人角色 · 书面窗 · 方法 · 准用期 · 禁「加湿罐在当窗过」
        │  无主人 / 无窗 / 无方法 / 无准用期 → 拒进入「可签」状态
        ▼
  ③ AT-联 钉联锁方法：书面窗 · 方法（气流证明、高水位停加湿等；以本网与 OEM 书面为准） · 到场角色 · AD 仪表准用指针
        │  无窗 / 「口头联锁」/ 「绕过高水位联锁」 → 拒联锁签
        ▼
  ④ AT-验 本组本机房本期实测：实测记录 · 禁套他站他期曲线/照片 · 会签
        │  套票 / 只看监控绿 → 拒签
        ▼
  ⑤ 会签放行「精密空调冷凝水与加湿除湿联锁准用」；假绿≠放行；未闭项挂整改
        │
        ▼
  ⑥ 冷凝水路径/加湿除湿策略/联锁规程变更 → 走 J → 再验 AT
```
