## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 本篇用法（教学） |
|------|------------------|
| **AT** | 本篇贴纸：精密空调冷凝水·加湿除湿·联锁交底 |
| **AT-凝** | 冷凝水路径台账（盘·管·泵·高水位） |
| **AT-湿** | 加湿除湿有主有窗有方法准用期 |
| **AT-联** | 联锁窗与书面方法（气流证明、高水位停等） |
| **AT-验** | 本组本机房本期实测·禁套·会签 |
| **AT-治** | 假绿·顶替·绕联锁·不安全排水·功率战·泄密治理 |
| **精密空调 / CRAC** | 机房专用温湿度控制单元；本篇钉冷凝路径与加湿除湿联锁交底，不替代 AI 温湿度巡检 |
| **接水盘** | 冷凝水收集盘角色；看着干≠准用 |
| **冷凝水泵** | 将冷凝水排出机柜的泵角色（若有） |
| **高水位告警** | 水位过高告警角色；常与停加湿等联锁（以 OEM/本网书面为准） |
| **加湿罐/电极加湿** | 加湿本体角色之一；罐在≠窗过 |
| **除湿** | 通过降温等方式去湿；与加湿对打（CRAC fighting）要有秩序，本篇只钉交底不写节能数值 |
| **联锁准用** | 会签后允许宣称本期冷凝/加湿联锁交底合格；假绿≠准用 |
| **假绿** | 监控绿/盘干/罐在冒充准用；挂 R |
| **套票** | 套他站他期曲线/照片；AT-验拒签 |
| **L3** | 对外脱敏等级：禁真实站名/全称/序列号/单位名/联系人 |
| **AI / AO / AS / N** | 温湿度 / 漏水汇排 / UPS旁路 / 监控风暴——均不顶替 AT |
| **R / J** | 假绿挂 R；变更走 J 后再验 AT |

**易错观念（纠一次）**

1. 「接水盘看着干 = 冷凝准用」→ **错**。要有台账与本期联锁实测。  
2. 「加湿罐在 = 窗过」→ **错**。要有主人、窗、方法、准用期。  
3. 「AI 温湿度过 = AT 过」→ **错**。AI≠AT。  
4. 「AO 漏水过 = 冷凝排水路径交底过」→ **错**。AO≠AT。  
5. 「N 监控绿 = 本期联锁实测过」→ **错**。N≠AT。  
6. 「高水位告警烦，先旁路联锁」→ **禁**。绕联锁挂 N/R。  
7. 「溢水先抬功率压告警」→ **禁功率战**。  
8. 「邻站照片改机房号能交差」→ **套票拒签**。
