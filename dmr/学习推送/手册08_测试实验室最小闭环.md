# 手册 08 · 运维分诊：测试实验室最小闭环

> **手册模式 · 岗位深挖（运维 / 测试交界）第 8 篇**（接第 40 课收官 · 手册 01–07 之后 · **不是第 41 课**）  
> 适合：手册 01–07 已经给了你贴纸 A–F 和五格梯子，可一到「能不能在台架上复现」你就卡住——「现场偶发，实验室好好的」「金机也挂，到底怪谁」「Grant 了，台架上有没有声？」「射频三过了，还要不要测？」「中继一发就聋，怎么在台架上证明是双工自扰」——你想学会**先在可控台架上把故障钉死，再决定贴哪张贴纸、要不要出外勤爬铁塔**的人  
> 阅读量：约 **30–40 分钟** · **不重 dump CACH / EMB / Slot Type 全字段**（第 18–22 课已有）、**不重讲 Hunt / Reason / 鉴权算术**（手册01–05）、**不发明 ETSI 条款号**、**不写真实频点 / 站点名 / 个号 / 密钥**（全部教学虚构） · 要把「**刺激 → 观察 → 判定 → 证据包；没有闭环就没有贴纸；金机对照是每一环的锚**」钉成肌肉记忆  
> **频谱 / 调制提醒（弱项短补）**：一条 DMR 信道占 **12.5 kHz** 宽的一条「车道」；车道里用 **4FSK**（四个频偏台阶，每个符号装 2 bit，约 **4800 符号/秒 → 9.6 kbps** 毛速率）装货；再用 **2-slot TDMA** 把时间切成 **30 ms** 一格、两格一轮 **60 ms**，两路话轮流用。台架上的每一种闭环，最终都在问这三句话里的某一句：**「我刺激的是不是正确的那条车道 / 那个时间格？」「观察端是否真的看到了 4FSK 台阶被正确判出？」「判定有没有写成可挂到总三联单的证据包？」** 四句话原版见 `学习推送/加餐_频率带宽与调制解调.md`。本篇把第 40 课 §5.3b「测试实验室最小集」展开成可执行的六条闭环。

## 1. 为什么要写这篇手册（动机 + 现场对话）

前七篇手册教你**认病**：贴纸 A–E 是协议层，贴纸 F 是射频层（五格梯子）。可现场还有一种更糟的病——**认错地方**：

- 运维：「现场偶发登记失败，实验室怎么也复现不了。」——没有**刺激剧本**，只是「开机看看」。  
- 测试：「仪表上 SYNC、CC 都好，用户说没声。」——没做 **Grant→业务信道有声** 闭环，停在第 3 格。  
- 班长：「金机也挂，肯定是基站坏了。」——金机对照没做完：同点、同写频、同固件基线？还是把金机也写成了故障机同款坏写频？  
- 新人：「那就出外勤吧，带分析仪去站下。」——五格梯子第 1–4 格在台架上**还没问完**，外勤成本先花掉了。  
- 站务：「减敏？你有证据吗？」——没有**发射开 / 关**对比的台架记录，只有口头「感觉聋了」。  
- 网优：「覆盖问题。」——台架上射频三过（能量够、CC 对、BER 低），现场却贴 F-弱——**没做「射频三过 vs 协议贴纸」分流**。  
- 用户：「直通能通，上中继不行。」——上下行不对称，现场像贴纸 B；台架上用可变衰减能一次分清。

这几句背后是同一件事：

> **「测过了」这个词在现场至少有四个意思**：  
> **① 刺激（stimulus）**：你对系统做了什么（登记、呼叫、注入已知电平、开启发射）  
> **② 观察（observation）**：你看到了什么一手证据（网管、空口、屏显、仪表；手册06 的 E1–E5）  
> **③ 判定（verdict）**：过 / 不过 / 不确定；贴哪张贴纸；下一动作是什么  
> **④ 证据包（evidence pack）**：能挂到总三联单、脱敏后可交接的那一组截图 / 日志 / 对时记录  
> 缺任何一环，就不叫**闭环**——叫「看了一眼」。

本篇目标：能背出**最小闭环四件套**；会用新贴纸 **G（实验室 / 闭环验证）** 和 **插页 G**；能跑通**六条实用闭环**（金机对照、登记/鉴权信令、Grant→有声、上下行不对称、射频三过分流、减敏台架）；会把闭环结果写进总三联单并可与插页 A–F 组合；能填完《本网测试实验室最小闭环检查表》（含 10 个工作实例对照）；自测过关后，回库把本网最近两张「现场偶发、实验室好好的」工单（脱敏到 L3）按本篇重写。

**本篇硬禁令（写进脑子）**：不发明 ETSI 条款号（帧结构锚点以第 18–22 课、`01-空中接口/` 笔记为准）；**不写真实批复频点、真实站点名 / 站号、真实个号、真实密钥、真实仪表序列号进公开仓库**（本篇所有电平、BER、CC、衰减值都是**教学值**）；**不教未授权发射、不教在批复外频点上做任何发射测试**——台架发射只走本单位实验室 / 维护窗规程与假负载；不把厂商仪表菜单中文名当成 ETSI 正式名；本篇不写下一篇手册正文；**不把「开大功率」当排障手段**（手册07 加功率禁令在台架上同样成立）。

## 2. 总图 / 故事：先在台架上把虫子钉死

### 2.1 一句话：闭环 = 刺激 → 观察 → 判定 → 证据包

把第 40 课 §5.3b 展开成一张图：

```text
   ┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────────┐
   │  刺激     │ ──▶ │  观察     │ ──▶ │  判定     │ ──▶ │  证据包       │
   │ stimulus │     │ observe  │     │ verdict  │     │ evidence pack│
   └──────────┘     └──────────┘     └──────────┘     └──────────────┘
        │                 │                │                  │
   固定剧本：         一手来源：        过/不过/X          挂总三联单
   登记/组呼/         网管+空口+        贴纸 A–F 或 G      A1–A6 / T / N
   鉴权失败对照/      屏显+仪表         下一动作写清        插页 G + 脱敏
   注入已知电平/
   发射开·关
```

**四件套缺一不可**：

| 件 | 没有它会发生什么 | 好例子（教学虚构） | 坏例子 |
|----|------------------|--------------------|--------|
| 刺激 | 「随便开开看」→ 偶发永远偶发 | 「剧本 R-登：开机→等 Aloha→发 C_RAND；重复 10 次」 | 「测了一下登记」 |
| 观察 | 只剩口头「好像挂了」 | 「网管 19:02:11 ACK(Reason=—)；空口可解本网 CC；屏显注册成功」 | 「用户说不行」 |
| 判定 | 证据一堆，没人敢结案 | 「10/10 成功 → 过；贴 G：台架闭环通过；现场另查 F」 | 「感觉是干扰」 |
| 证据包 | 交接时对方重测一遍 | 「对时偏差 −00:00:12；截图 3 张已 L2；插页 G 填齐」 | 微信里一张模糊照片 |

> **剧本比设备贵。** 没有剧本，再贵的分析仪也只是看热闹——第 40 课原话，本篇把它写成检查表。

### 2.2 台架最小物理图（没有黄金仪表也能起步）

```text
                    ┌─────────────┐
                    │ 假负载 / 衰减 │◀── 经批准的台架发射只进这里
                    └──────▲──────┘
                           │
   ┌────────┐   同轴/耦合   ┌──────┴──────┐   监听/注入    ┌──────────┐
   │ 金机    │◀────────────▶│ 合路/隔离/   │◀─────────────▶│ 分析仪或  │
   │ (对照)  │              │ 可变衰减器   │               │ 可抓突发  │
   └────────┘              └──────┬──────┘               │ 的接收端  │
   ┌────────┐                     │                      └──────────┘
   │ 待测机  │◀────────────────────┘
   │ (DUT)  │
   └────────┘
        │
        ▼ 网管 / 屏显 / 录音（观察端）
```

**最小集（接第 40 课 §5.3b）**：

1. **金机** 1 台（已知写频、固件、天线正常；有基线记录）  
2. **待测机（DUT）** 1 台  
3. **可观察手段**至少一种：网管日志、空口抓取、带 CC/BER 的分析仪、或「金机听音 + 录音」  
4. **固定剧本**（本篇 §3.2 六条闭环）  
5. **对时锚点**（手册06 对时三步）  
6. **假负载 + 可变衰减**（做电平扫描 / 减敏对比时；发射必须经批准）

没有分析仪时：**诚实写「仅金机 RSSI + 现象，未测 CC/BER」**，判定最多到 X 或「需补测」，不许假装射频三过。

### 2.3 新贴纸 G：实验室 / 闭环验证

| 贴纸 | 一句话 | 层 | 回哪篇 |
|------|--------|----|--------|
| A 猎站 | 还没守住自家 TSCC | 协议 | 手册04 |
| B 登记 | 到了前台没给钥匙 | 协议 | 手册01 |
| C Grant 无声 | 发了房卡，房间静 | 协议 | 手册02 |
| D 鉴权 | 出了题、交了卷、没过 | 协议 | 手册05 |
| E 管理操作 | Stun/Revive/DGNA/短信没按预期 | 协议 | 手册03 |
| F 覆盖 / 干扰 | 车道本身出了问题 | 射频 | 手册07 |
| **G 实验室 / 闭环（新）** | **故障能否在可控台架上按剧本复现；证据包是否齐** | **验证层（横切）** | **本篇** |
| X 证据不足 | 诚实地说还不知道 | — | 手册06 |

**G 不是第七种病，是验病的章。** 用法：

- **G 过 + 现场仍挂** → 现场条件差（多半 F 或配置漂移），不是「终端玄学」  
- **G 不过（台架可复现）** → 先修台架能复现的根因（写频 / 固件 / 协议贴纸 A–E），再谈外勤  
- **G 不确定（刺激或观察缺）** → 结论只能是 X，补闭环，禁止贴 A–F 结案

**组合规则（接手册06 §4.6「最多两张贴纸」）**：

| 组合 | 含义 | 典型 |
|------|------|------|
| **G 主 + B 次** | 台架按登记剧本可稳定复现失败 | 写频缺行 / Reason 剧本对得上 |
| **G 主 + C 次** | 台架 Grant→业务信道无声可复现 | CHAN 门牌 / 时隙写错 |
| **G 主 + D 次** | 台架鉴权失败可复现 | K/PSN 问题；先证明有题有答 |
| **G 主 + F 次** | 台架用衰减/发射对比复现射频指纹 | 减敏、过载；外勤补点 |
| **F 主 + G 次** | 现场像 F，台架射频三过 | 真覆盖 / 他网；G 证明不是终端 |
| **禁止：只贴 G 结案** | G 说明「验过了」，不说明「病叫什么」 | 必须带 A–F 或 X |

## 3. 核心交付：四件套工作流 + 六条闭环 + 插页 G

### 3.1 最小闭环工作流（每张「要进实验室」的工单照念）

```text
① 选环：用户原话 / 现场指纹 → §5.1 表 → 选闭环①–⑥（可组合，主环写清）
② 对时：手册06 对时三步；表头写基准与偏差
③ 金机锚：确认金机基线未过期（§7.3）；金机先跑同一剧本应「过」
④ 刺激：按剧本执行 N 次（建议 ≥10 次或至稳定）；记录每一次
⑤ 观察：网管 + 空口/仪表 + 屏显，至少两个一手来源（E1）
⑥ 判定：过 / 不过 / X；贴纸 G +（A–F 或仅 X）；下一动作 / 禁止动作
⑦ 装袋：填插页 G；截图脱敏；挂总三联单；需要外勤的写清「台架已排除什么」
```

**金机先过，DUT 再测。** 金机都不过 → 先修实验室（写频服务器、中继台架、仪表、剧本），禁止给 DUT 下「终端故障」结论。

### 3.2 六条实用闭环（本篇心脏）

#### 闭环① · 金机对照闭环（每一张单的锚）

| 件 | 内容 |
|----|------|
| 刺激 | 同点（或同台架衰减档）、同信道逻辑号、同剧本；金机与 DUT **交替**各跑 N 次 |
| 观察 | 成功/失败计数；若有仪表：RSSI、CC、BER；屏显与网管是否一致 |
| 判定 | 金机过 + DUT 不过 → 终端侧（写频/固件/硬件/天线）；两者都不过 → 系统/射频/剧本；两者都过 → 现场偶发或条件差异（转 F 或配置漂移） |
| 证据包 | 「金机基线编号、固件版本哈希（脱敏）、N 次结果表」 |

**铁律**：金机必须是**已知良好**，不是「另一台也可能坏的机器」。金机基线过期（例如写频批次大变更后未重跑）→ 先刷新基线。

#### 闭环② · 登记 / 鉴权信令闭环

| 件 | 内容 |
|----|------|
| 刺激 | 剧本 R-登：开机搜网→等本网 Aloha/SYNC→发登记；剧本 R-鉴：触发鉴权（本网规程允许的方式）；各含**故意失败对照**（如关闭鉴权密钥行的对照机，教学用） |
| 观察 | 空口：有无题有无答（手册05）；网管：ACK 族 / Reason；屏显 |
| 判定 | 可稳定复现 → G 主 + B 或 D；对得上 Reason 剧本 → 按手册01/05；台架过、现场不过 → 查现场 F 或列表/Hunt（A） |
| 证据包 | 信令时间线（对时后）；Reason 值（教学码可用）；「有题有答」勾选 |

#### 闭环③ · Grant → 业务信道有声闭环

| 件 | 内容 |
|----|------|
| 刺激 | 剧本 R-呼：发起组呼/个呼（教学对象号）；等待 Grant；在业务信道听音 / 看业务 burst |
| 观察 | 是否真 Grant（手册02 第一问）；CHAN·时隙·门牌；业务信道 Payload SYNC·CC·时隙；**有没有声**（录音或仪表） |
| 判定 | Grant 到了但无声且射频三过 → C；业务信道 BER 高 / CC 乱 → F 主 + C 次；台架有声现场无声 → 现场 F 或覆盖 |
| 证据包 | Grant 时间戳 + 业务信道 5 秒录音（脱敏）+ CC/时隙记录 |

#### 闭环④ · 上下行不对称闭环

| 件 | 内容 |
|----|------|
| 刺激 | 可变衰减扫描：从「金机舒适区」逐步加衰减（教学步进 3–5 dB）；每档做：听下行 Aloha / 试上行登记或短呼 |
| 观察 | 每档：下行是否可解本网 CC；上行是否有 ACK；BER |
| 判定 | 下行仍好、上行先挂 → **上行链路更弱**（像 B，实为覆盖/衰减差）；上下行几乎同档挂 → 对称问题或终端 |
| 证据包 | 「衰减档 × 下行/上行结果」表；结论写「不对称方向」 |

> 现场「直通能通、上中继不行」常落在这里：直通是对称短距；中继暴露上行。台架用衰减模拟「变远」，比直接出外勤便宜。

#### 闭环⑤ · 射频三过 vs 协议贴纸分流闭环

| 件 | 内容 |
|----|------|
| 刺激 | 在**业务或控制信道**（按故障类型选）注入/接收到「金机舒适区」电平 |
| 观察 | 五格梯子前四格：能量、SYNC、本网 CC、BER（手册07） |
| 判定 | **三过**（能量够、本网 CC、BER 低）→ **离开射频**，按 A–E 分诊；任一格不过 → 贴 F，不要先翻 Reason |
| 证据包 | A3 写成「①②③④」四行，禁止写「信号好/差」 |

这一环专门治两种浪费：**射频三过还在爬铁塔**；**第 1 格都没问就在翻 Reason 剧本**。

#### 闭环⑥ · 减敏 / 双工自扰台架闭环（概念教学；维护窗）

| 件 | 内容 |
|----|------|
| 刺激 | **仅维护窗、经批准、假负载**：接收端注入已知测试信号（或固定金机位置）；本站发射机 **停发** vs **发射** 各测一轮（接手册07 R6） |
| 观察 | 两状态 BER / 灵敏度差异（教学：记「差了多少 dB」相对量，不写绝对门限） |
| 判定 | 发射时明显变差 → F-互（减敏），转站务查双工器/隔离/接头；两状态差不多 → 排除本站自扰，转外扰或协议 |
| 证据包 | R6 表格；批准单号（L1）；**禁止**把真实站名/频点写进公开仓 |

**衰减器 3:1（手册07 R7）**可作⑥的姐妹环：加 10 dB 衰减，真信号降约 10 dB，三阶互调产物降约 30 dB——台架上比站下更安全，但仍须规程。


### 3.2.1 组合拳：一张单常跑几条环？

| 现场指纹 | 建议顺序（主→次） | 止损 |
|----------|-------------------|------|
| 单机问题 | ① →（不过则）②或③ | ①已定终端就停 |
| 登不上 | ① → ⑤ → ② | ⑤非本网 CC 则转 F，不深挖 Reason |
| 没声 | ① → ⑤ → ③ | ⑤不过先 F |
| 直通/中继差 | ① → ④ → ⑤ | ④定上行后外勤补点 |
| 一发射就聋 | ① → ⑤ → **预约⑥** | 无窗则 A6 写未做，不臆断减敏 |
| 偶发 | ① → ⑤ → 加长 N（≥30）或 mixed 时段 | 台架仍过 → G 过转现场 |

**止损规则**：已经能唯一解释的环，就不要为了「看起来勤奋」把六条全跑一遍——但 **①几乎总要有**。

### 3.3 总三联单：实验室证据怎么写

| # | 项 | 实验室工单好例子（教学虚构） | 坏例子 |
|---|----|------------------------------|--------|
| A1 | 设备 + 时间 | 「台架#L2；金机G3+DUT#17；分析仪#2；19:02–19:25；网管基准，分析仪 −00:00:12」 | 「下午测的」 |
| A2 | 信道 + 台架拓扑 | 「CH-α（逻辑号）；合路器+30 dB 衰减档；假负载」 | 真实 MHz |
| A3 | 闭环结论 | 「闭环③：Grant 10/10；业务 CC=本网；BER 低；有声。射频三过 → 非 F」 | 「台架正常」 |
| A4 | 序列 | 「19:05 起剧本 R-呼；19:06:02 Grant；19:06:05–19:06:20 有声」 | 「打通了」 |
| A5 | 原始证据 | 「录音 1 段（已消音地点）；网管导出；插页 G」 | 只写结论 |
| A6 | 负证据 | 「闭环⑥未做（无维护窗）；闭环④衰减扫描未做」 | 不写 |

### 3.4 插页 G · 实验室 / 闭环验证（挂在总三联单后）

| # | 格 | 填什么（教学虚构例） |
|---|----|----------------------|
| R1 | 主闭环编号 | ①金机对照 / ②登记鉴权 / ③Grant有声 / ④上下行 / ⑤射频三过分流 / ⑥减敏台架（主 + 次，最多两个） |
| R2 | 剧本名与次数 | 「R-呼 ×10；金机先跑 ×5 过」 |
| R3 | 金机锚 | 「金机G3；基线日期；同写频批次？是/否」 |
| R4 | 台架拓扑 | 「衰减档 __ dB；假负载；合路/直连；（草图编号）」 |
| R5 | 刺激摘要 | 「做什么、对谁、故意失败对照有无」 |
| R6 | 观察摘要 | 「网管 / 空口 / 屏显 / 仪表：各一句」 |
| R7 | 判定 | 「过 / 不过 / X；贴纸 G + __；下一动作；禁止动作」 |
| R8 | 证据包清单 | 「对时记录、截图 n、录音、插页、是否已 L2 脱敏」 |

**插页组合**：G 几乎总与 A–F 之一同挂；**单独一张只有 G 的单不算结案**。G 与 X 同挂 = 「做了闭环但刺激/观察仍不够」。

### 3.5 「未闭环禁止」卡（贴实验室门）

```text
在插页 G 的 R1–R8 没填完之前，下面这些话不许进结论栏：
  × 「终端故障」        （金机对照没做完）
  × 「基站故障」        （金机也不过时，先查台架/剧本）
  × 「覆盖问题」        （闭环⑤射频三过没问）
  × 「干扰」            （没有 CC/BER/时段证据，手册07）
  × 「实验室正常所以是用户问题」 （现场条件未比对）
可以做：
  ✓ 选环、对时、金机先跑、按剧本刺激、双源观察、装证据包
  ✓ 判定为 X 并写清缺哪一件
```


### 3.6 证据等级在实验室怎么落到格（接手册06 E1–E5）

| 等级 | 实验室例子 | 能不能单独支撑「不过」判定 |
|------|------------|----------------------------|
| E1 一手 | 本人在台架看网管+分析仪 | 能 |
| E2 同步多源 | 网管与空口时间线对齐后一致 | 能，且更强 |
| E3 线索 | 用户电话里说的「刚才挂了」 | 不能单独 |
| E4 推导 | 「所以应该是减敏」但无⑥ | 不能当结案 |
| E5 推测 | 「肯定是厂家固件锅」 | 禁止进结论栏 |

插页 G 的 R6 至少要能指到 **E1 或 E2**；只有 E3 时 R7 只能写 X。

## 4. 深潜：为什么台架能（或不能）代替现场

### 4.1 弱项短补：台架上的 12.5 kHz / 4FSK / 30 ms 意味着什么

台架不是「另一个世界」，它还是同一条车道：

| 概念 | 台架上要盯的 | 刺激打偏时的后果 |
|------|--------------|------------------|
| **12.5 kHz 车道** | 合路/仪表中心频率是否对准逻辑信道对应的教学频点（L0 保管，不进公开仓） | 打到邻道 → 假「无信号」或假「邻频」 |
| **4FSK 四个台阶** | BER / 星座（若有）是否干净；电平是否落在接收机线性区 | 电平过高 → 过载像 F-互；过低 → 像 F-弱 |
| **30 ms 时隙** | Grant 指定的 TS1/TS2 是否真在听那一格 | 听错时隙 → 假「Grant 无声」（贴纸 C 冤案） |

**SINAD 与 BER**：模拟时代常用 **12 dB SINAD** 定义灵敏度；数字时代常用 **达到某 BER 的最低电平**。台架上两者都是「质量尺子」，但 DMR 排障优先 **BER + CC + SYNC**（手册07 三数），SINAD 更多出现在模拟对比或仪表说明书里——知道名字即可，不必在 DMR 闭环里强行测 SINAD。

### 4.2 台架能钉死什么、钉不死什么

| 能钉死（适合 G） | 钉不死（需要现场 / 手册07） |
|------------------|------------------------------|
| 写频缺行、门牌错误、固件回归 | 他网按时段占用（F-同时间规律） |
| 鉴权 K/PSN 配错（手册05） | 真实传播：楼体、电梯、车体损耗 |
| Grant 后听错时隙 / CHAN | 共址互调随天气/天线阻抗变化 |
| 终端频偏过大（金机对照） | 直通用户「碰巧」出现在某时段 |
| 双工器接头松（⑥在站上维护窗） | 复用距离在交界处的空间指纹 |

**所以 G 的正确姿势不是「实验室过了就结案」**，而是：「实验室排除了 A–E 和终端，现场请按 F 七步补证据」——或反过来。

### 4.3 观察端的「一手」纪律（接手册06）

闭环里最容易掺假的是观察：

- **只用用户口述** → 不是 E1，是 E3 线索  
- **只看厂商网管中文「失败」** → 要落到 Reason / 空口有无题有答  
- **仪表未对时** → A4 时间线不可用  
- **金机与 DUT 不同时、不同衰减档对比** → 假对照  

**双源最小集**：网管 **或** 屏显 + 空口/仪表/录音——至少两路。

### 4.4 故意失败对照：为什么剧本里要有「故意挂」

第 40 课说固定剧本要含「登记鉴权失败、Grant 后故意写错 CC」。因为：

```text
  只会测「快乐路径」
       → 你分不清「观察端坏了」还是「真的过了」
  快乐路径 + 故意失败对照
       → 观察端能报失败 = 仪表/网管链路可信
       → 故意写错 CC 后应无声/拒收 = 接收机在认 CC（第3格活着）
```

**故意失败只在台架、教学机、假负载上做**；不对生产用户、不对批复外频率、不把错误写频留在出库机器上。

### 4.5 证据包与脱敏（实验室版补丁）

| 级别 | 实验室可留 | 公开仓 / 外发群 |
|------|------------|-----------------|
| L0 | 真实频点、站号、个号、密钥材料 | **禁止** |
| L1 | 逻辑信道号、内部工单号、金机资产号 | 仅内网 |
| L2 | 相对电平、相对衰减档、教学 CC、对时偏差 | 可外发协作（去站名） |
| L3 | 本篇实例这种：无任何可定位信息 | 培训 / 公开手册 |

频谱/星座截图：绝对频率刻度改相对；仪表序列号打码；背景里的站点铭牌裁掉。


### 4.6 闭环与五格梯子对照表（防止跳格）

| 闭环 | 主要爬哪几格 | 典型出口贴纸 | 一句话防呆 |
|------|--------------|--------------|------------|
| ① 金机对照 | 全格对比「是谁差」 | 终端 / 系统 / X | 先分锅，再分病 |
| ② 登记/鉴权 | 第 5 格为主，先确认第 2–3 格活着 | B / D / A | 没本网 Aloha 别谈 Reason |
| ③ Grant有声 | 第 5 格 + 业务信道第 2–4 格 | C / F+C | Grant≠有声 |
| ④ 上下行 | 第 1–4 格分上下行各爬一次 | F-弱（上行） | 像 B 先疑覆盖 |
| ⑤ 射频分流 | **只爬第 1–4 格** | 离开→A–E 或贴 F | 三过就停射频 |
| ⑥ 减敏台架 | 第 4 格在两种发射状态下 | F-互 | 无批准不做 |

```text
  错误跳格示例（禁止）：
  「登记失败」──跳过①⑤──▶ 直接换基站板件
  「没声」──跳过③的听音──▶ 只看网管 Grant 计数就结案
  「偶发」──实验室开机一次成功──▶ 写闭环通过
```

### 4.7 台架安全与合规（写进实验室墙）

本篇所有发射相关步骤，默认遵守：

1. **频率**：只用本单位实验室批复 / 屏蔽室 / 假负载回路；公开文档只写逻辑信道号。  
2. **功率**：教学与排障用**最低足够**功率；不拿「加大功率」当变量（手册07 禁令）。  
3. **批准**：闭环⑥、任何站上发射开/关，必须维护窗 + 书面/工单批准。  
4. **负载**：不确定天线回路时，**先假负载**；驻波异常立刻停发。  
5. **人员**：不明设备、不明线缆，不接发射口。  
6. **记录**：批准单号进 R8 / A1（L1），公开仓删掉可识别信息。

> 闭环是为了**可重复的证据**，不是为了在台架上「多发射几次碰运气」。

## 5. 现场映射：用户原话 → 选哪条闭环；对话脚本

### 5.1 原话 → 主闭环

| 原话（E3 线索） | 主闭环 | 次环 / 出口 |
|-----------------|--------|-------------|
| 「就我这台不行」 | ① 金机对照 | 终端栏；不贴 F |
| 「有时登不上」 | ② 登记/鉴权 | 台架过→现场 F 或 A |
| 「鉴权失败」 | ② + 手册05 七步 | G 主 + D |
| 「Grant 了没声」 | ③ Grant有声 | 射频三过→C；否则 F+C |
| 「直通行，中继不行」 | ④ 上下行不对称 | 常为上行弱；像 B |
| 「信号满格登不上」 | ⑤ 再 ② | 先问 CC 是否本网（F-同） |
| 「中继一说话就断」 | ⑥ 减敏台架 | 维护窗；F-互 |
| 「实验室好好的」 | ①+⑤ 后外勤 | G 过证明非终端玄学 |
| 「晚上七点准时挂」 | ⑤ 台架通常过 | 转手册07 时段 F-同 |
| 「换了写频就不行」 | ①+②+③ | 写频 diff（L0） |

### 5.2 实验室 40 分钟标准节奏（可复印）

```text
00–05  读工单；选主闭环；对时；确认金机基线
05–10  金机跑同一剧本（应过）；不过则停，先修台架
10–25  DUT 按剧本 ×N；双源观察；填 R5/R6
25–32  需要则补⑤射频三过或④衰减扫描
32–38  判定；填插页 G；装证据包；脱敏检查
38–40  写下一动作：结案 / 转手册01–07 / 预约维护窗⑥
```

### 5.3 值班对话脚本

#### 对话 A · 「实验室复现不了」

> 班长：现场老挂，实验室好好的，是不是用户乱讲？  
> 你：实验室「好好的」要写清跑的是哪个剧本、几次、金机有没有先过。若闭环①⑤都过，我倾向贴 **G 过 + 转现场 F**——不是否认用户，是排除了终端和写频。下一步按手册07 七步补时段和 CC。

#### 对话 B · 「金机也挂，基站挂了」

> 你：金机也挂时，先别定基站。请看：金机基线日期、写频批次、台架衰减档、中继台架是否假负载。金机基线过期或剧本打到错时隙，会造成「双挂」假象。我先重刷金机基线再下结论。

#### 对话 C · 「先出外勤吧」

> 你：外勤可以，但闭环⑤还没做。台架上若射频三过，外勤目标就不是爬塔测场强，而是按手册01–05 抓信令；若三不过，外勤才带频谱仪按 F。我先花 15 分钟做⑤，可能省一次出车。

#### 对话 D · 「减敏你有证据吗？」

> 你：现在没有，只有现象。我申请维护窗做闭环⑥：假负载、发射开/关对比，把 BER 差记进插页 G 的 R7。没有 R6 对比，我不会在单子上写减敏。

#### 对话 E · 「把功率开大再测」

> 你：台架上开大功率对假负载可能安全，但对判型常常有害——过载会制造假 F-互。闭环用**已知衰减档**扫，不靠加功率。手册07 加功率禁令在实验室同样贴着。

### 5.4 反例集

| 错误 | 正确 |
|------|------|
| 实验室开机登记一次成功就写「闭环通过」 | 固定次数 + 金机先跑 + 故意失败对照 |
| 无分析仪却写「射频三过」 | 写「未测 CC/BER」，判定 X 或仅协议侧 |
| 把厂商菜单「发射测试」当 ETSI 名 | 用教学名：刺激/观察；菜单名放括号 |
| 闭环过了就结案不管现场 | G 过 + 说明现场仍需 F 或配置核对 |
| 维护窗外做⑥发射对比 | 禁止；写进 A6「未做⑥」 |

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「就我这台登记失败」→ G + B（写频）
闭环①：金机 10/10 登记成功；DUT 0/10。闭环②：空口有 C_RAND，网管 Reason 对得上「未授权」（教学码）。**G 主 + B 次**。写频缺组附件。教训：没有①就会误判基站。

### 例 2 · 「Grant 了没声」→ G + C
闭环③：Grant 10/10；业务信道听错时隙（人耳听 TS1，Grant 在 TS2）。射频三过。**G 主 + C 次**。修正监听时隙后有声。对照手册02 四问第二问。

### 例 3 · 「满格登不上」台架版 → 先⑤再分流
闭环⑤：台架舒适区电平，解出 CC=9，本网 CC=3（教学值）——台架合路器误接到教学用「邻系统」信号源。**不是现场 F，是台架拓扑错**。修好合路后闭环②过。教训：R4 台架拓扑必须写。

### 例 4 · 「直通行中继不行」→ ④ 上行先挂
衰减扫描：下行 CC 可解至较高衰减档；上行登记在较低衰减档就无 ACK。金机同样。**G 主 + F-弱（上行）表象像 B**。下一动作：网优看上行覆盖；用户临时「靠近再登」。

### 例 5 · 「鉴权失败」→ G + D
闭环②：空口「有题有答」，答后 NACK；金机同 K 基线过。**G 主 + D 次**，转手册05（K/PSN/串号）。若空口「有题无答」则先查 F 或终端发射，不急着怪密钥。

### 例 6 · 「中继一转发就断」→ ⑥ 减敏
维护窗闭环⑥：停发 BER 低；发射 BER 明显升高（教学相对差）。**G 主 + F-互**。站务紧固双工器接头后复测无差异——复测写回同一张单。

### 例 7 · 「实验室正常、现场晚上挂」→ G 过转 F-同
①⑤③台架全过。现场按时段录：19:00 起本网 CC 消失、他网 CC 出现（手册07 例1 同类）。**F-同（主）+ G（次，证明非终端）**。禁止写「用户胡说」。

### 例 8 ·（对照）未闭环就贴「终端故障」→ 被打回
原单：一次登记失败，结论终端故障，未做①。重做①：金机同台架也不过——中继台架假负载未接好，驻波保护。**结论 X→修台架**；DUT 无问题。本例应进误贴周报。


### 例 9 · 「短信偶发丢失」→ 先 G 再决定是否 E
用户报「短信有时到有时不到」。闭环①金机与 DUT 同台架：用教学短信剧本 R-短 ×20。金机 20/20，DUT 18/20 失败两次均在「业务信道 BER 瞬时升高」窗口（分析仪记录）。**不是先贴 E**：补闭环⑤发现台架合路器接触不良导致偶发 F 指纹。紧固后 20/20。**G 主，E 排除**。教训：管理业务（贴纸 E）也要先过射频三过与金机对照。

### 例 10 · 「Stun 成功但 Revive 无效」台架剧本
闭环扩展（接手册03）：剧本 R-管：Stun→确认无呼出→Revive→确认恢复。金机全过；DUT Stun 过、Revive 后仍无呼出。空口可见 Revive 相关信令（教学描述，不写厂商菜单名），网管显示已 Revive。继续闭环①换天线 / 换电池后仍挂 → 终端固件状态机可疑，转终端维修，**G 主 + E 次**；A6 写明「射频三过已做」。

### 6.5 测试 × 运维 × 站务 对齐会：15 分钟议程

```text
00–03  本周 G 类单：过 / 不过 / X 计数；误贴（未闭环就下终端结论）数
03–07  抽一张「G 过转现场」：现场是否按 F 补了证据？
07–11  金机基线是否过期；剧本库是否新增故意失败对照
11–15  维护窗⑥预约；下周只改 3 条行动
```

## 8. 术语表（本篇约 28 词）+ 易错观念

| 术语 | 一句话 | 易错 |
|------|--------|------|
| 闭环 | 刺激→观察→判定→证据包 | 缺一环就不算测过 |
| 刺激 stimulus | 你对系统做的固定动作 | 不是「随便开开」 |
| 观察 observation | 一手证据来源 | 用户口述是线索不是观察 |
| 判定 verdict | 过/不过/X + 贴纸 | 不能只有感觉 |
| 证据包 | 可挂三联单的材料组合 | 要脱敏 |
| 金机 | 已知良好对照终端 | 基线过期就不是金机 |
| DUT | 待测设备 | — |
| 剧本 | 可重复的刺激序列 | 比仪表贵 |
| 故意失败对照 | 已知应失败的剧本 | 只在台架教学机做 |
| 贴纸 G | 实验室闭环验证章 | 不单独结案 |
| 插页 G | R1–R8 台架记录 | 与 A–F 插页并列 |
| 射频三过 | 能量够+本网CC+BER低 | 三过就离开射频 |
| 五格梯子 | 能量→同步→身份→质量→业务 | 手册07 |
| 12.5 kHz | DMR 信道带宽 | 台架中心不能偏道 |
| 4FSK | 四台阶频偏调制 | 台阶判错=误码 |
| TDMA 30 ms | 一时隙时长 | 听错时隙→假无声 |
| BER | 误码率 | 数字灵敏度常用尺子 |
| SINAD | 模拟灵敏度常用尺子 | DMR 闭环不强制 |
| 灵敏度 | 达质量门限的最低电平 | 门限看设备规格 |
| 衰减扫描 | 用已知衰减模拟变远 | 优于乱加功率 |
| 上下行不对称 | 听得见基站、基站听不见你 | 像 B，实为链路 |
| 假负载 | 吸收发射功率的终端负载 | 台架发射默认入口 |
| 减敏 desense | 自发自收导致灵敏度下降 | 闭环⑥开/关对比 |
| 合路/隔离 | 台架信号分配与保护 | 拓扑写错会假故障 |
| 对时 | 多源时钟对齐 | 手册06 |
| 脱敏 L0–L3 | 证据能去哪 | 实验室也要守 |
| 维护窗 | 批准的可发射测试时段 | 窗外不做⑥ |
| X | 证据不足 | 诚实比结案重要 |

**五个易错观念**：① 开过机 ≠ 闭环；② 金机也挂 ≠ 基站坏；③ 实验室过 ≠ 现场无问题；④ 无 CC/BER ≠ 可写射频三过；⑤ 加功率 ≠ 台架标准刺激。

## 9. 自测（10 题）+ 参考答案

1. 最小闭环四件套是什么？缺观察时能不能贴 A–F 结案？  
2. 贴纸 G 和贴纸 F 有什么不同？G 能否单独结案？  
3. 为什么金机必须先跑同一剧本？金机不过时怎么办？  
4. 闭环③里「有 Grant」和「有声」是不是一回事？  
5. 上下行不对称闭环④的典型观察是什么？容易误贴哪张贴纸？  
6. 射频三过之后下一步应该去哪？  
7. 闭环⑥减敏对比的前提条件有哪些？  
8. 「实验室正常、现场晚上挂」最合理的贴纸组合？  
9. 没有分析仪时，A3 应该怎么写？  
10. 故意失败对照的目的是什么？可以在生产用户机器上留错误写频吗？

### 参考答案

1. 刺激→观察→判定→证据包。缺观察时结论只能偏 X，不能当 A–F 结案。  
2. F 是射频病因；G 是「台架是否按剧本验证过」的章。G 不能单独结案，须带 A–F 或 X。  
3. 金机先过证明台架/剧本/观察端可信；金机不过先修实验室，不给 DUT 下终端故障结论。  
4. 不是。Grant 只是房卡；有声要在业务信道确认 Payload/听音（手册02）。  
5. 下行仍可解、上行先无 ACK；易误贴 B。  
6. 离开射频，按手册01–05 贴 A–E。  
7. 维护窗、经批准、假负载/规程；发射开 vs 停发对比同一测试信号。  
8. F-同（或相应 F 子类）主 + G 次（证明台架/终端非根因）。  
9. 诚实写「仅金机 RSSI/现象，未测 CC/BER」，不写射频三过。  
10. 验证观察端能报失败、接收机在认 CC 等；**不可以**把错误写频留在出库/生产用户机器上。
