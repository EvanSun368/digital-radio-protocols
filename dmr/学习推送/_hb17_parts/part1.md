## 1. 为什么要写这篇手册（动机 + 现场对话）

前十六篇手册教你认病、交维、写频、电源监控、有源隔离：贴纸 A–E 协议层，F 射频，G 实验室，H 话务，I 室分，J 写频，K 电源，L 井库，M 批量/OTAP，N 监控/对时/风暴，O 有源隔离/减敏。可现场还有一类「病」——**不是洞内灯灭了，而是门口两家喇叭对着过道抢客，过客耳朵左右跳，洞里还灌进隔壁店的广告**：

- 施工队：「洞内走测过了，可以签。」——没人问口部切换区画在哪；开通两周门口乒乓投诉刷屏。  
- 新人：「门口一过就断，肯定是同频。」——没先问切换窗与邻站泄漏；假 F 工单满天飞。  
- 班长：「门口糊，邻站功率再加两格。」——外溢更大，洞内更吵；整段口部被自己抢客拖垮。  
- 射频同事：「洞内听到邻站，肯定干扰。」——可能是邻站泄漏进洞（P-泄）；先 P，再挂 F。  
- 领导：「加个站盖门口就行。」——切换窗未定义、泄漏未测就加站 = 门口再多一家喇叭。  
- 手册13 学过的人：「L-切 不是已经写过坡道猎站吗？」——L 管井库三维路径与门开闭；本篇是 **口部/出入口切换与邻站泄漏的加深册**，主贴新贴纸 **P**。  
- 手册10 学过的人：「I-覆 口部也测过。」——I 管交维清单气质；本篇钉死切换窗定义、泄漏测点、拒签门槛。  
- 有人：「加功率压一下门口断话。」——加功率是手册07/09/10/16 禁区；本篇也禁。

这几句背后是同一件事：

> **「口部切换 / 邻站泄漏」这个词在现场至少有五个坑**：  
> **① P-口**：口部/出入口覆盖与切换区定义——洞口、楼门、库坡道、换乘口；谁的优势区画到哪  
> **② P-切**：切换窗/驻留/乒乓/切换失败气质（制度层，**不 dump 空口字段**）——窗多宽、能不能停、会不会左右跳  
> **③ P-泄**：邻站泄漏进洞/进楼/进库——隔壁喇叭的声浪灌进你店里  
> **④ P-邻**：邻站参数与功率外溢边界（脱敏）——邻站该响到哪、不该响到哪  
> **⑤ P-治**：治理与拒签——口部未测禁签、金机口部走测、脱敏 L3  
> 把 ①–⑤ 当成「厂商切换参数自动搞定」或「出了事用手册07 先开同频单」，会把口部债与邻站外溢债留给整条走廊与下一班。

本篇目标：能背出**口部切换与邻站泄漏治理工作流**；会用新贴纸 **P（口部/切换/泄漏）** 与五个子类；会填 **插页 P（R1–R8）** 和《本网口部切换与邻站泄漏治理卡》；能用「**两家商店喇叭对着门口抢客**」或「**地铁换乘口两列车同时喊话**」故事讲清切换窗与泄漏；能拒绝「口部未测就签、用加功率掩盖邻站串音、未做金机口部走测、切换窗未定义就加站」；自测过关后，回库把本网最近一次口部/邻站相关事件（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：不发明 ETSI 条款号；**不写真实批复频点、真实楼宇名、真实站号、真实个号、真实密钥、真实单位名进公开仓库**；**不教干扰攻击、故意抬噪邻站、仿冒切换、空口劫持步骤**——只讲制度与治理；不重写手册13 / 10 / 07 / 16 / 09 全文（只给指针）；**手册13 的 L-切、手册10 的 I-覆 仍生效，本篇加深口部切换与邻站泄漏**；**不把加功率/加增益/盲目加站当乒乓与泄漏的止痛药**；口部/泄漏问题**主贴 P**，可挂 L/I/F/O，禁止把「门口左右跳」直接写成「用户捣蛋」或「协议玄学」；结案词用贴纸 P + 本网证据；公开蜂窝/ DAS 口部切换、泄漏控制、邻区规划资料只借**精神与顺序**——**不背条款号当 ETSI、不背厂商菜单当本网制度、不把蜂窝 RSRP 数字抄进 DMR 公开包当法规**。

## 2. 总图 / 故事：口部像「两家商店喇叭对着门口抢客 / 地铁换乘口两列车同时喊话」

### 2.1 一句话：必须先证明口部切换区画清、邻站泄漏可测、金机口部走测过关，再谈加站加功率——否则门口抢客、洞内串音、交维假绿

   ┌──────────────────────────────────────────────────────────────┐
   │  商场走廊 / 地铁换乘口（本网隧道口·楼门·库坡道·站厅出入口）   │

   │   店 A 喇叭 = 本站/本扇区覆盖 ——P-口 的「自己店」              │

口诀：

> **先画门口，再定切换窗，后测泄漏，末金机走测。**  
> 两家喇叭对着门口抢客还不划界 = 换乘口两列车同时喊话——**切换窗必须可指认。**  
> 只测店内不测门口 = 交维假绿——**口部/出入口金机走测强制。**

### 2.2 「门口抢客」五段直觉（弱项短补，钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **口部定义** | 店门口过道画在哪 | 洞口/楼门/坡道/换乘口的优势区边界；室内外过渡带 | P-口 |
| **切换窗** | 过客该在哪一段换耳朵 | 窗的空间长度与驻留气质；乒乓=左右跳；失败=断话气质（制度层，不 dump 字段） | P-切 |
| **邻站泄漏** | 隔壁广告灌进店里 | 洞外/楼外邻站能量进洞/进楼/进库；门口串音 | P-泄 |
| **邻站外溢** | 喇叭音量不该喊过界 | 邻站功率/参数边界（教学相对值）；禁靠加功率抢客 | P-邻 |
| **治理** | 拒签与交维台账 | 口部未测禁签；金机口部走测；公开包脱敏 L3 | P-治 |

> 公开蜂窝/DAS 设计资料常写「出入口应有明确双向切换区」「控制室内信号外泄以免路边快移用户误切」「扇区边界避开滞留区以免乒乓」——本篇只借**顺序直觉**：定义口部 → 定义切换窗 → 测泄漏 → 核邻站外溢边界 → 金机口部走测 → 拒签治理。**不背厂商邻区参数菜单 / 不背标准条款号当 ETSI / 不把蜂窝 RSRP 门限抄进 DMR 公开包当法规。**

### 2.4 新贴纸 P：口部 / 切换 / 泄漏（五个子类）

```text

```

| 子类 | 一句话 | 典型拒签 / 拒加站触发 |
|------|--------|----------------------|
| **P-口** | 口部/切换区未在图上可指认 → 禁签 | 「洞内测了」但门口无测点无边界 |
| **P-切** | 切换窗未定义或乒乓未排除 → 禁签/禁加站 | 门口左右跳当「用户走快」结案 |
| **P-泄** | 邻站泄漏未测 → 禁签 | 洞内听到邻站却无泄漏对照 |
| **P-邻** | 外溢边界未写或靠加功率抢客 → 拒 | 「邻站再响一点盖过去」 |
| **P-治** | 拒签门槛 + 金机口部走测 + 脱敏 | 用公网满格或只测洞内交差 |

## 3. 核心交付：插页 P + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 P（而不是先贴 L / I / F / O）

| 现象 | 优先贴纸 | 说明 |
|------|----------|------|
| 隧道口/楼门/库坡道乒乓、断话 | **主 P**，可挂 L/I | L 管井库路径；门口抢客用 P |
| 洞内/楼内听到邻站串音 | **P-泄**，可次挂 F | 先问泄漏，禁先开同频单 |
| 交维只测洞内不测口部 | **P-口 / P-治** 拒签 | 呼应手册10「金机走测」气质 |
| 要加站/加功率「盖门口」 | **P-邻 / P-治** 拒 | 规则1/2；先证切换与泄漏 |
| 切换窗口头说说无图 | **P-切** 拒签 | 窗必须可指认 |
| 井道门关衰减/厅门黑洞 | 主 **L**，不是 P | P 不管轿厢门本身 |
| 有源远端啸叫抬噪 | 主 **O**，口部症状可次挂 P | 先隔离再谈门口 |
| 真同频/邻道被证明 | 主 **F**，P 作排除项 | 先排除泄漏与乒乓气质 |

### 3.2 插页 P · 口部 / 切换 / 泄漏（挂在总三联单或室分/井库交维首页后）

| 行 | 名称 | 填写示例（教学虚构） |
|----|------|----------------------|
| **R1** | 主子类 + 次子类 | 「主 P-切 / 次 P-泄」（或 P-口 / P-邻 / P-治） |
| **R2** | 口部形态 | 「隧道口双扇区过渡；楼门室内外；库坡道」（脱敏，无楼名站号） |
| **R3** | 切换区定义 | 「图上可指认边界；优势区归属；滞留区是否避开扇区边」 |
| **R4** | 切换窗气质 | 「窗大致长度/驻留是否够；乒乓有无；失败气质有无（制度描述，不 dump 字段）」 |
| **R5** | 邻站泄漏 | 「洞外↔洞内 / 门外↔门内对照；教学相对值；是否灌入」 |
| **R6** | 邻站外溢边界 | 「邻站功率/参数边界教学相对值；是否靠加功率抢客」 |
| **R7** | 金机口部走测 | 「口部双侧/双向路径点位；与洞内对照；可挂 L 门开闭若涉及」 |
| **R8** | 判定与动作 | 「拒签 / 带条件签（14 日内补口部复测）/ 禁加站加功率；脱敏 L3」 |

> **R3 与 R5 不过 → 口部相关交维必须拒签。**  
> **R7 不过 → 禁止「洞内测了就算」签字。**  
> **R8 若写「加功率/加站试试」→ 本页作废重填。**

### 3.4 和总三联单怎么写（接手册06）

- **现象**：写「口部双向走测时乒乓」或「洞内可闻邻站串音」，不要写「同频」除非已排除 P。  
- **证据**：切换区图（脱敏）、泄漏对照相对值、金机口部点位、邻站外溢边界相对值。  
- **时钟**：若与手册15 风暴同时，写清三钟差；漂移大则禁秒级因果。  
- **贴纸栏**：主 **P-? **，次挂 L/I/F/O/H（若有）。  
- **结案词**：用 P 子类 + 动作（改窗/抑泄漏/拒签/带条件），禁用「加功率好了」「加站就好了」。
