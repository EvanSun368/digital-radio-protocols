## 4. 五个插页：每类故障只多问那几格

总单回答「证据是否成立」；插页回答「这类故障**特有的**几格」。每个插页控制在 4–6 格，细节全部回原手册，**不在这里重 dump**。

### 4.1 插页 A · 猎站 / CHAN（回手册04）

| 格 | 填什么 | 好例子（教学虚构） |
|----|--------|--------------------|
| A-1 | 终端猎站列表版本 + 计划类型（固定 / 灵活） | 「短列表 v3，含站A/站B；灵活计划」 |
| A-2 | 能否解 SYScode / Aloha，SYScode 是否本网 | 「Aloha 稳定，SYScode 匹配本网」 |
| A-3 | 守住 TSCC 了吗（有没有本机登记 RAND） | 「全窗无本机登记 RAND」 |
| A-4 | 网络近期是否新开 / 撤载频、改 TSCC | 「10-09 撤旧 TSCC」 |
| A-5 | Hunt 卡在哪一阶段（手册04 四阶段指纹） | 「疑似一直在扫列表」 |

**一句话判法**：A-3 为「无本机登记 RAND」→ 先 A，别谈 B/D。

### 4.2 插页 B · 登记（回手册01）

| 格 | 填什么 | 好例子（教学虚构） |
|----|--------|--------------------|
| B-1 | 登记 C_RAND 时间 | 「10:02:11」 |
| B-2 | 回条族：ACK / NACK / WACK | 「C_NACKD」 |
| B-3 | Reason 十六进制原码 | 「0x2B」 |
| B-4 | 窗内有无 AHOY + ACKU 0x48（排除 D） | 「无」 |
| B-5 | 对应《本网 Reason 剧本》哪一行 | 「剧本第 3 行」 |

**一句话判法**：B-4 为「有」→ 升级插页 D；为「无」→ 留在 B。

### 4.3 插页 C · Grant 无声（回手册02）

| 格 | 填什么 | 好例子（教学虚构） |
|----|--------|--------------------|
| C-1 | 业务 C_RAND（呼叫类型）时间 | 「18:02:11 组呼语音」 |
| C-2 | 真 Grant 吗 + 票样名 | 「TV_GRANT ×3」 |
| C-3 | CHAN 逻辑号 + 时隙位 | 「CHAN=17，slot 位=0」 |
| C-4 | 终端写频里有没有这个 CHAN | 「老批次无 17」 |
| C-5 | Payload 上 SYNC / CC / 时隙能否对上 | 「Payload 有语音帧，CC 一致」 |

**一句话判法**：C-2 不是 Grant（是 ACK 或 NACK）→ 回 B 或手册01，别在 C 里打转。

### 4.4 插页 D · 鉴权（回手册05）

| 格 | 填什么 | 好例子（教学虚构） |
|----|--------|--------------------|
| D-1 | 有题（AHOY）有答（ACKU 0x48）吗 | 「有」 |
| D-2 | 随后结局（Reason / 超时） | 「NACK 0x2B」 |
| D-3 | K 状态（**只写有/无/同步时间，不写值**） | 「网管有记录；10-10 导入」 |
| D-4 | PSN 状态（启用 / 换板后重录否） | 「启用；本周返厂，未重录」 |
| D-5 | 串号排查 | 「同号仅一台在网」 |
| D-6 | 正向 / 反向 | 「正向（登记场景）」 |

**一句话判法**：D-1 为「无」→ 这张单不是 D，退回 B 或 A（手册05 七步①）。

### 4.5 插页 E · 管理操作：Stun / Revive / DGNA / 短信（回手册03、第39课）

| 格 | 填什么 | 好例子（教学虚构） |
|----|--------|--------------------|
| E-1 | 操作类型 + 下发时间 + 下发人 | 「Stun，19:10:03，网管-03」 |
| E-2 | 审批单号（管理操作必须有） | 「审批 S-0412」 |
| E-3 | 终端是否在线 / 在哪个站 | 「最近登记站B，19:05」 |
| E-4 | 空口回条（原码） | 「ACK 回条；或 Reason 0x14」 |
| E-5 | 是否涉及反向鉴权 | 「是；回 0x14 → 走手册05 七步⑦」 |
| E-6 | 重发次数 | 「0 次（按规矩先查再发）」 |

**一句话判法**：E-4 出现 `0x14` → **禁止盲目重发**，先对 K（手册03 + 手册05）。E-2 为空 → 不是技术问题，是流程问题，先补审批。

### 4.6 插页组合规则

| 组合 | 常见场景 | 主次 |
|------|----------|------|
| B + A | 登记被拒后终端去猎站，掉到邻站 | 主 B，次 A |
| D + B | 有题答对后 NACK | 主 D（B 只记 Reason） |
| C + A | Grant 到新载频，终端门牌没这号，回 TSCC 后又猎站 | 主 C |
| E + D | 遥毙回 0x14 | 主 E，D 做七步⑦ |
| A + C + D | — | **不允许**；回总单重对时，先去掉一个 |

## 5. 现场映射：烂单 → 好单；对话脚本

### 5.1 常见烂单句式 → 应改成什么

| 烂单原句 | 问题 | 改成（教学虚构） |
|----------|------|------------------|
| 「用户说登不上」 | E4 转述；无时间；无现象原话 | 「T3：用户#A 10:02 开机，屏显『注册失败』（照片附件1）」 |
| 「信号不好」 | E5 推测；空口没看 | 「A3：Aloha 稳定可解；A6：全窗无本机 RAND」 |
| 「注册失败 2B」 | 无时间；无设备；无窗 | 「A4：10:02:11 C_RAND → 10:02:12 C_NACKD 0x2B（网管时间）」 |
| 「系统正常」 | 无证据 | 「N6：同时段同站 40 次登记 39 成功」 |
| 「鉴权失败」 | 没写题答对 | 「D-1：有 AHOY + ACKU 0x48；D-2：随后 NACK 0x2B」或「A6：全窗无 AHOY → 非 D」 |
| 「频点 4xx.xxxx 有干扰」（进了群） | 脱敏越级 | 「CH-α 疑似干扰，原始频点见 L1 工单附件」 |
| 「已重发遥毙 3 次，无果」 | 违规动作 | 「E-6：已重发 3 次（违规，已上报）；E-4：每次回 0x14」 |
| 「厂商要日志，已发全天日志」 | 最小必要失守 | 「已发 10:00–10:10 摘录，个号替换为用户#A/#B」 |

### 5.2 值班对话脚本（可直接照着说）

**对话 A · 夜班交来一张「三栏都有字」的空心单**

- 你：「我看三栏都写了，先问三个问题：时间窗是几点到几点？空口栏是谁录的、录到了这个时间吗？网络栏那句『正常』是查了什么？」  
- 夜班：「大概十点，空口没录，网络是我看了眼网管没告警。」  
- 你：「那这单现在是『证据收集中』，贴纸先写 X。今天白班补：用户再复现一次，我们开分析仪先对时再录；网管导 10:00–10:05 那台的登记日志。」

**对话 B · 网管和分析仪时间对不上**

- 测试：「网管说 10:02 拒绝，我录的里面 10:02 什么都没有。」  
- 你：「你录制开头对时了吗？没有的话，找一条你录到、网管也有的登记成功，当锚点。」  
- 测试：「找到了，网管 10:00:05，我这边 09:56:53。」  
- 你：「偏差减三分十二秒。那你去看 09:58:59 附近——就是网管的 10:02:11。表头写上『以网管为准，分析仪 −00:03:12』。」

**对话 C · 群里有人贴了带个号的截图**

- 你：「这张图里有完整个号和站名，麻烦先撤回。群里是 L2，个号留末四位、站名用代号。原图放到 L1 工单附件里。」  
- 同事：「就内部群，没关系吧？」  
- 你：「群会被转发、被截图，出了群就控制不住了。规矩是按去处脱敏，不按『我觉得没关系』。」

**对话 D · 厂商要「完整日志」**

- 厂商：「请把网管全部日志发我们分析。」  
- 你：「我们按最小必要给：事件时间窗前后五分钟，只含涉事终端，个号已替换为代号。要更多时间段请说明原因，我们再按单申请。密钥类信息任何情况都不提供。」

**对话 E · 班长质检退单**

- 班长：「这张单我打 6 分，退回。」  
- 你：「扣在哪？」  
- 班长：「对时 0、负证据 0、动作 1。空口栏只写了看到 NACK，没写有没有看到 AHOY，所以没法排除鉴权；也没写禁止动作。」  
- 你：「明白，补 A6『全窗无 AHOY』和『禁止换天线、禁止重发』，再交。」

### 5.3 「先证据 / 后结论」反例集

1. **先结论**：「肯定是覆盖」→ 派人上塔 → 实际是 Reason 0x2B 开户问题。**教训**：A4 没填就不许谈覆盖。  
2. **先修改**：看见「鉴权失败」立刻重导 K → 把原本正确的 K 覆盖错了。**教训**：D-1 没证实之前不许动开户库。  
3. **先重发**：Stun 没回音就连发 → 多次管理命令叠加，状态更难判断。**教训**：E-6 > 0 必须写原因。  
4. **先外发**：图省事整包日志给厂商 → 个号泄露。**教训**：外发前过 §7.4。  
5. **先口头**：电话里说清了，工单没写 → 第二天换班全丢。**教训**：口头结论 5 分钟内落单。

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 空心单 → 补证后变 B

- **原单**：T「用户说登不上」；A「没看」；N「正常」。质检 3 分，退回。  
- **补证**：用户#A 复现；分析仪对时（−00:03:12）；A4「10:02:11 C_RAND(登记) → 10:02:12 C_NACKD 0x2B」；A6「全窗无 AHOY」；N2「个号未加入新批次授权」。  
- **结论**：贴纸 B；下一动作「开户补授权」；禁止「换机 / 换天线」。质检 13 分，入范例库。

### 例 2 · 时间没对时，结论差点反了

- 网管 10:02 报拒绝；分析仪在「10:02」看到一条 **ACK 成功**，于是有人写「网管误报」。  
- 对时后发现分析仪慢 3 分 12 秒，「10:02」的 ACK 其实是网管时间 10:05:14 **第二次开机成功**的那次。  
- **结论**：第一次是 B（Reason 0x2B），第二次成功是因为白班 10:04 已补授权。**教训**：没对时，「先后」都会搞反。

### 例 3 · 「鉴权失败」单，A6 写出负证据

- 网管中文提示写「鉴权失败」。空口栏 A6「全窗无 C_AHOY」。  
- **结论**：不是 D。按插页 B，Reason 原码为 0x2A，对《本网 Reason 剧本》处理。网管提示文字记入「线索」，并给网管同事发一条「该提示文字与空口不符」的备注。

### 例 4 · 真 D：返厂换板

- D-1 有 AHOY + 0x48；D-2 随后 NACK；D-4「本周返厂换主板，PSN 未重录」。  
- **结论**：主 D，次 B。下一动作「开户按流程重录 PSN（L0 系统内完成）」。工单里 PSN 只写「已重录 / 未重录」，不写值。

### 例 5 · Grant 了没声：插页 C 一格就破案

- C-2「TV_GRANT ×3」；C-3「CHAN=17」；C-4「该终端写频包为旧批次，无 17」。  
- **结论**：贴纸 C；下一动作「该批终端补写频」；禁止「查射频」。N5 写明「10-09 新增逻辑号 17」——网络变更和终端版本**在同一张单里对上了**，这就是三联单的价值。

### 例 6 · B + A 组合

- 用户#B 登记被拒（0x2B）后，空口栏看到终端离开站B TSCC；网管 30 秒后在站C 看到它的登记 RAND。  
- **结论**：主 B（根因开户），次 A（拒绝后猎站属正常行为，见手册01 例「登记拒绝后去猎站」）。**不要**把「掉到站C」当覆盖问题另开一单。

### 例 7 · 管理操作 E：缺审批

- E-1「Stun，19:10」；E-2 空。  
- **结论**：先暂停技术排查，补审批单号；补齐后 E-4 显示 ACK 正常回条，终端已按预期禁用——这张单本来就**不是故障**，是流程没走完被当成了「Stun 失败」。

### 例 8 · E + D：遥毙回 0x14

- E-4「Reason 0x14」；E-6「0 次重发」（好习惯）。  
- **结论**：主 E，D 做七步⑦反向；下一动作「开户核该机 K 同步时间」；禁止「重发 Kill」。

### 例 9 · 脱敏事故复盘

- 群里一张截图露出完整个号 + 站点真名 + 频点。  
- **处置**：撤回；L1 工单补「脱敏事故」记录；按 §3.4 重发 L2 版本；班组周会复盘一次。  
- **教训**：脱敏一票否决，不靠自觉，靠**发之前过检查表**（§7.4）。
