## 1. 为什么要写这篇手册（动机 + 现场对话）

前六十四篇手册从 A–E 协议一路写到 BK 蒸发器盘管清洗与翅片完好：其中 **BI 回答「日用/储油罐油位与泄漏」**（日用油箱里的油不是散热器里的缸套水，**油位/泄漏过 ≠ 冷却液液位/保护过**），**AR 回答「柴油发电机房通风排烟与燃油安全巡检边界」**（燃油安全窗里可能顺带提到冷却，但没有单独给冷却液液位和高温/低水位保护各钉一张巡检台账），**AF 回答「油机市电切换与机房供电巡检」**（周检/本体清单会写到冷却液，**写到 ≠ 本篇台账过**），**AV 回答「日用油箱油品净化与加油交接」**（加的是油，不是冷却液），**AO 回答「漏水与接地汇流排探测」**（地面积水探头绿 ≠ 缸套水路液位/保护过），**N 回答「监控对时与告警风暴」**，**BK / BJ / BH / AG / AD / AA / AQ** 各管蒸发器盘管清洗翅片、吸排过热过冷、冷却水泵冷凝水、电池充电器、备件、首年巡检与视频证据。可还没有单独钉死一件事——**机房柴油发电机冷却液液位与高温低水位保护不是「看着有液 / 表看着在绿区 / 保护灯绿 / 口头说加过了 / BI 油位过 / AR 燃油安全过 / AF 切换或周检过 / AV 油品过 / AO 漏水探头过就能签」：冷却液液位的台账要钉死；高温保护与低水位保护两侧都要有主人有窗有方法有准用期；边界窗与方法要书面固定；本期实测禁套他站他期——能不能签「机房柴油发电机冷却液液位与高温低水位保护巡检准用」？** 这就是本篇的 **BL**——**机房柴油发电机冷却液液位与高温低水位保护交底台账**（Excel 风格双字母：BK 之后 → **BL**）。

**五个词必须先分清，再往下读（本篇反复钉）**：

| 中文词 | 英文 | 作用 | 本系列谁管 | 不等于 |
|--------|------|------|------------|--------|
| **冷却液 / 缸套水** | coolant / jacket water | 在发动机水套、散热器、膨胀水壶（回液瓶）里循环、带走燃烧室热量的液体路径 | **BL-位**（本篇）管液位；保护窗 **BL-护** | **≠ 日用油箱里的柴油**；**看着有液 ≠ 液位台账过**；**BI≠BL** |

| **高温保护** | high coolant temperature protection | 冷却液温度高报警/停机保护窗；有主有方法有准用期 | **BL-护**（本篇，高温侧） | **保护灯绿 ≠ 窗过**；**高温保护过 ≠ 低水位保护过** |

- 通风排烟与燃油安全 → **AR**。油机市电切换与供电巡检 → **AF**（周检写到冷却液 ≠ 本篇台账）。油品净化加油 → **AV**。漏水汇排 → **AO**。**AR ≠ BL；AF ≠ BL；AV ≠ BL；AO ≠ BL**。  
- 进机房先 **AN**（门禁过 ≠ 交底过）。气灭 → **AL**。风暴先 **N**，缺秩序整改仍 **BL**；油位泄漏另问 **BI**；燃油安全另问 **AR**；切换/试车另问 **AF**；油品另问 **AV**；地面积水另问 **AO**；**禁功率战、绕联锁、旁通、不安全泄放冷却液教条、热机/带压乱开散热器盖教条**。  
- 假绿/顶替挂 **R**；变更走 **J** 后再验 BL。  
- 无柴油发电机、无缸套水/散热器冷却液路径 → 书面「不适用」；**不得**用 BL 顶 AF/AR/BI/AV/AO，也不得用它们顶 BL。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **冷却液液位台账钉死**：机组、散热器或膨胀水壶角色与液位窗、本期对照各自有账（编号脱敏）；禁「看着有液就算过」「口头说加过了」；液位过 ≠ 保护过，保护过 ≠ 液位过。  
2. **高温/低水位保护侧有主有窗有方法/准用期**：高温侧与低水位侧分开看；测点、动作（报警/停机）、合格窗与准用期以本网与 OEM 书面为准；每次保护交底有主人角色、有书面窗、有方法、有准用期；禁「保护灯绿就算过」「表看着在绿区就算过」「套邻站保护照片」；高温保护过 ≠ 低水位保护过。  
3. **边界窗与方法钉死**：书面固定；方法含与 BI/AR/AF/AV/AO/N 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明配比配方、泄放步骤、绕联锁操作或热机开盖步骤教条；**不重写 BI/AR/AF/AV/AO 全文**）；禁「窗再说」「绕高温/低水位等保护联锁」「开旁通冒充」「不安全泄放冷却液教条」「热机/带压乱开散热器盖教条」「把配比当教条」「伪造台账」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、液位对照、高温侧与低水位侧保护必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「机房柴油发电机冷却液液位与高温低水位保护巡检准用」；假绿 ≠ 放行。  
6. **禁顶替 AF/AR/BI/AV/AO/AD/AA/N/AQ 等，主贴 BL，假绿≠放行挂 R**：他贴签都不顶本期冷却液液位/保护签。**尤其 BI ≠ BL、AR ≠ BL、AF ≠ BL、AV ≠ BL、AO ≠ BL：油位/泄漏过 ≠ 冷却液液位/保护过；燃油安全过 ≠ 冷却液过；油机市电过 ≠ 冷却液过（周检写到 ≠ 本篇台账）；油品/加油过 ≠ 冷却液过；漏水探头过 ≠ 本窗；看着有液 ≠ 台账过；灯绿/表绿 ≠ 窗过；口头加过 ≠ 窗过；液位过 ≠ 保护窗过；高温保护过 ≠ 低水位保护过。**  
7. **液位异常/高温或低水位告警风暴挂 N，边界/门限/窗变更走 J；禁功率战；禁绕联锁；禁不安全泄放冷却液教条；禁旁通；禁伪造台账；禁热机/带压乱开散热器盖教条**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。液位/保护乱窗、假绿、高温或低水位告警常被误当「覆盖病」→**禁功率战**；挂 N；变更走 J。冷却液/保护失序不是覆盖病。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/油机或散热器序列号全文/可还原坐标与联系人；禁公开传播未脱敏液位门限与保护参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签冷却液液位/保护准用、无实测冒充边界过、绕联锁/旁通/不安全泄放/热机开盖冒充秩序齐，不是法外运维智慧**。医院/数据中心公开资料只作故事类比（§10），翻译成本网语言就是 BL-位 / BL-护 / BL-界 / BL-验 / BL-治。

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机房柴油发电机冷却液液位与高温低水位保护巡检准用」、对外宣传「看着有液/灯绿/表绿/口头加过秒过」、把未实测写成已过、把绕联锁/旁通/不安全泄放/热机开盖写成秩序齐。允许做的：补冷却液液位台账、补保护窗、重开边界窗、挂 R/N/J、内部挂整改。

### 4.3 「机房柴油发电机冷却液液位与高温低水位保护巡检准用」最小集（BL）——缺页不能签准用

### 5.5 与弱项的现场对照（再钉一次）

冷却液乱账、保护乱窗、假绿、高温/低水位告警风暴，常先伤站点保供电与**上行**体验——机组在最需要时因热保护或低水位保护停下来，站点环境先乱。有人把这些当「覆盖病」抬功率——**禁功率战**。冷却液/保护失序不是覆盖病。先问 BL 秩序并分诊 BI/AR/AF/AV/AO，风暴挂 N，变更走 J。弱项短补：**12.5 kHz / 4FSK / 2-slot TDMA**。
## 6. 工作实例（12 则，教学虚构，L3）

1. **看着有液 / 口头加过想签准用**：称散热器里看得见液体、班长说加过要签 → 查 BL1 无本期液位对照 → **拒签**；补 BL-位。  
2. **保护灯绿 / 表看着在绿区 / 套邻站保护照片**：称「灯是绿的 / 表在绿区 / 邻站照片差不多」免窗页 → **拒签**；补 BL-护。  
3. **BI 顶替 BL**：用油位/泄漏签顶本期冷却液液位/保护签 → **挂 R**；**油位/泄漏过 ≠ 冷却液液位/高温低水位保护过**；油不是缸套水。  
4. **AR 顶替 BL**：称通风排烟燃油安全刚过，冷却液免做 → **挂 R**；**通风排烟燃油安全过 ≠ 冷却液液位/保护过**。  
5. **AF 顶替 BL**：称油机市电切换刚过，或周检单上冷却液打了勾，本篇台账免 → **拒签**；**油机市电过 ≠ 冷却液液位/保护过**；**AF 周检写到冷却液 ≠ 本篇台账**。  
6. **AV 顶替 BL**：称油品净化和加油交接刚过，冷却液窗免 → **挂 R**；**油品净化/加油过 ≠ 冷却液过**。  
7. **AO 顶替 / N 绿免实测**：称漏水探头绿或大屏监控绿，本期实测免 → **拒签**；漏水探头过 ≠ 冷却液液位/保护过；N绿≠BL过；补 BL-验。  
8. **高温顶低水位 / 低水位顶高温**：称高温保护测过了，低水位照抄，或反之 → **拒签**；**高温保护过 ≠ 低水位保护过**；两侧分开实测。  
9. **液位顶保护**：称液位签过了，保护窗免做 → **拒签**；**液位过 ≠ 保护窗过**。  
10. **套邻站表**：拷邻站液位/保护表改机房号 → **BL-验 拒签重测**。  
11. **功率战 / 不安全泄放 / 热机开盖 / 绕联锁 / 旁通**：高温或低水位告警要抬功率，或放一点冷却液消告警、还烫着拧散热器盖、绕保护、开旁通后要求准用 → **禁功率战**；**禁不安全泄放冷却液教条**；**禁热机/带压乱开散热器盖教条**；**禁绕联锁**；**禁旁通**；先挂 N/R；缺秩序整改贴 BL；禁签。  
12. **无油机路径乱签 / 泄密**：本站无柴油发电机或无缸套水/散热器冷却液路径却不写「不适用」乱签准用，或公开群贴真实油机、散热器序列号与液位门限 → **拒签**并/或补书面不适用并/或 **L3 违规**；一侧不适用 ≠ 另一侧自动免。

## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 本篇用法（教学） |
|------|------------------|
| **冷却液 / 缸套水** | coolant / jacket water：在水套、散热器、膨胀水壶里循环带走热量的液体路径；**≠ 日用油箱里的柴油**；**看着有液 ≠ 液位台账过** |
| **冷却液液位** | coolant level：散热器和/或膨胀水壶的液位窗与本期对照；**BL-位**；**口头加过 ≠ 窗过**；**液位过 ≠ 保护窗过** |
| **散热器 / 膨胀水壶** | radiator / expansion tank（回液瓶、补液壶）：液位观测常落在这两类角色上；具体以本网与 OEM 书面为准；**禁热机/带压乱开散热器盖** |
| **高温保护** | high coolant temperature protection：冷却液温度高报警/停机窗；**BL-护**（高温侧）；**灯绿/表绿 ≠ 窗过**；**高温保护过 ≠ 低水位保护过** |
| **低水位保护** | low coolant level protection：冷却液液位低报警/停机窗；**BL-护**（低水位侧）；一侧过 ≠ 另一侧过 |
| **油位 / 泄漏** | 归 **BI**；**油位/泄漏过 ≠ 冷却液液位/保护过**；油不是缸套水 |
| **通风排烟燃油安全** | 归 **AR**；**燃油安全过 ≠ 冷却液液位/保护过** |
| **油机市电切换** | 归 **AF**；**切换过 ≠ 冷却液台账过**；**AF 周检写到冷却液 ≠ 本篇台账** |
| **油品净化加油** | 归 **AV**；**油品/加油过 ≠ 冷却液过** |
| **漏水探测** | 归 **AO**；**漏水探头过 ≠ 冷却液液位/保护过** |
| **假绿** | 无实测/无会签却显示通过；挂 R；≠ 放行 |
| **套票** | 套他站他期液位/保护表；BL-验 拒签 |
| **不安全泄放冷却液教条** | 用放掉冷却液去消告警或冒充窗过；**本篇硬禁**；具体补液/处置只认本网与 OEM 书面窗 |
| **热机/带压乱开散热器盖教条** | 机组仍热或系统仍带压时拧开散热器盖；公开资料强调有烫伤风险；**本篇硬禁** |
| **开旁通冒充 / 绕高温/低水位联锁** | 靠旁通或绕保护让表看起来绿；**本篇硬禁** |
| **配比/化学配方教条** | 把冷却液配比、药剂配方写成可照抄的步骤；**本篇不写**；只认本网与 OEM 书面 |
| **功率战** | 用抬功率压高温/低水位告警；**禁**；先挂 N；冷却液/保护失序不是覆盖病 |
| **贴纸 BL / BI ≠ BL / 脱敏 L3** | 本篇主贴；位/护/界/验/治五子类；油位泄漏 ≠ BL；燃油安全 ≠ BL；油机市电 ≠ BL；油品 ≠ BL；漏水探头 ≠ 本窗；禁真实站名/机房全称/油机或散热器序列号全文/联系人 |

**易错观念（纠一次）**  
- 「看着有液 / 口头加过 = 准用」→ 错；要 BL-位台账 + 本期实测。  
- 「保护灯绿 / 表看着在绿区 = 窗过」→ 错；要 BL-护 主人窗方法。  
- 「BI / AR / AF / AV / AO 过 = BL 过」→ 错；油位/泄漏 ≠ 冷却液；燃油安全 ≠ 冷却液；油机市电/周检写到 ≠ 本篇台账；油品/加油 ≠ 冷却液；漏水探头 ≠ 本窗。  
- 「液位过 = 保护过」「高温过 = 低水位过」→ 错；分账分验。  
- 「N 绿 = 本期实测过」→ 错；风暴绿 ≠ 交底准用。  
- 「放一点液消告警 / 还烫着开盖 = 办法」「抬功率压告警 = 救急」「旁通 / 绕联锁 = 赶工」→ 错；硬禁；禁功率战。  
- 「没有柴油机或没有缸套水路径就整篇乱签或口头免」→ 错；书面勾「不适用」；不得用 BL 顶 AF/AR/BI/AV/AO，也不得用它们顶 BL。

### 参考答案

1. 位 / 护 / 界 / 验 / 治；口诀：**液位有账，保护有窗，边界有法，会签才放。**  
2. 规则1（冷却液液位台账钉死）；属 **BL-位**。液位 ≠ 保护，**不能**互相顶。看着有液 ≠ 台账过；口头加过 ≠ 窗过。  
3. 规则2。**不能**；保护灯绿 / 表看着在绿区 ≠ 窗过。高温保护过 ≠ 低水位保护过，**不能**互相顶。  
4. **不能**。BI ≠ BL。油不是缸套水。本篇**不重写** BI 全文。  
5. **都不能**。AR ≠ BL；AF ≠ BL（周检写到冷却液 ≠ 本篇台账）；AV ≠ BL；AO ≠ BL。  
6. **不能**。N 绿 ≠ BL 过；看着有液 ≠ 台账过。  
7. **BL-验 拒签重测**；禁套他站他期。  
8. **不能**抬功率；先挂 **N**；缺秩序整改贴 **BL**；油位问 BI，燃油安全问 AR，切换问 AF，油品问 AV，漏水问 AO；**禁功率战**。冷却液/保护失序**不是**覆盖病。  
9. **不允许**；禁不安全泄放冷却液教条、热机/带压乱开散热器盖教条、旁通、绕高温/低水位联锁、配比教条；具体方法只认本网与 OEM 书面窗，本篇不展开泄放、开盖与配方步骤；挂 N/R，禁签。  
10. **不能**互相顶替。无柴油发电机或无缸套水/散热器冷却液路径，书面勾「不适用」；不得用 BL 顶 AF/AR/BI/AV/AO，也不得用它们顶 BL。  
11. 假绿挂 **R**；有冷却液路径时主贴仍 **BL**。不得用 BL 顶 AF/AR/BI/AV/AO。  
12. **12.5 kHz** / **4FSK** / **2-slot TDMA**；告警窗 **禁功率战**；常被误当**覆盖病**→禁功率战，挂 N，变更走 J。
