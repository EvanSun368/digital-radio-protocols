## 8. 术语表（本篇约 18 词）+ 易错观念

| 词 | 本篇用法（教学） |
|----|------------------|
| **AL** | 本篇贴纸：气灭·疏散·联锁秩序 |
| **AL-气** | 气灭台账/钢瓶/探头准用子类 |
| **AL-散** | 疏散路径与集合点子类 |
| **AL-联** | 联锁交底窗与方法子类 |
| **AL-验** | 本期交底实测子类 |
| **AL-治** | 假绿/顶替/套票/功率战/泄密治理 |
| **气灭台账** | 气体灭火系统书面台账（格式以本网为准） |
| **钢瓶准用** | 灭火剂钢瓶在账且准用期内（不写序列号全文） |
| **探头** | 烟感/温感等探测相关角色（不教破坏/旁路） |
| **疏散路径** | 从机房到安全出口的书面路径 |
| **集合点** | 疏散后书面集合位置 |
| **联锁交底窗** | 气灭—疏散—相关设备联动的书面天窗 |
| **联锁方法** | 预告警/释放与疏散、空调停机等书面步骤摘要 |
| **假绿** | 监控/大屏绿灯冒充准用（挂 R） |
| **套票** | 用他机房他期交底照片冒充本期 |
| **顶替** | 用 AI/AK/AH/AF/AD 等签顶掉 AL 本期签 |
| **功率战** | 告警/登记失败时抬功率硬扛（禁） |
| **L3 脱敏** | 公开材料去真实站名/机房全称/钢瓶号/联系人 |

**易错观念（钉死）**  
- ❌ 气瓶在 = 可以签 → ✅ 台账+钢瓶/探头准用才谈准用。  
- ❌ 疏散图贴了 = 演练过 → ✅ 书面路径/集合点主人 + 本期交底。  
- ❌ 温湿度绿 = 气灭联锁过 → ✅ AI 不顶替 AL；书面联锁窗方法。  
- ❌ 监控绿 = 准用过 → ✅ 假绿挂 R；会签才放。  
- ❌ 气灭窗登记失败先抬功率 → ✅ 禁功率战；先 AL/N。
