## 1. 为什么要写这篇手册（动机 + 现场对话）

前三十八篇手册从 A–E 协议一路写到 AK 爬塔交叉：其中 **AK 回答「铁塔/桅杆爬塔与第三方交叉」**，**AI 回答「机房温湿度与空调联锁」**，**AH 回答「多业主合路/POI 界面」**，**AF 回答「油机市电」**，**AD 回答「备件仪表准用」**，**AA 回答「交维后首年巡检」**，**N 回答「电源监控/对时/告警风暴」**。可还没有单独钉死一件事——**机房消防气灭不是「钢瓶在就能签」：气灭台账/钢瓶/探头准用要钉死；疏散路径与集合点要有主人有书面；联锁交底窗与方法要书面固定；本组本机房本期交底与实测禁套他机房他期——能不能签「气灭/疏散联锁准用」？** 这就是本篇的 **AL**——**机房消防气灭与应急疏散联锁交底**。

- 运维岗：「钢瓶在机房角落，气灭就算齐了。」——**无台账/准用仍准用** = 本篇拒签（规则1）。  
- 外包：「疏散图墙上贴了，集合点口头说一声。」——**路径/集合点无主人无书面** = 规则2。  
- 物业：「联锁上次测过差不多，温湿度也绿。」——**无联锁窗方法，只听口头/套温湿度绿** = 规则3。  
- 外包：「邻机房上周交底票参数差不多，拷过来改个房号。」——**套他机房他期** = 规则4。  
- 班长：「AI 温湿度签还在，AK 爬塔也过了，气灭疏散也能签。」——**用 AI/AK/AH/AF/AD/AA/N 顶替 AL** = 规则6。  
- 站务：「大屏监控绿了，气灭联锁准用就算过。」——**假绿≠会签放行** = 规则5/6。  
- 网优：「气灭预告警窗有人登记失败，功率抬一点稳住。」——**功率战** = 规则7。  
- 宣传岗：「把真实机房全称、钢瓶号、联系人发群表扬。」——**L3 违规** = 规则8。  

这几句背后是同一件事：

> **「机房消防气灭与应急疏散联锁」在现场至少有五个坑**：**① AL-气** 气灭台账/钢瓶/探头准用入账，禁「气瓶在就能签」「口头说一声」；**② AL-散** 疏散路径与集合点有主人、有书面，禁「疏散图贴了就算」；**③ AL-联** 联锁交底窗与方法钉死，禁「上次测过差不多」「温湿度绿当联锁过」；**④ AL-验** 本组本机房本期交底与实测（禁套他机房他期票/照片），会签才放行「气灭/疏散联锁准用」；**⑤ AL-治** 治理（假绿、用 AI/AK/AH/AF/AD/AA/N 顶替、伪造准用、功率战、旁路探头、泄密）。  
> 把 ①–⑤ 当成「气瓶在就能签」「疏散图贴了就演练过」「温湿度绿就当气灭准用」，每一次气灭维保、每一次疏散演练、每一次联锁交底，都会先吵「账是谁的、路径谁负责、交底是不是本期的」。

## 2. 总图 / 故事：气灭疏散像「医院手术室/药库气体灭火 + 消防疏散演练——不能只看钢瓶在」

### 2.1 一句话：气瓶在不是「可以签准用」、疏散图贴了不是「演练过了」——要先建气灭台账与钢瓶探头准用，疏散路径与集合点有主人有书面，联锁交底窗与方法钉死，本组本机房本期交底，会签才放行；假绿、套邻机房交底票、用 AI/AK/AH/AF/AD/AA/N 顶替，一律拒签

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  医院手术室/药库气体灭火 + 消防疏散演练联锁  =  本网 AL     │
   │                                                              │
   │  气瓶/钢瓶台账·探头准用钉死       ≈ AL-气  气灭台账准用钉死 │
   │  疏散路径/集合点责任书面边界       ≈ AL-散  疏散有主有书面   │
   │  气灭—疏散—空调联锁交底窗方法钉死 ≈ AL-联  联锁窗与方法钉死 │
   │  本期交底实测禁套邻楼交底票       ≈ AL-验  本组本机房本期   │
   │  假绿≠放行·顶替·伪造·功率战     ≈ AL-治  治理与脱敏 L3   │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **气灭有账，疏散有主，联锁有窗，本期交底，会签才放。**  
> 气瓶在还无台账准用 = 医院药库只看钢瓶在不查准用期——**拒签「气灭/疏散联锁准用」**。  
> 疏散图贴了但无本期演练/联锁交底 = 手术室墙上贴了疏散图却从未做联锁演练——**假绿，挂 R，拒签**。

```text
        │  无账 / 准用断档 / 关键探头未入 → 不签气灭/疏散联锁准用
        ▼
  ② AL-散 钉疏散路径/集合点：主人角色 · 书面路径与集合点 · 禁「图贴了就算」
        │  无主人 / 无书面路径 → 拒进入「可签」状态
        ▼
  ③ AL-联 钉联锁窗：书面窗 · 联锁方法（气灭预告警/释放与疏散、相关空调停机等） · 到场角色
        │  无窗 / 「温湿度绿当联锁过」 → 拒联锁签
        ▼
  ④ AL-验 本组本机房本期交底与实测：交底记录 · 禁套他机房他期票/照片
        │  套票 / 只看监控绿 → 拒签
        ▼
  ⑤ 会签「气灭/疏散联锁准用」或「有条件整改」：本网授权本人签
        │  缺签 / 假绿顶替 → 拒签准用
        ▼
  ⑥ 变更（气灭系统/联锁逻辑/门限/停发策略）→ 走 J + 触发再交底/再验（常挂 N 看监控、挂 AI 看温湿度联锁、挂 AD 看仪表）
```

> **一句话分辨**：**AI** 回答「温湿度联锁**过了没有**」；**AK** 回答「爬塔/交叉**清不清**」；**AH** 回答「合路界面**清不清**」；**AD** 回答「仪表准用期**到了没有**」；**AL** 回答「这一窗气灭台账 + 这一路疏散路径 + 这一窗联锁交底**台账清不清、路径有没有主、本期交底过了没有**」。**五个问题，五张（类）贴纸，不能一笔带过。**

### 2.6 气灭与疏散联锁最小工作流（背下来）

```text
  AL-气 台账 + 钢瓶 + 探头准用钉死
       ├─→ 有账+准用？疏散路径有主人书面？ ──否──→ 拒签 / 补账补散
       └─→ 是
  AL-联 约联锁窗 + 书面方法 + 到场勾选 + 相关空调/门禁态确认（可挂 AI）
       │
  AL-验 本组本机房本期：交底记录 → 禁套声明 → 实测留痕
       │  套票 / 只看绿灯 → 拒签
       ▼
  会签「气灭/疏散联锁准用」或挂整改；重大未闭禁签准用
       │
  放行或拒签；公开材料 L3；变更走 J 再触发
```

## 3. 核心交付：插页 AL + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AL（而不是先贴 AI / AK / AH / AF / N）

| 现场要办的事 | 主贴 | 说明 |
|--------------|------|------|
| 气灭台账、疏散路径、联锁交底签、假绿拒签 | **AL** | 本篇主职 |
| 温湿度/空调联锁巡检 | **AI**（可挂 AL） | 环境过≠气灭准用 |
| 爬塔/交叉施工 | **AK**（可挂 AL） | 爬塔过≠气灭疏散过 |
| 合路/POI 界面 | **AH**（可挂 AL） | 合路清≠气灭/疏散界面清 |
| 油机市电 | **AF**（可挂 AL） | 供电过≠气灭过 |
| 气灭相关仪表入库准用 | **AD**（可挂 AL） | 仪表准用≠本期气灭过 |
| 交维后首年巡检日历 | **AA**（可挂 AL） | 首年日历≠本期联锁窗 |
| 监控对时、告警风暴 | **N**（可挂 AL） | 监控绿≠气灭联锁准用过 |
| 大屏绿想直接签气灭疏散准用 | **AL-治 + R** | 假绿≠气灭通过 |
| 套邻机房旧交底票 | **AL-治** | 禁套；须本期本组本机房交底 |

### 3.2 插页 AL · 气 / 散 / 联 / 验 / 治（挂在总三联单或气灭/疏散单后）

| 插页行 | 检查项（教学） | 缺了怎么办 |
|--------|----------------|------------|
| **AL1** | 气灭台账在：钢瓶角色、探头角色、准用期角色书面 | 缺 → **拒签准用** |
| **AL2** | 钢瓶/探头到场可追溯；禁「气瓶在就算准用」 | 缺 → **拒「口头说一声」** |
| **AL3** | 疏散路径与集合点有主人：主人角色；书面路径/集合点 | 缺 → **拒签** |
| **AL4** | 联锁窗书面在（日期角色/天窗角色）；联锁方法书面；相关方到场勾选 | 缺 → **拒联锁签** |
| **AL5** | 本组本机房本期交底与实测记录在；脱敏站与窗一致；禁套他机房他期票/照片 | 套/缺 → **拒签** |
| **AL6** | 相关仪表在 AD 准用期内（挂 AD 指针）；相关温湿度/空调态可挂 AI；禁旁路探头叙事 | 缺/旁路嫌疑 → **拒签或整改** |
| **AL7** | 「气灭/疏散联锁准用」会签：相关授权本人签；重大未闭禁准用 | 缺签 → **拒签** |
| **AL8** | 公开材料 L3；变更项走 J；禁功率战叙事 | 违 → **治理** |

> 插页每一行都对应硬规则：AL1/AL2→规则1，AL3→规则2，AL4→规则3，AL5→规则4，AL7→规则5，顶替/假绿→规则6，AL6/AL8→规则7/8。**任何一行缺项，就停在那一行。**

### 3.3 和总三联单怎么写（接手册06）

- **现象栏**：写「气灭台账断档 / 疏散无主 / 联锁未交底 / 套他机房交底 / 监控假绿 / 旁路探头嫌疑」等可复核现象，**不写空口玄学**。  
- **贴纸栏**：主贴 **AL**；支撑可贴 AI / AK / AH / AF / AD / AA / N / R / J。  
- **处置栏**：拒签 / 补气灭台账 / 补疏散主人 / 重开联锁窗 / 重交底 / 挂 R/N/J——**写动作，不写空口字段**。  
- **脱敏**：站/机房用角色编号；禁单位名全文、禁真实站名、禁钢瓶序列号全文。

### 3.4 《本网机房消防气灭与应急疏散联锁台账卡》预告

§7 给出可复印模板：封面拒签门槛、气灭页、疏散页、联锁页、交底实测页、会签准用页、夜班速填五行。**一张卡跑完一窗气灭/一次疏散联锁交底：气→散→联→验→签**；与 AI 温湿度、AK 爬塔、AH 合路、AD 仪表指针对齐，避免「温湿度签还在就当气灭过」「爬塔过就当疏散过」「合路界面清就当气灭界面清」。
