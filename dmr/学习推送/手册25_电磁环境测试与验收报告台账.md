## 1. 为什么要写这篇手册（动机 + 现场对话）

前二十四篇手册把「家里怎么养」「邻居怎么处」「投诉怎么分诊」「证照台账怎么对」「重大保障临时窗怎么钉」「非法线索怎么上报」基本写全了：A–E 协议，F 射频指纹，G 实验室，H 话务，I 室分，J 写频，K 电源，L 井库，M 批量 / OTAP，N 监控对时，O 有源隔离，P 口部，Q 金机，R 假绿演练，S 邻频协调，T 干扰投诉，U 许可执照台账，V 临时保障窗，W 非法/黑广播线索。可现场还有一类债——**电磁环境测试与验收报告台账**：

- 开站岗：「三年前那份电磁环境报告还在文件夹里，直接拿来签验收吧。」——**旧报告套新址/新配置** = 本篇拒签（规则3）。  
- 测试岗：「频谱仪检定上周过期，先测完交维，下月再送检。」——**仪器检定/校准过期** = 规则2。  
- 网管：「屏上全绿、假绿演练也过了，还要什么电磁环境实测报告？」——**假绿 ≠ 实测验收**（规则6，挂 R 提醒）。  
- 项目经理：「报告缺测点表和仪器证书页，领导催着签交维就绪。」——**缺项断链禁当正式验收证据**（规则4）。  
- 工程：「天线换了、功率角色调了，先开着，回头再补测。」——**重大变更后须复测再签**（规则5）。  
- 协调岗：「共址邻频那边环境吵，我们把功率顶上去就能过验收。」——**禁功率战掩盖环境问题**（规则7）。  
- 宣传：「把报告全文号和真实测点坐标贴公开周报。」——**L3 违规**（规则8）。

这几句背后是同一件事：

> **「电磁环境测试与验收报告台账」在现场至少有五个坑**：**① X-测** 测试方案与仪器有效性（检定/校准在有效期内、方法与测点角色、频段/功率/占用角色与许可一致）；**② X-验** 验收判据与报告完整性（结论可追溯、与现场一致、断链报告禁当正式验收证据）；**③ X-账** 报告台账可对账（编号角色、有效期、覆盖站址角色、复测触发）；**④ X-签** 签字边界（谁可签验收/交维就绪；缺报告/过期/不一致拒签）；**⑤ X-治** 拒签治理（伪造/套用旧报告、未复测变更、公开泄密、假绿顶替实测）。  
> 把 ①–⑤ 当成「文件夹里有纸就行」「过期仪器先用着」「屏绿=环境过了」「旧报告套新楼」「变更先开再测」，会把下一任、验收方、主管部门和本网合规一起拖进泥潭。

本篇目标：能背出**电磁环境测试与验收报告工作流**；会用新贴纸 **X（测 / 验 / 账 / 签 / 治）** 与五个子类；会填**插页 X（X1–X8）**和《本网电磁环境测试与验收报告台账卡》；能用「**大楼消防验收报告台账 + 计量检定证书**」故事讲清：先对覆盖与在检、结论与现场一致、缺页断链拒签、变更复测、签字边界；能拒绝「套旧报告、仪器过期、假绿顶替、缺项强签、未复测先用、功率战掩盖、公开泄密」；自测过关后，回库把本网最近一次开站/交维相关报告台账（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：凡引法规与标准均指向已公开发布的文书标题与官方链接（《中华人民共和国无线电管理条例》《无线电频率使用许可管理办法》《地面无线电台（站）管理规定》《无线电台执照管理规定》、国无办〔2025〕1号、生态环境部公开的《电磁环境控制限值》GB 8702 相关页面、ITU 频谱监测手册、ETSI EN 300 113 / TS 102 361 等），**限值数字、程序、豁免范围、复校间隔以原文与属地最新要求为准，本篇只作教学转述，不发明条款号以外的「内部口径」或内部配额**；**现象与台账一律用相对道号、角色标签、脱敏编号表述，禁真实频点 / 站名 / 单位名 / 报告全文号 / 检定证书全文号 / 联系人 / 坐标**；**不教伪造/涂改/套用报告、不教无证发射、不教功率战掩盖环境、不教规避监测与检查**；G 仍管实验室方法，F 仍管指纹，S 仍管邻频协调，O 仍管有源隔离，U/V 仍管证照与临时窗，R 仍管假绿——**电磁环境测试与验收报告台账主贴 X**；外国 / ITU / 厂商应用笔记只借**测量方法与仪器能力级表述**，**验收与签字以国内法规、属地要求与本网书面判据为准**。

## 2. 总图 / 故事：报告像「消防验收台账 + 计量检定证书」

### 2.1 一句话：电磁环境测试与验收报告像大楼消防验收报告台账 + 计量检定证书——开工验收前先对报告是否覆盖本楼、仪器是否在检、结论是否与现场一致；旧报告套新楼、检定过期、缺页断链一律拒签入住/交维

```text
   ┌──────────────────────────────────────────────────────────────────┐
   │   大楼消防验收 + 计量检定（= 本网开站/交维 + 电磁环境报告台账） │
   │                                                                  │
   │   测试方案与仪器（X-测）                                         │
   │     方案覆盖本楼角色 · 仪器检定/校准在有效期内 · 方法与许可一致  │
   │                                                                  │
   │   验收判据与报告完整（X-验）                                     │
   │     结论可追溯 · 与现场一致 · 断链/缺页禁正式验收证据            │
   │                                                                  │
   │   报告台账可对账（X-账）                                         │
   │     编号角色 · 有效期 · 覆盖站址角色 · 复测触发                  │
   │                                                                  │
   │   签字边界（X-签）                                               │
   │     谁可签验收/交维就绪 · 缺报告/过期/不一致 → 拒签              │
   │                                                                  │
   │   拒签治理（X-治）                                               │
   │     伪造/套旧报告 · 未复测变更 · 公开泄密 · 假绿顶替实测         │
   └──────────────────────────────────────────────────────────────────┘
```

口诀：

> **先对覆盖，再对在检；结论对现场，台账能对账。**  
> 旧报告套新楼 = 拿隔壁楼消防报告来办本楼入住——**拒签**。  
> 检定过期仍测仍签 = 灭火器过期也贴「验收合格」——**拒签**。

### 2.2 「消防报告台账 + 计量检定」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **测试方案与仪器** | 验收方案写清测哪几层、用哪台经检定的仪器 | 方案覆盖站址角色；仪器检定/校准有效；频段/功率/占用角色与许可一致 | X-测 |
| **验收判据与报告** | 报告结论对照规范，缺页/涂改退回 | 结论可追溯；与现场配置一致；断链禁正式验收 | X-验 |
| **报告台账** | 每栋楼一份可检索台账：编号、有效期、覆盖范围 | 编号角色、有效期、覆盖站址、复测触发可对账 | X-账 |
| **签字边界** | 消防验收谁有权签「可入驻」 | 谁可签验收/交维就绪；缺报告/过期/不一致拒签 | X-签 |
| **拒签治理** | 套旧报告、造假、灭火器过期硬签 → 追责 | 伪造/套旧、未复测变更、公开泄密、假绿顶替 → 拒签/治理 | X-治 |

> 公开文书与标准告诉我们：设置使用无线电台（站）应依法取得许可与执照；技术方案应可行且不对依法使用的其他频率产生有害干扰；电磁环境公众曝露控制有国家环境质量标准（如 GB 8702《电磁环境控制限值》，教学指针，**限值与豁免以原文为准**）；测量仪器应在有效检定/校准状态（计量语境：以证书载明的复校/有效日期为准）。本篇只借「先覆盖、再在检、结论对现场、台账可对账、签字有边界」的顺序，**不编造本网内部限值数字、不教涂改报告过关**。

### 2.3 和手册07 / 08 / 16 / 20 / 22 / 23 的咬合（指针，不重写）

- **手册08 G**：实验室方法、仪器与夹具——**可支撑 X-测 的方法与仪器有效性**，不能代替「本站址角色验收报告台账」；G 测指纹 ≠ X 签交维。  
- **手册07 F**：射频指纹——可支撑「配置/发射特征是否对得上报告角色」，**不能代替**完整验收报告。  
- **手册16 O / 10 I / 13 L**：有源隔离、室分、井库——拓扑或有源变更常触发 **X 复测**（规则5）；主贴仍可是 X，次挂 O/I/L。  
- **手册20 S**：边界/共址/邻频相关验收须书面协调或挂 S；禁功率战掩盖环境问题（规则7）。  
- **手册22 U / 23 V**：许可与执照、临时窗——**频段/功率/时段角色须与报告方案一致**；无证/过期仍走 U/V，不拿「有旧环境报告」顶替证照。  
- **手册21 T / 24 W**：投诉与非法线索——环境异常投诉可挂 T；疑似非法源走 W；**验收台账本身主贴 X**。  
- **手册19 R**：假绿演练——**屏上看见 ≠ 实测验收**（规则6）；可挂 R 提醒，主贴仍 X。

### 2.4 新贴纸 X：测 / 验 / 账 / 签 / 治（五个子类）

```text
                ┌──────────── 贴纸 X · 测/验/账/签/治 ────────────┐
                │  X-测  测试方案与仪器有效性：在检·方法·测点角色·与许可一致 │
                │  X-验  验收判据与报告完整：结论可追溯·与现场一致·断链禁正式 │
                │  X-账  报告台账可对账：编号角色·有效期·覆盖站址·复测触发   │
                │  X-签  签字边界：谁可签验收/交维；缺报告/过期/不一致拒签   │
                │  X-治  拒签治理：伪造套旧·未复测变更·公开泄密·假绿顶替     │
                └──────────────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签 / 拒放行触发 |
|------|--------|----------------------|
| **X-测** | 仪器过期或方法与许可不符仍测仍签 → 拒签 | 「检定过期先测完再补」 |
| **X-验** | 报告缺页/断链/结论对不上现场 → 禁正式验收 | 「缺仪器证书页也先签」 |
| **X-账** | 台账对不上覆盖站址或有效期 → 禁签就绪 | 「文件夹有纸=台账齐」 |
| **X-签** | 无授权人签、或强签缺报告项 → 拒签 | 「领导催签就签」 |
| **X-治** | 套旧报告、伪造、假绿顶替、公开泄密 → 治理 | 「拿 A 址报告签 B 址」 |

### 2.5 电磁环境测试与验收报告最小工作流（背下来）

```text
  拟签「开站验收 / 交维就绪 / 重大变更后复验」
        │
        ▼
  是否有覆盖本站址角色、本频段角色、本时段的有效报告？（X-账）
        │无 / 过期 / 覆盖不对──▶ 拒签；开测或补测（规则1、2）
        │有候选报告
        ▼
  仪器检定/校准是否在有效期内？方法与测点角色是否与方案/许可一致？（X-测）
        │否──▶ 拒签；送检或改方案（规则2）
        │是
        ▼
  报告结论是否完整可追溯？与现场配置/功率角色是否一致？（X-验）
        │缺项断链 / 不一致──▶ 禁当正式验收证据；内部可挂「待测/待补」（规则3、4）
        │一致且完整
        ▼
  近期是否有重大变更（频点角色、天线、功率、室分拓扑等）未复测？（规则5）
        │有──▶ 拒签；复测/补测后再走 X
        │无
        ▼
  边界/共址/邻频相关？→ 书面协调或挂 S（规则7）
  假绿/屏绿能否顶替？→ 不能；挂 R 提醒（规则6）
        │
        ▼
  授权人按 X-签 边界签字；台账入库；公开包 L3（规则8）
  结案词用 X 子类；可挂 G/F/S/O/I/L 支撑，主贴 X
```

现场口诀：

> **先对覆盖，再对在检；结论对现场，台账能对账。**  
> 跳过对账的「交维就绪」= 拿过期灭火器证办入住。

## 3. 核心交付：插页 X + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 X（而不是先贴 G / U / R / S）

| 现场信号 | 主贴 | 可次挂 |
|----------|------|--------|
| 开站验收 / 交维就绪要看电磁环境报告台账 | **X** | G / U / S |
| 实验室方法/仪器能力争议 | **G**（不是 X） | 可挂 X-测 |
| 许可/执照是否覆盖 | **U / V** | 报告方案须与之一致 |
| 屏绿/假绿想顶替实测 | **X-治** + 挂 **R** | — |
| 边界/共址/邻频环境验收 | **X** + 挂 **S** | O / I |
| 室分/井库/有源拓扑变更后复测 | **X** | I / L / O |
| 伪造/套旧报告/公开泄密 | **X-治** | — |

> **口诀**：实验室方法 → **G**；证照覆盖 → **U / V**；假绿演练 → **R**；邻居协调 → **S**；**电磁环境测试报告与验收签字台账 → X**。可叠挂，**该类验收主贴 X**。

### 3.2 插页 X · 测 / 验 / 账 / 签 / 治（挂在总三联单或验收单后）

| 行 | 名称 | 填写示例（教学虚构，L3） |
|----|------|--------------------------|
| **X1** | 方案摘要角色 | 「频段角色·测点角色·方法角色·与许可/执照台账互挂编号脱敏」 |
| **X2** | 仪器有效期 | 「仪器角色·检定/校准证书角色·有效期至____·在检□/过期□」——过期禁测禁签 |

> **X5 结论不可追溯或与现场不一致 → 禁正式验收（规则3、4）。**  
> **X6 缺勾 → 禁签验收/交维就绪（规则1）。**  
> **X7 有触发未复测 → 拒签（规则5）。**  
> **X8 公开包出现真实频点/报告全文号/坐标 → L3 违规（规则8）。**

## 4. 深潜：八条硬规则 + 分诊题 + 报告最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **先证有效测试报告与台账覆盖（站址角色、频段角色、时段）再签验收/交维就绪**。  
2. **无有效报告、仪器检定/校准过期、方法与许可不符 → 拒签**。  
3. **报告与现场不一致（站址角色/配置/功率角色对不上）→ 拒签；禁套用旧报告**。  
4. **缺项、断链、无法追溯判据的报告 → 禁当正式验收证据**（内部可挂「待测/待补」）。  
5. **重大变更（频点角色、天线、功率、室分拓扑等）后须复测/补测再签；禁「先用着再说」**。  
6. **可挂 G/F/S/O/I/L 支撑，但主贴 X；假绿/屏上看见不等于实测验收（挂 R 提醒）**。  
7. **边界/共址/邻频相关验收须书面协调或挂 S；争议走无线电管理机构；禁功率战掩盖环境问题**。  
8. **对外/公开仓一律脱敏 L3；禁贴真实频点/站名/单位名/报告全文号/坐标**。

> 法规与标准锚点（已核公开原文，教学转述，**以原文为准**）：《无线电管理条例》对频率使用许可、台站设置使用、监测与干扰查处等作总则；《无线电频率使用许可管理办法》《地面无线电台（站）管理规定》《无线电台执照管理规定》对许可、台站与执照规范作要求；国无办〔2025〕1号提供规划与技术要求指针；生态环境部公开的 GB 8702《电磁环境控制限值》是国家环境质量标准指针（**限值、评价方法、豁免以原文为准**）；测量仪器有效性遵循计量检定/校准证书载明的有效期/复校日期（教学不编造统一年数）。**这些是合规与验收秩序，不是「文件夹有纸就能签字」或「功率战过验收」的借口。**

### 4.2 验收前分诊题（X-账 / X-测）——先问「这报告盖的是不是本楼」

```text
  ① 台账里有没有覆盖「本站址角色 + 本频段角色 + 本时段」的报告？
     → 无/过期/覆盖不对：拒签；开测或补测（规则1、2）

  ② 出具该报告时仪器是否在检？证书角色是否可追溯？
     → 过期/无证书角色：拒签该次测量作正式依据（规则2）

  ③ 方案方法、测点角色、功率/占用角色是否与现行许可/执照/现场配置一致？
     → 否：拒签；禁套旧报告（规则2、3）

  ④ 报告是否缺页、断链、结论无法对照书面判据？
     → 是：禁正式验收；内部待补（规则4）

  ⑤ 自报告出具后是否发生重大变更未复测？
     → 是：拒签；复测（规则5）

  ⑥ 是否边界/共址/邻频相关且无书面协调？
     → 是：挂 S；争议报管理机构；禁功率战（规则7）

  ⑦ 是否有人要用屏绿/假绿顶替？
     → 是：拒签；挂 R；主贴 X-治（规则6）
```

**未过分诊题的冻结清单**：签「交维就绪」「验收合格」、对外宣传「环境已达标」、用过期仪器出正式报告、套 A 址报告签 B 址。允许做的：台账对账、送检、补测方案、挂 S、内部挂待测/待补。

### 4.3 报告最小集（X-验）——缺页不能办入住

| 序号 | 最小集项（教学） | 为什么必须有 | 缺了会怎样 |
|------|------------------|--------------|------------|
| 1 | **报告编号角色 + 出具日** | 台账对账锚点 | 禁正式验收 |
| 2 | **覆盖站址角色**（禁公开坐标原文） | 防套旧报告 | 对不上 → 拒签 |
| 3 | **频段/业务角色与许可互挂** | 与 U 台账一致 | 方法与许可不符 → 拒签 |
| 4 | **仪器角色 + 检定/校准有效期** | 测量有效性 | 过期 → 拒签 |
| 5 | **测点角色清单与方法摘要** | 可复核 | 「测过了」四个字不够 |
| 6 | **结论对照判据 + 可追溯附件角色** | 正式验收依据 | 断链/缺页 → 禁正式证据 |
| 7 | **保管链未断声明** | 断链=降级 | 断链禁当正式验收证据（规则4） |

> **口诀**：号、址、频、仪、点、结、链——**七字验钉**（教学记忆；现场以属地与合同/制度书面判据为准，但 **覆盖+在检+结论可追溯+保管链** 几乎不可砍）。  
> **断链识别**：缺仪器证书页、缺测点表、涂改无登记、公开群传后再当正式附件、报告与现场配置对不上——一律降级，禁正式验收依赖。

### 4.4 台账路径（X-账）——每栋楼一本可检索账

| 步 | 动作 | 拒签点 |
|----|------|--------|
| 1 | 一站址角色一主档（或一集群角色一档+子站列表） | 「所有站共用一份永远有效」 |
| 2 | 登记：编号角色、出具方角色、出具日、有效期策略（本网制度）、覆盖范围 | 口头说有报告无台账 |
| 3 | 互挂 U/V 许可执照编号脱敏、G 实验室单号脱敏（若有） | 报告与证照两张皮 |
| 4 | 复测触发清单写入台账（频点/天线/功率/室分等） | 变更不登触发 |
| 5 | 到期预警与过期关停签字路径（与交维/开站闸门互锁） | 「过期了先用着」 |
| 6 | 公开导出仅 L3；原件全文号受控另册 | 公开贴全文号 |

与手册22：U 管许可执照是否覆盖；**X 管环境测试报告是否覆盖且有效**——两本账都过才谈「合规开站/交维」叙事。与手册23：临时窗内的测试仍须仪器在检与方案覆盖，**临时不等于免报告**。

### 4.5 签字边界（X-签 / 规则1–4）——谁有权写「可入住」

| 本网可以签（教学） | 本网不可以签（红线） |
|--------------------|----------------------|
| 台账勾选齐全、报告完整在检、与现场一致、无未复测重大变更 | 缺报告/过期/不一致仍签「验收合格/交维就绪」 |
| 授权角色按制度会签（教学不编造职务名） | 「谁在场谁签」「领导催签跳过台账」 |
| 内部挂「待测/待补」并冻结放行 | 待测状态对外宣传「已达标」 |
| 拒签并开 X-治 工单 | 套旧报告、伪造涂改后补签 |

> **明确不教**：如何伪造报告、如何涂改有效期、如何用过期仪器「看起来像在检」、如何把 A 址 PDF 改成 B 址。需要法定监测或环评类程序的，**按主管部门与属地要求走**——你方只做边界内的台账、对账、拒签与复测安排。

### 4.6 弱项短补：有报告 ≠ 覆盖本址 ≠ 在检 ≠ 与现场一致 ≠ 已签字就绪 ≠ 屏绿

```text
   文件夹有PDF   覆盖本站址角色   仪器在检   与现场一致   已签就绪   屏/假绿
   ───────────  ──────────────  ────────  ──────────  ────────  ────────
   仅有纸        台账 X-账对上     X-测      X-验        X-签      R≠X
   ✗ 「有PDF = 可交维」
   ✗ 「三年前测过 = 永远覆盖」
   ✗ 「检定过期但数据好看 = 可正式验收」
   ✗ 「配置改了报告还能用」
   ✗ 「屏全绿 = 电磁环境验收过了」
   ✗ 「待补状态可以对外说已达标」
```

所以规则1、3、6才硬：**先证覆盖与在检；不一致拒签；假绿不能顶替实测。**

### 4.7 与开站 / 交维 / 变更怎么衔接（只讲合规路径）

教学流程（细节以属地、合同与本网制度为准）：

1. **立项 / 拟开站**：查 U/V 证照台账 + 查 X 报告台账是否覆盖。  
2. **无有效覆盖**：编制方案（X-测）→ 仪器在检 → 实施测试 → 出报告。  
3. **入库台账（X-账）**：编号角色、有效期、覆盖、复测触发、互挂 U/G。  
4. **验收会签（X-签）**：对照拒签卡；缺项则待补，不放行。  
5. **交维**：交维包含 X 台账摘要（L3）+ 原件受控指针；假绿演练（R）是监控课，不是 X 替代。  
6. **运行中变更**：触发清单命中 → 复测/补测 → 更新台账 → 再签。  
7. **边界共址**：挂 S；争议报无线电管理机构。  
8. **结案**：X 子类结案词；套旧/伪造走 X-治。

**明确不教**：如何无报告发射、如何伪造涂改、如何规避检查与监测、如何用干扰压制「测好看」。

### 4.8 验收 / 交维前 15 分钟清单（可复印）

| 分钟 | 动作 |
|------|------|
| 0–3 | 打开台账卡：站址角色、候选报告编号角色、有效期 |
| 3–7 | X-账/X-测分诊七问；仪器在检？覆盖对吗？ |
| 7–10 | X-验最小集勾选；缺项 → 待补，禁签就绪 |
| 10–13 | 查复测触发与现场配置是否一致；边界则挂 S |
| 13–15 | 拒签卡自检（未套旧/未假绿顶替/未功率战）；交班口述 |

夜班压缩版：至少完成「有覆盖报告角色 + 在检可读 + 与现场无矛盾声明 + 未强签缺项」四项——**四项缺一仍禁签交维就绪**。

### 4.9 与 G / U / S / R / O / I / L 单据互挂（X → 实验室 / 证照 / 邻居 / 假绿 / 有源室分井库）

```text
  实验室（G）
        │
        └── 方法与仪器能力支撑 X-测；不能代替站址验收台账

  证照 / 临时窗（U / V）
        │
        └── 频段功率时段角色与报告方案一致；无证不拿环境报告顶替

  邻频协调（S）
        │
        └── 边界/共址验收：X 主贴 + S 协调编号互挂（均脱敏）

  假绿（R）
        │
        └── 仅提醒「看见≠实测」；禁止 R 顶替 X

  有源 / 室分 / 井库（O / I / L）

        └── 拓扑或有源变更 → 触发 X 复测
```

批量验收 / 周报：任何「环境达标」表述必须能追溯到 X 卡且公开 L3——**「领导要稿」不能代替报告最小集**。

## 5. 现场映射：原话 → X 子类；对话脚本；夜班；禁写词

### 5.1 原话速查表

| 原话 | 主贴 | 动作 |

### 5.2 对话脚本（五则）

**脚本1 · 套旧报告**  
对方：「文件夹里有份报告，格式差不多，站名改一下就行。」  
你：「规则3：报告与现场不一致、禁套用旧报告。先 X-账对覆盖站址角色；对不上就补测。主贴 X-治。」

**脚本2 · 仪器过期**  
对方：「检定上周过期，数据看起来还行，先签。」  
你：「规则2：仪器检定/校准过期 → 拒签正式验收依据。送检或换在检仪器重测。主贴 X-测。」

**脚本3 · 假绿顶替**  
对方：「假绿演练都过了，交维别再卡环境报告。」  
你：「规则6：假绿/屏上看见不等于实测验收。可挂 R 提醒，主贴仍是 X；无有效报告拒签交维就绪。」

**脚本4 · 变更先用着**  
对方：「功率角色调了一档，先开业务，下季度再复测。」  
你：「规则5：重大变更后须复测/补测再签；禁先用着再说。主贴 X-账，冻结放行。」

**脚本5 · 功率战过验收**  
对方：「邻频吵，我们边界功率顶满，测出来好看点。」  
你：「规则7：禁功率战掩盖环境问题；边界挂 S；争议报无线电管理机构。主贴 X-治，挂 S。」

### 5.3 夜班 15 分钟怎么用

1. 扫 X 台账：过期报告条数、待补条数、未复测变更条数（应为可解释且未强签）。  
2. 查仪器墙/台账：在用测试仪器是否有过期仍出正式报告。  
3. 查互挂：开站/交维单是否挂 X；边界是否挂 S；假绿是否被误当 X。  
4. 交班口述：待测/待补、已拒签原因（X 子类）、复测计划角色、主人。

### 5.4 「电磁环境验收三问」（贴验收室 / 网管室）

```text
  1. 报告覆盖的是本站址角色、本频段角色、本时段吗？有效吗？
  2. 仪器在检吗？结论与现场配置一致吗？有没有缺页断链？
  3. 有没有未复测的重大变更？有没有人想用屏绿或功率战顶替？
```

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「三年前报告直接签交维」→ X-账 / X-治

现象：项目催交维，拟用三年前 PDF，站址角色已扩建。  
处置：X-账对覆盖失败；拒签；开补测。  
结案词：「X-治：禁套旧报告；已开补测。」

### 例 2 · 「检定过期仍出正式报告」→ X-测

现象：频谱仪证书过期三日，测试班仍出具正式验收附件。  
处置：该次测量降级；拒作正式依据；送检后重测。  
结案词：「X-测：仪器过期，拒签正式验收。」

### 例 3 · 「缺仪器证书页与测点表」→ X-验

现象：报告正文有结论，附件缺仪器页与测点表，保管链不清。  
处置：断链/缺项；内部待补；禁正式验收。  
结案词：「X-验：缺项断链禁正式证据。」

### 例 4 · 「屏全绿顶替实测」→ X-治 + R

现象：网管主张假绿演练通过即可签环境验收。  
处置：拒顶替；挂 R 提醒；主贴 X；无报告则待测。  
结案词：「规则6：假绿≠实测；主贴 X。」

### 例 5 · 「天线更换未复测先开」→ 规则5 / X-账

现象：天线型号角色变更，业务已开，复测排下月。  
处置：冻结「验收/交维就绪」叙事；限期复测；开治理。  
结案词：「规则5：变更未复测，禁先用着再说。」

### 例 6 · 「实验室指纹单当验收报告」→ G + X

现象：只有 G 指纹测试单，无站址电磁环境验收报告。  
处置：G 可挂支撑；不代替 X；补站址报告或拒签交维。  
结案词：「G 支撑≠X 验收台账。」

### 例 7 · 「共址邻频功率战过测」→ X-治 + S

现象：联测前拟抬本网边界功率「压住」环境噪声观感。  
处置：禁止；挂 S；恢复合规功率角色；争议报管理机构。  
结案词：「规则7：禁功率战掩盖；已挂 S。」

### 例 8 · 「A 址报告改站名给 B 址」→ X-治

现象：发现 PDF 元数据与站址角色不符，疑似套用。  
处置：拒签；保全原件受控；开 X-治；必要时依法报告路径（不教伪造反制细节）。  
结案词：「X-治：疑似套用，拒签并治理。」

### 例 9 · 「公开周报贴全文号与坐标」→ X-治 / L3

现象：周报含报告全文号与测点坐标。  
处置：下架；改 L3；原件受控；培训规则8。  
结案词：「X-治：L3 违规已纠正。」

### 例 10 · 「临时保障窗声称免报告」→ V + X

现象：V 窗内临时台，主张「临时就几天不用环境报告」。  
处置：V 管窗与许可；X 仍要求方案覆盖与仪器在检；无有效依据拒签「保障就绪」中的环境项。  
结案词：「临时≠免 X；已拒签环境项。」

## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 一句话 |
|------|--------|
| **电磁环境测试（教学用语）** | 对站址角色周围射频环境按方案测量并记录，服务开站/交维/变更验收（方法细节以方案与属地要求为准） |
| **验收报告** | 载明方法、仪器、测点角色、结论与判据对照的书面结果，作正式验收证据须完整可追溯 |
| **报告台账** | 按站址角色检索的报告编号、有效期、覆盖范围、复测触发与互挂索引（X-账） |
| **仪器有效性** | 检定/校准证书在有效期内且适用于本次方法（X-测） |
| **检定 / 校准** | 计量语境下证明仪器量值可靠的活动；以证书载明日期为准（教学不编造统一年限） |
| **覆盖** | 报告的站址角色、频段角色、时段与当前验收对象一致 |
| **套用旧报告** | 把他址/他配置/过期报告当作本验收依据，本篇红线 |
| **断链报告** | 缺页、缺证书、缺测点、保管链断裂，降级禁正式验收 |
| **待测 / 待补** | 内部允许挂起，但禁签正式验收/交维就绪 |
| **复测触发** | 频点/天线/功率/室分等变更后必须再测的条件 |
| **签字边界** | 谁有权在何种勾选齐全时签署验收/交维（X-签） |
| **假绿顶替** | 用监控全绿或假绿演练代替实测报告，本篇红线 |
| **主贴 X** | 电磁环境测试与验收报告台账以 X 为主键，可挂 G/U/S/O/I/L/R |
| **L3** | 公开包最高脱敏等级（本系列约定） |
| **GB 8702 指针** | 《电磁环境控制限值》国家环境质量标准公开指针（限值以原文为准） |
| **消防验收隐喻** | 用大楼消防报告台账+计量检定讲清覆盖、在检、拒签 |
| **功率战掩盖** | 用抬功率等方式制造「测好看」，本篇红线 |
| **正式验收证据** | 可进入签字与交维闸门的报告；待补/断链/过期不算 |

**易错观念**

1. ✗ 文件夹有 PDF = 可交维 → ✓ 先对覆盖、在检、与现场一致。  
2. ✗ 三年前测过 = 永远有效 → ✓ 有效期与复测触发看台账。  
3. ✗ 检定过期但曲线好看 = 可正式验收 → ✓ 过期拒签正式依据。  
4. ✗ 配置改了报告还能用 → ✓ 重大变更须复测。  
5. ✗ 屏全绿 = 环境验收过了 → ✓ 假绿≠X。  
6. ✗ 实验室指纹单 = 站址验收报告 → ✓ G 支撑≠代替 X。  
7. ✗ 临时窗免报告 → ✓ 临时≠免 X。  
8. ✗ 功率顶上去就能过测 → ✓ 功率战红线；挂 S。  
9. ✗ 缺页先签回头补 → ✓ 缺项断链禁正式证据。  
10. ✗ 公开培训可贴报告全文号与坐标 → ✓ 公开 L3，原件受控。
