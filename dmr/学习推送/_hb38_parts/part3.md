## 8. 术语表（本篇约 18 词）+ 易错观念

| 词 | 本篇用法（教学） |
|----|------------------|
| **AK** | 本篇贴纸：爬塔·界面·交叉秩序 |
| **AK-爬** | 作业票/方案/到场子类 |
| **AK-界** | 塔桅/平台责任界面子类 |
| **AK-交** | 第三方交叉窗与停让许可子类 |
| **AK-验** | 本期交底实测子类 |
| **AK-治** | 假绿/顶替/套票/功率战/泄密治理 |
| **爬塔作业票** | 登高作业书面许可（格式以本网为准） |
| **方案** | 作业范围与步骤书面（不写真实坐标） |
| **责任界面** | 谁管塔身/平台/天线层/接地的书面边界 |
| **交叉施工窗** | 与第三方共用时间的书面天窗 |
| **停让许可** | 交叉时谁停谁让的书面方法 |
| **RF 暴露确认** | 靠近天线前的暴露评估/确认书面 |
| **停发确认** | 相关发射停/控的书面确认（不教伪造） |
| **假绿** | 监控/大屏绿灯冒充准用（挂 R） |
| **套票** | 用他站他期作业票/交底照片冒充本期 |
| **顶替** | 用 AJ/AI/AH/AD 等签顶掉 AK 本期签 |
| **功率战** | 告警/登记失败时抬功率硬扛（禁） |
| **L3 脱敏** | 公开材料去真实站名/塔号/联系人 |

**易错观念（钉死）**  
- ❌ 安全帽戴了 = 可以上 → ✅ 作业票+方案+到场才谈准用。  
- ❌ 对方说忙完了 = 交叉过 → ✅ 书面交叉窗与停让许可。  
- ❌ 天馈签还在 = 爬塔也能签 → ✅ AJ 不顶替 AK。  
- ❌ 监控绿 = 准用过 → ✅ 假绿挂 R；会签才放。  
- ❌ 爬塔窗登记失败先抬功率 → ✅ 禁功率战；先 AK/N。
