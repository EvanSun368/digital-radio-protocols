## 1. 为什么要写这篇手册（动机 + 现场对话）

前三十八篇手册从 A–E 协议一路写到 AK 爬塔交叉：其中 **AK 回答「铁塔/桅杆爬塔与第三方交叉」**，**AI 回答「机房温湿度与空调联锁」**，**AH 回答「多业主合路/POI 界面」**，**AF 回答「油机市电」**，**AD 回答「备件仪表准用」**，**AA 回答「交维后首年巡检」**，**N 回答「电源监控/对时/告警风暴」**。可还没有单独钉死一件事——**机房消防气灭不是「钢瓶在就能签」：气灭台账/钢瓶/探头准用要钉死；疏散路径与集合点要有主人有书面；联锁交底窗与方法要书面固定；本组本机房本期交底与实测禁套他机房他期——能不能签「气灭/疏散联锁准用」？** 这就是本篇的 **AL**——**机房消防气灭与应急疏散联锁交底**。

- 运维岗：「钢瓶在机房角落，气灭就算齐了。」——**无台账/准用仍准用** = 本篇拒签（规则1）。  
- 外包：「疏散图墙上贴了，集合点口头说一声。」——**路径/集合点无主人无书面** = 规则2。  
- 物业：「联锁上次测过差不多，温湿度也绿。」——**无联锁窗方法，只听口头/套温湿度绿** = 规则3。  
- 外包：「邻机房上周交底票参数差不多，拷过来改个房号。」——**套他机房他期** = 规则4。  
- 班长：「AI 温湿度签还在，AK 爬塔也过了，气灭疏散也能签。」——**用 AI/AK/AH/AF/AD/AA/N 顶替 AL** = 规则6。  
- 站务：「大屏监控绿了，气灭联锁准用就算过。」——**假绿≠会签放行** = 规则5/6。  
- 网优：「气灭预告警窗有人登记失败，功率抬一点稳住。」——**功率战** = 规则7。  
- 宣传岗：「把真实机房全称、钢瓶号、联系人发群表扬。」——**L3 违规** = 规则8。  

这几句背后是同一件事：

> **「机房消防气灭与应急疏散联锁」在现场至少有五个坑**：**① AL-气** 气灭台账/钢瓶/探头准用入账，禁「气瓶在就能签」「口头说一声」；**② AL-散** 疏散路径与集合点有主人、有书面，禁「疏散图贴了就算」；**③ AL-联** 联锁交底窗与方法钉死，禁「上次测过差不多」「温湿度绿当联锁过」；**④ AL-验** 本组本机房本期交底与实测（禁套他机房他期票/照片），会签才放行「气灭/疏散联锁准用」；**⑤ AL-治** 治理（假绿、用 AI/AK/AH/AF/AD/AA/N 顶替、伪造准用、功率战、旁路探头、泄密）。  
> 把 ①–⑤ 当成「气瓶在就能签」「疏散图贴了就演练过」「温湿度绿就当气灭准用」，每一次气灭维保、每一次疏散演练、每一次联锁交底，都会先吵「账是谁的、路径谁负责、交底是不是本期的」。

## 2. 总图 / 故事：气灭疏散像「医院手术室/药库气体灭火 + 消防疏散演练——不能只看钢瓶在」

### 2.1 一句话：气瓶在不是「可以签准用」、疏散图贴了不是「演练过了」——要先建气灭台账与钢瓶探头准用，疏散路径与集合点有主人有书面，联锁交底窗与方法钉死，本组本机房本期交底，会签才放行；假绿、套邻机房交底票、用 AI/AK/AH/AF/AD/AA/N 顶替，一律拒签

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  医院手术室/药库气体灭火 + 消防疏散演练联锁  =  本网 AL     │
   │                                                              │
   │  气瓶/钢瓶台账·探头准用钉死       ≈ AL-气  气灭台账准用钉死 │
   │  疏散路径/集合点责任书面边界       ≈ AL-散  疏散有主有书面   │
   │  气灭—疏散—空调联锁交底窗方法钉死 ≈ AL-联  联锁窗与方法钉死 │
   │  本期交底实测禁套邻楼交底票       ≈ AL-验  本组本机房本期   │
   │  假绿≠放行·顶替·伪造·功率战     ≈ AL-治  治理与脱敏 L3   │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **气灭有账，疏散有主，联锁有窗，本期交底，会签才放。**  
> 气瓶在还无台账准用 = 医院药库只看钢瓶在不查准用期——**拒签「气灭/疏散联锁准用」**。  
> 疏散图贴了但无本期演练/联锁交底 = 手术室墙上贴了疏散图却从未做联锁演练——**假绿，挂 R，拒签**。

```text
  ② AL-散 钉疏散路径/集合点：主人角色 · 书面路径与集合点 · 禁「图贴了就算」
        │  无主人 / 无书面路径 → 拒进入「可签」状态
        ▼
  ③ AL-联 钉联锁窗：书面窗 · 联锁方法（气灭预告警/释放与疏散、相关空调停机等） · 到场角色
        │  无窗 / 「温湿度绿当联锁过」 → 拒联锁签
        ▼
  ④ AL-验 本组本机房本期交底与实测：交底记录 · 禁套他机房他期票/照片
        │  套票 / 只看监控绿 → 拒签
        ▼
  ⑤ 会签「气灭/疏散联锁准用」或「有条件整改」：本网授权本人签
        │  缺签 / 假绿顶替 → 拒签准用
        ▼
  ⑥ 变更（气灭系统/联锁逻辑/门限/停发策略）→ 走 J + 触发再交底/再验（常挂 N 看监控、挂 AI 看温湿度联锁、挂 AD 看仪表）
```

> **一句话分辨**：**AI** 回答「温湿度联锁**过了没有**」；**AK** 回答「爬塔/交叉**清不清**」；**AH** 回答「合路界面**清不清**」；**AD** 回答「仪表准用期**到了没有**」；**AL** 回答「这一窗气灭台账 + 这一路疏散路径 + 这一窗联锁交底**台账清不清、路径有没有主、本期交底过了没有**」。**五个问题，五张（类）贴纸，不能一笔带过。**

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **气灭台账/钢瓶/探头准用钉死：无台账、钢瓶或探头准用断档不得签「气灭/疏散联锁准用」；禁「气瓶在就能签」「口头说一声」**。  
2. **疏散路径与集合点有主人有书面：主人角色书面；路径/集合点书面；禁「疏散图贴了就算」**。  
3. **联锁交底窗与方法钉死：联锁窗、联锁方法（气灭—疏散—相关空调等）、到场角色书面固定；禁「上次测过差不多」「温湿度绿当联锁过」**。  
4. **本组本机房本期交底与实测：须本脱敏机房、本窗交底与实测；禁套他机房/他期交底票或照片**。  
5. **会签才放行：相关授权本人会签后，方可签「气灭/疏散联锁准用」；重大未闭项禁合格**。  
6. **禁顶替：可挂 AI/AK/AH/AF/AD/AA/N/R 支撑，但机房消防气灭与应急疏散联锁主贴 AL；AI 温湿度签、AK 爬塔签、AH 合路签、AF 油机签、AD 仪表签、AA 首年签、N 监控绿、大屏绿灯均不得顶替 AL 本期气灭疏散签；主贴 AL；监测大屏/系统绿灯、假绿不等于放行（挂 R）**。  
7. **气灭/疏散联锁窗禁功率战；监控/告警风暴挂 N；气灭系统/联锁逻辑/门限/停发策略等变更走 J 并评估再交底/再验**。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/钢瓶序列号全文/可还原坐标与联系人**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签气灭准用、无联锁交底冒充演练过，不是法外运维智慧**。医院手术室/药库气灭与疏散演练公开资料、清洁灭火剂/火灾报警公开科普只作故事与方法类比（§2.2）：**气要约、散要主、联要窗、验要测、绿灯不算过**——翻译成本网语言就是 AL-气 / AL-散 / AL-联 / AL-验 / AL-治。**这些是气灭疏散联锁秩序，不是「气瓶在就签」「疏散图贴了就算」「抬功率压告警」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「气灭/疏散联锁准用」、对外宣传「分钟级一键气灭秒过」、把未交底写成已过。允许做的：补气灭台账、补疏散主人、重开联锁窗、重交底、挂 R/N/J、内部挂整改。

| 旁路探头交差 | 破坏/旁路传感器 | 规则7；治理；禁教 |

### 4.10 气灭 / 疏散 / 联锁与 AL 的咬合（教学直觉，门限以本网为准）

- **气灭台账**：公开常识强调有账、有准用、有探头；格式与审批**以本网制度为准**——AL 钉「有没有账、准用清不清、本期有没有交底」。  
- **疏散路径/集合点**：公开疏散演练直觉；**不教伪造演练记录**。  
- **联锁交底窗**：气灭预告警/释放与疏散、相关空调停机的时间窗——类似医院手术室/药库气灭与疏散演练；**书面窗与方法入账**。  
- **上行更脆 + 禁功率战**：气灭/疏散窗有人乱键/抬功率常先伤上行体验——先 AL，再谈「覆盖病」（X 指针）。  
- **AD / AI 指针**：相关仪表入库走 AD；空调联动可挂 AI；**不能**用旧签日期顶本期 AL 窗。

### 4.11 与温湿度（AI）/ 爬塔（AK）/ 合路（AH）/ 油机（AF）/ 仪表（AD）/ 首年（AA）/ 监控（N）怎么配合

- AI 温湿度并行：气灭常联动空调停机，各贴各的；环境过≠气灭准用。  
- AK 爬塔：登高过≠气灭疏散过。  
- AH 合路界面：合路清≠气灭/疏散界面清。  
- AF 油机：供电过≠气灭过；气灭窗市电态可挂 AF。  
- AD 仪表并行：仪表期内≠气灭准用过。  
- AA 首年巡检：日历抽检气灭可挂 AA，**主贴本期联锁仍 AL**。  
- N 告警风暴：气灭预告警/疏散窗铃响先挂 N 理风暴，**不先抬功率**；N 绿≠ AL 过。

### 4.12 气灭/疏散窗与上行更脆直觉

- 先 AL/N/AI/AD：台账、监控、温湿度联锁、仪表解释得清不清。  
- 解释不清再挂覆盖（X）/干扰（I）分诊；**禁止**一抖就功率战。  
- 上行更脆：气灭预告警与疏散人流叠加时，乱键/抬功率常先伤上行——先确认联锁秩序，再下「覆盖病」结论。

## 6. 工作实例（12 则，教学虚构，L3）

1. **气瓶在无台账**  
   现象：钢瓶可见，台账未入账、准用期空白。  
   处置：AL-气 拒签准用；补台账与钢瓶/探头准用。  

2. **疏散图贴了无主人书面**  
   现象：墙上有图，集合点口头互推。  
   处置：AL-散 拒签；书面补主人与路径/集合点；挂整改。  

3. **温湿度绿当联锁过**  
   现象：AI 大屏绿，无书面联锁窗方法。  
   处置：AL-联 拒签；重开书面联锁窗；主贴 AL。  

4. **套邻机房交底票**  
   现象：交底报告机房号涂改痕迹。  
   处置：AL-验/治 拒签；本窗重交底。  

5. **用 AI 温湿度签顶本期 AL**  
   现象：「温湿度签还在有效期，不用再贴气灭。」  
   处置：规则6；AI 可挂支撑，主贴仍 AL。  

6. **用 AK 爬塔签顶 AL**  
   现象：「爬塔交叉刚过，气灭疏散也能签。」  
   处置：规则6；爬塔≠气灭疏散；主贴 AL。  

7. **用 AH 合路签顶气灭界面**  
   现象：「合路界面绿了，气灭界面就算清。」  
   处置：规则6；合路≠气灭；主贴 AL。  

8. **旁路探头交差嫌疑**  
   现象：三联单出现「先旁路探头再测」叙事。  
   处置：AL-治 治理；禁旁路；整改后重交底（不教方法）。  

9. **气灭预告警窗抬功率压登记失败**  
   现象：上行失败被写成覆盖病。  
   处置：AL-治 禁功率战；先 AL/N；确认账与联锁；再谈 X。  

10. **监控绿当气灭过**  
    现象：大屏绿，气灭交底停在半月前。  
    处置：AL-治 + R 假绿；重开交底窗；主贴 AL。  

11. **改联锁逻辑未走 J**  
    现象：气灭窗私改联锁延时后「监控更绿」。  
    处置：挂 J；评估后 AL 再交底/再验（常挂 N/AI/AD）。  

12. **公开群发机房全称与钢瓶号**  
    现象：含可定位站信息。  
    处置：AL-治 规则8；撤回；L3 重发教学版。
