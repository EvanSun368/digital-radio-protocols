## 1. 为什么要写这篇手册（动机 + 现场对话）

前十七篇手册教你认病、交维、写频、批量、电源监控、有源隔离、口部泄漏：贴纸 A–E 协议层，F 射频，G 实验室，H 话务，I 室分，J 写频，K 电源，L 井库，M 批量/OTAP，N 监控/对时/风暴，O 有源隔离，P 口部切换。可现场还有一类「病」——**不是当天空口才坏，而是对照样与柜台货慢慢漂开了，没人按周期抽检**：

- 写频员：「手册11 写完验过了，金机也过了，可以收工。」——两周后抽检三台，信道摘要/功能项对不上现服；没人做**漂移巡检**。  
- 班长：「值班室那台一直是金机。」——上周夜班「临时改一下」Hangtime，档案没更新；金机先漂，对照全部说谎（指针 J-基）。  
- 新人：「全网感觉正常，别折腾抽检了。」——感觉 ≠ 对照表；无漂移判据 = 假绿（可挂 N）。  
- 领导：「大批量 OTAP 进度条走完就行。」——手册14 完成账有了，但**写后强制金机对照抽检**没做；M 过不等于 Q 过。  
- 射频同事：「这几台怪，肯定干扰。」——可能是批次漂移（Q-漂）；先 Q，再挂 F。  
- 有人：「机子怪，功率再加两格 / Hangtime 拧大点。」——加功率/乱拧是手册07/09/11 禁区；本篇也禁。  
- 手册11 学过的人：「J-基 不是已经写过金机档案吗？」——J 管变更当天的读写回滚锚；本篇是 **大批量之后与日常周期的漂移巡检加深册**，主贴新贴纸 **Q**。  
- 手册14 学过的人：「M-界 完成报表不是强制吗？」——完成账管「写没写完」；本篇管「写完之后还漂不漂、抽不抽」。

这几句背后是同一件事：

> **「金机基线漂移巡检」这个词在现场至少有五个坑**：  
> **① Q-金**：金机档案与样本身份——谁是金机、档案号、机型/固件/codeplug 指纹（教学层摘要，**不写真实密钥**）  
> **② Q-漂**：漂移判据——相对基线的偏差：功能项 / 信道表摘要 / 测听气质 / CPS 哈希或对照表（教学层）  
> **③ Q-巡**：巡检周期与抽样——大批量写频后强制抽检；周/月巡；抽检比例  
> **④ Q-比**：对照与复测——金机 vs 现役抽检机；台架/金机走测气质指针 G/J  
> **⑤ Q-治**：治理与拒签——漂移超阈禁放行；禁用「感觉还行」结案；脱敏 L3  
> 把 ①–⑤ 当成「写完就永久正常」或「出了事用手册01–05 / 07 分诊」，会把整队配置债与假绿债留给下一班。

本篇目标：能背出**金机基线漂移巡检工作流**；会用新贴纸 **Q（金机/漂移/巡检）** 与五个子类；会填 **插页 Q（R1–R8）** 和《本网金机基线漂移巡检卡》；能用「**药监对照样 + 柜台货抽检**」故事讲清金机与现役机慢慢漂开；能拒绝「无档案就说金机、无判据就放行、大批量后不抽检、用加功率掩盖机子怪、金机本身从不巡检」；自测过关后，回库把本网最近一次写频后抽检/金机漂移事件（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：不发明 ETSI 条款号；**不写真实批复频点、楼名、站号、个号、密钥、单位名进公开仓库**；**不教攻击/仿冒/破解/空口劫持**——只讲制度与治理；不重写手册11 / 14 / 08 / 15 全文（只给指针）；**J/M 仍生效，本篇加深漂移巡检**；**不把加功率/加信道/乱拧 Hangtime 当「机子怪」止痛药**；漂移**主贴 Q**，可挂 J/M/G/N；结案用 Q + 本网证据；公开 CM/漂移资料只借**精神与顺序**——**不背条款当 ETSI、不背 CPS 菜单当制度、不把蜂窝 KPI 抄进 DMR 公开包当法规**。

## 2. 总图 / 故事：金机像「药监对照样 + 柜台货抽检」

### 2.1 一句话：必须先证明金机档案可对、漂移判据书面、大批量后抽检过关，再谈「全网感觉正常」——否则对照样先漂、柜台货悄悄变质、交维假绿

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  药监所 / 药店柜台（本网金机制度柜 · 现役机队）                 │
   │                                                              │
   │   对照样 = 金机（Q-金）——有档案号、批号、指纹摘要的标准样       │
   │   柜台货 = 现役抽检机（Q-巡 / Q-比）——应按同一配方出厂          │
   │   配方卡 = 基线/现服索引（指针 J-基）——现服 + 上一版            │
   │   检验指标 = 漂移判据（Q-漂）——功能项/信道摘要/测听/对照表      │
   │   抽检节奏 = 巡检周期（Q-巡）——大批量后强制；周/月巡；比例      │
   │   对天平 = 对照复测（Q-比）——金机 vs 抽检机；可挂 G 气质        │
   │   拒签台账 = 治理（Q-治）——超阈禁放行；禁「感觉还行」；L3       │
   │                                                              │
   │   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐     │
   │   │ 核金机  │──▶│ 写判据  │──▶│ 定抽检  │──▶│ 对照复测│     │
   │   │ (Q-金)  │   │ (Q-漂)  │   │ (Q-巡)  │   │ (Q-比)  │     │
   │   └────┬────┘   └────┬────┘   └────▲────┘   └────┬────┘     │
   │        │             │             │              │           │
   │        │无档案禁金    │无判据禁签   │批量后强制    │对不上超阈 │
   │        ▼             ▼             │              ▼           │
   │   ┌─────────┐   ┌─────────┐       │         ┌─────────┐     │
   │   │ 金机自巡│   │ 回滚隔离│───────┘         │ 拒签放行│     │
   │   │ (Q-金)  │   │ (J-回)  │                 │ (Q-治)  │     │
   │   └─────────┘   └─────────┘                 └────┬────┘     │
   │        ▲                                          │           │
   │   禁加功率/加信道/乱拧 Hangtime 掩盖「机子怪」→ 治理（Q-治）◀─┘ │
   │   禁：感觉正常结案；金机从不巡；批量完成账代替漂移抽检          │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **先核对照样，再写检验指标，后定抽检节奏，末上柜台货对天平。**  
> 对照样先漂还拿去验货 = 药监自己变质——**金机本身也要巡检。**  
> 大批量写完不抽检 = 空投完不打开包装袋尝一口——**M 过 ≠ Q 过。**

### 2.2 「对照样与柜台货」五段直觉（弱项短补，钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **金机身份** | 药监柜里的对照样瓶 | 谁是金机、档案号、机型/固件/指纹摘要；金机≠随便好机 | Q-金 |
| **漂移判据** | 检验指标单 | 相对基线偏多少算漂：功能项/信道摘要/测听气质/对照表（教学层，不写密钥） | Q-漂 |
| **巡检抽样** | 抽检节奏与比例 | 大批量/OTAP 后强制；周巡/月巡；抽几台、怎么抽 | Q-巡 |
| **对照复测** | 柜台货 vs 对照样上同一台天平 | 金机与抽检机并测；可挂 G/J 气质 | Q-比 |
| **治理拒签** | 超标批次禁出库 | 超阈回滚/重写/隔离；禁感觉结案；脱敏 L3 | Q-治 |

> 公开配置管理常识（如 NIST SP 800-53 CM-2 / CM-3、SP 800-128 SecCM 公开页所说）：**维护基线、保留先前配置以支持回滚、检测未授权变更（漂移）**。本篇只借**顺序直觉**：核金机 → 写判据 → 定抽检 → 对照复测 → 超阈治理。**不背条款号当 ETSI / 不背厂商 CPS 菜单当本网制度 / 不把 IT 金镜像工具名抄进 DMR 公开包当法规。**

### 2.3 和手册11 / 14 / 08 / 15 / 06 的咬合（指针，不重写）

- **手册11 贴纸 J**：写频变更回滚与金机基线——**J-基** 建档案，**J-回** 管验失败回滚；本篇是 **漂移巡检加深册**。变更当天仍走 J；**写完之后漂不漂、抽不抽主贴 Q**。  
- **手册14 贴纸 M**：大批量/OTAP——完成账管「写没写完」；**写后强制金机对照抽检用 Q 钉死**（M 过 ≠ Q 过）。  
- **手册08 贴纸 G**：实验室金机对照闭环——Q-比 **调用** 金机业务闭环气质，不重写六闭环全文。  
- **手册15 贴纸 N**：监控/对时/风暴/假绿——「全网感觉正常」常是假绿；漂移抽检拒签可挂 N，**主贴仍 Q**。  
- **手册06**：证据五要素与脱敏 L0–L3；公开仓/教学材料 **≥L2，教学例强制 L3**。  
- **手册01 / 02 / 05**：坏写频/漂移可表现为登记怪、Grant 无声、鉴权失败气质——先问「最近批量写过吗、金机档案是否仍准」，再进协议分诊。  
- **手册07 / 09**：加功率、加信道、乱拧 Hangtime **不是**漂移止痛药。

### 2.4 新贴纸 Q：金机 / 漂移 / 巡检（五个子类）

```text
                    ┌──────── 贴纸 Q · 金机/漂移/巡检 ────────┐
                    │  Q-金  金机档案与样本身份：谁是金机·档案号·机型/固件/指纹摘要 │
                    │  Q-漂  漂移判据：功能项/信道摘要/测听气质/对照表（教学层）   │
                    │  Q-巡  巡检周期与抽样：大批量后强制·周/月巡·抽检比例         │
                    │  Q-比  对照与复测：金机 vs 现役抽检机；可挂 G/J 气质         │
                    │  Q-治  治理与拒签：超阈禁放行·禁感觉结案·脱敏 L3           │
                    └──────────────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签 / 拒放行触发 |
|------|--------|----------------------|
| **Q-金** | 金机无档案或金机本身未巡 → 禁当对照样 | 「值班室那台一直好」但无档案号 |
| **Q-漂** | 无书面漂移判据 / 无对照表 → 禁签放行 | 「感觉差不多」当判据 |
| **Q-巡** | 大批量/OTAP 后未抽检 → 禁放行 | 完成账有、抽检零 |
| **Q-比** | 金机 vs 抽检机未并测 → 禁结案 | 只测抽检机不碰金机 |
| **Q-治** | 超阈未回滚/隔离仍放行；假绿；泄密 | 「先上勤再慢慢改」 |

### 2.5 金机基线漂移巡检最小工作流（背下来）

```text
  要宣布「全网/本批配置正常」或大批量后放行
        │
        ▼
  金机档案在？身份可指认？金机自身最近巡过？──否──▶ 拒（Q-金 / 规则6）
        │是
        ▼
  漂移判据书面？对照表/摘要字段齐？──否──▶ 拒签（Q-漂 / 规则4）
        │是
        ▼
  本窗口是否大批量/OTAP 后？──是──▶ 强制抽检包（Q-巡 / 规则3；指针 M）
        │否（日常周/月巡）
        ▼
  按本网比例抽检现役机 + 金机并测（Q-比；可挂 G）
        │
        ▼
  相对基线：过 / 临界 / 超阈？
        │过 → 记巡检卡；可谈「正常」
        │临界 → 带条件；缩短复检窗
        │超阈 → 禁放行；回滚/重写/隔离批次（Q-治 + J-回）；禁加功率叙事
```

现场口诀：

> **先核样，再写指标，后抽检，末对天平。**  
> 跳过抽检的「感觉正常」= 没打开包装就说药没过期。

## 3. 核心交付：插页 Q + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 Q（而不是先贴 J / M / G / N）

| 现场信号 | 主贴 | 可次挂 |
|----------|------|--------|
| 大批量/OTAP 刚完成，要宣布放行 | **Q**（强制抽检） | M（完成账）、J（回滚入口） |
| 「机子怪」但最近写过/批量过 | **Q** | J/M；排除后再挂 F/A–E |
| 金机对照突然全军说谎 | **Q-金**（金机先漂） | J-基、G |
| 无判据却要签「配置正常」 | **Q-漂 / Q-治** | N（假绿） |
| 变更当天空白 CPS / 无备份要写 | 仍主贴 **J** | 本篇可挂 Q 气质提醒「写后还要巡」 |
| 监控全绿但抽检对不上 | **Q** | N |

> **口诀**：变更当天的读写回滚走 **J**；舰队尺度的试投完成账走 **M**；**写完之后漂不漂、周期抽不抽走 Q**。三者可叠挂，漂移巡检**主贴 Q**。

### 3.2 插页 Q · 金机 / 漂移 / 巡检（挂在总三联单或写频/批量作业包首页后）

| 行 | 名称 | 填写示例（教学虚构） |
|----|------|----------------------|
| **R1** | 主子类 + 次子类 | 「主 Q-巡 / 次 Q-比」（或 Q-金 / Q-漂 / Q-治） |
| **R2** | 金机身份 | 「档案号 G-18-07；机型族 T；固件标签（脱敏）；指纹摘要批次 B」（禁真实个号密钥） |
| **R3** | 基线指针 | 「现服索引号；上一版档案号；最近 J 变更单号（脱敏）」 |
| **R4** | 漂移判据 | 「功能项清单勾选；信道逻辑表摘要；测听气质项；对照表版本」（教学层） |
| **R5** | 巡检触发 | 「大批量后强制 / 周巡 / 月巡 / 事件驱动（投诉簇）」 |
| **R6** | 抽样方案 | 「比例或台数；分层（机型族/批次）；随机+关键岗位机」 |
| **R7** | 对照复测 | 「金机与抽检机并测结果；可挂 G 闭环气质；过/临界/超阈」 |
| **R8** | 判定与动作 | 「放行 / 带条件（缩短复检）/ 禁放行→回滚重写隔离；脱敏 L3」 |

> **R2 与 R4 不过 → 禁止以「金机对照」名义签字。**  
> **R5 若为大批量后且 R6/R7 空 → 禁止放行（规则3）。**  
> **R8 若写「加功率/拧 Hangtime 试试」或「感觉还行」→ 本页作废重填。**

### 3.3 「无档案 / 无判据 / 未抽检 / 超阈」拒签卡（贴写频室 / 交维台 / 网管）

```text
  ┌────────────── 金机漂移巡检拒签卡（贴纸 Q）──────────────┐
  │  × 金机无档案号/指纹摘要就把某台当对照样                  │
  │  × 金机本身超过本网巡检窗未自检仍拿去验货                  │
  │  × 无书面漂移判据 / 无对照表就签「配置正常」                │
  │  × 大批量写频/OTAP 后零抽检就放行（有完成账也不行）        │
  │  × 只测抽检机、不并测金机就结案                            │
  │  × 漂移超阈仍放行；「先上勤再慢慢改」                      │
  │  × 用加功率 / 加信道 / 乱拧 Hangtime 掩盖「机子怪」        │
  │  × 用「全网感觉正常」或监控假绿代替对照表                  │
  │  × 公开包出现真实频点 / 个号 / 密钥 / 站名 / 单位名        │
  │  √ 例外：书面窗、原因、审批、到期复检——写进 R8             │
  └────────────────────────────────────────────────────────┘
```

### 3.4 和总三联单怎么写（接手册06）

- **现象**：写「抽检机信道摘要与现服不符」或「金机档案过期未自巡」，不要写「干扰」除非已排除 Q。  
- **证据**：金机档案号（脱敏）、判据版本、抽样清单、对照结果相对描述、回滚单号指针。  
- **时钟**：若与手册15 风暴同时，写清三钟差；漂移大则禁秒级因果。  
- **贴纸栏**：主 **Q-? **，次挂 J/M/G/N（若有）。  
- **结案词**：用 Q 子类 + 动作（复检/回滚/隔离/拒签），禁用「加功率好了」「感觉正常了」。

## 4. 深潜：八条硬规则 + 金机/漂移/巡检直觉 + 假病禁令

### 4.1 八条硬规则（本篇钉子）

1. **先证金机档案与基线可对，再谈「全网感觉正常」**——对照样没核，禁止宣布柜台货合格。  
2. **禁用加功率 / 加信道 / 乱拧 Hangtime 掩盖「机子怪」**——呼应手册07/09/11；功率不是漂移补丁。  
3. **大批量写频 / OTAP 后强制金机对照抽检**——指针手册14 M、手册11 J；M 完成账不替代 Q。  
4. **无漂移判据 / 无对照表 → 禁签放行**——「感觉差不多」不是判据。  
5. **漂移超阈 → 禁放行；先回滚 / 重写 / 隔离批次**——指针 J-回；禁止带病上勤。  
6. **金机 ≠ 随便好机；金机本身也要巡检（防金机先漂）**——变质的对照样比没有对照样更危险。  
7. **可挂 J/M/G，但主贴 Q；假绿拒签**——监控全绿、感觉正常，对不上对照表照样拒。  
8. **公开材料脱敏 L3；不写真实频点/楼名/站号/个号/密钥/单位名**——教学与公开仓双禁。

### 4.2 金机直觉：「对照样要有瓶签」（Q-金）

金机不是「这台听起来还行」的口语，而是**可审计的样本身份**：

| 字段（教学） | 像什么 | 常见坑 |
|--------------|--------|--------|
| **档案号** | 瓶签批号 | 口头「值班室那台」无号 |
| **机型族 / 固件气质** | 药品规格 | 跨机型拿来当金机 |
| **指纹摘要** | 配方摘要（非密钥） | 只写「已备份」无摘要字段 |
| **有效期 / 最近自巡** | 对照样复检日期 | 金机半年未自巡仍验货 |
| **存放与权限** | 药监柜双人 | 谁都能「临时改一下」 |

```text
  这台能当金机吗？
        │
        ▼
  有档案号+指纹摘要？──否──▶ 拒授牌（Q-金 / 规则6）
        │是
        ▼
  最近自巡在窗内？──否──▶ 先自巡/重锚；禁立即验货
        │是
        ▼
  记录 R2/R3；进入判据与抽检
```

### 4.3 漂移判据直觉：「检验指标要写在纸上」（Q-漂）

本篇讲**制度层对照**，**不写真实密钥、不 dump 厂商 CPS 全菜单、不发明哈希算法当法规**：

| 判据类（教学） | 白话 | 运维动作 |
|----------------|------|----------|
| **功能项勾选** | 紧急键/扫描/提示音等是否仍按现服 | 清单化；变更后重勾 |
| **信道逻辑摘要** | 区/信道逻辑表批次是否一致（脱敏） | 摘要对摘要，禁抄真实频点进公开包 |
| **测听气质** | 登记/有声/关键业务听感是否仍「过」 | 调用 G/J-验 气质，不重写全文 |
| **对照表/哈希气质** | CPS 工程对照或本网允许的摘要核对 | 有就用；无则诚实写「未建哈希，用摘要表」 |

> 公开 IT「金镜像漂移检测」只借「**活体配置要对比批准基线**」的常识——**不把某云厂商漂移工具名写进本网公开制度当强制。**

### 4.4 巡检抽样直觉：「空投完要开袋抽检」（Q-巡）

| 触发 | 最低动作（教学） | 拒签点 |
|------|------------------|--------|
| **大批量/OTAP 刚完成** | 强制抽检包：金机并测 + 分层抽现役 | 完成账有、抽检零 → 禁放行 |
| **周巡** | 按本网比例抽；含至少一台金机自巡 | 连续空窗 |
| **月巡** | 扩大比例或全关键岗位机 | 只抽「好说话的班组」 |
| **事件驱动** | 投诉簇/异常气质后追加抽检 | 用「偶发」糊弄 |

**和手册14 的咬合**：M-试 是起飞前试投；Q-巡 是落地后开袋——**两道都要过**。

### 4.5 对照复测直觉：「同一台天平」（Q-比）

```text
  抽检机「怪」
        │
        ▼
  金机并测同一剧本？──否──▶ 补 R7；禁单测结案
        │是
        ▼
  金机过、抽检不过 → 批次/个体漂移；回滚/重写路径（J-回）
  金机不过、抽检也不过 → 先疑金机先漂或剧本/台架；禁宣告「基站挂了」
  金机过、抽检过 → 记录过；可谈放行
        │
        ▼
  超阈？──是──▶ 禁放行（规则5）；隔离批次
```

### 4.6 「假干扰 / 假容量 / 假协议 / 假绿」怎么认

| 假病名 | 真身往往是 | 禁令 |
|--------|------------|------|
| 假干扰 | 批次漂移导致听感怪（Q-漂） | 禁先开 F 同频单 |
| 假容量 | 参数漂后队列/Hangtime 乱 | 禁加信道掩盖 |
| 假协议 | 写坏/漂后登记鉴权怪 | 先 Q/J，再挂 A–E |
| 假绿 | 监控正常、感觉正常、对照表不过 | 挂 N 气质，主贴 Q 拒签 |
| 假金机 | 无档案「好机」或金机已漂 | 规则6 |

### 4.7 假病禁令墙（与加功率叙事）

```text
  × 「机子怪，功率加两格」           → 规则2
  × 「Hangtime 拧大点压住」         → 规则2；指针 J/H
  × 「全网感觉正常，别抽了」         → 规则1/4
  × 「OTAP 完成账有了，抽检以后再说」→ 规则3
  × 「金机上周改过，档案明天补」     → 规则6；先隔离金机资格
  × 「超阈先上勤，周末再刷」         → 规则5
  × 「监控全绿说明配置没漂」         → 假绿；规则7
```

### 4.8 大批量后强制抽检最小包（可复印）

| 步骤 | 做什么 | 记录到 |
|------|--------|--------|
| 0 | 冻结加功率/乱拧叙事；确认 M 完成账与 J 现服索引 | R3/R5 |
| 1 | 核金机档案 + 金机自巡（若过期先自巡） | R2 |
| 2 | 按分层方案抽现役机（机型族/批次/岗位） | R6 |
| 3 | 金机与抽检机并测同一最小业务包（指针 G/J-验） | R7 |
| 4 | 对判据逐项：过/临界/超阈 | R4/R7 |
| 5 | 判定：放行 / 带条件 / 禁放行→回滚隔离；禁「感觉行」 | R8 |

### 4.9 和手册11 J / 手册14 M 怎么叠挂

- 变更当天空白 CPS、无备份 → **主 J**，本篇提醒写后还有 Q。

- 不要用「先加功率」换「先对基线」——禁令叠加时，**两个都要守**。

### 4.10 和弱项加餐的衔接

漂移管的是 **12.5 kHz** 这一格里账本是否与对照样对齐——**不**把信道变 25 kHz，也不改 4FSK / 30 ms。加功率叙事 → 回加餐 + 规则2。

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「OTAP 完成账全绿，零抽检放行」→ Q-巡（次挂 M）

- **现象**：舰队 OTAP 完成报表成功/失败/未达齐全；当日宣布放行；三日后关键岗位机功能项对不上。  
- **误判**：有完成账 = 配置正常。  
- **正解**：M 过 ≠ Q 过；强制抽检包缺失 → 拒签级事故复盘；补抽检 + 超阈机回滚。  
- **贴纸**：主 Q-巡，次 M-界。

### 例 2 · 「值班室金机被临时改 Hangtime」→ Q-金（次挂 J-基）

- **现象**：金机对照突然大面积「不过」；有人喊基站挂了。  
- **误判**：先开基站故障单。  
- **正解**：金机上周夜班临时改过未更新档案；隔离金机资格 → 上一版重刷 → 自巡 → 再授牌。  
- **贴纸**：主 Q-金，次 J-基。

### 例 3 · 「感觉正常拒抽检」→ Q-漂 / Q-治

- **现象**：领导要求别折腾；无对照表。  
- **误判**：体感可替代判据。  
- **正解**：无 R4 禁签；书面判据补齐前不得宣布配置正常。  
- **贴纸**：Q-漂 + Q-治。

### 例 4 · 「怪机加功率」→ Q-治 + 规则2

- **现象**：抽检三台听感怪；有人建议功率加两格。  
- **误判**：覆盖病。  
- **正解**：先并测金机；确认批次摘要漂移 → 回滚/重写；功率工单作废。  
- **贴纸**：主 Q-治，禁挂「加功率结案」。

### 例 5 · 「只抽办公室机」→ Q-巡

- **现象**：抽样两台都过；一线车载机后来大量异常。  
- **误判**：抽检已做。  
- **正解**：未分层；R6 作废重抽（含关键岗位/批次）。  
- **贴纸**：Q-巡。

### 例 6 · 「只测抽检机不碰金机」→ Q-比

- **现象**：抽检机「过」就结案；金机实际已漂。  
- **误判**：单边测等于对照。  
- **正解**：无并测 = 没上同一台天平；补 R7。  
- **贴纸**：Q-比。

### 例 7 · 「超阈先上勤」→ Q-治 / 规则5

- **现象**：对照超阈；班次紧，先发机。  
- **误判**：业务优先可豁免阈值。  
- **正解**：禁放行；隔离批次；有线回滚路径（指针 J-回 / M-界）。  
- **贴纸**：Q-治。

### 例 8 · 「监控全绿当没漂」→ Q-治 + N

- **现象**：网管无告警；抽检摘要不对。  
- **误判**：假绿 = 真正常。  
- **正解**：配置漂移常不进性能告警；对照表优先；可挂 N。  
- **贴纸**：主 Q，次 N。

### 例 9 · 「公开巡检报告写真实个号频点」→ Q-治

- **现象**：为「好对照」把真实参数写进可外传材料。  
- **误判**：方便。  
- **正解**：L3 脱敏；用档案号与摘要；泄露按制度升级。  
- **贴纸**：Q-治。

### 例 10 · 「漂移当协议玄学」→ Q-比（次挂 A–E 仅排除后）

- **现象**：登记失败气质增多；有人直接手册01 开单。  
- **误判**：协议层优先。  
- **正解**：假干扰排除三问 → 发现刚批量；先 Q 抽检；确认漂后再决定是否次挂 A–E。  
- **贴纸**：主 Q，次挂仅在排除后。

### 6.5 漂移对齐会：20 分钟议程

1. 触发：批量后/周巡/事件（2′）  
2. 金机柜：档案与自巡窗（3′）  
3. 抽检：过/临界/超阈台数（5′）  
4. 超阈处置进度（5′）  
5. 假绿与加功率叙事（3′）  
6. 下窗复检写入日历（2′）

## 8. 术语表（本篇约 28 词）+ 易错观念

| 术语 | 白话 | 易错 |
|------|------|------|
| **金机** | 带档案的对照样终端 | ≠ 随便一台好机 |
| **基线 / 现服** | 当前批准的配置账本摘要 | ≠ 「机里现在是啥就算」 |
| **上一版** | 可回滚的先前基线 | 只留现服 = 书柜空 |
| **漂移** | 活体配置相对基线的未对齐偏差 | ≠ 一定是射频干扰 |
| **漂移判据** | 书面检验指标 | ≠ 感觉差不多 |
| **对照表** | 摘要/功能项/允许的核对表 | 公开包禁真实密钥频点 |
| **指纹摘要** | 教学层配置身份摘要 | ≠ 把密钥写进公开仓 |
| **巡检** | 按周期或事件核对是否漂 | ≠ 写完当天验一次就终身 |
| **强制抽检** | 大批量/OTAP 后必做的开袋抽 | ≠ 可用完成账替代 |
| **抽样比例** | 抽多少、怎么分层 | ≠ 只抽好说话的班组 |
| **并测** | 金机与抽检机同一剧本 | ≠ 单测抽检机 |
| **超阈** | 超过判据允许偏差 | → 禁放行 |
| **临界** | 未超阈但需缩短复检 | ≠ 假装过 |
| **回滚** | 写回上一版（指针 J-回） | ≠ 在失败稿上连续乱拧 |
| **隔离批次** | 超阈机退出勤务 | ≠ 先上勤再改 |
| **授牌 / 撤牌** | 给予或取消金机资格 | 金机漂了要先撤牌 |
| **自巡** | 金机自身按窗复检 | 金机也要被巡 |
| **假绿** | 监控/感觉正常但对不上对照 | 指针 N；主贴 Q 拒签 |
| **codeplug** | 电台配置工程/文件气质 | 跨机型禁互写（指针 J/M） |
| **CPS** | 客户编程软件气质 | 先读后写（指针 J） |
| **OTAP** | 空口写频 | 强稳覆盖+足电+完成账+本篇抽检 |
| **变更单** | 写什么、影响谁的审批单 | 指针 J-变 |
| **L3 脱敏** | 公开教学最高脱敏档 | 禁真实频点个号密钥站名 |
| **12.5 kHz** | 一条 DMR 信道宽度 | 漂移不改变它 |
| **4FSK** | 装货调制 | 漂移不改变它 |
| **30 ms / 60 ms** | 时隙与双时隙一轮 | 漂移不改变它 |
| **主贴 Q** | 漂移巡检主贴纸 | 可挂 J/M/G/N |
| **M 过 ≠ Q 过** | 完成账 ≠ 漂移抽检过 | 两道门槛 |

**易错观念（钉死）**

1. 「写完验过 = 永远不漂」——错；要周期与事件巡检。  
2. 「金机不会坏」——错；金机先漂更危险。  
3. 「感觉正常 / 监控绿 = 没漂」——错；要对照表。  
4. 「完成账全绿可放行」——错；大批量后还要 Q。  
5. 「机子怪就加功率」——错；规则2。  
6. 「漂移是 ETSI 某条款号」——本篇不发明条款号；借 CM 精神即可。
