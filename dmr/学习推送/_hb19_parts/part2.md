## 4. 深潜：八条硬规则 + 采集/备/绿/演直觉 + 假病禁令

### 4.1 八条硬规则（本篇钉子）

1. **先证采集链心跳与非假绿，再写空口/干扰/协议玄学**——探头与屏没对上，射频单先冻结。  
2. **禁用加功率 / 加信道 / 乱拧参数掩盖「监控看不见」**——呼应手册07/09；功率不是采集补丁。  
3. **采集无主备或无切换验证 → 禁签「监控已就绪」交维**——有两台机器 ≠ 高可用。  
4. **假绿（采集僵死/断链仍全绿）= 拒签 / 拒放行**——值班屏假装没事比铃响更危险。  
5. **假绿演练未做或无书面窗 → 禁签交维 / 禁宣称监控可靠**——无「故意断一路」证据 = 假绿债。  
6. **演练窗可挂 N/K，但采集 HA 与假绿剧本主贴 R**——对时风暴与电源倒换不顶替采集演练账。  
7. **双采集脑裂 / 双写未治理 → 禁当高可用完成**——两路互刷绿比单路更会骗人。  
8. **公开材料脱敏 L3；不写真实站名/频点/个号/密钥/网管地址**——教学与公开仓双禁。

### 4.2 采集身份直觉：「雷达要有编号与扫区」（R-采）

采集不是「大屏在刷新」的口语，而是**可审计的探头身份**：

| 字段（教学） | 像什么 | 常见坑 |
|--------------|--------|--------|
| **采集角色标签** | 主雷达呼号 | 口头「那台服务器」无标签 |
| **对象清单版本** | 扫区图 | 采什么说不清；清单与墙不一致 |
| **心跳周期 / 超时** | 雷达转一圈时限 | 无超时定义，僵死永不发现 |
| **最近成功拍** | 最后回波时间 | 只看颜色不看时间戳 |
| **权限与变更** | 谁能动采集配置 | 随手改轮询间隔无单 |

```text
  这路采集能签「在线」吗？
        │
        ├─ 无角色标签 / 无对象清单版本 ──▶ 否（R-采）
        ├─ 无心跳或超时定义 ──▶ 否（假绿温床）
        ├─ 最近成功拍超过本网超时仍绿 ──▶ 假绿（R-绿）
        └─ 标签+清单+心跳均过 ──▶ 再问主备与演练
```

### 4.3 主备直觉：「备雷达要能接班」（R-备）

| 项 | 过关样子 | 不过样子 |
|----|----------|----------|
| **双路存在** | 主/备角色书面 | 「好像有两台」无角色 |
| **切换窗验证** | 有日期、有结果、有恢复 | 从没切过宣称 HA |
| **失败域分离** | 不同主机/路径气质（教学） | 同机双进程当双路 |
| **脑裂治理** | 同时只一路写主视图或有去重/仲裁 | 双写互刷、墙闪绿又红又绿 |
| **回切策略** | 自动/手动书面；禁乒乓无记录 | 回切无人知、账对不上 |

> 公开双采集器/failover 文档只借精神：**备机要够得着同一批对象、切换要可测、要有回切策略**。不绑定某商业 NMS 菜单。

### 4.4 假绿直觉：「屏绿不等于雷达转」（R-绿）

假绿 = **采集已死或静默缺口，墙仍显示正常/全绿**。

| 假绿样子 | 怎么认 | 动作 |
|----------|--------|------|
| 进程僵死仍绿 | 心跳超时；最近成功拍过老 | 拒签（规则4） |
| 链路断仍绿 | 合成探针/死人手柄不响 | 先修探测再谈业务 |
| 静默缺口 | 中间缺拍无人知 | 缺口告警；演练验证 |
| 「抑制」伪装绿 | 全静音交班（指针 N） | 禁全静音常态；例外书面 |

与手册18 **Q 漂移**分清：

| | 金机漂移 Q | 采集假绿 R |
|--|------------|------------|
| 坏在哪 | 柜台货相对对照样漂了 | 探头/采集链僵死屏却绿 |
| 典型原话 | 「机子怪」「抽检对不上」 | 「大屏全绿但站早挂了」 |
| 主贴 | Q | R |

### 4.5 演练直觉：「故意断一路证铃响」（R-演）

假绿演练最小剧本（教学默认，按本网裁剪）：

1. **书面窗**：起止、审批角色、影响范围、中止条件。  
2. **基线**：演练前确认墙状态、心跳、最近成功拍（脱敏记录）。  
3. **注入**：只断演练名单内一路（主采 / 备采 / 单探针），禁扩大杀伤。  
4. **期望**：在超时内铃响或屏变色；若不变 = 演练失败 = 假绿债坐实。  
5. **恢复**：按剧本恢复；确认回稳态；记恢复时长。  
6. **关闭**：假设成立否、意外影响、跟进项；脱敏 L3 入卡。

```text
  演练窗开了吗？──否──▶ 禁止开断（规则5）
        │是
        ▼
  只动书面名单？──否──▶ 中止
        │是
        ▼
  断后会响/会变？──否──▶ 演练失败；拒签「监控可靠」；开 R-治
        │是
        ▼
  恢复 + 记证 + 可缩短复演周期
```

### 4.6 「假干扰 / 假容量 / 假协议 / 假绿」怎么认

| 假病 | 听起来像 | 先问 |
|------|----------|------|
| 假干扰 | 「看不见肯定同频」 | 采集心跳？假绿？ |
| 假容量 | 「加信道就好了」 | 是监控盲还是真话务？手册09 |
| 假协议 | 「肯定鉴权玄学」 | 屏是否在说谎？ |
| 假绿 | 「全绿没事」 | 最近演练？僵死判据？ |

### 4.7 假病禁令墙（与加功率叙事）

```text
  × 监控看不见 → 加功率 / 加信道
  × 大屏绿 → 跳过采集身份与演练账
  × 有两台采集机 → 自动等于 HA 完成
  × 演练太吓人 → 签字代替「会响」证据
  × 倒换窗铃响 → 全静音交班（指针 N 禁令）
  × 配置漂移与采集假绿 → 混成一句「监控有问题」结案
  √ 先 R 工作流；可挂 N/K/G/Q；结案用子类+证据
```

### 4.8 假绿演练最小包（可复印）

| 项 | 必填 |
|----|------|
| 窗 | 起止 + 审批角色 |
| 范围 | 对象清单子集（脱敏） |
| 动作 | 断主 / 断备 / 断探针（选一） |
| 期望 | 超时内响铃或变色 |
| 中止 | 误伤扩大 / 真业务事故阈值 |
| 证据 | 相对描述 + 日志指针（L3） |
| 结果 | 过 / 失败→拒签→修复→复演 |

### 4.9 和手册15 N / 手册12 K / 手册18 Q 怎么叠挂

- 风暴铃墙：先排除 **R 假绿**，再按 **N** 根因/对时。  
- 市电倒换演练：物理主贴可 **K**，采集是否假绿、是否做过断采集演练主贴 **R**。  
- 抽检对不上：走 **Q**；同时墙全绿要问是否 **R-绿**。  
- 三者可同日爆发：先假绿（R）→ 再对时风暴（N）→ 再漂移（Q）；物理倒换挂 K。

### 4.10 和弱项加餐的衔接

12.5 kHz / 4FSK / 30 ms 两槽背熟，你才说得清：**采集 HA 管的是机房眼睛与心跳，不是调制台阶**。有人要用加功率/加信道治「监控看不见」时，回加餐 + 手册07/09 + 本篇八条硬规则。

## 5. 现场映射：原话 → R 子类；对话脚本；反例

### 5.1 原话速查表

| 现场原话 | 先贴 | 一句话动作 |
|----------|------|------------|
| 「大屏全绿，监控已就绪，签交维吧」 | R-演 / R-治 | 要演练账与切换验证；无则拒签 |
| 「采集进程好像挂了，但墙还绿」 | R-绿 | 假绿拒签；先修探测 |
| 「我们有双采集，高可用做完了」 | R-备 | 要切换窗记录；脑裂是否治理 |
| 「假绿演练太吓人，别做了」 | R-演 | 无书面窗禁宣称可靠 |
| 「监控看不见，肯定干扰，加功率」 | R-治 | 禁令；先 R 再谈 F |
| 「倒换窗铃响，把监控静音」 | N + R | 禁全静音常态；采集是否假绿另问 R |
| 「抽检对不上，监控也绿」 | Q 与 R 分清 | 漂→Q；采僵→R |
| 「两台采集同时写，墙闪来闪去」 | R-备 | 脑裂；禁当 HA 完成 |
| 「公开总结写了网管地址和站名」 | R-治 | L3 重写；拒公开 |
| 「业务掉话，先别查采集了」 | R-采 | 先心跳非假绿，再空口玄学（规则1） |

### 5.2 对话脚本（六则）

**脚本 A · 交维要签监控就绪**  
- 对方：「大屏绿了，签吧。」  
- 你：「插页 R2/R3/R6 呢？采集身份、切换验证、假绿演练窗。」  
- 对方：「没有演练，但一直很稳。」  
- 你：「无演练 = 假绿债。规则5，拒签交维。」

**脚本 B · 假绿现场**  
- 对方：「站早不在线了，墙怎么还绿？」  
- 你：「R-绿。心跳超时了吗？最近成功拍？」  
- 对方：「超时定义……好像没写。」  
- 你：「先补 R-采 心跳/超时，再谈干扰。假绿拒放行。」

**脚本 C · 有双机无切换**  
- 对方：「两台采集都在，HA 完成。」  
- 你：「最近一次切换窗验证日期？脑裂治理勾选？」  
- 对方：「没切过，怕出事。」  
- 你：「没切过就不能签 HA。规则3、7。排演练窗。」

**脚本 D · 加功率叙事**  
- 对方：「监控老看不见，功率加两格。」  
- 你：「禁止。规则2。看不见先证采集链，不是抬功率。」  
- 对方：「那信道再开一个？」  
- 你：「同样禁。手册07/09 + 本篇 R-治。」

**脚本 E · 与 N/K 叠挂**  
- 对方：「倒换演练铃墙炸了，是不是风暴 N？」  
- 你：「可挂 N；物理可挂 K。问一句：断采集演练做过吗？主贴仍可能是 R。」  
- 对方：「只做过油机倒换。」  
- 你：「K 有了；R-演 还缺。别把倒换窗当假绿演练账。」

**脚本 F · 与 Q 分清**  
- 对方：「机子怪，监控又全绿，是不是假绿？」  
- 你：「先分：抽检对不上走 Q；采集僵死仍绿走 R。两边都要问，别混结案。」  
- 对方：「那先贴哪个？」  
- 你：「采集心跳超时优先排除 R-绿；心跳正常再 Q-比。」

### 5.3 反例墙（贴网管 / NOC / 交维台）

```text
  × 交维单「监控已就绪」无 R6/R7
  × HA 验收只拍两台服务器合影
  × 假绿演练用「桌面走走流程」代替真断一路
  × 演练失败（铃不响）仍签字「可靠」
  × 双写脑裂用「刷新一下就好」结案
  × 监控盲区开加功率/加信道工单
  × 把 Q 漂移单改标题成「假绿」糊弄
  × 公开材料贴网管 URL / 真实站号
  √ 书面窗 + 真断 + 会响证据 + L3
```

### 5.4 夜班 15 分钟怎么用

1. **3 分钟**：看采集心跳/最近成功拍（脱敏屏）；有超时仍绿 → 记 R-绿。  
2. **4 分钟**：主备角色是否都活；有无脑裂闪烁。  
3. **4 分钟**：本周假绿演练窗是否临近/过期；过期未做 → 交班写「R-演 债」。  
4. **4 分钟**：三联单现象栏禁用「干扰」除非已排除 R；贴纸栏主 R 若适用。

### 5.5 单次假绿演练 40 分钟标准节奏（可复印）

| 分钟 | 动作 |
|------|------|
| 0–5 | 开窗确认：审批、范围、中止、基线拍 |
| 5–10 | 复述期望：超时内响铃或变色 |
| 10–20 | 注入：断书面名单内一路；观察 |
| 20–28 | 记录：响/未响；屏变/未变；副作用 |
| 28–35 | 恢复：回稳态；确认心跳 |
| 35–40 | 关闭：过/失败；R8；脱敏入卡；失败则拒签 |

大范围演练加倍；禁止与真事故窗重叠。

### 5.6 「监控看不见三问」（贴射频班）

1. 采集心跳与最近成功拍正常吗？（R-采 / R-绿）  
2. 主备切换与假绿演练账在吗？（R-备 / R-演）  
3. 若前两问过，再挂 F/H/A–E——**禁止直接加功率**。

### 5.7 与手册15 / 12 交维当日的衔接（指针）

- 交维包：N 的对时/风暴卡 + **R 的采集 HA/演练卡** 齐；缺 R 禁「监控就绪」。  
- 电源倒换交维：K 三联单有，仍要问 R-演 是否覆盖采集侧。  
- 假绿气质拒签：N 规则6 与 R 规则4 同向；**演练剧本与主备账主贴 R**。

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「交维全绿无演练」→ R-演 / R-治

- **现象**：新站交维，网管大屏全绿，签字「监控已就绪」。  
- **排除**：问演练窗与切换验证——皆无。  
- **贴法**：主 R-演，次 R-治。  
- **动作**：拒签；排书面假绿演练；过后再签。  
- **禁令**：禁止用「一直很稳」代替演练账。

### 例 2 · 「采集僵死墙仍绿」→ R-绿

- **现象**：业务侧已发现站异常，墙仍全绿。  
- **排除**：心跳超时；最近成功拍远超本网阈值。  
- **贴法**：主 R-绿；可挂 N-监。  
- **动作**：拒放行；拉起采集；补死人手柄/合成探针气质探测；复测。  
- **禁令**：禁止先开同频干扰单。

### 例 3 · 「双机合影当 HA」→ R-备

- **现象**：验收材料两张采集机照片，无切换记录。  
- **贴法**：R-备。  
- **动作**：安排切换窗；记结果；脑裂检查。  
- **禁令**：禁签「高可用完成」。

### 例 4 · 「看不见就加功率」→ R-治 + 规则2

- **现象**：监控缺口，工单写加功率。  
- **贴法**：R-治。  
- **动作**：撤加功率叙事；走 R 工作流。  
- **禁令**：手册07/09 同步贴。

### 例 5 · 「演练桌面走过场」→ R-演

- **现象**：演练记录写「已桌面推演」，未真断一路。  
- **贴法**：R-演。  
- **动作**：判定演练无效；重做真断；要会响证据。  
- **禁令**：签字代替响铃不算过。

### 例 6 · 「双写脑裂闪绿」→ R-备 规则7

- **现象**：主备同时写，墙状态闪烁，偶发「全绿」。  
- **贴法**：R-备。  
- **动作**：仲裁/去重/单主视图；未治理前禁当 HA。  
- **禁令**：禁止「刷新就好」结案。

### 例 7 · 「倒换窗全静音」→ N + R

- **现象**：油机倒换怕铃，交班全静音；采集异常被盖。  
- **贴法**：次挂 N-治；问 R 是否假绿被静音掩盖。  
- **动作**：禁全静音常态；倒换窗书面抑制项要列清单到期恢复；采集心跳单独盯。  
- **禁令**：静音 ≠ 假绿演练。

### 例 8 · 「漂移单改名假绿」→ Q vs R

- **现象**：抽检对不上，有人把单改成「监控假绿」想走快捷拒签。  
- **贴法**：先分诊；心跳正常则主 Q；采僵则主 R。  
- **动作**：分清结案词；可叠挂不可偷换。  
- **禁令**：禁止标题游戏。

### 例 9 · 「公开报告写网管地址」→ R-治

- **现象**：周报截图含网管 URL 与站名。  
- **贴法**：R-治。  
- **动作**：撤回；L3 重写；追培训。  
- **禁令**：规则8。

### 例 10 · 「铃不响仍签可靠」→ R-演 / R-治

- **现象**：演练断主采，超时内无铃无变色，仍签「监控可靠」。  
- **贴法**：主 R-演，次 R-治。  
- **动作**：演练失败；拒签；修探测后再复演。  
- **禁令**：失败演练不得粉饰。

### 例厚补 · 「半绿半盲」五分钟口诀

> 先看心跳是否假绿（R）→ 再看对时是否漂移（N）→ 再看是否倒换窗（K）→ 末才空口分诊。  
> 任何一步不过，禁加功率叙事。

### 6.5 采集对齐会：20 分钟议程

1. **3 分钟**：本周假绿/采集中断事件条数（L3）。  
2. **5 分钟**：插页 R 抽查——R2/R3/R6 空的单子点名。  
3. **5 分钟**：下一次假绿演练窗排期与范围。
