## 1. 为什么要写这篇手册（动机 + 现场对话）

前十八篇手册教你认病、交维、写频、批量、电源监控、有源隔离、口部泄漏、金机漂移：贴纸 A–E 协议层，F 射频，G 实验室，H 话务，I 室分，J 写频，K 电源，L 井库，M 批量/OTAP，N 监控/对时/风暴，O 有源隔离，P 口部切换，Q 金机漂移。可现场还有一类「病」——**不是告警风暴本身，而是采集链僵死、单路无备、从没故意断过探头证铃会响，值班屏却一直绿**：

- 网管：「大屏全绿，监控已就绪，可以签交维。」——采集进程早僵死，最后一拍还停在「正常」；**假绿**（指针 N，本篇加深 **采集 HA + 演练**）。  
- 班长：「我们有双采集。」——从没做过切换窗验证；主挂了备不接，或双写脑裂互相刷绿。  
- 新人：「假绿演练？那不是故意搞坏吗？」——不故意断一路，就不知道铃会不会响；无演练 = 假绿债。  
- 领导：「监控看不见，肯定是干扰，加功率 / 加信道。」——看不见 ≠ 空口病；加功率是手册07/09 禁区；本篇也禁。  
- 手册15 学过的人：「N 不是已经讲假绿了吗？」——N 管对时/风暴/假绿气质；本篇是 **采集链高可用与假绿演练剧本加深册**，主贴新贴纸 **R**。  
- 手册18 学过的人：「金机漂移 Q 和假绿一样吗？」——**配置漂移 ≠ 采集假绿**；Q 管柜台货漂开，R 管探头僵死仍显绿。  
- 电源同事：「倒换窗铃响是正常的。」——可挂 K；采集侧是否假绿、演练是否做过，**主贴仍 R**。  
- 有人：「断探头演练太吓人，签个字就算了。」——无书面演练窗、无「会响」证据 → 禁签「监控可靠」。

这几句背后是同一件事：

> **「网管采集高可用与假绿演练」这个词在现场至少有五个坑**：  
> **① R-采**：采集链身份与探头——谁采、采什么、心跳/超时  
> **② R-备**：采集高可用——双路/主备、切换窗、脑裂禁令  
> **③ R-绿**：假绿定义与探测——采集僵死仍显绿、静默缺口  
> **④ R-演**：假绿演练剧本——定期断探头/断采集证「会响」、演练窗书面  
> **⑤ R-治**：治理与拒签——无演练禁签交维、假绿拒放行、脱敏 L3  
> 把 ①–⑤ 当成「大屏绿就永远可靠」或「出了事用手册01–05 / 07 分诊」，会把整队假绿债留给下一班。

本篇目标：能背出**网管采集高可用与假绿演练工作流**；会用新贴纸 **R（采集/备/绿/演/治）** 与五个子类；会填 **插页 R（R1–R8）** 和《本网网管采集高可用与假绿演练卡》；能用「**机场塔台双雷达 + 值班屏全绿演练**」故事讲清主备采集与假绿债；能拒绝「无主备就签监控就绪、假绿放行、无演练宣称可靠、用加功率掩盖看不见、把配置漂移当采集假绿」；自测过关后，回库把本网最近一次采集中断/假绿/演练事件（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：不发明 ETSI 条款号；**不写真实批复频点、楼名、站号、个号、密钥、单位名、网管地址进公开仓库**；**不教攻击/仿冒/破解/空口劫持**——只讲制度与治理；不重写手册15 / 12 / 06 / 08 / 18 全文（只给指针）；**N/K/G/Q 仍生效，本篇加深采集 HA + 假绿演练**；**不把加功率/加信道当「监控看不见」止痛药**；采集与假绿**主贴 R**，可挂 N/K/G/Q；结案用 R + 本网证据；公开 NMS/HA/混沌演练资料只借**精神与顺序**——**不背条款当 ETSI、不背厂商菜单当制度、不把蜂窝 KPI / IT 工具名抄进 DMR 公开包当法规**。

## 2. 总图 / 故事：采集像「机场塔台双雷达 + 值班屏全绿演练」

### 2.1 一句话：必须先证明采集链心跳非假绿、主备切换可验证、假绿演练书面会响，再谈「监控已就绪」——否则值班屏全绿、探头早僵、交维假绿债

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  机场塔台（本网网管值班室 · 采集柜）                         │
   │                                                              │
   │   主雷达 = 主采集（R-采 / R-备）——有身份、心跳、超时          │
   │   备雷达 = 备采集（R-备）——切换窗可证；禁脑裂双写未治理       │
   │   值班屏 = 网管大屏 ——一直绿 ≠ 探头活着                      │
   │   故意断一路 = 假绿演练（R-演）——证铃会响、屏会变             │
   │   拒签台 = 交维拒签（R-治）——无演练签字 = 假绿债              │
   │                                                              │
   │   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐     │
   │   │ 核采集  │──▶│ 证主备  │──▶│ 定义假绿│──▶│ 演练会响│     │
   │   │ (R-采)  │   │ (R-备)  │   │ (R-绿)  │   │ (R-演)  │     │
   │   └────┬────┘   └────┬────┘   └────▲────┘   └────┬────┘     │
   │        │             │             │              │           │
   │        │无身份禁签   │无切换禁HA   │僵死仍绿拒签  │无窗禁签  │
   │        ▼             ▼             │              ▼           │
   │   ┌─────────┐   ┌─────────┐       │         ┌─────────┐     │
   │   │ 心跳超时│   │ 脑裂禁令│───────┘         │ 拒签交维│     │
   │   │ (R-采)  │   │ (R-备)  │                 │ (R-治)  │     │
   │   └─────────┘   └─────────┘                 └────┬────┘     │
   │        ▲                                          │           │
   │   禁加功率/加信道掩盖「监控看不见」→ 治理（R-治）◀───────────┘ │
   │   禁：大屏绿当可靠；无演练签交维；双写未治理当 HA 完成         │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **先核探头身份，再证主备切换，后定义假绿，末上演练证会响。**  
> 值班屏一直绿还说监控可靠 = 塔台雷达早停转、屏却假装没事——**假绿债。**  
> 有双路从不切 = 备雷达落灰——**有备 ≠ 高可用。**

### 2.2 「塔台双雷达」五段直觉（弱项短补，钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **采集身份** | 主雷达编号与扫区 | 谁采、采什么对象、心跳/超时；探头清单书面 | R-采 |
| **采集高可用** | 主备双雷达 + 切换窗 | 双路/主备；切换可测；脑裂双写禁当完成 | R-备 |
| **假绿定义** | 屏全绿但雷达停转 | 僵死/断链仍显绿；静默缺口；死人手柄气质 | R-绿 |
| **假绿演练** | 故意断一路证铃响 | 定期断探头/断采集；书面窗；证「会响」 | R-演 |
| **治理拒签** | 无演练拒签放飞 | 无演练禁签交维；假绿拒放行；脱敏 L3 | R-治 |

> 公开可观测性常识（如双采集器故障切换、Prometheus/Thanos HA 去重、混沌 Game Day、死人手柄/合成探测精神）：**采集要可冗余、静默失败要被发现、演练要有书面窗与中止条件**。本篇只借**顺序直觉**：核身份 → 证主备 → 定义假绿 → 演练会响 → 拒签治理。**不背工具名当 ETSI / 不背厂商网管菜单当本网制度 / 不把 IT 混沌实验剧本原文抄进 DMR 公开包当法规。**

### 2.4 新贴纸 R：采集 / 备 / 绿 / 演 / 治（五个子类）

```text
                    ┌──────── 贴纸 R · 采集/备/绿/演/治 ────────┐
                    │  R-采  采集链身份与探头：谁采·采什么·心跳/超时           │
                    │  R-备  采集高可用：双路/主备·切换窗·脑裂禁令             │
                    │  R-绿  假绿定义与探测：采集僵死仍显绿·静默缺口           │
                    │  R-演  假绿演练剧本：定期断探头/断采集证会响·书面窗       │
                    │  R-治  治理与拒签：无演练禁签交维·假绿拒放行·脱敏 L3     │
                    └──────────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签 / 拒放行触发 |
|------|--------|----------------------|
| **R-采** | 采集无身份/无心跳超时定义 → 禁签监控就绪 | 「大屏在绿」但说不清谁在采 |
| **R-备** | 无主备或无切换验证 / 脑裂未治理 → 禁当 HA | 「有两台采集机」从没切过 |
| **R-绿** | 僵死仍绿 / 静默缺口未探测 → 假绿拒签 | 进程死了墙仍全绿 |
| **R-演** | 假绿演练未做或无书面窗 → 禁签交维 | 「太吓人不做演练」仍宣称可靠 |
| **R-治** | 假绿放行；加功率掩盖看不见；泄密 | 「先上勤再慢慢看监控」 |

### 2.5 采集高可用与假绿演练最小工作流（背下来）

```text
  要签「监控已就绪」/ 交维 / 宣称可靠
        │
        ▼
  采集链身份清楚？心跳/超时书面？──否──▶ 拒签（R-采 / 规则1）
        │是
        ▼
  主备存在且切换窗验证过？脑裂已治？──否──▶ 禁签 HA / 禁「监控就绪」（R-备 / 规则3、7）
        │是
        ▼
  假绿探测存在？（僵死会变色/会响）──否──▶ 假绿拒签（R-绿 / 规则4）
        │是
        ▼
  假绿演练书面窗做过且「会响」有证？──否──▶ 禁签交维（R-演 / 规则5）
        │是
        ▼
  结案 + 脱敏 L3；主贴 R；可挂 N/K/G/Q
  禁加功率/加信道掩盖「看不见」；禁大屏绿代替演练账
```

现场口诀：

> **先身份，再主备，后假绿，末演练。**  
> 跳过演练的「全绿交维」= 塔台从没试过断雷达，却说双雷达可靠。

## 3. 核心交付：插页 R + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 R（而不是先贴 N / K / Q / G）

| 现场信号 | 主贴 | 可次挂 |
|----------|------|--------|
| 交维要签「监控已就绪」 | **R**（采集 HA + 演练） | N（对时/风暴气质） |
| 大屏全绿但怀疑采集僵死 | **R-绿** | N-监 |
| 双采集从没切过 / 疑脑裂 | **R-备** | — |
| 假绿演练窗 / 故意断探头 | **R-演** | N；物理倒换可挂 K |
| 倒换窗铃响像风暴 | 可挂 **N**；采集侧是否假绿仍问 **R** | K |
| 抽检对不上但采集也绿 | **Q** 与 **R** 分清：漂是 Q，采僵是 R | N |
| 「看不见就加功率」 | **R-治** + 禁令 | F/H（排除后） |

> **口诀**：对时/风暴/假绿气质走 **N**；电源倒换物理走 **K**；配置漂移走 **Q**；**采集链身份、主备、假绿探测、演练剧本走 R**。可叠挂，采集 HA 与假绿演练**主贴 R**。

### 3.2 插页 R · 采集 / 备 / 绿 / 演 / 治（挂在总三联单或网管交班首页后）

| 行 | 名称 | 填写示例（教学虚构） |
|----|------|----------------------|
| **R1** | 主子类 + 次子类 | 「主 R-演 / 次 R-备」（或 R-采 / R-绿 / R-治） |
| **R2** | 采集身份 | 「主采角色标签 A；对象清单版本（脱敏）；心跳周期/超时阈值」（禁真实网管地址） |
| **R3** | 主备与切换 | 「主/备角色；最近切换窗验证日期；切换结果过/失败；脑裂治理勾选」 |
| **R4** | 假绿定义 | 「僵死判据：心跳超时仍绿；静默缺口时长；死人手柄/合成探针气质（教学层）」 |
| **R5** | 假绿探测 | 「探针名（脱敏）；期望变色/响铃行为；最近探测结果」 |
| **R6** | 演练窗 | 「书面窗起止；审批人（脱敏角色）；中止条件；影响范围（对象清单子集）」 |
| **R7** | 演练动作与证据 | 「断哪路（主/备/探针）；铃是否响；屏是否变；恢复步骤；录像/日志指针（L3）」 |
| **R8** | 判定与动作 | 「可签交维 / 带条件（缩短复演）/ 拒签；脱敏 L3」 |

> **R2 与 R4 不过 → 禁止以「监控已就绪」名义签字。**  
> **R3 若宣称 HA 但切换验证空 → 禁止签 HA 完成（规则3、7）。**  
> **R6/R7 若交维要求监控可靠但为空 → 禁止签交维（规则5）。**  
> **R8 若写「加功率/加信道试试」或「大屏绿就算了」→ 本页作废重填。**

### 3.3 「假绿拒签 / 无演练禁签交维」卡（贴网管 / NOC / 交维台）

```text
  ┌────────────── 采集HA与假绿演练拒签卡（贴纸 R）──────────────┐
  │  × 说不清谁采、采什么、心跳/超时就把大屏当可靠                │
  │  × 无主备或无切换窗验证就签「监控高可用 / 已就绪」            │
  │  × 双采集脑裂/双写未治理仍当 HA 完成                          │
  │  × 采集僵死/断链墙仍全绿却放行（假绿）                        │
  │  × 假绿演练未做或无书面窗就签交维 / 宣称监控可靠              │
  │  × 用加功率 / 加信道掩盖「监控看不见」                        │
  │  × 把配置漂移（Q）和采集假绿（R）混成一锅结案                │
  │  × 用「值班屏一直绿」代替演练账与切换验证                    │
  │  × 公开包出现真实频点 / 个号 / 密钥 / 站名 / 网管地址 / 单位名│
  │  √ 例外：书面窗、原因、审批、到期复演——写进 R6/R8             │
  └────────────────────────────────────────────────────────────┘
```

### 3.4 和总三联单怎么写（接手册06）

- **现象**：写「采集心跳超时墙仍绿」或「演练断主采铃未响」，不要写「干扰」除非已排除 R。  
- **证据**：采集角色标签（脱敏）、对象清单版本、切换验证日期、演练窗、响铃/变色相对描述；禁真实网管 IP/URL。  
- **时钟**：若与手册15 风暴同时，写清三钟差；漂移大则禁秒级因果（指针 N-时）。  
- **贴纸栏**：主 **R-? **，次挂 N/K/G/Q（若有）。  
- **结案词**：用 R 子类 + 动作（复演/修复采集/拒签），禁用「加功率好了」「大屏绿了就算」。
