## 1. 为什么要写这篇手册（动机 + 现场对话）

前六十七篇手册从 A–E 协议一路写到 BN 冷凝器盘管清洗与翅片完好：其中 **AF 回答「油机市电切换与机房供电巡检」**（周检/本体清单的 AF-油角色会写到燃油/机油/冷却/电瓶，但**周检写到机油 ≠ 本篇台账**，也没有单独给机油液位和机油压力/油温保护各钉一张巡检台账），**BI 回答「日用/储油罐油位与泄漏」**（日用油箱、储油罐里的柴油不是机油，**燃油油位/泄漏过 ≠ 机油液位/保护过**），**BL 回答「冷却液液位与高温/低水位保护」**（散热器里的缸套水不是曲轴箱里的机油，**冷却液液位/保护过 ≠ 机油液位/油压油温保护过**），**AV 回答「日用油箱油品净化与加油交接」**（加的、净的是燃油，不是润滑机油），**AR 回答「柴油发电机房通风排烟与燃油安全巡检边界」**（燃油安全窗里可能顺带提到机油，但没有单独给机油液位和油压/油温保护各钉一张巡检台账），**AO 回答「漏水与接地汇流排」**（地面积水探头 OK 不是本篇机油窗）。可还没有单独钉死一件事——**机房不是「油尺看着有油、油压灯绿、油温灯绿、周检写到机油，就等于机油路径过关」**。这就是本篇的 **BO**：机油液位要有台账与本期对照；机油压力保护与油温保护要各有主人、有窗、有方法、有准用期；两边边界方法要钉死；本组本机房本期要实测，禁套邻站表——能不能签「机房柴油发电机机油液位与机油压力/油温保护巡检准用」？

**五个词必须先分清，再往下读（本篇反复钉）**：

| 中文词 | 英文 | 作用 | 本系列谁管 | 不等于 |
|--------|------|------|------------|--------|
| **机油** | motor oil / engine lubricating oil | 在曲轴箱、油底壳、油道里循环、润滑并带走摩擦热量的液体路径 | **BO-位**（本篇）管液位；保护窗 **BO-护** | **≠ 日用油箱/储油罐里的柴油**；**≠ 散热器里的缸套水**；**看着有油 ≠ 机油液位台账过**；**BI≠BO**；**BL≠BO** |
| **机油液位** | engine oil level | 油尺和/或观察窗上的液位窗与本期对照（冷态/静置核对角色以本网与 OEM 书面为准） | **BO-位**（本篇） | **油尺看着有油 ≠ 台账过**；**口头说加过机油 ≠ 方法过**；**液位过 ≠ 保护窗过** |
| **机油压力保护** | oil pressure protection | 机油压力低报警/停机保护窗；有主有方法有准用期 | **BO-护**（本篇，油压侧） | **油压灯绿 / 表看着在绿区 ≠ 窗过**；**油压保护过 ≠ 油温保护过** |
| **油温保护** | oil temperature protection | 机油温度高报警/停机保护窗；与油压侧分开看 | **BO-护**（本篇，油温侧） | **油温灯绿 / 表看着在绿区 ≠ 窗过**；**油温保护过 ≠ 油压保护过** |
| **冷却液 / 燃油油位** | coolant / fuel level | 缸套水路归 **BL**；日用/储油罐燃油油位与泄漏归 **BI** | **BL** / **BI** | **≠ BO**；冷却液过 ≠ 机油过；燃油油位过 ≠ 机油过 |

### 2.3 和手册33（AF）/ 62（BI）/ 65（BL）/ 49（AV）/ 45（AR）/ 42（AO）/ 15（N）等的咬合（指针，不重写）

- **BI（手册62）**：日用/储油罐燃油油位与泄漏，**没有**单独给机油液位 + 机油压力/油温保护一张巡检台账；**BI ≠ BO**——燃油油位/泄漏过 ≠ 机油液位/保护过；柴油不是机油；燃油路径可挂 BI，机油主贴仍 BO；**不得互相顶替**；**不重写 BI 全文**。
- **BL（手册65）**：冷却液液位与高温/低水位保护；**BL ≠ BO**——冷却液液位/保护过 ≠ 机油液位/油压油温保护过；缸套水不是机油；冷却液可挂 BL，机油主贴仍 BO；**不重写 BL 全文**。两路液体都在同一台机组上，但不是同一张台账。

- **AR（手册45）**：通风排烟与燃油**安全**巡检；**AR ≠ BO**——燃油安全过 ≠ 机油液位/保护过；可挂 AR，机油主贴仍 BO；**不重写 AR 全文**。进风排烟乱可能影响散热与油温，但 AR 签的不是本台账。
- **AO（手册42）**：漏**水**探测与汇流排；**AO ≠ BO**——漏水探头 OK ≠ 机油液位/保护过；地面积水可挂 AO，机油路径主贴仍 BO。机油外漏落到地面，积液现象可回 AO 或其他泄漏路径，液位与保护台账仍回 BO。
- **AN / AL / AD / AA / AQ**：门禁过 ≠ 交底过；气灭过 ≠ 交底过；入库走 AD，**不能**用旧 AD 签顶本期 BO 窗；首年抽检可挂 AA；调录像另开 AQ（视频过 ≠ BO 准用）；**不教绕过门禁/保护联锁**。
- **N（手册15）**：机油液位异常/油压或油温告警风暴挂 N，**不先抬功率**；**禁绕联锁、禁旁通、禁不安全泄放机油教条、禁热机开盖开塞教条**；N 绿 ≠ BO 过。

## 3. 核心交付：插页 BO + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 BO（而不是先贴 AF / BI / BL / AV / AR / AO / N）

- 要签「机房柴油发电机机油液位与机油压力/油温保护巡检准用」、要开机油液位交底窗、要交底机油压力/油温保护侧 → **主贴 BO**。  
- 油机市电切换与供电巡检 → **AF**（周检写到机油 ≠ 本篇台账）。日用/储油罐燃油油位与泄漏 → **BI**。冷却液液位与高温/低水位保护 → **BL**。燃油油品净化加油 → **AV**。通风排烟与燃油安全 → **AR**。漏水汇排 → **AO**。**AF ≠ BO；BI ≠ BO；BL ≠ BO；AV ≠ BO；AR ≠ BO；AO ≠ BO**。  
- 进机房先 **AN**（门禁过 ≠ 交底过）。气灭 → **AL**。风暴先 **N**，缺秩序整改仍 **BO**；切换、燃油油位、冷却液、油品、燃油安全、地面积水分问 AF/BI/BL/AV/AR/AO；**禁功率战、绕联锁、旁通、不安全泄放机油教条、热机开盖开塞教条**。  
- 假绿/顶替挂 **R**；变更走 **J** 后再验 BO。  
- 无柴油发电机，或无机油液位/机油压力/油温保护路径 → 书面「不适用」；**不得**用 BO 顶 AF/BI/BL/AV/AR，也不得用它们顶 BO。液位侧不适用 ≠ 保护侧自动免；油压窗不适用 ≠ 油温窗自动免；AF/BI/BL 过了或它们不适用 ≠ 机油路径自动免。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **机油液位台账钉死**：机组、油尺或观察窗或油底壳角色与液位窗、本期对照各自有账（编号脱敏）；禁「看着有油就算过」「油尺看着有油就算过」「口头说加过机油」；液位过 ≠ 保护过，保护过 ≠ 液位过。  
2. **机油压力/油温保护侧有主有窗有方法·准用期**：油压侧与油温侧分开看；测点、动作（报警/停机）、合格窗与准用期以本网与 OEM 书面为准；每次保护交底有主人角色、有书面窗、有方法、有准用期；禁「油压灯绿就算过」「油温灯绿就算过」「表看着在绿区就算过」「套邻站保护照片」；油压保护过 ≠ 油温保护过。  
3. **边界窗与方法钉死**：书面固定；方法含与 AF/BI/BL/AV/AR/AO/N 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明换油放油步骤、泄放步骤、绕联锁操作或热机开盖开塞步骤教条；**不重写 AF/BI/BL/AV/AR/AO 全文**）；禁「窗再说」「绕机油压力/油温等保护联锁」「开旁通冒充」「不安全泄放机油教条」「热机开盖开塞教条」「伪造台账」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、机油液位对照、油压侧与油温侧保护必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「机房柴油发电机机油液位与机油压力/油温保护巡检准用」；假绿 ≠ 放行。  
6. **禁顶替 AF/BI/BL/AV/AR/AO/AD/AA/N/AQ 等，主贴 BO，假绿≠放行挂 R**：他贴签都不顶本期机油液位/保护签。**尤其 AF ≠ BO、BI ≠ BO、BL ≠ BO、AV ≠ BO、AR ≠ BO、AO ≠ BO。** 油机市电过 ≠ 机油过（周检写到机油 ≠ 本篇台账）；燃油油位/泄漏过 ≠ 机油过（柴油不是机油）；冷却液液位/保护过 ≠ 机油过（缸套水不是机油）；燃油油品/加油过 ≠ 机油过；燃油安全过 ≠ 机油过；漏水探头过 ≠ 本窗。看着有油/油尺看着有油 ≠ 台账过；灯绿/表绿 ≠ 窗过；口头加过机油 ≠ 方法过；液位过 ≠ 保护窗过；油压保护过 ≠ 油温保护过。
7. **机油液位异常/油压或油温告警风暴挂 N，边界/门限/窗变更走 J；禁功率战；禁绕机油压力/油温等保护联锁；禁旁通；禁不安全泄放机油教条；禁热机开盖开塞教条；禁伪造台账**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。机油/保护乱窗、假绿、油压或油温告警常被误当「覆盖病」→**禁功率战**；挂 N；变更走 J。机油/保护失序不是覆盖病。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/油机或发动机序列号全文/可还原坐标与联系人；禁公开传播未脱敏机油门限与保护参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签机油液位/保护准用、无实测冒充边界过、绕联锁/旁通/不安全泄放机油/热机开盖开塞冒充秩序齐，不是法外运维智慧**。医院/数据中心公开资料只作故事类比（§10），翻译成本网语言就是 BO-位 / BO-护 / BO-界 / BO-验 / BO-治。

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机房柴油发电机机油液位与机油压力/油温保护巡检准用」、对外宣传「看着有油/油尺看着有油/灯绿/表绿/口头加过机油秒过」、把未实测写成已过、把绕联锁/旁通/不安全泄放机油/热机开盖开塞写成秩序齐。允许做的：补机油液位台账、补保护窗、重开边界窗、挂 R/N/J、内部挂整改。

### 5.5 与弱项的现场对照（再钉一次）

机油乱账、保护乱窗、假绿、油压/油温告警风暴，常先伤站点保供电与**上行**体验——机组在最需要时因油压保护或油温保护停下来，站点环境先乱。有人把这些当「覆盖病」抬功率——**禁功率战**。机油/保护失序不是覆盖病。先问 BO 秩序并分诊 AF/BI/BL/AV/AR/AO，风暴挂 N，变更走 J。弱项短补：**12.5 kHz / 4FSK / 2-slot TDMA**。

## 6. 工作实例（12 则，教学虚构，L3）

1. **看着有油 / 油尺看着有油 / 口头加过机油想签准用**：称曲轴箱里看得见油、油尺有油、班长说加过机油要签 → 查 BO1 无本期机油液位对照 → **拒签**；补 BO-位。  
2. **油压灯绿 / 油温灯绿 / 表看着在绿区 / 套邻站保护照片**：称「灯是绿的 / 表在绿区 / 邻站照片差不多」免窗页 → **拒签**；补 BO-护。  
3. **AF 顶替 BO**：称油机市电切换刚过，或周检单上机油打了勾，本篇台账免 → **拒签**；**油机市电过 ≠ 机油液位/保护过**；**AF 周检写到机油 ≠ 本篇台账**。  
4. **BI 顶替 BO**：用燃油油位/泄漏签顶本期机油液位/保护签 → **挂 R**；**燃油油位/泄漏过 ≠ 机油液位/油压油温保护过**；柴油不是机油。  
5. **BL 顶替 BO**：称冷却液液位和高温低水位保护刚过，机油免做 → **挂 R**；**冷却液液位/保护过 ≠ 机油液位/油压油温保护过**；缸套水不是机油。  
6. **AV / AR 顶替 BO**：称燃油油品净化和加油交接刚过，或通风排烟燃油安全刚过，机油窗免 → **挂 R**；**燃油油品净化/加油过 ≠ 机油过**；**通风排烟燃油安全过 ≠ 机油液位/保护过**。  
7. **AO 顶替 / N 绿免实测**：称漏水探头绿或大屏监控绿，本期实测免 → **拒签**；漏水探头过 ≠ 机油液位/保护过；N绿≠BO过；补 BO-验。  
8. **油压顶油温 / 油温顶油压**：称油压保护测过了，油温照抄，或反之 → **拒签**；**油压保护过 ≠ 油温保护过**；两侧分开实测。  
9. **液位顶保护**：称机油液位签过了，保护窗免做 → **拒签**；**液位过 ≠ 保护窗过**。  
10. **套邻站表**：拷邻站机油液位/保护表改机房号 → **BO-验 拒签重测**。  
11. **功率战 / 不安全泄放机油 / 热机开盖开塞 / 绕联锁 / 旁通**：油压或油温告警要抬功率，或放一点机油消告警、还烫着拧加注口或滤清器或放油塞、绕保护、开旁通后要求准用 → **禁功率战**；**禁不安全泄放机油教条**；**禁热机开盖开塞教条**；**禁绕联锁**；**禁旁通**；先挂 N/R；缺秩序整改贴 BO；禁签。  
12. **无油机路径乱签 / 泄密**：本站无柴油发电机或无机油液位/机油压力/油温保护路径却不写「不适用」乱签准用，或公开群贴真实油机、发动机序列号与机油门限 → **拒签**并/或补书面不适用并/或 **L3 违规**；液位侧不适用 ≠ 保护侧自动免；油压窗不适用 ≠ 油温窗自动免；AF/BI/BL 过了或它们不适用 ≠ 机油路径自动免。

## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 本篇用法（教学） |
|------|------------------|
| **机油** | motor oil / engine lubricating oil：在曲轴箱、油底壳、油道里循环润滑并带走摩擦热的液体路径；**≠ 日用油箱/储油罐里的柴油**；**≠ 散热器里的缸套水**；**看着有油 ≠ 机油液位台账过** |
| **机油液位** | engine oil level：油尺和/或观察窗的液位窗与本期对照；**BO-位**；**油尺看着有油 ≠ 台账过**；**口头加过机油 ≠ 方法过**；**液位过 ≠ 保护窗过** |
| **油尺 / 观察窗 / 油底壳** | dipstick / sight glass / oil pan（湿式油底壳常见）：液位观测常落在这些角色上；具体以本网与 OEM 书面为准；**禁热机开盖开塞** |
| **机油压力保护** | oil pressure protection：机油压力低报警/停机窗；**BO-护**（油压侧）；**油压灯绿/表绿 ≠ 窗过**；**油压保护过 ≠ 油温保护过** |
| **油温保护** | oil temperature protection：机油温度高报警/停机窗；**BO-护**（油温侧）；一侧过 ≠ 另一侧过 |
| **机油泵 / 泄压阀** | oil pump / relief valve：公开资料借「油压有形成与限压角色」；门限与方法只认本网与 OEM 书面；本篇不写拆泵或调阀教条 |
| **燃油油位 / 泄漏** | 归 **BI**；**燃油油位/泄漏过 ≠ 机油液位/保护过**；柴油不是机油 |
| **冷却液液位 / 高温低水位保护** | 归 **BL**；**冷却液过 ≠ 机油过**；缸套水不是机油 |
| **油机市电切换** | 归 **AF**；**切换过 ≠ 机油台账过**；**AF 周检写到机油 ≠ 本篇台账** |
| **燃油油品净化加油 / 通风排烟燃油安全 / 漏水探测** | 分归 **AV / AR / AO**；三者过都不等于机油液位/保护过 |
| **假绿** | 无实测/无会签却显示通过；挂 R；≠ 放行 |
| **套票** | 套他站他期机油液位/保护表；BO-验 拒签 |
| **不安全泄放机油教条** | 用放掉机油去消告警或冒充窗过；**本篇硬禁**；具体补油/处置只认本网与 OEM 书面窗 |
| **热机开盖开塞教条** | 本篇简称，一律指机组仍热或系统仍带压时乱开**加注口、滤清器或油底壳放油塞**；公开资料强调有烫伤与喷溅风险；**本篇硬禁** |
| **开旁通冒充 / 绕机油压力/油温联锁** | 靠旁通或绕保护让表看起来绿；**本篇硬禁** |
| **功率战** | 用抬功率压油压/油温告警；**禁**；先挂 N；机油/保护失序不是覆盖病 |
| **贴纸 BO / AF≠BO / BI≠BO / BL≠BO / 脱敏 L3** | 本篇主贴；位/护/界/验/治五子类；油机市电 ≠ BO；燃油油位泄漏 ≠ BO；冷却液 ≠ BO；燃油油品 ≠ BO；燃油安全 ≠ BO；漏水探头 ≠ 本窗；禁真实站名/机房全称/油机或发动机序列号全文/联系人 |

**易错观念（纠一次）**  
- 「看着有油 / 油尺看着有油 / 口头加过机油 = 准用」→ 错；要 BO-位台账 + 本期实测。  
- 「油压灯绿 / 油温灯绿 / 表看着在绿区 = 窗过」→ 错；要 BO-护 主人窗方法。  
- 「AF / BI / BL / AV / AR / AO 过 = BO 过」→ 错；油机市电/周检写到 ≠ 本篇台账；燃油油位/泄漏 ≠ 机油；冷却液 ≠ 机油；燃油油品/加油 ≠ 机油；燃油安全 ≠ 机油；漏水探头 ≠ 本窗。  
- 「液位过 = 保护过」「油压过 = 油温过」→ 错；分账分验。  
- 「N 绿 = 本期实测过」→ 错；风暴绿 ≠ 交底准用。  
- 「放一点机油消告警 / 还烫着开盖开塞 = 办法」「抬功率压告警 = 救急」「旁通 / 绕联锁 = 赶工」→ 错；硬禁；禁功率战。  
- 「没有柴油机或没有机油路径就整篇乱签或口头免；AF/BI/BL 过了或它们不适用就自动免机油」→ 错；书面勾「不适用」；不得用 BO 顶 AF/BI/BL/AV/AR，也不得用它们顶 BO；液位侧不适用 ≠ 保护侧自动免；油压窗不适用 ≠ 油温窗自动免。
