> **频谱 / 调制提醒（弱项短补）**：一条 DMR 信道占 **12.5 kHz**；**4FSK** 装货；**2-slot TDMA** 把时间切成 **30 ms** 一格、两格一轮 **60 ms**。电源与倒换**不改变**这些物理台阶——它只是让「基站这台 ICU 监护仪」有没有电、有没有干净的电、倒换时会不会抖一下。若有人把「加功率」当电源闪断补丁，或把倒换窗口的短时登记失败/Grant 无声说成「协议玄学」，先回 `学习推送/加餐_频率带宽与调制解调.md`，再挂本篇贴纸 **K**，而不是先拧射频旋钮。

## 1. 为什么要写这篇手册（动机 + 现场对话）

前十一篇手册教你认病与交维：贴纸 A–E 协议层，F 射频层，G 实验室闭环，H 话务，I 室分/隧道，J 写频/基线。可现场还有一类「病」——**不是空口今天才坏，而是电源链在抖、倒换剧本没演过、告警铃被掐哑**：

- 夜班：「市电闪了一下，全站登记刷屏，过两分钟又好了。」——有人立刻挂手册01；没人先看整流/蓄电池是否在撑，ATS 有没有抖。  
- 班长：「油机不是有吗？怎么站还掉？」——油机燃油低位、启动电池虚接、自启未测；市电掉了三分钟才有人发现油机没转。  
- 施工队：「交维测过交流电压 220 了，可以签。」——没做「市电→后备→回切」剧本；ATS 粘连、回切失败、UPS 拒收油机，全是签字后的雷。  
- 网管：「告警太多，先静音。」——电池低压、整流模块退出、油机未备妥被静音；真正停电那晚铃不响。  
- 射频同事：「肯定是同频干扰，BER 跳了。」——倒换瞬间直流母线晃了一下，基站复位/锁相抖；手册07 的 F 气质有，**主因却是 K**。  
- 话务同事：「忙时掉话，要加信道。」——其实是欠压导致远端站间歇掉、容量账假坏；手册09 气质有，**主贴仍是 K**。  
- 新人：「那不就是假覆盖假干扰吗？」——对，症状可以挂 F/H/A/B，但**电源交维要的是倒换证据与边界责任**，不是事后空口分诊叙事。

这几句背后是同一件事：

> **「基站电源」这个词在现场至少有五个坑**：  
> **① K-市**：市电入口、整流模块、交流质量——闪断、缺相、整流 N+1 失效却无人知  
> **② K-备**：蓄电池 / UPS / 油机——老化、续航虚标、燃油/启动失败、UPS 与油机不兼容  
> **③ K-切**：ATS / 倒换与回切剧本——未演练、粘连、回切失败、倒换窗口制造「假空口病」  
> **④ K-告**：监控与告警——静音、阈值乱改、告警到不了值班、对时错导致三联单对不上  
> **⑤ K-交**：交维边界——谁管市电进户、谁管油机、谁管直流屏、谁签倒换剧本；签了等于签了一份说不清的生命支持链  
> 把 ①–⑤ 当成「掉电再慢慢查」或「先用手册07/09 分诊」，会把整站电源债留给下一班，并污染空口病历。

本篇目标：能背出**基站电源与后备切换交维工作流**；会用新贴纸 **K（电源/后备）** 与五个子类；会填 **插页 K（R1–R8）** 和《本网基站电源与后备切换交维卡》；能用「**医院 ICU + 备用发电机**」故事讲清市电/整流/电池/UPS/油机/ATS；能拒绝「只测电压不测倒换、告警静音、加功率掩盖闪断假干扰」；自测过关后，回库把本网最近一次电源/倒换相关事件（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：不发明 ETSI 条款号；**不写真实批复频点、真实站号、真实个号、真实密钥、真实单位名进公开仓库**；不重写手册07 / 08 / 09 / 10 / 11 全文（只给指针）；**不把「加功率」当电源闪断/欠压引起的假干扰补丁**；倒换窗口的短时登记失败/Grant 无声可**挂**手册01/02 气质，但**主贴 K**，禁止把电源病写成协议玄学；结案词用贴纸 K + 本网证据；公开电源工程常识可对齐 NFPA 110 / 电信 −48 V 直流厂实践的**精神**——**不背标准条款号当 ETSI**。

## 2. 总图 / 故事：基站像「医院 ICU + 备用发电机」

### 2.1 一句话：交维 = 先证明「日常供氧、短暂呼吸机、备用发电机、护士站铃、交接班清单」都过关，再签字

```text
   │   │ (K-市)  │   │ (K-市)  │   │ ±电池浮充│   │ (业务)  │     │

   │   │ (K-切)  │   │ (K-备)  │  回切也要剧本          │           │
   │   └─────────┘   └─────────┘                       │           │
   │        ▲                                          ▼           │
```

口诀：

> **日常靠市电整流；闪断靠电池/UPS；长停靠油机+ATS；铃不能不响；签字前必须演一遍倒换。**  
> 只测「有 220 V」就签字 = 只量体温就说 ICU 交接完成。  
> 倒换瞬间空口抖一下 = 换呼吸机管子时监护仪波形晃一下——**先查管子，别先改病人药方（加功率）**。

### 2.2 「生命支持链」五段直觉（弱项短补，钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **市电 + 整流** | 医院日常供氧管道 | 交流质量、缺相、整流 N+1、直流母线是否由整流扛着 | K-市 |
| **蓄电池 / UPS** | 短暂呼吸机 / 桥接秒级到分钟级 | 续航、老化、浮充、UPS 是否拒收油机 | K-备 |
| **油机 + ATS** | 备用发电机 + 自动阀门 | 自启、燃油、启动电池、稳定后才倒换、回切冷却 | K-切 / K-备 |
| **告警监控** | 护士站铃 | 低压/整流退出/油机未备妥必须到人；禁长期静音 | K-告 |
| **交维边界** | 交接班清单 | 谁管进户、谁管油机、谁签剧本、备件与巡检周期 | K-交 |

> 公开工程常识（电信站常见 **−48 V** 直流厂、整流浮充电池、ATS 监压后切油机、双转换 UPS 桥接等）：本篇只借**顺序直觉**——市电掉 → 电池/UPS 先撑 → 油机起来且电压频率合格 → ATS 切过去 → 市电稳后再回切。**不背 NFPA/IEEE/ITU 条款号当 ETSI**。

### 2.4 新贴纸 K：电源 / 后备（五个子类）

```text
                    ┌──────── 贴纸 K · 电源/后备 ────────┐
                    │  K-市  市电入口 / 整流 / 交流质量     │
                    │  K-备  蓄电池·UPS·油机后备           │
                    │  K-切  ATS 倒换 / 回切剧本           │
                    │  K-告  告警监控 / 禁长期静音         │
                    │  K-交  交维边界 / 签字责任           │
                    └────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签 / 拒放行触发 |
|------|--------|----------------------|
| **K-市** | 市电与整流能扛日常负载；闪断有记录可查 | 只报「有电」无整流状态；缺相/模块退出未闭环 |
| **K-备** | 电池/UPS/油机续航与自启可证明 | 燃油不足仍签；电池从未做放电抽检；UPS 未与油机联调 |
| **K-切** | 交维必须演「市电→后备→回切」 | 只测电压不测倒换；ATS 粘连未发现；回切失败无记录 |
| **K-告** | 关键告警到人；禁止长期静音当「消缺」 | 低压告警被静音；告警对时错；值班收不到 |
| **K-交** | 市电/油机/直流屏/基线谁管写清 | 「电源归物业」口头一句；备件与巡检周期空 |

**和贴纸 A–J / X 的咬合**：

- 电源链异常期间**优先 K**；空口症状可挂 A/B/F/H，但结案词须写清「主贴 K + 次挂××」。  
- 实验室/金机验证挂 **G/J**；室分远端电源挂 **I** 边界问句 + 本篇 K。  
- 贴纸 **X**：只有「好像闪过电」的口述、无 ATS/油机/直流曲线与倒换记录时，先 X，**禁止结案为干扰/容量/终端玄学**。

### 2.5 电源交维最小工作流（背下来）

```text
  ① 开交维/检修单（K-交）：范围、站型、谁签字、窗口、影响范围（脱敏）
  ② 读现状（K-市/K-备/K-告）：市电、整流模块、母线电压、电池状态、告警清单、油机燃油/启动电池
  ③ 禁令检查：关键告警是否被静音？无倒换剧本是否还想签字？→ 停
  ④ 演剧本（K-切）：市电模拟失电或许可窗口下切后备 → 观察母线/基站业务 → 回切市电
  ⑤ 业务抽检（调用 G 气质）：金机登记/Grant有声/上下行；倒换窗症状记为 K，不先写协议玄学
  ⑥ 证据包：插页 K、倒换时序、告警截屏（脱敏）、拒签或放行结论
  ⑦ 过 → 更新交维卡与巡检周期；不过 → 拒签/关窗；禁止用加功率掩盖
```

## 3. 核心交付：插页 K + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 K（而不是先贴 A–F / H）

优先贴 **K** 的触发（命中一条就先走本篇）：

1. 市电闪断、缺相、整流模块退出、直流母线电压异常。  
2. 油机未自启、燃油/启动失败、ATS 拒切或粘连、回切失败。  
3. UPS/电池续航与名牌不符，或 UPS 在油机上反复拒收。  
4. 关键电源告警被静音、阈值被改到「永不响」。  
5. 交维「只测了电压」、未做市电→后备→回切剧本。  
6. 倒换窗口出现成片登记失败 / Grant 无声 / 「假干扰假容量」——**先 K 后**再决定是否挂 01/02/07/09。

### 3.2 插页 K · 电源 / 后备（挂在总三联单或交维包首页后）

| 格 | 名称 | 你要填什么（脱敏 L3） |
|----|------|----------------------|
| R1 | 事件窗与对时 | 市电/ATS/油机/网管告警是否同一时钟窗；对时差 |
| R2 | K 子类初判 | K-市 / K-备 / K-切 / K-告 / K-交（可多选，标主贴） |
| R3 | 市电与整流 | 入口状态、模块在位/退出、母线电压趋势（不写真实站名） |
| R4 | 后备能力 | 电池/UPS 续航抽检、油机燃油、启动电池、自启结果 |
| R5 | 倒换剧本 | 市电→后备时刻、稳定判据、回切时刻、是否粘连/拒切 |
| R6 | 业务影响 | 倒换窗是否出现登记/Grant/覆盖/话务气质；主贴仍写 K |
| R7 | 告警与静音 | 关键告警是否到达；有无静音；谁批准、何时恢复 |
| R8 | 证据包清单 | 「插页 K；倒换时序；告警脱敏截屏；拒签/放行；三联单号」 |

**插页组合**：K 常与 G（业务抽检）、X（证据不足）、必要时 A/B/F/H（倒换窗症状）同挂。**不要**把「油机没起来」写成「用户终端玄学」。

### 3.3 「未演倒换禁止签」卡（贴机房/验收会议室）

在插页 K 的 R4–R5 没填之前，下面这些话不许进交维窗：

> 「电压测过了，差不多。」  
> 「油机上次好像能启动。」  
> 「告警太多先静音，交维过后再开。」  
> 「倒换怕影响业务，这次不演了。」  
> 「闪断那一下肯定是干扰，先加功率稳住。」  
> 「电源归物业，我们只管无线。」（边界空 = K-交 拒签）

**拒签句式（背）**：

> 「插页 K 的 R5 空着。先完成市电→后备→回切剧本并留下时序，再谈签字。加功率不是电源补丁。」

### 3.4 和总三联单怎么写（接手册06）

| 三联单栏 | 电源事件怎么写 | 禁止写法 |
|----------|----------------|----------|
| 表头对时 | 市电掉电时刻、ATS 动作、油机点火、网管告警同一窗 | 「大概晚上」 |
| T 症状 | 「倒换窗成片登记失败 90 秒后自愈」等可观察句 | 「协议坏了」无证据 |
| A 动作 | 「切油机 / 回切 / 解除静音 / 拒签」 | 「先加功率试试」 |
| N 下一步 | 「换启动电池 / 重演剧本 / 修 ATS」 | 「观察观察」无责任人 |
| A5 证据 | 「插页 K、倒换时序、告警脱敏、金机抽检」 | 只口头 |
| 结论 | 主贴 K-×；次挂 A/B/F/H（若有） | 主贴写成干扰却无射频证据 |

### 3.5 《本网基站电源与后备切换交维卡》预告

§7 给完整模板：封面拒签门槛、主表、倒换剧本页、夜班速填。交维/半年电检/油机保养后，至少填一版（脱敏入库）。

## 4. 深潜：八条硬规则 + 倒换顺序直觉 + 假病禁令

### 4.1 八条硬规则（本篇钉子）

1. **先读电源链，再写空口病**——闪断/欠压/倒换窗，优先贴纸 K。  
2. **交维必须做「市电→后备→回切」剧本**——只测电压 = 未交维。  
3. **电池/UPS 是桥，油机是长备**——桥断了油机来不及；油机好但桥虚，照样抖。  
4. **ATS 要验切与回切**——粘连、拒切、回切失败都是拒签项。  
5. **关键告警禁止长期静音**——静音须有时限、审批、恢复检查（K-告）。  
6. **禁止用加功率掩盖电源闪断假干扰**——功率是手册07/09 的禁区补丁，不是 K 的药。  
7. **倒换窗症状可挂 A/B/F/H，但不得主写成协议玄学**——主贴 K。  
8. **边界写清再签字（K-交）**——市电进户、油机、直流屏、监控、备件、巡检周期；口头「归物业」不算。

### 4.2 倒换顺序直觉（市电 / 整流 / 蓄电池 / UPS / 油机 / ATS）

```text
  t0  市电异常（闪断/失电/越限）
  t1  整流扛不住或退出 → 直流母线由蓄电池浮充/放电支撑（K-市→K-备）
  t1' 若有 UPS：负载侧由 UPS 逆变器继续供（双转换气质：桥接，不靠「切换瞬间」）
  t2  ATS 确认不是毛刺（防误启延时）→ 发油机启动
  t3  油机建压建频合格 → ATS 切到油机（K-切）
  t4  UPS/整流重新接受输入、电池回充；记录是否「拒收油机」来回抖
  t5  市电恢复并稳定 → 回切市电 → 油机冷却停机
```

现场口诀：

> **先撑（电池/UPS），再唤（油机），后切（ATS），稳了再回（回切）。**  
> 交维若跳过 t2–t5，等于没演过换呼吸机。

### 4.3 交维剧本最低验收包（K-切 心脏）

| 步骤 | 要看到什么 | 不过怎么办 |
|------|------------|------------|
| 模拟或许可失电 | 母线/UPS 支撑，基站未立即「死透」 | 查电池/UPS；拒签长备故事 |
| 油机自启 | 时限内点火、电压频率进窗 | 查燃油、启动电池、控制器；K-备 |
| ATS 切换 | 切到后备有事件记录；无粘连 | 修 ATS；拒签 |
| 业务抽检 | 金机登记/有声/上下行（G 气质） | 记 K + 次挂；禁止加功率 |
| 回切市电 | 回切成功、油机冷却逻辑正常 | 回切失败 = 拒签 |
| 告警闭环 | 全过程告警到达且可脱敏存证 | 静音未恢复 = K-告 拒签 |

### 4.4 「假覆盖 / 假干扰 / 假容量」怎么认

| 假病外表 | 常见电源真因 | 错误处置 | 正确主贴 |
|----------|--------------|----------|----------|
| 假覆盖（F-弱气质） | 欠压掉站、远端单元失电 | 加功率、加直放站增益 | K-市/K-备 |
| 假干扰（F-同气质） | 倒换窗锁相/复位抖、BER 跳一下又好 | 扫「同频」几天 | K-切（次挂 F） |
| 假容量（H 气质） | 多站间歇掉电、话务账假坏 | 加信道、拧 Hangtime | K（次挂 H） |
| 假登记/假 Grant | 倒换窗短时协议症状 | 立刻改写频/鉴权 | K（次挂 A/B） |

**三问快判（背）**：

1. **对时**：症状高峰是否落在市电毛刺 / ATS / 油机窗口？（R1）  
2. **母线**：直流是否在放电或越限？（R3）  
3. **铃**：关键电源告警是否到达、是否被静音？（R7）  

三问里有「是」，就**先写 K**；三问全「否」且有持续射频证据，再进手册07 梯子。切记：倒换窗「抖一下又好」优先是 K-切 的正常/异常副作用，不是先开同频工单。

### 4.5 整流 · 电池 · UPS · 油机：现场只记「量级直觉」（不背厂商菜单）

| 对象 | 你要会问的三句话 | 常见坑 |
|------|------------------|--------|
| 整流 | 几块在位？有没有退出？负载是不是已经靠电池扛？ | 「屏上还有电压」就当整流健康 |
| 电池 | 最近一次放电抽检何时？实际桥接多久？温度补偿有没有管？ | 名牌安时当续航圣经 |
| UPS | 是不是双转换气质？在油机上会不会拒收？充电电流有没有限制？ | 从未与油机联调就交维 |
| 油机 | 自启时限？燃油？启动电池？冷却回切？ | 「保养过」代替本窗剧本 |
| ATS | 切过去事件？回切事件？有无粘连/拒切？ | 只拍铭牌照片 |

> 教学站不要抄真实阈值进公开仓。本网浮充窗、低压告警点、油机建压时限，写在**本网交维卡**（脱敏），不写进本篇正文当「全世界标准」。

### 4.6 和弱项加餐的衔接

12.5 kHz / 4FSK / 30 ms 两槽背熟，你才说得清：**电源抖的是「电」，不是「调制台阶」**。有人要用加功率治闪断假干扰时，回加餐 + 手册07/09 + 本篇八条硬规则。

## 5. 现场映射：原话 → K 子类；对话脚本；反例

### 5.1 原话速查表

| 现场原话 | 主子类 | 你先要的证据 |
|----------|--------|--------------|
| 「电闪了一下就好了」 | K-市 / K-切 | 母线曲线、ATS 事件、告警窗 |
| 「油机有，但站还是掉」 | K-备 | 自启日志、燃油、启动电池 |
| 「交维电压 OK」 | K-切 / K-交 | 倒换剧本时序；无则拒签 |
| 「告警先静音」 | K-告 | 谁批、时限、恢复检查 |
| 「肯定干扰」但倒换窗抖 | K-切（次挂 F） | 先电源时序，再梯子 |
| 「忙时容量不够」但欠压 | K-备（次挂 H） | 母线与掉站对齐 |
| 「电源归物业」 | K-交 | 边界书面；口头不算 |
| 「UPS 在油机上反复切」 | K-备 / K-切 | UPS 拒收记录、walk-in/充电限制 |

### 5.2 对话脚本（六则）

**脚本 A · 交维只测电压**

> 对方：「交流 220 测过了，签吧。」  
> 你：「插页 K 的 R5 空着。请做市电→后备→回切，留下时序和业务抽检。只测电压不算交维。」

**脚本 B · 倒换窗假干扰**

> 对方：「BER 跳了，按手册07 扫同频。」  
> 你：「先对 R1 对时：是否正在 ATS/油机窗口？主贴 K-切；梯子可以挂，但加功率禁止。」

**脚本 C · 告警静音**

> 对方：「电池低压天天叫，静音了清静。」  
> 你：「K-告 拒放行。静音必须有时限和审批；交维前恢复铃，否则拒签。」

**脚本 D · 油机「应该没问题」**

> 对方：「上个月保养过，不用演了。」  
> 你：「保养单代替不了本窗剧本。启动给我看，切过去给我看，回切给我看。」

**脚本 E · 假容量要加信道**

> 对方：「忙时掉话，按手册09 加信道。」  
> 你：「先把掉站时刻和母线/整流告警对齐。若对齐，主贴 K，次挂 H；电源不稳时加信道是假账。」

**脚本 F · 边界口头推诿**

> 对方：「进户电归物业，油机归后勤，我们只管空口。」  
> 你：「K-交 拒签。交维卡上要有书面边界：谁管市电、谁管油机、谁管直流屏、谁收告警。口头三家不管 = 事故预告。」

### 5.3 反例墙（贴机房）

1. 只测电压就签字。  
2. 倒换怕影响业务 → 永远不演。  
3. 关键告警长期静音。  
4. 闪断后先加功率。  
5. 把油机未启写成「终端问题」。  
6. 边界口头「归物业」。  
7. UPS 与油机从未联调。  
8. 回切失败仍说「基本成功」。  
9. 用公网机房电检报告代替本网倒换剧本。  
10. 证据不对时，硬写手册01 结案。

### 5.4 夜班 15 分钟怎么用

```text
1'  看 K-告：有无静音？低压/整流退出是否在叫？
3'  看母线/整流：是否在放电？模块是否退出？
3'  油机：燃油、加热/预热（若有）、启动电池电压
3'  最近一次倒换记录还在不在？对时是否漂？
5'  若正在闪断：记 R1–R6 草稿；禁加功率；主贴 K
```

### 5.5 单次交维 40 分钟标准节奏（可复印；复杂站加倍）

```text
0–5'   开单 + 边界确认（K-交）+ 解除不当静音（K-告）
5–12'  读现状：市电、整流、母线、电池/UPS、燃油、启动电池（K-市/K-备）
12–28' 演剧本：失电/切后备 → 观察母线与业务 → 回切（K-切）；金机抽检（G气质）
28–35' 填插页 K R1–R8；异常立刻拒签项打勾
35–40' 结论：放行 / 带条件 / 拒签；证据包入库（脱敏）；下周复查点
```

带条件放行只允许「非关键、有时限、有责任人」的尾巴（例如铭牌照片补传），**不允许**「倒换没演先签」。

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「市电闪断，登记刷屏两分钟自愈」→ K-市 / K-切

现象：夜班投诉「全站登不上」；两分钟后恢复。  
观察：整流日志有输入跌落；ATS 未切油机（防误启延时内已恢复）；电池短暂放电；网管登记拒绝告警与母线放电窗对齐。  
错法：按手册01 改终端参数；加功率；结案「终端批量异常」。  
正法：主贴 K-市；次挂 A 仅作症状；插页 R1/R3/R6；教育「闪断自愈 ≠ 无事」，查市电质量与整流 N+1；三联单对时写清「未进入油机窗」。

### 例 2 · 「电池老化，名牌 4 小时实际 40 分钟」→ K-备

现象：计划停电演练，电池很快到低压告警。  
观察：浮充电压看起来「正常」，放电抽检才露馅。  
错法：「电压还有 48 就行」。  
正法：K-备 拒签长续航故事；安排容量抽检/更换；交维卡写清实际桥接时间。

### 例 3 · 「油机燃油低位 / 启动失败」→ K-备

现象：真停电，油机未转；站靠电池撑死后掉站。  
观察：燃油低位告警上周被静音；启动电池虚接。  
错法：「无线侧先应急加功率覆盖邻站」。  
正法：K-备 + K-告；恢复铃；修启动链；补演剧本。

### 例 4 · 「ATS 粘连，回切失败」→ K-切

现象：市电已恢复，负载仍挂油机；有人以为「自动会回去」。  
观察：ATS 事件停在「已切后备」；回切失败告警被忽略。  
错法：交维报告写「倒换成功」。  
正法：R5 记回切失败；拒签；修 ATS；回切也是剧本一半。

### 例 5 · 「告警静音当消缺」→ K-告

现象：交维当天机房「很安静」。  
观察：电池低压、整流模块退出、油机未备妥均静音。  
错法：「先签，告警下周再开」。  
正法：封面拒签；K-告 不恢复不签字。

### 例 6 · 「交维只测电压不测倒换」→ K-切 / K-交

现象：验收包只有万用表照片。  
观察：无油机自启录像/时序、无 ATS 事件、无回切、无业务抽检。  
错法：领导催进度先签。  
正法：拒签；引用「未演倒换禁止签」卡。

### 例 7 · 「假覆盖：欠压掉远端」→ K-备（次挂 F）

现象：远端覆盖「忽有忽无」，有人要加直放站增益。  
观察：直流欠压与掉远程告警对齐；金机近端正常；室分远端（手册10 气质）随母线跌落而掉。  
错法：按 F-弱 加功率；开大直放站增益「先照亮」。  
正法：主贴 K-备；次挂 F 仅作症状；修电源/馈电后再走测；I-有源 的增益旋钮这次先冻结。

### 例 8 · 「假容量：多站间歇掉电」→ K（次挂 H）

现象：忙时掉话，申请加信道。  
观察：掉站时刻与市电毛刺/整流退出对齐；话务模型本身未饱和；「忙时」曲线其实是「掉电站数」曲线。  
错法：手册09 直接加信道；拧 Hangtime。  
正法：主贴 K；H 作次挂；电源稳后再谈容量；对齐会上展示「掉站与母线」双轴图（脱敏）。

### 例 9 · 「假干扰：倒换窗 BER 跳」→ K-切（次挂 F）

现象：倒换演练时 BER 告警闪一下。  
观察：时序上紧贴 ATS 切换；前后无持续同频证据；金机在稳定油机供电后 BER 回落。  
错法：开工单「排查同频」一周；临时加功率。  
正法：记入 R5/R6；主贴 K-切；次挂 F；禁止加功率；若每次倒换都抖，查 UPS/整流对油机的接受窗，而不是先怪邻频。

### 例 10 ·（对照）实验室 G 过 vs 现场电源抖 → 不是终端玄学优先

现象：金机在手册08 闭环全过；一到某站夜班就「怪」。  
观察：该站 UPS 在油机上拒收、反复充放。  
错法：怀疑金机漂移（手册11 J-基）或终端。  
正法：主贴 K-备/K-切；J/G 作对照证明「终端锚还在」。

```text
3–8'   抽一份插页 K：R1 对时、R5 剧本是否空
8–12'  反例墙对照：有无加功率、有无只测电压
12–16' 下一次交维窗口与拒签门槛确认
16–20' 备件：启动电池、燃油、整流模块、ATS 服务联系人
```
