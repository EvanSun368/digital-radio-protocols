## 1. 为什么要写这篇手册（动机 + 现场对话）

前六十五篇手册从 A–E 协议一路写到 BL 冷却液液位与高温/低水位保护：其中 **BL 回答「柴油发电机冷却液液位与高温/低水位保护」**（油机缸套水不是精密空调阀路，**冷却液液位/保护过 ≠ 膨胀阀开度/过热控制过**），**AX 回答「精密空调压缩机与制冷剂边界」**（会把膨胀阀写成蒸汽压缩循环里的一个角色，**并不单独给开度台账 + 过热控制窗**），**BJ 回答「压缩机吸排气压力与过热度过冷度巡检」**（管吸/排压力和过热度/过冷度**巡检实测**，引用过 TXV 词条 ≠ 本篇已写过；**过热度测过了 ≠ 开度台账过；过热过冷巡检过 ≠ 过热控制窗过；压力窗过 ≠ 阀开度/控制窗过**），**AI 回答「机房温湿度与空调联锁」**（回风/送风温湿度过 ≠ 开度/过热控制过），**BK 回答「蒸发器盘管清洗与翅片完好」**（盘管洗过、翅片看着齐 ≠ 阀开度/过热控制过），**AT / AU / BG / AO / N** 各管冷凝加湿、滤网、漏水与监控，**AD / AA / AQ** 各管备件、首年巡检与视频。可还没有单独钉死一件事——**机房精密空调膨胀阀/电子膨胀阀开度与过热控制不是「看着阀在 / 开度百分比绿 / 过热度看着在绿区 / 控制器灯绿 / 口头说阀正常 / AX 压缩机冷媒过 / BJ 过热过冷巡检过就能签」：开度的台账要钉死；过热控制侧要有主人有窗有方法有准用期；边界窗与方法要书面固定；本期实测禁套他站他期——能不能签「机房精密空调膨胀阀/电子膨胀阀开度与过热控制巡检准用」？** 这就是本篇的 **BM**——**机房精密空调膨胀阀/电子膨胀阀开度与过热控制交底台账**（Excel 风格双字母：BL 之后 → **BM**）。

**五个词必须先分清，再往下读（本篇反复钉）**：

| 中文词 | 英文 | 作用 | 本系列谁管 | 不等于 |

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **膨胀阀/电子膨胀阀开度台账钉死**：机组、阀角色与开度窗、本期对照各自有账（编号脱敏）；禁「看着阀在 / 开度百分比绿 / 口头说阀正常就算过」；开度过 ≠ 过热控制窗过，控制窗过 ≠ 开度过；TXV 侧过 ≠ EEV 侧过。
2. **过热控制侧有主有窗有方法/准用期**：与开度侧分开看；设定、回路、执行方法与准用期以本网与 OEM 书面为准；每次过热控制交底有主人角色、有书面窗、有方法、有准用期；禁「过热度看着在绿区 / 控制器灯绿 / 套邻站过热控制照片就算过」；开度过 ≠ 控制窗过；TXV 侧过 ≠ EEV 侧过。
3. **边界窗与方法钉死**：书面固定；方法含与 AX/BJ/AI/BK/AT/AU/BG/AO/N 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明开度百分比或过热设定门限、泄放步骤、绕联锁操作、强行全开全关或过热螺丝步骤教条；**不重写 AX/BJ/AI/BK 全文**）；禁「窗再说」「绕过热保护或阀控制联锁」「开旁通阀冒充控制」「不安全泄放制冷剂教条」「未授权调阀教条」「把门限当教条」「伪造台账」。
4. **本组本机房本期实测禁套他站他期**：实测记录、开度对照、过热控制必须本期本组本机房；套邻站/邻院账 = 拒签。
5. **会签才放行**：缺授权会签不得签「机房精密空调膨胀阀/电子膨胀阀开度与过热控制巡检准用」；假绿 ≠ 放行。
6. **禁顶替 AX/BJ/AI/AT/AU/BG/BK/AO/AD/AA/N/AQ 等，主贴 BM，假绿≠放行挂 R**：他贴签都不顶本期开度/过热控制签。**尤其 AX ≠ BM、BJ ≠ BM、AI ≠ BM、BK ≠ BM：压缩机与制冷剂边界过 ≠ 开度/过热控制过（AX 提到膨胀阀只是循环角色，并不单独给本台账）；过热度测过了 ≠ 开度台账过；过热过冷巡检过 ≠ 过热控制窗过；压力窗过 ≠ 阀开度/控制窗过（BJ 引用过 TXV 词条 ≠ 本篇已写过）；温湿度过 ≠ 开度/过热控制过；盘管清洗/翅片完好过 ≠ 开度/过热控制过。** 看着阀在 / 开度百分比绿 / 过热度绿 / 控制器灯绿 / 口头阀正常，都不是窗过；开度过 ≠ 控制窗过；TXV 侧过 ≠ EEV 侧过。
7. **开度或过热控制异常/告警风暴挂 N，边界/门限/窗变更走 J；禁功率战；禁绕联锁；禁旁通；禁不安全泄放制冷剂教条；禁未授权调阀教条；禁伪造台账**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。开度/过热控制乱窗、假绿、告警风暴常被误当「覆盖病」→**禁功率战**；挂 N；变更走 J。开度/过热控制失序不是覆盖病。
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/精密空调或阀体序列号全文/可还原坐标与联系人；禁公开传播未脱敏开度百分比、过热设定与控制参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签开度/过热控制准用、无实测冒充边界过、绕联锁/旁通/不安全泄放/未授权调阀冒充秩序齐，不是法外运维智慧**。医院/数据中心公开资料只作故事类比（§10），翻译成本网语言就是 BM-阀 / BM-热 / BM-界 / BM-验 / BM-治。

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机房精密空调膨胀阀/电子膨胀阀开度与过热控制巡检准用」、对外宣传「看着阀在/开度绿/过热度绿/灯绿/口头阀正常秒过」、把未实测写成已过、把绕联锁/旁通/泄放/未授权调阀写成秩序齐。允许做的：补开度台账、补过热控制窗、重开边界窗、挂 R/N/J、内部挂整改。

### 4.3 「机房精密空调膨胀阀/电子膨胀阀开度与过热控制巡检准用」最小集（BM）——缺页不能签准用

2. 过热控制侧主人与书面窗、方法、准用期页（与开度侧分开看；含禁过热度绿、禁控制器灯绿、禁套邻站照片、BJ 过热过冷巡检过≠控制窗过勾选）
3. 书面边界窗与方法页（与 AX/BJ/AI/BK/AT/AU/BG/AO/N 分工；以本网与 OEM 为准；声明不重写 AX/BJ/AI/BK）
4. 本期本组本机房实测记录（开度对照、过热控制分别留痕；TXV/EEV 按实有路径；禁套声明）
5. AX/BJ/AI/BK 边界勾选（防顶替：压缩机制冷剂边界过≠开度/过热控制过，过热度测过了≠开度台账过，过热过冷巡检过≠控制窗过，温湿度过≠本窗，盘管翅片过≠本窗）

8. 未闭项清单（有则挂整改，重大未闭禁签准用）

10. 变更指针（若本期有机组/阀角色/开度或过热控制窗方法/门限变更 → J）

### 5.2 对话脚本（教学）

**脚本A（看着阀在 / 开度绿 / 口头阀正常想签）**
新人：「阀看着在，开度百分比也是绿的，班长还说阀正常，签准用吧。」
班长：「BM1——开度台账和本期对照呢？看着阀在≠开度台账过，开度百分比绿≠台账过，口头说阀正常≠窗过。补账再谈会签。」

**脚本B（BJ / AX 顶替）**
外包：「BJ 过热过冷刚巡检过，AX 压缩机冷媒签也还在，开度和过热控制免了。」
班长：「BJ≠BM，AX≠BM。过热度测过了≠开度台账过，过热过冷巡检过≠过热控制窗过，压力窗过≠阀开度/控制窗过。AX 提到膨胀阀只是循环角色，并不单独给本台账。过热过冷回BJ，冷媒回AX；开度与过热控制主贴仍BM。顶替挂R。」

**脚本C（AI / BK / 过热度绿 / 灯绿）**
外包：「AI 温湿度刚过，BK 盘管翅片也过了，而且过热度看着在绿区、控制器灯是绿的，窗页免了。」

**脚本D（TXV 顶 EEV / 开度顶控制窗）**
外包：「这台热力膨胀阀感温包看着在，电子膨胀阀那页照抄；再说开度都签过了，过热控制窗免了。」

### 5.5 与弱项的现场对照（再钉一次）

开度乱账、过热控制乱窗、假绿、开度或过热保护告警风暴，常先伤站点环境与**上行**体验——阀失序、过热控制回路乱，蒸发器给液和压缩机回气先乱，送回风跟着飘。有人把这些当「覆盖病」抬功率——**禁功率战**。开度/过热控制失序不是覆盖病。先问 BM 秩序并分诊 AX/BJ/AI/BK，风暴挂 N，变更走 J。弱项短补：**12.5 kHz / 4FSK / 2-slot TDMA**。
## 6. 工作实例（12 则，教学虚构，L3）

1. **看着阀在 / 开度百分比绿 / 口头阀正常想签准用**：称阀体还在、控制器开度百分比是绿的、班长说阀正常要签 → 查 BM1 无本期开度对照 → **拒签**；补 BM-阀。
2. **过热度看着在绿区 / 控制器灯绿 / 套邻站过热控制照片**：称「过热度在绿区 / 灯是绿的 / 邻站照片差不多」免窗页 → **拒签**；补 BM-热。过热度看着在绿区 ≠ 过热控制窗过。
3. **BJ 顶替 BM**：用过热过冷巡检签顶本期开度/过热控制签 → **挂 R**；**过热度测过了 ≠ 开度台账过**；**过热过冷巡检过 ≠ 过热控制窗过**；**压力窗过 ≠ 阀开度/控制窗过**；引用过 TXV 词条 ≠ 本篇已写过。
4. **AX 顶替 BM**：称压缩机与制冷剂边界刚过，膨胀阀只是循环角色，本篇免做 → **挂 R**；**压缩机制冷剂边界过 ≠ 开度/过热控制过**；AX 提到膨胀阀只是循环角色，并不单独给本台账。
5. **AI 顶替 / BK 顶替**：称回风送风温湿度刚过，或盘管清洗与翅片完好刚过，开度与过热控制免 → **挂 R**；**温湿度过 ≠ 开度/过热控制过**；**盘管清洗/翅片完好过 ≠ 开度/过热控制过**。
6. **TXV 顶 EEV / EEV 顶 TXV**：称热力膨胀阀感温包看着在，电子膨胀阀页照抄，或反之；一侧不适用就口头免另一侧 → **拒签**；**TXV 侧过 ≠ EEV 侧过**；一侧不适用须书面单独勾选，不等于另一侧自动免。
7. **开度顶控制窗**：称开度签过了，过热控制窗免做 → **拒签**；**开度过 ≠ 过热控制窗过**。
8. **旁通 / 绕联锁 / 泄放 / 未授权调阀**：开旁通冒充控制、绕联锁、放一点制冷剂消告警、未授权强制全开或全关、乱拧过热螺丝后要求准用 → **禁旁通**；**禁绕联锁**；**禁不安全泄放制冷剂教条**；**禁未授权调阀教条**；先挂 N/R；缺秩序整改贴 BM；禁签。
9. **套邻站表**：拷邻站开度/过热控制表改机房号 → **BM-验 拒签重测**。

## 8. 术语表（本篇约 18 词）+ 易错观念

|------|------------------|
