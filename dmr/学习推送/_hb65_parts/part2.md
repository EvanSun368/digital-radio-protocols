## 3. 核心交付：插页 BL + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 BL（而不是先贴 BI / AR / AF / AV / AO / N）

- 要签「机房柴油发电机冷却液液位与高温低水位保护巡检准用」、要开冷却液液位交底窗、要交底高温/低水位保护侧 → **主贴 BL**。  
- 日用/储油罐油位与泄漏 → **BI**（手册62）。**BI ≠ BL**；油不是缸套水；不重写 BI。  
- 通风排烟与燃油安全 → **AR**。油机市电切换与供电巡检 → **AF**（周检写到冷却液 ≠ 本篇台账）。油品净化加油 → **AV**。漏水汇排 → **AO**。**AR ≠ BL；AF ≠ BL；AV ≠ BL；AO ≠ BL**。  
- 进机房先 **AN**（门禁过 ≠ 交底过）。气灭 → **AL**。风暴先 **N**，缺秩序整改仍 **BL**；油位泄漏另问 **BI**；燃油安全另问 **AR**；切换/试车另问 **AF**；油品另问 **AV**；地面积水另问 **AO**；**禁功率战、绕联锁、旁通、不安全泄放冷却液教条、热机/带压乱开散热器盖教条**。  
- 假绿/顶替挂 **R**；变更走 **J** 后再验 BL。  
- 无柴油发电机、无缸套水/散热器冷却液路径 → 书面「不适用」；**不得**用 BL 顶 AF/AR/BI/AV/AO，也不得用它们顶 BL。

### 3.4 与总三联单怎么写（脱敏 L3）

- **现象栏**：写「液位缺账 / 看着有液无核对 / 口头加过 / 保护灯绿顶窗 / 表绿顶窗 / 一侧顶另一侧 / 他贴顶 BL / 套票 / 泄放/旁通/绕联锁/热机开盖嫌疑」等角色化现象；**不写**真实机房全称、油机或散热器序列号全文、可还原液位门限全文。  
- **贴纸栏**：主贴 **BL**；邻贴指针 BI/AR/AF/AV/AO/AN/AL/N/R/J 按需勾。  
- **处置栏**：补 BL-位 / 补 BL-护 / 补 BL-界 / BL-验 重测 / 会签或拒签 / 挂 R / 挂 N / 走 J。  
- **会签栏**：准用 / 有条件整改 / 拒签；假绿 ≠ 放行。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **冷却液液位台账钉死**：机组、散热器或膨胀水壶角色与液位窗、本期对照各自有账（编号脱敏）；禁「看着有液就算过」「口头说加过了」；液位过 ≠ 保护过，保护过 ≠ 液位过。  
2. **高温/低水位保护侧有主有窗有方法/准用期**：高温侧与低水位侧分开看；测点、动作（报警/停机）、合格窗与准用期以本网与 OEM 书面为准；每次保护交底有主人角色、有书面窗、有方法、有准用期；禁「保护灯绿就算过」「表看着在绿区就算过」「套邻站保护照片」；高温保护过 ≠ 低水位保护过。  
3. **边界窗与方法钉死**：书面固定；方法含与 BI/AR/AF/AV/AO/N 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明配比配方、泄放步骤、绕联锁操作或热机开盖步骤教条；**不重写 BI/AR/AF/AV/AO 全文**）；禁「窗再说」「绕高温/低水位等保护联锁」「开旁通冒充」「不安全泄放冷却液教条」「热机/带压乱开散热器盖教条」「把配比当教条」「伪造台账」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、液位对照、高温侧与低水位侧保护必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「机房柴油发电机冷却液液位与高温低水位保护巡检准用」；假绿 ≠ 放行。  
6. **禁顶替 AF/AR/BI/AV/AO/AD/AA/N/AQ 等，主贴 BL，假绿≠放行挂 R**：他贴签都不顶本期冷却液液位/保护签。**尤其 BI ≠ BL、AR ≠ BL、AF ≠ BL、AV ≠ BL、AO ≠ BL：油位/泄漏过 ≠ 冷却液液位/保护过；燃油安全过 ≠ 冷却液过；油机市电过 ≠ 冷却液过（周检写到 ≠ 本篇台账）；油品/加油过 ≠ 冷却液过；漏水探头过 ≠ 本窗；看着有液 ≠ 台账过；灯绿/表绿 ≠ 窗过；口头加过 ≠ 窗过；液位过 ≠ 保护窗过；高温保护过 ≠ 低水位保护过。**  
7. **液位异常/高温或低水位告警风暴挂 N，边界/门限/窗变更走 J；禁功率战；禁绕联锁；禁不安全泄放冷却液教条；禁旁通；禁伪造台账；禁热机/带压乱开散热器盖教条**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。液位/保护乱窗、假绿、高温或低水位告警常被误当「覆盖病」→**禁功率战**；挂 N；变更走 J。冷却液/保护失序不是覆盖病。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/油机或散热器序列号全文/可还原坐标与联系人；禁公开传播未脱敏液位门限与保护参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签冷却液液位/保护准用、无实测冒充边界过、绕联锁/旁通/不安全泄放/热机开盖冒充秩序齐，不是法外运维智慧**。医院/数据中心公开资料只作故事类比（§10），翻译成本网语言就是 BL-位 / BL-护 / BL-界 / BL-验 / BL-治。

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机房柴油发电机冷却液液位与高温低水位保护巡检准用」、对外宣传「看着有液/灯绿/表绿/口头加过秒过」、把未实测写成已过、把绕联锁/旁通/不安全泄放/热机开盖写成秩序齐。允许做的：补冷却液液位台账、补保护窗、重开边界窗、挂 R/N/J、内部挂整改。

| 「AV 油品加油刚过」 | AV≠BL | 油品 **AV**；冷却液仍 **BL** |

| 「AO 探头绿 / AN 门禁过了 / AL 气灭过了 / AD 入库签还在」 | AO≠BL；门禁≠交底；气灭≠交底；入库≠本期窗 | 邻贴各回各位；交底/主窗仍 **BL** |
| 「N 监控绿，实测免做」 | N≠BL | 风暴 **N**；本期实测仍 **BL** |
| 「高温/低水位告警一片」 | 先风暴还是先抬功率？ | 先 **N**；缺秩序整改 **BL**；油位另问 **BI**；燃油安全另问 **AR**；切换另问 **AF**；油品另问 **AV**；漏水另问 **AO**；**禁功率战**；**禁绕联锁/旁通/泄放/热机开盖** |
| 「改机组/散热器或膨胀水壶角色/液位或保护窗方法/门限」 | 有没有走变更？ | **J** + 再验 **BL** |
| 「邻站液位/保护表拷过来改机房号」 | 套票？ | **BL-验** 拒签 |
| 「放一点冷却液消告警 / 还烫着开盖 / 开旁通 / 绕高温低水位联锁 / 按经验兑配比」 | 冒充/绕联锁/违章？ | **禁**；挂整改；主贴 **BL-治**（具体补液/保护方法只认本网与 OEM 书面窗，本篇不展开配方与开盖步骤） |
| 「本站没有柴油发电机，也没有缸套水/散热器冷却液路径」 | 有没有冷却液路径？ | 书面「不适用」；不拿 BL 顶 AF/AR/BI/AV/AO，也不拿它们顶 BL |

### 4.3 「机房柴油发电机冷却液液位与高温低水位保护巡检准用」最小集（BL）——缺页不能签准用

1. 冷却液液位台账页（机组·散热器或膨胀水壶·液位窗·本期对照；含看着有液≠台账过、口头加过≠窗过、液位过≠保护窗过勾选）  
2. 高温/低水位保护侧主人与书面窗、方法、准用期页（两侧分开看；含禁灯绿、禁表绿、禁套邻站照片勾选）  
3. 书面边界窗与方法页（与 BI/AR/AF/AV/AO/N 分工；以本网与 OEM 为准；声明不重写 BI/AR/AF/AV/AO）  
4. 本期本组本机房实测记录（液位对照、高温侧、低水位侧分别留痕；禁套声明）  
5. BI/AR/AF/AV/AO 边界勾选（防顶替：油位/泄漏过≠冷却液液位/保护过，燃油安全过≠冷却液过，油机市电/周检写到≠本篇台账，油品过≠冷却液过，漏水探头过≠窗过）  
6. AD/AN/AL/N/AA/AQ 与 AG/AP/BH/BK 等边界勾选（入库≠本期窗；门禁/气灭过≠交底过；N 绿≠BL 过；各过≠BL 过）  
7. 会签页（准用或有条件整改）  
8. 未闭项清单（有则挂整改，重大未闭禁签准用）  
9. 脱敏勾选（L3）  
10. 变更指针（若本期有机组/散热器或膨胀水壶角色/液位或保护窗方法/门限变更 → J）  
11. 不适用声明（无柴油发电机或无缸套水/散热器冷却液路径，书面勾选；不得顶 AF/AR/BI/AV/AO；一侧不适用 ≠ 另一侧自动免）

> **口诀**：位、护、界、窗、房、测、签、闭、密、界——**十字液位钉**（教学记忆；现场以本网书面规程为准，但 **冷却液液位台账 + 高温/低水位保护窗方法 + 边界方法 + 本组本机房本期实测 + 会签** 几乎不可砍）。

- [ ] 「看着有液≠台账过」「口头加过≠窗过」勾选  
- [ ] 「液位过≠保护窗过」「保护窗过≠液位过」「BI过≠冷却液液位过」「AF周检写到≠本篇台账」勾选  

### 4.5 保护窗与边界清单（BL-护 / BL-界）

- [ ] 保护侧主人、书面窗、方法/准用期（本网与 OEM 书面）；高温侧、低水位侧分开入账（或勾不适用）  
- [ ] 「灯绿≠窗过」「表绿≠窗过」「禁套邻站保护照片」「高温过≠低水位过」「液位过≠保护窗过」勾选

### 4.6 与 BI / AR / AF / AV / AO / N / … 的分工表（钉死，防互相顶替）

|------|------------|----------------|

### 4.7 台账路径（从发现到会签，教学骨架）

        │         油机市电/试车？→ AF；油品？→ AV；漏水？→ AO；风暴？→ N

### 5.2 对话脚本（教学）

**脚本A（看着有液 / 口头加过想签）**  
新人：「散热器看着有液，班长也说上个月加过了，签准用吧。」  
班长：「BL1——冷却液液位台账和本期对照呢？看着有液≠液位台账过，口头说加过了≠窗过。补账再谈会签。」

**脚本B（BI / AF 顶替）**  
外包：「BI 油位泄漏签还在，AF 周检单上冷却液也打了勾，冷却液和保护免了。」  
班长：「BI≠BL，AF≠BL。油位/泄漏回BI，油机市电回AF；冷却液液位与保护主贴仍BL。日用油箱里的油不是散热器里的缸套水。AF 周检写到冷却液≠本篇台账。顶替挂R。本篇不重写BI/AF全文。」

**脚本C（AR / AV / AO / 灯绿表绿）**  
外包：「AR 燃油安全刚过，AV 油品也过了，AO 探头还是绿的，而且保护灯是绿的、表也在绿区，窗页免了。」  
班长：「AR≠BL，AV≠BL，AO≠BL。通风排烟燃油安全过≠冷却液过；油品过≠冷却液过；漏水探头过≠冷却液液位/保护过。保护灯绿、表看着在绿区≠窗过。补BL-护主人窗方法。本篇不重写AR/AV/AO全文。」

**脚本D（高温顶低水位 / 液位顶保护）**  
外包：「高温保护刚测过，低水位这边照抄；再说液位都签过了，保护窗免了。」  
班长：「高温保护过≠低水位保护过；液位过≠保护窗过。两侧各自实测，分账分验。一侧签过不能顶另一侧。」

**脚本E（泄放 / 热机开盖 / 绕联锁 / 套票）**  
外包：「邻站液位保护表改个机房号交差。或者放一点冷却液告警就消，还烫着把散热器盖拧开看看，保护先绕开。」  
班长：「BL-验拒签重测。禁套他站他期。禁不安全泄放冷却液教条，禁热机/带压乱开散热器盖教条，禁旁通，禁绕联锁。挂N/R，禁签。液位过≠保护过。」

### 5.4 禁写词 / 允许写

禁止写：真实站名、机房全称、油机或散热器序列号全文、单位名、联系人、真实频点、未脱敏门限与保护参数；禁止写「看着有液就过」「灯绿/表绿就过」「口头加过就过」「他贴顶 BL」「抬功率」「泄放步骤」「配比配方」「热机开盖步骤」「旁通/绕联锁」「套邻站表」。允许写：脱敏角色、现象、贴纸（BL/BI/AR/AF/AV/AO/N/R/J）、动作（补账/重测/拒签）。

### 5.5 与弱项的现场对照（再钉一次）

冷却液乱账、保护乱窗、假绿、高温/低水位告警风暴，常先伤站点保供电与**上行**体验——机组在最需要时因热保护或低水位保护停下来，站点环境先乱。有人把这些当「覆盖病」抬功率——**禁功率战**。冷却液/保护失序不是覆盖病。先问 BL 秩序并分诊 BI/AR/AF/AV/AO，风暴挂 N，变更走 J。弱项短补：**12.5 kHz / 4FSK / 2-slot TDMA**。
