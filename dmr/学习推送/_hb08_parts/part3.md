### 例 2 · 「Grant 了没声」→ G + C
闭环③：Grant 10/10；业务信道听错时隙（人耳听 TS1，Grant 在 TS2）。射频三过。**G 主 + C 次**。修正监听时隙后有声。对照手册02 四问第二问。

### 例 3 · 「满格登不上」台架版 → 先⑤再分流
闭环⑤：台架舒适区电平，解出 CC=9，本网 CC=3（教学值）——台架合路器误接到教学用「邻系统」信号源。**不是现场 F，是台架拓扑错**。修好合路后闭环②过。教训：R4 台架拓扑必须写。

### 例 4 · 「直通行中继不行」→ ④ 上行先挂
衰减扫描：下行 CC 可解至较高衰减档；上行登记在较低衰减档就无 ACK。金机同样。**G 主 + F-弱（上行）表象像 B**。下一动作：网优看上行覆盖；用户临时「靠近再登」。

### 例 5 · 「鉴权失败」→ G + D
闭环②：空口「有题有答」，答后 NACK；金机同 K 基线过。**G 主 + D 次**，转手册05（K/PSN/串号）。若空口「有题无答」则先查 F 或终端发射，不急着怪密钥。

### 例 6 · 「中继一转发就断」→ ⑥ 减敏
维护窗闭环⑥：停发 BER 低；发射 BER 明显升高（教学相对差）。**G 主 + F-互**。站务紧固双工器接头后复测无差异——复测写回同一张单。

### 例 7 · 「实验室正常、现场晚上挂」→ G 过转 F-同
①⑤③台架全过。现场按时段录：19:00 起本网 CC 消失、他网 CC 出现（手册07 例1 同类）。**F-同（主）+ G（次，证明非终端）**。禁止写「用户胡说」。

### 例 8 ·（对照）未闭环就贴「终端故障」→ 被打回
原单：一次登记失败，结论终端故障，未做①。重做①：金机同台架也不过——中继台架假负载未接好，驻波保护。**结论 X→修台架**；DUT 无问题。本例应进误贴周报。


### 例 9 · 「短信偶发丢失」→ 先 G 再决定是否 E
用户报「短信有时到有时不到」。闭环①金机与 DUT 同台架：用教学短信剧本 R-短 ×20。金机 20/20，DUT 18/20 失败两次均在「业务信道 BER 瞬时升高」窗口（分析仪记录）。**不是先贴 E**：补闭环⑤发现台架合路器接触不良导致偶发 F 指纹。紧固后 20/20。**G 主，E 排除**。教训：管理业务（贴纸 E）也要先过射频三过与金机对照。

### 例 10 · 「Stun 成功但 Revive 无效」台架剧本
闭环扩展（接手册03）：剧本 R-管：Stun→确认无呼出→Revive→确认恢复。金机全过；DUT Stun 过、Revive 后仍无呼出。空口可见 Revive 相关信令（教学描述，不写厂商菜单名），网管显示已 Revive。继续闭环①换天线 / 换电池后仍挂 → 终端固件状态机可疑，转终端维修，**G 主 + E 次**；A6 写明「射频三过已做」。

### 6.5 测试 × 运维 × 站务 对齐会：15 分钟议程

```text
00–03  本周 G 类单：过 / 不过 / X 计数；误贴（未闭环就下终端结论）数
03–07  抽一张「G 过转现场」：现场是否按 F 补了证据？
07–11  金机基线是否过期；剧本库是否新增故意失败对照
11–15  维护窗⑥预约；下周只改 3 条行动
```

## 8. 术语表（本篇约 28 词）+ 易错观念

| 术语 | 一句话 | 易错 |
|------|--------|------|
| 闭环 | 刺激→观察→判定→证据包 | 缺一环就不算测过 |
| 刺激 stimulus | 你对系统做的固定动作 | 不是「随便开开」 |
| 观察 observation | 一手证据来源 | 用户口述是线索不是观察 |
| 判定 verdict | 过/不过/X + 贴纸 | 不能只有感觉 |
| 证据包 | 可挂三联单的材料组合 | 要脱敏 |
| 金机 | 已知良好对照终端 | 基线过期就不是金机 |
| DUT | 待测设备 | — |
| 剧本 | 可重复的刺激序列 | 比仪表贵 |
| 故意失败对照 | 已知应失败的剧本 | 只在台架教学机做 |
| 贴纸 G | 实验室闭环验证章 | 不单独结案 |
| 插页 G | R1–R8 台架记录 | 与 A–F 插页并列 |
| 射频三过 | 能量够+本网CC+BER低 | 三过就离开射频 |
| 五格梯子 | 能量→同步→身份→质量→业务 | 手册07 |
| 12.5 kHz | DMR 信道带宽 | 台架中心不能偏道 |
| 4FSK | 四台阶频偏调制 | 台阶判错=误码 |
| TDMA 30 ms | 一时隙时长 | 听错时隙→假无声 |
| BER | 误码率 | 数字灵敏度常用尺子 |
| SINAD | 模拟灵敏度常用尺子 | DMR 闭环不强制 |
| 灵敏度 | 达质量门限的最低电平 | 门限看设备规格 |
| 衰减扫描 | 用已知衰减模拟变远 | 优于乱加功率 |
| 上下行不对称 | 听得见基站、基站听不见你 | 像 B，实为链路 |
| 假负载 | 吸收发射功率的终端负载 | 台架发射默认入口 |
| 减敏 desense | 自发自收导致灵敏度下降 | 闭环⑥开/关对比 |
| 合路/隔离 | 台架信号分配与保护 | 拓扑写错会假故障 |
| 对时 | 多源时钟对齐 | 手册06 |
| 脱敏 L0–L3 | 证据能去哪 | 实验室也要守 |
| 维护窗 | 批准的可发射测试时段 | 窗外不做⑥ |
| X | 证据不足 | 诚实比结案重要 |

**五个易错观念**：① 开过机 ≠ 闭环；② 金机也挂 ≠ 基站坏；③ 实验室过 ≠ 现场无问题；④ 无 CC/BER ≠ 可写射频三过；⑤ 加功率 ≠ 台架标准刺激。

## 9. 自测（10 题）+ 参考答案

1. 最小闭环四件套是什么？缺观察时能不能贴 A–F 结案？  
2. 贴纸 G 和贴纸 F 有什么不同？G 能否单独结案？  
3. 为什么金机必须先跑同一剧本？金机不过时怎么办？  
4. 闭环③里「有 Grant」和「有声」是不是一回事？  
5. 上下行不对称闭环④的典型观察是什么？容易误贴哪张贴纸？  
6. 射频三过之后下一步应该去哪？  
7. 闭环⑥减敏对比的前提条件有哪些？  
8. 「实验室正常、现场晚上挂」最合理的贴纸组合？  
9. 没有分析仪时，A3 应该怎么写？  
10. 故意失败对照的目的是什么？可以在生产用户机器上留错误写频吗？

### 参考答案

1. 刺激→观察→判定→证据包。缺观察时结论只能偏 X，不能当 A–F 结案。  
2. F 是射频病因；G 是「台架是否按剧本验证过」的章。G 不能单独结案，须带 A–F 或 X。  
3. 金机先过证明台架/剧本/观察端可信；金机不过先修实验室，不给 DUT 下终端故障结论。  
4. 不是。Grant 只是房卡；有声要在业务信道确认 Payload/听音（手册02）。  
5. 下行仍可解、上行先无 ACK；易误贴 B。  
6. 离开射频，按手册01–05 贴 A–E。  
7. 维护窗、经批准、假负载/规程；发射开 vs 停发对比同一测试信号。  
8. F-同（或相应 F 子类）主 + G 次（证明台架/终端非根因）。  
9. 诚实写「仅金机 RSSI/现象，未测 CC/BER」，不写射频三过。  
10. 验证观察端能报失败、接收机在认 CC 等；**不可以**把错误写频留在出库/生产用户机器上。
