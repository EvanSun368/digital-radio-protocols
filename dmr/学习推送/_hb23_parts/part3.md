## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 一句话 |
|------|--------|
| **临时频率许可/批复** | 保障期依法取得的临时用频凭证（教学喻：会展临时用电证） |
| **批准文件** | 临时/试验等情形下与许可证同等效力的用频批准（以办法原文为准） |
| **保障窗** | 书面载明的允许临时用频/设台的起止时段（教学喻：占道证时段） |
| **联测窗** | 本网与必要邻居约定的联合测试与验收时段 |
| **保障就绪** | 临时覆盖+在窗+联测完成+回收计划在册后的签字状态 |
| **临时台账** | 本网对临时批复/窗/联测/回收字段的可对账登记（脱敏） |
| **回收关停** | 窗末日降功率、停发、拆临时天线、回滚信道表并回写台账 |
| **临时变永久** | 超窗继续使用临时频或擅自写入日常表且无 U 转正——本篇红线 |
| **先开后补** | 无批复先发射再补手续——本篇红线 |
| **脱敏编号** | 公开与教学用的替代编号，非全文号 |
| **功率上限** | 临时批复载明发射功率不得突破（变更前） |
| **重大活动保障** | 主办/承办向无线电管理部门提出临时用频与设备等保障需求的活动场景 |
| **无线电管制** | 特定时间区域依法限制/禁止用频或采取技术阻断等（见管制规定） |
| **主贴 V** | 临时保障问题以 V 为主键，可挂 U/S/T/J/M |
| **L3** | 公开包最高脱敏等级（本系列约定） |
| **书面起止** | 保障窗以书面为准，聊天记录不算 |
| **必要邻居** | 联测最小集中必须纳入的边界/共址对端（本网制度定义） |
| **转正** | 临时需求转为长期使用时走 U 许可/执照路径，核准前关停 |

**易错观念**

1. ✗ 有拟用表 = 已获临时批复 → ✓ 拟用表 ≠ 批复。  
2. ✗ 永久许可在 = 不问保障窗 → ✓ 临时段仍要 V；永久段仍要 U。  
3. ✗ 本网自测全绿 = 保障就绪 → ✓ 必要邻居联测未完禁签就绪。  
4. ✗ 闭幕留着临时站方便运维 → ✓ 窗末日强制回收。  
5. ✗ 临时道好用就写进日常表 → ✓ 禁临时变永久；转正走 U。  
6. ✗ 先开后补是保障惯例 → ✓ 本篇红线。  
7. ✗ 降功率不用通知邻居 → ✓ 边界临时变更仍挂 S。  
8. ✗ 有临时批复可对抗管制命令 → ✓ 管制命令优先服从。  
9. ✗ OTAP 成功代替合规 → ✓ OTAP 不创造临时批复。  
10. ✗ 公开培训可以贴批复全文号 → ✓ 全文号受控，公开 L3。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **V** 五子类：临 / 窗 / 联 / 收 / 治。  
- 故事：会展临时用电证 + 施工占道证 + 闭幕拆线还路。  
- 八条硬规则：**先证临时覆盖再写频开站**；**无批复/过期/超窗拒签**；**书面起止禁临时变永久与先开后补**；**联测未完禁签就绪**；**写频/OTAP前对临时台账**；**闭幕强制回收**；**跨网挂 S、投诉挂 T**；**脱敏 L3**。  
- 与 U/S/T/J/M 分工：U=永久证照；S=邻居联测方法；T=投诉分诊；J/M=怎么改参数；**V=这次保障的临时资格、窗、联测与回收**。

### 11.2 回库路径
现场「要开临时站 / 写临时信道 / 签保障就绪」→ 本篇（贴纸 V + 插页 V + 联测窗卡）→ 临时批复五组 + 书面窗 + 联测 + 回收计划 → 影响边界挂 S → 再放行 J/M；闭幕走回收；投诉挂 T；转永久走 U；公开 L3。

### 11.3 下一篇手册候选（本篇不写正文）

- **电磁环境测试与验收报告台账**（开站前电磁环境与执照申请材料咬合）

### 11.4 给带新人的三句话
1. 临时站开之前先问：批复还盖得住保障期吗？书面窗在期内吗？  
2. 联测没完不能签「保障就绪」；闭幕必须拆线还路，不能临时变永久。  
3. 全文号不许进公开包；边界临时变更先通知邻居。
