## 1. 为什么要写这篇手册（动机 + 现场对话）

前二十二篇手册把「家里怎么养」「邻居怎么处」「投诉怎么分诊」「证照台账怎么对」基本写全了：A–E 协议，F 射频指纹，G 实验室，H 话务，I 室分，J 写频，K 电源，L 井库，M 批量 / OTAP，N 监控对时，O 有源隔离，P 口部，Q 金机，R 假绿演练，S 邻频协调，T 干扰投诉，U 许可执照台账。可现场还有一类债——**重大保障临时频率与联测窗**：

- 保障办：「活动下周开幕，临时频批复还没下来，先按拟用表写频开站。」——**先开后补** = 本篇拒签（规则2、3）。  
- 写频岗：「临时信道表昨晚改了，批复还是旧起止时刻。」——**未对临时台账**（规则5，挂 J / U）。  
- 联测班长：「本网自测全绿，邻居没空，先签『保障就绪』吧。」——**联测窗未完成** = 规则4（挂 S）。  
- 领导：「闭幕当晚业务还忙，临时站先留着，下周再拆。」——**临时变永久 / 不回收** = 规则3、6。  
- 邻网协调：「我们保障期临时抬了边界侧功率，忘了通知你们。」——**跨网未通知**（规则7，挂 S；若已投诉挂 T）。  
- 新人：「临时批复和永久许可不是一回事吗？过了保障窗还能不能用？」——**临时 ≠ 永久**（弱项短补）：会展临时用电证有起止时刻与功率上限；闭幕必须断电拆线交还，不能「临时变永久」。

这几句背后是同一件事：

> **「重大保障临时频率与联测窗」在现场至少有五个坑**：**① V-临** 临时许可/批复仍有效、覆盖保障期拟用频点组/地域/用途/功率上限；**② V-窗** 保障窗书面起止时刻，禁超窗、禁「先开后补」、禁「临时变永久」；**③ V-联** 联测窗（本网+必要邻居）完成才签保障就绪；**④ V-收** 闭幕/窗末日强制回收：降功率/关停/拆临时天线/回写台账；**⑤ V-治** 无批复/过期/超窗拒签，跨网挂 S，投诉挂 T，公开仓 L3。  
> 把 ①–⑤ 当成「有拟用表就能开」「联测以后补」「闭幕先留着」「临时变永久」，会把下一任、邻居、主管部门和保障指挥部一起拖进泥潭。

本篇目标：能背出**重大保障临时频率与联测窗工作流**；会用新贴纸 **V（临 / 窗 / 联 / 收 / 治）** 与五个子类；会填**插页 V（V1–V8）**和《本网重大保障临时频率与联测窗卡》；能用「**会展中心临时用电证 + 施工占道证 + 闭幕当晚必须拆线还路**」故事讲清：先证覆盖再开站、书面起止、联测验收、强制回收、拒签；能拒绝「无批复开站、超窗继续、临时变永久、联测未完签就绪、公开泄密」；自测过关后，回库把本网最近一次重大保障（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：凡引法规均指向已公开发布的文书标题与官方链接（《中华人民共和国无线电管理条例》《无线电频率使用许可管理办法》《地面无线电台（站）管理规定》《无线电台执照管理规定》《中华人民共和国无线电管制规定》及属地重大活动保障公开文件等），**数字、时限、程序以原文与属地最新要求为准，本篇只作教学转述，不发明条款号以外的「内部口径」**；**现象与台账一律用相对道号、角色标签、脱敏编号表述，禁真实频点 / 站名 / 单位名 / 许可或批复全文号 / 联系人 / 坐标**；**不教无证发射、伪造涂改批复、规避监测与检查、把临时频永久化、查找/对抗非法设台或黑广播的技术细节**；J / M 仍管写频与批量边界，U 仍管永久证照台账，S 仍管邻频联测，T 仍管投诉进线——**临时保障主贴 V**；外国 / ITU 资料只借**重大活动频谱协调与监测方法**，**临时许可与设台以国内法规与属地无线电管理机构为准**。

## 2. 总图 / 故事：临时频率像「会展临时用电证 + 施工占道证 + 闭幕拆线还路」

### 2.1 一句话：临时频率像会展临时用电证（有起止、有功率上限、有用途），保障窗像施工占道证（书面划定时段与区域），联测像通电验收，闭幕必须断电拆线交还道路——禁「临时变永久」「先开后补」

```text
   ┌──────────────────────────────────────────────────────────────────┐
   │   会展中心物业 + 城管占道窗口（= 无线电管理机构 / 保障指挥）    │
   │                                                                  │
   │   临时用电证（V-临 · 临时频率许可/批复）                        │
   │     起止时刻 · 用途 · 使用范围 · 功率/容量上限 · 批复事项       │
   │                                                                  │
   │   施工占道证（V-窗 · 保障窗）                                    │
   │     书面起止 · 区域边界 · 禁超窗作业 · 禁「先占后补证」         │
   │                                                                  │
   │   通电/联调验收（V-联 · 联测窗）                                 │
   │     本网金机 + 必要邻居联测 · 未验收禁签「保障就绪」            │
   │                                                                  │
   │   闭幕拆线还路（V-收 · 回收关停）                                │
   │     降功率/关停/拆临时天线/回写台账 · 禁「先用着再说」         │
   │                                                                  │
   │   治理拒签（V-治）                                               │
   │     无批复/过期/超窗禁开 · 挂S/T · 公开仓 L3                   │
   └──────────────────────────────────────────────────────────────────┘
```

口诀：

> **先证临时覆盖，再写频开临时站；有窗有测，闭幕必收。**  
> 无批复 / 过期 / 超窗还开站 = 没临时用电证就通大功率——**拒签**。  
> 闭幕不拆线 = 占道证过期还堵路——**违规**。

### 2.2 「临时用电 + 占道 + 闭幕拆线」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **临时许可** | 会展临时用电证 | 批复仍有效？覆盖保障期拟用频点组/地域/用途/功率上限？ | V-临 |
| **保障窗** | 施工占道证 | 书面起止时刻；禁超窗；禁先开后补；禁临时变永久 | V-窗 |
| **联测** | 通电/联调验收 | 本网+必要邻居联测完成才签「保障就绪」 | V-联 |
| **回收** | 闭幕断电拆线还路 | 降功率/关停/拆临时天线/回写台账；窗末日强制 | V-收 |
| **拒签治理** | 无证禁通电、过期禁占道 | 无批复/过期/超窗拒签；跨网挂 S；投诉挂 T；L3 | V-治 |

> 公开文书告诉我们：使用无线电频率通常应取得许可；临时使用无线电频率的，许可期限有专门上限（教学转述：《无线电频率使用许可管理办法》载明临时使用无线电频率的许可期限不超过 12 个月，**具体办理与属地要求以原文为准**）；对于临时使用、试验使用等情形，管理机构可颁发无线电频率使用批准文件，与许可证具有同等效力；设置、使用无线电台（站）通常应取得无线电台执照，重大活动可由主办/承办单位统一申请临时设台路径（属地条例/规定有公开表述的，以属地原文为准）；重大活动期间主办单位应向无线电管理部门提出保障需求。本篇只借「先批后用、有窗有测、到期必收」的顺序，**不编造内部时限数字以外已核原文的内容**。

### 2.3 和手册11 / 14 / 20 / 21 / 22 的咬合（指针，不重写）

- **手册22 U**：永久许可与执照台账。本篇临时批复**不替代**永久 U；保障期内若动用永久频点/台站，仍须 U 覆盖；临时台账可与 U 台账互挂脱敏编号。

### 2.4 新贴纸 V：临 / 窗 / 联 / 收 / 治（五个子类）

```text
                ┌──────────── 贴纸 V · 临/窗/联/收/治 ────────────┐
                │  V-临  临时批复有效且覆盖：频点组·地域·用途·功率上限·保障期 │
                │  V-窗  保障窗书面起止：禁超窗·禁先开后补·禁临时变永久     │
                │  V-联  联测窗完成：本网+必要邻居；未完禁签保障就绪         │
                │  V-收  闭幕强制回收：降功率/关停/拆临时天线/回写台账       │
                │  V-治  拒签治理：无批复过期超窗禁开·挂S/T·L3             │
                └──────────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签 / 拒放行触发 |
|------|--------|----------------------|
| **V-临** | 无临时批复、批复过期或不覆盖拟用方案 → 禁写频开临时站 | 「批复明天就到，今晚先开」 |
| **V-窗** | 无书面起止、超窗、先开后补、临时变永久叙事 → 拒签 | 「先开着，窗回头补」 |
| **V-联** | 联测窗未完成（缺邻居必要侧）仍签保障就绪 → 拒签 | 「本网自测够了」 |
| **V-收** | 闭幕/窗末日未降功率关停拆临时天线回写台账 → 治理 | 「先用着再说」 |
| **V-治** | 无批复开站、超窗继续、公开泄密、跨网不通知 → 治理 | 「公开贴批复全文号」 |

### 2.5 重大保障临时频率与联测窗最小工作流（背下来）

```text
  拟写临时信道 / 开临时站 / 临时扩功率 / OTAP 临时表 / 签保障就绪
        │
        ▼
  临时许可/批复仍有效？覆盖保障期拟用频点组·地域·用途·功率上限？（V-临）
        │否──▶ 拒签；走临时申请/延续路径（规则1、2）· 挂 U 若涉永久证照
        │是
        ▼
  保障窗是否书面起止？当前是否在窗内？有无「先开后补」「临时变永久」叙事？（V-窗）
        │否──▶ 拒签开站扩功率挪频（规则2、3）
        │是
        ▼
  联测窗完成？（本网金机 + 必要邻居；影响边界则挂 S）
        │否──▶ 禁签「保障就绪」（V-联 / 规则4）
        │是
        ▼
  写频 / OTAP / 临时信道表前再次核对临时台账（规则5，挂 J / M / U，主贴 V）
        │
        ▼
  保障期运行：超窗预警；投诉进线挂 T；边界变更先通知后复测（规则7）
        │
        ▼
  闭幕 / 窗末日：强制回收——降功率/关停/拆临时天线/回写台账（规则6）
  结案词用 V 子类；公开包 L3（规则8）
```

现场口诀：

> **先证临时覆盖，再写频开站；有窗有测，闭幕必收。**  
> 跳过联测的「保障就绪」= 没通电验收就对外宣称展馆可进场。

## 3. 核心交付：插页 V + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 V（而不是先贴 U / S / T / J / M）

| 现场信号 | 主贴 | 可次挂 |
|----------|------|--------|
| 重大保障临时频 / 临时站 / 保障窗 | **V**（先对临时批复与窗） | U / S / J / M |
| 临时批复临期 / 过期 / 超窗 | **V-治** | U（若涉永久） |
| 联测未完要签保障就绪 | **V-联** | S |
| 闭幕回收 / 窗末日关停 | **V-收** | U（台账回写） |
| 跨网/边界临时频 | **V** + 挂 **S** | T（若已投诉） |
| 保障期投诉进线 | **T**（不是 V） | 可查 V 作内因 |
| 永久许可/执照变更（非临时） | **U**（不是 V） | — |
| 仅写频参数对错、临时批复与窗已齐 | **J**（临时段已由 V 放行） | V 存档指针 |

> **口诀**：永久证照 → **U**；邻居与联测方法 → **S**；投诉分诊 → **T**；写什么进终端 → **J / M**；**临时批复还盖得住保障期吗、窗在不在、联测完了吗、闭幕收了吗 → V**。可叠挂，**临时保障主贴 V**。

### 3.2 插页 V · 临 / 窗 / 联 / 收 / 治（挂在总三联单或保障/写频单后）

| 行 | 名称 | 填写示例（教学虚构，L3） |
|----|------|--------------------------|
| **V1** | 主子类 + 次子类 | 「主 V-临 / 次 V-联」（或 V-窗 / V-收 / V-治） |
| **V2** | 临时批复核对 | 「有效期内 · 覆盖保障期 · 频点组覆盖（相对道号）· 地域覆盖 · 用途一致 · 功率上限已读」——禁写真实频点与全文号 |
| **V3** | 保障窗书面起止 | 「起：活动日前 D 日 HH:MM · 止：闭幕日 HH:MM · 书面编号角色 · 当前在窗内」 |
| **V4** | 临时台账对账勾选 | 「□批复编号(脱敏) □起止时刻 □频点组脱敏 □功率上限 □临时台址脱敏 □联测状态 □回收计划」 |
| **V5** | 联测窗 | 「本网金机：完成 · 必要邻居：已挂 S 完成 / 未完成」——未完成禁签保障就绪（规则4） |
| **V6** | 邻居与边界 | 「不影响边界 / 已书面通知+联测窗」——未通知禁宣称跨网临时就绪（规则7） |
| **V7** | 动作与禁令 | 「已冻结无批复开站；已排回收清单；拒签超窗 OTAP」 |
| **V8** | 回收与脱敏 | 「窗末日回收主人角色；公开包 L3；全文号仅存受控柜」 |

> **V2 / V3 任一否 → 禁止写频开临时站扩功率挪频（规则1、2、3）。**  
> **V4 缺任一项 → 禁签「保障就绪」相关放行（与规则4、5同向）。**  
> **V5 联测未完 → 禁签保障就绪（规则4）。**  
> **V6 影响边界但未通知 → 本页作废重填（规则7）。**  
> **V7 若写「先开后补」「临时变永久」「先用着再说」→ 本页作废（规则2、3、6）。**  
> **V8 无回收主人 → 禁签开幕放行（规则6 前置）。**

### 3.3 「无批复/过期/超窗/未联测/不回收拒签」卡（贴值班台 / 写频室 / 保障办）

```text
  ┌──── 重大保障临时频率与联测窗拒签卡（贴纸 V）────┐
  │  × 无临时批复或不覆盖保障期仍写频开临时站        │
  │  × 批复过期 / 超保障窗仍开站扩功率挪频            │
  │  × 「先开后补」「临时变永久」叙事                   │
  │  × 联测窗未完成（本网或必要邻居）仍签保障就绪    │
  │  × 写频 / OTAP / 临时信道表前未对临时台账          │
  │  × 闭幕/窗末日未降功率关停拆临时天线回写台账      │
  │  × 边界侧临时频不通知邻居、不联测（应挂 S）        │
  │  × 公开包出现真实频点 / 站名 / 单位名 / 批复全文号 / 坐标 / 联系人 │
  │  √ 例外：主管部门书面调取原件——走法定程序，另册登记 │
  └──────────────────────────────────────────────────┘
```

### 3.4 和总三联单怎么写（接手册06）

- **现象**：写「拟开临时站 / 拟写临时信道 / 拟签保障就绪 + V 子类」，**联测未完、回收未排前不写「保障就绪」**。  
- **证据**：临时批复有效期角色、书面起止、临时台账勾选、联测记录角色、邻居通知（若有）、回收清单；全部 L3。  
- **结论**：用 V 子类 + 放行/拒签；次挂 U/S/T/J/M 时写清主贴仍是 V。  
- **动作**：申请/延续临时批复、冻结工单、排联测窗、排回收——**禁止**写「先开后补」「先用着再说」。
