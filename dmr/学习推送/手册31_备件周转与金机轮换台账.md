## 1. 为什么要写这篇手册（动机 + 现场对话）

前三十篇手册从 A–E 协议一路写到 AC 机动开撤：其中 **G 回答「台架闭环有没有金机锚」**，**J 回答「写频变更与金机基线怎么回滚」**，**手册18 回答「金机基线漂没漂」**，**Y 回答「检测贴签与准入账齐不齐」**，**AC 回答「机动这一趟开撤清不清、回库指针有没有」**。可还没有单独钉死一件事——**备件从入库到顶岗到回库，金机从标定到轮换到隔离，台账谁建、谁签、谁负责过期与漂移？能不能拿过期金机去「证明」现场机合格？能不能套他站基线？** 这就是本篇的 **AD**——**备件周转与金机轮换台账**。

- 仓管：「柜里随便拿一台顶岗，回头补账。」——**无账出库顶岗** = 本篇拒准（规则1）。  
- 网优：「金机借给外勤修车三周了，基线过期也先用着对照。」——**过期/漂移金机顶岗** = 规则4。  
- 写频员：「他站金机码片拷过来，省得重做基线。」——**套他站他机基线** = 规则5。  
- 班长：「库管系统绿灯，这台就能发。」——**假绿顶替校准/准用签** = 规则6。  
- 项目经理：「坏了直接换备件，序列号以后再录。」——**口头周转、无主人** = 规则1 / 规则3。  
- 实验室：「金机一直钉死不轮换，越用越『标准』。」——**不轮换、不巡漂移** = 规则2 / 规则3（回挂手册18）。  
- 施工队：「功率抬一点压邻居，备件机先顶着。」——**功率战** = 规则7。  
- 宣传岗：「把备件序列号全文、库位、金机基线截图发群表扬周转快。」——**L3 违规** = 规则8。  

这几句背后是同一件事：

> **「备件周转与金机轮换」在现场至少有五个坑**：**① AD-周** 入库/出库/回库/隔离必须进台账，禁无账顶岗；**② AD-换** 金机轮换有计划、有替岗、有对照窗，禁「永远同一台不换」也不许「随便换一台当金机」；**③ AD-账** 台账有主人、有脱敏编号、有状态机（在库/在检/准用/在岗/待修/隔离/报废）；**④ AD-准** 效期与基线期内、贴签与校准指针齐才签「准用/可顶岗」；**⑤ AD-治** 治理（过期顶岗、套基线、假绿、伪造账、功率战、泄密）。  
> 把 ①–⑤ 当成「柜里有就能发」「绿灯就能用」「口头说一声」，每一次金机对照、每一次应急换机、每一次交维后首年巡检抽检，都会先吵「到底哪台是金机、基线过没过期、备件从哪来的」。

本篇目标：能背出**备件/金机周转工作流**；会用新贴纸 **AD（周 / 换 / 账 / 准 / 治）**；会填**插页 AD（AD1–AD8）**和《本网备件周转与金机轮换台账卡》；能用「**医院抢救车 / 药房近效期：入库贴签 → 效期上架 → 近效先出轮换 → 过期隔离退库**」故事讲清入库必账、有期才准用、轮换有记录、过期禁顶岗；能拒绝无账发机、过期金机对照、套他站基线、假绿放行；自测过关后，回库把本网最近一次备件出库或金机轮换（L3）重对一遍：入库账、基线有效期、轮换主人、准用签、隔离项。

**本篇硬禁令（写进脑子）**：凡引法规与标准只指向已公开发布的文书标题与官方链接（无线电管理条例、频率使用许可管理办法、地面无线电台（站）管理规定、国无办〔2025〕1号；**只作故事类比**的医院抢救车/基数药品近效期轮换公开规范标题，以及公开的金机/golden unit、备件库存、无线电资产/缓存管理资料），**程序、期限、责任以原文与属地最新要求及本网制度 / 合同为准，本篇只作教学转述，不发明条款号与内部口径**；抢救车药品管理与境外 radio cache / golden unit 公开资料**不是**中国专网台站法定依据；**现象与台账一律用相对道号、角色标签、脱敏编号，禁真实频点 / 站名 / 单位名 / 序列号全文 / 库位坐标 / 联系人**；**不教伪造周转台账、不教功率战、不教规避监测、不教过期金机顶岗、不教套他站基线不经重基线、不教假绿顶替**；G / J / Q / Y / AA / AC / R / S / T 各管各的——**周转与轮换台账主贴 AD**；金机对照方法回 G，基线变更回 J，漂移巡检回手册18，贴签准入回 Y，机动回库指针回 AC——**AD 管「账与期与轮换秩序」，不替代对照方法本身**。

## 2. 总图 / 故事：备件与金机像「医院抢救车 / 药房近效期：入库贴签 → 效期上架 → 近效先出轮换 → 过期隔离退库」

### 2.1 一句话：备件不是「柜里有就能发」、金机不是「贴了金机标签就永远标准」——要先入库建账贴签，效期与基线期内才准用，轮换要有主人有记录，过期/漂移必须隔离，不能拿过期药去「证明」别人合格

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  抢救车/药房近效期轮换  =  本网备件周转 + 金机轮换台账         │
   │                                                              │
   │  入库验收·贴签·建账         ≈ AD-周  入库必账必签·标识进柜   │
   │  近效先出·值班轮换·替岗     ≈ AD-换  金机/热备按计划轮换     │
   │  基数卡·效期卡·交接记录     ≈ AD-账  台账主人·状态机·脱敏号 │
   │  有效期内才可取用·近效预警  ≈ AD-准  基线期/校准期才签准用   │
   │  过期隔离·变色禁发·假绿治理 ≈ AD-治  过期顶岗·套基线·假绿   │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **入库必账，有期才准，轮换有主，过期隔离。**  
> 柜里有就发 = 抢救车没点检就发过期针剂——**拒签「准用/可顶岗」**。  
> 金机永不动、过期还对照 = 标准样过期还当尺——**拒对照结论入库**。

### 2.2 「抢救车 / 药房近效期」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **周转** | 药从药房入库、贴签、按位上架；用后补齐回账 | 备件/金机入库验收、标识、入柜、出库顶岗、回库点检 | AD-周 |
| **轮换** | 近效先出、值班抢救车定期开箱检查与替换 | 金机按计划轮换、热备与在岗对调、漂移巡检窗 | AD-换 |
| **台账** | 基数卡、效期卡、交接班记录、封闭/开箱留痕 | 台账卡：脱敏编号、状态、主人、基线指针、出入记录 | AD-账 |
| **准用** | 有效期内、性状正常才可取用；近效预警先调剂 | 基线有效期/校准指针/贴签（Y）齐才签「准用」 | AD-准 |
| **治理** | 过期/变色隔离退库；禁涂改效期；禁口头补账 | 过期顶岗、套他站基线、假绿、伪造账、泄密 → 治理 | AD-治 |

> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：医疗机构抢救车/基数药品管理强调**目录与基数相对固定、先进先出/近效先用、近效期标识、过期不得使用、使用后及时补充并留记录、定期检查**（团体标准与地方规范公开标题见 §10，**只借秩序直觉，不是无线电法定依据**）；RF 生产测试中的 **golden unit / golden sample** 公开资料强调**已知好机作参考、要有基线记录、要有验证日程、磨损与漂移要退役**（§10）。本篇只借这串顺序——**本网备件与金机的准用、轮换周期、基线方法以本网制度与合同为准**。

### 2.3 和手册08 / 11 / 14 / 18 / 26 / 27 / 28 / 30 等的咬合（指针，不重写）

- **G（手册08）**：实验室闭环里的**金机对照方法**；AD 不重写怎么测，只钉「这台金机有没有账、有没有期内基线、能不能当锚」。  
- **J（手册11）**：写频变更回滚与**金机基线制度**；基线更新、变更单、回滚指针挂 J；AD 管周转账与准用期。  
- **手册14**：大批量写频与 OTAP；批量改写后，备件/金机是否同步进账与重基线——指针回 14 + J，主贴仍可能 AD（账没跟上）。  
- **手册18**：金机基线**漂移巡检**；AD-换 / AD-准 的「期内」常靠 18 的巡检证据；漂了 → 隔离，禁继续顶岗对照。  
- **Y（手册26）**：检测贴签与准入；备件发往重大活动场次时常与 Y 同场——Y 管「检了没、准入账」，AD 管「库内周转与金机轮换账」。  
- **Z / AA**：开站交维与首年巡检；抽检备件/金机状态时可挂 AD 台账核对，不互相顶替。  
- **AC（手册30）**：机动开撤**回库指针**（历史亦称 Q）；撤收回库的金机/备件必须接上 AD 台账，禁「撤完就失踪」。

- **R / S / T**：假绿挂 R；跨网/互扰挂 S；投诉挂 T；禁功率战。

### 2.4 新贴纸 AD：周 / 换 / 账 / 准 / 治（五个子类）

> 小彩蛋：双字母贴纸续写——**AA** 管「交维后首年巡检与保修尾项」；**AB** 管「室分复测」；**AC** 管「机动开撤」；**AD** 管「备件周转与金机轮换台账」。A–Z 既有含义不改；新专题用 AA、AB、AC、AD… 续写。

```text
                ┌──────────── 贴纸 AD · 周/换/账/准/治 ────────────┐
                │  AD-周  周转：入库·出库·回库·隔离·补齐进账         │
                │  AD-换  轮换：金机计划轮换·热备替岗·漂移巡检窗     │
                │  AD-账  台账：脱敏编号·状态机·主人·基线指针       │
                │  AD-准  准用：基线期/校准/贴签齐才签「准用」       │
                │  AD-治  治理：过期顶岗·套基线·假绿·伪账·泄密     │
                └──────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒准 / 拒轮换签触发 |
|------|--------|-------------------------|
| **AD-周** | 无账出入库、账实不符仍要发机 → 拒发 | 「回头补账先拿走」 |
| **AD-换** | 无计划乱换金机、或该换不换仍当锚 → 停换/拒对照 | 「永远这台金机不用换」 |
| **AD-账** | 无主人、无状态、序列全文上公开仓 → 治理 | 「口头说一声就行」 |
| **AD-准** | 过期/无基线/贴签不符仍签准用 → 拒准 | 「过期几天没事」 |
| **AD-治** | 套他站基线、假绿、伪账、功率战、泄密 → 治理 | 「拷他站金机码片」 |

### 2.5 入库建账 → 标定/贴签 → 准用 → 在岗/轮换 → 回库/隔离 阶段梯（背下来）

```text
  ① AD-周 入库：到货验收 · 脱敏编号 · 入柜定位 · 建台账行
        │  缺账 / 账实不符 → 拒入正式库（隔离待查）
        ▼
  ② 标定与贴签指针：金机做基线（挂 G/J）· 检测贴签（Y）· 校准有效期
        │  金机无基线记录 → 不得标「金机准用」
        ▼
  ③ AD-准 签「准用/可顶岗」：期内 + 贴签一致 + 授权本人签 + 台账主人
        │  过期/漂移/套基线 → 拒准
        ▼
  ④ 在岗使用 / AD-换 按计划轮换（金机对照窗、热备对调）
        │  变更写频/固件 → 走 J 并重基线；漂移 → 手册18 + 隔离
        ▼
  ⑤ 回库点检（或 AC 撤收回库指针）→ 状态改回「在库/在检」
        │  损坏/可疑 → 「待修/隔离」；禁直接当准用
        ▼
  ⑥ 过期/报废/隔离出库：台账闭环；禁回流顶岗
```

> **一句话分辨**：**G** 回答「台架上**怎么对照**」；**J** 回答「基线**怎么变更回滚**」；**手册18** 回答「基线**漂没漂**」；**Y** 回答「检测贴签准入齐不齐」；**AC** 回答「机动回库指针接没接上」；**AD** 回答「这台备件/金机**账在不在、期在不在、轮换清不清**」。**六个问题，六张（类）贴纸，不能一笔带过。**

## 3. 核心交付：插页 AD + 拒发/拒准/拒轮换签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AD（而不是先贴 G / J / Y / AC）

| 场景 | 主贴 | 为什么 |
|------|------|--------|

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **入库必账必签：备件/金机入正式库前须验收记录 + 脱敏编号 + 台账行；无账不得出库顶岗；账实不符先隔离**。  
2. **金机有基线有期：称「金机」必须有基线记录指针（G/J）与有效期角色；无基线或过期不得当对照锚**。  
3. **轮换有主有记录：出库/轮换/回库须有主人角色与记录；金机按计划轮换，禁口头周转**。  
4. **过期/漂移禁顶岗：基线过期、贴签过期、漂移巡检不过 → 状态改隔离/待检，禁继续准用或对照**。  
5. **禁套：禁套他站他机基线不经本网重基线；禁套他机过期贴签；禁改日期伪装期内**。  
6. **可挂 G/J/Y/AC/R/Q 支撑，但周转与轮换台账主贴 AD；库系统绿灯、假绿不等于已准用（挂 R 提醒）**。  
7. **写频/固件/角色变更走 J 并评估重基线；跨网挂 S，投诉挂 T；禁功率战；保修/巡检抽检可挂 AA**。  
8. **对外/公开仓一律脱敏 L3；禁贴序列号全文/库位坐标/真实站名单位名/联系人**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可、地面无线电台（站）规定决定「台站与设备按什么秩序管」——**备件乱发、过期金机当尺，不是法外运维智慧**。抢救车近效期与 golden unit 公开资料只作故事与方法类比（§2.2）：**有账、有期、近效先出、过期隔离、参考件要维护**——翻译成本网语言就是 AD-周 / AD-换 / AD-账 / AD-准 / AD-治。**这些是周转秩序，不是「无账先发」「过期继续对照」「拷他站基线」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「准用/可顶岗」「金机对照合格入库」、对外宣传「分钟级无账发机」、把隔离机写成准用。允许做的：补验收、补基线、隔离、挂 R/J、内部挂待检。

|----------|------|------|
| 台架上怎么用金机复现故障 | 对照方法 | **G** |
| 写频改了基线怎么回滚 | 变更单 | **J** |
| 金机指标是不是漂了 | 巡检窗 | **手册18** + AD 状态 |
| 活动场次机子检了没 | 贴签准入 | **Y**（常挂 AD） |

### 4.3 「准用」最小集（AD-准）——缺页不能签「准用/可顶岗」

| 序号 | 最小集项（教学） | 为什么必须有 | 缺了会怎样 |
|------|------------------|--------------|------------|
| 1 | **脱敏资产编号**与实物一致 | 防拿错机、防无账机 | 对不上 → 拒发 |
| 2 | **状态=准用**（非隔离/待修/过期） | 状态机是闸 | 非准用 → 拒发 |
| 3 | **金机：基线记录指针 + 有效期未过** | 尺必须在期内 | 过期 → 拒对照 |
| 4 | **贴签/校准有效期指针**（常挂 Y） | 防过期贴 | 过期/套贴 → 拒准 |
| 5 | **出库主人 + 用途角色 + 预计回库** | 有主可追 | 无主 → 拒发 |
| 6 | **授权本人签「准用」**（首次准入或复检后） | 可复核 | 「系统绿」不够 |
| 7 | **与写频/固件角色边界一致**（变更走 J） | 防旧基线套新码 | 不符 → 挂 J，拒准 |
| 8 | **回库点检勾选**（再次准用前） | 外勤机可能已伤 | 未点检 → 不改回准用 |
| 9 | **漂移巡检指针**（金机，挂手册18） | 期内也可能漂 | 应巡未巡 → 慎当锚 |

> **口诀**：号、态、基、签、主、人、界、回、漂——**九字准用钉**（教学记忆；现场以本网书面备件/金机规程为准，但 **账号 + 期内基线 + 准用签 + 有主人** 几乎不可砍）。  
> **弱项短补（为什么过期金机比坏备件更危险）**：坏备件顶岗，用户马上喊「不通」；**过期金机当尺**，实验室会把好机器判坏、坏机器判好，整网工单方向全反，还看起来「很科学」。这和抢救车发过期急救药一样——**不是「还能用一点」，是「用了会系统性害人」**。

### 4.5 轮换与隔离清单（AD-换 / AD-治）

### 4.10 金机「期内」不等于「免巡」——和手册18 的咬合表

| 情况 | 手册18 | AD |
|------|--------|-----|
| 到巡检窗，指标仍在容差 | 记「未漂」 | 保持准用；更新巡检指针日期角色 |
| 到巡检窗，指标出容差 | 记「漂移」 | **立即隔离**；禁对照；安排重基线或退役 |
| 未到巡检窗，但外勤磕碰/私改写频嫌疑 | 可提前触发巡检 | 先隔离待检，不凭感觉继续当锚 |
| 刚完成 J 变更重基线 | 新基线日起算巡检周期 | AD 更新基线有效期与准用签 |

> **口诀**：期内管「日历没过期」；巡检管「尺子还直不直」——**两道闸，缺一不可**。

### 4.11 备件品类最小分工（教学，不发明库存定额）

| 品类角色 | 周转关注点 | 常见拒发点 |
|----------|------------|------------|
| 手台/车台整机 | 写频角色是否与用途一致；电池电量直觉 | 无准用、写频角色不符（挂 K/J） |
| 功放 / 信道机模块 | 回库必点检；禁带伤准用 | 未点检改回准用 |
| 馈线 / 跳线 / 接头 | 外观与通断直觉；驻波相关故障高发 | 账实不符、混用他站线材角色 |
| 金机（对照专用） | 基线期 + 漂移巡检 + 少外勤滥用 | 当普通备件顶岗磨损耗尺 |
| 测试辅件（负载/衰减等） | 校准有效期指针 | 过期仍出具「定量」结论 |

> **金机尽量不做普通顶岗备件**：抢救车里的「标准对照液」不会拿去当日常输液——磨坏了，整网对照失真。

### 4.12 与保修 / 首年巡检（AA）抽检怎么配合

交维后首年巡检（手册28）若抽到「备件柜账实、金机期内、轮换记录」，**抽检结论可挂 AA，缺项整改主贴仍是 AD**——AA 不替代建账，AD 不替代巡检计划本身。保修期内设备返修进出库，同样走 AD-周，并在台账备注保修单号角色（脱敏）。

### 5.2 三段对话脚本（可练）

## 6. 工作实例（10 则，教学虚构，L3）

1. **无账发机**  
   现象：夜班从柜里拿车台顶岗，未登台账。  
   处置：AD-周 追回或补建账并补准用核；三联单记治理。  
   教训：支援速度不等于无账机。

2. **过期金机对照**  
   现象：金机基线过期 40 天，仍出具「对照合格」。  
   处置：撤销结论；隔离金机；换期内金机重对；挂手册18。  
   教训：过期尺比坏机更害人。

3. **套他站基线**  
   现象：写频员拷邻网金机码片标「本网金机」。  
   处置：AD-治；取消金机角色；本网重基线（J/G）。  
   教训：拷贝≠基线。

4. **假绿放行**  
   现象：资产系统显示 Available，班长直接发重大活动场。  
   处置：挂 R；查准用签与 Y 贴签；缺则拒发。  
   教训：系统态≠AD-准。

5. **金机永不轮换**  
   现象：同一台金机使用两年未轮换未巡漂移。  
   处置：AD-换 强制轮换窗；手册18 巡检；必要时退役。  
   教训：不用的近效药也会过期——常用的尺也会磨。

6. **机动回库失踪**  
   现象：AC 签撤完，备件未进 AD 账。  
   处置：AC+AD；追实物；补回库点检；禁直接改准用。  
   教训：撤完指针必须接台账。

7. **热备顶岗未改状态**  
   现象：热备已在岗两周，台账仍显示在库准用。  
   处置：补出库行与主人；状态改在岗。  
   教训：账实长期背离是事故温床。

8. **批量 OTAP 后未重基线**  
   现象：手册14 批量升级后，金机未走 J 重基线仍对照。  
   处置：挂 J+AD；冻结对照结论；重基线后再准用。  
   教训：固件变了，尺的刻度也可能变。

9. **功率战顶岗**  
   现象：备件机被抬功率压邻居。  
   处置：禁功率战；挂 S；AD-治；参数回写走 J。  
   教训：备件不是功率战工具。

10. **公开仓泄密**  
    现象：把序列号全文与库位发到公开群。  
    处置：撤回；L3 重发；AD-治。  
    教训：周转效率可以表扬，编号必须脱敏。


11. **把金机当普通顶岗**  
    现象：缺机时把唯一金机发给现场用一周。  
    处置：AD-换/治；追回；点检+漂移巡检；必要时重基线；热备应另备非金机顶岗机。  
    教训：尺拿去干活，回来可能已不是尺。

12. **隔离机回流准用**  
    现象：隔离区机器被好心人「擦干净」放回准用架，未重检。  
    处置：追回隔离；强制在检流程；台账记治理。  
    教训：隔离不是「暂时放一下」的货架。

## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 一句话（教学） |
|------|----------------|
| **备件** | 用于顶岗替换的手台/车台/模块等（非正在主用编制内的那一台角色） |
| **金机** | 已知基线、用于对照的参考机（golden unit 直觉）；**不是**「最好的新机」同义词 |
| **基线** | 金机在规定方法下记录的参考结果与配置指针（挂 G/J） |
| **AD-周** | 入库出库回库隔离的周转秩序 |
| **AD-换** | 金机/热备按计划轮换 |
| **AD-账** | 台账、状态机、主人、脱敏编号 |
| **AD-准** | 期内+签准用才可顶岗/当锚 |
| **AD-治** | 过期顶岗、套基线、假绿、伪账等治理 |
| **准用** | 授权签过的可用状态；≠系统绿灯 |
| **隔离** | 过期/漂移/可疑，禁顶岗禁对照 |
| **轮换** | 按计划换上换下并留痕 |
| **近效先出** | 故事借语：先消耗更近有效期的库存（FIFO/FEFO 直觉） |
| **假绿** | 系统/屏显示可用，但无准用签或已过期 |
| **套基线** | 把他站他机基线当成本网金机基线 |
| **回库点检** | 外勤返回后的最小检查，通过前不改回准用 |
| **九字准用钉** | 号态基签主人界回漂（教学记忆） |
| **轮换八字钉** | 计划换、换下检、换上准、对照留痕 |
| **与 G/J/18 分工** | 量法 / 改尺 / 看歪；AD 管账与期 |

**易错观念**

- ❌「柜里有就能发」→ ✅ 入库必账，准用才发。  
- ❌「金机标签=永远标准」→ ✅ 有基线有期，漂移要隔离。  
- ❌「拷他站基线更快」→ ✅ 禁套；本网重基线。  
- ❌「系统绿=准用」→ ✅ 假绿挂 R，主贴 AD。  
- ❌「机动撤完机自然回库」→ ✅ AC 指针必须接 AD 账。

## 9. 自测（12 题）+ 参考答案

1. 贴纸 AD 五个子类是什么？各用四个字以内说明。  
2. 抢救车/药房故事里，「近效先出 / 过期隔离」主要对应 AD 哪两段？  
3. 八条硬规则里，哪一条要求入库必账必签？  
4. 为什么过期金机比坏备件往往更危险？  
5. 「准用」至少要具备哪几样（九字准用钉里不可砍的）？  
6. 金机永不轮换有什么问题？主贴哪一子类？  
7. AD 与 G / J / 手册18 的分工一句话？  
8. 套他站金机基线，主贴什么？能不能直接当本网金机？  
9. 库系统绿灯想发机，应挂什么提醒？主贴谁？  
10. 机动 AC 撤完但备件未进账，应挂哪两张？  
11. 批量 OTAP 后金机未重基线仍对照，应走什么变更贴纸？  
12. 公开材料能不能贴序列号全文与库位？依据哪条规则？

### 参考答案

1. **周**（周转出入库）、**换**（金机/热备轮换）、**账**（台账状态主人）、**准**（期内准用签）、**治**（过期套基线假绿泄密）。  
2. **AD-换** 与 **AD-准/治**（近效轮换；过期隔离禁顶岗）。  
3. **规则1**。  
4. 它会系统性判错好坏，整网工单方向反转，还看起来「科学」。  
5. **脱敏号与账、状态准用、期内基线/贴签、准用签、出库主人**（规则1–4；九字钉核心）。  
6. 磨损与漂移积累，尺会歪；主贴 **AD-换**（并挂手册18）。  
7. **G 量法、J 改尺、18 看歪、AD 管哪把尺在不在保质期与借还清不清**。  
8. **AD-治**；**不能**，须本网重基线。  
9. 挂 **R**；主贴 **AD**（规则6）。  
10. **AC + AD**。  
11. **J**（并 AD 更新基线期；规则7）。  
12. **不能**；**规则8 脱敏 L3**。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AD** 五子类：周 / 换 / 账 / 准 / 治——双字母续写的第四张，负责备件与金机「账在不在、期在不在、轮换清不清」。  
- 故事：医院抢救车 / 药房近效期——入库贴签 → 效期上架 → 近效先出轮换 → 过期隔离退库；金机是「标准样」，过期不能当尺。  
- 阶段梯：入库建账 → 标定贴签 → 准用 → 在岗/轮换 → 回库/隔离/报废。  
- 八条硬规则：**入库必账必签**；**金机有基线有期**；**轮换有主有记录**；**过期漂移禁顶岗**；**禁套他站他机基线**；**主贴 AD，假绿≠可用**；**变更走 J、复测挂回**；**脱敏 L3**。

### 11.2 下一篇手册候选（本篇不写正文）
- **隧道/地铁区间联测与换乘责任界面**（与 AB/I/S/N 咬合）  
- **油机/市电切换与机房供电巡检边界**（与 AC 展开电源勾选、AA 巡检咬合，仍 L3）

### 11.3 给带新人的三句话
1. 备件不是柜里有就能发：入库必账，准用才出库，回库要点检。  
2. 金机不是贴了标签就永远标准：有基线有期，漂移要隔离，禁套他站基线。  
3. 假绿挂 R；主贴 AD；变更走 J；机动回库接 AC；公开脱敏 L3。
