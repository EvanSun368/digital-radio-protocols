## 1. 为什么要写这篇手册（动机 + 现场对话）

前二十三篇手册把「家里怎么养」「邻居怎么处」「投诉怎么分诊」「证照台账怎么对」「重大保障临时窗怎么钉」基本写全了：A–E 协议，F 射频指纹，G 实验室，H 话务，I 室分，J 写频，K 电源，L 井库，M 批量 / OTAP，N 监控对时，O 有源隔离，P 口部，Q 金机，R 假绿演练，S 邻频协调，T 干扰投诉，U 许可执照台账，V 临时保障窗。可现场还有一类债——**非法设台与黑广播类线索内部上报边界**：

- 夜班：「扫频听见一段像卖药广告的广播，是不是黑广播？我马上发群让大家定位。」——**未分诊就对外定性 + 越权排查叙事** = 本篇拒签（规则1、3、4）。  
- 运维班长：「这干扰太烦，先把边界功率顶上去压一压。」——**功率战报复** = 规则3、7（挂 S/T 提醒）。  
- 新人：「我们自己无证那台是不是也算非法设台？要不要按黑广播举报自己？」——**本网无证/过期是 U/V 治理，不是猎杀叙事**（规则6）。  
- 领导：「证据还不齐，但对外先说『已确认黑广播』，好推动。」——**证据最小集未齐禁对外正式定性**（规则2）。  
- 协调岗：「邻居那边好像有不明发射，我们自己去找找到了再谈。」——**跨网先协调挂 S；争议报无线电管理机构**（规则7）；**不自行排查对抗**（规则3）。  
- 宣传：「把录音原件和真实频点贴到公开周报，让大家提高警惕。」——**L3 违规 + 断链风险**（规则8）。

这几句背后是同一件事：

> **「非法设台与黑广播类线索」在现场至少有五个坑**：**① W-线** 线索怎么进线、怎么分级（疑似非法设台 / 疑似黑广播 / 本网故障误报 / 邻网合法 / 不明）；**② W-证** 证据最小集与保全（时间、地点角色、现象描述、本网日志指针、录音/频谱截图角色——一律 L3；断链禁当正式对外证据）；**③ W-报** 内部上报路径与对外依法报告边界（谁可报、报给谁、报什么、不报什么）；**④ W-界** 运维边界——本网只做合规监测与自家台账；**不自行排查对抗、不私自定位打击、不功率战报复、不网暴、不「私了」**；**⑤ W-治** 拒签/拒放行——假线索、无证据最小集就对外定性、公开仓泄密、越权执法叙事。  
> 把 ①–⑤ 当成「听见像就是」「先定性再补证」「自己去捣窝点」「功率顶回去」「发自媒体定罪」，会把下一任、邻居、主管部门和本网合规一起拖进泥潭。

本篇目标：能背出**非法设台与黑广播类线索内部上报工作流**；会用新贴纸 **W（线 / 证 / 报 / 界 / 治）** 与五个子类；会填**插页 W（W1–W8）**和《本网非法设台与黑广播类线索内部上报卡》；能用「**药店发现假药线索 → 内部登记 + 送监管，不当街私了、不当侦探自己捣窝点**」故事讲清：先分诊、证据保全、依法上报、运维边界、拒签；能拒绝「未分诊对外定性、证据未齐定罪、自行排查对抗、功率战、网暴私了、公开泄密」；自测过关后，回库把本网最近一次相关线索（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：凡引法规均指向已公开发布的文书标题与官方链接（《中华人民共和国无线电管理条例》《无线电频率使用许可管理办法》《地面无线电台（站）管理规定》《无线电台执照管理规定》《中华人民共和国无线电管制规定》及工信部/国无办公开的打击黑广播·非法设台相关通报与科普、干扰投诉受理公开文件等），**数字、时限、程序、处罚幅度以原文与属地最新要求为准，本篇只作教学转述，不发明条款号以外的「内部口径」或内部配额**；**现象与台账一律用相对道号、角色标签、脱敏编号表述，禁真实频点 / 站名 / 单位名 / 证据原件全文号 / 联系人 / 坐标**；**不教查找/测向定位打击/拆窝点/干扰对抗/规避监测/伪造报告/私力执法话术**；T 仍管投诉进线分诊，U/V 仍管本网证照与临时窗，S 仍管邻频协调——**非法/黑广播类线索主贴 W**；外国 / ITU 资料只借**频谱监测与频谱管理方法级表述**，**查处与执法以国内法规与属地无线电管理机构为准**。

## 2. 总图 / 故事：线索像「药店发现假药 → 内部登记 + 送监管」

### 2.1 一句话：非法设台 / 黑广播类线索像药店发现假药线索——先分诊是不是假药、保全证据最小集、内部登记上报、依法送监管；不当街私了、不当侦探自己捣窝点、不网暴定罪

```text
   ┌──────────────────────────────────────────────────────────────────┐
   │   药店值班 + 药监/公安法定渠道（= 本网运维 + 无线电管理机构等） │
   │                                                                  │
   │   进线分诊（W-线）                                               │
   │     疑似假药 / 本店过期药 / 邻店合法货 / 顾客误报 / 不明          │
   │                                                                  │
   │   证据保全（W-证）                                               │
   │     时间·地点角色·现象·本店台账指针·录音截图角色 · 断链禁对外   │
   │                                                                  │
   │   内部上报 + 依法外报（W-报）                                    │
   │     谁可报·报给谁·报什么·不报什么 · 禁自媒体定罪                │
   │                                                                  │
   │   运维边界（W-界）                                               │
   │     只做合规监测与自家台账 · 不自行捣窝点·不功率战·不私了      │
   │                                                                  │
   │   治理拒签（W-治）                                               │
   │     假线索/无证最小集定性/公开泄密/越权执法叙事 → 拒签         │
   └──────────────────────────────────────────────────────────────────┘
```

口诀：

> **先分诊，再保全；内部有主人，对外走法定。**  
> 未分诊就对外喊「黑广播」= 药店没核对就把顾客当售假犯游街——**拒签**。  
> 自己开车去捣窝点 = 药店员当街私了——**越权，本篇红线**。

### 2.2 「假药线索 → 送监管」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **线索进线** | 顾客/同事报「这药不对劲」 | 先分级：疑似非法设台 / 疑似黑广播 / 本网故障误报 / 邻网合法 / 不明 | W-线 |
| **证据保全** | 留样、拍照、记录批号角色（脱敏） | 时间·地点角色·现象·本网日志指针·录音/频谱截图角色；断链禁正式对外 | W-证 |
| **上报路径** | 内部质管登记 → 依法送药监/公安 | 内部有主人与时限；对外走无线电管理机构等法定渠道；禁网暴/自媒体定罪 | W-报 |
| **运维边界** | 药店员不是侦缉队 | 只做合规监测与自家台账；不自行排查对抗、不定位打击、不功率战、不私了 | W-界 |
| **拒签治理** | 假线索/无样定性/游街泄密拒签 | 假线索、无证据最小集对外定性、公开仓泄密、越权执法叙事 → 拒签 | W-治 |

> 公开文书告诉我们：不得擅自使用无线电频率，不得擅自设置、使用无线电台（站）；无线电管理机构负责监测、干扰查处；任何组织或者个人对未经许可擅自使用无线电频率或者违法使用无线电频率的行为，有权向无线电管理机构举报；依法设置、使用的无线电台（站）受到有害干扰的，可以向无线电管理机构投诉；工信部公开通报中鼓励通过 12381 等公开渠道投诉举报「黑广播」「伪基站」等（教学转述，**渠道与时限以原文与属地最新要求为准**）。本篇只借「先分诊、保全证据、依法报告、运维不做私力执法」的顺序，**不编造内部配额、不教查处技术细节**。

- **手册21 T**：投诉已进线后的分诊与证据链。**用户投诉「干扰」主贴 T**；若分诊后倾向「疑似非法设台/黑广播类」→ **可转主贴 W，互挂 T**。本篇不重写投诉证据链全文。

### 2.4 新贴纸 W：线 / 证 / 报 / 界 / 治（五个子类）

```text
                ┌──────────── 贴纸 W · 线/证/报/界/治 ────────────┐
```

| 子类 | 一句话 | 典型拒签 / 拒放行触发 |

## 3. 核心交付：插页 W + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 W（而不是先贴 T / U / V / S）

| 现场信号 | 主贴 | 可次挂 |
|----------|------|--------|
| 疑似非法设台 / 黑广播类线索（非普通用户投诉话术） | **W**（先分诊+证据+上报边界） | T / S |
| 用户已投诉「干扰」进线 | **T**（不是 W） | 分诊后可转/挂 W |
| 本网无证 / 过期 / 超窗临时发射 | **U / V**（不是 W） | — |
| 跨网疑似不明发射、需邻居协调 | **W** + 挂 **S** | T（若已投诉） |
| 假线索 / 无证据最小集要对外定性 | **W-治** | — |
| 仅本网故障误报（已证） | **T** 或运维故障单 | 可结案为「非 W」 |

> **口诀**：投诉进线 → **T**；本网证照/临时窗自纠 → **U / V**；邻居协调方法 → **S**；**非法/黑广播类线索的分诊·证据·上报·运维边界 → W**。可叠挂，**该类线索主贴 W**。

### 3.2 插页 W · 线 / 证 / 报 / 界 / 治（挂在总三联单或线索单后）

| 行 | 名称 | 填写示例（教学虚构，L3） |
|----|------|--------------------------|
| **W1** | 主子类 + 次子类 | 「主 W-线 / 次 W-证」（或 W-报 / W-界 / W-治） |
| **W2** | 线索分级 | 「疑似黑广播 / 疑似非法设台 / 本网故障误报 / 邻网合法 / 不明」——未选禁对外定性 |
| **W3** | 证据最小集勾选 | 「□时间 □地点角色 □现象描述 □本网日志指针 □录音/频谱截图角色（若有）□保管链未断」 |
| **W4** | 内部上报 | 「主人角色 · 时限 · 已报/待报 · 报出内容 L3 摘要」 |
| **W5** | 对外依法报告 | 「未报 / 已走法定渠道角色（如公开投诉受理路径）· 回执角色」——禁填自媒体链接当「已报」 |
| **W6** | 运维边界确认 | 「未自行定位打击 · 未功率战 · 未私了毁证 · 未网暴」——任一项勾「已做」→ 本页作废进治理 |
| **W7** | 与 T/U/V/S 互挂 | 「挂 T 编号脱敏 / 挂 U·V 自纠编号 / 挂 S 协调编号 / 无」 |
| **W8** | 脱敏与结案词 | 「公开包 L3；结案词用 W 子类；禁真实频点与原件全文号」 |

> **W2 未分诊 → 禁止对外正式定性（规则1）。**  
> **W3 缺任一项（教学最小集）→ 禁对外正式定性「非法设台/黑广播」；内部可挂待证（规则2）。**  
> **W4 无主人或超时无动作 → 开治理（规则4）。**  
> **W5 若写「已发群/已发短视频定罪」→ 本页作废（规则4）。**  
> **W6 若勾选了排查对抗/功率战/私了 → 本页作废进 W-治（规则3）。**  
> **W8 公开包出现真实频点/原件全文号 → L3 违规（规则8）。**

### 3.4 和总三联单怎么写（接手册06）

## 4. 深潜：八条硬规则 + 分诊题 + 证据最小集 + 上报路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **先分诊线索属性再谈上报**（本网故障误报 / 邻网合法 / 疑似非法设台 / 疑似黑广播 / 不明）——**未分诊禁对外正式定性**。  
2. **证据最小集未齐 → 禁对外正式定性「非法设台 / 黑广播」**；内部可挂「待证」继续保全。  
3. **运维边界：不自行排查对抗、不教测向定位打击细节、不功率战报复、不私了毁证**——药店员不是侦缉队。  
4. **内部上报有主人与时限；对外依法报告走无线电管理机构等法定渠道**（公开如 12381 等以属地最新为准）；**禁网暴 / 自媒体定罪**。  
5. **与手册21 T 分工：投诉进线主贴 T；非法 / 黑广播类线索主贴 W；可互挂**——不要两张皮互相顶。  
6. **与手册22 U / 23 V：本网无证 / 过期 / 超窗是 U/V 治理，不是「黑广播猎杀」；本网违章先自纠合规**——禁把自家违章写成「查获黑广播」。  
7. **跨网疑似问题先协调挂 S；争议报无线电管理机构；禁报复**——功率战不是协调。  
8. **脱敏 L3：公开包禁真实频点、站名、单位名、坐标、联系人、完整证据原件号**——原件受控另册。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：《无线电管理条例》明确不得擅自使用无线电频率、不得擅自设置使用无线电台（站），无线电管理机构负责监测与干扰查处，受到有害干扰可向无线电管理机构投诉；《无线电频率使用许可管理办法》明确任何组织或者个人对未经许可擅自使用或违法使用无线电频率的行为有权向无线电管理机构举报；《地面无线电台（站）管理规定》明确执照与使用行为规范；工信部公开通报鼓励通过 12381 等公开渠道投诉举报「黑广播」「伪基站」等。**这些是主管部门的管理与举报路径，不是你方「私力执法」或「功率战报复」的借口。**

### 4.2 线索分诊题（W-线）——假药线索先问「是不是假药」

```text
  ① 是否更像本网故障 / 误操作 / 假绿 / 邻道泄漏（挂 F/N/R/P）？
     → 是：主贴运维故障或 T（若已投诉），结案「本网误报」；禁对外定性非法/黑广播

  ② 是否更像本网无证 / 过期 / 超窗临时发射（挂 U/V）？
     → 是：主贴 U/V 自纠；禁写成「查获黑广播」（规则6）

  ③ 是否更像邻网合法业务（已协调/可核对邻居台账角色）？
     → 是：挂 S 核对；可能转「邻网合法」；禁猎杀叙事

  ④ 现象是否符合公开科普中的「黑广播」群众识别直觉（如异常广告内容角色、不报台号等——仅作分诊线索，非定罪）？
     → 倾向疑似黑广播：主贴 W，进入证据最小集；仍禁未证对外正式定性

  ⑤ 是否疑似未许可设台/用频，但内容不属广播广告类？
     → 倾向疑似非法设台：主贴 W；同上

  ⑥ 以上都不够清晰？
     → 分级「不明」；内部待证；禁对外定性；可依法咨询/报告渠道（规则4）
```

**未过分诊题的冻结清单**：对外新闻稿/周报写「已确认非法设台/黑广播」、发动群定位、功率顶回去、私了谈判毁证。允许做的：内部登记、证据保全、本网自查、挂 S 预协调、起草依法报告材料（L3）。

### 4.3 证据最小集（W-证）——留样才能送检

| 序号 | 最小集项（教学） | 为什么必须有 | 缺了会怎样 |
|------|------------------|--------------|------------|
| 1 | **时间**（起止或首次发现时刻） | 对账与保管链锚点 | 禁对外正式定性；内部待证 |
| 2 | **地点角色**（台址脱敏 / 区域角色，禁坐标原文公开） | 可复核、可移交 | 公开写真坐标 → L3 违规 |
| 3 | **现象描述**（听感/看感/业务影响，角色标签） | 分诊依据 | 「很烦」四个字不够 |
| 4 | **本网日志指针**（告警/录音索引/监测记录角色，脱敏） | 区分本网故障 | 无指针易误报 |
| 5 | **录音 / 频谱截图角色**（若有；保管链） | 可移交依法渠道 | 断链禁当正式对外证据 |
| 6 | **保管链未断声明** | 断链=证据降级 | 断链禁当正式对外证据（规则2） |

> **口诀**：时、地、象、志、样、链——**六字证钉**（教学记忆；现场以属地与主管部门要求为准，但 **时间+现象+可追溯指针+保管链** 几乎不可砍）。  
> **断链识别**：原件丢失、多人传阅无登记、公开群转发后「再当正式证据」、截图无来源角色——一律降级，禁对外正式定性依赖。

### 4.4 内部上报与对外依法报告（W-报）——送监管怎么办

| 步 | 动作 | 拒签点 |
|----|------|--------|
| 1 | 指定内部主人（角色）与时限（本网制度；教学不编造小时数） | 「大家看看」无主人 |
| 2 | 内部上报内容：W2 分级 + W3 勾选 + L3 摘要；禁夹带真实频点/坐标/全文号 | 内报夹带明文敏感 |
| 3 | 判断是否需对外依法报告：疑似非法/黑广播且证据达本网外报门槛 | 证据未齐却外报「已确认」 |
| 4 | 对外路径：无线电管理机构等法定渠道（公开如 12381 干扰投诉/举报路径、属地窗口——**以原文与属地最新为准**） | 发自媒体/短视频定罪 |
| 5 | 回执与台账：外报回执角色、内部办结状态互挂 | 口头说报了无记录 |
| 6 | 配合依法调查：按主管部门要求提供受控原件；公开材料仍 L3 | 把原件丢进公开群 |

与手册21：若线索源于用户投诉，**进线主贴 T**，转 W 时互挂编号。与手册20：跨网先 S，不把「协调」做成「联合私了」。

### 4.5 运维边界（W-界 / 规则3）——药店员不是侦缉队

| 本网可以做（教学） | 本网不可以做（红线） |
|--------------------|----------------------|
| 合规监测记录、现象登记、自家台账对账 | 自行测向定位打击、拆窝点、私入民宅/楼顶「取缔」 |
| 本网故障排查与 U/V 自纠 | 功率战报复、故意干扰对方 |
| 按制度内部上报、依法外报 | 网暴、人肉、自媒体定罪游街 |
| 挂 S 书面协调、保存回执 | 私了毁证、私下收钱了事 |
| 按主管部门要求配合提供证据 | 伪造/涂改证据、教人规避监测 |

> **明确不教**：如何找非法台、如何测向交叉定位、如何拆设备、如何干扰压制、如何躲监测、如何伪造举报材料。需要技术查处的，**交给有法定职责的无线电管理机构等**——你方只做边界内的登记、保全与依法报告。

### 4.6 弱项短补：投诉 ≠ 非法定性 ≠ 本网无证 ≠ 邻网合法 ≠ 已外报

```text
   用户投诉（T）   非法/黑广播定性（W）   本网无证过期（U/V）   邻网合法（S）   已依法外报
   ─────────────  ─────────────────────  ───────────────────  ─────────────  ──────────
   进线怎么分诊    对外正式定性须证据齐     自纠合规·非猎杀      先协调核对     法定渠道+回执
   主贴 T          主贴 W·可挂 T            主贴 U/V             挂 S           W-报

   ✗ 「有投诉 = 已确认黑广播」
   ✗ 「本网无证 = 按黑广播举报自己并对外宣传」
   ✗ 「听见像广告 = 可以发群定罪」
   ✗ 「邻居不清楚 = 可以功率顶回去」
   ✗ 「内报了 = 等于外报了」
   ✗ 「截图发过群 = 保管链完整」
```

所以规则5、6才硬：**投诉主贴 T，非法类线索主贴 W；本网违章走 U/V，不走猎杀叙事。**

### 4.7 与主管部门路径怎么衔接（只讲合规路径，不教规避）

教学流程（细节以属地最新要求与官方受理材料为准）：

1. **发现 / 接报**：登记进线；W-线分诊。  
2. **本网自查**：是否本网故障、无证、过期、超窗、邻道泄漏——是则转 U/V/T/F 等，结束「W 猎杀叙事」。  
3. **证据保全**：W-证六字钉；原件受控。  
4. **内部上报**：主人与时限；L3 摘要。  
5. **对外依法报告**（达门槛时）：走无线电管理机构等法定渠道；公开科普与通报中常见的 12381 等路径可作入口提示——**以原文与属地为准**。  
6. **跨网**：先挂 S；争议仍报管理机构；禁报复。  
7. **配合调查**：按要求提供；公开仓不放原件全文号。  
8. **结案**：W 子类结案词；假线索走 W-治 复盘。

**明确不教**：如何无证发射、如何伪造涂改证据、如何规避监测与检查、如何「私了」话术过关、如何定位打击非法设台或黑广播。

### 4.8 线索处置前 15 分钟清单（可复印）

| 0–3 | 打开线索卡：进线来源角色、首次时刻、粗现象 |
| 3–7 | W-线分诊六问；若本网/U/V/邻网合法 → 转贴并停止「非法定性」 |
| 7–10 | W-证勾选；缺项 → 内部待证，禁对外正式定性 |

夜班压缩版：至少完成「已分诊 + 证据勾选可读 + 有主人 + 未越权动作」四项——**四项缺一仍禁对外正式定性**。

### 4.9 与 T / U / V / S 单据互挂（W → 投诉 / 证照 / 临时窗 / 邻居）

## 5. 现场映射：原话 → W 子类；对话脚本；夜班；禁写词

### 5.1 原话速查表

| 原话 | 主贴 | 动作 |
|------|------|------|
| 「听见像卖药广告，是黑广播吧？」 | W-线 | 分诊；禁未证对外定性 |
| 「证据还不齐，先对外说确认了」 | W-证 / W-治 | 拒签对外定性；内部待证 |
| 「我们开车去楼顶找」 | W-界 / W-治 | 拒签；依法报告路径 |
| 「功率顶上去压一压」 | W-界 | 禁功率战；挂 S/T |
| 「发短视频让网友帮忙定位」 | W-报 / W-治 | 拒签；走法定渠道 |
| 「我们无证那台也举报成黑广播」 | U/V | 自纠；禁猎杀叙事 |
| 「邻居不明发射，先私了」 | W + S | 协调；禁私了毁证；争议报管理机构 |
| 「用户投诉干扰」 | T | 进线主贴 T；可转/挂 W |
| 「公开周报贴真实频点+录音」 | W-治 | L3 违规下架 |

### 5.2 对话脚本（五则）

**脚本1 · 未分诊定性**  
对方：「这声音一听就是黑广播，周报就这么写。」  
你：「规则1、2：未分诊、证据未齐禁对外正式定性。先 W-线分诊 + W-证勾选；对外用待证或依法报告表述。主贴 W-治。」

**脚本2 · 自己去捣窝点**  
对方：「位置大概在哪片，我们夜班自己去拆了省事。」  
你：「规则3：运维不做排查对抗与私自取缔。登记、保全、依法报告。主贴 W-界。」

**脚本3 · 功率战**  
对方：「对面烦死了，边界功率先顶满。」  
你：「规则3、7：禁功率战报复。跨网挂 S；投诉挂 T；争议报无线电管理机构。主贴 W-界，挂 S。」

**脚本4 · 本网无证当黑广播宣传**  
对方：「正好借这个机会，把我们过期那台也写成查获。」  
你：「规则6：本网过期走 U 自纠，不是黑广播猎杀叙事。主贴 U，禁止 W 对外定性自家。」

**脚本5 · 自媒体定罪**  
对方：「先发抖音，有人认识设备就行。」  
你：「规则4、8：对外走法定渠道；禁网暴自媒体定罪；公开 L3。主贴 W-报 / W-治。」

### 5.3 夜班 15 分钟怎么用

1. 扫线索台账：待证条数、超时报条数、未分诊条数（应为 0 对外定性）。  
2. 查越权动作：有无「自行定位/功率战/发群定罪」记录（应为 0）。  
3. 查互挂：投诉转 W、跨网挂 S、本网转 U/V 是否写清。  
4. 交班口述：待证、已内报、已外报、冻结原因（W 子类）、主人。

### 5.4 「非法/黑广播线索三问」（贴网管室 / 值班台）

```text
  1. 分诊结果是什么？（本网误报 / 邻网合法 / 疑似非法 / 疑似黑广播 / 不明）
  2. 证据最小集齐了吗？保管链断了没有？
```

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「听见像广告就定性」→ W-线 / W-治

现象：夜班扫频听感异常，周报草稿写「已确认黑广播」。  
处置：拒签周报表述；W-线分诊；证据未齐挂待证。  
结案词：「W-治：未分诊未证，禁对外正式定性。」

### 例 2 · 「证据缺保管链仍外报已确认」→ W-证

现象：截图曾发工作群，无保管登记，欲对外「已确认非法设台」。  
处置：断链降级；补保全新证据或仅报「待证线索」；禁正式定性。  
结案词：「W-证：断链禁当正式对外证据。」

### 例 3 · 「自己去楼顶取缔」→ W-界

现象：班长带人拟自行定位拆除。  
处置：立即制止；转依法报告路径；开治理复盘。  
结案词：「W-界：拒自行排查对抗；已改法定渠道。」

### 例 4 · 「功率顶回去」→ W-界 + S

现象：边界侧拟抬功率压制不明信号。  
处置：禁功率战；挂 S；若有投诉挂 T；记录 W。  
结案词：「W-界：禁功率战；已挂 S。」

### 例 5 · 「本网过期台写成查获黑广播」→ U + W-治

现象：宣传欲把本网过期发射写成打击成效。  
处置：拒签；主贴 U 关停自纠；禁止猎杀叙事。  
结案词：「规则6：本网违章走 U，不走 W 猎杀。」

### 例 6 · 「投诉进线未转贴」→ T + W

现象：用户投诉干扰，值班直接开 W「黑广播」结案。  
处置：主贴改回 T 分诊；若倾向非法类再挂 W；互挂编号。  
结案词：「规则5：投诉主贴 T；可挂 W。」

### 例 7 · 「跨网私了」→ W + S

现象：邻网私下约定「各退一步」并销毁录音。  
处置：拒私了毁证；恢复保全；挂 S 正式协调；必要时报管理机构。  
结案词：「W-界：禁私了毁证；已挂 S。」

### 例 8 · 「公开周报贴真实频点」→ W-治 / L3

现象：周报含真实频点与联系人。  
处置：下架；改 L3；原件受控；培训规则8。  
结案词：「W-治：L3 违规已纠正。」

### 例 9 · 「假线索报复邻居」→ W-治

现象：与邻居纠纷后，伪造「疑似黑广播」线索欲外报。  
处置：W-线识假；拒签外报；治理与道歉路径（本网制度）；挂 S 降温。  
结案词：「W-治：假线索拒签；禁报复。」

### 例 10 · 「内报超时无主人」→ W-报

现象：待证线索悬置，无主人，超本网时限。  
处置：补指定主人；升级内部催办；复盘制度空洞。  
结案词：「W-报：无主人超时，已补主人并复盘。」

## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 一句话 |
|------|--------|
| **非法设台（教学用语）** | 未经许可擅自设置、使用无线电台（站）等违法情形的统称（定性权在法定主体；本网只分诊上报） |
| **黑广播（公开科普用语）** | 公开材料中对未经审批私自设立非法广播电台等行为的通俗称呼（教学转述，以主管部门表述为准） |
| **线索** | 尚未依法认定的可疑信息进线，不等于已定罪 |
| **分诊** | 先分级再决定主贴与是否外报（W-线） |
| **证据最小集** | 对外正式定性前不可缺的教学最小证据组（W-证） |
| **保管链** | 证据从采集到移交的可追溯登记；断链则降级 |
| **待证** | 内部允许挂起继续保全，但禁对外正式定性 |
| **内部上报** | 本网主人+时限+L3 摘要的对内路径（W-报） |
| **依法外报** | 向无线电管理机构等法定渠道报告/投诉/举报 |
| **运维边界** | 本网只做合规监测与台账，不做私力执法（W-界） |
| **功率战** | 用抬功率等方式报复或压制，本篇红线 |
| **私了** | 私下了结并常伴毁证，本篇红线 |
| **主贴 W** | 非法/黑广播类线索以 W 为主键，可挂 T/S/U/V |
| **L3** | 公开包最高脱敏等级（本系列约定） |
| **12381 等公开路径** | 工信部公开材料中的干扰投诉等入口提示（以原文与属地为准） |
| **猎杀叙事** | 把本网 U/V 违章或未证线索写成「查获黑广播」的错误对外叙事 |
| **假线索** | 故意伪造或重大过失误报并企图对外定性 |
| **法定主体** | 依法有权查处、处罚的无线电管理机构等，不是本网运维班组 |

**易错观念**

1. ✗ 听见像 = 已确认黑广播 → ✓ 先分诊 + 证据；定性权不在夜班口嗨。  
2. ✗ 有投诉 = 可以对外定罪 → ✓ 投诉主贴 T；升 W 仍要证据最小集。  
3. ✗ 本网无证 = 按黑广播宣传 → ✓ 走 U/V 自纠。  
4. ✗ 自己去拆更快点 → ✓ 运维边界；依法报告。  
5. ✗ 功率顶回去是维权 → ✓ 功率战红线。  
6. ✗ 发自媒体算举报 → ✓ 法定渠道；禁网暴定罪。  
7. ✗ 断链截图仍可当正式证据 → ✓ 断链降级。  
8. ✗ 内报了等于外报了 → ✓ 两回事。  
9. ✗ 邻居纠纷可以假线索报复 → ✓ 假线索 W-治。  
10. ✗ 公开培训可以贴真实频点与原件号 → ✓ 公开 L3，原件受控。

## 9. 自测（12 题）+ 参考答案

1. 贴纸 W 五个子类是什么？各用四个字以内说明。  
2. 「药店假药线索 → 送监管」分别对应线、证、报、界中的哪段直觉？  
3. 八条硬规则里，哪一条直接禁止未分诊对外定性？  
4. 证据最小集教学六项是哪些？断链能不能当正式对外证据？  
5. 投诉进线应主贴 T 还是 W？何时挂 W？  
6. 本网执照过期仍发射，应主贴什么？能否写成查获黑广播？  
7. 运维边界列出至少四条「不可以」。  
8. 跨网疑似不明发射，应先挂什么？争议报谁？  
9. 对外报告应走什么渠道？自媒体算不算？  
10. 证据未齐时内部能否挂「待证」？对外呢？  
11. 公开包能否出现真实频点与证据原件全文号？  
12. 发现有人要功率战报复，主贴与动作是什么？

### 参考答案

1. 线/证/报/界/治：进线分诊、证据保全、上报路径、运维边界、拒签治理。  
2. 进线→线；留样→证；送监管→报；不当侦探→界。  
3. 规则1。  
4. 时、地角色、象、志、样、链；不能。  
5. 主贴 T；分诊后倾向非法/黑广播类可转/挂 W。  
6. 主贴 U（或临时超窗则 V）；不能。  
7. 不自行排查对抗、不定位打击、不功率战、不私了、不网暴（答出四条即可）。  
8. 先挂 S；争议报无线电管理机构。  
9. 无线电管理机构等法定渠道（如公开的 12381 等，以属地为准）；不算。  
10. 内部可以待证；对外禁正式定性。  
11. 不能；规则8。  
12. 主贴 W-界；制止、挂 S/T、依法路径；禁抬功率。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **W** 五子类：线 / 证 / 报 / 界 / 治。  
- 故事：药店发现假药线索 → 内部登记 + 送监管；不当街私了、不当侦探捣窝点。
