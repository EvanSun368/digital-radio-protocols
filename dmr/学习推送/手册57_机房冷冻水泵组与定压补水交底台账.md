| **治** | 假绿≠可以签；禁用「冷冻水冷却塔签」「压缩机制冷剂签」「漏水签」「温湿度签」「监控签」顶本期泵组/定压补水 | 假绿、顶替 BA/AX/AO/…、关阀/旁通/绕联锁、功率战、泄密 → 治理 | BD-治 |

> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：冷冻水泵组与定压/膨胀罐/补水公开概述强调**有账要验、泵在转≠准用、压力绿≠窗过、口头补水正常≠方法过、边界要有书面方法、泵组与定压补水要有本期核对秩序**（§10，**只借秩序直觉**；**本篇不写逐步关阀/开旁通/不安全泄水/带压违章操作教条**）；医院手术室/ICU 与数据中心 CHW pump / pressurization / makeup-water 公开资料强调**环境绿≠泵组/定压补水合格、冷冻水冷却塔侧过≠泵组定压过、漏水探头过≠补水台账过、压缩机制冷剂过≠泵组过、温湿度过≠定压窗过、监控绿≠本期实测过**（§10，**只作故事类比**）。本篇只借这串顺序——**本网泵组台账格式、定压补水窗方法、边界顺序与合格门限以本网制度、合同与 OEM 书面为准**。

### 2.3 和手册54（BA）/ 51（AX）/ 42（AO）/ 36（AI）/ 47（AT）/ 15（N）/ 56（BC）等的咬合（指针，不重写）

### 4.1 八条硬规则（本篇钉子）

## 6. 工作实例（12 则，教学虚构，L3）

1. **泵在转想签准用**：泵指示灯转，运维要签准用 → 查 BD1，无泵组台账本期核对 → **拒签**；补 BD-泵。  
2. **压力绿 / 口头补水正常当窗过**：外包称「定压看着绿 / 补水正常」免窗页 → **拒签**；补 BD-补 主人/窗/方法/准用期。  
3. **BA 顶替 BD**：班长用 BA 冷冻水冷却塔签顶本期泵组定压签 → **挂 R**；主贴仍 BD；BA过≠BD过。  
4. **AO / AX 顶替**：站务称漏水与压缩机制冷剂过了泵组补水免做 → **拒签顶替**；AO≠BD、AX≠BD；漏水≠补水台账。  
5. **N 绿免实测**：大屏环境绿，本期实测免 → **拒签**；N绿≠BD过；补 BD-验。  
6. **套邻站表**：外包拷邻站泵组/定压表改机房号 → **BD-验 拒签重测**；禁套。  
7. **功率战**：泵跳闸/定压失压告警，网优要抬功率 → **禁功率战**；先挂 N；缺秩序整改贴 BD。  
8. **关阀冒充**：外包关阀消告警后要求准用 → **禁**；挂 N/R；禁签。  
9. **开旁通冒充**：新人开旁通让压力变绿 → **禁**；挂整改；主贴 BD-治。  
10. **AI/AT/BC 混签**：环境班称 AI 温湿度与 AT 冷凝、BC 机柜PUE过了，泵组定压免 → **拒签**；AI≠BD、AT≠BD、BC≠BD。  
11. **AD 顶实测**：仪表入库签日期还在，实测免 → **拒签**；AD 只支撑仪表；主窗仍 BD。  
12. **泄密发群**：新人公开群贴真实回路编号与定压门限 → **L3 违规**；脱敏重发；挂 BD-治。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **BD** 五子类：泵 / 补 / 界 / 验 / 治——双字母续写在 BC 之后的第一张 **BD**，负责机房冷冻水泵组与定压补水「台账清不清、补水有没有窗、边界有没有法、本期过了没有」。  
- 口诀：**泵组有账，补水有窗，边界有法，会签才放。**  
- 故事：医院手术室/ICU 冷冻水泵组与定压补水（或数据中心 chilled-water pump / pressurization / makeup-water）——泵在转≠准用；压力绿≠窗过；口头说泵组/补水正常≠方法过。  
- 八条硬规则：**泵组台账钉死**；**定压补水有主有窗有方法/准用期**；**泵组与定压补水边界窗与方法钉死**；**本期实测禁套**；**会签才放行**；**禁顶替 BA/AX/AO/AI/AT/AY/AZ/AU/BB/BC/AW/AF/AS/AD/AN/AA/N/AQ/AV/AR/AG/AP，主贴 BD，假绿≠放行挂 R**；**异常风暴挂 N、变更走 J、禁功率战/关阀冒充/开旁通/绕联锁/不安全泄水带压违章/伪造台账**；**脱敏 L3**。  
- **BD 不替代 BA，也不替代 AX，也不替代 AO，也不替代 AI**：BA=冷冻水与冷却塔侧边界；AX=压缩机制冷剂；AO=漏水汇排；AI=温湿度联锁巡检；BD=泵组与定压补水准用。**BA ≠ BD；AO ≠ BD；AX ≠ BD。**

### 11.3 给带新人的三句话
1. 泵组不是泵在转就能签：泵组有账，本期核对钉死。  
2. 定压补水不是压力绿就算过、边界不是口头说泵组正常就算过：主人窗方法准用期，边界书面方法，本期实测会签才算准用；禁关阀冒充、禁开旁通、禁绕联锁、禁带压违章。  
3. 假绿挂 R；主贴 BD；BA/AX/AO/N 不顶替；异常窗禁功率战禁关阀禁旁通；公开脱敏 L3。
