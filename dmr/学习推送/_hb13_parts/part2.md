
## 4. 深潜：八条硬规则 + 井道/车库射频直觉 + 假病禁令

### 4.1 八条硬规则（本篇钉子）

1. **先证明井道/车库射频路径，再写干扰或容量**——电梯/车库黑洞优先贴纸 L，禁止直接当纯 F 或纯 H。  
2. **禁止用加功率 / 开大直放站增益掩盖井道或车库黑洞**——功率是手册07/09/10 的禁区补丁，不是 L 的药。  
3. **金机走测强制包：每层厅门 + 轿厢中运行 + 车库每层 + 坡道**——少一项 = 未交维。  
4. **门开 vs 门关必须对照**——只开门测 = 拒签（L-门）。  
5. **边界写清再签字（L-交）**——楼宇室分 / DMR 信源 / 物业消防无线 / 电梯维保；口头「归××」不算。  
6. **对时与三联单五要素仍适用（指针手册06）**——走测、投诉、网管必须同一窗；脱敏到 L3。  
7. **症状可挂 F（覆盖/干扰）、I（室分）、A/B（登记/Grant），但不得主写成协议玄学**——主贴 L。  
8. **脱敏到 L3**——公开仓与教学推送禁止真实频点、楼宇名、站号、个号、密钥、单位名。

### 4.2 井道 / 轿厢 / 车库射频直觉（不背厂商菜单）

```text
  地面大厅有信号
        │
        ▼
  厅门区域（门开）── 尚可？──否──▶ 查 I-覆 / L-井（厅门天线或泄漏耦合）
        │是
        ▼
  轿厢内门开 ── 尚可？──否──▶ L-井 / L-门（耦合不够）
        │是
        ▼
  轿厢内门关 ── 尚可？──否──▶ L-门（金属笼衰减）+ 查井道路径是否「只靠门缝泄漏」
        │是
        ▼
  中运行升降（门关）── 连续？──否──▶ L-切 / L-井（层间黑洞、扇区边界）
        │是
        ▼
  车库每层 + 坡道行驶 ── 过？──否──▶ L-库 / L-切
        │是
        ▼
  边界书面（L-交）→ 可谈签字
```

现场口诀：

> **先路径，再门对照，再运动，后边界。**  
> 交维若跳过门关与中运行，等于没把罐笼放进井筒就签字。

### 4.3 专项剧本最低验收包（L-门 / L-切 心脏）

| 步骤 | 要看到什么 | 不过怎么办 |
|------|------------|------------|
| 点位表含井道/车库 | 设计测点含厅门、轿厢、每车库层、坡道 | 补点位；拒签「只测走廊」 |
| 井道/车库路径证明 | 泄漏或厅门方案可指认；必要 VSWR/DTF | L-井/L-库；开口项书面 |
| 门开对照 | 同层门开：金机梯子（能量→SYNC→身份→BER→业务） | 先修路径，不谈签字 |
| 门关对照 | 同层门关：同上；记录衰减差 | 门关失败 = L-门 拒签项 |
| 中运行升降 | 从最低到最高（或抽样连续段）门关行驶 | 层间黑洞记 R3/R6 |
| 车库每层 | 空车抽测 + 条件允许时满车抽测 | 只测一层 = 拒签 |
| 坡道行驶 | 进出坡道连续业务可接受 | L-切；查扇区边界 |
| 边界与证据 | L-交 书面；插页 L R1–R8 | 口头三家不管 = 拒签 |

### 4.4 「假覆盖 / 假干扰 / 假容量 / 假协议」怎么认

| 假病外表 | 常见井道/车库真因 | 错误处置 | 正确主贴 |
|----------|-------------------|----------|----------|
| 假覆盖（F-弱气质） | 井道无路径、车库层屏蔽、门关衰减 | 加功率、加直放站增益 | L-井/L-库/L-门 |
| 假干扰（F-同气质） | 门关瞬间 BER 跳、升降层间毛刺 | 扫「同频」几天 | L-门/L-切（次挂 F） |
| 假容量（H 气质） | 多部电梯/车库盲区造成掉话账假坏 | 加信道、拧 Hangtime | L（次挂 H） |
| 假登记/假 Grant | 升降/门关窗短时协议症状 | 立刻改写频/鉴权 | L（次挂 A/B） |
| 假室分总包过关 | 走廊 I-覆 过、井道/车库未测 | 直接签手册10 | 本篇 L 拒签 |

**三问快判（背）**：

1. **路径**：井道/车库有没有可指认的天线或泄漏？（R3/R4）  
2. **门**：门开/门关对照做了没有？（R5）  
3. **运动**：中运行升降与坡道行驶测了没有？（R6）  

三问里有「否」，就**先写 L**；三问全「是」且有持续同频/容量证据，再进手册07/09。切记：门关「抖一下又好」优先是 L-门/L-切 的结构副作用，不是先开同频工单。

### 4.5 泄漏 · 厅门天线 · 车库形态：现场只记「量级直觉」

| 对象 | 你要会问的三句话 | 常见坑 |
|------|------------------|--------|
| 井道泄漏同轴 | 有没有装？两端能否扫？进水/接头？ | 「图纸有」代替实物照片与 DTF |
| 厅门天线 | 每隔几层一副？门关能否耦进轿厢？ | 只在大堂放一副指望照亮全井 |
| 轿厢金属笼 | 门关衰减实测多少气质？ | 用门开数据签字 |
| 车库泄漏/天线 | 每层巷道是否连续？分支有无断？ | 只测坡道口，不进车位深处 |
| 有源远端 | 是否在线？电源是否稳（指针 K）？ | 远端掉电当「覆盖玄学」 |
| 扇区边界 | 井道/坡道是否被扇区缝劈开？ | 升降中疯狂猎站仍说「终端问题」 |

> 教学楼不要抄真实阈值进公开仓。本网门关衰减门限、走测点密度、BER 阈值，写在**本网交维卡**（脱敏），不写进本篇正文当「全世界标准」。

### 4.6 和弱项加餐的衔接

12.5 kHz / 4FSK / 30 ms 两槽背熟，你才说得清：**井道/车库改的是「路径与衰减」，不是「调制台阶」**。有人要用加功率治电梯黑洞时，回加餐 + 手册07/09/10 + 本篇八条硬规则。

## 5. 现场映射：原话 → L 子类；对话脚本；反例

### 5.1 原话速查表

| 现场原话 | 主子类 | 你先要的证据 |
|----------|--------|--------------|
| 「电梯里没信号」 | L-井 / L-门 | 点位表、门开/门关、井道方案 |
| 「关门就死，开门就好」 | L-门 | 同层门对照表 |
| 「某几层黑洞，其它层还行」 | L-井 | 层间走测、泄漏/厅门间距 |
| 「B2 没信号，B1 还行」 | L-库 | 每层走测、远端状态 |
| 「下坡道掉话」 | L-切 / L-库 | 坡道行驶记录、扇区边界 |
| 「交维走廊过了」 | L-交 / L-井 | 井道/车库是否进点位表 |
| 「加功率就能亮」 | 禁令 | 拒签；回八条硬规则 |
| 「井道归电梯公司」 | L-交 | 书面边界；口头不算 |
| 「满车以后更差」 | L-库 | 满车抽测；多径/遮挡记录 |
| 「升降中机器人音」 | L-切（次挂 F） | 中运行 BER/业务窗；先路径 |

### 5.2 对话脚本（六则）

**脚本 A · 交维只测走廊**

> 对方：「一楼到顶层走廊金机都过了，签吧。」  
> 你：「插页 L 的 R3–R6 空着。请做厅门 + 轿厢门开/门关 + 中运行 + 车库每层/坡道。只测走廊不算本专项交维。」

**脚本 B · 门关假干扰**

> 对方：「门关 BER 跳了，按手册07 扫同频。」  
> 你：「先做同层门开/门关对照。主贴 L-门；梯子可以挂，但加功率禁止。」

**脚本 C · 加功率掩盖**

> 对方：「基站功率加 3 dB，电梯就有了。」  
> 你：「八条硬规则第 2 条。加功率不是井道药。先证明路径与门对照，再谈射频优化。」

**脚本 D · 边界口头推诿**

> 对方：「井道归电梯维保，车库室分归甲公司，我们只管信源。」  
> 你：「L-交 拒签。交维卡上要有书面边界：谁管井道器件、谁管车库分支、谁管 DMR 信源、谁收投诉。口头三家不管 = 事故预告。」

**脚本 E · 假容量要加信道**

> 对方：「上班高峰电梯里掉话，按手册09 加信道。」  
> 你：「先把掉话时刻和门关/升降窗、车库层对齐。若对齐，主贴 L，次挂 H；结构盲区时加信道是假账。」

**脚本 F · 只开门测**

> 对方：「门关测起来要协调电梯，太麻烦，开门数据也行。」  
> 你：「L-门 拒签。罐笼门封死后才是真实勤务状态。门关对照是强制项，不是可选项。」

### 5.3 反例墙（贴验收会议室）

1. 只测走廊就签字。  
2. 只开门测，不做门关对照。  
3. 电梯/车库未进点位表。  
4. 井道黑洞先加功率。  
5. 把「门关数字悬崖」写成终端玄学。  
6. 边界口头「归电梯公司」。  
7. 车库只测 B1 不测更深一层。  
8. 从未做中运行升降走测。  
9. 用公网 LTE 绿图代替 DMR 金机梯子。  
10. 证据不对时，硬写手册01/07 结案。

### 5.4 夜班 15 分钟怎么用

```text
1'  有无电梯/车库投诉？对时窗抄下来（R1 草稿）
3'  金机：就近一部电梯 — 门开 / 门关各一次业务
3'  若有车库权限：抽最深一层一个角 + 坡道口
3'  查点位表：今晚投诉点是否在表上？不在 → 记 L-交/L-井 开口
5'  若正在投诉高峰：记 R2–R7 草稿；禁加功率；主贴 L
```

### 5.5 单次专项交维 40 分钟标准节奏（可复印；高层/多层车库加倍）

```text
0–5'   开单 + 边界确认（L-交）+ 禁令宣读（禁加功率、禁只测走廊）
5–12'  读现状：点位表、井道方案照片、车库远端、上次走测（L-井/L-库）
12–28' 金机剧本：厅门抽样 → 门开/门关 → 中运行升降段 → 车库层/坡道（L-门/L-切）
28–35' 填插页 L R1–R8；异常立刻拒签项打勾；必要扫线补测预约
35–40' 结论：放行 / 带条件 / 拒签；证据包入库（脱敏）；下周复查点
```

带条件放行只允许「非关键、有时限、有责任人」的尾巴（例如某层厅门照片补传），**不允许**「门关未测 / 中运行未测 / 车库未测先签」。

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「电梯关门断话，开门恢复」→ L-门

现象：保安投诉「轿厢里一关门就没声」。  
观察：同层门开金机业务过；门关 BER 上悬崖；厅门有天线但耦合仅靠门缝。  
错法：换手台；加基站功率；结案「终端批量异常」。  
正法：主贴 L-门；次挂 F 仅作症状；插页 R5；推动井道路径增强或厅门方案复测；三联单写清门对照。

### 例 2 · 「某几层厅门黑洞」→ L-井

现象：5–7 层厅门无声，其它层尚可。  
观察：泄漏/厅门间距过大；5 层接头 VSWR 异常；点位表缺层间抽测。  
错法：按 F-弱 扫同频一周。  
正法：L-井；修接头/补点；层间走测进交维包。

### 例 3 · 「交维走廊过，第三天电梯投诉」→ L-井 / L-交

现象：签字后电梯投诉刷屏。  
观察：交维包无电梯测点；井道方案口头「以后加」。  
错法：「先观察」。  
正法：拒收历史包为完整交维；开 L-交 边界会；补剧本后重签。

### 例 4 · 「B2 无信号，B1 正常」→ L-库

现象：地下二层对讲困难。  
观察：B2 远端告警退出；或 B2 分支未接；空车测与满车测差大。  
错法：加信道；开大直放站增益。  
正法：L-库；查远端/分支（可挂 K 若电源）；每层走测强制。

### 例 5 · 「坡道行驶猎站乱跳」→ L-切

现象：车辆进出坡道掉话、机器人音。  
观察：坡道被两个扇区缝劈开；门禁闸机金属加重；未做行驶剧本。  
错法：改终端猎站参数先顶锅。  
正法：L-切；记录行驶窗；调整扇区边界或补覆盖（室分侧）；主贴 L。

### 例 6 · 「加功率照亮电梯」→ 禁令命中

现象：夜班把基站功率加大后电梯「好像好点」。  
观察：井道仍无路径照片；门关对照未做；邻层干扰投诉上升。  
错法：把加功率写进「优化措施」。  
正法：回退功率；主贴 L；引用硬规则第 2 条；对齐会通报反例。

### 例 7 · 「假干扰：升降中 BER 跳」→ L-切（次挂 F）

现象：罐笼升降时 BER 告警闪。  
观察：时序紧贴穿过某层无天线区；稳定停层后门关业务恢复。  
错法：开工单「排查同频」一周。  
正法：R6 记录；主贴 L-切/L-井；次挂 F；禁加功率。

### 例 8 · 「假容量：早高峰电梯掉话」→ L（次挂 H）

现象：上班高峰掉话，申请加信道。  
观察：掉话集中在门关升降窗；话务模型未饱和；「忙时」其实是「罐笼窗」。  
错法：手册09 直接加信道。  
正法：主贴 L；H 次挂；路径与门对照过关后再谈容量。

### 例 9 · 「假协议：升降窗登记失败」→ L（次挂 A）

现象：升降中短时登记失败刷屏。  
观察：与层间黑洞对齐；停层后自愈；金机实验室 G 全过。  
错法：按手册01 改终端参数。  
正法：主贴 L；次挂 A；修井道路径；J/G 作对照证明终端锚还在。

### 例 10 ·（对照）手册10 走廊 I-覆 过 vs 本篇 L 未过

现象：室分总包按手册10 走廊/口部签字；电梯与车库未做专项。  
观察：I 插页 R6 只写「电梯抽测口头 OK」。  
错法：认为手册10 已覆盖本篇。  
正法：本篇是 I-覆 加深专项；L 剧本未完成不得宣称「楼宇三维覆盖交维完成」。

### 6.5 电梯·车库对齐会：20 分钟议程

```text
0–3'   本周电梯/车库投诉清单（脱敏）
3–8'   抽一份插页 L：R5 门对照、R6 运动剧本是否空
8–12'  反例墙对照：有无加功率、有无只测走廊
12–16' 下一次井道窗口与物业/电梯维保协调点
16–20' 边界：室分商 / 信源 / 物业 / 电梯维保联系人是否仍有效
```
