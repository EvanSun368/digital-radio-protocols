## 1. 为什么要写这篇手册（动机 + 现场对话）

前四十二篇手册从 A–E 协议一路写到 AO 漏水汇排：其中 **AG 回答「电池与充电器梯队轮换与容量抽检」**，**AF 回答「油机市电」**，**AD 回答「备件仪表准用」**，**AA 回答「交维后首年巡检」**，**AO 回答「机房漏水与接地汇流排巡检」**，**AM 回答「天馈接地与防雷浪涌」**，**AN 回答「机房门禁与访客陪同」**，**N 回答「电源监控/对时/告警风暴」**。可还没有单独钉死一件事——**蓄电池组内阻与核对性放电不是「表绿就能签」：内阻台账要钉死；核对性放电要有主人有窗有方法有准用期；抽检窗与方法（内阻仪/放电仪）要书面固定；本组本机房本期实测禁套他站他期——能不能签「内阻/核对性放电准用」？** 这就是本篇的 **AP**——**蓄电池组内阻与核对性放电**。

- 运维岗：「内阻表还绿着，内阻巡检就算齐了。」——**无台账/无本期实测仍准用** = 本篇拒签（规则1）。  
- 外包：「浮充电压都在，核对性放电肯定过。」——**只浮充电压当核对过** = 规则2。  
- 物业：「上次测过差不多，放电再说。」——**无抽检窗方法，只听口头** = 规则3。  
- 外包：「邻站上周内阻曲线参数差不多，拷过来改个机房号。」——**套他站他期** = 规则4。  
- 班长：「AG 容量梯队签还在，AF 供电也过了，内阻核对也能签。」——**用 AG/AF/AD/AA/AO/AM/AN/N 顶替 AP** = 规则6。  
- 站务：「大屏浮充绿了，内阻/核对性放电准用就算过。」——**假绿≠会签放行** = 规则5/6。  
- 网优：「电池低压告警一片，功率抬一点稳住业务。」——**功率战** = 规则7（无关也写禁，系列一致）。  
- 宣传岗：「把真实电池序列号、机房编号发群表扬。」——**L3 违规** = 规则8。  

这几句背后是同一件事：

> **「蓄电池组内阻与核对性放电」在现场至少有五个坑**：**① AP-阻** 蓄电池组/单体内阻台账钉死，禁「表绿就能签」「口头说一声」；**② AP-核** 核对性放电有主人、有窗、有方法、有准用期，禁「只浮充电压当核对过」；**③ AP-抽** 抽检窗与方法钉死（内阻仪/放电仪方法；门限以本网为准），禁「只看监控绿」；**④ AP-验** 本组本机房本期实测（禁套他站他期曲线/照片），会签才放行「内阻/核对性放电准用」；**⑤ AP-治** 治理（假绿、用 AG/AF/AD/AA/AO/AM/AN/N 顶替、伪造内阻/放电账、旁路电池告警、功率战、泄密）。  
> 把 ①–⑤ 当成「表绿就能签」「浮充在就算过」「容量梯队签还在内阻也能签」，每一次内阻抽测、每一次核对放电、每一次夜班交班，都会先吵「账是谁的、窗谁开的、曲线是不是本期的」。

本篇目标：能背出**内阻 + 核对性放电工作流**；会用新贴纸 **AP（阻 / 核 / 抽 / 验 / 治）**；会填**插页 AP（AP1–AP8）**和《本网蓄电池组内阻与核对性放电台账卡》；能用「**医院手术室/ICU AED / 抢救车蓄电池内阻与核对性放电**」故事讲清内阻表绿≠合格、只看浮充电压≠核对过、套邻站内阻曲线=拒签、AG 容量梯队签不顶替本期内阻/核对签、内阻抽测≠完整容量试验、监控绿≠本期实测过、用 AG/AF/AD 签顶 AP 内阻核对签=拒签、假绿≠会签放行；能拒绝无账准用、套曲线、用他贴顶替本期内阻/核对签、假绿放行；自测过关后，回库把本网最近一次蓄电池组内阻或核对性放电（L3）重对一遍：内阻台账、核对窗、抽检方法、本期实测、会签项、拒签项。

**本篇硬禁令（写进脑子）**：凡引法规与标准只指向已公开发布的文书标题与官方链接（无线电管理条例、频率使用许可管理办法、地面无线电台（站）管理规定、国无办〔2025〕1号；**只作故事类比**的医院 AED/抢救车电池公开资料标题，以及公开的 VRLA/铅酸/UPS/−48 V 机房电池内阻与核对性放电概述资料），**程序、期限、责任以原文与属地最新要求及本网制度 / 合同为准，本篇只作教学转述，不发明条款号与内部口径**；医院 AED 电池维护、境外 IEEE/厂商 VRLA 内阻与放电测试公开资料与 UPS 电池科普**不是**中国专网台站「贴纸 AP」的法定依据；**现象与台账一律用相对道号、角色标签、脱敏站/机房编号，禁真实频点 / 站名 / 机房全称 / 电池序列号全文 / 单位名 / 联系人**；**不教伪造内阻台账、不教伪造放电曲线、不教旁路电池告警、不教偷改内阻/放电门限、不教功率战、不教假绿顶替**；AG / AF / AD / AA / AO / AM / AN / N / R / J 各管各的——**蓄电池组内阻与核对性放电主贴 AP**；梯队容量回 AG，油机市电回 AF，仪表准用回 AD，首年巡检回 AA，漏水汇排回 AO，天馈接地浪涌回 AM，门禁访客回 AN，监控风暴回 N——**AP 管「内阻·核对放电边界」，不替代 AG 的梯队轮换与容量抽检准用，也不替代 AD 的仪表准用本身，更不替代 N 的告警风暴秩序本身**。

## 2. 总图 / 故事：内阻核对像「医院手术室/ICU AED / 抢救车蓄电池内阻与核对性放电——不能只看表绿」

### 2.1 一句话：内阻表绿不是「可以签准用」、只看浮充电压不是「核对过了」、监控绿不是「本期实测过了」——要先建内阻台账，核对性放电有主人有窗有方法有准用期，抽检窗与方法钉死，本组本机房本期实测，会签才放行；假绿、套邻站曲线、用 AG/AF/AD/AA/AO/AM/AN/N 顶替，一律拒签

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  医院手术室/ICU AED/抢救车电池内阻+核对性放电  =  本网 AP    │
   │                                                              │
   │  蓄电池组/单体内阻台账钉死           ≈ AP-阻  内阻台账钉死   │
   │  核对性放电有主有窗有方法准用期     ≈ AP-核  核对有主有窗   │
   │  抽检窗·方法钉死（内阻仪/放电仪）   ≈ AP-抽  抽检窗方法钉   │
   │  本期实测禁套邻站内阻/放电曲线       ≈ AP-验  本组本机房本期 │
   │  假绿≠放行·顶替·伪造·旁路·功率战   ≈ AP-治  治理与脱敏L3 │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **内阻有账，核对有窗，抽测本期，会签才放。**  
> 内阻表绿还无台账/无本期实测 = AED 柜只看自检灯绿从不建内阻账——**拒签「内阻/核对性放电准用」**。  
> 只看浮充电压当核对过 = 抢救车电池只看浮充在从未按窗核对放电——**假绿，挂 R，拒签**。  
> AG 容量梯队过≠内阻/核对放电过；内阻抽测≠完整容量试验；监控绿≠本期实测过。

### 2.3 和手册34（AG）/ 33（AF）/ 31（AD）/ 28（AA）/ 42（AO）/ 40（AM）/ 41（AN）/ 15（N）等的咬合（指针，不重写）

- **AA（手册28）**：交维后**首年巡检**日历；内阻/核对抽检可挂 AA，缺内阻核对秩序整改主贴仍 AP。  
- **AO（手册42）**：漏水汇排；漏水过≠内阻核对过；电池室漏水可挂 AO，内阻核对主贴仍 AP。  
- **AM（手册40）**：天馈接地浪涌；接地过≠内阻核对过。  
- **AN（手册41）**：门禁访客；进机房做内阻/核对仍要 AN——**门禁过≠内阻核对过**。  
- **N（手册15）**：监控/**对时**/告警风暴；内阻异常风暴/放电窗风险挂 N 理风暴，**不先抬功率**；**禁旁路电池告警**；N 绿≠ AP 过。  
- **R / J / X / I**：假绿挂 R；变更（电池组改造、内阻门限、核对放电规程）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 AP 证内阻/核对秩序，再谈覆盖病**。

| **AP-验** | 套他站他期曲线/照片、无会签 → 拒签 | 「邻站内阻曲线拷过来改机房号」 |
| **AP-治** | 假绿、用 AG/AF/AD/AA/AO/AM/AN/N 顶替、旁路电池告警、功率战、泄密 → 治理 | 「AG 签还在，内阻也能过」 |

### 2.5 建内阻台账 → 钉核对主人 → 抽检窗钉死 → 本期实测 → 会签放行 → 变更再验 阶段梯（背下来）

```text
  ① AP-阻 建内阻台账：组角色 · 单体角色 · 内阻基线/趋势角色 · 禁「表绿就能签」「口头说一声」
        │  无账 / 表绿无实测 → 不签内阻/核对性放电准用
        ▼
  ② AP-核 钉核对主人：核对性放电主人角色 · 书面窗 · 方法 · 准用期 · 禁「只浮充电压当核对过」
        │  无主人 / 无窗 / 无方法 / 无准用期 → 拒进入「可签」状态
        ▼
  ③ AP-抽 钉抽检窗：书面窗 · 方法（内阻仪/放电仪等；门限以本网为准） · 到场角色 · AD 准用指针
        │  无窗 / 「监控绿当过」 → 拒抽检签
        ▼
  ④ AP-验 本组本机房本期实测：实测记录 · 禁套他站他期曲线/照片 · 会签
        │  套票 / 只看浮充绿 → 拒签
        ▼
  ⑤ 会签「内阻/核对性放电准用」或「有条件整改」：本网授权本人签
        │  缺签 / 假绿顶替 → 拒签准用
        ▼
  ⑥ 变更（电池组改造/内阻门限/核对放电规程）→ 走 J + 触发再抽/再验（常挂 N 看电池告警风暴、挂 AG 看梯队/容量、挂 AD 看内阻仪/放电仪）
```

> **一句话分辨**：**AG** 回答「梯队·充电器·容量抽检**过了没有**」；**AF** 回答「油机市电切换·供电巡检**清不清**」；**AD** 回答「内阻仪/放电仪**准用不清**」；**N** 回答「告警风暴**理不理**」；**AP** 回答「这一组蓄电池 + 这一窗内阻测试 + 这一窗核对性放电**台账清不清、核对有没有窗、本期过了没有**」。**五个问题，五张（类）贴纸，不能一笔带过。**  
> **AP vs AG 钉死**：**AG** = 电池与充电器**梯队轮换与容量抽检准用**；**AP** = 蓄电池组**内阻测试**与**核对性放电**巡检边界——内阻/核对看起来像「容量健康」，但本篇管的是**内阻台账与核对放电边界**，不顶替 AG 的梯队/容量抽检准用；**AG 过 ≠ AP 过**；容量梯队签 ≠ 内阻/核对放电准用；内阻抽测 ≠ 完整容量试验（门限以本网为准，不发明条款）。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **蓄电池组/单体内阻台账钉死**：组与单体角色、基线/趋势入账；禁「表绿就能签」「口头说一声」。  
2. **核对性放电有主有窗有方法/准用期**：每组核对放电有主人角色、有书面窗、有方法、有准用期；禁「只浮充电压当核对过」。  
3. **抽检窗与方法钉死**：书面固定；方法含内阻仪/放电仪等（**门限以本网为准**）；禁「放电再说」「只看监控绿」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、曲线、照片必须本期本组本机房；套邻站账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「内阻/核对性放电准用」；假绿 ≠ 放行。  
6. **禁顶替 AG/AF/AD/AA/AO/AM/AN/N，主贴 AP，假绿≠放行挂 R**：容量梯队签、供电签、仪表签、首年签、漏水签、接地签、门禁签都不顶本期内阻/核对签。  
7. **内阻异常风暴/放电窗风险挂 N，电池组改造/门限变更走 J，禁功率战；禁旁路电池告警**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/电池序列号全文/可还原坐标与联系人**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签内阻核对准用、无实测冒充抽检过，不是法外运维智慧**。医院 AED/抢救车电池公开资料、VRLA/UPS 内阻与放电公开科普只作故事与方法类比（§2.2）：**阻要约、核要窗、抽要法、验要实测、浮充绿不算过**——翻译成本网语言就是 AP-阻 / AP-核 / AP-抽 / AP-验 / AP-治。**这些是内阻核对巡检边界秩序，不是「表绿就签」「浮充当核对」「抬功率压告警」「旁路电池告警」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「内阻/核对性放电准用」、对外宣传「分钟级一键内阻秒过」、把未实测写成已过。允许做的：补内阻台账、补核对窗、重开抽检窗、重实测、挂 R/N/J、内部挂整改。

### 4.10 内阻 / 核对 / 抽检与 AP 的咬合（教学直觉，门限以本网为准）

- **内阻表绿 ≠ 合格**：要有台账、本期实测。  
- **只看浮充电压 ≠ 核对过**：要有主人、窗、方法、准用期、本期核对。  
- **监控绿 ≠ 本期实测过**：要有书面抽检窗与方法留痕。  
- **AG 容量梯队过 ≠ 内阻/核对过**：AG 与 AP 各管各的。  
- **内阻抽测 ≠ 完整容量试验**：完整容量回 AG；本篇不发明门限。  
- **供电过 ≠ 内阻核对过**：AF 与 AP 各管各的。  
- **仪表在期内 ≠ 本期抽检窗可免**：AD 只答设备准用期。  
- **门禁过 ≠ 内阻核对过**：AN 与 AP 各管各的；进机房仍要 AN。  
- **漏水过 ≠ 内阻核对过**：AO 与 AP 各管各的。  
- **监控绿 ≠ 内阻/核对准用过**：N 绿不顶 AP。  
- **门限、合格判据、抽检窗长度、放电深度以本网制度/合同为准**——本篇不发明数值与条款号；公开内阻/放电资料只借秩序直觉。

### 4.11 与梯队容量（AG）/ 油机（AF）/ 仪表（AD）/ 首年（AA）/ 漏水（AO）/ 接地（AM）/ 门禁（AN）/ 监控（N）怎么配合

进机房做内阻/核对抽检常见组合：**AN** 办门禁访客 → **AP** 办内阻核对抽检 → 完整容量另窗走 **AG** → 仪表准用回 **AD** → 供电边界可挂 **AF** → 内阻异常风暴/放电窗风险挂 **N** → 电池组/门限/规程变更走 **J**。容量抽检窗与内阻核对窗可同日不同贴，**互不顶替**；内阻异常可触发 AG 再看梯队/容量，内阻核对秩序仍 AP。

### 4.12 内阻异常 / 放电窗与上行更脆直觉

蓄电池组内阻劣化、核对放电未做、浮充假绿、放电窗告警风暴、旁路电池告警，常先让后备与空口变「脆」：掉电、误告、掉话——手台功率小、天线短，**上行往往比下行先不够用**。现场第一反应不该是抬功率，而该是：

```text
  内阻异常风暴 / 放电窗风险 / 电池低压告警
       │
       ├─→ 告警风暴？ → 挂 N 理风暴（对时/风暴秩序）；禁旁路电池告警
       ├─→ 内阻/核对台账与本期实测清不清？ → 主贴 AP
       ├─→ 完整容量？ → 另窗 AG（不顶替）
       ├─→ 仪表准用？ → AD（支撑）
       ├─→ 有人要抬功率？ → 禁功率战
       └─→ 要改电池组/门限/规程？ → 走 J + 再验
```

12.5 kHz / 4FSK / 2-slot TDMA 的窄车道里，乱抬功率只会先伤邻道与自身秩序；**先问 AP 秩序，再谈覆盖病（X/I 指针）**。

## 6. 工作实例（12 则，教学虚构，L3）

1. **表绿拒签**：脱敏机房-07 内阻表绿，无内阻台账页 → AP-阻拒签「内阻/核对性放电准用」；允许补账，不允许口头顶过。  
2. **浮充假绿**：机房角色-B 浮充电压在，无核对性放电书面窗与本期核对记录 → 挂 R，补 AP-核/抽后再谈会签。  
3. **套邻站曲线**：外包拷邻站上周内阻曲线改机房号交差 → AP-验拒签，责令本期本组本机房重开实测。  
4. **容量顶内阻**：班长称「AG 容量梯队签还在，内阻也能签」→ 拒签；容量过≠内阻/核对过；主贴仍 AP。  
5. **供电顶核对**：AF 供电巡检会签在有效窗，想顺带签核对性放电 → 拒签；AF≠AP；各管各的。  
6. **仪表顶窗**：AD 内阻仪仍在准用期内，外包想免做抽检窗 → 拒签；AD 只支撑设备准用，不顶 AP 窗。  
7. **门禁顶抽检**：AN 门禁陪同交底过，想免做内阻核对抽检 → 拒签；门禁过≠内阻核对过；进机房仍要 AN，抽检仍要 AP。  
8. **旁路电池告警**：有人想旁路电池低压告警消铃 → **禁**；挂整改 + N/R；本期实测未做不得签准用。  
9. **门限变更未走 J**：私自改内阻门限或核对放电规程未走变更 → 补走 J，触发再验 AP；未闭前禁签准用。  
10. **放电窗抬功率**：电池低压告警一片，网优想抬功率压掉话 → **禁功率战**；先 N 后 AP；上行更脆先问秩序。  
11. **内阻当完整容量**：外包称「内阻抽测过了就等于完整容量试验」→ 拒签叙事；内阻≠完整容量；完整容量另窗 AG；本期内阻核对仍 AP。  
12. **群泄密**：宣传岗把真实电池序列号与机房全称发群表扬 → L3 违规，撤帖脱敏重发；治理勾 AP-治。

7. 先 N 理风暴；**禁功率战**；**禁旁路电池告警**；缺内阻核对秩序整改主贴 AP。  
8. 走 **J** + 再验 **AP**。  
9. 不能。AD 只支撑设备准用，不顶 AP 窗。  
10. 表绿≠合格 → AP-阻；浮充≠核对 → AP-核。AG = 梯队轮换与容量抽检准用；AP = 内阻测试与核对性放电巡检边界。**不等于**；内阻抽测 ≠ 完整容量试验。  
11. 阻、核、窗、法、房、测、签、闭、密、界；几乎不可砍：**内阻台账 + 核对窗方法 + 本组本机房本期实测 + 会签**。  
12. 禁真实频点/站名/机房全称/电池序列号全文/单位名/联系人；**不教**伪造内阻/放电曲线/旁路电池告警/功率战。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AP** 五子类：阻 / 核 / 抽 / 验 / 治——双字母续写的第十六张，负责内阻·核对「台账清不清、核对有没有窗、本期过了没有」。  
- 故事：医院手术室/ICU AED / 抢救车蓄电池内阻与核对性放电——内阻表绿≠合格；只看浮充电压≠核对过；AG 容量梯队签≠内阻/核对放电准用；内阻抽测≠完整容量试验；监控绿≠本期实测过；套邻站内阻曲线=拒签；AG/AF/AD/AA/AO/AM/AN/N 不顶替 AP；假绿≠会签放行。  
- 阶段梯：建内阻台账 → 钉核对主人 → 抽检窗钉死 → 本期实测 → 会签放行 → 变更再验。  
- 八条硬规则：**蓄电池组/单体内阻台账钉死**；**核对性放电有主有窗有方法/准用期**；**抽检窗与方法钉死**；**本组本机房本期实测禁套他站他期**；**会签才放行「内阻/核对性放电准用」**；**禁顶替 AG/AF/AD/AA/AO/AM/AN/N 等，主贴 AP，假绿≠放行挂 R**；**内阻异常风暴/放电窗风险挂 N、电池组改造/门限变更走 J、禁功率战、禁旁路电池告警**；**脱敏 L3**。  
- **AP vs AG**：AG = 梯队轮换与容量抽检准用；AP = 内阻测试与核对性放电巡检边界；AG 过 ≠ AP 过；内阻抽测 ≠ 完整容量试验。
