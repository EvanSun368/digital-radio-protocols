### 2.3 和手册51（AX）/ 47（AT）/ 36（AI）/ 42（AO）/ 52（AY）/ 53（AZ）/ 48（AU）/ 41（AN）/ 15（N）/ 50（AW）等的咬合（指针，不重写）

- **AX（手册51）**：精密空调压缩机与制冷剂；**AX ≠ BA**——压缩机/制冷剂过≠冷冻水/塔侧边界过；机内冷媒回路可挂 AX，冷冻水/冷却塔侧主贴仍 BA。  
- **AT（手册47）**：冷凝水与加湿除湿联锁；**AT ≠ BA**——冷凝/加湿过≠塔侧排污/水质窗过；冷凝排水可挂 AT，冷却塔侧主贴仍 BA。  
- **AI（手册36）**：温湿度与空调联锁**巡检边界**；**AI ≠ BA**——AI 管温湿度测点/门限/联锁巡检秩序；**BA 管冷冻水台账·冷却塔窗·水侧/塔侧边界交底准用**；温湿度过≠进出水温度窗过；「环境绿」≠ BA 过。  
- **AO（手册42）**：漏水探测与汇流排；**AO ≠ BA**——漏水过≠水侧边界交底过；水浸可挂 AO，冷冻水/塔侧主贴仍 BA（并挂 N 理风暴）。  
- **AY（手册52）**：新风正压与防火阀；**AY ≠ BA**——新风正压/防火阀过≠冷冻水/塔侧过。  
- **AZ（手册53）**：冷通道封闭与机柜进出风；**AZ ≠ BA**——冷通道封闭/进出风过≠冷冻水/塔侧过；气流与水路各管各的。  
- **AU（手册48）**：滤网压差与气流组织；**AU ≠ BA**——滤网/压差/气流过≠水侧塔侧过。  
- **AN（手册41）**：门禁过≠冷冻水/塔侧交底过；进机房/上塔区仍要 AN；**不教绕过门禁/水阀/塔联锁**。  
- **AW（手册50）**：列头柜与末端配电；**AW ≠ BA**——列头末端过≠冷冻水/塔侧过。  
- **AS / AF**：UPS 旁路 / 油机市电；供电过≠冷冻水/塔侧过。  
- **AD（手册31）**：温度计/水质取样器具入库走 AD；**不能**用旧 AD 签日期顶本期 BA 窗或实测窗。  
- **AA（手册28）**：首年巡检日历；冷冻水/塔侧抽检可挂 AA，缺秩序整改主贴仍 BA。  
- **N（手册15）**：监控/对时/告警风暴；冷冻水/冷却塔异常风暴挂 N 理风暴，**不先抬功率**；**禁关阀冒充、禁开旁通冒充、禁绕水阀/塔联锁、禁不安全泄水排污**；N 绿≠ BA 过。  
- **AQ（手册44）**：冷冻水/塔侧异常事件要调录像 → 另开 AQ；视频过≠BA 准用。  
- **AV / AR / AG / AP**：油品/燃油/电池/内阻；均不顶替 BA。  
- **R / J / X / I**：假绿挂 R；变更（边界门限、塔侧窗方法、冷冻水回路角色）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 BA 证冷冻水/冷却塔侧边界秩序，再谈覆盖病**。

## 3. 核心交付：插页 BA + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 BA（而不是先贴 AX / AT / AI / AO / AY / AZ / AU / N）

- 要签「机房冷冻水与冷却塔侧边界准用」、要开冷冻水/冷却塔窗、要交底水侧与塔侧/机内冷媒边界 → **主贴 BA**。  
- 精密空调压缩机与制冷剂本身 → **AX**（手册51）；冷冻水/塔侧本体窗仍 BA。  
- 冷凝水与加湿除湿本身 → **AT**；塔侧排污/水质窗仍 BA。  
- 温湿度测点/门限/联锁巡检本身 → **AI**；进出水温度窗仍 BA。  
- 漏水与汇流排本身 → **AO**；水侧边界交底仍 BA。  
- 新风正压与防火阀本身 → **AY**；冷冻水/塔侧仍 BA。  
- 冷通道封闭与机柜进出风本身 → **AZ**；水路仍 BA。  
- 滤网压差与气流组织本身 → **AU**；水路仍 BA。  
- 进机房/上塔区做交底 → 先 **AN**；门禁过≠冷冻水/塔侧交底过；**不教绕过门禁/水阀/塔联锁**。  
- 冷冻水/冷却塔告警风暴 → 先 **N** 理风暴；缺冷冻水/塔侧秩序整改仍 **BA**；**禁功率战**；**禁关阀冒充**；**禁开旁通冒充**；**禁不安全泄水排污**。  
- 假绿/顶替 → 挂 **R**；变更边界门限/塔侧窗方法/冷冻水回路角色 → 走 **J** 后再验 BA。  
- 本站无冷冻水/冷却塔回路 → 书面勾「不适用」；**不得**用 BA 顶 AX 风冷机内冷媒或 AZ 冷通道签。

```text
  │ 3. 无书面边界方法 / 关阀冒充 / 开旁通冒充               │
  │ 4. 套他站他期水质或进出水温度表                       │
  │ 5. 用 AX/AT/AI/AO/AY/AZ/AU/AN/AA/N/AQ/AW… 顶替本期BA │
  │ 6. 假绿放行 / 功率战 / 绕水阀塔联锁 / 不安全泄水排污   │
  │ 7. 未脱敏贴出真实回路编号全文或可还原门限               │
  │ 处置：拒签 → 补账/重测/挂R/挂N/走J；主贴仍 BA         │
  └────────────────────────────────────────────────────┘
```

### 3.4 与总三联单怎么写（脱敏 L3）

- **封面**：脱敏机房角色 + 本期相对期号 + 贴纸 BA + 「机房冷冻水与冷却塔侧边界交底」。  
- **现象栏**：只写角色与现象（如「供回水回路角色缺账」「塔侧风扇转无窗」「边界无书面方法」「套票嫌疑」），**不写**真实回路编号全文、水质门限可还原全文、单位名、联系人。  
- **动作栏**：补 BA-冻 / 补 BA-塔 / 补 BA-界 / 本期实测 / 会签 / 拒签挂改 / 挂 R / 挂 N / 走 J。  
- **边界栏**：勾清 AX/AT/AI/AO/AY/AZ/AU/AN/N——各过≠BA 过。  
- **会签栏**：准用 / 有条件整改 / 拒签；假绿 ≠ 会签放行。  
- **附件**：插页 BA1–BA8；AD 仪表准用指针（若用）；J 变更指针（若有）。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **冷冻水侧台账钉死**：供回水回路角色、换热器角色、阀件角色入账（编号脱敏）；禁「供水温度绿就算过」「口头说水侧正常」。  
2. **冷却塔侧有主有窗有方法/准用期**：风机/填料/补水排污/水质测点等以本网与 OEM 书面为准；每次塔侧相关维护有主人角色、有书面窗、有方法、有准用期；禁「风扇转当窗过」。  
3. **水侧与塔侧/机内冷媒边界窗与方法钉死**：书面固定；方法含水侧与塔侧/机内冷媒交界核对、与 AX/AT/AO/AI 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明逐步关阀/开旁通/不安全泄水排污操作教条）；禁「窗再说」「关阀冒充可过」「开旁通冒充可过」「绕水阀/塔联锁」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、水质表、进出水温度表必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「机房冷冻水与冷却塔侧边界准用」；假绿 ≠ 放行。  
6. **禁顶替 AX/AT/AI/AO/AY/AZ/AU/AN/AA/N/AQ/AW/AF/AS/AD/AV/AR/AG/AP，主贴 BA，假绿≠放行挂 R**：压缩机制冷剂签、冷凝加湿签、温湿度签、漏水签、新风正压防火阀签、冷通道进出风签、滤网气流签、门禁签、首年签、监控签、视频签、列头末端签、旁路签、油机签、仪表签、油品签、通风燃油签、电池签、内阻签都不顶本期冷冻水冷却塔签。  
7. **冷冻水/冷却塔异常风暴挂 N，边界/门限变更走 J，禁功率战；禁关阀冒充；禁开旁通冒充可过；禁伪造台账；禁绕水阀/塔联锁；禁不安全泄水/排污教条**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/回路编号全文/可还原坐标与联系人；禁公开传播未脱敏水质门限与边界参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签冷冻水冷却塔准用、无实测冒充边界过、关阀/开旁通冒充可过、不安全泄水排污冒充秩序齐，不是法外运维智慧**。医院冷冻水/冷却塔、数据中心 CHW/冷却塔公开资料只作故事与方法类比（§2.2）：**冻要约、塔要窗、界要法、验要本期、供水绿不算过、风扇转不算窗过、关阀旁通不算办法**——翻译成本网语言就是 BA-冻 / BA-塔 / BA-界 / BA-验 / BA-治。**这些是机房冷冻水与冷却塔侧边界交底秩序，不是「供水绿就签」「风扇转当过」「抬功率压告警」「关阀消告警」「开旁通冒充」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机房冷冻水与冷却塔侧边界准用」、对外宣传「供水绿/风扇转秒过」、把未实测写成已过、把关阀/开旁通写成秩序齐。允许做的：补冷冻水台账、补冷却塔窗、重开边界窗、挂 R/N/J、内部挂整改。

## 6. 工作实例（12 则，教学虚构，L3）

1. **供水绿想签准用**：运维以「供水温度绿」申请准用 → 班长翻 BA1 无冷冻水侧台账 → **拒签**；补冻侧台账与本期核对后再议。  
2. **风扇转顶塔侧窗**：外包称「风扇在转」→ BA2 无主人无窗 → **拒签**；补塔侧窗方法。  
3. **AX 签顶 BA**：班长想用 AX 压缩机制冷剂签顶本期 BA → **拒签顶替**；可挂 R；主贴仍 BA。  
4. **AT 顶塔侧排污**：冷凝加湿签在，想免塔侧排污/水质窗 → AT≠BA；塔侧仍要 BA2。  
5. **AI 顶进出水窗**：温湿度绿想免进出水温度窗 → AI≠BA；进出水窗仍 BA。  
6. **AO 顶水侧边界**：漏水探头过想免水侧边界交底 → AO≠BA；边界仍 BA3。  
7. **AY/AZ 顶水路**：新风正压/冷通道刚过想免冷冻水 → AY≠BA、AZ≠BA；水路仍 BA。  
8. **N 绿免实测**：大屏环境绿想免本期实测 → N≠BA；BA4 本期实测必做。  
9. **套邻站水质表**：外包拷邻站水质/进出水温度表改机房号 → **BA-验 拒签重测**。  
10. **关阀消告警**：外包关阀消供水告警后申请准用 → **禁**；挂 N/R；禁签准用。  
11. **开旁通冒充**：旁通开后温度「看着绿」→ **禁开旁通冒充**；挂整改。  
12. **公开群贴回路编号**：新人把真实回路编号与水质门限发工作群 → **L3 违规**；撤回脱敏；挂治。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **BA** 五子类：冻 / 塔 / 界 / 验 / 治——双字母续写在 AZ 之后的第一张 **BA**，负责机房冷冻水与冷却塔侧「台账清不清、塔侧有没有窗、边界有没有法、本期过了没有」。  
- 口诀：**冷冻水有账，冷却塔有窗，边界有法，会签才放。**  
- 故事：医院手术室/ICU 冷冻水与冷却塔侧（或数据中心 CHW / 冷却塔）——供水温度绿≠准用；风扇转≠窗过；口头说水侧正常≠方法过。  
- 八条硬规则：**冷冻水侧台账钉死**；**冷却塔侧有主有窗有方法/准用期**；**水侧与塔侧/机内冷媒边界窗与方法钉死**；**本组本机房本期实测禁套他站他期**；**会签才放行「机房冷冻水与冷却塔侧边界准用」**；**禁顶替 AX/AT/AI/AO/AY/AZ/AU/AN/AA/N/AQ/AW/AF/AS/AD/AV/AR/AG/AP 等，主贴 BA，假绿≠放行挂 R**；**冷冻水/冷却塔异常风暴挂 N、边界/门限变更走 J、禁功率战、禁关阀冒充、禁开旁通冒充、禁伪造台账、禁绕水阀/塔联锁、禁不安全泄水排污教条**；**脱敏 L3**。  
- **BA 不替代 AX，也不替代 AT，也不替代 AI，也不替代 AO，也不替代 AY，也不替代 AZ**：AX=压缩机制冷剂；AT=冷凝加湿；AI=温湿度联锁巡检；AO=漏水汇排；AY=新风正压防火阀；AZ=冷通道封闭进出风；BA=冷冻水与冷却塔侧边界交底准用。
