## 1. 为什么要写这篇手册（动机 + 现场对话）

前五十八篇手册从 A–E 协议一路写到 BE 加湿器水质与电极蒸汽罐更换：其中 **AM 回答「天馈接地与防雷浪涌抽检」**（天馈/塔脚/天馈侧 SPD），**AO 回答「漏水与汇流排探测」**，**AW/AF/AS 回答「供电链」**，**BC 回答「机柜配电与PUE/负载分区」**，**AD 回答「备件仪表准用」**，**AN 回答「门禁与访客陪同」**，**AA 回答「交维后首年巡检」**，**N 回答「电源监控/对时/告警风暴」**，**AQ 回答「视频监控调阅与证据链」**，**BE 回答「加湿器水质与电极蒸汽罐更换」**，**BD 回答「冷冻水泵组与定压补水」**。可还没有单独钉死一件事——**机房内接地与等电位联接、以及机房侧/配电侧浪涌保护不是「接地棒在 / 看着连着 / 口头说接地正常 / SPD 绿灯就能签」：机房接地台账要钉死（机柜/汇流排/设备外壳/等电位联接角色·测点）；等电位联接要有主人有窗有方法有准用期（联接螺栓/跨接线/等电位带·周期窗；禁看着连着当窗过、禁口头连过）；机房 SPD 与接地/等电位边界窗与方法要书面固定（与 AM/AO/AW/AF/AS/BC/AN/N 分工；禁旁路SPD、禁拆跨接冒充、禁不安全带电违章）；本组本机房本期实测禁套他站他期——能不能签「机房接地与等电位浪涌保护准用」？** 这就是本篇的 **BF**——**机房接地与等电位浪涌保护巡检交底台账**（Excel 风格双字母：BE 之后 → **BF**）。

## 3. 核心交付：插页 BF + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 BF（而不是先贴 AM / AO / AW / AD / N）

- 要签「机房接地与等电位浪涌保护准用」、要开等电位联接窗、要交底机房侧SPD与接地/等电位边界 → **主贴 BF**。  
- 天馈接地与防雷浪涌抽检本身（天馈/塔脚/天馈侧SPD） → **AM**（手册40）；机房内接地·等电位·机房侧SPD本体窗仍 BF。**AM ≠ BF**。  
- 漏水探测与汇流排本身 → **AO**；等电位准用仍 BF（**AO ≠ BF**：漏水 ≠ 等电位准用）。  
- 列头末端 / 油机市电 / UPS旁路 / 机柜PUE → **AW / AF / AS / BC**；等电位仍 BF（**供电过 ≠ 等电位过**）。  
- 接地电阻表/钳表/跨接线/SPD备件入库 → **AD**；本期等电位/SPD窗仍 BF（**AD ≠ BF**：备件入库 ≠ 本期等电位/SPD窗）。  
- 进机房做交底 → 先 **AN**；门禁过≠接地等电位交底过；**不教绕过门禁/不安全带电**。  
- 接地/等电位/SPD告警风暴 → 先 **N** 理风暴；缺机房接地等电位秩序整改仍 **BF**；**禁功率战**；**禁旁路SPD**；**禁拆跨接冒充**；**禁不安全带电违章**。  
- 假绿/顶替 → 挂 **R**；变更接地系统/等电位联接方法/SPD型号位置/门限 → 走 **J** 后再验 BF。  
- 本站无机房等电位路径或无机房侧SPD路径 → 书面勾「不适用」；**不得**用 BF 顶 AM，也不得用 AM 顶 BF。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **机房接地台账钉死**：机柜/汇流排/设备外壳/等电位联接角色·测点入账（编号脱敏）；禁「接地棒在就算过」「口头说接地正常」。  
2. **等电位联接有主有窗有方法/准用期**：联接螺栓/跨接线/等电位带·周期窗等以本网与 OEM 书面为准；每次等电位相关维护有主人角色、有书面窗、有方法、有准用期；禁「看着连着当窗过」「口头连过」。  
3. **机房浪涌保护（SPD）与接地/等电位边界窗与方法钉死**：书面固定；方法含机房侧/配电侧SPD与接地/等电位边界核对、与 AM/AO/AW/AF/AS/BC/AN/N 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明逐步旁路SPD/拆跨接/不安全带电违章操作教条）；禁「窗再说」「旁路SPD」「拆跨接冒充」「不安全带电违章」「伪造台账」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、接地表、等电位表、SPD表必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「机房接地与等电位浪涌保护准用」；假绿 ≠ 放行。  
6. **禁顶替 AM/AO/AW/AF/AS/BC/AD/AN/AA/N/AQ/BE/BD/AT/AI/AX/AY/AZ/AU/BB/BA/AV/AR/AG/AP/AJ/AK/AH/AL，主贴 BF，假绿≠放行挂 R**：天馈接地浪涌签、漏水签、列头末端签、油机市电签、UPS旁路签、机柜PUE签、仪表/备件签、门禁签、首年签、监控签、视频签、水质换罐签、泵组定压补水签……都不顶本期机房接地等电位签。**尤其：AM ≠ BF，AO ≠ BF，AW ≠ BF，AD ≠ BF，N ≠ BF。**  
7. **接地/等电位/SPD 异常风暴挂 N，边界/门限/联接窗变更走 J，禁功率战；禁旁路SPD；禁拆跨接冒充；禁不安全带电违章；禁伪造台账**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/汇流排·SPD·跨接编号全文/可还原坐标与联系人；禁公开传播未脱敏接地/等电位/SPD门限与参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签机房接地等电位准用、无实测冒充边界过、旁路SPD/拆跨接/不安全带电违章冒充秩序齐，不是法外运维智慧**。医院等电位联接与机房浪涌保护、数据中心 equipment bonding / equipotential bonding / facility SPD / ground bar 公开资料只作故事与方法类比（§2.2）：**地要约、等要窗、涌要法、验要本期、棒在不算过、看着连着不算窗过、口头接地正常不算方法过、绿灯不算过、旁路SPD不算办法**——翻译成本网语言就是 BF-地 / BF-等 / BF-涌 / BF-验 / BF-治。**这些是机房接地与等电位浪涌交底秩序，不是「棒在就签」「看着连着当过」「抬功率压告警」「旁路SPD先过」「拆跨接冒充」「带电违章冒充」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机房接地与等电位浪涌保护准用」、对外宣传「棒在/看着连着/口头接地正常/SPD绿灯秒过」、把未实测写成已过、把旁路SPD/拆跨接/带电违章写成秩序齐。允许做的：补机房接地台账、补等电位窗、重开SPD边界窗、挂 R/N/J、内部挂整改。

## 6. 工作实例（12 则，教学虚构，L3）

1. **接地棒在想签准用**：运维称棒还在要签准用 → 查 BF1，无机房接地台账本期核对 → **拒签**；补 BF-地。  
2. **看着连着 / 口头连过当窗过**：外包称「看着连着 / 连过了」免窗页 → **拒签**；补 BF-等 主人/窗/方法/准用期。  
3. **AM 顶替 BF**：班长用 AM 天馈接地浪涌签顶本期机房等电位签 → **挂 R**；主贴仍 BF；**AM过≠BF过**。  
4. **AO / AW 顶替**：站务称漏水与列头末端过了等电位免做 → **拒签顶替**；AO≠BF、AW≠BF；漏水≠等电位；供电≠等电位。  
5. **N 绿免实测**：大屏监控绿，本期实测免 → **拒签**；N绿≠BF过；补 BF-验。  
6. **套邻站表**：外包拷邻站接地/等电位/SPD表改机房号 → **BF-验 拒签重测**；禁套。  
7. **功率战**：雷击/SPD告警，网优要抬功率 → **禁功率战**；先挂 N；缺秩序整改贴 BF；天馈侧另问 AM。  
8. **旁路SPD冒充**：外包旁路SPD消告警后要求准用 → **禁**；挂 N/R；禁签。  
9. **拆跨接冒充**：新人拆跨接「量一下」再冒充连好 → **禁**；挂整改；主贴 BF-治。  
10. **AD / AF / AS / BC 混签**：环境班称 AD 入库与 AF/AS/BC 供电过了，等电位免 → **拒签**；AD≠本期窗、供电≠等电位。  
11. **不安全带电违章**：外包未授权带电拧联接螺栓要求准用 → **禁**；挂 N/R；禁签。  
12. **泄密发群**：新人公开群贴真实汇流排号与SPD序列号 → **L3 违规**；脱敏重发；挂 BF-治。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **BF** 五子类：地 / 等 / 涌 / 验 / 治——双字母续写在 BE 之后的第一张 **BF**，负责机房接地与等电位浪涌保护「台账清不清、等电位有没有窗、浪涌边界有没有法、本期过了没有」。  
- 口诀：**接地有账，等电位有窗，浪涌有法，会签才放。**  
- 故事：医院手术室/ICU 等电位联接与机房浪涌保护巡检（或数据中心 equipment bonding / equipotential bonding / facility SPD / ground bar）——棒在≠准用；看着连着≠窗过；口头接地正常≠方法过；SPD绿灯≠本期过。  
- 八条硬规则：**机房接地台账钉死**；**等电位联接有主有窗有方法/准用期**；**机房SPD与接地/等电位边界窗与方法钉死**；**本期实测禁套**；**会签才放行**；**禁顶替 AM/AO/AW/AF/AS/BC/AD/AN/AA/N/AQ/BE/BD/…，主贴 BF，假绿≠放行挂 R**；**异常风暴挂 N、变更走 J、禁功率战/旁路SPD/拆跨接冒充/不安全带电违章/伪造台账**；**脱敏 L3**。  
- **BF 不替代 AM，也不替代 AO，也不替代 AW，也不替代 AD，也不替代 N**：AM=天馈接地浪涌；AO=漏水汇排探测；AW/AF/AS/BC=供电链；AD=备件仪表准用；BF=机房接地与等电位/机房侧SPD准用。**AM ≠ BF；AO ≠ BF；AW ≠ BF；AD ≠ BF；N ≠ BF。**
