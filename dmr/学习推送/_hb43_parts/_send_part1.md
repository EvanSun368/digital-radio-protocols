## 1. 为什么要写这篇手册（动机 + 现场对话）

前四十二篇手册从 A–E 协议一路写到 AO 漏水汇排：其中 **AG 回答「电池与充电器梯队轮换与容量抽检」**，**AF 回答「油机市电」**，**AD 回答「备件仪表准用」**，**AA 回答「交维后首年巡检」**，**AO 回答「机房漏水与接地汇流排巡检」**，**AM 回答「天馈接地与防雷浪涌」**，**AN 回答「机房门禁与访客陪同」**，**N 回答「电源监控/对时/告警风暴」**。可还没有单独钉死一件事——**蓄电池组内阻与核对性放电不是「表绿就能签」：内阻台账要钉死；核对性放电要有主人有窗有方法有准用期；抽检窗与方法（内阻仪/放电仪）要书面固定；本组本机房本期实测禁套他站他期——能不能签「内阻/核对性放电准用」？** 这就是本篇的 **AP**——**蓄电池组内阻与核对性放电**。

- 运维岗：「内阻表还绿着，内阻巡检就算齐了。」——**无台账/无本期实测仍准用** = 本篇拒签（规则1）。

- 物业：「上次测过差不多，放电再说。」——**无抽检窗方法，只听口头** = 规则3。  
- 外包：「邻站上周内阻曲线参数差不多，拷过来改个机房号。」——**套他站他期** = 规则4。  
- 班长：「AG 容量梯队签还在，AF 供电也过了，内阻核对也能签。」——**用 AG/AF/AD/AA/AO/AM/AN/N 顶替 AP** = 规则6。

| **AP-阻** | 无内阻台账、表绿无本期实测仍准用 → 拒签 | 「表绿就能签」「口头说一声」 |
| **AP-核** | 核对放电无主人、无窗、无方法、只看浮充 → 拒签 | 「只浮充电压当核对过」 |
| **AP-抽** | 无书面抽检窗/方法、只听口头或套监控绿 → 拒签 | 「放电再说」「监控绿当过」 |
| **AP-验** | 套他站他期曲线/照片、无会签 → 拒签 | 「邻站内阻曲线拷过来改机房号」 |
| **AP-治** | 假绿、用 AG/AF/AD/AA/AO/AM/AN/N 顶替、旁路电池告警、功率战、泄密 → 治理 | 「AG 签还在，内阻也能过」 |

### 2.5 建内阻台账 → 钉核对主人 → 抽检窗钉死 → 本期实测 → 会签放行 → 变更再验 阶段梯（背下来）

```text
  ① AP-阻 建内阻台账：组角色 · 单体角色 · 内阻基线/趋势角色 · 禁「表绿就能签」「口头说一声」
        │  无账 / 表绿无实测 → 不签内阻/核对性放电准用
        ▼
  ② AP-核 钉核对主人：核对性放电主人角色 · 书面窗 · 方法 · 准用期 · 禁「只浮充电压当核对过」
        │  无主人 / 无窗 / 无方法 / 无准用期 → 拒进入「可签」状态
        ▼
  ③ AP-抽 钉抽检窗：书面窗 · 方法（内阻仪/放电仪等；门限以本网为准） · 到场角色 · AD 准用指针
        │  无窗 / 「监控绿当过」 → 拒抽检签
        ▼
  ④ AP-验 本组本机房本期实测：实测记录 · 禁套他站他期曲线/照片 · 会签
        │  套票 / 只看浮充绿 → 拒签
        ▼
  ⑤ 会签「内阻/核对性放电准用」或「有条件整改」：本网授权本人签
        │  缺签 / 假绿顶替 → 拒签准用
        ▼
  ⑥ 变更（电池组改造/内阻门限/核对放电规程）→ 走 J + 触发再抽/再验（常挂 N 看电池告警风暴、挂 AG 看梯队/容量、挂 AD 看内阻仪/放电仪）
```

> **一句话分辨**：**AG** 回答「梯队·充电器·容量抽检**过了没有**」；**AF** 回答「油机市电切换·供电巡检**清不清**」；**AD** 回答「内阻仪/放电仪**准用不清**」；**N** 回答「告警风暴**理不理**」；**AP** 回答「这一组蓄电池 + 这一窗内阻测试 + 这一窗核对性放电**台账清不清、核对有没有窗、本期过了没有**」。**五个问题，五张（类）贴纸，不能一笔带过。**  
> **AP vs AG 钉死**：**AG** = 电池与充电器**梯队轮换与容量抽检准用**；**AP** = 蓄电池组**内阻测试**与**核对性放电**巡检边界——内阻/核对看起来像「容量健康」，但本篇管的是**内阻台账与核对放电边界**，不顶替 AG 的梯队/容量抽检准用；**AG 过 ≠ AP 过**；容量梯队签 ≠ 内阻/核对放电准用；内阻抽测 ≠ 完整容量试验（门限以本网为准，不发明条款）。

### 2.6 内阻与核对性放电最小工作流（背下来）

```text
  AP-阻 台账 + 组/单体内阻角色钉死
       ├─→ 有账？核对有主人窗方法准用期？ ──否──→ 拒签 / 补账补核
       └─→ 是
  AP-抽 约抽检窗 + 书面方法（内阻仪/放电仪）+ 到场勾选 + AD 准用指针
       │
  AP-验 本组本机房本期：实测记录 → 禁套声明 → 留痕 → 会签
       │  套票 / 只看浮充绿 → 拒签
       ▼
  会签「内阻/核对性放电准用」或挂整改；重大未闭禁签准用
       │
  放行或拒签；公开材料 L3；变更走 J 再触发；内阻异常风暴/放电窗风险挂 N；禁旁路电池告警
```

## 3. 核心交付：插页 AP + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AP（而不是先贴 AG / AF / AD / N）

| 现场要办的事 | 主贴 | 说明 |
|--------------|------|------|
| 内阻台账、核对放电、抽检签、假绿拒签 | **AP** | 本篇主职 |
| 内阻异常复测、核对放电复验 | **AP** | 本篇主场 |
| 蓄电池组/单体内阻趋势、基线对照 | **AP**（阻+抽） | 表绿≠合格；与 AG 边界见下 |
| 梯队轮换/容量抽检准用 | **AG**（可挂 AP） | AG 管梯队/容量；内阻/核对边界仍 AP |
| 油机/市电切换、供电巡检 | **AF**（可挂 AP） | 供电过≠内阻核对过 |
| 内阻仪/放电仪入库准用 | **AD**（可挂 AP） | 设备准用≠本期抽检过 |
| 交维后首年巡检日历 | **AA**（可挂 AP） | 首年日历≠本期抽检窗 |
| 电池室漏水/汇排 | **AO**（可挂 AP） | 漏水过≠内阻核对过 |
| 门禁/访客进机房做抽检 | **AN**（可挂 AP） | 门禁过≠内阻核对过 |
| 内阻异常风暴、放电窗风险、电池低压告警 | **N**（可挂 AP） | 先风暴后秩序；禁功率战；禁旁路电池告警 |
| 大屏浮充绿想直接签内阻/核对准用 | **AP-治 + R** | 假绿≠内阻/核对通过 |
| 套邻站旧内阻/放电曲线 | **AP-治** | 禁套；须本期本组本机房实测 |

### 3.2 插页 AP · 阻 / 核 / 抽 / 验 / 治（挂在总三联单或内阻/核对单后）

| 插页行 | 检查项（教学） | 缺了怎么办 |
|--------|----------------|------------|
| **AP1** | 内阻台账在：组/单体角色书面；基线/趋势可追溯 | 缺 → **拒签准用** |
| **AP2** | 禁「表绿就能签」「口头说一声」勾选 | 缺 → **拒「表绿就能签」** |
| **AP3** | 核对性放电有主人：主人角色；书面窗；方法；准用期；浮充≠核对 | 缺 → **拒签** |
| **AP4** | 抽检窗书面在；方法书面（内阻仪/放电仪等）；到场角色勾选；门限以本网为准 | 缺 → **拒抽检签** |
| **AP5** | 本组本机房本期实测记录在；脱敏机房与窗一致；禁套他站他期曲线/照片 | 套/缺 → **拒签** |
| **AP6** | 与 AG 容量梯队边界、与 AD 仪表准用边界勾选清晰；禁互相顶替叙事；内阻抽测≠完整容量试验勾选 | 混贴顶替 → **拒签或整改** |
| **AP7** | 「内阻/核对性放电准用」会签：相关授权本人签；重大未闭禁准用 | 缺签 → **拒签** |
| **AP8** | 公开材料 L3；变更项走 J；禁功率战；禁旁路电池告警叙事 | 违 → **治理** |

> 插页每一行都对应硬规则：AP1/AP2→规则1，AP3→规则2，AP4→规则3，AP5→规则4，AP6/AP7→规则5/6，AP8→规则7/8。**任何一行缺项，就停在那一行。**

### 3.3 和总三联单怎么写（接手册06）

- **现象栏**：写「内阻台账断档 / 核对无窗 / 只浮充当核对 / 套他站曲线 / 浮充假绿 / 放电窗风险 / 旁路电池告警嫌疑」等可复核现象，**不写空口玄学**。  
- **贴纸栏**：主贴 **AP**；支撑可贴 AG / AF / AD / AA / AO / AM / AN / N / R / J。  
- **处置栏**：拒签 / 补内阻台账 / 补核对窗 / 重开抽检窗 / 重实测 / 挂 R/N/J——**写动作，不写空口字段**。  
- **脱敏**：站/机房用角色编号；禁单位名全文、禁真实站名、禁电池序列号全文、禁联系人。

### 3.4 《本网蓄电池组内阻与核对性放电台账卡》预告

§7 给出可复印模板：封面拒签门槛、阻页、核页、抽页、验页、会签准用页、夜班速填五行。**一张卡跑完一窗抽检：阻→核→抽→验→签**；与 AG 容量梯队、AF 油机、AD 仪表指针对齐，避免「容量梯队过就当内阻过」「浮充绿就当核对过」「仪表在期内就免抽检窗」「监控绿就免实测」。
