## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **蓄电池组/单体内阻台账钉死**：组与单体角色、基线/趋势入账；禁「表绿就能签」「口头说一声」。  
2. **核对性放电有主有窗有方法/准用期**：每组核对放电有主人角色、有书面窗、有方法、有准用期；禁「只浮充电压当核对过」。  
3. **抽检窗与方法钉死**：书面固定；方法含内阻仪/放电仪等（**门限以本网为准**）；禁「放电再说」「只看监控绿」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、曲线、照片必须本期本组本机房；套邻站账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「内阻/核对性放电准用」；假绿 ≠ 放行。  
6. **禁顶替 AG/AF/AD/AA/AO/AM/AN/N，主贴 AP，假绿≠放行挂 R**：容量梯队签、供电签、仪表签、首年签、漏水签、接地签、门禁签都不顶本期内阻/核对签。  
7. **内阻异常风暴/放电窗风险挂 N，电池组改造/门限变更走 J，禁功率战；禁旁路电池告警**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/电池序列号全文/可还原坐标与联系人**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签内阻核对准用、无实测冒充抽检过，不是法外运维智慧**。医院 AED/抢救车电池公开资料、VRLA/UPS 内阻与放电公开科普只作故事与方法类比（§2.2）：**阻要约、核要窗、抽要法、验要实测、浮充绿不算过**——翻译成本网语言就是 AP-阻 / AP-核 / AP-抽 / AP-验 / AP-治。**这些是内阻核对巡检边界秩序，不是「表绿就签」「浮充当核对」「抬功率压告警」「旁路电池告警」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「内阻/核对性放电准用」、对外宣传「分钟级一键内阻秒过」、把未实测写成已过。允许做的：补内阻台账、补核对窗、重开抽检窗、重实测、挂 R/N/J、内部挂整改。

### 4.3 「内阻/核对性放电准用」最小集（AP）——缺页不能签「内阻/核对性放电准用」

1. 内阻台账页（组/单体/基线趋势）  
2. 核对性放电主人与书面窗、方法、准用期页  
3. 书面抽检窗与方法页（内阻仪/放电仪）  
4. 本期本组本机房实测记录（禁套声明）  
5. AG 容量梯队边界勾选（防顶替；内阻≠完整容量）

7. AF 供电边界勾选（若相关，防顶替）  
8. 会签页（准用或有条件整改）  
9. 未闭项清单（有则挂整改，重大未闭禁签准用）  
10. 脱敏勾选（L3）  
11. 变更指针（若本期有电池组/门限/规程变更 → J）

### 4.7 台账路径（一窗内阻/核对抽检跑完）

1. 开窗：核对书面抽检窗与到场角色  
2. 对账：AP-阻 台账 vs 现场组/单体；AP-核 核对清单 vs 主人/窗/方法/准用期  
3. 抽检：按本网方法做内阻仪/放电仪等（**不写死门限数值**）  
4. 留痕：本期本组本机房记录；禁套声明勾选  
5. 分诊：异常 → 挂整改；内阻异常风暴/放电窗风险 → N；假绿嫌疑 → R；变更需求 → J；完整容量另窗走 AG；仪表准用回 AD  
6. 会签：准用或有条件整改；交班口述未闭项  

### 4.8 签字前 15 分钟清单（可复印）

1. 内阻台账页在不在？组/单体/基线趋势齐不齐？  
2. 核对主人、书面窗、方法、准用期在不在？有没有只看浮充？  
3. 书面抽检窗与方法在不在？（内阻仪/放电仪）  
4. 是不是本组本机房**本期**实测？（禁套他站他期曲线/照片）  
5. 有没有人想用 AG/AF/AD/AA/AO/AM/AN/N 签顶 AP？  
6. AP vs AG 边界勾清了没有？（梯队/容量回 AG；内阻/核对回 AP；内阻≠完整容量）  
7. 内阻异常/放电窗有没有人要抬功率或旁路电池告警？→ 禁，挂 N；旁路挂整改/R  
8. 会签人是不是本网授权角色？重大未闭是否仍想硬签合格？  
9. L3：有没有真实站名/电池序列号全文/机房全称/联系人进单或进群？

### 4.10 内阻 / 核对 / 抽检与 AP 的咬合（教学直觉，门限以本网为准）

- **内阻表绿 ≠ 合格**：要有台账、本期实测。  
- **只看浮充电压 ≠ 核对过**：要有主人、窗、方法、准用期、本期核对。  
- **监控绿 ≠ 本期实测过**：要有书面抽检窗与方法留痕。  
- **AG 容量梯队过 ≠ 内阻/核对过**：AG 与 AP 各管各的。  
- **内阻抽测 ≠ 完整容量试验**：完整容量回 AG；本篇不发明门限。  
- **供电过 ≠ 内阻核对过**：AF 与 AP 各管各的。  
- **仪表在期内 ≠ 本期抽检窗可免**：AD 只答设备准用期。  
- **门禁过 ≠ 内阻核对过**：AN 与 AP 各管各的；进机房仍要 AN。  
- **漏水过 ≠ 内阻核对过**：AO 与 AP 各管各的。  
- **监控绿 ≠ 内阻/核对准用过**：N 绿不顶 AP。  
- **门限、合格判据、抽检窗长度、放电深度以本网制度/合同为准**——本篇不发明数值与条款号；公开内阻/放电资料只借秩序直觉。

### 4.11 与梯队容量（AG）/ 油机（AF）/ 仪表（AD）/ 首年（AA）/ 漏水（AO）/ 接地（AM）/ 门禁（AN）/ 监控（N）怎么配合

进机房做内阻/核对抽检常见组合：**AN** 办门禁访客 → **AP** 办内阻核对抽检 → 完整容量另窗走 **AG** → 仪表准用回 **AD** → 供电边界可挂 **AF** → 内阻异常风暴/放电窗风险挂 **N** → 电池组/门限/规程变更走 **J**。容量抽检窗与内阻核对窗可同日不同贴，**互不顶替**；内阻异常可触发 AG 再看梯队/容量，内阻核对秩序仍 AP。

### 4.12 内阻异常 / 放电窗与上行更脆直觉

蓄电池组内阻劣化、核对放电未做、浮充假绿、放电窗告警风暴、旁路电池告警，常先让后备与空口变「脆」：掉电、误告、掉话——手台功率小、天线短，**上行往往比下行先不够用**。现场第一反应不该是抬功率，而该是：

```text
  内阻异常风暴 / 放电窗风险 / 电池低压告警
       │
       ├─→ 告警风暴？ → 挂 N 理风暴（对时/风暴秩序）；禁旁路电池告警
       ├─→ 内阻/核对台账与本期实测清不清？ → 主贴 AP
       ├─→ 完整容量？ → 另窗 AG（不顶替）
       ├─→ 仪表准用？ → AD（支撑）
       ├─→ 有人要抬功率？ → 禁功率战
       └─→ 要改电池组/门限/规程？ → 走 J + 再验
```

12.5 kHz / 4FSK / 2-slot TDMA 的窄车道里，乱抬功率只会先伤邻道与自身秩序；**先问 AP 秩序，再谈覆盖病（X/I 指针）**。

## 6. 工作实例（12 则，教学虚构，L3）

1. **表绿拒签**：脱敏机房-07 内阻表绿，无内阻台账页 → AP-阻拒签「内阻/核对性放电准用」；允许补账，不允许口头顶过。  
2. **浮充假绿**：机房角色-B 浮充电压在，无核对性放电书面窗与本期核对记录 → 挂 R，补 AP-核/抽后再谈会签。  
3. **套邻站曲线**：外包拷邻站上周内阻曲线改机房号交差 → AP-验拒签，责令本期本组本机房重开实测。  
4. **容量顶内阻**：班长称「AG 容量梯队签还在，内阻也能签」→ 拒签；容量过≠内阻/核对过；主贴仍 AP。  
5. **供电顶核对**：AF 供电巡检会签在有效窗，想顺带签核对性放电 → 拒签；AF≠AP；各管各的。  
6. **仪表顶窗**：AD 内阻仪仍在准用期内，外包想免做抽检窗 → 拒签；AD 只支撑设备准用，不顶 AP 窗。  
7. **门禁顶抽检**：AN 门禁陪同交底过，想免做内阻核对抽检 → 拒签；门禁过≠内阻核对过；进机房仍要 AN，抽检仍要 AP。  
8. **旁路电池告警**：有人想旁路电池低压告警消铃 → **禁**；挂整改 + N/R；本期实测未做不得签准用。  
9. **门限变更未走 J**：私自改内阻门限或核对放电规程未走变更 → 补走 J，触发再验 AP；未闭前禁签准用。  
10. **放电窗抬功率**：电池低压告警一片，网优想抬功率压掉话 → **禁功率战**；先 N 后 AP；上行更脆先问秩序。  
11. **内阻当完整容量**：外包称「内阻抽测过了就等于完整容量试验」→ 拒签叙事；内阻≠完整容量；完整容量另窗 AG；本期内阻核对仍 AP。  
12. **群泄密**：宣传岗把真实电池序列号与机房全称发群表扬 → L3 违规，撤帖脱敏重发；治理勾 AP-治。
