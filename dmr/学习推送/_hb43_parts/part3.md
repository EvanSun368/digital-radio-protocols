## 8. 术语表（本篇约 18 词）+ 易错观念

| 词 | 本篇用法（教学） |
|----|------------------|
| **AP** | 本篇贴纸：内阻·核对放电边界 |
| **AP-阻** | 蓄电池组/单体内阻台账 |
| **AP-核** | 核对性放电主人与窗/方法/准用期 |
| **AP-抽** | 抽检窗与方法（内阻仪/放电仪） |
| **AP-验** | 本组本机房本期实测、会签 |
| **AP-治** | 假绿、顶替、伪造、旁路电池告警、功率战、泄密治理 |
| **内阻 / 阻抗** | 单体或组内阻/阻抗角色（教学；测法与门限以本网为准） |
| **核对性放电** | 按本网窗与方法做的核对/验证性放电；**不等于**完整容量试验本身（完整容量回 AG） |
| **浮充电压** | 浮充维持电压；**不等于**核对过、不等于内阻合格 |
| **内阻仪 / 放电仪** | 抽检用仪表；入库准用回 AD |
| **表绿≠合格** | 仪表/监控显示绿不等于台账齐、不等于本期抽检过 |
| **浮充≠核对** | 只看浮充电压不等于核对性放电已做 |
| **内阻≠完整容量** | 内阻抽测不等于完整容量试验；完整容量回 AG |
| **假绿** | 监控/浮充绿但无本期秩序实证；挂 R |
| **套票** | 套他站他期曲线/照片当本期 |
| **功率战** | 用抬功率压告警/压掉话；内阻/放电窗也禁止 |
| **L3** | 脱敏等级：禁真实频点/站名/全称/电池序列号全文/单位名/联系人 |
| **AG / AF / AD / N / R / J** | 容量梯队 / 油机市电 / 仪表准用 / 风暴 / 假绿 / 变更——指针，不重写 |
| **十字阻核钉** | 阻、核、窗、法、房、测、签、闭、密、界 |

**易错观念**  
- ✗ 内阻表绿 = 合格 → ✓ 要有账、本期实测。  
- ✗ 只看浮充电压 = 核对过 → ✓ 要有主人、窗、方法、准用期、本期核对。  
- ✗ 监控绿 = 本期实测过 → ✓ 要有书面抽检窗与方法留痕。  
- ✗ AG 容量过 / 供电过 / 仪表在期内 = 内阻核对过 → ✓ AG / AF / AD ≠ AP。  
- ✗ 内阻抽测 = 完整容量试验 → ✓ 内阻≠完整容量；完整容量回 AG。  
- ✗ 邻站曲线能用 → ✓ 套票拒签。  
- ✗ 电池告警先抬功率 / 旁路消铃 → ✓ 先 N 后 AP，禁功率战，禁旁路。  
- ✗ 伪造内阻/放电曲线消告警 → ✓ 红线，禁止；本篇不教手法。

2. 规则1；AP-阻。  
3. 规则2。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AP** 五子类：阻 / 核 / 抽 / 验 / 治——双字母续写的第十六张，负责内阻·核对「台账清不清、核对有没有窗、本期过了没有」。  
- 故事：医院手术室/ICU AED / 抢救车蓄电池内阻与核对性放电——内阻表绿≠合格；只看浮充电压≠核对过；AG 容量梯队签≠内阻/核对放电准用；内阻抽测≠完整容量试验；监控绿≠本期实测过；套邻站内阻曲线=拒签；AG/AF/AD/AA/AO/AM/AN/N 不顶替 AP；假绿≠会签放行。  
- 阶段梯：建内阻台账 → 钉核对主人 → 抽检窗钉死 → 本期实测 → 会签放行 → 变更再验。  
- 八条硬规则：**蓄电池组/单体内阻台账钉死**；**核对性放电有主有窗有方法/准用期**；**抽检窗与方法钉死**；**本组本机房本期实测禁套他站他期**；**会签才放行「内阻/核对性放电准用」**；**禁顶替 AG/AF/AD/AA/AO/AM/AN/N 等，主贴 AP，假绿≠放行挂 R**；**内阻异常风暴/放电窗风险挂 N、电池组改造/门限变更走 J、禁功率战、禁旁路电池告警**；**脱敏 L3**。  
- **AP vs AG**：AG = 梯队轮换与容量抽检准用；AP = 内阻测试与核对性放电巡检边界；AG 过 ≠ AP 过；内阻抽测 ≠ 完整容量试验。
