## 1. 为什么要写这篇手册（动机 + 现场对话）

前二十篇手册把「家里怎么养」和「邻居怎么处」基本写全了：A–E 协议，F 射频指纹，G 实验室，H 话务，I 室分，J 写频，K 电源，L 井库，M 批量 / OTAP，N 监控对时，O 有源隔离，P 口部，Q 金机，R 假绿演练，S 邻频协调与边界联测。可现场还有一类债——**投诉已经进来了**：

- 用户：「我们这块听不清，肯定被干扰了！」——**未分诊**：可能是本网覆盖空洞、金机漂移、写频错、假绿、也可能是真干扰。  
- 班长：「对方说我们压了他们，先把功率开大顶回去！」——**未分诊就动手** = 功率战（手册20 规则2 + 本篇规则1）。  
- 网管岗：「屏上全绿，怎么可能有干扰？」——**假绿**（手册19 R）：心跳在、业务未必在；或告警风暴把真干扰淹没（手册15 N）。  
- 对方单位：「你们的证据不对时，我们不认。」——频谱截图、录音、金机记录若**无统一对时**，证据链断在第一步。  
- 领导：「兄弟单位，私了吧，录音别留了。」——**私了毁证**；条例给的路径是向无线电管理机构投诉，不是私下销毁物证。  
- 新人：「这不就是手册07 F 吗？」——F 是**病长什么样**（同频 / 邻道 / 互调 / 时隙指纹）；本篇是**投诉进来之后的分诊台 + 物证链 + 判定路径**，主贴新贴纸 **T**。跨网要协调复测时挂 **S**。

这几句背后是同一件事：

> **「干扰投诉分诊与证据链」在现场至少有五个坑**：**① T-分** 先分内因/外因、同网/跨网、瞬时/持续、语音/数据、单点/片区；**② T-证** 证据最小集（对时、金机/频谱/BER/录音/网管、地点、双方状态）；**③ T-链** 采集→保管→互签→脱敏，断链禁结案；**④ T-判** 可自愈 / 需联测 / 需协调(S) / 需主管部门 / 假绿或操作误报；**⑤ T-治** 无证据禁结案、禁功率战报复、禁私了毁证、公开仓 L3。  
> 把 ①–⑤ 当成「有投诉就加功率」「没证据也能甩锅」「断链也凑合结案」，会把下一任和主管部门一起拖进泥潭。

本篇目标：能背出**干扰投诉分诊与证据链工作流**；会用新贴纸 **T（分 / 证 / 链 / 判 / 治）** 与五个子类；会填**插页 T（T1–T8）**和《本网干扰投诉分诊与证据链卡》；能用「**医院急诊分诊台 + 法医物证链**」故事讲清：先分诊再开刀、物证最小集、保管链不断、判定五种出口、拒签与上报；能拒绝「未分诊就加功率、无证据结案、断链当正式证据、假绿当干扰成立、私了毁证、公开泄密」；自测过关后，回库把本网最近一次干扰投诉（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：凡引条款均已核原文（《无线电管理条例》第六十五条、六十六条；工信部无线电干扰投诉受理中心相关通知与工作流程；ITU-R SM.1753 / SM.854 / SM.1392 等监测方法），**数字与程序以原文为准，本篇只作教学转述**；**现象与证据一律用相对道号、角色标签、相对刻度表述，禁真实频点 / 站名 / 单位名 / 联系人 / 坐标 / 可识别原声**；**不教干扰、压制、报复性发射、毁证或绕过许可**；F 仍管指纹，S 仍管事前协调与双方联测，跨网投诉**主贴 T**，需协调复测时**挂 S**；外国 / 厂商资料只借**测量与定位方法**，**投诉与查处以国内法规与属地无线电管理机构为准**。

## 2. 总图 / 故事：干扰投诉像「医院急诊分诊台 + 法医物证链」

### 2.1 一句话：投诉进来先分诊（是哪一类病），再取最小物证集并保管不断链，再判定走哪条出口（自愈 / 联测 / 协调 / 主管部门 / 误报），证据不齐或断链就不结案——否则急诊室会把骨折当感冒治、把假绿当恶性干扰、把物证弄丢还跟人打官司

```text
   ┌──────────────────────────────────────────────────────────────────┐
   │   急诊大厅：有人推门喊「疼！」（= 干扰投诉进线）                │
   │                                                                  │
   │   分诊台护士先问五组题（T-分）                                    │
   │     内因还是外因？同网还是跨网？瞬时还是持续？                    │
   │     语音还是数据？单点还是片区？                                  │
   │                                                                  │
   │   法医物证最小集（T-证）                                         │
   │     时间对齐（钟）· 金机/频谱/BER/录音/网管截图 · 地点 · 双方状态│
   │                                                                  │
   │   物证保管链（T-链）                                             │
   │     采集 → 封存保管 → 互签 → 对外脱敏；断一环禁当正式证据        │
   │                                                                  │
   │   主治判定五出口（T-判）                                         │
   │     可自愈 / 需联测 / 需协调(S) / 需主管部门 / 假绿·操作误报     │
   │                                                                  │
   │   治理拒签（T-治）                                               │
   │     无证据禁结案 · 禁功率战报复 · 禁私了毁证 · 公开仓 L3         │
   │                                                                  │
   │   ✗ 未分诊就开大刀（加功率/关邻站）= 规则1                      │
   │   ✗ 物证袋破了还拿去出庭 = 断链禁结案（规则3）                   │
   │   ✗ 监护仪全绿就说病人没病 = 假绿拒签（规则5）                   │
   └──────────────────────────────────────────────────────────────────┘
```

口诀：

> **先分诊，再取证，链不断，后判定。**  
> 未分诊就加功率 = 急诊没问病史就开胸——**害人害己**。  
> 物证袋破了还结案 = 断链——**法庭（主管部门 / 对方）不认。**

### 2.2 「急诊分诊 + 物证链」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **分诊** | 急诊分诊台五组题 | 内因/外因、同网/跨网、瞬时/持续、语音/数据、单点/片区——先贴标签再动手 | T-分 |
| **取证** | 法医最小物证清单 | 对时 + 金机/频谱/BER/录音/网管 + 地点 + 双方状态 | T-证 |
| **保管链** | 物证袋编号、移交签字、封存 | 采集→保管→互签→脱敏；缺一环禁当正式证据 | T-链 |
| **判定** | 主治开五条出口之一 | 可自愈 / 需联测 / 需协调(S) / 需主管部门 / 假绿或操作误报 | T-判 |
| **拒签治理** | 病历不全不结案、禁私了毁证 | 无证据禁结案、禁功率战、禁毁证、争议上报、L3 | T-治 |

> 公开方法（ITU-R SM.1753 噪底测量、SM.854 测向定位、SM.1392 监测系统基本要求、Keysight / R&S 干扰搜寻教程）告诉我们：**先确认现象可复现与可记录，再谈定位与归责**。国内投诉路径以《无线电管理条例》第六十五条、工信部干扰投诉受理中心流程为准。本篇只借顺序，不抄门限、不发明时限数字以外已核原文的内容。

### 2.3 和手册07 / 15 / 18 / 19 / 20 的咬合（指针，不重写）

- **手册07 F**：F 是**射频诊断指纹**（同频 / 邻道 / 互调 / 时隙、3:1 衰减器）。投诉分诊判定「本网射频异常」时**次挂 F**；**未分诊前不直接用 F 结案「对方干扰」**。  
- **手册15 N**：证据最小集的第一件是**对时**；钟差未写清 → 断链。告警风暴可能掩盖真投诉，也可能制造假投诉。  
- **手册18 Q**：取证必须用**在档金机**；金机漂移未排除 → 可能是误报（T-判「操作/金机误报」）。  
- **手册19 R**：网管「全绿」不能单独证明「无干扰」——**假绿拒签「干扰不成立」也拒签「干扰成立」**；先证业务真实态。  
- **手册20 S**：**事前**邻居台账、兼容核算、双方四态联测。本篇是**投诉已进线**的事后分诊；跨网需协调复测时**主贴 T，挂 S**。  
- **手册06**：对外交换、上报、公开仓一律 **L3**。

### 2.4 新贴纸 T：分 / 证 / 链 / 判 / 治（五个子类）

```text
                ┌──────────── 贴纸 T · 分/证/链/判/治 ────────────┐
                │  T-分  分诊标签：内因·外因·同网·跨网·瞬时·持续·语/数·单点·片区 │
                │  T-证  证据最小集：对时·金机/频谱/BER/录音/网管·地点·双方状态 │
                │  T-链  保管链：采集→保管→互签→脱敏；断链禁结案                 │
                │  T-判  判定出口：自愈·联测·协调(S)·主管部门·假绿/误报         │
                │  T-治  治理拒签：无证据禁结案·禁功率战·禁毁证·争议上报·L3     │
                └──────────────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签 / 拒放行触发 |
|------|--------|----------------------|
| **T-分** | 五组分诊题未答完就动手 → 禁开工单 | 「反正就是干扰，先开大」 |
| **T-证** | 证据最小集缺任一项 → 禁结案 / 禁对外甩锅 | 「就一张截图，没对时」 |
| **T-链** | 无保管记录、无互签、已脱敏原件被删 → 断链禁当正式证据 | 「录音我听完就删了」 |
| **T-判** | 未走完分诊+取证就写「对方恶意干扰」→ 拒签 | 「感觉是他们」 |
| **T-治** | 功率战、私了毁证、公开泄密 → 治理 | 「私了吧，证据别留」 |

### 2.5 干扰投诉分诊与证据链最小工作流（背下来）

```text
  投诉进线（用户 / 对方单位 / 网管告警 / 值班口述）
        │
        ▼
  五组分诊标签齐？（内因外因·同网跨网·瞬时持续·语/数·单点片区）
        │否──▶ 先补 T-分；禁加功率 / 加信道 / 关邻站（规则1）
        │是
        ▼
  证据最小集齐？对时写清？──否──▶ 禁结案、禁对外甩锅（T-证 / 规则2）
        │是
        ▼
  保管链完整？（采集→保管→互签→脱敏路径）──否──▶ 断链禁当正式证据（T-链 / 规则3）
        │是
        ▼
  判定出口（T-判）─────────────────────────────────────┐
        │                                                │
        ├─ 可自愈（本网可复现故障已修复）→ 结案 + L3      │
        ├─ 需联测（现象跨边界 / 需四态）→ 挂 S-测         │
        ├─ 需协调（邻居台账 / 兼容）→ 挂 S-协 / S-邻      │
        ├─ 需主管部门 → 依法投诉路径（规则6）             │
        └─ 假绿 / 操作 / 金机误报 → 拒签「干扰成立」（规则5）
        │
        ▼
  结案词用 T 子类 + 出口；跨网主贴 T 可挂 S/F/N/Q/R
  变更侧先通知后复测（规则7）；全程禁功率战报复、禁私了毁证（规则4、6）
  公开包 L3（规则8）
```

现场口诀：

> **先分诊，再取证，链不断，后判定。**  
> 跳过分诊的「加功率工单」= 急诊没量血压就开刀。

## 3. 核心交付：插页 T + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 T（而不是先贴 F / S / R）

| 现场信号 | 主贴 | 可次挂 |
|----------|------|--------|
| 用户 / 对方 / 值班投诉「有干扰」进线 | **T**（先分诊） | F（指纹）、N（对时）、Q（金机） |
| 分诊为跨网 / 边界外溢嫌疑 | **T** + 挂 **S** | F-邻 |
| 分诊为本网射频指纹清晰 | **T-判**（本网）+ **F** | O / P 若适用 |
| 网管全绿但业务差 / 告警风暴 | **T** + **R** / **N** | 假绿拒签干扰成立 |
| 「被压了先开大」 | **T-治** | S-治（功率战） |
| 「私了，证据删了」 | **T-治** | — |
| 事前开通 / 扩容协调（尚无投诉） | **S**（不是 T） | — |

> **口诀**：病长什么样 → **F**；事前邻居与联测 → **S**；假绿与采集 → **R**；**投诉已进线的分诊、物证、判定、拒签 → T**。可叠挂，**投诉主贴 T**。

### 3.2 插页 T · 分 / 证 / 链 / 判 / 治（挂在总三联单或投诉单后）

| 行 | 名称 | 填写示例（教学虚构，L3） |
|----|------|--------------------------|
| **T1** | 主子类 + 次子类 | 「主 T-分 / 次 T-证」（或 T-链 / T-判 / T-治） |
| **T2** | 分诊五组标签 | 「外因候选 · 跨网 · 持续 · 语音为主 · 片区（边界-脱敏编号）」——禁写真实地名 |
| **T3** | 证据最小集勾选 | 「□对时与钟差 □金机号 □频谱相对刻度 □BER □录音（已脱敏说明）□网管截图 □地点角色标签 □双方状态（谁发谁静）」 |
| **T4** | 对时与钟差 | 「对时源：本网 NTP / 卫星钟（脱敏）；各方钟差写清；未对时 → 断链」 |
| **T5** | 保管链 | 「采集人角色 · 封存编号（脱敏）· 移交签字 · 原件保管位置角色 · 对外版脱敏等级」 |
| **T6** | 判定出口 | 「可自愈 / 需联测 / 需协调(S) / 需主管部门 / 假绿或操作误报」——单选主出口 |
| **T7** | 动作与禁令 | 「已冻结加功率工单；约 S 联测窗 / 已起草上报材料（L3）/ 拒签干扰成立」 |
| **T8** | 结案与脱敏 | 「结案词=T子类+出口；公开包 L3；原件保留期限按本网制度」 |

> **T2 未齐 → 禁止开加功率 / 加信道 / 关邻站工单（规则1）。**  
> **T3 缺任一项 → 禁结案、禁对外甩锅（规则2）。**  
> **T5 断链 → 该批证据禁当正式证据（规则3）。**  
> **T6 若写「感觉对方恶意」而无出口依据 → 本页作废重填。**  
> **T7 若写「开大顶回去」「私了删证」→ 本页作废（规则4、6）。**

### 3.3 「无证据禁结案 / 断链禁当正式证据」卡（贴值班台 / 网优班）

```text
  ┌────────── 干扰投诉分诊与证据链拒签卡（贴纸 T）──────────┐
  │  × 五组分诊标签未齐就开加功率 / 加信道 / 关邻站工单      │
  │  × 证据最小集缺对时 / 金机 / 地点 / 双方状态就结案甩锅  │
  │  × 无保管编号、无移交互签、原件已毁仍当正式证据        │
  │  × 仅凭网管全绿就签「干扰不成立」或「干扰成立」        │
  │  × 跨网投诉不贴 T、不挂 S，直接塞进 F 或 P 结案        │
  │  × 用加功率 / 抬增益报复邻网（功率战）                  │
  │  × 私了并销毁录音 / 频谱 / 金机记录                      │
  │  × 公开包出现真实频点 / 站名 / 单位名 / 联系人 / 坐标 / 可识别原声 │
  │  √ 例外：主管部门书面调取原件——走法定程序，另册登记    │
  └────────────────────────────────────────────────────────┘
```

### 3.4 和总三联单怎么写（接手册06）

- **现象**：写「投诉进线 + 分诊标签」，**未取证前不写「对方干扰成立」**，只写「干扰候选 / 待分诊」。  
- **证据**：对时与钟差、金机号、相对频谱刻度、BER、录音说明（已脱敏）、网管截图角色、地点角色标签、双方状态；全部 L3。  
- **贴纸栏 / 结案词**：主 **T-?**，次挂 S / F / N / Q / R；结案用子类 + 判定出口，禁「开大就好了」「私了算了」。

## 4. 深潜：八条硬规则 + 分诊五组题 + 证据最小集 + 保管链 + 判定出口

### 4.1 八条硬规则（本篇钉子）

1. **先分诊再动手：禁未分诊就加功率 / 加信道 / 关邻站**——分诊五组题未答完，射频变更工单冻结。  
2. **证据最小集未齐 → 禁结案 / 禁对外甩锅**——缺对时、金机、地点或双方状态，结论只写「候选」。  
3. **断链（无对时 / 无保管 / 无互签）→ 禁当正式证据**——物证袋破了不能拿去「出庭」。  
4. **跨网投诉主贴 T，协调复测挂 S；本网射频指纹挂 F；禁用功率战报复**——可叠挂，不可偷换；报复性抬功率双输且违规。  
5. **假绿 / 操作误报 / 金机漂移 → 拒签「干扰成立」**——也拒签仅凭全绿就写「干扰不成立」；先证业务真实态（手册19 R、18 Q、15 N）。  
6. **争议走无线电管理机构，禁私了毁证**——《无线电管理条例》第六十五条：依法设台受有害干扰可向无线电管理机构投诉；第六十六条：管理机构可要求维修、校准或降功率。私了并销毁录音 / 频谱 / 金机记录 = 本篇红线。  
7. **变更侧先通知后复测**（咬合手册20 规则7）——任一方边界侧 / 相关参数变更，先通知、后复测；未复测禁宣称「投诉已消除」。  
8. **脱敏 L3：公开包禁真实频点 / 站名 / 单位名 / 联系人 / 坐标 / 录音原声可识别内容**——上报材料按主管部门要求另行登记，公开仓与教学库只用 L3。

> 法规锚点（已核原文，教学转述）：《无线电管理条例》**第六条**不得造成有害干扰；**第六十五条**受扰可投诉，处理遵循「频带外让频带内、次要业务让主要业务、后用让先用、无规划让有规划」；**第六十六条**可要求维修、校准或降功率，无法消除可责令暂停发射。工信部依托 12381 设立无线电干扰投诉受理中心（工信厅无函〔2023〕25号）：统一受理、按责办理；民航/铁路/水上等系统应**先自查排除内因**再申诉。**这些是主管部门的处理规则与受理路径，不是你方单方「判对方让频」或「未取证就定性」的依据。**

### 4.2 分诊五组题（T-分）——急诊台必问

```text
  ① 内因 / 外因
     内因：本网覆盖空洞、设备故障、写频错误、金机漂移、电源/监控、操作失误、假绿
     外因：邻网外溢、共址互调、非法发射、工业噪声、其他合法业务
     → 先排内因清单（可并行取证，但结案前内因项要有勾选结果）

  ② 同网 / 跨网
     同网：本网邻站泄漏、口部、室分 → 可挂 P/O，主流程仍走 T 分诊
     跨网：邻单位 / 跨制式 / 跨行政区 → 主贴 T，协调复测挂 S

  ③ 瞬时 / 持续
     瞬时：秒级～分钟级，难复现 → 更依赖频谱瀑布 / 录音 / 网管时序
     持续：小时级以上或周期性 → 可约联测窗、可复现取证

  ④ 语音 / 数据
     语音：听感、BER、丢字、单通
     数据：短数据 / 状态消息失败率、确认超时（勿用「听不清」一句话糊弄）

  ⑤ 单点 / 片区
     单点：一楼一层一车 → 优先查本地设备 / 近场噪声 / 该点金机
     片区：多点同向劣化 → 边界、共址、邻道、片区电源或汇聚侧
```

**分诊未完成的冻结清单**：加功率、加信道、关邻站、私自挪频、对外发「对方干扰」函。允许做的：取证、对时、金机复核、查台账、约联测窗、起草 L3 上报草稿。

### 4.3 证据最小集（T-证）——少一件就不齐

| 序号 | 最小集项 | 为什么必须有 | 缺了会怎样 |
|------|----------|--------------|------------|
| 1 | **时间对齐** | 多方记录才能对齐因果 | 断链；对方可质疑「不是同一时刻」 |
| 2 | **金机记录** | 排除终端个体与漂移（Q） | 可能把金机坏当干扰 |
| 3 | **频谱 / 接收表现** | 相对刻度：本道中心还是偏侧能量 | 无法区分同频 / 邻道 / 宽带噪声 |
| 4 | **BER 或业务质量** | 把「听不清」量化 | 只剩主观口述 |
| 5 | **录音或业务日志**（按需） | 瞬时难复现时的旁证；对外须脱敏 | 瞬时案可能无法闭环 |
| 6 | **网管截图** | 告警、信道占用、链路态；警惕假绿 | 与现场脱节 |
| 7 | **地点角色标签** | 单点还是片区；是否「远我近他」 | 无法复测 |
| 8 | **双方状态** | 谁发谁静；是否双静基线 | 无法归因 |

> **口诀**：钟、机、谱、质、音、管、地、态——**八字最小集**。教学记忆用，现场按本网制度裁剪，但 **1、2、7、8 与对时** 几乎不可砍。

### 4.4 保管链（T-链）——急诊物证袋怎么走

```text
  采集（现场角色 + 时间戳 + 设备编号脱敏）
        │
        ▼
  封存（编号、介质、哈希或份数登记——按本网制度；教学不规定具体算法）
        │
        ▼
  移交互签（交班 / 跨班 / 跨单位交换：签字角色 + 时间）
        │
        ▼
  使用与复制（分析用副本；原件不动；副本同样登记）
        │
        ▼
  对外 / 上报（L3 版；原件按主管部门调取程序另册）
        │
        ▼
  留存与销毁（到期销毁须双人见证登记；禁私下删）
```

**断链典型姿势（全部拒签正式证据资格）**：

- 录音「听完就删了」无编号；  
- 频谱截图手机相册无时间源、无钟差；  
- 跨单位微信传图无互签、无脱敏说明；  
- 结案后为「私了」格式化金机 / 删网管；  
- 公开周报贴出真实频点与站名。

### 4.5 判定五出口（T-判）

| 出口 | 进入条件（教学） | 下一步 | 结案词示例（L3） |
|------|------------------|--------|------------------|
| **可自愈** | 内因明确且已修复，复测正常 | 结案；归档证据 | 「T-判自愈：本网××类内因已修复」 |
| **需联测** | 跨边界 / 需四态才能归因 | 挂 S-测，排联测窗 | 「T-判需联测：待 S 四态」 |
| **需协调(S)** | 邻居台账 / 兼容 / 变更通知缺失 | 挂 S-协 / S-邻 | 「T-判需协调：补 S 台账与核算」 |
| **需主管部门** | 协调不成 / 涉嫌非法发射 / 依法应投诉 | 走 12381 或属地管理机构；材料 L3+原件另册 | 「T-判上报：已依法投诉」 |
| **假绿/误报** | R/Q/N 证明非干扰或不可成立 | 拒签「干扰成立」；改挂 R/Q/N | 「T-判误报：假绿/金机/操作」 |

**禁止的第六出口**：「先开大再说」——不是出口，是违规。

### 4.6 弱项短补：为什么「听不清」不等于「邻道干扰」

```text
   「听不清」可能来自：
     · 覆盖边缘场强弱（本网规划 / 阻挡）——内因
     · 本道同频复用过近——本网 F-同
     · 邻道裙边 + 远近效应——跨网 T + S / F-邻
     · 互调产物落在本道——F-互 + 共址 S-邻
     · 写频错信道 / 错时隙 / 错色码——J / 操作误报
     · 金机漂移、电池、天线——Q
     · 网管假绿掩盖真实链路态——R
```

所以分诊五组题的第一刀永远是：**先列内因清单并勾选，再谈外因与对方。**

### 4.7 与主管部门路径怎么衔接（只讲路径，不教对抗）

教学流程（以公开通知为准，细节以属地最新要求为准）：

1. **本网自查**：内因清单 + 证据最小集 + 保管链；系统（行业）单位按通知要求**先自查再申诉**。  
2. **协调尝试**：跨网则挂 S；能书面协调解决的，优先协调 + 复测（规则7）。  
3. **依法投诉**：协调不成或涉嫌违法设台 / 有害干扰 → 向无线电管理机构投诉（条例第六十五条）；也可经 12381 无线电干扰投诉热线进入受理中心流程。  
4. **材料**：受理单所需技术资料用 **L3 对外版 + 按要求提供的原件**；本篇不编造表格字段，以官方受理单为准。  
5. **配合查处**：按管理机构要求提供监测配合、停发窗口等——**停发须本网审批，禁止网优个人扩大停发范围**。  
6. **结果归档**：回执、处置结果与本网 T8 结案对齐；公开宣传稿仍 L3。

### 4.8 投诉处理 60 分钟标准节奏（可复印，夜班可压缩）

| 分钟 | 动作 |
|------|------|
| 0–5 | 接诉：记录投诉人角色、现象、起止、地点角色；开 T1/T2 |
| 5–15 | 五组分诊；冻结加功率类工单；拉内因清单 |
| 15–35 | 取证：对时、金机、频谱相对刻度、BER、网管；写 T3/T4 |
| 35–45 | 封存编号、移交互签；T5 |
| 45–55 | 判定出口 T6；若需 S 则起草联测窗；若需上报则起草 L3 材料 |
| 55–60 | T7/T8；交班口述「冻结项 + 出口 + 下一步主人」 |

瞬时难复现案：拉长取证窗，优先瀑布图 / 录音旁证 / 网管时序，**仍禁无证据结案**。


### 4.9 证据时间线怎么画（T-证 / T-链）——给对方和主管部门看的「同一条时间轴」

投诉扯皮最常见的一句是：「你们说的那个时刻，我们根本没发射。」没有**同一条时间轴**，双方各执一词。教学画法（全部相对时刻、角色标签）：

```text
  统一时间轴（已对时，钟差已写进 T4）
  t0  投诉进线（用户角色 / 对方单位角色）
  t1  本网双静基线频谱（相对刻度）——若能做
  t2  现象复现窗：金机 BER 劣化段
  t3  网管对应告警 / 占用曲线（注意假绿）
  t4  对方状态声明或联测态切换（若已挂 S）
  t5  封存时刻（保管编号生效）
```

规则：

- 所有截图文件名 / 元数据时间若不可信，以**对时后的手记时刻**为准，并在 T4 写明。  
- 瞬时案画「现象出现的最早 / 最晚边界」+ 瀑布图片段说明，仍须封存。  
- 对外交换版只保留相对时刻与角色，去掉真实地名与绝对坐标（L3）。

### 4.10 「内因清单」最小勾选（T-分 附件，可复印）

未勾完内因就对外发「干扰函」= 本篇高频事故。最小勾选（教学）：

```text
  □ 该点 / 片区最近本网是否改过功率、天线、台址、信道、写频、固件
  □ 金机是否在档、是否近期校准 / 比对（Q）
  □ 覆盖规划 / 阻挡 / 电梯井库等已知空洞（L / P / I 指针）
  □ 室分有源告警、光路、隔离（O）
  □ 电源、倒换、对时、告警风暴（K / N）
  □ 网管采集是否假绿（R）
  □ 用户终端是否别的信道 / 时隙 / 色码（J / 操作）
  □ 同网邻站口部泄漏是否已按 P 排查
```

全部勾完仍指向外因 → 才进入「外因候选 + 跨网挂 S / 上报」主路径。

### 4.11 与手册20 四态联测的交接单（T → S）

当 T-判出口为「需联测」时，向 S6 窗口移交的最小字段（L3）：

| 移交项 | 内容 |
|--------|------|
| 投诉摘要 | 分诊五组标签 + 现象相对描述 |
| 已有证据编号 | T5 封存号列表 |
| 建议点位 | 历史投诉点 + 远我近他候选（脱敏编号） |
| 对时方式 | 与 T4 一致 |
| 中止条件 | 真实业务受影响超阈即停 |
| 结案依赖 | 四态结果互签后回写 T6/T8 |

**禁止**：联测窗里偷偷加功率「顺便试试」；联测窗不是功率实验窗（规则1、4）。

## 5. 现场映射：原话 → T 子类；对话脚本；夜班节奏

### 5.1 原话速查表

| 现场原话 | 先贴 | 一句话动作 |
|----------|------|------------|
| 「这块听不清，肯定干扰」 | T-分 | 五组题；先内因清单 |
| 「对方压我们，开大顶回去」 | T-治 | 规则1+4；冻结功率工单 |
| 「屏上全绿，不可能有干扰」 | T + R | 假绿：先证业务真实态 |
| 「就一张截图，结案说是他们」 | T-证 | 最小集未齐禁甩锅 |
| 「录音听完删了，省事」 | T-链 / T-治 | 断链 + 毁证红线 |
| 「边界那边两家扯皮」 | T + S | 主 T，挂 S-测 |
| 「本网站近处互调指纹」 | T-判 + F-互 | 本网射频挂 F；共址再挂 S-邻 |
| 「金机这台自己就不稳」 | T-判误报 + Q | 拒签干扰成立 |
| 「兄弟单位私了吧」 | T-治 | 规则6；禁私了毁证 |
| 「改完天线消停了，不用复测」 | T + 规则7 | 变更后须复测再结案 |
| 「周报把对方站名频点写上去了」 | T-治 | 撤回，L3 重写 |

### 5.2 对话脚本（五则）

**脚本 A · 未分诊就动手**  
- 班长：「用户投诉干扰，把中继功率开到顶。」  
- 你：「规则1：先分诊。T2 五组标签呢？内因清单勾了吗？」  
- 班长：「反正先顶住投诉。」  
- 你：「加功率工单冻结。先取证最小集；跨网再挂 S。功率战双输。」

**脚本 B · 证据不齐甩锅**  
- 网优：「截图发给对方，让他们认。」  
- 你：「对时呢？金机号呢？双方状态呢？T3 缺项禁对外甩锅，规则2。」  
- 网优：「那要多久？」  
- 你：「按 60 分钟节奏把最小集齐；齐了再谈判定出口。」

**脚本 C · 假绿**  
- 值班：「网管全绿，投诉是误报。」  
- 你：「R 规则：全绿≠业务好。金机走测 + 真实呼叫验证；否则拒签『干扰不成立』，也先拒签『干扰成立』。」  

**脚本 D · 私了毁证**  
- 领导：「和对方领导喝了酒，私了，录音别留了。」  
- 你：「规则6：争议走管理机构；禁毁证。录音封存进 T-链；协调可以谈，物证不能毁。」  

**脚本 E · 跨网挂 S**  
- 网优：「分诊是跨网持续片区，邻道偏侧能量。」  
- 你：「主贴 T，挂 S-测；约双方四态。未联测前结论写『候选』，不写『恶意』。」


**脚本 F · 瞬时难复现**  
- 用户：「刚才明明咔了一下，你们怎么测都没有？」  
- 你：「瞬时案不结『无干扰』。我们留瀑布触发、对时、金机守候窗；你下次一出现立刻报时刻。证据闭包前，结论写『未复现、监测中』。」  
- 班长：「那投诉单先关了？」  
- 你：「可以改状态为监测中，**不是结案**。T8 结案要等出口闭合。」

### 5.3 夜班 15 分钟怎么用

1. **3 分钟**：新投诉列表；每条是否已有 T2 标签。  
2. **4 分钟**：进行中的案：T3 缺哪项；有无断链风险。  
3. **4 分钟**：有无被冻结的加功率工单被悄悄打开——有则拦截（规则1）。  
4. **4 分钟**：三联单现象栏禁写「对方干扰成立」除非 T6 出口已闭合且证据链完整。

### 5.4 「投诉三问」（贴值班台）

1. 五组分诊标签齐了吗？（T-分）  
2. 证据最小集与对时齐了吗？保管链签了吗？（T-证 / T-链）  
3. 判定出口是哪一个？跨网挂 S 了吗？假绿排了吗？（T-判）  
三问不过，**禁止结案、禁止对外定性函、禁止加功率报复。**


### 5.5 投诉单「现象栏」禁写词与可写词（贴值班台）

| 禁写（未闭合前） | 可写 |
|------------------|------|
| 对方恶意干扰 | 外因候选；邻道偏侧能量（相对） |
| 已确认是某某单位 | 跨网候选；待联测 |
| 无干扰（仅因全绿） | 监控显示正常，业务待核实（R） |
| 用户误报（未取证） | 瞬时未复现，监测中 |
| 开大后正常故无事 | （禁止该叙事）功率变更须许可与复测 |

### 5.6 交班口述模板（30 秒）

> 「投诉案（脱敏编号）：分诊标签是 ____；最小集缺 ____；保管号 ____；出口暂定 ____；加功率工单已冻结；下一步主人是 ____；跨网是否挂 S：____。」

背下来，比「那个干扰还在查」有用一百倍。

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「用户喊干扰，其实是覆盖空洞」→ T-分 / T-判自愈
- **现象**：单点听不清，用户坚称干扰。  
- **分诊**：内因候选 · 同网 · 持续 · 语音 · 单点。  
- **证据**：金机在该点 RSSI/BER 差，邻点正常；频谱本道无异常偏侧能量。  
- **贴法**：主 T-判自愈，次（覆盖类本网工单，非本篇展开）。  
- **禁令**：未分诊不得对邻网发干扰函。

### 例 2 · 「未分诊功率战」→ T-治
- **现象**：对方投诉后本网抬功率，对方也抬，边界更差。  
- **贴法**：主 T-治，挂 S-治。  
- **动作**：双方回到许可参数；补分诊与取证；约四态；必要上报。  
- **禁令**：规则1、4；功率是许可事项。

### 例 3 · 「一张无对时截图对外甩锅」→ T-证 / T-链
- **现象**：仅一张手机频谱图发对方。  
- **贴法**：主 T-证，次 T-链。  
- **动作**：撤回；补对时与最小集；互签后再交换 L3 版。  
- **禁令**：规则2、3。

### 例 4 · 「网管全绿拒投诉」→ T + R
- **现象**：投诉持续，监控全绿。  
- **排除**：采集心跳在、业务链路实测失败（假绿剧本，手册19）。  
- **贴法**：主 T-判（先不定干扰），次 R。  
- **动作**：拒签「无干扰」；先治假绿；再重新分诊。  

### 例 5 · 「跨网邻道偏侧」→ T + S + F-邻
- **现象**：片区持续，频谱偏第一邻道侧能量抬升。  
- **分诊**：外因候选 · 跨网 · 持续 · 语音 · 片区。  
- **贴法**：主 T，挂 S-测 + F-邻。  
- **动作**：证据链齐后约四态；未联测不写「恶意」。  

### 例 6 · 「金机漂移当干扰」→ T-判误报 + Q
- **现象**：同一点只有某台金机差，更换在档金机正常。  
- **贴法**：主 T-判误报，次 Q。  
- **动作**：拒签干扰成立；金机送检 / 退役流程。  

### 例 7 · 「私了删录音」→ T-治
- **现象**：协调酒局后要求删除现场录音与频谱。  
- **贴法**：主 T-治。  
- **动作**：拒绝毁证；封存保管；协调可继续，物证按链保留；必要时依法投诉。  
- **禁令**：规则6。

### 例 8 · 「变更后不复测就宣称消除」→ 规则7
- **现象**：对方改下倾后口头说好了，本网未复测即结案。  
- **贴法**：主 T-判需联测，挂 S。  
- **动作**：复测窗 + 最小集对比变更前后；通过后才 T8 结案。  


### 例 9 · 「瞬时脉冲，难复现」→ T-证加厚 + 禁草率结案
- **现象**：用户报告「咔一下就没了」，现场即时频谱干净。  
- **分诊**：外因待定 · 同网或跨网待定 · **瞬时** · 语音 · 单点。  
- **动作**：拉长监测窗；保留瀑布/触发记录；核对网管时序；必要时多日同窗守候。  
- **贴法**：主 T-证，次 T-分（标签保持「待定」直至复现或旁证闭合）。  
- **禁令**：不得因「现在测不到」就对外结案「无干扰」或「用户误报」——瞬时案的结案标准是**证据闭包**，不是**此刻安静**。

### 例 10 · 「上报材料与公开周报混用」→ T-治 / L3
- **现象**：准备提交管理机构的材料被直接贴进公开学习周报，含可识别通话与站名。  
- **贴法**：主 T-治。  
- **动作**：周报撤回；公开仓 L3 重写；上报材料走另册，按调取程序管理原件。  
- **禁令**：规则8——上报原件 ≠ 公开包。

## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 一句话 |
|------|--------|
| **有害干扰** | 严重损害、阻碍或一再阻断合法无线电业务的干扰（教学口径；精确定义以法规与主管部门为准） |
| **分诊标签** | 五组题贴在投诉单上的结构化标签（T-分） |
| **内因 / 外因** | 本网自身问题 / 网外因素 |
| **证据最小集** | 结案前不可缺的那几类物证（T-证） |
| **对时 / 钟差** | 多方时间源对齐及差值记录；证据链第一环 |
| **保管链** | 采集→保管→互签→脱敏的完整路径（T-链） |
| **断链** | 保管链任一环缺失，证据失去正式资格 |
| **判定出口** | 自愈 / 联测 / 协调 / 主管部门 / 误报 五选一主出口 |
| **假绿** | 监控显示正常但业务真实态异常（手册19） |
| **金机** | 在档参考终端；取证与排误报用（手册18） |
| **四态联测** | 双静 / 甲发乙静 / 甲静乙发 / 双发（手册20） |
| **功率战** | 双方互相抬功率报复，双输 |
| **私了毁证** | 私下了结并销毁物证；本篇红线 |
| **12381 干扰投诉** | 工信部公共服务电话中的无线电干扰投诉入口（以官方通知为准） |
| **受理中心** | 工业和信息化部无线电干扰投诉受理中心（统一受理、按责办理） |
| **脱敏 L3** | 公开 / 教学最高脱敏等级 |
| **相对道号 / 相对刻度** | 不写真实频点与绝对地理坐标的表述法 |
| **贴纸 T** | 本篇主贴纸：分 / 证 / 链 / 判 / 治 |

**易错观念**

| 错 | 对 |
|----|----|
| 有投诉就是邻网干扰 | 先分诊；大量是内因 / 误报 |
| 先开大顶住投诉 | 未分诊禁动手；功率战双输 |
| 一张截图就能定责 | 最小集 + 保管链 |
| 全绿=无干扰 | 假绿可能；要业务验证 |
| 私了就把证据删了 | 禁毁证；争议走管理机构 |
| 投诉制度=F 诊断 | F 是指纹；T 是分诊与证据链；S 是事前协调联测 |

## 9. 自测（12 题）+ 参考答案

1. 贴纸 T 五个子类各是什么？各用一句话。  
2. 分诊五组题是哪五组？为什么未分诊禁加功率？  
3. 证据最小集至少应强调哪几项？缺对时属于什么问题？  
4. 保管链四步是什么？「听完就删录音」触犯哪条规则？  
5. 判定五出口是哪些？「先开大再说」为什么不是出口？  
6. 跨网投诉主贴什么？为什么还要挂 S？本网射频指纹挂什么？  
7. 网管全绿能否单独签「干扰不成立」？为什么？  
8. 条例第六十五条、六十六条分别给了投诉方和管理机构什么路径？（教学转述）  
9. 系统（行业）单位在向受理中心申诉前，公开通知要求先做什么？  
10. 情景：对方要求酒局私了并删频谱——你怎么回？贴哪张子类？  
11. 情景：分诊为跨网持续片区邻道偏侧，最小集已齐——下一步出口与挂贴？  
12. 公开包里出现真实站名与可识别通话原声，违反哪条？怎么改？

### 参考答案
1. **T-分** 分诊标签；**T-证** 证据最小集；**T-链** 保管链；**T-判** 判定出口；**T-治** 拒签治理（禁功率战、毁证、L3）。  
2. 内因外因、同网跨网、瞬时持续、语音数据、单点片区；未分诊动手易误伤、易功率战（规则1）。  
3. 对时、金机、频谱/质量、地点、双方状态等；缺对时 = 断链风险（规则3）且最小集不齐（规则2）。  
4. 采集→保管→互签→脱敏；毁证 + 断链，规则3与6。  
5. 自愈 / 联测 / 协调(S) / 主管部门 / 假绿或误报；开大是违规不是出口。  
6. 主贴 T，挂 S 做协调复测；本网指纹挂 F（规则4）。  
7. 不能；可能假绿（规则5 + 手册19）。  
8. 六十五条：受扰可投诉，管理机构应及时处理并告知；处理原则含后用让先用等。六十六条：可要求维修、校准或降功率，无法消除可责令暂停发射。（以原文为准）  
9. **先自查**，排除自身设备故障、用户误操作等内因，再申诉并提供技术资料（受理中心通知要点）。  
10. 拒绝毁证；协调可谈、物证封存；贴 **T-治**；必要依法投诉（规则6）。  
11. T-判「需联测」或「需协调」；主 T 挂 S-测 / S-协；未联测不写恶意。  
12. 规则8；撤回；L3 重写为相对道号、角色标签、相对刻度、录音改「已脱敏说明」。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **T** 五子类：分 / 证 / 链 / 判 / 治。  
- 故事：医院急诊分诊台 + 法医物证链。  
- 八条硬规则：**先分诊再动手**；**最小集未齐禁结案**；**断链禁当正式证据**；**跨网主贴 T 挂 S、本网挂 F、禁功率战**；**假绿/误报拒签**；**争议走主管部门、禁毁证**；**变更先通知后复测**；**脱敏 L3**。  
- 与 F/S/R 分工：F=指纹，S=事前协调联测，R=假绿，**T=投诉进线后的分诊与证据链**。

### 11.2 回库路径
现场「投诉进线」→ 本篇（贴纸 T + 插页 T + 分诊卡）→ 内因排完再谈外因 → 跨网挂 S → 指纹挂 F → 对时 N、金机 Q、假绿 R → 争议交无线电管理机构；全程禁功率战与毁证。

### 11.3 下一篇手册候选（本篇不写正文）
- **频率许可变更与台站执照台账**（功率 / 天线 / 台址 / 信道变更与 J 写频单、S 协调书、T 投诉案三账对齐）  
- **重大保障临时频率与联测窗**（临时设台、保障期投诉分诊与联测窗衔接）  
- （可选）**非法设台 / 黑广播类线索的内部上报边界**（只讲依法报告与证据保全，不讲排查对抗细节）

### 11.4 给带新人的三句话
1. 有人喊干扰，先分诊五组题，别先拧功率旋钮。  
2. 没有对时和保管链的截图，不能拿去定责。  
3. 私了可以谈和解，物证不能毁；谈不拢找主管部门。
