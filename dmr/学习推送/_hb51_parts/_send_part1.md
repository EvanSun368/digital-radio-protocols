| **治** | 假绿≠可以签；禁用「温湿度签」「冷凝签」「滤网签」「漏水签」「监控签」顶本期压缩机/制冷剂 | 假绿、顶替 AI/AT/AU/…、绕联锁、不安全泄放、功率战、泄密 → 治理 | AX-治 |

> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：精密空调/CRAC 压缩机与制冷剂回路公开概述强调**有账要验、压缩机灯绿≠准用、冷媒罐在≠窗做完、边界要有书面方法、检漏与充注要有资质与书面规程**（§10，**只借秩序直觉**；**本篇不写逐步充注/泄放教条**）；医院手术室/ICU 环境控制公开资料强调**环境绿≠压缩机/制冷剂边界合格、温湿度过≠压缩机台账过、冷凝排水过≠制冷剂回路过、滤网干净≠冷媒边界过**（§10，**只作故事类比**）。本篇只借这串顺序——**本网压缩机台账格式、制冷剂窗方法、边界顺序与合格门限以本网制度、合同与 OEM 书面为准**。

### 2.3 和手册36（AI）/ 47（AT）/ 48（AU）/ 42（AO）/ 46（AS）/ 33（AF）/ 50（AW）/ 31（AD）/ 41（AN）/ 28（AA）/ 15（N）/ 44（AQ）/ 49（AV）/ 45（AR）/ 34（AG）/ 43（AP）/ 39（AL）等的咬合（指针，不重写）

- **AI（手册36）**：温湿度与空调联锁**巡检边界**；**AI ≠ AX**——AI 管温湿度测点/门限/联锁巡检秩序；**AX 管精密空调压缩机台账·制冷剂本体窗·边界交底准用**；温湿度过≠压缩机/制冷剂过；「环境绿」「联锁巡检绿」≠ AX 过。  
- **AT（手册47）**：冷凝水与加湿除湿联锁；**AT ≠ AX**——冷凝/加湿过≠压缩机/制冷剂边界过；冷凝排水可挂 AT，压缩机/制冷剂主贴仍 AX。  
- **AU（手册48）**：滤网压差与气流组织；**AU ≠ AX**——滤网/压差/气流过≠制冷剂边界过；气流差可挂 AU，压缩机/制冷剂仍 AX。  
- **AO（手册42）**：漏水探测与汇流排；**AO ≠ AX**——漏水探头过≠冷媒泄漏边界交底过；冷凝水浸湿可挂 AO，制冷剂泄漏嫌疑边界主贴仍 AX（并挂 N 理风暴）。  
- **AS（手册46）**：UPS 旁路；**AS ≠ AX**——旁路过≠精密空调压缩机过。  
- **AF（手册33）**：油机市电；供电过≠压缩机/制冷剂过。  
- **AW（手册50）**：列头柜与末端配电；**AW ≠ AX**——列头末端过≠精密空调压缩机过；配电与制冷各管各的。  
- **AD（手册31）**：压力表/检漏仪入库走 AD；**不能**用旧 AD 签日期顶本期 AX 窗或实测窗。  
- **AN（手册41）**：门禁过≠压缩机/制冷剂交底过；进机房仍要 AN。  
- **AA（手册28）**：首年巡检日历；压缩机/制冷剂抽检可挂 AA，缺秩序整改主贴仍 AX。  
- **N（手册15）**：监控/对时/告警风暴；压缩机/制冷剂/边界异常风暴挂 N 理风暴，**不先抬功率**；**禁绕过保护联锁、禁不安全泄放制冷剂**；N 绿≠ AX 过。  
- **AQ（手册44）**：压缩机跳停/泄漏事件要调录像 → 另开 AQ；视频过≠AX 准用。  
- **AV / AR / AG / AP / AL**：油品/燃油/电池/内阻/气灭；均不顶替 AX。  
- **R / J / X / I**：假绿挂 R；变更（压缩机策略、制冷剂充注规程、边界门限）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 AX 证压缩机/制冷剂边界秩序，再谈覆盖病**。

### 2.4 新贴纸 AX：压 / 剂 / 界 / 验 / 治（五个子类）

> 小彩蛋：双字母贴纸续写——**AA** 首年巡检；**AB** 室分复测；**AC** 机动开撤；**AD** 备件金机；**AE** 区间联测；**AF** 油机市电；**AG** 电池充电器；**AH** 合路/POI 界面；**AI** 温湿度联锁；**AJ** 天馈驻波；**AK** 爬塔交叉；**AL** 气灭疏散；**AM** 接地浪涌；**AN** 门禁访客；**AO** 漏水汇排；**AP** 内阻核对；**AQ** 视频调阅；**AR** 油机房通风燃油；**AS** UPS 旁路；**AT** 冷凝加湿联锁；**AU** 滤网压差气流；**AV** 日用油箱油品净化加油；**AW** 列头柜与末端配电巡检；**AX** 管「机房精密空调压缩机与制冷剂边界」。A–Z 既有含义不改；新专题用 AA、AB、AC… 续写。

```text
                ┌──────────── 贴纸 AX · 压/剂/界/验/治 ────────────┐
                │  AX-压  压缩：压缩机台账钉死（本体·吸排气·保护联锁） │
                │  AX-剂  制冷剂：有主有窗有方法准用期（类型·充注/检漏） │

```

|------|----------|--------|
| **AX-压** | 无压缩机台账、灯绿无本期保护核对仍准用 → 拒签 | 「压缩机灯绿就能签」「口头说一声」 |

| **AX-验** | 套他站他期曲线/照片/压力读数、无会签 → 拒签 | 「邻站压力曲线拷过来改机房号」 |
| **AX-治** | 假绿、用 AI/AT/AU/AO/AF/AS/AD/AN/AA/N/AQ/AV/AR/AG/AP/AL/AW 顶替、绕联锁、不安全泄放、功率战 → 治理 | 「AI/AT/AU 签还在，压缩机也能过」 |

### 2.5 建压缩机台账 → 钉制冷剂窗 → 边界方法钉死 → 本期实测 → 会签放行 → 变更再验 阶段梯（背下来）

```text
  ① AX-压 建压缩机台账：机房/精密空调角色 · 压缩机本体/吸排气侧/保护联锁角色 · 禁「压缩机灯绿就能签」「口头说一声」
        │  无账 / 灯绿无实测 → 不签精密空调压缩机与制冷剂边界准用
        ▼
  ② AX-剂 钉制冷剂窗：制冷剂主人角色 · 书面窗 · 方法 · 准用期 · 禁「冷媒罐在当窗过」「未授权泄放」
        │  无主人 / 无窗 / 无方法 / 无准用期 → 拒进入「可签」状态
        ▼
  ③ AX-界 钉边界方法：书面窗 · 方法（压/剂交界核对；与 AI/AT/AU/AO 分工；以本网与 OEM 书面为准） · 到场角色 · AD 仪表准用指针
        │  无窗 / 「口头检过漏」/ 「绕过保护联锁」 → 拒边界签
        ▼
  ④ AX-验 本组本机房本期实测：实测记录 · 禁套他站他期曲线/照片/压力读数 · 会签
        │  套票 / 只看监控绿 → 拒签
        ▼
  ⑤ 会签放行「精密空调压缩机与制冷剂边界准用」· 假绿≠放行 · 主贴 AX
        ▼
  ⑥ 压缩机策略/制冷剂充注规程/边界门限变更 → 走 J → 再验 AX
```

### 2.7 一晚怎么走完（教学节奏，不替代本网书面规程）

1. 翻压缩机台账（AX-压）：本体/吸排气/保护联锁角色在不在；灯绿≠准用勾选。  
2. 翻制冷剂窗（AX-剂）：主人、窗、方法、准用期；罐在≠窗过；禁不安全泄放勾选。  
3. 翻边界方法（AX-界）：书面方法；与 AI/AT/AU/AO 分工勾清；禁口头检过漏、禁绕保护联锁。  
4. 做/核对本期实测（AX-验）：本组本机房本期；禁套他站他期。  
5. 会签或拒签；风暴挂 N；变更走 J；假绿挂 R；全程 L3。
