## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 本篇用法（教学） |
|------|------------------|
| **AX** | 本篇贴纸：压缩机·制冷剂·边界交底 |
| **AX-压** | 压缩机台账子类 |
| **AX-剂** | 制冷剂窗方法子类 |
| **AX-界** | 边界窗方法子类 |
| **AX-验** | 本期实测与会签子类 |
| **AX-治** | 假绿/顶替/绕联锁/泄放/功率战/泄密治理 |
| **压缩机台账** | 本体·吸排气·保护联锁入账（脱敏） |
| **制冷剂窗** | 有主有窗有方法有准用期；禁不安全泄放 |
| **边界窗** | 压/剂交界与 AI/AT/AU/AO 分工书面方法 |
| **CRAC** | 计算机机房精密空调（故事类比用语） |
| **冷媒类型角色** | 以本网与 OEM 书面为准的类型指针（脱敏） |
| **保护联锁** | 高压/低压/油压等保护（不教绕过） |
| **假绿** | 灯绿/监控绿冒充准用 → 挂 R |
| **套票** | 套他站他期曲线/照片/压力读数 |
| **L3** | 脱敏等级：禁真实站名/全称/序列号/联系人等 |
| **N** | 告警风暴贴纸；N 绿≠AX 过 |
| **J** | 变更贴纸；策略/规程/门限变更走 J |
| **R** | 假绿贴纸 |

**易错观念**

1. 「压缩机灯绿 = 可以签准用」——错；要有台账与本期边界实测。  
2. 「冷媒罐在 = 窗做完」——错；要有主人、窗、方法、准用期。  
3. 「口头说检过漏 = 方法过」——错；要有书面边界方法。  
4. 「AI/AT/AU/AO/N 过 = AX 过」——错；各钉各的，禁顶替。  
5. 「告警多就抬功率 / 旁路保护 / 放空制冷剂」——错且危险；禁功率战、禁绕联锁、禁不安全泄放。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AX** 五子类：压 / 剂 / 界 / 验 / 治——双字母续写的第二十四张，负责精密空调压缩机与制冷剂「台账清不清、制冷剂有没有窗、边界有没有法、本期过了没有」。  
- 口诀：**压缩机有账，制冷剂有窗，边界有法，会签才放。**  
- 故事：医院手术室/ICU 精密空调 CRAC 压缩机与制冷剂回路——压缩机灯绿≠准用；冷媒罐在≠窗过；口头说检过漏≠方法过。  
- 八条硬规则：**压缩机台账钉死**；**制冷剂有主有窗有方法/准用期**；**边界窗与方法钉死**；**本组本机房本期实测禁套他站他期**；**会签才放行「精密空调压缩机与制冷剂边界准用」**；**禁顶替 AI/AT/AU/AO/AF/AS/AD/AN/AA/N/AQ/AV/AR/AG/AP/AL/AW 等，主贴 AX，假绿≠放行挂 R**；**压缩机/制冷剂/边界异常风暴挂 N、压缩机策略/制冷剂充注规程/边界门限变更走 J、禁功率战、禁绕安全联锁、禁不安全泄放制冷剂**；**脱敏 L3**。
