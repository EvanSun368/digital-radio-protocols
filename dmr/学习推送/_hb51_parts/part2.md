# 手册 51 · 运维制度：机房精密空调压缩机与制冷剂边界交底台账

> **（续 · 手册51 · 贴纸 AX · 档案 part2 · §4–7）**


## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **压缩机台账钉死**：机房角色、压缩机本体 / 吸排气侧 / 保护联锁角色入账；禁「压缩机灯绿就能签」「口头说一声」。  
2. **制冷剂有主有窗有方法/准用期**：每次制冷剂相关维护有主人角色、有书面窗、有方法、有准用期；禁「冷媒罐在当窗过」；**禁未授权泄放/排放制冷剂**。  
3. **边界窗与方法钉死**：书面固定；方法含压缩机侧与制冷剂侧交界核对、与 AI/AT/AU/AO 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明逐步充注/检漏/泄放操作教条）；禁「窗再说」「口头检过漏」「绕过高压/低压/油压等保护联锁」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、照片、压力读数必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「精密空调压缩机与制冷剂边界准用」；假绿 ≠ 放行。  
6. **禁顶替 AI/AT/AU/AO/AF/AS/AD/AN/AA/N/AQ/AV/AR/AG/AP/AL/AW，主贴 AX，假绿≠放行挂 R**：温湿度签、冷凝加湿签、滤网压差签、漏水签、旁路签、油机签、仪表签、门禁签、首年签、监控签、视频签、油品签、通风燃油签、电池签、内阻签、气灭签、列头末端签都不顶本期压缩机/制冷剂签。  
7. **压缩机/制冷剂/边界异常风暴挂 N，压缩机策略/制冷剂充注规程/边界门限变更走 J，禁功率战；禁绕过安全联锁；禁不安全泄放制冷剂**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/精密空调序列号全文/可还原坐标与联系人；禁公开传播未脱敏冷媒充注量与边界门限参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签压缩机/制冷剂准用、无实测冒充边界过、绕联锁冒充秩序齐、未授权泄放制冷剂，不是法外运维智慧**。医院精密空调/CRAC 公开资料、厂商压缩机/制冷剂公开科普、EPA Section 608 等公开页只作故事与方法类比（§2.2）：**压要约、剂要窗、界要法、验要本期、灯绿不算过、泄放不算办法**——翻译成本网语言就是 AX-压 / AX-剂 / AX-界 / AX-验 / AX-治。**这些是精密空调压缩机与制冷剂边界交底秩序，不是「灯绿就签」「罐在当过」「抬功率压告警」「绕联锁」「放空制冷剂」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「精密空调压缩机与制冷剂边界准用」、对外宣传「压缩机一通制冷剂秒过」、把未实测写成已过、把绕联锁/泄放写成秩序齐。允许做的：补压缩机台账、补制冷剂窗、重开边界窗、挂 R/N/J、内部挂整改。

### 4.3 「精密空调压缩机与制冷剂边界准用」最小集（AX）——缺页不能签准用

1. 压缩机台账页（本体·吸排气·保护联锁）  
2. 制冷剂主人与书面窗、方法、准用期页（含禁不安全泄放勾选）

6. AT 冷凝加湿边界勾选（防顶替；AT 过≠AX 过）  
7. AU 滤网压差气流边界勾选（防顶替；AU 过≠AX 过）  
8. AO 漏水边界勾选（防顶替；漏水过≠冷媒边界交底过）  
9. N 风暴边界勾选（防顶替；N 绿≠AX 过）  
10. AN 门禁边界勾选（若进人：先 AN；门禁过≠压缩机/制冷剂交底过）  
11. AW 列头末端边界勾选（若同站：AW 过≠AX 过）

13. 会签页（准用或有条件整改）  
14. 未闭项清单（有则挂整改，重大未闭禁签准用）  
15. 脱敏勾选（L3）  
16. 变更指针（若本期有压缩机策略/制冷剂充注规程/边界门限变更 → J）

### 5.5 与弱项的现场对照（再钉一次）

压缩机跳停、制冷剂无窗、假绿准用，往往先伤**站点环境与设备生存**，再伤空口：上行 12.5 kHz / 4FSK / 2-slot 本来就脆，有人把高压低压告警当覆盖病去抬功率——**禁功率战**。先 AX 证压缩机/制冷剂边界秩序，再谈 X/I 覆盖干扰。

## 6. 工作实例（12 则，教学虚构，L3）

1. **压缩机灯绿就要签准用** → 拒签；补 AX-压台账与本期实测。  
2. **冷媒罐在当窗过** → 拒签；补 AX-剂主人/窗/方法。  
3. **口头说检过漏** → 拒签；补 AX-界书面方法。  
4. **套邻站压力曲线/照片改机房号** → AX-验 拒签重测。  
5. **AI 温湿度签顶本期压缩机/制冷剂签** → 拒签顶替；AI≠AX；可挂 R。  
6. **AT 冷凝加湿签顶压缩机/制冷剂边界** → 拒签；AT≠AX。  
7. **AU 滤网压差签顶制冷剂边界** → 拒签；AU≠AX。  
8. **AO 漏水签顶冷媒泄漏边界交底** → 拒签；漏水过≠冷媒边界交底过。  
9. **N 监控绿免本期实测 / 高压告警抬功率** → 拒签实测免做；挂 N；**禁功率战**；缺秩序整改 AX。  
10. **绕过高压/低压保护联锁消告警** → **禁**；挂 N/R；禁签准用。  
11. **未授权把制冷剂放到空气里再充** → **禁不安全泄放**；挂整改；本篇不教逐步泄放；AX-治。
