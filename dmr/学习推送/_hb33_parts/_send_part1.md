## 1. 为什么要写这篇手册（动机 + 现场对话）

前三十二篇手册从 A–E 协议一路写到 AE 区间联测：其中 **K 回答「市电/后备/倒换/告警/交维」物理层与交维剧本**，**N 回答「电源监控/对时/告警风暴」**，**AA 回答「交维后首年巡检」**，**AC 回答「机动开撤（常勾选电源）」**，**AD 回答「备件与金机账期」**，**AE 回答「区间联测与换乘界面」**。可还没有单独钉死一件事——**机房不是「网管全绿就等于备电过关」：市电↔油机切换要有书面窗与方案；油机燃油/机油/冷却/电瓶要有主人有账；机房供电巡检路线与周期要钉死；本机房本期切换/试车要实测，禁套邻站报告——能不能签「供电巡检/切换合格」？** 这就是本篇的 **AF**——**油机/市电切换与机房供电巡检**。

- 夜班：「ATS 绿灯亮着，随便按一下试倒换。」——**无书面切换窗/方案仍操作** = 本篇拒签（规则1）。  
- 站务：「市电掉了才发现油机日用箱没油。」——**油机无主人无账** = 规则2。  
- 巡检岗：「机房供电巡检？上个月路过看过一眼。」——**巡检周期/对象未钉死** = 规则3。  
- 外包：「邻站上周试车报告参数差不多，拷过来。」——**套他站他期** = 规则4。  
- 班长：「网管全绿，签供电合格吧。」——**假绿≠切换/试车通过** = 规则5/6。  
- 电源岗：「手册12 交维时做过倒换，K 签过就行，不用再贴 AF。」——**用 K 顶替 AF** = 规则6。  
- 网优：「倒换窗基站抖了一下，功率抬一点稳住。」——**功率战** = 规则7。  
- 宣传岗：「把真实机房编号、油机序列号、试车曲线发群表扬。」——**L3 违规** = 规则8。  

这几句背后是同一件事：

> **「油机/市电切换与机房供电巡检」在现场至少有五个坑**：**① AF-切** 市电↔油机（或双路市电）切换窗、书面切倒方案、到场角色钉死，禁「随便按一下」；**② AF-油** 油机本体（燃油/机油/冷却/电瓶/试车记录）与月度/周期试车台账有主人；**③ AF-巡** 机房供电巡检路线、对象清单、周期钉死；**④ AF-验** 本机房本期切换/试车实测（电压/负载/回切/告警联动），禁套他站他期报告；**⑤ AF-治** 治理（假绿、用 K/N/AA 顶替、伪造试车账、功率战、泄密）。  
> 把 ①–⑤ 当成「网管绿就算备电过」「交维做过一次就永远过」「口头说一声油机有油」，每一次市电闪断、每一次月度试车、每一次机房交班，都会先吵「到底谁该来切、报告是不是这机房的」。

本篇目标：能背出**切换/试车 + 机房供电巡检工作流**；会用新贴纸 **AF（切 / 油 / 巡 / 验 / 治）**；会填**插页 AF（AF1–AF8）**和《本网油机市电切换与机房供电巡检台账卡》；能用「**医院备用发电机月度试车 + 配电室双电源切换演练**」故事讲清试车窗钉死≠随便踩油门、市电掉了才发现没油=拒签、网管全绿但半年没实车=假绿、套邻站试车报告=拒签；能拒绝随便按 ATS、套邻站报告、用 K/N 顶替切换验签、假绿放行；自测过关后，回库把本网最近一次油机试车或市电切换演练（L3）重对一遍：切换窗、油机账、巡检周期、本期实测、签合格项、拒签项。

**本篇硬禁令（写进脑子）**：凡引法规与标准只指向已公开发布的文书标题与官方链接（无线电管理条例、频率使用许可管理办法、地面无线电台（站）管理规定、国无办〔2025〕1号；**只作故事类比**的医院应急电源/备用发电机月度试车与双电源切换公开资料标题，以及公开的 ATS/柴油发电机/电信 −48 V 机房电源概述资料），**程序、期限、责任以原文与属地最新要求及本网制度 / 合同为准，本篇只作教学转述，不发明条款号与内部口径**；医院应急电源试车、境外 NFPA 备用电源公开资料与 ATS 厂商科普**不是**中国专网台站「贴纸 AF」的法定依据；**现象与台账一律用相对道号、角色标签、脱敏机房编号，禁真实频点 / 站名 / 机房全称 / 油机序列号全文 / 单位名 / 联系人**；**不教伪造试车台账、不教功率战、不教规避监测、不教套他站报告、不教假绿顶替、不教绕过告警**；K / N / AA / AC / AD / AE / R / T / J 各管各的——**油机/市电切换与机房供电巡检主贴 AF**；物理倒换交维回 K，监控对时风暴回 N，首年巡检回 AA——**AF 管「切换窗·油机试车·机房供电巡检秩序」，不替代 K 的物理交维剧本本身，也不替代 N 的监控对时治理**。

## 2. 总图 / 故事：切换与巡检像「医院备用发电机月度试车 + 配电室双电源切换演练」

### 2.1 一句话：备电不是「网管绿就过」、试车不是「随便踩一下油门」——要先钉切换/试车窗与书面方案，油机有主人有账，机房供电巡检周期钉死，本机房本期实测，切换/试车通过才签供电合格；假绿、套邻站报告、用 K/N 顶替，一律拒签

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  医院备用发电机月度试车 + 双电源切换演练  =  本网 AF 切换与巡检 │
   │                                                              │
   │  试车窗预约·书面方案·到场角色     ≈ AF-切  切换窗与方案钉死   │
   │  燃油机油冷却电瓶·月度试车有账   ≈ AF-油  油机本体与试车台账 │
   │  配电室巡检路线·对象清单·周期   ≈ AF-巡  机房供电巡检钉死   │
   │  本期实测电压负载回切告警联动   ≈ AF-验  本机房本期实测禁套 │
   │  假绿≠放行·顶替·伪造账·功率战   ≈ AF-治  治理与脱敏 L3       │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **窗钉死，油机有账，巡检有期，本期实测，切换才签。**  
> 市电掉了才发现没油 = 医院停电才发现日用箱空——**拒签「供电合格/可交班」**。  
> 网管全绿但半年没实车 = 配电柜绿灯亮着却从未带载试车——**假绿，挂 R，拒签**。

### 2.2 「医院备用发电机试车 / 双电源切换演练」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **切换** | 医院月度试车要预约窗、书面方案、相关科室到场，禁「夜班随便踩油门」 | 市电↔油机（或双路市电）切换窗与书面切倒方案钉死，到场角色勾选 | AF-切 |
| **油机** | 燃油、机油、冷却液、电瓶、滤芯有主人有账；月度/周期带载试车留痕 | 油机本体清单与试车台账有主人；禁「口头说有油」 | AF-油 |
| **巡检** | 配电室巡检有路线、有对象清单、有周期（周/月角色） | 机房供电巡检路线与对象钉死：市电进线、ATS、整流/UPS、直流屏、油机侧 | AF-巡 |
| **验收** | 本期带载试车：电压、负载、回切、告警联动要实测；禁抄邻院报告 | 本机房本期切换/试车实测；方法与 K 指针对齐；禁套他站他期 | AF-验 |
| **治理** | 假绿≠备电过；禁涂改试车账；禁用「交维做过」顶本期试车 | 假绿、顶替 K/N/AA、伪造账、功率战、泄密 → 治理 | AF-治 |

> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：备用发电机与 ATS（自动转换开关）公开科普强调**监测市电→启动油机→稳压后切载→市电恢复后回切→冷却停机**的顺序（§10，**只借秩序直觉**）；电信机房 −48 V 直流供电公开概述强调**市电/油机经 ATS 进整流，电池浮充扛切换间隙**（§10）；医院应急电源月度试车公开资料强调**要有窗、要带载、要留记录，不能只看绿灯**（§10，**故事类比，不是无线电法定依据**）。本篇只借这串顺序——**本网切换窗、试车门限、合格标准以本网制度与合同为准**。

### 2.3 和手册12（K）/ 15（N）/ 28（AA）/ 30（AC）/ 31（AD）/ 32（AE）等的咬合（指针，不重写）

- **K（手册12）**：市电/后备/倒换/告警/**交维**物理剧本；AF 不重写怎么做一次交维倒换，只钉「这一窗、这一机房、本期切换/试车有没有做完、谁签供电合格」。  
- **N（手册15）**：电源监控/**对时**/告警风暴；倒换窗铃响先挂 N 理风暴，**不先抬功率**；N 绿≠ AF 试车过。  
- **AA（手册28）**：交维后**首年巡检**日历；抽检供电可挂 AA，缺切换/试车秩序整改主贴仍 AF。  
- **AC（手册30）**：机动开撤常勾选电源；车载/机动站电源勾选≠固定机房 AF 台账。  
- **AD（手册31）**：备件/金机；试车用仪表/备件须 AD 准用期内，AD 不替代切换签。  
- **AE（手册32）**：区间联测；与机房供电并行时各贴各的——区间过≠机房供电过。  
- **R / T / J**：假绿挂 R；投诉挂 T；变更（换油机控制器、改 ATS 定值、改配电拓扑）走 J。

### 2.4 新贴纸 AF：切 / 油 / 巡 / 验 / 治（五个子类）

> 小彩蛋：双字母贴纸续写——**AA** 首年巡检；**AB** 室分复测；**AC** 机动开撤；**AD** 备件金机；**AE** 区间联测；**AF** 管「油机/市电切换与机房供电巡检」。A–Z 既有含义不改；新专题用 AA、AB、AC、AD、AE、AF… 续写。

```text
                ┌──────────── 贴纸 AF · 切/油/巡/验/治 ────────────┐
                │  AF-切  切换：窗钉死·书面方案·到场角色               │
                │  AF-油  油机：燃油机油冷却电瓶·试车台账有主人       │
                │  AF-巡  巡检：机房供电路线·对象清单·周期钉死       │
                │  AF-验  验收：本机房本期电压负载回切告警·禁套     │
                │  AF-治  治理：假绿·顶替K/N·伪造账·功率战·泄密     │
                └──────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签触发 |
|------|--------|--------------|
| **AF-切** | 无书面窗/方案、该到场未到场仍要切 → 拒签 | 「夜班随便按一下 ATS」 |
| **AF-油** | 燃油/冷却/电瓶无主人无账、试车台账断档 → 拒签 | 「市电掉了才发现没油」 |
| **AF-巡** | 巡检路线/对象/周期未钉死仍签合格 → 拒签 | 「路过看一眼就算巡检」 |
| **AF-验** | 套他站他期、只看绿灯不测回切/告警 → 拒签 | 「邻站试车报告拷过来」 |
| **AF-治** | 假绿、用 K/N/AA 顶替、功率战、泄密 → 治理 | 「网管绿了供电也算过」 |

### 2.5 钉窗 → 清油机账 → 巡检到位 → 本期实测 → 会签合格 → 变更再验 阶段梯（背下来）

```text
  ① AF-切 钉窗：切换/试车窗角色 · 书面切倒方案 · 到场角色清单
        │  无窗 / 无方案 → 不切换、不签合格
        ▼
  ② AF-油 清油机账：燃油/机油/冷却/电瓶主人 · 上次试车日 · 滤芯期
        │  无主人 / 账断档 / 明显缺油 → 拒进入「可签」状态
        ▼
  ③ AF-巡 巡检到位：市电进线·ATS·整流/UPS·直流屏·油机侧·接地/环境角色项
        │  路线未跑完 / 对象漏项 → 有条件整改或拒签
        ▼
  ④ AF-验 本机房本期实测：电压 · 负载（角色门限）· 回切 · 告警联动 · 禁套他站他期
        │  只看绿灯 / 套报告 → 拒签
        ▼
  ⑤ 会签「供电巡检/切换合格」或「有条件整改」：授权本人签
        │  缺签 / 假绿顶替 → 拒签合格
        ▼
  ⑥ 变更（换控制器/改 ATS 定值/改配电/换电池组）→ 走 J + 触发再验（常挂 N 看监控）
```

> **一句话分辨**：**K** 回答「交维时倒换**剧本怎么跑**」；**N** 回答「监控**对时与风暴怎么治**」；**AA** 回答「首年巡检**日历抽谁**」；**AF** 回答「这一窗切换 + 这台油机 + 这条供电巡检**窗清不清、账清不清、本期过了没有**」。**四个问题，四张（类）贴纸，不能一笔带过。**

### 2.6 切换/试车与供电巡检最小工作流（背下来）

```text
  AF-切 约窗 + 书面方案 + 到场勾选
       ├─→ 有书面窗+方案？油机账齐？ ──否──→ 拒签 / 补窗补账
       └─→ 是
  AF-巡 按路线巡检对象打勾（可与试车同窗）
       │
  AF-验 本机房本期：切出 → 稳载观察 → 回切 → 告警联动核对（挂 N 指针）
       │  套报告 / 只看绿灯 → 拒签
       ▼
  会签「供电合格/可交班」或挂整改；重大未闭禁签合格
       │
  放行或拒签；公开材料 L3；变更走 J 再触发
```

## 3. 核心交付：插页 AF + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AF（而不是先贴 K / N / AA）

| 现场要办的事 | 主贴 | 说明 |
|--------------|------|------|
| 切换窗、油机试车、供电巡检合格签、假绿拒签 | **AF** | 本篇主职 |
| 开站/交维第一次市电↔后备剧本 | **K**（可挂 AF） | 交维物理剧本；交维后周期试车主贴 AF |
| 告警风暴、时钟漂移、假采集 | **N** | 监控治理；不顶替试车签 |
| 交维后首年日历抽检供电 | **AA**（看 AF） | 日历抽检≠本期切换验 |
| 大屏全绿想直接签供电合格 | **AF-治 + R** | 假绿≠切换/试车通过 |
| 套邻站旧试车报告 | **AF-治** | 禁套；须本期本机房实测 |

### 3.2 插页 AF · 切 / 油 / 巡 / 验 / 治（挂在总三联单或切换/试车单后）

| 插页行 | 检查项（教学） | 缺了怎么办 |
|--------|----------------|------------|
| **AF1** | 切换/试车窗书面在（日期角色/天窗角色）；相关角色到场清单勾选 | 缺 → **拒切换/拒签** |
| **AF2** | 书面切倒方案在：切出顺序、稳载观察、回切顺序、异常中止条件（挂 K 指针） | 缺 → **拒切换** |
| **AF3** | 油机主人角色书面；燃油/机油/冷却/电瓶状态有账；上次试车日可追溯 | 缺 → **拒签合格** |
| **AF4** | 机房供电巡检路线与对象清单：市电进线、ATS、整流/UPS、直流屏、油机侧、环境角色项 | 缺 → **拒签** |
| **AF5** | 本机房本期实测记录在；脱敏机房编号与窗一致；禁套他站他期 | 套/缺 → **拒签** |
| **AF6** | 回切成功 + 告警联动核对（与 N 指针：风暴是否可解释）有记录 | 该核未核 → **有条件整改或拒签** |
| **AF7** | 「供电巡检/切换合格」会签：授权本人签；重大未闭禁合格 | 缺签 → **拒签** |
| **AF8** | 公开材料 L3；变更项走 J；禁功率战叙事 | 违 → **治理** |

> 插页每一行都对应硬规则：AF1/AF2→规则1，AF3→规则2，AF4→规则3，AF5/AF6→规则4，AF7→规则5，顶替/假绿→规则6，AF8→规则7/8。**任何一行缺项，就停在那一行。**

### 3.3 和总三联单怎么写（接手册06）

- **现象栏**：写「切换窗角色 / 试车未实车 / 巡检漏项 / 回切未核」等可复核现象，**不写空口玄学**。  
- **贴纸栏**：主贴 **AF**；支撑可贴 K / N / AA / AC / AD / R / T / J。  
- **处置栏**：拒签 / 补窗 / 补油机账 / 重测 / 挂 R/N/J——**写动作，不写空口字段**。  
- **脱敏**：机房用角色编号；禁序列号全文、禁真实站名。

### 3.4 《本网油机市电切换与机房供电巡检台账卡》预告

§7 给出可复印模板：封面拒签门槛、切换窗页、油机账页、巡检路线页、实测页、会签合格页、夜班速填五行。**一张卡跑完一窗切换/一次月度试车：窗→油→巡→验→签**；与 K 交维剧本、N 监控、AA 巡检日历指针对齐，避免「交维做过一次就永远当供电合格」。
