## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **切换/试车窗与书面方案钉死：无书面切换窗（或试车窗）与切倒方案不得切换、不得签「供电合格」；该到场未到场视为未完成**。  
2. **油机与燃油/冷却/电瓶等有主人有账：油机本体清单与月度/周期试车台账须有书面主人；账断档、明显缺油不得进入可签状态**。  
3. **机房供电巡检周期与对象钉死：巡检路线、对象清单、周期（周/月角色）书面固定；路过看一眼不算巡检**。  
4. **本机房本期切换/试车实测：须本脱敏机房、本窗、含电压/负载/回切/告警联动（角色项）；禁套他站/他期报告**。  
5. **切换/试车通过才签：授权本人会签后，方可签「供电巡检/切换合格/可交班」；重大未闭项禁合格**。  
6. **禁顶替：可挂 K/N/AA/AC/AD/R 支撑，但油机/市电切换与机房供电巡检主贴 AF；K 交维签、N 监控绿、AA 抽检签均不得顶替 AF 本期切换/试车签；主贴 AF；监测大屏/系统绿灯、假绿不等于放行（挂 R）**。  
7. **倒换窗射频抖动禁功率战；监控风暴挂 N；换油机控制器/改 ATS 定值/改配电拓扑等变更走 J 并评估再验**。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/油机序列号全文/可还原试车曲线含定位信息/联系人**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无窗乱切、无试车冒充备电过关，不是法外运维智慧**。医院应急电源试车与 ATS/电信 −48 V 公开资料只作故事与方法类比（§2.2）：**窗要约、油要账、巡要期、验要测、绿灯不算过**——翻译成本网语言就是 AF-切 / AF-油 / AF-巡 / AF-验 / AF-治。**这些是供电巡检与切换秩序，不是「随便按 ATS」「拷邻站报告」「抬功率压倒换抖」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「供电合格/可交班」、对外宣传「分钟级一键倒换秒过」、把未试车写成已过。允许做的：补窗、补油机账、重巡、重测、挂 R/N/J、内部挂整改。

### 4.2 分诊题：这件事贴 AF 还是贴别的？

| 现场问题 | 先问 | 主贴 |
|----------|------|------|
| 交维第一次倒换剧本怎么跑 | 交维物理 | **K** |
| 网管铃狂响、时钟不对 | 监控/对时 | **N** |
| 首年巡检该不该抽这机房供电 | 日历 | **AA**（看 AF） |
| 本月油机试车窗约了没 | 窗与方案 | **AF-切** |
| 日用箱油位谁负责 | 主人台账 | **AF-油** |
| 邻站试车报告能不能用 | 是否本机房本期 | **AF-验/治** |
| 大屏全绿想签供电合格 | 有无会签实测 | **AF-治 + R** |
| 倒换窗基站抖、想抬功率 | 先供电还是射频 | **AF-治 + N**（禁功率战） |
| ATS 定值改了要不要再验 | 变更 | **J + AF** |

### 4.3 「供电合格」最小集（AF）——缺页不能签「供电巡检/切换合格」

| 序号 | 最小集项（教学） | 为什么必须有 | 缺了会怎样 |
|------|------------------|--------------|------------|
| 1 | **书面切换/试车窗**与到场角色勾选 | 无窗则操作无可追溯 | 拒切换/拒签 |
| 2 | **书面切倒方案**（挂 K 指针） | 防「随便按一下」 | 拒切换 |
| 3 | **油机主人**与燃油/冷却/电瓶账 | 防掉电才发现没油 | 拒签 |
| 4 | **巡检路线与对象**清单 | 防路过冒充巡检 | 拒签 |
| 5 | **本机房本期**实测记录 | 防套报告 | 拒签 |
| 6 | **回切 + 告警联动**核对 | 切出去还要回得来 | 该核未核→整改或拒 |
| 7 | **授权本人会签** | 可复核 | 「系统绿」不够 |
| 8 | **重大未闭清单**（若有）有主有期 | 带病合格禁 | 重大未闭→拒合格 |
| 9 | **公开材料 L3** | 防定位泄露 | 违→治理 |

> **口诀**：窗、案、油、巡、房、回、签、闭、密——**九字供电钉**（教学记忆；现场以本网书面规程为准，但 **书面窗 + 油机账 + 本机房本期实测 + 会签** 几乎不可砍）。  
> **弱项短补（为什么倒换窗要先问供电）**：切换瞬间电压/相位冲击，基站可能重启、监测短暂假绿、上行登记失败——**12.5 kHz / 4FSK / 2-slot TDMA 的空口台阶没变**，变的是「这台 ICU 监护仪」有没有干净电。只开射频工单抬功率，等于医院发电机试车抖电时去拧监护仪灵敏度旋钮。**先 AF（及 K/N 指针），再谈射频。**

### 4.4 切换窗清单（AF-切）——缺页不能切

| 清单项（教学） | 像医院试车预约 | 未齐就切换？ |
|----------------|----------------|--------------|
| 书面窗（日期/时段角色） | 预约手术室停电演练窗 | 否 |
| 书面切倒方案（切出/稳载/回切/中止） | 书面演练脚本 | 否 |
| 到场角色勾选（电源/网管/站务角色） | 相关科室到场 | 关键未到=未完成 |
| 业务影响告知角色（若本网要求） | 病区知情 | 按本网制度 |
| 中止与回退条件书面 | 异常即停 | 否→拒切 |

### 4.5 油机与巡检清单（AF-油 / AF-巡）

| 清单项（教学） | 像什么 | 未齐？ |
|----------------|--------|--------|
| 油机主人角色 | 设备科主人 | 无主→拒签 |
| 燃油/日用箱油位记录 | 日用箱巡查 | 断档→拒签 |
| 机油/冷却液/电瓶状态 | 周检项 | 漏→整改或拒 |
| 上次试车日与结果 | 月度试车账 | 超期未试→拒签合格 |
| 巡检路线图角色 | 配电室路线 | 无路线→拒签 |
| 对象：市电进线·ATS·整流/UPS·直流屏·油机侧 | 对象清单 | 漏项→整改或拒 |

### 4.6 与 K / N / AA / AC / AD 的分工表（钉死，防互相顶替）

| 贴纸 | 主职一句话 | 能不能顶替 AF？ |
|------|------------|-----------------|
| **K** | 交维物理倒换剧本 | **不能**；交维签≠本期月度试车签 |
| **N** | 监控对时与告警风暴 | **不能**；风暴理清≠试车过 |
| **AA** | 首年巡检日历 | **不能**；抽检≠本期切换验 |
| **AC** | 机动开撤（可勾电源） | **不能**；车载勾选≠固定机房 AF |
| **AD** | 备件金机准用 | **不能**；仪表准用≠供电合格 |
| **AF** | 切换窗·油机试车·供电巡检秩序与合格签 | 本篇主贴 |
| **R** | 假绿提醒 | 支撑 |
| **J** | 变更 | 改 ATS/油机/配电后触发再验 |

### 4.9 「假绿 / 套报告 / 随便按」对照表（钉死）

| 现场说法 | 像医院故事 | 处置 |
|----------|------------|------|
| 网管全绿签合格 | 配电柜绿灯当试车过 | 拒签；挂 R；主贴 AF |
| 邻站报告拷过来 | 抄邻院试车账 | 拒签；AF-治 |
| 夜班随便按 ATS | 随便踩油门 | 拒切；补窗补方案 |
| 交维 K 签过不用再试 | 开业验收顶掉月度试车 | 规则6；主贴 AF |
| 倒换抖就抬功率 | 拧监护仪灵敏度 | 禁功率战；挂 N/AF |

### 4.10 双路市电 / UPS / 整流 −48 V 与 AF 的咬合

- **双路市电切换**：仍走 AF-切窗与方案；对象清单含两路进线与切换装置角色。  
- **UPS**：巡检对象可含；UPS 维护细节以本网规程为准，AF 钉「有没有按路线检、本期有没有验」。  
- **整流 / −48 V 直流屏**：电信机房常见；切换间隙常靠电池浮充——**电池状态进 AF-巡/油侧相关项或另册，但不得用「电池还在」顶替油机试车**。  
- **K 指针**：交维时已跑过的物理剧本可复用为 AF 方案附件，**不能**用旧交维签日期顶本期窗。

### 4.11 与首年巡检（AA）/ 机动站（AC）怎么配合

- AA 抽到供电项：看 AF 台账是否断档；缺则主贴 AF 整改，AA 记抽检结果。  
- AC 机动站电源勾选：回固定机房后仍要接上 AF 巡检/试车指针，**车载一夜≠机房月度试车**。

### 4.12 倒换窗话务抖与投诉（T）怎么并存

- 先 AF/N：供电与监控解释得清不清。  
- 解释不清再挂 T/射频分诊；**禁止**一抖就功率战。  
- 上行更脆：倒换后先抽测上行登记/话音，再下「覆盖病」结论。

## 5. 现场映射：原话速查、对话脚本、夜班、禁写词、交班口述

### 5.1 原话 → 贴纸速查

| 原话 | 贴纸 | 追问 |
|------|------|------|
| 「ATS 亮着，按一下试试」 | AF-切 | 书面窗？方案？到场？ |
| 「市电掉了油机没起来——没油」 | AF-油 | 主人？油位账？上次试车？ |
| 「供电巡检上个月路过看过」 | AF-巡 | 路线对象周期？勾选单？ |
| 「邻站试车报告拷过来」 | AF-治 | 本机房本期窗号？禁套 |
| 「K 交维签过，不用再贴 AF」 | AF-治 | 规则6：禁顶替；主贴 AF |
| 「网管全绿，签供电合格」 | AF-治 + R | 会签？假绿≠通过 |
| 「倒换抖一下，功率抬一点」 | AF-治 + N | 禁功率战；先供电 |
| 「油机序列号试车曲线发群」 | AF-治 | 脱敏 L3；撤回 |

### 5.2 三段对话脚本（可练）

**脚本 A · 拒签（随便按 ATS）**  
对方：「夜班没事，ATS 按一下练手。」  
你：「AF-切：无书面窗与方案不得切换。不是不练，是拒无窗乱切——约窗、方案、到场齐了，我才能走实测闸。」

**脚本 B · 拒签（假绿）**  
对方：「大屏全绿，签供电合格吧。」  
你：「AF-治 + R：假绿≠本期切换/试车通过。AF5/AF6 实测与回切告警核在哪里？没有就不能签合格。」

**脚本 C · 拒签（套邻站报告）**  
对方：「邻站上周测过，改个机房号交差。」  
你：「AF-验/治：禁套他站他期。要过闸，就本窗本机房实测——改号不是试车。」

### 5.3 夜班压缩卡（四问）

1. **窗？** 今晚有没有书面切换/试车窗？  
2. **油？** 油位/电瓶账是否断档？  
3. **验？** 是本期本机房，还是拷贝？  
4. **签？** 会签人是授权本人吗？假绿有没有挂 R？

### 5.4 禁写词（三联单/交班）

- ❌「估计有油」「应该能切」「网管绿就是过了」「跟邻站一样」「功率抬稳就行」  
- ✅「书面窗角色××」「油位账日期角色××」「本期实测记录号角色××」「回切核完成」「挂 R：假绿未验」

### 5.5 交班口述 30 秒模板

> 「本班机房角色××：AF 窗××（有/无）；油机账（正常/断档项）；巡检路线（完成/漏项）；本期实测（有/无/拒签原因）；会签（已签/未签）；挂 R/N/J（有/无）。下班续：______。」

## 6. 工作实例（12 则，教学虚构，L3）

1. **夜班无窗按 ATS**  
   现象：无书面窗试切，基站抖、监测闪。  
   处置：AF-切 拒认操作；补窗补方案；挂 N 看风暴；禁功率战。  

2. **市电闪断油机没油**  
   现象：日用箱空，油机未起。  
   处置：AF-油 主人追责补账；拒签「供电合格」直至补油+试车窗。  

3. **网管全绿半年未实车**  
   现象：大屏绿，试车台账停在半年前。  
   处置：AF-治 + R 假绿；重开试车窗；主贴 AF。  

4. **套邻站试车报告**  
   现象：报告机房号涂改痕迹。  
   处置：AF-验/治 拒签；本窗重测。  

5. **用 K 交维签顶月度试车**  
   现象：「交维做过倒换，不用月度试。」  
   处置：规则6；K 可挂支撑，主贴仍 AF。  

6. **巡检只看整流面板**  
   现象：油机侧、ATS、电瓶未勾。  
   处置：AF-巡 漏项整改；未齐拒签合格。  

7. **切出成功但未回切核**  
   现象：停在油机侧交班。  
   处置：AF6 强制回切核；未核=未完成。  

8. **倒换窗抬功率压登记失败**  
   现象：上行失败被写成覆盖病。  
   处置：AF-治 禁功率战；先 AF/N；上行抽测。  

9. **改 ATS 延时定值未走 J**  
   现象：私自改参数后试车「更快」。  
   处置：挂 J；回退或评估后 AF 再验。  

10. **机动站 AC 电源勾选冒充机房 AF**  
    现象：车载一夜勾选当月度试车。  
    处置：AC≠AF；固定机房另开 AF 窗。  

11. **告警风暴未对时就定「油机故障」**  
    现象：时钟漂移导致因果颠倒。  
    处置：先 N 对时；再 AF 验；禁空口定责。  

12. **公开群发油机序列号与曲线**  
    现象：含可定位机房信息。  
    处置：AF-治 规则8；撤回；L3 重发教学版。
