## 1. 为什么要写这篇手册（动机 + 现场对话）

前十五篇手册教你认病、交维、写频、电源监控与风暴：贴纸 A–E 协议层，F 射频，G 实验室，H 话务，I 室分，J 写频，K 电源，L 井库，M 批量/OTAP，N 监控/对时/风暴。可现场还有一类「病」——**不是今晚空口才坏，而是室分有源把喇叭对着自己的麦克风，自己喊自己，整栋楼被减敏**：

- 施工队：「下行口功率测过了，增益开到最大，可以签。」——没人问隔离与上行噪底；开通两周金机「听得到、打不出去」。  
- 新人：「远端一开，近端糊了，肯定是同频。」——没先问有源自激气质；假 F 工单满天飞。  
- 班长：「电梯里没信号，增益再加两格。」——隔离不够，越加越啸；整网被自己喊自己拖垮。  
- 射频同事：「站边反而差，一转发就断，肯定互调。」——可能是上行噪底抬高（减敏）；先 O，再挂 F。  
- 领导：「AGC 会自动压振荡，别拦着拧。」——AGC/ALC 不是隔离的替代品；隔离≫增益是设计债，不是菜单债。  
- 手册10 学过的人：「I-有源不是已经写过增益隔离噪底吗？」——I 管交维清单气质；本篇是 **有源隔离与减敏台架的加深册**，主贴新贴纸 **O**。  
- 实验室同事：「现场拧不动，台架也复现不了就算了？」——**台架可复现才允许现场拧参**；不可复现 = 拒签拧参。  
- 有人：「加功率压一下减敏观感。」——加功率是手册07/09/10 禁区；本篇也禁。

这几句背后是同一件事：

> **「室分有源 / 隔离 / 减敏」这个词在现场至少有五个坑**：  
> **① O-隔**：隔离——施主/重发、空间/极化/频段隔离直觉；**隔离必须明显大于增益**  
> **② O-敏**：减敏——上行噪底抬高、前端过载、整网被「自己喊自己」拖垮  
> **③ O-台**：台架——屏蔽箱/衰减链/金机台架复现隔离与减敏；对照手册08 G 气质  
> **④ O-噪**：噪底与增益预算——上行噪底、增益设定、AGC/ALC 气质、告警  
> **⑤ O-治**：治理与拒签——交维拒签、禁拧增益掩盖、金机走测、脱敏 L3  
> 把 ①–⑤ 当成「厂商 AGC 自动搞定」或「出了事用手册07 先开同频单」，会把隔离债与减敏债留给整栋楼与邻站。

本篇目标：能背出**室分有源隔离与减敏台架工作流**；会用新贴纸 **O（隔离/减敏/台架）** 与五个子类；会填 **插页 O（R1–R8）** 和《本网室分有源隔离与减敏台架卡》；能用「**歌剧院返送啸叫 / 麦克风对着音箱**」或「**水泵自己把水管震裂**」故事讲清自激与减敏；能拒绝「未测噪底就签、只测下行、用加增益掩盖空点、AGC 替代隔离、台架未复现就现场拧参」；自测过关后，回库把本网最近一次有源室分交维或减敏事件（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：不发明 ETSI 条款号；**不写真实批复频点、真实楼宇名、真实站号、真实个号、真实密钥、真实单位名进公开仓库**；**不教振荡绕过、告警屏蔽后门、故意抬噪攻击邻站**——只讲制度与台架治理；不重写手册10 / 07 / 08 / 13 / 15 全文（只给指针）；**手册10 的 I 规则交维清单仍生效，本篇加深有源隔离与减敏台架**；**不把加功率/加直放站增益当空点或减敏的止痛药**；有源隔离/减敏问题**主贴 O**，可挂 I/F/G，禁止把「远端一开近端糊」直接写成「用户捣蛋」；结案词用贴纸 O + 本网证据；公开 BDA/DAS 交维、隔离测试、上行噪声、减敏计算、屏蔽箱测量资料只借**精神与顺序**——**不背条款号当 ETSI、不背厂商菜单当本网制度**。

### 2.1 一句话：必须先证明隔离≫增益、上行噪底可测、台架可复现，再谈现场拧参——否则自己喊自己、整网减敏、交维假绿

   ┌──────────────────────────────────────────────────────────────┐
   │  歌剧院舞台（本网有源室分 / 直放站 / 光纤远端）                │

   │   麦克风 = 施主侧（听基站/听上行）——O-隔 的「听」端            │

口诀：

> **先隔离，再增益，后噪底，末台架。**  
> 麦克风对着音箱还开大音量 = 歌剧院啸叫——**隔离≫增益。**  
> 只测音箱响不测话筒前噪声 = 交维假绿——**上行噪底未测禁签。**

### 2.2 「歌剧院」五段直觉（弱项短补，钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **隔离** | 麦与音箱的空间/极化/墙体隔开 | 施主侧与重发侧要隔开；隔离必须明显大于增益；方向性施主天线常是解药之一 | O-隔 |
| **减敏** | 啸叫把人声盖住 / 耳膜麻木 | 上行噪底抬高 → 远端「听得到、打不出去」；站边反而差气质 | O-敏 |
| **台架** | 排练厅先排戏再上场 | 屏蔽箱/衰减链/金机可复现，才允许现场拧参；对照手册08 G | O-台 |
| **噪底与增益** | 声压计 + 音控台推子 | 远端开关对比、增益步进对比；AGC/ALC 气质；告警清零 | O-噪 |
| **治理** | 拒签与交维台账 | 未测拒签；禁拧增益掩盖空点；公开包脱敏 L3 | O-治 |

> 公开 BDA/DAS 交维资料常写「隔离至少比增益高一截（常见工程话术约 +15～+20 dB 量级直觉）」「开通前后测施主站噪底/有效灵敏度」「不要把室内天线对着施主视线」——本篇只借**顺序直觉**：证隔离 → 测噪底 → 台架复现 → 金机施主/覆盖对照 → 告警清零 → 拒签治理。**不背厂商菜单步骤 / 不背标准条款号当 ETSI / 不教绕过振荡检测。**

### 2.4 新贴纸 O：隔离 / 减敏 / 台架（五个子类）

```text
                    ┌──────── 贴纸 O · 隔离/减敏/台架 ────────┐
                    │  O-隔  隔离：施主/重发·空间/极化/频段；隔离≫增益              │
                    │  O-敏  减敏：上行噪底抬高·前端过载·自己喊自己拖垮整网          │
                    │  O-台  台架：屏蔽箱/衰减链/金机复现；对照手册08 G 气质         │
                    │  O-噪  噪底与增益预算：上行噪底·增益设定·AGC/ALC·告警         │
                    │  O-治  治理与拒签：交维拒签·禁拧掩盖·金机走测·脱敏 L3         │
                    └──────────────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签 / 拒拧触发 |
|------|--------|----------------------|
| **O-隔** | 隔离未证或隔离≪增益 → 禁开大增益 | 施主与室内天线近距对视；隔离测试未做 |
| **O-敏** | 开通后施主/近端噪底明显抬 → 减敏债 | 「听得到打不出去」；站边反而差 |
| **O-台** | 台架不可复现 → 禁现场拧参 | 「现场感觉好一点」无台架对照 |
| **O-噪** | 上行噪底未测 / 告警未清 → 禁签有源交维 | 只测下行口功率就签字 |
| **O-治** | 拒签门槛 + 脱敏；禁加功率/加增益掩盖 | 用公网满格或加功率叙事交差 |

### 2.5 有源隔离 / 减敏最小工作流（背下来）

        ▼

        │是
        ▼
  告警清零、光路正常？──否──▶ 禁开大增益（O-噪 / 规则6）
        │是
        ▼
  台架（屏蔽箱/衰减链）可复现？──否──▶ 禁现场拧参（O-台 / 规则4）

        ▼

> **先隔，再噪，后台架，末金机。**  
> 跳过隔离的拧增益 = 把歌剧院音控推子拧到啸叫。

## 3. 核心交付：插页 O + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 O（而不是先贴 I / F / G）

| 现象 | 优先贴纸 | 说明 |
|------|----------|------|
| 有源交维：增益/隔离/噪底/告警 | **主 O**，总流程挂 I | I 是交维母册；隔离减敏加深用 O |
| 远端一开，近端/施主侧糊或 BER 跳 | **O-敏**，可次挂 F | 先问自激/抬噪，禁先开同频单 |
| 电梯/井道加增益越加越差 | **O-隔 / O-敏**，可挂 L | 指针手册13，不重写井库 |
| 现场要拧参，台架未复现 | **O-台** 拒拧 | 对照 G，不重写六闭环 |
| 只测下行口功率要签字 | **O-噪 / O-治** 拒签 | 呼应手册10「禁只测下行」 |
| 光路/远端告警未清仍要开大增益 | **O-噪** 禁拧 | 可次挂 N（告警风暴） |
| 无源接头进水、VSWR 坏 | 主 **I-无源**，不是 O | O 不管无源断点本身 |
| 真同频/邻道被证明 | 主 **F**，O 作排除项 | 先排除有源自激气质 |

### 3.2 插页 O · 隔离 / 减敏 / 台架（挂在总三联单或室分交维首页后）

| 行 | 名称 | 填写示例（教学虚构） |
|----|------|----------------------|
| **R1** | 主子类 + 次子类 | 「主 O-隔 / 次 O-噪」（或 O-敏 / O-台 / O-治） |
| **R2** | 系统形态 | 「光纤近端+远端；施主定向；室内吸顶」（脱敏，无楼名） |
| **R3** | 隔离证据 | 「施主↔覆盖隔离教学相对值；方向/距离/墙体措施；隔离≫增益？」 |
| **R4** | 增益设定 | 「上/下行增益教学相对值；步进记录；是否动过 AGC/ALC」 |
| **R5** | 上行噪底 | 「远端关/开对照；近端/施主侧教学相对值；是否抬高」 |
| **R6** | 台架复现 | 「屏蔽箱/衰减链编号（教学）；复现结果；不可复现则拒拧」 |
| **R7** | 金机对照 | 「施主侧点位 + 覆盖侧点位；门开闭若涉及井道则指针 L」 |

## 4. 深潜：八条硬规则 + 隔离/减敏/台架直觉 + 假病禁令

### 4.1 八条硬规则（本篇钉子）

1. **先证隔离再谈增益（隔离≫增益）**——麦克风对着音箱禁止开大音量。  
2. **禁加功率 / 加直放站增益掩盖空点或减敏**——呼应手册07/09/10；拧增益不是补丁。  
3. **上行噪底未测 → 禁签有源交维**——只测下行 = 假绿交维。  
4. **台架可复现才允许现场拧参**——不可复现 = 拒拧；对照手册08 G 气质。  
5. **金机走测必含施主侧与覆盖侧对照**——单侧满格不算过。  
6. **告警未清 / 光路异常 → 禁开大增益**——先治水泵告警，再谈水压。  
7. **可挂 I/F/G，但主贴 O；假干扰先问有源自激气质**——禁把啸叫写成用户捣蛋。  
8. **公开材料脱敏 L3；不写真实频点/楼名/站号/个号/密钥**——教学与公开仓双禁。

### 4.2 隔离直觉：「不要自己喊自己」

有源系统（直放站 / 部分光纤远端架构）常有一句工程常识：

> **施主侧与重发侧要隔开；隔离要明显大于增益。**  
> 白话：你把喇叭对着自己的麦克风，增益越大越容易啸叫——射频上就是自激 / 抬噪底 / 减敏气质。

| 隔离手段（教学直觉） | 像什么 | 常见坑 |
|----------------------|--------|--------|
| **空间隔离** | 麦与音箱拉远、隔墙 | 室内天线贴窗对着施主；顶楼吸顶正对施主 |
| **极化 / 方向性** | 定向施主天线收窄波束 | 施主用全向「图省事」；波束被女儿墙挡住却没重瞄 |
| **频段 / 滤波气质** | 不同戏台不同音域 | 过宽带宽把邻系统噪声一起放大（借公开工程报告精神，不背条款） |
| **衰减 / 耦合器调整** | 音控推子与分支衰减 | 为补空点去掉必要衰减，直接啃隔离余量 |

```text
  增益开大一格
        │
        ▼
  隔离余量还够？──否──▶ 啸叫/自激气质（O-隔→O-敏）
        │是
        ▼
  上行噪底抬了吗？──是──▶ 减敏债（O-敏）；降增益或改隔离，禁再拧大
        │否
        ▼
  金机施主侧+覆盖侧仍过？──否──▶ 拒签或带条件
        │是
        ▼
  记录 R3/R4/R5；允许谨慎保持设定
```

> 公开交维话术常见「隔离 ≥ 增益 + 一截余量（约 15～20 dB 量级被多方引用）」——本篇把它当作**教学量级直觉**，**不是**你网必须照抄的法规数字；你网以《本网…卡》与厂商手册为准，但**顺序不可倒**：先隔离证据，后增益数字。

### 4.3 减敏直觉：「整网被自己喊自己拖垮」

**减敏（desense）白话**：接收机前端被多余功率/噪声填满，灵敏度变差——不是「天线坏了」，而是「耳朵被噪声淹了」。

| 现场观感 | 更像 O-敏 还是真 F？ | 动作 |
|----------|----------------------|------|
| 远端一开，近端/施主侧突然糊 | 先 O-敏 | 远端关/开对照噪底；降增益 |
| 覆盖侧满格，打出去对方听不清 | 先 O-敏（上行） | 查上行增益与施主噪底 |
| 站边反而差、一转发就断 | O-敏 气质，可挂 F-互 | 先排除有源抬噪，再开互调梯子 |
| 多栋楼同时变差，无频率变更 | 多远端复合抬噪 | O-噪 预算；禁逐楼加增益 |
| 真有邻频发射证据 | 主 F | O 作排除项写进三联单 |

**和 12.5 kHz 弱项的衔接**：噪底讨论的带宽台阶仍是 **12.5 kHz** 这一格的直觉；有源把噪声放大，**不会**把信道变成 25 kHz，也不改变 4FSK / 30 ms 时隙——它只是让「这一格里的底噪」变脏。

### 4.4 台架直觉：排练厅先排戏（O-台 ↔ 手册08 G）

| 台架要素 | 干什么 | 拒拧条件 |
|----------|--------|----------|
| **屏蔽箱 / 屏蔽房气质** | 把「麦」和「音箱」人为隔开，测泄漏与隔离 | 箱门缝泄漏未评估却当「已隔离」 |
| **衰减链** | 用已知衰减模拟路径损耗与隔离余量 | 衰减器未标定、跳线滥竽充数 |
| **金机** | 固定机型/固件/写频基线（指针 J） | 随便抓一台「好机」当金机 |
| **开关对照** | 有源关/开、增益步进 | 只有「感觉好一点」无数字相对值 |
| **记录** | 进 R6；不可复现写明 | 不可复现仍批准现场拧参 = 违规 |

> 本篇**不重写**手册08 六闭环；只要求：凡现场拧增益，必须能在台架用「关/开 + 步进 + 金机」讲清同一故事。讲不清 = **O-台 拒拧**。

### 4.5 「假干扰 / 假弱覆盖 / 假容量 / 假协议」怎么认

| 假病名 | 真身往往是 | 禁令 |
|--------|------------|------|
| 假同频 | 有源自激 / 抬噪（O-隔/O-敏） | 禁先开 F 同频单 |
| 假弱覆盖 | 上行减敏；下行看起来满格 | 禁加功率补空点 |
| 假容量 | 多远端复合噪底；高峰更显 | 禁加信道掩盖 |
| 假协议 | 抬噪后登记/重传异常 | 先 O，再挂 A–E |
| 假电源 | 远端掉电（挂 K）被当成隔离病 | 先看告警与供电 |

### 4.6 假病禁令墙（与加功率叙事）

```text
  × 「增益再开大一点就满格」     → 掩盖空点 / 啃隔离余量
  × 「AGC 开着不会啸叫」         → AGC 不是隔离替代品
  × 「先加功率压过去今晚」       → 手册07/09/10/本篇四连禁
  × 「公网满格说明室分好了」     → 指标错位；要 DMR 金机
  × 「台架做不出，现场拧一下」   → O-台 拒拧
  × 「告警红着也能先开通」       → 规则6 禁开大增益
  × 「把振荡检测关了省事」       → 禁止；属危险绕过，本篇不教
```

### 4.8 增益步进与「小步」纪律（现场可复印）

| 步骤 | 做什么 | 记录到 |
|------|--------|--------|
| 0 | 写下当前上/下行增益教学相对值；拍照面板（脱敏后入库） | R4 |
| 1 | 确认隔离证据仍有效；若搬家/改天线则重做 R3 | R3 |
| 2 | 每次只动 **一小步**（教学：一格/一档，忌连跳三档） | R4 |
| 3 | 每步后：远端关/开听感或噪底相对值；金机抽测一点 | R5/R7 |
| 4 | 任一步出现啸叫气质/噪底明显抬 → **立刻回退**并停 | R8 |
| 5 | 目标覆盖达到即停；禁止「再加两格留余量」啃隔离 | R8 |

> 口诀：**一小步，一对照，一记录；啸叫即回退。**  
> 把「连续拧满再看」当成施工速度 = 把歌剧院推子一把推到底。

### 4.9 施主侧与覆盖侧：为什么金机必须两边走

```text
  覆盖侧金机满格 ──┐
                   ├── 只说明「音箱够响」
  施主侧/近端糊 ───┘
                   └── 可能「麦克风被噪声淹」= 上行减敏

  正确对照：
  覆盖侧点位（听下行、看注册） + 施主侧或近端点位（看上行是否干净）
```

- **只测覆盖侧**：最常见的假绿交维。  
- **只测施主侧**：可能漏掉分支空点（那是 I-覆 的事，但有源仍要两侧）。  
- **井道场景**：厅门开/闭对照仍归手册13；本篇要求在 R7 写明「已做 L 门开闭」或「本期不涉及井道」。

### 4.10 和公开「隔离余量」话术怎么相处（不抄法规数字进公开仓）

多方公开交维材料会出现类似说法：

- 隔离应比系统增益高一截（常见引用约 +15 dB 或 +20 dB 量级）；  
- 开通前后在施主站看噪底/有效灵敏度，应无明显变差；  
- 室内天线避开门窗对视施主；施主尽量定向。  

**本网用法**：

1. 把它们当成 **R3/R5 的检查问句**，不是把某国消防表数字写进公开仓当「ETSI 要求」。  
2. 你网《本网…卡》与厂商手册给出的门限优先；本篇管**顺序与拒签**。  
3. 教学材料里只用「教学相对值 / 余量是否足够」——规则8。

### 4.7 和弱项加餐的衔接

12.5 kHz / 4FSK / 30 ms 两槽背熟，你才说得清：**有源隔离与增益管的是工程放大与自激风险，不是调制台阶**。有人要用加功率/加增益治空点或减敏时，回加餐 + 手册07/10 + 本篇八条硬规则。

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「远端一开，近端糊，被写成同频」→ O-敏（次挂 F）

- **现象**：光纤远端启用后，近端金机上行差。  
- **错法**：直接开同频工单，加功率。  
- **正法**：远端关/开对照，噪底抬高；降上行增益；隔离复查。  
- **结案**：主 O-敏；F 作排除项；规则2/7。

### 例 2 · 「电梯加增益越加越差」→ O-隔（挂 L）

- **现象**：井道远端增益步进后啸叫气质。  
- **错法**：继续加增益；关振荡检测。  
- **正法**：停拧；查厅门/轿厢天线与施主路径；改隔离或降增益。  
- **结案**：主 O-隔；次 L；指针手册13，不重写。

### 例 3 · 「只测下行口功率就签字」→ O-噪 / O-治

- **现象**：交维包只有下行口功率表。  
- **错法**：带条件都懒得写就全签。  
- **正法**：拒签；补 R3/R5/R7。  
- **结案**：规则3/5；回手册10 最小测试包气质。

### 例 4 · 「AGC 开着不会有问题」→ O-隔

- **现象**：隔离测试不及格，施工称 AGC 会管。  
- **错法**：相信菜单叙事开通。  
- **正法**：隔离≫增益未证 → 禁开大增益；AGC 不顶替 R3。  
- **结案**：规则1；写入反例墙。

### 例 5 · 「台架做不出，现场拧好了」→ O-台

- **现象**：屏蔽箱衰减链复现失败，现场凭感觉拧。  
- **错法**：以「用户说好了」结案。  
- **正法**：拒拧；修台架或改隔离设计后再来。  
- **结案**：规则4；对照 G。

### 例 6 · 「光路告警红着仍满增益」→ O-噪（可挂 N）

- **现象**：光收告警未清，远端时断时续，有人把增益拧满「补覆盖」。  
- **错法**：加增益掩盖光路。  
- **正法**：禁开大增益；先光路；风暴铃挂 N。  
- **结案**：规则6；指针手册15。

### 例 7 · 「多远端复合，整片区减敏」→ O-噪 / O-敏

- **现象**：三栋教学楼远端同时满配，施主侧噪底抬。  
- **错法**：逐栋再加增益。  
- **正法**：做复合噪底预算；降总上行贡献；分批开通。  
- **结案**：O-噪；禁令墙「多远端满增益」。

### 例 8 · 「用加功率压减敏观感」→ 禁令（O + F）

- **现象**：减敏后下行听感差，夜班加站功。  
- **错法**：功率叙事过夜。  
- **正法**：回退功率；治隔离/增益；三联单记违规尝试。  
- **结案**：规则2；手册07 禁区。

### 例 9 · 「公网满格当室分验收」→ O-治

- **现象**：领导用手机公网信号验收。  
- **错法**：公网满格签字。  
- **正法**：DMR 金机施主侧+覆盖侧；拒签公网替代。  
- **结案**：规则5/8 气质；指标错位。

### 例 10 · 「公开分享写出楼名频点」→ O-治

- **现象**：复盘材料带真实楼宇与批复频点。  
- **错法**：直接进公开仓。  
- **正法**：L3 脱敏；教学相对值；删真实标识。  
- **结案**：规则8。

### 例 11 · 「方向性施主被女儿墙挡住，施工改全向」→ O-隔

- **现象**：为「好瞄准」把施主改成全向，隔离余量崩塌。  
- **错法**：用加增益补覆盖空洞。  
- **正法**：恢复定向、重瞄主瓣净空；重做 R3；降增益至余量恢复。  
- **结案**：主 O-隔；写入反例「全向省事」。

### 例 12 · 「衰减垫片被拆去补空点」→ O-隔 / O-治

- **现象**：分支上教学用衰减被拆除，空点亮了，整层啸叫气质。  
- **错法**：认为「衰减是浪费功率」。  
- **正法**：衰减往往是隔离余量的一部分；恢复或改设计；拒签「拆衰减当优化」。  
- **结案**：规则1/2；O-治记违规变更。

### 例厚补 · 「半隔离半空点」怎么排优先级（5 分钟口诀）

> **先隔离债，再空点债；先噪底，后功率叙事。**  
> 隔离不够时补空点 = 先把音控拧到啸叫再怪观众席有柱子。

## 8. 术语表（本篇约 30 词）+ 易错观念

| 术语 | 白话 |
|------|------|
| 施主侧 | 有源系统「听」基站/网络的那一侧（像麦克风） |
| 重发/覆盖侧 | 对楼内「喊」的那一侧（像音箱） |
| 隔离 | 施主与覆盖之间的射频隔开程度；要≫增益 |
| 增益 | 有源放大倍数；不是覆盖万能药 |
| 减敏 | 噪底抬高导致接收变差 |
| 上行噪底 | 上行方向底噪；有源常在此暴露问题 |
| 自激/振荡气质 | 自己喊自己形成正反馈 |
| AGC | 自动增益控制；辅助不是隔离替代 |
| ALC | 自动电平控制；同上 |
| 直放站/BDA | 双向放大类有源设备统称（教学） |
| 光纤远端 | 近端+光缆+远端单元形态 |
| 室分/DAS | 室内分布系统 |
| 金机 | 基线终端；指针手册11 |
| 台架 | 实验室/屏蔽箱复现场 |
| 衰减链 | 已知衰减组合，模拟路径 |
| 屏蔽箱 | 抑制外界耦合的测试箱 |
| 口功率 | 天线口或分支口功率；不能单凭它签有源 |
| VSWR/DTF | 无源链路指标；主归 I-无源 |
| PIM | 无源互调；可挂 F/I，不是 O 主场 |
| 12.5 kHz | DMR 信道带宽台阶 |
| 4FSK | DMR 调制 |
| 时隙 30 ms | TDMA 一格 |
| 三联单 | 手册06 证据写法 |
| 脱敏 L3 | 去掉真实频点楼名站号个号密钥 |
| 假绿交维 | 指标不全却显示可签 |
| 复合噪底 | 多远端噪声叠加 |
| 振荡检测 | 设备自带防啸机制；禁止关闭当优化 |
| 带条件签 | 书面开口项+到期；非随便放行 |
| 主贴/次挂 | 结案主因贴纸与次要贴纸 |
| 教学相对值 | 脱敏后的比较用读数，非真实批复参数 |

**易错观念**

1. 「增益越大覆盖越好」——隔离不够时增益是啸叫油门。  
2. 「AGC 等于隔离」——不等于。  
3. 「下行满格 = 上行也好」——减敏专打上行。  
4. 「公网满格 = DMR 好」——指标错位。  
5. 「台架是实验室的事，现场不用」——规则4 相反。  
6. 「有源病就是同频」——先 O 后 F。  
7. 「关振荡检测能多盖一层」——禁止。  
8. 「手册10 写过就不用 O」——I 是母册，O 是加深钉。
