## 1. 为什么要写这篇手册（动机 + 现场对话）

前六十七篇手册从 A–E 协议一路写到 BN 冷凝器盘管清洗与翅片完好：其中 **AF 回答「油机市电切换与机房供电巡检」**（周检/本体清单的 AF-油角色会写到燃油/机油/冷却/电瓶，但**周检写到机油 ≠ 本篇台账**，也没有单独给机油液位和机油压力/油温保护各钉一张巡检台账），**BI 回答「日用/储油罐油位与泄漏」**（日用油箱、储油罐里的柴油不是机油，**燃油油位/泄漏过 ≠ 机油液位/保护过**），**BL 回答「冷却液液位与高温/低水位保护」**（散热器里的缸套水不是曲轴箱里的机油，**冷却液液位/保护过 ≠ 机油液位/油压油温保护过**），**AV 回答「日用油箱油品净化与加油交接」**（加的、净的是燃油，不是润滑机油），**AR 回答「柴油发电机房通风排烟与燃油安全巡检边界」**（燃油安全窗里可能顺带提到机油，但没有单独给机油液位和油压/油温保护各钉一张巡检台账），**AO 回答「漏水与接地汇流排」**（地面积水探头 OK 不是本篇机油窗）。可还没有单独钉死一件事——**机房不是「油尺看着有油、油压灯绿、油温灯绿、周检写到机油，就等于机油路径过关」**。这就是本篇的 **BO**：机油液位要有台账与本期对照；机油压力保护与油温保护要各有主人、有窗、有方法、有准用期；两边边界方法要钉死；本组本机房本期要实测，禁套邻站表——能不能签「机房柴油发电机机油液位与机油压力/油温保护巡检准用」？

**五个词必须先分清，再往下读（本篇反复钉）**：

| 中文词 | 英文 | 作用 | 本系列谁管 | 不等于 |
|--------|------|------|------------|--------|
| **机油** | motor oil / engine lubricating oil | 在曲轴箱、油底壳、油道里循环、润滑并带走摩擦热量的液体路径 | **BO-位**（本篇）管液位；保护窗 **BO-护** | **≠ 日用油箱/储油罐里的柴油**；**≠ 散热器里的缸套水**；**看着有油 ≠ 机油液位台账过**；**BI≠BO**；**BL≠BO** |
| **机油液位** | engine oil level | 油尺和/或观察窗上的液位窗与本期对照（冷态/静置核对角色以本网与 OEM 书面为准） | **BO-位**（本篇） | **油尺看着有油 ≠ 台账过**；**口头说加过机油 ≠ 方法过**；**液位过 ≠ 保护窗过** |
| **机油压力保护** | oil pressure protection | 机油压力低报警/停机保护窗；有主有方法有准用期 | **BO-护**（本篇，油压侧） | **油压灯绿 / 表看着在绿区 ≠ 窗过**；**油压保护过 ≠ 油温保护过** |
| **油温保护** | oil temperature protection | 机油温度高报警/停机保护窗；与油压侧分开看 | **BO-护**（本篇，油温侧） | **油温灯绿 / 表看着在绿区 ≠ 窗过**；**油温保护过 ≠ 油压保护过** |
| **冷却液 / 燃油油位** | coolant / fuel level | 缸套水路归 **BL**；日用/储油罐燃油油位与泄漏归 **BI** | **BL** / **BI** | **≠ BO**；冷却液过 ≠ 机油过；燃油油位过 ≠ 机油过 |

```text
   │  机油液位路径 + 机油压力/油温保护路径  =  本网 BO            │
   │                                                              │
   │  机油液位台账钉死（机组·油尺或观察窗或油底壳·液位窗·本期对照）≈ BO-位  机油有账 │
   │  保护侧有主有窗有方法准用期（油压侧与油温侧分开看）≈ BO-护  保护有窗 │
   │  边界窗·方法钉死（与AF/BI/BL/AV/AR/AO/N分工）≈ BO-界  边界有法 │
   │  本期实测禁套邻站机油液位/保护表           ≈ BO-验  本组本机房本期 │
   │  假绿≠放行·顶替·泄放·旁通·绕联锁·热机开盖开塞·功率战 ≈ BO-治  治理与脱敏L3 │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **机油有账，保护有窗，边界有法，会签才放。**

> **AF≠BO**（周检写到机油≠本篇台账）；**BI≠BO**（柴油不是机油）；**BL≠BO**（缸套水不是机油）；**AV≠BO；AR≠BO；AO≠BO**。液位过≠保护窗过；油压保护过≠油温保护过；N 绿≠本期实测过。看着有油/油尺看着有油≠台账过；灯绿/表绿≠窗过；口头说加过机油≠方法过。

### 2.2 「医院手术室/ICU / 数据中心应急柴油发电机机油液位 + 机油压力/油温保护路径」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **位** | 机组入账→油尺或观察窗或油底壳角色→液位窗→本期对照→禁「看着有油/油尺看着有油就算过」「口头说加过机油」 | 机油液位台账钉死；看着有油≠台账过；口头加过机油≠方法过；液位过 ≠ 保护过；**AF 周检勾到机油 ≠ 本台账**；**BI 燃油油位 ≠ 本液位**；**BL 冷却液液位 ≠ 本液位** | BO-位 |
| **护** | 机油压力保护与油温保护两侧都有主人、有窗、有方法、有准用期；禁「油压灯绿/油温灯绿就算过」「表看着在绿区就算过」「套邻站保护照片」 | 灯绿≠窗过；表绿≠窗过；油压侧过 ≠ 油温侧过；两侧分开实测 | BO-护 |
| **界** | 边界窗有书面方法（与 AF/BI/BL/AV/AR/AO/N 分工；以本网与 OEM 为准）；禁绕机油压力/油温联锁、旁通、不安全泄放机油教条、热机开盖开塞教条、伪造台账 | 边界窗与方法书面固定；**不重写 AF/BI/BL/AV/AR/AO** | BO-界 |
| **验** | 本期机油液位/保护实测留痕；禁抄邻院机油液位或保护表 | 本组本机房本期实测；禁套他站他期机油液位/保护表 | BO-验 |
| **治** | 假绿≠可以签；禁用「切换签」「燃油油位签」「冷却液签」「油品签」「燃油安全签」「漏水探头签」「监控签」顶本期机油液位/保护 | 假绿、他贴顶替、泄放/旁通/绕联锁/热机开盖开塞、功率战、泄密 → 治理 | BO-治 |

> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：柴油发电机、机油/润滑、机油泵、油压与泄压阀、湿式油底壳与油尺公开概述强调**液位有核对角色、机油不是燃油也不是缸套水、机油压力保护与油温保护常是两条独立路径、看着有油≠本期核对过、保护灯绿≠窗过、热机带压不可乱开加注口/滤清器/放油塞**（§10，**只借秩序直觉**；**本篇不写换油放油步骤、不写泄放步骤、不写绕联锁操作教条，不重写邻贴全文**）。医院/数据中心应急发电机公开资料强调**周检条目写到机油≠专项台账过、切换试车过≠机油窗过、告警绿≠本期核对合格**（§10，**只作故事类比**）。**本网台账格式、窗方法、边界顺序与合格门限以本网制度、合同与 OEM 书面为准**。

### 2.3 和手册33（AF）/ 62（BI）/ 65（BL）/ 49（AV）/ 45（AR）/ 42（AO）/ 15（N）等的咬合（指针，不重写）

- **AF（手册33）**：油机市电切换与供电巡检，周检/本体清单的 AF-油角色会写到燃油/机油/冷却/电瓶；**AF ≠ BO**——切换过 ≠ 机油液位/保护过；**AF 周检写到机油 ≠ 本篇台账**；切换/试车可挂 AF，机油主贴仍 BO；**不重写 AF 全文**。
- **BI（手册62）**：日用/储油罐燃油油位与泄漏，**没有**单独给机油液位 + 机油压力/油温保护一张巡检台账；**BI ≠ BO**——燃油油位/泄漏过 ≠ 机油液位/保护过；柴油不是机油；燃油路径可挂 BI，机油主贴仍 BO；**不得互相顶替**；**不重写 BI 全文**。
- **BL（手册65）**：冷却液液位与高温/低水位保护；**BL ≠ BO**——冷却液液位/保护过 ≠ 机油液位/油压油温保护过；缸套水不是机油；冷却液可挂 BL，机油主贴仍 BO；**不重写 BL 全文**。两路液体都在同一台机组上，但不是同一张台账。
- **AV（手册49）**：燃油油品、净化与加油交接；**AV ≠ BO**——燃油油品/加油过 ≠ 机油过；加的是燃油，不是润滑机油；**不重写 AV 全文**。
- **AR（手册45）**：通风排烟与燃油**安全**巡检；**AR ≠ BO**——燃油安全过 ≠ 机油液位/保护过；可挂 AR，机油主贴仍 BO；**不重写 AR 全文**。进风排烟乱可能影响散热与油温，但 AR 签的不是本台账。
- **AO（手册42）**：漏**水**探测与汇流排；**AO ≠ BO**——漏水探头 OK ≠ 机油液位/保护过；地面积水可挂 AO，机油路径主贴仍 BO。机油外漏落到地面，积液现象可回 AO 或其他泄漏路径，液位与保护台账仍回 BO。
- **AN / AL / AD / AA / AQ**：门禁过 ≠ 交底过；气灭过 ≠ 交底过；入库走 AD，**不能**用旧 AD 签顶本期 BO 窗；首年抽检可挂 AA；调录像另开 AQ（视频过 ≠ BO 准用）；**不教绕过门禁/保护联锁**。
- **N（手册15）**：机油液位异常/油压或油温告警风暴挂 N，**不先抬功率**；**禁绕联锁、禁旁通、禁不安全泄放机油教条、禁热机开盖开塞教条**；N 绿 ≠ BO 过。
- **AG / AP / BH / BK / BJ / BN**：电池/内阻、冷却水泵冷凝水、蒸发器/冷凝器盘管清洗翅片、吸排过热过冷均不顶替 BO。机房精密空调冷却水 ≠ 柴油机机油。
- **R / J / X / I**：假绿挂 R；变更走 J 后再验 BO；覆盖/干扰可挂 X/I——**先 BO 证机油液位与保护秩序，再谈覆盖病**。

### 2.4 新贴纸 BO：位 / 护 / 界 / 验 / 治（五个子类）

> 小彩蛋：双字母贴纸续写——**AA** 起至 **BN** 冷凝器盘管清洗与翅片完好（对照见手册67 §2.4），A–Z 与 AA–BN 既有含义不改。本篇 **BO** 管「机房柴油发电机机油液位与机油压力/油温保护」（**BN 之后第一张 BO**）。

### 2.5 建机油液位台账 → 钉保护窗 → 边界方法钉死 → 本期实测 → 会签放行 → 变更再验 阶段梯（背下来）

### 2.7 一晚怎么走完（教学节奏，不替代本网书面规程）

1. 翻 BO1：机油液位台账在？看着有油/油尺看着有油≠准用、口头加过机油≠方法过、液位过≠保护过、AF≠BO / BI≠BO / BL≠BO 勾了吗？无柴油机/无机油液位路径是否书面「不适用」？  
2. 翻 BO2：机油压力保护与油温保护主人/窗/方法/准用期；禁灯绿、禁表绿、禁套邻站照片；油压保护过≠油温保护过勾了吗？油压窗不适用≠油温窗自动免？  
3. 翻 BO3：边界书面方法；禁绕机油压力/油温联锁、禁旁通、禁不安全泄放机油教条、禁热机开盖开塞教条；邻贴分工勾清（尤其 AF/BI/BL/AV/AR/AO）。  
4. 翻 BO4：本期机油液位对照、本期油压侧与油温侧保护分别留痕；禁套声明。  
5. 会签或拒签；风暴挂 N；变更走 J；L3。
