## 3. 核心交付：插页 BO + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 BO（而不是先贴 AF / BI / BL / AV / AR / AO / N）

- 要签「机房柴油发电机机油液位与机油压力/油温保护巡检准用」、要开机油液位交底窗、要交底机油压力/油温保护侧 → **主贴 BO**。  
- 油机市电切换与供电巡检 → **AF**（周检写到机油 ≠ 本篇台账）。日用/储油罐燃油油位与泄漏 → **BI**。冷却液液位与高温/低水位保护 → **BL**。燃油油品净化加油 → **AV**。通风排烟与燃油安全 → **AR**。漏水汇排 → **AO**。**AF ≠ BO；BI ≠ BO；BL ≠ BO；AV ≠ BO；AR ≠ BO；AO ≠ BO**。  
- 进机房先 **AN**（门禁过 ≠ 交底过）。气灭 → **AL**。风暴先 **N**，缺秩序整改仍 **BO**；切换、燃油油位、冷却液、油品、燃油安全、地面积水分问 AF/BI/BL/AV/AR/AO；**禁功率战、绕联锁、旁通、不安全泄放机油教条、热机开盖开塞教条**。  
- 假绿/顶替挂 **R**；变更走 **J** 后再验 BO。  
- 无柴油发电机，或无机油液位/机油压力/油温保护路径 → 书面「不适用」；**不得**用 BO 顶 AF/BI/BL/AV/AR，也不得用它们顶 BO。液位侧不适用 ≠ 保护侧自动免；油压窗不适用 ≠ 油温窗自动免；AF/BI/BL 过了或它们不适用 ≠ 机油路径自动免。

### 3.4 与总三联单怎么写（脱敏 L3）

- **现象栏**：写「机油液位缺账 / 看着有油或油尺看着有油无核对 / 口头加过机油 / 油压灯绿或油温灯绿顶窗 / 表绿顶窗 / 一侧顶另一侧 / 他贴顶 BO / 套票 / 泄放/旁通/绕联锁/热机开盖开塞嫌疑」等角色化现象；**不写**真实机房全称、油机或发动机序列号全文、可还原机油门限全文。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **机油液位台账钉死**：机组、油尺或观察窗或油底壳角色与液位窗、本期对照各自有账（编号脱敏）；禁「看着有油就算过」「油尺看着有油就算过」「口头说加过机油」；液位过 ≠ 保护过，保护过 ≠ 液位过。  
2. **机油压力/油温保护侧有主有窗有方法·准用期**：油压侧与油温侧分开看；测点、动作（报警/停机）、合格窗与准用期以本网与 OEM 书面为准；每次保护交底有主人角色、有书面窗、有方法、有准用期；禁「油压灯绿就算过」「油温灯绿就算过」「表看着在绿区就算过」「套邻站保护照片」；油压保护过 ≠ 油温保护过。  
3. **边界窗与方法钉死**：书面固定；方法含与 AF/BI/BL/AV/AR/AO/N 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明换油放油步骤、泄放步骤、绕联锁操作或热机开盖开塞步骤教条；**不重写 AF/BI/BL/AV/AR/AO 全文**）；禁「窗再说」「绕机油压力/油温等保护联锁」「开旁通冒充」「不安全泄放机油教条」「热机开盖开塞教条」「伪造台账」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、机油液位对照、油压侧与油温侧保护必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「机房柴油发电机机油液位与机油压力/油温保护巡检准用」；假绿 ≠ 放行。  
6. **禁顶替 AF/BI/BL/AV/AR/AO/AD/AA/N/AQ 等，主贴 BO，假绿≠放行挂 R**：他贴签都不顶本期机油液位/保护签。**尤其 AF ≠ BO、BI ≠ BO、BL ≠ BO、AV ≠ BO、AR ≠ BO、AO ≠ BO。** 油机市电过 ≠ 机油过（周检写到机油 ≠ 本篇台账）；燃油油位/泄漏过 ≠ 机油过（柴油不是机油）；冷却液液位/保护过 ≠ 机油过（缸套水不是机油）；燃油油品/加油过 ≠ 机油过；燃油安全过 ≠ 机油过；漏水探头过 ≠ 本窗。看着有油/油尺看着有油 ≠ 台账过；灯绿/表绿 ≠ 窗过；口头加过机油 ≠ 方法过；液位过 ≠ 保护窗过；油压保护过 ≠ 油温保护过。
7. **机油液位异常/油压或油温告警风暴挂 N，边界/门限/窗变更走 J；禁功率战；禁绕机油压力/油温等保护联锁；禁旁通；禁不安全泄放机油教条；禁热机开盖开塞教条；禁伪造台账**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。机油/保护乱窗、假绿、油压或油温告警常被误当「覆盖病」→**禁功率战**；挂 N；变更走 J。机油/保护失序不是覆盖病。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/油机或发动机序列号全文/可还原坐标与联系人；禁公开传播未脱敏机油门限与保护参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签机油液位/保护准用、无实测冒充边界过、绕联锁/旁通/不安全泄放机油/热机开盖开塞冒充秩序齐，不是法外运维智慧**。医院/数据中心公开资料只作故事类比（§10），翻译成本网语言就是 BO-位 / BO-护 / BO-界 / BO-验 / BO-治。

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机房柴油发电机机油液位与机油压力/油温保护巡检准用」、对外宣传「看着有油/油尺看着有油/灯绿/表绿/口头加过机油秒过」、把未实测写成已过、把绕联锁/旁通/不安全泄放机油/热机开盖开塞写成秩序齐。允许做的：补机油液位台账、补保护窗、重开边界窗、挂 R/N/J、内部挂整改。

### 4.2 分诊题：这件事贴 BO 还是贴别的？

### 4.3 「机房柴油发电机机油液位与机油压力/油温保护巡检准用」最小集（BO）——缺页不能签准用

1. 机油液位台账页（机组·油尺或观察窗或油底壳·液位窗·本期对照；含看着有油/油尺看着有油≠台账过、口头加过机油≠方法过、液位过≠保护窗过勾选）  
2. 机油压力/油温保护侧主人与书面窗、方法、准用期页（两侧分开看；含禁灯绿、禁表绿、禁套邻站照片勾选）  
3. 书面边界窗与方法页（与 AF/BI/BL/AV/AR/AO/N 分工；以本网与 OEM 为准；声明不重写 AF/BI/BL/AV/AR/AO）  
4. 本期本组本机房实测记录（机油液位对照、油压侧、油温侧分别留痕；禁套声明）  
5. AF/BI/BL/AV/AR/AO 边界勾选（防顶替：油机市电/周检写到≠本篇台账，燃油油位/泄漏过≠机油液位/保护过，冷却液过≠机油过，燃油油品过≠机油过，燃油安全过≠机油过，漏水探头过≠窗过）  
6. AD/AN/AL/N/AA/AQ 与 AG/AP/BH/BK/BN 等边界勾选（入库≠本期窗；门禁/气灭过≠交底过；N 绿≠BO 过；各过≠BO 过）  
7. 会签页（准用或有条件整改）  
8. 未闭项清单（有则挂整改，重大未闭禁签准用）  
9. 脱敏勾选（L3）  
10. 变更指针（若本期有机组/油尺或观察窗或油底壳角色/液位或保护窗方法/门限变更 → J）  
11. 不适用声明（无柴油发电机，或无机油液位/机油压力/油温保护路径，书面勾选；不得顶 AF/BI/BL/AV/AR；一侧不适用 ≠ 另一侧自动免；AF/BI/BL 过了或它们不适用 ≠ 机油路径自动免）

> **口诀**：位、护、界、窗、房、测、签、闭、密、界——**十字机油钉**（教学记忆；现场以本网书面规程为准，但 **机油液位台账 + 机油压力/油温保护窗方法 + 边界方法 + 本组本机房本期实测 + 会签** 几乎不可砍）。

- [ ] 「看着有油≠台账过」「油尺看着有油≠台账过」「口头加过机油≠方法过」勾选

### 4.5 保护窗与边界清单（BO-护 / BO-界）

- [ ] 保护侧主人、书面窗、方法/准用期（本网与 OEM 书面）；油压侧、油温侧分开入账（或勾不适用）

### 5.2 对话脚本（教学）

**脚本A（看着有油 / 口头加过机油想签）**  
新人：「油尺看着有油，班长也说上个月加过机油，签准用吧。」  
班长：「BO1——机油液位台账和本期对照呢？看着有油、油尺看着有油≠台账过，口头说加过机油≠方法过。补账再谈会签。」

**脚本B（AF / BI 顶替）**  
外包：「AF 周检单上机油打了勾，BI 燃油油位泄漏签还在，机油和保护免了。」  
班长：「AF≠BO，BI≠BO。油机市电回AF，燃油油位/泄漏回BI；机油液位与保护主贴仍BO。周检写到机油≠本篇台账。柴油不是机油。顶替挂R。本篇不重写AF/BI全文。」

**脚本C（BL / AV / AR / AO / 灯绿表绿）**  
外包：「BL 冷却液刚过，AV、AR、AO 也过了，油压灯、油温灯都绿、表也在绿区，窗页免了。」  
班长：「BL≠BO，AV≠BO，AR≠BO，AO≠BO。缸套水不是机油；燃油油品过≠机油过；燃油安全过≠机油过；漏水探头过≠机油液位/保护过。灯绿、表绿≠窗过。补BO-护。本篇不重写BL/AV/AR/AO全文。」

**脚本D（油压顶油温 / 液位顶保护）**  
外包：「油压保护刚测过，油温这边照抄；液位都签过了，保护窗免了。」  
班长：「油压保护过≠油温保护过；液位过≠保护窗过。两侧各自实测，分账分验。一侧签过不能顶另一侧。」

**脚本E（泄放 / 热机开盖开塞 / 绕联锁 / 套票）**  
外包：「邻站机油液位保护表改个机房号交差。或者放一点机油告警就消，还烫着开盖开塞，保护先绕开。」  
班长：「BO-验拒签重测。禁套他站他期。禁不安全泄放机油教条，禁热机开盖开塞教条，禁旁通，禁绕联锁。挂N/R，禁签。液位过≠保护过。」

### 5.5 与弱项的现场对照（再钉一次）

机油乱账、保护乱窗、假绿、油压/油温告警风暴，常先伤站点保供电与**上行**体验——机组在最需要时因油压保护或油温保护停下来，站点环境先乱。有人把这些当「覆盖病」抬功率——**禁功率战**。机油/保护失序不是覆盖病。先问 BO 秩序并分诊 AF/BI/BL/AV/AR/AO，风暴挂 N，变更走 J。弱项短补：**12.5 kHz / 4FSK / 2-slot TDMA**。
