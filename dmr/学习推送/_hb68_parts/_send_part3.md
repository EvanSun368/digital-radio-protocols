## 6. 工作实例（12 则，教学虚构，L3）

1. **看着有油 / 油尺看着有油 / 口头加过机油想签准用**：称曲轴箱里看得见油、油尺有油、班长说加过机油要签 → 查 BO1 无本期机油液位对照 → **拒签**；补 BO-位。  
2. **油压灯绿 / 油温灯绿 / 表看着在绿区 / 套邻站保护照片**：称「灯是绿的 / 表在绿区 / 邻站照片差不多」免窗页 → **拒签**；补 BO-护。  
3. **AF 顶替 BO**：称油机市电切换刚过，或周检单上机油打了勾，本篇台账免 → **拒签**；**油机市电过 ≠ 机油液位/保护过**；**AF 周检写到机油 ≠ 本篇台账**。  
4. **BI 顶替 BO**：用燃油油位/泄漏签顶本期机油液位/保护签 → **挂 R**；**燃油油位/泄漏过 ≠ 机油液位/油压油温保护过**；柴油不是机油。  
5. **BL 顶替 BO**：称冷却液液位和高温低水位保护刚过，机油免做 → **挂 R**；**冷却液液位/保护过 ≠ 机油液位/油压油温保护过**；缸套水不是机油。  
6. **AV / AR 顶替 BO**：称燃油油品净化和加油交接刚过，或通风排烟燃油安全刚过，机油窗免 → **挂 R**；**燃油油品净化/加油过 ≠ 机油过**；**通风排烟燃油安全过 ≠ 机油液位/保护过**。  
7. **AO 顶替 / N 绿免实测**：称漏水探头绿或大屏监控绿，本期实测免 → **拒签**；漏水探头过 ≠ 机油液位/保护过；N绿≠BO过；补 BO-验。  
8. **油压顶油温 / 油温顶油压**：称油压保护测过了，油温照抄，或反之 → **拒签**；**油压保护过 ≠ 油温保护过**；两侧分开实测。  
9. **液位顶保护**：称机油液位签过了，保护窗免做 → **拒签**；**液位过 ≠ 保护窗过**。  
10. **套邻站表**：拷邻站机油液位/保护表改机房号 → **BO-验 拒签重测**。  
11. **功率战 / 不安全泄放机油 / 热机开盖开塞 / 绕联锁 / 旁通**：油压或油温告警要抬功率，或放一点机油消告警、还烫着拧加注口或滤清器或放油塞、绕保护、开旁通后要求准用 → **禁功率战**；**禁不安全泄放机油教条**；**禁热机开盖开塞教条**；**禁绕联锁**；**禁旁通**；先挂 N/R；缺秩序整改贴 BO；禁签。  
12. **无油机路径乱签 / 泄密**：本站无柴油发电机或无机油液位/机油压力/油温保护路径却不写「不适用」乱签准用，或公开群贴真实油机、发动机序列号与机油门限 → **拒签**并/或补书面不适用并/或 **L3 违规**；液位侧不适用 ≠ 保护侧自动免；油压窗不适用 ≠ 油温窗自动免；AF/BI/BL 过了或它们不适用 ≠ 机油路径自动免。
