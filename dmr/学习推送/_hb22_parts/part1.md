## 1. 为什么要写这篇手册（动机 + 现场对话）

前二十一篇手册把「家里怎么养」「邻居怎么处」「投诉怎么分诊」基本写全了：A–E 协议，F 射频指纹，G 实验室，H 话务，I 室分，J 写频，K 电源，L 井库，M 批量 / OTAP，N 监控对时，O 有源隔离，P 口部，Q 金机，R 假绿演练，S 邻频协调，T 干扰投诉分诊。可现场还有一类债——**证照与台账**：

- 写频岗：「这张写频单的频点，许可还在有效期内吗？」——**未对账**：写频文件 ≠ 许可，也 ≠ 执照。  
- 开站班长：「执照上周到期了，先开着，下周再续。」——**过期仍开站** = 本篇拒签（规则2、6）。  
- 项目经理：「站要先搬到新机房，证回头补。」——**先搬后补证** = 迁户口窗口没批就搬家（规则3）。  
- 合规岗：「台账缺功率上限和变更履历，先签『合规就绪』吧。」——**缺项禁签**（规则4）。  
- 领导：「批量 OTAP 赶工期，来不及对每台的许可覆盖。」——**写频/OTAP 前未对账**（规则5，挂 J / M）。  
- 邻网协调：「我们改了边界侧功率，忘了通知你们。」——**变更未通知邻居**（规则7，挂 S；若已投诉挂 T）。  
- 新人：「许可和执照不是一回事吗？」——**许可 ≠ 执照 ≠ 写频文件**（弱项短补）：房产证管「这块地能不能用、怎么用」；户口本管「这个户口落在哪、户主是谁」；写频文件只是「家里怎么排座位」。

这几句背后是同一件事：

> **「频率许可变更与台站执照台账」在现场至少有五个坑**：**① U-许** 许可仍有效、范围覆盖拟用频点/地域/用途/期限；**② U-照** 执照仍有效、台址/功率/天线/设备与执照载明一致；**③ U-账** 台账可对账（编号脱敏、台址脱敏、频点组脱敏、功率上限、有效期、变更履历）；**④ U-变** 变更走书面审批，禁私自挪频挪站扩功率；**⑤ U-治** 无证/过期/缺项拒签，到期预警与关停，跨网挂 S，公开仓 L3。  
> 把 ①–⑤ 当成「有写频文件就能开」「过期先用着」「先搬后补」「台账凑合签」，会把下一任、邻居和主管部门一起拖进泥潭。

本篇目标：能背出**频率许可与台站执照台账工作流**；会用新贴纸 **U（许 / 照 / 账 / 变 / 治）** 与五个子类；会填**插页 U（U1–U8）**和《本网频率许可与台站执照台账卡》；能用「**房产证 + 户口本 + 迁户口窗口**」故事讲清：先证覆盖再开站、禁先搬后补、台账可对账、变更窗口、拒签与预警；能拒绝「无证开站、过期先用、私自挪频、缺项签合规、公开泄密」；自测过关后，回库把本网最近一次开站/写频/变更（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：凡引法规均指向已公开发布的文书标题与官方链接（《中华人民共和国无线电管理条例》《无线电频率使用许可管理办法》《地面无线电台（站）管理规定》《无线电台执照管理规定》等），**数字、时限、程序以原文与属地最新要求为准，本篇只作教学转述，不发明条款号以外的「内部口径」**；**现象与台账一律用相对道号、角色标签、脱敏编号表述，禁真实频点 / 站名 / 单位名 / 许可或执照全文号 / 联系人 / 坐标**；**不教无证发射、私自挪频挪站、伪造涂改证件、规避监管**；J / M 仍管写频与批量边界，S 仍管邻频协调，T 仍管投诉进线后分诊——**证照与台账主贴 U**；外国 / ITU 资料只借**频谱管理与执照记录方法**，**许可与设台以国内法规与属地无线电管理机构为准**。

## 2. 总图 / 故事：许可与执照像「房产证 + 户口本 + 迁户口窗口」

### 2.1 一句话：频率许可像房产证/土地证（这块频谱怎么用、用多久），台站执照像户口本/营业执照（这个台落在哪、功率天线多少），变更像迁户口——先到窗口核准再搬家，禁先搬后补证；台账是家里的户口本复印件夹，缺页就不能对外说「我们合规就绪」

```text
   ┌──────────────────────────────────────────────────────────────────┐
   │   不动产登记中心 + 派出所户籍窗口（= 无线电管理机构）            │
   │                                                                  │
   │   房产证 / 土地证（U-许 · 频率使用许可）                          │
   │     用途 · 使用范围 · 期限 · 使用率要求 · 许可证事项             │
   │                                                                  │
   │   户口本 / 营业执照（U-照 · 无线电台执照）                        │
   │     台址或使用区域 · 频率 · 发射功率 · 占用带宽 · 设备核准 · 有效期 │
   │                                                                  │
   │   家里户口本夹（U-账 · 本网台账）                                 │
   │     许可编号(脱敏) · 执照编号(脱敏) · 台址脱敏 · 频点组脱敏     │
   │     功率上限 · 有效期 · 变更履历 —— 缺项禁签「合规就绪」         │
   │                                                                  │
   │   迁户口窗口（U-变）                                             │
   │     改频点 / 改台址 / 改功率 / 改天线 / 改用途 → 先书面变更审批  │
   │     ✗ 先搬家后补证 = 规则3                                       │
   │                                                                  │
   │   治理拒签（U-治）                                               │
   │     无证/过期禁开站 · 到期预警关停 · 跨网挂S · 公开仓 L3         │
   └──────────────────────────────────────────────────────────────────┘
```

口诀：

> **先证覆盖，再写频开站；先核准，再搬家。**  
> 无证 / 过期还开站 = 没房产证就对外出租——**拒签**。  
> 先搬后补证 = 迁户口没批就撕掉旧门牌——**违规**。

### 2.2 「房产证 + 户口本 + 迁户口」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **许可** | 房产证 / 土地证 | 频点、地域、用途、期限是否仍有效且覆盖拟用方案 | U-许 |
| **执照** | 户口本 / 营业执照 | 台址、功率、天线/设备、有效期是否与现场一致 | U-照 |
| **台账** | 家里户口本夹 + 变更页 | 编号脱敏、台址脱敏、频点组、功率上限、有效期、履历可对账 | U-账 |
| **变更** | 迁户口窗口 | 改频/址/功率/天线/用途 → 书面审批后再实施；禁私挪 | U-变 |
| **拒签治理** | 无证禁出租、过期禁营业 | 无证/过期/缺项拒签；到期预警；跨网通知；L3 | U-治 |

> 公开文书告诉我们：使用无线电频率通常应取得许可；设置、使用无线电台（站）通常应取得无线电台执照；许可证/执照载明事项变更应向作出许可决定的无线电管理机构办理变更；期限届满需继续使用的，应在届满前按规定时限提出延续申请（具体时限与材料以《无线电管理条例》《无线电频率使用许可管理办法》《地面无线电台（站）管理规定》等原文及属地要求为准）。本篇只借「先证后用、变更先批、台账可对」的顺序，**不编造内部时限数字以外已核原文的内容**。

### 2.3 和手册11 / 14 / 20 / 21 的咬合（指针，不重写）

- **手册11 J**：写频单、色码、时隙、密钥边界。本篇规定——**写频前强制核对台账 U**；许可/执照不覆盖 → **拒签写频**（规则5）。  
- **手册14 M**：大批量写频 / OTAP 风险边界。批量**不豁免**台账对账；错钥/脏库之外，再加「证照过期/缺项」拒签。

### 2.4 新贴纸 U：许 / 照 / 账 / 变 / 治（五个子类）

```text
                ┌──────────── 贴纸 U · 许/照/账/变/治 ────────────┐
                │  U-许  许可有效且覆盖：频点组·地域·用途·期限·使用率要求   │
                │  U-照  执照有效且一致：台址·功率·带宽·设备核准·有效期     │
                │  U-账  台账可对账：编号脱敏·台址脱敏·频点组·上限·履历     │
                │  U-变  变更书面审批：频/址/功率/天线/用途；禁先搬后补     │
                │  U-治  拒签治理：无证过期禁开·预警关停·挂S·L3           │
                └──────────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签 / 拒放行触发 |
|------|--------|----------------------|
| **U-许** | 许可过期、范围不覆盖拟用频点/地域/用途 → 禁写频开站 | 「许可快到期了，先开」 |
| **U-照** | 执照过期、台址/功率与执照不一致 → 禁开站扩功率 | 「执照回头补，站先上」 |
| **U-账** | 台账缺编号脱敏、有效期、功率上限或变更履历 → 禁签合规就绪 | 「字段以后补，先签字」 |
| **U-变** | 未书面变更审批就挪频/挪站/抬功率 → 拒签变更放行 | 「先搬后补证」 |
| **U-治** | 无证开站、过期继续、公开泄密、跨网不通知 → 治理 | 「先用着再说」「公开贴全文号」 |

### 2.5 频率许可与台站执照台账最小工作流（背下来）

```text
  拟写频 / 开站 / 扩功率 / 挪频 / 挪站 / OTAP / 变更
        │
        ▼
  许可仍有效？范围覆盖拟用频点·地域·用途？（U-许）
        │否──▶ 拒签；走延续/变更/新许可路径（规则1、2）
        │是
        ▼
  执照仍有效？台址·功率·天线/设备与执照一致？（U-照）
        │否──▶ 拒签开站/扩功率；走延续/变更（规则1、2）
        │是
        ▼
  台账可对账？（编号脱敏·台址脱敏·频点组·功率上限·有效期·履历）
        │否──▶ 禁签「合规就绪」（U-账 / 规则4）
        │是
        ▼
  是否变更事项？（频点/台址/功率/天线/用途）
        │是──▶ 书面变更审批完成？──否──▶ 禁实施（U-变 / 规则3）
        │         │是
        │         ▼
        │      影响边界/邻居？──是──▶ 先通知挂 S，后复测（规则7）
        │
        ▼
  写频 / OTAP / 开站前再次核对台账（规则5，挂 J / M，主贴 U）
        │
        ▼
  有效期预警：到期前 N 天（本网制度）预警；过期未续 → 降级/关停路径（规则6）
  结案词用 U 子类；公开包 L3（规则8）
```

现场口诀：

> **先证覆盖，再写频开站；先核准，再搬家。**  
> 跳过台账对账的「开站工单」= 没查房产证就对外签约。

## 3. 核心交付：插页 U + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 U（而不是先贴 J / M / S / T）

| 现场信号 | 主贴 | 可次挂 |
|----------|------|--------|
| 写频 / OTAP / 开站前核证照 | **U**（先对账） | J / M |
| 许可或执照临期 / 过期 | **U-治** | — |
| 拟改频点 / 台址 / 功率 / 天线 / 用途 | **U-变** | S（边界）、J（写频） |
| 台账缺项仍要签「合规就绪」 | **U-账** | — |
| 变更影响邻居 / 边界 | **U-变** + 挂 **S** | T（若已投诉） |
| 投诉进线（已是事后） | **T**（不是 U） | 可查 U 作内因 |
| 仅写频参数对错、证照已齐 | **J**（证照段已由 U 放行） | U 存档指针 |

> **口诀**：写什么进终端 → **J / M**；邻居与联测 → **S**；投诉分诊 → **T**；**证还有效吗、账对得上吗、变更批了吗 → U**。可叠挂，**证照与台账主贴 U**。

### 3.2 插页 U · 许 / 照 / 账 / 变 / 治（挂在总三联单或开站/写频单后）

| 行 | 名称 | 填写示例（教学虚构，L3） |
|----|------|--------------------------|
| **U1** | 主子类 + 次子类 | 「主 U-许 / 次 U-账」（或 U-照 / U-变 / U-治） |
| **U2** | 许可五组核对 | 「有效期内 · 频点组覆盖（相对道号）· 地域覆盖 · 用途一致 · 期限/使用率要求已读」——禁写真实频点与全文号 |
| **U3** | 执照字段核对 | 「有效期内 · 台址脱敏编号一致 · 功率≤执照上限 · 带宽/设备核准代码角色一致」 |
| **U4** | 台账对账勾选 | 「□许可编号(脱敏) □执照编号(脱敏) □台址脱敏 □频点组脱敏 □功率上限 □有效期 □变更履历」 |
| **U5** | 变更事项与审批 | 「无变更 / 有变更：事项=功率上限调整；审批回执角色编号；实施日≥核准日」 |
| **U6** | 邻居与复测 | 「不影响边界 / 已挂 S 通知+复测窗」——未通知禁宣称变更完成（规则7） |
| **U7** | 动作与禁令 | 「已冻结无证开站工单；已启动续期；拒签 OTAP 全量」 |
| **U8** | 预警与脱敏 | 「到期前 N 天预警已触发；公开包 L3；全文号仅存受控柜」 |

> **U2 / U3 任一否 → 禁止写频开站扩功率挪频（规则1、2）。**  
> **U4 缺任一项 → 禁签「合规就绪」（规则4）。**  
> **U5 有变更但无审批 → 禁实施（规则3）。**  
> **U6 影响边界但未通知 → 本页作废重填（规则7）。**  
> **U7 若写「先开着再说」「先搬后补」→ 本页作废（规则2、3、6）。**

### 3.3 「无证/过期/缺项拒签」卡（贴值班台 / 写频室 / 开站班）

```text
  ┌────────── 频率许可与台站执照台账拒签卡（贴纸 U）──────────┐
  │  × 许可过期或不覆盖拟用频点/地域/用途仍写频开站            │
  │  × 执照过期或台址/功率与执照不一致仍开站扩功率            │
  │  × 未书面变更审批就挪频 / 挪站 / 抬功率 / 改天线 / 改用途  │
  │  × 台账缺编号脱敏、有效期、功率上限或变更履历仍签合规就绪  │
  │  × 写频 / OTAP / 开站前未核对台账（J/M 不豁免）            │
  │  × 过期未续仍「先用着再说」——无降级/关停路径               │
  │  × 边界侧变更不通知邻居、不复测（应挂 S）                  │
  │  × 公开包出现真实频点 / 站名 / 单位名 / 许可执照全文号 / 坐标 / 联系人 │
  │  √ 例外：主管部门书面调取原件——走法定程序，另册登记        │
  └────────────────────────────────────────────────────────────┘
```

### 3.4 和总三联单怎么写（接手册06）

- **现象**：写「拟开站 / 拟写频 / 拟变更 + U 子类」，**未对账前不写「合规就绪」**。  
- **证据**：许可有效期角色、执照有效期角色、台账勾选、变更审批回执角色、邻居通知（若有）；全部 L3。  
- **结论**：用 U 子类 + 放行/拒签；次挂 J/M/S/T 时写清主贴仍是 U。  
- **动作**：续期、变更申请、冻结工单、预警、关停路径——**禁止**写「先开后补」。
