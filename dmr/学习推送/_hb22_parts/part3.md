## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 一句话 |
|------|--------|
| **频率使用许可** | 依法取得的频谱使用权凭证（教学喻：房产证） |
| **无线电台执照** | 合法设置、使用无线电台（站）的凭证（教学喻：户口本） |
| **台账** | 本网对许可/执照关键字段的可对账登记（脱敏） |
| **载明事项** | 证照上写明的频率、台址、功率、期限等 |
| **变更** | 改载明事项，须向原许可/发证路径办理 |
| **延续** | 期限届满前申请继续使用 |
| **注销 / 停用** | 终止使用并按规定交回执照、拆除等（以原文为准） |
| **覆盖** | 拟用方案落在许可/执照允许范围内 |
| **脱敏编号** | 公开与教学用的替代编号，非全文号 |
| **功率上限** | 执照载明发射功率不得突破（变更前） |
| **型号核准** | 发射设备依法核准（代码角色入台账） |
| **临时设台** | 法规允许的紧急/重大活动路径，≠ 永久无证 |
| **预警窗** | 到期前 N 天的本网提醒与冻结策略 |
| **关停路径** | 过期未续时的降级/停发审批流程 |
| **合规就绪** | 台账可对账且证照覆盖后的签字状态 |
| **主贴 U** | 证照台账问题以 U 为主键，可挂 J/M/S/T |
| **L3** | 公开包最高脱敏等级（本系列约定） |
| **书面审批** | 变更/延续等以管理机构核准为准，聊天记录不算 |

**易错观念**

1. ✗ 有写频文件 = 已许可已设台合法 → ✓ 许可、执照、写频三层。  
2. ✗ 许可有效 = 每个中继都有执照 → ✓ 设台通常另需执照。  
3. ✗ 过期三天没事 → ✓ 过期即拒签开站扩功率挪频。  
4. ✗ 先搬后补是行业惯例 → ✓ 本篇红线。  
5. ✗ 台账是给审计看的形式主义 → ✓ 台账是放行闸刀。  
6. ✗ 降功率不用通知邻居 → ✓ 边界变更仍挂 S。  
7. ✗ 公开培训可以贴全文号方便对账 → ✓ 全文号受控，公开 L3。  
8. ✗ OTAP 成功代替合规 → ✓ OTAP 不创造许可与执照。

## 9. 自测（12 题）+ 参考答案

1. 贴纸 U 五个子类是什么？各用四个字以内说明。  
2. 「房产证 / 户口本 / 迁户口」分别对应许可、执照、变更中的哪一段直觉？  
3. 八条硬规则里，哪一条直接禁止「先搬后补证」？  
4. 许可五组核对题列出至少四组。  
5. 执照字段最小集为什么必须包含功率上限？  
6. 台账七勾选缺「变更履历」能否签合规就绪？为什么？  
7. 写频前为什么要主贴 U 而不是只贴 J？  
8. 批量 OTAP 能否以「批次对过一次」代替每台对账？本篇教学立场是什么？  
9. 边界侧功率变更后，只做 U 变更核准、不挂 S，违反哪条规则？  
10. 到期预警的 N 必须是全国统一数字吗？本篇考什么？  
11. 公开包能否出现执照全文号？  
12. 用户投诉「干扰」时，主贴应是 T 还是 U？U 还能干什么？

### 参考答案

1. 许/照/账/变/治：许可覆盖、执照一致、台账可对、变更审批、拒签治理。  
2. 房产证→许可；户口本→执照；迁户口窗口→变更。  
3. 规则3（及 U-变）。  
4. 有效期、频点组覆盖、地域、用途（+其他载明事项）。  
5. 防止现场超执照发射；扩功率须先变更。  
6. 不能；规则4 缺项禁签。  
7. J 管参数怎么写；U 管有没有资格写；主贴 U 再挂 J。  
8. 教学从严：不豁免；试点也要对账；同执照合并须制度明文。  
9. 规则7。  
10. 不必统一；考「有预警+有关停路径+有主人」。  
11. 不能；规则8，全文号受控另册。  
12. 主贴 T；U 可作内因勾选（证照是否过期/是否越界发射等）。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **U** 五子类：许 / 照 / 账 / 变 / 治。  
- 故事：房产证 + 户口本 + 迁户口窗口。  
- 八条硬规则：**先证覆盖再写频开站**；**无证/过期拒签**；**变更书面审批禁私挪**；**台账缺项禁签合规**；**写频/OTAP前强制对账**；**到期预警与关停**；**跨网变更挂 S**；**脱敏 L3**。  
- 与 J/M/S/T 分工：J/M=怎么改参数；S=邻居联测；T=投诉分诊；**U=有没有资格改、账对不对**。

### 11.2 回库路径
现场「要写频 / 开站 / 变更」→ 本篇（贴纸 U + 插页 U + 台账卡）→ 许可五组 + 执照字段 + 七勾选 → 有变更走窗口 → 影响边界挂 S → 再放行 J/M；过期走预警关停；公开 L3。

### 11.3 下一篇手册候选（本篇不写正文）
- **重大保障临时频率与联测窗**（临时设台、保障期与 S/T/U 衔接）  
- **非法设台与黑广播类线索内部上报边界**（只讲依法报告与证据保全，不讲排查对抗细节）  
- （可选）**电磁环境测试与验收报告台账**（开站前电磁环境与执照申请材料咬合）

### 11.4 给带新人的三句话
1. 写频开站前先问：许可和执照还盖得住今晚要做的事吗？  
2. 搬家（改频改址改功率）先去窗口，不要先搬后补证。  
3. 台账缺页就不能签「合规就绪」；全文号不许进公开包。
