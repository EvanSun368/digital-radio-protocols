## 4. 深潜：八条硬规则 + 许可五组核对 + 执照字段 + 台账节奏 + 变更窗口

### 4.1 八条硬规则（本篇钉子）

1. **先证许可与执照仍有效、范围覆盖拟用频点/台址/功率/天线，再谈写频开站**——覆盖未证，射频与写频工单冻结。  
2. **无有效许可/执照或过期 → 禁开新站 / 禁扩功率 / 禁挪频（拒签）**——「先用着再说」不是出口。  
3. **变更（频点/台址/功率/天线/用途）必须走书面变更审批，禁私自挪频挪站**——与手册20 S「禁私自挪频」咬合；先搬后补证 = 红线。  
4. **台账必须可对账：许可编号(脱敏)、执照编号(脱敏)、台址脱敏编号、频点组脱敏、功率上限、有效期、变更履历——缺项禁签「合规就绪」**。  
5. **写频 / OTAP / 开站前强制核对台账**（挂手册11 J / 14 M，**主贴 U**）——批量不豁免。  
6. **过期预警制度：到期前 N 天预警（N 由本网制度规定）；过期未续 → 降级/关停路径，禁「先用着再说」**——教学不规定唯一 N，但必须有预警与关停动作主人。  
7. **跨网/边界协调变更先通知邻居后复测（挂 S）；投诉类挂 T；禁功率战**——变更完成 ≠ 邻居已知。  
8. **脱敏 L3：公开包禁真实频点、站名、单位名、许可/执照全文号、坐标、联系人**——原件受控另册。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：《无线电管理条例》明确使用频率通常应取得许可、设台通常应取得无线电台执照，并规定许可/执照期限与延续申请时限等；《无线电频率使用许可管理办法》明确不得擅自扩大使用范围或改变用途，拟变更许可证载明事项应提出申请，期限届满需继续使用应按规定时限申请延续；《地面无线电台（站）管理规定》明确执照应载明台址或使用区域、频率、发射功率、占用带宽、设备型号核准代码、有效期等，变更载明事项应办理变更，延续应在届满前按规定时限申请。**这些是主管部门的许可与设台规则，不是你方「先开后补」或「台账缺项也签字」的借口。**

### 4.2 许可五组核对题（U-许）——房产证必问

```text
  ① 有效期
     是否在有效期内？距到期是否已进入本网预警窗（N 天）？
     → 临期：启动延续；过期：拒签开站/写频，走关停或续期完成后再议

  ② 频点组覆盖
     拟用相对道号是否落在许可载明范围内？（教学用相对道号，禁真实频点）
     → 不覆盖：变更或新许可，禁私自挪到「旁边道」

  ③ 地域 / 使用范围
     拟设台址或使用区域是否在许可使用范围内？
     → 超范围：变更，禁「先搬到范围外再说」

  ④ 用途
     业务用途是否与许可一致？（专网语音/数据等角色标签）
     → 改用途：变更审批，禁擅自改用途

  ⑤ 其他载明事项
     使用率要求、特别规定事项等是否已读并落入台账备注？
     → 未读：补读；与现场冲突：升级合规岗，禁假装没看见
```

**许可未过五组题的冻结清单**：写频、OTAP、开新站、扩功率、私自挪频。允许做的：台账核对、起草延续/变更材料（L3）、约主管部门窗口、挂 S 预通知（若变更可能影响邻居）。

### 4.3 执照字段最小集（U-照）——户口本必核

| 序号 | 最小集项（教学） | 为什么必须有 | 缺了 / 不一致会怎样 |
|------|------------------|--------------|---------------------|
| 1 | **有效期** | 过期执照不能当「合法设台」凭证 | 拒签开站；走延续或关停 |
| 2 | **台址或使用区域**（脱敏编号） | 执照落点与现场一致 | 「人户分离」——先变更 |
| 3 | **使用频率**（相对道号 / 频点组脱敏） | 与许可及写频一致 | 写频拒签 |
| 4 | **发射功率上限** | 现场功率不得超过执照载明 | 扩功率拒签；先变更 |
| 5 | **占用带宽** | 与信道规划 / 设备一致 | 异常则冻结 |
| 6 | **设备型号核准代码**（角色） | 发射设备依法核准 | 未核准设备禁开站叙事 |
| 7 | **执照编号**（台账仅存脱敏） | 对账索引 | 缺编号 → 台账不可对 |

> **口诀**：期、址、频、功、宽、核、号——**七字最小集**。教学记忆用；现场以执照样式与属地要求为准，但 **有效期、台址、频率、功率** 几乎不可砍。

### 4.4 台账对账节奏（U-账）

```text
  日常（每次写频 / OTAP / 开站工单）
        → U4 七勾选全绿才放行（规则5）

  周期（本网制度：如每月 / 每季）
        → 全量有效期扫描；临期清单；变更履历抽查

  变更后 24h 内（教学建议节奏，可按本网压缩/拉长）
        → 回写履历；若影响边界 → S 通知与复测记录挂接

  交班
        → 口述「临期条数 + 冻结工单 + 在途变更」
```

**缺项典型姿势（全部禁签「合规就绪」）**：

- 只有写频文件，没有许可/执照有效期字段；  
- 有全文号贴在公开周报（L3 违规）；  
- 功率上限空白，现场「凭经验拧」；  
- 变更履历只有微信聊天记录、无审批回执角色；  
- 台址变更了，台账还是旧脱敏编号。

### 4.5 变更窗口标准节奏（U-变）——迁户口怎么办

| 步 | 动作 | 拒签点 |
|----|------|--------|
| 1 | 明确变更事项（频/址/功率/天线/用途） | 「先改现场再想事项」 |
| 2 | 核对现许可/执照是否允许该方向；起草变更申请（材料以官方要求为准） | 材料造假（红线） |
| 3 | 提交作出许可决定的无线电管理机构；取得变更核准/新执照 | 未核准就实施 |
| 4 | 若影响邻居/边界：书面通知 + 挂 S；约定复测窗 | 只改不通知 |
| 5 | 核准后实施：写频/调功率/搬站；金机复核（Q）；台账回写履历 | 实施日早于核准日 |
| 6 | 复测与结案：U8 +（若有）S 联测记录；公开包 L3 | 未复测宣称「已消除影响」 |

与手册20 四态联测交接：边界侧功率/频点变更后，**U 放行实施 ≠ S 验收完成**；两边单据互挂编号（脱敏）。

### 4.6 弱项短补：许可 ≠ 执照 ≠ 写频文件

```text
   许可（房产证）     执照（户口本）      写频文件（家里排座位表）
   ─────────────     ─────────────      ─────────────────────
   频谱怎么用         这个台能不能设      终端/中继里写什么参数
   用途·范围·期限     台址·功率·设备      信道·色码·时隙·密钥…
   变更找许可窗口     变更找执照窗口      变更前必须先有前两者覆盖

   ✗ 「写频文件在，就能开站」
   ✗ 「有许可就等于每台都有执照」
   ✗ 「执照在，就能随便改功率到许可上限以外」
   ✗ 「OTAP 成功 = 合规」（OTAP 只改终端，不创造许可）
```

所以规则5才硬：**写频 / OTAP / 开站前强制对账 U**——J 和 M 管「怎么改参数的风险」，U 管「改这些参数的资格还在不在」。

### 4.7 与主管部门路径怎么衔接（只讲合规路径，不教规避）

教学流程（细节以属地最新要求与官方受理材料为准）：

1. **自查台账**：U2–U4 勾选；临期清单；现场与执照一致性抽测。  
2. **延续**：期限届满需继续使用 → 在届满前按规定时限向作出许可决定的机构提出延续申请（条例与办法对频率许可、地面规定对执照均有「届满前申请延续」的要求，**具体工作日数以原文为准**）。  
3. **变更**：拟变更许可证或执照载明事项 → 向作出许可决定的机构申请变更；核准前禁实施。  
4. **新设台 / 新许可**：按条例与《地面无线电台（站）管理规定》等提交材料（含频率许可证明、设备核准、技术方案等——**以官方清单为准，本篇不编造表格字段**）。  
5. **临时设台**：法规对紧急情况或重大活动临时设台有专门路径与事后报告要求——**下一篇候选「重大保障临时频率与联测窗」展开；本篇只提醒：临时不是「无证永久」**。  
6. **配合检查**：按管理机构要求提供维护记录、接受检查检测；公开宣传稿仍 L3。  
7. **结果归档**：回执、新证照与台账 U8 对齐；全文号受控，公开仓脱敏。

**明确不教**：如何无证发射、如何伪造涂改证件、如何规避监测与检查、如何「先开后补」话术过关。

### 4.8 到期预警与关停路径（U-治 / 规则6）

| 阶段 | 教学动作 | 禁令 |
|------|----------|------|
| 预警窗（到期前 N 天） | 台账标黄；通知合规主人；启动延续材料 | 禁新开站、禁扩容叙事 |
| 临期未交材料 | 升级领导；冻结相关写频/OTAP | 禁「再拖一周」 |
| 过期日 | 降级或关停路径启动（本网制度写清主人与签字） | 禁「先用着再说」 |
| 续期完成 | 台账回写新有效期；解除冻结 | 公开包仍 L3 |

N 的数值由本网制度规定（可与财务缴费、合同、维保窗口对齐）；**本篇考核的是「有预警 + 有关停路径 + 有主人」**，不是某一个万能天数。

### 4.9 开站 / 写频前 15 分钟对账清单（可复印）

| 分钟 | 动作 |
|------|------|
| 0–3 | 打开台账卡：目标台址脱敏编号、拟用相对道号 |
| 3–7 | U2 许可五组题；U3 执照七字段 |
| 7–10 | U4 七勾选；缺项 → 拒签并开缺陷单 |
| 10–13 | 若有变更：U5 审批回执；U6 邻居通知 |
| 13–15 | 放行签字（角色）或拒签；交班口述 |

夜班压缩版：至少完成「有效期 + 频点组覆盖 + 功率上限 + 台址一致」四项，其余次日补全勾选——**四项缺一仍拒签**。

### 4.10 与 J / M 单据互挂（U → 写频 / OTAP）

```text
  写频单 / OTAP 批次单（J / M）
        │
        ├── 必填：台账卡编号（脱敏）· U 放行角色 · 放行时刻
        ├── 禁填：许可/执照全文号、真实频点、真实站名
        └── 若 U 拒签 → J/M 单状态=冻结，原因=U子类
```

批量 OTAP：按手册14「先试点后全量」；试点名单中的每一台也必须能追溯到 U4 勾选——**「批次已对过一次」不能代替「每台可对账」**（教学从严；本网若有「同执照批量终端」合并规则，须写进制度并仍保留有效期与功率上限核对）。

## 5. 现场映射：原话 → U 子类；对话脚本；夜班；禁写词

### 5.1 原话速查表

| 原话 | 主贴 | 动作 |
|------|------|------|
| 「许可还有效吗？覆盖这个道吗？」 | U-许 | 五组核对 |
| 「执照过期了，先开着」 | U-治 | 拒签；续期或关停 |
| 「站先搬，证后补」 | U-变 | 拒签；先变更审批 |
| 「台账缺功率上限，先签合规」 | U-账 | 拒签合规就绪 |
| 「OTAP 赶工期，来不及对账」 | U + M | 拒签全量；可试点且试点也要对账 |
| 「改了边界功率，邻居不知道」 | U-变 + S | 补通知+复测；禁功率战 |
| 「用户投诉干扰」 | T | 本篇只提供证照内因勾选 |
| 「写频色码错了」 | J | 证照段已由 U 放行后再查 J |

### 5.2 对话脚本（五则）

**脚本1 · 过期先开**  
对方：「执照刚过期三天，业务不能停，先开。」  
你：「规则2：过期禁开新站扩功率挪频。现在走续期加急 + 降级/关停路径；不是先开后补。主贴 U-治。」

**脚本2 · 先搬后补**  
对方：「机房合同到期，今晚必须搬站，变更下周再办。」  
你：「规则3：变更先书面审批。今晚能搬的前提是变更已核准；否则拒签搬站工单。主贴 U-变。」

**脚本3 · 台账缺项签字**  
对方：「审计要『合规就绪』，字段回头补。」  
你：「规则4：缺项禁签。今晚补 U4 七勾选，补不齐就签『台账缺陷、未就绪』。主贴 U-账。」

**脚本4 · 批量 OTAP**  
对方：「200 台一起 OTAP，没法一台一台对许可。」  
你：「规则5：写频/OTAP 前强制对账，批量不豁免。按执照分组对账 + 手册14 试点；对不上的剔出批次。主贴 U，挂 M。」

**脚本5 · 变更不通知邻居**  
对方：「我们降了边界功率，对邻居是好事，不用打招呼。」  
你：「规则7：边界变更先通知后复测，挂 S。降功率也可能改覆盖与投诉归因；补通知。主贴 U-变。」

### 5.3 夜班 15 分钟怎么用

1. 扫台账临期清单（黄灯条数）。  
2. 查在途变更：有无「未核准已实施」。  
3. 查冻结写频/OTAP 单是否仍被绕过。  
4. 交班口述：临期、在途变更、冻结原因（U 子类）。

### 5.4 「证照三问」（贴写频室 / 开站班）

```text
  1. 许可和执照还在有效期内吗？覆盖今晚要做的事吗？
  2. 台账 U4 七勾选全了吗？
  3. 有变更吗？核准了吗？邻居要不要挂 S？
```

### 5.5 现象栏禁写词与可写词（贴值班台）

| 禁写 | 可写（L3） |
|------|------------|
| 真实频点、全文许可/执照号 | 相对道号、脱敏编号 |
| 「先开后补」「先用着再说」 | 「U 拒签：过期/缺项/未核准变更」 |
| 「合法规避一下」 | 「走延续/变更窗口」 |
| 真实站名、单位名、坐标、联系人 | 台址脱敏编号、角色标签 |
| 「邻居爱咋咋地」 | 「已/未挂 S 通知与复测」 |

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「写频单在，许可已过期」→ U-许 / U-治

现象：写频岗按旧文件写相对道号组 A，台账显示许可过期。  
处置：拒签写频；冻结 OTAP；启动延续；主贴 U-许。  
结案词：「U-治：许可过期未续，禁写频开站。」

### 例 2 · 「执照台址与机房不一致」→ U-照 / U-变

现象：现场已迁到新机房角色 B，执照仍为台址脱敏编号 A。  
处置：拒签「开站完成」；走台址变更；核准前禁对外宣称合法设台完成。  
结案词：「U-变：台址变更未核准，禁先搬后补叙事。」

### 例 3 · 「台账缺变更履历仍签合规」→ U-账

现象：审计要签字，功率去年抬过，履历空白。  
处置：拒签合规就绪；补审批回执角色或启动补正路径；公开包不得出现全文号。  
结案词：「U-账：履历缺项，禁签合规就绪。」

### 例 4 · 「先抬功率顶覆盖」→ U-变 + 禁功率战

现象：覆盖投诉，班长欲超执照上限抬功率。  
处置：若未超上限但仍属变更载明功率，走变更；若超上限，拒签；覆盖类先挂 T 分诊 / F / Q，禁功率战。  
结案词：「U-变拒签超执照功率；投诉转 T。」

### 例 5 · 「OTAP 全网赶工期」→ U + M

现象：重大活动前全量 OTAP，未做 U4。  
处置：按手册14 试点；试点台必须 U4 全绿；未对账台剔出；主贴 U 挂 M。  
结案词：「U+M：批量不豁免台账对账。」

### 例 6 · 「边界改频未通知邻居」→ U-变 + S

现象：本网边界相对道号组调整已实施，邻网次日投诉。  
处置：主贴 T 分诊；并行查 U——变更审批有无、S 通知有无；补通知与复测；禁报复抬功率。  
结案词：「U-变缺陷致投诉；挂 S/T；规则7。」

### 例 7 · 「临期无预警」→ U-治

现象：到期前一日才发现，延续材料未交。  
处置：标红；冻结新开站；紧急延续；复盘预警制度（N 天与主人）。  
结案词：「U-治：预警失效，已补路径。」

### 例 8 · 「公开周报贴出执照全文号」→ U-治 / L3

现象：宣传稿含真实站名与执照全文号。  
处置：下架；改 L3；原件受控；培训规则8。  
结案词：「U-治：L3 违规已纠正。」

### 例 9 · 「有许可无执照开中继」→ U-照

现象：频率许可有效，中继站未取照即发射。  
处置：立即停发路径（本网审批）；补执照申请；不教「躲监测」。  
结案词：「U-照：无执照禁设台发射。」

### 例 10 · 「变更核准后未回写台账」→ U-账

现象：变更已核准并实施，台账有效期/功率上限仍旧值，次日写频按旧上限拒签争议。  
处置：24h 内回写履历；对账节奏写入交班；放行争议以台账+回执为准。  
结案词：「U-账：变更后未回写，对账节奏失效。」
