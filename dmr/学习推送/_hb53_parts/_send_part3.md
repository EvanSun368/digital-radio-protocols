## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 本篇用法（教学） |
|------|------------------|
| **AZ** | 本篇贴纸：冷通道封闭·机柜进出风交底 |
| **AZ-封** | 冷/热通道封闭台账子类 |
| **AZ-进** | 机柜进风窗方法子类 |
| **AZ-出** | 机柜出风/热通道窗方法子类 |
| **AZ-验** | 本期实测与会签子类 |
| **AZ-治** | 假绿/顶替/拆盲板/堵进出风/功率战/泄密治理 |
| **封闭台账** | 门/顶/侧封·盲板·地板开孔密封入账（脱敏） |
| **进风窗** | 有主有窗有方法有准用期；禁回风绿当进风过；禁空U无盲板 |
| **出风窗** | 出风路径·热通道回风与 AU/AI/AY/AO 分工书面方法 |
| **盲板（Blanking panel）** | 空U位封闭件；缺盲板=冷热短路常见口 |
| **冷通道 / 热通道** | 机柜进风侧 / 出风侧通道角色（故事类比；以本网书面为准） |
| **回风绿** | 回风侧指示绿≠进风准用 |
| **假绿** | 门关绿/监控绿冒充准用 → 挂 R |
| **套票** | 套他站他期热力图/进出风照片 |
| **L3** | 脱敏等级：禁真实站名/全称/通道号/联系人等 |
| **N** | 告警风暴贴纸；N 绿≠AZ 过 |
| **J** | 变更贴纸；策略/门限变更走 J |
| **R** | 假绿贴纸 |

**易错观念**

1. 「通道门关着 = 可以签准用」——错；要有封闭台账与本期进出风实测。  
2. 「回风绿 = 进风过」——错；要有书面进风窗与方法、本期核对、空U盲板。  
3. 「口头说封好了 = 方法过」——错；要有书面封闭台账与方法。  
4. 「AU/AI/AY/AO/AN/N/AX 过 = AZ 过」——错；各钉各的，禁顶替。  
5. 「告警多就抬功率 / 拆盲板 / 堵进出风」——错且危险；禁功率战、禁拆盲板冒充、禁堵进出风。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AZ** 五子类：封 / 进 / 出 / 验 / 治——双字母续写的第二十六张，负责机房冷通道封闭与机柜进出风「台账清不清、进风有没有窗、出风有没有法、本期过了没有」。  
- 口诀：**封闭有账，进风有窗，出风有法，会签才放。**  
- 故事：医院手术室/ICU 或药房冷链/洁净走廊不混风 + 设备吸冷排热不能短路（或数据中心冷热通道封闭）——通道门关着≠准用；回风绿≠进风过；口头说封好了≠方法过；空U无盲板≠封闭过。  
- 八条硬规则：**冷/热通道封闭台账钉死**；**机柜进风有主有窗有方法/准用期**；**机柜出风/热通道窗与方法钉死**；**本组本机房本期实测禁套他站他期**；**会签才放行「机房冷通道封闭与机柜进出风准用」**；**禁顶替 AU/AI/AY/AO/AN/AA/N/AQ/AT/AX/AF/AS/AD/AV/AR/AG/AP/AW 等，主贴 AZ，假绿≠放行挂 R**；**封闭/进出风异常风暴挂 N、封闭策略/进风出风门限变更走 J、禁功率战、禁拆盲板/拆封闭冒充、禁堵进出风、禁伪造台账、禁绕过冷通道门禁/联锁**；**脱敏 L3**。  
- **AZ 不替代 AU，也不替代 AI，也不替代 AY，也不替代 AO，也不替代 AN**：AU=滤网压差气流；AI=温湿度联锁巡检；AY=新风正压防火阀；AO=漏水汇排；AN=门禁访客；AZ=冷通道封闭与机柜进出风交底准用。
