# 手册 53 · 运维制度：机房冷通道封闭与机柜进出风交底台账（续送）

> **贴纸 AZ · 封/进/出/验/治** · 口诀：**封闭有账，进风有窗，出风有法，会签才放。** · 教学用 · L3 · **不是第 53 课**  
> 接上文；禁拆盲板冒充、禁堵进出风、禁功率战、禁假绿顶替；主贴 AZ ≠ AU/AI/AY/AO/AN/N。

## 3. 核心交付：插页 AZ + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AZ（而不是先贴 AU / AI / AY / AO / AN / N / AX）

- 要签「机房冷通道封闭与机柜进出风准用」、要开封闭/进风/出风窗、要交底冷通道与机柜进出风边界 → **主贴 AZ**。  
- 滤网压差与气流组织本身 → **AU**（手册48）；冷通道封闭/进出风本体窗仍 AZ。  
- 温湿度测点/门限/联锁巡检本身 → **AI**；进出风本体窗仍 AZ。  
- 新风正压与防火阀本身 → **AY**；冷通道封闭仍 AZ。  
- 漏水与汇流排本身 → **AO**；进出风路径交底仍 AZ。  
- 进机房做交底 → 先 **AN**；门禁过≠冷通道交底过；**不教绕过冷通道门禁/联锁**。  
- 精密空调压缩机与制冷剂 → **AX**；AX 过≠ AZ 过。  
- 封闭/进出风告警风暴 → 先 **N** 理风暴；缺封闭/进出风秩序整改仍 **AZ**；**禁功率战**；**禁拆盲板冒充**；**禁堵进出风**。  
- 假绿/顶替 → 挂 **R**；变更封闭策略/进风出风门限 → 走 **J** 后再验 AZ。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **冷/热通道封闭台账钉死**：机房角色、门/端门 / 顶封与侧封 / 盲板空U / 地板开孔密封角色入账；禁「通道门关着就算过」「口头说封好了」。  
2. **机柜进风有主有窗有方法/准用期**：每次进风相关维护有主人角色、有书面窗、有方法、有准用期；禁「回风绿当进风过」；**禁空U不装盲板冒充**。  
3. **机柜出风/热通道窗与方法钉死**：书面固定；方法含出风路径·热通道回风交界核对、与 AU/AI/AY/AO 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明逐步拆封闭/堵进出风操作教条）；禁「窗再说」「出风随便堵」「热通道门常开冒充巡检方便」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、热力图、进出风照片必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「机房冷通道封闭与机柜进出风准用」；假绿 ≠ 放行。  
6. **禁顶替 AU/AI/AY/AO/AN/AA/N/AQ/AT/AX/AF/AS/AD/AV/AR/AG/AP/AW，主贴 AZ，假绿≠放行挂 R**：滤网压差气流签、温湿度签、新风正压防火阀签、漏水签、门禁签、首年签、监控签、视频签、冷凝加湿签、压缩机制冷剂签、旁路签、油机签、仪表签、油品签、通风燃油签、电池签、内阻签、列头末端签都不顶本期冷通道进出风签。  
7. **封闭/进出风异常风暴挂 N，封闭策略/进风出风门限变更走 J，禁功率战；禁拆盲板/拆封闭冒充；禁堵进出风；禁伪造冷通道封闭与进出风台账；禁绕过冷通道门禁/联锁**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/通道编号全文/可还原坐标与联系人；禁公开传播未脱敏进出风门限与封闭参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签冷通道进出风准用、无实测冒充边界过、拆盲板冒充封闭、堵进出风冒充秩序齐，不是法外运维智慧**。医院洁净/冷链、数据中心冷热通道与盲板公开资料只作故事与方法类比（§2.2）：**封要约、进要窗、出要法、验要本期、门关不算过、回风绿不算进风过、拆盲板不算办法**——翻译成本网语言就是 AZ-封 / AZ-进 / AZ-出 / AZ-验 / AZ-治。**这些是机房冷通道封闭与机柜进出风交底秩序，不是「门关就签」「回风绿当过」「抬功率压告警」「拆盲板」「堵进出风」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机房冷通道封闭与机柜进出风准用」、对外宣传「门一关进出风秒过」、把未实测写成已过、把拆盲板/堵进出风写成秩序齐。允许做的：补封闭台账、补进风窗、重开出风窗、挂 R/N/J、内部挂整改。

### 4.3 「机房冷通道封闭与机柜进出风准用」最小集（AZ）——缺页不能签准用

1. 封闭台账页（门/顶/侧封·盲板·地板开孔密封）  
2. 进风主人与书面窗、方法、准用期页（含禁回风绿当进风过、禁空U无盲板勾选）  
3. 书面出风窗与方法页（出风路径·热通道回风；与 AU/AI/AY/AO 分工；以本网与 OEM 为准）  
4. 本期本组本机房实测记录（禁套声明）  
5. AU 滤网压差气流边界勾选（防顶替；AU 过≠AZ 过）  
6. AI 温湿度边界勾选（防顶替；AI 过≠AZ 过）  
7. AY 新风正压防火阀边界勾选（防顶替；AY 过≠冷通道封闭过）  
8. AO 漏水边界勾选（防顶替；AO 过≠进出风路径交底过）  
9. AN 门禁边界勾选（若进人：先 AN；门禁过≠冷通道交底过）  
10. N 风暴边界勾选（防顶替；N 绿≠AZ 过）  
11. AX/AT/AW 边界勾选（若同站：各过≠AZ 过）  
12. AD 仪表准用指针（若用，支撑）  
13. 会签页（准用或有条件整改）  
14. 未闭项清单（有则挂整改，重大未闭禁签准用）  
15. 脱敏勾选（L3）  
16. 变更指针（若本期有封闭策略/进风出风门限变更 → J）

### 4.7 台账路径（从发现到会签，教学骨架）

```text

        ↓
  补 AZ-封 封闭台账 / 补 AZ-进 进风窗 / 补 AZ-出 出风方法
        ↓

        ↓

```

### 4.8 15 分钟夜班清单（AZ8 展开）

### 5.5 与弱项的现场对照（再钉一次）

## 6. 工作实例（12 则，教学虚构，L3）

1. **通道门关着就要签准用** → 拒签；补 AZ-封台账与本期实测。  
2. **回风绿当进风过 / 口头说封好了** → 拒签；补 AZ-进主人/窗/方法；补 AZ-封书面台账。  
3. **空U不装盲板冒充封闭** → 拒签；补盲板核对；属 AZ-进 / AZ-封。  
4. **套邻站热力图/进出风照片改机房号** → AZ-验 拒签重测。  
5. **AU 滤网压差气流签顶本期冷通道进出风签** → 拒签顶替；AU≠AZ；可挂 R。  
6. **AI 温湿度签顶进出风 / AY 新风正压签顶冷通道封闭** → 拒签；AI≠AZ；AY≠AZ。  
7. **AO 漏水签顶进出风路径 / AN 门禁签顶冷通道交底** → 拒签；AO≠AZ；AN≠AZ。  
8. **AX 压缩机制冷剂签顶进出风 / AT 冷凝加湿签顶进出风** → 拒签；AX≠AZ；AT≠AZ。  
9. **N 监控绿免本期实测 / 进风告警抬功率** → 拒签实测免做；挂 N；**禁功率战**；缺秩序整改 AZ。  
10. **拆盲板/拆侧封冒充可过** → **禁**；挂 N/R；禁签准用。  
11. **堵进出风口消热点 / 热通道门常开冒充巡检方便** → **禁堵进出风**；禁门常开冒充；挂整改；本篇不教堵进出风；AZ-治。  
12. **进机房门禁过了就当冷通道交底过 / 公开群贴真实通道号与门限** → AN 过≠AZ 过；L3 违规撤帖脱敏；补 AZ。
