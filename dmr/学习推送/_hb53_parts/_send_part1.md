| **出** | 出风窗有书面方法（出风路径·热通道回风交界；与 AU/AI/AY/AO 分工；以本网与 OEM 为准）；禁「出风随便堵」「热通道门常开冒充巡检方便」 | 出风窗与方法书面固定；禁堵出风；禁门常开冒充 | AZ-出 |
| **验** | 本期封闭/进出风实测留痕；禁抄邻院热力图 | 本组本机房本期实测；禁套他站他期热力图/进出风照片 | AZ-验 |
| **治** | 假绿≠可以签；禁用「滤网气流签」「温湿度签」「新风正压签」「漏水签」「门禁签」「监控签」顶本期冷通道进出风 | 假绿、顶替 AU/AI/AY/…、拆盲板、堵进出风、功率战、泄密 → 治理 | AZ-治 |

> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：冷热通道封闭与盲板公开概述强调**有账要验、通道门关着≠准用、回风绿≠进风过、空U要盲板、封闭缝隙要查、进出风要有书面核对秩序**（§10，**只借秩序直觉**；**本篇不写逐步拆封闭/堵进出风教条**）；医院洁净/冷链与数据中心冷热通道公开资料强调**环境绿≠封闭进出风合格、滤网气流过≠封闭进出风台账过、温湿度过≠进风窗过、新风正压过≠冷通道封闭过**（§10，**只作故事类比**）。本篇只借这串顺序——**本网封闭台账格式、进风窗方法、出风顺序与合格门限以本网制度、合同与 OEM 书面为准**。

### 2.3 和手册48（AU）/ 36（AI）/ 52（AY）/ 42（AO）/ 41（AN）/ 15（N）/ 51（AX）/ 47（AT）/ 50（AW）/ 46（AS）/ 33（AF）/ 31（AD）/ 28（AA）/ 44（AQ）等的咬合（指针，不重写）

- **AU（手册48）**：滤网压差与气流组织；**AU ≠ AZ**——滤网/压差/气流过≠冷通道封闭与机柜进出风交底过；气流差可挂 AU，冷通道封闭/进出风仍 AZ。  
- **AI（手册36）**：温湿度与空调联锁**巡检边界**；**AI ≠ AZ**——AI 管温湿度测点/门限/联锁巡检秩序；**AZ 管封闭台账·进风本体窗·出风交底准用**；温湿度过≠进出风过；「环境绿」「联锁巡检绿」≠ AZ 过。  
- **AY（手册52）**：新风正压与防火阀；**AY ≠ AZ**——新风正压/防火阀过≠冷通道封闭过；新风与冷通道各管各的。  
- **AO（手册42）**：漏水探测与汇流排；**AO ≠ AZ**——漏水过≠进出风路径交底过。  
- **AN（手册41）**：门禁过≠冷通道交底过；进机房仍要 AN；**不教绕过冷通道门禁/联锁**。  
- **AX（手册51）**：精密空调压缩机与制冷剂；**AX ≠ AZ**——压缩机/制冷剂过≠进出风过。  
- **AT（手册47）**：冷凝水与加湿除湿；**AT ≠ AZ**——冷凝/加湿过≠进出风过。  
- **AW（手册50）**：列头柜与末端配电；**AW ≠ AZ**——列头末端过≠进出风过。  
- **AS / AF**：UPS 旁路 / 油机市电；供电过≠冷通道进出风过。  
- **AD（手册31）**：温湿度计/风速仪/热成像仪入库走 AD；**不能**用旧 AD 签日期顶本期 AZ 窗或实测窗。  
- **AA（手册28）**：首年巡检日历；冷通道进出风抽检可挂 AA，缺秩序整改主贴仍 AZ。  
- **N（手册15）**：监控/对时/告警风暴；封闭/进出风异常风暴挂 N 理风暴，**不先抬功率**；**禁拆盲板冒充、禁堵进出风**；N 绿≠ AZ 过。  
- **AQ（手册44）**：进出风异常/封闭失效事件要调录像 → 另开 AQ；视频过≠AZ 准用。  
- **AV / AR / AG / AP**：油品/燃油/电池/内阻；均不顶替 AZ。  
- **R / J / X / I**：假绿挂 R；变更（封闭策略、进风出风门限）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 AZ 证冷通道封闭与进出风秩序，再谈覆盖病**。

### 2.4 新贴纸 AZ：封 / 进 / 出 / 验 / 治（五个子类）

> 小彩蛋：双字母贴纸续写——**AA** 首年巡检；**AB** 室分复测；**AC** 机动开撤；**AD** 备件金机；**AE** 区间联测；**AF** 油机市电；**AG** 电池充电器；**AH** 合路/POI 界面；**AI** 温湿度联锁；**AJ** 天馈驻波；**AK** 爬塔交叉；**AL** 气灭疏散；**AM** 接地浪涌；**AN** 门禁访客；**AO** 漏水汇排；**AP** 内阻核对；**AQ** 视频调阅；**AR** 油机房通风燃油；**AS** UPS 旁路；**AT** 冷凝加湿联锁；**AU** 滤网压差气流；**AV** 日用油箱油品净化加油；**AW** 列头柜与末端配电巡检；**AX** 精密空调压缩机与制冷剂边界；**AY** 新风正压与防火阀；**AZ** 管「机房冷通道封闭与机柜进出风」。A–Z 既有含义不改；新专题用 AA、AB、AC… 续写。

### 2.5 建封闭台账 → 钉进风窗 → 出风方法钉死 → 本期实测 → 会签放行 → 变更再验 阶段梯（背下来）

```text
  ① AZ-封 建封闭台账：机房角色 · 门/顶/侧封 · 盲板 · 地板开孔密封 · 禁「通道门关着就算过」「口头说封好了」
        │  无账 / 门关无实测 → 不签机房冷通道封闭与机柜进出风准用
        ▼
  ② AZ-进 钉进风窗：进风主人角色 · 书面窗 · 方法 · 准用期 · 禁「回风绿当进风过」「空U不装盲板冒充」
        │  无主人 / 无窗 / 无方法 / 无准用期 → 拒进入「可签」状态
        ▼
  ③ AZ-出 钉出风方法：书面窗 · 方法（出风路径·热通道回风交界；与 AU/AI/AY/AO 分工；以本网与 OEM 书面为准） · 到场角色 · AD 仪表准用指针
        │  无窗 / 「出风随便堵」/ 「热通道门常开」 → 拒出风签
        ▼
  ④ AZ-验 本组本机房本期实测：实测记录 · 禁套他站他期热力图/进出风照片 · 会签
        │  套票 / 无会签 → 拒签
        ▼
  ⑤ 会签放行「机房冷通道封闭与机柜进出风准用」；假绿挂 R；风暴挂 N；变更走 J 后再验
```

### 2.7 一晚怎么走完（教学节奏，不替代本网书面规程）

5. 会签或拒签；风暴挂 N；变更走 J；L3。
