## 1. 为什么要写这篇手册（动机 + 现场对话）

前三十七篇手册从 A–E 协议一路写到 AJ 天馈驻波：其中 **AJ 回答「天馈驻波与跳线老化抽检」**，**AI 回答「机房温湿度与空调联锁」**，**AH 回答「多业主合路/POI 界面」**，**AD 回答「备件仪表准用」**，**AA 回答「交维后首年巡检」**，**AF 回答「油机市电」**，**N 回答「电源监控/对时/告警风暴」**。可还没有单独钉死一件事——**铁塔/桅杆不是「安全帽戴了就能上」：爬塔作业票/方案/到场角色要钉死；塔/桅杆/平台责任界面要有主人有书面边界；第三方交叉施工窗与停让/许可要书面固定；本组本站本期交底与实测禁套他站他期——能不能签「爬塔/交叉施工准用」？** 这就是本篇的 **AK**——**铁塔/桅杆爬塔作业与第三方交叉施工界面**。

- 运维岗：「安全帽戴了，安全带也挂了，可以上。」——**无作业票/方案仍准用** = 本篇拒签（规则1）。  
- 外包：「塔是谁的口头说一声，平台谁管也口头。」——**界面无主人无书面边界** = 规则2。  
- 物业：「外立面清洗队说忙完了，你们就能爬。」——**无交叉窗/停让许可，只听对方口头** = 规则3。  
- 外包：「邻站上周交底票参数差不多，拷过来改个站号。」——**套他站他期** = 规则4。  
- 班长：「AJ 天馈签还在，AI 温湿度也过了，爬塔也能签。」——**用 AJ/AI/AH/AD/AA/AF/N 顶替 AK** = 规则6。  
- 站务：「大屏监控绿了，爬塔准用就算过。」——**假绿≠会签放行** = 规则5/6。  
- 网优：「爬塔窗有人登记失败，功率抬一点稳住。」——**功率战** = 规则7。  
- 宣传岗：「把真实塔号、站名、联系人发群表扬。」——**L3 违规** = 规则8。  

这几句背后是同一件事：

> **「铁塔/桅杆爬塔与第三方交叉施工」在现场至少有五个坑**：**① AK-爬** 爬塔作业票/方案/到场角色入账，禁「安全帽戴了就能上」「口头说一声」；**② AK-界** 铁塔/桅杆/平台责任界面有主人、有书面边界，禁口头「塔是谁的」；**③ AK-交** 第三方交叉施工窗与停让/许可方法钉死，禁「对方说忙完了就爬」；**④ AK-验** 本组本站本期交底与实测（禁套他站他期票/照片），会签才放行「爬塔/交叉施工准用」；**⑤ AK-治** 治理（假绿、用 AJ/AI/AH/AD/AA/AF/N 顶替、伪造作业票、功率战、带电未确认就上、泄密）。  
> 把 ①–⑤ 当成「安全帽戴了就能上」「对方说忙完了就能爬」「口头说一声谁管塔」，每一次登高、每一次外立面交叉、每一次带电天线旁作业，都会先吵「票是谁的、界面谁负责、交底是不是本期的」。

本篇目标：能背出**爬塔作业 + 交叉施工界面工作流**；会用新贴纸 **AK（爬 / 界 / 交 / 验 / 治）**；会填**插页 AK（AK1–AK8）**和《本网铁塔桅杆爬塔与交叉施工台账卡》；能用「**医院屋顶空调外机/冷却塔登高检修 + 第三方外立面清洗/脚手架交叉施工**」故事讲清安全帽戴了≠作业票过、对方说忙完了≠交叉窗许可过、套邻楼交底票=拒签、用 AJ/AI/AH/AD 签顶 AK 爬塔签=拒签、假绿≠会签放行；能拒绝无票上塔、套交底、用他贴顶替本期爬塔签、假绿放行；自测过关后，回库把本网最近一次爬塔或交叉施工交底（L3）重对一遍：作业票、界面主人、交叉窗、本期交底、会签项、拒签项。

**本篇硬禁令（写进脑子）**：凡引法规与标准只指向已公开发布的文书标题与官方链接（无线电管理条例、频率使用许可管理办法、地面无线电台（站）管理规定、国无办〔2025〕1号；**只作故事类比**的医院屋顶空调外机/冷却塔登高与外立面清洗/脚手架交叉施工公开资料标题，以及公开的登高/防坠落/作业许可/RF 暴露概述资料），**程序、期限、责任以原文与属地最新要求及本网制度 / 合同为准，本篇只作教学转述，不发明条款号与内部口径**；医院屋顶登高、外立面清洗、境外塔工/RF 意识公开科普**不是**中国专网台站「贴纸 AK」的法定依据；**现象与台账一律用相对道号、角色标签、脱敏站/塔桅编号，禁真实频点 / 站名 / 机房全称 / 塔桅序列号全文 / 单位名 / 联系人**；**不教伪造作业票、不教绕过登高安全、不教规避 RF 监测、不教偷爬交叉窗、不教功率战、不教假绿顶替、不教带电未确认就上**；AJ / AI / AH / AD / AA / AF / N / R / J 各管各的——**铁塔/桅杆爬塔与交叉施工主贴 AK**；天馈驻波回 AJ，温湿度联锁回 AI，合路界面回 AH，备件仪表回 AD，首年巡检回 AA，油机市电回 AF，监控风暴回 N——**AK 管「爬塔·界面·交叉秩序」，不替代 AJ 的天馈驻波抽检，也不替代 AI 的温湿度联锁，更不替代 AH 的合路界面门卫**。

## 2. 总图 / 故事：爬塔交叉像「医院屋顶空调外机/冷却塔登高 + 外立面清洗脚手架——不能只看安全帽戴了」

### 2.1 一句话：安全帽戴了不是「可以上」、对方说忙完了不是「交叉窗过了」——要先建爬塔作业票与方案，塔桅界面有主人有书面边界，交叉窗与停让许可钉死，本组本站本期交底，会签才放行；假绿、套邻站交底票、用 AJ/AI/AH/AD/AA/AF/N 顶替，一律拒签

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  医院屋顶空调外机/冷却塔登高 + 外立面清洗脚手架交叉  =  本网 AK │
   │                                                              │
   │  登高作业票·方案·到场角色钉死     ≈ AK-爬  爬塔票与方案钉死 │
   │  屋顶/平台/设备责任界面书面边界   ≈ AK-界  塔桅界面有主有界 │
   │  清洗队/脚手架交叉窗·停让许可钉死 ≈ AK-交  交叉窗与停让许可 │
   │  本期交底实测禁套邻楼交底票       ≈ AK-验  本组本站本期     │
   │  假绿≠放行·顶替·伪造票·功率战   ≈ AK-治  治理与脱敏 L3   │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **爬塔有票，界面有主，交叉有窗，本期交底，会签才放。**  
> 安全帽戴了还无作业票 = 医院屋顶登高只看安全帽不查作业票——**拒签「爬塔/交叉施工准用」**。  
> 对方说忙完了但无书面交叉窗 = 外立面清洗队口头「忙完了」却从未做停让许可——**假绿，挂 R，拒签**。

### 2.2 「医院屋顶空调外机/冷却塔登高 + 外立面清洗脚手架交叉」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **爬** | 登高作业票/方案/角色到场→禁「安全帽戴了就能上」 | 爬塔作业票、方案、到场角色钉死；禁口头说一声 | AK-爬 |
| **界** | 屋顶/平台/冷却塔设备责任界面有主人、有书面边界 | 铁塔/桅杆/平台界面有主人有书面边界；禁口头「塔是谁的」 | AK-界 |
| **交** | 外立面清洗/脚手架交叉有窗、有停让许可；禁「对方说忙完了就爬」 | 交叉施工窗与停让/许可方法书面固定 | AK-交 |
| **验** | 本期交底实测留痕；禁抄邻楼交底票 | 本组本站本期交底与实测；禁套他站他期 | AK-验 |
| **治** | 假绿≠可以上；禁用「天馈签」「温湿度签」「合路签」顶本期爬塔 | 假绿、顶替 AJ/AI/AH/AD/AA/AF/N、伪造票、功率战、泄密 → 治理 | AK-治 |

### 2.3 和手册37（AJ）/ 36（AI）/ 35（AH）/ 31（AD）/ 28（AA）/ 33（AF）/ 15（N）等的咬合（指针，不重写）

- **AJ（手册37）**：天馈驻波与跳线老化抽检；爬塔常伴天馈作业，可挂 AJ，**缺爬塔/交叉秩序整改主贴仍 AK**——天馈过≠爬塔票过。  
- **AI（手册36）**：机房温湿度与空调联锁；环境过≠爬塔准用——各贴各的。  
- **AH（手册35）**：合路/POI 界面；合路界面清≠塔桅爬塔界面清。  
- **AD（手册31）**：登高用仪表、RF 监测仪入库走 AD；**不能**用旧 AD 签日期顶本期 AK 窗。  
- **AA（手册28）**：交维后**首年巡检**日历；爬塔抽检可挂 AA，缺爬塔/交叉秩序整改主贴仍 AK。  
- **AF（手册33）**：油机市电；供电过≠爬塔过。  
- **N（手册15）**：监控/**对时**/告警风暴；爬塔窗告警风暴挂 N 理风暴，**不先抬功率**；N 绿≠ AK 准用过。  
- **R / J / X / I**：假绿挂 R；变更（换天线、改馈线、改门限）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 AK 证爬塔/交叉秩序，再谈覆盖病**。

### 2.5 建作业票 → 钉界面主人 → 交叉窗钉死 → 本期交底 → 会签放行 → 变更再验 阶段梯（背下来）

```text
  ① AK-爬 建爬塔作业票：票号角色 · 方案角色 · 到场角色勾选 · 禁「安全帽戴了」「口头说一声」
        │  无票 / 无方案 / 关键未到 → 不签爬塔/交叉准用
        ▼
  ② AK-界 钉塔桅/平台界面：主人角色 · 书面边界（谁管塔身/平台/天线层/接地）书面
        │  无主人 / 无书面边界 → 拒进入「可签」状态
        ▼
  ③ AK-交 钉交叉窗：书面窗 · 停让/许可方法 · 第三方到场角色 · RF暴露/停发确认书面
        │  无窗 / 「对方说忙完了」 → 拒交叉签
        ▼
  ④ AK-验 本组本站本期交底与实测：交底记录 · 禁套他站他期票/照片
        │  套票 / 只看监控绿 → 拒签
        ▼
  ⑤ 会签「爬塔/交叉施工准用」或「有条件整改」：本网授权本人签
        │  缺签 / 假绿顶替 → 拒签准用
        ▼
  ⑥ 变更（换天线/改馈线/改门限）→ 走 J + 触发再交底/再验（常挂 N 看监控、挂 AJ 看天馈、挂 AD 看仪表）
```

> **一句话分辨**：**AJ** 回答「天馈驻波抽检**过了没有**」；**AI** 回答「温湿度联锁**过了没有**」；**AH** 回答「合路界面**清不清**」；**AD** 回答「仪表准用期**到了没有**」；**AK** 回答「这一窗爬塔作业票 + 这一座塔桅界面 + 这一窗交叉停让**台账清不清、界面有没有主、本期交底过了没有**」。**五个问题，五张（类）贴纸，不能一笔带过。**

### 2.6 爬塔与交叉施工最小工作流（背下来）

```text
       │

       │  套票 / 只看绿灯 → 拒签
       ▼
  会签「爬塔/交叉施工准用」或挂整改；重大未闭禁签准用
       │
  放行或拒签；公开材料 L3；变更走 J 再触发
```

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **爬塔作业票/方案/到场角色钉死：无作业票、无方案或到场角色未勾选不得签「爬塔/交叉施工准用」；禁「安全帽戴了就能上」「口头说一声」**。  
2. **铁塔/桅杆/平台责任界面有主人有书面边界：主人角色书面；塔身/平台/天线层/接地等边界书面；禁口头「塔是谁的」**。  
3. **第三方交叉施工窗与停让/许可方法钉死：交叉窗、停让/许可方法、第三方到场角色书面固定；禁「对方说忙完了就爬」**。  
4. **本组本站本期交底与实测：须本脱敏站、本窗交底与实测；禁套他站/他期作业票或交底照片**。  
5. **会签才放行：相关授权本人会签后，方可签「爬塔/交叉施工准用」；重大未闭项禁合格**。  
6. **禁顶替：可挂 AJ/AI/AH/AD/AA/AF/N/R 支撑，但铁塔/桅杆爬塔与交叉施工主贴 AK；AJ 天馈签、AI 温湿度签、AH 合路签、AD 仪表签、AA 首年签、AF 油机签、N 监控绿、大屏绿灯均不得顶替 AK 本期爬塔签；主贴 AK；监测大屏/系统绿灯、假绿不等于放行（挂 R）**。  
7. **爬塔/交叉窗禁功率战、禁带电未确认就上；监控/告警风暴挂 N；换天线/改馈线/改门限等变更走 J 并评估再交底/再验；RF 暴露/停发确认须书面**。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/塔桅序列号全文/可还原坐标与联系人**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无作业票乱签爬塔、无交叉许可冒充准用，不是法外运维智慧**。医院屋顶登高与外立面清洗/脚手架公开资料、塔工/RF 意识公开科普只作故事与方法类比（§2.2）：**爬要约、界要主、交要窗、验要测、绿灯不算过**——翻译成本网语言就是 AK-爬 / AK-界 / AK-交 / AK-验 / AK-治。**这些是爬塔交叉秩序，不是「安全帽戴了就上」「对方说忙完了就爬」「抬功率压告警」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「爬塔/交叉施工准用」、对外宣传「分钟级一键爬塔秒过」、把未交底写成已过。允许做的：补作业票、补界面主人、重开交叉窗、重交底、挂 R/N/J、内部挂整改。

> **弱项短补（为什么爬塔窗要先问秩序再开「覆盖病」工单）**：爬塔靠近带电天线时，RF 暴露与人乱键/抬功率叠加，常先伤**上行体验与人身安全**——手台上行本来就弱，窗内有人抬功率更容易先被写成「覆盖病」——**12.5 kHz / 4FSK / 2-slot TDMA 的空口台阶没变**，变的是「安全帽绿」有没有人认作业票、有没有本期交叉停让。只开射频工单抬功率，等于屋顶登高时去拧无影灯亮度。**先 AK（及 N/AJ/AD 指针），再谈覆盖（X）/干扰（I）。**

### 4.10 爬塔 / RF 暴露 / 交叉停让与 AK 的咬合（教学直觉，门限以本网为准）

- **爬塔作业票**：公开常识强调有票、有方案、有到场；格式与审批**以本网制度为准**——AK 钉「有没有票、有没有方案、本期有没有交底」。  
- **RF 暴露/停发确认**：靠近带电天线时的公开安全直觉；**不教规避监测、不教伪造停发**。  
- **交叉停让许可**：第三方脚手架/外立面清洗与本网上塔的时间窗——类似医院屋顶与清洗队交叉；**书面窗与停让方法入账**。  
- **上行更脆 + 禁功率战**：爬塔窗有人乱键/抬功率常先伤上行体验——先 AK，再谈「覆盖病」（X 指针）。  
- **AD 指针**：RF 监测仪、登高相关仪表入库走 AD；**不能**用旧 AD 签日期顶本期 AK 窗。

### 4.11 与天馈（AJ）/ 温湿度（AI）/ 合路（AH）/ 仪表（AD）/ 首年（AA）/ 油机（AF）/ 监控（N）怎么配合

- AJ 天馈并行：爬塔常伴天馈作业，各贴各的；天馈过≠爬塔票过。  
- AI 温湿度：环境过≠爬塔过；屋顶空调外机故事可并行类比。  
- AH 合路界面：合路清≠塔桅界面清。  
- AD 仪表并行：仪表期内≠爬塔准用过。  
- AA 首年巡检：日历抽检爬塔可挂 AA，**主贴本期爬塔仍 AK**。  
- AF 油机：供电过≠爬塔过。  
- N 告警风暴：爬塔窗铃响先挂 N 理风暴，**不先抬功率**；N 绿≠ AK 过。

### 4.12 爬塔窗与上行更脆 / RF 暴露直觉

- 先 AK/N/AJ/AD：作业票、监控、天馈、仪表解释得清不清。  
- 解释不清再挂覆盖（X）/干扰（I）分诊；**禁止**一抖就功率战。  
- 上行更脆 + RF 暴露：爬塔靠近天线时，乱键/抬功率与暴露叠加——先确认停发/暴露书面，再下「覆盖病」结论。

### 5.2 三段对话脚本（可练）

**脚本 A · 拒签（安全帽 / 口头 / 无界面）**

## 6. 工作实例（12 则，教学虚构，L3）

1. **安全帽戴了无作业票**  
   现象：安全帽齐，票号未入账。  
   处置：AK-爬 拒签准用；补作业票与方案到场。  

2. **口头「塔是谁的」无界面主人**  
   现象：平台责任互推。  
   处置：AK-界 拒签；书面补主人与边界；挂整改。  

3. **对方说忙完了无书面交叉窗**  
   现象：清洗队口头忙完，无停让许可。  
   处置：AK-交 拒签；重开书面交叉窗；主贴 AK。  

4. **套邻站交底票**  
   现象：交底报告站号涂改痕迹。  
   处置：AK-验/治 拒签；本窗重交底。  

5. **用 AJ 天馈签顶本期 AK**  
   现象：「天馈签还在有效期，不用再贴爬塔。」  
   处置：规则6；AJ 可挂支撑，主贴仍 AK。  

6. **用 AI 温湿度签顶 AK**  
   现象：「温湿度联锁刚过，爬塔也能签。」  
   处置：规则6；环境≠爬塔窗；主贴 AK。  

7. **用 AH 合路签顶塔桅界面**  
   现象：「合路界面绿了，塔桅界面就算清。」  
   处置：规则6；合路≠塔桅；主贴 AK。  

8. **带电未确认就上**  
   现象：无 RF 暴露/停发书面确认。  
   处置：AK6 拒上；书面确认后再走交底（挂 AD 指针看仪表）。  

9. **爬塔窗抬功率压登记失败**  
   现象：上行失败被写成覆盖病。  
   处置：AK-治 禁功率战；先 AK/N；确认票与停发；再谈 X。  

10. **监控绿当爬塔过**  
    现象：大屏绿，作业票停在半月前。  
    处置：AK-治 + R 假绿；重开交底窗；主贴 AK。  

11. **换天线未走 J**  
    现象：爬塔窗私自换天线后「监控更绿」。  
    处置：挂 J；评估后 AK 再交底/再验（常挂 N/AJ/AD）。  

12. **公开群发塔号与联系人**  
    现象：含可定位站信息。  
    处置：AK-治 规则8；撤回；L3 重发教学版。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AK** 五子类：爬 / 界 / 交 / 验 / 治——双字母续写的第十一张，负责爬塔·界面·交叉「台账清不清、界面有没有主、本期交底过了没有」。  
- 故事：医院屋顶空调外机/冷却塔登高检修 + 第三方外立面清洗/脚手架交叉——安全帽戴了≠作业票过；对方说忙完了≠交叉窗许可过；套邻楼交底票=拒签；AJ/AI/AH/AD/AA/AF/N 不顶替 AK；假绿≠会签放行。  
- 阶段梯：建作业票 → 钉界面主人 → 交叉窗钉死 → 本期交底 → 会签放行 → 变更再验。  
- 八条硬规则：**爬塔作业票/方案/到场钉死**；**铁塔/桅杆/平台界面有主人有书面边界**；**交叉窗与停让许可方法钉死**；**本组本站本期交底实测禁套他站他期**；**会签才放行**；**禁顶替 AJ/AI/AH/AD/AA/AF/N 等，主贴 AK，假绿≠放行挂 R**；**爬塔/交叉窗禁功率战、禁带电未确认就上、监控风暴挂 N、变更走 J、RF暴露/停发确认书面**；**脱敏 L3**。
