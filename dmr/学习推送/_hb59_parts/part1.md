## 1. 为什么要写这篇手册（动机 + 现场对话）

前五十八篇手册从 A–E 协议一路写到 BE 加湿器水质与电极蒸汽罐更换：其中 **AM 回答「天馈接地与防雷浪涌抽检」**（天馈/塔脚/天馈侧 SPD），**AO 回答「漏水与汇流排探测」**，**AW/AF/AS 回答「供电链」**，**BC 回答「机柜配电与PUE/负载分区」**，**AD 回答「备件仪表准用」**，**AN 回答「门禁与访客陪同」**，**AA 回答「交维后首年巡检」**，**N 回答「电源监控/对时/告警风暴」**，**AQ 回答「视频监控调阅与证据链」**，**BE 回答「加湿器水质与电极蒸汽罐更换」**，**BD 回答「冷冻水泵组与定压补水」**。可还没有单独钉死一件事——**机房内接地与等电位联接、以及机房侧/配电侧浪涌保护不是「接地棒在 / 看着连着 / 口头说接地正常 / SPD 绿灯就能签」：机房接地台账要钉死（机柜/汇流排/设备外壳/等电位联接角色·测点）；等电位联接要有主人有窗有方法有准用期（联接螺栓/跨接线/等电位带·周期窗；禁看着连着当窗过、禁口头连过）；机房 SPD 与接地/等电位边界窗与方法要书面固定（与 AM/AO/AW/AF/AS/BC/AN/N 分工；禁旁路SPD、禁拆跨接冒充、禁不安全带电违章）；本组本机房本期实测禁套他站他期——能不能签「机房接地与等电位浪涌保护准用」？** 这就是本篇的 **BF**——**机房接地与等电位浪涌保护巡检交底台账**（Excel 风格双字母：BE 之后 → **BF**）。

> **接地有账，等电位有窗，浪涌有法，会签才放。**

> **AM 天馈接地浪涌过≠BF**（天馈/塔脚/天馈侧SPD ≠ 机房内接地与等电位/机房侧SPD）；AO 漏水过≠BF；AW 列头末端过≠BF；AF 油机市电过≠BF；AS UPS旁路过≠BF；BC 机柜PUE过≠BF；AD 备件入库过≠本期等电位/SPD窗过；BE 水质换罐过≠BF；BD 泵组定压补水过≠BF；N 监控绿≠本期实测过；AN 门禁过≠接地等电位交底过；AJ 驻波绿≠BF；AI 温湿度过≠BF。

### 2.2 「医院手术室/ICU 等电位联接与机房浪涌保护巡检（或数据中心 equipment bonding / equipotential bonding / facility SPD / ground bar）」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **地** | 机柜/汇流排/设备外壳/等电位联接角色·测点入账→禁「接地棒在就算过」「口头说接地正常」 | 机房接地台账钉死；禁口头说一声；**AM天馈侧≠本机房内台账** | BF-地 |
| **等** | 等电位联接有主人、有窗、有方法、有准用期；禁「看着连着当窗过」「口头连过」 | 联接螺栓/跨接线/等电位带·周期窗有账有验；看着连着≠窗过 | BF-等 |
| **涌** | 边界窗有书面方法（机房SPD与接地/等电位交界；与 AM/AO/AW/AF/AS/BC/AN/N 分工；以本网与 OEM 为准）；禁「旁路SPD」「拆跨接冒充」「不安全带电违章」 | 边界窗与方法书面固定；禁旁路SPD/拆跨接/不安全带电违章 | BF-涌 |
| **验** | 本期接地/等电位/SPD实测留痕；禁抄邻院接地账 | 本组本机房本期实测；禁套他站他期接地/等电位/SPD表 | BF-验 |
| **治** | 假绿≠可以签；禁用「天馈接地浪涌签」「漏水签」「供电签」「备件入库签」「监控签」顶本期机房接地等电位 | 假绿、顶替 AM/AO/AW/AD/N/…、旁路SPD、拆跨接、带电违章、功率战、泄密 → 治理 | BF-治 |

> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：接地/等电位/防雷/SPD 公开概述强调**有账要验、棒在≠合格、看着连着≠窗过、绿灯不算过、边界要有书面方法、接地与等电位与SPD要有本期核对秩序**（§10，**只借秩序直觉**；**本篇不写逐步旁路SPD/拆跨接/不安全带电违章操作教条**）；医院手术室/ICU 与数据中心 equipment bonding / equipotential bonding / facility SPD / ground bar 公开资料强调**接地棒在≠等电位合格、SPD绿灯≠本期抽检过、天馈侧过≠机房内过、漏水探头过≠等电位过、供电过≠等电位过、备件入库过≠本期窗过、监控绿≠本期实测过**（§10，**只作故事类比**）。本篇只借这串顺序——**本网机房接地台账格式、等电位窗方法、SPD边界顺序与合格门限以本网制度、合同与 OEM 书面为准**。

### 2.3 和手册40（AM）/ 42（AO）/ 50（AW）/ 33（AF）/ 46（AS）/ 56（BC）/ 31（AD）/ 15（N）等的咬合（指针，不重写）

- **AM（手册40）**：天馈接地与防雷浪涌抽检（天馈/塔脚/**天馈侧** SPD）；**AM ≠ BF**——天馈侧接地浪涌过≠机房内接地与等电位/机房侧SPD过；天馈侧可挂 AM，机房内接地·等电位·机房侧SPD主贴仍 BF；**不得用 BF 顶 AM，也不得用 AM 顶 BF**。**天馈接地浪涌 ≠ 机房接地等电位准用**——钉死再钉死。  
- **AO（手册42）**：漏水探测与汇流排；**AO ≠ BF**——漏水过≠等电位准用；水浸可挂 AO，等电位主贴仍 BF（并挂 N 理风暴）。**漏水探测 ≠ 等电位联接准用**——钉死。  
- **AW（手册50）**：列头柜与末端配电；**AW ≠ BF**——供电过≠等电位过。  
- **AF（手册33）**：油机市电；**AF ≠ BF**——供电过≠等电位过；雷雨窗市电/油机态可挂 AF 指针。  
- **AS（手册46）**：UPS 旁路；**AS ≠ BF**——旁路过≠等电位过；**禁把 UPS 旁路与旁路SPD混为一谈**。  
- **BC（手册56）**：机柜配电与PUE/负载分区；**BC ≠ BF**——机柜PUE过≠等电位过。  
- **AD（手册31）**：接地电阻表、钳表、跨接线/SPD备件入库走 AD；**不能**用旧 AD 签日期顶本期 BF 等电位/SPD窗或实测窗。**备件入库 ≠ 本期等电位/SPD窗**——钉死。  
- **AN（手册41）**：门禁过≠接地等电位交底过；进机房仍要 AN；**不教绕过门禁/不安全带电**。  
- **AA（手册28）**：首年巡检日历；接地/等电位/SPD抽检可挂 AA，缺秩序整改主贴仍 BF。  
- **N（手册15）**：监控/对时/告警风暴；接地/等电位/SPD异常风暴挂 N 理风暴，**不先抬功率**；**禁旁路SPD、禁拆跨接冒充、禁不安全带电违章**；N 绿≠ BF 过。  
- **AQ（手册44）**：接地/等电位/SPD异常事件要调录像 → 另开 AQ；视频过≠BF 准用。  
- **BE / BD / AT / AI / AX / AY / AZ / AU / BB / BA**：水质换罐 / 泵组定压补水 / 冷凝加湿 / 温湿度 / 压缩机制冷剂 / 新风 / 冷通道 / 滤网气流 / 室外机冷凝侧 / 冷冻水冷却塔；均不顶替 BF。  
- **AJ / AK / AH / AL**：驻波 / 爬塔 / 合路 / 气灭；驻波绿≠BF；爬塔窗可顺带目视机房侧接地卡箍，**缺机房接地账整改主贴仍 BF**（天馈侧仍回 AM）。  
- **AV / AR / AG / AP**：油品/燃油/电池/内阻；均不顶替 BF。  
- **R / J / X / I**：假绿挂 R；变更（接地系统、等电位联接方法、SPD型号/位置、门限）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 BF 证机房接地与等电位/SPD秩序，再谈覆盖病**；天馈侧仍先问 AM。

### 2.4 新贴纸 BF：地 / 等 / 涌 / 验 / 治（五个子类）

### 2.5 建机房接地台账 → 钉等电位窗 → SPD边界方法钉死 → 本期实测 → 会签放行 → 变更再验 阶段梯（背下来）

```text
  ① BF-地 建机房接地台账：机房角色 · 机柜接地 · 汇流排/测点 · 设备外壳 · 禁「接地棒在」「口头说接地正常」
        │  无账 / 棒在无实测 → 不签机房接地与等电位浪涌准用
        ▼
  ② BF-等 钉等电位窗：主人角色 · 书面窗 · 方法 · 准用期 · 禁「看着连着当窗过」「口头连过」
        │  无主人 / 无窗 / 无方法 / 无准用期 → 拒进入「可签」状态
        ▼
  ③ BF-涌 钉SPD边界方法：书面窗 · 方法（机房SPD与接地/等电位边界；与 AM/AO/AW/AF/AS/BC/AN/N 分工；以本网与 OEM 书面为准） · 到场角色 · AD 仪表/备件准用指针
        │  无窗 / 「旁路SPD」/ 「拆跨接冒充」/ 「不安全带电违章」 → 拒边界签
        ▼
  ④ BF-验 本组本机房本期实测：实测记录 · 禁套他站他期接地/等电位/SPD表 · 会签
        │  套票 / 无会签 → 拒签
        ▼
  ⑤ 会签放行「机房接地与等电位浪涌保护准用」；假绿挂 R；风暴挂 N；变更走 J 后再验
```

### 2.7 一晚怎么走完（教学节奏，不替代本网书面规程）

1. 翻 BF1：机房接地台账在不在？接地棒在≠准用勾了没有？**AM天馈侧≠本机房内**勾了没有？  
2. 翻 BF2：等电位主人/窗/方法/准用期；禁口头连过当窗过；禁看着连着当窗过。  
3. 翻 BF3：SPD与接地/等电位边界书面方法；禁旁路SPD/拆跨接/不安全带电违章；AM/AO/AW/AF/AS/BC/AN/N 分工勾清。  
4. 翻 BF4：本期实测；禁套声明。  
5. 会签或拒签；风暴挂 N；变更走 J；L3。
