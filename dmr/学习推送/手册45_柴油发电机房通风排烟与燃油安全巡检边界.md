## 1. 为什么要写这篇手册（动机 + 现场对话）

前四十四篇手册从 A–E 协议一路写到 AQ 视频调阅：其中 **AF 回答「油机市电切换与机房供电巡检」**，**AL 回答「机房消防气灭与应急疏散联锁」**，**AG 回答「电池与充电器梯队」**，**AP 回答「内阻与核对性放电」**，**AI 回答「温湿度与空调联锁」**，**AO 回答「漏水与接地汇流排」**，**AN 回答「门禁与访客陪同」**，**AD 回答「备件仪表准用」**，**AA 回答「交维后首年巡检」**，**N 回答「电源监控/对时/告警风暴」**，**AQ 回答「视频监控调阅与证据链」**。可还没有单独钉死一件事——**柴油发电机房通风排烟与燃油安全不是「风机绿灯就能签」：通风/燃烧空气台账要钉死；排烟与废气边界要有主人有界有方法有准用期；燃油与日用油箱巡检窗与方法要书面固定；本组本机房本期实测禁套他站他期——能不能签「通风排烟/燃油安全准用」？** 这就是本篇的 **AR**——**柴油发电机房通风排烟与燃油安全巡检边界**。

- 运维岗：「风机还亮着绿灯，通风巡检就算齐了。」——**无通风台账/无本期实测仍准用** = 本篇拒签（规则1）。  
- 外包：「排烟口开着，废气边界肯定过。」——**口开着当边界过** = 规则2。  
- 物业：「油箱看着有油，燃油安全再说。」——**无巡检窗方法，只听口头** = 规则3。  
- 外包：「邻站上周通风照片参数差不多，拷过来改个机房号。」——**套他站他期** = 规则4。  
- 班长：「AF 油机市电签还在，AL 气灭也过了，通风燃油也能签。」——**用 AF/AL/AG/AP/AI/AO/AN/AD/AA/N/AQ 顶替 AR** = 规则6。  
- 站务：「大屏油机监控绿了，通风排烟/燃油安全准用就算过。」——**假绿≠会签放行** = 规则5/6。  
- 网优：「油机高温/低油位告警一片，功率抬一点稳住业务。」——**功率战** = 规则7（无关也写禁，系列一致）。  
- 宣传岗：「把真实油机房编号、油箱序列号发群表扬。」——**L3 违规** = 规则8。  

这几句背后是同一件事：

> **「柴油发电机房通风排烟与燃油安全」在现场至少有五个坑**：**① AR-风** 通风/燃烧空气台账钉死，禁「风机绿灯就能签」「口头说一声」；**② AR-排** 排烟与废气边界有主人、有界、有方法、有准用期，禁「排烟口开着当边界过」；**③ AR-燃** 燃油与日用油箱巡检窗与方法钉死（油位·泄漏·通气·围堰等；门限以本网为准），禁「看着有油当巡检过」「只看监控绿」；**④ AR-验** 本组本机房本期实测（禁套他站他期曲线/照片），会签才放行「通风排烟/燃油安全准用」；**⑤ AR-治** 治理（假绿、用 AF/AL/AG/AP/AI/AO/AN/AD/AA/N/AQ 顶替、伪造通风燃油账、旁路风机联锁、不安全泄油旁路、功率战、泄密）。  
> 把 ①–⑤ 当成「风机绿灯就能签」「口开着就算过」「油机市电签还在通风也能签」，每一次油机试机、每一次燃油巡检、每一次夜班交班，都会先吵「账是谁的、窗谁开的、照片是不是本期的、边界清不清」。

本篇目标：能背出**通风 + 排烟废气 + 燃油安全工作流**；会用新贴纸 **AR（风 / 排 / 燃 / 验 / 治）**；会填**插页 AR（AR1–AR8）**和《本网柴油发电机房通风排烟与燃油安全台账卡》；能用「**医院手术室/ICU 保供电机房备用柴油发电机房通风排烟与燃油安全**」故事讲清风机绿灯≠通风合格、排烟口开着≠废气边界过、油箱看着有油≠燃油安全巡检过、套邻站通风照片=拒签、AF 油机市电签不顶替本期通风燃油签、AL 气灭过≠燃油日用油箱过、N 监控绿≠本期实测过、用 AF/AL/N 签顶 AR 通风燃油签=拒签、假绿≠会签放行；能拒绝无账准用、套票、用他贴顶替本期通风燃油签、假绿放行；自测过关后，回库把本网最近一次柴油发电机房通风/排烟/燃油巡检（L3）重对一遍：通风台账、排烟边界、燃油窗、本期实测、会签项、拒签项。

### 2.3 和手册33（AF）/ 39（AL）/ 34（AG）/ 43（AP）/ 36（AI）/ 42（AO）/ 41（AN）/ 31（AD）/ 28（AA）/ 15（N）/ 44（AQ）等的咬合（指针，不重写）

- **AG（手册34）** / **AP（手册43）**：电池充电器梯队 / 内阻核对；电池过≠通风燃油过；油机启动电池可挂 AG/AP，风路燃油主贴仍 AR。  
- **AI（手册36）**：温湿度与空调联锁；温湿度过≠油机房通风合格；机房空调与油机房风路各管各的。  
- **AO（手册42）**：漏水汇排；漏水过≠燃油泄漏巡检过；油机房地漏/围堰积水可挂 AO，燃油安全主贴仍 AR。  
- **AN（手册41）**：门禁访客；进油机房做通风/燃油巡检仍要 AN——**门禁过≠通风燃油过**。  
- **AD（手册31）**：风速仪/测温/测漏仪表等入库走 AD；**不能**用旧 AD 签日期顶本期 AR 窗。  
- **AA（手册28）**：交维后**首年巡检**日历；通风燃油抽检可挂 AA，缺通风燃油秩序整改主贴仍 AR。  
- **N（手册15）**：监控/**对时**/告警风暴；通风/排烟/燃油异常风暴挂 N 理风暴，**不先抬功率**；**禁旁路风机联锁、禁不安全泄油消告警**；N 绿≠ AR 过。  
- **AQ（手册44）**：视频调阅；油机房事件要调录像另开 AQ；视频过≠通风燃油过。  
- **R / J / X / I**：假绿挂 R；变更（风路改造、排烟路由、油箱策略、巡检规程）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 AR 证通风燃油秩序，再谈覆盖病**。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **通风/燃烧空气台账钉死**：机房角色、进风/燃烧空气/冷却风路入账；禁「风机绿灯就能签」「口头说一声」。  
2. **排烟与废气有主有界有方法/准用期**：每次核对有主人角色、有书面边界、有方法、有准用期；禁「排烟口开着当边界过」。  
3. **燃油与日用油箱巡检窗与方法钉死**：书面固定；方法含油位·泄漏·通气·围堰等（**门限以本网为准**）；禁「窗再说」「看着有油当过」「只看监控绿」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、照片、读数必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「通风排烟/燃油安全准用」；假绿 ≠ 放行。  
6. **禁顶替 AF/AL/AG/AP/AI/AO/AN/AD/AA/N/AQ，主贴 AR，假绿≠放行挂 R**：油机市电签、气灭签、电池签、内阻签、温湿度签、漏水签、门禁签、仪表签、首年签、监控签、视频签都不顶本期通风燃油签。  
7. **通风/排烟/燃油异常风暴挂 N，风路/排烟路由/油箱策略变更走 J，禁功率战；禁旁路风机联锁；禁不安全泄油旁路**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/油机油箱序列号全文/可还原坐标与联系人；禁公开传播未脱敏油箱参数与机房编号**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签通风燃油准用、无实测冒充巡检过、旁路联锁冒充秩序齐，不是法外运维智慧**。医院保供电油机房公开资料、柴油发电机房通风/排烟/燃油公开科普只作故事与方法类比（§2.2）：**风要约、排要界、燃要窗、验要本期、灯绿不算过**——翻译成本网语言就是 AR-风 / AR-排 / AR-燃 / AR-验 / AR-治。**这些是通风排烟燃油巡检边界秩序，不是「风机绿就签」「口开着当过」「抬功率压告警」「旁路联锁」「不安全泄油」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「通风排烟/燃油安全准用」、对外宣传「风机一开通风秒过」、把未实测写成已过、把旁路联锁写成秩序齐。允许做的：补通风台账、补排烟边界、重开燃油窗、挂 R/N/J、内部挂整改。

## 6. 工作实例（12 则，教学虚构，L3）

1. **风机绿拒签**：脱敏油机房-05 风机绿灯，无通风台账页 → AR-风拒签「通风排烟/燃油安全准用」；允许补账，不允许口头顶过。  
2. **口开着假绿**：油机房角色-C 排烟口看着开着，无书面边界与回灌核对记录 → 挂 R，补 AR-排后再谈会签。  
3. **看着有油假绿**：日用油箱液位看着有，无书面燃油窗与泄漏通气围堰方法 → AR-燃拒签；假绿可挂 R。  
4. **套邻站照片**：外包拷邻站上周通风/油箱照片改机房号交差 → AR-验拒签，责令本期本组本机房重测。  
5. **市电顶通风**：班长称「AF 油机市电签还在，通风燃油也能签」→ 拒签；切换过≠通风燃油过；主贴仍 AR。  
6. **气灭顶燃油**：AL 气灭疏散交底过，想免做燃油日用油箱巡检 → 拒签；气灭过≠燃油日用油箱过。  
7. **监控顶实测**：N 监控大屏绿，外包想免做本期实测 → 拒签；N 绿≠AR 过。  
8. **仪表顶窗**：AD 风速仪仍在准用期内，外包想免做燃油/通风窗 → 拒签；AD 只支撑设备准用，不顶 AR 窗。  
9. **旁路联锁 / 不安全泄油**：有人想旁路风机联锁消高温，或泄油消液位告警 → **禁**；挂整改 + N/R；本期未实测不得签准用。  
10. **风路变更未走 J**：私自改进风百叶或排烟路由未走变更 → 补走 J，触发再验 AR；未闭前禁签准用。  
11. **高温窗抬功率**：油机高温/低油位告警一片，网优想抬功率压掉话 → **禁功率战**；先 N 后 AR；上行更脆先问秩序。  
12. **群泄密**：宣传岗把真实油机房编号与油箱序列号发群表扬 → L3 违规，撤帖脱敏重发；治理勾 AR-治。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AR** 五子类：风 / 排 / 燃 / 验 / 治——双字母续写的第十八张，负责通风排烟·燃油安全「台账清不清、排烟有没有界、燃油有没有窗、本期过了没有」。  
- 故事：医院手术室/ICU 保供电机房备用柴油发电机房——风机绿灯≠通风合格；排烟口开着≠废气边界过；油箱看着有油≠燃油安全巡检过；AF 油机市电签≠通风燃油准用；AL 气灭过≠燃油日用油箱过；N 监控绿≠本期实测过；套邻站照片=拒签；AF/AL/AG/AP/AI/AO/AN/AD/AA/N/AQ 不顶替 AR；假绿≠会签放行。  
- 阶段梯：建通风台账 → 钉排烟边界 → 燃油窗钉死 → 本期实测 → 会签放行 → 变更再验。  
- 八条硬规则：**通风/燃烧空气台账钉死**；**排烟与废气有主有界有方法/准用期**；**燃油与日用油箱巡检窗与方法钉死**；**本组本机房本期实测禁套他站他期**；**会签才放行「通风排烟/燃油安全准用」**；**禁顶替 AF/AL/AG/AP/AI/AO/AN/AD/AA/N/AQ 等，主贴 AR，假绿≠放行挂 R**；**通风/排烟/燃油异常风暴挂 N、风路/排烟路由/油箱策略变更走 J、禁功率战、禁旁路风机联锁、禁不安全泄油**；**脱敏 L3**。  
- **AR vs AF**：AF = 油机市电切换与供电巡检；AR = 油机房通风台账 + 排烟废气边界 + 燃油日用油箱窗 + 本期实测 + 会签；AF 过 ≠ AR 过。  
- **AR vs AL**：AL = 气灭与应急疏散联锁；AR = 燃油与日用油箱安全巡检边界；AL 过 ≠ 燃油日用油箱过。  
- **AR vs N**：N = 电源监控/对时/告警风暴；AR = 通风排烟燃油巡检边界；N 绿 ≠ AR 过。
