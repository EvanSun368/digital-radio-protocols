## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **先证：许可/临时设台或既有机动边界（U/V）、检测贴签与准入（Y）、写频角色（K）、场地停车摆位边界齐再开站；缺任一项 → 拒开**。  
2. **本车本期：须本车本期实测上下行冒烟测最小集（含两时隙与驻波直觉）才可签「机动站可放行」；禁套他车他场他期旧测；假绿/远程看一眼不等于放行**。  
3. **开站有台账有主人有时限：可放行必须写入台账卡（主人角色、执勤时限/撤收预计）；无主人无时限视为未闭环**。  
4. **撤收清场齐才签「撤完」：天线/馈线/电源/频点与临时增益功率回写/日志归档/备件回库指针；禁口头撤、禁「撤了当没开过」**。  
5. **禁套：禁套他车他场过期贴签、禁套他车写频不经复核、禁套旧冒烟测改日期；清单不符即拒开/拒放行**。  
6. **可挂 V/Y/U/K/Z/J/R/S/T/Q 支撑，但机动开撤主贴 AC；屏绿、假绿、远程一眼都不等于已开站可放行（挂 R 提醒）**。  
7. **跨网挂 S，用户投诉挂 T；禁功率战；参数/临时增益变更走 J；趴窝变准固定评估 AB/J**。  
8. **对外/公开仓一律脱敏 L3；禁贴真实频点/站名/单位名/车号全文/坐标/联系人**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可、地面无线电台（站）规定决定「能不能设、按什么参数设」——**机动开站不是法外之地，先开着补手续不是合法捷径**。消防车出警与境外 COW/Deployable 公开资料只作故事与部署秩序类比（§2.2）：**先边界、再展开、使用前确认、撤场归位留记录**——翻译成本网语言就是 AC-界 / AC-开 / AC-验 / AC-撤。**这些是开撤秩序，不是「无证先开」「假绿放行」「口头撤场」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机动站可放行」「撤完」「本次开站正常」、对外宣传「分钟级无证开站」、把未清场写成「已归位」。允许做的：补许可/贴签/写频、补冒烟测、挂 S/T/U、内部挂待开/待放行/待撤清。

### 4.2 分诊题：这件事贴 AC 还是贴别的？

| 现场问题 | 先问 | 主贴 |
|----------|------|------|
| 固定楼站交维签没签清 | 是否长期固定站 | **Z** |
| 活动设备检了没、准入账在不在 | 贴签与清单 | **Y**（常挂 AC） |
| 执照/临时设台边界在不在 | 许可链 | **U / V** |
| 写频对不对 | 参数角色 | **K** |
| 这辆车这一趟能不能开 | 先证是否齐 | **AC-界 → AC-开** |
| 能不能放行手台进网 | 本车本期冒烟测过没 | **AC-验** |
| 撤完没有、临时参数回没回 | 清场清单 | **AC-撤** |
| 屏绿想打勾放行 | 有无本期实测 | **AC-治 + R** |
| 和旁边固定站互相吵 | 是否跨网 | **S** + 挂 AC |
| 趴窝两周还当临时 | 是否准固定 | **J + AB** 评估 |

### 4.3 本车本期冒烟测最小集（AC-验）——缺页不能签「可放行」

| 序号 | 最小集项（教学） | 为什么必须有 | 缺了会怎样 |
|------|------------------|--------------|------------|
| 1 | **本车本期标识**（车/机动站角色 + 开站时段角色） | 防套他车他期 | 对不上 → 拒放行 |
| 2 | **下行抽测**（承诺区/关键点角色） | 「基站还说得出去」 | 缺 → 拒放行 |
| 3 | **上行边缘抽测** | 临时天线与手台上行常先塌 | 缺 → 拒放行（头号坑） |
| 4 | **两时隙抽测** | 2-slot TDMA 两格都要能用 | 只测一格 → 拒放行 |
| 5 | **天线驻波 / 馈线直觉检查勾选** | 临时架设最易驻波漂 | 「感觉响」不够 |
| 6 | **电源与接地勾选（挂 AC-开）** | 油机/市电不稳先拖垮上行 | 缺项停在开或拒放行 |
| 7 | **与许可/写频边界一致核对** | 防开错道、越界功率角色 | 不符 → 挂 U/K，拒放行 |
| 8 | **测人/时间角色 + 仪器有效期指针** | 可复核 | 「测过了」三个字不够 |
| 9 | **共址/邻居预案勾选（必要时挂 S）** | 临时邻居互调与抬噪 | 高风险场次缺预案 → 慎放行 |

> **口诀**：车、下、上、隙、驻、电、界、人、邻——**九字冒烟钉**（教学记忆；现场以本网书面机动开站规程为准，但 **本车本期 + 上下行 + 两时隙 + 驻波直觉** 几乎不可砍）。  
> **弱项短补（为什么机动站特别要盯上行与驻波）**：固定站天馈经年调试；机动站今晚才绑的天线、临时盘的馈线、油机电压一抖，**下行「听起来还行」、上行先不够用**。用户感受是「调度喊得到我，我喊不回调度」。**只扫下行或只看屏绿就放行，等于消防车到场不试水压、只看泵组指示灯绿。**

### 4.4 开站前先证与展开清单（AC-界 / AC-开）——缺页不能开

| 清单项（教学） | 像消防车故事里的 | 未齐就开？ |
|----------------|------------------|------------|
| 许可/临时设台或既有机动边界（U/V） | 出警权限 | **否** → 拒开 |
| 检测贴签有效且本车本场一致（Y） | 器材年检标 | **否** |
| 写频与参数角色复核（K） | 对讲频道与呼号约定 | **否** |
| 场地停车摆位 / 进出通道 | 停车位与水源位置 | **否**（不安全则停） |
| 市电 / 油机 / 油量 / 切换预案 | 泵组动力 | 缺 → 停在开 |
| 接地 / 防雷直觉（以本网规程为准） | 现场电气安全 | 缺 → 停在开 |
| 天线架设安全（高度、拉线、周边） | 架梯与作业安全 | 缺 → 停在开 |
| 共址邻居知情/预案（必要时 S） | 与周边单位协调 | 高风险场次倾向必有 |

### 4.5 撤收清场清单（AC-撤）——缺页不能签「撤完」

| 清场项（教学） | 像消防车撤场 | 未齐就签撤完？ |
|----------------|--------------|----------------|
| 天线降落 / 拆收 / 固定运输态 | 收梯收装 | **否** |
| 馈线 / 跳线 / 接头清点回装 | 收水带 | **否** |
| 电源断开、油机冷却归位、线缆回收 | 停泵收线 | **否** |
| 临时频点 / 临时增益 / 临时功率**回写** | 阀门回位 | **否**（头号坑） |
| 开站日志 / 冒烟测记录归档 | 出警记录 | **否** |
| 金机 / 备件 / 测试手台回库指针（Q） | 器材归库 | 缺指针 → 不签撤完 |
| 场地恢复（锥桶、占位、垃圾） | 现场清场 | 以本网/场地要求为准 |
| 台账卡签「撤完」+ 主人确认 | 归队销单 | 口头不算 |

> **口诀**：天线馈线电源回、参数回写账归档——**撤清七字钉**（教学；**回写**与**归档**几乎不可砍）。

### 4.6 与 Z 固定站开站交维的分工表（钉死，防互相顶替）

| 问题 | Z（手册27） | AC（本篇） |
|------|------------|------------|
| 对象 | 固定站长期开站与交维 | 应急车/机动站**这一趟**开撤 |
| 典型输出 | 交维签字、资料齐、试运行 | 「可放行」+「撤完」+ 开撤台账 |
| 前置 | U/X/S/K/N/J-Q 等阶段梯 | U/V/Y/K/场地 + 本车本期冒烟 |
| 能否互相顶替 | **不能**用机动开站台账顶交维 | **不能**用交维报告省略本期冒烟测 |
| 超时/趴窝 | 固定侧变更走 J、复测走 AB | 机动变准固定 → 评估 J/AB，退出「临时」口径 |

> **口诀**：Z 像消防站建成验收；AC 像今晚这一趟出警——**验收证不能当出警单，出警单也不能当建成证**。

### 4.7 台账路径（一趟机动开站跑完）

| 时点（教学） | 台账动作 | 主贴 |
|--------------|----------|------|
| 任务下达 | 建开撤台账卡；填车/站角色、预计时限、主人 | AC |
| 开站前 | AC1–AC4 先证与展开勾选；缺项拒开 | AC-界/开 |
| 冒烟后 | AC5 九字冒烟钉；通过→AC6 签可放行 | AC-验 |
| 执勤中 | 时限监控；变更走 J；共址挂 S；投诉挂 T | AC+支撑 |
| 撤收 | AC7 清场七字钉；回写；归档；签撤完 | AC-撤 |
| 回库 | 备件/金机指针；交班口述；公开材料 L3 | AC+Q |

### 4.8 签字前 15 分钟清单（可复印）

| 分钟 | 动作 |
|------|------|
| 0–3 | 打开台账卡：车/站角色、主人、时限、当前阶段（待开/待放行/执勤/待撤） |
| 3–6 | AC1–AC3：许可、贴签、写频是否本车本场本期 |
| 6–9 | AC4：摆车架设电源接地天线安全勾选 |
| 9–12 | AC5/AC6：九字冒烟钉是否本车本期；本人签可放行 |
| 12–15 | 若撤收：AC7 清场回写归档；拒签卡；交班口述；L3 |

夜班压缩版：至少确认「**先证齐 + 本车本期冒烟指针在 + 有主人有时限 + 撤则清场回写在**」四项——**四项缺一仍禁签可放行与撤完**。

### 4.9 「可放行」vs「待开/待撤清」状态表（钉死）

| 状态 | 含义（教学） | 允许对外口径（L3） |
|------|--------------|-------------------|
| 待开 | 先证或展开未齐 | 内部准备；禁宣传「已开站」 |
| 待放行 | 已展开、冒烟未过或未签 | 禁放行手台进网当正式 |
| 可放行 | 冒烟通过+本人签+台账有主人时限 | 可说「机动站按规程放行」（禁贴频点车号） |
| 待撤清 | 任务结束、清场未齐 | 禁签「撤完」；禁留临时参数 |
| 已撤完 | 清场回写归档齐 | 可内部销单；公开仍 L3 |
| 冻结 | 越界/干扰/安全项 | 禁功率战硬顶；挂 S/U/J |

> **口诀**：开、放、撤三段闸；**假绿与口头，过不了任何一闸**。

## 5. 现场映射：原话速查、对话脚本、夜班、禁写词、交班口述

### 5.1 原话 → 贴纸速查

| 你听到的原话 | 先贴 | 下一句该问 |
|--------------|------|------------|
| 「执照复印件在，先开着」 | AC-界 | 许可边界指针？临时设台/机动批复在？ |
| 「他车贴签撕过来贴」 | AC-治 | 本车本场有效贴？Y 准入账一致吗？ |
| 「屏绿了，手台进网吧」 | AC-验 + R | 本车本期上下行冒烟测指针？ |
| 「撤了当没开过」 | AC-撤 | 清场清单？临时增益回写了吗？台账呢？ |
| 「机动开三天等于交维了」 | AC-界 vs Z | 固定站还是机动这一趟？别混贴纸 |
| 「趴窝两周还临时着」 | J + AB | 是否触发准固定评估？ |
| 「功率抬一点压邻居」 | AC-治 + S | 禁功率战；跨网挂 S |
| 「车号频点发群表扬」 | AC-治 | 脱敏 L3；立刻撤回公开 |

### 5.2 三段对话脚本（可练）

**脚本 A · 拒开（先证不齐）**  
对方：「车到了，先开着，手续明天补。」  
你：「AC-界：许可/贴签/写频/场地四项，今晚缺哪项？缺一项我拒开，不是拒支援——是拒无边界发射。」

**脚本 B · 拒放行（假绿）**  
对方：「网管屏全绿，放行吧。」  
你：「AC-验：本车本期下行、上行、两时隙、驻波勾选在哪？假绿挂 R，主贴 AC；没有九字冒烟钉我拒签可放行。」

**脚本 C · 拒撤签（口头撤）**  
对方：「撤完了，临时增益先留着下次省事。」  
你：「AC-撤：天线馈线电源、参数回写、日志归档、回库指针——七字钉缺一不签撤完。留临时增益等于阀门不回位。」

### 5.3 夜班压缩卡（四问）

1. **界**：许可·贴签·写频·场地，本车本场本期齐不齐？  
2. **验**：九字冒烟钉指针在不在？谁签的可放行？时限到没到？  
3. **撤**：若任务结束，清场回写归档齐不齐？  
4. **治**：有没有套贴、假绿、功率战、公开泄密？

### 5.4 禁写词（三联单/交班）

- 禁：真实频点、车号全文、GPS 坐标、单位全称、联系人电话。  
- 禁：「先开着再说」「假绿也算」「撤了当没开过」「套他车贴」。  
- 改写：用角色编号、相对道号、阶段状态（待开/可放行/待撤清/已撤完）。

### 5.5 交班口述 30 秒模板

> 「AC 机动开撤：车/站角色××，阶段××；先证 AC1–3 ××；冒烟 AC5 ××；可放行签××、时限××；共址 S ××；待撤清项××；公开材料已 L3。下一班先对时限与清场回写。」

## 6. 工作实例（10 则，教学虚构，L3）

1. **无许可先开**  
   现象：重大活动前夜，项目经理要求「车到即开」。  
   处置：AC-界 拒开；补 U/V 许可指针与 Y 贴签后再进 AC-开。  
   教训：支援速度不等于无边界发射。

2. **套他车过期贴签**  
   现象：写频员把另一辆车的检测贴撕到本车。  
   处置：AC-治 + Y；清单不符拒开；重新本车检测贴签链。  
   教训：贴签跟人/车/场绑定，不跟「看起来像」。

3. **假绿放行**  
   现象：网管远程屏绿，班长签「可放行」。  
   处置：挂 R；撤销放行；补 AC-验 九字冒烟钉（尤其上行与驻波）。  
   教训：假绿≠出水点检。

4. **只测下行不测上行**  
   现象：下行场强「还行」，手台上行边缘全军覆没。  
   处置：拒放行；补上行与两时隙；弱项短补复盘。  
   教训：机动站上行更脆。

5. **口头撤场留临时增益**  
   现象：任务结束，天线收了，临时增益档位未回写。  
   处置：拒签撤完；强制回写并归档；交班点名。  
   教训：撤清七字钉，回写不可砍。

6. **用 AC 台账顶 Z 交维**  
   现象：固定楼站资料不齐，拿「应急车开过三天」交差。  
   处置：分诊回 Z；AC 只证明机动这一趟，不顶交维。  
   教训：出警单≠建成验收证。

7. **共址临时邻居功率战**  
   现象：与固定站互相抬功率压对方。  
   处置：禁功率战；挂 S；AC 台账记录联测窗指针；必要时降功率或改摆位（走 J）。  
   教训：跨网秩序大于「谁声音大」。

8. **写频克隆他车未复核**  
   现象：为赶时间克隆他车码片，载频角色与本场许可不符。  
   处置：拒开/拒放行；回挂 K/U；按本场边界重写并复核。  
   教训：克隆不是复核。

9. **趴窝变准固定不评估**  
   现象：机动中继在工地趴窝三周，仍称「临时」，从不复测。  
   处置：触发 J/AB 评估；退出纯 AC「临时」口径或补周期与变更。  
   教训：日历会揭穿「临时」。

10. **公开仓泄密**  
    现象：宣传岗把车号全文、摆车坐标、临时频点发到公开群。  
    处置：AC-治；撤回；L3 重发；三联单记治理。  
    教训：响应速度可以表扬，细节必须脱敏。
