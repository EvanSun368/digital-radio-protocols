## 1. 为什么要写这篇手册（动机 + 现场对话）

前二十九篇手册从 A–E 协议一路写到 AB 室分复测：其中 **V 回答「重大活动设备检没检、贴没贴」**，**Y 回答「贴签与准入台账齐不齐」**，**Z 回答「固定站开站交维签没签清」**，**U 回答「执照 / 许可边界在不在」**，**K 回答「写频参数角色对不对」**。可还没有单独钉死一件事——**应急通信车 / 机动中继 / COW 类快速开站，开之前要先证什么？冒烟测过了才能放行吗？开了几天怎么撤？和固定站交维是不是一回事？趴窝变「准固定」要不要走 AB/J？** 这就是本篇的 **AC**——**应急通信车 / 机动站快速开站与撤收边界**。

- 项目经理：「执照在仓库复印件有，先开着，明天补手续。」——**无许可/临时设台边界仍开站** = 本篇拒开（规则1）。  
- 司机：「上次那辆车的检测贴签还能看清，撕下来贴这辆。」——**套他车他场过期贴** = 规则5。  
- 写频员：「临时活动信道我昨天写过别的车，克隆一份。」——**套他车写频 / 角色不符** = 规则1 / 规则5（回挂 K）。  
- 网管：「屏全绿、远程看一眼，手台可以进网了。」——**假绿顶替本车本期冒烟测** = 规则2 / 规则6。  
- 协调岗：「撤场了当没开过，临时增益先留着下次省事。」——**口头撤、不清场、不回写** = 规则4。  
- 班长：「机动站开了两周，等于固定站交维完了，别再折腾签字。」——**用 AC 临时开站顶 Z 交维** = 与 Z 分工不清。  
- 施工队：「天线临时拧高一点、功率抬一档压邻居。」——**功率战** = 规则7。  
- 宣传岗：「把车号、临时频点、摆车坐标发群里表扬响应速度。」——**L3 违规** = 规则8。  

这几句背后是同一件事：

> **「应急通信车 / 机动站快速开站与撤收」在现场至少有五个坑**：**① AC-开** 开站前先证（许可/临时设台或既有机动边界、检测贴签、写频、场地停车摆位、电源接地、天线安全）；**② AC-验** 本车本期上下行冒烟测最小集才可签「机动站可放行」；**③ AC-撤** 撤收清场清单齐才签「撤完」；禁口头撤、禁留临时增益/功率未回写；**④ AC-界** 与固定站 Z 交维分工；许可/贴签/写频/场地边界；趴窝变准固定回挂 AB/J；**⑤ AC-治** 治理（假绿、套他车、无台账、功率战、泄密）。  
> 把 ①–⑤ 当成「先开着再说」「屏绿就能放行」「撤了当没开过」，每一次重大活动、每一次灾害机动、每一次临时补盲，都会先吵「到底有没有许可、谁签的放行、撤完没有、临时参数回没回写」。

本篇目标：能背出**机动站开撤工作流**；会用新贴纸 **AC（开 / 验 / 撤 / 界 / 治）**；会填**插页 AC（AC1–AC8）**和《本网应急通信车/机动站开撤台账卡》；能用「**消防车出警：到场摆车 → 出水前点检 → 撤场收装归位**」故事讲清先证再开、点检才出水（放行）、撤场必须归位台账；能拒绝无许可先开、假绿放行、套他车贴、口头撤、功率战；自测过关后，回库把本网最近一次机动开站（L3）重对一遍：开站前证照链、冒烟测、放行签、撤收清场与回写。

**本篇硬禁令（写进脑子）**：凡引法规与标准只指向已公开发布的文书标题与官方链接（无线电管理条例、频率使用许可管理办法、地面无线电台（站）管理规定、国无办〔2025〕1号；**只作故事类比**的消防车出警摆车/出水前点检/撤场归位公开直觉，以及公开的 COW / 便携中继 / 应急通信部署资料），**程序、期限、责任以原文与属地最新要求及本网制度 / 合同为准，本篇只作教学转述，不发明条款号与内部口径**；消防车出警与境外 COW/Deployable 公开资料**不是**中国专网台站法定依据；**现象与台账一律用相对道号、角色标签、脱敏编号，禁真实频点 / 站名 / 单位名 / 车号全文 / 坐标 / 联系人**；**不教伪造开站记录、不教功率战、不教规避监测、不教无许可先开站、不教假绿顶替、不教套他车过期贴**；V / Y / Z / U / K / Q / J / S / T / R / X / AA / AB 各管各的——**机动快速开撤边界主贴 AC**；ITU 应急电信、DHS COW/便携中继、FirstNet Deployable 等公开资料只借**部署秩序与清场意识**，**许可、贴签、写频、放行与撤收签字以本网制度与属地要求为准**。

## 2. 总图 / 故事：机动开撤像「消防车出警：到场摆车 → 出水前点检 → 撤场收装归位」

### 2.1 一句话：应急车开站不是「车到了就能出水」——要先有出警许可与摆位边界，出水前必须点检（冒烟测），撤场必须收装归位留台账；固定站交维像「这座消防站长期建成验收」，机动开站像「这辆车今晚这一趟出警」

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  消防车出警摆车+点检+撤场  =  本网应急车/机动站开站+放行+撤收 │
   │                                                              │
   │  出警许可·停车摆位·水源边界 ≈ AC-界  许可·贴签·写频·场地     │
   │  到场摆车·架梯·接水带       ≈ AC-开  摆车·架天线·上电·接地   │
   │  出水前点检·试压·沟通       ≈ AC-验  本车本期上下行冒烟测    │
   │  允许出水 / 指挥下达        ≈ AC-验→放行  签「机动站可放行」 │
   │  撤场收装·归位·出警记录     ≈ AC-撤  清场清单·回写·台账归档 │
   │  无证出水·假绿·留临时接头   ≈ AC-治  假绿·套贴·口头撤·功率战 │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **先证再摆，点检才放，撤清才签，禁套他车。**  
> 车到了就放行手台 = 消防车到场不点检就出水——**拒签「机动站可放行」**。  
> 撤场当没开过、临时增益留着 = 水带接头扔现场、压力阀不回位——**拒签「撤完」**。

### 2.2 「消防车出警摆车 + 点检 + 撤场」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **边界** | 出警权限、停车位、水源与周边安全距离书面清楚 | 频率/执照/临时设台或既有机动许可、检测贴签、写频角色、场地停车与共址预案 | AC-界 |
| **开站** | 到场摆车、架梯、接水带、启动泵组 | 摆车、架天线、馈线、市电/油机、接地防雷直觉、上电 | AC-开 |
| **点检/放行** | 出水前点检、试压、与指挥沟通确认可出水 | 本车本期上下行冒烟测最小集通过 → 签「机动站可放行」 | AC-验 |
| **撤收** | 收装水带、归位阀门、清点器材、出警记录归档 | 天线馈线电源频点临时增益回写、日志归档、备件/金机回库指针 | AC-撤 |
| **治理** | 无证出水、用他车器材顶、假绿、留临时接头不回位 | 假绿、套他车贴、口头撤、功率战、公开泄密 → 拒签 / 治理 | AC-治 |

> 公开文书与公开部署资料告诉我们（**教学转述，以原文为准**）：应急出动讲究**许可边界、到场展开、使用前确认、撤场归位与记录**；境外 COW / Deployable / 便携中继公开资料强调**可运输、可快速部署、供电与回传、事后回收**（出处见 §10）。本篇只借这串顺序直觉——**本网机动开站许可、贴签、写频、放行与撤收以属地要求与本网制度为准，消防车故事与境外 Deployable 资料不是台站法定依据**。

### 2.3 和手册22 / 23 / 26 / 27 / 08 / 11 / 19 / 20 / 21 / 25 / 28 / 29 等的咬合（指针，不重写）

- **U（手册22）/ V（手册23）**：执照、临时设台或既有机动许可边界是 AC-界 的**前置**；无边界先回 U/V，不急着 AC-开。  
- **Y（手册26）**：检测贴签与准入台账是 AC 开站前的**贴签链**；重大活动场次常与 Y 同场咬合——Y 管「机子检了没、准入账在不在」，AC 管「这辆车本期开没开、放没放、撤没撤」。  
- **Z（手册27）**：**固定站**开站验收与交维签字；**AC ≠ Z**——机动快速开撤不能顶替固定站交维，固定站交维也不能省略机动开站的本期冒烟测。  
- **K（写频相关篇）**：写频与参数角色是 AC-界 / AC-开 前置；禁套他车码片不经复核。  
- **Q / N**：金机、备件、联测窗可在撤收回库与共址预案时指针挂回。  
- **J（手册11）**：临时功率/增益/载频角色变更走 J；机动站**长期趴窝变准固定**须评估变更与复测（指针 AB）。  
- **S（手册20）/ T（手册21）**：与固定站共址临时邻居挂 S 预案；用户投诉挂 T；禁功率战。  
- **R（手册19）**：屏绿 ≠ 已开站可放行；挂 R 提醒，主贴 AC。  
- **X（手册25）**：若机动开站需要环境报告类证据，方法级指针回 X；**日常冒烟测最小集仍是 AC-验 本职**。  
- **AA / AB**：首年巡检与室分复测管固定侧长期秩序；机动趴窝变准固定时，**触发复测 / 变更回挂 AB/J**，不是 AC 单独能「永久化」。

### 2.4 新贴纸 AC：开 / 验 / 撤 / 界 / 治（五个子类）

> 小彩蛋：双字母贴纸续写——**AA** 管「交维后首年还在保的巡检与尾项」；**AB** 管「室分 / 隧道电磁环境还合不合格」；**AC** 管「应急车 / 机动站这一趟开没开清、放没放清、撤没撤清」。A–Z 既有含义不改；新专题用 AA、AB、AC… 续写。

```text
                ┌──────────── 贴纸 AC · 开/验/撤/界/治 ────────────┐
                │  AC-开  开站展开：摆车·架天线·上电·接地·馈线     │
                │  AC-验  本期实测：上下行冒烟测·两时隙·驻波直觉   │
                │  AC-撤  撤收清场：天线馈线电源·频点回写·台账归档 │
                │  AC-界  边界前置：许可·贴签·写频·场地·与Z分工   │
                │  AC-治  治理：假绿·套贴·口头撤·功率战·泄密       │
                └──────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒开 / 拒放行 / 拒撤签触发 |
|------|--------|--------------------------------|
| **AC-界** | 无许可/贴签/写频/场地边界仍要开 → 拒开 | 「执照复印件在仓库」 |
| **AC-开** | 摆车架设上电缺项、天线不安全仍要冒烟 → 停在开 | 「天线先凑合绑一下」 |
| **AC-验** | 无本车本期冒烟测、假绿、套旧测 → 拒放行 | 「远程屏绿就放行」 |
| **AC-撤** | 清场不全、临时增益未回写、口头撤 → 拒签撤完 | 「撤了当没开过」 |
| **AC-治** | 套他车、功率战、公开泄密、无台账 → 治理 | 「他车贴撕过来」 |

### 2.5 先证边界 → 开站展开 → 冒烟放行 → 执勤 → 撤收签字 阶段梯（背下来）

```text
  ① AC-界 先证：许可/临时设台或机动边界 · 贴签Y · 写频K · 场地停车
        │  缺任一项 → 拒开（不是「先开着补」）
        ▼
  ② AC-开 展开：摆车 · 架天线 · 馈线 · 市电/油机 · 接地防雷直觉
        │  安全与缺项未清 → 停在开，不进验
        ▼
  ③ AC-验 本车本期冒烟测最小集（上下行·两时隙·驻波直觉）
        │  跨网可疑 → 挂 S；投诉 → 挂 T；参数不符 → 挂 U
        ▼
  ④ 通过 + 授权签字 → 签「机动站可放行」（有主人、有时限）
        │  假绿/旧测/他车测 → 拒放行
        ▼
  ⑤ 执勤窗内：台账在线；重大变更走 J；超时/趴窝评估 AB/J
        ▼
  ⑥ AC-撤 清场清单齐 + 回写 + 归档 → 签「撤完」
        │  口头撤 / 留临时增益 / 无台账 → 拒签撤完
        ▼
  ⑦ 金机/备件回库指针（Q）· 日志归档 · 交班口述
```

> **一句话分辨**：**Z** 回答「这座**固定站**交维签没签清」；**Y** 回答「这台机**检测贴签与准入**齐不齐」；**V/U** 回答「**许可 / 活动检测**边界在不在」；**AC** 回答「这辆应急车 / 这座机动中继**这一趟**开没开清、放没放清、撤没撤清」。**四个问题，四张贴纸，不能一笔带过。**

```text
  AC-开 展开（摆车架设上电） ──缺项──→ 停在开
       │齐
       ▼
  AC-验 本车本期冒烟测 ──不过──→ 拒放行 / 整改再测
       │过
       ▼
  签「可放行」+ 主人 + 时限写入台账
       │
       ▼
  执勤（变更走J；共址挂S；投诉挂T；假绿挂R）
       │
       ▼
  AC-撤 清场+回写+归档 ──不齐──→ 拒签撤完
       │齐
       ▼
  签「撤完」· 回库指针 · 交班
```

## 3. 核心交付：插页 AC + 拒开/拒放行/拒撤签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AC（而不是先贴 Z / Y / V / U）

| 场景 | 主贴 | 为什么 |
|------|------|--------|
| 应急车 / 机动中继 / 临时补盲站**这一趟**要开、放、撤 | **AC** | 本篇主职 |
| 固定楼站开站交维签字 | **Z** | 长期交维 ≠ 机动开撤 |
| 重大活动设备检测贴签与准入台账 | **Y**（常与 AC 同场） | Y 管贴签准入；AC 管开撤放行 |
| 执照/临时设台/既有机动许可边界不清 | **U / V** 先 | 边界是 AC-界 前置 |
| 写频参数角色不对 | **K** 先 | 写频是开站前置 |
| 屏绿想当已放行 | **AC-治 + R** | 假绿≠放行 |
| 与固定站共址吵起来 | **S** + 挂 AC | 跨网秩序 |
| 用户投诉「临时站没用」 | **T** | 投诉链；本网仍回 AC 台账 |
| 机动站趴窝变准固定 | **J + AB** 评估 | AC 不能永久化 |

### 3.2 插页 AC · 开 / 验 / 撤 / 界 / 治（挂在总三联单或开撤单后）

| 插页 | 检查项（教学） | 过闸？ |
|------|----------------|--------|
| **AC1** | 许可/临时设台或既有机动边界指针在（U/V）；本车/本站角色标识在 | 缺 → **拒开** |
| **AC2** | 检测贴签有效且与本车本场清单一致（Y）；禁套他车他场过期贴 | 缺/套 → **拒开** |
| **AC3** | 写频与参数角色复核在（K）；与许可边界一致 | 缺 → **拒开** |
| **AC4** | 场地停车摆位 / 市电油机 / 接地防雷直觉 / 天线架设安全勾选 | 缺 → **停在开** |
| **AC5** | 本车本期冒烟测最小集：下行、上行、两时隙、驻波直觉、测人/时间角色 | 缺 → **拒放行** |
| **AC6** | 「机动站可放行」签字：授权角色本人签；台账有主人、有时限 | 缺 → **拒放行** |
| **AC7** | 撤收清场：天线馈线电源、频点/临时增益/功率回写、日志归档、备件回库指针 | 缺 → **拒签撤完** |
| **AC8** | 脱敏 L3：公开材料无真实频点/车号全文/坐标/联系人；禁宣传「无证秒开」 | 违 → **治理** |

> 插页每一行都对应一条硬规则：AC1–AC3→规则1与规则5，AC5/AC6→规则2与规则3，AC7→规则4，AC8→规则8，假绿→规则6。**任何一行缺项，就停在那一行。**

### 3.3 和总三联单怎么写（接手册06）

- **现象栏**：写「机动开站缺项 / 冒烟测未过 / 撤收清场不齐」等角色描述；**禁**写真实频点、车号全文、坐标。  
- **贴纸栏**：主贴 **AC**；支撑可贴 Y / U / V / K / Z（对照）/ J / S / T / R。  
- **处置栏**：拒开 / 拒放行 / 拒撤签 / 补证 / 补测 / 清场回写 / 挂 S——**写动作，不写空口字段**。  
- **脱敏**：公开仓与交班群只留角色编号与相对道号。

### 3.4 《本网应急通信车/机动站开撤台账卡》预告

§7 给出可复印模板：封面拒签门槛、边界页、开站展开页、冒烟与放行页、撤收清场页、夜班速填五行。**一张卡跑完一趟开→放→撤**；与 Y 准入账、U/V 许可指针、K 写频单号角色对齐，避免「开了没账、撤了无痕」。
