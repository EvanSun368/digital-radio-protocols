## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **联测窗与方法钉死：无书面联测窗（天窗/封锁点角色）与方法（挂 X/I 指针）不得开测、不得签放行；该到场未到场视为联测未完成**。  
2. **换乘/责任界面主人清楚：换乘站、换乘通道、线际与漏缆-室分衔接须有书面主人角色与配合清单；口头分界无效**。  
3. **本区间本期实测：须本脱敏区间、本联测窗、上下行双时隙实测；禁套他区间/他站/他期报告；半段不得顶整段**。  
4. **联测通过才签：界面各方授权本人会签后，方可签「区间/换乘放行」；重大未闭项禁放行**。  
5. **禁顶替：可挂 X/I/AB/S/Z/AC/AD/R 支撑，但区间联测与换乘责任界面主贴 AE；AB 室分绿、X 单点绿、Z 他阶段签均不得顶替 AE 联测签**。  
6. **主贴 AE；监测大屏/系统绿灯、假绿不等于联测通过（挂 R 提醒）**。  
7. **跨网挂 S，投诉挂 T；禁功率战抬功率「压」换乘弱场；覆盖/写频/漏缆变更走 J 并评估再联测**。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/线路名/区间桩号/频点/可还原场强表/联系人**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**半段冒充整段、无联测放行，不是法外运维智慧**。城轨通信验收/专用无线与消防分区联测公开资料只作故事与方法类比（§2.2）：**窗要约、界要清、联要测、单边不算过**——翻译成本网语言就是 AE-联 / AE-换 / AE-界 / AE-测 / AE-治。**这些是联测秩序，不是「半段绿先开通」「拷邻区报告」「抬功率压弱场」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「区间/换乘放行」、对外宣传「分钟级半段绿秒过」、把未联测界面写成已过。允许做的：补窗、补主人、重测、挂 R/S/J、内部挂整改。

### 4.2 分诊题：这件事贴 AE 还是贴别的？

| 现场问题 | 先问 | 主贴 |
|----------|------|------|
| 覆盖布点怎么抽 | 方法 | **X / I** |
| 站厅室分到期该不该复测 | 周期/变更 | **AB** |
| 两网在换乘站互相吵 | 互扰 | **S**（挂 AE） |
| 整站能不能交维 | 阶段梯 | **Z**（看 AE 签） |
| 这段区间联测窗约了没 | 窗与到场 | **AE-联** |
| 换乘通道谁负责无线 | 主人清单 | **AE-换/界** |
| 邻区间报告能不能用 | 是否本区本期 | **AE-测/治** |
| 大屏全绿想放行 | 有无会签 | **AE-治 + R** |
| 漏缆接头换了要不要再测 | 变更 | **J + AE**（室分侧常挂 AB） |

### 4.3 「联测放行」最小集（AE）——缺页不能签「区间/换乘放行」

| 序号 | 最小集项（教学） | 为什么必须有 | 缺了会怎样 |
|------|------------------|--------------|------------|
| 1 | **书面联测窗**与到场角色勾选 | 无窗则测无可追溯 | 拒开测/拒签 |
| 2 | **方法书面**（X/I 指针）含上下行双时隙 | 防只测好看的一侧 | 拒测 |
| 3 | **界面主人**与配合清单 | 防推诿 | 拒签 |
| 4 | **责任分界**角色图/表 | 防口头界 | 拒签 |
| 5 | **本区间本期**实测记录 | 防套报告 | 拒签 |
| 6 | **衔接处抽样**记录 | 换乘/接头最脆 | 该抽未抽→整改或拒 |
| 7 | **各方本人会签** | 可复核 | 「系统绿」不够 |
| 8 | **重大未闭清单**（若有）有主有期 | 带病放行禁 | 重大未闭→拒放行 |
| 9 | **公开材料 L3** | 防定位泄露 | 违→治理 |

> **口诀**：窗、法、主、界、区、衔、签、闭、密——**九字联测钉**（教学记忆；现场以本网书面联测规程为准，但 **书面窗 + 界面主人 + 本区本期实测 + 会签** 几乎不可砍）。  
> **弱项短补（为什么上行更先不够用）**：隧道里手台贴漏缆走，下行（基站→手台）往往还「听得见」，上行（手台→基站）功率小、耦合损失大，**先哑在上行**——只报下行绿就签放行，等于消防联测只看「本区烟感亮了」不看「对面排烟启没启」。这和换乘通道只测本侧话音、不测跨线呼叫一样危险。

### 4.4 联测窗清单（AE-联）——缺页不能开测

| 清单项（教学） | 像消防联测预约 | 未齐就开测？ |
|----------------|----------------|--------------|
| 窗日期/时段角色书面 | 预约联测日 | **否** |
| 到场角色：区间侧、站台/室分侧、换乘对侧（若适用） | 双方到场 | **否** |
| 方法附件或指针（X/I） | 联测方案 | **否** |
| 安全/封锁要点角色勾选（教学，不写真实规程） | 作业安全交底 | 按本网安全制度 |
| 测试机/金机准用指针（AD） | 器具有效 | 过期器具→拒出具定量结论 |

### 4.5 界面与换乘清单（AE-换 / AE-界）

| 项（教学） | 像分区界与通道移交 | 未齐？ |
|------------|---------------------|--------|
| 换乘通道无线主人角色 | 通道责任方 | 无主→拒签 |
| 线A/线B 车控室配合项（通话等角色） | 互送/互通联测项 | 缺项→记整改 |
| 漏缆↔室分衔接点角色列表 | 分区界设备 | 无列表→拒签 |
| 分界图/表与现场一致 | 责任分界图 | 口头→无效 |
| 投诉/弱场历史指针（T） | 联测前已知病 | 已知重大病未闭→慎放行 |

> **口诀**：有主、有界、有清单、有对侧——**界面八字钉**（教学；**有主有界**几乎不可砍）。

### 4.6 与 X/I / AB / S / Z 的分工表（钉死，防互相顶替）

| 问题 | 谁主答 | AE 做什么 |
|------|--------|-----------|
| 怎么布点、判覆盖 | **X / I** | 要求方法指针进联测窗 |
| 室分何时复测、装修触不触发 | **AB** | 室分侧可并行；不顶区间联测签 |
| 跨网互扰 | **S** | 联测中发现互扰挂 S |
| 整站交维 | **Z** | 交维看 AE 联测是否已签 |
| 这段区间/换乘能不能放行 | **AE** | 主职 |

> **口诀**：X/I 是量法，AB 是室分日历，S 是邻居吵架，Z 是整站户口本，AE 是**这一段隧道与换乘门卫联检有没有双方到齐签字**。

| 分钟 | 动作 |

| 3–6 | AE1/AE2：窗与到场、方法含上下行双时隙？ |

### 4.9 「半段 / 单边 / 假绿」对照表（钉死）

| 现象 | 像消防联测 | AE 处置 |
|------|------------|---------|
| 只测下行不测上行 | 只看烟感不看排烟联锁 | 拒签；补上行 |
| 只测区间中段不测衔接 | 只测分区中心不测防火门 | 补衔接抽样 |
| 本侧绿、对侧未到场 | 单侧签字 | 拒签放行 |
| 室分 AB 绿想顶区间 | 用感烟年检顶分区联锁联测 | 规则5 禁顶替 |
| 大屏全绿无会签 | 监控室绿灯当验收 | 挂 R；主贴 AE |

### 4.10 漏缆 / 室分 / 机动补盲 与 AE 的咬合

| 情况 | 他贴 | AE |
|------|------|-----|
| 漏缆接头更换 | 变更走 J；方法可挂 X | **再开联测窗**；衔接处必抽 |
| 站厅装修改室分 | **AB** 触发复测 | 若影响换乘通道界面 → AE 同步 |
| 隧道口机动车补盲 | **AC** 开撤 | 补盲若声称「顶区间合格」→ **AE 拒认**，除非进正式联测窗 |
| 金机/测试机过期 | **AD** | 拒出具定量联测结论 |

### 4.11 与开站交维（Z）/ 首年巡检（AA）怎么配合

开站阶段梯（手册27）里，区间/换乘联测通常落在覆盖验证与试运行前后——**Z 签字人应核对 AE7 会签**；缺 AE 联测签，Z 可拒「带病交维」。交维后首年巡检（手册28）若抽到区间/换乘，**抽检结论可挂 AA，缺项整改主贴仍是 AE**。

### 4.12 投诉弱场（T）与跨网（S）在换乘站怎么并存

换乘站投诉「通道无信号」常同时触及：覆盖方法（X/I）、室分是否到期（AB）、是否跨网（S）、界面谁主（AE）。**分诊顺序教学建议**：先 AE 问「界面主人与最近联测窗」→ 再 X/I 看方法 → 有互扰挂 S → 投诉闭环挂 T。**不要**一上来抬功率。

## 5. 现场映射：原话速查、对话脚本、夜班、禁写词、交班口述

### 5.1 原话 → 贴纸速查

| 你听到的原话 | 先贴 | 下一句该问 |
|--------------|------|------------|
| 「区间中段够了，整条算过」 | AE-测 | 衔接处？上行？本区本期？ |
| 「换乘通道归土建」 | AE-换/界 | 无线主人书面？配合清单？ |
| 「邻区间报告拷过来」 | AE-治 | 本区本期窗号？禁套 |
| 「室分 AB 全绿，区间不用联测」 | AE-治 | 规则5：禁顶替；主贴 AE |
| 「大屏全绿，签放行」 | AE-治 + R | 会签？假绿≠通过 |
| 「对侧车控室今晚不来」 | AE-联 | 到场清单；未到场=未完成 |
| 「功率抬一点压通道弱场」 | AE-治 + S | 禁功率战 |
| 「桩号场强表发群表扬」 | AE-治 | 脱敏 L3；撤回 |

### 5.2 三段对话脚本（可练）

**脚本 A · 拒签（半段顶整段）**  
对方：「中段场强漂亮，开通节点紧，先签放行。」  
你：「AE-测：本区间本期要含衔接处与上行。半段绿≠整段过——不是拒开通，是拒带病放行。今晚能补抽样，我才能走会签闸。」

**脚本 B · 拒签（界面无主）**  
对方：「通道无线以后再说，先签站台。」  
你：「AE-换/界：换乘通道无书面主人与配合清单，放行签无效。把主人角色和分界写上，对侧到场，再联测。」

**脚本 C · 拒套报告**  
对方：「邻区间上周测过，拷一份改个号。」  
你：「AE-治：禁套他区间他期。要过闸，就本窗本区实测——改号不是联测。」

### 5.3 夜班压缩卡（四问）

1. **窗**：有没有书面联测窗与到场勾选？  
2. **主**：换乘/线际/衔接界面主人书面在？  
3. **测**：是否本区本期、上下行双时隙、衔接处有抽样？  
4. **治**：有没有半段顶整段、套报告、假绿、功率战、公开泄密？

### 5.4 禁写词（三联单/交班）

- 禁：真实站名、线路名、区间桩号、频点、可还原坐标场强表、联系人电话。  
- 禁：「半段就算过」「拷邻区报告」「室分绿顶区间」「抬功率压过去」「系统绿就行」。  
- 改写：用脱敏区间编号、窗角色、主人角色、相对道号。

### 5.5 交班口述 30 秒模板

> 「AE 联测：脱敏区间××窗××；界面主人××；今夜实测上下行双时隙××；衔接抽样××；会签××；整改未闭××；跨网 S××；公开已 L3。下一班先对未闭与对侧到场。」

## 6. 工作实例（12 则，教学虚构，L3）

1. **半段顶整段**  
   现象：只测区间中段下行，签发「全区间合格」。  
   处置：撤销；补上行与衔接；AE-测 拒认原签。  
   教训：半段绿不是整段过。

2. **换乘通道无主**  
   现象：站台签完，通道弱场投诉；双方互推。  
   处置：AE-换/界 书面定主人；重开联测窗。  
   教训：界面口头=事故温床。

3. **套邻区间报告**  
   现象：把邻区报告改脱敏号交差。  
   处置：AE-治；作废；本区本期重测。  
   教训：改号≠联测。

4. **AB 顶替 AE**  
   现象：室分复测全绿，班长主张区间免联测。  
   处置：规则5；主贴 AE；AB 仅支撑室分侧。  
   教训：日历绿≠界面联测过。

5. **假绿放行**  
   现象：网管全绿，无会签就对外宣布开通。  
   处置：挂 R；追 AE7；缺则改「未放行」。  
   教训：大屏≠会签。

6. **对侧未到场**  
   现象：线B 车控室未到，线A 单方签「换乘互通合格」。  
   处置：AE-联 认定未完成；拒签。  
   教训：单边签字像单侧防火联锁。

7. **只测下行**  
   现象：下行漂亮，上行掉话集中在漏缆远端。  
   处置：补上行；讲清弱项；拒原放行。  
   教训：上行往往先不够用。

8. **机动补盲冒充区间合格**  
   现象：AC 机动车在洞口补盲一夜，次日称「区间已好」。  
   处置：AC+AE；补盲≠联测窗；须正式 AE 联测。  
   教训：临时补盲不是验收。

9. **漏缆接头更换未再联测**  
   现象：换接头后直接恢复运营宣称合格。  
   处置：J + AE；衔接处重抽。  
   教训：硬件变了，联测要重生。

10. **功率战压换乘弱场**  
    现象：抬功率压邻居制式。  
    处置：禁功率战；挂 S；参数回写走 J。  
    教训：弱场要用联测与界面治理，不靠功率战。

11. **公开仓泄密**  
    现象：真实桩号+场强表发公开群。  
    处置：撤回；L3 重发；AE-治。  
    教训：联测效率可表扬，定位信息必须脱敏。

12. **金机过期仍出定量结论**  
    现象：联测用测试机校准过期，仍报精确 dBm 门限。  
    处置：AD+AE；结论降级或作废；换期内器具重测。  
    教训：尺歪了，联测数字不可信。
