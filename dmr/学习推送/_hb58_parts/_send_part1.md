> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：电极/蒸汽加湿与电导率/水质公开概述强调**有账要验、湿度绿≠准用、口头水质正常≠方法过、口头换过≠窗过、边界要有书面方法、水质与换罐要有本期核对秩序**（§10，**只借秩序直觉**；**本篇不写逐步关阀/开旁通/绕加湿联锁/不安全排空/带电违章操作教条**）；医院手术室/ICU 与数据中心 CRAC/CRAH electrode / steam humidifier canister 公开资料强调**环境绿≠水质/换罐合格、冷凝加湿联锁过≠水质换罐过、温湿度过≠换罐窗过、漏水探头过≠水质台账过、泵组定压补水过≠水质过、备件入库过≠本期换罐窗过、监控绿≠本期实测过**（§10，**只作故事类比**）。本篇只借这串顺序——**本网水质台账格式、换罐窗方法、边界顺序与合格门限以本网制度、合同与 OEM 书面为准**。

### 2.3 和手册47（AT）/ 36（AI）/ 42（AO）/ 57（BD）/ 31（AD）/ 15（N）等的咬合（指针，不重写）

- **AT（手册47）**：冷凝水与加湿除湿联锁；**AT ≠ BE**——冷凝加湿联锁过≠水质与换罐过；联锁可挂 AT，水质·电极/蒸汽罐更换主贴仍 BE；**不得用 BE 顶 AT，也不得用 AT 顶 BE**。**冷凝加湿联锁 ≠ 水质换罐准用**——钉死。  
- **AI（手册36）**：温湿度与空调联锁巡检；**AI ≠ BE**——温湿度过≠水质/换罐窗过。  
- **AO（手册42）**：漏水探测与汇流排；**AO ≠ BE**——漏水过≠水质台账过；水浸可挂 AO，水质主贴仍 BE（并挂 N 理风暴）。**漏水 ≠ 水质台账**——钉死。  
- **BD（手册57）**：冷冻水泵组与定压补水；**BD ≠ BE**——泵组/定压/补水过≠加湿器水质与换罐过；定压补水水质测点（若有）≠本篇加湿器水质台账。  
- **AD（手册31）**：电极罐/蒸汽罐/水质取样器具入库走 AD；**不能**用旧 AD 签日期顶本期 BE 换罐窗或实测窗。**备件入库 ≠ 本期换罐窗**——钉死。  
- **AX（手册51）**：精密空调压缩机与制冷剂；**AX ≠ BE**——压缩机/制冷剂过≠水质/换罐过。  
- **BA / AY / AZ / AU / BB / BC**：冷冻水冷却塔 / 新风正压 / 冷通道进出风 / 滤网气流 / 室外机冷凝侧 / 机柜PUE；均不顶替 BE。  
- **AW / AF / AS**：列头末端 / 油机市电 / UPS 旁路；供电过≠水质/换罐过。  
- **AN（手册41）**：门禁过≠水质换罐交底过；进机房仍要 AN；**不教绕过门禁/加湿联锁**。  
- **AA（手册28）**：首年巡检日历；水质/换罐抽检可挂 AA，缺秩序整改主贴仍 BE。  
- **N（手册15）**：监控/对时/告警风暴；水质/换罐异常风暴挂 N 理风暴，**不先抬功率**；**禁关阀冒充、禁开旁通、禁绕加湿联锁、禁不安全排空/带电违章**；N 绿≠ BE 过。  
- **AQ（手册44）**：水质/换罐异常事件要调录像 → 另开 AQ；视频过≠BE 准用。  
- **AV / AR / AG / AP**：油品/燃油/电池/内阻；均不顶替 BE。  
- **R / J / X / I**：假绿挂 R；变更（电导率门限、换罐窗方法、水源角色）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 BE 证水质与换罐秩序，再谈覆盖病**。

### 2.4 新贴纸 BE：水 / 罐 / 界 / 验 / 治（五个子类）

> 小彩蛋：双字母贴纸续写——**AA** 首年巡检；**AB** 室分复测；**AC** 机动开撤；**AD** 备件金机；**AE** 区间联测；**AF** 油机市电；**AG** 电池充电器；**AH** 合路/POI 界面；**AI** 温湿度联锁；**AJ** 天馈驻波；**AK** 爬塔交叉；**AL** 气灭疏散；**AM** 接地浪涌；**AN** 门禁访客；**AO** 漏水汇排；**AP** 内阻核对；**AQ** 视频调阅；**AR** 油机房通风燃油；**AS** UPS 旁路；**AT** 冷凝加湿联锁；**AU** 滤网压差气流；**AV** 日用油箱油品净化加油；**AW** 列头柜与末端配电巡检；**AX** 精密空调压缩机与制冷剂边界；**AY** 新风正压与防火阀；**AZ** 冷通道封闭与机柜进出风；**BA** 冷冻水与冷却塔侧边界；**BB** 风冷室外机与冷凝侧边界；**BC** 机柜配电与PUE/负载分区；**BD** 冷冻水泵组与定压补水；**BE** 管「机房加湿器水质与电极蒸汽罐更换」（**BD 之后第一张 BE**）。A–Z 既有含义不改；新专题用 AA、AB、AC… 续写。

### 2.5 建水质台账 → 钉换罐窗 → 边界方法钉死 → 本期实测 → 会签放行 → 变更再验 阶段梯（背下来）

```text
  ① BE-水 建水质台账：机房角色 · 水源 · 电导率/水质测点 · 软水/RO/去离子路径角色 · 禁「湿度绿就算过」「口头说水质正常」
        │  无账 / 湿度绿无实测 → 不签水质与换罐准用
        ▼
  ② BE-罐 钉换罐窗：主人角色 · 书面窗 · 方法 · 准用期 · 禁「湿度绿当窗过」「口头换过」
        │  无主人 / 无窗 / 无方法 / 无准用期 → 拒进入「可签」状态
        ▼
  ③ BE-界 钉边界方法：书面窗 · 方法（水质/换罐与冷凝加湿/温湿度/漏水边界；与 AT/AI/AO/AX/N 分工；以本网与 OEM 书面为准） · 到场角色 · AD 仪表/耗材准用指针
        │  无窗 / 「关阀冒充」/ 「开旁通」/ 「绕加湿联锁」/ 「不安全排空/带电违章」 → 拒边界签
        ▼
  ④ BE-验 本组本机房本期实测：实测记录 · 禁套他站他期水质/换罐表 · 会签
        │  套票 / 无会签 → 拒签
        ▼
  ⑤ 会签放行「机房加湿器水质与电极蒸汽罐更换准用」；假绿挂 R；风暴挂 N；变更走 J 后再验
```

### 2.6 签字前流程图（冻结清单入口）

```text
  要签「机房加湿器水质与电极蒸汽罐更换准用」？
        │
        ├─ 水质台账缺 / 湿度绿无本期核对 ────────→ 停 · 补 BE-水
        ├─ 换罐无主无窗 / 口头换过当过 / 湿度绿当窗过 → 停 · 补 BE-罐
        ├─ 无书面边界窗方法 / 关阀·旁通·绕联锁·排空带电违章 → 停 · 补 BE-界；禁关阀/旁通/绕联锁/不安全排空带电违章
        ├─ 套他站他期水质/换罐表 ──────────→ 停 · BE-验 拒签重测
        ├─ 用 AT/AI/AO/BD/AD/AN/AA/N/AQ/… 顶替 → 停 · 挂 R；主贴仍 BE
        └─ 以上皆过 + 会签 ───────────────────→ 可签准用（假绿≠放行）
```

### 2.7 一晚怎么走完（教学节奏，不替代本网书面规程）

1. 翻 BE1：水质台账在不在？湿度绿≠准用勾了没有？  
2. 翻 BE2：换罐主人/窗/方法/准用期；禁口头换过当窗过；禁湿度绿当窗过。  
3. 翻 BE3：边界书面方法；禁关阀/开旁通/绕加湿联锁/不安全排空/带电违章；AT/AI/AO/AX/N 分工勾清。  
4. 翻 BE4：本期实测；禁套声明。  
5. 会签或拒签；风暴挂 N；变更走 J；L3。
