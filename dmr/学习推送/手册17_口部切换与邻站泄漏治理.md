## 1. 为什么要写这篇手册（动机 + 现场对话）

前十六篇手册教你认病、交维、写频、电源监控、有源隔离：贴纸 A–E 协议层，F 射频，G 实验室，H 话务，I 室分，J 写频，K 电源，L 井库，M 批量/OTAP，N 监控/对时/风暴，O 有源隔离/减敏。可现场还有一类「病」——**不是洞内灯灭了，而是门口两家喇叭对着过道抢客，过客耳朵左右跳，洞里还灌进隔壁店的广告**：

- 施工队：「洞内走测过了，可以签。」——没人问口部切换区画在哪；开通两周门口乒乓投诉刷屏。  
- 新人：「门口一过就断，肯定是同频。」——没先问切换窗与邻站泄漏；假 F 工单满天飞。  
- 班长：「门口糊，邻站功率再加两格。」——外溢更大，洞内更吵；整段口部被自己抢客拖垮。  
- 射频同事：「洞内听到邻站，肯定干扰。」——可能是邻站泄漏进洞（P-泄）；先 P，再挂 F。  
- 领导：「加个站盖门口就行。」——切换窗未定义、泄漏未测就加站 = 门口再多一家喇叭。  
- 手册13 学过的人：「L-切 不是已经写过坡道猎站吗？」——L 管井库三维路径与门开闭；本篇是 **口部/出入口切换与邻站泄漏的加深册**，主贴新贴纸 **P**。  
- 手册10 学过的人：「I-覆 口部也测过。」——I 管交维清单气质；本篇钉死切换窗定义、泄漏测点、拒签门槛。  
- 有人：「加功率压一下门口断话。」——加功率是手册07/09/10/16 禁区；本篇也禁。

这几句背后是同一件事：

> **「口部切换 / 邻站泄漏」这个词在现场至少有五个坑**：  
> **① P-口**：口部/出入口覆盖与切换区定义——洞口、楼门、库坡道、换乘口；谁的优势区画到哪  
> **② P-切**：切换窗/驻留/乒乓/切换失败气质（制度层，**不 dump 空口字段**）——窗多宽、能不能停、会不会左右跳  
> **③ P-泄**：邻站泄漏进洞/进楼/进库——隔壁喇叭的声浪灌进你店里  
> **④ P-邻**：邻站参数与功率外溢边界（脱敏）——邻站该响到哪、不该响到哪  
> **⑤ P-治**：治理与拒签——口部未测禁签、金机口部走测、脱敏 L3  
> 把 ①–⑤ 当成「厂商切换参数自动搞定」或「出了事用手册07 先开同频单」，会把口部债与邻站外溢债留给整条走廊与下一班。

本篇目标：能背出**口部切换与邻站泄漏治理工作流**；会用新贴纸 **P（口部/切换/泄漏）** 与五个子类；会填 **插页 P（R1–R8）** 和《本网口部切换与邻站泄漏治理卡》；能用「**两家商店喇叭对着门口抢客**」或「**地铁换乘口两列车同时喊话**」故事讲清切换窗与泄漏；能拒绝「口部未测就签、用加功率掩盖邻站串音、未做金机口部走测、切换窗未定义就加站」；自测过关后，回库把本网最近一次口部/邻站相关事件（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：不发明 ETSI 条款号；**不写真实批复频点、真实楼宇名、真实站号、真实个号、真实密钥、真实单位名进公开仓库**；**不教干扰攻击、故意抬噪邻站、仿冒切换、空口劫持步骤**——只讲制度与治理；不重写手册13 / 10 / 07 / 16 / 09 全文（只给指针）；**手册13 的 L-切、手册10 的 I-覆 仍生效，本篇加深口部切换与邻站泄漏**；**不把加功率/加增益/盲目加站当乒乓与泄漏的止痛药**；口部/泄漏问题**主贴 P**，可挂 L/I/F/O，禁止把「门口左右跳」直接写成「用户捣蛋」或「协议玄学」；结案词用贴纸 P + 本网证据；公开蜂窝/ DAS 口部切换、泄漏控制、邻区规划资料只借**精神与顺序**——**不背条款号当 ETSI、不背厂商菜单当本网制度、不把蜂窝 RSRP 数字抄进 DMR 公开包当法规**。

## 2. 总图 / 故事：口部像「两家商店喇叭对着门口抢客 / 地铁换乘口两列车同时喊话」

### 2.1 一句话：必须先证明口部切换区画清、邻站泄漏可测、金机口部走测过关，再谈加站加功率——否则门口抢客、洞内串音、交维假绿

   ┌──────────────────────────────────────────────────────────────┐

   │   店 A 喇叭 = 本站/本扇区覆盖 ——P-口 的「自己店」              │

口诀：

> **先画门口，再定切换窗，后测泄漏，末金机走测。**  
> 两家喇叭对着门口抢客还不划界 = 换乘口两列车同时喊话——**切换窗必须可指认。**  
> 只测店内不测门口 = 交维假绿——**口部/出入口金机走测强制。**

### 2.2 「门口抢客」五段直觉（弱项短补，钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **口部定义** | 店门口过道画在哪 | 洞口/楼门/坡道/换乘口的优势区边界；室内外过渡带 | P-口 |
| **切换窗** | 过客该在哪一段换耳朵 | 窗的空间长度与驻留气质；乒乓=左右跳；失败=断话气质（制度层，不 dump 字段） | P-切 |
| **邻站泄漏** | 隔壁广告灌进店里 | 洞外/楼外邻站能量进洞/进楼/进库；门口串音 | P-泄 |
| **邻站外溢** | 喇叭音量不该喊过界 | 邻站功率/参数边界（教学相对值）；禁靠加功率抢客 | P-邻 |
| **治理** | 拒签与交维台账 | 口部未测禁签；金机口部走测；公开包脱敏 L3 | P-治 |

> 公开蜂窝/DAS 设计资料常写「出入口应有明确双向切换区」「控制室内信号外泄以免路边快移用户误切」「扇区边界避开滞留区以免乒乓」——本篇只借**顺序直觉**：定义口部 → 定义切换窗 → 测泄漏 → 核邻站外溢边界 → 金机口部走测 → 拒签治理。**不背厂商邻区参数菜单 / 不背标准条款号当 ETSI / 不把蜂窝 RSRP 门限抄进 DMR 公开包当法规。**

### 2.4 新贴纸 P：口部 / 切换 / 泄漏（五个子类）

| 子类 | 一句话 | 典型拒签 / 拒加站触发 |
|------|--------|----------------------|
| **P-口** | 口部/切换区未在图上可指认 → 禁签 | 「洞内测了」但门口无测点无边界 |
| **P-切** | 切换窗未定义或乒乓未排除 → 禁签/禁加站 | 门口左右跳当「用户走快」结案 |
| **P-泄** | 邻站泄漏未测 → 禁签 | 洞内听到邻站却无泄漏对照 |
| **P-邻** | 外溢边界未写或靠加功率抢客 → 拒 | 「邻站再响一点盖过去」 |
| **P-治** | 拒签门槛 + 金机口部走测 + 脱敏 | 用公网满格或只测洞内交差 |

## 3. 核心交付：插页 P + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 P（而不是先贴 L / I / F / O）

| 现象 | 优先贴纸 | 说明 |
|------|----------|------|
| 隧道口/楼门/库坡道乒乓、断话 | **主 P**，可挂 L/I | L 管井库路径；门口抢客用 P |
| 洞内/楼内听到邻站串音 | **P-泄**，可次挂 F | 先问泄漏，禁先开同频单 |
| 交维只测洞内不测口部 | **P-口 / P-治** 拒签 | 呼应手册10「金机走测」气质 |
| 要加站/加功率「盖门口」 | **P-邻 / P-治** 拒 | 规则1/2；先证切换与泄漏 |
| 切换窗口头说说无图 | **P-切** 拒签 | 窗必须可指认 |
| 井道门关衰减/厅门黑洞 | 主 **L**，不是 P | P 不管轿厢门本身 |
| 有源远端啸叫抬噪 | 主 **O**，口部症状可次挂 P | 先隔离再谈门口 |
| 真同频/邻道被证明 | 主 **F**，P 作排除项 | 先排除泄漏与乒乓气质 |

### 3.2 插页 P · 口部 / 切换 / 泄漏（挂在总三联单或室分/井库交维首页后）

| 行 | 名称 | 填写示例（教学虚构） |
|----|------|----------------------|
| **R1** | 主子类 + 次子类 | 「主 P-切 / 次 P-泄」（或 P-口 / P-邻 / P-治） |
| **R2** | 口部形态 | 「隧道口双扇区过渡；楼门室内外；库坡道」（脱敏，无楼名站号） |
| **R3** | 切换区定义 | 「图上可指认边界；优势区归属；滞留区是否避开扇区边」 |
| **R4** | 切换窗气质 | 「窗大致长度/驻留是否够；乒乓有无；失败气质有无（制度描述，不 dump 字段）」 |
| **R5** | 邻站泄漏 | 「洞外↔洞内 / 门外↔门内对照；教学相对值；是否灌入」 |
| **R6** | 邻站外溢边界 | 「邻站功率/参数边界教学相对值；是否靠加功率抢客」 |
| **R7** | 金机口部走测 | 「口部双侧/双向路径点位；与洞内对照；可挂 L 门开闭若涉及」 |
| **R8** | 判定与动作 | 「拒签 / 带条件签（14 日内补口部复测）/ 禁加站加功率；脱敏 L3」 |

> **R3 与 R5 不过 → 口部相关交维必须拒签。**  
> **R7 不过 → 禁止「洞内测了就算」签字。**  
> **R8 若写「加功率/加站试试」→ 本页作废重填。**

### 3.4 和总三联单怎么写（接手册06）

- **现象**：写「口部双向走测时乒乓」或「洞内可闻邻站串音」，不要写「同频」除非已排除 P。  
- **证据**：切换区图（脱敏）、泄漏对照相对值、金机口部点位、邻站外溢边界相对值。  
- **时钟**：若与手册15 风暴同时，写清三钟差；漂移大则禁秒级因果。  
- **贴纸栏**：主 **P-? **，次挂 L/I/F/O/H（若有）。  
- **结案词**：用 P 子类 + 动作（改窗/抑泄漏/拒签/带条件），禁用「加功率好了」「加站就好了」。

## 4. 深潜：八条硬规则 + 口部/切换/泄漏直觉 + 假病禁令

### 4.1 八条硬规则（本篇钉子）

1. **先证口部切换与邻站泄漏，再谈加站加功率**——门口抢客没划界，禁止再挂喇叭。  
2. **禁加功率 / 加增益掩盖泄漏与乒乓**——呼应手册07/09/10/16；功率不是门口补丁。  
3. **口部 / 出入口金机走测强制**——只测洞内/楼内 = 假绿交维。  
4. **切换窗未定义 → 禁签（也禁盲目加站）**——窗必须在图上可指认，含驻留气质。  
5. **邻站泄漏未测 → 禁签**——洞外↔洞内 / 门外↔门内对照缺一不可（适用场景）。  
6. **可挂 L/I/F/O，但主贴 P；假干扰先问泄漏与乒乓气质**——禁把抢客写成用户捣蛋。  
7. **邻站外溢边界必须书面（脱敏相对值）；禁靠加功率抢客**——P-邻 不是口头承诺。  
8. **公开材料脱敏 L3；不写真实频点/楼名/站号/个号/密钥**——教学与公开仓双禁。

### 4.2 口部直觉：「先把门口画在地图上」（P-口）

口部不是「洞内最后一米」的模糊说法，而是**可指认的过渡带**：

| 口部类型（教学） | 像什么 | 常见坑 |
|------------------|--------|--------|
| **隧道/管廊出入口** | 地铁出站闸机前过道 | 只测洞内；洞外邻站灌入未测 |
| **楼宇门厅/旋转门** | 商场正门 | 室内 DAS 外泄到路边；快移用户误切 |
| **地下库坡道** | 螺旋坡入口 | 与手册13 L-切 叠挂；只测库内层 |
| **换乘/连廊口** | 两列车同时喊话的站台口 | 双扇区边界落在滞留区 → 乒乓 |

```text
  交维包有没有「口部」这一页？
        │
        ▼
  图上能用手指指出切换区？──否──▶ 拒签（P-口 / 规则4）
        │是
        ▼
  金机是否走过该区双向？──否──▶ 拒签（规则3）
        │是
        ▼
  记录 R2/R3/R7；进入泄漏与窗检查
```

### 4.3 切换窗直觉：「过客该在哪一段换耳朵」（P-切）

本篇讲**制度层气质**，**不 dump 空口切换字段、不背厂商邻区参数表**：

| 气质词 | 白话 | 运维动作 |
|--------|------|----------|
| **切换窗** | 从听 A 换成听 B 的空间段落 | 要能在图上圈出来；避开长期滞留区 |
| **驻留** | 过客在窗里是否待得够稳 | 窗太窄+走过快 → 失败气质；窗落在等人处 → 乒乓 |
| **乒乓** | 左右跳、来回抢客 | 先问窗与外溢，禁加功率 |
| **切换失败气质** | 门口断话/重登/听感悬崖 | 先 P，可次挂 A–E；禁先骂协议 |

> 公开蜂窝资料里的「迟滞 / 触发时间」等词，本篇只借「**不要刚越线就跳、也不要僵在坏链路上**」的常识——**不把某制式参数名写进本网公开制度当 ETSI 强制。**

### 4.4 泄漏直觉：「隔壁广告灌进店里」（P-泄）

| 现场观感 | 更像 P-泄 还是真 F？ | 动作 |
|----------|----------------------|------|
| 洞内/楼内清晰听到邻站业务 | 先 P-泄 | 洞外↔洞内对照；抑外溢或改口部优势 |
| 门口糊、进门十米又好 | 窗/泄漏交界 | R3+R5；禁加功率 |
| 整层靠窗位置像「半个室外站」 | 室外灌入 | 可挂 I；主因常是泄漏/优势不足 |
| 真有邻频发射证据 | 主 F | P 作排除项写进三联单 |

**和 12.5 kHz 弱项的衔接**：泄漏讨论的仍是 **12.5 kHz** 这一格里谁更响；邻站外溢**不会**把信道变成 25 kHz，也不改变 4FSK / 30 ms——它只是让「这一格里多了一个不该这么响的声音」。

### 4.5 邻站外溢边界（P-邻，脱敏）

```text
  邻站该响到哪？
        │
        ▼
  书面外溢边界（教学相对值）有吗？──否──▶ 补 R6；禁「再加两格」
        │是
        ▼
  是否靠加功率/加增益抢门口？──是──▶ 违规；回退；规则2
        │否
        ▼
  口部金机仍过？──否──▶ 改窗/改优势/抑泄漏，不加功率
        │是
        ▼
  记录 R6；允许保持
```

### 4.6 「假干扰 / 假弱覆盖 / 假容量 / 假协议」怎么认

| 假病名 | 真身往往是 | 禁令 |
|--------|------------|------|
| 假同频 | 邻站泄漏 / 口部抢客（P-泄/P-切） | 禁先开 F 同频单 |
| 假弱覆盖 | 切换失败气质；窗太窄 | 禁加功率补门口 |
| 假容量 | 乒乓占资源；高峰更显 | 禁加信道掩盖 |
| 假协议 | 门口断话后登记异常 | 先 P，再挂 A–E |
| 假有源 | 口部有源啸叫（挂 O）被当成泄漏 | 先排除 O 再定 P |

### 4.7 假病禁令墙（与加功率叙事）

```text
  × 「门口糊，邻站功率再加两格」 → 抢客加剧；规则2
  × 「洞内测了，门口差不多」     → 假绿；规则3
  × 「切换窗口头说过就行」       → 规则4；要图上可指认
  × 「泄漏以后再测，先签字」     → 规则5
  × 「加个站盖门口」未证窗与泄   → 规则1
  × 「用户走太快才乒乓」结案     → 禁令；先查窗与外溢
  × 「公网满格说明口部好了」     → 指标错位；要 DMR 金机
```

### 4.8 金机口部走测最小包（可复印）

| 步骤 | 做什么 | 记录到 |
|------|--------|--------|
| 0 | 冻结加站加功率叙事；确认口部图 | R2/R3 |
| 1 | 金机从外→内走一遍（教学路径） | R7 |
| 2 | 金机从内→外走一遍 | R7 |
| 3 | 滞留点（若有）站 30–60 秒看是否乒乓气质 | R4 |
| 4 | 洞外/门外与洞内/门内听邻站是否灌入（相对） | R5 |
| 5 | 判定：过 / 拒签 / 带条件；禁「感觉行」 | R8 |

> 口诀：**双向走，滞留看，内外对照泄；不加功率。**  
> 把「只扫洞内」当成交维速度 = 只在店里试音就说门口抢客交接完成。

### 4.9 和手册13 L-切 / 手册10 I-覆 怎么叠挂

| 场景 | 主贴 | 次挂 |

### 4.10 和弱项加餐的衔接

12.5 kHz / 4FSK / 30 ms 两槽背熟，你才说得清：**口部切换与泄漏管的是「谁在门口喊、喊进没进洞」，不是调制台阶**。有人要用加功率/加站治乒乓或泄漏时，回加餐 + 手册07/10/13 + 本篇八条硬规则。

### 5.6 「假同频」排除三问（贴射频班）

1. **洞外/门外把邻站优势拿掉（或对比远点），洞内串音是否明显下降？**——是 → 高度疑 P-泄。  
2. **金机在口部滞留，是否左右跳？**——是 → P-切 窗/外溢问题。  
3. **回退邻站近期加功率后，门口是否反而稳？**——是 → 规则2 被违反过，先回退再治理。

三问都指向真同频/邻道证据之前，**禁止**把工单标题写成「同频干扰」结案。

## 6. 工作实例（12 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「隧道口左右跳，被写成同频」→ P-切（次挂 F）

- **现象**：金机过洞口时听感左右跳，偶发断话。  
- **错法**：直接开同频工单，邻站加功率。  
- **正法**：画切换区；滞留观察乒乓；查外溢；回退加功率。  
- **结案**：主 P-切；F 作排除项；规则2/6。

### 例 2 · 「洞内听到邻站广告」→ P-泄

- **现象**：洞内业务可闻邻站声浪。  
- **错法**：当干扰长期挂起；洞内加增益。  
- **正法**：内外对照；抑外溢或强化口部本站优势；禁加功率。  
- **结案**：主 P-泄；可挂 I；规则5。

### 例 3 · 「只测洞内就签字」→ P-口 / P-治

- **现象**：交维包无口部点位。  
- **错法**：带条件都懒得写就全签。  
- **正法**：拒签；补 R3/R5/R7。  
- **结案**：规则3/4/5；回手册10 气质。

### 例 4 · 「领导要加站盖门口」→ P-口 / P-切

- **现象**：投诉多，决策加站。  
- **错法**：未画窗未测泄就立杆。  
- **正法**：先完成工作流；窗与泄过关再评估是否真缺站。  
- **结案**：规则1；写入反例墙。

### 例 5 · 「邻站再响两格压断话」→ P-邻（禁令）

- **现象**：夜班加邻站功率。  
- **错法**：功率叙事过夜。  
- **正法**：回退；治窗与泄漏；三联单记违规。  
- **结案**：规则2/7。

### 例 6 · 「安检排队处乒乓」→ P-切

- **现象**：扇区边界落在滞留区。  
- **错法**：骂用户站着不动。  
- **正法**：把窗挪到通行段；或调优势归属（脱敏相对）。  
- **结案**：R3/R4；禁甩锅用户。

### 例 7 · 「库坡道乱跳」→ P + L

- **现象**：驶入坡道猎站毛刺 + 口部抢客。  
- **错法**：只加站或只加功率。  
- **正法**：L 证路径/门；P 证窗与泄；金机坡道+口部。  
- **结案**：主 P 或按主因；指针手册13。

### 例 8 · 「楼门室内信号灌到路边」→ P-泄 / P-邻

- **现象**：路边快移用户误切室内站气质。  
- **错法**：室内再加增益「更满」。  
- **正法**：控外溢；口部优势重新划界；禁加增益掩盖。  
- **结案**：P-泄/P-邻；可挂 I/O。

### 例 9 · 「公网满格当口部验收」→ P-治

- **现象**：领导用手机公网信号看门口。  
- **错法**：公网满格签字。  
- **正法**：DMR 金机口部双向；拒签公网替代。  
- **结案**：规则3/8。

### 例 10 · 「公开分享写出站名频点」→ P-治

- **现象**：复盘带真实站号与批复频点。  
- **错法**：进公开仓。  
- **正法**：L3 脱敏；教学相对值。  
- **结案**：规则8。

### 例 11 · 「有源远端在口部，加增益补乒乓」→ O + P

- **现象**：口部远端增益步进后更跳。  
- **错法**：继续加增益。  
- **正法**：先手册16 隔离/噪底；再 P 看窗与泄；禁加增益掩盖。  
- **结案**：主因属啸叫则主 O；属抢客则主 P；规则2。

### 例 12 · 「切换失败后登记异常，被写成协议病」→ P-切（次挂 A–E）

- **现象**：门口断话后终端重登。  
- **错法**：先开协议深挖单。  
- **正法**：先证口部窗与泄漏；协议作次挂。  
- **结案**：规则6；冻结玄学。

### 例厚补 · 「半泄漏半空点」怎么排优先级（5 分钟口诀）

> **先泄漏与窗，再空点；先金机口部，后加站叙事。**  
> 泄漏未清时补空点 = 先让两家喇叭继续抢客再怪过道有柱子。

口部切换不改 12.5 kHz / 4FSK / 30 ms；它改的是「谁在门口主导、邻站有没有灌进来」。加功率叙事出现时，回加餐 + 本篇规则2。

### 11.8 十分钟给领导的电梯演讲

> 「口部最怕两家喇叭抢客。我们要求：切换区图上可指认、邻站泄漏测过、金机口部双向走过，才允许谈加站；不签字给只测洞内的包；不加功率掩盖乒乓和串音。这是交维制度，不是厂商邻区菜单。」

### 11.9 和手册13 / 16 同时爆发时怎么分工

- 坡道猎站 + 门口乒乓 → **L 管路径与门**，**P 管窗与泄漏**。  
- 口部有源啸叫 + 泄漏观感 → **O 管隔离与噪底**，**P 管是否真是邻站灌入**。  
- 不要用「先加功率」换「先画窗」——两个禁令叠加时，**两个都要守**。
