## 1. 为什么要写这篇手册（动机 + 现场对话）

前二十五篇手册把「家里怎么养」「邻居怎么处」「投诉怎么分诊」「证照台账怎么对」「重大保障临时窗怎么钉」「非法线索怎么上报」「电磁环境报告怎么验收」基本写全了：A–E 协议，F 射频指纹，G 实验室，H 话务，I 室分，J 写频，K 电源，L 井库，M 批量 / OTAP，N 监控对时，O 有源隔离，P 口部，Q 金机，R 假绿演练，S 邻频协调，T 干扰投诉，U 许可执照台账，V 临时保障窗，W 非法/黑广播线索，X 电磁环境报告台账。可现场还有一类债——**重大活动设备检测贴签与准入台账**（设备侧，与 V 的频率/窗侧咬合）：

- 保障岗：「上周那场活动的检测贴还在机器上，这场直接进。」——**他场/过期贴套本场** = 本篇拒入（规则3）。  
- 写频岗：「清单外多抬了两台手台，先写频进网，回头再检。」——**设备与活动清单不符 / 无有效贴签** = 规则2。  
- 网管：「屏上全绿、假绿演练也过了，还要什么设备检测贴签？」——**假绿 ≠ 已检测准入**（规则6，挂 R 提醒）。  
- 项目经理：「检测记录缺页、台账没勾，领导催着签准入放行。」——**缺项断链禁当正式准入证据**（规则4）。  
- 工程：「活动中途换了天线、功率角色调了，先用着，闭幕再补检。」——**重大变更须复检/重贴签**（规则5）。  
- 协调岗：「共址邻网设备也要进同一机房，我们先抬，邻居慢慢协调。」——**跨网准入须先通知或挂 S**（规则7）。  
- 宣传：「把贴签全文号和真实设备序列贴公开周报。」——**L3 违规**（规则8）。

这几句背后是同一件事：

> **「重大活动设备检测贴签与准入台账」在现场至少有五个坑**：**① Y-检** 检测有效性（检测记录角色、方法角色、有效期、设备角色与活动清单一致）；**② Y-签** 贴签（贴签与实物一致、本场本机、未过期、禁套用他场/他机/过期贴）；**③ Y-账** 准入台账可对账（活动角色、设备角色、贴签角色、时段、勾选齐全）；**④ Y-准** 准入放行签字边界（谁可签准入/写频开站放行；无贴签/过期/不符拒入拒签）；**⑤ Y-治** 拒入/治理（伪造套贴、清单外强入、未复检变更、公开泄密、假绿顶替检测）。  
> 把 ①–⑤ 当成「机器上有张旧贴就行」「清单外先抬进去」「屏绿=已准入」「借别人贴签」「变更先用再检」，会把下一任、保障办、主管部门和本网合规一起拖进泥潭。

本篇目标：能背出**重大活动设备检测贴签与准入工作流**；会用新贴纸 **Y（检 / 签 / 账 / 准 / 治）** 与五个子类；会填**插页 Y（Y1–Y8）**和《本网重大活动设备检测贴签与准入台账卡》；能用「**大型演出/会展安检贴纸 + 工牌准入台账**」故事讲清：先对有效贴签与台账勾选、贴签对实物、清单对活动、缺项断链拒入、变更复检重贴、签字边界；能拒绝「套他场贴、过期贴、借贴、清单外强入、假绿顶替、未复检先用、功率战掩盖、公开泄密」；自测过关后，回库把本网最近一次重大活动设备准入台账（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：凡引法规与标准均指向已公开发布的文书标题与官方链接（《中华人民共和国无线电管理条例》《无线电频率使用许可管理办法》《地面无线电台（站）管理规定》《无线电台执照管理规定》《中华人民共和国无线电管制规定》、国无办〔2025〕1号、属地重大活动无线电保障公开材料等），**程序、期限、管制命令以原文与属地最新要求为准，本篇只作教学转述，不发明条款号以外的「内部口径」或内部配额**；**现象与台账一律用相对道号、角色标签、脱敏编号表述，禁真实频点 / 站名 / 单位名 / 检测单全文号 / 贴签全文号 / 设备序列全文 / 联系人 / 坐标**；**不教伪造/涂改/套用贴签、不教无证发射、不教功率战掩盖准入问题、不教规避监测与检查**；V 仍管临时频率与联测窗，U 仍管许可执照，X 仍管电磁环境报告，J/M 仍管写频/OTAP，Q 仍管金机基线，R 仍管假绿——**重大活动设备检测贴签与准入台账主贴 Y**；外国 / ITU / 厂商材料只借**活动频谱管理与设备管理方法级表述**，**准入与签字以国内法规、属地要求与本网书面判据为准**。

## 2. 总图 / 故事：准入像「安检贴纸 + 工牌准入台账」

### 2.1 一句话：重大活动设备检测贴签与准入像大型演出/会展的安检贴纸 + 工牌准入台账——入场前先对贴签是否有效、是否本场本机、台账是否勾选；过期贴、借贴、清单外、缺项断链一律拒入

```text
   ┌──────────────────────────────────────────────────────────────────┐
   │   会展安检贴 + 工牌准入台账（= 本网重大活动设备检测贴签 + 准入） │
   │                                                                  │
   │   检测有效性（Y-检）                                             │
   │     检测记录角色 · 方法角色 · 有效期 · 设备与活动清单一致        │
   │                                                                  │
   │   贴签（Y-签）                                                   │
   │     贴签对实物 · 本场本机 · 未过期 · 禁套他场/他机/过期贴        │
   │                                                                  │
   │   准入台账可对账（Y-账）                                         │
   │     活动角色 · 设备角色 · 贴签角色 · 时段 · 勾选齐全             │
   │                                                                  │
   │   准入放行签字边界（Y-准）                                       │
   │     谁可签准入/写频开站放行 · 无贴签/过期/不符 → 拒入拒签        │
   │                                                                  │
   │   拒入治理（Y-治）                                               │
   │     伪造套贴 · 清单外强入 · 未复检变更 · 公开泄密 · 假绿顶替     │
   └──────────────────────────────────────────────────────────────────┘
```

口诀：

> **先对贴签，再对台账；贴签对实物，清单对活动。**  
> 他场旧贴进本场 = 拿隔壁展厅安检贴来过本厅安检——**拒入**。  
> 过期贴仍放行 = 灭火器过期也贴「可入场」——**拒入**。

### 2.2 「安检贴纸 + 工牌准入」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **检测有效性** | 安检机检过、有效期内、项目对得上本场清单 | 检测记录有效；方法角色清楚；设备与活动清单一致 | Y-检 |
| **贴签** | 安检贴纸贴在本件行李/本机上，不能撕给别人 | 贴签与实物一致；本场本机；未过期；禁套用 | Y-签 |
| **准入台账** | 工牌系统可检索：谁、哪场、何时、有无有效贴 | 活动/设备/贴签/时段可对账；勾选齐全 | Y-账 |
| **准入放行签字** | 门岗谁有权刷「可入场」 | 谁可签准入/写频开站放行；无贴签/过期/不符拒入 | Y-准 |
| **拒入治理** | 假贴、借贴、清单外强闯 → 追责 | 伪造套贴、强入、未复检、假绿顶替、泄密 → 拒入/治理 | Y-治 |

> 公开文书与属地材料告诉我们：设置使用无线电台（站）应依法取得许可与执照；临时用频有许可期限与不得擅自扩大范围等要求；重大任务等情形下可依法实施无线电管制；属地重大活动保障公开材料常见「提前提出临时用频与设备需求」「设备检测贴签」等**方法级**表述（教学借流程直觉，**不抄具体频点与内部数字当本网指标**）。本篇只借「先检测贴签、再台账准入、贴签对实物、清单对活动、签字有边界」的顺序，**不编造本网内部检测指标数字、不教伪造贴签过关**。

### 2.3 和手册11 / 14 / 15 / 19 / 22 / 23 / 25 的咬合（指针，不重写）

- **手册23 V**：临时频率与联测窗——**本篇是重大活动就绪的设备侧**；V 管窗与许可时段，Y 管「哪台机器有没有有效检测贴签可进场/可写频」。无 V 覆盖仍走 V，不拿「有贴签」顶替临时批复。  
- **手册22 U**：许可与执照台账——**贴签不代替执照**；无证/过期仍走 U，Y 只管活动设备准入。  
- **手册25 X**：电磁环境报告台账——**准入 ≠ 环境验收**；设备准入过了不等于站址环境报告可签交维；可叠挂，各管各的。  
- **手册11 J / 14 M**：写频 / OTAP——**活动设备写频或 OTAP 前强制对 Y 准入台账**；无有效贴签/台账未勾 → 拒签写频开站。  
- **手册15 Q**：金机基线——可支撑「准入后参数是否偏离金机」；**不能代替**检测贴签与准入台账。  
- **手册19 R**：假绿演练——**屏上看见 ≠ 已检测准入**（规则6）；可挂 R 提醒，主贴仍 Y。  
- **手册20 S / 21 T / 24 W**：邻频、投诉、非法线索——跨网共址设备准入先通知或挂 S；投诉挂 T；疑似非法设备线索走 W；**设备准入本身主贴 Y**。

### 2.4 新贴纸 Y：检 / 签 / 账 / 准 / 治（五个子类）

```text
                ┌──────────── 贴纸 Y · 检/签/账/准/治 ────────────┐
                │  Y-检  检测有效性：记录·方法·有效期·与活动清单一致 │
                │  Y-签  贴签：对实物·本场本机·未过期·禁套他场他机   │
                │  Y-账  准入台账可对账：活动·设备·贴签·时段·勾选   │
                │  Y-准  准入放行签字：谁可签准入/写频开站；缺项拒入 │
                │  Y-治  拒入治理：伪造套贴·强入·未复检·假绿·泄密   │
                └──────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒入 / 拒签触发 |
|------|--------|----------------------|
| **Y-检** | 检测过期或设备与活动清单不符仍放行 → 拒入 | 「检测上周过期先抬进去」 |
| **Y-签** | 贴签与实物不一致 / 他场他机过期贴 → 拒入 | 「借隔壁展厅那张贴」 |
| **Y-账** | 台账对不上活动/设备/时段或未勾选 → 禁正式准入 | 「清单口头说有=台账齐」 |
| **Y-准** | 无授权人签、或强签缺贴签项 → 拒签 | 「领导催签就放行」 |
| **Y-治** | 伪造套贴、清单外强入、假绿顶替、公开泄密 → 治理 | 「撕 A 机贴贴到 B 机」 |

### 2.5 重大活动设备检测贴签与准入最小工作流（背下来）

```text
  拟「设备准入 / 写频开站 / 活动中换机复检」
        │
        ▼
  是否有覆盖本活动角色、本设备角色、本时段的有效检测与贴签？（Y-账 / Y-签）
        │无 / 过期 / 清单不符──▶ 拒入拒签；补检或剔除清单外机（规则1、2）
        │有候选贴签
        ▼
  贴签是否与实物一致？是否本场本机？是否套用他场/他机/过期贴？（Y-签）
        │否──▶ 拒入；禁套用（规则3）
        │是
        ▼
  检测记录是否完整可追溯？台账勾选是否齐全？（Y-检 / Y-账）
        │缺项断链 / 未勾──▶ 禁当正式准入证据；内部可挂「待检/待补」（规则4）
        │完整且已勾
        ▼
  活动中是否有重大变更（换机、改功率角色、改天线）未复检/重贴签？（规则5）
        │有──▶ 拒入/冻结放行；复检重贴后再走 Y
        │无
        ▼
  写频/OTAP？→ 强制对 Y 台账（挂 J/M）；无贴签拒签写频
  证照/临时窗？→ 互挂 U/V；贴签不代替执照
  环境验收？→ 不混用 X；准入≠环境验收
  跨网/共址？→ 先通知或挂 S（规则7）
  假绿/屏绿能否顶替？→ 不能；挂 R 提醒（规则6）
        │
        ▼
  授权人按 Y-准 边界签字放行；台账入库；公开包 L3（规则8）
  结案词用 Y 子类；可挂 V/U/J/M/Q/X 支撑，主贴 Y
```

现场口诀：

> **先对贴签，再对台账；贴签对实物，清单对活动。**  
> 跳过对账的「准入放行」= 拿过期安检贴闯门岗。

## 3. 核心交付：插页 Y + 拒入卡 + 与总三联单怎么写

### 3.1 什么时候贴 Y（而不是先贴 V / U / X / R / J）

| 现场信号 | 主贴 | 可次挂 |
|----------|------|--------|
| 重大活动设备要检测贴签 / 准入放行 | **Y** | V / U / J |
| 临时频率窗 / 联测窗是否覆盖 | **V**（不是 Y） | 设备侧仍须 Y |
| 许可/执照是否覆盖 | **U** | 贴签不代替执照 |
| 电磁环境报告是否可签验收 | **X**（不是 Y） | 准入≠环境验收 |
| 写频 / OTAP 前对活动设备 | **J / M** + 强制挂 **Y** | — |
| 屏绿/假绿想顶替已检测准入 | **Y-治** + 挂 **R** | — |
| 跨网/共址设备同场准入 | **Y** + 挂 **S** | V |
| 伪造/套贴/公开泄密 | **Y-治** | — |

> **口诀**：临时窗 → **V**；证照 → **U**；环境报告 → **X**；写频/OTAP → **J/M**（先对 Y）；假绿 → **R**；邻居 → **S**；**重大活动设备检测贴签与准入 → Y**。可叠挂，**该类准入主贴 Y**。

### 3.2 插页 Y · 检 / 签 / 账 / 准 / 治（挂在总三联单或准入单后）

| 行 | 名称 | 填写示例（教学虚构，L3） |
|----|------|--------------------------|
| **Y1** | 活动角色摘要 | 「活动角色·保障时段角色·与 V 临时窗互挂编号脱敏」 |
| **Y2** | 设备角色清单 | 「手台/车台/中继角色·数量角色·与活动清单一致□」——不符拒入 |
| **Y3** | 检测有效期 | 「检测记录角色·方法角色·有效期至____·在有效□/过期□」——过期拒入 |
| **Y4** | 贴签角色 | 「贴签脱敏编号·本场本机□·与实物一致□·未套用□」 |
| **Y5** | 台账勾选 | 「□覆盖本活动 □设备在清单 □贴签有效 □时段覆盖 □未重大未复检变更」 |
| **Y6** | 写频/OTAP 闸门 | 「拟写频/OTAP？是→已对 Y 台账□；未对→拒签 J/M」 |
| **Y7** | 复检/重贴触发 | 「无 / 换机 / 改功率角色 / 改天线 / 他场转入 / 其他____」 |
| **Y8** | 拒入门槛 | 「缺任一项正式准入项 → 拒入拒签；内部可挂待检/待补」 |

> **Y2 清单不符 → 拒入（规则2）。**  
> **Y3 过期 → 禁止以该贴签作为正式准入依据（规则2）。**  
> **Y4 贴签与实物不一致或套用 → 拒入（规则3）。**  
> **Y5 缺勾 → 禁签正式准入/写频开站放行（规则1、4）。**  
> **Y6 未对 Y 仍写频 → 拒签（与 J/M 互锁）。**  
> **Y7 有触发未复检重贴 → 拒入/冻结（规则5）。**  
> **Y8 公开包出现真实频点/贴签全文号/设备序列全文 → L3 违规（规则8）。**

### 3.3 「套贴 / 过期贴 / 假绿顶替 / 缺项强入拒入」卡（贴值班台 / 门岗 / 写频室）

```text
  ┌──── 重大活动设备检测贴签与准入拒入卡（贴纸 Y）────┐
  │  × 无覆盖本活动角色+本设备角色+本时段的有效贴签仍准入 │

  │  × 设备与活动清单不符；清单外强入                    │
```

### 3.4 和总三联单怎么写（接手册06）

- **现象**：写「拟准入/写频开站/换机复检 + Y 子类」，**未对账前不写「设备已检测准入可写频」**。  
- **证据**：活动角色、设备清单角色、检测有效期、贴签角色、台账勾选、复检触发、互挂 V/U/J。  
- **结论**：用 Y 子类 + 待检/待补/已准入/拒入；次挂 V/U/J/M/Q/X/R/S 时写清主贴仍是 Y。  
- **动作**：对账、补检、重贴签、剔除清单外、挂 S、拒入——**禁止**写「套他场贴」「过期先抬」「屏绿顶替」「先用着再说」「借贴进场」。
