## 4. 深潜：八条硬规则 + 分诊题 + 设备检测最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **先证有效检测贴签与准入台账覆盖（活动角色、设备角色、时段）再准入/写频开站**。  
2. **无有效贴签、检测过期、设备与活动清单不符 → 拒入/拒签**。  
3. **贴签与实物不一致；禁套用他场/他机/过期贴 → 拒入**。  
4. **缺项、断链、无法追溯的检测记录/台账勾选 → 禁当正式准入证据**（内部可挂「待检/待补」）。  
5. **活动中重大变更（换机、改功率角色、改天线）须复检/重贴签再放行；禁「先用着再说」**。  
6. **可挂 V/U/J/M/Q/X 支撑，但设备准入主贴 Y；假绿/屏上看见不等于已检测准入（挂 R 提醒）**。  
7. **跨网/共址设备准入须先通知协调或挂 S；争议走无线电管理机构；禁功率战/私了**。  
8. **对外/公开仓一律脱敏 L3；禁贴真实频点/站名/单位名/贴签全文号/设备序列全文/坐标**。

> 法规与公开材料锚点（已核公开原文，教学转述，**以原文为准**）：《无线电管理条例》对频率使用许可、台站设置使用、监测与干扰查处等作总则；《无线电频率使用许可管理办法》对临时用频期限与不得擅自扩大范围等作要求；《地面无线电台（站）管理规定》《无线电台执照管理规定》对台站与执照规范作要求；《无线电管制规定》明确重大任务等情形下可依法实施管制——**保障期若遇管制指令，本网设备必须服从，不得以「我们有检测贴签」对抗管制命令**；国无办〔2025〕1号提供规划与技术要求指针；属地重大活动保障公开材料（如北京无线电管理规定公开 PDF、十五运会广州赛区无线电安全保障访谈等）可见「提前提出设备需求」「设备检测贴签」等方法级表述。**这些是合规与准入秩序，不是「机器上有张旧贴就能进场」或「贴签顶替执照」的借口。**

### 4.2 准入前分诊题（Y-账 / Y-检 / Y-签）——先问「这贴盖的是不是本场本机」

```text
  ① 台账里有没有覆盖「本活动角色 + 本设备角色 + 本时段」的有效检测与贴签？
     → 无/过期/清单不符：拒入；补检或剔除（规则1、2）

  ② 贴签是否贴在本实物上？是否本场本机？有无套用痕迹？
     → 否/套用：拒入（规则3）

  ③ 检测记录是否完整可追溯？方法角色是否清楚？
     → 缺项断链：禁正式准入；内部待补（规则4）

  ④ 台账勾选是否齐全？写频/OTAP 是否已对 Y？
     → 未勾/未对：拒签准入与写频（规则1、4；挂 J/M）

  ⑤ 自贴签出具后是否发生换机/改功率角色/改天线未复检重贴？
     → 是：拒入/冻结；复检重贴（规则5）

  ⑥ 是否跨网/共址设备同场且未通知协调？
     → 是：挂 S；争议报管理机构；禁功率战私了（规则7）

  ⑦ 是否有人要用屏绿/假绿或「有执照就行」顶替检测准入？
     → 是：拒签；挂 R；执照走 U，主贴仍 Y-治（规则6）
```

**未过分诊题的冻结清单**：签「准入放行」「保障设备就绪」、对外宣传「设备已全部检测贴签」、清单外强入、未对 Y 写频、套他场贴。允许做的：台账对账、补检、重贴签、剔除清单外、挂 S、内部挂待检/待补。

### 4.3 设备检测最小集（Y-检 / Y-签）——缺页不能过门岗

| 序号 | 最小集项（教学） | 为什么必须有 | 缺了会怎样 |
|------|------------------|--------------|------------|
| 1 | **活动角色 + 时段角色** | 防他场套用 | 对不上 → 拒入 |
| 2 | **设备角色清单**（禁公开序列全文） | 防清单外强入 | 不符 → 拒入 |
| 3 | **检测记录角色 + 出具日/有效期** | 检测有效性 | 过期/无记录 → 拒入 |
| 4 | **贴签角色 + 与实物一致声明** | 防借贴套贴 | 不一致 → 拒入 |
| 5 | **方法角色摘要** | 可复核 | 「检过了」三个字不够 |
| 6 | **台账勾选 + 互挂 V/U** | 正式准入依据 | 未勾/两张皮 → 禁正式准入 |
| 7 | **保管链未断声明** | 断链=降级 | 断链禁当正式准入证据（规则4） |

> **口诀**：场、机、检、贴、法、账、链——**七字准钉**（教学记忆；现场以属地与活动保障书面要求为准，但 **本场本机+有效贴签+台账勾选+保管链** 几乎不可砍）。  
> **断链识别**：缺检测记录页、贴签与机身对不上、涂改无登记、公开群传后再当正式附件、他场贴撕到本机——一律降级，禁正式准入依赖。

### 4.4 台账路径（Y-账）——每场活动一本可检索账

| 步 | 动作 | 拒入点 |
|----|------|--------|
| 1 | 一活动角色一主档（设备子表按角色列） | 「全年所有活动共用一张永远有效贴」 |
| 2 | 登记：设备角色、检测有效期、贴签角色、时段 | 口头说有贴无台账 |
| 3 | 互挂 V 临时窗、U 执照编号脱敏、J/M 写频单脱敏（若有） | 贴签与证照/写频两张皮 |
| 4 | 复检/重贴触发写入台账（换机/功率/天线等） | 变更不登触发 |
| 5 | 到期预警与过期拒入路径（与写频/开站闸门互锁） | 「过期了先用着」 |
| 6 | 公开导出仅 L3；原件全文号受控另册 | 公开贴全文号/序列全文 |

与手册23：V 管临时频率与联测窗是否覆盖保障期；**Y 管设备是否经检测贴签可准入**——两本账都过才谈「保障设备就绪」叙事。与手册22：U 管执照；**贴签不代替执照**。与手册25：X 管环境报告；**准入 ≠ 环境验收**。

### 4.5 签字边界（Y-准 / 规则1–4）——谁有权写「可入场」

| 本网可以签（教学） | 本网不可以签（红线） |
|--------------------|----------------------|
| 台账勾选齐全、贴签有效对实物、清单一致、无未复检重大变更 | 无贴签/过期/不符仍签「准入放行/写频开站」 |
| 授权角色按制度会签（教学不编造职务名） | 「谁在场谁签」「领导催签跳过台账」 |
| 内部挂「待检/待补」并冻结放行 | 待检状态对外宣传「已全部贴签准入」 |
| 拒入并开 Y-治 工单 | 套贴、伪造涂改后补签 |

> **明确不教**：如何伪造贴签、如何涂改有效期、如何把 A 机贴撕到 B 机、如何规避门岗与监测。需要法定检测或管制配合的，**按主管部门与属地要求走**——你方只做边界内的台账、对账、拒入与复检安排。

### 4.6 弱项短补：有贴 ≠ 本场本机 ≠ 在有效期 ≠ 清单一致 ≠ 已签字准入 ≠ 屏绿 ≠ 有执照

```text
   机器有贴纸  本场本机  在有效期  清单一致  已签准入  屏/假绿  有执照
   ──────────  ────────  ────────  ────────  ────────  ───────  ──────
   仅有纸      Y-签对上   Y-检     Y-账      Y-准      R≠Y     U≠Y
   ✗ 「有旧贴 = 可进本场」
   ✗ 「上周检过 = 本场永远有效」
   ✗ 「借贴/撕贴 = 可过门岗」
   ✗ 「清单外先抬回头补」
   ✗ 「屏全绿 = 已检测准入」
   ✗ 「有执照 = 免检测贴签」
   ✗ 「准入过了 = 环境验收也过了」
```

所以规则1、3、6才硬：**先证覆盖与有效贴签；不一致拒入；假绿/执照不能顶替检测准入。**

### 4.7 与写频 / 临时窗 / 环境验收怎么衔接（只讲合规路径）

教学流程（细节以属地、活动保障办与本网制度为准）：

1. **活动立项**：查 V 临时窗 + U 证照 + 拟设备清单。  
2. **设备检测贴签（Y-检 / Y-签）**：按清单检测 → 贴签 → 登记。  
3. **入库台账（Y-账）**：活动/设备/贴签/时段/勾选、复检触发、互挂 V/U。  
4. **准入会签（Y-准）**：对照拒入卡；缺项则待补，不放行。  
5. **写频/OTAP（J/M）**：强制对 Y；未对拒签。  
6. **活动中变更**：触发清单命中 → 复检/重贴 → 更新台账 → 再放行。  
7. **跨网共址**：先通知或挂 S；争议报无线电管理机构。  
8. **结案**：Y 子类结案词；套贴/强入走 Y-治；环境项另走 X；闭幕回收与 V 窗呼应。

**明确不教**：如何无贴签发射、如何伪造涂改、如何规避检查与监测、如何用干扰压制「看起来合规」。

### 4.8 准入 / 写频前 15 分钟清单（可复印）

| 分钟 | 动作 |
|------|------|
| 0–3 | 打开台账卡：活动角色、设备清单、候选贴签角色、有效期 |
| 3–7 | Y-账/Y-检/Y-签分诊七问；贴签对实物？清单对吗？ |
| 7–10 | 最小集勾选；缺项 → 待补，禁签准入/写频 |
| 10–13 | 查复检触发与现场是否一致；跨网则挂 S；写频则对 J/M |
| 13–15 | 拒入卡自检（未套贴/未假绿顶替/未清单外）；交班口述 |

夜班压缩版：至少完成「有本场有效贴签角色 + 与实物一致 + 清单无矛盾声明 + 未强签缺项」四项——**四项缺一仍禁签准入放行与写频开站**。

### 4.9 与 V / U / X / J / M / Q / R / S 单据互挂（Y → 临时窗 / 证照 / 环境 / 写频 / 金机 / 假绿 / 邻居）

```text
  临时窗（V）
        │
        └── 时段与活动角色互挂；无 V 覆盖不拿贴签顶替临时批复

  证照（U）
        │
        └── 贴签不代替执照；无证走 U

  环境报告（X）
        │
        └── 准入 ≠ 环境验收；各管各的闸门

  写频 / OTAP（J / M）
        │
        └── 强制先对 Y；未对拒签写频开站

  金机（Q）
        │
        └── 可支撑准入后基线比对；不代替贴签

  假绿（R）
        │
        └── 仅提醒「看见≠检测准入」；禁止 R 顶替 Y

  邻频协调（S）
        │
        └── 跨网/共址准入：Y 主贴 + S 协调编号互挂（均脱敏）
```

批量准入 / 周报：任何「设备已全部检测贴签」表述必须能追溯到 Y 卡且公开 L3——**「领导要稿」不能代替检测最小集**。

## 5. 现场映射：原话 → Y 子类；对话脚本；夜班；禁写词

### 5.1 原话速查表

| 原话 | 主贴 | 动作 |
|------|------|------|
| 「上周那场的贴直接进本场」 | Y-签 / Y-治 | 对活动角色；禁套他场 |
| 「检测过期了先抬进去再补」 | Y-检 | 拒入；先补检重贴 |
| 「借隔壁组那张贴贴上」 | Y-签 / Y-治 | 拒入；禁借贴套贴 |
| 「清单外多两台先写频」 | Y-账 / Y-准 | 拒签写频；剔除或补检入库 |
| 「屏全绿还要什么贴签」 | Y-治 + R | 假绿≠检测准入；拒顶替 |
| 「换天线先用着闭幕再检」 | Y-账 / 规则5 | 拒入/冻结；复检重贴 |
| 「有执照免检测贴签」 | U + Y | 贴签不代替；仍须 Y |
| 「准入过了环境验收也齐了」 | X + Y | 准入≠环境验收 |
| 「公开周报贴贴签全文号+序列」 | Y-治 | L3 违规下架 |

### 5.2 对话脚本（五则）

**脚本1 · 他场旧贴**  
对方：「机器上还有上周展会的贴，颜色差不多，直接进。」  
你：「规则3：禁套用他场/他机/过期贴。先 Y-账对活动角色；对不上就补检重贴。主贴 Y-治。」

**脚本2 · 过期仍放行**  
对方：「检测昨天才过期一天，先放行写频。」  
你：「规则2：检测过期 → 拒入拒签。补检重贴后再走 Y。主贴 Y-检。」

**脚本3 · 假绿顶替**  
对方：「假绿演练都过了，准入别再卡贴签。」  
你：「规则6：假绿/屏上看见不等于已检测准入。可挂 R 提醒，主贴仍是 Y；无有效贴签拒签准入。」

**脚本4 · 变更先用着**  
对方：「活动中途换了功率角色，先保障，闭幕再复检。」  
你：「规则5：重大变更须复检/重贴签再放行；禁先用着再说。主贴 Y-账，冻结写频与放行。」

**脚本5 · 清单外强入 + 跨网**  
对方：「邻网两台也要进机房，先抬，贴签回头补，协调以后再说。」  
你：「规则2、7：清单不符拒入；跨网先通知或挂 S；禁私了。主贴 Y-治，挂 S。」

### 5.3 夜班 15 分钟怎么用

1. 扫 Y 台账：过期贴条数、待补条数、清单外条数、未复检变更条数（应为可解释且未强签）。  
2. 抽查门岗/写频室：在用设备贴签是否与实物一致、是否本场。  
3. 查互挂：写频单是否挂 Y；临时窗是否挂 V；跨网是否挂 S；假绿是否被误当 Y。  
4. 交班口述：待检/待补、已拒入原因（Y 子类）、复检计划角色、主人。

### 5.4 「设备准入三问」（贴门岗 / 写频室 / 保障办）

```text
  1. 贴签覆盖的是本活动角色、本设备角色、本时段吗？有效吗？对本机吗？
  2. 台账勾选齐了吗？检测记录有没有缺页断链？清单有没有外机？
  3. 有没有未复检的换机/改功率/改天线？有没有人想用屏绿、借贴或执照顶替？
```

### 5.5 现象栏禁写词与可写词（贴值班台）

| 禁写 | 可写（L3） |
|------|------------|
| 真实频点、坐标、贴签全文号、设备序列全文 | 相对道号、活动角色、设备角色、脱敏编号 |
| 「已准入可写频」（台账未过时） | 「Y 待补：缺贴签有效期勾选」 |
| 「套用他场贴」「借贴进场」「过期先抬」 | 「Y-签/Y-治：已拒入；待补检重贴」 |
| 「屏绿=已检测准入」「有执照免贴签」 | 「假绿≠Y；已挂 R；贴签不代替 U」 |
| 「准入=环境验收过了」 | 「Y≠X；环境项另走手册25」 |

### 5.6 交班口述模板（30 秒）

> 「活动角色甲，设备角色清单乙，贴签脱敏丙，有效期至角色日；与实物一致；功率角色变更未复检 → 已拒签写频与准入；主人丁；已开复检重贴单；挂 S 预告邻居角色。下一班禁强签，先复检入库。」

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「上周展会贴直接进本场」→ Y-签 / Y-治

现象：保障催准入，拟用他场活动残留贴签。  
处置：Y-账对活动角色失败；拒入；开本场补检重贴。  
结案词：「Y-治：禁套他场贴；已开补检。」

### 例 2 · 「检测过期仍放行写频」→ Y-检

现象：检测有效期过期两日，写频岗拟照常写活动信道。  
处置：拒签写频；拒入；补检重贴后再对 Y。  
结案词：「Y-检：检测过期，拒签准入与写频。」

### 例 3 · 「借贴 / 撕 A 贴 B」→ Y-签 / Y-治

现象：门岗发现贴签编号角色与机身不一致，疑似挪贴。  
处置：拒入；保全；开 Y-治；禁放行。  
结案词：「Y-治：贴签与实物不一致，拒入并治理。」

### 例 4 · 「清单外多机先抬」→ Y-账 / Y-准

现象：清单外两台手台已抬入机房，主张「先保障回头补检」。  
处置：冻结准入叙事；剔除或补检入库前禁写频；开治理。  
结案词：「规则2：清单不符拒入；禁先用着再说。」

### 例 5 · 「屏全绿顶替检测准入」→ Y-治 + R

现象：网管主张假绿演练通过即可签设备准入。  
处置：拒顶替；挂 R 提醒；主贴 Y；无有效贴签则待检。  
结案词：「规则6：假绿≠检测准入；主贴 Y。」

### 例 6 · 「换天线未复检先用」→ 规则5 / Y-账

现象：活动中天线角色变更，业务已开，复检排闭幕。  
处置：冻结「准入/写频开站」叙事；限期复检重贴；开治理。  
结案词：「规则5：变更未复检重贴，禁先用着再说。」

### 例 7 · 「有执照主张免贴签」→ U + Y

现象：主张本网执照有效，重大活动免设备检测贴签。  
处置：U 管执照覆盖；Y 仍要求本场检测贴签与台账；无贴签拒入。  
结案词：「贴签不代替执照；执照不代替 Y。」

### 例 8 · 「准入过了就签环境交维」→ X + Y

现象：设备准入台账齐全，拟顺带签电磁环境交维就绪。  
处置：Y 过不等于 X 过；环境报告另对手册25；禁混闸门。  
结案词：「准入≠环境验收；Y≠X。」

### 例 9 · 「公开周报贴全文号与序列」→ Y-治 / L3

现象：周报含贴签全文号与设备序列全文。  
处置：下架；改 L3；原件受控；培训规则8。  
结案词：「Y-治：L3 违规已纠正。」

### 例 10 · 「共址邻网设备未通知先抬」→ Y + S

现象：共址邻网设备拟同机房准入，未书面通知，主张「抬头不见低头见」。  
处置：先通知或挂 S；争议报管理机构；禁功率战私了；本网侧仍须 Y 清单覆盖。  
结案词：「规则7：跨网先协调挂 S；已拒私了。」
