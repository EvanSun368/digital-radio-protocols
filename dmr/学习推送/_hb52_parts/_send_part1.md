| **治** | 假绿≠可以签；禁用「温湿度签」「滤网气流签」「气灭签」「门禁签」「监控签」「压缩机制冷剂签」顶本期新风正压/防火阀 | 假绿、顶替 AI/AU/AL/…、绕联锁、堵死新风、功率战、泄密 → 治理 | AY-治 |

> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：新风/补风与正压、防火阀公开概述强调**有账要验、正压表绿≠准用、防火阀灯在位≠交底过、阀要有书面测试与检查秩序、新风路径要有账**（§10，**只借秩序直觉**；**本篇不写逐步绕阀/堵新风教条**）；医院手术室/ICU/隔离区环境控制公开资料强调**环境绿≠新风正压/防火阀合格、温湿度过≠新风台账过、滤网气流过≠正压/阀交底过、气灭过≠防火阀交警边界过**（§10，**只作故事类比**）。本篇只借这串顺序——**本网新风台账格式、正压窗方法、防火阀顺序与合格门限以本网制度、合同与 OEM 书面为准**。

### 2.3 和手册36（AI）/ 48（AU）/ 39（AL）/ 41（AN）/ 15（N）/ 51（AX）/ 47（AT）/ 42（AO）/ 50（AW）/ 46（AS）/ 33（AF）/ 31（AD）/ 28（AA）/ 44（AQ）等的咬合（指针，不重写）

- **AI（手册36）**：温湿度与空调联锁**巡检边界**；**AI ≠ AY**——AI 管温湿度测点/门限/联锁巡检秩序；**AY 管新风台账·正压本体窗·防火阀交底准用**；温湿度过≠新风正压过；「环境绿」「联锁巡检绿」≠ AY 过。  
- **AU（手册48）**：滤网压差与气流组织；**AU ≠ AY**——滤网/压差/气流过≠新风正压/防火阀交底过；气流差可挂 AU，新风正压/防火阀仍 AY。  
- **AL（手册39）**：气灭与疏散；**AL ≠ AY**——气灭过≠防火阀交警边界过；气灭联动可挂 AL，防火阀交底主贴仍 AY（并挂 N 理风暴）。  
- **AN（手册41）**：门禁过≠新风正压交底过；进机房仍要 AN。  
- **AX（手册51）**：精密空调压缩机与制冷剂；**AX ≠ AY**——压缩机/制冷剂过≠新风正压过；制冷与新风/阀各管各的。  
- **AT（手册47）**：冷凝水与加湿除湿；**AT ≠ AY**——冷凝/加湿过≠新风正压过。  
- **AO（手册42）**：漏水探测与汇流排；**AO ≠ AY**——漏水过≠新风路径交底过。  
- **AW（手册50）**：列头柜与末端配电；**AW ≠ AY**——列头末端过≠新风正压过。  
- **AS / AF**：UPS 旁路 / 油机市电；供电过≠新风正压/防火阀过。  
- **AD（手册31）**：压差表/风速仪入库走 AD；**不能**用旧 AD 签日期顶本期 AY 窗或实测窗。  
- **AA（手册28）**：首年巡检日历；新风正压/防火阀抽检可挂 AA，缺秩序整改主贴仍 AY。  
- **N（手册15）**：监控/对时/告警风暴；新风/正压/防火阀异常风暴挂 N 理风暴，**不先抬功率**；**禁绕过防火阀联锁、禁堵死新风冒充正压**；N 绿≠ AY 过。  
- **AQ（手册44）**：正压失稳/阀误关事件要调录像 → 另开 AQ；视频过≠AY 准用。  
- **AV / AR / AG / AP**：油品/燃油/电池/内阻；均不顶替 AY。  
- **R / J / X / I**：假绿挂 R；变更（新风策略、正压门限、防火阀联锁）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 AY 证新风正压与防火阀秩序，再谈覆盖病**。

### 2.4 新贴纸 AY：新 / 正 / 阀 / 验 / 治（五个子类）
