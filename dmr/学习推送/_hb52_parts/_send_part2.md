## 3. 核心交付：插页 AY + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AY（而不是先贴 AI / AU / AL / AN / N / AX）

- 要签「机房新风正压与防火阀准用」、要开新风/正压/防火阀窗、要交底新风正压与防火阀边界 → **主贴 AY**。  
- 温湿度测点/门限/联锁巡检本身 → **AI**（手册36）；新风正压/防火阀本体窗仍 AY。  
- 滤网压差与气流组织本身 → **AU**；新风正压/防火阀交底仍 AY。  
- 气灭与疏散本身 → **AL**；防火阀交警边界仍 AY；气灭联动可挂 AL。  
- 进机房做交底 → 先 **AN**；门禁过≠新风正压交底过。  
- 精密空调压缩机与制冷剂 → **AX**；AX 过≠ AY 过。  
- 新风/正压/防火阀告警风暴 → 先 **N** 理风暴；缺新风正压/防火阀秩序整改仍 **AY**；**禁功率战**；**禁绕联锁**；**禁堵死新风冒充正压**。  
- 假绿/顶替 → 挂 **R**；变更新风策略/正压门限/防火阀联锁 → 走 **J** 后再验 AY。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **新风台账钉死**：机房角色、新风/补风路径 / 新风机组与风阀 / 滤网与进风角色入账；禁「正压表绿就能签」「口头说一声」。  
2. **正压有主有窗有方法/准用期**：每次正压相关维护有主人角色、有书面窗、有方法、有准用期；禁「正压表绿当窗过」；**禁堵死新风冒充正压**。  
3. **防火阀窗与方法钉死**：书面固定；方法含防火阀/防火烟阀交界核对、与 AL/AU/AI/AN 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明逐步绕阀/复位操作教条）；禁「窗再说」「口头试过阀」「绕过防火阀/风阀联锁」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、正压曲线、阀位照片必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「机房新风正压与防火阀准用」；假绿 ≠ 放行。  
6. **禁顶替 AI/AU/AL/AN/AA/N/AQ/AT/AO/AX/AF/AS/AD/AV/AR/AG/AP/AW，主贴 AY，假绿≠放行挂 R**：温湿度签、滤网压差气流签、气灭签、门禁签、首年签、监控签、视频签、冷凝加湿签、漏水签、压缩机制冷剂签、旁路签、油机签、仪表签、油品签、通风燃油签、电池签、内阻签、列头末端签都不顶本期新风正压/防火阀签。  
7. **新风/正压/防火阀异常风暴挂 N，新风策略/正压门限/防火阀联锁变更走 J，禁功率战；禁绕过防火阀与风阀联锁；禁堵死新风冒充正压；禁伪造新风正压防火阀台账**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/防火阀编号全文/可还原坐标与联系人；禁公开传播未脱敏压差门限与阀联锁参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签新风正压/防火阀准用、无实测冒充边界过、绕联锁冒充秩序齐、堵死新风冒充正压，不是法外运维智慧**。医院正压/隔离、防火阀公开资料、UL/NFPA/AMCA 公开页只作故事与方法类比（§2.2）：**新要约、正要窗、阀要法、验要本期、表绿不算过、堵新风不算办法**——翻译成本网语言就是 AY-新 / AY-正 / AY-阀 / AY-验 / AY-治。**这些是机房新风正压与防火阀交底秩序，不是「表绿就签」「灯在位当过」「抬功率压告警」「绕联锁」「堵死新风」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机房新风正压与防火阀准用」、对外宣传「正压一绿阀秒过」、把未实测写成已过、把绕联锁/堵新风写成秩序齐。允许做的：补新风台账、补正压窗、重开阀窗、挂 R/N/J、内部挂整改。

### 4.3 「机房新风正压与防火阀准用」最小集（AY）——缺页不能签准用

1. 新风台账页（路径·机组/风阀·滤网进风）

8. AN 门禁边界勾选（若进人：先 AN；门禁过≠新风正压交底过）  
9. N 风暴边界勾选（防顶替；N 绿≠AY 过）  
10. AX 压缩机制冷剂边界勾选（若同站：AX 过≠AY 过）

| **AV** | 日用油箱油品净化加油 | **不能** |
| **AR** | 油机房通风·排烟·燃油 | **不能** |
| **R / J** | 假绿 / 变更 | 假绿挂 R；变更走 J 后再验 AY |

### 4.7 台账路径（从发现到会签，教学骨架）

```text
  发现新风/正压/防火阀问题 → 主贴 AY
        ↓
  补 AY-新 新风台账 / 补 AY-正 正压窗 / 补 AY-阀 防火阀方法
        ↓
  AY-验 本期实测（禁套）→ 勾清 AI/AU/AL/AN/N/AX 边界
        ↓
  会签准用 / 拒签挂整改；假绿挂 R；风暴挂 N；变更走 J
```

> **路径口诀**：发现贴 AY → 补新补正补阀 → 本期实测禁套 → 边界勾清 → 会签才放 / 拒签挂改。

### 4.8 15 分钟夜班清单（AY8 展开）

1. **2 分钟**：新风台账页在不在？表绿≠准用勾选有没有？  
2. **3 分钟**：正压窗页：主人、窗、方法、准用期；正压表绿≠窗过；禁堵死新风。  
3. **4 分钟**：防火阀窗：书面方法有没有？禁口头试阀/禁绕联锁勾选；AL/AU/AI/AN 分工勾清。  
4. **3 分钟**：本期实测有没有？禁套声明勾了没有？N/AX 边界勾了没有？  
5. **3 分钟**：有无绕联锁/堵死新风/抬功率念头？有则挂 N/R，**禁签准用**；L3 勾选。

## 6. 工作实例（12 则，教学虚构，L3）

1. **正压表绿就要签准用** → 拒签；补 AY-新台账与本期实测。  
2. **正压表绿当窗过 / 防火阀灯在位当阀过** → 拒签；补 AY-正主人/窗/方法；补 AY-阀书面方法。  
3. **口头说试过阀** → 拒签；补 AY-阀书面方法。  
4. **套邻站正压曲线/阀位照片改机房号** → AY-验 拒签重测。  
5. **AI 温湿度签顶本期新风正压签** → 拒签顶替；AI≠AY；可挂 R。  
6. **AU 滤网压差气流签顶新风正压/防火阀交底** → 拒签；AU≠AY。  
7. **AL 气灭签顶防火阀交警边界** → 拒签；AL≠AY。  
8. **AN 门禁签顶新风正压交底 / AX 压缩机制冷剂签顶新风正压** → 拒签；AN≠AY；AX≠AY。  
9. **N 监控绿免本期实测 / 正压告警抬功率** → 拒签实测免做；挂 N；**禁功率战**；缺秩序整改 AY。  
10. **绕过防火阀联锁消告警** → **禁**；挂 N/R；禁签准用。  
11. **堵死新风口冒充正压表绿** → **禁堵死新风冒充正压**；挂整改；本篇不教堵新风；AY-治。  
12. **进机房门禁过了就当新风正压交底过 / 公开群贴真实阀号与门限** → AN 过≠AY 过；L3 违规撤帖脱敏；补 AY。
