### 2.3 和手册47（AT）/ 36（AI）/ 42（AO）/ 57（BD）/ 31（AD）/ 15（N）等的咬合（指针，不重写）

- **AT（手册47）**：冷凝水与加湿除湿联锁；**AT ≠ BE**——冷凝加湿联锁过≠水质与换罐过；联锁可挂 AT，水质·电极/蒸汽罐更换主贴仍 BE；**不得用 BE 顶 AT，也不得用 AT 顶 BE**。**冷凝加湿联锁 ≠ 水质换罐准用**——钉死。  
- **AI（手册36）**：温湿度与空调联锁巡检；**AI ≠ BE**——温湿度过≠水质/换罐窗过。  
- **AO（手册42）**：漏水探测与汇流排；**AO ≠ BE**——漏水过≠水质台账过；水浸可挂 AO，水质主贴仍 BE（并挂 N 理风暴）。**漏水 ≠ 水质台账**——钉死。  
- **BD（手册57）**：冷冻水泵组与定压补水；**BD ≠ BE**——泵组/定压/补水过≠加湿器水质与换罐过；定压补水水质测点（若有）≠本篇加湿器水质台账。  
- **AD（手册31）**：电极罐/蒸汽罐/水质取样器具入库走 AD；**不能**用旧 AD 签日期顶本期 BE 换罐窗或实测窗。**备件入库 ≠ 本期换罐窗**——钉死。  
- **AX（手册51）**：精密空调压缩机与制冷剂；**AX ≠ BE**——压缩机/制冷剂过≠水质/换罐过。  
- **BA / AY / AZ / AU / BB / BC**：冷冻水冷却塔 / 新风正压 / 冷通道进出风 / 滤网气流 / 室外机冷凝侧 / 机柜PUE；均不顶替 BE。  
- **AW / AF / AS**：列头末端 / 油机市电 / UPS 旁路；供电过≠水质/换罐过。  
- **AN（手册41）**：门禁过≠水质换罐交底过；进机房仍要 AN；**不教绕过门禁/加湿联锁**。  
- **AA（手册28）**：首年巡检日历；水质/换罐抽检可挂 AA，缺秩序整改主贴仍 BE。  
- **N（手册15）**：监控/对时/告警风暴；水质/换罐异常风暴挂 N 理风暴，**不先抬功率**；**禁关阀冒充、禁开旁通、禁绕加湿联锁、禁不安全排空/带电违章**；N 绿≠ BE 过。  
- **AQ（手册44）**：水质/换罐异常事件要调录像 → 另开 AQ；视频过≠BE 准用。  
- **AV / AR / AG / AP**：油品/燃油/电池/内阻；均不顶替 BE。  
- **R / J / X / I**：假绿挂 R；变更（电导率门限、换罐窗方法、水源角色）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 BE 证水质与换罐秩序，再谈覆盖病**。

## 3. 核心交付：插页 BE + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 BE（而不是先贴 AT / AI / AO / BD / AD / N）

- 要签「机房加湿器水质与电极蒸汽罐更换准用」、要开水质/换罐窗、要交底水质与换罐边界 → **主贴 BE**。  
- 冷凝水与加湿除湿联锁本身 → **AT**（手册47）；水质·电极/蒸汽罐更换本体窗仍 BE。  
- 温湿度联锁巡检本身 → **AI**；水质/换罐窗仍 BE。  
- 漏水探测与汇流排本身 → **AO**；水质台账仍 BE（**AO ≠ BE**：漏水 ≠ 水质台账）。  
- 冷冻水泵组与定压补水本身 → **BD**；加湿器水质/换罐仍 BE（**BD ≠ BE**）。  
- 电极罐/蒸汽罐/水质取样器具入库 → **AD**；本期换罐窗仍 BE（**AD ≠ BE**：备件入库 ≠ 本期换罐窗）。  
- 进机房做交底 → 先 **AN**；门禁过≠水质换罐交底过；**不教绕过门禁/加湿联锁**。  
- 水质/换罐告警风暴 → 先 **N** 理风暴；缺水质/换罐秩序整改仍 **BE**；**禁功率战**；**禁关阀冒充**；**禁开旁通**；**禁绕加湿联锁**；**禁不安全排空/带电违章**。  
- 假绿/顶替 → 挂 **R**；变更电导率门限/换罐窗方法/水源角色 → 走 **J** 后再验 BE。  
- 本站无电极/蒸汽加湿或无水质/换罐路径 → 书面勾「不适用」；**不得**用 BE 顶 AT 或 AI。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **加湿器水质台账钉死**：水源角色、电导率/水质测点、软水/RO/去离子路径角色入账（编号脱敏）；禁「湿度绿就算过」「口头说水质正常」。  
2. **电极/蒸汽罐更换有主有窗有方法/准用期**：电极罐/蒸汽罐·更换周期窗·耗材准用等以本网与 OEM 书面为准；每次换罐相关维护有主人角色、有书面窗、有方法、有准用期；禁「湿度绿当窗过」「口头换过」。  
3. **水质/换罐与冷凝加湿/温湿度/漏水边界窗与方法钉死**：书面固定；方法含水质/换罐与冷凝加湿/温湿度/漏水边界核对、与 AT/AI/AO/AX/N 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明逐步关阀/开旁通/绕加湿联锁/不安全排空/带电违章操作教条）；禁「窗再说」「关阀冒充」「开旁通冒充」「绕加湿联锁」「不安全排空/带电违章」「伪造台账」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、水质表、换罐表必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「机房加湿器水质与电极蒸汽罐更换准用」；假绿 ≠ 放行。  
6. **禁顶替 AT/AI/AO/AX/AY/AZ/AU/BB/BA/BD/BC/AW/AF/AS/AD/AN/AA/N/AQ/AV/AR/AG/AP，主贴 BE，假绿≠放行挂 R**：冷凝加湿签、温湿度签、漏水签、压缩机制冷剂签、新风签、冷通道签、滤网气流签、室外机冷凝侧签、冷冻水冷却塔签、泵组定压补水签、机柜PUE签、列头末端签、油机市电签、旁路签、仪表/备件签、门禁签、首年签、监控签、视频签、油品签、通风燃油签、电池签、内阻签都不顶本期水质/换罐签。**尤其：AT ≠ BE，AI ≠ BE，AO ≠ BE，BD ≠ BE，AD ≠ BE。**  
7. **水质/换罐异常风暴挂 N，边界/门限/换罐窗变更走 J，禁功率战；禁关阀冒充；禁开旁通；禁绕联锁；禁不安全排空/带电违章；禁伪造台账**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/回路编号全文/可还原坐标与联系人；禁公开传播未脱敏电导率门限与换罐参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签水质/换罐准用、无实测冒充边界过、关阀/开旁通/绕加湿联锁/不安全排空/带电违章冒充秩序齐，不是法外运维智慧**。医院加湿器水质与电极/蒸汽罐更换、数据中心 CRAC/CRAH electrode / steam humidifier canister 公开资料只作故事与方法类比（§2.2）：**水要约、罐要窗、界要法、验要本期、湿度绿不算过、口头水质正常不算方法过、口头换过不算窗过、关阀旁通绕联锁不算办法**——翻译成本网语言就是 BE-水 / BE-罐 / BE-界 / BE-验 / BE-治。**这些是水质与换罐交底秩序，不是「湿度绿就签」「口头换过当过」「抬功率压告警」「关阀先过」「旁通冒充」「绕联锁冒充」「带电违章冒充」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机房加湿器水质与电极蒸汽罐更换准用」、对外宣传「湿度绿/口头水质正常/口头换过秒过」、把未实测写成已过、把关阀/旁通/绕联锁/排空带电违章写成秩序齐。允许做的：补水质台账、补换罐窗、重开边界窗、挂 R/N/J、内部挂整改。

## 6. 工作实例（12 则，教学虚构，L3）

1. **湿度绿想签准用**：湿度指示绿，运维要签准用 → 查 BE1，无水质台账本期核对 → **拒签**；补 BE-水。  
2. **口头水质正常 / 口头换过当窗过**：外包称「水质正常 / 换过了」免窗页 → **拒签**；补 BE-罐 主人/窗/方法/准用期。  
3. **AT 顶替 BE**：班长用 AT 冷凝加湿签顶本期水质换罐签 → **挂 R**；主贴仍 BE；AT过≠BE过。  
4. **AI / AO 顶替**：站务称温湿度与漏水过了水质换罐免做 → **拒签顶替**；AI≠BE、AO≠BE；漏水≠水质台账。  
5. **N 绿免实测**：大屏环境绿，本期实测免 → **拒签**；N绿≠BE过；补 BE-验。  
6. **套邻站表**：外包拷邻站水质/换罐表改机房号 → **BE-验 拒签重测**；禁套。  
7. **功率战**：加湿跳闸/电极罐告警，网优要抬功率 → **禁功率战**；先挂 N；缺秩序整改贴 BE。  
8. **关阀冒充**：外包关阀消告警后要求准用 → **禁**；挂 N/R；禁签。  
9. **开旁通 / 绕联锁冒充**：新人开旁通或绕加湿联锁让湿度变绿 → **禁**；挂整改；主贴 BE-治。  
10. **BD / AD / BC 混签**：环境班称 BD 泵组定压补水与 AD 备件入库、BC 机柜PUE过了，水质换罐免 → **拒签**；BD≠BE、AD≠本期换罐窗、BC≠BE。  
11. **不安全排空/带电违章**：外包未按本网书面排空就带电拆罐要求准用 → **禁**；挂 N/R；禁签。  
12. **泄密发群**：新人公开群贴真实回路编号与电导率门限 → **L3 违规**；脱敏重发；挂 BE-治。
