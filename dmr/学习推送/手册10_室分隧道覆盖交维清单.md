# 手册 10 · 运维交维：室分·隧道覆盖交维清单

> **手册模式 · 岗位深挖（运维 / 交维 / 站务交界）第 10 篇**（接第 40 课收官 · 手册 01–09 之后 · **不是第 41 课**）  
> 适合：手册 01–09 已经给了你贴纸 A–H 和五格梯子，可一到「大楼交维签字 / 隧道开通 / 室分改造验收」你就慌——竣工图不全、接头没扫、只测下行不测上行、用公网 LTE 指标代替 DMR、签字后才发现电梯井盲区或泄漏电缆进水——你想学会**先证明「管子通、水压够、漏点在设计位置」再签字**的人  
> 阅读量：约 **30–40 分钟** · **不重 dump CACH / EMB / Slot Type 全字段**（第 18–22 课已有）、**不重写手册07 干扰分诊全文 / 手册08 实验室六闭环全文**（只给指针）、**不发明 ETSI 条款号**、**不写真实频点 / 站点名 / 个号 / 密钥 / 真实楼宇名**（全部教学虚构、脱敏到 L3） · 要把「**交维签字 ≠ 覆盖永久正确；只测下行不够；加功率掩盖不断的接头；室分资料不全 = 下次事故的种子**」钉成肌肉记忆  
> **频谱 / 调制提醒（弱项短补）**：一条 DMR 信道占 **12.5 kHz**；**4FSK** 装货；**2-slot TDMA** 把时间切成 **30 ms** 一格、两格一轮 **60 ms**。室分/隧道不改变这些台阶——它只是把「基站门口的那一瓢水」用馈线、功分、泄漏电缆、远端单元**分到走廊、电梯、岔道、洞口**。本篇问的不是「台阶解没解对」，而是：**管子通不通？分叉后每一支水压够不够？漏水是不是发生在设计该漏的缝上？** 四句话原版见 `学习推送/加餐_频率带宽与调制解调.md`。

## 1. 为什么要写这篇手册（动机 + 现场对话）

前九篇手册教你认病：贴纸 A–E 是协议层，贴纸 F 是射频层，贴纸 G 是实验室闭环，贴纸 H 是话务/容量。可现场还有一类「病」——**不是今晚才发作，而是交维那天就埋下的**：

- 施工队：「下行口功率测过了，可以签。」——没人问上行噪底；开通两周后金机在远端「听得到、打不出去」。  
- 监理：「竣工图在 U 盘里。」——U 盘里是初版；隐蔽工程照片缺三分之一；点位表与墙上实际天线对不上。  
- 运维：「隧道口切换老掉。」——交维时没做口部双向走测；泄漏电缆端头密封照片找不到。  
- 班长：「电梯里没信号，加个直放站增益。」——隔离不够，自己喊自己，噪底抬高，整栋楼被减敏（接手册07 F-互气质，本篇不重写梯子）。  
- 领导：「公网 LTE 走测图都绿了，DMR 应该没问题。」——公网指标**不能**代替本网 DMR 的 RSSI·SYNC·CC·BER。  
- 新人：「那不就是手册07 的 F-弱吗？」——症状可以落到 F-弱，但**交维场景要的是验收清单与边界责任**，不是事后分诊叙事；本篇贴纸 **I** 管的是「签之前证明什么」。

这几句背后是同一件事：

> **「交维」这个词在现场至少有五个坑**：  
> **① I-资**：资料/竣工图/点位表/隐蔽工程照片不全——签了等于签了一份说不清的资产  
> **② I-无源**：馈线/接头/功分/耦合器/天线的 VSWR·DTF·插损不过——管子本身漏气或堵  
> **③ I-有源**：直放站/光纤远端/远端单元增益·隔离·噪底·告警不对——水泵自己在抖  
> **④ I-覆**：步行/车载覆盖走测不达标、口部切换、电梯/岔道盲区——水龙头安错层  
> **⑤ I-交**：交维边界不清（谁管信源谁管室分、备件、巡检周期、金机基线）——以后坏了没人认账  
> 把 ①–⑤ 当成「签完再慢慢调」或「开通后用手册07 慢慢分」，会把整栋楼/整条隧道的隐患留给下一班。

本篇目标：能背出**室分·隧道交维工作流**；会用新贴纸 **I（室分/隧道交维）** 与五个子类；会填 **插页 I（R1–R8）** 和《本网室分·隧道覆盖交维清单》；能用「水管分叉」故事讲清被动室分 / 有源 / 泄漏电缆；能拒绝「未测就签、只测下行、用公网指标代替 DMR」；自测过关后，回库把本网最近一份室分或隧道交维包（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：不发明 ETSI 条款号；**不写真实批复频点、真实楼宇/隧道名、真实站号、真实个号、真实密钥进公开仓库**；不重写手册07 五格梯子全文、手册08 六闭环全文（只给指针与衔接）；**不把「开大功率 / 开大直放站增益」当交维补救**；隔离度只用「不要自己喊自己」的量级直觉（可指向 ETR 053 公开工程报告作阅读，**不背条款号**）；结案词用贴纸 I + 本网证据，不用厂商室分品牌当 ETSI 强制术语。

## 2. 总图 / 故事：大楼 / 隧道像「水管分叉」

### 2.1 一句话：交维 = 先证明「管子通、水压够、漏点在设计位置」再签字

```text
   ┌──────────────────────────────────────────────────────────┐
   │  信源（基站 / 近端）  ≈ 总水阀                                │
   │         │                                                 │
   │         ▼                                                 │
   │  合路 / 功分 / 耦合器  ≈ 分水器                               │
   │         │                                                 │
   │    ┌────┴────┬────────────┐                               │
   │    ▼         ▼            ▼                               │
   │  馈线分支   泄漏电缆     光纤→远端单元                      │
   │  （走廊）   （隧道缝）    （有源远端）                       │
   │    │         │            │                               │
   │    ▼         ▼            ▼                               │
   │  天线/缝隙  缝隙辐射     远端天线                           │
   │                                                           │
   │  交维要证明：                                               │
   │  · 管子通（接头/馈线/分支 VSWR·DTF·插损）→ 贴纸 I-无源       │
   │  · 水泵稳（有源增益·隔离·噪底·告警）→ 贴纸 I-有源             │
   │  · 水到该到的龙头（走测达标、口部/电梯/岔道）→ 贴纸 I-覆      │
   │  · 图纸与实物一致（点位表/隐蔽照）→ 贴纸 I-资                 │
   │  · 以后谁修谁巡（边界/备件/金机基线）→ 贴纸 I-交              │
   └──────────────────────────────────────────────────────────┘
```

口诀：

> **先证明管子，再谈水龙头感觉。**  
> 只听「这层好像有信号」就签字 = 只摸龙头温度、不查水管有没有裂。  
> 交维清单要的是**可复查的测量与资料**，不是开通当天的好运气。

### 2.2 三种常见「水管」直觉对比（弱项短补，钉死）

| 形态 | 像什么 | 运维直觉 | 交维最爱漏的项 |
|------|--------|----------|----------------|
| **被动室分** | 纯管子+分水器+龙头（无源） | 故障多在接头进水、功分接反、天线被挡 | VSWR/DTF/插损分段；点位与图纸一致 |
| **有源 / 光纤直放站** | 管子中间加了水泵（近端+远端） | 增益、隔离、噪底、告警、光路都会「自己制造病」 | 上下行平衡；隔离＞增益一截；告警清零 |
| **泄漏电缆（隧道）** | 管子侧壁开了设计好的细缝一路漏 | 端头密封、卡子接地、口部切换、水浸是经典坑 | 两端 DTF；口部双向走测；隐蔽密封照 |

> 同一栋楼/同一条隧道可以**混用**三种形态。交维时按**分支**建账，不要一张总表糊弄整条系统。

### 2.3 和五格梯子（手册07）怎么咬合

室分交维的「覆盖走测」最终仍要落到：

```text
  能量（RSSI/场强体感）→ SYNC → 身份（CC/CACH气质）→ BER → 业务
```

本篇**不重写**五格梯子与 F 五子类。交维场景的特殊点是：

- 走测点位按**设计点位表**取样，不是随便走廊溜达。  
- **上下行都要测**：只测下行口功率 = 只证明「龙头有水往外喷」，不证明「你喊得回去」。  
- 交维不合格时，先贴 **I-无源 / I-有源 / I-覆**，再决定要不要转手册07 的 F 分诊叙事。  
- 开通后的「突然变差」：优先怀疑二次施工破坏、进水、增益被人拧过——仍用 I 的复查清单，再挂 F。

### 2.4 新贴纸 I：室分 / 隧道交维（五个子类）

```text
                    ┌──────── 贴纸 I · 室分/隧道交维 ────────┐
                    │                                        │
         ┌──────────┼──────────┬──────────┬──────────┐      │
         ▼          ▼          ▼          ▼          ▼      │
      I-资       I-无源      I-有源      I-覆       I-交    │
   资料/竣工图   馈线接头    直放站/     走测盲区   边界责任 │
   点位/隐蔽照   功分天线    光纤远端    口部切换   备件巡检 │
   不全         VSWR·DTF    增益隔离    电梯岔道   金机基线 │
                插损不过    噪底告警    不达标               │
                    └────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型一手证据（教学） | 常见误贴 |
|------|--------|----------------------|----------|
| **I-资** | 账本不全，资产说不清 | 竣工图缺页；点位表与实物不符；隐蔽工程无照 | 「以后补资料」空话 |
| **I-无源** | 管子/接头/分支物理不过 | VSWR 超限；DTF 见异常反射；分支插损离谱 | 直接开大功率掩盖 |
| **I-有源** | 水泵抖：增益/隔离/噪底/告警 | 上行噪底抬高；隔离不足自激气质；远端告警未清 | 当 F-弱 盲目加天线 |
| **I-覆** | 设计该到的点到不了 / 口部切换差 | 金机走测 RSSI·SYNC·CC·BER 不达标；电梯/岔道盲 | 用公网 LTE 绿图代替 |
| **I-交** | 谁管什么、怎么巡、金机基线谁存 | 信源/室分界面口头约定；无备件清单；无巡检周期 | 「出了问题再找施工方」 |

**和贴纸 A–H 的咬合**：

- 交维当天**优先 I**，不要一上来用协议贴纸 A–E 解释「电梯没信号」。  
- 走测中若出现「满格登不上 / 有声咔咔 / 站边反而差」，**指针回手册07** 五格梯子与 F 子类——那是开通后分诊，本篇管的是**签之前最小证明包**。  
- 贴纸 G（手册08）：金机基线应在交维时入库；以后实验室对照才有「交维日金线」。  
- 贴纸 H：室分本身一般不加信道；若交维后高峰忙，仍走手册09，**不要用加室分增益冒充扩容**。  
- 贴纸 X：只有「感觉还行」的口述、没有 VSWR/走测/资料清单时，先 X，**禁止签字**。

## 3. 核心交付：交维工作流 + 插页 I + 本网清单预告

### 3.1 室分·隧道交维工作流（每次验收照念）

```text
  ① 资料开门：竣工图、点位表、设备清单、隐蔽工程照片、变更单
  ② 无源分段：回波/VSWR、DTF（长线两端）、分支插损；（有条件）PIM
  ③ 有源项：近端/远端增益、隔离直觉检查、上行噪底、告警清零、光功率（光纤时）
  ④ 口功率与平衡：关键耦合点下行口功率；抽测上行可达性
  ⑤ 金机走测：按点位表；记 RSSI·SYNC·CC·BER·业务（接手册07 梯子，不重写）
  ⑥ 专项抽测：电梯轿厢、地下车库角、隧道口部双向、岔道/横通道
  ⑦ 边界落纸：信源 vs 室分界面、备件、巡检周期、金机基线存放
  ⑧ 禁止：未测就签；只测下行；公网 LTE 代替 DMR；加功率/加增益掩盖断点
```

### 3.2 子类判定速查（心脏表）

| 若你看见… | 优先子类 | 下一刀 |
|-----------|----------|--------|
| 点位表与墙上天线编号对不上；隐蔽照缺失 | I-资 | 补测前先补资料或标「开口项」；拒签整包也可 |
| 某分支 VSWR 超限；DTF 在预计接头位置尖峰 | I-无源 | 打开该段；查进水/力矩/功分接反；返工后复测 |
| 长泄漏电缆一端正常、另一端 DTF 异常 | I-无源（隧道） | 两端测；查中间卡子/进水/机械损伤 |
| 远端一开，近端上行噪底明显抬高 | I-有源 | 降增益；查隔离与安装距离；禁止继续加大增益 |
| 告警灯未清、光收无光、远端掉线 | I-有源 | 先清告警再谈覆盖 |
| 走廊尚可，电梯/岔道/口部金机梯子失败 | I-覆 | 按设计补点或改分支；走测记录进交维包 |
| 「LTE 都绿了所以 DMR 过」 | **拒绝该证据** | 强制本网金机走测；倾向 I-覆 证据不足→X |
| 信源归 A 队、室分归 B 队，口头说「出了事再说」 | I-交 | 书面界面 + 备件 + 巡检；否则带条件签 |
| 交维后半月突然变差，无二次施工记录 | 复查 I-无源/有源 | 进水与被人拧增益是高频；再挂手册07 若需 |

### 3.3 插页 I · 室分 / 隧道交维（挂在总三联单或交维包首页后）

| # | 格 | 填什么（教学虚构例） |
|---|----|----------------------|
| R1 | 主子类 + 次子类 | 「主 I-无源 / 次 I-资」（或 I-有源 / I-覆 / I-交） |
| R2 | 系统形态 | 「被动室分 + 电梯井有源远端」（或「泄漏电缆主+口部天线」） |
| R3 | 资料齐套 | 「竣工图√ 点位表√ 隐蔽照缺 2 处已列开口项」 |
| R4 | 无源测量 | 「分支 A/B/C VSWR·DTF·插损：过/不过；PIM：做/未做」 |
| R5 | 有源测量 | 「增益设定（教学相对值）；隔离检查；上行噪底；告警清零」 |
| R6 | 覆盖走测 | 「点位表 N 点；金机 RSSI·SYNC·CC·BER；口部/电梯/岔道抽测」 |
| R7 | 判定与动作 | 「带条件签：开口项 14 日内补隐蔽照+复测分支 B；禁止加增益」 |
| R8 | 证据包清单 | 「插页 I；测量曲线（已 L2）；走测表；签字页；金机基线入库号」 |

**插页组合**：I 常与 F（开通后分诊）、G（金机基线）、X（证据不足拒签）同挂。**不要**把「交维未测」写成「用户不会用机器」。

### 3.4 「未测禁止签」卡（贴验收会议室）

```text
在插页 I 的 R3–R6 没填之前，下面这些话不许进签字栏：
  × 「下行口功率看着行，先签」     （缺上行与走测）
  × 「公网图都绿了」               （公网 ≠ 本网 DMR）
  × 「资料回头补」                 （无开口项书面 = 拒）
  × 「增益再开大一点就满格」       （掩盖断点 / 制造自激）
  × 「隧道车开过去听得见就行」     （缺口部双向与 DTF）
可以做：
  ✓ 列开口项与复测日期；带条件签必须书面
  ✓ 判定为 X 并写清缺哪一包证据
  ✓ 金机按点位表走测并入库基线
```

### 3.6 《本网室分·隧道覆盖交维清单》预告

## 4. 深潜：三种形态 + 最小测试包 + 隔离直觉 + 「签字≠永久正确」

### 4.1 被动室分 vs 有源/光纤 vs 泄漏电缆（对照表加厚）

| 维度 | 被动室分 | 有源 / 光纤直放站 | 泄漏电缆（隧道） |
|------|----------|------------------|------------------|
| 能量怎么走 | 合路→功分→馈线→天线 | 近端↔光/电↔远端→天线 | 沿线缝隙连续「漏」 |
| 典型优点 | 结构简单、无源噪底贡献小 | 远距离、分层灵活 | 隧道纵向连续覆盖友好 |
| 典型坑 | 接头进水、功分接反、天线被装修挡 | 隔离不足、增益乱拧、上行噪底、光路告警 | 端头密封、卡子、水浸、口部切换 |
| 交维最小证 | 分段 VSWR/DTF/插损 + 点位走测 | 上项 + 增益/隔离/噪底/告警 | 两端 DTF + 口部双向走测 + 密封照 |
| 和 F 的关系 | 开通后变差常先查无源破坏 | 减敏/自激气质接 F-互 | 口部易被当成 F-弱/F-时，先查交维是否做过 |

### 4.2 交维最小测试包（每项一句「为什么要测」）

#### 4.2.1 回波 / VSWR（驻波）

- **白话**：管子里有没有「撞回来的水」。  
- **交维用法**：按分支/频段扫；超限就别谈覆盖感觉。  
- **别混成**：VSWR 好 ≠ 覆盖一定好（还可能功分后某支路没接天线）。

#### 4.2.2 DTF（Distance-to-Fault，时域/距离找故障）

- **白话**：用尺子在管子里找「哪一米撞得最狠」。  
- **交维用法**：长馈线、长泄漏电缆**强烈建议**；最好**两端都测**（一端看不见的损伤，另一端可能清楚）。  
- **教学虚构例**：预计 120 m 处接头反射异常 → 打开发现进水。

#### 4.2.3 插损 / 分支损耗

- **白话**：分水器和管子吃掉了多少水压。  
- **交维用法**：与设计预算比；某支路离谱偏低 → 接反、空载、接头差。

#### 4.2.4 PIM（无源互调，有条件做）

- **白话**：松接头、劣质金属在大功率下自己「唱杂音」。  
- **交维用法**：有仪表就做关键汇聚段；没条件须在交维包写「未做 PIM + 原因」，不能假装做过。  
- **指针**：理解入口见 §10 Anritsu PIM 公开页；本篇不教操作菜单逐步点击。

#### 4.2.5 口功率（下行）与上行可达

- **白话**：龙头喷出来多少；你对着龙头喊，总阀听不听得到。  
- **交维用法**：关键耦合口记下行；远端用金机做业务/登记抽测证明上行。  
- **禁令**：**只测下行口功率就签字 = 本篇点名反例。**

#### 4.2.6 上行噪底（尤其有源）

- **白话**：水泵有没有把泥沙搅进回水管。  
- **交维用法**：远端开关对比；增益步进对比；记录教学相对值。  
- **和手册07**：噪底抬高后的「站边反而差 / 一转发就断」气质接 F-互——交维阶段就应拦住。

#### 4.2.7 金机走测（接五格梯子，不重写）

按点位表：能量 → SYNC → CC 气质 → BER → 业务。电梯、车库角、隧道口部、岔道**强制抽测**。金机与写频基线入库（接手册08 金机对照气质）。

### 4.3 隔离度直觉：「不要自己喊自己」

有源系统（直放站/部分光纤远端架构）常有一句工程常识：

> **施主侧与重发侧要隔开；隔离要明显大于增益。**  
> 白话：你把喇叭对着自己的麦克风，增益越大越容易啸叫——射频上就是自激/抬噪底。

阅读入口：ETSI **ETR 053**（无线电站点工程公开技术报告）讨论站点工程与兼容测量的工程气质——**本篇只借量级直觉，不背、不发明条款号**。现场口令：

```text
  增益↑ 而 隔离不变 → 危险区靠近
  天线对打 / 泄漏路径短 → 先改安装与屏蔽，再谈增益
  「再开两格就满格」→ 先怀疑在喂自激，而不是在补覆盖
```

### 4.4 「交维签字 ≠ 覆盖永久正确」

| 时间炸弹 | 看起来像 | 交维时该留下什么 |
|----------|----------|------------------|
| 接头缓慢进水 | 两周后某分支 VSWR 恶化、走测变差 | DTF 基线曲线；力矩/密封照 |
| 装修二次破坏 | 某层突然盲 | 点位表与照片；巡检周期（I-交） |
| 有人把远端增益拧大 | 「更好了」然后整网上行变差 | 增益铅封/照片/网管只读基线 |
| 加信源功率掩盖断点 | 暂时满格，干扰边界被毁 | **禁止**该补救；断点必须修 |
| 口部植被/金属门变更 | 隧道口切换恶化 | 口部走测基线；变更复测制度 |

> 交维包的价值，一半在「今天过没过」，一半在「三个月后还能不能对照」。没有基线的签字，是一张会过期的安慰剂。

### 4.5 和弱项加餐的衔接

室分不改变 12.5 kHz / 4FSK / 30 ms 两槽。走测时 BER 差，可能是场强弱，也可能是干扰/自激——**用梯子分，不靠感觉加增益**。卡住回 `学习推送/加餐_频率带宽与调制解调.md`，再回手册07 §2。

## 5. 现场映射：原话 → I 子类；对话脚本；反例

### 5.1 原话 → 主子类

| 用户 / 施工 / 监理原话 | 先问 | 主子类倾向 |
|------------------------|------|------------|
| 「资料在微信里，回头导」 | 交维包是否齐套书面？ | I-资（不齐则开口项或拒签） |
| 「这根电缆 VSWR 差点，凑合」 | DTF 定位？能否返工？ | I-无源 |
| 「远端开大一格就满格」 | 噪底变了吗？隔离查了吗？ | I-有源（高危） |
| 「走廊行，电梯不行」 | 点位表有无电梯测点？金机梯子？ | I-覆 |
| 「LTE 路测报告附上了」 | 有无本网 DMR 金机走测？ | **拒作主证据**；缺则 I-覆/X |
| 「信源他们管，室分我们管，出了事再说」 | 书面界面？ | I-交 |
| 「开通后再慢慢调」 | R3–R6 空着吗？ | **拒签**气质 |
| 「加点功率遮一下断点」 | — | **禁止**；回 I-无源返工 |

### 5.2 值班 / 验收对话脚本

#### 对话 A · 「下行测过了，签吧」

> 你：上行噪底和金机远端业务测了吗？电梯/口部抽测了吗？  
> 若无 → 「本网清单要求上下行都要。现在签不合规，先补测。」

#### 对话 B · 「公网都绿了」

> 你：公网与本网 DMR 不是同一条水管。请按点位表用本网金机走 RSSI·SYNC·CC·BER。  
> 公网报告可作**附件参考**，不能作签字主证据。

#### 对话 C · 「增益再开大就行」

> 你：开大增益可能自己喊自己，把上行噪底抬起来，整段被减敏。先查无源断点与隔离，禁止用增益掩盖。

#### 对话 D · 「资料回头补」

> 你：可以带条件签，但必须书面开口项：缺什么、谁补、哪天复验。没有开口项 = 拒签。

#### 对话 E · 「隧道开车听得见就行」

> 你：还要两端 DTF、口部双向、岔道抽测、端头密封照。听得见是必要，不是充分。

### 5.3 反例集（禁止清单）

| 反例 | 为什么有害 | 正确动作 |
|------|------------|----------|
| 未测就签 | 把隐患合法化 | R3–R6 填完或书面开口项 |
| 只测下行不测上行 | 掩盖「听得到打不出」 | 口功率 + 金机上行业务 |
| 公网 LTE 代替 DMR | 指标族不同 | 本网金机梯子走测 |
| 加功率/加增益掩盖断点 | 破坏干扰边界；制造自激 | 返工 I-无源；查 I-有源隔离 |
| 一张总 VSWR 糊弄全部分支 | 藏坏支路 | 按分支建账 |
| 长泄漏电缆只测一端 | 漏看远端损伤 | 两端 DTF |
| 无隐蔽照却称「已密封」 | 进水无法追责 | I-资 开口项 |
| 交维不入库金机基线 | 以后 G/F 对照失锚 | 基线进手册08 气质档案 |

### 5.4 40 分钟标准节奏（单次关键验收可复印；大项目按分支加倍）

```text
  0–5 min    资料开门：图、点位、隐蔽照、变更单（I-资）
  5–15 min   无源关键分支 VSWR/DTF/插损抽检（I-无源）
  15–25 min  有源项：增益/告警/噪底对比（无有源则改走测）
  25–35 min  金机点位走测 + 电梯/口部/岔道抽测（I-覆）
  35–40 min  填插页 I；开口项或拒签/签字；金机基线入库嘱咐（I-交）
```

大隧道/大楼：把 5–35 min 按分支滚动，**不要压缩成「下午看一眼」**。

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「签完第三天电梯没信号」→ I-资 + I-覆

现象：交维当日走廊走测尚可；电梯未列入点位表。  
观察：补测电梯轿厢金机 SYNC/BER 失败；井道无天线照片。  
判定：主 I-覆，次 I-资（点位表缺项）。  
动作：开口项补井道方案；拒收「口头说以后加」。  
教训：点位表缺专项 = 交维包先天不足。

### 例 2 · 「分支 B 差点 VSWR，功率开大遮一下」→ I-无源（禁止掩盖）

现象：施工建议临时加大信源功率。  
观察：DTF 在预计接头位置反射异常。  
判定：I-无源。拒签该分支；返工接头后复测。  
禁令：功率掩盖进交维负面案例库。

### 例 3 · 「远端一开，近端上行噪底抬一截」→ I-有源

现象：覆盖「变好」，但同站户外金机上行变差。  
观察：远端增益偏高；施主/重发隔离不足气质；告警偶发。  
判定：I-有源。降增益、改安装隔离；复测噪底与走测。  
指针：开通后若仍「站边差」，挂手册07 F-互继续分诊。

### 例 4 · 「泄漏电缆一端漂亮、另一端乱七八糟」→ I-无源（隧道）

现象：只从口部 A 测 DTF 合格；口部 B 投诉弱。  
观察：从 B 端测见中段异常；打开发现卡子处护套破损失水浸。  
判定：I-无源。两端测写入强制条款。  
证据：两端曲线对比进交维包。

### 例 5 · 「LTE 绿图附卷要求签字」→ 拒作主证据

现象：监理附公网路测。  
观察：无本网金机点位走测表。  
判定：证据不足（X）倾向；要求补 I-覆。  
话术：用 §5.2 对话 B。

### 例 6 · 「资料微信传过就行」→ I-资

现象：U 盘/网盘链接失效；隐蔽照缺失。  
观察：现场天线编号与初版图不一致。  
判定：I-资。带条件签须书面开口项；否则拒签。  
对齐手册06：证据要可归档，不接受「我发过」。

### 例 7 · 「口部切换老掉，说是干扰」→ I-覆（先）

现象：隧道口反复搜网。  
观察：交维包无口部双向走测；洞内尚可。  
判定：先 I-覆 补测口部；若梯子显示身份层异常再挂手册07 F-同/F-时。  
教训：别一开口部就先打架干扰——先问交维做过没有。

### 例 8 · 「谁管信源谁管室分说不清」→ I-交

现象：故障单在两队间踢皮球。  
观察：界面无书面；备件无清单；巡检周期空白。  
判定：I-交。补《界面与巡检》页才能闭口项。  
金机基线存放位置写进 I-交。

### 例 9 · 「装修后某层突然盲」→ 复查 I-无源

现象：交维半年后单层投诉。  
观察：对照交维 DTF 基线，新出现反射峰；装修队曾动吊顶。  
判定：二次破坏导致 I-无源复发；挂巡检制度（I-交）追责。  
价值：没有交维基线就无法证明「以前好过」。

### 例 10 ·（对照）实验室金机正常、现场远端不行 → 不是终端玄学

现象：班长要换一批手台。  
观察：手册08 气质台架 G 过；现场仅室分远端区域差；VSWR 异常。  
判定：主 I-无源/I-覆，不换机。  
教训：G 过支持「别先砸终端」；交维/室分账优先。

### 6.5 交维对齐会：20 分钟议程

```text
  1) 本周交维项目清单与开口项（3 min）
  2) Top 拒签/带条件原因：I 子类分布（4 min）
  3) 误证统计：公网图/只测下行/加增益掩盖（4 min）
  4) 金机基线是否入库；与手册08 档案对齐（4 min）
  5) 巡检与二次施工破坏案例复盘（5 min）
```

**易错观念十条**：

1. 「下行口功率过 = 可以签」→ 缺上行与走测。  
2. 「公网绿 = DMR 绿」→ 否。  
3. 「增益开大 = 交维补丁」→ 高危。  
4. 「VSWR 好 = 整栋没问题」→ 分支与走测仍要做。  
5. 「泄漏电缆测一端够了」→ 两端更稳。  
6. 「资料微信发过 = 归档」→ 要可复查附件。  
7. 「签字后永远正确」→ 进水与二次破坏会毁掉。  
8. 「电梯没信号先换手台」→ 先查点位与井道。  
9. 「交维是施工的事，运维别管」→ I-交 就是运维的未来。  
10. 「加信源功率遮断点」→ 禁止。

**题 10.** 列出封面拒签门槛至少四条（与 §7.1 对齐）。

### 参考答案

1. **I-资**资料不全；**I-无源**管子接头测不过；**I-有源**增益隔离噪底告警不对；**I-覆**走测/专项不达标；**I-交**边界备件巡检基线不清。拒签例：无开口项的缺资料；关键分支 DTF 不过；有源告警未清；无金机走测；加增益掩盖。  
2. 下行只证明「能喷出水」，不证明「喊得回去」与业务可达；远端「听得到打不出」会被放进网。  
3. 一端看不见的损伤/进水，另一端常更明显；口部对称问题也需要两端对照。  
4. **I-有源**；查噪底对比、隔离/安装、告警；禁止继续开增益。  
5. 可作附件参考；**不能**当本网 DMR 签字主证据。  
6. R3 挡「资料口头齐」；R4 挡「感觉管子没事」；R5 挡「有源没看就签」；R6 挡「没走测/用公网代替」。  
7. 喇叭对着自己麦克风会啸叫；增益越大越危险；所以隔离要明显大于增益，先改安装再谈开增益。  
8. 交维 DTF/VSWR 基线曲线（看有无新反射）+ 点位/隐蔽照（看是否二次破坏）；同时查增益是否被人拧过。  
9. 交维签前主战场是 I；开通后出现满格登不上、咔咔声、站边差等，用梯子进 F。口部问题先确认交维是否做过口部测，再决定是否主攻干扰。  
10. 资料关键件缺失且无开口项；关键分支无源测不过未返工；有源告警/噪底不可接受；无本网金机走测；试图用公网或加功率/增益代替整改（答出≥4 条即可）。
