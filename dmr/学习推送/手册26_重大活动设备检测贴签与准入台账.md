## 1. 为什么要写这篇手册（动机 + 现场对话）

前二十五篇手册把「家里怎么养」「邻居怎么处」「投诉怎么分诊」「证照台账怎么对」「重大保障临时窗怎么钉」「非法线索怎么上报」「电磁环境报告怎么验收」基本写全了：A–E 协议，F 射频指纹，G 实验室，H 话务，I 室分，J 写频，K 电源，L 井库，M 批量 / OTAP，N 监控对时，O 有源隔离，P 口部，Q 金机，R 假绿演练，S 邻频协调，T 干扰投诉，U 许可执照台账，V 临时保障窗，W 非法/黑广播线索，X 电磁环境报告台账。可现场还有一类债——**重大活动设备检测贴签与准入台账**（设备侧，与 V 的频率/窗侧咬合）：

- 保障岗：「上周那场活动的检测贴还在机器上，这场直接进。」——**他场/过期贴套本场** = 本篇拒入（规则3）。  
- 写频岗：「清单外多抬了两台手台，先写频进网，回头再检。」——**设备与活动清单不符 / 无有效贴签** = 规则2。  
- 网管：「屏上全绿、假绿演练也过了，还要什么设备检测贴签？」——**假绿 ≠ 已检测准入**（规则6，挂 R 提醒）。  
- 项目经理：「检测记录缺页、台账没勾，领导催着签准入放行。」——**缺项断链禁当正式准入证据**（规则4）。  
- 工程：「活动中途换了天线、功率角色调了，先用着，闭幕再补检。」——**重大变更须复检/重贴签**（规则5）。  
- 协调岗：「共址邻网设备也要进同一机房，我们先抬，邻居慢慢协调。」——**跨网准入须先通知或挂 S**（规则7）。  
- 宣传：「把贴签全文号和真实设备序列贴公开周报。」——**L3 违规**（规则8）。

这几句背后是同一件事：

> **「重大活动设备检测贴签与准入台账」在现场至少有五个坑**：**① Y-检** 检测有效性（检测记录角色、方法角色、有效期、设备角色与活动清单一致）；**② Y-签** 贴签（贴签与实物一致、本场本机、未过期、禁套用他场/他机/过期贴）；**③ Y-账** 准入台账可对账（活动角色、设备角色、贴签角色、时段、勾选齐全）；**④ Y-准** 准入放行签字边界（谁可签准入/写频开站放行；无贴签/过期/不符拒入拒签）；**⑤ Y-治** 拒入/治理（伪造套贴、清单外强入、未复检变更、公开泄密、假绿顶替检测）。  
> 把 ①–⑤ 当成「机器上有张旧贴就行」「清单外先抬进去」「屏绿=已准入」「借别人贴签」「变更先用再检」，会把下一任、保障办、主管部门和本网合规一起拖进泥潭。

本篇目标：能背出**重大活动设备检测贴签与准入工作流**；会用新贴纸 **Y（检 / 签 / 账 / 准 / 治）** 与五个子类；会填**插页 Y（Y1–Y8）**和《本网重大活动设备检测贴签与准入台账卡》；能用「**大型演出/会展安检贴纸 + 工牌准入台账**」故事讲清：先对有效贴签与台账勾选、贴签对实物、清单对活动、缺项断链拒入、变更复检重贴、签字边界；能拒绝「套他场贴、过期贴、借贴、清单外强入、假绿顶替、未复检先用、功率战掩盖、公开泄密」；自测过关后，回库把本网最近一次重大活动设备准入台账（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：凡引法规与标准均指向已公开发布的文书标题与官方链接（《中华人民共和国无线电管理条例》《无线电频率使用许可管理办法》《地面无线电台（站）管理规定》《无线电台执照管理规定》《中华人民共和国无线电管制规定》、国无办〔2025〕1号、属地重大活动无线电保障公开材料等），**程序、期限、管制命令以原文与属地最新要求为准，本篇只作教学转述，不发明条款号以外的「内部口径」或内部配额**；**现象与台账一律用相对道号、角色标签、脱敏编号表述，禁真实频点 / 站名 / 单位名 / 检测单全文号 / 贴签全文号 / 设备序列全文 / 联系人 / 坐标**；**不教伪造/涂改/套用贴签、不教无证发射、不教功率战掩盖准入问题、不教规避监测与检查**；V 仍管临时频率与联测窗，U 仍管许可执照，X 仍管电磁环境报告，J/M 仍管写频/OTAP，Q 仍管金机基线，R 仍管假绿——**重大活动设备检测贴签与准入台账主贴 Y**；外国 / ITU / 厂商材料只借**活动频谱管理与设备管理方法级表述**，**准入与签字以国内法规、属地要求与本网书面判据为准**。

## 2. 总图 / 故事：准入像「安检贴纸 + 工牌准入台账」

### 2.1 一句话：重大活动设备检测贴签与准入像大型演出/会展的安检贴纸 + 工牌准入台账——入场前先对贴签是否有效、是否本场本机、台账是否勾选；过期贴、借贴、清单外、缺项断链一律拒入

```text
   ┌──────────────────────────────────────────────────────────────────┐
   │   会展安检贴 + 工牌准入台账（= 本网重大活动设备检测贴签 + 准入） │
   │                                                                  │
   │   检测有效性（Y-检）                                             │
   │     检测记录角色 · 方法角色 · 有效期 · 设备与活动清单一致        │
   │                                                                  │
   │   贴签（Y-签）                                                   │
   │     贴签对实物 · 本场本机 · 未过期 · 禁套他场/他机/过期贴        │
   │                                                                  │
   │   准入台账可对账（Y-账）                                         │
   │     活动角色 · 设备角色 · 贴签角色 · 时段 · 勾选齐全             │
   │                                                                  │
   │   准入放行签字边界（Y-准）                                       │
   │     谁可签准入/写频开站放行 · 无贴签/过期/不符 → 拒入拒签        │
   │                                                                  │
   │   拒入治理（Y-治）                                               │
   │     伪造套贴 · 清单外强入 · 未复检变更 · 公开泄密 · 假绿顶替     │
   └──────────────────────────────────────────────────────────────────┘
```

口诀：

> **先对贴签，再对台账；贴签对实物，清单对活动。**  
> 他场旧贴进本场 = 拿隔壁展厅安检贴来过本厅安检——**拒入**。  
> 过期贴仍放行 = 灭火器过期也贴「可入场」——**拒入**。

### 2.2 「安检贴纸 + 工牌准入」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **检测有效性** | 安检机检过、有效期内、项目对得上本场清单 | 检测记录有效；方法角色清楚；设备与活动清单一致 | Y-检 |
| **贴签** | 安检贴纸贴在本件行李/本机上，不能撕给别人 | 贴签与实物一致；本场本机；未过期；禁套用 | Y-签 |
| **准入台账** | 工牌系统可检索：谁、哪场、何时、有无有效贴 | 活动/设备/贴签/时段可对账；勾选齐全 | Y-账 |
| **准入放行签字** | 门岗谁有权刷「可入场」 | 谁可签准入/写频开站放行；无贴签/过期/不符拒入 | Y-准 |
| **拒入治理** | 假贴、借贴、清单外强闯 → 追责 | 伪造套贴、强入、未复检、假绿顶替、泄密 → 拒入/治理 | Y-治 |

> 公开文书与属地材料告诉我们：设置使用无线电台（站）应依法取得许可与执照；临时用频有许可期限与不得擅自扩大范围等要求；重大任务等情形下可依法实施无线电管制；属地重大活动保障公开材料常见「提前提出临时用频与设备需求」「设备检测贴签」等**方法级**表述（教学借流程直觉，**不抄具体频点与内部数字当本网指标**）。本篇只借「先检测贴签、再台账准入、贴签对实物、清单对活动、签字有边界」的顺序，**不编造本网内部检测指标数字、不教伪造贴签过关**。

### 2.3 和手册11 / 14 / 15 / 19 / 22 / 23 / 25 的咬合（指针，不重写）

- **手册23 V**：临时频率与联测窗——**本篇是重大活动就绪的设备侧**；V 管窗与许可时段，Y 管「哪台机器有没有有效检测贴签可进场/可写频」。无 V 覆盖仍走 V，不拿「有贴签」顶替临时批复。  
- **手册22 U**：许可与执照台账——**贴签不代替执照**；无证/过期仍走 U，Y 只管活动设备准入。  
- **手册25 X**：电磁环境报告台账——**准入 ≠ 环境验收**；设备准入过了不等于站址环境报告可签交维；可叠挂，各管各的。  
- **手册11 J / 14 M**：写频 / OTAP——**活动设备写频或 OTAP 前强制对 Y 准入台账**；无有效贴签/台账未勾 → 拒签写频开站。  
- **手册15 Q**：金机基线——可支撑「准入后参数是否偏离金机」；**不能代替**检测贴签与准入台账。  
- **手册19 R**：假绿演练——**屏上看见 ≠ 已检测准入**（规则6）；可挂 R 提醒，主贴仍 Y。  
- **手册20 S / 21 T / 24 W**：邻频、投诉、非法线索——跨网共址设备准入先通知或挂 S；投诉挂 T；疑似非法设备线索走 W；**设备准入本身主贴 Y**。

### 2.4 新贴纸 Y：检 / 签 / 账 / 准 / 治（五个子类）

```text
                ┌──────────── 贴纸 Y · 检/签/账/准/治 ────────────┐
                │  Y-检  检测有效性：记录·方法·有效期·与活动清单一致 │
                │  Y-签  贴签：对实物·本场本机·未过期·禁套他场他机   │
                │  Y-账  准入台账可对账：活动·设备·贴签·时段·勾选   │
                │  Y-准  准入放行签字：谁可签准入/写频开站；缺项拒入 │
                │  Y-治  拒入治理：伪造套贴·强入·未复检·假绿·泄密   │
                └──────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒入 / 拒签触发 |
|------|--------|----------------------|
| **Y-检** | 检测过期或设备与活动清单不符仍放行 → 拒入 | 「检测上周过期先抬进去」 |
| **Y-签** | 贴签与实物不一致 / 他场他机过期贴 → 拒入 | 「借隔壁展厅那张贴」 |
| **Y-账** | 台账对不上活动/设备/时段或未勾选 → 禁正式准入 | 「清单口头说有=台账齐」 |
| **Y-准** | 无授权人签、或强签缺贴签项 → 拒签 | 「领导催签就放行」 |
| **Y-治** | 伪造套贴、清单外强入、假绿顶替、公开泄密 → 治理 | 「撕 A 机贴贴到 B 机」 |

### 2.5 重大活动设备检测贴签与准入最小工作流（背下来）

```text
  拟「设备准入 / 写频开站 / 活动中换机复检」
        │
        ▼
  是否有覆盖本活动角色、本设备角色、本时段的有效检测与贴签？（Y-账 / Y-签）
        │无 / 过期 / 清单不符──▶ 拒入拒签；补检或剔除清单外机（规则1、2）
        │有候选贴签
        ▼
  贴签是否与实物一致？是否本场本机？是否套用他场/他机/过期贴？（Y-签）
        │否──▶ 拒入；禁套用（规则3）
        │是
        ▼
  检测记录是否完整可追溯？台账勾选是否齐全？（Y-检 / Y-账）
        │缺项断链 / 未勾──▶ 禁当正式准入证据；内部可挂「待检/待补」（规则4）
        │完整且已勾
        ▼
  活动中是否有重大变更（换机、改功率角色、改天线）未复检/重贴签？（规则5）
        │有──▶ 拒入/冻结放行；复检重贴后再走 Y
        │无
        ▼
  写频/OTAP？→ 强制对 Y 台账（挂 J/M）；无贴签拒签写频
  证照/临时窗？→ 互挂 U/V；贴签不代替执照
  环境验收？→ 不混用 X；准入≠环境验收
  跨网/共址？→ 先通知或挂 S（规则7）
  假绿/屏绿能否顶替？→ 不能；挂 R 提醒（规则6）
        │
        ▼
  授权人按 Y-准 边界签字放行；台账入库；公开包 L3（规则8）
  结案词用 Y 子类；可挂 V/U/J/M/Q/X 支撑，主贴 Y
```

现场口诀：

> **先对贴签，再对台账；贴签对实物，清单对活动。**  
> 跳过对账的「准入放行」= 拿过期安检贴闯门岗。

## 3. 核心交付：插页 Y + 拒入卡 + 与总三联单怎么写

### 3.1 什么时候贴 Y（而不是先贴 V / U / X / R / J）

| 现场信号 | 主贴 | 可次挂 |
|----------|------|--------|
| 重大活动设备要检测贴签 / 准入放行 | **Y** | V / U / J |
| 临时频率窗 / 联测窗是否覆盖 | **V**（不是 Y） | 设备侧仍须 Y |
| 许可/执照是否覆盖 | **U** | 贴签不代替执照 |
| 电磁环境报告是否可签验收 | **X**（不是 Y） | 准入≠环境验收 |
| 写频 / OTAP 前对活动设备 | **J / M** + 强制挂 **Y** | — |
| 屏绿/假绿想顶替已检测准入 | **Y-治** + 挂 **R** | — |
| 跨网/共址设备同场准入 | **Y** + 挂 **S** | V |
| 伪造/套贴/公开泄密 | **Y-治** | — |

> **口诀**：临时窗 → **V**；证照 → **U**；环境报告 → **X**；写频/OTAP → **J/M**（先对 Y）；假绿 → **R**；邻居 → **S**；**重大活动设备检测贴签与准入 → Y**。可叠挂，**该类准入主贴 Y**。

### 3.2 插页 Y · 检 / 签 / 账 / 准 / 治（挂在总三联单或准入单后）

| 行 | 名称 | 填写示例（教学虚构，L3） |
|----|------|--------------------------|
| **Y1** | 活动角色摘要 | 「活动角色·保障时段角色·与 V 临时窗互挂编号脱敏」 |
| **Y2** | 设备角色清单 | 「手台/车台/中继角色·数量角色·与活动清单一致□」——不符拒入 |
| **Y3** | 检测有效期 | 「检测记录角色·方法角色·有效期至____·在有效□/过期□」——过期拒入 |
| **Y4** | 贴签角色 | 「贴签脱敏编号·本场本机□·与实物一致□·未套用□」 |
| **Y5** | 台账勾选 | 「□覆盖本活动 □设备在清单 □贴签有效 □时段覆盖 □未重大未复检变更」 |
| **Y6** | 写频/OTAP 闸门 | 「拟写频/OTAP？是→已对 Y 台账□；未对→拒签 J/M」 |
| **Y7** | 复检/重贴触发 | 「无 / 换机 / 改功率角色 / 改天线 / 他场转入 / 其他____」 |
| **Y8** | 拒入门槛 | 「缺任一项正式准入项 → 拒入拒签；内部可挂待检/待补」 |

> **Y2 清单不符 → 拒入（规则2）。**  
> **Y3 过期 → 禁止以该贴签作为正式准入依据（规则2）。**  
> **Y4 贴签与实物不一致或套用 → 拒入（规则3）。**  
> **Y5 缺勾 → 禁签正式准入/写频开站放行（规则1、4）。**  
> **Y6 未对 Y 仍写频 → 拒签（与 J/M 互锁）。**  
> **Y7 有触发未复检重贴 → 拒入/冻结（规则5）。**  
> **Y8 公开包出现真实频点/贴签全文号/设备序列全文 → L3 违规（规则8）。**

### 3.3 「套贴 / 过期贴 / 假绿顶替 / 缺项强入拒入」卡（贴值班台 / 门岗 / 写频室）

### 3.4 和总三联单怎么写（接手册06）

- **现象**：写「拟准入/写频开站/换机复检 + Y 子类」，**未对账前不写「设备已检测准入可写频」**。  
- **证据**：活动角色、设备清单角色、检测有效期、贴签角色、台账勾选、复检触发、互挂 V/U/J。

- **动作**：对账、补检、重贴签、剔除清单外、挂 S、拒入——**禁止**写「套他场贴」「过期先抬」「屏绿顶替」「先用着再说」「借贴进场」。

## 4. 深潜：八条硬规则 + 分诊题 + 设备检测最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **先证有效检测贴签与准入台账覆盖（活动角色、设备角色、时段）再准入/写频开站**。  
2. **无有效贴签、检测过期、设备与活动清单不符 → 拒入/拒签**。  
3. **贴签与实物不一致；禁套用他场/他机/过期贴 → 拒入**。  
4. **缺项、断链、无法追溯的检测记录/台账勾选 → 禁当正式准入证据**（内部可挂「待检/待补」）。  
5. **活动中重大变更（换机、改功率角色、改天线）须复检/重贴签再放行；禁「先用着再说」**。  
6. **可挂 V/U/J/M/Q/X 支撑，但设备准入主贴 Y；假绿/屏上看见不等于已检测准入（挂 R 提醒）**。  
7. **跨网/共址设备准入须先通知协调或挂 S；争议走无线电管理机构；禁功率战/私了**。  
8. **对外/公开仓一律脱敏 L3；禁贴真实频点/站名/单位名/贴签全文号/设备序列全文/坐标**。

> 法规与公开材料锚点（已核公开原文，教学转述，**以原文为准**）：《无线电管理条例》对频率使用许可、台站设置使用、监测与干扰查处等作总则；《无线电频率使用许可管理办法》对临时用频期限与不得擅自扩大范围等作要求；《地面无线电台（站）管理规定》《无线电台执照管理规定》对台站与执照规范作要求；《无线电管制规定》明确重大任务等情形下可依法实施管制——**保障期若遇管制指令，本网设备必须服从，不得以「我们有检测贴签」对抗管制命令**；国无办〔2025〕1号提供规划与技术要求指针；属地重大活动保障公开材料（如北京无线电管理规定公开 PDF、十五运会广州赛区无线电安全保障访谈等）可见「提前提出设备需求」「设备检测贴签」等方法级表述。**这些是合规与准入秩序，不是「机器上有张旧贴就能进场」或「贴签顶替执照」的借口。**

### 4.2 准入前分诊题（Y-账 / Y-检 / Y-签）——先问「这贴盖的是不是本场本机」

```text
  ① 台账里有没有覆盖「本活动角色 + 本设备角色 + 本时段」的有效检测与贴签？
     → 无/过期/清单不符：拒入；补检或剔除（规则1、2）

  ② 贴签是否贴在本实物上？是否本场本机？有无套用痕迹？
     → 否/套用：拒入（规则3）

  ③ 检测记录是否完整可追溯？方法角色是否清楚？
     → 缺项断链：禁正式准入；内部待补（规则4）

  ④ 台账勾选是否齐全？写频/OTAP 是否已对 Y？
     → 未勾/未对：拒签准入与写频（规则1、4；挂 J/M）

  ⑤ 自贴签出具后是否发生换机/改功率角色/改天线未复检重贴？
     → 是：拒入/冻结；复检重贴（规则5）

  ⑥ 是否跨网/共址设备同场且未通知协调？
     → 是：挂 S；争议报管理机构；禁功率战私了（规则7）

  ⑦ 是否有人要用屏绿/假绿或「有执照就行」顶替检测准入？
     → 是：拒签；挂 R；执照走 U，主贴仍 Y-治（规则6）
```

**未过分诊题的冻结清单**：签「准入放行」「保障设备就绪」、对外宣传「设备已全部检测贴签」、清单外强入、未对 Y 写频、套他场贴。允许做的：台账对账、补检、重贴签、剔除清单外、挂 S、内部挂待检/待补。

### 4.3 设备检测最小集（Y-检 / Y-签）——缺页不能过门岗

| 序号 | 最小集项（教学） | 为什么必须有 | 缺了会怎样 |
|------|------------------|--------------|------------|
| 1 | **活动角色 + 时段角色** | 防他场套用 | 对不上 → 拒入 |
| 2 | **设备角色清单**（禁公开序列全文） | 防清单外强入 | 不符 → 拒入 |
| 3 | **检测记录角色 + 出具日/有效期** | 检测有效性 | 过期/无记录 → 拒入 |
| 4 | **贴签角色 + 与实物一致声明** | 防借贴套贴 | 不一致 → 拒入 |
| 5 | **方法角色摘要** | 可复核 | 「检过了」三个字不够 |
| 6 | **台账勾选 + 互挂 V/U** | 正式准入依据 | 未勾/两张皮 → 禁正式准入 |
| 7 | **保管链未断声明** | 断链=降级 | 断链禁当正式准入证据（规则4） |

> **口诀**：场、机、检、贴、法、账、链——**七字准钉**（教学记忆；现场以属地与活动保障书面要求为准，但 **本场本机+有效贴签+台账勾选+保管链** 几乎不可砍）。  
> **断链识别**：缺检测记录页、贴签与机身对不上、涂改无登记、公开群传后再当正式附件、他场贴撕到本机——一律降级，禁正式准入依赖。

### 4.4 台账路径（Y-账）——每场活动一本可检索账

| 步 | 动作 | 拒入点 |
|----|------|--------|
| 1 | 一活动角色一主档（设备子表按角色列） | 「全年所有活动共用一张永远有效贴」 |
| 2 | 登记：设备角色、检测有效期、贴签角色、时段 | 口头说有贴无台账 |
| 3 | 互挂 V 临时窗、U 执照编号脱敏、J/M 写频单脱敏（若有） | 贴签与证照/写频两张皮 |
| 4 | 复检/重贴触发写入台账（换机/功率/天线等） | 变更不登触发 |
| 5 | 到期预警与过期拒入路径（与写频/开站闸门互锁） | 「过期了先用着」 |
| 6 | 公开导出仅 L3；原件全文号受控另册 | 公开贴全文号/序列全文 |

与手册23：V 管临时频率与联测窗是否覆盖保障期；**Y 管设备是否经检测贴签可准入**——两本账都过才谈「保障设备就绪」叙事。与手册22：U 管执照；**贴签不代替执照**。与手册25：X 管环境报告；**准入 ≠ 环境验收**。

### 4.5 签字边界（Y-准 / 规则1–4）——谁有权写「可入场」

| 本网可以签（教学） | 本网不可以签（红线） |
|--------------------|----------------------|
| 台账勾选齐全、贴签有效对实物、清单一致、无未复检重大变更 | 无贴签/过期/不符仍签「准入放行/写频开站」 |
| 授权角色按制度会签（教学不编造职务名） | 「谁在场谁签」「领导催签跳过台账」 |
| 内部挂「待检/待补」并冻结放行 | 待检状态对外宣传「已全部贴签准入」 |
| 拒入并开 Y-治 工单 | 套贴、伪造涂改后补签 |

> **明确不教**：如何伪造贴签、如何涂改有效期、如何把 A 机贴撕到 B 机、如何规避门岗与监测。需要法定检测或管制配合的，**按主管部门与属地要求走**——你方只做边界内的台账、对账、拒入与复检安排。

### 4.6 弱项短补：有贴 ≠ 本场本机 ≠ 在有效期 ≠ 清单一致 ≠ 已签字准入 ≠ 屏绿 ≠ 有执照

```text
   机器有贴纸  本场本机  在有效期  清单一致  已签准入  屏/假绿  有执照
   ──────────  ────────  ────────  ────────  ────────  ───────  ──────
   仅有纸      Y-签对上   Y-检     Y-账      Y-准      R≠Y     U≠Y
   ✗ 「有旧贴 = 可进本场」
   ✗ 「上周检过 = 本场永远有效」
   ✗ 「借贴/撕贴 = 可过门岗」
   ✗ 「清单外先抬回头补」
   ✗ 「屏全绿 = 已检测准入」
   ✗ 「有执照 = 免检测贴签」
   ✗ 「准入过了 = 环境验收也过了」
```

所以规则1、3、6才硬：**先证覆盖与有效贴签；不一致拒入；假绿/执照不能顶替检测准入。**

### 4.7 与写频 / 临时窗 / 环境验收怎么衔接（只讲合规路径）

教学流程（细节以属地、活动保障办与本网制度为准）：

1. **活动立项**：查 V 临时窗 + U 证照 + 拟设备清单。  
2. **设备检测贴签（Y-检 / Y-签）**：按清单检测 → 贴签 → 登记。  
3. **入库台账（Y-账）**：活动/设备/贴签/时段/勾选、复检触发、互挂 V/U。  
4. **准入会签（Y-准）**：对照拒入卡；缺项则待补，不放行。  
5. **写频/OTAP（J/M）**：强制对 Y；未对拒签。  
6. **活动中变更**：触发清单命中 → 复检/重贴 → 更新台账 → 再放行。  
7. **跨网共址**：先通知或挂 S；争议报无线电管理机构。  
8. **结案**：Y 子类结案词；套贴/强入走 Y-治；环境项另走 X；闭幕回收与 V 窗呼应。

**明确不教**：如何无贴签发射、如何伪造涂改、如何规避检查与监测、如何用干扰压制「看起来合规」。

### 4.8 准入 / 写频前 15 分钟清单（可复印）

| 分钟 | 动作 |
|------|------|
| 0–3 | 打开台账卡：活动角色、设备清单、候选贴签角色、有效期 |
| 3–7 | Y-账/Y-检/Y-签分诊七问；贴签对实物？清单对吗？ |
| 7–10 | 最小集勾选；缺项 → 待补，禁签准入/写频 |
| 10–13 | 查复检触发与现场是否一致；跨网则挂 S；写频则对 J/M |
| 13–15 | 拒入卡自检（未套贴/未假绿顶替/未清单外）；交班口述 |

夜班压缩版：至少完成「有本场有效贴签角色 + 与实物一致 + 清单无矛盾声明 + 未强签缺项」四项——**四项缺一仍禁签准入放行与写频开站**。

### 4.9 与 V / U / X / J / M / Q / R / S 单据互挂（Y → 临时窗 / 证照 / 环境 / 写频 / 金机 / 假绿 / 邻居）

```text
  临时窗（V）
        │
        └── 时段与活动角色互挂；无 V 覆盖不拿贴签顶替临时批复

  证照（U）
        │
        └── 贴签不代替执照；无证走 U

  环境报告（X）
        │
        └── 准入 ≠ 环境验收；各管各的闸门

  写频 / OTAP（J / M）
        │
        └── 强制先对 Y；未对拒签写频开站

  金机（Q）
        │
        └── 可支撑准入后基线比对；不代替贴签

  假绿（R）
        │
        └── 仅提醒「看见≠检测准入」；禁止 R 顶替 Y

  邻频协调（S）
        │
        └── 跨网/共址准入：Y 主贴 + S 协调编号互挂（均脱敏）
```

批量准入 / 周报：任何「设备已全部检测贴签」表述必须能追溯到 Y 卡且公开 L3——**「领导要稿」不能代替检测最小集**。

### 5.2 对话脚本（五则）

**脚本1 · 他场旧贴**  
对方：「机器上还有上周展会的贴，颜色差不多，直接进。」  
你：「规则3：禁套用他场/他机/过期贴。先 Y-账对活动角色；对不上就补检重贴。主贴 Y-治。」

**脚本2 · 过期仍放行**  
对方：「检测昨天才过期一天，先放行写频。」  
你：「规则2：检测过期 → 拒入拒签。补检重贴后再走 Y。主贴 Y-检。」

**脚本3 · 假绿顶替**  
对方：「假绿演练都过了，准入别再卡贴签。」  
你：「规则6：假绿/屏上看见不等于已检测准入。可挂 R 提醒，主贴仍是 Y；无有效贴签拒签准入。」

**脚本4 · 变更先用着**  
对方：「活动中途换了功率角色，先保障，闭幕再复检。」  
你：「规则5：重大变更须复检/重贴签再放行；禁先用着再说。主贴 Y-账，冻结写频与放行。」

**脚本5 · 清单外强入 + 跨网**  
对方：「邻网两台也要进机房，先抬，贴签回头补，协调以后再说。」  
你：「规则2、7：清单不符拒入；跨网先通知或挂 S；禁私了。主贴 Y-治，挂 S。」

### 5.3 夜班 15 分钟怎么用

1. 扫 Y 台账：过期贴条数、待补条数、清单外条数、未复检变更条数（应为可解释且未强签）。  
2. 抽查门岗/写频室：在用设备贴签是否与实物一致、是否本场。  
3. 查互挂：写频单是否挂 Y；临时窗是否挂 V；跨网是否挂 S；假绿是否被误当 Y。  
4. 交班口述：待检/待补、已拒入原因（Y 子类）、复检计划角色、主人。

### 5.4 「设备准入三问」（贴门岗 / 写频室 / 保障办）

```text
  1. 贴签覆盖的是本活动角色、本设备角色、本时段吗？有效吗？对本机吗？
  2. 台账勾选齐了吗？检测记录有没有缺页断链？清单有没有外机？
  3. 有没有未复检的换机/改功率/改天线？有没有人想用屏绿、借贴或执照顶替？
```

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「上周展会贴直接进本场」→ Y-签 / Y-治

现象：保障催准入，拟用他场活动残留贴签。  
处置：Y-账对活动角色失败；拒入；开本场补检重贴。  
结案词：「Y-治：禁套他场贴；已开补检。」

### 例 2 · 「检测过期仍放行写频」→ Y-检

现象：检测有效期过期两日，写频岗拟照常写活动信道。  
处置：拒签写频；拒入；补检重贴后再对 Y。  
结案词：「Y-检：检测过期，拒签准入与写频。」

### 例 3 · 「借贴 / 撕 A 贴 B」→ Y-签 / Y-治

现象：门岗发现贴签编号角色与机身不一致，疑似挪贴。  
处置：拒入；保全；开 Y-治；禁放行。  
结案词：「Y-治：贴签与实物不一致，拒入并治理。」

### 例 4 · 「清单外多机先抬」→ Y-账 / Y-准

现象：清单外两台手台已抬入机房，主张「先保障回头补检」。  
处置：冻结准入叙事；剔除或补检入库前禁写频；开治理。  
结案词：「规则2：清单不符拒入；禁先用着再说。」

### 例 5 · 「屏全绿顶替检测准入」→ Y-治 + R

现象：网管主张假绿演练通过即可签设备准入。  
处置：拒顶替；挂 R 提醒；主贴 Y；无有效贴签则待检。  
结案词：「规则6：假绿≠检测准入；主贴 Y。」

### 例 6 · 「换天线未复检先用」→ 规则5 / Y-账

现象：活动中天线角色变更，业务已开，复检排闭幕。  
处置：冻结「准入/写频开站」叙事；限期复检重贴；开治理。  
结案词：「规则5：变更未复检重贴，禁先用着再说。」

### 例 7 · 「有执照主张免贴签」→ U + Y

现象：主张本网执照有效，重大活动免设备检测贴签。  
处置：U 管执照覆盖；Y 仍要求本场检测贴签与台账；无贴签拒入。  
结案词：「贴签不代替执照；执照不代替 Y。」

### 例 8 · 「准入过了就签环境交维」→ X + Y

现象：设备准入台账齐全，拟顺带签电磁环境交维就绪。  
处置：Y 过不等于 X 过；环境报告另对手册25；禁混闸门。  
结案词：「准入≠环境验收；Y≠X。」

### 例 9 · 「公开周报贴全文号与序列」→ Y-治 / L3

现象：周报含贴签全文号与设备序列全文。  
处置：下架；改 L3；原件受控；培训规则8。  
结案词：「Y-治：L3 违规已纠正。」

### 例 10 · 「共址邻网设备未通知先抬」→ Y + S

现象：共址邻网设备拟同机房准入，未书面通知，主张「抬头不见低头见」。  
处置：先通知或挂 S；争议报管理机构；禁功率战私了；本网侧仍须 Y 清单覆盖。  
结案词：「规则7：跨网先协调挂 S；已拒私了。」

## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 一句话 |
|------|--------|
| **设备检测（教学用语）** | 对拟参加重大活动的无线设备按方案做符合性/状态检查并记录（方法细节以属地与活动保障要求为准） |
| **检测贴签** | 检测通过后贴于本实物、载明本场本机有效期角色的标识（教学不规定颜色与版式） |
| **准入台账** | 按活动角色检索的设备、贴签、时段、勾选与互挂索引（Y-账） |
| **本场本机** | 贴签对应的活动角色与实物设备角色一致，禁止挪贴 |
| **套用贴签** | 把他场/他机/过期贴当作本场本机依据，本篇红线 |
| **活动清单** | 本场拟准入设备角色列表；清单外禁强入 |
| **断链记录** | 缺页、缺贴签对照、保管链断裂，降级禁正式准入 |
| **待检 / 待补** | 内部允许挂起，但禁签正式准入/写频开站 |
| **复检 / 重贴触发** | 换机、改功率角色、改天线等后必须再检再贴的条件 |
| **准入放行签字边界** | 谁有权在何种勾选齐全时签署准入/写频开站（Y-准） |
| **假绿顶替** | 用监控全绿或假绿演练代替检测贴签准入，本篇红线 |
| **贴签≠执照** | 检测贴签不能代替 U 许可执照 |
| **准入≠环境验收** | 设备准入不能代替 X 电磁环境报告验收 |
| **主贴 Y** | 重大活动设备检测贴签与准入以 Y 为主键，可挂 V/U/J/M/Q/X/R/S |
| **L3** | 公开包最高脱敏等级（本系列约定） |
| **安检贴纸隐喻** | 用会展安检贴+工牌台账讲清本场本机、有效期、拒入 |
| **功率战/私了** | 用抬功率或私下了结掩盖准入/干扰问题，本篇红线 |
| **正式准入证据** | 可进入放行与写频闸门的检测贴签台账；待补/断链/过期不算 |

**易错观念**

1. ✗ 机器上有旧贴 = 可进本场 → ✓ 先对本场本机、有效期、台账勾选。  
2. ✗ 上周检过 = 本场永远有效 → ✓ 有效期与活动角色看台账。  
3. ✗ 借贴/撕贴 = 可过门岗 → ✓ 贴签必须对实物；套用拒入。  
4. ✗ 清单外先抬回头补 → ✓ 清单不符拒入；禁先用着再说。  
5. ✗ 屏全绿 = 已检测准入 → ✓ 假绿≠Y。  
6. ✗ 有执照 = 免检测贴签 → ✓ 贴签不代替执照，执照不代替 Y。  
7. ✗ 准入过了 = 环境验收也过了 → ✓ Y≠X。  
8. ✗ 未对 Y 也可写频 → ✓ 写频/OTAP 前强制对 Y。  
9. ✗ 缺页先放行回头补 → ✓ 缺项断链禁正式准入证据。  
10. ✗ 公开培训可贴贴签全文号与序列全文 → ✓ 公开 L3，原件受控。

4. 场、机、检、贴、法、账、链；不能。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **Y** 五子类：检 / 签 / 账 / 准 / 治。  
- 故事：大型演出/会展安检贴纸 + 工牌准入台账——先对本场本机与有效贴签，过期贴/借贴/清单外/缺项一律拒入。  
- 八条硬规则：**先证有效贴签与准入台账覆盖**；**无贴签/检测过期/清单不符拒入**；**贴签对实物禁套用**；**缺项断链禁正式证据**；**变更须复检重贴**；**主贴 Y，假绿≠检测准入**；**跨网挂 S，禁功率战私了**；**脱敏 L3**。  
- 与 V/U/X/J/M/Q/R/S 分工：V=临时窗；U=证照；X=环境报告；J/M=写频/OTAP（先对 Y）；Q=金机基线；R=假绿提醒；S=邻居协调；**Y=重大活动设备检测贴签与准入台账**。

### 11.2 回库路径
现场「设备准入/写频开站/换机复检」→ 本篇（贴纸 Y + 插页 Y + 台账卡）→ 对本场本机与有效贴签 → 检测最小集 → 复检触发检查 → 写频对 Y → 跨网挂 S → 授权签字或拒入；公开 L3。

### 11.3 下一篇手册候选（本篇不写正文）
- **开站验收与交维签字边界**（与 R/Q/U/X/Y 咬合）  
- **室分电磁环境复测周期与变更触发**（与 I/X 咬合）  
- （可选）**应急通信车/机动站准入**（与 V/Y 咬合，仍 L3）

### 11.4 给带新人的三句话
1. 机器上有旧贴不等于可进本场；先对本场本机、有效期、台账勾选。  
2. 假绿、执照、环境报告都代替不了检测贴签准入；缺页断链只能待补，不能强入。  
3. 变更后先复检重贴再放行；写频前强制对 Y；跨网挂 S；公开材料脱敏；主贴 Y。

### 11.6 十分钟给领导的电梯演讲
> 重大活动设备进场和写频前先对检测贴签与准入台账：贴签是不是本场本机、有没有过期、设备是否在活动清单里、台账勾选齐不齐。无有效贴签、检测过期、借贴套贴、清单外强入、缺页断链，一律不签准入放行或写频开站，内部可以待检待补。活动中换机改功率改天线必须复检重贴，禁止先用着再说。监控全绿和假绿演练不能顶替检测准入；贴签不能代替执照，设备准入不能代替电磁环境验收。写频和 OTAP 前必须先对准入台账。跨网共址要先通知或挂邻频协调，禁止功率战和私了。临时频率窗、证照、环境报告各管各的，设备检测贴签与准入主贴 Y。公开材料脱敏。
