## 1. 为什么要写这篇手册（动机 + 现场对话）

前六十八篇手册从 A–E 协议一路写到 BO 机油液位与机油压力/油温保护：其中 **BB 回答「风冷室外机与冷凝侧边界」**（机位/回路/风扇转、进出风净距、风机/翅片角色和冷凝侧测点；**风扇转 ≠ 室外机台账过**，也**并不**单独给冷凝风机转速 + 冷凝压力调节一张巡检台账），**BJ 回答「压缩机吸排气压力与过热度过冷度巡检」**（排气压力是压缩机排出侧高压角色，**排气压力巡检过 ≠ 冷凝压力调节窗过**，也没有单独给风机转速台账），**AX 回答「压缩机与制冷剂边界」**，**BM 回答「膨胀阀/电子膨胀阀开度与过热控制」**（过热/膨胀阀是蒸发侧，不是冷凝侧风机与冷凝压力调节），**BN 回答「冷凝器盘管清洗与翅片完好」**（盘管干净/翅片齐 ≠ 转速/冷凝压力调节过），**AI / BA / N** 各管温湿度联锁、冷冻水与冷却塔侧、监控。系列 01–68 **还没有**单独钉死一件事——**不是「风扇在转 / 转速表看着有数 / 控制器转速灯绿 / 冷凝压力表看着在绿区 / 高压灯绿 / 口头调过风机转速 / BB 或 BJ 或 AX、BM、BN 过就能签」：转速台账要钉死；冷凝压力调节侧要有主有窗有方法有准用期；边界方法要书面固定；本期实测禁套——能不能签「机房精密空调冷凝风机转速与冷凝压力调节巡检准用」？** 这就是本篇的 **BP**（Excel 风格：BO 之后 → **BP**）。写前已核对系列手册 01–68 标题，尚无该专题正文。该题只在手册68 §11.2 作为候选出现过，并在 BB、BJ 里以相关*角色*出现，但都不是本篇这张巡检台账。

**现场对话（教学虚构，L3）**

- 运维：「风扇在转，今晚能签准用。」——**风扇转 ≠ 转速台账过** = 规则1。

- 站务：「转速签过了，调节窗照抄一份。」——**转速过 ≠ 冷凝压力调节窗过** = 规则1/2/4。
- 外包：「调节窗勾过了，转速页用同一张表。」——**冷凝压力调节窗过 ≠ 转速台账过** = 规则1/2/4。
- 班长：「BB 室外机和冷凝侧边界刚签过，风扇也在转，转速这边也能签。」——**BB 边界过 ≠ 本篇**；**风扇转 ≠ 本篇台账过** = 规则6（**BB ≠ BP**）。BB 提到风机/翅片角色和冷凝侧测点，**并不**单独给本篇台账。
