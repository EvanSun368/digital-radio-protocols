## 1. 为什么要写这篇手册（动机 + 现场对话）

前六十八篇手册从 A–E 协议一路写到 BO 机油液位与机油压力/油温保护：其中 **BB 回答「风冷室外机与冷凝侧边界」**（机位/回路/风扇转、进出风净距、风机/翅片角色和冷凝侧测点；**风扇转 ≠ 室外机台账过**，也**并不**单独给冷凝风机转速 + 冷凝压力调节一张巡检台账），**BJ 回答「压缩机吸排气压力与过热度过冷度巡检」**（排气压力是压缩机排出侧高压角色，**排气压力巡检过 ≠ 冷凝压力调节窗过**，也没有单独给风机转速台账），**AX 回答「压缩机与制冷剂边界」**，**BM 回答「膨胀阀/电子膨胀阀开度与过热控制」**（过热/膨胀阀是蒸发侧，不是冷凝侧风机与冷凝压力调节），**BN 回答「冷凝器盘管清洗与翅片完好」**（盘管干净/翅片齐 ≠ 转速/冷凝压力调节过），**AI / BA / N** 各管温湿度联锁、冷冻水与冷却塔侧、监控。系列 01–68 **还没有**单独钉死一件事——**不是「风扇在转 / 转速表看着有数 / 控制器转速灯绿 / 冷凝压力表看着在绿区 / 高压灯绿 / 口头调过风机转速 / BB 或 BJ 或 AX、BM、BN 过就能签」：转速台账要钉死；冷凝压力调节侧要有主有窗有方法有准用期；边界方法要书面固定；本期实测禁套——能不能签「机房精密空调冷凝风机转速与冷凝压力调节巡检准用」？** 这就是本篇的 **BP**（Excel 风格：BO 之后 → **BP**）。写前已核对系列手册 01–68 标题，尚无该专题正文。该题只在手册68 §11.2 作为候选出现过，并在 BB、BJ 里以相关*角色*出现，但都不是本篇这张巡检台账。

- 运维：「风扇在转，今晚能签准用。」——**风扇转 ≠ 转速台账过** = 规则1。

### 3.1 什么时候贴 BP（而不是先贴 BB / BJ / AX / BM / BN / AI / BA / N）

- 要签「机房精密空调冷凝风机转速与冷凝压力调节巡检准用」、要开冷凝风机转速交底窗、要交底冷凝压力调节侧 → **主贴 BP**。
- 风冷室外机与冷凝侧边界（机位/回路/风扇转、净距、风机/翅片角色和冷凝侧测点）→ **BB**。**BB ≠ BP**；风扇转 ≠ 本篇台账过；BB 不单独给本篇台账；不重写 BB。
- 吸排气压力与过热度过冷度 → **BJ**。**BJ ≠ BP**；排气压力巡检过 ≠ 冷凝压力调节窗过；不重写 BJ。
- 压缩机与制冷剂边界 → **AX**。开度与过热控制 → **BM**。盘管清洗与翅片完好 → **BN**。**AX ≠ BP；BM ≠ BP；BN ≠ BP**。
- 温湿度联锁 → **AI**。冷冻水冷却塔 → **BA**。漏水汇排 → **AO**。
- 进机房/上屋面室外机区先 **AN**（门禁过 ≠ 交底过）。气灭 → **AL**。风暴先 **N**，缺秩序整改仍 **BP**；上述硬禁项与功率战一律禁止。
- 假绿/顶替挂 **R**；变更走 **J** 后再验 BP。
- 无精密空调，或无冷凝风机转速/冷凝压力调节路径（例如纯冷冻水末端、无风冷冷凝风机的路径） → 书面「不适用」；冷冻水/塔侧问 BA，**不得**用 BP 顶 BB/BJ/AX/BM/BN 等，也不得用它们顶 BP。一侧不适用 ≠ 另一侧自动免。BB/BJ 等过了或它们不适用 ≠ 本路径自动免。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **冷凝风机转速台账钉死**：冷凝风机角色与转速窗、本期对照各自有账（编号脱敏）；禁「风扇转就算过」「转速表看着有数就算过」「控制器转速灯绿就算过」「口头调过风机转速」；转速过 ≠ 冷凝压力调节窗过，冷凝压力调节窗过 ≠ 转速台账过。
2. **冷凝压力调节侧有主有窗有方法准用期**：与转速侧分开看；测点、调节手段（转速等，以本网与 OEM 书面为准）、合格窗与准用期书面固定；每次调节交底有主人角色、有书面窗、有方法、有准用期；禁「冷凝压力表看着在绿区就算过」「高压灯绿就算过」「套邻站调节照片」；调节窗过 ≠ 转速台账过；排气压力巡检过 ≠ 本调节窗过。
3. **边界窗与方法钉死**：书面固定；方法含与 BB/BJ/AX/BM/BN/AI/BA/N 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明强制改转速/停转、熔断保护、泄放或绕联锁步骤；**不重写 BB/BJ/AX/BM/BN 全文**）；禁「窗再说」「绕联锁」「开旁通冒充」「不安全泄放制冷剂教条」「未授权强制改转速/强制停转或熔断高低压保护教条」「伪造台账」。
4. **本组本机房本期实测禁套他站他期**：实测记录、转速对照、冷凝压力调节必须本期本组本机房；套邻站/邻院账 = 拒签。
5. **会签才放行**：缺授权会签不得签「机房精密空调冷凝风机转速与冷凝压力调节巡检准用」；假绿 ≠ 放行。
6. **禁顶替 BB/BJ/AX/BM/BN 等，主贴 BP，假绿≠放行挂 R**：他贴签都不顶本期转速/调节签。**尤其 BB ≠ BP、BJ ≠ BP、AX ≠ BP、BM ≠ BP、BN ≠ BP，以及 AI≠BP、BA≠BP；风扇转 ≠ 本篇台账过；排气压力巡检过 ≠ 冷凝压力调节窗过；冷冻水/冷却塔 ≠ 风冷冷凝风机转速。**
7. **异常风暴挂 N；变更走 J；禁功率战；禁绕联锁；禁旁通；禁不安全泄放制冷剂教条；禁未授权强制改转速/强制停转或熔断高低压保护教条；禁伪造**：上行更脆时先问秩序，不先抬功率。乱窗、假绿、冷凝高压或风机转速告警风暴常被误当「覆盖病」→**禁功率战**；挂 N；变更走 J。
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/精密空调或风机序列号全文/可还原坐标与联系人；禁公开传播未脱敏转速细节、调节参数与门限**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签准用、无实测冒充边界过、绕联锁/旁通/泄放/强制改转速或停转或熔断保护冒充秩序齐，不是法外运维智慧**。医院/数据中心公开资料只作故事类比（§10）。

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签准用、对外宣传「风扇转/灯绿/表绿/口头调过秒过」、把未实测写成已过、把绕联锁/旁通/泄放/强制改转速或停转或熔断保护写成秩序齐。允许做的：补账、补窗、挂 R/N/J、内部挂整改。

### 4.3 「机房精密空调冷凝风机转速与冷凝压力调节巡检准用」最小集（BP）——缺页不能签准用

1. 转速台账页（冷凝风机·转速窗·本期对照；含风扇转≠台账过、看着有数/灯绿≠台账过、口头调过≠方法过、一侧过≠另一侧过勾选）
2. 冷凝压力调节侧主人与书面窗、方法、准用期页（与转速分开看；含禁表绿、禁高压灯绿、禁套邻站照片、排气压力巡检过≠本窗勾选）
3. 书面边界窗与方法页（与 BB/BJ/AX/BM/BN/AI/BA/N 分工；以本网与 OEM 为准；声明不重写邻贴）
4. 本期本组本机房实测记录（转速对照、冷凝压力调节分别留痕；禁套声明）
5. BB/BJ/AX/BM/BN 及 AI/BA/AO 边界勾选（防顶替）
6. AD/AN/AL/N/AA/AQ 边界勾选（入库≠本期窗；门禁/气灭过≠交底过；N 绿≠BP 过）
7. 会签页（准用或有条件整改）
8. 未闭项清单（有则挂整改，重大未闭禁签准用）
9. 脱敏勾选（L3）
10. 变更指针（若本期有风机角色/转速或调节窗方法/门限变更 → J）
11. 不适用声明（无精密空调，或无本路径，含纯冷冻水末端、无风冷冷凝风机的路径，书面勾选；不得顶 BB/BJ/AX/BM/BN；一侧不适用 ≠ 另一侧自动免；BB/BJ 等过了或它们不适用 ≠ 本路径自动免）

> **口诀**：转、压、界、窗、房、测、签、闭、密、界——**十字转速钉**（教学记忆；现场以本网书面规程为准，但 **冷凝风机转速台账 + 冷凝压力调节窗方法 + 边界方法 + 本组本机房本期实测 + 会签** 几乎不可砍）。

### 4.5 冷凝压力调节窗与边界清单（BP-压 / BP-界）

- [ ] 「表看着在绿区≠窗过」「高压灯绿≠窗过」「禁套邻站调节照片」「调节窗过≠转速台账过」「排气压力巡检过≠本窗」勾选

### 5.2 对话脚本（教学）

**脚本A（风扇转 / 转速灯绿 / 口头调过想签）**
新人：「风扇在转，转速表也有数，控制器转速灯绿，班长还说上个月调过，签准用吧。」
班长：「BP1——转速台账和本期对照呢？风扇转≠转速台账过，看着有数/转速灯绿≠台账过，口头调过≠方法过。补账再谈会签。」

**脚本B（BB 顶替 / 风扇转）**
外包：「BB 室外机和冷凝侧边界签还在，风扇也在转，转速和调节窗免了。」
班长：「BB≠BP。室外机/净距/风扇回BB；转速与冷凝压力调节主贴仍BP。风扇转≠本篇台账过。BB 提到风机/翅片角色和冷凝侧测点，并不单独给本篇台账。顶替挂R。本篇不重写BB全文。」

**脚本C（BJ 顶替 / 表绿当窗过）**
外包：「BJ 吸排和过热过冷刚过，排气压力也在绿区，冷凝压力表看着也绿，高压灯绿，调节窗免了。」

**脚本D（AX / BM / BN 顶替）**
外包：「AX 冷媒边界刚过，BM 开度控制也绿，BN 盘管刚洗过翅片也齐，转速免了。」

外包：「邻站转速表改个机房号交差。或者转速先强制拉满、保护先熔断，旁通开一下，再泄一点制冷剂。」

### 5.5 与弱项的现场对照（再钉一次）

转速乱账、冷凝压力调节乱窗、假绿、冷凝高压/风机转速告警风暴，常先伤站点环境与**上行**体验。有人把这些当「覆盖病」抬功率——**禁功率战**。先问 BP 秩序并分诊 BB/BJ/AX/BM/BN，风暴挂 N，变更走 J。弱项短补：**12.5 kHz / ≤8.5 kHz 占用 / 4FSK / 2-slot TDMA**；上行往往比下行先不够用。脏窗和告警风暴先伤站点环境与空口秩序，不是先去抬功率的「覆盖病」。

## 6. 工作实例（12 则，教学虚构，L3）

1. **风扇在转 / 口头调过想签**：称风扇在转、班长说调过要签 → 查 BP1 无本期对照 → **拒签**；补 BP-转。风扇转 ≠ 转速台账过；口头调过 ≠ 方法过。
2. **转速表看着有数 / 控制器转速灯绿**：称「表上有数、灯是绿的」免台账页 → **拒签**；补 BP-转。看着有数 / 转速灯绿 ≠ 台账过。
3. **冷凝压力表看着在绿区 / 高压灯绿**：称「表在绿区、高压灯绿」免调节窗 → **拒签**；补 BP-压。表绿 / 高压灯绿 ≠ 冷凝压力调节窗过。
4. **BB 顶替 BP**：用室外机/冷凝侧边界签或「风扇在转」顶本期签 → **挂 R**；**边界过 ≠ 本篇**；**风扇转 ≠ 本篇台账过**。BB 提到风机/翅片角色和冷凝侧测点，并不单独给本篇台账。
5. **BJ 顶替 BP**：称吸排和过热过冷刚过、排气压力也绿，调节窗免 → **拒签**；**吸排/过热过冷过 ≠ 本篇**；**排气压力巡检过 ≠ 冷凝压力调节窗过**（排气压力是压缩机排出侧高压角色）。
6. **AX 顶替 BP**：用压缩机/制冷剂边界签顶本期签 → **挂 R**；**压缩机/制冷剂边界过 ≠ 本篇**。
7. **BM 顶替 BP**：称开度和过热控制刚过，调节窗免 → **挂 R**；**开度/过热控制过 ≠ 本篇**（过热/膨胀阀是蒸发侧）。
8. **BN 顶替 BP**：称盘管刚洗过、翅片也齐，转速和调节窗免 → **挂 R**；**盘管清洗/翅片完好过 ≠ 本篇**；盘管干净/翅片齐 ≠ 转速/调节过。

### 11.3 给带新人的三句话
1. 冷凝风机不是风扇在转、转速灯绿、口头调过就能签：转速有账，本期对照钉死；**室外机/冷凝侧边界过≠本篇，风扇转≠转速台账过**。
