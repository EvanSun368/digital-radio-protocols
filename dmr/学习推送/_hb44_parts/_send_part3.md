## 8. 术语表（本篇约 18 词）+ 易错观念

| 词 | 本篇用法（教学） |
|----|------------------|
| **AQ** | 本篇贴纸：视频调阅·证据链边界 |
| **AQ-视** | 机房视频点位/通道台账 |
| **AQ-调** | 调阅主人与窗/权限/方法/准用期 |
| **AQ-链** | 抽调窗与方法（导出·哈希·保管链） |
| **AQ-验** | 本组本机房本期调阅、会签 |
| **AQ-治** | 假绿、顶替、伪造哈希、删改/旁路、私下外泄、功率战、泄密治理 |
| **点位 / 通道** | 摄像头覆盖位置与录像通道角色（教学；编号脱敏） |
| **调阅窗** | 按本网授权的书面时间窗与权限窗；**不等于**摄像头灯亮 |
| **导出 / 哈希 / 保管链** | 授权导出、完整性摘要、交接留痕（算法与格式以本网为准） |
| **VMS / NVR / DVR** | 视频管理/网络录像/数字录像系统角色（公开词；本网选型不写死） |
| **灯绿≠已调出** | 摄像头指示灯绿不等于本期片段已按窗调出 |
| **告警绿≠证据齐** | 监控告警大屏绿不等于录像证据链齐 |
| **N 绿≠AQ 过** | 告警风暴秩序过不等于视频调阅准用过 |
| **T 过≠AQ 过** | 射频/频谱证据过不等于机房视频物证过 |
| **假绿** | 监控/告警绿但无本期秩序实证；挂 R |
| **套票** | 套他站他期片段当本期 |
| **功率战** | 用抬功率压告警/压掉话；调阅/丢失窗也禁止 |
| **L3** | 脱敏等级：禁真实频点/站名/全称/摄像头序列号全文/单位名/联系人/未脱敏片段公开传播 |
| **N / T / AN / AD / R / J** | 风暴 / 射频投诉证据 / 门禁 / 仪表准用 / 假绿 / 变更——指针，不重写 |
| **十字视链钉** | 视、调、窗、链、房、测、签、闭、密、界 |

**易错观念**  
- ✗ 摄像头绿灯 = 已调出本期片段 → ✓ 要有账、本期调阅。  
- ✗ 监控告警绿 = 录像证据齐 → ✓ 要有主人、窗、权限、方法、准用期、导出哈希保管链。  
- ✗ N 绿 = AQ 过 → ✓ 风暴秩序 ≠ 调阅证据链。  
- ✗ T 过 / 门禁过 / 仪表在期内 = 视频调阅过 → ✓ T / AN / AD ≠ AQ。  
- ✗ 邻院片段能用 → ✓ 套票拒签。  
- ✗ 录像告警先抬功率 / 旁路消铃 / 私下拷贝 → ✓ 先 N 后 AQ，禁功率战，禁旁路，禁私下外泄。  
- ✗ 伪造哈希消争议 → ✓ 红线，禁止；本篇不教手法。  
- ✗ 射频物证可以顶机房视频物证 → ✓ 各开各的窗；T≠AQ。

### 参考答案

1. 视 / 调 / 链 / 验 / 治；口诀：**画面有账，调阅有窗，链不断档，会签才放。**  
2. 规则1；AQ-视。  
3. 规则2。  
4. 不能。告警绿≠证据齐；需主人、窗、权限、方法、准用期、本期导出哈希保管链（AQ-调/链）。  
5. 不对。拒签；主贴 AQ；假绿/顶替可挂 R。N≠AQ；T≠AQ；AN≠AQ。  
6. 套票（AQ-验）；主贴 AQ，拒签重调阅。  
7. 先 N 理风暴；**禁功率战**；**禁旁路录像**；**禁私下拷贝外泄**；缺调阅证据链秩序整改主贴 AQ。  
8. 走 **J** + 再验 **AQ**。  
9. 不能。AD 只支撑设备准用，不顶 AQ 窗。  
10. 灯绿≠已调出 → AQ-视；告警绿≠证据齐 → AQ-调/链。N = 对时与告警风暴；T = 射频/频谱证据链；AN = 门禁访客陪同；AQ = 机房视频调阅与证据链边界。N 绿≠AQ 过；T 过≠AQ 过；门禁过≠视频调阅过。  
11. 视、调、窗、链、房、测、签、闭、密、界；几乎不可砍：**点位台账 + 调阅窗方法 + 导出哈希保管链 + 本组本机房本期调阅 + 会签**。  
12. 禁真实频点/站名/机房全称/摄像头序列号全文/单位名/联系人/未脱敏片段公开传播；**不教**绕过摄像头/删改录像/伪造哈希/私下外泄/功率战。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AQ** 五子类：视 / 调 / 链 / 验 / 治——双字母续写的第十七张，负责视频调阅·证据链「台账清不清、调阅有没有窗、链断没断、本期过了没有」。  
- 故事：医院手术室/ICU 安防录像调阅与物证链——摄像头绿灯≠已调出本期片段；监控告警绿≠录像证据齐；N 风暴签≠视频调阅准用；T 射频证据≠机房视频物证；门禁过≠视频调阅过；套邻院录像=拒签；N/T/AN/AD/AA/AO/AM/AP 不顶替 AQ；假绿≠会签放行。  
- 阶段梯：建点位台账 → 钉调阅主人 → 抽调窗钉死 → 本期调阅 → 会签放行 → 变更再验。  
- 八条硬规则：**视频点位/通道台账钉死**；**调阅有主有窗有权限有方法/准用期**；**抽调窗与方法钉死**；**本组本机房本期调阅禁套他站他期**；**会签才放行「视频调阅/证据链准用」**；**禁顶替 N/T/AN/AD/AA/AO/AM/AP 等，主贴 AQ，假绿≠放行挂 R**；**调阅异常/录像丢失风暴挂 N、策略/保留期/通道变更走 J、禁功率战、禁删改/旁路录像、禁私下拷贝外泄**；**脱敏 L3**。  
- **AQ vs N**：N = 电源监控/对时/告警风暴；AQ = 机房视频点位台账 + 调阅窗/权限/方法 + 保管链/哈希/导出留痕 + 本期调阅 + 会签；N 绿 ≠ AQ 过。  
- **AQ vs T**：T = 干扰投诉射频/频谱证据链；AQ = 机房 CCTV/安防录像调阅证据链；T 过 ≠ AQ 过。  
- **AQ vs AN**：AN = 门禁与访客陪同；进机房调录像仍要 AN；门禁过 ≠ 视频调阅过。
