## 1. 为什么要写这篇手册（动机 + 现场对话）

前六十二篇手册从 A–E 协议一路写到 BI 日用/储油罐油位与泄漏：其中 **AX 回答「机房精密空调压缩机与制冷剂边界」**（压缩机台账里会写到吸排气侧角色，制冷剂窗里会写到类型/充注/检漏，但没有单独给吸排气压力**和**过热度过冷度各钉一张巡检台账），**AI 回答「温湿度与空调联锁巡检边界」**（回风温度绿 ≠ 过热度窗过），**AT 回答「冷凝水与加湿除湿联锁」**，**AU 回答「滤网压差与气流组织」**，**BG 回答「精密空调过滤器压差与滤网更换」**，**AO 回答「漏水与汇流排探测」**，**N 回答「监控对时与告警风暴」**，**AY / AZ / BB / BA / BE / AD / AN / AA / AQ** 各管新风正压防火阀、冷通道进出风、风冷室外机冷凝侧、冷冻水冷却塔侧、加湿器水质换罐、备件、门禁、首年巡检与视频证据。可还没有单独钉死一件事——**机房精密空调压缩机吸排气压力与过热度过冷度不是「压缩机灯绿 / 压力表看着有数 / 口头说过热过冷正常 / AX 压缩机冷媒边界过 / AI 温湿度过 / AT 冷凝加湿过 / AU 或 BG 滤网过 / AO 漏水探头过就能签」：吸气侧与排气侧的压力台账要各自钉死；过热度与过冷度侧要有主人有窗有方法有准用期；边界窗与方法要书面固定；本期实测禁套他站他期——能不能签「机房精密空调压缩机吸排气压力与过热度过冷度巡检准用」？** 这就是本篇的 **BJ**——**机房精密空调压缩机吸排气压力与过热度过冷度巡检交底台账**（Excel 风格双字母：BI 之后 → **BJ**）。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **吸排气压力台账钉死**：吸气侧与排气侧各自有账；表计/变送器角色入账（编号脱敏）；禁「压缩机灯绿就算过」「看着有压力数就算过」「口头说压力正常」；吸气过 ≠ 排气过，排气过 ≠ 吸气过。  
2. **过热度/过冷度侧有主有窗有方法/准用期**：测点、查表或控制器读出、合格窗以本网与 OEM 书面为准；每次过热过冷交底有主人角色、有书面窗、有方法、有准用期；禁「口头说过热过冷正常」「套邻站过热过冷数」；过热度过 ≠ 过冷度过。  
3. **边界窗与方法钉死**：书面固定；方法含与 AX/AI/AT/AU/BG/AO/N 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明逐步充注/泄放/绕联锁操作教条；**不重写 AX/AI/AT/AU/BG/AO 全文**）；禁「窗再说」「绕高压/低压/油压等保护联锁」「不安全泄放制冷剂」「开旁通冒充」「伪造台账」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、吸气压力、排气压力、过热度、过冷度必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「机房精密空调压缩机吸排气压力与过热度过冷度巡检准用」；假绿 ≠ 放行。  
6. **禁顶替 AX/AI/AT/AU/BG/AO/AD/AA/N/AQ/AY/AZ/BB/BA/BE/AF/AS/AW 等，主贴 BJ，假绿≠放行挂 R**：他贴签都不顶本期吸排/过热过冷签。**尤其：AX ≠ BJ，AI ≠ BJ，AT ≠ BJ，AU ≠ BJ，BG ≠ BJ，AO ≠ BJ；压缩机/制冷剂边界过 ≠ 吸排/过热过冷台账过；温湿度过 ≠ 过热过冷过；冷凝加湿过 ≠ 吸排/过热过冷过；滤网压差/换网过 ≠ 吸排/过热过冷过；漏水探头过 ≠ 窗过；灯绿 ≠ 台账过；看着有数 ≠ 本期核对过；口头说过热过冷正常 ≠ 窗过。**  
7. **吸排压力异常/过热过冷乱窗/告警风暴挂 N，边界/门限/窗变更走 J，禁功率战；禁绕联锁；禁不安全泄放；禁旁通；禁伪造台账**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。吸排/过热过冷乱窗、假绿、告警风暴常被误当「覆盖病」→**禁功率战**；挂 N；变更走 J。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/精密空调序列号全文/可还原坐标与联系人；禁公开传播未脱敏吸排/过热过冷门限与参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签吸排/过热过冷准用、无实测冒充边界过、绕联锁/不安全泄放/旁通冒充秩序齐，不是法外运维智慧**。医院/数据中心公开资料只作故事类比（§10），翻译成本网语言就是 BJ-压 / BJ-热 / BJ-界 / BJ-验 / BJ-治。

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机房精密空调压缩机吸排气压力与过热度过冷度巡检准用」、对外宣传「灯绿/看着有数/口头正常秒过」、把未实测写成已过、把绕联锁/不安全泄放/旁通写成秩序齐。允许做的：补吸排气压力台账、补过热过冷窗、重开边界窗、挂 R/N/J、内部挂整改。

1. **压缩机灯绿 / 看着有数想签准用**：称灯绿、压力表有数要签 → 查 BJ1 无本期台账核对 → **拒签**；补 BJ-压。
