## 1. 为什么要写这篇手册（动机 + 现场对话）

前二十一篇手册把「家里怎么养」「邻居怎么处」「投诉怎么分诊」基本写全了：A–E 协议，F 射频指纹，G 实验室，H 话务，I 室分，J 写频，K 电源，L 井库，M 批量 / OTAP，N 监控对时，O 有源隔离，P 口部，Q 金机，R 假绿演练，S 邻频协调，T 干扰投诉分诊。可现场还有一类债——**证照与台账**：

- 写频岗：「这张写频单的频点，许可还在有效期内吗？」——**未对账**：写频文件 ≠ 许可，也 ≠ 执照。  
- 开站班长：「执照上周到期了，先开着，下周再续。」——**过期仍开站** = 本篇拒签（规则2、6）。  
- 项目经理：「站要先搬到新机房，证回头补。」——**先搬后补证** = 迁户口窗口没批就搬家（规则3）。  
- 合规岗：「台账缺功率上限和变更履历，先签『合规就绪』吧。」——**缺项禁签**（规则4）。  
- 领导：「批量 OTAP 赶工期，来不及对每台的许可覆盖。」——**写频/OTAP 前未对账**（规则5，挂 J / M）。  
- 邻网协调：「我们改了边界侧功率，忘了通知你们。」——**变更未通知邻居**（规则7，挂 S；若已投诉挂 T）。  
- 新人：「许可和执照不是一回事吗？」——**许可 ≠ 执照 ≠ 写频文件**（弱项短补）：房产证管「这块地能不能用、怎么用」；户口本管「这个户口落在哪、户主是谁」；写频文件只是「家里怎么排座位」。

这几句背后是同一件事：

> **「频率许可变更与台站执照台账」在现场至少有五个坑**：**① U-许** 许可仍有效、范围覆盖拟用频点/地域/用途/期限；**② U-照** 执照仍有效、台址/功率/天线/设备与执照载明一致；**③ U-账** 台账可对账（编号脱敏、台址脱敏、频点组脱敏、功率上限、有效期、变更履历）；**④ U-变** 变更走书面审批，禁私自挪频挪站扩功率；**⑤ U-治** 无证/过期/缺项拒签，到期预警与关停，跨网挂 S，公开仓 L3。  
> 把 ①–⑤ 当成「有写频文件就能开」「过期先用着」「先搬后补」「台账凑合签」，会把下一任、邻居和主管部门一起拖进泥潭。

本篇目标：能背出**频率许可与台站执照台账工作流**；会用新贴纸 **U（许 / 照 / 账 / 变 / 治）** 与五个子类；会填**插页 U（U1–U8）**和《本网频率许可与台站执照台账卡》；能用「**房产证 + 户口本 + 迁户口窗口**」故事讲清：先证覆盖再开站、禁先搬后补、台账可对账、变更窗口、拒签与预警；能拒绝「无证开站、过期先用、私自挪频、缺项签合规、公开泄密」；自测过关后，回库把本网最近一次开站/写频/变更（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：凡引法规均指向已公开发布的文书标题与官方链接（《中华人民共和国无线电管理条例》《无线电频率使用许可管理办法》《地面无线电台（站）管理规定》《无线电台执照管理规定》等），**数字、时限、程序以原文与属地最新要求为准，本篇只作教学转述，不发明条款号以外的「内部口径」**；**现象与台账一律用相对道号、角色标签、脱敏编号表述，禁真实频点 / 站名 / 单位名 / 许可或执照全文号 / 联系人 / 坐标**；**不教无证发射、私自挪频挪站、伪造涂改证件、规避监管**；J / M 仍管写频与批量边界，S 仍管邻频协调，T 仍管投诉进线后分诊——**证照与台账主贴 U**；外国 / ITU 资料只借**频谱管理与执照记录方法**，**许可与设台以国内法规与属地无线电管理机构为准**。

## 2. 总图 / 故事：许可与执照像「房产证 + 户口本 + 迁户口窗口」

### 2.1 一句话：频率许可像房产证/土地证（这块频谱怎么用、用多久），台站执照像户口本/营业执照（这个台落在哪、功率天线多少），变更像迁户口——先到窗口核准再搬家，禁先搬后补证；台账是家里的户口本复印件夹，缺页就不能对外说「我们合规就绪」

```text
   ┌──────────────────────────────────────────────────────────────────┐
   │   不动产登记中心 + 派出所户籍窗口（= 无线电管理机构）            │
   │                                                                  │
   │   房产证 / 土地证（U-许 · 频率使用许可）                          │
   │     用途 · 使用范围 · 期限 · 使用率要求 · 许可证事项             │
   │                                                                  │
   │   户口本 / 营业执照（U-照 · 无线电台执照）                        │
   │     台址或使用区域 · 频率 · 发射功率 · 占用带宽 · 设备核准 · 有效期 │
   │                                                                  │
   │   家里户口本夹（U-账 · 本网台账）                                 │
   │     许可编号(脱敏) · 执照编号(脱敏) · 台址脱敏 · 频点组脱敏     │
   │     功率上限 · 有效期 · 变更履历 —— 缺项禁签「合规就绪」         │
   │                                                                  │
   │   迁户口窗口（U-变）                                             │
   │     改频点 / 改台址 / 改功率 / 改天线 / 改用途 → 先书面变更审批  │
   │     ✗ 先搬家后补证 = 规则3                                       │
   │                                                                  │
   │   治理拒签（U-治）                                               │
   │     无证/过期禁开站 · 到期预警关停 · 跨网挂S · 公开仓 L3         │
   └──────────────────────────────────────────────────────────────────┘
```

口诀：

> **先证覆盖，再写频开站；先核准，再搬家。**  
> 无证 / 过期还开站 = 没房产证就对外出租——**拒签**。  
> 先搬后补证 = 迁户口没批就撕掉旧门牌——**违规**。

### 2.2 「房产证 + 户口本 + 迁户口」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **许可** | 房产证 / 土地证 | 频点、地域、用途、期限是否仍有效且覆盖拟用方案 | U-许 |
| **执照** | 户口本 / 营业执照 | 台址、功率、天线/设备、有效期是否与现场一致 | U-照 |
| **台账** | 家里户口本夹 + 变更页 | 编号脱敏、台址脱敏、频点组、功率上限、有效期、履历可对账 | U-账 |
| **变更** | 迁户口窗口 | 改频/址/功率/天线/用途 → 书面审批后再实施；禁私挪 | U-变 |
| **拒签治理** | 无证禁出租、过期禁营业 | 无证/过期/缺项拒签；到期预警；跨网通知；L3 | U-治 |

> 公开文书告诉我们：使用无线电频率通常应取得许可；设置、使用无线电台（站）通常应取得无线电台执照；许可证/执照载明事项变更应向作出许可决定的无线电管理机构办理变更；期限届满需继续使用的，应在届满前按规定时限提出延续申请（具体时限与材料以《无线电管理条例》《无线电频率使用许可管理办法》《地面无线电台（站）管理规定》等原文及属地要求为准）。本篇只借「先证后用、变更先批、台账可对」的顺序，**不编造内部时限数字以外已核原文的内容**。

### 2.3 和手册11 / 14 / 20 / 21 的咬合（指针，不重写）

- **手册11 J**：写频单、色码、时隙、密钥边界。本篇规定——**写频前强制核对台账 U**；许可/执照不覆盖 → **拒签写频**（规则5）。

### 2.4 新贴纸 U：许 / 照 / 账 / 变 / 治（五个子类）

```text
                ┌──────────── 贴纸 U · 许/照/账/变/治 ────────────┐
                │  U-许  许可有效且覆盖：频点组·地域·用途·期限·使用率要求   │
                │  U-照  执照有效且一致：台址·功率·带宽·设备核准·有效期     │
                │  U-账  台账可对账：编号脱敏·台址脱敏·频点组·上限·履历     │
                │  U-变  变更书面审批：频/址/功率/天线/用途；禁先搬后补     │
                │  U-治  拒签治理：无证过期禁开·预警关停·挂S·L3           │
                └──────────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签 / 拒放行触发 |
|------|--------|----------------------|
| **U-许** | 许可过期、范围不覆盖拟用频点/地域/用途 → 禁写频开站 | 「许可快到期了，先开」 |
| **U-照** | 执照过期、台址/功率与执照不一致 → 禁开站扩功率 | 「执照回头补，站先上」 |
| **U-账** | 台账缺编号脱敏、有效期、功率上限或变更履历 → 禁签合规就绪 | 「字段以后补，先签字」 |
| **U-变** | 未书面变更审批就挪频/挪站/抬功率 → 拒签变更放行 | 「先搬后补证」 |
| **U-治** | 无证开站、过期继续、公开泄密、跨网不通知 → 治理 | 「先用着再说」「公开贴全文号」 |

### 2.5 频率许可与台站执照台账最小工作流（背下来）

```text
  拟写频 / 开站 / 扩功率 / 挪频 / 挪站 / OTAP / 变更
        │
        ▼
  许可仍有效？范围覆盖拟用频点·地域·用途？（U-许）
        │否──▶ 拒签；走延续/变更/新许可路径（规则1、2）
        │是
        ▼
  执照仍有效？台址·功率·天线/设备与执照一致？（U-照）
        │否──▶ 拒签开站/扩功率；走延续/变更（规则1、2）
        │是
        ▼
  台账可对账？（编号脱敏·台址脱敏·频点组·功率上限·有效期·履历）
        │否──▶ 禁签「合规就绪」（U-账 / 规则4）
        │是
        ▼
  是否变更事项？（频点/台址/功率/天线/用途）
        │是──▶ 书面变更审批完成？──否──▶ 禁实施（U-变 / 规则3）
        │         │是
        │         ▼
        │      影响边界/邻居？──是──▶ 先通知挂 S，后复测（规则7）
        │
        ▼
  写频 / OTAP / 开站前再次核对台账（规则5，挂 J / M，主贴 U）
        │
        ▼
  有效期预警：到期前 N 天（本网制度）预警；过期未续 → 降级/关停路径（规则6）
  结案词用 U 子类；公开包 L3（规则8）
```

现场口诀：

> **先证覆盖，再写频开站；先核准，再搬家。**  
> 跳过台账对账的「开站工单」= 没查房产证就对外签约。

## 3. 核心交付：插页 U + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 U（而不是先贴 J / M / S / T）

| 现场信号 | 主贴 | 可次挂 |
|----------|------|--------|
| 写频 / OTAP / 开站前核证照 | **U**（先对账） | J / M |
| 许可或执照临期 / 过期 | **U-治** | — |
| 拟改频点 / 台址 / 功率 / 天线 / 用途 | **U-变** | S（边界）、J（写频） |
| 台账缺项仍要签「合规就绪」 | **U-账** | — |
| 变更影响邻居 / 边界 | **U-变** + 挂 **S** | T（若已投诉） |
| 投诉进线（已是事后） | **T**（不是 U） | 可查 U 作内因 |
| 仅写频参数对错、证照已齐 | **J**（证照段已由 U 放行） | U 存档指针 |

> **口诀**：写什么进终端 → **J / M**；邻居与联测 → **S**；投诉分诊 → **T**；**证还有效吗、账对得上吗、变更批了吗 → U**。可叠挂，**证照与台账主贴 U**。

### 3.2 插页 U · 许 / 照 / 账 / 变 / 治（挂在总三联单或开站/写频单后）

| 行 | 名称 | 填写示例（教学虚构，L3） |
|----|------|--------------------------|
| **U1** | 主子类 + 次子类 | 「主 U-许 / 次 U-账」（或 U-照 / U-变 / U-治） |
| **U2** | 许可五组核对 | 「有效期内 · 频点组覆盖（相对道号）· 地域覆盖 · 用途一致 · 期限/使用率要求已读」——禁写真实频点与全文号 |
| **U3** | 执照字段核对 | 「有效期内 · 台址脱敏编号一致 · 功率≤执照上限 · 带宽/设备核准代码角色一致」 |
| **U4** | 台账对账勾选 | 「□许可编号(脱敏) □执照编号(脱敏) □台址脱敏 □频点组脱敏 □功率上限 □有效期 □变更履历」 |
| **U5** | 变更事项与审批 | 「无变更 / 有变更：事项=功率上限调整；审批回执角色编号；实施日≥核准日」 |
| **U6** | 邻居与复测 | 「不影响边界 / 已挂 S 通知+复测窗」——未通知禁宣称变更完成（规则7） |
| **U7** | 动作与禁令 | 「已冻结无证开站工单；已启动续期；拒签 OTAP 全量」 |
| **U8** | 预警与脱敏 | 「到期前 N 天预警已触发；公开包 L3；全文号仅存受控柜」 |

> **U2 / U3 任一否 → 禁止写频开站扩功率挪频（规则1、2）。**  
> **U4 缺任一项 → 禁签「合规就绪」（规则4）。**  
> **U5 有变更但无审批 → 禁实施（规则3）。**  
> **U6 影响边界但未通知 → 本页作废重填（规则7）。**  
> **U7 若写「先开着再说」「先搬后补」→ 本页作废（规则2、3、6）。**

### 3.3 「无证/过期/缺项拒签」卡（贴值班台 / 写频室 / 开站班）

```text
  ┌────────── 频率许可与台站执照台账拒签卡（贴纸 U）──────────┐
  │  × 许可过期或不覆盖拟用频点/地域/用途仍写频开站            │

  │  × 未书面变更审批就挪频 / 挪站 / 抬功率 / 改天线 / 改用途  │

  └────────────────────────────────────────────────────────────┘
```

### 3.4 和总三联单怎么写（接手册06）

- **现象**：写「拟开站 / 拟写频 / 拟变更 + U 子类」，**未对账前不写「合规就绪」**。  
- **证据**：许可有效期角色、执照有效期角色、台账勾选、变更审批回执角色、邻居通知（若有）；全部 L3。  
- **结论**：用 U 子类 + 放行/拒签；次挂 J/M/S/T 时写清主贴仍是 U。  
- **动作**：续期、变更申请、冻结工单、预警、关停路径——**禁止**写「先开后补」。

## 4. 深潜：八条硬规则 + 许可五组核对 + 执照字段 + 台账节奏 + 变更窗口

### 4.1 八条硬规则（本篇钉子）

1. **先证许可与执照仍有效、范围覆盖拟用频点/台址/功率/天线，再谈写频开站**——覆盖未证，射频与写频工单冻结。  
2. **无有效许可/执照或过期 → 禁开新站 / 禁扩功率 / 禁挪频（拒签）**——「先用着再说」不是出口。  
3. **变更（频点/台址/功率/天线/用途）必须走书面变更审批，禁私自挪频挪站**——与手册20 S「禁私自挪频」咬合；先搬后补证 = 红线。  
4. **台账必须可对账：许可编号(脱敏)、执照编号(脱敏)、台址脱敏编号、频点组脱敏、功率上限、有效期、变更履历——缺项禁签「合规就绪」**。  
5. **写频 / OTAP / 开站前强制核对台账**（挂手册11 J / 14 M，**主贴 U**）——批量不豁免。  
6. **过期预警制度：到期前 N 天预警（N 由本网制度规定）；过期未续 → 降级/关停路径，禁「先用着再说」**——教学不规定唯一 N，但必须有预警与关停动作主人。  
7. **跨网/边界协调变更先通知邻居后复测（挂 S）；投诉类挂 T；禁功率战**——变更完成 ≠ 邻居已知。  
8. **脱敏 L3：公开包禁真实频点、站名、单位名、许可/执照全文号、坐标、联系人**——原件受控另册。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：《无线电管理条例》明确使用频率通常应取得许可、设台通常应取得无线电台执照，并规定许可/执照期限与延续申请时限等；《无线电频率使用许可管理办法》明确不得擅自扩大使用范围或改变用途，拟变更许可证载明事项应提出申请，期限届满需继续使用应按规定时限申请延续；《地面无线电台（站）管理规定》明确执照应载明台址或使用区域、频率、发射功率、占用带宽、设备型号核准代码、有效期等，变更载明事项应办理变更，延续应在届满前按规定时限申请。**这些是主管部门的许可与设台规则，不是你方「先开后补」或「台账缺项也签字」的借口。**

### 4.2 许可五组核对题（U-许）——房产证必问

```text
  ① 有效期
     是否在有效期内？距到期是否已进入本网预警窗（N 天）？
     → 临期：启动延续；过期：拒签开站/写频，走关停或续期完成后再议

  ② 频点组覆盖
     拟用相对道号是否落在许可载明范围内？（教学用相对道号，禁真实频点）
     → 不覆盖：变更或新许可，禁私自挪到「旁边道」

  ③ 地域 / 使用范围
     拟设台址或使用区域是否在许可使用范围内？
     → 超范围：变更，禁「先搬到范围外再说」

  ④ 用途
     业务用途是否与许可一致？（专网语音/数据等角色标签）
     → 改用途：变更审批，禁擅自改用途

  ⑤ 其他载明事项
     使用率要求、特别规定事项等是否已读并落入台账备注？
     → 未读：补读；与现场冲突：升级合规岗，禁假装没看见
```

**许可未过五组题的冻结清单**：写频、OTAP、开新站、扩功率、私自挪频。允许做的：台账核对、起草延续/变更材料（L3）、约主管部门窗口、挂 S 预通知（若变更可能影响邻居）。

### 4.3 执照字段最小集（U-照）——户口本必核

| 序号 | 最小集项（教学） | 为什么必须有 | 缺了 / 不一致会怎样 |
|------|------------------|--------------|---------------------|
| 1 | **有效期** | 过期执照不能当「合法设台」凭证 | 拒签开站；走延续或关停 |
| 2 | **台址或使用区域**（脱敏编号） | 执照落点与现场一致 | 「人户分离」——先变更 |
| 3 | **使用频率**（相对道号 / 频点组脱敏） | 与许可及写频一致 | 写频拒签 |
| 4 | **发射功率上限** | 现场功率不得超过执照载明 | 扩功率拒签；先变更 |
| 5 | **占用带宽** | 与信道规划 / 设备一致 | 异常则冻结 |
| 6 | **设备型号核准代码**（角色） | 发射设备依法核准 | 未核准设备禁开站叙事 |
| 7 | **执照编号**（台账仅存脱敏） | 对账索引 | 缺编号 → 台账不可对 |

> **口诀**：期、址、频、功、宽、核、号——**七字最小集**。教学记忆用；现场以执照样式与属地要求为准，但 **有效期、台址、频率、功率** 几乎不可砍。

### 4.4 台账对账节奏（U-账）

```text
  日常（每次写频 / OTAP / 开站工单）
        → U4 七勾选全绿才放行（规则5）

  周期（本网制度：如每月 / 每季）
        → 全量有效期扫描；临期清单；变更履历抽查

  变更后 24h 内（教学建议节奏，可按本网压缩/拉长）
        → 回写履历；若影响边界 → S 通知与复测记录挂接

  交班
        → 口述「临期条数 + 冻结工单 + 在途变更」
```

**缺项典型姿势（全部禁签「合规就绪」）**：

- 只有写频文件，没有许可/执照有效期字段；  
- 有全文号贴在公开周报（L3 违规）；  
- 功率上限空白，现场「凭经验拧」；  
- 变更履历只有微信聊天记录、无审批回执角色；  
- 台址变更了，台账还是旧脱敏编号。

### 4.5 变更窗口标准节奏（U-变）——迁户口怎么办

| 步 | 动作 | 拒签点 |
|----|------|--------|
| 1 | 明确变更事项（频/址/功率/天线/用途） | 「先改现场再想事项」 |
| 2 | 核对现许可/执照是否允许该方向；起草变更申请（材料以官方要求为准） | 材料造假（红线） |
| 3 | 提交作出许可决定的无线电管理机构；取得变更核准/新执照 | 未核准就实施 |
| 4 | 若影响邻居/边界：书面通知 + 挂 S；约定复测窗 | 只改不通知 |
| 5 | 核准后实施：写频/调功率/搬站；金机复核（Q）；台账回写履历 | 实施日早于核准日 |
| 6 | 复测与结案：U8 +（若有）S 联测记录；公开包 L3 | 未复测宣称「已消除影响」 |

与手册20 四态联测交接：边界侧功率/频点变更后，**U 放行实施 ≠ S 验收完成**；两边单据互挂编号（脱敏）。

### 4.6 弱项短补：许可 ≠ 执照 ≠ 写频文件

```text
   许可（房产证）     执照（户口本）      写频文件（家里排座位表）
   ─────────────     ─────────────      ─────────────────────
   频谱怎么用         这个台能不能设      终端/中继里写什么参数
   用途·范围·期限     台址·功率·设备      信道·色码·时隙·密钥…
   变更找许可窗口     变更找执照窗口      变更前必须先有前两者覆盖

   ✗ 「写频文件在，就能开站」
   ✗ 「有许可就等于每台都有执照」
   ✗ 「执照在，就能随便改功率到许可上限以外」
   ✗ 「OTAP 成功 = 合规」（OTAP 只改终端，不创造许可）
```

所以规则5才硬：**写频 / OTAP / 开站前强制对账 U**——J 和 M 管「怎么改参数的风险」，U 管「改这些参数的资格还在不在」。

### 4.7 与主管部门路径怎么衔接（只讲合规路径，不教规避）

教学流程（细节以属地最新要求与官方受理材料为准）：

1. **自查台账**：U2–U4 勾选；临期清单；现场与执照一致性抽测。  
2. **延续**：期限届满需继续使用 → 在届满前按规定时限向作出许可决定的机构提出延续申请（条例与办法对频率许可、地面规定对执照均有「届满前申请延续」的要求，**具体工作日数以原文为准**）。  
3. **变更**：拟变更许可证或执照载明事项 → 向作出许可决定的机构申请变更；核准前禁实施。  
4. **新设台 / 新许可**：按条例与《地面无线电台（站）管理规定》等提交材料（含频率许可证明、设备核准、技术方案等——**以官方清单为准，本篇不编造表格字段**）。  
5. **临时设台**：法规对紧急情况或重大活动临时设台有专门路径与事后报告要求——**下一篇候选「重大保障临时频率与联测窗」展开；本篇只提醒：临时不是「无证永久」**。  
6. **配合检查**：按管理机构要求提供维护记录、接受检查检测；公开宣传稿仍 L3。  
7. **结果归档**：回执、新证照与台账 U8 对齐；全文号受控，公开仓脱敏。

**明确不教**：如何无证发射、如何伪造涂改证件、如何规避监测与检查、如何「先开后补」话术过关。

### 4.8 到期预警与关停路径（U-治 / 规则6）

| 阶段 | 教学动作 | 禁令 |
|------|----------|------|
| 预警窗（到期前 N 天） | 台账标黄；通知合规主人；启动延续材料 | 禁新开站、禁扩容叙事 |
| 临期未交材料 | 升级领导；冻结相关写频/OTAP | 禁「再拖一周」 |
| 过期日 | 降级或关停路径启动（本网制度写清主人与签字） | 禁「先用着再说」 |
| 续期完成 | 台账回写新有效期；解除冻结 | 公开包仍 L3 |

N 的数值由本网制度规定（可与财务缴费、合同、维保窗口对齐）；**本篇考核的是「有预警 + 有关停路径 + 有主人」**，不是某一个万能天数。

### 4.9 开站 / 写频前 15 分钟对账清单（可复印）

| 分钟 | 动作 |
|------|------|
| 0–3 | 打开台账卡：目标台址脱敏编号、拟用相对道号 |
| 3–7 | U2 许可五组题；U3 执照七字段 |
| 7–10 | U4 七勾选；缺项 → 拒签并开缺陷单 |
| 10–13 | 若有变更：U5 审批回执；U6 邻居通知 |
| 13–15 | 放行签字（角色）或拒签；交班口述 |

夜班压缩版：至少完成「有效期 + 频点组覆盖 + 功率上限 + 台址一致」四项，其余次日补全勾选——**四项缺一仍拒签**。

### 4.10 与 J / M 单据互挂（U → 写频 / OTAP）

```text
  写频单 / OTAP 批次单（J / M）
        │
        ├── 必填：台账卡编号（脱敏）· U 放行角色 · 放行时刻
        ├── 禁填：许可/执照全文号、真实频点、真实站名
        └── 若 U 拒签 → J/M 单状态=冻结，原因=U子类
```

批量 OTAP：按手册14「先试点后全量」；试点名单中的每一台也必须能追溯到 U4 勾选——**「批次已对过一次」不能代替「每台可对账」**（教学从严；本网若有「同执照批量终端」合并规则，须写进制度并仍保留有效期与功率上限核对）。

| 原话 | 主贴 | 动作 |

### 5.2 对话脚本（五则）

**脚本1 · 过期先开**  
对方：「执照刚过期三天，业务不能停，先开。」  
你：「规则2：过期禁开新站扩功率挪频。现在走续期加急 + 降级/关停路径；不是先开后补。主贴 U-治。」

**脚本2 · 先搬后补**  
对方：「机房合同到期，今晚必须搬站，变更下周再办。」  
你：「规则3：变更先书面审批。今晚能搬的前提是变更已核准；否则拒签搬站工单。主贴 U-变。」

**脚本3 · 台账缺项签字**  
对方：「审计要『合规就绪』，字段回头补。」  
你：「规则4：缺项禁签。今晚补 U4 七勾选，补不齐就签『台账缺陷、未就绪』。主贴 U-账。」

**脚本4 · 批量 OTAP**  
对方：「200 台一起 OTAP，没法一台一台对许可。」  
你：「规则5：写频/OTAP 前强制对账，批量不豁免。按执照分组对账 + 手册14 试点；对不上的剔出批次。主贴 U，挂 M。」

**脚本5 · 变更不通知邻居**  
对方：「我们降了边界功率，对邻居是好事，不用打招呼。」  
你：「规则7：边界变更先通知后复测，挂 S。降功率也可能改覆盖与投诉归因；补通知。主贴 U-变。」

### 5.3 夜班 15 分钟怎么用

1. 扫台账临期清单（黄灯条数）。  
2. 查在途变更：有无「未核准已实施」。  
3. 查冻结写频/OTAP 单是否仍被绕过。  
4. 交班口述：临期、在途变更、冻结原因（U 子类）。

### 5.4 「证照三问」（贴写频室 / 开站班）

```text
  1. 许可和执照还在有效期内吗？覆盖今晚要做的事吗？
  2. 台账 U4 七勾选全了吗？
  3. 有变更吗？核准了吗？邻居要不要挂 S？
```

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「写频单在，许可已过期」→ U-许 / U-治

现象：写频岗按旧文件写相对道号组 A，台账显示许可过期。  
处置：拒签写频；冻结 OTAP；启动延续；主贴 U-许。  
结案词：「U-治：许可过期未续，禁写频开站。」

### 例 2 · 「执照台址与机房不一致」→ U-照 / U-变

现象：现场已迁到新机房角色 B，执照仍为台址脱敏编号 A。  
处置：拒签「开站完成」；走台址变更；核准前禁对外宣称合法设台完成。  
结案词：「U-变：台址变更未核准，禁先搬后补叙事。」

### 例 3 · 「台账缺变更履历仍签合规」→ U-账

现象：审计要签字，功率去年抬过，履历空白。  
处置：拒签合规就绪；补审批回执角色或启动补正路径；公开包不得出现全文号。  
结案词：「U-账：履历缺项，禁签合规就绪。」

### 例 4 · 「先抬功率顶覆盖」→ U-变 + 禁功率战

现象：覆盖投诉，班长欲超执照上限抬功率。  
处置：若未超上限但仍属变更载明功率，走变更；若超上限，拒签；覆盖类先挂 T 分诊 / F / Q，禁功率战。  
结案词：「U-变拒签超执照功率；投诉转 T。」

### 例 5 · 「OTAP 全网赶工期」→ U + M

现象：重大活动前全量 OTAP，未做 U4。  
处置：按手册14 试点；试点台必须 U4 全绿；未对账台剔出；主贴 U 挂 M。  
结案词：「U+M：批量不豁免台账对账。」

### 例 6 · 「边界改频未通知邻居」→ U-变 + S

现象：本网边界相对道号组调整已实施，邻网次日投诉。  
处置：主贴 T 分诊；并行查 U——变更审批有无、S 通知有无；补通知与复测；禁报复抬功率。  
结案词：「U-变缺陷致投诉；挂 S/T；规则7。」

### 例 7 · 「临期无预警」→ U-治

现象：到期前一日才发现，延续材料未交。  
处置：标红；冻结新开站；紧急延续；复盘预警制度（N 天与主人）。  
结案词：「U-治：预警失效，已补路径。」

### 例 8 · 「公开周报贴出执照全文号」→ U-治 / L3

现象：宣传稿含真实站名与执照全文号。  
处置：下架；改 L3；原件受控；培训规则8。  
结案词：「U-治：L3 违规已纠正。」

### 例 9 · 「有许可无执照开中继」→ U-照

现象：频率许可有效，中继站未取照即发射。  
处置：立即停发路径（本网审批）；补执照申请；不教「躲监测」。  
结案词：「U-照：无执照禁设台发射。」

### 例 10 · 「变更核准后未回写台账」→ U-账

现象：变更已核准并实施，台账有效期/功率上限仍旧值，次日写频按旧上限拒签争议。  
处置：24h 内回写履历；对账节奏写入交班；放行争议以台账+回执为准。  
结案词：「U-账：变更后未回写，对账节奏失效。」

## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 一句话 |
|------|--------|
| **频率使用许可** | 依法取得的频谱使用权凭证（教学喻：房产证） |
| **无线电台执照** | 合法设置、使用无线电台（站）的凭证（教学喻：户口本） |
| **台账** | 本网对许可/执照关键字段的可对账登记（脱敏） |
| **载明事项** | 证照上写明的频率、台址、功率、期限等 |
| **变更** | 改载明事项，须向原许可/发证路径办理 |
| **延续** | 期限届满前申请继续使用 |
| **注销 / 停用** | 终止使用并按规定交回执照、拆除等（以原文为准） |
| **覆盖** | 拟用方案落在许可/执照允许范围内 |
| **脱敏编号** | 公开与教学用的替代编号，非全文号 |
| **功率上限** | 执照载明发射功率不得突破（变更前） |
| **型号核准** | 发射设备依法核准（代码角色入台账） |
| **临时设台** | 法规允许的紧急/重大活动路径，≠ 永久无证 |
| **预警窗** | 到期前 N 天的本网提醒与冻结策略 |
| **关停路径** | 过期未续时的降级/停发审批流程 |
| **合规就绪** | 台账可对账且证照覆盖后的签字状态 |
| **主贴 U** | 证照台账问题以 U 为主键，可挂 J/M/S/T |
| **L3** | 公开包最高脱敏等级（本系列约定） |
| **书面审批** | 变更/延续等以管理机构核准为准，聊天记录不算 |

**易错观念**

1. ✗ 有写频文件 = 已许可已设台合法 → ✓ 许可、执照、写频三层。  
2. ✗ 许可有效 = 每个中继都有执照 → ✓ 设台通常另需执照。  
3. ✗ 过期三天没事 → ✓ 过期即拒签开站扩功率挪频。  
4. ✗ 先搬后补是行业惯例 → ✓ 本篇红线。  
5. ✗ 台账是给审计看的形式主义 → ✓ 台账是放行闸刀。  
6. ✗ 降功率不用通知邻居 → ✓ 边界变更仍挂 S。  
7. ✗ 公开培训可以贴全文号方便对账 → ✓ 全文号受控，公开 L3。  
8. ✗ OTAP 成功代替合规 → ✓ OTAP 不创造许可与执照。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **U** 五子类：许 / 照 / 账 / 变 / 治。  
- 故事：房产证 + 户口本 + 迁户口窗口。  
- 八条硬规则：**先证覆盖再写频开站**；**无证/过期拒签**；**变更书面审批禁私挪**；**台账缺项禁签合规**；**写频/OTAP前强制对账**；**到期预警与关停**；**跨网变更挂 S**；**脱敏 L3**。  
- 与 J/M/S/T 分工：J/M=怎么改参数；S=邻居联测；T=投诉分诊；**U=有没有资格改、账对不对**。

### 11.2 回库路径
现场「要写频 / 开站 / 变更」→ 本篇（贴纸 U + 插页 U + 台账卡）→ 许可五组 + 执照字段 + 七勾选 → 有变更走窗口 → 影响边界挂 S → 再放行 J/M；过期走预警关停；公开 L3。

### 11.3 下一篇手册候选（本篇不写正文）
- **重大保障临时频率与联测窗**（临时设台、保障期与 S/T/U 衔接）  
- **非法设台与黑广播类线索内部上报边界**（只讲依法报告与证据保全，不讲排查对抗细节）  
- （可选）**电磁环境测试与验收报告台账**（开站前电磁环境与执照申请材料咬合）

### 11.4 给带新人的三句话
1. 写频开站前先问：许可和执照还盖得住今晚要做的事吗？  
2. 搬家（改频改址改功率）先去窗口，不要先搬后补证。  
3. 台账缺页就不能签「合规就绪」；全文号不许进公开包。
