- **AW（手册50）**：列头柜与末端配电巡检；**AW ≠ BC**——列头末端过≠机柜配电与PUE/负载分区过；列头/末端巡检可挂 AW，机柜PDU·PUE·负载分区主贴仍 BC；**不得用 BC 顶 AW，也不得用 AW 顶 BC**。  
- **AF（手册33）**：油机市电切换与供电巡检；**AF ≠ BC**——油机市电过≠机柜/PUE/分区过。  
- **AS（手册46）**：UPS 旁路；**AS ≠ BC**——旁路过≠机柜/PUE/分区过。  
- **AD（手册31）**：钳表/功率计/热成像仪入库走 AD；**不能**用旧 AD 签日期顶本期 BC 窗或实测窗。  
- **AN（手册41）**：门禁过≠机柜/PUE交底过；进机房仍要 AN；**不教绕过门禁/电气联锁**。  
- **AA（手册28）**：首年巡检日历；机柜/PUE/分区抽检可挂 AA，缺秩序整改主贴仍 BC。  
- **N（手册15）**：监控/对时/告警风暴；机柜/PUE/负载分区异常风暴挂 N 理风暴，**不先抬功率**；**禁绕电气联锁、禁未授权带电**；N 绿≠ BC 过。  
- **AQ（手册44）**：机柜/PUE/分区异常事件要调录像 → 另开 AQ；视频过≠BC 准用。  
- **AV / AR / AG / AP**：油品/燃油/电池/内阻；均不顶替 BC。  
- **AI / AT / AU / AO / AL / BB / AX / BA / AY / AZ**：环境与冷源侧；均不顶替 BC——BB 室外机冷凝侧过≠BC；AZ 冷通道进出风过≠BC。  
- **R / J / X / I**：假绿挂 R；变更（分区门限、能效窗方法、机柜/PDU角色）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 BC 证机柜配电与PUE/负载分区秩序，再谈覆盖病**。

## 3. 核心交付：插页 BC + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 BC（而不是先贴 AW / AF / AS / N）

- 要签「机柜配电与PUE/负载分区巡检准用」、要开机柜PDU/能效窗、要交底负载分区边界 → **主贴 BC**。  
- 列头柜与末端配电巡检本身 → **AW**（手册50）；机柜PDU·PUE·负载分区本体窗仍 BC。  
- 油机市电切换与供电巡检本身 → **AF**；机柜/PUE/分区仍 BC。  
- UPS 旁路本身 → **AS**；机柜/PUE/分区仍 BC。  
- 进机房做交底 → 先 **AN**；门禁过≠机柜/PUE交底过；**不教绕过门禁/电气联锁**。  
- 机柜/PUE/负载分区告警风暴 → 先 **N** 理风暴；缺机柜/PUE/分区秩序整改仍 **BC**；**禁功率战**；**禁绕电气联锁**；**禁未授权带电**。  
- 假绿/顶替 → 挂 **R**；变更分区门限/能效窗方法/机柜·PDU角色 → 走 **J** 后再验 BC。  
- 本站无独立机柜PDU/PUE/负载分区计量路径 → 书面勾「不适用」；**不得**用 BC 顶 AW 或 AF/AS。

### 4.1 八条硬规则（本篇钉子）

1. **机柜配电台账钉死**：机柜角色、机架PDU角色、支路/插座角色入账（编号脱敏）；禁「灯绿就算过」「口头说机柜电正常」。  
2. **PUE/负载有主有窗有方法/准用期**：能效窗口/负载测点/分区计量等以本网与 OEM 书面为准；每次PUE/负载相关维护有主人角色、有书面窗、有方法、有准用期；禁「灯绿当窗过」「口头PUE正常」。  
3. **负载分区边界窗与方法钉死**：书面固定；方法含负载分区边界核对、与 AW/AF/AS/N 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明逐步绕电气联锁/未授权带电操作教条）；禁「窗再说」「绕电气联锁」「未授权带电」「伪造台账」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、机柜表、PUE表、分区表必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「机柜配电与PUE/负载分区巡检准用」；假绿 ≠ 放行。  
6. **禁顶替 AW/AF/AS/AD/AN/AA/N/AQ/AV/AR/AG/AP/AI/AT/AU/AO/AL/BB/AX/BA/AY/AZ，主贴 BC，假绿≠放行挂 R**：列头末端签、油机市电签、旁路签、仪表签、门禁签、首年签、监控签、视频签、油品签、通风燃油签、电池签、内阻签、温湿度签、冷凝加湿签、滤网气流签、漏水签、气灭签、室外机冷凝侧签、压缩机制冷剂签、冷冻水冷却塔签、新风正压签、冷通道签都不顶本期机柜/PUE/分区签。  
7. **机柜/PUE/负载分区异常风暴挂 N，分区/门限/能效窗变更走 J，禁功率战；禁绕电气联锁；禁未授权带电；禁伪造台账**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/机柜序列号全文/回路编号全文/可还原坐标与联系人；禁公开传播未脱敏能效门限与分区参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签机柜/PUE/分区准用、无实测冒充边界过、绕电气联锁、未授权带电冒充秩序齐，不是法外运维智慧**。医院保供电机房机柜配电与负载分区/能效、数据中心 rack PDU + PUE / load-zone 公开资料只作故事与方法类比（§2.2）：**柜要约、荷要窗、区要法、验要本期、灯绿不算过、口头PUE正常不算窗过、绕联锁未授权带电不算办法**——翻译成本网语言就是 BC-柜 / BC-荷 / BC-区 / BC-验 / BC-治。**这些是机柜配电与PUE/负载分区巡检交底秩序，不是「灯绿就签」「口头PUE正常当过」「抬功率压告警」「绕联锁先过」「未授权带电冒充」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机柜配电与PUE/负载分区巡检准用」、对外宣传「灯绿/口头PUE正常秒过」、把未实测写成已过、把绕联锁/未授权带电写成秩序齐。允许做的：补机柜配电台账、补PUE/负载窗、重开分区窗、挂 R/N/J、内部挂整改。

2. **口头PUE正常当窗过**：外包称「PUE看着正常」免窗页 → **拒签**；补 BC-荷 主人/窗/方法/准用期。  
3. **AW 顶替 BC**：班长用 AW 列头末端签顶本期机柜PUE签 → **挂 R**；主贴仍 BC；AW过≠BC过。  
4. **AF/AS 顶替**：站务称油机市电与旁路过了机柜PDU免做 → **拒签顶替**；AF≠BC、AS≠BC。  
5. **N 绿免实测**：大屏配电绿，本期实测免 → **拒签**；N绿≠BC过；补 BC-验。  
6. **套邻站表**：外包拷邻站机柜/PUE表改机房号 → **BC-验 拒签重测**；禁套。  
7. **功率战**：分区过载告警，网优要抬功率 → **禁功率战**；先挂 N；缺秩序整改贴 BC。  
8. **绕联锁冒充**：外包绕电气联锁消告警后要求准用 → **禁**；挂 N/R；禁签。  
9. **未授权带电冒充**：新人未授权带电拧端子读数变绿 → **禁**；挂整改；主贴 BC-治。  
10. **BB/AZ 混签**：环境班称 BB 室外机与 AZ 冷通道过了，机柜分区免 → **拒签**；BB≠BC、AZ≠BC。  
11. **AD 顶实测**：仪表入库签日期还在，实测免 → **拒签**；AD 只支撑仪表；主窗仍 BC。  
12. **泄密发群**：新人公开群贴真实机柜序列号 → **L3 违规**；脱敏重发；挂 BC-治。

## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 本篇用法（教学） |
|------|------------------|
| **机柜配电** | 机柜侧电源分配角色（机柜·机架PDU·支路/插座）；BC-柜 |
| **机架 PDU** | Rack PDU；机柜内配电单元角色（脱敏编号）；≠ AW 列头柜本身 |
| **PUE** | Power Usage Effectiveness；能效秩序直觉；**口头PUE正常≠窗过**；门限以本网书面为准 |
| **负载** | IT/设备侧用电负荷角色；有测点、有窗、有方法 |
| **负载分区** | 按区/按列/按回路划分的负载边界；BC-区 |
| **能效窗** | PUE/能效相关书面维护窗；有主人有准用期 |
| **分区计量** | 分区级功率/电能计量角色；脱敏；不写可还原门限全文 |
| **灯绿** | 指示灯/监控绿；**≠ 台账过、≠ 窗过、≠ 本期实测过** |
| **假绿** | 无实测/无会签却显示通过；挂 R；≠ 放行 |
| **套票** | 套他站他期机柜/PUE/分区表；BC-验 拒签 |
| **绕电气联锁** | 绕过电气安全联锁冒充可过；**本篇硬禁** |
| **未授权带电** | 未经授权的带电作业冒充可过；**本篇硬禁** |
| **功率战** | 用抬功率压机柜/PUE/分区告警；**禁**；先挂 N |
| **贴纸 BC** | 本篇主贴；柜/荷/区/验/治五子类 |
| **AW ≠ BC** | 列头末端巡检 ≠ 机柜配电与PUE/负载分区 |
| **AF ≠ BC** | 油机市电 ≠ 机柜/PUE/分区 |
| **AS ≠ BC** | UPS 旁路 ≠ 机柜/PUE/分区 |
| **N ≠ BC** | 风暴秩序 ≠ 本期实测 |
| **脱敏 L3** | 禁真实站名/机房全称/机柜序列号全文/回路编号全文/联系人 |

**易错观念（纠一次）**  
- 「灯绿 = 准用」→ 错；要 BC-柜台账 + 本期实测。  
- 「口头PUE正常 = 窗过」→ 错；要 BC-荷 主人窗方法。  
- 「AW 过 = BC 过」→ 错；列头末端 ≠ 机柜PDU/PUE/分区。  
- 「N 绿 = 本期实测过」→ 错；风暴绿 ≠ 交底准用。  
- 「绕联锁消告警 = 办法」→ 错；硬禁。  
- 「抬功率压分区告警 = 救急」→ 错；禁功率战。
