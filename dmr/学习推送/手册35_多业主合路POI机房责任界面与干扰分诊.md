## 1. 为什么要写这篇手册（动机 + 现场对话）

前三十四篇手册从 A–E 协议一路写到 AG 电池抽检：其中 **S 回答「邻频协调与边界联测」**，**AE 回答「隧道/地铁区间联测与换乘责任界面」**，**T 回答「干扰投诉分诊与证据链」**，**AB/X/I 回答「室分复测」**，**AG 回答「电池与充电器梯队」**。可还没有单独钉死一件事——**多业主合路/POI 机房不是「柜里有设备就能签界面清」：合路台账与业主端口要钉死；责任界面要有主人；干扰分诊窗与方法要书面固定；本组本机房本期实测禁套他业主他期——能不能签「合路/POI 界面准用」？** 这就是本篇的 **AH**——**多业主合路/POI 机房责任界面与干扰分诊**。

- 合路岗：「柜里 POI 有灯，各家设备都在，界面肯定清。」——**无合路/业主台账仍准用** = 本篇拒签（规则1）。  
- 物业：「合用机房钥匙在我这，谁坏谁修口头说一声。」——**责任界面无主人无书面边界** = 规则2。  
- 网优：「网管全绿，不用分诊了。」——**只看网管绿，无分诊窗/方法** = 规则3。  
- 外包：「邻业主上周曲线参数差不多，拷过来改个端口号。」——**套他业主他期** = 规则4。  
- 班长：「S 邻频签还在，AE 区间也过了，合路界面也能签。」——**用 S/AE/T 顶替 AH** = 规则6。  
- 站务：「单边业主测绿了，整段合路算过。」——**单边绿≠整段过** = 规则5/6。  
- 网优：「合路窗基站抖了一下，功率抬一点稳住。」——**功率战** = 规则7。  
- 宣传岗：「把真实业主名、机房编号、端口曲线发群表扬。」——**L3 违规** = 规则8。  

这几句背后是同一件事：

> **「多业主合路/POI 机房责任界面与干扰分诊」在现场至少有五个坑**：**① AH-合** 合路/POI 台账与各业主端口、馈入/馈出角色、合路器/POI 柜编号入账，禁「柜里有就算清」；**② AH-界** 责任界面有主人（本网/他业主/物业/集成角色）、书面边界（端口侧/公共侧/馈线侧），禁口头「谁坏谁修」；**③ AH-诊** 干扰分诊窗、方法（隔离端口/对端静默/底噪观察等角色项）、到场角色书面固定，禁「看一眼网管绿」；**④ AH-验** 本组本机房本期实测（禁套他业主他期曲线），会签才放行「合路/POI 界面准用」；**⑤ AH-治** 治理（假绿、用 S/AE/T/AB 顶替、伪造界面账、功率战、泄密）。  
> 把 ①–⑤ 当成「柜里有就能签」「网管绿就算多业主过」「口头说一声界面清」，每一次合路增业主、每一次干扰互告、每一次室分复测并行，都会先吵「到底谁的端口、谁负责诊、曲线是不是本期的」。

本篇目标：能背出**合路/POI 界面 + 干扰分诊工作流**；会用新贴纸 **AH（合 / 界 / 诊 / 验 / 治）**；会填**插页 AH（AH1–AH8）**和《本网多业主合路/POI 机房责任界面与干扰分诊台账卡》；能用「**商场/医院共享楼宇合用电梯机房——谁按谁修 / 合用配电间责任界面**」故事讲清柜里有设备≠界面清、网管绿≠分诊过、套邻业主曲线=拒签、用 S/AE/T 签顶 AH 界面签=拒签、单边绿≠整段过；能拒绝无主界面、套曲线、用他贴顶替本期合路签、假绿放行；自测过关后，回库把本网最近一次合路/POI 增业主或干扰分诊（L3）重对一遍：合路账、界面主人、分诊窗、本期实测、会签项、拒签项。

**本篇硬禁令（写进脑子）**：凡引法规与标准只指向已公开发布的文书标题与官方链接（无线电管理条例、频率使用许可管理办法、地面无线电台（站）管理规定、国无办〔2025〕1号；**只作故事类比**的商场/医院合用电梯机房、合用配电间责任界面公开资料标题，以及公开的 DAS/POI/合路器/PIM 多运营商共享站点概述资料），**程序、期限、责任以原文与属地最新要求及本网制度 / 合同为准，本篇只作教学转述，不发明条款号与内部口径**；境外 DAS/POI/PIM 公开资料与商场电梯合用故事**不是**中国专网台站「贴纸 AH」的法定依据；**现象与台账一律用相对道号、角色标签、脱敏机房/业主编号，禁真实频点 / 站名 / 机房全称 / 业主单位名 / 联系人**；**不教伪造合路台账、不教功率战、不教规避监测、不教套他业主曲线、不教假绿顶替、不教绕过告警**；S / AE / T / AB / X / I / R / J / N / AG 各管各的——**合路/POI 机房责任界面与干扰分诊主贴 AH**；邻频边界回 S，区间换乘回 AE，投诉证据回 T——**AH 管「合路·界面·分诊秩序」，不替代 S 的邻频协调本身，也不替代 AE 的区间联测门卫，更不替代 T 的投诉证据链**。

## 2. 总图 / 故事：合路/POI 机房像「商场/医院共享楼宇合用电梯机房——谁按谁修」

### 2.1 一句话：合路柜里有设备不是「界面清了」、网管绿不是「分诊过了」——要先建合路/POI 台账与业主端口，责任界面有主人，分诊窗与方法钉死，本组本机房本期实测，会签才放行；假绿、套邻业主曲线、用 S/AE/T 顶替、单边绿当整段过，一律拒签

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  合用电梯机房「谁按谁修」+ 合用配电间责任界面  =  本网 AH    │
   │                                                              │
   │  电梯/配电入账·各业主端口贴签     ≈ AH-合  合路/POI 台账     │
   │  按钮侧/井道侧/公共侧谁主谁修     ≈ AH-界  责任界面有主人   │
   │  故障分诊窗·方法·到场角色钉死     ≈ AH-诊  干扰分诊窗与方法 │
   │  本期实测禁套邻楼/邻业主曲线     ≈ AH-验  本组本机房本期   │
   │  假绿≠放行·顶替·伪造账·功率战   ≈ AH-治  治理与脱敏 L3     │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **合路有账，界面有主，分诊有窗，本期实测，会签才放。**  
> 柜里有设备还无主人界面 = 合用电梯机房没人认「谁按谁修」——**拒签「合路/POI 界面准用」**。  
> 网管全绿但半年没分诊 = 配电间绿灯亮着却从未做合用界面抽检——**假绿，挂 R，拒签**。

### 2.2 「合用电梯机房 / 合用配电间」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **合** | 电梯/配电入账→各业主按钮/回路贴签→合用设备清单 | 合路/POI 台账与各业主端口钉死；禁「柜里有就算清」 | AH-合 |
| **界** | 按钮侧/井道侧/公共侧书面边界；谁坏谁修有主人 | 责任界面有主人；端口侧/公共侧/馈线侧书面 | AH-界 |
| **诊** | 故障分诊有窗、有方法、有到场；禁「看一眼总柜绿」 | 干扰分诊窗与方法、到场角色书面固定 | AH-诊 |
| **验** | 本期实测留痕；禁抄邻楼电梯检修账 | 本组本机房本期实测；禁套他业主他期 | AH-验 |
| **治** | 假绿≠界面过；禁用「邻频签」「区间签」「投诉签」顶本期界面 | 假绿、顶替 S/AE/T/AB、伪造账、功率战、泄密 → 治理 | AH-治 |

> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：DAS/POI 公开概述强调**各运营商信号在 Point of Interface 汇合，隔离、滤波、合路与监测口是界面秩序的一部分**（§10，**只借秩序直觉**）；PIM/互调公开资料强调**多载波合路处非线性可抬高底噪，尤其伤上行**（§10）；商场/医院合用电梯机房「谁按谁修」只作故事类比（§10，**不是无线电法定依据**）。本篇只借这串顺序——**本网合路台账、界面边界、分诊门限、合格标准以本网制度与合同为准**。

### 2.3 和手册20（S）/ 21（T）/ 32（AE）/ AB·X·I / 34（AG）等的咬合（指针，不重写）

- **S（手册20）**：邻频协调与**边界联测**；频率邻居怎么处——**S 管空口邻居，不替代 AH 机房内物理合路界面**。  
- **AE（手册32）**：隧道/地铁**区间联测与换乘责任界面**；区间/换乘谁责——**AE 管区间，AH 管合路机房/POI 柜**。  
- **T（手册21）**：干扰**投诉分诊与证据链**；告谁拿什么证——**T 管投诉证据，AH 管合路界面主人与分诊入口**；合路窗投诉常先 AH 再挂 T。  
- **AB / X / I（室分复测）**：室分复测≠合路界面过；复测可挂支撑，**主贴合路界面仍 AH**。  
- **AG（手册34）**：电池梯队；合路机房可并行抽检电池，各贴各的。  
- **R / J / N**：假绿挂 R；变更（增业主端口、改合路衰减、换 POI 模块）走 J；合路窗告警风暴挂 N，**不先抬功率**。

### 2.5 建合路账 → 钉界面主人 → 分诊窗钉死 → 本期实测 → 会签放行 → 变更再验 阶段梯（背下来）

```text
  ① AH-合 建合路/POI 台账：合路器/POI 柜角色 · 各业主端口贴签 · 馈入/馈出角色
        │  无台账 / 端口未贴签 → 不签界面准用
        ▼
  ② AH-界 钉责任界面：主人角色（本网/他业主/物业/集成）· 端口侧/公共侧/馈线侧书面边界
        │  无主人 / 无书面边界 → 拒进入「可签」状态
        ▼
  ③ AH-诊 钉分诊窗：书面窗 · 方法（隔离端口/对端静默/底噪观察等角色项）· 到场角色
        │  无窗 / 无方法 / 「只看绿灯」 → 拒分诊签
        ▼
  ④ AH-验 本组本机房本期实测：各业主端口角色项 · 禁套他业主他期 · 单边绿≠整段过
        │  套曲线 / 单边绿当整段 / 只看网管绿 → 拒签
        ▼
  ⑤ 会签「合路/POI 界面准用」或「有条件整改」：相关业主/本网授权本人签
        │  缺签 / 假绿顶替 → 拒签准用
        ▼
  ⑥ 变更（增业主端口/改合路衰减/换 POI 模块）→ 走 J + 触发再分诊/再验（常挂 N 看监控、挂 S/T 看邻频与投诉）
```

> **一句话分辨**：**S** 回答「频率邻居**怎么协调联测**」；**AE** 回答「区间/换乘**界面过了没有**」；**T** 回答「投诉**证据链怎么建**」；**AH** 回答「这一柜合路/POI + 这一组业主端口 + 这一窗分诊**台账清不清、界面有没有主、本期过了没有**」。**四个问题，四张（类）贴纸，不能一笔带过。**

### 2.6 合路/POI 界面与干扰分诊最小工作流（背下来）

```text

       ├─→ 有台账+端口贴签？界面有主人书面边界？ ──否──→ 拒签 / 补账补界
       └─→ 是
  AH-诊 约窗 + 书面方法 + 到场勾选
       │
  AH-验 本组本机房本期：端口隔离观察 → 底噪/上行角色项 → 禁套声明 · 单边≠整段
       │  套曲线 / 单边绿 / 只看绿灯 → 拒签
       ▼
  会签「合路/POI 界面准用」或挂整改；重大未闭禁签准用
       │
```

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **合路/POI 台账与业主界面钉死：无合路/POI 台账、业主端口未贴签不得签「合路/POI 界面准用」；禁「柜里有设备就算界面清」**。  
2. **责任界面有主人：本网/他业主/物业/集成等角色书面；端口侧/公共侧/馈线侧边界书面；禁口头「谁坏谁修」**。  
3. **干扰分诊窗与方法钉死：分诊窗、方法（隔离端口/对端静默/底噪观察等角色项）、到场角色书面固定；禁「看一眼网管绿」**。  
4. **本组本机房本期实测：须本脱敏机房、本窗、相关业主端口实测；禁套他业主/他期曲线；单边绿≠整段过**。  
5. **会签才放行：相关授权本人会签后，方可签「合路/POI 界面准用」；重大未闭项禁合格**。  
6. **禁顶替：可挂 S/AE/T/AB/X/I/R 支撑，但合路/POI 界面与干扰分诊主贴 AH；S 邻频签、AE 区间签、T 投诉签、AB 室分签、网管绿灯均不得顶替 AH 本期界面签；主贴 AH；监测大屏/系统绿灯、假绿不等于放行（挂 R）**。  
7. **合路/分诊窗射频抖动禁功率战；监控/告警风暴挂 N；增业主端口/改合路衰减/换 POI 模块等变更走 J 并评估再分诊/再验**。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/业主单位名/可还原端口曲线含定位信息/联系人**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无合路台账乱签界面、无分诊冒充多业主过关，不是法外运维智慧**。合用电梯机房「谁按谁修」与 DAS/POI/PIM 公开资料只作故事与方法类比（§2.2）：**合要约、界要主、诊要窗、验要测、绿灯不算过**——翻译成本网语言就是 AH-合 / AH-界 / AH-诊 / AH-验 / AH-治。**这些是合路界面秩序，不是「柜里有就签」「拷邻业主曲线」「抬功率压合路抖」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「合路/POI 界面准用」、对外宣传「分钟级一键多业主秒过」、把未分诊写成已过。允许做的：补合路账、补界面主人、重开分诊窗、重测、挂 R/N/J、内部挂整改。

### 4.10 POI / 合路器 / PIM 与 AH 的咬合（教学直觉，门限以本网为准）

- **POI（Point of Interface）**：各业主信号进入共享室分/合路的**物理汇合点**；公开 DAS 资料强调隔离、滤波、监测口——AH 钉「有没有账、有没有主、本期有没有诊」。  
- **合路器 / 多网络合路**：多路进、复合出；备用端口终止负载等细节以本网规程与合同为准。  
- **PIM / 互调**：多载波合路处非线性可抬高底噪，**上行更先受伤**；分诊方法可含隔离端口观察（角色项），**不教规避监测、不教伪造 PIM 报告**。  
- **AD 指针**：分诊仪表、备用合路模块入库走 AD；**不能**用旧 AD 签日期顶本期 AH 窗。

### 4.11 与邻频（S）/ 区间（AE）/ 投诉（T）/ 室分（AB）怎么配合

- S 边界联测并行：各贴各的；邻频过≠合路柜界面过。  
- AE 区间联测：区间/换乘与合路机房同时有事时，**AE 管区间，AH 管柜**。  
- T 投诉：合路互告先 AH 分诊入口，证据链挂 T；**投诉结案不顶替 AH 会签**。  
- AB 室分复测：复测点位可支撑，**室分复测绿≠合路界面准用**。

### 4.12 合路窗话务抖与上行更脆

- 先 AH/N/S：界面、监控、邻频解释得清不清。  
- 解释不清再挂 T/射频分诊；**禁止**一抖就功率战。  
- 上行更脆：合路/PIM/隔离问题常先伤上行——先抽测上行登记/话音，再下「覆盖病」结论。

### 5.2 三段对话脚本（可练）

**脚本 A · 拒签（柜里有就算清 / 无主人）**

**脚本 B · 拒签（假绿 / 网管绿）**  
对方：「大屏全绿，签合路界面准用吧。」  
你：「AH-治 + R：假绿≠本期分诊通过。AH5/AH6 本期实测与仪表准用在哪里？没有就不能签准用。」

**脚本 C · 拒签（用 S/AE/T 顶替 / 套曲线 / 单边冒充）**  
对方：「S 邻频签还在，邻业主曲线也差不多，改个端口号；再说单边已经绿了。」  
你：「AH-验/治：S/AE/T 不顶替 AH；禁套他业主他期；单边绿≠整段过。要过闸，就本窗本组本机房相关端口实测会签——改号不是分诊。」

### 5.3 夜班压缩卡（四问）

1. **合？** 今晚合路/POI 台账与端口贴签在不在？  
2. **界？** 界面主人与书面边界清不清？  
3. **验？** 是本期本组本机房，还是拷贝曲线/单边冒充？  
4. **签？** 会签人是授权本人吗？假绿有没有挂 R？

### 5.4 禁写词（三联单/交班）

## 6. 工作实例（12 则，教学虚构，L3）

1. **柜里有设备无台账**  
   现象：POI 灯亮，端口无贴签。  
   处置：AH-合 拒签准用；补合路台账与端口贴签。  

2. **口头「谁坏谁修」无主人**  
   现象：公共侧馈线故障互推。  
   处置：AH-界 拒签；书面补主人与边界；挂整改。  

3. **网管全绿半年未分诊**  
   现象：大屏绿，分诊台账停在半年前。  
   处置：AH-治 + R 假绿；重开分诊窗；主贴 AH。  

4. **套邻业主端口曲线**  
   现象：报告端口号涂改痕迹。  
   处置：AH-验/治 拒签；本窗重测。  

5. **单边绿冒充整段过**  
   现象：只测一家业主端口就签全家准用。  
   处置：AH-验 拒签；相关端口补测会签。  

6. **用 S 邻频签顶本期 AH**  
   现象：「邻频签还在有效期，不用再贴合路。」  
   处置：规则6；S 可挂支撑，主贴仍 AH。  

7. **用 AE 区间签顶 AH**  
   现象：「区间联测刚过，POI 也能签。」  
   处置：规则6；区间≠合路柜；主贴 AH。  

8. **用 T 投诉结案顶界面会签**  
   现象：「投诉回函了，界面就算清。」  
   处置：规则6；投诉≠界面准用；主贴 AH。  

9. **分诊仪表过期仍出数**  
   现象：频谱仪 AD 准用期已过。  
   处置：AH6 拒认测值；换期内仪表重测（挂 AD）。  

10. **合路窗抬功率压登记失败**  
    现象：上行失败被写成覆盖病。  
    处置：AH-治 禁功率战；先 AH/N/S；上行抽测。  

11. **增业主端口未走 J**  
    现象：私自加端口后「网管更绿」。  
    处置：挂 J；评估后 AH 再分诊/再验（常挂 S/T）。  

12. **公开群发业主名与端口曲线**  
    现象：含可定位机房信息。  
    处置：AH-治 规则8；撤回；L3 重发教学版。

## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 一句话（教学） |
|------|----------------|
| **合路/POI** | 多业主信号物理汇合的合路器或 Point of Interface 柜 |
| **业主端口** | 某一业主馈入/馈出合路柜的端口角色 |
| **责任界面** | 端口侧/公共侧/馈线侧书面边界与主人 |
| **干扰分诊** | 按书面窗与方法定位合路相关干扰入口（非投诉全文） |
| **底噪** | 接收机噪声底；合路/PIM 问题常先抬上行底噪 |
| **PIM** | 无源互调；多载波合路处非线性产物（公开常识词） |
| **AH-合** | 合路/POI 台账与端口贴签钉死 |
| **AH-界** | 责任界面有主人有书面边界 |
| **AH-诊** | 分诊窗与方法、到场齐全 |
| **AH-验** | 本组本机房本期实测禁套；单边≠整段 |
| **AH-治** | 假绿、顶替、套曲线、功率战、泄密治理 |
| **假绿** | 系统/大屏显示正常，但无本期分诊会签 |
| **套曲线** | 把他业主他期记录改号当本期 |
| **单边绿** | 只验一家端口却宣称整段合路过 |
| **九字合路钉** | 合界窗法房边签闭密（教学记忆） |
| **与 S/AE/T 分工** | 邻频 / 区间换乘 / 投诉证据；AH 管合路界面门卫 |
| **隔离端口观察** | 分诊方法角色项：临时隔离某端口看底噪/话务变化（以本网规程为准） |
| **合用电梯隐喻** | 柜里有≠界面清；谁按谁修要有书面主人 |

**易错观念**

- ❌「网管绿=合路界面过」→ ✅ 假绿挂 R，主贴 AH。  
- ❌「S/AE/T 签=永远不用贴 AH」→ ✅ 均不顶替 AH 本期。  
- ❌「室分复测绿=合路界面过」→ ✅ AB≠AH。  
- ❌「拷邻业主曲线更快」→ ✅ 禁套；本窗本组本机房实测。  
- ❌「单边绿整段过」→ ✅ 相关端口齐+会签。  
- ❌「合路抖就抬功率」→ ✅ 禁功率战；先 AH/N/S。

9. 大屏网管全绿想签界面准用，应挂什么提醒？主贴谁？  
10. 室分复测 AB 绿了，能不能代替 AH 合路界面准用？  
11. 私自增业主端口或改合路衰减后应走什么变更贴纸并怎样处理？  
12. 公开材料能不能贴真实业主单位名与机房全称？依据哪条规则？

### 参考答案

1. **合**（合路台账端口）、**界**（界面主人边界）、**诊**（分诊窗与方法）、**验**（本期本组实测）、**治**（假绿顶替套曲线功率战泄密）。  
2. **AH-合**（亦可答界：无主人则界面不清）。  
3. **规则1**。  
4. 合路/PIM/隔离不足常先抬上行底噪；上行更先掉；空口台阶（12.5 kHz/4FSK/2-slot）没变，先证界面/分诊再谈射频，避免误开功率战。  
5. **合路台账、界面主人、本组本机房本期实测、会签**（规则1–5；九字钉核心）。  
6. **规则6**；主贴仍是 **AH**。  
7. **S 邻频边界、AE 区间换乘、T 投诉证据、AH 管合路·界面·分诊能不能签准用**。  
8. **AH-治**（验）；**不能**。  
9. 挂 **R**；主贴 **AH**（规则6）。  
10. **不能**；室分复测≠合路界面准用。  
11. **J**，并重开 AH 分诊/验收窗（规则7；常挂 S/T/N）。  
12. **不能**；**规则8 脱敏 L3**。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AH** 五子类：合 / 界 / 诊 / 验 / 治——双字母续写的第八张，负责合路·界面·分诊「台账清不清、界面有没有主、本期过了没有」。  
- 故事：商场/医院共享楼宇合用电梯机房「谁按谁修」+ 合用配电间责任界面——柜里有设备≠界面清；网管绿≠分诊过；套邻业主曲线=拒签；S/AE/T 不顶替 AH；单边绿≠整段过。  
- 阶段梯：建合路账 → 钉界面主人 → 分诊窗钉死 → 本期实测 → 会签放行 → 变更再验。  
- 八条硬规则：**合路/POI 台账与业主界面钉死**；**责任界面有主人**；**干扰分诊窗与方法钉死**；**本组本机房本期实测禁套他业主他期（单边≠整段）**；**会签才放行**；**禁顶替 S/AE/T/AB 等，主贴 AH，假绿≠放行挂 R**；**合路窗禁功率战、监控风暴挂 N、变更走 J**；**脱敏 L3**。
