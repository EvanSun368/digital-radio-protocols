## 8. 术语表（本篇约 18 词）+ 易错观念

| 词 | 本篇用法（教学） |
|----|------------------|
| **AO** | 本篇贴纸：漏水·汇排·巡检边界 |
| **AO-漏** | 漏水探测点/排水路径/地漏与告警台账 |
| **AO-汇** | 机房侧汇流排/等电位主人与准用期/测点 |
| **AO-巡** | 巡检窗与方法（漏痕/湿度指针/紧固/连续性） |
| **AO-验** | 本组本机房本期实测、会签 |
| **AO-治** | 假绿、顶替、伪造、旁路探头、切断等电位、功率战、泄密治理 |
| **排水路径** | 漏水从探测点到地漏/集水的路径角色（教学；本网定义） |
| **机房侧汇流排** | 机房内等电位/接地汇流排巡检对象；**不等于** AM 的天馈接地抽检准用 |
| **等电位连接** | 机房侧导电部分电位均衡连接（故事类比借医院 OR/ICU；门限以本网为准） |
| **测点** | 汇排/等电位巡检与抽测的固定角色点 |
| **探头在≠合格** | 漏水探头存在不等于台账齐、不等于本期巡检过 |
| **螺丝在≠合格** | 汇排紧固件在不等于等电位合格、不等于本期抽测过 |
| **假绿** | 监控绿但无本期秩序实证；挂 R |
| **套票** | 套他站他期照片/曲线当本期 |
| **功率战** | 用抬功率压告警/压掉话；漏水告警窗也禁止 |
| **L3** | 脱敏等级：禁真实频点/站名/全称/点位号全文/汇排号全文/单位名/联系人 |
| **AM / AI / AN / N / R / J** | 天馈接地浪涌 / 温湿度 / 门禁访客 / 风暴 / 假绿 / 变更——指针，不重写 |
| **十字漏汇钉** | 漏、汇、窗、法、房、测、签、闭、密、界 |

**易错观念**  
- ✗ 漏水探头在 = 巡检合格 → ✓ 要有账、排水路径、本期实测。  
- ✗ 汇流排螺丝在 = 等电位合格 → ✓ 要有主人、测点、准用期、本期抽测。  
- ✗ 监控绿 = 本期实测过 → ✓ 要有书面巡检窗与方法留痕。  
- ✗ 温湿度过 / 天馈接地过 / 门禁过 = 漏水汇排过 → ✓ AI / AM / AN ≠ AO。  
- ✗ 邻站照片能用 → ✓ 套票拒签。  
- ✗ 漏水告警先抬功率 → ✓ 先 N 后 AO，禁功率战。  
- ✗ 旁路探头/切断等电位消告警 → ✓ 红线，禁止；本篇不教手法。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AO** 五子类：漏 / 汇 / 巡 / 验 / 治——双字母续写的第十五张，负责漏水·汇排「台账清不清、汇排有没有测、本期过了没有」。  
- 故事：医院手术室/ICU 机房漏水告警与等电位接地汇流排巡检——漏水探头在≠巡检合格；汇流排螺丝在≠等电位合格；温湿度绿≠漏水巡检过；AM 天馈接地准用≠机房侧汇排巡检过；监控绿≠本期实测过；套邻站巡检照片=拒签；AN/AM/AL/AK/AI/AH/AF/AD/AA/N 不顶替 AO；假绿≠会签放行。  
- 阶段梯：建漏水台账 → 钉汇排主人 → 巡检窗钉死 → 本期实测 → 会签放行 → 变更再验。  
- 八条硬规则：**漏水探测点/排水路径/地漏与告警台账钉死**；**接地汇流排/等电位连接有主有准用期/测点**；**巡检窗与方法钉死**；**本组本机房本期实测禁套他站他期**；**会签才放行「漏水/汇流排巡检准用」**；**禁顶替 AN/AM/AL/AK/AI/AH/AF/AD/AA/N 等，主贴 AO，假绿≠放行挂 R**；**漏水告警风暴/浸水风险挂 N、漏水点位/汇流排改造/门限变更走 J、禁功率战**；**脱敏 L3**。  
- **AO vs AM**：AM = 天馈接地与 SPD 抽检准用；AO = 机房漏水探测台账 + 机房侧汇流排巡检边界。
