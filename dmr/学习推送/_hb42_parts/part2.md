## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **漏水探测点/排水路径/地漏与告警台账钉死**：探测点、排水路径、地漏与告警入账；禁「探头在就能签」「口头说一声」。  
2. **接地汇流排/等电位连接有主有准用期/测点**：每条机房侧汇流排、每组等电位连接有主人角色、有准用期、有测点；禁「螺丝在就算」「只看外观绿」。  
3. **巡检窗与方法钉死**：书面固定；方法含目视漏痕、湿度联锁指针、汇流排紧固/连续性抽测等（**门限以本网为准**）；禁「下雨再说」「只看监控绿」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、照片、曲线必须本期本组本机房；套邻站账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「漏水/汇流排巡检准用」；假绿 ≠ 放行。  
6. **禁顶替 AN/AM/AL/AK/AI/AH/AF/AD/AA/N，主贴 AO，假绿≠放行挂 R**：门禁签、天馈接地签、气灭签、温湿度签、合路签、仪表签都不顶本期漏水汇排签。  
7. **漏水告警风暴/浸水风险挂 N，漏水点位/汇流排改造/门限变更走 J，禁功率战**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/漏水点位编号全文/汇流排编号全文/可还原坐标与联系人**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签漏水汇排准用、无实测冒充巡检过，不是法外运维智慧**。医院手术室/ICU 漏水与等电位公开资料、数据中心漏水探测/汇流排公开科普只作故事与方法类比（§2.2）：**漏要约、汇要测、巡要窗、验要实测、监控绿不算过**——翻译成本网语言就是 AO-漏 / AO-汇 / AO-巡 / AO-验 / AO-治。**这些是漏水汇排巡检边界秩序，不是「探头在就签」「螺丝在就算」「抬功率压告警」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「漏水/汇流排巡检准用」、对外宣传「分钟级一键漏水秒过」、把未实测写成已过。允许做的：补漏水台账、补汇排测点、重开巡检窗、重实测、挂 R/N/J、内部挂整改。

|------------|------|------|

| 「温湿度绿了，漏水也算过」 | 温湿度≠漏水 | 温湿度 **AI**；漏水仍 **AO** |
| 「天馈接地刚签，汇排免测」 | AM≠AO | 天馈/SPD **AM**；机房侧汇排仍 **AO** |
| 「门禁交底过了，巡检也免」 | 门禁≠漏水汇排 | 门禁 **AN**；巡检仍 **AO** |
| 「仪表还在准用期内」 | AD 只答设备准用 | **AD** 支撑；主窗仍 **AO** |

### 4.7 台账路径（一窗漏水/汇排巡检跑完）

1. 开窗：核对书面巡检窗与到场角色  
2. 对账：AO-漏 台账 vs 现场探测点/排水路径；AO-汇 汇排清单 vs 测点/准用期  
3. 巡检：按本网方法做目视漏痕/湿度指针/汇排紧固·连续性抽测等（**不写死门限数值**）  
4. 留痕：本期本组本机房记录；禁套声明勾选  
5. 分诊：异常 → 挂整改；漏水告警风暴/浸水 → N；假绿嫌疑 → R；变更需求 → J；湿度相关可挂 AI；天馈/SPD 另窗走 AM  
6. 会签：准用或有条件整改；交班口述未闭项

### 4.10 漏水 / 汇排 / 巡检与 AO 的咬合（教学直觉，门限以本网为准）

- **漏水探头在 ≠ 巡检合格**：要有台账、排水路径、本期实测。  
- **汇流排螺丝在 ≠ 等电位合格**：要有主人、测点、准用期、本期抽测。  
- **监控绿 ≠ 本期实测过**：要有书面巡检窗与方法留痕。  
- **温湿度过 ≠ 漏水巡检过**：AI 与 AO 各管各的。  
- **AM 天馈接地准用 ≠ 机房侧汇排巡检过**：AM 与 AO 各管各的。  
- **门禁过 ≠ 漏水汇排过**：AN 与 AO 各管各的；进机房仍要 AN。  
- **气灭过 ≠ 漏水过**：AL 与 AO 各管各的。  
- **仪表在期内 ≠ 本期巡检窗可免**：AD 只答设备准用期。  
- **监控绿 ≠ 漏水汇排准用过**：N 绿不顶 AO。  
- **门限、合格判据、巡检窗长度、抽测清单以本网制度/合同为准**——本篇不发明数值与条款号；公开漏水/汇排资料只借秩序直觉。

### 4.11 与门禁（AN）/ 天馈接地（AM）/ 气灭（AL）/ 爬塔（AK）/ 温湿度（AI）/ 合路（AH）/ 油机（AF）/ 仪表（AD）/ 首年（AA）/ 监控（N）怎么配合

进机房做漏水/汇排巡检常见组合：**AN** 办门禁访客 → **AO** 办漏水汇排巡检 → 湿度异常可挂 **AI** → 天馈/SPD 另窗走 **AM** → 漏水告警风暴/浸水挂 **N** → 点位/汇排/门限变更走 **J**。温湿度巡检窗与漏水巡检窗可同日不同贴，**互不顶替**；湿度指针可挂 AI，漏水台账仍 AO。天馈接地抽检：AM 管准用，**机房侧汇排巡检边界仍 AO**。

### 4.12 漏水告警窗与上行更脆直觉

漏水浸设备、汇流排松动/断档、等电位劣化、漏水告警风暴掩盖真实浸水路径，常先让设备与空口变「脆」：掉电、误告、掉话——手台功率小、天线短，**上行往往比下行先不够用**。现场第一反应不该是抬功率，而该是：

```text
  漏水告警风暴 / 浸水风险 / 汇排异常
       │
       ├─→ 告警风暴？ → 挂 N 理风暴（对时/风暴秩序）
       ├─→ 漏水/汇排台账与本期实测清不清？ → 主贴 AO
       ├─→ 湿度联锁？ → 可挂 AI（支撑）
       ├─→ 天馈/SPD？ → 另窗 AM（不顶替）
       ├─→ 有人要抬功率？ → 禁功率战
       └─→ 要改点位/汇排/门限？ → 走 J + 再验
```

12.5 kHz / 4FSK / 2-slot TDMA 的窄车道里，乱抬功率只会先伤邻道与自身秩序；**先问 AO 秩序，再谈覆盖病（X/I 指针）**。

## 6. 工作实例（12 则，教学虚构，L3）

1. **探头在拒签**：脱敏机房-07 漏水探头在，无排水路径台账页 → AO-漏拒签「漏水/汇流排巡检准用」；允许补账，不允许口头顶过。  
2. **螺丝假绿**：机房角色-B 汇流排螺丝在，无本期测点抽测记录 → 挂 R，补 AO-汇/巡后再谈会签。  
3. **套邻站照片**：外包拷邻站上周漏水巡检照片改机房号交差 → AO-验拒签，责令本期本组本机房重开实测。  
4. **温湿度顶漏水**：班长称「AI 温湿度签还在，漏水也能签」→ 拒签；环境过≠漏水过；主贴仍 AO。  
5. **天馈接地顶汇排**：AM 天馈接地浪涌会签在有效窗，想顺带签机房侧汇排巡检 → 拒签；AM≠AO；各管各的。  
6. **门禁顶巡检**：AN 门禁陪同交底过，想免做漏水汇排巡检 → 拒签；门禁过≠漏水汇排过；进机房仍要 AN，巡检仍要 AO。  
7. **仪表顶窗**：AD 测阻仪仍在准用期内，外包想免做巡检窗 → 拒签；AD 只支撑设备准用，不顶 AO 窗。  
8. **旁路探头**：有人想旁路漏水传感器消告警 → **禁**；挂整改 + N/R；本期实测未做不得签准用。  
9. **点位变更未走 J**：私自改漏水点位布局未走变更 → 补走 J，触发再验 AO；未闭前禁签准用。  
10. **浸水风暴抬功率**：漏水告警一片，网优想抬功率压掉话 → **禁功率战**；先 N 后 AO；上行更脆先问秩序。  
11. **首年日历挂项**：AA 首年巡检日历到了「漏水/汇排抽检」项，但缺汇排测点页 → 日历可挂 AA，缺页整改主贴仍 AO。  
12. **群泄密**：宣传岗把真实机房漏水点位编号与汇流排编号发群表扬 → L3 违规，撤帖脱敏重发；治理勾 AO-治。
