- **R / J / X / I**：假绿挂 R；变更（漏水点位布局、汇流排改造、巡检门限）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 AO 证漏水/汇排秩序，再谈覆盖病**。

### 2.4 新贴纸 AO：漏 / 汇 / 巡 / 验 / 治（五个子类）

> 小彩蛋：双字母贴纸续写——**AA** 首年巡检；**AB** 室分复测；**AC** 机动开撤；**AD** 备件金机；**AE** 区间联测；**AF** 油机市电；**AG** 电池充电器；**AH** 合路/POI 界面；**AI** 温湿度联锁；**AJ** 天馈驻波；**AK** 爬塔交叉；**AL** 气灭疏散；**AM** 接地浪涌；**AN** 门禁访客；**AO** 管「机房漏水与接地汇流排巡检边界」。A–Z 既有含义不改；新专题用 AA、AB、AC… 续写。

```text
                ┌──────────── 贴纸 AO · 漏/汇/巡/验/治 ────────────┐
                │  AO-漏  漏水：探测点/排水路径/地漏与告警台账钉死   │
                │  AO-汇  汇排：机房侧汇流排/等电位有主有准用期测点 │
                │  AO-巡  巡检：窗·方法钉死（漏痕/湿度指针/紧固测） │
                │  AO-验  验收：本组本机房本期实测·禁套他站他期     │
                │  AO-治  治理：假绿·顶替AN/AM/AI·伪造·旁路·泄密   │
                └──────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签触发 |
|------|--------|--------------|
| **AO-漏** | 无漏水台账、排水路径未入账仍准用 → 拒签 | 「探头在就能签」「口头说一声」 |
| **AO-汇** | 汇流排无主人、无测点、无准用期、只看螺丝在 → 拒签 | 「螺丝在就算」「只看外观绿」 |
| **AO-巡** | 无书面巡检窗/方法、只听口头或套监控绿 → 拒签 | 「下雨再说」「监控绿当过」 |
| **AO-验** | 套他站他期照片/曲线、无会签 → 拒签 | 「邻站巡检照片拷过来改机房号」 |
| **AO-治** | 假绿、用 AN/AM/AL/AK/AI/AH/AF/AD/AA/N 顶替、旁路探头、切断等电位、功率战、泄密 → 治理 | 「AM 签还在，汇排也能过」 |

### 2.5 建漏水台账 → 钉汇排主人 → 巡检窗钉死 → 本期实测 → 会签放行 → 变更再验 阶段梯（背下来）

```text
  ① AO-漏 建漏水台账：探测点角色 · 排水路径角色 · 地漏/告警角色 · 禁「探头在就能签」「口头说一声」
        │  无账 / 路径未入 / 告警断档 → 不签漏水/汇流排巡检准用
        ▼
  ② AO-汇 钉汇排主人：机房侧汇流排角色 · 等电位连接角色 · 准用期 · 测点 · 禁「螺丝在就算」
        │  无主人 / 无测点 / 无准用期 → 拒进入「可签」状态
        ▼
  ③ AO-巡 钉巡检窗：书面窗 · 方法（目视漏痕、湿度联锁指针、汇排紧固/连续性抽测等） · 到场角色 · 门限以本网为准
        │  无窗 / 「监控绿当过」 → 拒巡检签
        ▼
  ④ AO-验 本组本机房本期实测：实测记录 · 禁套他站他期照片/曲线 · 会签
        │  套票 / 只看监控绿 → 拒签
        ▼
  ⑤ 会签「漏水/汇流排巡检准用」或「有条件整改」：本网授权本人签
        │  缺签 / 假绿顶替 → 拒签准用
        ▼
  ⑥ 变更（漏水点位布局/汇流排改造/巡检门限）→ 走 J + 触发再巡/再验（常挂 N 看漏水风暴、挂 AI 看湿度联锁、挂 AD 看测阻仪）
```

> **一句话分辨**：**AM** 回答「天馈接地与 SPD **过了没有**」；**AI** 回答「温湿度联锁**清不清**」；**AN** 回答「门禁访客陪同**清不清**」；**N** 回答「告警风暴**理不理**」；**AO** 回答「这一机房漏水探测 + 这一组机房侧汇流排 + 这一窗巡检**台账清不清、汇排有没有测、本期过了没有**」。**五个问题，五张（类）贴纸，不能一笔带过。**  
> **AO vs AM 钉死**：**AM** = 天馈接地与 SPD 抽检**准用**；**AO** = 机房漏水探测台账 + 机房侧汇流排巡检**边界**——汇流排二字看起来像接地，但本篇管的是**机房侧巡检边界与漏水咬合**，不顶替 AM 的天馈/SPD 抽检准用。

### 2.6 漏水与汇流排巡检最小工作流（背下来）

```text
  AO-漏 台账 + 探测点/排水路径/地漏告警钉死
       ├─→ 有账+路径？汇排有主人测点准用期？ ──否──→ 拒签 / 补账补汇
       └─→ 是
  AO-巡 约巡检窗 + 书面方法（目视漏痕/湿度指针/汇排紧固·连续性抽测）+ 到场勾选
       │
  AO-验 本组本机房本期：实测记录 → 禁套声明 → 留痕 → 会签
       │  套票 / 只看监控绿 → 拒签
       ▼
  会签「漏水/汇流排巡检准用」或挂整改；重大未闭禁签准用
       │
  放行或拒签；公开材料 L3；变更走 J 再触发；漏水告警风暴/浸水风险挂 N
```
