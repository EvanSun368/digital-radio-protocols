## 8. 术语表（本篇约 18 词）+ 易错观念

| 词 | 本篇用法（教学） |
|----|------------------|
| **AS** | 本篇贴纸：UPS 旁路·维护旁路·切换交底 |
| **AS-旁** | 旁路种类台账（静态·维护·环绕/外置） |
| **AS-维** | 维护旁路主人与窗/方法/准用期 |
| **AS-切** | 切换窗与书面方法（顺序以本网/OEM为准） |
| **AS-验** | 本组本机房本期实测、会签 |
| **AS-治** | 假绿、顶替、绕联锁、未授权乱切、功率战、泄密治理 |
| **静态旁路** | UPS 内部电子旁路路径角色（教学；**不等于**绿灯就能签准用） |
| **维护旁路** | 机械/外置路径，使 UPS 可隔离检修而负载仍可由旁路源供电（教学） |
| **环绕 / 外置旁路** | 整机外绕旁路柜/开关角色（有则入账；无则标不适用） |
| **旁路绿灯≠切换准用** | 旁路指示灯绿不等于按窗切换交底合格 |
| **合上≠窗过** | 维护旁路合闸看着合上不等于维护窗做完 |
| **AF 过≠AS 过** | 油机市电切换过不等于 UPS 旁路切换过 |
| **AG/AP 过≠旁路切换过** | 电池/内阻过不等于旁路切换过 |
| **假绿** | 旁路/监控绿但无本期秩序实证；挂 R |
| **套票** | 套他站他期曲线/照片当本期 |
| **功率战** | 用抬功率压告警/压掉话；旁路异常窗也禁止 |
| **L3** | 脱敏等级：禁真实频点/站名/全称/UPS 序列号全文/单位名/联系人/未脱敏旁路参数公开传播 |
| **AF / AG / AP / N / AN / AR / AD / R / J** | 油机市电 / 电池 / 内阻 / 风暴 / 门禁 / 通风燃油 / 仪表准用 / 假绿 / 变更——指针，不重写 |
| **十字旁切钉** | 旁、维、切、窗、房、测、签、闭、密、界 |

**易错观念**  
- ✗ 旁路绿灯 = 切换准用 → ✓ 要有账、本期切换实测。  
- ✗ 维护旁路合上 = 窗过 → ✓ 要有主人、窗、方法、准用期、本期核对。  
- ✗ 口头切换 = 方法过 → ✓ 要有书面切换窗与方法（以本网/OEM为准）。  
- ✗ AF 过 / AG/AP 过 / N 绿 = AS 过 → ✓ AF / AG / AP / N ≠ AS。  
- ✗ 邻站照片能用 → ✓ 套票拒签。  
- ✗ 旁路告警先抬功率 / 绕联锁消铃 / 未授权乱切 → ✓ 先 N 后 AS，禁功率战，禁绕联锁，禁未授权乱切。  
- ✗ 电池过可以顶旁路切换 → ✓ 各开各的窗；AG/AP≠AS。  
- ✗ 油机市电签可以顶 UPS 旁路签 → ✓ AF≠AS。  
- ✗ 油机房通风燃油过可以顶 UPS 旁路 → ✓ AR≠AS。

### 参考答案

1. 旁 / 维 / 切 / 验 / 治；口诀：**旁路有账，维护有窗，切换有法，会签才放。**  
2. 规则1；AS-旁。  
3. 规则2。  
4. 不能。合上≠窗过；旁路绿≠切换准用；需主人、窗/方法、准用期、本期实测（AS-维/切/验）。  
5. 不对。拒签；主贴 AS；假绿/顶替可挂 R。AF≠AS；AG/AP≠AS；N≠AS。

7. 先 N 理风暴；**禁功率战**；**禁绕旁路/安全联锁**；**禁未授权带电乱切**；缺旁路秩序整改主贴 AS。

11. 旁、维、切、窗、房、测、签、闭、密、界；几乎不可砍：**旁路台账 + 维护窗方法 + 切换方法 + 本组本机房本期实测 + 会签**。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AS** 五子类：旁 / 维 / 切 / 验 / 治——双字母续写的第十九张，负责 UPS 旁路·维护旁路切换「台账清不清、维护有没有窗、切换有没有法、本期过了没有」。  
- 故事：医院手术室/ICU 保供电机房 UPS——旁路绿灯≠切换准用；维护旁路合上≠窗做完；口头切≠方法过；AF 油机市电签≠ UPS 旁路准用；AG/AP 电池过≠旁路切换过；N 监控绿≠本期切换实测过；AN 门禁过≠旁路交底过；AR 通风燃油过≠ UPS 旁路过；套邻站照片=拒签；AF/AG/AP/AI/AO/AN/AD/AA/N/AQ/AR 不顶替 AS；假绿≠会签放行。  
- 阶段梯：建旁路台账 → 钉维护窗 → 切换方法钉死 → 本期实测 → 会签放行 → 变更再验。  
- 八条硬规则：**旁路种类台账钉死**；**维护旁路有主有窗有方法/准用期**；**切换窗与方法钉死**；**本组本机房本期实测禁套他站他期**；**会签才放行「UPS旁路与维护旁路切换准用」**；**禁顶替 AF/AG/AP/AI/AO/AN/AD/AA/N/AQ/AR 等，主贴 AS，假绿≠放行挂 R**；**旁路/切换异常风暴挂 N、旁路策略/切换规程变更走 J、禁功率战、禁绕旁路联锁、禁未授权带电乱切**；**脱敏 L3**。  
- **AS vs AF**：AF = 油机市电切换与供电巡检；AS = UPS 旁路台账 + 维护窗 + 切换方法 + 本期实测 + 会签；AF 过 ≠ AS 过。  
- **AS vs AG/AP**：AG/AP = 电池与内阻；AS = 旁路切换交底；电池过 ≠ 旁路切换过。  
- **AS vs N**：N = 电源监控/对时/告警风暴；AS = 旁路切换交底边界；N 绿 ≠ AS 过。  
- **AS vs AR**：AR = 油机房通风燃油；AS = UPS 旁路切换；AR 过 ≠ AS 过。
