- **AW（手册50）**：列头柜与末端配电巡检；**AW ≠ BC**——列头末端过≠机柜配电与PUE/负载分区过；列头/末端巡检可挂 AW，机柜PDU·PUE·负载分区主贴仍 BC；**不得用 BC 顶 AW，也不得用 AW 顶 BC**。  
- **AF（手册33）**：油机市电切换与供电巡检；**AF ≠ BC**——油机市电过≠机柜/PUE/分区过。  
- **AS（手册46）**：UPS 旁路；**AS ≠ BC**——旁路过≠机柜/PUE/分区过。  
- **AD（手册31）**：钳表/功率计/热成像仪入库走 AD；**不能**用旧 AD 签日期顶本期 BC 窗或实测窗。  
- **AN（手册41）**：门禁过≠机柜/PUE交底过；进机房仍要 AN；**不教绕过门禁/电气联锁**。  
- **AA（手册28）**：首年巡检日历；机柜/PUE/分区抽检可挂 AA，缺秩序整改主贴仍 BC。  
- **N（手册15）**：监控/对时/告警风暴；机柜/PUE/负载分区异常风暴挂 N 理风暴，**不先抬功率**；**禁绕电气联锁、禁未授权带电**；N 绿≠ BC 过。  
- **AQ（手册44）**：机柜/PUE/分区异常事件要调录像 → 另开 AQ；视频过≠BC 准用。  
- **AV / AR / AG / AP**：油品/燃油/电池/内阻；均不顶替 BC。  
- **AI / AT / AU / AO / AL / BB / AX / BA / AY / AZ**：环境与冷源侧；均不顶替 BC——BB 室外机冷凝侧过≠BC；AZ 冷通道进出风过≠BC。  
- **R / J / X / I**：假绿挂 R；变更（分区门限、能效窗方法、机柜/PDU角色）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 BC 证机柜配电与PUE/负载分区秩序，再谈覆盖病**。

## 3. 核心交付：插页 BC + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 BC（而不是先贴 AW / AF / AS / N）

- 要签「机柜配电与PUE/负载分区巡检准用」、要开机柜PDU/能效窗、要交底负载分区边界 → **主贴 BC**。  
- 列头柜与末端配电巡检本身 → **AW**（手册50）；机柜PDU·PUE·负载分区本体窗仍 BC。  
- 油机市电切换与供电巡检本身 → **AF**；机柜/PUE/分区仍 BC。  
- UPS 旁路本身 → **AS**；机柜/PUE/分区仍 BC。  
- 进机房做交底 → 先 **AN**；门禁过≠机柜/PUE交底过；**不教绕过门禁/电气联锁**。  
- 机柜/PUE/负载分区告警风暴 → 先 **N** 理风暴；缺机柜/PUE/分区秩序整改仍 **BC**；**禁功率战**；**禁绕电气联锁**；**禁未授权带电**。  
- 假绿/顶替 → 挂 **R**；变更分区门限/能效窗方法/机柜·PDU角色 → 走 **J** 后再验 BC。  
- 本站无独立机柜PDU/PUE/负载分区计量路径 → 书面勾「不适用」；**不得**用 BC 顶 AW 或 AF/AS。

### 3.4 与总三联单怎么写（脱敏 L3）

- **封面**：脱敏机房角色 + 本期相对期号 + 贴纸 BC + 「机柜配电与PUE/负载分区巡检交底」。  
- **现象栏**：只写角色与现象（如「机柜角色缺账」「PUE无窗」「分区无书面方法」「套票嫌疑」），**不写**真实机柜序列号全文、回路编号全文、门限可还原全文、单位名、联系人。  
- **动作栏**：补 BC-柜 / 补 BC-荷 / 补 BC-区 / 本期实测 / 会签 / 拒签挂改 / 挂 R / 挂 N / 走 J。  
- **边界栏**：勾清 AW/AF/AS/AD/AN/N——各过≠BC 过。  
- **会签栏**：准用 / 有条件整改 / 拒签；假绿 ≠ 会签放行。  
- **附件**：插页 BC1–BC8；AD 仪表准用指针（若用）；J 变更指针（若有）。
