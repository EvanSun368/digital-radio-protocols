> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：冷凝器与风冷空调公开概述强调**有账要验、风扇转≠准用、翅片看着干净≠窗过、边界要有书面方法、冷凝侧测点与净距要有本期核对秩序**（§10，**只借秩序直觉**；**本篇不写逐步关阀/开旁通/不安全泄冷媒操作教条**）；医院手术室/ICU 与数据中心风冷 CRAC outdoor / condenser 公开资料强调**环境绿≠室外机冷凝侧边界合格、压缩机/制冷剂过≠室外机本体窗过、机内冷凝排水过≠室外机冷凝侧窗过、冷冻水冷却塔过≠风冷室外机过、温湿度过≠冷凝侧测点窗过、滤网气流过≠室外机进出风净距过、冷通道封闭过≠室外机准用**（§10，**只作故事类比**）。本篇只借这串顺序——**本网室外机台账格式、冷凝侧窗方法、边界顺序与合格门限以本网制度、合同与 OEM 书面为准**。

### 2.3 和手册51（AX）/ 47（AT）/ 54（BA）/ 36（AI）/ 48（AU）/ 52（AY）/ 53（AZ）/ 42（AO）/ 41（AN）/ 15（N）/ 50（AW）等的咬合（指针，不重写）

- **AX（手册51）**：精密空调压缩机与制冷剂；**AX ≠ BB**——压缩机/制冷剂过≠室外机/冷凝侧边界过；机内冷媒回路可挂 AX，风冷室外机/冷凝侧主贴仍 BB。  
- **AT（手册47）**：机房内冷凝水与加湿除湿联锁；**AT ≠ BB**——机内冷凝/加湿过≠室外机冷凝侧（风冷冷凝器侧）窗过；机内冷凝排水可挂 AT，室外机冷凝侧主贴仍 BB。  
- **BA（手册54）**：冷冻水与冷却塔侧；**BA ≠ BB**——冷冻水/塔侧过≠风冷室外机/冷凝侧过；无塔/无冷冻水回路的风冷站主贴 BB，有塔/冷冻水回路主贴 BA；**不得用 BB 顶 BA，也不得用 BA 顶 BB**。  
- **AI（手册36）**：温湿度与空调联锁**巡检边界**；**AI ≠ BB**——AI 管温湿度测点/门限/联锁巡检秩序；**BB 管室外机台账·冷凝侧窗·室外机/冷凝侧边界交底准用**；温湿度过≠冷凝侧测点窗过；「环境绿」≠ BB 过。  
- **AU（手册48）**：滤网压差与气流组织；**AU ≠ BB**——机内滤网/压差/气流过≠室外机进出风净距/冷凝侧翅片窗过。  
- **AY（手册52）**：新风正压与防火阀；**AY ≠ BB**——新风正压/防火阀过≠室外机/冷凝侧过。  
- **AZ（手册53）**：冷通道封闭与机柜进出风；**AZ ≠ BB**——冷通道封闭/进出风过≠室外机/冷凝侧过；室内气流与室外机冷凝侧各管各的。  
- **AO（手册42）**：漏水探测与汇流排；**AO ≠ BB**——漏水过≠室外机/冷凝侧边界交底过。  
- **AN（手册41）**：门禁过≠室外机/冷凝侧交底过；进机房/上屋面室外机区仍要 AN；**不教绕过门禁/室外机联锁**。  
- **AW（手册50）**：列头柜与末端配电；**AW ≠ BB**——列头末端过≠室外机/冷凝侧过。  
- **AS / AF**：UPS 旁路 / 油机市电；供电过≠室外机/冷凝侧过。  
- **AD（手册31）**：温度计/净距尺/冷凝侧核对器具入库走 AD；**不能**用旧 AD 签日期顶本期 BB 窗或实测窗。  
- **AA（手册28）**：首年巡检日历；室外机/冷凝侧抽检可挂 AA，缺秩序整改主贴仍 BB。  
- **N（手册15）**：监控/对时/告警风暴；室外机/冷凝侧异常风暴挂 N 理风暴，**不先抬功率**；**禁关阀冒充、禁开旁通冒充、禁绕室外机联锁、禁不安全泄冷媒**；N 绿≠ BB 过。  
- **AQ（手册44）**：室外机/冷凝侧异常事件要调录像 → 另开 AQ；视频过≠BB 准用。  
- **AV / AR / AG / AP**：油品/燃油/电池/内阻；均不顶替 BB。  
- **R / J / X / I**：假绿挂 R；变更（边界门限、冷凝侧窗方法、室外机机位/回路角色）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 BB 证室外机/冷凝侧边界秩序，再谈覆盖病**。

### 2.4 新贴纸 BB：室 / 凝 / 界 / 验 / 治（五个子类）

> 小彩蛋：双字母贴纸续写——**AA** 首年巡检；**AB** 室分复测；**AC** 机动开撤；**AD** 备件金机；**AE** 区间联测；**AF** 油机市电；**AG** 电池充电器；**AH** 合路/POI 界面；**AI** 温湿度联锁；**AJ** 天馈驻波；**AK** 爬塔交叉；**AL** 气灭疏散；**AM** 接地浪涌；**AN** 门禁访客；**AO** 漏水汇排；**AP** 内阻核对；**AQ** 视频调阅；**AR** 油机房通风燃油；**AS** UPS 旁路；**AT** 冷凝加湿联锁；**AU** 滤网压差气流；**AV** 日用油箱油品净化加油；**AW** 列头柜与末端配电巡检；**AX** 精密空调压缩机与制冷剂边界；**AY** 新风正压与防火阀；**AZ** 冷通道封闭与机柜进出风；**BA** 冷冻水与冷却塔侧边界；**BB** 管「机房风冷室外机与冷凝侧边界」（**BA 之后第一张 BB**）。A–Z 既有含义不改；新专题用 AA、AB、AC… 续写。
