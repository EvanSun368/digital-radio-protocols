## 8. 术语表（本篇约 18 词）+ 易错观念

| 词 | 本篇用法（教学） |
|----|------------------|
| **室外机侧** | 机位、回路、风机翅片等室外机本体角色集合；主贴 BB-室 |
| **冷凝侧** | 翅片清洁、进出风净距、冷凝侧测点等风冷冷凝器侧角色；主贴 BB-凝 |
| **机位角色** | 脱敏后的室外机安装位身份标签；禁写编号全文 |
| **风机翅片角色** | 室外机风机与翅片换热面角色入账；风扇转≠台账过 |
| **进出风净距** | 室外机进风/排风与障碍物的书面净距核对；以本网与 OEM 为准 |
| **冷凝侧窗** | 冷凝侧维护/核对的书面时间窗与方法；翅片看着干净≠窗过 |
| **冷凝侧测点** | 冷凝侧温度/压差等核对测点角色；门限以本网与 OEM 书面为准 |
| **边界窗** | 室外机与机内冷媒/室内侧交界的书面核对窗；主贴 BB-界 |
| **机内冷媒边界** | 与 AX 压缩机制冷剂的分工交界；AX 过≠BB 过 |
| **关阀冒充** | 用关闭阀门消告警冒充边界过；**本篇硬禁** |
| **开旁通冒充** | 用旁通让读数「看着绿」冒充可过；**本篇硬禁** |
| **绕室外机联锁** | 绕过室外机保护/联锁冒充可过；**本篇硬禁** |
| **本期实测** | 本组本机房本相对期的实测；禁套他站他期 |
| **会签放行** | 授权角色会签后才可称准用；假绿≠放行 |
| **假绿** | 表面绿/灯绿/风扇转冒充准用；挂 R |
| **贴纸 BB** | 本篇主贴；室/凝/界/验/治五子类 |
| **AX≠BB / BA≠BB** | 压缩机制冷剂过≠室外机冷凝侧过；冷冻水冷却塔过≠风冷室外机过 |
| **脱敏 L3** | 对外不出现可还原站/机房/回路编号与门限全文 |
| **不适用声明** | 本站无风冷室外机时的书面勾选；不得顶 BA/AX |

**易错观念（打叉）**  
- ✗ 风扇转 = 室外机准用 → ✓ 要有台账与本期实测。  
- ✗ 翅片看着干净 = 冷凝侧窗过 → ✓ 要有主人窗方法准用期。  
- ✗ AX/AT/BA/AI/AU/AY/AZ 签可顶 BB → ✓ 各管各的，主贴 BB。  
- ✗ 关阀/开旁通/绕联锁消告警可签 → ✓ 硬禁；挂 N/R。  
- ✗ N 监控绿可免实测 → ✓ N 绿≠BB 过。  
- ✗ 无风冷室外机也可用 BB 顶 BA → ✓ 勾不适用；不得顶 BA/AX。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **BB** 五子类：室 / 凝 / 界 / 验 / 治——双字母续写在 BA 之后的第一张 **BB**，负责机房风冷室外机与冷凝侧「台账清不清、冷凝侧有没有窗、边界有没有法、本期过了没有」。  
- 口诀：**室外机有账，冷凝侧有窗，边界有法，会签才放。**  
- 故事：医院手术室/ICU 风冷精密空调室外机与冷凝侧（或数据中心风冷 CRAC outdoor unit / condenser side）——风扇转≠准用；翅片看着干净≠窗过；口头说冷凝侧正常≠方法过。  
- 八条硬规则：**室外机侧台账钉死**；**冷凝侧有主有窗有方法/准用期**；**边界窗与方法钉死**；**本期实测禁套**；**会签才放行**；**禁顶替 AX/AT/BA/AI/AU/AY/AZ/AO/AN/AA/N/AQ/AW/AF/AS/AD/AV/AR/AG/AP，主贴 BB，假绿≠放行挂 R**；**异常风暴挂 N、变更走 J、禁功率战/关阀/旁通/伪造台账/绕联锁/不安全泄冷媒**；**脱敏 L3**。  
- **BB 不替代 AX，也不替代 AT，也不替代 BA，也不替代 AI，也不替代 AU，也不替代 AY，也不替代 AZ**：AX=压缩机制冷剂；AT=机内冷凝加湿；BA=冷冻水冷却塔；AI=温湿度联锁巡检；AU=滤网压差气流；AY=新风正压防火阀；AZ=冷通道封闭进出风；BB=风冷室外机与冷凝侧边界交底准用。
