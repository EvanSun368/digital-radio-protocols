## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **室外机侧台账钉死**：机位角色、回路角色、风机翅片角色入账（编号脱敏）；禁「风扇转就算过」「口头说室外机正常」。  
2. **冷凝侧有主有窗有方法/准用期**：翅片清洁/进出风净距/冷凝侧测点等以本网与 OEM 书面为准；每次冷凝侧相关维护有主人角色、有书面窗、有方法、有准用期；禁「翅片看着干净当窗过」。  
3. **室外机与机内冷媒/室内侧边界窗与方法钉死**：书面固定；方法含室外机与机内冷媒/室内侧交界核对、与 AX/AT/AI/AU/BA 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明逐步关阀/开旁通/不安全泄冷媒操作教条）；禁「窗再说」「关阀冒充可过」「开旁通冒充可过」「绕室外机联锁」「不安全泄冷媒」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、室外机表、冷凝侧表必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「机房风冷室外机与冷凝侧边界准用」；假绿 ≠ 放行。  
6. **禁顶替 AX/AT/BA/AI/AU/AY/AZ/AO/AN/AA/N/AQ/AW/AF/AS/AD/AV/AR/AG/AP，主贴 BB，假绿≠放行挂 R**：压缩机制冷剂签、机内冷凝加湿签、冷冻水冷却塔签、温湿度签、滤网气流签、新风正压防火阀签、冷通道进出风签、漏水签、门禁签、首年签、监控签、视频签、列头末端签、旁路签、油机签、仪表签、油品签、通风燃油签、电池签、内阻签都不顶本期室外机冷凝侧签。  
7. **室外机/冷凝侧异常风暴挂 N，边界/门限变更走 J，禁功率战；禁关阀冒充；禁开旁通冒充可过；禁伪造台账；禁绕室外机联锁；禁不安全泄冷媒教条**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/回路编号全文/可还原坐标与联系人；禁公开传播未脱敏冷凝侧门限与边界参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签室外机冷凝侧准用、无实测冒充边界过、关阀/开旁通冒充可过、绕室外机联锁、不安全泄冷媒冒充秩序齐，不是法外运维智慧**。医院风冷室外机/冷凝侧、数据中心风冷 CRAC outdoor / condenser 公开资料只作故事与方法类比（§2.2）：**室要约、凝要窗、界要法、验要本期、风扇转不算过、翅片看着干净不算窗过、关阀旁通绕联锁不算办法**——翻译成本网语言就是 BB-室 / BB-凝 / BB-界 / BB-验 / BB-治。**这些是机房风冷室外机与冷凝侧边界交底秩序，不是「风扇转就签」「翅片看着干净当过」「抬功率压告警」「关阀消告警」「开旁通冒充」「绕联锁先过」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机房风冷室外机与冷凝侧边界准用」、对外宣传「风扇转/翅片看着干净秒过」、把未实测写成已过、把关阀/开旁通/绕联锁写成秩序齐。允许做的：补室外机台账、补冷凝侧窗、重开边界窗、挂 R/N/J、内部挂整改。

### 4.7 台账路径（从发现到会签，教学骨架）

```text
  发现室外机/冷凝侧问题 → 主贴 BB
        ↓
  补 BB-室 室外机台账 / 补 BB-凝 冷凝侧窗 / 补 BB-界 边界方法
        ↓
  BB-验 本期实测（禁套）→ 勾清 AX/AT/BA/AI/AU/AY/AZ/AO/AN/N 边界
        ↓
  会签准用 / 拒签挂整改；假绿挂 R；风暴挂 N；变更走 J
```

> **路径口诀**：发现贴 BB → 补室补凝补界 → 本期实测禁套 → 边界勾清 → 会签才放 / 拒签挂改。

## 6. 工作实例（12 则，教学虚构，L3）

1. **风扇转想签准用**：运维以「风扇在转」申请准用 → 班长翻 BB1 无室外机侧台账 → **拒签**；补室侧台账与本期核对后再议。  
2. **翅片看着干净顶冷凝侧窗**：外包称「翅片挺干净」→ BB2 无主人无窗 → **拒签**；补冷凝侧窗方法。  
3. **AX 签顶 BB**：班长想用 AX 压缩机制冷剂签顶本期 BB → **拒签顶替**；可挂 R；主贴仍 BB。  
4. **AT 顶室外机冷凝侧**：机内冷凝加湿签在，想免室外机冷凝侧窗 → AT≠BB；冷凝侧仍要 BB2。  
5. **BA 顶风冷室外机**：冷冻水冷却塔刚过想免风冷室外机 → BA≠BB；风冷路径仍 BB（或勾不适用后不得顶 BA）。  
6. **AI 顶冷凝侧测点**：温湿度绿想免冷凝侧测点窗 → AI≠BB；测点窗仍 BB。  
7. **AU/AY/AZ 顶室外机**：滤网气流/新风正压/冷通道刚过想免室外机 → AU≠BB、AY≠BB、AZ≠BB；室外机仍 BB。  
8. **N 绿免实测**：大屏环境绿想免本期实测 → N≠BB；BB4 本期实测必做。  
9. **套邻站冷凝侧表**：外包拷邻站室外机/冷凝侧表改机房号 → **BB-验 拒签重测**。  
10. **关阀消告警**：外包关阀消冷凝侧告警后申请准用 → **禁**；挂 N/R；禁签准用。  
11. **开旁通 / 绕联锁冒充**：旁通开后读数「看着绿」或绕室外机联锁想先过 → **禁**；挂整改。  
12. **公开群贴回路编号**：新人把真实回路编号与冷凝侧门限发工作群 → **L3 违规**；撤回脱敏；挂治。

> 十二则共性：**主贴 BB；风扇转≠准用；翅片看着干净≠窗过；他贴不顶替；套票拒签；关阀/旁通/绕联锁禁；假绿挂 R；风暴挂 N；变更走 J；脱敏 L3。**
