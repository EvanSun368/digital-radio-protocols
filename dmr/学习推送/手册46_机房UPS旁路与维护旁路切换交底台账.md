## 1. 为什么要写这篇手册（动机 + 现场对话）

前四十五篇手册从 A–E 协议一路写到 AR 油机房通风燃油：其中 **AF 回答「油机市电切换与机房供电巡检」**，**AG 回答「电池与充电器梯队」**，**AP 回答「内阻与核对性放电」**，**AI 回答「温湿度与空调联锁」**，**AO 回答「漏水与接地汇流排」**，**AN 回答「门禁与访客陪同」**，**AD 回答「备件仪表准用」**，**AA 回答「交维后首年巡检」**，**N 回答「电源监控/对时/告警风暴」**，**AQ 回答「视频监控调阅与证据链」**，**AR 回答「柴油发电机房通风排烟与燃油安全」**。可还没有单独钉死一件事——**机房 UPS 旁路与维护旁路切换不是「旁路绿灯就能签」：旁路种类台账要钉死（静态旁路·维护旁路·环绕/外置旁路角色）；维护旁路要有主人有窗有方法有准用期；切换窗与方法要书面固定；本组本机房本期实测禁套他站他期——能不能签「UPS旁路与维护旁路切换准用」？** 这就是本篇的 **AS**——**机房 UPS 旁路与维护旁路切换交底台账**。

- 运维岗：「旁路还亮着绿灯，切换交底就算齐了。」——**无旁路台账/无本期切换实测仍准用** = 本篇拒签（规则1）。  
- 外包：「维护旁路合上了，窗肯定做完了。」——**合上当窗过** = 规则2。  
- 物业：「切换方法口头说一声就行。」——**无书面切换窗方法** = 规则3。  
- 外包：「邻站上周旁路切换照片参数差不多，拷过来改个机房号。」——**套他站他期** = 规则4。  
- 班长：「AF 油机市电签还在，AG/AP 电池也过了，UPS 旁路也能签。」——**用 AF/AG/AP/AI/AO/AN/AD/AA/N/AQ/AR 顶替 AS** = 规则6。  
- 站务：「大屏 UPS 旁路监控绿了，旁路切换准用就算过。」——**假绿≠会签放行** = 规则5/6。  
- 网优：「UPS 旁路/市电直通告警一片，功率抬一点稳住业务。」——**功率战** = 规则7（无关也写禁，系列一致）。  
- 宣传岗：「把真实 UPS 序列号、旁路柜编号发群表扬。」——**L3 违规** = 规则8。  

这几句背后是同一件事：

> **「机房 UPS 旁路与维护旁路切换」在现场至少有五个坑**：**① AS-旁** 旁路种类台账钉死（静态旁路·维护旁路·环绕/外置旁路角色），禁「旁路绿灯就能签」「口头说一声」；**② AS-维** 维护旁路有主人、有窗、有方法、有准用期，禁「维护旁路合上当窗过」；**③ AS-切** 切换窗与方法钉死（先静态/内旁再维护旁路等；顺序以本网与 OEM 书面为准），禁「口头切换」「未授权带电乱切」；**④ AS-验** 本组本机房本期实测（禁套他站他期曲线/照片），会签才放行「UPS旁路与维护旁路切换准用」；**⑤ AS-治** 治理（假绿、用 AF/AG/AP/AI/AO/AN/AD/AA/N/AQ/AR 顶替、伪造旁路切换账、绕过旁路联锁、未授权带电乱切、功率战、泄密）。

## 2. 总图 / 故事：UPS 旁路像「医院手术室/ICU 保供电机房 UPS——不能只看旁路绿灯」

### 2.1 一句话：旁路绿灯不是「可以签准用」、维护旁路合上不是「窗做完了」、监控绿不是「本期切换实测过了」——要先建旁路种类台账，维护旁路有主人有窗有方法有准用期，切换窗与方法钉死，本组本机房本期实测，会签才放行；假绿、套邻站照片、用 AF/AG/AP/AI/AO/AN/AD/AA/N/AQ/AR 顶替，一律拒签

   ┌──────────────────────────────────────────────────────────────┐
   │  医院手术室/ICU 保供电机房 UPS 旁路切换  =  本网 AS           │
   │                                                              │
   │  旁路种类台账钉死（静态·维护·环绕/外置） ≈ AS-旁  旁路有账   │

> **旁路有账，维护有窗，切换有法，会签才放。**  
> 旁路绿灯还无旁路台账/无本期切换实测 = 手术室保供电机房旁路灯亮从未建旁路账、从未按窗做切换交底——**拒签「UPS旁路与维护旁路切换准用」**。  
> 维护旁路合上当窗过 = ICU 保供电机房维护旁路合闸看着合上从未按书面窗与方法核对——**假绿，挂 R，拒签**。

- **AA（手册28）**：交维后**首年巡检**日历；旁路切换抽检可挂 AA，缺旁路秩序整改主贴仍 AS。  
- **N（手册15）**：监控/**对时**/告警风暴；旁路/切换异常风暴挂 N 理风暴，**不先抬功率**；**禁绕过旁路联锁、禁未授权带电乱切**；N 绿≠ AS 过。  
- **AQ（手册44）**：视频调阅；旁路切换事件要调录像另开 AQ；视频过≠旁路切换过。  
- **AR（手册45）**：油机房通风燃油；**AR ≠ AS**——油机房通风燃油过≠ UPS 旁路切换过；油机房与 UPS 机房各管各的。  
- **R / J / X / I**：假绿挂 R；变更（旁路策略、切换规程、维护旁路柜改造）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 AS 证旁路切换秩序，再谈覆盖病**。

### 2.4 新贴纸 AS：旁 / 维 / 切 / 验 / 治（五个子类）

> 小彩蛋：双字母贴纸续写——**AA** 首年巡检；**AB** 室分复测；**AC** 机动开撤；**AD** 备件金机；**AE** 区间联测；**AF** 油机市电；**AG** 电池充电器；**AH** 合路/POI 界面；**AI** 温湿度联锁；**AJ** 天馈驻波；**AK** 爬塔交叉；**AL** 气灭疏散；**AM** 接地浪涌；**AN** 门禁访客；**AO** 漏水汇排；**AP** 内阻核对；**AQ** 视频调阅；**AR** 油机房通风燃油；**AS** 管「机房 UPS 旁路与维护旁路切换」。A–Z 既有含义不改；新专题用 AA、AB、AC… 续写。

## 3. 核心交付：插页 AS + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AS（而不是先贴 AF / AG / AP / N）

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **旁路种类台账钉死**：机房角色、静态旁路 / 维护旁路 / 环绕（外置）旁路入账；禁「旁路绿灯就能签」「口头说一声」。  
2. **维护旁路有主有窗有方法/准用期**：每次维护有主人角色、有书面窗、有方法、有准用期；禁「维护旁路合上当窗过」。  
3. **切换窗与方法钉死**：书面固定；方法含切换顺序与核对项（**顺序以本网与 OEM 书面为准**；本篇不发明逐步带电操作教条）；禁「窗再说」「口头切」「未授权带电乱切」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、照片、读数必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「UPS旁路与维护旁路切换准用」；假绿 ≠ 放行。  
6. **禁顶替 AF/AG/AP/AI/AO/AN/AD/AA/N/AQ/AR，主贴 AS，假绿≠放行挂 R**：油机市电签、电池签、内阻签、温湿度签、漏水签、门禁签、仪表签、首年签、监控签、视频签、通风燃油签都不顶本期旁路切换签。  
7. **旁路/切换异常风暴挂 N，旁路策略/切换规程变更走 J，禁功率战；禁绕过旁路/安全联锁；禁未授权带电乱切旁路**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/UPS 序列号全文/可还原坐标与联系人；禁公开传播未脱敏旁路柜编号与切换参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签旁路切换准用、无实测冒充切换过、绕联锁冒充秩序齐，不是法外运维智慧**。医院保供电 UPS 公开资料、厂商静态旁路/维护旁路公开科普只作故事与方法类比（§2.2）：**旁要约、维要窗、切要法、验要本期、灯绿不算过**——翻译成本网语言就是 AS-旁 / AS-维 / AS-切 / AS-验 / AS-治。**这些是 UPS 旁路与维护旁路切换交底秩序，不是「旁路绿就签」「合上当过」「抬功率压告警」「绕联锁」「未授权乱切」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「UPS旁路与维护旁路切换准用」、对外宣传「旁路一合切换秒过」、把未实测写成已过、把绕联锁写成秩序齐。允许做的：补旁路台账、补维护窗、重开切换窗、挂 R/N/J、内部挂整改。

### 4.3 「UPS旁路与维护旁路切换准用」最小集（AS）——缺页不能签准用

1. 旁路种类台账页（静态·维护·环绕/外置）  
2. 维护旁路主人与书面窗、方法、准用期页  
3. 书面切换窗与方法页（顺序以本网与 OEM 为准）  
4. 本期本组本机房实测记录（禁套声明）  
5. AF 油机市电边界勾选（防顶替；AF 过≠AS 过）  
6. AG/AP 电池/内阻边界勾选（防顶替；电池过≠旁路切换过）  
7. N 风暴边界勾选（防顶替；N 绿≠AS 过）  
8. AN 门禁边界勾选（若进人：先 AN；门禁过≠旁路交底过）  
9. AR 通风燃油边界勾选（若同站：AR 过≠AS 过）  
10. AD 仪表准用指针（若用，支撑）  
11. 会签页（准用或有条件整改）  
12. 未闭项清单（有则挂整改，重大未闭禁签准用）  
13. 脱敏勾选（L3）  
14. 变更指针（若本期有旁路策略/切换规程变更 → J）

> **口诀**：旁、维、切、窗、房、测、签、闭、密、界——**十字旁切钉**（教学记忆；现场以本网书面规程为准，但 **旁路台账 + 维护窗方法 + 切换方法 + 本组本机房本期实测 + 会签** 几乎不可砍）。

- [ ] 维护旁路角色入账  
- [ ] 环绕/外置旁路角色入账（若有）

## 6. 工作实例（12 则，教学虚构，L3）

1. **旁路绿灯就要签准用** → 拒签；补 AS-旁台账与本期实测。  
2. **维护旁路合上当窗过** → 拒签；补 AS-维主人/窗/方法。  
3. **切换口头说一声** → 拒签；补 AS-切书面方法。  
4. **套邻站旁路切换照片改机房号** → AS-验 拒签重测。  
5. **AF 油机市电签顶本期旁路签** → 拒签顶替；AF≠AS；可挂 R。  
6. **AG/AP 电池签顶旁路切换** → 拒签；电池过≠旁路切换过。  
7. **N 监控绿免本期实测** → 拒签；N≠AS。  
8. **旁路告警抬功率** → 挂 N；**禁功率战**；缺秩序整改 AS。  
9. **绕旁路联锁消告警** → **禁**；挂 N/R；禁签准用。  
10. **未授权带电乱切旁路** → **禁**；挂整改；本篇不教逐步乱切。  
11. **进机房门禁过了就当旁路交底过** → AN 过≠AS 过；补 AS。  
12. **公开群贴真实 UPS 序列号** → L3 违规；撤帖脱敏；AS-治。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AS** 五子类：旁 / 维 / 切 / 验 / 治——双字母续写的第十九张，负责 UPS 旁路·维护旁路切换「台账清不清、维护有没有窗、切换有没有法、本期过了没有」。  
- 故事：医院手术室/ICU 保供电机房 UPS——旁路绿灯≠切换准用；维护旁路合上≠窗做完；口头切≠方法过；AF 油机市电签≠ UPS 旁路准用；AG/AP 电池过≠旁路切换过；N 监控绿≠本期切换实测过；AN 门禁过≠旁路交底过；AR 通风燃油过≠ UPS 旁路过；套邻站照片=拒签；AF/AG/AP/AI/AO/AN/AD/AA/N/AQ/AR 不顶替 AS；假绿≠会签放行。  
- 阶段梯：建旁路台账 → 钉维护窗 → 切换方法钉死 → 本期实测 → 会签放行 → 变更再验。  
- 八条硬规则：**旁路种类台账钉死**；**维护旁路有主有窗有方法/准用期**；**切换窗与方法钉死**；**本组本机房本期实测禁套他站他期**；**会签才放行「UPS旁路与维护旁路切换准用」**；**禁顶替 AF/AG/AP/AI/AO/AN/AD/AA/N/AQ/AR 等，主贴 AS，假绿≠放行挂 R**；**旁路/切换异常风暴挂 N、旁路策略/切换规程变更走 J、禁功率战、禁绕旁路联锁、禁未授权带电乱切**；**脱敏 L3**。  
- **AS vs AF**：AF = 油机市电切换与供电巡检；AS = UPS 旁路台账 + 维护窗 + 切换方法 + 本期实测 + 会签；AF 过 ≠ AS 过。  
- **AS vs AG/AP**：AG/AP = 电池与内阻；AS = 旁路切换交底；电池过 ≠ 旁路切换过。  
- **AS vs N**：N = 电源监控/对时/告警风暴；AS = 旁路切换交底边界；N 绿 ≠ AS 过。  
- **AS vs AR**：AR = 油机房通风燃油；AS = UPS 旁路切换；AR 过 ≠ AS 过。

### 11.3 给带新人的三句话
1. 旁路不是绿灯就能签：旁路有账，本期切换实测钉死。
