## 1. 为什么要写这篇手册（动机 + 现场对话）

前二十九篇手册从 A–E 协议一路写到 AB 室分复测：其中 **V 回答「重大活动设备检没检、贴没贴」**，**Y 回答「贴签与准入台账齐不齐」**，**Z 回答「固定站开站交维签没签清」**，**U 回答「执照 / 许可边界在不在」**，**K 回答「写频参数角色对不对」**。可还没有单独钉死一件事——**应急通信车 / 机动中继 / COW 类快速开站，开之前要先证什么？冒烟测过了才能放行吗？开了几天怎么撤？和固定站交维是不是一回事？趴窝变「准固定」要不要走 AB/J？** 这就是本篇的 **AC**——**应急通信车 / 机动站快速开站与撤收边界**。

- 项目经理：「执照在仓库复印件有，先开着，明天补手续。」——**无许可/临时设台边界仍开站** = 本篇拒开（规则1）。  
- 司机：「上次那辆车的检测贴签还能看清，撕下来贴这辆。」——**套他车他场过期贴** = 规则5。  
- 写频员：「临时活动信道我昨天写过别的车，克隆一份。」——**套他车写频 / 角色不符** = 规则1 / 规则5（回挂 K）。  
- 网管：「屏全绿、远程看一眼，手台可以进网了。」——**假绿顶替本车本期冒烟测** = 规则2 / 规则6。  
- 协调岗：「撤场了当没开过，临时增益先留着下次省事。」——**口头撤、不清场、不回写** = 规则4。  
- 班长：「机动站开了两周，等于固定站交维完了，别再折腾签字。」——**用 AC 临时开站顶 Z 交维** = 与 Z 分工不清。  
- 施工队：「天线临时拧高一点、功率抬一档压邻居。」——**功率战** = 规则7。  
- 宣传岗：「把车号、临时频点、摆车坐标发群里表扬响应速度。」——**L3 违规** = 规则8。  

这几句背后是同一件事：

> **「应急通信车 / 机动站快速开站与撤收」在现场至少有五个坑**：**① AC-开** 开站前先证（许可/临时设台或既有机动边界、检测贴签、写频、场地停车摆位、电源接地、天线安全）；**② AC-验** 本车本期上下行冒烟测最小集才可签「机动站可放行」；**③ AC-撤** 撤收清场清单齐才签「撤完」；禁口头撤、禁留临时增益/功率未回写；**④ AC-界** 与固定站 Z 交维分工；许可/贴签/写频/场地边界；趴窝变准固定回挂 AB/J；**⑤ AC-治** 治理（假绿、套他车、无台账、功率战、泄密）。  
> 把 ①–⑤ 当成「先开着再说」「屏绿就能放行」「撤了当没开过」，每一次重大活动、每一次灾害机动、每一次临时补盲，都会先吵「到底有没有许可、谁签的放行、撤完没有、临时参数回没回写」。

本篇目标：能背出**机动站开撤工作流**；会用新贴纸 **AC（开 / 验 / 撤 / 界 / 治）**；会填**插页 AC（AC1–AC8）**和《本网应急通信车/机动站开撤台账卡》；能用「**消防车出警：到场摆车 → 出水前点检 → 撤场收装归位**」故事讲清先证再开、点检才出水（放行）、撤场必须归位台账；能拒绝无许可先开、假绿放行、套他车贴、口头撤、功率战；自测过关后，回库把本网最近一次机动开站（L3）重对一遍：开站前证照链、冒烟测、放行签、撤收清场与回写。

**本篇硬禁令（写进脑子）**：凡引法规与标准只指向已公开发布的文书标题与官方链接（无线电管理条例、频率使用许可管理办法、地面无线电台（站）管理规定、国无办〔2025〕1号；**只作故事类比**的消防车出警摆车/出水前点检/撤场归位公开直觉，以及公开的 COW / 便携中继 / 应急通信部署资料），**程序、期限、责任以原文与属地最新要求及本网制度 / 合同为准，本篇只作教学转述，不发明条款号与内部口径**；消防车出警与境外 COW/Deployable 公开资料**不是**中国专网台站法定依据；**现象与台账一律用相对道号、角色标签、脱敏编号，禁真实频点 / 站名 / 单位名 / 车号全文 / 坐标 / 联系人**；**不教伪造开站记录、不教功率战、不教规避监测、不教无许可先开站、不教假绿顶替、不教套他车过期贴**；V / Y / Z / U / K / Q / J / S / T / R / X / AA / AB 各管各的——**机动快速开撤边界主贴 AC**；ITU 应急电信、DHS COW/便携中继、FirstNet Deployable 等公开资料只借**部署秩序与清场意识**，**许可、贴签、写频、放行与撤收签字以本网制度与属地要求为准**。

## 2. 总图 / 故事：机动开撤像「消防车出警：到场摆车 → 出水前点检 → 撤场收装归位」

### 2.1 一句话：应急车开站不是「车到了就能出水」——要先有出警许可与摆位边界，出水前必须点检（冒烟测），撤场必须收装归位留台账；固定站交维像「这座消防站长期建成验收」，机动开站像「这辆车今晚这一趟出警」

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  消防车出警摆车+点检+撤场  =  本网应急车/机动站开站+放行+撤收 │
   │                                                              │
   │  出警许可·停车摆位·水源边界 ≈ AC-界  许可·贴签·写频·场地     │
   │  到场摆车·架梯·接水带       ≈ AC-开  摆车·架天线·上电·接地   │
   │  出水前点检·试压·沟通       ≈ AC-验  本车本期上下行冒烟测    │
   │  允许出水 / 指挥下达        ≈ AC-验→放行  签「机动站可放行」 │
   │  撤场收装·归位·出警记录     ≈ AC-撤  清场清单·回写·台账归档 │
   │  无证出水·假绿·留临时接头   ≈ AC-治  假绿·套贴·口头撤·功率战 │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **先证再摆，点检才放，撤清才签，禁套他车。**  
> 车到了就放行手台 = 消防车到场不点检就出水——**拒签「机动站可放行」**。  
> 撤场当没开过、临时增益留着 = 水带接头扔现场、压力阀不回位——**拒签「撤完」**。

### 2.2 「消防车出警摆车 + 点检 + 撤场」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **边界** | 出警权限、停车位、水源与周边安全距离书面清楚 | 频率/执照/临时设台或既有机动许可、检测贴签、写频角色、场地停车与共址预案 | AC-界 |
| **开站** | 到场摆车、架梯、接水带、启动泵组 | 摆车、架天线、馈线、市电/油机、接地防雷直觉、上电 | AC-开 |
| **点检/放行** | 出水前点检、试压、与指挥沟通确认可出水 | 本车本期上下行冒烟测最小集通过 → 签「机动站可放行」 | AC-验 |
| **撤收** | 收装水带、归位阀门、清点器材、出警记录归档 | 天线馈线电源频点临时增益回写、日志归档、备件/金机回库指针 | AC-撤 |
| **治理** | 无证出水、用他车器材顶、假绿、留临时接头不回位 | 假绿、套他车贴、口头撤、功率战、公开泄密 → 拒签 / 治理 | AC-治 |

> 公开文书与公开部署资料告诉我们（**教学转述，以原文为准**）：应急出动讲究**许可边界、到场展开、使用前确认、撤场归位与记录**；境外 COW / Deployable / 便携中继公开资料强调**可运输、可快速部署、供电与回传、事后回收**（出处见 §10）。本篇只借这串顺序直觉——**本网机动开站许可、贴签、写频、放行与撤收以属地要求与本网制度为准，消防车故事与境外 Deployable 资料不是台站法定依据**。

### 2.3 和手册22 / 23 / 26 / 27 / 08 / 11 / 19 / 20 / 21 / 25 / 28 / 29 等的咬合（指针，不重写）

- **U（手册22）/ V（手册23）**：执照、临时设台或既有机动许可边界是 AC-界 的**前置**；无边界先回 U/V，不急着 AC-开。  
- **Y（手册26）**：检测贴签与准入台账是 AC 开站前的**贴签链**；重大活动场次常与 Y 同场咬合——Y 管「机子检了没、准入账在不在」，AC 管「这辆车本期开没开、放没放、撤没撤」。  
- **Z（手册27）**：**固定站**开站验收与交维签字；**AC ≠ Z**——机动快速开撤不能顶替固定站交维，固定站交维也不能省略机动开站的本期冒烟测。  
- **K（写频相关篇）**：写频与参数角色是 AC-界 / AC-开 前置；禁套他车码片不经复核。  
- **Q / N**：金机、备件、联测窗可在撤收回库与共址预案时指针挂回。  
- **J（手册11）**：临时功率/增益/载频角色变更走 J；机动站**长期趴窝变准固定**须评估变更与复测（指针 AB）。  
- **S（手册20）/ T（手册21）**：与固定站共址临时邻居挂 S 预案；用户投诉挂 T；禁功率战。  
- **R（手册19）**：屏绿 ≠ 已开站可放行；挂 R 提醒，主贴 AC。  
- **X（手册25）**：若机动开站需要环境报告类证据，方法级指针回 X；**日常冒烟测最小集仍是 AC-验 本职**。  
- **AA / AB**：首年巡检与室分复测管固定侧长期秩序；机动趴窝变准固定时，**触发复测 / 变更回挂 AB/J**，不是 AC 单独能「永久化」。

### 2.4 新贴纸 AC：开 / 验 / 撤 / 界 / 治（五个子类）

> 小彩蛋：双字母贴纸续写——**AA** 管「交维后首年还在保的巡检与尾项」；**AB** 管「室分 / 隧道电磁环境还合不合格」；**AC** 管「应急车 / 机动站这一趟开没开清、放没放清、撤没撤清」。A–Z 既有含义不改；新专题用 AA、AB、AC… 续写。

```text
                ┌──────────── 贴纸 AC · 开/验/撤/界/治 ────────────┐
                │  AC-开  开站展开：摆车·架天线·上电·接地·馈线     │
                │  AC-验  本期实测：上下行冒烟测·两时隙·驻波直觉   │
                │  AC-撤  撤收清场：天线馈线电源·频点回写·台账归档 │
                │  AC-界  边界前置：许可·贴签·写频·场地·与Z分工   │
                │  AC-治  治理：假绿·套贴·口头撤·功率战·泄密       │
                └──────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒开 / 拒放行 / 拒撤签触发 |
|------|--------|--------------------------------|
| **AC-界** | 无许可/贴签/写频/场地边界仍要开 → 拒开 | 「执照复印件在仓库」 |
| **AC-开** | 摆车架设上电缺项、天线不安全仍要冒烟 → 停在开 | 「天线先凑合绑一下」 |
| **AC-验** | 无本车本期冒烟测、假绿、套旧测 → 拒放行 | 「远程屏绿就放行」 |
| **AC-撤** | 清场不全、临时增益未回写、口头撤 → 拒签撤完 | 「撤了当没开过」 |
| **AC-治** | 套他车、功率战、公开泄密、无台账 → 治理 | 「他车贴撕过来」 |

### 2.5 先证边界 → 开站展开 → 冒烟放行 → 执勤 → 撤收签字 阶段梯（背下来）

```text
  ① AC-界 先证：许可/临时设台或机动边界 · 贴签Y · 写频K · 场地停车
        │  缺任一项 → 拒开（不是「先开着补」）
        ▼
  ② AC-开 展开：摆车 · 架天线 · 馈线 · 市电/油机 · 接地防雷直觉
        │  安全与缺项未清 → 停在开，不进验
        ▼
  ③ AC-验 本车本期冒烟测最小集（上下行·两时隙·驻波直觉）
        │  跨网可疑 → 挂 S；投诉 → 挂 T；参数不符 → 挂 U
        ▼
  ④ 通过 + 授权签字 → 签「机动站可放行」（有主人、有时限）
        │  假绿/旧测/他车测 → 拒放行
        ▼
  ⑤ 执勤窗内：台账在线；重大变更走 J；超时/趴窝评估 AB/J
        ▼
  ⑥ AC-撤 清场清单齐 + 回写 + 归档 → 签「撤完」
        │  口头撤 / 留临时增益 / 无台账 → 拒签撤完
        ▼
  ⑦ 金机/备件回库指针（Q）· 日志归档 · 交班口述
```

> **一句话分辨**：**Z** 回答「这座**固定站**交维签没签清」；**Y** 回答「这台机**检测贴签与准入**齐不齐」；**V/U** 回答「**许可 / 活动检测**边界在不在」；**AC** 回答「这辆应急车 / 这座机动中继**这一趟**开没开清、放没放清、撤没撤清」。**四个问题，四张贴纸，不能一笔带过。**

```text
       │过
       ▼
  签「可放行」+ 主人 + 时限写入台账
       │
       ▼
  执勤（变更走J；共址挂S；投诉挂T；假绿挂R）
       │
       ▼
  AC-撤 清场+回写+归档 ──不齐──→ 拒签撤完
       │齐
       ▼
  签「撤完」· 回库指针 · 交班
```

## 3. 核心交付：插页 AC + 拒开/拒放行/拒撤签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AC（而不是先贴 Z / Y / V / U）

| 场景 | 主贴 | 为什么 |
|------|------|--------|
| 应急车 / 机动中继 / 临时补盲站**这一趟**要开、放、撤 | **AC** | 本篇主职 |
| 固定楼站开站交维签字 | **Z** | 长期交维 ≠ 机动开撤 |
| 重大活动设备检测贴签与准入台账 | **Y**（常与 AC 同场） | Y 管贴签准入；AC 管开撤放行 |
| 执照/临时设台/既有机动许可边界不清 | **U / V** 先 | 边界是 AC-界 前置 |
| 写频参数角色不对 | **K** 先 | 写频是开站前置 |
| 屏绿想当已放行 | **AC-治 + R** | 假绿≠放行 |
| 与固定站共址吵起来 | **S** + 挂 AC | 跨网秩序 |
| 用户投诉「临时站没用」 | **T** | 投诉链；本网仍回 AC 台账 |
| 机动站趴窝变准固定 | **J + AB** 评估 | AC 不能永久化 |

### 3.2 插页 AC · 开 / 验 / 撤 / 界 / 治（挂在总三联单或开撤单后）

| 插页 | 检查项（教学） | 过闸？ |
|------|----------------|--------|
| **AC1** | 许可/临时设台或既有机动边界指针在（U/V）；本车/本站角色标识在 | 缺 → **拒开** |
| **AC2** | 检测贴签有效且与本车本场清单一致（Y）；禁套他车他场过期贴 | 缺/套 → **拒开** |
| **AC3** | 写频与参数角色复核在（K）；与许可边界一致 | 缺 → **拒开** |
| **AC4** | 场地停车摆位 / 市电油机 / 接地防雷直觉 / 天线架设安全勾选 | 缺 → **停在开** |
| **AC5** | 本车本期冒烟测最小集：下行、上行、两时隙、驻波直觉、测人/时间角色 | 缺 → **拒放行** |
| **AC6** | 「机动站可放行」签字：授权角色本人签；台账有主人、有时限 | 缺 → **拒放行** |
| **AC7** | 撤收清场：天线馈线电源、频点/临时增益/功率回写、日志归档、备件回库指针 | 缺 → **拒签撤完** |
| **AC8** | 脱敏 L3：公开材料无真实频点/车号全文/坐标/联系人；禁宣传「无证秒开」 | 违 → **治理** |

> 插页每一行都对应一条硬规则：AC1–AC3→规则1与规则5，AC5/AC6→规则2与规则3，AC7→规则4，AC8→规则8，假绿→规则6。**任何一行缺项，就停在那一行。**

### 3.3 和总三联单怎么写（接手册06）

- **现象栏**：写「机动开站缺项 / 冒烟测未过 / 撤收清场不齐」等角色描述；**禁**写真实频点、车号全文、坐标。  
- **贴纸栏**：主贴 **AC**；支撑可贴 Y / U / V / K / Z（对照）/ J / S / T / R。  
- **处置栏**：拒开 / 拒放行 / 拒撤签 / 补证 / 补测 / 清场回写 / 挂 S——**写动作，不写空口字段**。  
- **脱敏**：公开仓与交班群只留角色编号与相对道号。

### 3.4 《本网应急通信车/机动站开撤台账卡》预告

§7 给出可复印模板：封面拒签门槛、边界页、开站展开页、冒烟与放行页、撤收清场页、夜班速填五行。**一张卡跑完一趟开→放→撤**；与 Y 准入账、U/V 许可指针、K 写频单号角色对齐，避免「开了没账、撤了无痕」。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **先证：许可/临时设台或既有机动边界（U/V）、检测贴签与准入（Y）、写频角色（K）、场地停车摆位边界齐再开站；缺任一项 → 拒开**。  
2. **本车本期：须本车本期实测上下行冒烟测最小集（含两时隙与驻波直觉）才可签「机动站可放行」；禁套他车他场他期旧测；假绿/远程看一眼不等于放行**。  
3. **开站有台账有主人有时限：可放行必须写入台账卡（主人角色、执勤时限/撤收预计）；无主人无时限视为未闭环**。  
4. **撤收清场齐才签「撤完」：天线/馈线/电源/频点与临时增益功率回写/日志归档/备件回库指针；禁口头撤、禁「撤了当没开过」**。  
5. **禁套：禁套他车他场过期贴签、禁套他车写频不经复核、禁套旧冒烟测改日期；清单不符即拒开/拒放行**。  
6. **可挂 V/Y/U/K/Z/J/R/S/T/Q 支撑，但机动开撤主贴 AC；屏绿、假绿、远程一眼都不等于已开站可放行（挂 R 提醒）**。  
7. **跨网挂 S，用户投诉挂 T；禁功率战；参数/临时增益变更走 J；趴窝变准固定评估 AB/J**。  
8. **对外/公开仓一律脱敏 L3；禁贴真实频点/站名/单位名/车号全文/坐标/联系人**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可、地面无线电台（站）规定决定「能不能设、按什么参数设」——**机动开站不是法外之地，先开着补手续不是合法捷径**。消防车出警与境外 COW/Deployable 公开资料只作故事与部署秩序类比（§2.2）：**先边界、再展开、使用前确认、撤场归位留记录**——翻译成本网语言就是 AC-界 / AC-开 / AC-验 / AC-撤。**这些是开撤秩序，不是「无证先开」「假绿放行」「口头撤场」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机动站可放行」「撤完」「本次开站正常」、对外宣传「分钟级无证开站」、把未清场写成「已归位」。允许做的：补许可/贴签/写频、补冒烟测、挂 S/T/U、内部挂待开/待放行/待撤清。

### 4.2 分诊题：这件事贴 AC 还是贴别的？

| 现场问题 | 先问 | 主贴 |
|----------|------|------|
| 固定楼站交维签没签清 | 是否长期固定站 | **Z** |
| 活动设备检了没、准入账在不在 | 贴签与清单 | **Y**（常挂 AC） |
| 执照/临时设台边界在不在 | 许可链 | **U / V** |
| 写频对不对 | 参数角色 | **K** |
| 这辆车这一趟能不能开 | 先证是否齐 | **AC-界 → AC-开** |
| 能不能放行手台进网 | 本车本期冒烟测过没 | **AC-验** |
| 撤完没有、临时参数回没回 | 清场清单 | **AC-撤** |
| 屏绿想打勾放行 | 有无本期实测 | **AC-治 + R** |
| 和旁边固定站互相吵 | 是否跨网 | **S** + 挂 AC |
| 趴窝两周还当临时 | 是否准固定 | **J + AB** 评估 |

### 4.3 本车本期冒烟测最小集（AC-验）——缺页不能签「可放行」

| 序号 | 最小集项（教学） | 为什么必须有 | 缺了会怎样 |
|------|------------------|--------------|------------|
| 1 | **本车本期标识**（车/机动站角色 + 开站时段角色） | 防套他车他期 | 对不上 → 拒放行 |
| 2 | **下行抽测**（承诺区/关键点角色） | 「基站还说得出去」 | 缺 → 拒放行 |
| 3 | **上行边缘抽测** | 临时天线与手台上行常先塌 | 缺 → 拒放行（头号坑） |
| 4 | **两时隙抽测** | 2-slot TDMA 两格都要能用 | 只测一格 → 拒放行 |
| 5 | **天线驻波 / 馈线直觉检查勾选** | 临时架设最易驻波漂 | 「感觉响」不够 |
| 6 | **电源与接地勾选（挂 AC-开）** | 油机/市电不稳先拖垮上行 | 缺项停在开或拒放行 |
| 7 | **与许可/写频边界一致核对** | 防开错道、越界功率角色 | 不符 → 挂 U/K，拒放行 |
| 8 | **测人/时间角色 + 仪器有效期指针** | 可复核 | 「测过了」三个字不够 |
| 9 | **共址/邻居预案勾选（必要时挂 S）** | 临时邻居互调与抬噪 | 高风险场次缺预案 → 慎放行 |

> **口诀**：车、下、上、隙、驻、电、界、人、邻——**九字冒烟钉**（教学记忆；现场以本网书面机动开站规程为准，但 **本车本期 + 上下行 + 两时隙 + 驻波直觉** 几乎不可砍）。  
> **弱项短补（为什么机动站特别要盯上行与驻波）**：固定站天馈经年调试；机动站今晚才绑的天线、临时盘的馈线、油机电压一抖，**下行「听起来还行」、上行先不够用**。用户感受是「调度喊得到我，我喊不回调度」。**只扫下行或只看屏绿就放行，等于消防车到场不试水压、只看泵组指示灯绿。**

### 4.4 开站前先证与展开清单（AC-界 / AC-开）——缺页不能开

| 清单项（教学） | 像消防车故事里的 | 未齐就开？ |
|----------------|------------------|------------|
| 许可/临时设台或既有机动边界（U/V） | 出警权限 | **否** → 拒开 |
| 检测贴签有效且本车本场一致（Y） | 器材年检标 | **否** |
| 写频与参数角色复核（K） | 对讲频道与呼号约定 | **否** |
| 场地停车摆位 / 进出通道 | 停车位与水源位置 | **否**（不安全则停） |
| 市电 / 油机 / 油量 / 切换预案 | 泵组动力 | 缺 → 停在开 |
| 接地 / 防雷直觉（以本网规程为准） | 现场电气安全 | 缺 → 停在开 |
| 天线架设安全（高度、拉线、周边） | 架梯与作业安全 | 缺 → 停在开 |
| 共址邻居知情/预案（必要时 S） | 与周边单位协调 | 高风险场次倾向必有 |

### 4.5 撤收清场清单（AC-撤）——缺页不能签「撤完」

| 清场项（教学） | 像消防车撤场 | 未齐就签撤完？ |
|----------------|--------------|----------------|
| 天线降落 / 拆收 / 固定运输态 | 收梯收装 | **否** |
| 馈线 / 跳线 / 接头清点回装 | 收水带 | **否** |
| 电源断开、油机冷却归位、线缆回收 | 停泵收线 | **否** |
| 临时频点 / 临时增益 / 临时功率**回写** | 阀门回位 | **否**（头号坑） |
| 开站日志 / 冒烟测记录归档 | 出警记录 | **否** |
| 金机 / 备件 / 测试手台回库指针（Q） | 器材归库 | 缺指针 → 不签撤完 |
| 场地恢复（锥桶、占位、垃圾） | 现场清场 | 以本网/场地要求为准 |
| 台账卡签「撤完」+ 主人确认 | 归队销单 | 口头不算 |

> **口诀**：天线馈线电源回、参数回写账归档——**撤清七字钉**（教学；**回写**与**归档**几乎不可砍）。

### 4.6 与 Z 固定站开站交维的分工表（钉死，防互相顶替）

| 问题 | Z（手册27） | AC（本篇） |
|------|------------|------------|
| 对象 | 固定站长期开站与交维 | 应急车/机动站**这一趟**开撤 |
| 典型输出 | 交维签字、资料齐、试运行 | 「可放行」+「撤完」+ 开撤台账 |
| 前置 | U/X/S/K/N/J-Q 等阶段梯 | U/V/Y/K/场地 + 本车本期冒烟 |
| 能否互相顶替 | **不能**用机动开站台账顶交维 | **不能**用交维报告省略本期冒烟测 |
| 超时/趴窝 | 固定侧变更走 J、复测走 AB | 机动变准固定 → 评估 J/AB，退出「临时」口径 |

> **口诀**：Z 像消防站建成验收；AC 像今晚这一趟出警——**验收证不能当出警单，出警单也不能当建成证**。

### 4.7 台账路径（一趟机动开站跑完）

| 时点（教学） | 台账动作 | 主贴 |
|--------------|----------|------|
| 任务下达 | 建开撤台账卡；填车/站角色、预计时限、主人 | AC |
| 开站前 | AC1–AC4 先证与展开勾选；缺项拒开 | AC-界/开 |
| 冒烟后 | AC5 九字冒烟钉；通过→AC6 签可放行 | AC-验 |
| 执勤中 | 时限监控；变更走 J；共址挂 S；投诉挂 T | AC+支撑 |

| 回库 | 备件/金机指针；交班口述；公开材料 L3 | AC+Q |

### 4.8 签字前 15 分钟清单（可复印）

| 分钟 | 动作 |
|------|------|
| 0–3 | 打开台账卡：车/站角色、主人、时限、当前阶段（待开/待放行/执勤/待撤） |
| 3–6 | AC1–AC3：许可、贴签、写频是否本车本场本期 |
| 6–9 | AC4：摆车架设电源接地天线安全勾选 |
| 9–12 | AC5/AC6：九字冒烟钉是否本车本期；本人签可放行 |
| 12–15 | 若撤收：AC7 清场回写归档；拒签卡；交班口述；L3 |

夜班压缩版：至少确认「**先证齐 + 本车本期冒烟指针在 + 有主人有时限 + 撤则清场回写在**」四项——**四项缺一仍禁签可放行与撤完**。

### 4.9 「可放行」vs「待开/待撤清」状态表（钉死）

| 状态 | 含义（教学） | 允许对外口径（L3） |
|------|--------------|-------------------|
| 待开 | 先证或展开未齐 | 内部准备；禁宣传「已开站」 |
| 待放行 | 已展开、冒烟未过或未签 | 禁放行手台进网当正式 |
| 可放行 | 冒烟通过+本人签+台账有主人时限 | 可说「机动站按规程放行」（禁贴频点车号） |
| 待撤清 | 任务结束、清场未齐 | 禁签「撤完」；禁留临时参数 |
| 已撤完 | 清场回写归档齐 | 可内部销单；公开仍 L3 |
| 冻结 | 越界/干扰/安全项 | 禁功率战硬顶；挂 S/U/J |

> **口诀**：开、放、撤三段闸；**假绿与口头，过不了任何一闸**。

## 5. 现场映射：原话速查、对话脚本、夜班、禁写词、交班口述

### 5.1 原话 → 贴纸速查

| 你听到的原话 | 先贴 | 下一句该问 |
|--------------|------|------------|
| 「执照复印件在，先开着」 | AC-界 | 许可边界指针？临时设台/机动批复在？ |
| 「他车贴签撕过来贴」 | AC-治 | 本车本场有效贴？Y 准入账一致吗？ |
| 「屏绿了，手台进网吧」 | AC-验 + R | 本车本期上下行冒烟测指针？ |
| 「撤了当没开过」 | AC-撤 | 清场清单？临时增益回写了吗？台账呢？ |
| 「机动开三天等于交维了」 | AC-界 vs Z | 固定站还是机动这一趟？别混贴纸 |
| 「趴窝两周还临时着」 | J + AB | 是否触发准固定评估？ |
| 「功率抬一点压邻居」 | AC-治 + S | 禁功率战；跨网挂 S |
| 「车号频点发群表扬」 | AC-治 | 脱敏 L3；立刻撤回公开 |

### 5.2 三段对话脚本（可练）

**脚本 A · 拒开（先证不齐）**  
对方：「车到了，先开着，手续明天补。」  
你：「AC-界：许可/贴签/写频/场地四项，今晚缺哪项？缺一项我拒开，不是拒支援——是拒无边界发射。」

**脚本 B · 拒放行（假绿）**  
对方：「网管屏全绿，放行吧。」  
你：「AC-验：本车本期下行、上行、两时隙、驻波勾选在哪？假绿挂 R，主贴 AC；没有九字冒烟钉我拒签可放行。」

**脚本 C · 拒撤签（口头撤）**  
对方：「撤完了，临时增益先留着下次省事。」  
你：「AC-撤：天线馈线电源、参数回写、日志归档、回库指针——七字钉缺一不签撤完。留临时增益等于阀门不回位。」

### 5.3 夜班压缩卡（四问）

1. **界**：许可·贴签·写频·场地，本车本场本期齐不齐？  
2. **验**：九字冒烟钉指针在不在？谁签的可放行？时限到没到？  
3. **撤**：若任务结束，清场回写归档齐不齐？  
4. **治**：有没有套贴、假绿、功率战、公开泄密？

### 5.4 禁写词（三联单/交班）

- 禁：真实频点、车号全文、GPS 坐标、单位全称、联系人电话。  
- 禁：「先开着再说」「假绿也算」「撤了当没开过」「套他车贴」。  
- 改写：用角色编号、相对道号、阶段状态（待开/可放行/待撤清/已撤完）。

### 5.5 交班口述 30 秒模板

> 「AC 机动开撤：车/站角色××，阶段××；先证 AC1–3 ××；冒烟 AC5 ××；可放行签××、时限××；共址 S ××；待撤清项××；公开材料已 L3。下一班先对时限与清场回写。」

## 6. 工作实例（10 则，教学虚构，L3）

1. **无许可先开**  
   现象：重大活动前夜，项目经理要求「车到即开」。  
   处置：AC-界 拒开；补 U/V 许可指针与 Y 贴签后再进 AC-开。  
   教训：支援速度不等于无边界发射。

2. **套他车过期贴签**  
   现象：写频员把另一辆车的检测贴撕到本车。  
   处置：AC-治 + Y；清单不符拒开；重新本车检测贴签链。  
   教训：贴签跟人/车/场绑定，不跟「看起来像」。

3. **假绿放行**  
   现象：网管远程屏绿，班长签「可放行」。  
   处置：挂 R；撤销放行；补 AC-验 九字冒烟钉（尤其上行与驻波）。  
   教训：假绿≠出水点检。

4. **只测下行不测上行**  
   现象：下行场强「还行」，手台上行边缘全军覆没。  
   处置：拒放行；补上行与两时隙；弱项短补复盘。  
   教训：机动站上行更脆。

5. **口头撤场留临时增益**  
   现象：任务结束，天线收了，临时增益档位未回写。  
   处置：拒签撤完；强制回写并归档；交班点名。  
   教训：撤清七字钉，回写不可砍。

6. **用 AC 台账顶 Z 交维**  
   现象：固定楼站资料不齐，拿「应急车开过三天」交差。  
   处置：分诊回 Z；AC 只证明机动这一趟，不顶交维。  
   教训：出警单≠建成验收证。

7. **共址临时邻居功率战**  
   现象：与固定站互相抬功率压对方。  
   处置：禁功率战；挂 S；AC 台账记录联测窗指针；必要时降功率或改摆位（走 J）。  
   教训：跨网秩序大于「谁声音大」。

8. **写频克隆他车未复核**  
   现象：为赶时间克隆他车码片，载频角色与本场许可不符。  
   处置：拒开/拒放行；回挂 K/U；按本场边界重写并复核。  
   教训：克隆不是复核。

9. **趴窝变准固定不评估**  
   现象：机动中继在工地趴窝三周，仍称「临时」，从不复测。  
   处置：触发 J/AB 评估；退出纯 AC「临时」口径或补周期与变更。  
   教训：日历会揭穿「临时」。

10. **公开仓泄密**  
    现象：宣传岗把车号全文、摆车坐标、临时频点发到公开群。  
    处置：AC-治；撤回；L3 重发；三联单记治理。  
    教训：响应速度可以表扬，细节必须脱敏。

## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 一句话（教学） |
|------|----------------|
| **应急通信车** | 车载可机动展开的通信平台（中继/调度等角色以本网为准） |
| **机动站 / 机动中继** | 非永久固定、按任务开撤的中继或基站角色 |
| **COW 类** | 公开资料中的 Cell on Wheels 等可运输部署站；本篇借「可运、可开、可收」直觉，非法定标签 |
| **AC-界** | 开站前许可/贴签/写频/场地边界 |
| **AC-开** | 摆车架设上电等展开动作 |
| **AC-验** | 本车本期冒烟测与可放行签字 |
| **AC-撤** | 清场回写归档与撤完签字 |
| **AC-治** | 套贴、假绿、口头撤、功率战、泄密等治理 |
| **冒烟测最小集** | 开站后放行前的最小实测（上下行、两时隙、驻波直觉等） |
| **可放行** | 冒烟通过且授权本人签、台账有主人有时限 |
| **撤完** | 清场回写归档齐后的销单状态 |
| **假绿** | 监控屏/远程状态绿，但无本期实测支撑 |
| **套贴** | 把他车他场过期检测贴用到本车本场 |
| **回写** | 把临时频点/增益/功率等恢复到许可与基线 |
| **准固定** | 机动站超时趴窝，实际接近固定使用，须评估 J/AB |
| **与 Z 分工** | 固定交维 ≠ 机动开撤 |
| **九字冒烟钉** | 车下上隙驻电界人邻（教学记忆） |
| **撤清七字钉** | 天线馈线电源回、参数回写账归档（教学记忆） |

**易错观念**

- ❌「车到了就能放行」→ ✅ 先证再开，点检才放行。  
- ❌「固定站交维过了，机动不用测」→ ✅ Z 与 AC 不同对象。  
- ❌「撤了当没开过」→ ✅ 无台账的开站是治理项。  
- ❌「临时增益留着下次方便」→ ✅ 不回写不得签撤完。  
- ❌「屏绿 = 合格」→ ✅ 假绿挂 R，主贴 AC。

## 9. 自测（12 题）+ 参考答案

1. 贴纸 AC 五个子类是什么？各用四个字以内说明。  
2. 消防车出警故事里，「出水前点检」对应 AC 哪一段？  
3. 八条硬规则里，哪一条要求先证许可/贴签/写频/场地再开站？  
4. 九字冒烟钉里，为什么机动站特别不能省上行？  
5. 「可放行」至少要具备哪三样（除冒烟通过外）？  
6. 撤收时「临时增益先留着」能不能签撤完？为什么？  
7. AC 与 Z 的分工一句话？  
8. 套他车检测贴签，主贴什么？还能不能开？  
9. 屏全绿想放行，应挂什么提醒贴纸？主贴谁？  
10. 机动站趴窝三周仍称临时，应评估挂回哪两类指针？  
11. 跨网互相抬功率，违反哪条硬规则？应挂什么？  
12. 公开材料能不能贴车号全文与临时频点？依据哪条规则？

### 参考答案

1. **开**（展开摆车架设）、**验**（本期冒烟放行）、**撤**（清场回写）、**界**（许可贴签写频场地）、**治**（假绿套贴功率战泄密）。  
2. **AC-验**（点检才出水 ≈ 冒烟测才放行）。  
3. **规则1**。  
4. 临时天馈与手台上行余量小，下行「还行」常掩盖上行先塌。  
5. **授权本人签字**、**台账主人**、**执勤时限**（规则3）。  
6. **不能**；违反规则4，回写是撤清不可砍项。  
7. **Z 管固定站交维；AC 管机动这一趟开撤**——互不顶替。  
8. **AC-治（+Y）**；**拒开**。  
9. 挂 **R**；主贴 **AC**（规则6）。  
10. **J** 与 **AB**（准固定/变更复测评估）。  
11. **规则7**；挂 **S**，禁功率战。  
12. **不能**；**规则8 脱敏 L3**。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AC** 五子类：开 / 验 / 撤 / 界 / 治——双字母续写的第三张，负责应急车/机动站「这一趟开没开清、放没放清、撤没撤清」。  
- 故事：消防车出警——到场摆车 → 出水前点检 → 撤场收装归位；固定站交维像消防站建成验收，不能和出警单混用。  
- 阶段梯：先证边界 → 开站展开 → 冒烟放行 → 执勤（有主人有时限）→ 撤收清场回写 → 归档销单。  
- 八条硬规则：**先证再开**；**本车本期冒烟才放行**；**有台账有主人有时限**；**撤清才签撤**；**禁套他车他场**；**主贴 AC，假绿≠放行**；**跨网挂 S、禁功率战、变更走 J**；**脱敏 L3**。

### 11.2 下一篇手册候选（本篇不写正文）
- **备件周转与金机轮换台账**（与 Q/AA/K/AC 咬合：金机、备件、开撤回库、复测漂移后基线更新）  
- **隧道/地铁区间联测与换乘责任界面**（与 AB/I/S 咬合）  
- **油机/市电切换与机房供电巡检边界**（与 AC 展开电源勾选、AA 巡检咬合，仍 L3）

### 11.3 给带新人的三句话
1. 应急车开站不是法外之地：许可、贴签、写频、场地先齐，再谈摆车架天线。  
2. 屏绿不能出水：本车本期上下行冒烟测过了，有主人有时限，才能签可放行；撤场必须回写清场留台账。  
3. 机动开撤 ≠ 固定交维；假绿挂 R；禁套他车；禁功率战；跨网挂 S；公开脱敏；主贴 AC。
