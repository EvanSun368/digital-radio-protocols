## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 本篇用法（教学） |
|------|------------------|
| **AU** | 本篇贴纸：精密空调滤网·压差·气流组织交底 |
| **AU-滤** | 滤网台账（初效·中效·回风·压差表） |
| **AU-压** | 压差有主有窗有方法准用期 |
| **AU-气** | 气流组织窗与书面方法（冷热通道、盲板、方向证明等） |
| **AU-验** | 本组本机房本期实测·禁套·会签 |
| **AU-治** | 假绿·顶替·绕联锁·旁通滤网·功率战·泄密治理 |
| **精密空调 / CRAC** | 机房专用温湿度控制单元；本篇钉滤网压差与气流组织交底，不替代 AI 温湿度巡检，也不替代 AT 冷凝加湿 |
| **滤网压差 / ΔP** | 滤网前后压差角色；外观干净≠压差准用；门限以本网与 OEM 书面为准 |
| **压差表/开关** | 监测滤网压差的仪表/开关角色；读数要有窗有方法 |
| **冷热通道** | 机柜冷风进/热风出通道组织；口头说顺≠方法过 |
| **盲板 / 封堵** | 机柜空位封堵角色；缺失可致气流短路（以本网书面为准） |
| **旁通滤网** | 擅自拆/旁通滤网冒充风量/准用——**本篇禁** |
| **气流组织准用** | 会签后允许宣称本期滤网压差气流交底合格；假绿≠准用 |
| **假绿** | 监控绿/滤网干净/滤网在冒充准用；挂 R |
| **套票** | 套他站他期曲线/照片；AU-验拒签 |
| **L3** | 对外脱敏等级：禁真实站名/全称/序列号/单位名/联系人 |
| **AI / AT / AO / N** | 温湿度 / 冷凝加湿 / 漏水汇排 / 监控风暴——均不顶替 AU |
| **R / J** | 假绿挂 R；变更走 J 后再验 AU |

**易错观念（纠一次）**

1. 「滤网看着干净 = 压差准用」→ **错**。要有台账与本期压差实测。  
2. 「滤网还在 = 窗过」→ **错**。要有主人、窗、方法、准用期。  
3. 「AI 温湿度过 = AU 过」→ **错**。AI≠AU。  
4. 「AT 冷凝加湿过 = AU 过」→ **错**。AT≠AU。  
5. 「AO 漏水过 = 滤网交底过」→ **错**。AO≠AU。  
6. 「N 监控绿 = 本期压差/气流实测过」→ **错**。N≠AU。  
7. 「压差告警烦，先旁路联锁 / 拆旁通滤网」→ **禁**。绕联锁/旁通滤网挂 N/R。  
8. 「高温气流告警先抬功率」→ **禁功率战**。  
9. 「邻站照片改机房号能交差」→ **套票拒签**。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AU** 五子类：滤 / 压 / 气 / 验 / 治——双字母续写的第二十一张，负责精密空调滤网压差气流「台账清不清、压差有没有窗、气流有没有法、本期过了没有」。  
- 口诀：**滤网有账，压差有窗，气流有法，会签才放。**  
- 故事：医院手术室/ICU 精密空调——滤网看着干净≠压差准用；滤网还在≠窗过；口头说气流顺≠方法过。  
- 八条硬规则：**滤网台账钉死**；**压差有主有窗有方法/准用期**；**气流组织窗与方法钉死**；**本组本机房本期实测禁套他站他期**；**会签才放行「精密空调滤网压差与气流组织准用」**；**禁顶替 AI/AT/AO/AS/AF/AG/AP/AN/AD/AA/N/AQ/AR 等，主贴 AU，假绿≠放行挂 R**；**滤网/压差/气流异常风暴挂 N、滤网策略/压差门限/气流组织变更走 J、禁功率战、禁绕安全联锁、禁旁通滤网冒充准用**；**脱敏 L3**。
