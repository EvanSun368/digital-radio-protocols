## 3. 核心交付：插页 AU + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AU（而不是先贴 AI / AT / AO / N）

- 要签「精密空调滤网压差与气流组织准用」、要开滤网/压差窗、要交底气流组织 → **主贴 AU**。  
- 温湿度测点/门限/联锁巡检本身 → **AI**（手册36）；滤网与压差本体窗仍 AU。  
- 冷凝水/加湿除湿联锁本身 → **AT**（手册47）；滤网压差气流仍 AU；AT 过≠AU 过。  
- 漏水探测/汇流排本身 → **AO**；滤网交底仍 AU；堵塞溢水可挂 AO。  
- 滤网/压差/气流告警风暴 → 先 **N** 理风暴；缺滤网/气流秩序整改仍 **AU**；**禁功率战**。  
- 进机房做交底 → 先 **AN**；门禁过≠滤网压差气流交底过。  
- UPS 旁路 → **AS**；AS 过≠ AU 过。  
- 假绿/顶替 → 挂 **R**；变更滤网策略/压差门限/气流组织 → 走 **J** 后再验 AU。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **滤网台账钉死**：机房角色、初效 / 中效 / 回风格 / 压差表（开关）入账；禁「滤网看着干净就能签」「口头说一声」。  
2. **压差有主有窗有方法/准用期**：每次压差核对/滤网更换有主人角色、有书面窗、有方法、有准用期；禁「滤网还在当窗过」「外观干净当压差过」。  
3. **气流组织窗与方法钉死**：书面固定；方法含冷热通道、盲板、气流方向证明等核对项（**顺序与门限以本网与 OEM 书面为准**；本篇不发明逐步拆滤网/调风机教条）；禁「窗再说」「口头气流」「绕过压差/气流安全联锁」「擅自拆旁通滤网冒充准用」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、照片、读数必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「精密空调滤网压差与气流组织准用」；假绿 ≠ 放行。  
6. **禁顶替 AI/AT/AO/AS/AF/AG/AP/AN/AD/AA/N/AQ/AR，主贴 AU，假绿≠放行挂 R**：温湿度签、冷凝加湿签、漏水签、旁路签、油机签、电池签、门禁签、仪表签、首年签、监控签、视频签、通风燃油签都不顶本期滤网压差气流签。  
7. **滤网/压差/气流异常风暴挂 N，滤网策略/压差门限/气流组织变更走 J，禁功率战；禁绕过压差/气流安全联锁；禁擅自拆旁通滤网冒充准用**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/精密空调序列号全文/可还原坐标与联系人；禁公开传播未脱敏压差门限与气流参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签滤网压差气流准用、无实测冒充压差过、绕联锁/旁通滤网冒充秩序齐，不是法外运维智慧**。医院精密空调/CRAC 公开资料、厂商滤网压差与冷热通道公开科普只作故事与方法类比（§2.2）：**滤要约、压要窗、气要法、验要本期、干净不算过**——翻译成本网语言就是 AU-滤 / AU-压 / AU-气 / AU-验 / AU-治。**这些是精密空调滤网压差与气流组织交底秩序，不是「干净就签」「滤网在当过」「抬功率压告警」「绕联锁」「旁通滤网」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「精密空调滤网压差与气流组织准用」、对外宣传「滤网一通气流秒过」、把未实测写成已过、把绕联锁/旁通滤网写成秩序齐。允许做的：补滤网台账、补压差窗、重开气流窗、挂 R/N/J、内部挂整改。

## 6. 工作实例（12 则，教学虚构，L3）

1. **滤网看着干净就要签准用** → 拒签；补 AU-滤台账与本期实测。  
2. **滤网还在当窗过** → 拒签；补 AU-压主人/窗/方法。  
3. **气流口头说顺** → 拒签；补 AU-气书面方法。  
4. **套邻站滤网/压差照片改机房号** → AU-验 拒签重测。  
5. **AI 温湿度签顶本期滤网压差气流签** → 拒签顶替；AI≠AU；可挂 R。  
6. **AT 冷凝加湿签顶滤网压差气流签** → 拒签；AT≠AU；冷凝加湿过≠滤网压差气流过。
