| **治** | 假绿≠可以签；禁用「温湿度签」「冷凝加湿签」「漏水签」「监控签」顶本期滤网压差气流 | 假绿、顶替 AI/AT/AO/…、绕联锁、旁通滤网、功率战、泄密 → 治理 | AU-治 |

> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：精密空调/CRAC 滤网与压差公开概述强调**有账要验、滤网看着干净≠压差准用、滤网还在≠窗做完、气流要有书面方法**（§10，**只借秩序直觉**）；医院手术室/ICU 环境控制与数据中心冷热通道公开资料强调**环境绿≠滤网压差气流合格、温湿度过≠滤网压差交底过、冷凝加湿过≠滤网气流过**（§10，**只作故事类比**）。本篇只借这串顺序——**本网滤网台账格式、压差窗方法、气流组织顺序与合格门限以本网制度、合同与 OEM 书面为准**。

### 2.3 和手册36（AI）/ 47（AT）/ 42（AO）/ 46（AS）/ 33（AF）/ 34（AG）/ 43（AP）/ 41（AN）/ 31（AD）/ 28（AA）/ 15（N）/ 44（AQ）/ 45（AR）等的咬合（指针，不重写）

- **AI（手册36）**：温湿度与空调联锁**巡检边界**；**AI ≠ AU**——AI 管温湿度测点/门限/联锁巡检秩序；**AU 管精密空调滤网台账·压差本体窗·气流组织交底准用**；温湿度过≠滤网压差气流过；「环境绿」「联锁巡检绿」≠ AU 过。  
- **AT（手册47）**：冷凝水与加湿除湿联锁；**AT ≠ AU**——冷凝/加湿联锁过≠滤网压差气流过；接水盘/加湿罐账不顶滤网/压差账。  
- **AO（手册42）**：漏水探测与汇流排；**AO ≠ AU**——漏水探头/地漏/汇排过≠滤网交底过；滤网堵塞溢水可挂 AO 理浸水，滤网压差气流主贴仍 AU。  
- **AS（手册46）**：UPS 旁路；**AS ≠ AU**——UPS 旁路过≠精密空调滤网过；机房保供电与环境各管各的。  
- **AF（手册33）**：油机市电；供电过≠滤网压差气流过。  
- **AG（手册34）** / **AP（手册43）**：电池/内阻；电池过≠滤网压差气流过。  
- **AN（手册41）**：门禁访客；进机房做滤网/压差/气流交底仍要 AN——**门禁过≠滤网压差气流交底过**。  
- **AD（手册31）**：仪表入库走 AD；**不能**用旧 AD 签日期顶本期 AU 窗。  
- **AA（手册28）**：首年巡检日历；滤网/压差抽检可挂 AA，缺滤网秩序整改主贴仍 AU。  
- **N（手册15）**：监控/对时/告警风暴；滤网/压差/气流异常风暴挂 N 理风暴，**不先抬功率**；**禁绕过压差/气流安全联锁、禁擅自拆旁通滤网冒充准用**；N 绿≠ AU 过。  
- **AQ（手册44）**：视频调阅；滤网堵塞/气流紊乱事件要调录像另开 AQ；视频过≠滤网压差气流过。  
- **AR（手册45）**：油机房通风燃油；AR 过≠ AU 过。  
- **R / J / X / I**：假绿挂 R；变更（滤网策略、压差门限、气流组织）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 AU 证滤网压差气流秩序，再谈覆盖病**。

### 2.4 新贴纸 AU：滤 / 压 / 气 / 验 / 治（五个子类）

> 小彩蛋：双字母贴纸续写——**AA** 首年巡检；**AB** 室分复测；**AC** 机动开撤；**AD** 备件金机；**AE** 区间联测；**AF** 油机市电；**AG** 电池充电器；**AH** 合路/POI 界面；**AI** 温湿度联锁；**AJ** 天馈驻波；**AK** 爬塔交叉；**AL** 气灭疏散；**AM** 接地浪涌；**AN** 门禁访客；**AO** 漏水汇排；**AP** 内阻核对；**AQ** 视频调阅；**AR** 油机房通风燃油；**AS** UPS 旁路；**AT** 冷凝加湿联锁；**AU** 管「机房精密空调滤网压差与气流组织」。A–Z 既有含义不改；新专题用 AA、AB、AC… 续写。

```text
                ┌──────────── 贴纸 AU · 滤/压/气/验/治 ────────────┐
                │  AU-滤  滤网：滤网台账钉死（初效·中效·回风·压差表） │
                │  AU-压  压差：压差有主有窗有方法准用期             │
                │  AU-气  气流：窗·方法钉死（冷热通道·盲板·方向证明） │
                │  AU-验  验收：本组本机房本期实测·禁套他站他期     │
                │  AU-治  治理：假绿·顶替AI/AT/AO/N·绕联锁·旁通·泄密 │
                └──────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签触发 |
|------|--------|--------------|
| **AU-滤** | 无滤网台账、滤网看着干净无本期压差实测仍准用 → 拒签 | 「滤网看着干净就能签」「口头说一声」 |
| **AU-压** | 压差无主人、无窗、只看滤网在 → 拒签 | 「滤网还在就算过」「外观干净当压差过」 |
| **AU-气** | 无书面气流窗/方法、口头气流、绕压差联锁、旁通滤网 → 拒签 | 「口头说气流顺就行」「压差告警旁路掉」「拆旁通滤网」 |

| **AU-治** | 假绿、用 AI/AT/AO/AS/AF/AG/AP/AN/AD/AA/N/AQ/AR 顶替、绕联锁、旁通滤网、功率战 → 治理 | 「AI/AT 签还在，滤网也能过」 |

### 2.5 建滤网台账 → 钉压差窗 → 气流方法钉死 → 本期实测 → 会签放行 → 变更再验 阶段梯（背下来）

```text
  ① AU-滤 建滤网台账：机房角色 · 初效/中效/回风格/压差表(开关)角色 · 禁「滤网看着干净就能签」「口头说一声」
        │  无账 / 滤网干净无实测 → 不签精密空调滤网压差与气流组织准用
        ▼
  ② AU-压 钉压差窗：压差主人角色 · 书面窗 · 方法 · 准用期 · 禁「滤网还在当窗过」「外观干净当压差过」
        │  无主人 / 无窗 / 无方法 / 无准用期 → 拒进入「可签」状态
        ▼
  ③ AU-气 钉气流方法：书面窗 · 方法（冷热通道、盲板、气流方向证明等；以本网与 OEM 书面为准） · 到场角色 · AD 仪表准用指针
        │  无窗 / 「口头气流」/ 「绕过压差联锁」/ 「拆旁通滤网」 → 拒气流签
        ▼
  ④ AU-验 本组本机房本期实测：实测记录 · 禁套他站他期曲线/照片 · 会签
        │  套票 / 只看监控绿 → 拒签
        ▼
  ⑤ 会签放行「精密空调滤网压差与气流组织准用」；假绿≠放行；未闭项挂整改
        │
        ▼
  ⑥ 滤网策略/压差门限/气流组织变更 → 走 J → 再验 AU
```
