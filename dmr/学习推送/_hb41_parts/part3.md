## 8. 术语表（本篇约 18 词）+ 易错观念

| 词 | 本篇用法（教学） |
|----|------------------|
| **AN** | 本篇贴纸：门禁·访客·陪同秩序 |
| **AN-门** | 门禁/权限/门锁/卡证台账 |
| **AN-访** | 访客与陪同人主人与准用期/授权窗 |
| **AN-陪** | 进机房前陪同交底窗与方法 |
| **AN-验** | 本组本机房本期交底、进签、离清点 |
| **AN-治** | 假绿、顶替、伪造、尾随、功率战、泄密治理 |
| **授权窗** | 访客/临时权限的有效时间窗（以本网为准） |
| **陪同人** | 本网授权陪同访客进机房的角色 |
| **登记≠陪同** | 访客签到本有字不等于已完成陪同交底 |
| **进机房会签** | 进门前授权角色书面放行 |
| **离机房清点** | 离房时人/物/门态核对 |
| **尾随进门** | 跟着授权人未授权进入；治理红线，本篇不教手法，只教拒签 |
| **假绿** | 刷卡绿/监控绿但无本期秩序实证；挂 R |
| **套票** | 套他站他期访客名单/照片当本期 |
| **功率战** | 用抬功率压告警/压掉话；门禁异常窗也禁止 |
| **L3** | 脱敏等级：禁真实频点/站名/全称/卡号全文/访客姓名全文/单位名/联系人 |
| **AM / AL / AH / AD / N / R / J** | 接地 / 气灭 / 合路 / 仪表 / 风暴 / 假绿 / 变更——指针，不重写 |
| **十字门禁钉** | 账、访、窗、法、房、进、离、签、闭、密 |

**易错观念**  
- ✗ 门禁卡在 = 可进 → ✓ 要有账、权限、本期交底。  
- ✗ 访客登记 = 已陪同 → ✓ 要有主人、授权窗、本期交底记录。  
- ✗ 刷卡绿 = 本期交底过 → ✓ 要有书面交底窗与方法留痕。  
- ✗ 气灭过 / 接地过 / 合路清 = 门禁过 → ✓ AL / AM / AH ≠ AN。  
- ✗ 邻站名单能用 → ✓ 套票拒签。  
- ✗ 门禁告警先抬功率 → ✓ 先 N 后 AN，禁功率战。  
- ✗ 尾随进门先通业务 → ✓ 红线，禁止；本篇不教手法。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AN** 五子类：门 / 访 / 陪 / 验 / 治——双字母续写的第十四张，负责门禁·访客·陪同「台账清不清、访客有没有主、本期过了没有」。  
- 故事：医院手术室/ICU/药库门禁与访客陪同——门禁卡在≠可进；访客登记≠已陪同；气灭过≠门禁过；AH 合路界面清≠门禁清；刷卡记录绿≠本期交底过；套邻站访客台账=拒签；AM/AL/AK/AI/AH/AF/AD/AA/N 不顶替 AN；假绿≠会签放行。  
- 阶段梯：建门禁台账 → 钉访客主人 → 陪同交底窗钉死 → 本期交底 → 会签放行（进+离） → 变更再验。  
- 八条硬规则：**门禁/权限/门锁台账钉死**；**访客与陪同人有主人有准用期/授权窗**；**陪同交底窗与方法钉死**；**本组本机房本期交底禁套他站他期**；**会签才放行进机房/离机房清点**；**禁顶替 AM/AL/AK/AI/AH/AF/AD/AA/N 等，主贴 AN，假绿≠放行挂 R**；**门禁异常/尾随/刷卡风暴挂 N、权限变更/厂商临时授权走 J、禁功率战**；**脱敏 L3**。
