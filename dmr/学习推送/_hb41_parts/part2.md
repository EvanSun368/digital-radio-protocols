## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **门禁/权限/门锁台账钉死**：门禁控制器、权限层级、门锁与卡证入账；禁「卡在就能进」「口头说一声」。  
2. **访客与陪同人有主有准用期/授权窗**：每位访客、每位陪同人有主人角色、有准用期或授权窗；禁「熟人就能进」「登记本随便写」。  
3. **陪同交底窗与方法钉死**：进机房前交底书面固定；方法含禁拍/禁触/禁带入物/疏散路径指针等（**门限以本网为准**）；禁「进了再说」「只看刷卡绿」。  
4. **本组本机房本期交底禁套他站他期**：交底记录、访客名单、照片必须本期本组本机房；套邻站账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「门禁/访客陪同交底准用」；进机房会签、离机房清点缺一不可；假绿 ≠ 放行。  
6. **禁顶替 AM/AL/AK/AI/AH/AF/AD/AA/N，主贴 AN，假绿≠放行挂 R**：接地签、气灭签、爬塔签、温湿度签、合路签、仪表签都不顶本期门禁陪同签。  
7. **门禁异常/尾随/刷卡风暴挂 N，权限变更/厂商临时授权走 J，禁功率战**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/门禁卡·徽章序列号全文/访客真实姓名全文/可还原坐标与联系人**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签门禁准用、无陪同交底冒充访客过，不是法外运维智慧**。医院手术室/ICU/药库门禁与访客公开资料、物理安全/访客管理公开科普只作故事与方法类比（§2.2）：**门要约、访要主、陪要窗、验要交底、刷卡绿不算过**——翻译成本网语言就是 AN-门 / AN-访 / AN-陪 / AN-验 / AN-治。**这些是门禁访客陪同秩序，不是「卡在就进」「熟人就算」「抬功率压告警」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「门禁/访客陪同交底准用」、对外宣传「分钟级一键门禁秒过」、把未交底写成已过。允许做的：补门禁台账、补访客主人、重开陪同交底窗、重交底、挂 R/N/J、内部挂整改。

### 4.3 「门禁/访客陪同交底准用」最小集（AN）——缺页不能签「门禁/访客陪同交底准用」

1. 门禁台账页（权限层级/门锁/卡证）  
2. 访客与陪同人主人与授权窗页  
3. 书面陪同交底窗与方法页  
4. 本期本组本机房交底记录（禁套声明）  
5. 进机房会签 + 离机房清点  
6. AD 访客证设备准用指针（若用，支撑）  
7. 会签页（准用或有条件整改）  
8. 未闭项清单（有则挂整改，重大未闭禁签准用）  
9. 脱敏勾选（L3）  
10. 变更指针（若本期有权限/临时授权/门禁策略变更 → J）

> **口诀**：账、访、窗、法、房、进、离、签、闭、密——**十字门禁钉**（教学记忆；现场以本网书面规程为准，但 **门禁台账 + 访客主人 + 本组本机房本期交底 + 会签（进+离）** 几乎不可砍）。

### 4.7 台账路径（一窗陪同交底/一次进机房跑完）

1. 开窗：核对书面陪同交底窗与到场角色  
2. 对账：AN-门 台账 vs 现场权限；AN-访 访客清单 vs 授权窗  
3. 交底：按本网方法做禁拍/禁触/禁带入物/疏散指针等交底（**不写死门限数值**）  
4. 进机房会签：授权角色签放行  
5. 留痕：本期本组本机房记录；禁套声明勾选  
6. 离机房清点：人、物、门态  
7. 分诊：异常 → 挂整改；尾随/刷卡风暴 → N；假绿嫌疑 → R；变更需求 → J  
8. 会签：准用或有条件整改；交班口述未闭项

8. 会签人是不是本网授权角色？重大未闭是否仍想硬签合格？

### 4.10 门禁 / 访客 / 陪同与 AN 的咬合（教学直觉，门限以本网为准）

- **门禁卡在 ≠ 可进**：要有台账、权限、本期交底。  
- **访客登记 ≠ 已陪同**：要有主人、授权窗、本期陪同交底记录。  
- **刷卡绿 ≠ 本期交底过**：要有书面交底窗与方法留痕。  
- **气灭过 ≠ 门禁过**：AL 与 AN 各管各的。  
- **接地过 ≠ 门禁过**：AM 与 AN 各管各的。  
- **合路界面清 ≠ 门禁清**：AH 与 AN 各管各的；业主进柜仍要 AN。  
- **爬塔过 ≠ 门禁交底过**：AK 可支撑第三方进站，进机房主贴仍 AN。  
- **仪表在期内 ≠ 本期交底窗可免**：AD 只答设备准用期。  
- **监控绿 ≠ 门禁陪同准用过**：N 绿不顶 AN。  
- **门限、合格判据、授权窗长度、交底清单以本网制度/合同为准**——本篇不发明数值与条款号；公开门禁/访客资料只借秩序直觉。

### 4.11 与接地（AM）/ 气灭（AL）/ 爬塔（AK）/ 温湿度（AI）/ 合路（AH）/ 油机（AF）/ 仪表（AD）/ 首年（AA）/ 监控（N）怎么配合

厂商进站常见组合：**AN** 办门禁访客陪同 → 进机房后按任务挂 **AM/AL/AH/AI** 等业务贴纸 → 门禁异常/刷卡风暴挂 **N** → 临时授权/权限变更走 **J**。气灭演练窗与访客交底窗冲突：各开各的窗，**互不顶替**；疏散路径指针可挂 AL，进门秩序仍 AN。合路业主进柜：AH 管界面责任，**进柜门禁仍 AN**。

### 4.12 门禁异常窗与上行更脆直觉

门禁失控、尾随进门、未陪同访客乱触设备、权限过期仍进、刷卡风暴掩盖真实进出，常先让设备与空口变「脆」：误碰、误改、告警风暴、掉话——手台功率小、天线短，**上行往往比下行先不够用**。现场第一反应不该是抬功率，而该是：

```text
  门禁异常 / 尾随 / 刷卡风暴
       │
       ├─→ 告警风暴？ → 挂 N 理风暴（对时/风暴秩序）
       ├─→ 门禁/访客台账与本期交底清不清？ → 主贴 AN
       ├─→ 有人要抬功率？ → 禁功率战
       └─→ 要改权限/临时授权/门禁策略？ → 走 J + 再验
```

12.5 kHz / 4FSK / 2-slot TDMA 的窄车道里，乱抬功率只会先伤邻道与自身秩序；**先问 AN 秩序，再谈覆盖病（X/I 指针）**。

## 6. 工作实例（12 则，教学虚构，L3）

1. **卡在拒签**：脱敏机房-07 门禁卡在，无台账权限页 → AN-门拒签「门禁/访客陪同交底准用」；允许补账，不允许口头顶过。  
2. **登记假绿**：机房角色-B 访客登记本有字，无本期陪同交底记录 → 挂 R，补 AN-访/陪后再谈会签。  
3. **套邻站名单**：外包拷邻站上周访客名单改站号交差 → AN-验拒签，责令本期本组本机房重开交底。  
4. **气灭顶门禁**：班长称「AL 气灭签还在，门禁也能签」→ 拒签；气灭过≠门禁过；主贴仍 AN。  
5. **接地顶门禁**：AM 接地浪涌会签在有效窗，想顺带签门禁陪同 → 拒签；AM 与 AN 各管各的。  
6. **合路顶门禁**：AH 合路界面清，业主想免 AN 进柜 → 拒签；合路清≠门禁清；进柜仍要 AN。  
7. **仪表顶窗**：AD 访客证打印机仍在准用期内，外包想免做交底窗 → 拒签；AD 只支撑设备准用，不顶 AN 窗。  
8. **尾随进门**：有人跟着授权人尾随进门 → **禁**；挂整改 + N/R；本期交底未做不得签准用。  
9. **临时授权未走 J**：私自给厂商开临时权限未走变更 → 补走 J，触发再验 AN；未闭前禁签准用。
