## 1. 为什么要写这篇手册（动机 + 现场对话）

| **AN-访** | 访客无主人、无授权窗、只听熟人 → 拒签 | 「熟人就能进」「登记本随便写」 |
| **AN-陪** | 无书面陪同交底窗/方法、只听口头或套刷卡绿 → 拒签 | 「进了再说」「刷卡绿当过」 |
| **AN-验** | 套他站他期访客名单/照片、无会签、离房未清点 → 拒签 | 「邻站访客名单拷过来改站号」 |
| **AN-治** | 假绿、用 AM/AL/AK/AI/AH/AF/AD/AA/N 顶替、尾随、功率战、泄密 → 治理 | 「AL 签还在，门禁也能过」 |

### 2.5 建门禁台账 → 钉访客主人 → 陪同交底窗钉死 → 本期交底 → 会签放行 → 变更再验 阶段梯（背下来）

```text
  ① AN-门 建门禁台账：门禁控制器角色 · 权限层级角色 · 门锁/卡证角色 · 禁「卡在就能进」「口头说一声」
        │  无账 / 权限未入 / 门锁断档 → 不签门禁/访客陪同交底准用
        ▼
  ② AN-访 钉访客主人：访客角色 · 陪同人角色 · 准用期/授权窗 · 禁「熟人就能进」
        │  无主人 / 无授权窗 → 拒进入「可签」状态
        ▼
  ③ AN-陪 钉陪同交底窗：书面窗 · 方法（禁拍/禁触/禁带入物/疏散路径指针等） · 到场角色 · 门限以本网为准
        │  无窗 / 「刷卡绿当过」 → 拒交底签
        ▼
  ④ AN-验 本组本机房本期交底：交底记录 · 进机房会签 · 离机房清点 · 禁套他站他期名单/照片
        │  套票 / 只看刷卡绿 / 离房未清点 → 拒签
        ▼
  ⑤ 会签「门禁/访客陪同交底准用」或「有条件整改」：本网授权本人签
        │  缺签 / 假绿顶替 → 拒签准用
        ▼
  ⑥ 变更（权限层级/厂商临时授权/门禁策略/授权窗）→ 走 J + 触发再交底/再验（常挂 N 看门禁风暴、挂 AD 看访客证设备）
```

> **一句话分辨**：**AM** 回答「接地浪涌**过了没有**」；**AL** 回答「气灭疏散联锁**清不清**」；**AH** 回答「合路/POI 界面**清不清**」；**AD** 回答「仪表准用期**到了没有**」；**AA** 回答「首年巡检日历**到了没有**」；**AN** 回答「这一机房门禁 + 这一组访客陪同 + 这一窗陪同交底**台账清不清、访客有没有主、本期过了没有**」。**六个问题，六张（类）贴纸，不能一笔带过。**

### 2.6 门禁与访客陪同最小工作流（背下来）

```text
  AN-门 台账 + 权限/门锁/卡证钉死
       ├─→ 有账+权限？访客有主人授权窗？ ──否──→ 拒签 / 补账补访
       └─→ 是
  AN-陪 约陪同交底窗 + 书面方法（禁拍/禁触/禁带入物/疏散指针）+ 到场勾选
       │
  AN-验 本组本机房本期：交底记录 → 进机房会签 → 离机房清点 → 禁套声明 → 留痕
       │  套票 / 只看刷卡绿 / 尾随 → 拒签
       ▼
  会签「门禁/访客陪同交底准用」或挂整改；重大未闭禁签准用
       │
  放行或拒签；公开材料 L3；变更走 J 再触发；门禁异常/刷卡风暴挂 N
```

## 3. 核心交付：插页 AN + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AN（而不是先贴 AM / AL / AH / N）

| 现场要办的事 | 主贴 | 说明 |
|--------------|------|------|
| 门禁台账、访客授权、陪同交底签、假绿拒签 | **AN** | 本篇主职 |
| 厂商/外包/参观进机房、临时授权窗 | **AN** | 本篇主场 |
| 权限到期、卡证挂失、门锁异常 | **AN**（门+访） | 卡在≠可进 |
| 气灭/疏散联锁交底 | **AL**（可挂 AN） | 气灭过≠门禁过；疏散指针可挂 AL |
| 天馈接地/浪涌抽检 | **AM**（可挂 AN） | 接地过≠门禁过；进站仍要 AN |
| 爬塔/第三方交叉进站 | **AN**（支撑 **AK**） | 登高秩序回 AK；进机房门禁主贴 AN |
| 温湿度/空调联锁 | **AI**（可挂 AN） | 环境过≠门禁过 |
| 合路/POI 界面、业主进柜 | **AH**（可挂 AN） | 合路清≠门禁清；业主进柜仍要 AN |
| 油机市电 | **AF**（可挂 AN） | 供电过≠门禁过 |
| 访客证打印设备/临时卡入库准用 | **AD**（可挂 AN） | 设备准用≠本期交底过 |
| 交维后首年巡检日历 | **AA**（可挂 AN） | 首年日历≠本期交底窗 |
| 门禁异常、尾随、刷卡风暴 | **N**（可挂 AN） | 先风暴后秩序；禁功率战 |
| 大屏刷卡绿想直接签门禁交底准用 | **AN-治 + R** | 假绿≠门禁通过 |
| 套邻站旧访客名单 | **AN-治** | 禁套；须本期本组本机房交底 |

### 3.2 插页 AN · 门 / 访 / 陪 / 验 / 治（挂在总三联单或门禁/访客单后）

| 插页行 | 检查项（教学） | 缺了怎么办 |
|--------|----------------|------------|
| **AN1** | 门禁台账在：权限层级/门锁/卡证角色书面 | 缺 → **拒签准用** |
| **AN2** | 权限到场可追溯；禁「卡在就能进」「口头说一声」 | 缺 → **拒「卡在就能进」** |
| **AN3** | 访客与陪同人有主人：主人角色；准用期/授权窗；登记≠已陪同 | 缺 → **拒签** |
| **AN4** | 陪同交底窗书面在；方法书面（禁拍/禁触/禁带入物/疏散路径指针等）；到场角色勾选 | 缺 → **拒交底签** |
| **AN5** | 本组本机房本期交底记录在；脱敏机房与窗一致；禁套他站他期名单/照片 | 套/缺 → **拒签** |
| **AN6** | 进机房会签 + 离机房清点在；相关疏散指针可挂 AL；禁尾随进门叙事 | 缺/尾随嫌疑 → **拒签或整改** |
| **AN7** | 「门禁/访客陪同交底准用」会签：相关授权本人签；重大未闭禁准用 | 缺签 → **拒签** |
| **AN8** | 公开材料 L3；变更项走 J；禁功率战叙事 | 违 → **治理** |

> 插页每一行都对应硬规则：AN1/AN2→规则1，AN3→规则2，AN4→规则3，AN5→规则4，AN6/AN7→规则5，顶替/假绿→规则6，AN6/AN8→规则7/8。**任何一行缺项，就停在那一行。**

### 3.3 和总三联单怎么写（接手册06）

- **现象栏**：写「门禁台账断档 / 访客无主 / 陪同交底未做 / 套他站名单 / 刷卡假绿 / 尾随嫌疑 / 离房未清点」等可复核现象，**不写空口玄学**。  
- **贴纸栏**：主贴 **AN**；支撑可贴 AM / AL / AK / AI / AH / AF / AD / AA / N / R / J。  
- **处置栏**：拒签 / 补门禁台账 / 补访客主人 / 重开陪同交底窗 / 重交底 / 挂 R/N/J——**写动作，不写空口字段**。  
- **脱敏**：站/机房用角色编号；禁单位名全文、禁真实站名、禁门禁卡·徽章序列号全文、禁访客真实姓名全文。

### 3.4 《本网机房门禁与访客陪同交底台账卡》预告

§7 给出可复印模板：封面拒签门槛、门页、访页、陪页、验页、会签准用页、夜班速填五行。**一张卡跑完一窗陪同交底/一次进机房：门→访→陪→验→签**；与 AM 接地、AL 气灭、AH 合路、AD 仪表指针对齐，避免「接地签还在就当门禁过」「气灭过就当访客过」「合路界面清就当门禁清」「刷卡绿就免交底」。
