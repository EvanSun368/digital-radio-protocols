## 1. 为什么要写这篇手册（动机 + 现场对话）

前三十四篇手册从 A–E 协议一路写到 AG 电池抽检：其中 **S 回答「邻频协调与边界联测」**，**AE 回答「隧道/地铁区间联测与换乘责任界面」**，**T 回答「干扰投诉分诊与证据链」**，**AB/X/I 回答「室分复测」**，**AG 回答「电池与充电器梯队」**。可还没有单独钉死一件事——**多业主合路/POI 机房不是「柜里有设备就能签界面清」：合路台账与业主端口要钉死；责任界面要有主人；干扰分诊窗与方法要书面固定；本组本机房本期实测禁套他业主他期——能不能签「合路/POI 界面准用」？** 这就是本篇的 **AH**——**多业主合路/POI 机房责任界面与干扰分诊**。

- 合路岗：「柜里 POI 有灯，各家设备都在，界面肯定清。」——**无合路/业主台账仍准用** = 本篇拒签（规则1）。  
- 物业：「合用机房钥匙在我这，谁坏谁修口头说一声。」——**责任界面无主人无书面边界** = 规则2。  
- 网优：「网管全绿，不用分诊了。」——**只看网管绿，无分诊窗/方法** = 规则3。  
- 外包：「邻业主上周曲线参数差不多，拷过来改个端口号。」——**套他业主他期** = 规则4。  
- 班长：「S 邻频签还在，AE 区间也过了，合路界面也能签。」——**用 S/AE/T 顶替 AH** = 规则6。  
- 站务：「单边业主测绿了，整段合路算过。」——**单边绿≠整段过** = 规则5/6。  
- 网优：「合路窗基站抖了一下，功率抬一点稳住。」——**功率战** = 规则7。  
- 宣传岗：「把真实业主名、机房编号、端口曲线发群表扬。」——**L3 违规** = 规则8。  

这几句背后是同一件事：

> **「多业主合路/POI 机房责任界面与干扰分诊」在现场至少有五个坑**：**① AH-合** 合路/POI 台账与各业主端口、馈入/馈出角色、合路器/POI 柜编号入账，禁「柜里有就算清」；**② AH-界** 责任界面有主人（本网/他业主/物业/集成角色）、书面边界（端口侧/公共侧/馈线侧），禁口头「谁坏谁修」；**③ AH-诊** 干扰分诊窗、方法（隔离端口/对端静默/底噪观察等角色项）、到场角色书面固定，禁「看一眼网管绿」；**④ AH-验** 本组本机房本期实测（禁套他业主他期曲线），会签才放行「合路/POI 界面准用」；**⑤ AH-治** 治理（假绿、用 S/AE/T/AB 顶替、伪造界面账、功率战、泄密）。  
> 把 ①–⑤ 当成「柜里有就能签」「网管绿就算多业主过」「口头说一声界面清」，每一次合路增业主、每一次干扰互告、每一次室分复测并行，都会先吵「到底谁的端口、谁负责诊、曲线是不是本期的」。

本篇目标：能背出**合路/POI 界面 + 干扰分诊工作流**；会用新贴纸 **AH（合 / 界 / 诊 / 验 / 治）**；会填**插页 AH（AH1–AH8）**和《本网多业主合路/POI 机房责任界面与干扰分诊台账卡》；能用「**商场/医院共享楼宇合用电梯机房——谁按谁修 / 合用配电间责任界面**」故事讲清柜里有设备≠界面清、网管绿≠分诊过、套邻业主曲线=拒签、用 S/AE/T 签顶 AH 界面签=拒签、单边绿≠整段过；能拒绝无主界面、套曲线、用他贴顶替本期合路签、假绿放行；自测过关后，回库把本网最近一次合路/POI 增业主或干扰分诊（L3）重对一遍：合路账、界面主人、分诊窗、本期实测、会签项、拒签项。

**本篇硬禁令（写进脑子）**：凡引法规与标准只指向已公开发布的文书标题与官方链接（无线电管理条例、频率使用许可管理办法、地面无线电台（站）管理规定、国无办〔2025〕1号；**只作故事类比**的商场/医院合用电梯机房、合用配电间责任界面公开资料标题，以及公开的 DAS/POI/合路器/PIM 多运营商共享站点概述资料），**程序、期限、责任以原文与属地最新要求及本网制度 / 合同为准，本篇只作教学转述，不发明条款号与内部口径**；境外 DAS/POI/PIM 公开资料与商场电梯合用故事**不是**中国专网台站「贴纸 AH」的法定依据；**现象与台账一律用相对道号、角色标签、脱敏机房/业主编号，禁真实频点 / 站名 / 机房全称 / 业主单位名 / 联系人**；**不教伪造合路台账、不教功率战、不教规避监测、不教套他业主曲线、不教假绿顶替、不教绕过告警**；S / AE / T / AB / X / I / R / J / N / AG 各管各的——**合路/POI 机房责任界面与干扰分诊主贴 AH**；邻频边界回 S，区间换乘回 AE，投诉证据回 T——**AH 管「合路·界面·分诊秩序」，不替代 S 的邻频协调本身，也不替代 AE 的区间联测门卫，更不替代 T 的投诉证据链**。

## 2. 总图 / 故事：合路/POI 机房像「商场/医院共享楼宇合用电梯机房——谁按谁修」

### 2.1 一句话：合路柜里有设备不是「界面清了」、网管绿不是「分诊过了」——要先建合路/POI 台账与业主端口，责任界面有主人，分诊窗与方法钉死，本组本机房本期实测，会签才放行；假绿、套邻业主曲线、用 S/AE/T 顶替、单边绿当整段过，一律拒签

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  合用电梯机房「谁按谁修」+ 合用配电间责任界面  =  本网 AH    │
   │                                                              │
   │  电梯/配电入账·各业主端口贴签     ≈ AH-合  合路/POI 台账     │
   │  按钮侧/井道侧/公共侧谁主谁修     ≈ AH-界  责任界面有主人   │
   │  故障分诊窗·方法·到场角色钉死     ≈ AH-诊  干扰分诊窗与方法 │
   │  本期实测禁套邻楼/邻业主曲线     ≈ AH-验  本组本机房本期   │
   │  假绿≠放行·顶替·伪造账·功率战   ≈ AH-治  治理与脱敏 L3     │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **合路有账，界面有主，分诊有窗，本期实测，会签才放。**  
> 柜里有设备还无主人界面 = 合用电梯机房没人认「谁按谁修」——**拒签「合路/POI 界面准用」**。  
> 网管全绿但半年没分诊 = 配电间绿灯亮着却从未做合用界面抽检——**假绿，挂 R，拒签**。

### 2.2 「合用电梯机房 / 合用配电间」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **合** | 电梯/配电入账→各业主按钮/回路贴签→合用设备清单 | 合路/POI 台账与各业主端口钉死；禁「柜里有就算清」 | AH-合 |
| **界** | 按钮侧/井道侧/公共侧书面边界；谁坏谁修有主人 | 责任界面有主人；端口侧/公共侧/馈线侧书面 | AH-界 |
| **诊** | 故障分诊有窗、有方法、有到场；禁「看一眼总柜绿」 | 干扰分诊窗与方法、到场角色书面固定 | AH-诊 |
| **验** | 本期实测留痕；禁抄邻楼电梯检修账 | 本组本机房本期实测；禁套他业主他期 | AH-验 |
| **治** | 假绿≠界面过；禁用「邻频签」「区间签」「投诉签」顶本期界面 | 假绿、顶替 S/AE/T/AB、伪造账、功率战、泄密 → 治理 | AH-治 |

> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：DAS/POI 公开概述强调**各运营商信号在 Point of Interface 汇合，隔离、滤波、合路与监测口是界面秩序的一部分**（§10，**只借秩序直觉**）；PIM/互调公开资料强调**多载波合路处非线性可抬高底噪，尤其伤上行**（§10）；商场/医院合用电梯机房「谁按谁修」只作故事类比（§10，**不是无线电法定依据**）。本篇只借这串顺序——**本网合路台账、界面边界、分诊门限、合格标准以本网制度与合同为准**。

### 2.3 和手册20（S）/ 21（T）/ 32（AE）/ AB·X·I / 34（AG）等的咬合（指针，不重写）

- **S（手册20）**：邻频协调与**边界联测**；频率邻居怎么处——**S 管空口邻居，不替代 AH 机房内物理合路界面**。  
- **AE（手册32）**：隧道/地铁**区间联测与换乘责任界面**；区间/换乘谁责——**AE 管区间，AH 管合路机房/POI 柜**。  
- **T（手册21）**：干扰**投诉分诊与证据链**；告谁拿什么证——**T 管投诉证据，AH 管合路界面主人与分诊入口**；合路窗投诉常先 AH 再挂 T。  
- **AB / X / I（室分复测）**：室分复测≠合路界面过；复测可挂支撑，**主贴合路界面仍 AH**。  
- **AG（手册34）**：电池梯队；合路机房可并行抽检电池，各贴各的。  
- **R / J / N**：假绿挂 R；变更（增业主端口、改合路衰减、换 POI 模块）走 J；合路窗告警风暴挂 N，**不先抬功率**。

### 2.5 建合路账 → 钉界面主人 → 分诊窗钉死 → 本期实测 → 会签放行 → 变更再验 阶段梯（背下来）

```text
  ① AH-合 建合路/POI 台账：合路器/POI 柜角色 · 各业主端口贴签 · 馈入/馈出角色
        │  无台账 / 端口未贴签 → 不签界面准用
        ▼
  ② AH-界 钉责任界面：主人角色（本网/他业主/物业/集成）· 端口侧/公共侧/馈线侧书面边界
        │  无主人 / 无书面边界 → 拒进入「可签」状态
        ▼
  ③ AH-诊 钉分诊窗：书面窗 · 方法（隔离端口/对端静默/底噪观察等角色项）· 到场角色
        │  无窗 / 无方法 / 「只看绿灯」 → 拒分诊签
        ▼
  ④ AH-验 本组本机房本期实测：各业主端口角色项 · 禁套他业主他期 · 单边绿≠整段过
        │  套曲线 / 单边绿当整段 / 只看网管绿 → 拒签
        ▼
  ⑤ 会签「合路/POI 界面准用」或「有条件整改」：相关业主/本网授权本人签
        │  缺签 / 假绿顶替 → 拒签准用
        ▼
  ⑥ 变更（增业主端口/改合路衰减/换 POI 模块）→ 走 J + 触发再分诊/再验（常挂 N 看监控、挂 S/T 看邻频与投诉）
```

> **一句话分辨**：**S** 回答「频率邻居**怎么协调联测**」；**AE** 回答「区间/换乘**界面过了没有**」；**T** 回答「投诉**证据链怎么建**」；**AH** 回答「这一柜合路/POI + 这一组业主端口 + 这一窗分诊**台账清不清、界面有没有主、本期过了没有**」。**四个问题，四张（类）贴纸，不能一笔带过。**

### 2.6 合路/POI 界面与干扰分诊最小工作流（背下来）

```text
  AH-合 合路/POI 台账 + 各业主端口贴签
       ├─→ 有台账+端口贴签？界面有主人书面边界？ ──否──→ 拒签 / 补账补界
       └─→ 是
  AH-诊 约窗 + 书面方法 + 到场勾选
       │
  AH-验 本组本机房本期：端口隔离观察 → 底噪/上行角色项 → 禁套声明 · 单边≠整段
       │  套曲线 / 单边绿 / 只看绿灯 → 拒签
       ▼
  会签「合路/POI 界面准用」或挂整改；重大未闭禁签准用
       │
  放行或拒签；公开材料 L3；变更走 J 再触发
```

## 3. 核心交付：插页 AH + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AH（而不是先贴 S / AE / T / AB）

| 现场要办的事 | 主贴 | 说明 |
|--------------|------|------|
| 合路/POI 台账、界面主人、分诊签、假绿拒签 | **AH** | 本篇主职 |
| 邻频协调、边界联测 | **S**（可挂 AH） | 空口邻居；不顶替机房合路界面 |
| 区间联测、换乘责任界面 | **AE**（可挂 AH） | 区间≠合路机房柜 |
| 干扰投诉证据链 | **T**（可挂 AH） | 投诉证据；合路入口常先 AH |
| 室分复测 | **AB/X/I**（可挂 AH） | 室分复测≠合路界面过 |
| 大屏网管绿想直接签界面准用 | **AH-治 + R** | 假绿≠分诊通过 |
| 套邻业主旧端口曲线 | **AH-治** | 禁套；须本期本组本机房实测 |

### 3.2 插页 AH · 合 / 界 / 诊 / 验 / 治（挂在总三联单或合路/分诊单后）

| 插页行 | 检查项（教学） | 缺了怎么办 |
|--------|----------------|------------|
| **AH1** | 合路/POI 台账在：合路器/POI 柜角色、各业主端口贴签、馈入/馈出角色书面 | 缺 → **拒签准用** |
| **AH2** | 业主端口清单可追溯：谁进谁出、备用/终止端口角色（角色标签） | 缺 → **拒「柜里有就算清」** |
| **AH3** | 责任界面有主人：本网/他业主/物业/集成角色；端口侧/公共侧/馈线侧书面边界 | 缺 → **拒签** |
| **AH4** | 分诊窗书面在（日期角色/天窗角色）；方法（隔离端口/对端静默/底噪等角色项）书面；到场角色勾选 | 缺 → **拒分诊签** |
| **AH5** | 本组本机房本期实测记录在；脱敏机房/业主端口与窗一致；禁套他业主他期；单边绿≠整段过 | 套/缺/单边冒充 → **拒签** |
| **AH6** | 分诊仪表在 AD 准用期内（挂 AD 指针）；条件角色项按本网规程记录 | 仪表过期 → **拒认测值或整改** |
| **AH7** | 「合路/POI 界面准用」会签：相关授权本人签；重大未闭禁准用 | 缺签 → **拒签** |
| **AH8** | 公开材料 L3；变更项走 J；禁功率战叙事 | 违 → **治理** |

> 插页每一行都对应硬规则：AH1/AH2→规则1，AH3→规则2，AH4→规则3，AH5/AH6→规则4，AH7→规则5，顶替/假绿→规则6，AH8→规则7/8。**任何一行缺项，就停在那一行。**

### 3.3 和总三联单怎么写（接手册06）

- **现象栏**：写「合路台账断档 / 界面无主 / 分诊未实测 / 套他业主曲线 / 单边绿冒充整段 / 网管假绿」等可复核现象，**不写空口玄学**。  
- **贴纸栏**：主贴 **AH**；支撑可贴 S / AE / T / AB / X / I / R / N / J / AD / AG。  
- **处置栏**：拒签 / 补合路账 / 补界面主人 / 重开分诊窗 / 重测 / 挂 R/N/J——**写动作，不写空口字段**。  
- **脱敏**：机房/业主人用角色编号；禁单位名全文、禁真实站名。

### 3.4 《本网多业主合路/POI 机房责任界面与干扰分诊台账卡》预告

§7 给出可复印模板：封面拒签门槛、合路页、界面页、分诊窗页、实测页、会签准用页、夜班速填五行。**一张卡跑完一窗分诊/一次增业主合路：合→界→诊→验→签**；与 S 邻频、AE 区间、T 投诉指针对齐，避免「邻频签还在就当合路界面过」「区间绿就当 POI 过」「投诉结案就当界面清」。
