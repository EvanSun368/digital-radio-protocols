## 3. 核心交付：插页 BQ + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 BQ（而不是先贴 AI / AT / BE / AU / AZ / BM / N）

- 要签「机房精密空调电加热再热与低湿保护巡检准用」、要开电加热再热交底窗、要交底低湿保护侧 → **主贴 BQ**。
- 温湿度与空调联锁巡检 → **AI**。**AI ≠ BQ**；温湿度联锁过 ≠ 本篇；AI 不单独给本篇台账；不重写 AI。
- 冷凝水与加湿除湿联锁 → **AT**。**AT ≠ BQ**；加湿罐在 ≠ 低湿保护窗过；除湿过 ≠ 再热台账过；不重写 AT。
- 水质与电极/蒸汽罐更换 → **BE**。**BE ≠ BQ**。不重写 BE。
- 滤网压差与气流组织 → **AU**。冷通道封闭与机柜进出风 → **AZ**。**AU ≠ BQ；AZ ≠ BQ**。开度与过热控制 → **BM**。**BM ≠ BQ**（BM 的过热是蒸发侧制冷过热，不是电加热器过热保护）。
- 冷凝风机转速与冷凝压力调节 → **BP**。盘管清洗/翅片、吸排与过热过冷等 → **BN / BJ** 等。邻贴过 ≠ 本篇，也不得用 BQ 顶它们。漏水汇排 → **AO**。
- 进机房先 **AN**（门禁过 ≠ 交底过）。气灭 → **AL**。风暴先 **N**，缺秩序整改仍 **BQ**；上述硬禁项与功率战一律禁止。
- 假绿/顶替挂 **R**；变更走 **J** 后再验 BQ。
- 无精密空调，或无电加热再热/低湿保护路径（例如纯冷冻水末端且无电加热、未配置低湿保护的路径） → 书面「不适用」；加湿问 AT，水质换罐问 BE，温湿度总联锁问 AI，**不得**与 AI/AT/BE 互顶。一侧不适用 ≠ 另一侧自动免。AI/AT/BE 过了或它们不适用 ≠ 本路径自动免。

### 3.4 与总三联单怎么写（脱敏 L3）

- **现象栏**：写「再热缺账 / 灯绿无核对 / 看着在加热或温度表绿 / 口头投过 / 湿度绿或低湿灯绿顶窗 / 一侧顶另一侧 / 他贴顶 BQ / 套票 / 强制投切或熔断保护/旁通/绕联锁/临时电炉/带电违章嫌疑」等角色化现象；**不写**真实机房全称、精密空调或加热器序列号全文、可还原再热或门限全文。

- **会签栏**：准用 / 有条件整改 / 拒签；假绿 ≠ 放行。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **电加热再热台账钉死**：电加热器角色与再热窗、本期对照各自有账（编号脱敏）；禁「灯绿就算过」「看着在加热就算过」「温度表绿就算过」「口头投过电加热」；再热过 ≠ 低湿保护窗过，低湿保护窗过 ≠ 再热台账过。
2. **低湿保护侧有主有窗有方法准用期**：与再热侧分开看；设定/告警/联锁动作、合格窗与准用期书面固定；每次低湿保护交底有主人角色、有书面窗、有方法、有准用期；禁「湿度表看着不低就算过」「低湿灯绿就算过」「湿度绿就算过」「套邻站低湿照片」；低湿保护窗过 ≠ 再热台账过；加湿罐在 ≠ 低湿保护窗过；除湿过 ≠ 再热台账过。
3. **边界窗与方法钉死**：书面固定；方法含与 AI/AT/BE/N/AU/AZ/BM 分工勾选，以及加热器过热保护、无气流证明不得投电加热（**顺序与门限以本网与 OEM 书面为准**；本篇不发明强制投切、熔断保护、绕联锁或带电检修步骤；**不重写 AI/AT/BE 全文**）；禁「窗再说」「绕联锁」「开旁通冒充」「未授权强制投切或熔断低湿/加热器过热保护教条」「用临时电炉顶替再热」「带电违章检修加热器」「伪造台账」。
4. **本组本机房本期实测禁套他站他期**：实测记录、再热对照、低湿保护必须本期本组本机房；套邻站/邻院账 = 拒签。
5. **会签才放行**：缺授权会签不得签「机房精密空调电加热再热与低湿保护巡检准用」；假绿 ≠ 放行。
6. **禁顶替 AI/AT/BE 等，主贴 BQ，假绿≠放行挂 R**：他贴签都不顶本期再热/低湿签。**尤其 AI ≠ BQ、AT ≠ BQ、BE ≠ BQ，以及 N≠BQ、AU/AZ≠BQ、BM≠BQ；温湿度联锁过 ≠ 本篇；加湿罐在 ≠ 低湿保护窗过；除湿过 ≠ 再热台账过；水质换罐过 ≠ 本篇；BM 的过热 ≠ 加热器过热保护。** 也不得用 BQ 顶 BP/BN/BJ 等。
7. **异常风暴挂 N；变更走 J；禁功率战；禁绕联锁；禁旁通；禁未授权强制投/切除电加热或熔断低湿保护/加热器过热保护教条；禁用临时电炉顶替再热；禁带电违章检修加热器；禁伪造**：上行更脆时先问秩序，不先抬功率。乱窗、假绿、加热器或低湿告警风暴常被误当「覆盖病」→**禁功率战**；挂 N；变更走 J。
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/精密空调或加热器序列号全文/可还原坐标与联系人；禁公开传播未脱敏再热细节、保护参数与门限**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签准用、无实测冒充边界过、绕联锁/旁通/强制投切或熔断保护/临时电炉/带电违章冒充秩序齐，不是法外运维智慧**。医院/数据中心公开资料只作故事类比（§10）。

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签准用、对外宣传「灯绿/看着在加热/表绿/口头投过/湿度绿秒过」、把未实测写成已过、把绕联锁/旁通/强制投切或熔断保护/临时电炉/带电违章写成秩序齐。允许做的：补账、补窗、挂 R/N/J、内部挂整改。

### 4.3 「机房精密空调电加热再热与低湿保护巡检准用」最小集（BQ）——缺页不能签准用

1. 再热台账页（电加热器·再热窗·本期对照；含灯绿/看着在加热/温度表绿≠台账过、口头投过≠方法过、一侧过≠另一侧过勾选）
2. 低湿保护侧主人与书面窗、方法、准用期页（与再热分开看；含禁湿度表看着不低、禁低湿灯绿、禁湿度绿、禁套邻站照片、加湿罐在≠本窗、除湿过≠再热勾选）
3. 书面边界窗与方法页（与 AI/AT/BE/N/AU/AZ/BM 分工；加热器过热保护、无气流证明不得投电加热；以本网与 OEM 为准；声明不重写邻贴）
4. 本期本组本机房实测记录（再热对照、低湿保护分别留痕；禁套声明）
5. AI/AT/BE 及 AU/AZ/BM 边界勾选（防顶替）
6. AD/AN/AL/N/AA/AQ 边界勾选（入库≠本期窗；门禁/气灭过≠交底过；N 绿≠BQ 过）
7. 会签页（准用或有条件整改）
8. 未闭项清单（有则挂整改，重大未闭禁签准用）
9. 脱敏勾选（L3）
10. 变更指针（若本期有加热器角色/再热或低湿保护窗方法/门限变更 → J）
11. 不适用声明（无精密空调或无本路径，含纯冷冻水末端且无电加热、未配置低湿保护的路径，书面勾选；不得顶 AI/AT/BE；一侧不适用 ≠ 另一侧自动免；AI/AT/BE 过了或它们不适用 ≠ 本路径自动免）

> **口诀**：热、护、界、窗、房、测、签、闭、密、界——**十字再热钉**（教学记忆；现场以本网书面规程为准，但 **再热台账 + 低湿保护窗方法 + 边界方法 + 本期实测 + 会签** 几乎不可砍）。

### 5.2 对话脚本（教学）

**脚本A（加热器灯绿 / 看着在加热 / 口头投过想签）**
新人：「加热器灯是绿的，看着也在加热，温度表在绿区，班长还说上个月投过，签准用吧。」

外包：「AI 温湿度与空调联锁签还在，再热和低湿窗免了。」

外包：「AT 冷凝水和加湿除湿联锁刚过，加湿罐还在，除湿也做过，湿度表看着不低，低湿灯绿，湿度绿，低湿窗和再热免了。」

### 5.5 与弱项的现场对照（再钉一次）

再热乱账、低湿保护乱窗、假绿、加热器/低湿告警风暴，常先伤站点环境与**上行**体验。有人把这些当「覆盖病」抬功率——**禁功率战**。先问 BQ 秩序并分诊 AI/AT/BE，风暴挂 N，变更走 J。弱项短补：**12.5 kHz / ≤8.5 kHz 占用 / 4FSK / 2-slot TDMA**；上行往往比下行先不够用。脏窗和告警风暴先伤站点环境与空口秩序，不是先去抬功率的「覆盖病」。
