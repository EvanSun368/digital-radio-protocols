## 1. 为什么要写这篇手册（动机 + 现场对话）

前六十九篇手册从 A–E 协议一路写到 BP 冷凝风机转速与冷凝压力调节：其中 **AI 回答「温湿度与空调联锁巡检边界」**（测点、联锁窗与温湿度总秩序；**温湿度过 ≠ 本篇**，也**并不**单独给电加热再热 + 低湿保护一张巡检台账），**AT 回答「冷凝水与加湿除湿联锁」**（接水盘/排水、加湿除湿联锁；**加湿罐在 ≠ 低湿保护窗过**，**除湿过 ≠ 再热台账过**），**BE 回答「加湿器水质与电极/蒸汽罐更换」**（水质测点与换罐窗；**水质换罐过 ≠ 本篇**），**N 回答「监控对时与告警风暴」**，**AU / AZ** 管气流组织与冷通道，**BM** 管膨胀阀开度与过热控制。系列 01–69 **还没有**单独钉死一件事——**不是「加热器灯绿 / 看着在加热 / 温度表绿 / 口头投过电加热 / 湿度表看着不低 / 低湿灯绿 / 湿度绿 / AI 或 AT 或 BE 过就能签」：再热台账要钉死；低湿保护侧要有主有窗有方法有准用期；边界方法要书面固定（加热器过热保护、无气流证明不得投电加热）；本期实测禁套——能不能签「机房精密空调电加热再热与低湿保护巡检准用」？** 这就是本篇的 **BQ**（Excel 风格：BP 之后 → **BQ**）。写前已核对系列手册 01–69 标题，尚无该专题正文。该题只在手册69 §11.2 作为候选出现过，并在 AI、AT、BE 里以相关*角色*出现，但都不是本篇这张巡检台账。

## 2. 总图 / 故事：再热/低湿像「医院手术室/ICU 或数据中心精密空调——不能只看加热器灯绿、不能只看湿度表或低湿灯绿」

### 2.1 一句话：加热器灯绿、看着在加热、温度表绿、口头投过电加热、湿度表看着不低、低湿灯绿、湿度绿、AI/AT/BE 过、监控绿，都不是「可以签准用」——要先建再热台账，低湿保护侧有主有窗有方法有准用期，边界方法钉死，本期实测，会签才放行；假绿、套邻站表、用他贴顶替，一律拒签

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  医院手术室/ICU · 数据中心精密空调 CRAC                       │
   │  电加热再热路径 + 低湿保护路径  =  本网 BQ                    │
   │  （Electric Reheat + Low-Humidity Protection）                │
   │                                                              │
   │  再热台账钉死（电加热器·再热窗·本期对照）≈ BQ-热  再热有账   │
   │  保护侧有主有窗有方法准用期（与再热侧分开看）≈ BQ-护  低湿保护有窗 │
   │  边界窗·方法钉死（与AI/AT/BE/N/AU/AZ/BM分工；         ≈ BQ-界  边界有法 │
   │    加热器过热保护·无气流证明不得投电加热）                   │
   │  本期实测禁套邻站再热/低湿表               ≈ BQ-验  本组本机房本期 │
   │  假绿≠放行·顶替·硬禁项·功率战 ≈ BQ-治  治理与脱敏L3          │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **再热有账，低湿保护有窗，边界有法，会签才放。**

> **AI≠BQ**（温湿度联锁过≠本篇；AI并不单独给本篇台账）；**AT≠BQ**（加湿罐在≠低湿保护窗过；除湿过≠再热台账过）；**BE≠BQ**；再热过≠低湿保护窗过；N 绿≠本期实测过。加热器灯绿/看着在加热/温度表绿≠再热台账过；口头投过电加热≠方法过；湿度表看着不低/低湿灯绿/湿度绿≠低湿保护窗过。**BM 的过热 ≠ 加热器过热保护。**

### 2.2 「医院手术室/ICU / 数据中心精密空调电加热再热 + 低湿保护路径」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **热** | 电加热再热入账→再热窗→本期对照→禁「灯绿就算过」「看着在加热就算过」「温度表绿就算过」「口头投过电加热」 | 再热台账钉死；灯绿/看着在加热/表绿≠台账过；口头投过≠方法过；再热过 ≠ 低湿窗过；**AI 温湿度过 ≠ 本台账** | BQ-热 |
| **护** | 低湿保护侧有主人、有窗、有方法、有准用期；禁「湿度表看着不低/低湿灯绿/湿度绿就算过」「套邻站低湿照片」 | 湿度绿/低湿灯绿≠窗过；低湿保护窗过 ≠ 再热台账过；**加湿罐在 ≠ 低湿保护窗过**；**AT/BE 过 ≠ 本窗过** | BQ-护 |
| **界** | 边界窗有书面方法（与 AI/AT/BE/N/AU/AZ/BM 分工；加热器过热保护、无气流证明不得投电加热；以本网与 OEM 为准）；禁绕联锁、旁通、未授权强制投/切除电加热、熔断低湿保护或加热器过热保护、临时电炉顶再热、带电违章检修、伪造台账 | 边界窗与方法书面固定；**不重写 AI/AT/BE**；**BM 过热 ≠ 加热器过热保护** | BQ-界 |
| **验** | 本期再热/低湿保护实测留痕；禁抄邻院再热或低湿表 | 本组本机房本期实测；禁套他站他期再热/低湿表 | BQ-验 |
| **治** | 假绿≠可以签；禁用「温湿度联锁签」「冷凝加湿签」「水质换罐签」「监控签」顶本期再热/低湿 | 假绿、他贴顶替、强制投切/熔断保护/旁通/绕联锁/临时电炉/带电违章、功率战、泄密 → 治理 | BQ-治 |

> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：电加热/加热元件、除湿后再热与湿度控制公开概述强调**再热与低湿保护各有角色、灯绿≠本期核对过、看着在加热≠台账过、湿度绿≠保护窗过、温湿度总联锁不是本再热台账、加湿联锁或换罐不是本低湿窗、蒸发侧过热不是加热器过热保护**（§10，**只借秩序直觉**；**本篇不写强制投切、熔断保护、绕联锁或带电检修步骤，不重写邻贴全文**）。医院/数据中心 CRAC 公开资料**只作故事类比**。**本网台账格式、窗方法、边界顺序与合格门限以本网制度、合同与 OEM 书面为准**。

### 2.3 和手册36（AI）/ 47（AT）/ 58（BE）/ 15（N）/ 48（AU）/ 53（AZ）/ 66（BM）等的咬合（指针，不重写）

- **AI（手册36）**：温湿度与空调联锁巡检；**没有**单独给电加热再热 + 低湿保护一张巡检台账；**AI ≠ BQ**——温湿度联锁过 ≠ 本篇；联锁可挂 AI，主贴仍 BQ；**不得互相顶替**；**不重写 AI 全文**。
- **AT（手册47）**：冷凝水与加湿除湿联锁；**AT ≠ BQ**——冷凝水/加湿除湿联锁过 ≠ 本篇；**加湿罐在 ≠ 低湿保护窗过**；**除湿过 ≠ 再热台账过**（除湿过冷析湿常是再热前置，但除湿联锁页不是再热台账）；加湿/冷凝可挂 AT，主贴仍 BQ；**不重写 AT 全文**。
- **BE（手册58）**：加湿器水质与电极/蒸汽罐更换；**BE ≠ BQ**——水质换罐过 ≠ 本篇；可挂 BE，主贴仍 BQ；**不重写 BE 全文**。
- **AU / AZ**：滤网压差与气流组织、冷通道封闭；**AU≠BQ；AZ≠BQ**——气流/冷通道过 ≠ 本篇；本篇气流证明是「投电加热前的书面证明」，不是 AU/AZ 那张台账；**不得互相顶替**。
- **BM（手册66）**：膨胀阀开度与过热控制；**BM ≠ BQ**——开度/过热控制过 ≠ 本篇；**BM 的过热是蒸发侧制冷过热，不是电加热器过热保护**；阀侧可挂 BM，主贴仍 BQ；**不重写 BM 全文**。
- **BP / BN / BJ / AX / BK 等**：转速调节、盘管清洗、吸排与过热过冷、压缩机冷媒等邻贴，**过了也不顶 BQ**；也**不得**用 BQ 去顶它们。
- **AO / AN / AL / AD / AA / AQ**：漏水探头 OK ≠ 本窗过；门禁/气灭过 ≠ 交底过；旧 AD 入库签不能顶本期窗；视频过 ≠ BQ 准用。
- **N（手册15）**：再热/低湿脏窗或加热器、低湿告警风暴挂 N，**不先抬功率**；**禁绕联锁、旁通、未授权强制投切或熔断低湿/加热器过热保护、临时电炉顶再热、带电违章检修**；N 绿 ≠ BQ 过。
- 假绿挂 **R**；变更走 **J** 后再验 BQ；覆盖/干扰可挂 X/I——**先 BQ 证再热与低湿保护秩序，再谈覆盖病**。

### 2.4 新贴纸 BQ：热 / 护 / 界 / 验 / 治（五个子类）

> 小彩蛋：双字母贴纸续写——**AA** 首年巡检起至 **BP** 冷凝风机转速与冷凝压力调节（对照见手册69 §2.4），A–Z 与 AA–BP 既有含义不改。本篇 **BQ** 管「电加热再热与低湿保护」（**BP 之后第一张 BQ**）。

```text
                ┌──────────── 贴纸 BQ · 热/护/界/验/治 ────────────┐
                │  BQ-热  热：电加热再热台账钉死（加热器·再热窗·本期对照） │
                │  BQ-护  护：低湿保护侧有主有窗有方法准用期（与再热侧分开看） │
                │  BQ-界  界：窗·方法钉死（与AI/AT/BE/N/AU/AZ/BM分工；     │
                │            加热器过热保护·无气流证明不得投电加热）         │
                │  BQ-验  验：本组本机房本期实测·禁套他站他期         │

                └──────────────────────────────────────────────────────┘
```

### 2.5 建再热台账 → 钉低湿保护窗 → 边界方法钉死 → 本期实测 → 会签放行 → 变更再验 阶段梯（背下来）

```text
  ① BQ-热 建电加热再热台账：机房/精密空调角色 · 电加热器角色 · 再热窗角色 · 本期对照 · 禁「灯绿就算过」「看着在加热就算过」「温度表绿就算过」「口头投过电加热」· 再热过≠低湿保护窗过

        ▼

        │  无主人 / 无窗 / 无方法 / 无准用期 → 拒进入「可签」状态
        ▼
  ③ BQ-界 钉边界方法：书面窗 · 方法（与 AI/AT/BE/N/AU/AZ/BM 分工；加热器过热保护、无气流证明不得投电加热；顺序与门限以本网与 OEM 书面为准） · 到场角色 · AD 备件/工具准用指针
        │  无窗 / 「绕联锁」/ 「开旁通冒充」/ 「未授权强制投切或熔断低湿保护/加热器过热保护教条」/ 「临时电炉顶再热」/ 「带电违章检修」/ 「伪造台账」 → 拒边界签

        │  套票 / 无会签 → 拒签

  ⑤ 会签放行「机房精密空调电加热再热与低湿保护巡检准用」；假绿挂 R；风暴挂 N；变更走 J 后再验
```

### 2.7 一晚怎么走完（教学节奏，不替代本网书面规程）

1. 翻 BQ1：再热台账在？灯绿/看着在加热/温度表绿≠准用、口头投过≠方法过、再热过≠低湿窗过、AI≠BQ / AT≠BQ / BE≠BQ 勾了吗？无本路径是否书面「不适用」？
2. 翻 BQ2：低湿保护主人/窗/方法/准用期；禁湿度表看着不低、禁低湿灯绿、禁湿度绿、禁套邻站照片；低湿保护窗过≠再热台账过、加湿罐在≠本窗过、除湿过≠再热台账过勾了吗？再热侧不适用≠保护侧自动免？
3. 翻 BQ3：边界书面方法；加热器过热保护与气流证明在不在方法里；禁绕联锁、禁旁通、禁未授权强制投切或熔断低湿/加热器过热保护、禁临时电炉、禁带电违章检修；邻贴分工勾清（尤其 AI/AT/BE；BM 过热≠加热器过热保护）。
4. 翻 BQ4：本期再热对照、本期低湿保护分别留痕；禁套声明。
5. 会签或拒签；风暴挂 N；变更走 J；L3。
