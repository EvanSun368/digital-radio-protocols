## 6. 工作实例（12 则，教学虚构，L3）

1. **加热器灯绿 / 口头投过想签**：称加热器灯绿、班长说投过要签 → 查 BQ1 无本期对照 → **拒签**；补 BQ-热。加热器灯绿 ≠ 再热台账过；口头投过电加热 ≠ 方法过。
2. **看着在加热 / 温度表看着在绿区**：称「看着在加热、温度表在绿区」免台账页 → **拒签**；补 BQ-热。看着在加热 / 温度表绿 ≠ 再热台账过。
3. **湿度表看着不低 / 低湿灯绿 / 湿度绿**：称「湿度不低、低湿灯绿、湿度绿」免保护窗 → **拒签**；补 BQ-护。湿度表看着不低 / 低湿灯绿 / 湿度绿 ≠ 低湿保护窗过。
4. **AI 顶替 BQ**：用温湿度与空调联锁签顶本期签 → **挂 R**；**温湿度联锁过 ≠ 本篇**。AI 并不单独给本篇台账。
5. **AT 顶替 BQ**：称冷凝水和加湿除湿联锁刚过、加湿罐还在、除湿也做过，低湿窗和再热免 → **拒签**；**冷凝水/加湿除湿联锁过 ≠ 本篇**；**加湿罐在 ≠ 低湿保护窗过**；**除湿过 ≠ 再热台账过**。
6. **BE 顶替 BQ**：用水质与电极/蒸汽罐更换签顶本期签 → **挂 R**；**水质换罐过 ≠ 本篇**。
7. **AU / AZ / BM 顶替 BQ**：称气流组织、冷通道或开度/过热控制刚过，气流证明或加热器过热保护免 → **挂 R**；**AU/AZ≠BQ**；**BM≠BQ**（BM 的过热是蒸发侧制冷过热，不是电加热器过热保护）。
8. **N / AO 顶替**：称监控绿或漏水探头绿了，本窗免 → **拒签**；各过 ≠ BQ 过；N绿≠本期实测过。
9. **再热顶低湿窗**：称再热签过故低湿窗免，或低湿窗勾过再热页照抄 → **拒签顶替**；再热过 ≠ 低湿保护窗过，反之亦然。
10. **套邻站表**：拷邻站再热/低湿表改机房号 → **BQ-验 拒签重测**。
11. **功率战 / 强制投切 / 熔断保护 / 绕联锁 / 旁通 / 临时电炉 / 带电违章**：加热器或低湿告警要抬功率，或未授权强制投/切除电加热、熔断低湿保护或加热器过热保护、绕联锁、开旁通、用临时电炉顶再热、带电违章检修后要求准用 → **一律硬禁**；先挂 N/R；缺秩序整改贴 BQ；禁签。
12. **无本路径乱签 / 泄密 / 用 BQ 顶邻贴**：纯冷冻水末端且无电加热、或未配置低湿保护路径却不写「不适用」乱签，或公开群贴真实精密空调或加热器序列号与再热门限，或拿 BQ 去顶 BP/BN/BJ → **拒签**并/或补书面不适用并/或 **L3 违规**；一侧不适用 ≠ 另一侧自动免；AI/AT/BE 过了或它们不适用 ≠ 本路径自动免。
