## 4. 深潜：八条硬规则 + 金机/漂移/巡检直觉 + 假病禁令

### 4.1 八条硬规则（本篇钉子）

1. **先证金机档案与基线可对，再谈「全网感觉正常」**——对照样没核，禁止宣布柜台货合格。  
2. **禁用加功率 / 加信道 / 乱拧 Hangtime 掩盖「机子怪」**——呼应手册07/09/11；功率不是漂移补丁。  
3. **大批量写频 / OTAP 后强制金机对照抽检**——指针手册14 M、手册11 J；M 完成账不替代 Q。  
4. **无漂移判据 / 无对照表 → 禁签放行**——「感觉差不多」不是判据。  
5. **漂移超阈 → 禁放行；先回滚 / 重写 / 隔离批次**——指针 J-回；禁止带病上勤。  
6. **金机 ≠ 随便好机；金机本身也要巡检（防金机先漂）**——变质的对照样比没有对照样更危险。  
7. **可挂 J/M/G，但主贴 Q；假绿拒签**——监控全绿、感觉正常，对不上对照表照样拒。  
8. **公开材料脱敏 L3；不写真实频点/楼名/站号/个号/密钥/单位名**——教学与公开仓双禁。

### 4.2 金机直觉：「对照样要有瓶签」（Q-金）

金机不是「这台听起来还行」的口语，而是**可审计的样本身份**：

| 字段（教学） | 像什么 | 常见坑 |
|--------------|--------|--------|
| **档案号** | 瓶签批号 | 口头「值班室那台」无号 |
| **机型族 / 固件气质** | 药品规格 | 跨机型拿来当金机 |
| **指纹摘要** | 配方摘要（非密钥） | 只写「已备份」无摘要字段 |
| **有效期 / 最近自巡** | 对照样复检日期 | 金机半年未自巡仍验货 |
| **存放与权限** | 药监柜双人 | 谁都能「临时改一下」 |

```text
  这台能当金机吗？
        │
        ▼
  有档案号+指纹摘要？──否──▶ 拒授牌（Q-金 / 规则6）
        │是
        ▼
  最近自巡在窗内？──否──▶ 先自巡/重锚；禁立即验货
        │是
        ▼
  记录 R2/R3；进入判据与抽检
```

### 4.3 漂移判据直觉：「检验指标要写在纸上」（Q-漂）

本篇讲**制度层对照**，**不写真实密钥、不 dump 厂商 CPS 全菜单、不发明哈希算法当法规**：

| 判据类（教学） | 白话 | 运维动作 |
|----------------|------|----------|
| **功能项勾选** | 紧急键/扫描/提示音等是否仍按现服 | 清单化；变更后重勾 |
| **信道逻辑摘要** | 区/信道逻辑表批次是否一致（脱敏） | 摘要对摘要，禁抄真实频点进公开包 |
| **测听气质** | 登记/有声/关键业务听感是否仍「过」 | 调用 G/J-验 气质，不重写全文 |
| **对照表/哈希气质** | CPS 工程对照或本网允许的摘要核对 | 有就用；无则诚实写「未建哈希，用摘要表」 |

> 公开 IT「金镜像漂移检测」只借「**活体配置要对比批准基线**」的常识——**不把某云厂商漂移工具名写进本网公开制度当强制。**

### 4.4 巡检抽样直觉：「空投完要开袋抽检」（Q-巡）

| 触发 | 最低动作（教学） | 拒签点 |
|------|------------------|--------|
| **大批量/OTAP 刚完成** | 强制抽检包：金机并测 + 分层抽现役 | 完成账有、抽检零 → 禁放行 |
| **周巡** | 按本网比例抽；含至少一台金机自巡 | 连续空窗 |
| **月巡** | 扩大比例或全关键岗位机 | 只抽「好说话的班组」 |
| **事件驱动** | 投诉簇/异常气质后追加抽检 | 用「偶发」糊弄 |

**和手册14 的咬合**：M-试 是起飞前试投；Q-巡 是落地后开袋——**两道都要过**。

### 4.5 对照复测直觉：「同一台天平」（Q-比）

```text
  抽检机「怪」
        │
        ▼
  金机并测同一剧本？──否──▶ 补 R7；禁单测结案
        │是
        ▼
  金机过、抽检不过 → 批次/个体漂移；回滚/重写路径（J-回）
  金机不过、抽检也不过 → 先疑金机先漂或剧本/台架；禁宣告「基站挂了」
  金机过、抽检过 → 记录过；可谈放行
        │
        ▼
  超阈？──是──▶ 禁放行（规则5）；隔离批次
```

### 4.6 「假干扰 / 假容量 / 假协议 / 假绿」怎么认

| 假病名 | 真身往往是 | 禁令 |
|--------|------------|------|
| 假干扰 | 批次漂移导致听感怪（Q-漂） | 禁先开 F 同频单 |
| 假容量 | 参数漂后队列/Hangtime 乱 | 禁加信道掩盖 |
| 假协议 | 写坏/漂后登记鉴权怪 | 先 Q/J，再挂 A–E |
| 假绿 | 监控正常、感觉正常、对照表不过 | 挂 N 气质，主贴 Q 拒签 |
| 假金机 | 无档案「好机」或金机已漂 | 规则6 |

### 4.7 假病禁令墙（与加功率叙事）

```text
  × 「机子怪，功率加两格」           → 规则2
  × 「Hangtime 拧大点压住」         → 规则2；指针 J/H
  × 「全网感觉正常，别抽了」         → 规则1/4
  × 「OTAP 完成账有了，抽检以后再说」→ 规则3
  × 「金机上周改过，档案明天补」     → 规则6；先隔离金机资格
  × 「超阈先上勤，周末再刷」         → 规则5
  × 「监控全绿说明配置没漂」         → 假绿；规则7
```

### 4.8 大批量后强制抽检最小包（可复印）

| 步骤 | 做什么 | 记录到 |
|------|--------|--------|
| 0 | 冻结加功率/乱拧叙事；确认 M 完成账与 J 现服索引 | R3/R5 |
| 1 | 核金机档案 + 金机自巡（若过期先自巡） | R2 |
| 2 | 按分层方案抽现役机（机型族/批次/岗位） | R6 |
| 3 | 金机与抽检机并测同一最小业务包（指针 G/J-验） | R7 |
| 4 | 对判据逐项：过/临界/超阈 | R4/R7 |
| 5 | 判定：放行 / 带条件 / 禁放行→回滚隔离；禁「感觉行」 | R8 |

> 口诀：**核样、写指标、开袋抽、对天平；超阈先回滚。**

### 4.9 和手册11 J / 手册14 M 怎么叠挂

- 变更当天空白 CPS、无备份 → **主 J**，本篇提醒写后还有 Q。  
- 舰队 OTAP 试投/完成账 → **主 M**，放行门槛叠加 **Q 抽检**。  
- 写完两周抽检对不上 → **主 Q**，回滚动作走 **J-回**。  
- 不要用「先加功率」换「先对基线」——禁令叠加时，**两个都要守**。

### 4.10 和弱项加餐的衔接

漂移管的是 **12.5 kHz** 这一格里账本是否与对照样对齐——**不**把信道变 25 kHz，也不改 4FSK / 30 ms。加功率叙事 → 回加餐 + 规则2。

### 5.2 对话脚本（六则）

**脚本 A · 大批量后要放行**  
对方：「完成报表都绿了，放行吧。」  
你：「M 完成账过了只说明写过程有账。按手册18，大批量后还要 Q 强制抽检：金机档案、判据、抽样、并测。R6/R7 空就不能签。」

**脚本 B · 感觉正常**  
对方：「全网感觉正常。」  
你：「感觉不是判据。把对照表和抽检结果拿来；没有 R4 我拒签。」

**脚本 C · 金机先漂**  
对方：「金机对照全军覆没，肯定是基站。」  
你：「先问金机档案上次自巡是哪天、有没有人临时改过。金机先漂会让所有对照说谎。先隔离金机资格，走 Q-金 + J-基 重锚。」

**脚本 D · 加功率掩盖**  
对方：「怪机功率加两格先顶上。」  
你：「禁止。漂移用回滚/重写/隔离，不用功率。规则2，写进拒签卡。」

**脚本 E · 只抽好班组**  
对方：「抽了两台办公室的，都好。」  
你：「抽样要分层：机型族、批次、关键岗位机。只抽好说话的班组 = 假抽检，R6 重做。」

**脚本 F · 公开包泄密**  
对方：「把真实频点和个号写进巡检报告方便对照。」  
你：「公开/教学包脱敏 L3。对照用摘要与档案号，不写真实频点个号密钥。」

### 5.4 夜班 15 分钟怎么用

1. 扫开口项：有无「待抽检放行」单（R5=大批量后且 R7 空）。  
2. 金机柜：档案号在不在、有无「临时改过未更新」便签。

4. 投诉簇涉及「写完后怪」→ 记事件驱动抽检，不等早班口头消化。

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「OTAP 完成账全绿，零抽检放行」→ Q-巡（次挂 M）

- **现象**：舰队 OTAP 完成报表成功/失败/未达齐全；当日宣布放行；三日后关键岗位机功能项对不上。  
- **误判**：有完成账 = 配置正常。  
- **正解**：M 过 ≠ Q 过；强制抽检包缺失 → 拒签级事故复盘；补抽检 + 超阈机回滚。  
- **贴纸**：主 Q-巡，次 M-界。

### 例 2 · 「值班室金机被临时改 Hangtime」→ Q-金（次挂 J-基）

- **现象**：金机对照突然大面积「不过」；有人喊基站挂了。  
- **误判**：先开基站故障单。  
- **正解**：金机上周夜班临时改过未更新档案；隔离金机资格 → 上一版重刷 → 自巡 → 再授牌。  
- **贴纸**：主 Q-金，次 J-基。

### 例 3 · 「感觉正常拒抽检」→ Q-漂 / Q-治

- **现象**：领导要求别折腾；无对照表。  
- **误判**：体感可替代判据。  
- **正解**：无 R4 禁签；书面判据补齐前不得宣布配置正常。  
- **贴纸**：Q-漂 + Q-治。

### 例 4 · 「怪机加功率」→ Q-治 + 规则2

- **现象**：抽检三台听感怪；有人建议功率加两格。  
- **误判**：覆盖病。  
- **正解**：先并测金机；确认批次摘要漂移 → 回滚/重写；功率工单作废。  
- **贴纸**：主 Q-治，禁挂「加功率结案」。

### 例 5 · 「只抽办公室机」→ Q-巡

- **现象**：抽样两台都过；一线车载机后来大量异常。  
- **误判**：抽检已做。  
- **正解**：未分层；R6 作废重抽（含关键岗位/批次）。  
- **贴纸**：Q-巡。

### 例 6 · 「只测抽检机不碰金机」→ Q-比

- **现象**：抽检机「过」就结案；金机实际已漂。  
- **误判**：单边测等于对照。  
- **正解**：无并测 = 没上同一台天平；补 R7。  
- **贴纸**：Q-比。

### 例 7 · 「超阈先上勤」→ Q-治 / 规则5

- **现象**：对照超阈；班次紧，先发机。  
- **误判**：业务优先可豁免阈值。  
- **正解**：禁放行；隔离批次；有线回滚路径（指针 J-回 / M-界）。  
- **贴纸**：Q-治。

### 例 8 · 「监控全绿当没漂」→ Q-治 + N

- **现象**：网管无告警；抽检摘要不对。  
- **误判**：假绿 = 真正常。  
- **正解**：配置漂移常不进性能告警；对照表优先；可挂 N。  
- **贴纸**：主 Q，次 N。

### 例 9 · 「公开巡检报告写真实个号频点」→ Q-治

- **现象**：为「好对照」把真实参数写进可外传材料。  
- **误判**：方便。  
- **正解**：L3 脱敏；用档案号与摘要；泄露按制度升级。  
- **贴纸**：Q-治。

### 例 10 · 「漂移当协议玄学」→ Q-比（次挂 A–E 仅排除后）

- **现象**：登记失败气质增多；有人直接手册01 开单。  
- **误判**：协议层优先。  
- **正解**：假干扰排除三问 → 发现刚批量；先 Q 抽检；确认漂后再决定是否次挂 A–E。  
- **贴纸**：主 Q，次挂仅在排除后。

### 6.5 漂移对齐会：20 分钟议程

1. 触发：批量后/周巡/事件（2′）  
2. 金机柜：档案与自巡窗（3′）  
3. 抽检：过/临界/超阈台数（5′）  
4. 超阈处置进度（5′）  
5. 假绿与加功率叙事（3′）  
6. 下窗复检写入日历（2′）
