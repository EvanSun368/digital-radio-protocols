## 1. 为什么要写这篇手册（动机 + 现场对话）

前十七篇手册教你认病、交维、写频、批量、电源监控、有源隔离、口部泄漏：贴纸 A–E 协议层，F 射频，G 实验室，H 话务，I 室分，J 写频，K 电源，L 井库，M 批量/OTAP，N 监控/对时/风暴，O 有源隔离，P 口部切换。可现场还有一类「病」——**不是当天空口才坏，而是对照样与柜台货慢慢漂开了，没人按周期抽检**：

- 写频员：「手册11 写完验过了，金机也过了，可以收工。」——两周后抽检三台，信道摘要/功能项对不上现服；没人做**漂移巡检**。  
- 班长：「值班室那台一直是金机。」——上周夜班「临时改一下」Hangtime，档案没更新；金机先漂，对照全部说谎（指针 J-基）。  
- 新人：「全网感觉正常，别折腾抽检了。」——感觉 ≠ 对照表；无漂移判据 = 假绿（可挂 N）。  
- 领导：「大批量 OTAP 进度条走完就行。」——手册14 完成账有了，但**写后强制金机对照抽检**没做；M 过不等于 Q 过。  
- 射频同事：「这几台怪，肯定干扰。」——可能是批次漂移（Q-漂）；先 Q，再挂 F。  
- 有人：「机子怪，功率再加两格 / Hangtime 拧大点。」——加功率/乱拧是手册07/09/11 禁区；本篇也禁。  
- 手册11 学过的人：「J-基 不是已经写过金机档案吗？」——J 管变更当天的读写回滚锚；本篇是 **大批量之后与日常周期的漂移巡检加深册**，主贴新贴纸 **Q**。  
- 手册14 学过的人：「M-界 完成报表不是强制吗？」——完成账管「写没写完」；本篇管「写完之后还漂不漂、抽不抽」。

这几句背后是同一件事：

> **「金机基线漂移巡检」这个词在现场至少有五个坑**：  
> **① Q-金**：金机档案与样本身份——谁是金机、档案号、机型/固件/codeplug 指纹（教学层摘要，**不写真实密钥**）  
> **② Q-漂**：漂移判据——相对基线的偏差：功能项 / 信道表摘要 / 测听气质 / CPS 哈希或对照表（教学层）  
> **③ Q-巡**：巡检周期与抽样——大批量写频后强制抽检；周/月巡；抽检比例  
> **④ Q-比**：对照与复测——金机 vs 现役抽检机；台架/金机走测气质指针 G/J  
> **⑤ Q-治**：治理与拒签——漂移超阈禁放行；禁用「感觉还行」结案；脱敏 L3  
> 把 ①–⑤ 当成「写完就永久正常」或「出了事用手册01–05 / 07 分诊」，会把整队配置债与假绿债留给下一班。

本篇目标：能背出**金机基线漂移巡检工作流**；会用新贴纸 **Q（金机/漂移/巡检）** 与五个子类；会填 **插页 Q（R1–R8）** 和《本网金机基线漂移巡检卡》；能用「**药监对照样 + 柜台货抽检**」故事讲清金机与现役机慢慢漂开；能拒绝「无档案就说金机、无判据就放行、大批量后不抽检、用加功率掩盖机子怪、金机本身从不巡检」；自测过关后，回库把本网最近一次写频后抽检/金机漂移事件（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：不发明 ETSI 条款号；**不写真实批复频点、楼名、站号、个号、密钥、单位名进公开仓库**；**不教攻击/仿冒/破解/空口劫持**——只讲制度与治理；不重写手册11 / 14 / 08 / 15 全文（只给指针）；**J/M 仍生效，本篇加深漂移巡检**；**不把加功率/加信道/乱拧 Hangtime 当「机子怪」止痛药**；漂移**主贴 Q**，可挂 J/M/G/N；结案用 Q + 本网证据；公开 CM/漂移资料只借**精神与顺序**——**不背条款当 ETSI、不背 CPS 菜单当制度、不把蜂窝 KPI 抄进 DMR 公开包当法规**。

## 2. 总图 / 故事：金机像「药监对照样 + 柜台货抽检」

### 2.1 一句话：必须先证明金机档案可对、漂移判据书面、大批量后抽检过关，再谈「全网感觉正常」——否则对照样先漂、柜台货悄悄变质、交维假绿

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  药监所 / 药店柜台（本网金机制度柜 · 现役机队）                 │
   │                                                              │
   │   对照样 = 金机（Q-金）——有档案号、批号、指纹摘要的标准样       │
   │   柜台货 = 现役抽检机（Q-巡 / Q-比）——应按同一配方出厂          │
   │   配方卡 = 基线/现服索引（指针 J-基）——现服 + 上一版            │
   │   检验指标 = 漂移判据（Q-漂）——功能项/信道摘要/测听/对照表      │
   │   抽检节奏 = 巡检周期（Q-巡）——大批量后强制；周/月巡；比例      │
   │   对天平 = 对照复测（Q-比）——金机 vs 抽检机；可挂 G 气质        │
   │   拒签台账 = 治理（Q-治）——超阈禁放行；禁「感觉还行」；L3       │
   │                                                              │
   │   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐     │
   │   │ 核金机  │──▶│ 写判据  │──▶│ 定抽检  │──▶│ 对照复测│     │
   │   │ (Q-金)  │   │ (Q-漂)  │   │ (Q-巡)  │   │ (Q-比)  │     │
   │   └────┬────┘   └────┬────┘   └────▲────┘   └────┬────┘     │
   │        │             │             │              │           │
   │        │无档案禁金    │无判据禁签   │批量后强制    │对不上超阈 │
   │        ▼             ▼             │              ▼           │
   │   ┌─────────┐   ┌─────────┐       │         ┌─────────┐     │
   │   │ 金机自巡│   │ 回滚隔离│───────┘         │ 拒签放行│     │
   │   │ (Q-金)  │   │ (J-回)  │                 │ (Q-治)  │     │
   │   └─────────┘   └─────────┘                 └────┬────┘     │
   │        ▲                                          │           │
   │   禁加功率/加信道/乱拧 Hangtime 掩盖「机子怪」→ 治理（Q-治）◀─┘ │
   │   禁：感觉正常结案；金机从不巡；批量完成账代替漂移抽检          │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **先核对照样，再写检验指标，后定抽检节奏，末上柜台货对天平。**  
> 对照样先漂还拿去验货 = 药监自己变质——**金机本身也要巡检。**  
> 大批量写完不抽检 = 空投完不打开包装袋尝一口——**M 过 ≠ Q 过。**

### 2.2 「对照样与柜台货」五段直觉（弱项短补，钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **金机身份** | 药监柜里的对照样瓶 | 谁是金机、档案号、机型/固件/指纹摘要；金机≠随便好机 | Q-金 |
| **漂移判据** | 检验指标单 | 相对基线偏多少算漂：功能项/信道摘要/测听气质/对照表（教学层，不写密钥） | Q-漂 |
| **巡检抽样** | 抽检节奏与比例 | 大批量/OTAP 后强制；周巡/月巡；抽几台、怎么抽 | Q-巡 |
| **对照复测** | 柜台货 vs 对照样上同一台天平 | 金机与抽检机并测；可挂 G/J 气质 | Q-比 |
| **治理拒签** | 超标批次禁出库 | 超阈回滚/重写/隔离；禁感觉结案；脱敏 L3 | Q-治 |

> 公开配置管理常识（如 NIST SP 800-53 CM-2 / CM-3、SP 800-128 SecCM 公开页所说）：**维护基线、保留先前配置以支持回滚、检测未授权变更（漂移）**。本篇只借**顺序直觉**：核金机 → 写判据 → 定抽检 → 对照复测 → 超阈治理。**不背条款号当 ETSI / 不背厂商 CPS 菜单当本网制度 / 不把 IT 金镜像工具名抄进 DMR 公开包当法规。**

### 2.3 和手册11 / 14 / 08 / 15 / 06 的咬合（指针，不重写）

- **手册11 贴纸 J**：写频变更回滚与金机基线——**J-基** 建档案，**J-回** 管验失败回滚；本篇是 **漂移巡检加深册**。变更当天仍走 J；**写完之后漂不漂、抽不抽主贴 Q**。  
- **手册14 贴纸 M**：大批量/OTAP——完成账管「写没写完」；**写后强制金机对照抽检用 Q 钉死**（M 过 ≠ Q 过）。  
- **手册08 贴纸 G**：实验室金机对照闭环——Q-比 **调用** 金机业务闭环气质，不重写六闭环全文。  
- **手册15 贴纸 N**：监控/对时/风暴/假绿——「全网感觉正常」常是假绿；漂移抽检拒签可挂 N，**主贴仍 Q**。  
- **手册06**：证据五要素与脱敏 L0–L3；公开仓/教学材料 **≥L2，教学例强制 L3**。  
- **手册01 / 02 / 05**：坏写频/漂移可表现为登记怪、Grant 无声、鉴权失败气质——先问「最近批量写过吗、金机档案是否仍准」，再进协议分诊。  
- **手册07 / 09**：加功率、加信道、乱拧 Hangtime **不是**漂移止痛药。

### 2.4 新贴纸 Q：金机 / 漂移 / 巡检（五个子类）

```text
                    ┌──────── 贴纸 Q · 金机/漂移/巡检 ────────┐
                    │  Q-金  金机档案与样本身份：谁是金机·档案号·机型/固件/指纹摘要 │
                    │  Q-漂  漂移判据：功能项/信道摘要/测听气质/对照表（教学层）   │
                    │  Q-巡  巡检周期与抽样：大批量后强制·周/月巡·抽检比例         │
                    │  Q-比  对照与复测：金机 vs 现役抽检机；可挂 G/J 气质         │
                    │  Q-治  治理与拒签：超阈禁放行·禁感觉结案·脱敏 L3           │
                    └──────────────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签 / 拒放行触发 |
|------|--------|----------------------|
| **Q-金** | 金机无档案或金机本身未巡 → 禁当对照样 | 「值班室那台一直好」但无档案号 |
| **Q-漂** | 无书面漂移判据 / 无对照表 → 禁签放行 | 「感觉差不多」当判据 |
| **Q-巡** | 大批量/OTAP 后未抽检 → 禁放行 | 完成账有、抽检零 |
| **Q-比** | 金机 vs 抽检机未并测 → 禁结案 | 只测抽检机不碰金机 |
| **Q-治** | 超阈未回滚/隔离仍放行；假绿；泄密 | 「先上勤再慢慢改」 |

### 2.5 金机基线漂移巡检最小工作流（背下来）

```text
  要宣布「全网/本批配置正常」或大批量后放行
        │
        ▼
  金机档案在？身份可指认？金机自身最近巡过？──否──▶ 拒（Q-金 / 规则6）
        │是
        ▼
  漂移判据书面？对照表/摘要字段齐？──否──▶ 拒签（Q-漂 / 规则4）
        │是
        ▼
  本窗口是否大批量/OTAP 后？──是──▶ 强制抽检包（Q-巡 / 规则3；指针 M）
        │否（日常周/月巡）
        ▼
  按本网比例抽检现役机 + 金机并测（Q-比；可挂 G）
        │
        ▼
  相对基线：过 / 临界 / 超阈？
        │过 → 记巡检卡；可谈「正常」
        │临界 → 带条件；缩短复检窗
        │超阈 → 禁放行；回滚/重写/隔离批次（Q-治 + J-回）；禁加功率叙事
```

现场口诀：

> **先核样，再写指标，后抽检，末对天平。**  
> 跳过抽检的「感觉正常」= 没打开包装就说药没过期。

## 3. 核心交付：插页 Q + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 Q（而不是先贴 J / M / G / N）

| 现场信号 | 主贴 | 可次挂 |
|----------|------|--------|
| 大批量/OTAP 刚完成，要宣布放行 | **Q**（强制抽检） | M（完成账）、J（回滚入口） |
| 「机子怪」但最近写过/批量过 | **Q** | J/M；排除后再挂 F/A–E |
| 金机对照突然全军说谎 | **Q-金**（金机先漂） | J-基、G |
| 无判据却要签「配置正常」 | **Q-漂 / Q-治** | N（假绿） |
| 变更当天空白 CPS / 无备份要写 | 仍主贴 **J** | 本篇可挂 Q 气质提醒「写后还要巡」 |
| 监控全绿但抽检对不上 | **Q** | N |

> **口诀**：变更当天的读写回滚走 **J**；舰队尺度的试投完成账走 **M**；**写完之后漂不漂、周期抽不抽走 Q**。三者可叠挂，漂移巡检**主贴 Q**。

### 3.2 插页 Q · 金机 / 漂移 / 巡检（挂在总三联单或写频/批量作业包首页后）

| 行 | 名称 | 填写示例（教学虚构） |
|----|------|----------------------|
| **R1** | 主子类 + 次子类 | 「主 Q-巡 / 次 Q-比」（或 Q-金 / Q-漂 / Q-治） |
| **R2** | 金机身份 | 「档案号 G-18-07；机型族 T；固件标签（脱敏）；指纹摘要批次 B」（禁真实个号密钥） |
| **R3** | 基线指针 | 「现服索引号；上一版档案号；最近 J 变更单号（脱敏）」 |
| **R4** | 漂移判据 | 「功能项清单勾选；信道逻辑表摘要；测听气质项；对照表版本」（教学层） |
| **R5** | 巡检触发 | 「大批量后强制 / 周巡 / 月巡 / 事件驱动（投诉簇）」 |
| **R6** | 抽样方案 | 「比例或台数；分层（机型族/批次）；随机+关键岗位机」 |
| **R7** | 对照复测 | 「金机与抽检机并测结果；可挂 G 闭环气质；过/临界/超阈」 |
| **R8** | 判定与动作 | 「放行 / 带条件（缩短复检）/ 禁放行→回滚重写隔离；脱敏 L3」 |

> **R2 与 R4 不过 → 禁止以「金机对照」名义签字。**  
> **R5 若为大批量后且 R6/R7 空 → 禁止放行（规则3）。**  
> **R8 若写「加功率/拧 Hangtime 试试」或「感觉还行」→ 本页作废重填。**

### 3.3 「无档案 / 无判据 / 未抽检 / 超阈」拒签卡（贴写频室 / 交维台 / 网管）

```text
  ┌────────────── 金机漂移巡检拒签卡（贴纸 Q）──────────────┐
  │  × 金机无档案号/指纹摘要就把某台当对照样                  │
  │  × 金机本身超过本网巡检窗未自检仍拿去验货                  │
  │  × 无书面漂移判据 / 无对照表就签「配置正常」                │
  │  × 大批量写频/OTAP 后零抽检就放行（有完成账也不行）        │
  │  × 只测抽检机、不并测金机就结案                            │
  │  × 漂移超阈仍放行；「先上勤再慢慢改」                      │
  │  × 用加功率 / 加信道 / 乱拧 Hangtime 掩盖「机子怪」        │
  │  × 用「全网感觉正常」或监控假绿代替对照表                  │
  │  × 公开包出现真实频点 / 个号 / 密钥 / 站名 / 单位名        │
  │  √ 例外：书面窗、原因、审批、到期复检——写进 R8             │
  └────────────────────────────────────────────────────────┘
```

### 3.4 和总三联单怎么写（接手册06）

- **现象**：写「抽检机信道摘要与现服不符」或「金机档案过期未自巡」，不要写「干扰」除非已排除 Q。  
- **证据**：金机档案号（脱敏）、判据版本、抽样清单、对照结果相对描述、回滚单号指针。  
- **时钟**：若与手册15 风暴同时，写清三钟差；漂移大则禁秒级因果。  
- **贴纸栏**：主 **Q-? **，次挂 J/M/G/N（若有）。  
- **结案词**：用 Q 子类 + 动作（复检/回滚/隔离/拒签），禁用「加功率好了」「感觉正常了」。
