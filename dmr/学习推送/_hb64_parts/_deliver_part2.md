## 3. 核心交付：插页 BK + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 BK（而不是先贴 AU / BG / AT / AI / AX / BJ / AO / N）

- 要签「机房精密空调蒸发器盘管清洗与翅片完好巡检准用」、要开蒸发器盘管清洗交底窗、要交底翅片完好侧 → **主贴 BK**。  
- 滤网压差与气流组织 → **AU**（手册48）。滤网更换 → **BG**（手册60）。**AU ≠ BK；BG ≠ BK**；不重写 AU/BG。  
- 冷凝加湿联锁 → **AT**。温湿度联锁 → **AI**。压缩机与制冷剂边界 → **AX**。吸排气压力与过热度过冷度 → **BJ**。漏水汇排 → **AO**。**AT ≠ BK；AI ≠ BK；AX ≠ BK；BJ ≠ BK；AO ≠ BK**。  
- 进机房先 **AN**（门禁过 ≠ 交底过）。气灭 → **AL**。风暴先 **N**，缺秩序整改仍 **BK**；滤网另问 **AU/BG**；温湿度另问 **AI**；冷凝另问 **AT**；本体另问 **AX**；吸排/过热过冷另问 **BJ**；**禁功率战、绕联锁、旁通、不安全化学清洗教条、高压水乱冲教条**。  
- 假绿/顶替挂 **R**；变更走 **J** 后再验 BK。  
- 无蒸发器盘管/直膨盘管路径（例如仅冷冻水 CRAH 且无独立盘管清洗窗） → 书面「不适用」；冷冻水侧问 BA/BD，**不得**用 BK 顶 AU/BG/AI/AT/AX/BJ，也不得用它们顶 BK。

### 3.4 与总三联单怎么写（脱敏 L3）

- **现象栏**：写「盘管缺账 / 看着干净无核对 / 口头洗过 / 滤网绿顶盘管 / 翅片看着齐 / 一侧顶另一侧 / 他贴顶 BK / 套票 / 不安全清洗教条/高压水乱冲/旁通绕联锁嫌疑」等角色化现象；**不写**真实机房全称、精密空调序列号全文、可还原盘管细节或门限全文。  
- **贴纸栏**：主贴 **BK**；邻贴指针 AU/BG/AT/AI/AX/BJ/AO/AN/AL/N/R/J 按需勾。  
- **处置栏**：补 BK-洗 / 补 BK-翅 / 补 BK-界 / BK-验 重测 / 会签或拒签 / 挂 R / 挂 N / 走 J。  
- **会签栏**：准用 / 有条件整改 / 拒签；假绿 ≠ 放行。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **盘管清洗台账钉死**：蒸发器盘管角色与清洗窗、清洗前后对照各自有账（编号脱敏）；禁「盘管看着干净就算过」「口头说洗过了」「滤网绿就算盘管过」；清洗过 ≠ 翅片过，翅片过 ≠ 清洗过。  
2. **翅片完好侧有主有窗有方法/准用期**：弯曲、压扁、缺失、大面积倒伏或堵塞对照以本网与 OEM 书面为准；每次翅片交底有主人角色、有书面窗、有方法、有准用期；禁「翅片看着齐就算过」「套邻站翅片照片」；翅片过 ≠ 清洗过。  
3. **边界窗与方法钉死**：书面固定；方法含与 AU/BG/AT/AI/AX/BJ/AO/N 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明化学清洗配方、高压水乱冲步骤或绕联锁操作教条；**不重写 AU/BG/AT/AI/AX/BJ 全文**）；禁「窗再说」「绕气流/压差/机组等保护联锁」「开旁通冒充」「不安全化学清洗教条」「高压水乱冲教条」「伪造台账」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、盘管清洗对照、翅片完好必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「机房精密空调蒸发器盘管清洗与翅片完好巡检准用」；假绿 ≠ 放行。  
6. **禁顶替 AU/BG/AT/AI/AX/BJ/AO/AD/AA/N/AQ/AY/AZ/BB/BA/BE/AF/AS/AW 等，主贴 BK，假绿≠放行挂 R**：他贴签都不顶本期盘管清洗/翅片完好签。**尤其：AU ≠ BK，BG ≠ BK，AT ≠ BK，AI ≠ BK，AX ≠ BK，BJ ≠ BK，AO ≠ BK；滤网压差/换网过 ≠ 盘管清洗/翅片完好过；冷凝加湿过 ≠ 盘管/翅片过；温湿度过 ≠ 盘管/翅片过；压缩机/制冷剂边界过 ≠ 盘管清洗/翅片完好过；吸排/过热过冷过 ≠ 盘管清洗/翅片完好过；漏水探头过 ≠ 窗过；看着干净 ≠ 台账过；看着齐 ≠ 窗过；口头洗过 ≠ 窗过；滤网绿 ≠ 盘管过。**  
7. **盘管脏堵/翅片损伤/清洗窗乱签/告警风暴挂 N，边界/门限/窗变更走 J，禁功率战；禁绕联锁；禁不安全化学清洗教条；禁高压水乱冲教条；禁旁通；禁伪造台账**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。盘管/翅片乱窗、假绿、高温高湿/气流告警风暴常被误当「覆盖病」→**禁功率战**；挂 N；变更走 J。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/精密空调序列号全文/可还原坐标与联系人；禁公开传播未脱敏盘管细节、清洗参数与门限**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签盘管清洗/翅片完好准用、无实测冒充边界过、绕联锁/旁通/不安全清洗教条/高压水乱冲冒充秩序齐，不是法外运维智慧**。医院/数据中心公开资料只作故事类比（§10），翻译成本网语言就是 BK-洗 / BK-翅 / BK-界 / BK-验 / BK-治。

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机房精密空调蒸发器盘管清洗与翅片完好巡检准用」、对外宣传「看着干净/看着齐/口头洗过/滤网绿秒过」、把未实测写成已过、把绕联锁/旁通/不安全化学清洗教条/高压水乱冲写成秩序齐。允许做的：补盘管清洗台账、补翅片完好窗、重开边界窗、挂 R/N/J、内部挂整改。

### 4.3 「机房精密空调蒸发器盘管清洗与翅片完好巡检准用」最小集（BK）——缺页不能签准用

1. 盘管清洗台账页（蒸发器盘管·清洗窗·清洗前后对照；含看着干净≠台账过、口头洗过≠窗过、滤网绿≠盘管过、一侧过≠另一侧过勾选）  
2. 翅片完好侧主人与书面窗、方法、准用期页（弯曲/压扁/缺失/堵塞分开看；含禁看着齐、禁套邻站照片勾选）  
3. 书面边界窗与方法页（与 AU/BG/AT/AI/AX/BJ/AO/N 分工；以本网与 OEM 为准；声明不重写 AU/BG/AT/AI/AX/BJ）  
4. 本期本组本机房实测记录（盘管清洗对照、翅片完好分别留痕；禁套声明）  
5. AU/BG/AT/AI/AX/BJ/AO 边界勾选（防顶替：滤网压差/换网过≠盘管清洗/翅片完好过，冷凝加湿过≠盘管/翅片过，温湿度过≠盘管/翅片过，压缩机冷媒边界过≠盘管/翅片过，吸排/过热过冷过≠盘管/翅片过，漏水探头过≠窗过）  
6. AD/AN/AL/N/AA/AQ 与 AY/AZ/BB/BA/BE 等边界勾选（入库≠本期窗；门禁/气灭过≠交底过；N 绿≠BK 过；各过≠BK 过）  
7. 会签页（准用或有条件整改）  
8. 未闭项清单（有则挂整改，重大未闭禁签准用）  
9. 脱敏勾选（L3）  
10. 变更指针（若本期有盘管角色/清洗或翅片窗方法/门限变更 → J）  
11. 不适用声明（无蒸发器盘管/直膨盘管路径，或仅冷冻水 CRAH 且无独立盘管清洗窗，书面勾选；不得顶 AU/BG/AI/AT/AX/BJ；一侧不适用 ≠ 另一侧自动免）

> **口诀**：洗、翅、界、窗、房、测、签、闭、密、界——**十字盘管钉**（教学记忆；现场以本网书面规程为准，但 **盘管清洗台账 + 翅片完好窗方法 + 边界方法 + 本组本机房本期实测 + 会签** 几乎不可砍）。

### 5.2 对话脚本（教学）

**脚本A（盘管看着干净 / 口头洗过想签）**  
新人：「盘管看着挺干净的，班长也说上个月洗过了，签准用吧。」  
班长：「BK1——蒸发器盘管清洗台账和本期对照呢？盘管看着干净≠清洗台账过，口头说洗过了≠窗过。补账再谈会签。」

**脚本B（AU / BG 顶替）**  
外包：「AU 滤网压差气流签还在，BG 刚换过网，盘管和翅片免了。」  
班长：「AU≠BK，BG≠BK。滤网压差/气流回AU，换网回BG；盘管清洗与翅片完好主贴仍BK。滤网绿≠盘管过，换网过≠翅片过。顶替挂R。本篇不重写AU/BG全文。」

**脚本C（AI / AT / 翅片看着齐）**  
外包：「回风温度稳，冷凝加湿也刚过，而且翅片远看齐刷刷的，窗页免了。」  
班长：「AI 温湿度过≠盘管/翅片过；AT 冷凝加湿过≠盘管/翅片过；翅片看着齐≠窗过。补BK-翅主人窗方法。本篇不重写AI/AT全文。」

**脚本D（AX / BJ 顶替）**  
外包：「AX 压缩机冷媒边界刚过，BJ 吸排和过热过冷也刚测过，换热没问题，清洗免了。」  
班长：「AX≠BK，BJ≠BK。压缩机/制冷剂边界回AX，吸排/过热过冷回BJ；盘管清洗与翅片完好主贴仍BK。空气侧脏、翅片扁，压力和过热过冷即使当时能读到数，也不能顶清洗台账。」

**脚本E（不安全清洗教条 / 高压水 / 绕联锁 / 套票）**  
外包：「邻站清洗表改个机房号交差。或者按经验配点药冲，高压水枪对着翅片冲，气流保护先绕开。」  
班长：「BK-验拒签重测。禁套他站他期。禁不安全化学清洗教条，禁高压水乱冲教条，禁旁通，禁绕联锁。挂N/R，禁签。清洗过≠翅片过。」

禁止写：真实站名、机房全称、精密空调序列号全文、单位名、联系人、真实频点、未脱敏门限与盘管细节；禁止写「看着干净就过」「看着齐就过」「口头洗过就过」「滤网绿就盘管过」「他贴顶 BK」「抬功率」「不安全化学清洗配方/步骤」「高压水乱冲步骤」「旁通/绕联锁」「套邻站表」。允许写：脱敏角色、现象、贴纸（BK/AU/BG/AT/AI/AX/BJ/AO/N/R/J）、动作（补账/重测/拒签）。

### 5.5 与弱项的现场对照（再钉一次）

盘管乱账、翅片乱窗、假绿、高温/气流/脏堵告警风暴，常先伤站点环境与**上行**体验。有人把这些当「覆盖病」抬功率——**禁功率战**。先问 BK 秩序并分诊 AU/BG/AT/AI/AX/BJ/AO，风暴挂 N，变更走 J。弱项短补：**12.5 kHz / 4FSK / 2-slot TDMA**。
