## 1. 为什么要写这篇手册（动机 + 现场对话）

前六十三篇手册从 A–E 协议一路写到 BJ 压缩机吸排气压力与过热度过冷度：其中 **AU 回答「滤网压差与气流组织」**（滤网台账 + 压差本体窗 + 冷热通道/盲板/气流方向，**并不**给蒸发器盘管清洗和翅片完好各钉一张巡检台账），**BG 回答「过滤器压差与滤网更换」**（更换窗 + 更换前后 ΔP，换网过 ≠ 盘管洗过），**AT 回答「冷凝水与加湿除湿联锁」**（盘管脏了冷凝水可能更乱，但冷凝加湿过 ≠ 盘管/翅片过），**AI 回答「温湿度与空调联锁巡检边界」**（回风温度绿 ≠ 盘管清洗过），**AX 回答「压缩机与制冷剂边界」**，**BJ 回答「吸排气压力与过热度过冷度巡检」**（盘管脏、翅片扁会让换热和过热过冷一起乱，但吸排/过热过冷过 ≠ 盘管清洗/翅片完好过），**AO 回答「漏水与汇流排探测」**，**N 回答「监控对时与告警风暴」**，**AY / AZ / BB / BA / BE / AD / AN / AA / AQ** 各管新风正压防火阀、冷通道进出风、风冷室外机冷凝侧、冷冻水冷却塔侧、加湿器水质换罐、备件、门禁、首年巡检与视频证据。可还没有单独钉死一件事——**机房精密空调蒸发器盘管清洗与翅片完好不是「盘管看着干净 / 翅片看着齐 / 口头说洗过了 / 滤网绿 / AU 或 BG 滤网过 / AT、AI、AX、BJ、AO 过就能签」：蒸发器盘管的清洗台账要钉死；翅片完好侧要有主人有窗有方法有准用期；边界窗与方法要书面固定；本期实测禁套他站他期——能不能签「机房精密空调蒸发器盘管清洗与翅片完好巡检准用」？** 这就是本篇的 **BK**——**机房精密空调蒸发器盘管清洗与翅片完好交底台账**（Excel 风格双字母：BJ 之后 → **BK**）。
