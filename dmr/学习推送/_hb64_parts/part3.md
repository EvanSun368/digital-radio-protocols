## 6. 工作实例（12 则，教学虚构，L3）

1. **盘管看着干净 / 口头洗过想签准用**：称盘管外观干净、班长说洗过要签 → 查 BK1 无本期清洗对照 → **拒签**；补 BK-洗。  
2. **翅片看着齐 / 套邻站翅片照片**：称「远看齐刷刷 / 邻站照片差不多」免窗页 → **拒签**；补 BK-翅。  
3. **AU 顶替 BK**：用滤网压差/气流签顶本期盘管清洗/翅片完好签 → **挂 R**；**滤网压差/气流过 ≠ 盘管清洗/翅片完好过**。  
4. **BG 顶替 BK**：称刚换网、滤网是新的，盘管翅片免做 → **挂 R**；**换网过 ≠ 盘管清洗/翅片完好过**。  
5. **AT 顶替 BK**：称冷凝加湿过了，盘管翅片免 → **拒签**；**冷凝加湿过 ≠ 盘管/翅片过**。  
6. **AI 顶替 BK**：称温湿度刚过、回风稳，清洗窗免做 → **挂 R**；**温湿度过 ≠ 盘管/翅片过**。  
7. **AX 顶替 BK**：用压缩机/制冷剂边界签顶本期盘管/翅片签 → **挂 R**；**压缩机/制冷剂边界过 ≠ 盘管清洗/翅片完好过**。  
8. **BJ 顶替 BK**：称吸排压力和过热过冷刚过，换热没问题，清洗免 → **拒签**；**吸排压力/过热过冷过 ≠ 盘管清洗/翅片完好过**。  
9. **AO 顶替 / N 绿免实测**：称漏水探头绿或大屏监控绿，本期实测免 → **拒签**；漏水探头过 ≠ 窗过；N绿≠BK过；补 BK-验。  
10. **套邻站表**：拷邻站清洗/翅片表改机房号 → **BK-验 拒签重测**。  
11. **功率战 / 不安全化学清洗教条 / 高压水乱冲 / 绕联锁 / 旁通**：高温或气流告警要抬功率，或按经验配药冲、高压水枪冲翅片、绕保护、开旁通后要求准用 → **禁功率战**；**禁不安全化学清洗教条**；**禁高压水乱冲教条**；**禁绕联锁**；**禁旁通**；先挂 N/R；缺秩序整改贴 BK；禁签。  
12. **清洗顶翅片 / 无蒸发器路径乱签 / 泄密**：称清洗签过故翅片免，或仅冷冻水 CRAH 且无独立盘管清洗窗却不写「不适用」乱签准用，或公开群贴真实精密空调序列号与盘管细节 → **拒签顶替**并/或补书面不适用并/或 **L3 违规**；一侧不适用 ≠ 另一侧自动免。
