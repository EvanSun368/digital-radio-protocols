## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 本篇用法（教学） |
|------|------------------|
| **AV** | 本篇贴纸：日用油箱油品·净化·加油交接交底 |
| **AV-油** | 油品台账（油种·批次·取样点·日用油箱） |
| **AV-净** | 净化有主有窗有方法准用期（滤芯·分水器·净化装置） |
| **AV-交** | 加油交接窗与书面方法（到场、计量、交接单、封样/留样指针等） |
| **AV-验** | 本组本机房本期实测·禁套·会签 |
| **AV-治** | 假绿·顶替·绕联锁·不安全泄油·私自掺油·功率战·泄密治理 |
| **日用油箱 / Day Tank** | 供油机短时运行的日用（日柜）油箱角色；本篇钉油品与加油交接，不替代 AR 的燃油安全巡检 |
| **油品 / 油样** | 油种·批次·取样点角色；看着有油≠油品合格；门限以本网与 OEM 书面为准 |
| **净化 / 燃料抛光（Fuel Polishing）** | 通过过滤/分水等书面方法去除水与杂质的角色；滤芯在≠窗过 |
| **分水器 / 滤芯** | 分水与过滤装置角色；读数/更换要有窗有方法；入库走 AD 不顶 AV 窗 |
| **加油交接** | 到场·计量·交接单·封样/留样指针；口头说加过油≠方法过 |
| **封样 / 留样指针** | 按本网书面规程的取样留痕角色（本篇不写死取样步骤） |
| **油品净化加油准用** | 会签后允许宣称本期油品净化加油交底合格；假绿≠准用 |
| **假绿** | 监控绿/油位绿/滤芯在冒充准用；挂 R |
| **套票** | 套他站他期曲线/照片/油样报告；AV-验拒签 |
| **L3** | 对外脱敏等级：禁真实站名/全称/序列号/单位名/联系人 |
| **AR / AF / AD / N** | 燃油安全 / 油机市电 / 备件仪表 / 监控风暴——均不顶替 AV |
| **R / J** | 假绿挂 R；变更走 J 后再验 AV |

**易错观念（纠一次）**

1. 「看着有油 = 油品合格」→ **错**。要有台账与本期油样实测。  
2. 「滤芯还在 = 窗过」→ **错**。要有主人、窗、方法、准用期。  
3. 「AR 燃油安全过 = AV 过」→ **错**。AR≠AV。  
4. 「AF 油机市电过 = AV 过」→ **错**。AF≠AV。  
5. 「AD 滤芯入库过 = 净化窗过」→ **错**。AD≠AV。  
6. 「N 监控绿 = 本期油品实测过」→ **错**。N≠AV。  
7. 「油品告警烦，先旁路联锁 / 不安全泄油 / 私自掺油」→ **禁**。绕联锁/泄油/掺油挂 N/R。  
8. 「低油位/油品告警先抬功率」→ **禁功率战**。  
9. 「邻站油样报告改机房号能交差」→ **套票拒签**。

### 参考答案

1. 油 / 净 / 交 / 验 / 治；口诀：**油品有账，净化有窗，交接有法，会签才放。**  
2. 违反规则1（油品台账钉死）；属 **AV-油**。  
3. 规则2。  
4. AR 管柴油发电机房**通风排烟与燃油安全巡检**（油位·泄漏·通气·围堰）；AF 管**油机市电切换与供电巡检**；AV 管日用油箱**油品台账·净化窗·加油交接交底准用**；**不能**互相顶替；AR 过≠AV 过；AF 过≠AV 过。  
5. **不能**。AD 入库过≠净化窗过；主贴仍 AV。  
6. **不能**。N 绿≠AV 过；要有本期油品/净化/加油实测与会签。  
7. **AV-验**；拒签；重测本期本组本机房。  
8. 走 **J**，再验 **AV**。  
9. **不能**抬功率（禁功率战）；先挂 **N** 理风暴；缺油品/净化/加油秩序整改贴 **AV**；**禁不安全泄油**；**禁私自掺油冒充净化过**。  
10. AV1 油；AV2 净；AV3 交；AV4 验；AV5 与 AR/AF/AD/N 等边界；AV6 会签；AV7 拒签触发；AV8 15 分钟夜班。  
11. **12.5 kHz**、**4FSK**、**2-slot TDMA**；低油位/油品告警常被误当成覆盖病去抬功率——**禁功率战**；先 AV/N 证秩序。  
12. 禁：真实站名、机房全称、日用油箱序列号全文、单位名、联系人、真实频点、未脱敏可还原编号；允许：脱敏角色、现象、贴纸、动作（补账/重测/拒签）。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AV** 五子类：油 / 净 / 交 / 验 / 治——双字母续写的第二十二张，负责日用油箱油品净化加油「台账清不清、净化有没有窗、交接有没有法、本期过了没有」。  
- 口诀：**油品有账，净化有窗，交接有法，会签才放。**  
- 故事：医院手术室/ICU 保供电机房备用柴油发电机日用油箱——看着有油≠油品合格；滤芯还在≠窗过；口头说加过油≠方法过。  
- 八条硬规则：**油品台账钉死**；**净化有主有窗有方法/准用期**；**加油交接窗与方法钉死**；**本组本机房本期实测禁套他站他期**；**会签才放行「日用油箱油品净化与加油交接准用」**；**禁顶替 AR/AF/AD/AN/AA/N/AQ/AS/AI/AT/AU/AO/AG/AP/AL 等，主贴 AV，假绿≠放行挂 R**；**油品/净化/加油异常风暴挂 N、油品策略/净化门限/加油规程变更走 J、禁功率战、禁绕安全联锁、禁不安全泄油、禁私自掺油冒充净化过**；**脱敏 L3**。  
- **AV 不替代 AR，也不替代 AF，也不替代 AD**：AR=通风排烟与燃油安全巡检（油位·泄漏·通气·围堰）；AF=油机市电切换与供电巡检；AD=备件仪表准用；AV=日用油箱油品净化+加油交接交底准用。
