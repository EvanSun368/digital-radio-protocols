## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **油品/日用油箱油品台账钉死**：机房/油箱角色、油种 / 批次角色 / 取样点角色 / 日用油箱角色入账；禁「看着有油就能签」「口头说一声」。  
2. **净化有主有窗有方法/准用期**：每次净化核对/滤芯更换有主人角色、有书面窗、有方法、有准用期（滤芯/分水器/净化装置）；禁「滤芯还在当窗过」「外观在当净化过」。  
3. **加油交接窗与方法钉死**：书面固定；方法含到场角色、计量、交接单、封样/留样指针等核对项（**顺序与门限以本网与 OEM 书面为准**；本篇不发明逐步泄油/掺油/拆联锁教条）；禁「窗再说」「口头加油」「绕过油品/净化/加油安全联锁」「不安全泄油」「私自掺油冒充净化过」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、照片、读数、油样报告必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「日用油箱油品净化与加油交接准用」；假绿 ≠ 放行。  
6. **禁顶替 AR/AF/AD/AN/AA/N/AQ/AS/AI/AT/AU/AO/AG/AP/AL，主贴 AV，假绿≠放行挂 R**：燃油安全签、油机市电签、仪表签、门禁签、首年签、监控签、视频签、旁路签、环境签、电池签、气灭签都不顶本期油品净化加油签。  
7. **油品/净化/加油异常风暴挂 N，油品策略/净化门限/加油规程变更走 J，禁功率战；禁绕过油品/净化/加油安全联锁；禁不安全泄油；禁私自掺油冒充净化过**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/日用油箱序列号全文/可还原坐标与联系人；禁公开传播未脱敏油样门限与油品参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签油品净化加油准用、无实测冒充油品过、绕联锁/泄油掺油冒充秩序齐，不是法外运维智慧**。医院保供电/柴油日用油箱公开资料、厂商油品净化与日用油箱公开科普只作故事与方法类比（§2.2）：**油要约、净要窗、交要法、验要本期、看着有油不算过**——翻译成本网语言就是 AV-油 / AV-净 / AV-交 / AV-验 / AV-治。**这些是日用油箱油品净化与加油交接交底秩序，不是「有油就签」「滤芯在当过」「抬功率压告警」「绕联锁」「不安全泄油」「私自掺油」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「日用油箱油品净化与加油交接准用」、对外宣传「油一加净化秒过」、把未实测写成已过、把绕联锁/泄油掺油写成秩序齐。允许做的：补油品台账、补净化窗、重开加油交接窗、挂 R/N/J、内部挂整改。

## 6. 工作实例（12 则，教学虚构，L3）

1. **看着有油就要签准用** → 拒签；补 AV-油台账与本期实测。  
2. **滤芯还在当窗过** → 拒签；补 AV-净主人/窗/方法。  
3. **口头说加过油** → 拒签；补 AV-交书面方法。  
4. **套邻站油样报告/照片改机房号** → AV-验 拒签重测。  
5. **AR 燃油安全签顶本期油品净化加油签** → 拒签顶替；AR≠AV；可挂 R。  
6. **AF 油机市电签顶油品净化加油签** → 拒签；AF≠AV；油机市电过≠油品过。  
7. **AD 滤芯入库签顶净化窗** → 拒签；入库过≠净化窗过。  
8. **N 监控绿免本期实测** → 拒签；N≠AV。  
9. **低油位/油品告警抬功率** → 挂 N；**禁功率战**；缺秩序整改 AV。  
10. **绕过油品/净化联锁消告警 / 不安全泄油 / 私自掺油冒充净化** → **禁**；挂 N/R；禁签准用。

12. **公开群贴真实日用油箱序列号** → L3 违规；撤帖脱敏；AV-治。
