## 1. 为什么要写这篇手册（动机 + 现场对话）

前四十八篇手册从 A–E 协议一路写到 AU 滤网压差气流：其中 **AR 回答「柴油发电机房通风排烟与燃油安全巡检边界」**（油位·泄漏·通气·围堰巡检），**AF 回答「油机市电切换与机房供电巡检」**，**AD 回答「备件仪表准用」**，**AN 回答「门禁与访客陪同」**，**AA 回答「交维后首年巡检」**，**N 回答「电源监控/对时/告警风暴」**，**AQ 回答「视频监控调阅与证据链」**，**AS 回答「UPS 旁路」**，**AI/AT/AU/AO 回答「环境侧」**，**AG/AP 回答「电池与内阻」**，**AL 回答「气灭疏散」**。可还没有单独钉死一件事——**日用油箱油品净化与加油交接不是「油箱看着有油就能签」：油品台账要钉死（油种·批次角色·取样点角色·日用油箱角色）；净化要有主人有窗有方法有准用期（滤芯/分水器/净化装置；滤芯在≠窗过）；加油交接窗与方法要书面固定；本组本机房本期实测禁套他站他期——能不能签「日用油箱油品净化与加油交接准用」？** 这就是本篇的 **AV**——**日用油箱油品净化与加油交接台账**。

- 运维岗：「油箱看着有油，油品交底就算齐了。」——**无油品台账/无本期油样实测仍准用** = 本篇拒签（规则1）。  
- 外包：「滤芯还在，净化窗肯定做完了。」——**滤芯在当窗过** = 规则2。  
- 物业：「口头说加过油就行。」——**无书面加油交接窗方法** = 规则3。  
- 外包：「邻站上周油样报告参数差不多，拷过来改个机房号。」——**套他站他期** = 规则4。  
- 班长：「AR 燃油安全签还在，AF 油机市电也过了，油品净化加油也能签。」——**用 AR/AF/AD/AN/AA/N/AQ/… 顶替 AV** = 规则6。  
- 站务：「大屏油位绿了，油品净化加油准用就算过。」——**假绿≠会签放行** = 规则5/6。  
- 网优：「低油位/油品告警一片，功率抬一点稳住业务。」——**功率战** = 规则7（无关也写禁，系列一致）。  
- 宣传岗：「把真实日用油箱序列号、油样门限发群表扬。」——**L3 违规** = 规则8。  

这几句背后是同一件事：

> **「日用油箱油品净化与加油交接」在现场至少有五个坑**：**① AV-油** 油品台账钉死（油种·批次角色·取样点角色·日用油箱角色），禁「看着有油就能签」「口头说一声」；**② AV-净** 净化有主人、有窗、有方法、有准用期（滤芯/分水器/净化装置），禁「滤芯还在当窗过」「只看滤芯外观不算净化窗」；**③ AV-交** 加油交接窗与方法钉死（到场角色·计量·交接单·封样/留样指针等；顺序与门限以本网与 OEM 书面为准），禁「口头说加过油」「绕过油品/净化/加油安全联锁」「不安全泄油」「私自掺油冒充净化过」；**④ AV-验** 本组本机房本期实测（禁套他站他期曲线/照片/油样报告），会签才放行「日用油箱油品净化与加油交接准用」；**⑤ AV-治** 治理（假绿、用 AR/AF/AD/AN/AA/N/AQ/AS/AI/AT/AU/AO/AG/AP/AL 顶替、伪造油品净化加油账、绕联锁、不安全泄油、私自掺油、功率战、泄密）。

| **治** | 假绿≠可以签；禁用「燃油安全签」「油机市电签」「监控签」顶本期油品净化加油 | 假绿、顶替 AR/AF/…、绕联锁、泄油掺油、功率战、泄密 → 治理 | AV-治 |

> 公开文书与公开资料告诉我们（**教学转述，以原文为准**）：柴油油品净化/日用油箱公开概述强调**有账要验、看着有油≠油品合格、滤芯还在≠窗做完、加油要有书面交接方法**（§10，**只借秩序直觉**）；医院手术室/ICU 保供电与应急发电机公开资料强调**油位绿≠油品合格、燃油安全巡检过≠油品净化过、油机市电过≠加油交接过**（§10，**只作故事类比**）。本篇只借这串顺序——**本网油品台账格式、净化窗方法、加油交接顺序与合格门限以本网制度、合同与 OEM 书面为准**。

### 2.3 和手册45（AR）/ 33（AF）/ 31（AD）/ 41（AN）/ 28（AA）/ 15（N）/ 44（AQ）/ 46（AS）/ 36（AI）/ 47（AT）/ 48（AU）/ 42（AO）/ 34（AG）/ 43（AP）/ 39（AL）等的咬合（指针，不重写）

- **AR（手册45）**：柴油发电机房通风排烟与**燃油安全巡检**（油位·泄漏·通气·围堰）；**AR ≠ AV**——AR 管燃油安全巡检边界；**AV 管油品台账·净化本体窗·加油交接交底准用**；油位/泄漏/围堰过≠油品净化加油过；「看着有油当巡检过」是 AR 的坑，「看着有油当油品合格」是 AV 的坑——**各钉各的**。  
- **AF（手册33）**：油机市电；**AF ≠ AV**——供电过≠油品净化加油过。  
- **AD（手册31）**：滤芯/仪表入库走 AD；**不能**用旧 AD 签日期顶本期 AV 净化窗或加油窗。  
- **AN（手册41）**：门禁访客；进机房做油品/净化/加油交底仍要 AN——**门禁过≠油品净化加油交底过**。  
- **AA（手册28）**：首年巡检日历；油品/净化抽检可挂 AA，缺油品秩序整改主贴仍 AV。  
- **N（手册15）**：监控/对时/告警风暴；油品/净化/加油异常风暴挂 N 理风暴，**不先抬功率**；**禁绕过油品/净化/加油安全联锁、禁不安全泄油、禁私自掺油冒充净化过**；N 绿≠ AV 过。  
- **AQ（手册44）**：视频调阅；加油过程要调录像另开 AQ；视频过≠油品净化加油准用过。  
- **AS（手册46）**：UPS 旁路；AS 过≠ AV 过。  
- **AI / AT / AU / AO**：环境侧（温湿度/冷凝加湿/滤网压差气流/漏水）；均不顶替 AV。  
- **AG / AP / AL**：电池/内阻/气灭；均不顶替 AV。  
- **R / J / X / I**：假绿挂 R；变更（油品策略、净化门限、加油规程）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 AV 证油品净化加油秩序，再谈覆盖病**。

### 2.4 新贴纸 AV：油 / 净 / 交 / 验 / 治（五个子类）

> 小彩蛋：双字母贴纸续写——**AA** 首年巡检；**AB** 室分复测；**AC** 机动开撤；**AD** 备件金机；**AE** 区间联测；**AF** 油机市电；**AG** 电池充电器；**AH** 合路/POI 界面；**AI** 温湿度联锁；**AJ** 天馈驻波；**AK** 爬塔交叉；**AL** 气灭疏散；**AM** 接地浪涌；**AN** 门禁访客；**AO** 漏水汇排；**AP** 内阻核对；**AQ** 视频调阅；**AR** 油机房通风燃油；**AS** UPS 旁路；**AT** 冷凝加湿联锁；**AU** 滤网压差气流；**AV** 管「日用油箱油品净化与加油交接」。A–Z 既有含义不改；新专题用 AA、AB、AC… 续写。

```text
                ┌──────────── 贴纸 AV · 油/净/交/验/治 ────────────┐
                │  AV-油  油品：油品台账钉死（油种·批次·取样点·日用油箱） │
                │  AV-净  净化：净化有主有窗有方法准用期（滤芯·分水器·净化） │
                │  AV-交  交接：窗·方法钉死（到场·计量·交接单·封样留样） │
                │  AV-验  验收：本组本机房本期实测·禁套他站他期         │
                │  AV-治  治理：假绿·顶替AR/AF/N·绕联锁·泄油掺油·泄密 │
                └──────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签触发 |
|------|--------|--------------|
| **AV-油** | 无油品台账、看着有油无本期油样实测仍准用 → 拒签 | 「看着有油就能签」「口头说一声」 |
| **AV-净** | 净化无主人、无窗、只看滤芯在 → 拒签 | 「滤芯还在就算过」「外观在当净化过」 |
| **AV-交** | 无书面加油交接窗/方法、口头加油、绕联锁、不安全泄油、私自掺油 → 拒签 | 「口头说加过油就行」「掺点新油冒充净化」「不安全泄油」 |
| **AV-验** | 套他站他期曲线/照片/油样报告、无会签 → 拒签 | 「邻站油样报告拷过来改机房号」 |
| **AV-治** | 假绿、用 AR/AF/AD/AN/AA/N/AQ/AS/AI/AT/AU/AO/AG/AP/AL 顶替、绕联锁、泄油掺油、功率战 → 治理 | 「AR/AF 签还在，油品也能过」 |

### 2.5 建油品台账 → 钉净化窗 → 加油交接方法钉死 → 本期实测 → 会签放行 → 变更再验 阶段梯（背下来）

```text
  ① AV-油 建油品台账：机房/油箱角色 · 油种/批次/取样点角色 · 禁「看着有油就能签」「口头说一声」
        │  无账 / 看着有油无实测 → 不签日用油箱油品净化与加油交接准用
        ▼
  ② AV-净 钉净化窗：净化主人角色 · 书面窗 · 方法 · 准用期 · 禁「滤芯还在当窗过」「外观在当净化过」
        │  无主人 / 无窗 / 无方法 / 无准用期 → 拒进入「可签」状态
        ▼
  ③ AV-交 钉加油交接方法：书面窗 · 方法（到场、计量、交接单、封样/留样指针等；以本网与 OEM 书面为准） · 到场角色 · AD 仪表准用指针
        │  无窗 / 「口头加油」/ 「绕过联锁」/ 「不安全泄油」/ 「私自掺油」 → 拒交接签
        ▼
  ④ AV-验 本组本机房本期实测：实测记录 · 禁套他站他期曲线/照片/油样报告 · 会签
        │  套票 / 只看监控绿 → 拒签
        ▼
  ⑤ 会签放行「日用油箱油品净化与加油交接准用」；假绿≠放行；未闭项挂整改
        │
        ▼
  ⑥ 油品策略/净化门限/加油规程变更 → 走 J → 再验 AV
```
