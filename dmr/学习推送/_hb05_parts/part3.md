## 8. 术语表（本篇约 28 词）+ 易错观念

| 术语 | 一句话 | 易错 |
|------|--------|------|
| **鉴权** | 验证「有没有这台的 K」 | 当成话音加密 |
| **挑战 RAND** | 24 bit 随机题 | 当成个号/网关 |
| **响应 Response** | 24 bit 答案 | 当成被叫地址 |
| **K** | 128 bit 一机一钥 | 以为会上空口 |
| **PSN** | 出厂钢印，可选入算 | 换板后忘更新 |
| **C_AHOY** | 网络出题（正向） | 只当成「点名被叫」 |
| **C_ACKU 0x48** | 手台交卷 | 当成普通 ACK |
| **C_ACKD 0x64** | 网络交卷（反向） | 与 0x48 方向搞反 |
| **C_ACKVIT** | 手台对 Stun/Kill「先答题」 | 当成普通确认 |

| **0x2A / 0x2B** | 登记拒绝通用 | 直接当「鉴权失败」 |
| **0x14** | 反向失败拒执行 | 当成用户拒接 |
| **0x00** | 不支持 Stun | 当成鉴权失败 |
| **0x44** | MS_Accepted（执行管理命令） | — |
| **0xE0 Wait** | 中间态 | 当成终失败 |
| **AUTHI** | 鉴权网关名 `FF FECD` | 与 RAND 范围混淆 |
| **独立轮询** | Mirror=0 的抽查 | 当成故障 |
| **正向鉴权** | TS 挑战 MS | — |
| **反向鉴权** | MS 挑战 TS（Stun/Kill） | 失败却盲发 Kill |
| **TNP_Timer** | 出题后等判卷 | 超时→猎站当射频故障 |
| **贴纸 D** | 真鉴权失败（有题有答） | 与 B 混贴 |
| **手册01三问** | 登记分诊 | 无题时误升 D |
| **手册04四问** | 猎站/CHAN | 无TSCC时开鉴权单 |
| **Privacy** | 话音加密位（Part4未定义） | 与鉴权混谈 |
| **RC4（本处）** | 鉴权搅拌机 | dump 攻击细节 / 当话音加密 |
| **测试向量** | 官方自检样例 | 本篇重做逐字节作业 |
| **dmrtc** | 开源控制器对照 | 当成规范本身 |
| **脱敏分诊卡** | 七步+批次表 | 填真实 K 入库 |

**易错观念对照**

| 错念 | 纠正 |
|------|------|
| 有 0x2A = 鉴权失败 | 先往前翻有没有题答对 |
| 鉴权失败 = 换天线 | 先①–④ |
| 鉴权 = 话音加密 | §4.5 三条线 |
| 遥毙失败再发一次 | 先对 K；Kill 很重 |
| 答案栏是被叫个号 | Reason 0x48 → 那是答案 |
| 没人按铃却出题 = 故障 | 独立轮询可能正常 |
| 用了 RC4 = 没鉴权 / = 绝对安全 | 门禁有效，但非端到端方案 |

### 参考答案

1. **不是第 41 课。** 手册模式第 5 篇。手册01认登记 Reason 门牌；本篇在有题有答时认鉴权中间步（贴纸 D）。  
2. ①真是鉴权吗 → ②交卷了吗 → ③K → ④PSN → ⑤串号 → ⑥工具链 → ⑦反向。证据：C_AHOY 出题 + C_ACKU Reason=`0x48`。  
3. A猎站（手册04）；B登记（手册01）；D真鉴权（本篇）；C Grant无声（手册02）。无 AHOY/无0x48 → **不能贴 D**，多贴 B（或查 A）。  
4. 它们是登记拒绝通用码；鉴权失败也走此路径。须往前翻题答对。  
5. **K 与 PSN 不上空口**；RAND/Response 上。换板后重读 PSN 并更新网管。  
6. 正向：TS 出题，MS 交卷 `0x48`。反向：MS 出题（ACKVIT），TS 交卷 `0x64`。  
7. Mirror=`000 0000₂`；通常是正常抽查，不当故障。  
8. 核网络侧该台 K；Kill 永久且必鉴权，盲发不能修钥匙问题，还有误操作风险。  
9. CC/SYS：是否同系统；鉴权：是否有 K；加密：旁人能否听懂（不在 Part4）。  
10. Grant无声 → 手册02，**不改 K**。无 SYScode → 手册04，**不开鉴权单**。  
11. 不是；`MSNot_Supported`；手册03。  
12. 真实 **K**、真实 **PSN**、**完整**个号（以及真实批复 MHz）。

## 11.7 常见问法速查（FAQ 式）

**Q1：Reason 是 0x2B，是不是一定鉴权失败？**  
A：不一定。往前翻有没有 AHOY+0x48。

**Q2：没有单独的「鉴权失败」Reason 吗？**  
A：Part 4 登记路径没有；失败走登记拒绝或超时猎站。

**Q3：鉴权过了话音就加密了吗？**  
A：**没有。** 鉴权≠加密；Privacy 不在 Part 4。

**Q4：分诊卡能不能写真实 K 方便夜班？**  
A：**不能写进学习推送/公开仓。** 真实 K 只留在受控开户系统。

**Q5：本篇要不要会手算 RC4、默写测试向量？**  
A：值班分诊**不要求**重做第35课作业；会认题答对与七步即可。工具链自检由责任人按第35课做。

**Q6：和手册01如何分工？**  
A：手册01管登记三问与 Reason 剧本；一旦确认有题有答后的拒绝，升级本篇贴纸 D 走七步。

**Q7：反向失败能当「用户拒接」结案吗？**  
A：**不能。** 管理场景下 `0x14` = 手台不认网络答案。
