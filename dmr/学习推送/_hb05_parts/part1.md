## 1. 为什么要写这篇手册（动机 + 现场对话）

第 35 课把「前台出题、你交卷、钥匙不出门」钉牢；第 40 课运维日历里，鉴权故障是登记三问的**下游深挖**——手册 01 只留名字指针（「本篇认门牌，第 35 课进门」），本篇就是把那扇门写成**可执行分诊卡**。

手册 01 专治「登不上」的三问与 Reason；手册 02 专治「Grant 了没声」；手册 03 专治 Stun/DGNA/短信话术；手册 04 专治猎站/CHAN 边界；本篇专治另一类更高频的**开鉴权后登不上 / 返厂机拒登 / 遥毙被拒 / 工单误写鉴权失败**——协议你会背，值班却卡在边界：

> 「网管写『鉴权失败』，空口其实根本没有 C_AHOY。」  
> 「有题有答，随后 `0x2B`——是钥匙错了，还是没开户？」  
> 「遥毙回了 `0x14`，要不要再发一次 Kill？」

现场你一定听过这些对话：

- 网管：「新开了鉴权，A 批都过了，B 批全部登记不上。」——十有八九是 **B 批 K 没导入网管**，或导入字节序/格式错位（第 35 课例；本篇七步③）。  
- 调度：「这台以前好好的，返厂修完回来就登不上。」——维修可能**换了主板**：PSN 出厂固化，网管还是旧钢印（七步④）。  
- 坐席：「工单写鉴权失败。」——你若立刻改 K，可能漏问第一句：**NACK 前面有没有一对「出题 + 交卷」？**（七步①）  
- 分析仪：「看见 C_AHOY，手台一直不回。」——不是钥匙错，是**没交卷**（不支持鉴权 / 未开启 / 入站没收到）→ 七步②，这时才谈射频。  
- 监听员：「C_ACKU 的 Target 显示成一个奇怪个号。」——那是 **24 bit 答案被当成地址显示**；Reason=`0x48` 就知道是交卷，不是个呼（第 35 课）。  
- 网管：「遥毙下发了，手台回 `0x14`。」——**反向鉴权失败**：手台不认网络答案；**禁止盲目重发 Kill**（七步⑦ + 手册03）。  
- 安全/采购：「用了 RC4，是不是等于没鉴权？话音有没有加密？」——**鉴权 ≠ 加密**；Part 4 Privacy 未定义（第 35 课 §8.3；本篇 §4.5）。  
- 班长：「Reason 是 `0x2A`，跟手册01剧本一样啊。」——对，**规范没有单独的「鉴权失败」Reason**；鉴权失败走登记拒绝路径。判法是**往前翻有没有题答对**（§2.3 贴纸）。

培训台如果只背「鉴权 = 密钥不对」六个字，值班会卡在同一处：

> **会背名词 ≠ 会走七步。**  
> 分诊 = 每次工单强制按便宜顺序问：  
> **① 真的是鉴权吗？**（有 C_AHOY 出题 + C_ACKU `0x48` 交卷）  
> **② 交卷了吗？**  
> **③ K 在网管且对吗？**  
> **④ PSN 两边一致吗？**  
> **⑤ 个号串号吗？**  
> **⑥ 网管/工具链算法对吗？**（测试向量自检，不重做第35课作业）  
> **⑦ 反向 Stun/Kill？**（指纹不同；失败勿盲发 Kill）  
> 七步答不清，不许升级为「覆盖差」或「换天线试试」；也不许在没题没答时结「鉴权失败」。

本篇目标：能画出「真鉴权 vs 普通登记拒绝 vs 猎站失败 vs Grant 无声」边界贴纸；会用七步分诊卡接单；会区分正向（TS 挑战 MS）与反向（MS 挑战 TS）；能说清鉴权≠加密；能填完《本网鉴权失败分诊卡》；自测过关后，回库翻第 35 / 32 / 34 / 39 课与 `鉴权与AnnexC频率.md` 把本网检查项补进卡——**不重做第 35 课 RC4 逐字节作业、不发明攻击步骤、不写真实 K/个号**。

**本篇硬禁令（写进脑子）**：不发明 ETSI 条款号（入口锚点以资料库 `04-集群协议/鉴权与AnnexC频率.md` §0–§6、`ReasonCode与Grant变体.md`、`Stun_DGNA_UDT与定时器.md`、第 35 / 32 / 34 / 39 / 40 课、手册 01–04 已有编号为准）；**不重 dump RC4 S-box / 测试向量逐字节作业**（第 35 课 §5 已做）；**不写密钥破解、重放攻击步骤、伪基站利用细节**（网络管理分诊口径，与手册 03 / 第 39 课 Stun 中性话术同级）；**不重 dump Reason 全表 / Grant 全变体 / Hunt 状态机 / CHAN 公式**（手册 01 / 02 / 04）；**不写真实批复频点、真实站点号、真实用户个号、真实 K/PSN 明文进公开仓库**（一律用占位符 / 脱敏）；不把厂商中文提示当成 ETSI 正式名；不把「用了 RC4」夸大成「端到端安全」或贬成「等于没鉴权」；本篇不写下一篇手册正文。

## 2. 总图 / 故事：旅馆暗号 + 边界贴纸

### 2.1 一句话：先证明「出过题、交过卷」，再查钥匙

继续旅馆比喻（第 31–40 课 + 手册 01–04 + 第 35 课）：

| 旅馆 | 空口 | 本篇工单常卡在哪 |
|------|------|------------------|
| 找导游集合点 | **Hunt**（手册04） | 还没到前台，谈不上鉴权 |
| 前台办入住 | **登记**（手册01） | 有 RAND+Reason，但**未必**走过鉴权 |
| 前台出随机题卡 | **C_AHOY**（Source=RAND） | 没题却结「鉴权失败」= 贴错贴纸 |
| 你用密码本交卷 | **C_ACKU**（Reason=`0x48`，Target=答案） | 有题无答 → 先查「交卷」，再查射频 |
| 前台用同一密码本判卷 | **C_ACKD `0x62` / C_NACKD `0x2A`·`0x2B`** | 规范**没有**单独「鉴权失败」Reason |
| 客房没声 | **Grant 无声**（手册02） | 鉴权通过后的问题，别回改 K |
| 前台要禁房卡，你先出题验前台 | **反向鉴权**（Stun/Kill） | 失败 → `0x14`；**勿盲发 Kill** |
| 密码本本身 | **K（128 bit）** | **永不上空口** |
| 钢印号 | **PSN** | 可选 XOR；换板最常踩 |

口诀：**先证明有题有答 → 再查钥匙与钢印 → 最后才谈射频。**  
把「普通登记拒绝」写成「鉴权失败」，或把「反向鉴权失败」当成「再发一次 Kill 就好」，是本篇最常见的两大口误。

```text
  │ 贴纸A · 猎站失败    │ │ 贴纸B · 登记失败    │ │ 贴纸D · 真鉴权失败  │ │ 贴纸C · Grant无声   │

  │ 证据：无自家SYScode │ │ 证据：有登记RAND    │ │ 证据：C_AHOY+0x48  │ │ 证据：真Channel    │
  │       /Aloha       │ │       +ACK/NACK+Reason│ │       随后 2A/2B等 │ │       Grant        │
  │ 下一刀：Hunt四问   │ │ 下一刀：三问+Reason │ │ 下一刀：七步②–⑥   │ │ 下一刀：四问       │
  │ 禁止：一上来改K    │ │ 禁止：没码值改鉴权  │ │ 禁止：没题结鉴权单 │ │ 禁止：回改K/PSN   │
  └────────────────────┘ └────────────────────┘ └────────────────────┘ └────────────────────┘
```

划界口诀（本篇新增「贴纸 D」）：

| 你想确认的事 | 成功长什么样 | 失败 / 假故障长什么样 |
|--------------|--------------|------------------------|
| **摸到自家 TSCC 了吗？** | 能解码 SYScode / Aloha | 只有能量 → 贴纸 A（手册04） |
| **登记办成了吗？** | 终 ACK `0x62`/`0x65` | 有 RAND+Reason 拒绝 → 贴纸 B；**再问有没有题答对** |
| **鉴权中间步走过吗？** | 有 C_AHOY（出题）+ C_ACKU `0x48`（交卷） | 无题无答却写「鉴权失败」→ **假鉴权单**，退回 B 或 A |
| **Grant 后进客房了吗？** | Payload 有声 | 有 Grant 无声 → 贴纸 C；**与钥匙无关** |

**最重要一条（第 35 课 §7）**：看到 `0x2A` / `0x2B`，**不能直接断定是鉴权失败**——它们是登记拒绝的通用理由。判断方法：**往前翻**，看这条 NACK 前面**有没有一对 C_AHOY（Service_Kind=`1110₂`，Source=题）+ C_ACKU（Reason=`0x48`）**。有，才是贴纸 D；没有，就是贴纸 B（开户/站点不允许等）。

## 3. 核心交付：七步分诊工作流 + 决策树 + 分诊卡行

### 3.1 七步工作流（每次工单照念 · 便宜优先）

把第 35 课 §9 展开成可勾选的七步（**越靠前越常见、越便宜**）：

```text
  第1步 · 真的是鉴权问题吗？
     证据：NACK（常见 0x2A/0x2B）或「登不上」现象前面，
           有没有 C_AHOY（出题，Source=RAND）+ C_ACKU（Reason=0x48，Target=答案）？
     没有 ──────────────► 不是鉴权 → 贴纸B（手册01）或贴纸A（手册04）
     有   ──────────────► 进第2步（贴纸D）

  第2步 · 手台交卷了吗？
     出题之后有没有 C_ACKU 0x48？
     没有 ──► 不支持/未开鉴权，或入站没收到题 → 这时才查覆盖与射频
     有   ──► 进第3步

  第3步 · 这台的 K 在网管里吗、对吗？
     个号 ↔ K 是否一一对应？刚写频改过 K 网管同步了吗？
     导入格式/字节序是否错位？（批次全挂的经典指纹）

  第4步 · PSN 两边用法一致吗？
     网络启用了 PSN？手台支持吗？录的是不是**这台机器现在**的钢印？
     ※ 返厂换板、借机调号最常踩

  第5步 · 是不是个号写错 / 串号？
     手台自报个号对应的 K，是不是另一台机器的？
     两台共用一个个号 → 至少一台永远过不了

  第6步 · 网络侧算法 / 工具链对吗？
     用第35课官方测试向量喂网管/测试仪做自检（结构核对即可）
     ※ 本篇不重做逐字节作业；新上线第三方网管先过这关

  第7步 · 反向场景（Stun / Revive / Kill）？
     指纹：C_AHOY(STUNI|KILLI) → C_ACKVIT(出题) → C_ACKD(0x64交卷)
           → 失败则 C_NACKU 0x14 Recipient_Refused
     ※ 手台不认网络答案：先对网络侧该台 K；禁止盲目重发 Kill
```

**口诀**：**先确认有题有答，再查钥匙，再查钢印，最后才查射频。**  
**结束条件**：七步（或提前转出的贴纸）都有证据（空口顺序 / 网管个号-K 对照版本号 / 写频批次，均脱敏）写入工单，才能谈「覆盖差」或「硬件坏了」。只有中文「鉴权失败」四个字 = 线索不足。

```text
                       有 C_AHOY + C_ACKU 0x48？
```

### 3.3 分诊卡行模板（脱敏 · 运维×开户共用）

| 字段 | 填什么 | 禁止填什么 |
|------|--------|------------|
| **个号（脱敏）** | 末 2–4 位或内部工单号 | 完整个号明文入库学习仓 |
| **批次 / 写频包** | `2026-09-b` / `机型X-包3` | 真实密钥文件路径外泄 |
| **鉴权开关** | 本站开/关；独立轮询开/关 | — |
| **空口顺序** | `RAND→AHOY→ACKU0x48→NACK2B` | 只写「鉴权失败」四字 |
| **K 状态** | 网管有记录？与写频同步？ | **真实 K 十六进制** |
| **PSN 状态** | 启用？支持？换板后已重录？ | 真实 PSN 明文公开仓 |
| **结论贴纸** | A / B / D / C / 反向⑦ | 贴纸混贴不写清 |
| **下一动作** | 同步K / 重录PSN / 转01 / 转04… | 「再发一次Kill碰运气」 |
