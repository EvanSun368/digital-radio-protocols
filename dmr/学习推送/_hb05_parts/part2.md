## 4. 深潜：七步背后的六颗钉子（只取运维用）

### 4.1 四个量：谁持有、上不上空口

| 名 | 宽度 | 谁持有 | 空口？ | 运维一句话 |
|----|------|--------|-------|------------|
| **K** | 128 bit | MS 与网管各一份 | **不上** | 一机一钥；丢了只坏一台 |
| **PSN** | ≥3 字节（算 3） | 出厂固化；网管录入 | **不上**（只影响答案 XOR） | 换板必重录 |
| **RAND** | 24 bit | 挑战方当场产生 | **上**（C_AHOY Source / C_ACKVIT Target） | 题每次都换，防重放 |
| **Response** | 24 bit | 被挑战方算出 | **上**（C_ACKU Target / C_ACKD AddInfo） | 答案；别当成个号 |

口诀：**题和答上天，钥匙和钢印不出门。**

### 4.2 什么时候出题（五种场景 · 运维认指纹）

| 场景 | 空口指纹 | 值班怎么认 |
|------|----------|------------|
| **登记中鉴权** | C_RAND(登记) → C_AHOY → C_ACKU 0x48 → 终ACK/NACK | 最常见；Mirror 回拷登记 Service_Options |
| **呼叫建立中鉴权** | C_RAND(呼叫) → C_AHOY → … → 通过则常跟 Grant | 答错 → 呼叫失败，不是 Grant 无声 |
| **独立鉴权轮询** | **无人按铃**却出题；Mirror=`000 0000₂` | 抽查，正常现象 |
| **业务信道上** | P_AHOY / P_ACKU，字段同 | 已在客房仍可出题 |
| **反向 Stun/Kill** | AHOY(STUNI\|KILLI) → ACKVIT → ACKD 0x64 → 0x44/0x14 | Kill **必须**鉴权；Stun 可选 |

### 4.3 三种结局怎么读（登记路径）

| 结局 | 空口 | 含义 |
|------|------|------|
| **通过** | C_ACKD `0x62`（或呼叫继续→Grant） | 鉴权只是中间步；结论在终 ACK / Grant |
| **不通过** | C_NACKD `0x2A` / `0x2B` | **无单独 Auth-Fail Reason**；须有题答对才称贴纸D |
| **没判卷 / 没交卷** | 出题后无下文；或无 0x48 | TNP 到期→猎站；或七步② |

`0x2A` Refused 可换站再试；`0x2B` Denied 可能进本站拒绝名单（T_DENREG）。鉴权失败回哪一个，**规范不定、看厂商**（如 dmrtc 答错常回 Denied）。

### 4.4 反向鉴权：Stun / Kill 指纹（中性网络管理口径）

```text
  TS --C_AHOY(STUNI|KILLI, Kind=1101₂)--> MS     管理命令
  MS --C_ACKVIT(Target=手台出的题)--> TS           兼确认 + 出题
  TS --C_ACKD(Reason=0x64, AddInfo=网络答案)--> MS 网络交卷
  MS 判卷：
       对上 → 执行，回 C_ACKU（MS_Accepted 0x44）
       对不上 → 不执行，回 C_NACKU（Recipient_Refused 0x14）
```

运维铁律：

1. **Kill 必须鉴权**——永久禁用路径，防冒充网络毁机。  
2. **Stun/Revive 鉴权可选**——手台发不发 ACKVIT 看实现。  
3. **`0x14` 在此语境 = 手台验不过网络**，不是「用户拒接个呼」（第 34/35 课：同一 Reason 要结合场景）。  
4. **`0x00` MSNot_Supported** = 不支持 Stun，**与钥匙无关**（手册03）。  
5. **反向失败 → 先对网络侧该台 K/PSN，禁止「再发一次 Kill 碰运气」。**

### 4.5 鉴权 ≠ 加密（三条线别画混）

| | 回答的问题 | 空口看得到 |
|--|-----------|------------|
| **Colour Code / SYScode** | 是不是同一个系统/站？ | 明文字段 |
| **鉴权（本篇）** | 手里有没有这台的 K？ | 题和答（各 24 bit）；**K 不上空口** |
| **加密（Privacy）** | 旁人能不能听懂话音/数据？ | **不在 Part 4**（Privacy 位未定义） |

口诀：**听到「RC4」先问——说的是鉴权搅拌机，还是话音加密方案？** 同名算法、不同规范、不同钥匙、不同用途。给安全同事一句话：**Part 4 鉴权是入网门禁，不是端到端安全方案。**

### 4.6 和手册01的咬合：Reason「长得像拒绝」，根因可能是 K/PSN

手册 01 剧本里 `0x2A`/`0x2B` 常写「未开户 / 站点不允许 / Denied 名单」。本篇补充：

| 手册01视角 | 本篇加一刀 |
|------------|------------|
| 有 RAND + Reason → 走三问 | **再问**：前面有没有 AHOY+0x48？ |
| 有 → 可能是贴纸 D | 七步③–⑤：K/PSN/串号 |
| 无 → 贴纸 B 本色 | 开户、站点策略、跨字节误读等 |
| 无 RAND → 可能贴纸 A | 手册04；禁止结鉴权单 |

边界口诀：**手册01认门牌（Reason），本篇认题答对（鉴权中间步）。**

## 5. 现场映射：中文提示 → 检查什么；对话脚本

### 5.1 网管 / 用户中文 → 先贴哪张贴纸

| 中文说法（线索） | 先怀疑 | 先做 |
|------------------|--------|------|
| 「鉴权失败」但无空口细节 | 假鉴权单 | 七步①：有无 AHOY+0x48 |
| 「开鉴权后整批登不上」 | K 导入/开关 | ①确认有题答对 → ③批次 K |
| 「一台返厂后拒登，其余正常」 | PSN 换板 | ④重读 PSN、更新网管 |
| 「出题后手台不回」 | 不支持/未开/入站 | ②；再谈射频 |
| 「没人按铃却周期性出题」 | 独立轮询 | Mirror=0；正常抽查 |
| 「遥毙回拒绝」 | 反向 0x14 | ⑦对 K；勿盲发 Kill |
| 「Stun 回不支持」 | 0x00 | 手册03；非鉴权 |
| 「一直搜网」却开鉴权单 | 贴纸 A | 手册04；退回 |
| 「有 Grant 没声」却改 K | 贴纸 C | 手册02；勿动钥匙 |
| 「Target 显示奇怪个号」 | 答案被当地址 | 看 Reason=0x48 |

### 5.2 值班对话脚本（可直接照着说）

#### 对话 A · 「鉴权失败」四个字工单

- 坐席：「用户鉴权失败。」  
- 你：「空口顺序有没有？具体说：有没有看到网络出题（C_AHOY），手台有没有交卷（Reason 0x48）？随后拒绝码是多少？」（七步①）  
- 坐席：「……只有中文提示，没有码。」  
- 你：「没有题答对证据，不能结鉴权单。先按手册01补三联单；若连登记 RAND 都没有，转手册04看是否还在猎站。」

#### 对话 B · 整批开鉴权后挂掉

- 网管：「B 批 40 台全挂，A 批正常。」  
- 你：「分析仪上 B 批是有题有答再拒绝，还是出题不回？」（①②）  
- 网管：「有题有答，随后 Denied。」  
- 你：「那走钥匙线：B 批 K 导入文件格式/字节序是否与 A 批一致？网管里抽两台 B 批个号看 K 记录是否非空且与写频同步。」（③）

#### 对话 C · 返厂机

- 调度：「这台修完回来就登不上。」  
- 你：「有题有答吗？本网启用 PSN 吗？维修单是否换过主板？」（①④）  
- 调度：「换过板，PSN 启用。」  
- 你：「用厂商工具重读钢印，更新网管该个号的 PSN；不要先重写 K 碰运气。」

#### 对话 D · 遥毙回 0x14

- 网管：「Kill 下发了，手台回 Recipient_Refused。」  
- 你：「这是反向鉴权失败：手台不认网络的答案。先核网络侧这台的 K 是否与写频一致。**先不要连续重发 Kill。**」（⑦ + 手册03）

#### 对话 E · 「答案像个呼地址」

- 新人：「1001 在个呼一个奇怪号。」  
- 你：「看 Reason：若是 0x48，Target 栏是**答案**不是被叫。别开错个呼故障单。」

### 5.3 「先钥匙 / 题答，后覆盖 / 射频」反例集

| 一上来就做的动作 | 为何常错 | 应先做 |
|------------------|----------|--------|
| 一听「鉴权失败」就改 K | 可能无题无答 | 七步① |
| 一听「登不上」就换天线 | 可能是 K/PSN | ①–④ |
| 一听 0x2A 就开「未开户」剧本 | 可能是鉴权未过 | 往前翻题答对 |
| 遥毙失败就连发 Kill | 可能锁死/毁机风险 | 对网络侧 K |
| Grant 无声却重导 K | 门牌/CC/时隙问题 | 手册02 |
| 搜网工单改鉴权开关 | 可能还在猎站 | 手册04 |

## 6. 工作实例（10 个厚例，均脱敏）

### 例 1 · 假鉴权单：无 AHOY 却写「鉴权失败」

**现象**：坐席结「鉴权失败」。  
**七步**：① **无** C_AHOY、无 0x48；有登记 RAND + `0x2A`。  
**贴纸**：B（手册01），不是 D。  
**动作**：退回三问 + Reason 剧本；禁止改 K。

### 例 2 · 整批 K 导入错位

**现象**：开鉴权后 B 批全挂，A 批正常。  
**七步**：①有题有答；②有交卷；③ **B 批 K 导入字节序/格式错**。  
**动作**：修导入工具链；用测试向量自检网管（⑥）；脱敏记录「B 批导入格式」。

### 例 3 · 返厂换板 PSN

**现象**：单台返厂后拒登，同批次其余正常。  
**七步**：①②过；④ **PSN 仍是旧钢印**。  
**动作**：工具重读 PSN → 更新网管；培训「换板必改钢印库」。

### 例 4 · 出题不交卷：老型号不支持

**现象**：开鉴权后某老型号一直登不上。  
**七步**：①有 AHOY；② **始终无 0x48**；TNP 后去猎站。  
**动作**：升级固件或鉴权豁免名单；**先别测驻波**。

### 例 5 · 个号串号：两机一个号

**现象**：两台里总有一台鉴权过不了。  
**七步**：⑤ 两机写了同一自报个号，K 只对得上其中一把。  
**动作**：拆分个号；网管 K 一一对应；脱敏记「串号」。

### 例 6 · 独立轮询被当成故障

**现象**：「没人按 PTT 却周期性 AHOY→ACKU」。  
**七步**：Mirror=0 → **独立轮询**（§4.2）。  
**动作**：向监控说明正常抽查；勿开故障单。

### 例 7 · 反向 Kill 回 0x14

**现象**：遥毙被拒。  
**七步**：⑦ 反向指纹完整；手台不认答案。  
**动作**：对网络侧 K；**停止连发 Kill**；手册03话术同步调度。

### 例 8 · Stun 回 0x00（非鉴权）

**现象**：以为鉴权失败。  
**边界**：`MSNot_Supported`——不支持 Stun。  
**动作**：回手册03；本篇结「非鉴权」。

### 例 9 · 登记拒绝后去猎站——规范接法

**现象**：`0x2B` 后手台离开再搜网。  
**边界**：贴纸 D 或 B 结案后，猎站是规范接法（手册04例8）。  
**动作**：工单两段写：鉴权/登记剧本 + 随后 Hunt 指纹；别开两张无关单。

### 例 10 ·（对照）干净成功：题→答→Reg_Accepted

**现象**：试点机登记，30 秒内可通。  
**空口**：C_RAND → C_AHOY → C_ACKU 0x48 → C_ACKD 0x62。  
**教学用途**：给新人当「正常长什么样」；工单可存脱敏顺序栏，不存真实 RAND/答案/K。

## 6.5 运维 × 开户 / 安全对齐会：20 分钟议程（可复印）

```text
0–3 min   本周「鉴权失败」工单张数；有几张七步①不成立（假鉴权单）
3–10 min  打开分诊卡：批次K同步、PSN换板流程、豁免名单是否更新
10–15 min 抽一张整批失败或返厂机工单，当面走七步
15–18 min 与安全对齐一句话：鉴权≠加密；公开材料无真实K
18–20 min 确认 Stun/Kill 反向失败流程：先对K、禁止盲发Kill
```

对齐口令：

> 运维：没题没答，不结鉴权单。  
> 开户：个号↔K↔PSN 不同步，不开放鉴权开关。  
> 安全：Part 4 鉴权是门禁，不是话音加密证明。

### 6.6 「题答 / 钥匙 / 射频」三层工具心态

| 层 | 工具直觉 | 回答的问题 | 本篇用法 |
|----|----------|------------|----------|
| 题答 | 空口分析 / 网管信令 | 有没有出题、交卷、终局 Reason？ | 七步①② |
| 钥匙 | 写频工具 / 网管开户库 | K/PSN/个号是否一一对应？ | 七步③–⑤ |
| 射频 | 频谱 / 场强 | 入站是否根本收不到题？ | **仅**在②无交卷后 |

口诀：**题答证明「走过鉴权门」，钥匙证明「算得对」，射频证明「听得见题」。** 三层没走完，不许只写「覆盖差」。
