## 1. 为什么要写这篇手册（动机 + 现场对话）

前二十二篇手册把「家里怎么养」「邻居怎么处」「投诉怎么分诊」「证照台账怎么对」基本写全了：A–E 协议，F 射频指纹，G 实验室，H 话务，I 室分，J 写频，K 电源，L 井库，M 批量 / OTAP，N 监控对时，O 有源隔离，P 口部，Q 金机，R 假绿演练，S 邻频协调，T 干扰投诉，U 许可执照台账。可现场还有一类债——**重大保障临时频率与联测窗**：

- 保障办：「活动下周开幕，临时频批复还没下来，先按拟用表写频开站。」——**先开后补** = 本篇拒签（规则2、3）。  
- 写频岗：「临时信道表昨晚改了，批复还是旧起止时刻。」——**未对临时台账**（规则5，挂 J / U）。  
- 联测班长：「本网自测全绿，邻居没空，先签『保障就绪』吧。」——**联测窗未完成** = 规则4（挂 S）。  
- 领导：「闭幕当晚业务还忙，临时站先留着，下周再拆。」——**临时变永久 / 不回收** = 规则3、6。  
- 邻网协调：「我们保障期临时抬了边界侧功率，忘了通知你们。」——**跨网未通知**（规则7，挂 S；若已投诉挂 T）。  
- 新人：「临时批复和永久许可不是一回事吗？过了保障窗还能不能用？」——**临时 ≠ 永久**（弱项短补）：会展临时用电证有起止时刻与功率上限；闭幕必须断电拆线交还，不能「临时变永久」。

这几句背后是同一件事：

> **「重大保障临时频率与联测窗」在现场至少有五个坑**：**① V-临** 临时许可/批复仍有效、覆盖保障期拟用频点组/地域/用途/功率上限；**② V-窗** 保障窗书面起止时刻，禁超窗、禁「先开后补」、禁「临时变永久」；**③ V-联** 联测窗（本网+必要邻居）完成才签保障就绪；**④ V-收** 闭幕/窗末日强制回收：降功率/关停/拆临时天线/回写台账；**⑤ V-治** 无批复/过期/超窗拒签，跨网挂 S，投诉挂 T，公开仓 L3。  
> 把 ①–⑤ 当成「有拟用表就能开」「联测以后补」「闭幕先留着」「临时变永久」，会把下一任、邻居、主管部门和保障指挥部一起拖进泥潭。

本篇目标：能背出**重大保障临时频率与联测窗工作流**；会用新贴纸 **V（临 / 窗 / 联 / 收 / 治）** 与五个子类；会填**插页 V（V1–V8）**和《本网重大保障临时频率与联测窗卡》；能用「**会展中心临时用电证 + 施工占道证 + 闭幕当晚必须拆线还路**」故事讲清：先证覆盖再开站、书面起止、联测验收、强制回收、拒签；能拒绝「无批复开站、超窗继续、临时变永久、联测未完签就绪、公开泄密」；自测过关后，回库把本网最近一次重大保障（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：凡引法规均指向已公开发布的文书标题与官方链接（《中华人民共和国无线电管理条例》《无线电频率使用许可管理办法》《地面无线电台（站）管理规定》《无线电台执照管理规定》《中华人民共和国无线电管制规定》及属地重大活动保障公开文件等），**数字、时限、程序以原文与属地最新要求为准，本篇只作教学转述，不发明条款号以外的「内部口径」**；**现象与台账一律用相对道号、角色标签、脱敏编号表述，禁真实频点 / 站名 / 单位名 / 许可或批复全文号 / 联系人 / 坐标**；**不教无证发射、伪造涂改批复、规避监测与检查、把临时频永久化、查找/对抗非法设台或黑广播的技术细节**；J / M 仍管写频与批量边界，U 仍管永久证照台账，S 仍管邻频联测，T 仍管投诉进线——**临时保障主贴 V**；外国 / ITU 资料只借**重大活动频谱协调与监测方法**，**临时许可与设台以国内法规与属地无线电管理机构为准**。

## 2. 总图 / 故事：临时频率像「会展临时用电证 + 施工占道证 + 闭幕拆线还路」

### 2.1 一句话：临时频率像会展临时用电证（有起止、有功率上限、有用途），保障窗像施工占道证（书面划定时段与区域），联测像通电验收，闭幕必须断电拆线交还道路——禁「临时变永久」「先开后补」

```text
   ┌──────────────────────────────────────────────────────────────────┐
   │   会展中心物业 + 城管占道窗口（= 无线电管理机构 / 保障指挥）    │
   │                                                                  │
   │   临时用电证（V-临 · 临时频率许可/批复）                        │
   │     起止时刻 · 用途 · 使用范围 · 功率/容量上限 · 批复事项       │
   │                                                                  │
   │   施工占道证（V-窗 · 保障窗）                                    │
   │     书面起止 · 区域边界 · 禁超窗作业 · 禁「先占后补证」         │
   │                                                                  │
   │   通电/联调验收（V-联 · 联测窗）                                 │
   │     本网金机 + 必要邻居联测 · 未验收禁签「保障就绪」            │
   │                                                                  │
   │   闭幕拆线还路（V-收 · 回收关停）                                │
   │     降功率/关停/拆临时天线/回写台账 · 禁「先用着再说」         │
   │                                                                  │
   │   治理拒签（V-治）                                               │
   │     无批复/过期/超窗禁开 · 挂S/T · 公开仓 L3                   │
   └──────────────────────────────────────────────────────────────────┘
```

口诀：

> **先证临时覆盖，再写频开临时站；有窗有测，闭幕必收。**  
> 无批复 / 过期 / 超窗还开站 = 没临时用电证就通大功率——**拒签**。  
> 闭幕不拆线 = 占道证过期还堵路——**违规**。

### 2.2 「临时用电 + 占道 + 闭幕拆线」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **临时许可** | 会展临时用电证 | 批复仍有效？覆盖保障期拟用频点组/地域/用途/功率上限？ | V-临 |
| **保障窗** | 施工占道证 | 书面起止时刻；禁超窗；禁先开后补；禁临时变永久 | V-窗 |
| **联测** | 通电/联调验收 | 本网+必要邻居联测完成才签「保障就绪」 | V-联 |
| **回收** | 闭幕断电拆线还路 | 降功率/关停/拆临时天线/回写台账；窗末日强制 | V-收 |
| **拒签治理** | 无证禁通电、过期禁占道 | 无批复/过期/超窗拒签；跨网挂 S；投诉挂 T；L3 | V-治 |

> 公开文书告诉我们：使用无线电频率通常应取得许可；临时使用无线电频率的，许可期限有专门上限（教学转述：《无线电频率使用许可管理办法》载明临时使用无线电频率的许可期限不超过 12 个月，**具体办理与属地要求以原文为准**）；对于临时使用、试验使用等情形，管理机构可颁发无线电频率使用批准文件，与许可证具有同等效力；设置、使用无线电台（站）通常应取得无线电台执照，重大活动可由主办/承办单位统一申请临时设台路径（属地条例/规定有公开表述的，以属地原文为准）；重大活动期间主办单位应向无线电管理部门提出保障需求。本篇只借「先批后用、有窗有测、到期必收」的顺序，**不编造内部时限数字以外已核原文的内容**。

### 2.3 和手册11 / 14 / 20 / 21 / 22 的咬合（指针，不重写）

- **手册22 U**：永久许可与执照台账。本篇临时批复**不替代**永久 U；保障期内若动用永久频点/台站，仍须 U 覆盖；临时台账可与 U 台账互挂脱敏编号。

### 2.4 新贴纸 V：临 / 窗 / 联 / 收 / 治（五个子类）

```text
                ┌──────────── 贴纸 V · 临/窗/联/收/治 ────────────┐
                │  V-临  临时批复有效且覆盖：频点组·地域·用途·功率上限·保障期 │
                │  V-窗  保障窗书面起止：禁超窗·禁先开后补·禁临时变永久     │
                │  V-联  联测窗完成：本网+必要邻居；未完禁签保障就绪         │
                │  V-收  闭幕强制回收：降功率/关停/拆临时天线/回写台账       │
                │  V-治  拒签治理：无批复过期超窗禁开·挂S/T·L3             │
                └──────────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签 / 拒放行触发 |
|------|--------|----------------------|
| **V-临** | 无临时批复、批复过期或不覆盖拟用方案 → 禁写频开临时站 | 「批复明天就到，今晚先开」 |
| **V-窗** | 无书面起止、超窗、先开后补、临时变永久叙事 → 拒签 | 「先开着，窗回头补」 |
| **V-联** | 联测窗未完成（缺邻居必要侧）仍签保障就绪 → 拒签 | 「本网自测够了」 |
| **V-收** | 闭幕/窗末日未降功率关停拆临时天线回写台账 → 治理 | 「先用着再说」 |
| **V-治** | 无批复开站、超窗继续、公开泄密、跨网不通知 → 治理 | 「公开贴批复全文号」 |

### 2.5 重大保障临时频率与联测窗最小工作流（背下来）

```text
  拟写临时信道 / 开临时站 / 临时扩功率 / OTAP 临时表 / 签保障就绪
        │
        ▼
  临时许可/批复仍有效？覆盖保障期拟用频点组·地域·用途·功率上限？（V-临）
        │否──▶ 拒签；走临时申请/延续路径（规则1、2）· 挂 U 若涉永久证照
        │是
        ▼
  保障窗是否书面起止？当前是否在窗内？有无「先开后补」「临时变永久」叙事？（V-窗）
        │否──▶ 拒签开站扩功率挪频（规则2、3）
        │是
        ▼
  联测窗完成？（本网金机 + 必要邻居；影响边界则挂 S）
        │否──▶ 禁签「保障就绪」（V-联 / 规则4）
        │是
        ▼
  写频 / OTAP / 临时信道表前再次核对临时台账（规则5，挂 J / M / U，主贴 V）
        │
        ▼
  保障期运行：超窗预警；投诉进线挂 T；边界变更先通知后复测（规则7）
        │
        ▼
  闭幕 / 窗末日：强制回收——降功率/关停/拆临时天线/回写台账（规则6）
  结案词用 V 子类；公开包 L3（规则8）
```

现场口诀：

> **先证临时覆盖，再写频开站；有窗有测，闭幕必收。**  
> 跳过联测的「保障就绪」= 没通电验收就对外宣称展馆可进场。

## 3. 核心交付：插页 V + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 V（而不是先贴 U / S / T / J / M）

| 现场信号 | 主贴 | 可次挂 |
|----------|------|--------|
| 重大保障临时频 / 临时站 / 保障窗 | **V**（先对临时批复与窗） | U / S / J / M |
| 临时批复临期 / 过期 / 超窗 | **V-治** | U（若涉永久） |
| 联测未完要签保障就绪 | **V-联** | S |
| 闭幕回收 / 窗末日关停 | **V-收** | U（台账回写） |
| 跨网/边界临时频 | **V** + 挂 **S** | T（若已投诉） |
| 保障期投诉进线 | **T**（不是 V） | 可查 V 作内因 |
| 永久许可/执照变更（非临时） | **U**（不是 V） | — |
| 仅写频参数对错、临时批复与窗已齐 | **J**（临时段已由 V 放行） | V 存档指针 |

> **口诀**：永久证照 → **U**；邻居与联测方法 → **S**；投诉分诊 → **T**；写什么进终端 → **J / M**；**临时批复还盖得住保障期吗、窗在不在、联测完了吗、闭幕收了吗 → V**。可叠挂，**临时保障主贴 V**。

### 3.2 插页 V · 临 / 窗 / 联 / 收 / 治（挂在总三联单或保障/写频单后）

| 行 | 名称 | 填写示例（教学虚构，L3） |
|----|------|--------------------------|
| **V1** | 主子类 + 次子类 | 「主 V-临 / 次 V-联」（或 V-窗 / V-收 / V-治） |
| **V2** | 临时批复核对 | 「有效期内 · 覆盖保障期 · 频点组覆盖（相对道号）· 地域覆盖 · 用途一致 · 功率上限已读」——禁写真实频点与全文号 |
| **V3** | 保障窗书面起止 | 「起：活动日前 D 日 HH:MM · 止：闭幕日 HH:MM · 书面编号角色 · 当前在窗内」 |
| **V4** | 临时台账对账勾选 | 「□批复编号(脱敏) □起止时刻 □频点组脱敏 □功率上限 □临时台址脱敏 □联测状态 □回收计划」 |
| **V5** | 联测窗 | 「本网金机：完成 · 必要邻居：已挂 S 完成 / 未完成」——未完成禁签保障就绪（规则4） |
| **V6** | 邻居与边界 | 「不影响边界 / 已书面通知+联测窗」——未通知禁宣称跨网临时就绪（规则7） |
| **V7** | 动作与禁令 | 「已冻结无批复开站；已排回收清单；拒签超窗 OTAP」 |
| **V8** | 回收与脱敏 | 「窗末日回收主人角色；公开包 L3；全文号仅存受控柜」 |

> **V2 / V3 任一否 → 禁止写频开临时站扩功率挪频（规则1、2、3）。**  
> **V4 缺任一项 → 禁签「保障就绪」相关放行（与规则4、5同向）。**  
> **V5 联测未完 → 禁签保障就绪（规则4）。**  
> **V6 影响边界但未通知 → 本页作废重填（规则7）。**  
> **V7 若写「先开后补」「临时变永久」「先用着再说」→ 本页作废（规则2、3、6）。**  
> **V8 无回收主人 → 禁签开幕放行（规则6 前置）。**

### 3.4 和总三联单怎么写（接手册06）

- **现象**：写「拟开临时站 / 拟写临时信道 / 拟签保障就绪 + V 子类」，**联测未完、回收未排前不写「保障就绪」**。

## 4. 深潜：八条硬规则 + 临时许可核对 + 联测窗节奏 + 回收关停路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **先证临时许可/批复仍有效且覆盖保障期拟用频点组/地域/用途/功率上限，再谈写频开临时站**——覆盖未证，射频与写频工单冻结；涉永久证照时挂 U。  
2. **无临时批复 / 过期 / 超窗 → 禁开临时站 / 禁扩功率 / 禁挪频（拒签）**——「先开后补」「先用着再说」不是出口。  
3. **保障窗必须书面起止；禁「临时变永久」「先开后补」**——占道证没批就占道 = 红线。  
4. **联测窗未完成（本网 + 必要邻居）禁签「保障就绪」**——挂 S；本网自测 ≠ 联测完成。  
5. **写频 / OTAP / 临时信道表前强制对临时台账**（挂手册11 J / 14 M / 22 U，**主贴 V**）——批量不豁免。  
6. **闭幕 / 窗末日强制回收：降功率 / 关停 / 拆临时天线 / 回写台账；禁「先用着再说」**——回收须有主人与签字。  
7. **跨网 / 边界临时频先通知后联测（挂 S）；投诉进线挂 T；禁功率战**——临时抬功率也不例外。  
8. **脱敏 L3：公开包禁真实频点、站名、单位名、许可/批复全文号、坐标、联系人**——原件受控另册。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：《无线电管理条例》明确使用频率通常应取得许可、设台通常应取得无线电台执照；《无线电频率使用许可管理办法》明确临时使用无线电频率的许可期限不超过 12 个月，临时/试验等情形可颁发批准文件并与许可证同等效力，不得擅自扩大使用范围或改变用途；《地面无线电台（站）管理规定》明确执照载明事项与变更/延续要求；《无线电管制规定》明确重大任务等情形下可依法实施无线电管制，管制命令含区域、对象、起止时间、频率范围等——**保障期若遇管制指令，本网临时站必须服从，不得以「我们有临时批复」对抗管制命令**；属地重大活动保障公开文件要求主办单位提前提出临时用频与设备需求。**这些是主管部门的许可、设台与管制规则，不是你方「先开后补」或「临时变永久」的借口。**

### 4.2 临时许可核对题（V-临）——临时用电证必问

```text
  ① 有效期与保障期覆盖
     批复是否在有效期内？是否完整覆盖拟保障时段（含彩排/撤场缓冲若批复载明）？
     → 临期：启动延期或压缩保障方案；过期/未覆盖：拒签开站写频

  ② 频点组覆盖
     拟用相对道号是否落在临时批复载明范围内？（教学用相对道号，禁真实频点）
     → 不覆盖：变更或新批复，禁私自挪到「旁边道」

  ③ 地域 / 使用范围
     拟设临时台址或使用区域是否在批复范围内？
     → 超范围：变更，禁「先搬到范围外再说」

  ④ 用途
     业务用途是否与批复一致？（保障指挥/交通/安保等角色标签）
     → 改用途：变更审批，禁擅自改用途

  ⑤ 功率 / 其他载明事项
     功率上限、特别规定、与永久许可关系是否已读并落入临时台账？
     → 未读：补读；拟超上限：先变更，禁「保障期例外私抬」
```

**临时批复未过五组题的冻结清单**：写临时信道、OTAP 临时表、开临时站、临时扩功率、私自挪频、签保障就绪。允许做的：临时台账核对、起草申请材料（L3）、约主管部门/保障指挥窗口、挂 S 预通知（若可能影响邻居）。

### 4.3 保障窗书面起止（V-窗）——占道证怎么钉

| 序号 | 最小集项（教学） | 为什么必须有 | 缺了会怎样 |
|------|------------------|--------------|------------|
| 1 | **书面起时刻** | 口头「大概开幕前」不可对账 | 拒签开站；补书面 |
| 2 | **书面止时刻** | 闭幕/撤场回收锚点 | 无末日 → 回收失主 |
| 3 | **文件角色编号（脱敏）** | 对账索引 | 缺编号 → 台账不可对 |
| 4 | **适用范围（区域角色）** | 超区域作业即超窗同类 | 超范围拒签 |
| 5 | **与批复有效期对齐检查** | 窗不能长过批复覆盖 | 不对齐 → 压缩窗或延期批复 |

> **口诀**：起、止、号、域、对齐——**五字窗钉**。教学记忆用；现场以批复与属地保障通知为准，但 **起止书面化** 几乎不可砍。  
> **「临时变永久」识别**：窗末日后仍发射、把临时相对道号写进「日常信道表」且无新的永久 U 覆盖、回收单空白却宣称「转正」——一律 V-治 拒签，走 U 变更/新许可路径，**不教话术过关**。

### 4.4 联测窗节奏（V-联）——通电验收怎么办

| 步 | 动作 | 拒签点 |
|----|------|--------|
| 1 | 定义联测窗：起止、参与角色（本网金机 + 必要邻居）、成功准则（L3） | 「开幕当天再测」无书面窗 |
| 2 | 本网侧：金机走测 / 关键点场强与话权（挂 Q/F 方法，主贴 V） | 只看网管假绿（挂 R 提醒） |
| 3 | 必要邻居：书面通知 + 挂 S；约定双方观测点 | 只发微信群、无回执角色 |
| 4 | 边界/共址：兼容与干扰最小集（指针手册20，不重写） | 单方自测签「双边就绪」 |
| 5 | 缺陷闭环：不合格项主人与复测时刻 | 带病签保障就绪 |
| 6 | 结案：V5 + S 联测记录互挂脱敏编号；公开包 L3 | 未联测宣称「保障就绪」 |

与手册20 四态联测交接：临时频联测 **V 放行开站 ≠ S 验收完成**；两边单据互挂。与手册19：屏全绿可能是假绿——**联测以金机与双边观测为准，不以值班屏单独定案**。

### 4.5 回收关停路径（V-收 / 规则6）

| 阶段 | 教学动作 | 禁令 |
|------|----------|------|
| 开幕前（回收计划） | 临时台账写明回收主人、清单（站/天线/信道表/OTAP 回滚） | 无主人禁签开幕放行 |
| 窗内临末日（前 N 小时，N 本网定） | 预警；冻结新开临时站；准备降功率/关停指令 | 禁「再拖一夜」 |
| 窗末日 / 闭幕 | 降功率 → 关停发射 → 拆临时天线（若有）→ 临时信道表回滚或冻结 → 台账回写 | 禁「先用着再说」 |
| 回收后 24h 内（教学建议） | 抽查：空口无临时相对道号残留；邻居知会（若曾挂 S） | 公开包仍 L3 |
| 若需转永久 | **另走 U 许可/执照路径**；转正核准前保持关停 | 禁口头「转正继续开」 |

### 4.6 弱项短补：临时批复 ≠ 永久许可 ≠ 写频文件 ≠ 联测记录

```text
   临时批复（用电证）  永久许可/执照（房产证+户口本）  写频文件（座位表）  联测记录（通电验收单）
   ────────────────  ────────────────────────────  ──────────────  ────────────────
   保障期怎么用频      日常长期怎么用、台怎么设        终端/中继写什么    窗内是否验收通过
   有起止·上限         U 台账（手册22）                 信道·色码·时隙…   本网+邻居观测
   到期必收            变更走 U-变                      改前须 V/U 覆盖   未完禁签就绪

   ✗ 「临时批复在，就能永久开」
   ✗ 「永久许可在，就能不问临时窗」
   ✗ 「写频成功 = 保障就绪」
   ✗ 「本网自测全绿 = 联测完成」
   ✗ 「OTAP 成功 = 合规」（OTAP 不创造临时批复）
```

所以规则5才硬：**写频 / OTAP / 临时信道表前强制对临时台账 V**——J/M 管「怎么改参数的风险」，U 管「永久资格」，V 管「这次保障的临时资格与窗」。

### 4.7 与主管部门 / 保障指挥路径怎么衔接（只讲合规路径，不教规避）

教学流程（细节以属地最新要求、活动保障通知与官方受理材料为准）：

1. **需求提出**：主办/承办或本网保障办按属地要求提前提出临时用频、临时设台、设备清单（L3 教学不编造表格字段）。  
2. **自查**：V2–V4 勾选；与永久 U 台账关系（哪些用永久、哪些用临时）；边界邻居清单。  
3. **取得临时许可/批复/临时执照路径**：按条例、办法、地面规定及属地重大活动规定办理；临时频率批准文件与许可证同等效力（办法公开表述）——**以原文与窗口要求为准**。  
4. **书面保障窗 + 联测窗**：写入临时台账；影响邻居挂 S。  
5. **写频/OTAP/开站**：规则5 对账后放行；金机复核。  
6. **保障期运行**：服从可能的无线电管制命令（《无线电管制规定》）；投诉挂 T；禁功率战。  
7. **闭幕回收**：规则6；台账回写；全文号受控，公开仓脱敏。  
8. **若转永久**：走 U，不走「临时顺延口头」。

**明确不教**：如何无证发射、如何伪造涂改批复、如何规避监测与管制、如何「先开后补」话术过关、如何把临时频藏进日常表永久使用、如何查找/对抗非法设台或黑广播。

### 4.8 开站 / 写频 / 签就绪前 15 分钟清单（可复印）

| 分钟 | 动作 |
|------|------|
| 0–3 | 打开临时台账卡：保障代号脱敏、拟用相对道号、窗起止 |
| 3–7 | V2 临时批复五组题；V3 窗在期内 |

### 4.9 与 J / M / U / S 单据互挂（V → 写频 / OTAP / 永久台账 / 邻居）

## 5. 现场映射：原话 → V 子类；对话脚本；夜班；禁写词

### 5.1 原话速查表

| 原话 | 主贴 | 动作 |
|------|------|------|
| 「临时批复还有效吗？盖得住保障期吗？」 | V-临 | 五组核对 |
| 「批复没到，先按拟用表开」 | V-治 | 拒签；等批复 |
| 「联测没完，先签保障就绪」 | V-联 | 拒签就绪；排联测 |
| 「闭幕了临时站先留着」 | V-收 | 强制回收路径 |

### 5.2 对话脚本（五则）

**脚本1 · 先开后补**  
对方：「批复明天肯定下来，今晚彩排必须开临时站。」  
你：「规则2、3：无批复/先开后补拒签。今晚能做的是台账预填与联测计划，不是发射。主贴 V-治。」

**脚本2 · 联测未完签就绪**  
对方：「本网金机全绿，邻居说明天再测，指挥部要『保障就绪』签字。」  
你：「规则4：联测窗未完成禁签保障就绪。可签『本网侧完成、双边未完成』，不能签就绪。主贴 V-联，挂 S。」

**脚本3 · 闭幕不拆**  
对方：「闭幕还有运维话务，临时站下周再关。」  
你：「规则6：窗末日强制回收。话务切回永久覆盖（须 U 仍有效）；临时段今晚关停路径走起。主贴 V-收。」

**脚本4 · 临时变永久**  
对方：「这组临时相对道号好用，写进日常模板吧。」  
你：「规则3：禁临时变永久。要长期用，走 U 许可/执照；核准前保持回收状态。主贴 V-治，挂 U。」

**脚本5 · 边界不通知**  
对方：「保障期临时降了边界功率，对邻居是好事，不用打招呼。」  
你：「规则7：跨网临时变更先通知后联测，挂 S。降功率也改覆盖与投诉归因；补通知。主贴 V，挂 S。」

### 5.3 夜班 15 分钟怎么用

1. 扫临时台账：在窗条数、临末日条数、无批复仍开站条数（应为 0）。  
2. 查联测状态：有无「未完成却签了就绪」。  
3. 查回收清单：窗末日是否有主人与指令草稿。  
4. 交班口述：在窗、临末日、冻结原因（V 子类）、回收主人。

### 5.4 「临时保障三问」（贴写频室 / 保障办）

```text
  1. 临时批复还在有效期内吗？覆盖今晚要做的事吗？书面窗在期内吗？
  2. 联测窗完成了吗？（本网 + 必要邻居）
  3. 回收主人是谁？窗末日指令准备好了吗？有没有「临时变永久」？
```

### 5.5 现象栏禁写词与可写词（贴值班台）

| 禁写 | 可写（L3） |
|------|------------|
| 真实频点、全文批复号 | 相对道号、脱敏编号 |
| 「先开后补」「临时变永久」「先用着再说」 | 「V 拒签：无批复/超窗/未联测/未回收」 |
| 「合法规避一下管制」 | 「服从管制命令；窗内按批复」 |

| 「邻居爱咋咋地」 | 「已/未挂 S 通知与联测」 |

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「拟用表在，批复未到」→ V-临 / V-治

现象：写频岗按拟用相对道号组 T1 写临时表，台账无批复编号脱敏。  
处置：拒签写频；冻结 OTAP；等批复入账；主贴 V-临。  
结案词：「V-治：无临时批复，禁写频开临时站。」

### 例 2 · 「批复有效期短于保障窗」→ V-窗 / V-临

现象：书面保障窗止于闭幕日 24:00，批复止于闭幕日前一日。  
处置：拒签「全窗就绪」；压缩窗或申请延期；未覆盖时段禁发射。  
结案词：「V-窗：窗与批复未对齐，禁超批复覆盖运行。」

### 例 3 · 「本网自测签保障就绪」→ V-联

现象：指挥部要签字，邻居联测未做。  
处置：拒签就绪；出「本网侧完成」中间态；挂 S 约窗。  
结案词：「V-联：联测未完，禁签保障就绪。」

### 例 4 · 「闭幕临时站继续开」→ V-收

现象：窗末日后空口仍见临时相对道号组 T1。  
处置：立即关停路径；拆临时天线；回滚信道表；台账标红；复盘主人。  
结案词：「V-收：超窗未回收，已关停并复盘。」

### 例 5 · 「临时道写入日常 OTAP」→ V-窗 + M + U

现象：运维欲把临时组写进全网日常模板并 OTAP。  
处置：拒签；临时段回收；若需长期用走 U；主贴 V-治 挂 M/U。  
结案词：「V：禁临时变永久；转 U 前保持关停。」

### 例 6 · 「边界临时抬功率未通知」→ V + S + 禁功率战

现象：保障期边界侧抬功率，邻网次日投诉。  
处置：主贴 T 分诊；并行查 V——批复是否允许、S 通知有无；补通知与复测；禁报复再抬。  
结案词：「V 缺陷致投诉；挂 S/T；规则7。」

### 例 7 · 「临时台账缺回收计划仍开幕」→ V-收 / V-账性勾选

现象：开幕放行单无回收主人。  
处置：拒签开幕放行；补 V8；补清单后再议。  
结案词：「V-收前置：无回收主人禁开幕放行。」

### 例 8 · 「公开周报贴出临时批复全文号」→ V-治 / L3

现象：宣传稿含真实场馆名与批复全文号。  
处置：下架；改 L3；原件受控；培训规则8。  
结案词：「V-治：L3 违规已纠正。」

### 例 9 · 「遇管制命令仍称有临时批复继续发射」→ V-治

现象：属地发布管制指令（公开教学场景），值班欲「我们有批复」继续。  
处置：服从管制命令与指令；临时站按命令限制/关停；记录 L3；不教对抗。  
结案词：「V-治：管制优先；批复不对抗管制命令。」

### 例 10 · 「联测完成但未回写临时台账」→ V-联 / 台账节奏

现象：双边联测已做，V5 仍空白，次日交接争议「到底就绪没有」。  
处置：24h 内回写；单据互挂 S 编号；就绪签字以台账+联测回执为准。  
结案词：「V：联测后未回写，对账节奏失效。」

## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 一句话 |
|------|--------|
| **临时频率许可/批复** | 保障期依法取得的临时用频凭证（教学喻：会展临时用电证） |
| **批准文件** | 临时/试验等情形下与许可证同等效力的用频批准（以办法原文为准） |
| **保障窗** | 书面载明的允许临时用频/设台的起止时段（教学喻：占道证时段） |
| **联测窗** | 本网与必要邻居约定的联合测试与验收时段 |
| **保障就绪** | 临时覆盖+在窗+联测完成+回收计划在册后的签字状态 |
| **临时台账** | 本网对临时批复/窗/联测/回收字段的可对账登记（脱敏） |
| **回收关停** | 窗末日降功率、停发、拆临时天线、回滚信道表并回写台账 |
| **临时变永久** | 超窗继续使用临时频或擅自写入日常表且无 U 转正——本篇红线 |
| **先开后补** | 无批复先发射再补手续——本篇红线 |
| **脱敏编号** | 公开与教学用的替代编号，非全文号 |
| **功率上限** | 临时批复载明发射功率不得突破（变更前） |
| **重大活动保障** | 主办/承办向无线电管理部门提出临时用频与设备等保障需求的活动场景 |
| **无线电管制** | 特定时间区域依法限制/禁止用频或采取技术阻断等（见管制规定） |
| **主贴 V** | 临时保障问题以 V 为主键，可挂 U/S/T/J/M |
| **L3** | 公开包最高脱敏等级（本系列约定） |
| **书面起止** | 保障窗以书面为准，聊天记录不算 |
| **必要邻居** | 联测最小集中必须纳入的边界/共址对端（本网制度定义） |
| **转正** | 临时需求转为长期使用时走 U 许可/执照路径，核准前关停 |

**易错观念**

1. ✗ 有拟用表 = 已获临时批复 → ✓ 拟用表 ≠ 批复。  
2. ✗ 永久许可在 = 不问保障窗 → ✓ 临时段仍要 V；永久段仍要 U。  
3. ✗ 本网自测全绿 = 保障就绪 → ✓ 必要邻居联测未完禁签就绪。  
4. ✗ 闭幕留着临时站方便运维 → ✓ 窗末日强制回收。  
5. ✗ 临时道好用就写进日常表 → ✓ 禁临时变永久；转正走 U。  
6. ✗ 先开后补是保障惯例 → ✓ 本篇红线。  
7. ✗ 降功率不用通知邻居 → ✓ 边界临时变更仍挂 S。  
8. ✗ 有临时批复可对抗管制命令 → ✓ 管制命令优先服从。  
9. ✗ OTAP 成功代替合规 → ✓ OTAP 不创造临时批复。  
10. ✗ 公开培训可以贴批复全文号 → ✓ 全文号受控，公开 L3。

### 参考答案

1. 临/窗/联/收/治：临时覆盖、书面保障窗、联测验收、回收关停、拒签治理。

3. 规则3（及 V-窗 / V-治）。  
4. 有效覆盖、频点组、地域、用途（+功率/其他）。  
5. 规则4；不够，必要邻居未测仍禁签就绪。

8. 规则7；主贴 V，挂 S；若已投诉挂 T。

10. 回收临时段；走 U 许可/执照转正；核准前保持关停。  
11. 不能；规则8，全文号受控另册。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **V** 五子类：临 / 窗 / 联 / 收 / 治。  
- 故事：会展临时用电证 + 施工占道证 + 闭幕拆线还路。  
- 八条硬规则：**先证临时覆盖再写频开站**；**无批复/过期/超窗拒签**；**书面起止禁临时变永久与先开后补**；**联测未完禁签就绪**；**写频/OTAP前对临时台账**；**闭幕强制回收**；**跨网挂 S、投诉挂 T**；**脱敏 L3**。  
- 与 U/S/T/J/M 分工：U=永久证照；S=邻居联测方法；T=投诉分诊；J/M=怎么改参数；**V=这次保障的临时资格、窗、联测与回收**。

### 11.2 回库路径
现场「要开临时站 / 写临时信道 / 签保障就绪」→ 本篇（贴纸 V + 插页 V + 联测窗卡）→ 临时批复五组 + 书面窗 + 联测 + 回收计划 → 影响边界挂 S → 再放行 J/M；闭幕走回收；投诉挂 T；转永久走 U；公开 L3。

### 11.3 下一篇手册候选（本篇不写正文）
- **非法设台与黑广播类线索内部上报边界**（只讲依法报告与证据保全，不讲排查对抗细节）  
- **电磁环境测试与验收报告台账**（开站前电磁环境与执照申请材料咬合）  
- （可选）**重大活动设备检测贴签与准入台账**（与本篇 V 设备侧咬合，仍 L3）

### 11.4 给带新人的三句话
1. 临时站开之前先问：批复还盖得住保障期吗？书面窗在期内吗？  
2. 联测没完不能签「保障就绪」；闭幕必须拆线还路，不能临时变永久。  
3. 全文号不许进公开包；边界临时变更先通知邻居。

### 11.6 十分钟给领导的电梯演讲
> 重大保障临时频先对批复是否覆盖保障期，书面窗起止，联测（含必要邻居）完成才能签保障就绪。无批复、超窗、先开后补、临时变永久一律拒签。写频和 OTAP 前对临时台账。闭幕强制降功率关停拆临时天线回写台账。边界临时变更先通知后联测。投诉走 T。转永久走 U。公开材料脱敏。贴纸 V，与永久证照 U、邻频 S、投诉 T、写频 J、批量 M 分工清楚。
