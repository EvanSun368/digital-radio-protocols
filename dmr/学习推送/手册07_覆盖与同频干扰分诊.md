## 1. 为什么要写这篇手册（动机 + 现场对话）

前六篇手册的贴纸 A–E 都是**协议层**的：猎站、登记、Grant、鉴权、管理操作。可现场有一大类工单，在协议层**根本没开始**，或者开始了但被**射频层**搅坏了。值班室里你一定听过这些：

- 用户：「**信号满格**，就是注册不上。」——满格是 RSSI（收到多少能量），不是「收到的是不是本网」。  
- 网优：「这里场强 -70 多（教学值），覆盖没问题。」——可分析仪上解出来的 **CC 是 9，本网是 3**（均为教学值）。那是别人的中继。  
- 用户：「说话断断续续，有咔咔声、机器人声。」——RSSI 不低，**BER 高**。不是远，是脏。  
- 班长：「每天晚上七点左右就不行，白天好好的。」——时间规律往往指向**别的发射机在那个时段开工**（他网、广播、其他业务），而不是你的天线晚上会变短。  
- 站务：「站点边上反而最差，走远一点倒好了。」——典型的**过载 / 阻塞 / 互调**指纹，不是覆盖。  
- 新人：「那就加大功率吧！」——加功率对弱覆盖可能有点用，对同频、互调、减敏**常常更糟**，还可能把自己变成别人的干扰源。  
- 测试：「中继自己一发射，自己的接收就变聋。」——**减敏（desense）**：自己的发射机在搅自己的接收机（双工器、天线隔离、连接器问题）。  
- 用户：「直通（脱网）模式能通，上中继就不行。」——中继上行接收端的问题（干扰 / 减敏 / 时序），而不是手台坏了。

这几句背后是同一件事：

> **「信号」这个词在现场至少有五个意思**：  
> **① 有没有能量**（RSSI / 频谱上有没有凸起）  
> **② 能不能对上节拍**（SYNC 能不能找到，一帧帧锁住）  
> **③ 是不是我家的**（CC 对不对，CACH / SYScode 是不是本网）  
> **④ 干不干净**（BER 低不低）  
> **⑤ 能不能办业务**（Aloha → 登记 → Grant → 有声，即贴纸 A–E 的世界）  
> 用户说「信号不好」，你要问清楚是**哪一层**不好。

本篇目标：能背出**「五格梯子」**；会用 **RSSI × BER × CC** 三个数把「覆盖 / 同频 / 邻频 / 互调减敏 / 时序」五类故障分开；会做**现场七步测量**（定点、金机、频谱、CC、BER、发射开关对比、衰减器测试）；会把结果写进总三联单空口栏 A1–A6，并新挂一张 **插页 F（覆盖 / 干扰）**；认识新贴纸 **F** 及其五个子类；能填完《本网覆盖与干扰分诊卡》；自测过关后，回库把本网最近三张「信号不好」工单（脱敏到 L3）按本篇重写。

**本篇硬禁令（写进脑子）**：不发明 ETSI 条款号（帧结构锚点以第 18–22 课、`01-空中接口/` 笔记为准；ETSI TR 102 398 只当「设计意图」的公开说明引用，不引条号）；**不写真实批复频点、真实站点名 / 站号、真实个号、真实 CC 规划表进公开仓库**（本篇所有 CC 值、dBm 值、BER 值都是**教学值**，不是任何规范门限）；**不教自行发射去「压制」干扰源**、不教去调别人的设备——发现他网 / 不明干扰，走本单位频谱管理与无线电管理机构的正规渠道；不把厂商网管上的中文提示当 ETSI 正式名；本篇不写下一篇手册正文。

## 2. 总图 / 故事：同一条车道上的五种麻烦

### 2.1 一句话：信道 = 一条 12.5 kHz 宽、按 30 ms 分格的车道

继续前面的比喻，但这次换成交通（因为射频本来就像路）：

```text
   频率方向（左右）：一条 12.5 kHz 宽的车道，左右是别人的车道
   ◀──── 邻道 ────▶◀════ 本道 12.5 kHz ════▶◀──── 邻道 ────▶

   时间方向（前后）：车道被切成格子，每格 30 ms，两格一轮 60 ms
   ┌──────┬──────┬──────┬──────┬──────┬──────┐
   │ TS1  │ TS2  │ TS1  │ TS2  │ TS1  │ TS2  │ ──▶ t
   └──────┴──────┴──────┴──────┴──────┴──────┘
     每格里的「车」= 一个 burst：中间有 SYNC（车牌底座），
     两边是载荷；下行（基站发）每格前面还有 CACH（路口指示牌）
```

在这条车道上，可能出现五种麻烦：

| 麻烦 | 交通比喻 | 射频说法 | 本篇子贴纸 |
|------|----------|----------|------------|
| **太远看不清** | 车开得远，牌子看不清 | 接收电平低，噪声相对大 → **弱覆盖** | **F-弱** |
| **同一车道来了别家车** | 别的车队也开在这条道上 | 同一频点上有他网 / 邻站信号 → **同频干扰** | **F-同** |
| **隔壁车道压线** | 隔壁车太宽 / 太近，蹭进来 | 相邻信道能量泄漏 / 本机选择性不够 → **邻频干扰** | **F-邻** |
| **路面被震坏** | 旁边大卡车太猛，路面裂了、长出「幽灵车」 | 强信号让接收机过载：**阻塞、减敏、互调** | **F-互** |
| **抢同一个时间格** | 两辆车同时挤进同一格 | 时隙 / 时序不对齐、直通与中继撞格 → **时序冲突** | **F-时** |

### 2.2 五格梯子（本篇最重要的图）

```text
  第5格  业务层  能否 Aloha → 登记 → Grant → 有声？     → 贴纸 A/B/C/D/E（手册01–05）
           ▲  只有下面四格都「过」，才轮到这一格
  第4格  质量层  BER 低吗？（同一个 CC 下解出来干净吗）   → 不干净：F-弱 / F-同 / F-互
           ▲
  第3格  身份层  CC 对吗？CACH/Aloha/SYScode 是本网吗？   → 不是本网：F-同（他网/邻站）
           ▲
  第2格  同步层  能找到 DMR SYNC、一帧帧锁住吗？         → 锁不住：F-弱 / F-邻 / F-互 / 非DMR
           ▲
  第1格  能量层  频点上有能量吗？多少（RSSI/频谱）？      → 没有：F-弱 / 设备 / 天馈
```

**记法：从下往上爬，哪一格先摔下来，就在哪一格找原因。** 不准跳格：第 1 格都没问（有没有能量），就直接去翻 Reason 剧本（第 5 格），这就是手册 06 说的「空心单」。

### 2.3 三个数字：RSSI × CC × BER

梯子五格里，现场最常见、最便宜能拿到的是三个数：

| 数字 | 回答哪一格 | 一句话 | 最容易犯的错 |
|------|-----------|--------|--------------|
| **RSSI**（接收信号强度指示） | 第 1 格 | 「这条车道上**总共**有多少能量」——它不管能量是谁的 | 把「满格」当成「本网信号好」 |
| **CC**（Color Code，色码，0–15） | 第 3 格 | 「这辆车**挂的是谁家的牌**」——每个 burst 都带，4 bit | 以为 CC 是加密；以为 CC 不同就绝对不干扰 |
| **BER**（误码率） | 第 4 格 | 「解出来的比特里**错了多少**」——越低越干净 | 不看 BER 只听声音；把 BER 和 RSSI 混成一个「信号」 |

**三个数的组合，就能把五类故障粗分开（本篇 §3.2 是完整表）：**

```text
   RSSI 低  + 有本网CC  + BER 高   → 太远：F-弱
   RSSI 高  + CC 不是本网          → 别人家的车：F-同（他网/邻站同频）
   RSSI 高  + 本网CC   + BER 高    → 车道被搅：F-同（叠加）/ F-互（减敏、互调）
   RSSI 高  + 锁不住 SYNC          → 不是DMR车 / 隔壁压线 / 路面坏：F-邻 / F-互 / 非DMR信号
   RSSI 正常 + 本网CC  + BER 低    → 射频没问题！回贴纸 A–E（协议层）
```

> 最后一行最值钱：**射频层「三过」（能量够、CC 对、BER 低），就请离开射频，去协议层找原因。** 这一行能省掉现场一半的「换天线、加功率、爬铁塔」。

### 2.4 为什么 DMR 有「身份层」：SYNC、CC、CACH 是协议给射频的证据

弱基础同学最容易觉得「干扰是射频的事，跟协议无关」。其实 DMR 的设计者早就在帧里放了几样东西，专门帮接收机**认出自家、拒绝别家**（ETSI TR 102 398《DMR General System Design》对此有公开说明：不同方向 / 类型用不同 SYNC 图样，帮助拒绝同频干扰；色码用来「给网络或某个中继编址」，以便拒绝同频干扰——这里只引设计意图，不引条款号）：

| 帧里的东西 | 在哪 | 帮你回答什么 | 回哪课 |
|-----------|------|--------------|--------|
| **SYNC**（48 bit 同步图样） | 每个 burst 中间 | 「这是不是 DMR 的车？是语音还是数据？是基站发的还是手台发的？」 | 第 16、19 课 |
| **CC**（色码，4 bit） | 数据 / 控制 burst 的 Slot Type 里；语音 burst 的 EMB 里 | 「这辆车是谁家的？」 | 第 20–21 课 |
| **CACH**（公共通告信道） | **只在基站下行**每个 burst 前面 | 「这一格是 TS1 还是 TS2？上行忙不忙？」——能稳定解出 CACH，说明你正在听一个**有节拍的基站** | 第 18 课 |
| **Aloha / SYScode**（Tier III） | TSCC 上的控制信令 | 「这是不是**本网**的控制信道？」 | 手册04、第36课 |

**所以：「能解出 SYNC → 能读出 CC → CC 等于本网 → 能稳定解 CACH / Aloha」本身就是一串协议层证据**，它们比「信号满格」可信一百倍。手册 06 §11.6 说过：空口栏 A3 写「可解 / 不可解 + CC 值」，不写「信号好」——本篇把这句话展开成一整套方法。

### 2.5 新贴纸 F（以及它和 A–E、X 的关系）

| 贴纸 | 一句话 | 层 | 回哪篇 |
|------|--------|----|--------|
| A 猎站 | 还没守住自家 TSCC | 协议（第5格） | 手册04 |
| B 登记 | 到了前台没给入住 | 协议 | 手册01 |
| C Grant 无声 | 发了房卡，房间静 | 协议 | 手册02 |
| D 鉴权 | 出了题、交了卷、没过 | 协议 | 手册05 |
| E 管理操作 | Stun/Revive/DGNA/短信没按预期 | 协议 | 手册03 |
| **F 覆盖 / 干扰（新）** | **车道本身出了问题：远、挤、压线、路面坏、抢格** | **射频（第1–4格）** | **本篇** |
| X 证据不足 | 诚实地说还不知道 | — | 手册06 |

**F 的五个子类**：**F-弱**（弱覆盖）、**F-同**（同频：他网 / 邻站 / 复用距离不够）、**F-邻**（邻频）、**F-互**（互调 / 阻塞 / 减敏）、**F-时**（时序 / 时隙冲突）。

**F 和 A 的边界最容易混**：手机一直搜网，可能是 A（列表 / SYScode / CHAN 写错，手册04），也可能是 F（根本收不到 / 收到的是别人）。**判法**：在同一位置用金机 + 分析仪看第 1–3 格。第 3 格「本网 CC + 本网 Aloha 稳定可解」→ 射频过关，是 A；第 1–3 格任何一格摔下来 → 先 F，修好 F 再看是否还有 A。手册 06 §4.6 的「最多两张贴纸」规则在这里常用：**F 主 + A 次**（「收得到但时好时坏，导致反复猎站」）。

## 3. 核心交付：五格梯子工作流 + 三数判型表 + 插页 F

### 3.1 五格梯子工作流（每张「信号不好」工单照念）

```text
① 能量：故障点上，本网频点有没有能量？RSSI 多少？频谱上凸起的形状像不像一个 12.5 kHz 的 DMR？
② 同步：分析仪能不能锁 DMR SYNC？锁住的是基站下行（BS-sourced）还是手台上行（MS-sourced）？
③ 身份：解出的 CC 是多少？等于本网规划吗？（Tier III：Aloha / SYScode 是不是本网？CACH 稳不稳？）
④ 质量：同一个本网 CC 下，BER 多少？时好时坏有没有规律（时间 / 位置 / 本站发射与否）？
⑤ 业务：前四格都过 → 离开射频，按手册01–05 贴 A–E；有一格没过 → 贴 F + 子类，按 §3.2 下一动作
```

**五问答不全，空口栏 A3 只能写「未测」，结论只能是 X**，不许写「覆盖问题」「干扰问题」——这两个词在本篇里是**需要证据的结论**，不是口头禅。

### 3.2 三数判型表（RSSI × SYNC/CC × BER → 子贴纸）

> 表中「高 / 低」都是**相对本网同类位置的正常值**说的（本网要自己建基线，§7.3）；本表不给任何 dBm 或 % 门限，因为门限取决于设备、天馈、业务要求。

| # | RSSI | SYNC | CC | BER | 其他指纹 | 初判 | 下一动作 |
|---|------|------|----|-----|----------|------|----------|
| 1 | 低 | 时有时无 | 本网 | 高 | 走近站点就好；金机同位置也差 | **F-弱** | 记位置 / 室内外 / 楼层；转网优补盲（§4.2） |
| 2 | 高 | 稳 | **非本网** | —（对本网无意义） | 本网频点上被别人占；时间有规律 | **F-同（他网）** | 记 CC、时段；**不自行发射对抗**；走频谱管理渠道（§4.3） |
| 3 | 高 | 稳 | 本网 / 他 CC **交替出现** | 本网时高 | 两个站覆盖交界处；同频复用 | **F-同（邻站/复用）** | 核同频复用规划与 CC 规划（L0 资料，不进公开仓） |
| 4 | 高 | 本网可锁 | 本网 | **高** | 声音咔咔；本站一发射就变差 | **F-互（减敏）** | 发射开 / 关对比；查双工器、天线隔离、接头（§4.5） |
| 5 | 高 | 锁不住 | — | — | 频谱上凸起不像 12.5 kHz DMR，或偏在一侧 | **F-邻 / 非 DMR 信号** | 看频谱形状、偏移；看邻道是谁（§4.4） |
| 6 | 高（甚至很高） | 时锁时丢 | 本网 | 高 | **离站越近越差**；加衰减后反而变好 | **F-互（阻塞 / 互调）** | 衰减器测试（§4.5）；找附近强发射源 |
| 7 | 正常 | 稳 | 本网 | 正常但**某个时隙**差 | 只 TS1 或只 TS2 差；直通用户在附近 | **F-时** | 看两时隙功率剖面；查直通 / 中继撞格（§4.6） |
| 8 | 正常 | 稳 | 本网 | 低 | 但就是登不上 / 没声 | **射频过关 → 不是 F** | 回贴纸 A–E（手册01–05） |

**三条铁律**：

1. **CC 不是本网，就别再讨论本网的 BER。** 你在测别人的车有多干净，没意义。先回答「为什么本网频点上全是别人」。  
2. **RSSI 高 + BER 高，几乎从不是覆盖问题。** 覆盖问题的样子是「RSSI 低 + BER 高」。高高组合要往同频叠加、互调、减敏想。  
3. **第 8 行出现时，立刻离开射频。** 别让「再测一次场强」拖住协议层排查。

### 3.3 总三联单空口栏：射频证据怎么写（接手册 06 §3.2）

手册 06 规定空口栏 A1–A6。本篇规定射频工单里这六项**必须**怎么写：

| # | 项 | 射频工单好例子（教学虚构） | 坏例子 |

| A1 | 录制设备 + 时间覆盖 | 「分析仪#2 + 频谱仪#1，19:02:00–19:20:00（以网管为准，分析仪 −00:00:41）」 | 「测了一下」 |

## 4. 深潜：五个子类背后的物理（只取运维要用的那一层）

### 4.1 先补弱项：噪声为什么会让 4FSK「判错台阶」

加餐课说过：4FSK 用**四个频偏台阶**装货，每个台阶代表 2 bit。常见示意（台阶值是 DMR 常见的标称偏移量，测试仪表上也这样显示）：

```text
  频偏
  +1944 Hz ─────  台阶「+3」  → 01
   +648 Hz ─────  台阶「+1」  → 00
   −648 Hz ─────  台阶「−1」  → 10
  −1944 Hz ─────  台阶「−3」  → 11
              ▲
   接收机每 1/4800 秒「看一眼」，判断当前落在哪个台阶
```

（比特映射以第 4 课 / `01-空中接口/` 笔记为准，这里只是帮你记「四个台阶」。）

接收机要做的事只有一件：**每个符号时刻，判断频偏落在哪个台阶。** 台阶之间只隔约 1.3 kHz。现在看三种麻烦怎么破坏这一眼：

| 情况 | 接收机看到的 | 结果 |
|------|--------------|------|
| **弱覆盖**（信号小，噪声相对大） | 台阶线变「毛」，上下抖 | 偶尔把 +1 判成 +3、−1 判成 +1 → **BER 升高**；RSSI 低 |
| **同频叠加**（两路 DMR 同时在一条道） | 两套台阶叠在一起，频偏是两者的「混合」 | 弱的那路基本解不出；强的那路若强得够多，仍能解（类似 FM 的**捕获效应**）→ **RSSI 高，但 CC 可能是别人的** |
| **互调 / 阻塞**（接收机前端被强信号「顶饱」） | 放大器失真，台阶被压扁、长出幻影 | SYNC 时锁时丢；**RSSI 高、BER 高**，离强源越近越差 |

**一句话**：BER 就是「判错台阶的比例」。RSSI 告诉你「声音多大」，BER 告诉你「听清了多少」。**大声嚷嚷但满嘴方言（他网）或在工地旁边说话（互调），声音再大也听不清。**

再接一句 TDMA：一个时隙 30 ms，里面除了载荷还有 SYNC。**SYNC 是接收机对表的地方**——它用这 48 bit 已知图样确认「我对准了一个 burst，而且是基站 / 手台发的、语音 / 数据」。锁不住 SYNC，后面的 CC、CACH、载荷全读不出。所以第 2 格（同步）排在第 3 格（身份）前面。

### 4.2 F-弱：真正的覆盖问题长什么样

**指纹**：

- RSSI 低（相对本网同类位置基线）；  
- 本网 CC 能解但时断时续，BER 高；  
- **金机在同一点同样差**（排除终端）；  
- **走近站点就变好**，有明显的空间规律（楼层、室内深处、地下、山背面）；  
- 时间上**没有规律**，或随人流 / 车流（人体、车辆遮挡）轻微变化。

**现场常见原因（只列运维要知道的）**：距离 / 地形遮挡；建筑穿透损耗（室内、电梯、地下）；天馈损耗（馈线、接头进水、天线倾角被风吹偏）；手台天线断 / 松 / 用错频段天线。

**注意上下行不对称**：DMR 中继下行（基站→手台）功率通常比手台上行大得多。会出现「**能听见基站（下行 Aloha 能解），但基站听不见我（上行登记 RAND 发了没回）**」。这时空口栏要写：「下行 CC=本网、BER 正常；上行无 ACK」——**它很像贴纸 B（登记无回应），但根因是上行覆盖**。判法：同点金机上行是否成功；离站近一点重试是否成功。

**下一动作**：补测量点（至少 3 个点画出「好—差」边界）；转网优（补盲、室分、调整天馈）；终端侧检查天线。**不做**：单点加功率。

### 4.3 F-同：同一车道上来了别人

**两种来源**：

1. **他网**：别的单位 / 别的系统在同一频点上使用（可能是合法复用、规划冲突，也可能是违规发射）。指纹：**CC 不是本网**，或干脆是模拟调频、其他数字制式（锁不住 DMR SYNC）。  
2. **本网邻站 / 同频复用**：本网为了省频率，在相隔足够远的站点复用同一频点，并给它们**不同的 CC**。指纹：在两站覆盖交界处，**本网 CC 和邻站 CC 交替出现**，谁强听谁。

**CC 能做什么、不能做什么（易错！）**：

| CC 能做的 | CC 不能做的 |
|-----------|-------------|
| 让接收机**拒收**别家 CC 的 burst，不至于被别人的中继「带着转发」、不至于手台被别人的话开静噪 | **不能把两路信号在空中分开**——两路同时到达，能量照样叠加，弱的一路照样被淹 |
| 帮你**认出**干扰是谁（是本网邻站还是外网） | 不是加密；不提供保密性（第 20 课 / 手册05「鉴权≠加密」同理） |
| 让同频复用在**距离足够**时安全共存 | 距离不够时救不了你——这时要的是频率规划，不是换 CC |

所以 F-同的结论永远要写清楚：**「CC 不同，所以没误转发；但能量叠加导致本网 BER 高」**，或**「本网频点上只剩他网 CC，本网被淹没」**。

**时间规律是 F-同 的好朋友**：他网常有作息（上下班、夜间作业、节假日）；本网邻站同频在高话务时段更容易「撞」。记下时段——**只写现象和时段，不写「肯定是某某单位」**（E5 推测，手册06 §3.5）。

**下一动作**：本网邻站 → 网优核复用距离与 CC 规划；他网 / 不明信号 → 整理脱敏证据，经本单位频谱管理岗报无线电管理机构。**不做**：自行发射对抗；在群里点名猜测。

### 4.4 F-邻：隔壁车道压线

12.5 kHz 车道的两边是别人的 12.5 kHz 车道。理想情况下各走各的，但现实里：

- **发射端压线**：邻道发射机的频谱「裙边」太宽（或本身有毛病），能量溢进本道；  
- **接收端看不清线**：本机接收滤波器选择性有限，邻道信号很强时（比如邻道的发射机就在旁边）漏进来。

**指纹**：

- 频谱仪上能量凸起**中心不在本道中心**，偏在一侧，或本道一侧边缘被「抬高」；  
- 锁不住 SYNC，或 BER 随邻道是否发射而跳变；  
- 和「离谁近」强相关：手台靠近某个邻道发射机时最差。

**和 F-同的区别**：F-同的能量**正好在本道中心**，常能解出别人的 CC；F-邻的能量**偏在一侧**，通常解不出完整 DMR。频谱截图上的「偏不偏」是最直观的证据（截图按 §3.3 改成相对刻度）。

**下一动作**：记录邻道活动时段；网优 / 频谱岗核邻道使用情况；站点上检查接收滤波。

### 4.5 F-互：路面被震坏（阻塞、减敏、互调）

这一类最反直觉：**信号越强，问题越大。**

```text
             正常                              被强信号顶饱
   输入 ─▶ [放大器：线性] ─▶ 干净输出     输入 ─▶ [放大器：饱和] ─▶ 失真 + 幻影
           小信号放大得好                       强信号把放大器推到极限
```

| 名称 | 一句话 | 典型现场 |
|------|--------|----------|
| **阻塞（blocking）** | 一个离本道不远的**强信号**把接收机前端顶饱，本道小信号被「压」住 | 手台站在别的大功率发射天线下面 |
| **减敏（desense）** | 接收机**灵敏度下降**——需要更强的信号才能解对。最常见的是**中继自己的发射机搅自己的接收机** | 中继一转发，上行用户就断；停发就好 |
| **互调（intermod，IMD）** | 两个（或多个）强信号在非线性器件里「相乘」，生出**新的频率**，恰好落进本道 | 典型三阶产物落在 **2f1−f2、2f2−f1**；几个站共址时多见；生锈接头、金属结构也可能产生（「无源互调」） |

**两个现场测试（在维护窗、经批准、按本单位规程做）**：

1. **发射开 / 关对比（查减敏）**：用信号源从中继接收端注入一个已知强度的测试信号（或用固定位置金机），分别在本站发射机**停发**和**发射**时看 BER / 灵敏度。两者差得多 → 减敏；差不多 → 排除本站减敏。公开资料（如 §10 的 scivision、SRG 俱乐部文章）都用这个思路：**同样的接收，换个状态，看差多少 dB。**  
2. **衰减器测试（查互调 / 阻塞，3:1 指纹）**：在接收机前加一个已知衰减（比如 10 dB）。**真实信号**会降 10 dB；**三阶互调产物**会降约 **30 dB**（因为它和输入的三次方有关），常常直接消失。**加衰减反而变好** = 接收机原来被顶饱了，是 F-互。

**下一动作**：减敏 → 站务查双工器、天线隔离、馈线和接头；互调 → 网优 / 频谱岗算共址发射机的组合频率，查无源互调源。**不做**：加功率（让产物更强）；随意拆装站点设备（走站务规程）。

### 4.6 F-时：两辆车抢同一个时间格

TDMA 的好处是两路话共用一条车道；代价是**大家必须对表**。DMR 中继模式下，手台跟着基站下行的节拍（CACH 告诉它哪格是 TS1、哪格是 TS2）在上行对应时隙发射。时序出问题的几种现场样子：

| 情况 | 现象 | 证据 |
|------|------|------|
| **直通（talk-around / 脱网）用户在中继频点附近直接发射** | 中继某个时隙间歇受扰；直通用户说话时，中继上的人听到断续 | 分析仪上看到 MS-sourced 的 burst 出现在不该出现的地方 / 时段 |
| **远近效应**：近处手台功率大，在相邻时隙的上升 / 下降沿「溢出」 | 只有一个时隙差，另一个时隙正常 | 功率-时间剖面（power profile）上能看到 burst 边缘异常 |
| **同频两个中继各打各的节拍**（同频复用 + 无时间同步） | 交界处两个时隙都时好时坏 | CC 交替 + 时隙边界对不齐 |
| **终端时钟 / 频率偏移大** | 某一台机器特别差，其他机器正常 | 分析仪显示该机频率误差 / 符号时钟误差偏大；**金机正常** |

**和贴纸 C 的边界**：Grant 到了业务信道某时隙后没声（手册02）。如果那个时隙在业务信道上**本网 CC 稳、BER 正常**，是 C；如果只有那个时隙 BER 高 / 被 MS-sourced 外来 burst 占，是 **F-时 主 + C 次**。

**最后一个提醒（终端频偏）**：手台本身频率偏了几百赫兹，接收会把台阶整体看歪，BER 升高；公开论坛里常见「调一下频率偏移，BER 就好了」的案例。**这其实是终端问题，不是空口干扰**——金机对照（R4）一做就分得开。归到终端栏 T1/T6，贴纸写 X 或按本网规则交终端维修，**不贴 F**。

## 5. 现场映射：用户原话 → 先爬哪一格；七步测量；对话脚本

### 5.1 用户 / 网管原话 → 先查哪格

| 原话（E3 线索） | 最可能先摔的格 | 先做什么 |
|-----------------|----------------|----------|
| 「没信号」「一格都没有」 | 第 1 格 | 金机同点看 RSSI；查手台天线 |
| 「信号满格登不上」 | 第 3 格 | 看 CC / Aloha 是不是本网 |
| 「有声但咔咔、机器人声」 | 第 4 格 | 看本网 CC 下 BER；看时间规律 |
| 「站边上反而差」 | 第 2–4 格（F-互） | 衰减器测试；看附近强发射源 |
| 「晚上 / 某时段准时不行」 | 第 3–4 格（F-同） | 按时段录 CC / BER |
| 「中继一说话我就断」 | 第 4 格（减敏） | 申请维护窗做发射开 / 关对比 |
| 「直通能通，上中继不行」 | 上行第 1–4 格 | 测中继上行接收；查直通 / 减敏 |
| 「只有我这台不行」 | 终端 | 金机对照；查频偏、天线、写频 |
| 「信号好好的，就是没声」 | 第 5 格 | 射频过关就回贴纸 C（手册02） |

### 5.2 现场七步测量（每次出外勤照做，约 30–60 分钟）

```text
步1 定点：选 2–3 个测量点（坏点 P1、交界 P2、好点 P3），记代号、室内外、楼层
步2 对时：按手册06 §3.3 做对时三步；表头写基准与偏差
步3 金机：同点同信道，金机 + 故障机各试一次（开机 / 登记 / 呼叫）
步4 能量：频谱仪 / 分析仪看本道能量与形状（中心？偏一侧？多个凸起？）→ 第1格
步5 同步 + 身份：分析仪锁 SYNC，读 CC；Tier III 再看 Aloha / SYScode → 第2–3格
步6 质量：本网 CC 下读 BER；换时段 / 换点再读，找规律 → 第4格
步7 对比测试（按需）：发射开 / 关（减敏）、衰减器（互调 / 阻塞）
     → 只在维护窗、经批准、按站务规程；测试结果写进插页 F 的 R6 / R7
收尾：填插页 F；按 §3.2 判型；外发前过手册06 §7.4 脱敏检查
```

**一张最小工具清单**：金机 1 台（已知写频 / 固件正常）、DMR 分析仪或带 CC / BER 显示的测试设备、频谱仪（或带瀑布图的 SDR，仅用于接收观察）、固定衰减器、对时用的网管锚点、记录表（§7.2）。没有分析仪时，至少用金机的 RSSI 显示 + 现象记录，**并在 A3 写「仅金机 RSSI，未测 CC / BER」**——诚实比好看重要。

### 5.3 值班对话脚本（可直接照着说）

#### 对话 A · 「信号满格就是登不上」

> 用户：满格啊，就是注册失败。  
> 你：满格说明那条频道上有不少能量，但不一定是咱们的。我们这边先用测试机在您那个位置看一下「色码」——就是每台中继自己挂的门牌号。  
> （测后）你：您那儿收到的门牌不是咱们的，是另一个系统的，比咱们的强。所以手台一直在跟「别人家」打招呼。这不是手台坏了，也不是您操作问题。我们已经记下时间和位置，交给频谱协调，先给您一个临时方案：____（本网自定，如换到哪个信道 / 去哪个位置）。

#### 对话 B · 「有声但是咔咔的」

> 你：咔咔声一般是「听到了但没听清」。我们会看一个叫误码率的数，看看是距离远（信号小）还是有东西在搅（信号大但脏）。  
> 方便的话告诉我：在哪几个位置最明显？固定时间段吗？旁边有没有别的大天线？

#### 对话 C · 网优说「场强没问题」

> 你：场强我同意没问题。我这边补一个数：同一个点，解出来的 CC 是 9，本网规划是 3（教学值）；本网 CC 出现时 BER 也偏高。所以我想贴 F-同，不是 F-弱——下一步可能要核一下这个频点的复用和外部占用，不是补覆盖。

#### 对话 D · 班长说「先把功率开大试试」

> 你：班长，五格梯子我们只爬到第 3 格，看到的是别人的 CC。现在开大功率，对方那边可能也受影响，咱们这边被淹的情况未必改善。我建议先按插页 F 把时段证据收齐，走频谱管理；功率调整等网优评估。

#### 对话 E · 站务说「中继最近灵敏度差」

> 你：能不能在下个维护窗做一次发射开 / 关对比？如果发射时 BER 明显更差，就是减敏，查双工器和接头；差不多的话，就不是本站自己搅自己，我们再看外面。

### 5.4 「先射频梯子 / 后协议贴纸」与「射频过关就离开」反例集

| 错误做法 | 正确做法 |
|----------|----------|
| 「注册失败」直接翻 Reason 剧本，发现空口根本没有本网 Aloha | 先爬第 1–3 格；没有本网 Aloha → 先 F 或 A |
| 场强满格就写「覆盖没问题，终端故障」 | 看 CC / BER；金机对照后再判终端 |
| 本网 CC、BER 都好，还在反复测场强 | 第 8 行：离开射频，回 A–E |

| 在群里发带真实频率刻度的频谱截图 | 改相对刻度，L2 去掉站名和经纬度 |

## 6. 工作实例（8 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「满格注册失败」→ F-同（他网）
T3「屏显注册失败，信号满格」。A3：①RSSI 高 ②SYNC 稳（BS-sourced）③CC=9，本网 CC=3 ④本网 BER 不可测。A6：全窗无本网 Aloha。R5：仅工作日 08:30–17:30。**结论 F-同（主）**；依据「A3③ + A6」；下一动作：脱敏证据交频谱管理岗；禁止：加功率、改 CC。**如果当初直接翻 Reason 剧本**，你会在第 5 格找一个不存在的 NACK。

### 例 2 · 「地下车库没信号」→ F-弱 + 上下行不对称
P1（地下二层）：下行 RSSI 低、本网 CC 时有时无、BER 高；P2（地下一层）：下行可解，上行登记 RAND 发出无回应；P3（地面）：正常。金机同样表现。**F-弱（主），B 只是表象**。下一动作：转网优评估室分；用户临时方案：上到地面再登记。

### 例 3 · 「中继一转发就断」→ F-互（减敏）
维护窗 R6：停发时上行测试 BER 低；发射时 BER 明显升高（教学值：从接近 0 升到数个百分点）。A6：频谱上无外来凸起。**F-互（减敏）**。站务查出双工器一端接头松动。修复后复测两状态无差异——**复测结果写回同一张单**，结案。

### 例 4 · 「站边上反而差」→ F-互（阻塞 / 互调）
P1（站下 50 m 内，教学值）：RSSI 很高，SYNC 时锁时丢；P2（稍远）：正常。R7：加 10 dB 衰减后，本网信号降约 10 dB，一个杂散凸起降约 30 dB 并消失，本网 BER 变好。**3:1 指纹 → 三阶互调**。网优按共址发射机列表（L0）计算组合频率，定位到某共址设备。公开工单只写「共址发射机甲 / 乙」。

### 例 5 · 「交界处时好时坏，反复搜网」→ F-同（邻站复用）主 + A 次
P2：CC=3 与 CC=5（均本网，教学值）交替，谁强听谁；手台在两个 TSCC 间来回猎站（插页 A：猎站列表正确）。**F-同（复用距离 / 规划）主 + A 次**。下一动作：网优核复用与 CC 规划；不改猎站列表（列表没错）。对照手册04 例 6「相邻站来回蹦」——那篇是协议视角，这篇补上射频视角。

### 例 6 · 「只有 TS2 有问题」→ F-时
同一业务信道 TS1 正常，TS2 BER 间歇高。分析仪看到 TS2 时段夹杂 MS-sourced 外来 burst，CC=本网。追查为附近一组用户在该频点使用直通模式。**F-时（主）+ C（次）**。下一动作：规范直通使用频点（本网写频规划，L0）；不动中继。

### 例 7 · 「就我这台不行」→ 不是 F
故障机 BER 高；金机同点同信道 BER 低。分析仪显示故障机频率误差明显偏大。**结论 X → 终端维修**（终端栏 T1/T6），不贴 F。教训：R4 金机对照一格，就能挡住一半误贴。

### 例 8 ·（对照）射频三过 → 回协议层
用户「信号好好的，Grant 了没声」。业务信道：RSSI 正常、本网 CC、BER 低、两时隙都干净。**第 8 行：射频过关**。转手册02 Grant 无声四问，查出业务信道门牌（CHAN）写频缺行——**贴纸 C**，与射频无关。这张单的好处是 A3 一行写清「射频三过」，后面的人不会再去爬铁塔。

## 8. 术语表（本篇约 26 词）+ 易错观念

| 术语 | 一句话 | 易错 |
|------|--------|------|
| 信道 / 车道 | 一条 12.5 kHz 宽的频率带子 | 频点是中心，带宽是宽度 |
| 4FSK | 四个频偏台阶装 2 bit / 符号 | 不是调幅；台阶判错 = 误码 |
| 符号率 | 约 4800 符号 / 秒 | 不等于比特率（9.6 kbps） |
| TDMA 时隙 | 30 ms 一格，两格一轮 60 ms | 两时隙可被不同问题影响 |
| burst | 一个时隙里发的一包 | — |
| SYNC | burst 中间的 48 bit 已知图样 | 区分语音 / 数据、BS / MS 来源 |
| CC 色码 | 4 bit（0–15）系统 / 中继身份 | 不是加密；不能把叠加的能量分开 |
| CACH | 基站下行每个 burst 前的通告信道 | 上行没有 CACH |
| Aloha / SYScode | Tier III 控制信道上的本网身份 | 手册04 |
| RSSI | 收到的总能量指示 | 不管是谁的能量 |
| BER | 误码率，判错比特比例 | 越低越干净 |
| 灵敏度 | 达到某 BER 门限所需最小电平 | 门限按设备规格 |
| 基线 | 本网同类位置的正常值 | 没基线就没有「高 / 低」 |
| 弱覆盖 F-弱 | 太远 / 遮挡，信号小 | RSSI 低 + BER 高 |
| 上下行不对称 | 听得见基站，基站听不见你 | 像 B，实为覆盖 |
| 同频干扰 F-同 | 同一频点上有他网 / 邻站 | 常能解出别人的 CC |
| 同频复用 | 远距离站点复用同一频点 + 不同 CC | 距离不够 CC 也救不了 |
| 捕获效应 | 两路叠加，强的一路仍可能被解出 | 弱的一路被淹 |
| 邻频干扰 F-邻 | 隔壁信道能量漏进来 | 频谱凸起偏一侧 |
| 选择性 | 接收机拒绝邻道的能力 | — |
| 阻塞 | 强信号顶饱前端，压住小信号 | 离强源越近越差 |
| 减敏 desense | 灵敏度下降；常是自发自收 | 发射开 / 关对比 |
| 互调 IMD | 强信号相乘生出新频率（如 2f1−f2） | 衰减 10 dB，产物降约 30 dB |
| 无源互调 | 接头 / 金属锈蚀产生的互调 | 不一定是有源设备 |
| 直通 talk-around | 不经中继、手台直接通 | 可能撞中继时隙 |
| 金机 | 已知正常的对照终端 | 每张 F 单都要有 |

**五个易错观念**：① 满格 ≠ 本网信号好；② CC 不同 ≠ 不干扰；③ RSSI 高 + BER 高 ≠ 覆盖；④ 加功率 ≠ 万能药；⑤ 射频三过还在测场强 = 浪费时间。

## 9. 自测（10 题）+ 参考答案

1. 五格梯子从下到上是哪五格？  
2. 「信号满格登不上」，最先看哪一格的哪个数？  
3. RSSI 高、本网 CC、BER 高，最不可能是哪个子贴纸？  
4. CC 能做什么、不能做什么？各说一条。  
5. 为什么上行覆盖问题容易被误贴成 B？怎么分？  
6. 衰减器测试的 3:1 指纹是什么意思？  
7. 减敏用什么对比测试？在什么条件下做？  
8. 只有 TS2 差、TS1 正常，先想哪个子贴纸？  
9. 「就我这台不行」且金机正常，贴 F 吗？  
10. 频谱截图发到运维群前，要做哪三件事？

### 参考答案

1. 能量 → 同步 → 身份（CC）→ 质量（BER）→ 业务（A–E）。  
2. 第 3 格：解出的 CC 是否本网（Tier III 加看 Aloha / SYScode）。  
3. F-弱（覆盖问题通常 RSSI 低）。应往 F-同叠加 / F-互想。  
4. 能：拒收别家 CC 的 burst、认出干扰来源；不能：把空中叠加的能量分开、不提供加密。  
5. 下行能解、上行 RAND 无回应，看起来像登记无回应；用金机同点对照、靠近站点重试，上行成功则是 F-弱。  
6. 加 10 dB 衰减，真实信号降 10 dB，三阶互调产物降约 30 dB → 是互调 / 接收机被顶饱。  
7. 发射开 / 关对比（同样的测试信号，看 BER / 灵敏度差多少）；只在维护窗、经批准、按站务规程。  
8. F-时（直通撞格、远近效应、时序），再看是否叠加 C。  
9. 不贴 F；归终端栏，结论 X 或终端维修（查频偏、天线、写频）。  
10. 改相对频率刻度；去掉站名 / 经纬度 / 方位角；裁剪无关区域后再打码（按 L2）。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子

1. **五格梯子**：能量 → 同步 → 身份 → 质量 → 业务；哪格先摔，在哪格找原因。  
2. **三个数**：RSSI（多少能量）、CC（谁家的）、BER（干不干净）。  
3. **满格 ≠ 本网**；**RSSI 高 + BER 高 ≠ 覆盖**；**CC 不同 ≠ 不干扰**。  
4. **贴纸 F** 五子类：弱 / 同 / 邻 / 互 / 时；可与 A、C 组合，不与 D 组合。  
5. **两个对比测试**：发射开 / 关（减敏）、衰减器 3:1（互调）——维护窗、经批准。  
6. **射频三过就离开射频**，回贴纸 A–E。  
7. **不加功率、不自行对抗、不贴真实频点**；他网走频谱管理渠道。
