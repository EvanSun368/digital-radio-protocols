## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **接地/汇流排/防雷浪涌台账钉死**：天馈接地、机柜接地、汇流排与测点入账；禁「接地棒在就能签」「口头说一声」。  
2. **接地与 SPD 有主有准用期**：每路接地段、每只 SPD 有主人角色、有准用期；禁「绿灯就算」「谁管都行」。  
3. **抽检窗与方法钉死**：雷雨季/周期窗书面固定；方法含接地电阻/连接连续性/SPD 外观与动作指示等（**门限以本网为准**）；禁「上次测过差不多」「只看监控绿」。  
4. **本组本站本期实测禁套他站他期**：曲线、照片、电阻记录必须本期本组本站；套邻站账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「接地/浪涌准用」；假绿 ≠ 放行。  
6. **禁顶替 AJ/AL/AK/AI/AH/AF/AD/AA/N，主贴 AM，假绿≠放行挂 R**：驻波签、气灭签、爬塔签、温湿度签、仪表签都不顶本期接地浪涌签。  
7. **雷雨/抽检窗禁功率战，监控风暴挂 N，接地/SPD/门限变更走 J**：上行更脆时先问秩序，不先抬功率。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/接地棒·SPD 序列号全文/可还原坐标与联系人**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签接地准用、无抽检冒充浪涌过，不是法外运维智慧**。医院手术室/ICU 等电位与 SPD 公开资料、接地/防雷/浪涌公开科普只作故事与方法类比（§2.2）：**接要约、涌要主、抽要窗、验要测、绿灯不算过**——翻译成本网语言就是 AM-接 / AM-涌 / AM-抽 / AM-验 / AM-治。**这些是接地浪涌抽检秩序，不是「棒在就签」「绿灯就算」「抬功率压告警」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「接地/浪涌准用」、对外宣传「分钟级一键接地秒过」、把未抽检写成已过。允许做的：补接地台账、补 SPD 主人、重开抽检窗、重测、挂 R/N/J、内部挂整改。

### 4.2 分诊题：这件事贴 AM 还是贴别的？

| 你听到的话 | 先问 | 主贴 |
|------------|------|------|
| 「接地棒还在，签一下准用」 | 有没有接地台账与测点？ | **AM**（无账拒签） |
| 「SPD 绿灯，浪涌过了」 | 有没有主人、准用期、本期抽检？ | **AM** |
| 「驻波绿了，接地也算过」 | 驻波≠接地 | 驻波 **AJ**；接地仍 **AM** |
| 「气灭交底过了，接地也能签」 | 气灭≠接地 | 气灭 **AL**；接地仍 **AM** |
| 「仪表还在准用期内」 | AD 只答仪表准用 | **AD** 支撑；主窗仍 **AM** |
| 「雷雨后告警一片」 | 先风暴还是先抬功率？ | 先 **N**；缺接地整改 **AM**；**禁功率战** |
| 「换 SPD 型号」 | 有没有走变更？ | **J** + 再验 **AM** |
| 「爬塔时看到卡箍松了」 | 登高秩序 + 接地整改 | 支撑 **AK**；整改主贴 **AM** |

### 4.3 「接地/浪涌准用」最小集（AM）——缺页不能签「接地/浪涌准用」

1. 接地台账页（天馈/机柜/汇流排测点）  
2. SPD 主人与准用期页  
3. 书面抽检窗与方法页  
4. 本期本组本站实测记录（禁套声明）  
5. AD 仪表准用指针（支撑）  
6. 会签页（准用或有条件整改）  
7. 未闭项清单（有则挂整改，重大未闭禁签准用）  
8. 脱敏勾选（L3）  
9. 变更指针（若本期有接地/SPD/门限变更 → J）

> **口诀**：账、涌、窗、法、站、仪、签、闭、密——**九字接地钉**（教学记忆；现场以本网书面规程为准，但 **接地台账 + SPD 主人 + 本组本站本期实测 + 会签** 几乎不可砍）。

### 4.7 台账路径（一窗接地/一次浪涌抽检跑完）

1. 开窗：核对书面抽检窗与到场角色  
2. 对账：AM-接 台账 vs 现场测点；AM-涌 SPD 清单 vs 准用期  
3. 仪表：核对 AD 准用（接地表/钳表等）  
4. 实测：按本网方法做电阻/连续性/SPD 外观与动作指示（**不写死门限数值**）  
5. 留痕：本期本组本站记录；禁套声明勾选  
6. 分诊：异常 → 挂整改；风暴 → N；假绿嫌疑 → R；变更需求 → J  
7. 会签：准用或有条件整改  
8. 交班：口述未闭项与下一窗  

### 4.8 签字前 15 分钟清单（可复印）

1. 接地台账页在不在？天馈/机柜/汇流排测点齐不齐？  
2. SPD 主人与准用期在不在？有没有只看绿灯？  
3. 书面抽检窗与方法在不在？（电阻/连续性/SPD 外观与动作指示）  
4. 是不是本组本站**本期**实测？（禁套他站他期曲线/照片）  
5. AD 仪表准用是否仍有效？（只支撑，不顶窗）  
6. 有没有人想用 AJ/AL/AK/AI/AH/AF/AD/AA/N 签顶 AM？  
7. 雷雨/抽检窗有没有人要抬功率或旁路 SPD？→ 禁，挂 N；旁路挂整改  
8. 会签人是不是本网授权角色？重大未闭是否仍想硬签合格？  
9. L3：有没有真实站名/序列号全文/联系人进单或进群？  
10. 若有接地系统/SPD/门限变更，J 单是否已挂、再验是否已排？

|------|--------|------|

| 邻站曲线改站号 | 套票 | 拒签，重测本期 |
| 用 AJ 驻波签顶接地签 | 顶替 | 拒签，主贴 **AM** |

### 4.10 接地 / 浪涌 / 抽检与 AM 的咬合（教学直觉，门限以本网为准）

- **接地棒在 ≠ 接地合格**：要有台账、测点、本期方法实测。  
- **SPD 绿灯 ≠ 本期抽检过**：要有主人、准用期、本期外观/动作指示记录。  
- **驻波绿 ≠ 接地准用**：AJ 与 AM 各管各的。  
- **气灭过 ≠ 接地过**：AL 与 AM 各管各的。  
- **爬塔过 ≠ 接地抽检过**：AK 可支撑目视，整改主贴仍 AM。  
- **仪表在期内 ≠ 本期抽检窗可免**：AD 只答准用期。  
- **监控绿 ≠ 接地浪涌准用过**：N 绿不顶 AM。  
- **门限、合格判据、仪表型号、抽检周期以本网制度/合同为准**——本篇不发明数值与条款号；公开防雷/SPD 资料只借秩序直觉。

### 4.11 与驻波（AJ）/ 气灭（AL）/ 爬塔（AK）/ 温湿度（AI）/ 合路（AH）/ 油机（AF）/ 仪表（AD）/ 首年（AA）/ 监控（N）怎么配合

雷雨后常见组合：**N** 理告警风暴 → **AM** 查接地/SPD → 必要时 **AJ** 复测驻波 → 仪表准用挂 **AD** → 若换 SPD/改门限走 **J**。爬塔窗发现卡箍松：支撑 **AK**，整改主贴 **AM**。气灭演练窗与接地抽检窗冲突：各开各的窗，**互不顶替**。

### 4.12 雷雨 / 抽检窗与上行更脆直觉

雷击浪涌、接地劣化、SPD 动作或失效、汇流排松动，常先让接收前端变「脆」：噪声抬、掉话、登记失败——手台功率小、天线短，**上行往往比下行先不够用**。现场第一反应不该是抬功率，而该是：

```text
  雷雨/抽检窗异常
       │
       ├─→ 告警风暴？ → 挂 N 理风暴（对时/风暴秩序）
       ├─→ 接地/SPD 台账与本期抽检清不清？ → 主贴 AM
       ├─→ 有人要抬功率？ → 禁功率战
       └─→ 要改接地系统/SPD/门限/停发？ → 走 J + 再验
```

12.5 kHz / 4FSK / 2-slot TDMA 的窄车道里，乱抬功率只会先伤邻道与自身秩序；**先问 AM 秩序，再谈覆盖病（X/I 指针）**。

### 5.2 三段对话脚本（可练）

**脚本 A · 棒在就能签？**  
外包：「棒还在塔脚下，签准用吧。」  
你：「AM-接先问：接地台账和测点页在哪？棒在≠合格。无账拒签『接地/浪涌准用』。」  
外包：「以前都这么签。」  
你：「本篇硬规则1。补账补测点再谈会签。」

**脚本 B · 绿灯就算？**  
站务：「SPD 面板绿灯，浪涌肯定过了。」  
你：「AM-涌：主人角色、准用期、本期外观/动作指示记录呢？绿灯≠本期抽检过。」  
站务：「那监控也绿啊。」  
你：「假绿挂 R。补本期抽检再谈放行。」

**脚本 C · 雷雨抬功率？**  
网优：「雷雨后登记失败多，功率抬一点稳住。」  
你：「禁功率战。先挂 N 理告警风暴，再按 AM 查接地/SPD 秩序。门限或 SPD 要改走 J。」  
网优：「驻波上周还绿。」  
你：「驻波绿≠接地准用。AJ 不顶 AM。」

### 5.3 夜班压缩卡（四问）

1. 本期接地/SPD 抽检窗到了没有？台账与测点在不在？SPD 主人准用在不在？  
2. 有没有人用 AJ 驻波签 / AL 气灭签 / AD 仪表签顶 AM？→ 拒  
3. 雷雨/告警风暴有没有人要抬功率或旁路 SPD？→ 禁，挂 N；旁路挂整改/R  
4. 交班未闭项：接地？SPD？会签？变更 J？L3？  

### 5.4 禁写词（三联单/交班）

禁写：真实频点、站名全称、机房全称、接地棒/SPD 序列号全文、单位名、联系人电话/微信；禁写「已旁路 SPD」「先抬功率压住」「邻站曲线改站号当本期」；禁写可还原坐标。

### 5.5 交班口述 30 秒模板

「本班 AM：接地台账页✓/缺；SPD 主人准用✓/缺；抽检窗✓/未到；本期实测✓/未做/套票已拒；会签✓/拒签原因…；支撑 AJ/N/AD/AK…；未闭项…；无功率战、无旁路 SPD；L3 已脱敏。」

## 6. 工作实例（12 则，教学虚构，L3）

1. **棒在拒签**：脱敏站-07 塔脚接地棒在，无台账测点页 → AM-接拒签「接地/浪涌准用」；允许补账，不允许口头顶过。  
2. **绿灯假绿**：机房角色-B SPD 面板绿，无本期外观/动作指示记录 → 挂 R，补 AM-涌/抽后再谈会签。  
3. **套邻站曲线**：外包拷邻站上周接地电阻曲线改站号交差 → AM-验拒签，责令本期本组本站重测。  
4. **驻波顶接地**：班长称「AJ 驻波签还在，接地也能签」→ 拒签；驻波绿≠接地准用；主贴仍 AM。  
5. **气灭顶接地**：AL 气灭疏散会签在有效窗，想顺带签接地浪涌 → 拒签；AL 与 AM 各管各的。  
6. **仪表顶窗**：AD 接地表仍在准用期内，外包想免做抽检窗 → 拒签；AD 只支撑仪表准用，不顶 AM 窗。  
7. **雷雨功率战**：雷雨后相对道号登记失败增多，有人要抬功率 → 禁功率战；先挂 N 理风暴，再 AM 查接地/SPD。  
8. **爬塔发现松箍**：AK 爬塔窗目视天馈接地卡箍松动 → 登高秩序支撑 AK，接地整改主贴 AM；禁「爬塔过就算接地过」。  
9. **换 SPD 未走 J**：私自更换 SPD 型号/位置未走变更 → 补走 J，触发再验 AM；未闭前禁签准用。  
10. **汇流排断档**：机柜接地线虚接，台账无此测点 → 补 AM-接入账 + 本期连续性实测；重大未闭禁合格。  
11. **首年日历挂项**：AA 首年巡检日历到了「接地抽检」项，但缺 SPD 主人页 → 日历可挂 AA，缺页整改主贴仍 AM。  
12. **群泄密**：宣传岗把真实站名与接地棒编号发群表扬 → L3 违规，撤帖脱敏重发；治理勾 AM-治。
