```text
        ▼
  ② AM-涌 钉 SPD 主人：主人角色 · 准用期 · 动作指示/外观等级 · 禁「绿灯就算」
        │  无主人 / 无准用期 → 拒进入「可签」状态
        ▼
  ③ AM-抽 钉抽检窗：书面窗（雷雨季/周期） · 方法（接地电阻/连接连续性/SPD 外观与动作指示） · 到场角色 · 仪表 AD 准用
        │  无窗 / 「监控绿当过」 → 拒抽检签
        ▼
  ④ AM-验 本组本站本期实测：实测记录 · 禁套他站他期曲线/照片
        │  套票 / 只看监控绿 → 拒签
        ▼
  ⑤ 会签「接地/浪涌准用」或「有条件整改」：本网授权本人签
        │  缺签 / 假绿顶替 → 拒签准用
        ▼
  ⑥ 变更（接地系统/SPD 型号位置/门限/停发策略）→ 走 J + 触发再抽检/再验（常挂 N 看监控、挂 AD 看仪表、挂 AJ 看驻波）
```

> **一句话分辨**：**AJ** 回答「天馈驻波**过了没有**」；**AL** 回答「气灭疏散联锁**清不清**」；**AD** 回答「仪表准用期**到了没有**」；**AA** 回答「首年巡检日历**到了没有**」；**AM** 回答「这一站天馈/机柜/汇流排接地 + 这一组 SPD + 这一窗接地浪涌抽检**台账清不清、SPD 有没有主、本期过了没有**」。**五个问题，五张（类）贴纸，不能一笔带过。**

### 2.6 接地与浪涌抽检最小工作流（背下来）

```text
  AM-接 台账 + 天馈/机柜/汇流排测点钉死
       ├─→ 有账+测点？SPD 有主人准用？ ──否──→ 拒签 / 补账补涌
       └─→ 是
  AM-抽 约抽检窗 + 书面方法（电阻/连续性/SPD）+ 到场勾选 + AD 仪表准用
       │
  AM-验 本组本站本期：实测记录 → 禁套声明 → 留痕
       │  套票 / 只看绿灯 → 拒签
       ▼
  会签「接地/浪涌准用」或挂整改；重大未闭禁签准用
       │
  放行或拒签；公开材料 L3；变更走 J 再触发；雷雨风暴挂 N（可并行 AJ 看驻波）
```

## 3. 核心交付：插页 AM + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AM（而不是先贴 AJ / AL / AD / N）

| 现场要办的事 | 主贴 | 说明 |
|--------------|------|------|
| 接地台账、SPD 准用、抽检签、假绿拒签 | **AM** | 本篇主职 |
| 雷雨季/周期接地电阻与连续性抽检、汇流排巡检 | **AM** | 本篇主场 |
| SPD/避雷器到期更换、动作指示异常、外观劣化 | **AM**（涌+抽） | 绿灯≠本期过 |
| 天馈驻波/跳线老化抽检 | **AJ**（可挂 AM） | 驻波绿≠接地准用 |
| 气灭/疏散联锁交底 | **AL**（可挂 AM） | 气灭过≠接地过 |
| 爬塔窗目视接地卡箍松动 | **AM**（支撑 **AK**） | 登高秩序回 AK；整改主贴 AM |
| 温湿度/空调联锁 | **AI**（可挂 AM） | 环境过≠接地过 |
| 合路/POI 界面 | **AH**（可挂 AM） | 合路清≠接地界面清 |
| 油机市电 | **AF**（可挂 AM） | 供电过≠接地过 |
| 接地电阻表/钳表入库准用 | **AD**（可挂 AM） | 仪表准用≠本期接地过 |
| 交维后首年巡检日历 | **AA**（可挂 AM） | 首年日历≠本期抽检窗 |
| 雷雨后告警风暴、设备异常重启 | **N**（可挂 AM） | 先风暴后秩序；禁功率战 |
| 大屏绿想直接签接地浪涌准用 | **AM-治 + R** | 假绿≠接地通过 |
| 套邻站旧接地曲线 | **AM-治** | 禁套；须本期本组本站实测 |

### 3.2 插页 AM · 接 / 涌 / 抽 / 验 / 治（挂在总三联单或接地/浪涌单后）

| 插页行 | 检查项（教学） | 缺了怎么办 |
|--------|----------------|------------|
| **AM1** | 接地台账在：天馈/机柜/汇流排测点角色书面 | 缺 → **拒签准用** |
| **AM2** | 测点到场可追溯；禁「接地棒在就算准用」「口头说一声」 | 缺 → **拒「棒在就能签」** |
| **AM3** | SPD/避雷器有主人：主人角色；准用期；动作指示/外观等级 | 缺 → **拒签** |
| **AM4** | 抽检窗书面在（雷雨季/周期）；方法书面（电阻/连续性/SPD）；到场角色勾选 | 缺 → **拒抽检签** |
| **AM5** | 本组本站本期实测记录在；脱敏站与窗一致；禁套他站他期曲线/照片 | 套/缺 → **拒签** |
| **AM6** | 相关仪表在 AD 准用期内（挂 AD 指针）；相关驻波可挂 AJ；禁旁路 SPD 叙事 | 缺/旁路嫌疑 → **拒签或整改** |
| **AM7** | 「接地/浪涌准用」会签：相关授权本人签；重大未闭禁准用 | 缺签 → **拒签** |
| **AM8** | 公开材料 L3；变更项走 J；禁功率战叙事 | 违 → **治理** |

> 插页每一行都对应硬规则：AM1/AM2→规则1，AM3→规则2，AM4→规则3，AM5→规则4，AM7→规则5，顶替/假绿→规则6，AM6/AM8→规则7/8。**任何一行缺项，就停在那一行。**

### 3.3 和总三联单怎么写（接手册06）

- **现象栏**：写「接地台账断档 / SPD 无主 / 抽检未做 / 套他站曲线 / 监控假绿 / 旁路 SPD 嫌疑 / 汇流排卡箍松动」等可复核现象，**不写空口玄学**。  
- **贴纸栏**：主贴 **AM**；支撑可贴 AJ / AL / AK / AI / AH / AF / AD / AA / N / R / J。  
- **处置栏**：拒签 / 补接地台账 / 补 SPD 主人 / 重开抽检窗 / 重测 / 挂 R/N/J——**写动作，不写空口字段**。  
- **脱敏**：站/机房用角色编号；禁单位名全文、禁真实站名、禁接地棒·SPD 序列号全文。

### 3.4 《本网天馈接地与防雷浪涌抽检台账卡》预告

§7 给出可复印模板：封面拒签门槛、接页、涌页、抽页、验页、会签准用页、夜班速填五行。**一张卡跑完一窗接地/一次浪涌抽检：接→涌→抽→验→签**；与 AJ 驻波、AL 气灭、AK 爬塔、AD 仪表指针对齐，避免「驻波签还在就当接地过」「气灭过就当浪涌过」「仪表准用期内就免抽检」。
