## 8. 术语表（本篇约 18 词）+ 易错观念

|----|------------------|

| **假绿** | 监控绿/指示灯绿但无本期秩序实证；挂 R |
| **套票** | 套他站他期曲线/照片当本期 |
| **功率战** | 用抬功率压告警/压掉话；雷雨抽检窗禁止 |
| **L3** | 脱敏等级：禁真实频点/站名/全称/序列号全文/单位名/联系人 |
| **AJ / AL / AD / N / R / J** | 驻波 / 气灭 / 仪表 / 风暴 / 假绿 / 变更——指针，不重写 |
| **上行更脆** | 手台→基站方向往往先不够用；雷雨/浪涌窗尤甚 |
| **九字接地钉** | 账、涌、窗、法、站、仪、签、闭、密 |

**易错观念**  
- ✗ 接地棒在 = 合格 → ✓ 要有账、测点、本期方法实测。  
- ✗ SPD 绿灯 = 本期过 → ✓ 要有主人、准用期、本期抽检记录。  
- ✗ 驻波绿 = 接地准用 → ✓ AJ ≠ AM。  
- ✗ 邻站曲线能用 → ✓ 套票拒签。  
- ✗ 雷雨先抬功率 → ✓ 先 N 后 AM，禁功率战。  
- ✗ 旁路 SPD 先通业务 → ✓ 红线，禁止。
