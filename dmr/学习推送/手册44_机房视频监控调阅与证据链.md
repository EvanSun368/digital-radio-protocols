## 1. 为什么要写这篇手册（动机 + 现场对话）

前四十三篇手册从 A–E 协议一路写到 AP 内阻核对：其中 **N 回答「电源监控/对时/告警风暴」**，**T 回答「干扰投诉分诊与射频/频谱证据链」**，**AN 回答「机房门禁与访客陪同」**，**AD 回答「备件仪表准用」**，**AA 回答「交维后首年巡检」**，**AO 回答「机房漏水与接地汇流排」**，**AM 回答「天馈接地与防雷浪涌」**，**AP 回答「蓄电池组内阻与核对性放电」**。可还没有单独钉死一件事——**机房视频监控调阅与证据链不是「摄像头绿灯就能签」：点位/通道台账要钉死；调阅要有主人有窗有权限有方法有准用期；抽调窗与方法（导出·哈希·保管链）要书面固定；本组本机房本期调阅禁套他站他期——能不能签「视频调阅/证据链准用」？** 这就是本篇的 **AQ**——**机房视频监控调阅与证据链**。

- 运维岗：「摄像头还亮着绿灯，视频调阅就算齐了。」——**无点位台账/无本期调阅仍准用** = 本篇拒签（规则1）。  
- 外包：「监控告警大屏全绿，录像证据肯定齐。」——**告警绿当证据齐** = 规则2/5。  
- 物业：「上次调过差不多，窗再说。」——**无抽调窗方法，只听口头** = 规则3。  
- 外包：「邻院上周录像片段参数差不多，拷过来改个机房号。」——**套他站他期** = 规则4。  
- 班长：「N 监控风暴签还在，T 干扰投诉射频证据也过了，视频调阅也能签。」——**用 N/T/AN/AD/AA/AO/AM/AP 顶替 AQ** = 规则6。  
- 站务：「大屏监控绿了，视频调阅/证据链准用就算过。」——**假绿≠会签放行** = 规则5/6。  
- 网优：「录像丢了告警一片，功率抬一点稳住业务。」——**功率战** = 规则7（无关也写禁，系列一致）。  
- 宣传岗：「把真实摄像头序列号、机房编号、调阅片段发群表扬。」——**L3 违规 / 私下外泄** = 规则8/7。  

这几句背后是同一件事：

> **「机房视频监控调阅与证据链」在现场至少有五个坑**：**① AQ-视** 机房视频点位/通道台账钉死，禁「摄像头绿灯就能签」「口头说一声」；**② AQ-调** 调阅有主人、有窗、有权限、有方法、有准用期，禁「告警绿当证据齐」「熟人说一声就能拷」；**③ AQ-链** 抽调窗与方法钉死（导出·哈希·保管链留痕；保留期以本网为准），禁「只看监控绿」「私下 U 盘无账」；**④ AQ-验** 本组本机房本期调阅（禁套他站他期片段），会签才放行「视频调阅/证据链准用」；**⑤ AQ-治** 治理（假绿、用 N/T/AN/AD/AA/AO/AM/AP 顶替、伪造哈希、删改/旁路录像、私下拷贝外泄、功率战、泄密）。  
> 把 ①–⑤ 当成「摄像头绿灯就能签」「告警绿就算过」「N/T 签还在视频也能签」，每一次调阅、每一次投诉对接、每一次夜班交班，都会先吵「账是谁的、窗谁开的、片段是不是本期的、链断没断」。

本篇目标：能背出**视频调阅 + 证据链工作流**；会用新贴纸 **AQ（视 / 调 / 链 / 验 / 治）**；会填**插页 AQ（AQ1–AQ8）**和《本网机房视频监控调阅与证据链台账卡》；能用「**医院手术室/ICU 安防录像调阅与物证链**」故事讲清摄像头绿灯≠已调出本期片段、监控告警绿≠录像证据齐、套邻院录像=拒签、N 风暴签不顶替本期调阅签、T 射频证据≠机房视频物证、门禁过≠视频调阅过、用 N/T/AN 签顶 AQ 调阅签=拒签、假绿≠会签放行；能拒绝无账准用、套片段、用他贴顶替本期调阅签、假绿放行；自测过关后，回库把本网最近一次机房视频调阅（L3）重对一遍：点位台账、调阅窗、导出哈希保管链、本期调阅、会签项、拒签项。

**本篇硬禁令（写进脑子）**：凡引法规与标准只指向已公开发布的文书标题与官方链接（无线电管理条例、频率使用许可管理办法、地面无线电台（站）管理规定、国无办〔2025〕1号；**只作故事类比**的医院安防录像公开资料标题，以及公开的 CCTV/VMS/保管链/审计轨迹概述资料），**程序、期限、责任以原文与属地最新要求及本网制度 / 合同为准，本篇只作教学转述，不发明条款号与内部口径**；医院安防录像、境外 NIST/SWGDE/ICO CCTV 公开资料与 VMS 科普**不是**中国专网台站「贴纸 AQ」的法定依据；**现象与台账一律用相对道号、角色标签、脱敏站/机房编号，禁真实频点 / 站名 / 机房全称 / 摄像头序列号全文 / 单位名 / 联系人**；**不教绕过摄像头、不教删改/覆盖录像、不教伪造导出哈希、不教旁路录像、不教私下拷贝外泄、不教功率战、不教假绿顶替**；N / T / AN / AD / AA / AO / AM / AP / R / J 各管各的——**机房视频监控调阅与证据链主贴 AQ**；监控风暴回 N，射频投诉证据回 T，门禁访客回 AN——**AQ 管「视频调阅·证据链边界」，不替代 N 的告警风暴秩序本身，也不替代 T 的射频/频谱证据链本身，更不替代 AN 的门禁陪同秩序本身**。

## 2. 总图 / 故事：视频调阅像「医院手术室/ICU 安防录像调阅与物证链——不能只看摄像头绿灯」

### 2.1 一句话：摄像头绿灯不是「可以签准用」、监控告警绿不是「证据齐了」、射频证据过不是「机房视频也过了」——要先建点位台账，调阅有主人有窗有权限有方法有准用期，抽调窗与方法钉死，本组本机房本期调阅，会签才放行；假绿、套邻院片段、用 N/T/AN/AD/AA/AO/AM/AP 顶替，一律拒签

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  医院手术室/ICU 安防录像调阅与物证链  =  本网 AQ              │
   │                                                              │
   │  点位/通道台账钉死                     ≈ AQ-视  画面有账     │
   │  调阅有主有窗有权限有方法准用期       ≈ AQ-调  调阅有窗     │
   │  抽调窗·方法钉死（导出·哈希·保管链） ≈ AQ-链  链不断档     │
   │  本期调阅禁套邻院片段                   ≈ AQ-验  本组本机房本期 │
   │  假绿≠放行·顶替·伪造·旁路·外泄·功率战 ≈ AQ-治  治理与脱敏L3 │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **画面有账，调阅有窗，链不断档，会签才放。**  
> 摄像头绿灯还无点位台账/无本期调阅 = 手术室走廊摄像头灯亮从未建点位账、从未按窗调出本期片段——**拒签「视频调阅/证据链准用」**。  
> 监控告警绿当证据齐 = ICU 安防大屏全绿却从未导出带哈希的本期片段——**假绿，挂 R，拒签**。  
> N 风暴过≠视频调阅过；T 射频证据≠机房视频物证；门禁过≠视频调阅过。

### 2.3 和手册15（N）/ 21（T）/ 41（AN）/ 31（AD）/ 28（AA）/ 42（AO）/ 40（AM）/ 43（AP）等的咬合（指针，不重写）

- **N（手册15）**：电源监控/**对时**/告警风暴；调阅异常/录像丢失风暴挂 N 理风暴，**不先抬功率**；**禁旁路录像、禁静音当交班常态**；**N 绿 ≠ AQ 过**——告警风暴秩序 ≠ 录像调阅证据链。  
- **T（手册21）**：干扰投诉分诊与**射频/频谱证据链**；**T 过 ≠ AQ 过**——射频物证 ≠ 机房视频物证；投诉要机房视频时另开 AQ 窗，互不顶替。  
- **AN（手册41）**：门禁访客陪同；**进机房调录像仍要 AN**——**门禁过 ≠ 视频调阅过**；门禁过只证明人能进，不证明本期片段已按窗调出、链未断。  
- **AD（手册31）**：导出介质/哈希工具等入库走 AD；**不能**用旧 AD 签日期顶本期 AQ 抽调窗。  
- **AA（手册28）**：交维后**首年巡检**日历；视频调阅抽检可挂 AA，缺调阅证据链秩序整改主贴仍 AQ。  
- **AO（手册42）**：漏水汇排；漏水过≠视频调阅过；漏水事件要调录像时另开 AQ。  
- **AM（手册40）**：天馈接地浪涌；接地过≠视频调阅过。  
- **AP（手册43）**：内阻核对；内阻过≠视频调阅过；电池室事件要调录像时另开 AQ。  
- **R / J / X / I**：假绿挂 R；变更（保留期、通道增删、调阅策略、存储策略）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 AQ 证视频调阅秩序，再谈覆盖病**；射频侧证据仍回 T/F。

|------|--------|--------------|
| **AQ-视** | 无点位/通道台账、灯绿无本期调阅仍准用 → 拒签 | 「摄像头绿灯就能签」「口头说一声」 |
| **AQ-调** | 调阅无主人、无窗、无权限、无方法、只看告警绿 → 拒签 | 「熟人说一声就能拷」「告警绿当证据齐」 |
| **AQ-链** | 无书面抽调窗/方法、无导出哈希保管链、私下 U 盘 → 拒签 | 「私下拷一下就行」「监控绿当过」 |
| **AQ-验** | 套他站他期片段、无会签 → 拒签 | 「邻院录像拷过来改机房号」 |
| **AQ-治** | 假绿、用 N/T/AN/AD/AA/AO/AM/AP 顶替、伪造哈希、删改/旁路、外泄、功率战 → 治理 | 「N/T 签还在，视频也能过」 |

### 2.5 建点位台账 → 钉调阅主人 → 抽调窗钉死 → 本期调阅实测 → 会签放行 → 变更再验 阶段梯（背下来）

```text
  ① AQ-视 建点位台账：机房角色 · 通道角色 · 覆盖范围角色 · 禁「摄像头绿灯就能签」「口头说一声」
        │  无账 / 灯绿无调阅 → 不签视频调阅/证据链准用
        ▼
  ② AQ-调 钉调阅主人：调阅主人角色 · 书面窗 · 权限 · 方法 · 准用期 · 禁「熟人说一声就能拷」「告警绿当证据齐」
        │  无主人 / 无窗 / 无权限 / 无方法 / 无准用期 → 拒进入「可签」状态
        ▼
  ③ AQ-链 钉抽调窗：书面窗 · 方法（导出·哈希·保管链留痕；保留期以本网为准） · 到场角色 · AD 介质/工具准用指针
        │  无窗 / 「监控绿当过」/ 私下 U 盘无账 → 拒抽调签
        ▼
  ④ AQ-验 本组本机房本期调阅：调阅记录 · 禁套他站他期片段 · 会签
        │  套票 / 只看告警绿 → 拒签
        ▼
  ⑤ 会签「视频调阅/证据链准用」或「有条件整改」：本网授权本人签
        │  缺签 / 假绿顶替 → 拒签准用
        ▼
  ⑥ 变更再验：保留期/通道增删/调阅策略/存储策略变更 → 走 J → 再开 AQ 窗
```

### 2.6 视频调阅与证据链最小工作流（背下来）

```text
  开窗 → 对点位账（AQ-视）→ 对调阅主人/权限/窗（AQ-调）
       → 按书面方法导出+记哈希+记保管链（AQ-链）
       → 确认本组本机房本期（AQ-验）→ 会签或拒签
       → 异常/丢失风暴 → N；假绿 → R；策略变更 → J
       → 进机房调录像仍要 AN；射频证据另走 T；禁功率战；禁删改旁路；禁私下外泄；L3
```

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **视频点位/通道台账钉死**：机房角色、通道角色、覆盖范围入账；禁「摄像头绿灯就能签」「口头说一声」。  
2. **调阅有主有窗有权限有方法/准用期**：每次调阅有主人角色、有书面窗、有权限、有方法、有准用期；禁「熟人说一声就能拷」「告警绿当证据齐」。  
3. **抽调窗与方法钉死**：书面固定；方法含导出·哈希·保管链留痕等（**保留期以本网为准**）；禁「窗再说」「只看监控绿」「私下 U 盘无账」。  
4. **本组本机房本期调阅禁套他站他期**：调阅记录、导出片段、哈希必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「视频调阅/证据链准用」；假绿 ≠ 放行。  
6. **禁顶替 N/T/AN/AD/AA/AO/AM/AP，主贴 AQ，假绿≠放行挂 R**：监控风暴签、射频证据签、门禁签、仪表签、首年签、漏水签、接地签、内阻签都不顶本期调阅签。  
7. **调阅异常/录像丢失风暴挂 N，策略/保留期/通道变更走 J，禁功率战；禁删改/旁路录像；禁私下拷贝外泄**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/摄像头序列号全文/可还原坐标与联系人；禁公开传播未脱敏调阅片段**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签视频调阅准用、无实测冒充调阅过、断链冒充证据齐，不是法外运维智慧**。医院安防录像公开资料、CCTV/VMS/保管链公开科普只作故事与方法类比（§2.2）：**视要约、调要窗、链要留痕、验要本期、灯绿不算过**——翻译成本网语言就是 AQ-视 / AQ-调 / AQ-链 / AQ-验 / AQ-治。**这些是视频调阅证据链巡检边界秩序，不是「灯绿就签」「告警绿当证据」「抬功率压告警」「删改旁路录像」「私下拷贝外泄」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「视频调阅/证据链准用」、对外宣传「分钟级一键调阅秒过」、把未调阅写成已过、把断链写成证据齐。允许做的：补点位台账、补调阅窗、重开抽调窗、重导出记哈希、挂 R/N/J、内部挂整改。

### 4.2 分诊题：这件事贴 AQ 还是贴别的？

| 你听到的话 | 先问 | 主贴 |
|------------|------|------|
| 「灯还绿，视频就算过」 | 有没有点位台账与本期调阅？ | **AQ**（无账拒签） |
| 「告警绿，证据肯定齐」 | 有没有主人、窗、权限、方法、准用期、本期导出哈希？ | **AQ** |
| 「N 风暴刚签，调阅免做」 | N≠AQ | 风暴 **N**；调阅证据链仍 **AQ** |
| 「T 射频证据过了，视频也过」 | 射频≠机房视频 | 射频 **T**；视频仍 **AQ** |
| 「门禁交底过了，调录像也免」 | 门禁≠视频调阅 | 门禁 **AN**；调阅仍 **AQ** |
| 「仪表/介质还在准用期内」 | AD 只答设备准用 | **AD** 支撑；主窗仍 **AQ** |
| 「录像丢了告警一片」 | 先风暴还是先抬功率？ | 先 **N**；缺调阅秩序整改 **AQ**；**禁功率战**；**禁旁路** |
| 「改保留期/改通道」 | 有没有走变更？ | **J** + 再验 **AQ** |
| 「邻院片段拷过来改机房号」 | 套票？ | **AQ-验** 拒签 |

### 4.3 「视频调阅/证据链准用」最小集（AQ）——缺页不能签「视频调阅/证据链准用」

1. 点位/通道台账页  
2. 调阅主人与书面窗、权限、方法、准用期页  
3. 书面抽调窗与方法页（导出·哈希·保管链）  
4. 本期本组本机房调阅记录（禁套声明）  
5. N 风暴边界勾选（防顶替；N 绿≠AQ 过）  
6. T 射频证据边界勾选（防顶替；T 过≠AQ 过）  
7. AN 门禁边界勾选（若进人：先 AN；门禁过≠调阅过）  
8. AD 介质/工具准用指针（若用，支撑）  
9. 会签页（准用或有条件整改）  
10. 未闭项清单（有则挂整改，重大未闭禁签准用）  
11. 脱敏勾选（L3）  
12. 变更指针（若本期有保留期/通道/策略变更 → J）

> **口诀**：视、调、窗、链、房、测、签、闭、密、界——**十字视链钉**（教学记忆；现场以本网书面规程为准，但 **点位台账 + 调阅窗方法 + 导出哈希保管链 + 本组本机房本期调阅 + 会签** 几乎不可砍）。

### 4.6 与 N / T / AN / AD / AA / AO / AM / AP 的分工表（钉死，防互相顶替）

| 贴纸 | 主职一句话 | 能不能顶替 AQ？ |
|------|------------|-----------------|
| **AQ** | 视频调阅·证据链边界 | —（本篇） |
| **N** | 监控对时与告警风暴 | **不能**；N 绿≠AQ 过；风暴先 N，秩序整改仍 AQ |
| **T** | 干扰投诉射频/频谱证据链 | **不能**；T 过≠AQ 过；射频≠机房视频 |

| **AA** | 首年巡检日历 | **不能**顶秩序整改 |

### 4.7 台账路径（一窗视频调阅抽调跑完）

1. 开窗：核对书面抽调窗与到场角色；进人则先办 AN  
2. 对账：AQ-视 台账 vs 现场点位/通道；AQ-调 调阅清单 vs 主人/窗/权限/方法/准用期  
3. 抽调：按本网方法导出、记哈希、记保管链交接（**不写死哈希算法与保留期数值**）  
4. 留痕：本期本组本机房记录；禁套声明勾选  
5. 分诊：异常 → 挂整改；调阅异常/录像丢失风暴 → N；假绿嫌疑 → R；变更需求 → J；射频证据另走 T；介质准用回 AD  
6. 会签：准用或有条件整改；交班口述未闭项  

### 4.8 签字前 15 分钟清单（可复印）

1. 点位/通道台账页在不在？覆盖范围齐不齐？  
2. 调阅主人、书面窗、权限、方法、准用期在不在？有没有只看告警绿？  
3. 书面抽调窗与方法在不在？（导出·哈希·保管链）  
4. 是不是本组本机房**本期**调阅？（禁套他站他期片段）  
5. 有没有人想用 N/T/AN/AD/AA/AO/AM/AP 签顶 AQ？  
6. AQ vs N / T / AN 边界勾清了没有？（风暴回 N；射频回 T；门禁回 AN；调阅证据链回 AQ）  
7. 调阅异常/录像丢失有没有人要抬功率或旁路录像或私下拷贝？→ 禁，挂 N；旁路/外泄挂整改/R  
8. 会签人是不是本网授权角色？重大未闭是否仍想硬签合格？

10. 若有保留期/通道/调阅策略变更，J 单是否已挂、再验是否已排？

### 4.10 调阅 / 证据链与 AQ 的咬合（教学直觉，保留期以本网为准）

- **摄像头绿灯 ≠ 已调出本期片段**：要有台账、本期调阅。  
- **监控告警绿 ≠ 录像证据齐**：要有主人、窗、权限、方法、准用期、本期导出哈希保管链。  
- **N 绿 ≠ AQ 过**：告警风暴秩序 ≠ 录像调阅证据链。  
- **T 过 ≠ AQ 过**：射频/频谱物证 ≠ 机房视频物证。  
- **门禁过 ≠ 视频调阅过**：AN 与 AQ 各管各的；进机房仍要 AN。  
- **仪表/介质在期内 ≠ 本期抽调窗可免**：AD 只答设备准用期。  
- **内阻过 / 漏水过 / 接地过 ≠ 视频调阅过**：AP / AO / AM 与 AQ 各管各的。  
- **保留期、哈希算法、抽调窗长度、导出格式以本网制度/合同为准**——本篇不发明数值与条款号；公开 CCTV/VMS/保管链资料只借秩序直觉。

### 4.11 与监控（N）/ 投诉证据（T）/ 门禁（AN）/ 仪表（AD）/ 首年（AA）/ 漏水（AO）/ 接地（AM）/ 内阻（AP）怎么配合

进机房做视频调阅常见组合：**AN** 办门禁访客 → **AQ** 办调阅导出哈希保管链 → 告警风暴/丢失挂 **N** → 射频投诉证据另走 **T** → 介质准用回 **AD** → 策略/保留期/通道变更走 **J**。投诉窗与调阅窗可同日不同贴，**互不顶替**；录像异常可触发 N 理风暴，调阅证据链秩序仍 AQ。

### 4.12 调阅异常 / 录像丢失与上行更脆直觉

机房视频调阅断档、录像丢失、对时漂移、告警风暴、旁路录像、私下拷贝外泄，常先让物理安防证据与空口叙事变「脆」：说不清谁进过机房、对不上投诉时段、误告——手台功率小、天线短，**上行往往比下行先不够用**。现场第一反应不该是抬功率，而该是：

```text
  调阅异常 / 录像丢失风暴 / 对时漂移
       │
       ├─→ 告警风暴？ → 挂 N 理风暴（对时/风暴秩序）；禁旁路录像
       ├─→ 点位台账与本期调阅清不清？ → 主贴 AQ
       ├─→ 要射频证据？ → 另走 T（不顶替）
       ├─→ 进人调录像？ → 先 AN（不顶替）
       ├─→ 介质/工具准用？ → AD（支撑）
       ├─→ 有人要抬功率？ → 禁功率战
       ├─→ 有人要私下拷/删改？ → 禁；挂整改/R
       └─→ 要改保留期/通道/策略？ → 走 J + 再验
```

12.5 kHz / 4FSK / 2-slot TDMA 的窄车道里，乱抬功率只会先伤邻道与自身秩序；**先问 AQ 秩序，再谈覆盖病（X/I 指针）**。

## 6. 工作实例（12 则，教学虚构，L3）

1. **灯绿拒签**：脱敏机房-07 摄像头绿灯，无点位台账页 → AQ-视拒签「视频调阅/证据链准用」；允许补账，不允许口头顶过。  
2. **告警假绿**：机房角色-B 监控告警全绿，无调阅书面窗与本期导出哈希记录 → 挂 R，补 AQ-调/链后再谈会签。  
3. **套邻院片段**：外包拷邻院上周录像片段改机房号交差 → AQ-验拒签，责令本期本组本机房重开调阅。  
4. **风暴顶调阅**：班长称「N 监控风暴签还在，调阅也能签」→ 拒签；风暴过≠调阅过；主贴仍 AQ。  
5. **射频顶视频**：T 干扰投诉射频证据会签在有效窗，想顺带签机房视频调阅 → 拒签；T≠AQ；射频≠机房视频。  
6. **门禁顶调阅**：AN 门禁陪同交底过，想免做视频调阅抽调 → 拒签；门禁过≠视频调阅过；进机房仍要 AN，调阅仍要 AQ。  
7. **介质顶窗**：AD 导出介质仍在准用期内，外包想免做抽调窗 → 拒签；AD 只支撑设备准用，不顶 AQ 窗。  
8. **旁路录像 / 私下拷贝**：有人想旁路录像告警消铃，或 U 盘私下拷片段外发 → **禁**；挂整改 + N/R；本期调阅未做不得签准用。  
9. **保留期变更未走 J**：私自改录像保留期或调阅策略未走变更 → 补走 J，触发再验 AQ；未闭前禁签准用。  
10. **丢失窗抬功率**：录像丢失告警一片，网优想抬功率压掉话 → **禁功率战**；先 N 后 AQ；上行更脆先问秩序。  
11. **内阻/漏水顶视频**：外包称「AP 内阻过了 / AO 漏水过了就等于视频调阅过」→ 拒签叙事；内阻/漏水≠视频调阅；本期调阅仍 AQ。  
12. **群泄密**：宣传岗把真实摄像头序列号与机房全称及未脱敏片段发群表扬 → L3 违规，撤帖脱敏重发；治理勾 AQ-治。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AQ** 五子类：视 / 调 / 链 / 验 / 治——双字母续写的第十七张，负责视频调阅·证据链「台账清不清、调阅有没有窗、链断没断、本期过了没有」。  
- 故事：医院手术室/ICU 安防录像调阅与物证链——摄像头绿灯≠已调出本期片段；监控告警绿≠录像证据齐；N 风暴签≠视频调阅准用；T 射频证据≠机房视频物证；门禁过≠视频调阅过；套邻院录像=拒签；N/T/AN/AD/AA/AO/AM/AP 不顶替 AQ；假绿≠会签放行。  
- 阶段梯：建点位台账 → 钉调阅主人 → 抽调窗钉死 → 本期调阅 → 会签放行 → 变更再验。  
- 八条硬规则：**视频点位/通道台账钉死**；**调阅有主有窗有权限有方法/准用期**；**抽调窗与方法钉死**；**本组本机房本期调阅禁套他站他期**；**会签才放行「视频调阅/证据链准用」**；**禁顶替 N/T/AN/AD/AA/AO/AM/AP 等，主贴 AQ，假绿≠放行挂 R**；**调阅异常/录像丢失风暴挂 N、策略/保留期/通道变更走 J、禁功率战、禁删改/旁路录像、禁私下拷贝外泄**；**脱敏 L3**。

- **AQ vs AN**：AN = 门禁与访客陪同；进机房调录像仍要 AN；门禁过 ≠ 视频调阅过。
