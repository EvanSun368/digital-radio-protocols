## 6. 工作实例（12 则，教学虚构，L3）

1. **看着有油想签准用**：称油箱看着有油要签 → 查 BI1 无本期台账核对 → **拒签**；补 BI-位。  
2. **地面看着干 / 围堰看着在 / 口头不漏**：称「地面是干的 / 围堰还在 / 班长说不漏」免窗页 → **拒签**；补 BI-漏。  
3. **AR 顶替 BI**：用燃油安全签顶本期油位/泄漏签 → **挂 R**；**燃油安全过 ≠ 油位/泄漏台账过**。  
4. **AV 顶替 BI**：称油品报告和加油交接刚过，油位泄漏窗免做 → **挂 R**；**油品报告过 ≠ 油位/泄漏窗过**。  
5. **AF 顶替 BI**：称油机市电切换过了，油肯定够 → **拒签**；**切换过 ≠ 油位泄漏过**。  
6. **AO 顶替 BI**：称漏水探头绿，漏油窗免 → **拒签**；**漏水探头过 ≠ 漏油窗过**。  
7. **N 绿免实测**：大屏监控绿，本期实测免 → **拒签**；N绿≠BI过；补 BI-验。  
8. **套邻站表**：拷邻站油位/泄漏表改机房号 → **BI-验 拒签重测**。  
9. **功率战**：低油位/泄漏告警，要抬功率 → **禁功率战**；先挂 N；缺秩序整改贴 BI。  
10. **不安全泄油 / 开旁通冒充**：泄油或开旁通消告警后要求准用 → **禁**；挂 N/R；禁签。  
11. **绕油位/泄漏联锁**：绕开低油位或泄漏联锁后要求准用 → **禁**；挂整改；主贴 BI-治。  
12. **日用油箱顶储油罐 / 无油机乱签 / 泄密**：称日用油箱签过故储油罐免，或无柴油发电机站点不写「不适用」却乱签准用，或公开群贴真实油箱编号 → **拒签顶替**并/或补书面不适用并/或 **L3 违规**；一侧不适用 ≠ 另一侧自动免。

## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 本篇用法（教学） |
|------|------------------|
| **日用油箱** | day tank：靠近发动机的近端油箱；**BI-位 / BI-漏**；**≠ 储油罐**；AR 会在燃油安全窗提到它，AV 管它的油品 |

- 「AR 燃油安全过 = 油位/泄漏台账过」→ 错；AR ≠ BI。

- 「AO 漏水探头绿 = 漏油窗过」→ 错；漏水探头 ≠ 漏油窗。  
- 「日用油箱过 = 储油罐过」→ 错；两侧分账分验。

### 参考答案

1. 位 / 漏 / 界 / 验 / 治；口诀：**油位有账，泄漏有窗，边界有法，会签才放。**  
2. 规则1（油位台账钉死）；属 **BI-位**。日用油箱 = day tank（近端供油）；储油罐 = bulk / storage tank（较大储量，常转供日用油箱）；**不能**互相顶；两侧各自入账、各自实测。  
3. 规则2。**不能**；地面看着干 ≠ 泄漏窗过；围堰看着在 ≠ 泄漏窗过。  
4. **不能**。AR ≠ BI；燃油安全过 ≠ 油位/泄漏台账过。本篇**不重写** AR 全文。油箱看着有油 ≠ 燃油安全巡检过（AR 的钉），也 ≠ 油位台账过（BI 的钉）。  
5. **都不能**。AV ≠ BI（油品报告过 ≠ 油位/泄漏窗过）；AF ≠ BI（切换过 ≠ 油位泄漏过）；AO ≠ BI（漏水探头过 ≠ 漏油窗过）。  
6. **不能**。N 绿 ≠ BI 过；看着有油 ≠ 油位台账过。  
7. **BI-验 拒签重测**；禁套他站他期。  
8. **不能**抬功率；先挂 **N**；缺秩序整改贴 **BI**；燃油安全问 **AR**，油品问 **AV**，切换问 **AF**，漏水问 **AO**；**禁功率战**。  
9. **不允许**；禁不安全泄油、开旁通冒充、绕油位/泄漏联锁；挂 N/R，禁签准用。  
10. **不能**互相顶替。无柴油发电机站点两侧均可书面勾「不适用」；有日用油箱无储油罐则只勾储油罐不适用，反之亦然。  
11. 日用油箱项书面勾「不适用」；储油罐按有无路径单独勾选，不得自动免。不得用 BI 顶 AR/AV/AF/AO。假绿挂 **R**；主贴仍 **BI**。

1. 油位不是看着有油就能签：日用油箱与储油罐各自有账，本期核对钉死；**燃油安全过≠油位台账过，油品过≠油位台账过**。
