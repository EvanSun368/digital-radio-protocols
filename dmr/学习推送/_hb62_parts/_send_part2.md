## 3. 核心交付：插页 BI + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 BI（而不是先贴 AR / AV / AF / AO / N）

- 要签「机房柴油发电机日用/储油罐油位与泄漏巡检准用」、要开油位交底窗、要交底泄漏侧（目视/油痕/探头/围堰/集油坑/油水分离） → **主贴 BI**。  
- 柴油发电机房通风排烟与燃油**安全** → **AR**（手册45）。**AR ≠ BI**；不重写 AR。  
- 日用油箱油品净化与加油交接 → **AV**（手册49）。**AV ≠ BI**；不重写 AV。  
- 油机市电切换与供电巡检 → **AF**（手册33）。**AF ≠ BI**。  
- 漏**水**探测与汇流排 → **AO**。**AO ≠ BI**（漏水探头 OK ≠ 漏油窗过）。  
- 进油机房做交底 → 先 **AN**；门禁过 ≠ 交底过。  
- 气灭疏散 → **AL**；气灭过 ≠ 油位/泄漏交底过。  
- 低油位/泄漏/窗乱签风暴 → 先 **N** 理风暴；缺秩序整改仍 **BI**；**禁功率战、不安全泄油、旁通、绕联锁**。  
- 假绿/顶替 → 挂 **R**；变更角色/窗方法/门限 → 走 **J** 后再验 BI。  
- 本站无日用油箱路径 → 日用油箱项书面勾「不适用」；储油罐侧单独勾选。  
- 本站无储油罐路径 → 储油罐项书面勾「不适用」；日用油箱侧单独勾选。  
- 本站无柴油发电机 → 两侧均可书面「不适用」；**不得**用 BI 顶 AR/AV/AF/AO，也不得用它们顶 BI。

### 3.4 与总三联单怎么写（脱敏 L3）

- **现象栏**：写「油位缺账 / 看着有油无核对 / 泄漏侧无窗 / 地面看着干当过 / 围堰看着在当过 / 口头不漏 / 日用油箱顶储油罐 / AR 顶油位泄漏 / AV 顶油位泄漏 / AF 顶油位泄漏 / AO 探头顶漏油窗 / 套票嫌疑 / 泄油/旁通嫌疑 / 绕联锁嫌疑」等角色化现象；**不写**真实机房全称、油箱序列号全文、可还原油位/泄漏门限全文。  
- **贴纸栏**：主贴 **BI**；邻贴指针 AR/AV/AF/AO/AN/AL/N/R/J 按需勾。  
- **处置栏**：补 BI-位 / 补 BI-漏 / 补 BI-界 / BI-验 重测 / 会签或拒签 / 挂 R / 挂 N / 走 J。  
- **会签栏**：准用 / 有条件整改 / 拒签；假绿 ≠ 放行。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **油位台账钉死**：日用油箱与储油罐各自有账；液位计/浮球/高低油位告警角色入账（编号脱敏）；禁「看着有油就算过」「口头说油位正常」；日用油箱过 ≠ 储油罐过，储油罐过 ≠ 日用油箱过。  
2. **泄漏侧有主有窗有方法/准用期**：目视/油痕/探头/围堰/集油坑/油水分离等以本网与 OEM 书面为准；每次泄漏交底有主人角色、有书面窗、有方法、有准用期；禁「地面看着干当窗过」「围堰看着在当窗过」「口头说不漏」。  
3. **油位与泄漏边界窗与方法钉死**：书面固定；方法含与 AR/AV/AF/AO/AN/AL/N 分工勾选（**顺序与门限以本网与 OEM 书面为准**；本篇不发明逐步不安全泄油/旁通/绕联锁操作教条；**不重写 AR/AV/AF/AO 全文**）；禁「窗再说」「不安全泄油」「开旁通冒充」「绕油位/泄漏联锁」「伪造台账」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、日用油箱表、储油罐表、泄漏窗必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「机房柴油发电机日用/储油罐油位与泄漏巡检准用」；假绿 ≠ 放行。  
6. **禁顶替 AR/AV/AF/AO/AN/AL/AD/AA/N/AQ/AG/AP/AS/BH 等，主贴 BI，假绿≠放行挂 R**：燃油安全签、油品签、切换签、漏水探头签、门禁签、气灭签、备件签、首年签、监控签……都不顶本期油位/泄漏签。**尤其：AR ≠ BI，AV ≠ BI，AF ≠ BI，AO ≠ BI；油箱看着有油 ≠ 燃油安全巡检过；油品报告过 ≠ 油位/泄漏窗过；油机市电过 ≠ 油位泄漏过；漏水探头过 ≠ 漏油窗过；看着有油 ≠ 油位台账过；地面看着干 ≠ 泄漏窗过；围堰看着在 ≠ 泄漏窗过。**  
7. **油位异常/泄漏/窗乱签风暴挂 N，边界/门限/油位泄漏窗变更走 J，禁功率战；禁不安全泄油；禁旁通；禁绕联锁；禁伪造台账**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/油箱序列号全文/可还原坐标与联系人；禁公开传播未脱敏油位/泄漏门限与参数**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签油位/泄漏准用、无实测冒充边界过、不安全泄油/旁通/绕联锁冒充秩序齐，不是法外运维智慧**。医院/数据中心公开资料只作故事类比（§10），翻译成本网语言就是 BI-位 / BI-漏 / BI-界 / BI-验 / BI-治。

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「机房柴油发电机日用/储油罐油位与泄漏巡检准用」、对外宣传「看着有油/地面干/围堰在/口头正常秒过」、把未实测写成已过、把不安全泄油/旁通/绕联锁写成秩序齐。允许做的：补油位台账、补泄漏窗、重开边界窗、挂 R/N/J、内部挂整改。

| 「泄油消告警 / 开旁通 / 绕联锁」 | 冒充/绕联锁/违章？ | **禁**；挂整改；主贴 **BI-治** |

### 4.3 「机房柴油发电机日用/储油罐油位与泄漏巡检准用」最小集（BI）——缺页不能签准用

1. 油位台账页（日用油箱·储油罐·液位计/浮球/高低位；含看着有油≠台账过、一侧过≠另一侧过勾选）  
2. 泄漏侧主人与书面窗、方法、准用期页（目视/油痕/探头/围堰/集油坑/油水分离；含禁地面看着干、禁围堰看着在、禁口头不漏勾选）  
3. 书面边界窗与方法页（与 AR/AV/AF/AO/AN/AL/N 分工；以本网与 OEM 为准；声明不重写 AR/AV/AF/AO）  
4. 本期本组本机房实测记录（日用油箱与储油罐的油位、泄漏分别留痕；禁套声明）  
5. AR/AV/AF/AO 边界勾选（防顶替：燃油安全过≠油位/泄漏台账过，油品过≠油位/泄漏窗过，切换过≠油位泄漏过，漏水探头过≠漏油窗过）  
6. AD/AN/AL/N/AA/AQ 边界勾选（备件入库≠本期窗；门禁过≠交底过；气灭过≠交底过；N 绿≠BI 过）  
7. AG/AP/AS/BH 等边界勾选（若同站：各过≠BI 过）  
8. 会签页（准用或有条件整改）  
9. 未闭项清单（有则挂整改，重大未闭禁签准用）  
10. 脱敏勾选（L3）  
11. 变更指针（若本期有油位角色/泄漏窗方法/门限变更 → J）  
12. 不适用声明（无日用油箱路径、无储油罐路径、无柴油发电机分别书面勾选；一侧不适用 ≠ 另一侧自动免；不得顶 AR/AV/AF/AO）

> **口诀**：位、漏、界、窗、房、测、签、闭、密、界——**十字油位钉**（教学记忆；现场以本网书面规程为准，但 **油位台账 + 泄漏窗方法 + 边界方法 + 本组本机房本期实测 + 会签** 几乎不可砍）。

### 4.6 与 AR / AV / AF / AO / N / … 的分工表（钉死，防互相顶替）

| 贴纸 | 主职一句话 | 能不能顶替 BI？ |
|------|------------|----------------|
| **AR** | 油机房通风排烟与燃油安全巡检 | **不能**（AR≠BI；不重写燃油安全全文） |
| **AV** | 油品净化与加油交接 | **不能**（油品报告过≠油位/泄漏窗过） |
| **AF** | 油机市电切换与供电巡检 | **不能**（切换过≠油位泄漏过） |
| **AO** | 漏水与汇流排探测 | **不能**（漏水探头OK≠漏油窗过） |
| **AN / AL / AD / AA / AQ** | 门禁 / 气灭 / 备件入库 / 首年抽检 / 视频 | **不能**（门禁≠交底；入库≠本期窗） |
| **AG / AP / AS / BH** | 电池充电器 / 内阻 / UPS 旁路 / 冷却水泵冷凝水侧 | **不能** |
| **N** | 监控对时告警风暴 | **不能**（N绿≠BI过） |
| **R / J** | 假绿治理 / 变更 | 支撑；变更后再验 BI；不顶替准用本身 |
| **BI** | 日用/储油罐油位·泄漏巡检准用 | **本篇主贴** |

### 4.7 台账路径（从发现到会签，教学骨架）

```text
  发现缺账/低油位/泄漏/假绿嫌疑
        │
        ├─ 先分诊：燃油安全？→ AR；油品/加油？→ AV；切换？→ AF；漏水？→ AO；风暴？→ N
        │         日用/储油罐油位 / 泄漏窗？→ BI
        ▼
  补 BI-位台账 → 补 BI-漏窗 → 补 BI-界边界方法
        │
        ▼
  本期本组本机房实测（禁套）→ 会签 / 拒签

        └─ 方法/门限/角色变更 → 走 J 后再验
```

### 5.2 对话脚本（教学）

**脚本A（看着有油想签）**  
新人：「油箱看着有油，签准用吧。」  
班长：「BI1——日用油箱和储油罐各自的油位台账与本期核对呢？看着有油≠油位台账过。补账再谈会签。」

**脚本B（AR 顶替）**  
外包：「AR 燃油安全签还在，油位泄漏免了。」  
班长：「AR≠BI。燃油安全回AR；油位/泄漏主贴仍BI。油箱看着有油≠燃油安全巡检过，也≠油位台账过。顶替挂R。本篇不重写AR全文。」

**脚本C（AV / 地面看着干）**  
外包：「地面是干的，而且 AV 油品报告刚过，泄漏窗免了。」  
班长：「地面看着干≠泄漏窗过；油品报告过≠油位/泄漏窗过。补BI-漏主人窗方法。本篇不重写AV全文。」

**脚本D（泄油/旁通）**  
外包：「泄一点油 / 旁通开一下，告警就消，再签准用。」  
班长：「禁不安全泄油，禁开旁通冒充。挂N/R，禁签。缺秩序整改贴BI-治。」

**脚本E（套票 / 一侧顶另一侧）**  
外包：「邻站油位泄漏表参数差不多，改个机房号。日用油箱那边签过了，储油罐照抄。」  
班长：「BI-验拒签重测。禁套他站他期。日用油箱过≠储油罐过。」

### 5.4 禁写词 / 允许写

禁止写：真实站名、机房全称、油箱序列号全文、单位名、联系人、真实频点、未脱敏门限；禁止写「看着有油就过」「地面干/围堰在就过」「他贴顶 BI」「抬功率」「不安全泄油/旁通/绕联锁」「套邻站表」。允许写：脱敏角色、现象、贴纸（BI/AR/AV/AF/AO/N/R/J）、动作（补账/重测/拒签）。

### 5.5 与弱项的现场对照（再钉一次）

低油位、泄漏、油位/泄漏窗乱签，常先伤站点保供电与**上行**体验。有人把告警当「覆盖病」抬功率——**禁功率战**。先问 BI 秩序（并分诊 AR 燃油安全、AV 油品、AF 切换、AO 漏水），风暴挂 N，变更走 J。弱项短补仍记：**12.5 kHz / 4FSK / 2-slot TDMA**。低油位 / 泄漏 / 窗乱签告警**不是覆盖病**。
