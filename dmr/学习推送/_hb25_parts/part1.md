## 1. 为什么要写这篇手册（动机 + 现场对话）

前二十四篇手册把「家里怎么养」「邻居怎么处」「投诉怎么分诊」「证照台账怎么对」「重大保障临时窗怎么钉」「非法线索怎么上报」基本写全了：A–E 协议，F 射频指纹，G 实验室，H 话务，I 室分，J 写频，K 电源，L 井库，M 批量 / OTAP，N 监控对时，O 有源隔离，P 口部，Q 金机，R 假绿演练，S 邻频协调，T 干扰投诉，U 许可执照台账，V 临时保障窗，W 非法/黑广播线索。可现场还有一类债——**电磁环境测试与验收报告台账**：

- 开站岗：「三年前那份电磁环境报告还在文件夹里，直接拿来签验收吧。」——**旧报告套新址/新配置** = 本篇拒签（规则3）。  
- 测试岗：「频谱仪检定上周过期，先测完交维，下月再送检。」——**仪器检定/校准过期** = 规则2。  
- 网管：「屏上全绿、假绿演练也过了，还要什么电磁环境实测报告？」——**假绿 ≠ 实测验收**（规则6，挂 R 提醒）。  
- 项目经理：「报告缺测点表和仪器证书页，领导催着签交维就绪。」——**缺项断链禁当正式验收证据**（规则4）。  
- 工程：「天线换了、功率角色调了，先开着，回头再补测。」——**重大变更后须复测再签**（规则5）。  
- 协调岗：「共址邻频那边环境吵，我们把功率顶上去就能过验收。」——**禁功率战掩盖环境问题**（规则7）。  
- 宣传：「把报告全文号和真实测点坐标贴公开周报。」——**L3 违规**（规则8）。

这几句背后是同一件事：

> **「电磁环境测试与验收报告台账」在现场至少有五个坑**：**① X-测** 测试方案与仪器有效性（检定/校准在有效期内、方法与测点角色、频段/功率/占用角色与许可一致）；**② X-验** 验收判据与报告完整性（结论可追溯、与现场一致、断链报告禁当正式验收证据）；**③ X-账** 报告台账可对账（编号角色、有效期、覆盖站址角色、复测触发）；**④ X-签** 签字边界（谁可签验收/交维就绪；缺报告/过期/不一致拒签）；**⑤ X-治** 拒签治理（伪造/套用旧报告、未复测变更、公开泄密、假绿顶替实测）。  
> 把 ①–⑤ 当成「文件夹里有纸就行」「过期仪器先用着」「屏绿=环境过了」「旧报告套新楼」「变更先开再测」，会把下一任、验收方、主管部门和本网合规一起拖进泥潭。

本篇目标：能背出**电磁环境测试与验收报告工作流**；会用新贴纸 **X（测 / 验 / 账 / 签 / 治）** 与五个子类；会填**插页 X（X1–X8）**和《本网电磁环境测试与验收报告台账卡》；能用「**大楼消防验收报告台账 + 计量检定证书**」故事讲清：先对覆盖与在检、结论与现场一致、缺页断链拒签、变更复测、签字边界；能拒绝「套旧报告、仪器过期、假绿顶替、缺项强签、未复测先用、功率战掩盖、公开泄密」；自测过关后，回库把本网最近一次开站/交维相关报告台账（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：凡引法规与标准均指向已公开发布的文书标题与官方链接（《中华人民共和国无线电管理条例》《无线电频率使用许可管理办法》《地面无线电台（站）管理规定》《无线电台执照管理规定》、国无办〔2025〕1号、生态环境部公开的《电磁环境控制限值》GB 8702 相关页面、ITU 频谱监测手册、ETSI EN 300 113 / TS 102 361 等），**限值数字、程序、豁免范围、复校间隔以原文与属地最新要求为准，本篇只作教学转述，不发明条款号以外的「内部口径」或内部配额**；**现象与台账一律用相对道号、角色标签、脱敏编号表述，禁真实频点 / 站名 / 单位名 / 报告全文号 / 检定证书全文号 / 联系人 / 坐标**；**不教伪造/涂改/套用报告、不教无证发射、不教功率战掩盖环境、不教规避监测与检查**；G 仍管实验室方法，F 仍管指纹，S 仍管邻频协调，O 仍管有源隔离，U/V 仍管证照与临时窗，R 仍管假绿——**电磁环境测试与验收报告台账主贴 X**；外国 / ITU / 厂商应用笔记只借**测量方法与仪器能力级表述**，**验收与签字以国内法规、属地要求与本网书面判据为准**。

## 2. 总图 / 故事：报告像「消防验收台账 + 计量检定证书」

### 2.1 一句话：电磁环境测试与验收报告像大楼消防验收报告台账 + 计量检定证书——开工验收前先对报告是否覆盖本楼、仪器是否在检、结论是否与现场一致；旧报告套新楼、检定过期、缺页断链一律拒签入住/交维

```text
   ┌──────────────────────────────────────────────────────────────────┐
   │   大楼消防验收 + 计量检定（= 本网开站/交维 + 电磁环境报告台账） │
   │                                                                  │
   │   测试方案与仪器（X-测）                                         │
   │     方案覆盖本楼角色 · 仪器检定/校准在有效期内 · 方法与许可一致  │
   │                                                                  │
   │   验收判据与报告完整（X-验）                                     │
   │     结论可追溯 · 与现场一致 · 断链/缺页禁正式验收证据            │
   │                                                                  │
   │   报告台账可对账（X-账）                                         │
   │     编号角色 · 有效期 · 覆盖站址角色 · 复测触发                  │
   │                                                                  │
   │   签字边界（X-签）                                               │
   │     谁可签验收/交维就绪 · 缺报告/过期/不一致 → 拒签              │
   │                                                                  │
   │   拒签治理（X-治）                                               │
   │     伪造/套旧报告 · 未复测变更 · 公开泄密 · 假绿顶替实测         │
   └──────────────────────────────────────────────────────────────────┘
```

口诀：

> **先对覆盖，再对在检；结论对现场，台账能对账。**  
> 旧报告套新楼 = 拿隔壁楼消防报告来办本楼入住——**拒签**。  
> 检定过期仍测仍签 = 灭火器过期也贴「验收合格」——**拒签**。

### 2.2 「消防报告台账 + 计量检定」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **测试方案与仪器** | 验收方案写清测哪几层、用哪台经检定的仪器 | 方案覆盖站址角色；仪器检定/校准有效；频段/功率/占用角色与许可一致 | X-测 |
| **验收判据与报告** | 报告结论对照规范，缺页/涂改退回 | 结论可追溯；与现场配置一致；断链禁正式验收 | X-验 |
| **报告台账** | 每栋楼一份可检索台账：编号、有效期、覆盖范围 | 编号角色、有效期、覆盖站址、复测触发可对账 | X-账 |
| **签字边界** | 消防验收谁有权签「可入驻」 | 谁可签验收/交维就绪；缺报告/过期/不一致拒签 | X-签 |
| **拒签治理** | 套旧报告、造假、灭火器过期硬签 → 追责 | 伪造/套旧、未复测变更、公开泄密、假绿顶替 → 拒签/治理 | X-治 |

> 公开文书与标准告诉我们：设置使用无线电台（站）应依法取得许可与执照；技术方案应可行且不对依法使用的其他频率产生有害干扰；电磁环境公众曝露控制有国家环境质量标准（如 GB 8702《电磁环境控制限值》，教学指针，**限值与豁免以原文为准**）；测量仪器应在有效检定/校准状态（计量语境：以证书载明的复校/有效日期为准）。本篇只借「先覆盖、再在检、结论对现场、台账可对账、签字有边界」的顺序，**不编造本网内部限值数字、不教涂改报告过关**。

### 2.3 和手册07 / 08 / 16 / 20 / 22 / 23 的咬合（指针，不重写）

- **手册08 G**：实验室方法、仪器与夹具——**可支撑 X-测 的方法与仪器有效性**，不能代替「本站址角色验收报告台账」；G 测指纹 ≠ X 签交维。  
- **手册07 F**：射频指纹——可支撑「配置/发射特征是否对得上报告角色」，**不能代替**完整验收报告。  
- **手册16 O / 10 I / 13 L**：有源隔离、室分、井库——拓扑或有源变更常触发 **X 复测**（规则5）；主贴仍可是 X，次挂 O/I/L。  
- **手册20 S**：边界/共址/邻频相关验收须书面协调或挂 S；禁功率战掩盖环境问题（规则7）。  
- **手册22 U / 23 V**：许可与执照、临时窗——**频段/功率/时段角色须与报告方案一致**；无证/过期仍走 U/V，不拿「有旧环境报告」顶替证照。  
- **手册21 T / 24 W**：投诉与非法线索——环境异常投诉可挂 T；疑似非法源走 W；**验收台账本身主贴 X**。  
- **手册19 R**：假绿演练——**屏上看见 ≠ 实测验收**（规则6）；可挂 R 提醒，主贴仍 X。

### 2.4 新贴纸 X：测 / 验 / 账 / 签 / 治（五个子类）

```text
                ┌──────────── 贴纸 X · 测/验/账/签/治 ────────────┐
                │  X-测  测试方案与仪器有效性：在检·方法·测点角色·与许可一致 │
                │  X-验  验收判据与报告完整：结论可追溯·与现场一致·断链禁正式 │
                │  X-账  报告台账可对账：编号角色·有效期·覆盖站址·复测触发   │
                │  X-签  签字边界：谁可签验收/交维；缺报告/过期/不一致拒签   │
                │  X-治  拒签治理：伪造套旧·未复测变更·公开泄密·假绿顶替     │
                └──────────────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签 / 拒放行触发 |
|------|--------|----------------------|
| **X-测** | 仪器过期或方法与许可不符仍测仍签 → 拒签 | 「检定过期先测完再补」 |
| **X-验** | 报告缺页/断链/结论对不上现场 → 禁正式验收 | 「缺仪器证书页也先签」 |
| **X-账** | 台账对不上覆盖站址或有效期 → 禁签就绪 | 「文件夹有纸=台账齐」 |
| **X-签** | 无授权人签、或强签缺报告项 → 拒签 | 「领导催签就签」 |
| **X-治** | 套旧报告、伪造、假绿顶替、公开泄密 → 治理 | 「拿 A 址报告签 B 址」 |

### 2.5 电磁环境测试与验收报告最小工作流（背下来）

```text
  拟签「开站验收 / 交维就绪 / 重大变更后复验」
        │
        ▼
  是否有覆盖本站址角色、本频段角色、本时段的有效报告？（X-账）
        │无 / 过期 / 覆盖不对──▶ 拒签；开测或补测（规则1、2）
        │有候选报告
        ▼
  仪器检定/校准是否在有效期内？方法与测点角色是否与方案/许可一致？（X-测）
        │否──▶ 拒签；送检或改方案（规则2）
        │是
        ▼
  报告结论是否完整可追溯？与现场配置/功率角色是否一致？（X-验）
        │缺项断链 / 不一致──▶ 禁当正式验收证据；内部可挂「待测/待补」（规则3、4）
        │一致且完整
        ▼
  近期是否有重大变更（频点角色、天线、功率、室分拓扑等）未复测？（规则5）
        │有──▶ 拒签；复测/补测后再走 X
        │无
        ▼
  边界/共址/邻频相关？→ 书面协调或挂 S（规则7）
  假绿/屏绿能否顶替？→ 不能；挂 R 提醒（规则6）
        │
        ▼
  授权人按 X-签 边界签字；台账入库；公开包 L3（规则8）
  结案词用 X 子类；可挂 G/F/S/O/I/L 支撑，主贴 X
```

现场口诀：

> **先对覆盖，再对在检；结论对现场，台账能对账。**  
> 跳过对账的「交维就绪」= 拿过期灭火器证办入住。

## 3. 核心交付：插页 X + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 X（而不是先贴 G / U / R / S）

| 现场信号 | 主贴 | 可次挂 |
|----------|------|--------|
| 开站验收 / 交维就绪要看电磁环境报告台账 | **X** | G / U / S |
| 实验室方法/仪器能力争议 | **G**（不是 X） | 可挂 X-测 |
| 许可/执照是否覆盖 | **U / V** | 报告方案须与之一致 |
| 屏绿/假绿想顶替实测 | **X-治** + 挂 **R** | — |
| 边界/共址/邻频环境验收 | **X** + 挂 **S** | O / I |
| 室分/井库/有源拓扑变更后复测 | **X** | I / L / O |
| 伪造/套旧报告/公开泄密 | **X-治** | — |

> **口诀**：实验室方法 → **G**；证照覆盖 → **U / V**；假绿演练 → **R**；邻居协调 → **S**；**电磁环境测试报告与验收签字台账 → X**。可叠挂，**该类验收主贴 X**。

### 3.2 插页 X · 测 / 验 / 账 / 签 / 治（挂在总三联单或验收单后）

| 行 | 名称 | 填写示例（教学虚构，L3） |
|----|------|--------------------------|
| **X1** | 方案摘要角色 | 「频段角色·测点角色·方法角色·与许可/执照台账互挂编号脱敏」 |

> **X2 过期 → 禁止以该次测量作为正式验收依据（规则2）。**  
> **X4 覆盖站址角色对不上 → 禁套用（规则3）。**  
> **X5 结论不可追溯或与现场不一致 → 禁正式验收（规则3、4）。**  
> **X6 缺勾 → 禁签验收/交维就绪（规则1）。**  
> **X7 有触发未复测 → 拒签（规则5）。**  
> **X8 公开包出现真实频点/报告全文号/坐标 → L3 违规（规则8）。**

### 3.3 「套旧报告 / 仪器过期 / 假绿顶替 / 缺项强签拒签」卡（贴值班台 / 网管室 / 验收室）

  ┌──── 电磁环境测试与验收报告拒签卡（贴纸 X）────┐

### 3.4 和总三联单怎么写（接手册06）

- **现象**：写「拟验收/交维/变更复测 + X 子类」，**未对账前不写「电磁环境已合格可交维」**。  
- **证据**：方案角色、仪器有效期、报告编号角色、测点角色、结论摘要（L3）、台账勾选、复测触发。  
- **结论**：用 X 子类 + 待测/待补/已验收/拒签；次挂 G/U/S/O/I/L/R 时写清主贴仍是 X。  
- **动作**：对账、送检、补测、复测、挂 S、拒签——**禁止**写「套旧报告」「过期先测」「屏绿顶替」「先用着再说」「功率顶上去过验收」。
