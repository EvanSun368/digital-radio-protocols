### 2.7 一晚怎么走完（教学节奏，不替代本网书面规程）

1. **进机房前**：AN 门禁/陪同勾选；确认本期是列头末端窗还是别的窗。  
2. **翻 AW1**：列头台账在不在？指示灯绿≠准用勾了没有？  
3. **翻 AW2–AW3**：末端主人窗方法；巡检书面方法；禁口头/绕联锁/带电违章。  
4. **做本期实测**：本组本机房；AD 仪表准用指针；禁套邻站热成像。  
5. **勾 AW5 边界**：AF/AS/AD/N/AN/AQ 过≠AW 过。  
6. **会签或拒签**：假绿挂 R；风暴挂 N；变更走 J；L3。  

> 时间紧就先走 **AW8 十五分钟夜班**；缺页一律停在缺的那一行，**不拿灯绿顶会签**。

## 3. 核心交付：插页 AW + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AW（而不是先贴 AF / AS / N）

- 要签「列头柜与末端配电巡检准用」、要开列头/末端窗、要交底巡检方法 → **主贴 AW**。  
- 油机市电切换与供电巡检本身 → **AF**（手册33）；列头末端仍 AW；AF 过≠AW 过。  
- UPS 旁路本身 → **AS**（手册46）；列头末端仍 AW；AS 过≠AW 过。  
- 列头/末端/配电告警风暴 → 先 **N** 理风暴；缺列头/末端/巡检秩序整改仍 **AW**；**禁功率战**。  
- 钳表/热成像仪入库 → **AD**；入库过≠本期实测过。  
- 巡检过程要调录像 → 另开 **AQ**；视频过≠AW 准用。  
- 假绿/顶替 → 挂 **R**；变更配电策略/门限/巡检规程 → 走 **J** 后再验 AW。

### 3.3 和总三联单怎么写（接手册06）
