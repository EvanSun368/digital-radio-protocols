## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **列头柜台账钉死**：柜体角色·进线/母线角色·馈出回路角色；编号脱敏；禁「指示灯绿就能签」「口头说一声」。  
2. **末端配电有主有窗有方法准用期**：支路/插座/PDU 单元；灯绿≠窗过；标签在≠巡检过。  
3. **巡检窗与方法钉死**：到场角色·目视/测温/紧固指针等以本网与 OEM 书面为准；禁口头测过电；禁教带电违章；禁绕电气安全联锁。  
4. **本组本机房本期实测禁套他站他期曲线/照片/热成像**。  
5. **会签才放行「列头柜与末端配电巡检准用」**。  
6. **禁顶替 AF/AS/AD/AN/AA/N/AQ/AV/AR/AI/AT/AU/AO/AG/AP/AL，主贴 AW，假绿≠放行挂 R**：油机市电签、旁路签、仪表签、门禁签、首年签、监控签、视频签、油品签、燃油安全签、环境签、电池签、气灭签都不顶本期列头末端签。  
7. **列头/末端/配电异常风暴挂 N；配电策略/门限/巡检规程变更走 J；禁功率战；禁绕过电气安全联锁冒充准用；禁伪造台账**。  
8. **脱敏 L3**：禁真实站名/机房全称/列头柜序列号全文/单位名/联系人/真实频点。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签列头末端准用、无实测冒充配电过、绕联锁/未授权带电违章冒充秩序齐，不是法外运维智慧**。医院保供电/列头配电公开资料、厂商 PDU 与支路监测公开科普只作故事与方法类比（§2.2）：**列要约、末要窗、巡要法、验要本期、灯绿不算过**——翻译成本网语言就是 AW-列 / AW-末 / AW-巡 / AW-验 / AW-治。**这些是列头柜与末端配电巡检交底秩序，不是「灯绿就签」「标签在当过」「抬功率压告警」「绕联锁」「未授权带电违章」的借口。**

### 4.7 台账路径（从发现到会签，教学骨架）

1. **发现**：三联单记脱敏机房/柜体角色 + 现象（列头无账 / 末端无窗 / 巡检无方法 / 灯绿假绿 / 套票嫌疑 / 配电告警风暴）。主贴 **AW**。

6. **交班**：用 §5.3 口述模板；L3 勾选；未闭项移交下一班。

## 6. 工作实例（12 则，教学虚构，L3）

1. **指示灯绿就要签准用** → 夜班看到列头柜面板全绿，直接在准用栏打勾。→ **拒签**；补 AW-列台账与本期回路核对；宣读「指示灯绿≠支路准用」。  
2. **标签还在当窗过** → 外包指着柜门标签说「还在有效期内，窗页免了」。→ **拒签**；补 AW-末主人/窗/方法；标签在≠巡检窗过。  
3. **口头说测过电** → 新人交班口述「测温做过了」但无书面方法页、无读数留痕。→ **拒签**；补 AW-巡书面方法；禁口头测过电。  
4. **套邻站热成像/照片改机房号** → 把邻站热成像文件名改成本机房角色交差。→ **AW-验 拒签重测**；本组本机房本期实测；可挂 R。  
5. **AF 油机市电签顶本期列头末端签** → 班长说「AF 上周刚签，列头免做」。→ **拒签顶替**；AF≠AW；油机市电过≠列头末端过；可挂 R。  
6. **AS UPS 旁路签顶列头末端签** → 「旁路切换演练过了，列头也能过」。→ **拒签**；AS≠AW；旁路过≠列头末端过。  
7. **AD 仪表入库签顶本期实测** → 「钳表/热成像仪还在准用期内，实测免」。→ **拒签**；入库过≠本期实测过；AD 只支撑仪表准用，主窗仍 AW。  
8. **N 监控绿免本期实测** → 「大屏配电全绿，实测免做」。→ **拒签**；N≠AW；要有本期列头/末端/巡检实测与会签。  
9. **支路跳闸/配电告警抬功率** → 网优想「告警一片，功率抬一点压过去」。→ 挂 **N**；**禁功率战**；缺列头/末端/巡检秩序整改贴 **AW**。  
10. **绕过电气安全联锁消告警 / 未授权带电违章** → 有人提议「旁路联锁消告警」或「带电拧一下就好」。→ **禁**；挂 N/R；禁签准用；**不教带电违章步骤**。  
11. **进机房门禁过了就当配电交底过** → 「AN 门禁陪同过了，列头也能签」。→ AN 过≠AW 过；补 AW；进机房仍要 AN。  
12. **公开群贴真实列头柜序列号** → 为「方便对账」把柜体序列号发到公开群。→ L3 违规；撤帖脱敏；AW-治；以后只写脱敏角色。
