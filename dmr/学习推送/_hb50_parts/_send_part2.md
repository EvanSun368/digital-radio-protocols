## 3. 核心交付：插页 AW + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AW（而不是先贴 AF / AS / N）

- 要签「列头柜与末端配电巡检准用」、要开列头/末端窗、要交底巡检方法 → **主贴 AW**。  
- 油机市电切换与供电巡检本身 → **AF**（手册33）；列头末端仍 AW；AF 过≠AW 过。  
- UPS 旁路本身 → **AS**（手册46）；列头末端仍 AW；AS 过≠AW 过。  
- 列头/末端/配电告警风暴 → 先 **N** 理风暴；缺列头/末端/巡检秩序整改仍 **AW**；**禁功率战**。  
- 钳表/热成像仪入库 → **AD**；入库过≠本期实测过。  
- 巡检过程要调录像 → 另开 **AQ**；视频过≠AW 准用。  
- 假绿/顶替 → 挂 **R**；变更配电策略/门限/巡检规程 → 走 **J** 后再验 AW。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **列头柜台账钉死**：柜体角色·进线/母线角色·馈出回路角色；编号脱敏；禁「指示灯绿就能签」「口头说一声」。  
2. **末端配电有主有窗有方法准用期**：支路/插座/PDU 单元；灯绿≠窗过；标签在≠巡检过。  
3. **巡检窗与方法钉死**：到场角色·目视/测温/紧固指针等以本网与 OEM 书面为准；禁口头测过电；禁教带电违章；禁绕电气安全联锁。  
4. **本组本机房本期实测禁套他站他期曲线/照片/热成像**。  
5. **会签才放行「列头柜与末端配电巡检准用」**。  
6. **禁顶替 AF/AS/AD/AN/AA/N/AQ/AV/AR/AI/AT/AU/AO/AG/AP/AL，主贴 AW，假绿≠放行挂 R**：油机市电签、旁路签、仪表签、门禁签、首年签、监控签、视频签、油品签、燃油安全签、环境签、电池签、气灭签都不顶本期列头末端签。  
7. **列头/末端/配电异常风暴挂 N；配电策略/门限/巡检规程变更走 J；禁功率战；禁绕过电气安全联锁冒充准用；禁伪造台账**。  
8. **脱敏 L3**：禁真实站名/机房全称/列头柜序列号全文/单位名/联系人/真实频点。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签列头末端准用、无实测冒充配电过、绕联锁/未授权带电违章冒充秩序齐，不是法外运维智慧**。医院保供电/列头配电公开资料、厂商 PDU 与支路监测公开科普只作故事与方法类比（§2.2）：**列要约、末要窗、巡要法、验要本期、灯绿不算过**——翻译成本网语言就是 AW-列 / AW-末 / AW-巡 / AW-验 / AW-治。**这些是列头柜与末端配电巡检交底秩序，不是「灯绿就签」「标签在当过」「抬功率压告警」「绕联锁」「未授权带电违章」的借口。**

### 4.4 列头清单（AW-列）——缺页不能签准用

- 柜体角色（脱敏编号；禁真实序列号全文）  
- 进线/母线角色（进线来源角色可记「市电侧/UPS 侧/油机侧角色」，**不替代 AF/AS 本身**）  
- 馈出回路角色（可按回路组/机柜行角色记，不写真实序列号）  
- A/B 路或双路供电角色指针（若本网有；只记有/无，不在此篇写切换步骤）  
- □ 指示灯绿≠支路准用  
- □ 禁指示灯绿就能签 □ 禁口头说一声  
- □ 与 AF（油机市电）/ AS（UPS 旁路）边界已勾：供电过≠列头台账过  

### 4.5 末端与巡检清单（AW-末 / AW-巡）

- 末端主人角色（运维/授权外包角色）  
- 书面窗：周期巡检 / 维护窗 / 整改复验 / 其他（本网定义）  
- 方法/准用期（以本网与 OEM 书面为准；**本篇不写死门限数值，不写逐步带电操作教条**）  
- 支路/插座/PDU 单元核对（有账/缺；灯态只作现象，不作准用依据）  
- □ 灯绿≠窗过 □ 标签在≠巡检过 □ 外观在≠准用  
- 书面巡检方法：到场角色 · 目视（变色/异味/异响指针）· 测温/热成像指针 · 紧固指针（**只记「按本网/OEM 书面」**）

- 相关仪表 AD 准用号（若用钳表/热成像仪）  
- BCM/支路监测映射核对指针（若本网有：映射角色有/缺；**不在此篇教如何改映射冒充准用**）

### 4.7 台账路径（从发现到会签，教学骨架）

1. **发现**：三联单记脱敏机房/柜体角色 + 现象（列头无账 / 末端无窗 / 巡检无方法 / 灯绿假绿 / 套票嫌疑 / 配电告警风暴）。主贴 **AW**。  
2. **补账**：AW-列补柜体·进线/母线·馈出；AW-末补主人·窗·方法·准用期；AW-巡补书面方法（只记「按本网/OEM 书面第___版」）。  
3. **开窗实测**：本组本机房本期实测；AD 仪表准用指针（若用钳表/热成像仪）；**禁套他站他期**；**禁口头测过电**；**禁绕联锁**；**禁未授权带电违章**。  
4. **边界勾选**：AF / AS / AD / N / AN / AQ 各勾「过≠AW 过」。  
5. **会签或拒签**：准用 / 有条件整改 / 拒签；假绿挂 **R**；风暴挂 **N**；变更走 **J** 后再验。  
6. **交班**：用 §5.3 口述模板；L3 勾选；未闭项移交下一班。

> **路径口诀**：发现贴 AW → 补列补末补巡 → 本期实测禁套 → 边界勾清 → 会签才放 / 拒签挂改。

### 4.8 15 分钟夜班清单（AW8 展开）

1. **2 分钟**：列头台账页在不在？指示灯绿≠准用勾选有没有？  
2. **3 分钟**：末端窗页：主人、窗、方法、准用期；灯绿≠窗过；标签在≠巡检过。  
3. **4 分钟**：巡检窗：书面方法有没有？禁口头测过电/禁绕联锁/禁未授权带电违章勾选。  
4. **3 分钟**：本期实测有没有？禁套声明勾了没有？AF/AS/AD/N 边界勾了没有？  
5. **3 分钟**：有无绕联锁/未授权带电违章/抬功率念头？有则挂 N/R，**禁签准用**；L3 勾选。

### 5.2 对话脚本（教学）

- **运维→班长**：「指示灯绿，今晚签列头末端准用？」——「先翻 AW1：有没有列头台账和本期回路核对？没有就拒签，允许补账。」  
- **外包→运维**：「标签还在，窗页免了吧？」——「标签在≠窗过。AW2 要有主人、窗、方法。」  
- **班长→外包**：「AF 油机市电签还在，AS 旁路也过了，列头也能过？」——「AF≠AW，AS≠AW。油机市电过、旁路过都不等于列头末端过。拒签顶替，可挂 R。」  
- **站务→运维**：「大屏配电绿，实测免？」——「N 绿≠AW 过。要有本期列头/末端/巡检实测与会签。」  
- **网优→班长**：「支路跳闸/配电告警一片，功率抬一点？」——「**禁功率战**。先 N 理风暴；缺列头/末端/巡检秩序整改贴 AW。」  
- **新人→师傅**：「测温到场我口头记得，还用写吗？」——「要写。AW3 书面方法钉死；禁口头测过电；以本网与 OEM 书面为准；**不教带电违章**。」

### 5.4 禁写词 / 允许写

禁止写：真实站名、机房全称、列头柜序列号全文、单位名、联系人、真实频点、未脱敏回路门限可还原信息；禁止写「指示灯绿就过」「标签在就过」「口头测过电就过」「AF/AS/AD 签顶 AW」「抬功率压配电告警」「绕联锁」「未授权带电违章」「套邻站热成像」。允许写：脱敏机房/柜体角色、现象（列头缺失/末端无窗/巡检无方法/假绿/风暴）、贴纸（AW/AF/AS/AD/N/AN/AQ/R/J）、动作（补账/重测/拒签）。

### 5.5 与弱项的现场对照（再钉一次）

列头台账乱、末端无窗、巡检假绿准用，往往先伤**站点保供电与设备生存**，再伤空口：上行 12.5 kHz / 4FSK / 2-slot 本来就脆，有人把支路跳闸/配电告警当覆盖病去抬功率——**禁功率战**。先 AW 证列头末端配电秩序，再谈 X/I 覆盖干扰。

## 6. 工作实例（12 则，教学虚构，L3）

1. **指示灯绿就要签准用** → 夜班看到列头柜面板全绿，直接在准用栏打勾。→ **拒签**；补 AW-列台账与本期回路核对；宣读「指示灯绿≠支路准用」。  
2. **标签还在当窗过** → 外包指着柜门标签说「还在有效期内，窗页免了」。→ **拒签**；补 AW-末主人/窗/方法；标签在≠巡检窗过。  
3. **口头说测过电** → 新人交班口述「测温做过了」但无书面方法页、无读数留痕。→ **拒签**；补 AW-巡书面方法；禁口头测过电。  
4. **套邻站热成像/照片改机房号** → 把邻站热成像文件名改成本机房角色交差。→ **AW-验 拒签重测**；本组本机房本期实测；可挂 R。  
5. **AF 油机市电签顶本期列头末端签** → 班长说「AF 上周刚签，列头免做」。→ **拒签顶替**；AF≠AW；油机市电过≠列头末端过；可挂 R。  
6. **AS UPS 旁路签顶列头末端签** → 「旁路切换演练过了，列头也能过」。→ **拒签**；AS≠AW；旁路过≠列头末端过。  
7. **AD 仪表入库签顶本期实测** → 「钳表/热成像仪还在准用期内，实测免」。→ **拒签**；入库过≠本期实测过；AD 只支撑仪表准用，主窗仍 AW。  
8. **N 监控绿免本期实测** → 「大屏配电全绿，实测免做」。→ **拒签**；N≠AW；要有本期列头/末端/巡检实测与会签。  
9. **支路跳闸/配电告警抬功率** → 网优想「告警一片，功率抬一点压过去」。→ 挂 **N**；**禁功率战**；缺列头/末端/巡检秩序整改贴 **AW**。  
10. **绕过电气安全联锁消告警 / 未授权带电违章** → 有人提议「旁路联锁消告警」或「带电拧一下就好」。→ **禁**；挂 N/R；禁签准用；**不教带电违章步骤**。  
11. **进机房门禁过了就当配电交底过** → 「AN 门禁陪同过了，列头也能签」。→ AN 过≠AW 过；补 AW；进机房仍要 AN。  
12. **公开群贴真实列头柜序列号** → 为「方便对账」把柜体序列号发到公开群。→ L3 违规；撤帖脱敏；AW-治；以后只写脱敏角色。
