## 8. 术语表（本篇约 18 词）+ 易错观念

| 术语 | 一句话 |
|------|--------|
| **非法设台（教学用语）** | 未经许可擅自设置、使用无线电台（站）等违法情形的统称（定性权在法定主体；本网只分诊上报） |
| **黑广播（公开科普用语）** | 公开材料中对未经审批私自设立非法广播电台等行为的通俗称呼（教学转述，以主管部门表述为准） |
| **线索** | 尚未依法认定的可疑信息进线，不等于已定罪 |
| **分诊** | 先分级再决定主贴与是否外报（W-线） |
| **证据最小集** | 对外正式定性前不可缺的教学最小证据组（W-证） |
| **保管链** | 证据从采集到移交的可追溯登记；断链则降级 |
| **待证** | 内部允许挂起继续保全，但禁对外正式定性 |
| **内部上报** | 本网主人+时限+L3 摘要的对内路径（W-报） |
| **依法外报** | 向无线电管理机构等法定渠道报告/投诉/举报 |
| **运维边界** | 本网只做合规监测与台账，不做私力执法（W-界） |
| **功率战** | 用抬功率等方式报复或压制，本篇红线 |
| **私了** | 私下了结并常伴毁证，本篇红线 |
| **主贴 W** | 非法/黑广播类线索以 W 为主键，可挂 T/S/U/V |
| **L3** | 公开包最高脱敏等级（本系列约定） |
| **12381 等公开路径** | 工信部公开材料中的干扰投诉等入口提示（以原文与属地为准） |
| **猎杀叙事** | 把本网 U/V 违章或未证线索写成「查获黑广播」的错误对外叙事 |
| **假线索** | 故意伪造或重大过失误报并企图对外定性 |
| **法定主体** | 依法有权查处、处罚的无线电管理机构等，不是本网运维班组 |

**易错观念**

1. ✗ 听见像 = 已确认黑广播 → ✓ 先分诊 + 证据；定性权不在夜班口嗨。  
2. ✗ 有投诉 = 可以对外定罪 → ✓ 投诉主贴 T；升 W 仍要证据最小集。  
3. ✗ 本网无证 = 按黑广播宣传 → ✓ 走 U/V 自纠。  
4. ✗ 自己去拆更快点 → ✓ 运维边界；依法报告。  
5. ✗ 功率顶回去是维权 → ✓ 功率战红线。  
6. ✗ 发自媒体算举报 → ✓ 法定渠道；禁网暴定罪。  
7. ✗ 断链截图仍可当正式证据 → ✓ 断链降级。  
8. ✗ 内报了等于外报了 → ✓ 两回事。  
9. ✗ 邻居纠纷可以假线索报复 → ✓ 假线索 W-治。  
10. ✗ 公开培训可以贴真实频点与原件号 → ✓ 公开 L3，原件受控。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **W** 五子类：线 / 证 / 报 / 界 / 治。  
- 故事：药店发现假药线索 → 内部登记 + 送监管；不当街私了、不当侦探捣窝点。  
- 八条硬规则：**先分诊再上报**；**证据未齐禁对外定性**；**运维不做排查对抗与功率战私了**；**内部有主人对外走法定渠道**；**与 T 分工**；**本网违章走 U/V 非猎杀**；**跨网挂 S**；**脱敏 L3**。  
- 与 T/U/V/S 分工：T=投诉进线；U/V=本网证照与临时窗自纠；S=邻居协调；**W=非法/黑广播类线索的分诊·证据·上报·运维边界**。

### 11.2 回库路径
