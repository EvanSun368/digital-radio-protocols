## 4. 深潜：八条硬规则 + 分诊题 + 证据最小集 + 上报路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **先分诊线索属性再谈上报**（本网故障误报 / 邻网合法 / 疑似非法设台 / 疑似黑广播 / 不明）——**未分诊禁对外正式定性**。  
2. **证据最小集未齐 → 禁对外正式定性「非法设台 / 黑广播」**；内部可挂「待证」继续保全。  
3. **运维边界：不自行排查对抗、不教测向定位打击细节、不功率战报复、不私了毁证**——药店员不是侦缉队。  
4. **内部上报有主人与时限；对外依法报告走无线电管理机构等法定渠道**（公开如 12381 等以属地最新为准）；**禁网暴 / 自媒体定罪**。  
5. **与手册21 T 分工：投诉进线主贴 T；非法 / 黑广播类线索主贴 W；可互挂**——不要两张皮互相顶。  
6. **与手册22 U / 23 V：本网无证 / 过期 / 超窗是 U/V 治理，不是「黑广播猎杀」；本网违章先自纠合规**——禁把自家违章写成「查获黑广播」。  
7. **跨网疑似问题先协调挂 S；争议报无线电管理机构；禁报复**——功率战不是协调。  
8. **脱敏 L3：公开包禁真实频点、站名、单位名、坐标、联系人、完整证据原件号**——原件受控另册。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：《无线电管理条例》明确不得擅自使用无线电频率、不得擅自设置使用无线电台（站），无线电管理机构负责监测与干扰查处，受到有害干扰可向无线电管理机构投诉；《无线电频率使用许可管理办法》明确任何组织或者个人对未经许可擅自使用或违法使用无线电频率的行为有权向无线电管理机构举报；《地面无线电台（站）管理规定》明确执照与使用行为规范；工信部公开通报鼓励通过 12381 等公开渠道投诉举报「黑广播」「伪基站」等。**这些是主管部门的管理与举报路径，不是你方「私力执法」或「功率战报复」的借口。**

### 4.2 线索分诊题（W-线）——假药线索先问「是不是假药」

```text
  ① 是否更像本网故障 / 误操作 / 假绿 / 邻道泄漏（挂 F/N/R/P）？
     → 是：主贴运维故障或 T（若已投诉），结案「本网误报」；禁对外定性非法/黑广播

  ② 是否更像本网无证 / 过期 / 超窗临时发射（挂 U/V）？
     → 是：主贴 U/V 自纠；禁写成「查获黑广播」（规则6）

  ③ 是否更像邻网合法业务（已协调/可核对邻居台账角色）？
     → 是：挂 S 核对；可能转「邻网合法」；禁猎杀叙事

  ④ 现象是否符合公开科普中的「黑广播」群众识别直觉（如异常广告内容角色、不报台号等——仅作分诊线索，非定罪）？
     → 倾向疑似黑广播：主贴 W，进入证据最小集；仍禁未证对外正式定性

  ⑤ 是否疑似未许可设台/用频，但内容不属广播广告类？
     → 倾向疑似非法设台：主贴 W；同上

  ⑥ 以上都不够清晰？
     → 分级「不明」；内部待证；禁对外定性；可依法咨询/报告渠道（规则4）
```

**未过分诊题的冻结清单**：对外新闻稿/周报写「已确认非法设台/黑广播」、发动群定位、功率顶回去、私了谈判毁证。允许做的：内部登记、证据保全、本网自查、挂 S 预协调、起草依法报告材料（L3）。

### 4.3 证据最小集（W-证）——留样才能送检

| 序号 | 最小集项（教学） | 为什么必须有 | 缺了会怎样 |
|------|------------------|--------------|------------|
| 1 | **时间**（起止或首次发现时刻） | 对账与保管链锚点 | 禁对外正式定性；内部待证 |
| 2 | **地点角色**（台址脱敏 / 区域角色，禁坐标原文公开） | 可复核、可移交 | 公开写真坐标 → L3 违规 |
| 3 | **现象描述**（听感/看感/业务影响，角色标签） | 分诊依据 | 「很烦」四个字不够 |
| 4 | **本网日志指针**（告警/录音索引/监测记录角色，脱敏） | 区分本网故障 | 无指针易误报 |
| 5 | **录音 / 频谱截图角色**（若有；保管链） | 可移交依法渠道 | 断链禁当正式对外证据 |
| 6 | **保管链未断声明** | 断链=证据降级 | 断链禁当正式对外证据（规则2） |

> **口诀**：时、地、象、志、样、链——**六字证钉**（教学记忆；现场以属地与主管部门要求为准，但 **时间+现象+可追溯指针+保管链** 几乎不可砍）。  
> **断链识别**：原件丢失、多人传阅无登记、公开群转发后「再当正式证据」、截图无来源角色——一律降级，禁对外正式定性依赖。

### 4.4 内部上报与对外依法报告（W-报）——送监管怎么办

| 步 | 动作 | 拒签点 |
|----|------|--------|
| 1 | 指定内部主人（角色）与时限（本网制度；教学不编造小时数） | 「大家看看」无主人 |
| 2 | 内部上报内容：W2 分级 + W3 勾选 + L3 摘要；禁夹带真实频点/坐标/全文号 | 内报夹带明文敏感 |
| 3 | 判断是否需对外依法报告：疑似非法/黑广播且证据达本网外报门槛 | 证据未齐却外报「已确认」 |
| 4 | 对外路径：无线电管理机构等法定渠道（公开如 12381 干扰投诉/举报路径、属地窗口——**以原文与属地最新为准**） | 发自媒体/短视频定罪 |
| 5 | 回执与台账：外报回执角色、内部办结状态互挂 | 口头说报了无记录 |
| 6 | 配合依法调查：按主管部门要求提供受控原件；公开材料仍 L3 | 把原件丢进公开群 |

与手册21：若线索源于用户投诉，**进线主贴 T**，转 W 时互挂编号。与手册20：跨网先 S，不把「协调」做成「联合私了」。

### 4.5 运维边界（W-界 / 规则3）——药店员不是侦缉队

| 本网可以做（教学） | 本网不可以做（红线） |
|--------------------|----------------------|
| 合规监测记录、现象登记、自家台账对账 | 自行测向定位打击、拆窝点、私入民宅/楼顶「取缔」 |
| 本网故障排查与 U/V 自纠 | 功率战报复、故意干扰对方 |
| 按制度内部上报、依法外报 | 网暴、人肉、自媒体定罪游街 |
| 挂 S 书面协调、保存回执 | 私了毁证、私下收钱了事 |
| 按主管部门要求配合提供证据 | 伪造/涂改证据、教人规避监测 |

> **明确不教**：如何找非法台、如何测向交叉定位、如何拆设备、如何干扰压制、如何躲监测、如何伪造举报材料。需要技术查处的，**交给有法定职责的无线电管理机构等**——你方只做边界内的登记、保全与依法报告。

### 4.6 弱项短补：投诉 ≠ 非法定性 ≠ 本网无证 ≠ 邻网合法 ≠ 已外报

```text
   用户投诉（T）   非法/黑广播定性（W）   本网无证过期（U/V）   邻网合法（S）   已依法外报
   ─────────────  ─────────────────────  ───────────────────  ─────────────  ──────────
   进线怎么分诊    对外正式定性须证据齐     自纠合规·非猎杀      先协调核对     法定渠道+回执
   主贴 T          主贴 W·可挂 T            主贴 U/V             挂 S           W-报

   ✗ 「有投诉 = 已确认黑广播」
   ✗ 「本网无证 = 按黑广播举报自己并对外宣传」
   ✗ 「听见像广告 = 可以发群定罪」
   ✗ 「邻居不清楚 = 可以功率顶回去」
   ✗ 「内报了 = 等于外报了」
   ✗ 「截图发过群 = 保管链完整」
```

所以规则5、6才硬：**投诉主贴 T，非法类线索主贴 W；本网违章走 U/V，不走猎杀叙事。**

### 4.7 与主管部门路径怎么衔接（只讲合规路径，不教规避）

教学流程（细节以属地最新要求与官方受理材料为准）：

1. **发现 / 接报**：登记进线；W-线分诊。  
2. **本网自查**：是否本网故障、无证、过期、超窗、邻道泄漏——是则转 U/V/T/F 等，结束「W 猎杀叙事」。  
3. **证据保全**：W-证六字钉；原件受控。  
4. **内部上报**：主人与时限；L3 摘要。  
5. **对外依法报告**（达门槛时）：走无线电管理机构等法定渠道；公开科普与通报中常见的 12381 等路径可作入口提示——**以原文与属地为准**。  
6. **跨网**：先挂 S；争议仍报管理机构；禁报复。  
7. **配合调查**：按要求提供；公开仓不放原件全文号。  
8. **结案**：W 子类结案词；假线索走 W-治 复盘。

**明确不教**：如何无证发射、如何伪造涂改证据、如何规避监测与检查、如何「私了」话术过关、如何定位打击非法设台或黑广播。

### 4.8 线索处置前 15 分钟清单（可复印）

| 分钟 | 动作 |
|------|------|
| 0–3 | 打开线索卡：进线来源角色、首次时刻、粗现象 |
| 3–7 | W-线分诊六问；若本网/U/V/邻网合法 → 转贴并停止「非法定性」 |
| 7–10 | W-证勾选；缺项 → 内部待证，禁对外正式定性 |
| 10–13 | 指定内部主人与时限；判断是否依法外报；跨网则挂 S |
| 13–15 | 拒签卡自检（未排查对抗/未功率战/未发自媒体）；交班口述 |

夜班压缩版：至少完成「已分诊 + 证据勾选可读 + 有主人 + 未越权动作」四项——**四项缺一仍禁对外正式定性**。

### 4.9 与 T / U / V / S 单据互挂（W → 投诉 / 证照 / 临时窗 / 邻居）

```text
  投诉单（T）
        │
        ├── 若分诊后转非法/黑广播类：主贴改/加 W，互挂脱敏编号
        └── 若确认本网故障：结案 T，不升 W

  证照 / 临时窗（U / V）
        │
        └── 本网无证过期超窗：主贴 U/V 自纠；禁止 W 猎杀叙事

  邻频协调（S）
        │
        └── 跨网疑似：W 主贴 + S 协调编号互挂（均脱敏）
```

批量宣传 / 周报：任何「打击成效」表述若涉及本网线索，必须能追溯到 W 卡且公开 L3——**「领导要稿」不能代替证据最小集**。

## 5. 现场映射：原话 → W 子类；对话脚本；夜班；禁写词

### 5.1 原话速查表

### 5.2 对话脚本（五则）

**脚本1 · 未分诊定性**  
对方：「这声音一听就是黑广播，周报就这么写。」  
你：「规则1、2：未分诊、证据未齐禁对外正式定性。先 W-线分诊 + W-证勾选；对外用待证或依法报告表述。主贴 W-治。」

**脚本2 · 自己去捣窝点**  
对方：「位置大概在哪片，我们夜班自己去拆了省事。」  
你：「规则3：运维不做排查对抗与私自取缔。登记、保全、依法报告。主贴 W-界。」

**脚本3 · 功率战**  
对方：「对面烦死了，边界功率先顶满。」  
你：「规则3、7：禁功率战报复。跨网挂 S；投诉挂 T；争议报无线电管理机构。主贴 W-界，挂 S。」

**脚本4 · 本网无证当黑广播宣传**  
对方：「正好借这个机会，把我们过期那台也写成查获。」  
你：「规则6：本网过期走 U 自纠，不是黑广播猎杀叙事。主贴 U，禁止 W 对外定性自家。」

**脚本5 · 自媒体定罪**  
对方：「先发抖音，有人认识设备就行。」  
你：「规则4、8：对外走法定渠道；禁网暴自媒体定罪；公开 L3。主贴 W-报 / W-治。」

### 5.3 夜班 15 分钟怎么用

1. 扫线索台账：待证条数、超时报条数、未分诊条数（应为 0 对外定性）。  
2. 查越权动作：有无「自行定位/功率战/发群定罪」记录（应为 0）。  
3. 查互挂：投诉转 W、跨网挂 S、本网转 U/V 是否写清。  
4. 交班口述：待证、已内报、已外报、冻结原因（W 子类）、主人。

### 5.4 「非法/黑广播线索三问」（贴网管室 / 值班台）

  3. 主人是谁？对外是走法定渠道还是想发自媒体？有没有人要自己去找/功率顶？

## 6. 工作实例（10 个厚例，均教学虚构、已脱敏到 L3）

### 例 1 · 「听见像广告就定性」→ W-线 / W-治

现象：夜班扫频听感异常，周报草稿写「已确认黑广播」。  
处置：拒签周报表述；W-线分诊；证据未齐挂待证。  
结案词：「W-治：未分诊未证，禁对外正式定性。」

### 例 2 · 「证据缺保管链仍外报已确认」→ W-证

现象：截图曾发工作群，无保管登记，欲对外「已确认非法设台」。  
处置：断链降级；补保全新证据或仅报「待证线索」；禁正式定性。  
结案词：「W-证：断链禁当正式对外证据。」

### 例 3 · 「自己去楼顶取缔」→ W-界

现象：班长带人拟自行定位拆除。  
处置：立即制止；转依法报告路径；开治理复盘。  
结案词：「W-界：拒自行排查对抗；已改法定渠道。」

### 例 4 · 「功率顶回去」→ W-界 + S

现象：边界侧拟抬功率压制不明信号。  
处置：禁功率战；挂 S；若有投诉挂 T；记录 W。  
结案词：「W-界：禁功率战；已挂 S。」

### 例 5 · 「本网过期台写成查获黑广播」→ U + W-治

现象：宣传欲把本网过期发射写成打击成效。  
处置：拒签；主贴 U 关停自纠；禁止猎杀叙事。  
结案词：「规则6：本网违章走 U，不走 W 猎杀。」

### 例 6 · 「投诉进线未转贴」→ T + W

现象：用户投诉干扰，值班直接开 W「黑广播」结案。  
处置：主贴改回 T 分诊；若倾向非法类再挂 W；互挂编号。  
结案词：「规则5：投诉主贴 T；可挂 W。」

### 例 7 · 「跨网私了」→ W + S

现象：邻网私下约定「各退一步」并销毁录音。  
处置：拒私了毁证；恢复保全；挂 S 正式协调；必要时报管理机构。  
结案词：「W-界：禁私了毁证；已挂 S。」

### 例 8 · 「公开周报贴真实频点」→ W-治 / L3
