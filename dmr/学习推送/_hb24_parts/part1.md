## 1. 为什么要写这篇手册（动机 + 现场对话）

前二十三篇手册把「家里怎么养」「邻居怎么处」「投诉怎么分诊」「证照台账怎么对」「重大保障临时窗怎么钉」基本写全了：A–E 协议，F 射频指纹，G 实验室，H 话务，I 室分，J 写频，K 电源，L 井库，M 批量 / OTAP，N 监控对时，O 有源隔离，P 口部，Q 金机，R 假绿演练，S 邻频协调，T 干扰投诉，U 许可执照台账，V 临时保障窗。可现场还有一类债——**非法设台与黑广播类线索内部上报边界**：

- 夜班：「扫频听见一段像卖药广告的广播，是不是黑广播？我马上发群让大家定位。」——**未分诊就对外定性 + 越权排查叙事** = 本篇拒签（规则1、3、4）。  
- 运维班长：「这干扰太烦，先把边界功率顶上去压一压。」——**功率战报复** = 规则3、7（挂 S/T 提醒）。  
- 新人：「我们自己无证那台是不是也算非法设台？要不要按黑广播举报自己？」——**本网无证/过期是 U/V 治理，不是猎杀叙事**（规则6）。  
- 领导：「证据还不齐，但对外先说『已确认黑广播』，好推动。」——**证据最小集未齐禁对外正式定性**（规则2）。  
- 协调岗：「邻居那边好像有不明发射，我们自己去找找到了再谈。」——**跨网先协调挂 S；争议报无线电管理机构**（规则7）；**不自行排查对抗**（规则3）。  
- 宣传：「把录音原件和真实频点贴到公开周报，让大家提高警惕。」——**L3 违规 + 断链风险**（规则8）。

这几句背后是同一件事：

> **「非法设台与黑广播类线索」在现场至少有五个坑**：**① W-线** 线索怎么进线、怎么分级（疑似非法设台 / 疑似黑广播 / 本网故障误报 / 邻网合法 / 不明）；**② W-证** 证据最小集与保全（时间、地点角色、现象描述、本网日志指针、录音/频谱截图角色——一律 L3；断链禁当正式对外证据）；**③ W-报** 内部上报路径与对外依法报告边界（谁可报、报给谁、报什么、不报什么）；**④ W-界** 运维边界——本网只做合规监测与自家台账；**不自行排查对抗、不私自定位打击、不功率战报复、不网暴、不「私了」**；**⑤ W-治** 拒签/拒放行——假线索、无证据最小集就对外定性、公开仓泄密、越权执法叙事。  
> 把 ①–⑤ 当成「听见像就是」「先定性再补证」「自己去捣窝点」「功率顶回去」「发自媒体定罪」，会把下一任、邻居、主管部门和本网合规一起拖进泥潭。

本篇目标：能背出**非法设台与黑广播类线索内部上报工作流**；会用新贴纸 **W（线 / 证 / 报 / 界 / 治）** 与五个子类；会填**插页 W（W1–W8）**和《本网非法设台与黑广播类线索内部上报卡》；能用「**药店发现假药线索 → 内部登记 + 送监管，不当街私了、不当侦探自己捣窝点**」故事讲清：先分诊、证据保全、依法上报、运维边界、拒签；能拒绝「未分诊对外定性、证据未齐定罪、自行排查对抗、功率战、网暴私了、公开泄密」；自测过关后，回库把本网最近一次相关线索（脱敏到 L3）按本篇重对一遍。

**本篇硬禁令（写进脑子）**：凡引法规均指向已公开发布的文书标题与官方链接（《中华人民共和国无线电管理条例》《无线电频率使用许可管理办法》《地面无线电台（站）管理规定》《无线电台执照管理规定》《中华人民共和国无线电管制规定》及工信部/国无办公开的打击黑广播·非法设台相关通报与科普、干扰投诉受理公开文件等），**数字、时限、程序、处罚幅度以原文与属地最新要求为准，本篇只作教学转述，不发明条款号以外的「内部口径」或内部配额**；**现象与台账一律用相对道号、角色标签、脱敏编号表述，禁真实频点 / 站名 / 单位名 / 证据原件全文号 / 联系人 / 坐标**；**不教查找/测向定位打击/拆窝点/干扰对抗/规避监测/伪造报告/私力执法话术**；T 仍管投诉进线分诊，U/V 仍管本网证照与临时窗，S 仍管邻频协调——**非法/黑广播类线索主贴 W**；外国 / ITU 资料只借**频谱监测与频谱管理方法级表述**，**查处与执法以国内法规与属地无线电管理机构为准**。

## 2. 总图 / 故事：线索像「药店发现假药 → 内部登记 + 送监管」

### 2.1 一句话：非法设台 / 黑广播类线索像药店发现假药线索——先分诊是不是假药、保全证据最小集、内部登记上报、依法送监管；不当街私了、不当侦探自己捣窝点、不网暴定罪

```text
   ┌──────────────────────────────────────────────────────────────────┐
   │   药店值班 + 药监/公安法定渠道（= 本网运维 + 无线电管理机构等） │
   │                                                                  │
   │   进线分诊（W-线）                                               │
   │     疑似假药 / 本店过期药 / 邻店合法货 / 顾客误报 / 不明          │
   │                                                                  │
   │   证据保全（W-证）                                               │
   │     时间·地点角色·现象·本店台账指针·录音截图角色 · 断链禁对外   │
   │                                                                  │
   │   内部上报 + 依法外报（W-报）                                    │
   │     谁可报·报给谁·报什么·不报什么 · 禁自媒体定罪                │
   │                                                                  │
   │   运维边界（W-界）                                               │
   │     只做合规监测与自家台账 · 不自行捣窝点·不功率战·不私了      │
   │                                                                  │
   │   治理拒签（W-治）                                               │
   │     假线索/无证最小集定性/公开泄密/越权执法叙事 → 拒签         │
   └──────────────────────────────────────────────────────────────────┘
```

口诀：

> **先分诊，再保全；内部有主人，对外走法定。**  
> 未分诊就对外喊「黑广播」= 药店没核对就把顾客当售假犯游街——**拒签**。  
> 自己开车去捣窝点 = 药店员当街私了——**越权，本篇红线**。

### 2.2 「假药线索 → 送监管」五段直觉（钉死）

| 段 | 像什么 | 运维直觉 | 本篇贴纸 |
|----|--------|----------|----------|
| **线索进线** | 顾客/同事报「这药不对劲」 | 先分级：疑似非法设台 / 疑似黑广播 / 本网故障误报 / 邻网合法 / 不明 | W-线 |
| **证据保全** | 留样、拍照、记录批号角色（脱敏） | 时间·地点角色·现象·本网日志指针·录音/频谱截图角色；断链禁正式对外 | W-证 |
| **上报路径** | 内部质管登记 → 依法送药监/公安 | 内部有主人与时限；对外走无线电管理机构等法定渠道；禁网暴/自媒体定罪 | W-报 |
| **运维边界** | 药店员不是侦缉队 | 只做合规监测与自家台账；不自行排查对抗、不定位打击、不功率战、不私了 | W-界 |
| **拒签治理** | 假线索/无样定性/游街泄密拒签 | 假线索、无证据最小集对外定性、公开仓泄密、越权执法叙事 → 拒签 | W-治 |

> 公开文书告诉我们：不得擅自使用无线电频率，不得擅自设置、使用无线电台（站）；无线电管理机构负责监测、干扰查处；任何组织或者个人对未经许可擅自使用无线电频率或者违法使用无线电频率的行为，有权向无线电管理机构举报；依法设置、使用的无线电台（站）受到有害干扰的，可以向无线电管理机构投诉；工信部公开通报中鼓励通过 12381 等公开渠道投诉举报「黑广播」「伪基站」等（教学转述，**渠道与时限以原文与属地最新要求为准**）。本篇只借「先分诊、保全证据、依法报告、运维不做私力执法」的顺序，**不编造内部配额、不教查处技术细节**。

### 2.3 和手册20 / 21 / 22 / 23 的咬合（指针，不重写）

- **手册21 T**：投诉已进线后的分诊与证据链。**用户投诉「干扰」主贴 T**；若分诊后倾向「疑似非法设台/黑广播类」→ **可转主贴 W，互挂 T**。本篇不重写投诉证据链全文。  
- **手册22 U / 23 V**：**本网无证、过期、超窗临时发射**是 U/V 治理与自纠合规，**不是「按黑广播猎杀本网」**（规则6）。对外叙事禁把本网违章写成「我们查获黑广播」。  
- **手册20 S**：跨网疑似问题**先协调挂 S**；争议报无线电管理机构；禁报复功率战（规则7）。  
- **手册07 F / 15 N / 19 R**：指纹、对时、假绿——可支撑「本网故障误报」分诊，**不能代替** W 分诊与证据最小集；屏全绿不等于「外面没有非法源」。  
- **手册06**：对外交换、公开仓一律 **L3**（规则8）。

### 2.4 新贴纸 W：线 / 证 / 报 / 界 / 治（五个子类）

```text
                ┌──────────── 贴纸 W · 线/证/报/界/治 ────────────┐
                │  W-线  线索进线分级：疑似非法/疑似黑广播/本网误报/邻网合法/不明 │

                │  W-治  拒签治理：假线索·无证最小集定性·公开泄密·越权执法叙事         │

```

| 子类 | 一句话 | 典型拒签 / 拒放行触发 |
|------|--------|----------------------|
| **W-线** | 未分诊就对外定性「非法/黑广播」→ 拒签 | 「听见像卖药就定性」 |
| **W-证** | 证据最小集未齐仍对外正式定性 → 拒签；内部可挂「待证」 | 「先对外说确认了，证回头补」 |
| **W-报** | 无主人/超时不上报，或走自媒体定罪 → 治理 | 「发短视频让网友帮忙找」 |
| **W-界** | 自行排查对抗、功率战、私了毁证 → 红线 | 「我们自己去定位拆了」 |
| **W-治** | 假线索、公开泄密、越权执法叙事 → 拒签/治理 | 「公开贴真实频点+录音原件」 |

## 3. 核心交付：插页 W + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 W（而不是先贴 T / U / V / S）

| 现场信号 | 主贴 | 可次挂 |
|----------|------|--------|
| 疑似非法设台 / 黑广播类线索（非普通用户投诉话术） | **W**（先分诊+证据+上报边界） | T / S |
| 用户已投诉「干扰」进线 | **T**（不是 W） | 分诊后可转/挂 W |
| 本网无证 / 过期 / 超窗临时发射 | **U / V**（不是 W） | — |
| 跨网疑似不明发射、需邻居协调 | **W** + 挂 **S** | T（若已投诉） |
| 假线索 / 无证据最小集要对外定性 | **W-治** | — |
| 仅本网故障误报（已证） | **T** 或运维故障单 | 可结案为「非 W」 |

> **口诀**：投诉进线 → **T**；本网证照/临时窗自纠 → **U / V**；邻居协调方法 → **S**；**非法/黑广播类线索的分诊·证据·上报·运维边界 → W**。可叠挂，**该类线索主贴 W**。

### 3.2 插页 W · 线 / 证 / 报 / 界 / 治（挂在总三联单或线索单后）

| 行 | 名称 | 填写示例（教学虚构，L3） |
|----|------|--------------------------|
| **W1** | 主子类 + 次子类 | 「主 W-线 / 次 W-证」（或 W-报 / W-界 / W-治） |
| **W2** | 线索分级 | 「疑似黑广播 / 疑似非法设台 / 本网故障误报 / 邻网合法 / 不明」——未选禁对外定性 |
| **W3** | 证据最小集勾选 | 「□时间 □地点角色 □现象描述 □本网日志指针 □录音/频谱截图角色（若有）□保管链未断」 |
| **W4** | 内部上报 | 「主人角色 · 时限 · 已报/待报 · 报出内容 L3 摘要」 |
| **W5** | 对外依法报告 | 「未报 / 已走法定渠道角色（如公开投诉受理路径）· 回执角色」——禁填自媒体链接当「已报」 |
| **W6** | 运维边界确认 | 「未自行定位打击 · 未功率战 · 未私了毁证 · 未网暴」——任一项勾「已做」→ 本页作废进治理 |
| **W7** | 与 T/U/V/S 互挂 | 「挂 T 编号脱敏 / 挂 U·V 自纠编号 / 挂 S 协调编号 / 无」 |
| **W8** | 脱敏与结案词 | 「公开包 L3；结案词用 W 子类；禁真实频点与原件全文号」 |

> **W2 未分诊 → 禁止对外正式定性（规则1）。**  
> **W3 缺任一项（教学最小集）→ 禁对外正式定性「非法设台/黑广播」；内部可挂待证（规则2）。**  
> **W4 无主人或超时无动作 → 开治理（规则4）。**  
> **W5 若写「已发群/已发短视频定罪」→ 本页作废（规则4）。**  
> **W6 若勾选了排查对抗/功率战/私了 → 本页作废进 W-治（规则3）。**  
> **W8 公开包出现真实频点/原件全文号 → L3 违规（规则8）。**

### 3.3 「未分诊定性 / 无证定罪 / 越权排查 / 功率战 / 泄密拒签」卡（贴值班台 / 网管室）

### 3.4 和总三联单怎么写（接手册06）

- **现象**：写「线索进线 + W 子类 + 分级结果」，**证据未齐、未分诊前不写「已确认非法/黑广播」**。  
- **证据**：时间、地点角色、现象、本网日志指针、录音/频谱截图角色、保管链；全部 L3。  
- **结论**：用 W 子类 + 待证/已内报/已依法外报/拒签；次挂 T/U/V/S 时写清主贴仍是 W（或已转 T/U/V）。  
- **动作**：分诊、保全、内部上报、依法外报、挂 S、本网自纠——**禁止**写「自己去找」「功率顶回去」「发群定罪」「私了」。
