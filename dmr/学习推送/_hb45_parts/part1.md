## 1. 为什么要写这篇手册（动机 + 现场对话）

前四十四篇手册从 A–E 协议一路写到 AQ 视频调阅：其中 **AF 回答「油机市电切换与机房供电巡检」**，**AL 回答「机房消防气灭与应急疏散联锁」**，**AG 回答「电池与充电器梯队」**，**AP 回答「内阻与核对性放电」**，**AI 回答「温湿度与空调联锁」**，**AO 回答「漏水与接地汇流排」**，**AN 回答「门禁与访客陪同」**，**AD 回答「备件仪表准用」**，**AA 回答「交维后首年巡检」**，**N 回答「电源监控/对时/告警风暴」**，**AQ 回答「视频监控调阅与证据链」**。可还没有单独钉死一件事——**柴油发电机房通风排烟与燃油安全不是「风机绿灯就能签」：通风/燃烧空气台账要钉死；排烟与废气边界要有主人有界有方法有准用期；燃油与日用油箱巡检窗与方法要书面固定；本组本机房本期实测禁套他站他期——能不能签「通风排烟/燃油安全准用」？** 这就是本篇的 **AR**——**柴油发电机房通风排烟与燃油安全巡检边界**。

- 运维岗：「风机还亮着绿灯，通风巡检就算齐了。」——**无通风台账/无本期实测仍准用** = 本篇拒签（规则1）。  
- 外包：「排烟口开着，废气边界肯定过。」——**口开着当边界过** = 规则2。  
- 物业：「油箱看着有油，燃油安全再说。」——**无巡检窗方法，只听口头** = 规则3。  
- 外包：「邻站上周通风照片参数差不多，拷过来改个机房号。」——**套他站他期** = 规则4。  
- 班长：「AF 油机市电签还在，AL 气灭也过了，通风燃油也能签。」——**用 AF/AL/AG/AP/AI/AO/AN/AD/AA/N/AQ 顶替 AR** = 规则6。  
- 站务：「大屏油机监控绿了，通风排烟/燃油安全准用就算过。」——**假绿≠会签放行** = 规则5/6。  
- 网优：「油机高温/低油位告警一片，功率抬一点稳住业务。」——**功率战** = 规则7（无关也写禁，系列一致）。  
- 宣传岗：「把真实油机房编号、油箱序列号发群表扬。」——**L3 违规** = 规则8。  

这几句背后是同一件事：

> **「柴油发电机房通风排烟与燃油安全」在现场至少有五个坑**：**① AR-风** 通风/燃烧空气台账钉死，禁「风机绿灯就能签」「口头说一声」；**② AR-排** 排烟与废气边界有主人、有界、有方法、有准用期，禁「排烟口开着当边界过」；**③ AR-燃** 燃油与日用油箱巡检窗与方法钉死（油位·泄漏·通气·围堰等；门限以本网为准），禁「看着有油当巡检过」「只看监控绿」；**④ AR-验** 本组本机房本期实测（禁套他站他期曲线/照片），会签才放行「通风排烟/燃油安全准用」；**⑤ AR-治** 治理（假绿、用 AF/AL/AG/AP/AI/AO/AN/AD/AA/N/AQ 顶替、伪造通风燃油账、旁路风机联锁、不安全泄油旁路、功率战、泄密）。  
> 把 ①–⑤ 当成「风机绿灯就能签」「口开着就算过」「油机市电签还在通风也能签」，每一次油机试机、每一次燃油巡检、每一次夜班交班，都会先吵「账是谁的、窗谁开的、照片是不是本期的、边界清不清」。

本篇目标：能背出**通风 + 排烟废气 + 燃油安全工作流**；会用新贴纸 **AR（风 / 排 / 燃 / 验 / 治）**；会填**插页 AR（AR1–AR8）**和《本网柴油发电机房通风排烟与燃油安全台账卡》；能用「**医院手术室/ICU 保供电机房备用柴油发电机房通风排烟与燃油安全**」故事讲清风机绿灯≠通风合格、排烟口开着≠废气边界过、油箱看着有油≠燃油安全巡检过、套邻站通风照片=拒签、AF 油机市电签不顶替本期通风燃油签、AL 气灭过≠燃油日用油箱过、N 监控绿≠本期实测过、用 AF/AL/N 签顶 AR 通风燃油签=拒签、假绿≠会签放行；能拒绝无账准用、套票、用他贴顶替本期通风燃油签、假绿放行；自测过关后，回库把本网最近一次柴油发电机房通风/排烟/燃油巡检（L3）重对一遍：通风台账、排烟边界、燃油窗、本期实测、会签项、拒签项。

## 2. 总图 / 故事：通风燃油像「医院手术室/ICU 保供电机房备用柴油发电机房——不能只看风机绿灯」

### 2.1 一句话：风机绿灯不是「可以签准用」、排烟口开着不是「废气边界过了」、油箱看着有油不是「燃油安全巡检过了」、监控绿不是「本期实测过了」——要先建通风台账，排烟废气有主人有界有方法有准用期，燃油日用油箱巡检窗与方法钉死，本组本机房本期实测，会签才放行；假绿、套邻站照片、用 AF/AL/AG/AP/AI/AO/AN/AD/AA/N/AQ 顶替，一律拒签

### 2.3 和手册33（AF）/ 39（AL）/ 34（AG）/ 43（AP）/ 36（AI）/ 42（AO）/ 41（AN）/ 31（AD）/ 28（AA）/ 15（N）/ 44（AQ）等的咬合（指针，不重写）

- **AL（手册39）**：气灭与应急疏散联锁；**AL ≠ AR**——气灭过≠燃油日用油箱过；气灭保护区与油机房界面可挂 AL，通风燃油主贴仍 AR。  
- **AG（手册34）** / **AP（手册43）**：电池充电器梯队 / 内阻核对；电池过≠通风燃油过；油机启动电池可挂 AG/AP，风路燃油主贴仍 AR。  
- **AI（手册36）**：温湿度与空调联锁；温湿度过≠油机房通风合格；机房空调与油机房风路各管各的。  
- **AO（手册42）**：漏水汇排；漏水过≠燃油泄漏巡检过；油机房地漏/围堰积水可挂 AO，燃油安全主贴仍 AR。  
- **AN（手册41）**：门禁访客；进油机房做通风/燃油巡检仍要 AN——**门禁过≠通风燃油过**。  
- **AD（手册31）**：风速仪/测温/测漏仪表等入库走 AD；**不能**用旧 AD 签日期顶本期 AR 窗。  
- **AA（手册28）**：交维后**首年巡检**日历；通风燃油抽检可挂 AA，缺通风燃油秩序整改主贴仍 AR。  
- **N（手册15）**：监控/**对时**/告警风暴；通风/排烟/燃油异常风暴挂 N 理风暴，**不先抬功率**；**禁旁路风机联锁、禁不安全泄油消告警**；N 绿≠ AR 过。  
- **AQ（手册44）**：视频调阅；油机房事件要调录像另开 AQ；视频过≠通风燃油过。  
- **R / J / X / I**：假绿挂 R；变更（风路改造、排烟路由、油箱策略、巡检规程）走 J；覆盖/干扰分诊可挂 X/I 指针——**先 AR 证通风燃油秩序，再谈覆盖病**。

### 2.4 新贴纸 AR：风 / 排 / 燃 / 验 / 治（五个子类）

> 小彩蛋：双字母贴纸续写——**AA** 首年巡检；**AB** 室分复测；**AC** 机动开撤；**AD** 备件金机；**AE** 区间联测；**AF** 油机市电；**AG** 电池充电器；**AH** 合路/POI 界面；**AI** 温湿度联锁；**AJ** 天馈驻波；**AK** 爬塔交叉；**AL** 气灭疏散；**AM** 接地浪涌；**AN** 门禁访客；**AO** 漏水汇排；**AP** 内阻核对；**AQ** 视频调阅；**AR** 管「柴油发电机房通风排烟与燃油安全」。A–Z 既有含义不改；新专题用 AA、AB、AC… 续写。

```text
                ┌──────────── 贴纸 AR · 风/排/燃/验/治 ────────────┐
                │  AR-风  通风：通风/燃烧空气台账钉死                 │
                │  AR-排  排烟：排烟与废气边界有主有界有方法准用期   │
                │  AR-燃  燃油：窗·方法钉死（油位·泄漏·通气·围堰） │
                │  AR-验  验收：本组本机房本期实测·禁套他站他期     │
                │  AR-治  治理：假绿·顶替AF/AL/N·旁路联锁·泄油·泄密 │
                └──────────────────────────────────────────────────────┘
```

| 子类 | 一句话 | 典型拒签触发 |
|------|--------|--------------|
| **AR-风** | 无通风台账、风机绿灯无本期实测仍准用 → 拒签 | 「风机绿灯就能签」「口头说一声」 |
| **AR-排** | 排烟无主人、无边界核对、只看口开着 → 拒签 | 「排烟口开着就算过」 |
| **AR-燃** | 无书面燃油巡检窗/方法、只看油位/监控绿 → 拒签 | 「看着有油就行」「监控绿当过」 |
| **AR-验** | 套他站他期曲线/照片、无会签 → 拒签 | 「邻站通风照片拷过来改机房号」 |
| **AR-治** | 假绿、用 AF/AL/AG/AP/AI/AO/AN/AD/AA/N/AQ 顶替、旁路风机联锁、不安全泄油、功率战 → 治理 | 「AF/AL 签还在，通风燃油也能过」 |

### 2.5 建通风台账 → 钉排烟边界 → 燃油窗钉死 → 本期实测 → 会签放行 → 变更再验 阶段梯（背下来）

```text
  ① AR-风 建通风台账：机房角色 · 进风/燃烧空气/冷却风路角色 · 禁「风机绿灯就能签」「口头说一声」
        │  无账 / 灯绿无实测 → 不签通风排烟/燃油安全准用
        ▼
  ② AR-排 钉排烟边界：排烟主人角色 · 书面边界（路由·终端·回灌/短路核对） · 方法 · 准用期 · 禁「口开着当过」
        │  无主人 / 无边界 / 无方法 / 无准用期 → 拒进入「可签」状态
        ▼
  ③ AR-燃 钉燃油窗：书面窗 · 方法（油位·泄漏·通气·围堰等；门限以本网为准） · 到场角色 · AD 仪表准用指针
        │  无窗 / 「看着有油当过」/ 「监控绿当过」 → 拒燃油签
        ▼
  ④ AR-验 本组本机房本期实测：实测记录 · 禁套他站他期曲线/照片 · 会签
        │  套票 / 只看监控绿 → 拒签
        ▼
  ⑤ 会签「通风排烟/燃油安全准用」或「有条件整改」：本网授权本人签
        │  缺签 / 假绿顶替 → 拒签准用
        ▼
  ⑥ 变更再验：风路改造 / 排烟路由变更 / 油箱策略 / 巡检规程变更 → 走 J → 再验 AR
```
