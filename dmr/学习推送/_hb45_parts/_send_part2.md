## 3. 核心交付：插页 AR + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AR（而不是先贴 AF / AL / N）

| 场景 | 主贴 | 说明 |
|------|------|------|
| 要签「通风排烟/燃油安全准用」、查通风台账、开燃油窗、核排烟边界 | **AR** | 本篇 |
| 油机市电切换/ATS/供电巡检 | **AF**；通风燃油另开 **AR** | AF≠AR |
| 气灭/疏散联锁交底 | **AL**；燃油日用油箱仍 **AR** | AL≠AR |
| 通风/排烟/燃油异常告警一片、对时漂移 | 先 **N**，缺通风燃油秩序整改仍 **AR** | N≠AR |
| 进人进油机房巡检 | 先 **AN** 再 **AR** | 门禁过≠通风燃油过 |
| 风速/测温/测漏仪表准用 | **AD** 支撑；主窗仍 **AR** | AD 不顶窗 |
| 风路/排烟路由/油箱策略变更 | **J** + 再验 **AR** | 变更走 J |

> **口诀**：风机绿先问账；口开着先问界；有油先问窗；AF/AL/N 过了仍要问本期实测——**主贴 AR**。

## 4. 深潜：八条硬规则 + 分诊题 + 最小集 + 台账路径 + 15分钟清单

### 4.1 八条硬规则（本篇钉子）

1. **通风/燃烧空气台账钉死**：机房角色、进风/燃烧空气/冷却风路入账；禁「风机绿灯就能签」「口头说一声」。  
2. **排烟与废气有主有界有方法/准用期**：每次核对有主人角色、有书面边界、有方法、有准用期；禁「排烟口开着当边界过」。  
3. **燃油与日用油箱巡检窗与方法钉死**：书面固定；方法含油位·泄漏·通气·围堰等（**门限以本网为准**）；禁「窗再说」「看着有油当过」「只看监控绿」。  
4. **本组本机房本期实测禁套他站他期**：实测记录、照片、读数必须本期本组本机房；套邻站/邻院账 = 拒签。  
5. **会签才放行**：缺授权会签不得签「通风排烟/燃油安全准用」；假绿 ≠ 放行。  
6. **禁顶替 AF/AL/AG/AP/AI/AO/AN/AD/AA/N/AQ，主贴 AR，假绿≠放行挂 R**：油机市电签、气灭签、电池签、内阻签、温湿度签、漏水签、门禁签、仪表签、首年签、监控签、视频签都不顶本期通风燃油签。  
7. **通风/排烟/燃油异常风暴挂 N，风路/排烟路由/油箱策略变更走 J，禁功率战；禁旁路风机联锁；禁不安全泄油旁路**：上行更脆时先问秩序，不先抬功率（无关也写禁，系列一致）。  
8. **对外/公开仓一律脱敏 L3；禁贴真实站名/机房全称/油机油箱序列号全文/可还原坐标与联系人；禁公开传播未脱敏油箱参数与机房编号**。

> 法规锚点（已核公开原文，教学转述，**以原文为准**）：无线电管理与台站、频率许可决定「台站与设备按什么秩序管」——**无台账乱签通风燃油准用、无实测冒充巡检过、旁路联锁冒充秩序齐，不是法外运维智慧**。医院保供电油机房公开资料、柴油发电机房通风/排烟/燃油公开科普只作故事与方法类比（§2.2）：**风要约、排要界、燃要窗、验要本期、灯绿不算过**——翻译成本网语言就是 AR-风 / AR-排 / AR-燃 / AR-验 / AR-治。**这些是通风排烟燃油巡检边界秩序，不是「风机绿就签」「口开着当过」「抬功率压告警」「旁路联锁」「不安全泄油」的借口。**

**签字前冻结清单**（未过 §2.6 流程图任何一格时）：签「通风排烟/燃油安全准用」、对外宣传「风机一开通风秒过」、把未实测写成已过、把旁路联锁写成秩序齐。允许做的：补通风台账、补排烟边界、重开燃油窗、挂 R/N/J、内部挂整改。

### 4.3 「通风排烟/燃油安全准用」最小集（AR）——缺页不能签「通风排烟/燃油安全准用」

1. 通风/燃烧空气台账页  
2. 排烟主人与书面边界、方法、准用期页  
3. 书面燃油巡检窗与方法页（油位·泄漏·通气·围堰）  
4. 本期本组本机房实测记录（禁套声明）  
5. AF 油机市电边界勾选（防顶替；AF 过≠AR 过）  
6. AL 气灭边界勾选（防顶替；AL 过≠燃油日用油箱过）  
7. N 风暴边界勾选（防顶替；N 绿≠AR 过）  
8. AN 门禁边界勾选（若进人：先 AN；门禁过≠通风燃油过）  
9. AD 仪表准用指针（若用，支撑）  
10. 会签页（准用或有条件整改）  
11. 未闭项清单（有则挂整改，重大未闭禁签准用）  
12. 脱敏勾选（L3）  
13. 变更指针（若本期有风路/排烟/油箱策略变更 → J）

> **口诀**：风、排、窗、燃、房、测、签、闭、密、界——**十字风燃钉**（教学记忆；现场以本网书面规程为准，但 **通风台账 + 排烟边界方法 + 燃油窗方法 + 本组本机房本期实测 + 会签** 几乎不可砍）。

### 5.4 禁写词 / 允许写

禁止写：真实站名、机房全称、油机/油箱序列号全文、单位名、联系人、真实频点、未脱敏油量可还原信息；禁止写「风机绿就过」「口开着就过」「看着有油就过」「AF/AL 签顶 AR」「抬功率压高温」「旁路风机联锁」「不安全泄油」「套邻站照片」。允许写：脱敏机房角色、现象（通风缺失/排烟边界不清/燃油无窗/假绿/风暴）、贴纸（AR/AF/AL/N/AN/R/J）、动作（补账/重测/拒签）。

### 5.5 与弱项的现场对照（再钉一次）

油机房通风不足 → 油机高温/拒载风险 → 站点掉电 → 空口掉话；有人误判成「覆盖病」去抬功率——**上行更脆，禁功率战**。排烟回灌/短路 → 废气进风口 → 燃烧不良/人员风险 → 告警风暴挂 **N**，秩序整改 **AR**。燃油泄漏或缺油 → 保供电断链 → 同样先秩序后射频。**12.5 kHz / 4FSK / 2-slot TDMA** 提醒：功率战既伤邻道又治不了油机房秩序病。

## 6. 工作实例（12 则，教学虚构，L3）

1. **风机绿拒签**：脱敏油机房-05 风机绿灯，无通风台账页 → AR-风拒签「通风排烟/燃油安全准用」；允许补账，不允许口头顶过。  
2. **口开着假绿**：油机房角色-C 排烟口看着开着，无书面边界与回灌核对记录 → 挂 R，补 AR-排后再谈会签。  
3. **看着有油假绿**：日用油箱液位看着有，无书面燃油窗与泄漏通气围堰方法 → AR-燃拒签；假绿可挂 R。  
4. **套邻站照片**：外包拷邻站上周通风/油箱照片改机房号交差 → AR-验拒签，责令本期本组本机房重测。  
5. **市电顶通风**：班长称「AF 油机市电签还在，通风燃油也能签」→ 拒签；切换过≠通风燃油过；主贴仍 AR。  
6. **气灭顶燃油**：AL 气灭疏散交底过，想免做燃油日用油箱巡检 → 拒签；气灭过≠燃油日用油箱过。  
7. **监控顶实测**：N 监控大屏绿，外包想免做本期实测 → 拒签；N 绿≠AR 过。  
8. **仪表顶窗**：AD 风速仪仍在准用期内，外包想免做燃油/通风窗 → 拒签；AD 只支撑设备准用，不顶 AR 窗。  
9. **旁路联锁 / 不安全泄油**：有人想旁路风机联锁消高温，或泄油消液位告警 → **禁**；挂整改 + N/R；本期未实测不得签准用。  
10. **风路变更未走 J**：私自改进风百叶或排烟路由未走变更 → 补走 J，触发再验 AR；未闭前禁签准用。  
11. **高温窗抬功率**：油机高温/低油位告警一片，网优想抬功率压掉话 → **禁功率战**；先 N 后 AR；上行更脆先问秩序。  
12. **群泄密**：宣传岗把真实油机房编号与油箱序列号发群表扬 → L3 违规，撤帖脱敏重发；治理勾 AR-治。
