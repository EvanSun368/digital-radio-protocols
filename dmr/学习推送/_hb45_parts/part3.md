## 8. 术语表（本篇约 18 词）+ 易错观念

| 词 | 本篇用法（教学） |
|----|------------------|
| **AR** | 本篇贴纸：通风·排烟·燃油安全边界 |
| **AR-风** | 柴油发电机房通风/燃烧空气台账 |
| **AR-排** | 排烟与废气边界主人与方法/准用期 |
| **AR-燃** | 燃油与日用油箱巡检窗与方法 |
| **AR-验** | 本组本机房本期实测、会签 |
| **AR-治** | 假绿、顶替、旁路联锁、不安全泄油、功率战、泄密治理 |
| **通风 / 燃烧空气** | 进风、冷却风、发动机燃烧用空气风路角色（教学；编号脱敏） |
| **排烟 / 废气边界** | 排烟路由、终端、防回灌/短路核对；**不等于**排烟口看着开着 |
| **日用油箱 / 燃油窗** | 日用（日柜）油箱与按本网授权的书面巡检窗；**不等于**液位看着有油 |
| **围堰 / 通气** | 泄漏围堵与油箱通气检查角色（方法以本网为准） |
| **风机绿灯≠通风合格** | 风机指示灯绿不等于风路按窗实测合格 |
| **口开着≠废气边界过** | 排烟口开着不等于废气边界核对过 |
| **看着有油≠燃油巡检过** | 液位看着有不等于燃油安全巡检过 |
| **AF 过≠AR 过** | 油机市电切换过不等于通风燃油准用过 |
| **AL 过≠燃油日用油箱过** | 气灭疏散过不等于燃油日用油箱巡检过 |
| **假绿** | 风机/监控/液位绿但无本期秩序实证；挂 R |
| **套票** | 套他站他期曲线/照片当本期 |
| **功率战** | 用抬功率压告警/压掉话；油机异常窗也禁止 |
| **L3** | 脱敏等级：禁真实频点/站名/全称/油机油箱序列号全文/单位名/联系人/未脱敏油箱参数公开传播 |
| **AF / AL / N / AD / R / J** | 油机市电 / 气灭疏散 / 风暴 / 仪表准用 / 假绿 / 变更——指针，不重写 |
| **十字风燃钉** | 风、排、窗、燃、房、测、签、闭、密、界 |

**易错观念**  
- ✗ 风机绿灯 = 通风合格 → ✓ 要有账、本期实测。  
- ✗ 排烟口开着 = 废气边界过 → ✓ 要有主人、边界、方法、准用期、本期核对。  
- ✗ 油箱看着有油 = 燃油安全巡检过 → ✓ 要有书面窗与泄漏通气围堰方法。  
- ✗ AF 过 / AL 过 / N 绿 = AR 过 → ✓ AF / AL / N ≠ AR。  
- ✗ 邻站照片能用 → ✓ 套票拒签。  
- ✗ 高温告警先抬功率 / 旁路联锁消铃 / 不安全泄油 → ✓ 先 N 后 AR，禁功率战，禁旁路联锁，禁不安全泄油。  
- ✗ 气灭过可以顶燃油日用油箱 → ✓ 各开各的窗；AL≠AR。  
- ✗ 油机市电签可以顶通风燃油签 → ✓ AF≠AR。

## 9. 自测（12 题）+ 参考答案

1. 贴纸 AR 的五个子类是什么？口诀是哪一句？  
2. 「风机绿灯就能签」违反哪条硬规则？属哪个子类？  
3. 八条硬规则里，哪一条要求排烟与废气有主有界有方法/准用期？  
4. 排烟口开着、油箱看着有油，能否代替废气边界过、燃油巡检过？为什么？  
5. 用 AF 油机市电签或 AL 气灭签或 N 监控签顶本期通风燃油签，对不对？应如何处置？  
6. 套邻站通风/油箱照片改机房号，属哪类问题？主贴谁？  
7. 通风/排烟/燃油异常风暴，应先贴什么？能不能抬功率？能不能旁路风机联锁？能不能不安全泄油？  
8. 改风路或排烟路由或油箱策略未走变更，应补什么贴纸路径？  
9. AD 风速仪仍在准用期内，能否免做 AR 巡检窗？  
10. 医院手术室/ICU 保供电机房故事里，「风机绿≠通风合格」「口开着≠废气边界过」「看着有油≠燃油巡检过」分别对应 AR 的哪几段？AR 与 AF、AR 与 AL、AR 与 N 怎么分？  
11. 十字风燃钉是哪十字？哪几项几乎不可砍？  
12. 本篇 L3 禁写哪些？旁路风机联锁/不安全泄油/功率战/套票允不允许教？

### 参考答案

1. 风 / 排 / 燃 / 验 / 治；口诀：**风路有账，排烟有界，燃油有窗，会签才放。**  
2. 规则1；AR-风。  
3. 规则2。  
4. 不能。口开着≠废气边界过；看着有油≠燃油巡检过；需主人、边界/窗、方法、准用期、本期实测（AR-排/燃/验）。  
5. 不对。拒签；主贴 AR；假绿/顶替可挂 R。AF≠AR；AL≠AR；N≠AR。  
6. 套票（AR-验）；主贴 AR，拒签重测。  
7. 先 N 理风暴；**禁功率战**；**禁旁路风机联锁**；**禁不安全泄油**；缺通风燃油秩序整改主贴 AR。  
8. 走 **J** + 再验 **AR**。  
9. 不能。AD 只支撑设备准用，不顶 AR 窗。  
10. 风机绿≠通风合格 → AR-风；口开着≠废气边界过 → AR-排；看着有油≠燃油巡检过 → AR-燃。AF = 油机市电切换与供电巡检；AL = 气灭疏散联锁；N = 对时与告警风暴；AR = 柴油发电机房通风排烟与燃油安全边界。AF 过≠AR 过；AL 过≠燃油日用油箱过；N 绿≠AR 过。  
11. 风、排、窗、燃、房、测、签、闭、密、界；几乎不可砍：**通风台账 + 排烟边界方法 + 燃油窗方法 + 本组本机房本期实测 + 会签**。  
12. 禁真实频点/站名/机房全称/油机油箱序列号全文/单位名/联系人/未脱敏油箱参数公开传播；**不教**旁路风机联锁/不安全泄油/功率战/套票。

## 11. 收束：你今天带走什么；下一篇候选

### 11.1 带走的钉子
- 贴纸 **AR** 五子类：风 / 排 / 燃 / 验 / 治——双字母续写的第十八张，负责通风排烟·燃油安全「台账清不清、排烟有没有界、燃油有没有窗、本期过了没有」。  
- 故事：医院手术室/ICU 保供电机房备用柴油发电机房——风机绿灯≠通风合格；排烟口开着≠废气边界过；油箱看着有油≠燃油安全巡检过；AF 油机市电签≠通风燃油准用；AL 气灭过≠燃油日用油箱过；N 监控绿≠本期实测过；套邻站照片=拒签；AF/AL/AG/AP/AI/AO/AN/AD/AA/N/AQ 不顶替 AR；假绿≠会签放行。  
- 阶段梯：建通风台账 → 钉排烟边界 → 燃油窗钉死 → 本期实测 → 会签放行 → 变更再验。  
- 八条硬规则：**通风/燃烧空气台账钉死**；**排烟与废气有主有界有方法/准用期**；**燃油与日用油箱巡检窗与方法钉死**；**本组本机房本期实测禁套他站他期**；**会签才放行「通风排烟/燃油安全准用」**；**禁顶替 AF/AL/AG/AP/AI/AO/AN/AD/AA/N/AQ 等，主贴 AR，假绿≠放行挂 R**；**通风/排烟/燃油异常风暴挂 N、风路/排烟路由/油箱策略变更走 J、禁功率战、禁旁路风机联锁、禁不安全泄油**；**脱敏 L3**。  
- **AR vs AF**：AF = 油机市电切换与供电巡检；AR = 油机房通风台账 + 排烟废气边界 + 燃油日用油箱窗 + 本期实测 + 会签；AF 过 ≠ AR 过。  
- **AR vs AL**：AL = 气灭与应急疏散联锁；AR = 燃油与日用油箱安全巡检边界；AL 过 ≠ 燃油日用油箱过。  
- **AR vs N**：N = 电源监控/对时/告警风暴；AR = 通风排烟燃油巡检边界；N 绿 ≠ AR 过。

### 11.3 给带新人的三句话
1. 通风不是风机绿就能签：风路有账，本期实测钉死。  
2. 排烟不是口开着就算过、燃油不是看着有油就算过：主人边界方法准用期，燃油窗油位泄漏通气围堰，本期实测会签才算准用。  
3. 假绿挂 R；主贴 AR；AF/AL/N 不顶替；异常窗禁功率战禁旁路联锁禁不安全泄油；公开脱敏 L3。
