## 1. 为什么要写这篇手册（动机 + 现场对话）

前三十五篇手册从 A–E 协议一路写到 AH 合路界面：其中 **AF 回答「油机/市电切换与机房供电巡检」**，**AA 回答「交维后首年巡检」**，**AG 回答「电池与充电器梯队抽检」**，**N 回答「电源监控/对时/告警风暴」**，**AH 回答「多业主合路/POI 机房责任界面」**。可还没有单独钉死一件事——**机房不是「感觉不热就能签环境过」：温湿度测点与采集频率要钉死；精密空调/联锁要有主人有准用期；联锁巡检窗与方法要书面固定；本组本机房本期实测禁套他站他期——能不能签「温湿度/联锁准用」？** 这就是本篇的 **AI**——**机房温湿度与空调联锁巡检边界**。

- 运维岗：「机房摸着不烫，温湿度肯定过。」——**无温湿度台账/测点仍准用** = 本篇拒签（规则1）。  
- 物业：「空调谁修口头说一声，联锁谁管也口头。」——**空调联锁无主人无准用期** = 规则2。  
- 网优：「环境监控全绿，不用做联锁巡检了。」——**只看网管绿，无联锁巡检窗/方法** = 规则3。  
- 外包：「邻站上周温湿度曲线参数差不多，拷过来改个机房号。」——**套他站他期** = 规则4。  
- 班长：「AF 供电签还在，AA 首年巡检也过了，温湿度联锁也能签。」——**用 AF/AA/AG 顶替 AI** = 规则6。  
- 站务：「大屏温湿度绿了，联锁准用就算过。」——**假绿≠会签放行** = 规则5/6。  
- 网优：「高温告警响了，功率抬一点稳住。」——**功率战** = 规则7。  
- 宣传岗：「把真实机房编号、空调序列号、温湿度曲线发群表扬。」——**L3 违规** = 规则8。  

这几句背后是同一件事：

> **「机房温湿度与空调联锁巡检」在现场至少有五个坑**：**① AI-温** 温湿度台账与测点位置、采集频率、报警门限角色入账，禁「感觉不热就算过」；**② AI-湿** 湿度侧与精密空调/加湿除湿本体有主人、有准用期（滤网/加湿罐/传感器校准期），禁口头「谁管谁修」；**③ AI-联** 联锁巡检窗、方法（主备切换/传感器比对/联锁动作观察等角色项）、到场角色书面固定，禁「看一眼环境绿」；**④ AI-验** 本组本机房本期实测（禁套他站他期曲线），会签才放行「温湿度/联锁准用」；**⑤ AI-治** 治理（假绿、用 AF/AA/AG/N 顶替、伪造环境账、功率战、旁路联锁、泄密）。  
> 把 ①–⑤ 当成「感觉不热就能签」「网管绿就算联锁过」「口头说一声谁管空调」，每一次换精密空调、每一次改采集频率、每一次高温告警风暴，都会先吵「测点是谁的、联锁谁负责、曲线是不是本期的」。

本篇目标：能背出**温湿度台账 + 空调联锁巡检工作流**；会用新贴纸 **AI（温 / 湿 / 联 / 验 / 治）**；会填**插页 AI（AI1–AI8）**和《本网机房温湿度与空调联锁巡检台账卡》；能用「**医院手术室/药库温湿度联锁 + 机房精密空调联锁巡检**」故事讲清感觉不热≠台账过、网管绿≠联锁过、套邻站曲线=拒签、用 AF/AA/AG 签顶 AI 联锁签=拒签、假绿≠会签放行；能拒绝无主联锁、套曲线、用他贴顶替本期温湿度签、假绿放行；自测过关后，回库把本网最近一次机房温湿度巡检或空调联锁演练（L3）重对一遍：温湿度账、联锁主人、巡检窗、本期实测、会签项、拒签项。

## 2. 总图 / 故事：机房温湿度联锁像「医院手术室/药库温湿度联锁——不能只摸额头」

### 2.1 一句话：感觉机房不热不是「温湿度过了」、网管环境绿不是「联锁过了」——要先建温湿度台账与测点，空调联锁有主人有准用期，联锁巡检窗与方法钉死，本组本机房本期实测，会签才放行；假绿、套邻站曲线、用 AF/AA/AG 顶替、旁路联锁，一律拒签

```text
   ┌──────────────────────────────────────────────────────────────┐
   │  医院手术室/药库温湿度联锁 + 机房精密空调联锁巡检  =  本网 AI │
   │                                                              │
   │  测点入账·采集频率·报警门限钉死   ≈ AI-温  温湿度台账钉死   │
   │  加湿除湿/精密空调有主人有准用期 ≈ AI-湿  空调联锁有主有期 │
   │  联锁巡检窗·方法·到场角色钉死     ≈ AI-联  联锁巡检窗与方法 │
   │  本期实测禁套邻院/邻站曲线       ≈ AI-验  本组本机房本期   │
   │  假绿≠放行·顶替·伪造账·功率战   ≈ AI-治  治理与脱敏 L3     │
   └──────────────────────────────────────────────────────────────┘
```

口诀：

> **温湿度有账，联锁有主，巡检有窗，本期实测，会签才放。**  
> 感觉不热还无测点台账 = 手术室只摸额头不看温湿度记录——**拒签「温湿度/联锁准用」**。  
> 环境监控全绿但半年没联锁巡检 = 药库绿灯亮着却从未做温湿度联锁抽检——**假绿，挂 R，拒签**。

### 2.3 和手册33（AF）/ 28（AA）/ 34（AG）/ 15（N）/ 31（AD）等的咬合（指针，不重写）

- **AF（手册33）**：油机/市电**切换与机房供电巡检**；供电过≠温湿度联锁过——**AF 管供电，AI 管温湿度与空调联锁**。  
- **AA（手册28）**：交维后**首年巡检**日历；抽检环境可挂 AA，缺温湿度/联锁秩序整改主贴仍 AI。  
- **AG（手册34）**：电池梯队；机房过热过湿伤电池寿命——**环境异常常挂 AG 看电池，但主贴环境联锁仍 AI**。  
- **N（手册15）**：监控/**对时**/告警风暴；高温/高湿告警风暴挂 N 理风暴，**不先抬功率**；N 绿≠ AI 联锁过。  
- **AD（手册31）**：温湿度计、校准仪入库走 AD；**不能**用旧 AD 签日期顶本期 AI 窗。  
- **R / J**：假绿挂 R；变更（换精密空调、改采集频率、改联锁阈值）走 J。

### 2.5 建温湿度账 → 钉空调主人 → 联锁窗钉死 → 本期实测 → 会签放行 → 变更再验 阶段梯（背下来）

```text
  ① AI-温 建温湿度台账：测点角色 · 采集频率 · 报警门限角色 · 禁「感觉不热」
        │  无台账 / 测点未入账 → 不签温湿度/联锁准用
        ▼
  ② AI-湿 钉精密空调/湿度侧主人：主人角色 · 准用期（滤网/加湿/传感器校准）书面
        │  无主人 / 无准用期 → 拒进入「可签」状态
        ▼
  ③ AI-联 钉联锁巡检窗：书面窗 · 方法（主备切换/传感器比对/联锁动作观察等角色项）· 到场角色
        │  无窗 / 无方法 / 「只看绿灯」 → 拒联锁签
        ▼
  ④ AI-验 本组本机房本期实测：温湿度角色项 · 联锁动作角色项 · 禁套他站他期
        │  套曲线 / 只看网管绿 → 拒签
        ▼
  ⑤ 会签「温湿度/联锁准用」或「有条件整改」：本网授权本人签
        │  缺签 / 假绿顶替 → 拒签准用
        ▼
  ⑥ 变更（换精密空调/改采集频率/改联锁阈值）→ 走 J + 触发再巡检/再验（常挂 N 看监控、挂 AF/AG 看供电与电池）
```

> **一句话分辨**：**AF** 回答「供电切换/试车**过了没有**」；**AA** 回答「首年巡检日历**到了没有**」；**AG** 回答「电池梯队抽检**过了没有**」；**AI** 回答「这一机房温湿度测点 + 这一组精密空调联锁 + 这一窗巡检**台账清不清、联锁有没有主、本期过了没有**」。**四个问题，四张（类）贴纸，不能一笔带过。**

### 2.6 温湿度与空调联锁最小工作流（背下来）

```text
  AI-温 温湿度台账 + 测点/频率钉死
       ├─→ 有台账+测点？空调联锁有主人准用期？ ──否──→ 拒签 / 补账补主
       └─→ 是
  AI-联 约窗 + 书面方法 + 到场勾选
       │
  AI-验 本组本机房本期：传感器比对 → 联锁动作观察 → 禁套声明
       │  套曲线 / 只看绿灯 → 拒签
       ▼
  会签「温湿度/联锁准用」或挂整改；重大未闭禁签准用
       │
  放行或拒签；公开材料 L3；变更走 J 再触发
```

## 3. 核心交付：插页 AI + 拒签卡 + 与总三联单怎么写

### 3.1 什么时候贴 AI（而不是先贴 AF / AA / AG / N）

| 现场要办的事 | 主贴 | 说明 |
|--------------|------|------|
| 温湿度台账、空调联锁主人、联锁巡检签、假绿拒签 | **AI** | 本篇主职 |
| 油机/市电切换试车、供电巡检 | **AF**（可挂 AI） | 供电≠温湿度联锁 |
| 交维后首年巡检日历 | **AA**（可挂 AI） | 首年日历≠本期联锁窗 |
| 电池梯队与容量抽检 | **AG**（可挂 AI） | 过热过湿伤电池时常并行；各贴各的 |
| 监控对时、告警风暴 | **N**（可挂 AI） | 环境绿≠联锁过 |
| 大屏环境绿想直接签联锁准用 | **AI-治 + R** | 假绿≠联锁通过 |
| 套邻站旧温湿度曲线 | **AI-治** | 禁套；须本期本组本机房实测 |

### 3.2 插页 AI · 温 / 湿 / 联 / 验 / 治（挂在总三联单或环境/联锁单后）

| 插页行 | 检查项（教学） | 缺了怎么办 |
|--------|----------------|------------|
| **AI1** | 温湿度台账在：测点角色、采集频率、报警门限角色书面 | 缺 → **拒签准用** |
| **AI2** | 测点清单可追溯：位置角色、主备传感器角色、最近校准日角色 | 缺 → **拒「感觉不热就算过」** |
| **AI3** | 精密空调/加湿除湿有主人：主人角色；准用期（滤网/加湿罐/传感器）书面 | 缺 → **拒签** |
| **AI4** | 联锁巡检窗书面在（日期角色/天窗角色）；方法（主备切换/传感器比对/联锁动作等角色项）书面；到场角色勾选 | 缺 → **拒联锁签** |
| **AI5** | 本组本机房本期实测记录在；脱敏机房与窗一致；禁套他站他期 | 套/缺 → **拒签** |
| **AI6** | 温湿度计/校准仪在 AD 准用期内（挂 AD 指针）；条件角色项按本网规程记录 | 仪表过期 → **拒认测值或整改** |
| **AI7** | 「温湿度/联锁准用」会签：相关授权本人签；重大未闭禁准用 | 缺签 → **拒签** |
| **AI8** | 公开材料 L3；变更项走 J；禁功率战、禁旁路联锁叙事 | 违 → **治理** |

> 插页每一行都对应硬规则：AI1/AI2→规则1，AI3→规则2，AI4→规则3，AI5/AI6→规则4，AI7→规则5，顶替/假绿→规则6，AI8→规则7/8。**任何一行缺项，就停在那一行。**

### 3.3 和总三联单怎么写（接手册06）

- **现象栏**：写「温湿度台账断档 / 联锁无主 / 联锁未实测 / 套他站曲线 / 网管假绿 / 旁路联锁嫌疑」等可复核现象，**不写空口玄学**。  
- **贴纸栏**：主贴 **AI**；支撑可贴 AF / AA / AG / N / R / J / AD / AH。  
- **处置栏**：拒签 / 补温湿度账 / 补空调主人 / 重开联锁窗 / 重测 / 挂 R/N/J——**写动作，不写空口字段**。  
- **脱敏**：机房/空调用角色编号；禁单位名全文、禁真实站名。

### 3.4 《本网机房温湿度与空调联锁巡检台账卡》预告

§7 给出可复印模板：封面拒签门槛、温湿度页、空调主人页、联锁窗页、实测页、会签准用页、夜班速填五行。**一张卡跑完一窗联锁巡检/一次换空调后复验：温→湿→联→验→签**；与 AF 供电、AA 首年、AG 电池指针对齐，避免「供电签还在就当温湿度过」「首年绿就当联锁过」「电池抽检绿就当环境清」。
